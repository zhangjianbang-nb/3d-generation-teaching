一 · 旧窑边的泥团

陶艺村最里面那间旧窑，窑门上的铁栓早就锈死了，推起来会发出一声长长的、像老人清嗓子的吱呀。窑膛里常年积着半指厚的窑灰，风一吹，灰就贴着地面打旋，带着一股烧过的土腥味。窑边靠墙堆着一排没人要的坯料，最靠里的那块黏土，村里人叫它小泥。 小泥没有五官，没有底座，正面看勉强能认出一只小猫的轮廓——两只尖耳朵，一条尾巴尖，可你只要往侧面挪半步，它就塌成一摊泥，边缘还带着手捏时留下的指印。它自己也知道这件事，因为它每天都被村里的孩子从不同角度打量，孩子们绕着它走一圈，嘴里念叨：“猫……泥……猫……泥……”像在数拍子。 老陶匠姓周，手上全是裂口，指甲缝里嵌着洗不掉的赭石色。他每天清晨来窑边翻坯，顺手把小泥往墙根推一推，免得它挡路。小泥不会说话，但它有个愿望，硬邦邦的，像坯里没揉开的气泡：让自己从任何一个角度看，都像一个真东西。 那天下午，周师傅蹲在窑门口抽烟，烟锅里的火星一明一灭。小泥的影子被斜阳拉得很长，从正面看是猫，从侧面看是一道歪歪扭扭的泥条。周师傅用烟锅点了点它：“你想被从四面八方看，就得先学会‘被看见’这件事。” 小泥不懂。它只知道一件事：它只会一个姿势。 天黑前，村里来了个背相机的年轻人，姓陈，在窑边支起三脚架，说要给村里的老物件拍一组“数字档案”。他围着小泥转，快门咔嚓咔嚓，每拍一张就低头看屏幕，嘴里嘟囔：“这个角度……嗯，这个角度它又不像猫了。” 小泥听着快门声，忽然觉得那声音像在给它量体温。它做了一个决定——这是它第一次抉择，虽然它自己都没意识到那算抉择：它不打算再靠捏、靠削、靠一个固定姿势去讨好某个角度了。它要让相机替它看，让每一张照片告诉它“你从这个角度应该长什么样”。 陈先生拍完最后一张，天已经擦黑，窑边的灯泡亮起来，黄黄的一团。他把照片导进笔记本，屏幕的光映在他脸上。小泥凑过去——它没有眼睛，但它能感到那些像素在发烫。它第一次听见一个词：渲染。 “你这不是建模，”陈先生对周师傅说，“你这是……一堆视角。要是能把这些视角反推回一个三维的东西，它就能从任意角度看都对。” 小泥把这句话记下了。它不知道什么叫“反推”，但它知道，它要变成一团能被相机走进去的东西。

工匠笔记

- 场景里的“相机围着小泥拍一圈”，对应的是多视角 2D 照片作为监督信号：每一张照片只说“你从这个角度应该长什么样”，不说“你内部是什么结构”。 - 小泥“只会一个姿势、侧面塌成泥”，对应的是单视角表示的根本缺陷：没有跨视角一致性，换个角度就露馅。 - 陈先生说的“把视角反推回三维”，对应可微渲染的核心思路：渲染是从 3D 到 2D 的正向过程，把像素误差反传回 3D 参数，就能用 2D 监督 3D。 - “快门像量体温”这个细节，映射的是渲染—比对—更新的闭环：每次拍摄都是一次测量，误差是唯一的老师。 - 这个类比哪里不像：真实的可微渲染不是“反推照片”，而是优化一个参数化的 3D 表示去拟合照片；照片本身不含深度，反推是病态的，必须靠表示的先验和正则来约束。

二 · 雾里的第一世

小泥的第一次投胎，选了一条最笨的路。 它把自己交给陈先生的相机，让相机围着它拍了一百张照片。每拍一张，相机就说：“从这个角度看，你应该是这样。”小泥没有骨架，没有表面，它把自己变成一团看不见的雾——空间里每一个点都有一个密度和一个颜色。密度大的地方，雾就浓；密度小的地方，雾就稀。相机沿着一条射线走进雾里，把沿途的密度和颜色一点一点累加起来，就画出一个像素。 它学会了体渲染。它不是被“建模”出来的，而是被“积分”出来的。 那三天是小泥最快活的三天。从左边看，是猫；从右边看，是猫；从上面看，还是猫。孩子们绕着它走，不再念“猫……泥……”，而是“猫、猫、猫”。周师傅蹲在窑门口，烟锅停在嘴边，看了很久，说了一句：“这回像了。” 可第四天，陶艺村搬来一个新场景。村东头要摆一个集市，陈先生把相机架到集市口，让小泥也去“看一眼”。小泥去了，然后它傻了——它不会。它没有记住“猫”，它只记住了“这一个场景的雾”。窑边那团雾的参数，换到集市上，一点用都没有。它得从头学起。 更难受的是慢。每次渲染，相机要沿着射线采几十上百个点，一个像素一个像素地积。小泥算一帧，慢得像老牛拉磨，陈先生的笔记本风扇呼呼地转，屏幕上的进度条像蜗牛爬。小泥蹲在窑边，听见窑灰落在地上的声音，一粒一粒，比它的渲染还快。 它第一次明白：可微渲染能让你被看见，但“一个场景一个模型”的身体，太贵、太慢、太不通用。 那天夜里，周师傅把烟锅在鞋底磕了磕，说：“你这不是不会变，你是把整个身子都用来记一个场景了。记性太好，反而走不动。” 小泥没吭声。它心里有个声音在问：能不能把“记细节”这件事，从脑子里挪出去？

工匠笔记

- 小泥“变成一团雾、每个点有密度和颜色”，对应 NeRF 的辐射场表示：一个 MLP 拟合 5D 输入（位置 + 视角）到密度与颜色的映射。 - 相机“沿射线走进雾里、把密度和颜色累加成一个像素”，对应体渲染积分；因为积分对参数可微，2D 照片的像素误差才能反传回 3D。 - “换到集市就从头学”，对应 NeRF 的逐场景优化：一个场景一个模型，不共享、不通用，场景一变就得重训。 - “采几十上百个点、慢得像老牛拉磨”，对应体渲染的采样开销：渲染慢是这条路线的硬代价。 - 这个类比哪里不像：NeRF 的“雾”不是真的无定形，它由 MLP 参数化，有平滑先验；真实系统还会用分层采样、重要性采样来减少采样点，不是纯靠蛮力。

三 · 十六层书架

小泥受不了三天一学。它跑到村里的图书室，管理员是个戴眼镜的老头，大家叫他哈希先生。图书室不大，书架却排得很密，空气里有旧纸和樟脑丸混在一起的味道。 哈希先生不给它大脑瓜，而是给了它十六层书架。第 1 层格子很大，一格能装下一整条街的轮廓；第 16 层格子很小，一格只装得下一个耳朵尖。每一层书架上的每个格子都有一个抽屉，抽屉里放着两个数字。 “你要查一个点，”哈希先生推了推眼镜，“就把这个点在不同分辨率的格子里各查一次，把十六个抽屉的数字拼起来，再问一个小助手‘这团数字是什么意思’。” 小泥试了试。它发现书架不大，抽屉还会“撞车”——两个不同的格子可能被分到同一个抽屉。它有点慌，哈希先生却说：“撞就撞，十六层一起看，撞出来的误差会被平均掉。” 小泥半信半疑地试了。结果两分钟，它就学会了集市那个场景，细节比第一世还清楚。它第一次感到“快”的快乐——那种快乐很具体，像夏天喝到第一口井水，凉得牙根发酸。 但哈希先生也提醒它：抽屉撞得太多，细节会丢；书架多大、几层、每层几个数字，都得按场景调。小泥蹲在书架前，闻着樟脑丸的味道，忽然明白了一件事：把“记细节”的活从大脑瓜转移到可查的表，速度能快一两个数量级；但表是死的，场景一换，表还得重学。 它做了第二次抉择：它不再追求“一个身体记住所有场景”，它接受“身体可以换，表可以重学”。这是它第一次对“通用”这件事松手。

工匠笔记

- “十六层书架、每层格子大小不同”，对应多分辨率哈希编码：不同分辨率存不同尺度的细节，粗层记大局，细层记局部。 - “每个格子一个抽屉、抽屉里两个数字”，对应哈希表里存的特征向量；查一个点就是在各分辨率上查表再拼接。 - “抽屉撞车、十六层一起看把误差平均掉”，对应哈希冲突：不同格点可能映射到同一槽位，多分辨率叠加让冲突的影响被稀释。 - “书架大小、层数要按场景调”，对应 Instant-NGP 的超参数敏感性：哈希表容量、层数、每层特征维度都是按场景调的。 - 这个类比哪里不像：哈希编码只是把“查表”做成可学习的特征网格，真正把特征解码成密度和颜色的仍是一个小 MLP；它不是纯查表，表本身也是训练出来的。

四 · 萤火虫显影店

小泥想要“实时”。 它走进一家没有灯的店，店里飞着几百万只萤火虫。空气里有一股淡淡的、像雨后被翻开的泥土的气味。店主是个瘦高个，说话很轻：“别做雾了，做萤火虫吧。每只萤火虫有位置、朝向、大小、透明度和颜色；它们投影到屏幕上，按远近排好队，从前往后叠，就能显影。” 小泥把自己拆成萤火虫。第一只落在猫耳朵上，第二只落在尾巴尖，第三只落在胡须……每只萤火虫都是一个被拉长的椭圆光斑。相机一来，它们先投影到屏幕，按深度排序，然后一只一只往像素上叠：前面的挡住后面的，半透明的让后面的透一点。 小泥第一次在 1080p 下跑出一百多帧，快得让它自己都吓了一跳。店里没有灯，但屏幕上亮得像白天。 可萤火虫太多了。场景越复杂，萤火虫越多，显存越吃紧；透明的玻璃、反光的金属，萤火虫也叠不干净。店主说：“你可以让它们生小萤火虫，也可以让没用的萤火虫熄灭，但总数还是会涨。” 小泥做了第三次抉择：它接受“显式基元 + 光栅化能换实时”，也接受“显存是硬代价”。它不再幻想一种又轻又快的身体，它开始学着在“快”和“装得下”之间做取舍。 那天夜里，它蹲在店门口，听见远处窑火的噼啪声，忽然觉得萤火虫的光有点像窑火——都是一粒一粒的，都是一闪一闪的，区别只在于一个烧的是土，一个烧的是显存。

工匠笔记

- “几百万只萤火虫，每只有位置、朝向、大小、透明度、颜色”，对应 3D 高斯：每个基元带协方差（朝向与大小）、不透明度、球谐颜色。 - “投影到屏幕、按深度排序、从前往后叠”，对应高斯的投影与光栅化：投影协方差，按深度排序后做 alpha 混合。 - “前面的挡住后面的，半透明的让后面的透一点”，对应 alpha 混合的透射率累积。 - “生小萤火虫 / 熄灭没用的萤火虫”，对应致密化与剪枝：按梯度与不透明度动态增删基元。 - 这个类比哪里不像：真实 3DGS 的排序不是每帧全量精确排序，而是按 tile 分块做近似排序；透明与反光仍是它的弱项，不是“叠不干净”这么简单。

五 · 模子师傅的零等值面

小泥虽然快，但表面还是一团雾。它想要一个“摸得着”的身体。 村里有位模子师傅，专做石膏模，院子里堆着半人高的石膏块，空气里飘着细细的白粉。师傅说：“你别记密度，记距离。空间里每个点到最近表面的距离，外面是正，里面是负，表面是零。把距离过一道 S 形门，变成密度，再去体渲染；零等值面就是你的皮肤。” 小泥照做。它发现，距离场有个脾气：梯度长度必须等于 1，否则它就不是真正的距离。师傅管这叫 Eikonal 正则，每天拿尺子量它的梯度。小泥还被要求把“表面锐度”从大调到小：一开始模子很厚，后来越来越薄，最后皮肤又薄又干净。它第一次提取出没有毛刺的网格。 但薄的东西难做：一片叶子、一根电线，距离场在薄结构两侧跳得太快，锐度一小就噪；不闭合的表面，内外分不清，模子会漏。小泥做了第四次抉择：它接受“SDF 能给干净表面”，也接受“薄结构、非闭合、训练慢仍是软肋”。它不再追求“一种身体包打天下”，它开始按任务挑身体。 周师傅来看它，用指甲在它表面划了一下，说：“这回摸得着了。”小泥没说话，但它知道，摸得着和看得见，是两件事。

工匠笔记

- “记距离而不是记密度，外面正、里面负、表面零”，对应 SDF：零等值面即表面。 - “距离过一道 S 形门变成密度，再去体渲染”，对应 NeuS 的 σ = αΨ_β(−f)：把 SDF 转成密度，让 alpha 在零等值面附近达到峰值。 - “梯度长度必须等于 1，师傅拿尺子量”，对应 Eikonal 正则：约束距离场是真正的距离场。 - “锐度从大调到小，模子从厚变薄”，对应 β 的退火：从粗到细，最后得到干净表面。 - 这个类比哪里不像：SDF 的“距离”是网络学出来的近似，不是解析距离；薄结构和非闭合表面仍是难点，Eikonal 正则也不能完全保证全局正确。

六 · 偷看画师做梦

小泥想要“文本变 3D”。可村里没有 3D 老师，只有一位画师，整天在梦里画 2D 图。画师做梦时，嘴里念叨：“一只孔雀站在冲浪板上。” 小泥没有 3D 数据，只能偷看画师的梦。它先把自己捏成一团乱雾，渲染出一张 64×64 的小图；把图弄脏，送进画师的梦里，问：“你觉得这团噪声应该是什么？”画师给出一个答案。小泥把“画师的答案”和“真实的噪声”相减，得到一条更新方向：往画师觉得更像孔雀的方向走。它把这条方向乘以“渲染对 3D 参数的雅可比”，就能更新自己的雾。 这就是 Score Distillation Sampling。 小泥走了很多步，花了很久，终于长出了孔雀和冲浪板。可它一转背面，发现孔雀有两张脸——每个视角都独立地做梦，梦与梦之间没有商量，于是正面、背面、侧面各长各的。它还发现颜色过饱和、纹理粘在一起。 小泥做了第五次抉择：它接受“2D 先验能凭空造 3D”，也接受“多面和过饱和是这套方法的胎记”。它不再幻想“一次做梦就全对”，它开始学着让梦与梦之间互相听。

工匠笔记

- “画师在梦里画 2D 图、小泥偷看”，对应预训练 2D 扩散模型作为先验：它只在 2D 上见过世界，没有 3D 数据。 - “把图弄脏送进梦里问答案，答案减噪声得到更新方向”，对应 SDS：用扩散模型的 score 构造更新方向。 - “方向乘以渲染对 3D 参数的雅可比”，对应把 2D 梯度通过可微渲染反传到 3D 参数。 - “每个视角独立做梦、正面背面各长各的”，对应 SDS 的多面问题：没有跨视角一致性约束。 - 这个类比哪里不像：SDS 不是真的“问画师答案”，而是用扩散模型的噪声预测构造一个代理梯度；它本身不保证几何正确，过饱和是已知副作用。

七 · 多视图合唱团

小泥受够了“每个视角各做梦”。它请来一个合唱团。 第一位歌手能看着一张参考图，唱出任意新视角；第二位让四位歌手站成一圈，唱的时候互相听，谁跑调就拉回来；第三位更夸张，让十六位歌手共享一本 3D 总谱，每个人唱之前先看总谱，唱完再把声音写回总谱；第四位还加了一个“法线声部”，用几何的调子约束颜色的调子。 合唱团确实一致多了。小泥从正面转到背面，耳朵还是那只耳朵，尾巴还是那条尾巴。可合唱团也会“串词”：遇到没见过的背面，歌手们会一起幻想出一个合理但错误的细节——比如猫的后脑勺长出了一朵花。 小泥做了第六次抉择：它接受“多视图一致性可以用共享注意力、共享 3D 体积、共享法线来换”，也接受“一致性不等于真实，背面仍是合理幻想”。它不再把“一致”当成“正确”，它开始学着在“合理”和“真实”之间留一条缝。

工匠笔记

- “看着参考图唱任意新视角”，对应 Zero-1-to-3：把相对位姿注入 2D 扩散，做新视角生成。 - “四位歌手站成一圈互相听”，对应 MVDream：用跨视角自注意力一次生成多视图，保证彼此一致。 - “十六位歌手共享一本 3D 总谱”，对应 SyncDreamer：共享 3D 体积，唱前看总谱、唱完写回。 - “法线声部约束颜色声部”，对应 Wonder3D：用几何（法线）约束外观，提升一致性。 - 这个类比哪里不像：多视图模型的一致性来自训练分布，不是真正的 3D 推理；没见过的背面仍是“合理幻想”，不是真实观测。

八 · 大工厂的一次前向

小泥最后走进一座大工厂。工厂门口写着：“一次前向，出 3D。” 它把一张图递进去，流水线先让一个巨人把图切成 token，用 Transformer 变成三平面；三平面再渲染出多视角，和真值比对。巨人说：“我不需要对你单独优化，我见过很多物体，一次前向就能猜出你的三平面。”小泥第一次感到“被理解”——不是被拟合，而是被先验猜中。 流水线继续往前走。有的环节把速度压到半秒；有的把输出换成高斯，渲染实时；有的把三平面换成稀疏体素，一套潜变量能解成高斯、网格或辐射场；有的把形状与纹理拆成两个 DiT，再加 PBR 三通道；有的做快速 UV 展开与 delighting；有的把稠密网格重拓扑成艺术家级网格；有的把整体拆成多个部件。 质检员在出口拦住小泥：“你有 UV 吗？有 PBR 吗？拓扑能动画吗？” 小泥做了第七次抉择：它接受“前馈大模型能规模化生产”，也接受“出厂前要过质检”。它不再把“生成”当成终点，它开始学着把“能进引擎”当成终点。

工匠笔记

- “一次前向、图切成 token、Transformer 变三平面”，对应前馈 3D 大模型：LRM 类方法用 Transformer 一次前向预测三平面。 - “三平面渲染多视角、和真值比对”，对应训练时的多视图渲染监督。 - “输出换成高斯 / 稀疏体素 / 网格”，对应不同前馈模型的输出表示：GS-LRM、TRELLIS、MeshAnything 等。 - “形状与纹理拆成两个 DiT、PBR 三通道”，对应 Hunyuan3D 2.x 的几何与纹理分离、PBR 材质。 - “质检员问 UV / PBR / 拓扑”，对应 UV/PBR/拓扑检查：资产能不能进引擎、能不能重光照、能不能动画。 - 这个类比哪里不像：前馈模型不是“见过很多物体就懂你”，它的泛化受训练分布限制；一次前向的输出仍需后处理与质检，不是即插即用。

九 · 会换身体的泥

七次投胎之后，小泥不再问“哪一种身体最好”。 它把七种身体排成一排：雾适合照片级重建，书架适合快速拟合，萤火虫适合实时，模子适合干净表面，偷梦适合没有 3D 数据的文本生成，合唱团适合单图补背面，工厂适合规模化生产。 老陶匠问它：“那你现在是什么？” 小泥说：“我是一块会换身体的泥。任务要实时，我就变萤火虫；任务要干净表面，我就变模子；任务要文本，我就去偷梦；任务要进引擎，我就去工厂排队。” 但它也知道自己还没有真正“活”：它不会动，不会疼，不会在物理世界里被推倒再爬起来。它听说远处有一座“世界工厂”，能把房间变成可漫游的世界，能给物体装上弹性与重量。小泥望着那座工厂，决定开始第八次投胎——这一次，它想成为一个有物理、有场景、有交互的“地方”，而不只是一个被看见的“东西”。 窑边的灯还亮着，黄黄的一团。周师傅把烟锅在鞋底磕了磕，没说话。小泥蹲在墙根，听见窑灰落在地上的声音，一粒一粒，像在数它还没走完的路。

工匠笔记

- “七种身体排成一排、按任务挑”，对应七类表示/路线：NeRF、哈希编码、3DGS、SDF/NeuS、SDS、多视图扩散、前馈大模型。 - “任务要实时变萤火虫、要干净表面变模子”，对应真实系统常按任务混合使用不同表示，而不是单一表示包打天下。 - “不会动、不会疼、不会被推倒”，对应静态 3D 资产的局限：没有物理、没有交互、没有场景级世界模型。 - “第八次投胎想成为‘地方’”，对应从“物体生成”走向“场景/世界生成”的方向。 - 这个类比哪里不像：七种身体不是互斥的，真实管线常把 3DGS 做渲染、SDF 做表面、前馈模型做初始化；故事把它们排成一排，是为了让读者看清每条路的代价，不是工程配方。
