一 · 把七次投胎摆上桌

陶艺村小学的教室漏风。窗纸糊了三层，风还是从缝里钻进来，吹得挂在梁上的那只旧猫陶响个不停——那是小泥第一次投胎成功后，老陶匠随手捏的纪念品，风一吹，尾巴就晃，像在点头。 阿砚是村里唯一一个既懂陶土又懂代码的年轻人。他被村长叫来，任务很怪：把「小泥的七次投胎」讲给一群工程师听，四十五分钟，最多九十分钟，不许念论文。阿砚答应了，然后坐在窑边发了三天呆。第四天傍晚，他把七块泥坯排在长桌上，每块代表一世。窑火在背后呼呼地喘，热气把桌面烤得发烫，他手指按上去，烫得缩回来——时间压力从这一刻开始。 「你要是照本宣科，」老陶匠蹲在门槛上抽旱烟，「他们听完只记得七个名词，记不住为什么疼。」 阿砚点头。他决定不按时间顺序讲，而是按「身体」讲：每一世小泥换了一副身体，每副身体都有它的脾气。他把七块泥坯翻过来，在底面用炭条写上机制名。 第一块，雾。阿砚捏起它，对着窗光看——泥坯表面粗糙，但他脑子里看见的是第一世的小泥：一团看不见的雾，空间里每个点都有密度和颜色，相机沿射线走进去，把沿途的密度和颜色累加起来，画出一个像素。他对着空教室小声说：「它不是被建模出来的，是被积分出来的。」这句话他练了七遍，因为工程师最容易在这里卡住：他们习惯「先有面，再有图」，而 NeRF 是反的，先有图，再把图反推成一团可积分的雾。 第二块，书架。哈希图书馆的十六层抽屉。阿砚在炭条字旁边画了十六道横线，最上面一道格子最大，最下面一道格子最小。「大局在上，细节在下，」他嘀咕，「查一个点，十六层各查一次，拼起来再问小助手。」他知道工程师会追问「撞车怎么办」，所以提前在桌角放了一小把豆子，准备讲到哈希冲突时撒一把，让豆子撞在一起，再用手一抹：「撞就撞，十六层一起看，误差被平均掉。」 第三块，萤火虫。阿砚从口袋里掏出一只玻璃瓶，里面是他在田埂上抓的十几只萤火虫，夜里一闪一闪。他准备在讲到 3DGS 时把灯关掉，让瓶里的光点在黑暗里浮起来。「每只带位置、朝向、大小、透明度、颜色，」他对着瓶子说，「投影到屏幕上，按远近排队，从前往后叠。」他试过一次，萤火虫在瓶里乱撞，根本排不成队，他笑了：真实萤火虫不听话，但高斯基元听话，因为它们是被优化出来的。 第四块，模子。他从窑边捡了一块石膏模的碎片，边缘锋利，割手。SDF 的零等值面就是这块碎片的表面：外面正，里面负，表面是零。他准备讲 Eikonal 正则时拿尺子量一量碎片的梯度——当然量不出来，但他会做一个动作：把尺子贴在碎片上，说「梯度长度必须等于 1，否则它就不是真正的距离」，让工程师看见「约束」是一个可以被尺子量的东西。 第五块，梦。他找不到道具，就从灶膛里抽出一根烧了一半的柴，炭头还红着。SDS 是偷看画师做梦：渲染一张小图，弄脏，送进梦里问「这团噪声应该是什么」，把答案和真实噪声相减，得到更新方向。他把炭头在桌上画了一道黑线：「梦没有 3D，只有 2D 的判断；小泥借这个判断，反推自己的雾往哪走。」他准备强调那个胎记：每个视角独立做梦，梦与梦不商量，所以孔雀长两张脸。 第六块，合唱团。他把七块泥坯围成一圈，中间留空。「四位歌手站一圈，唱同一首歌，谁跑调就拉回来。」Zero-1-to-3 看参考图唱新视角，MVDream 四位互相听，SyncDreamer 十六位共享一本 3D 总谱，Wonder3D 加法线声部。他准备在这里问听众一个问题：「一致性等于真实吗？」然后自己回答：不等于，背面仍是合理幻想。 第七块，工厂。他把泥坯翻过来，底面写着「一次前向」。LRM 把图切成 token，Transformer 出三平面；TripoSR 压速度；GS-LRM 换高斯；TRELLIS 换稀疏体素 SLAT；Hunyuan3D 拆形状与纹理；SF3D 做 UV 与 delighting；MeshAnything 重拓扑；PartCrafter 拆部件。他准备在这里放质检员那句话：「你有 UV 吗？有 PBR 吗？拓扑呢？」——因为工程师最懂这句话的重量。 七块泥坯摆好，阿砚退后一步看。它们不像七种技术，像七个人。他忽然明白老陶匠那句话：「想被从四面八方看，就得先学会被看见这件事。」教学不是讲机制，是讲每个机制「为什么疼、疼在哪、什么时候值得疼」。

工匠笔记

1. 七块泥坯=七类 3D 表示/路线：雾（NeRF）、书架（Instant-NGP）、萤火虫（3DGS）、模子（SDF/NeuS）、梦（SDS）、合唱团（多视图扩散）、工厂（前馈 3D 大模型）。像：每块泥坯都有「身体」的隐喻，能一眼记住。不像：真实系统常混合使用，例如 3DGS 做实时、SDF 做干净表面，不是七选一。 2. 炭条写机制名=把行话翻译成动作：积分、查表、排序混合、量梯度、相减、共享总谱、一次前向。像：动作比名词好记。不像：动作会简化掉数学细节，例如体渲染的 alpha 合成被压成「叠」。 3. 玻璃瓶萤火虫=显式基元 + 光栅化。像：光点投影、排序、叠加。不像：真实萤火虫不听话，高斯基元是被优化出来的，协方差和球谐颜色没有对应物。 4. 石膏碎片=零等值面。像：外面正、里面负、表面零。不像：碎片有厚度，SDF 是标量场，薄结构两侧跳变快，β 一小就噪。 5. 这个类比哪里不像：泥坯是静态的，七次投胎是动态的「换身体」；教学时要把「换」讲出来，否则听众以为七种身体互斥。

二 · 四十五分钟：只讲三次疼

上课那天，教室坐满了。工程师们带着笔记本，表情像来开评审会。阿砚没有开场白，直接把灯关了。玻璃瓶里的萤火虫亮起来，十几点绿光在黑暗里浮。「这是第三世，」他说，「百万只萤火虫，每只带位置、朝向、大小、透明度、颜色，投影后排序混合，1080p 跑一百多帧。」他停了三秒，让光点在听众眼睛里留下残影，然后开灯。 「四十五分钟，我只讲三次疼。」他在黑板上画三条横线。 第一次疼：雾。他讲 NeRF 的代价——一个场景一个模型，每次渲染沿射线采几十上百个点，慢得像老牛拉磨。他问：「你们谁做过只做一个场景、追求照片级的项目？」后排有人举手。「那 NeRF 仍然值得。」他说，「但你要生成，它太贵。」他把「可微渲染」翻译成一句话：「相机把像素误差反传回 3D，所以 2D 照片能监督 3D。」然后补一句：「但小泥没记住猫，只记住了这一个场景的雾。」 第二次疼：萤火虫。他讲 3DGS 的显存硬代价：场景越复杂，萤火虫越多；透明玻璃、反光金属叠不干净；致密化生小萤火虫，剪枝熄灭没用的，总数还是涨。他拿起玻璃瓶晃了晃：「快是真的快，贵也是真的贵。」一个工程师问：「那什么时候选高斯？」阿砚答：「任务要实时、要显式编辑，选它；任务要干净表面，别选它。」 第三次疼：工厂。他讲前馈大模型的一次前向：LRM 把图切成 token，Transformer 出三平面；TripoSR 压速度；GS-LRM 换高斯；TRELLIS 换稀疏体素 SLAT；Hunyuan3D 拆形状与纹理；SF3D 做 UV 与 delighting；MeshAnything 重拓扑；PartCrafter 拆部件。然后他停住，学质检员的语气：「你有 UV 吗？有 PBR 吗？拓扑呢？」教室里安静了两秒——工程师都懂，出图不等于进引擎。 四十五分钟到了，阿砚没有讲书架、模子、梦、合唱团。他把七块泥坯留在桌上，说：「剩下四世，九十分钟场再讲。今天你们只记住一件事：每种身体都有它的疼，选身体就是选疼法。」 散场时一个工程师走过来，摸了摸石膏碎片，说：「你刚才说梯度长度必须等于 1，我回去查一下 Eikonal。」阿砚点头。他知道这句话会生根。

工匠笔记

1. 关灯看萤火虫=3DGS 实时显影。像：光点浮在黑暗里，投影、排序、叠加的直觉。不像：真实萤火虫乱飞，高斯基元有协方差、不透明度、球谐颜色，是被优化出来的。 2. 三条横线=三次疼：NeRF 逐场景优化、3DGS 显存、前馈模型的质检。像：用「疼」组织四十五分钟，听众记住代价。不像：四十五分钟砍掉了书架、模子、梦、合唱团，教学上是取舍，不是技术上的不重要。 3. 「相机把像素误差反传回 3D」=可微渲染的翻译。像：一句话说清 2D 监督 3D。不像：雅可比、体渲染积分、alpha 合成的细节被压掉，工程师要回去补课。 4. 质检员三问=UV/PBR/拓扑检查。像：出图不等于进引擎。不像：真实质检还有重光照、动画、LOD、碰撞体，三问只是入口。 5. 这个类比哪里不像：四十五分钟像「试吃」，九十分钟才是「正餐」；试吃不能代替正餐，但能让人愿意坐下来。

三 · 九十分钟：把七世排成一排

九十分钟场在晚上。窑火没灭，教室里暖烘烘的，有松脂和土腥味。阿砚把七块泥坯排成一排，像七个小人站在桌上。他说：「今天不讲时间顺序，讲映射。每个角色、每个道具，对应哪个机制，为什么像，哪里不像。」 他先指雾。「小泥第一世选最笨的路：相机围着拍一百张照片，每拍一张就说『你从这个角度应该长这样』。小泥把自己变成雾，空间每个点有密度和颜色，相机沿射线走，把密度和颜色累加，画出一个像素。」他停一下，「这是体渲染。它不是被建模出来的，是被积分出来的。」一个工程师点头：「所以 2D 照片能监督 3D，是因为积分对参数可微。」阿砚说：「对，但代价是逐场景优化、渲染慢、静态。」 他指书架。「哈希先生给十六层书架，第 1 层格子大记大局，第 16 层格子小记细节。查一个点，十六层各查一次，拼起来问小助手。」他撒了一把豆子，豆子撞在一起。「抽屉会撞车，但十六层一起看，误差被平均掉。」他补一句：「书架不大，两分钟学会 Lego 场景。但表是死的，场景一换，表还得重学。」一个工程师问：「哈希冲突真的没关系？」阿砚答：「撞得太多细节会丢，书架大小、层数、每层几个数字都要按场景调。」 他指萤火虫。「每只带位置、朝向、大小、透明度、颜色，投影后排序混合。」他拿起玻璃瓶，「快，但显存是硬代价。」他讲致密化和剪枝，「总数还是会涨。」 他指模子。「别记密度，记距离。外面正，里面负，表面零。距离过一道 S 形门变成密度，再去体渲染；零等值面就是皮肤。」他拿尺子贴在石膏碎片上，「梯度长度必须等于 1，这叫 Eikonal 正则。β 从大调到小，模子从厚变薄，最后皮肤又薄又干净。」他补一句：「但薄结构、非闭合、训练慢是软肋。」 他指梦。「村里没有 3D 老师，只有画师在梦里画 2D。小泥渲染一张小图，弄脏，送进梦里问『这团噪声应该是什么』，把答案和真实噪声相减，得到更新方向，乘以渲染对 3D 参数的雅可比，更新自己的雾。」他停一下，「一万五千步，一个半小时，长出孔雀和冲浪板。但一转背面，孔雀两张脸——每个视角独立做梦，梦与梦不商量。」他补一句：「颜色过饱和、纹理粘在一起，是胎记。」 他指合唱团。「Zero-1-to-3 看参考图唱新视角；MVDream 四位站一圈互相听；SyncDreamer 十六位共享 3D 总谱；Wonder3D 加法线声部。」他问：「一致性等于真实吗？」自己答：「不等于。遇到没见过的背面，歌手一起幻想出合理但错误的细节——猫的后脑勺长出一朵花。」 他指工厂。「一次前向出 3D。LRM 切 token 出三平面；TripoSR 压速度；GS-LRM 换高斯；TRELLIS 换稀疏体素 SLAT；Hunyuan3D 拆形状与纹理；SF3D 做 UV 与 delighting；MeshAnything 重拓扑；PartCrafter 拆部件。」他学质检员：「你有 UV 吗？有 PBR 吗？拓扑呢？」然后说：「小泥第一次感到被理解——不是被拟合，是被先验猜中。」 讲完七世，他回到老陶匠的问题：「那你现在是什么？」他替小泥答：「我是一块会换身体的泥。任务要实时，变萤火虫；任务要干净表面，变模子；任务要文本，去偷梦；任务要进引擎，去工厂排队。」他停一下，「但它还没真正活：不会动，不会疼，不会在物理世界里被推倒再爬起来。」 教室里有人问：「那第八次投胎是什么？」阿砚说：「世界工厂，有物理、有场景、有交互的地方。」他没有展开——九十分钟到了。

工匠笔记

1. 七块泥坯排一排=七类表示并列。像：一眼看见「换身体」不是七选一，是按任务换。不像：真实系统常混合，例如 3DGS 做实时、SDF 做干净表面，泥坯是静态的。 2. 撒豆子=哈希冲突。像：豆子撞在一起，十六层平均误差。不像：哈希冲突是确定性的索引碰撞，豆子是随机的，撞得太多细节会丢。 3. 尺子量梯度=Eikonal 正则。像：梯度长度等于 1 是约束。不像：尺子量不出标量场梯度，真实训练用损失项罚偏离。 4. 孔雀两张脸=SDS 多面胎记。像：每个视角独立做梦，梦不商量。不像：真实 SDS 还有过饱和、纹理粘连，两张脸只是最直观的症状。 5. 这个类比哪里不像：九十分钟讲七世，每世只有几分钟，深度不够；教学用法是「先建立直觉，再回去读论文」，不是替代论文。

四 · 教学用法：四十五与九十怎么切

第二天，阿砚把两套教案写在窑边的墙上，用炭条。 四十五分钟：只讲三次疼。开场关灯看萤火虫（三分钟），讲 NeRF 的贵与慢（十分钟），讲 3DGS 的显存（十分钟），讲前馈工厂的质检（十分钟），最后留十二分钟问答。目标：让听众记住「每种身体都有疼，选身体就是选疼法」。不讲的四世（书架、模子、梦、合唱团）留在桌上，谁问就指泥坯。 九十分钟：讲七世映射。开场排七块泥坯（五分钟），每世八到十分钟，讲「角色/道具对应哪个机制、为什么像、哪里不像」，最后十五分钟讲「会换身体的泥」和第八次投胎的悬念。目标：让听众能自己说出「任务要实时选萤火虫，任务要干净表面选模子」。 阿砚在墙上补了一行小字：「四十五分钟是试吃，九十分钟是正餐。试吃不能代替正餐，但能让人愿意坐下来。」他又补一行：「每世至少留一个『哪里不像』，否则听众会把比喻当真理。」 老陶匠走过来看，旱烟的火星在暗里一明一灭。「你这墙上写的，」他说，「像不像给小泥画的七张脸？」 阿砚说：「像。但每张脸旁边都有一道裂缝，我标了『哪里不像』。」 老陶匠笑了：「裂缝才是真话。」

工匠笔记

1. 墙上教案=教学切分。像：四十五分钟三次疼，九十分钟七世映射。不像：真实课堂会因听众背景浮动，工程背景多讲质检，研究背景多讲 Eikonal 和 SDS。 2. 「试吃与正餐」=先直觉后细节。像：四十五分钟建立记忆点，九十分钟补映射。不像：试吃砍掉的四世不是不重要，是时间不够。 3. 「每世留一个哪里不像」=防止比喻当真理。像：裂缝标在每张脸旁边。不像：真实技术分歧比裂缝复杂，教学只能标最直观的那道。 4. 老陶匠的「裂缝才是真话」=类比的自省。像：比喻有边界。不像：边界不是缺陷，是教学的一部分。 5. 这个类比哪里不像：教案是静态的，课堂是动态的；听众的问题会改变切分，阿砚的墙只是起点。

五 · 新问题：第八次投胎怎么讲

夜里，阿砚坐在窑边，七块泥坯在桌上排着。窑火映得它们半红半黑，像七个睡着的人。他想起小泥尾声那句话：「我是一块会换身体的泥。」但他也知道，小泥还没真正活——不会动，不会疼，不会在物理世界里被推倒再爬起来。 他听说远处有一座「世界工厂」，能把房间变成可漫游的世界，能给物体装上弹性与重量。小泥决定开始第八次投胎，这一次，它想成为一个有物理、有场景、有交互的「地方」，而不只是一个被看见的「东西」。 阿砚在教案末尾加了一行：「第八次投胎：从『东西』到『地方』。教学上，这是从表示到场景、从静态到动态、从被看见到被交互的跳跃。四十五分钟讲不完，九十分钟也只能开个头。」 他放下炭条，听见窑里一声轻响——是那只旧猫陶的尾巴在风里点头。他忽然明白：七次投胎不是七种技术，是七次「学会被看见」的疼。教学不是把疼讲没，是把疼讲清楚，让听众自己选哪次疼值得。 他吹灭油灯，七块泥坯在黑暗里排着，像七个还没醒的人。明天，他要讲第八次投胎的开头——不是答案，是问题。

工匠笔记

1. 第八次投胎=从表示到场景/物理/交互。像：小泥从「东西」变成「地方」。不像：给定事实只提到「世界工厂」的听说，没有具体机制，教学只能定性。 2. 「七次投胎是七次学会被看见的疼」=教学立场。像：每种身体都有代价。不像：疼不是目的，是选择的依据；教学要把「什么时候值得疼」讲出来。 3. 旧猫陶尾巴点头=故事的回声。像：第一世的纪念品还在。不像：纪念品是静态的，小泥的七世是动态的换身体。 4. 「不是答案，是问题」=第八次投胎的教学定位。像：留悬念。不像：悬念不能代替机制，后续要补场景表示、物理、交互的具体内容。 5. 这个类比哪里不像：七块泥坯是静态道具，真实教学要面对听众的追问；泥坯不会回答，阿砚要回答。
