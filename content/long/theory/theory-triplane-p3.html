一 · 失效条件：冗余、拓扑与几何真值的三重边界

三平面不是无条件的胜利。它的第一类失效来自结构本身的对称冗余：三张平面并非独立，同一 3D 点被三个正交投影同时约束，任意两张平面在交线上必须给出一致的插值结果。生成器在训练中会利用这种冗余来共享结构，但当冗余被破坏时——例如三张平面分辨率不一致、插值核不同、或某一平面被单独微调——查询函数 F(x) 在交线附近会出现特征跳变，表现为渲染表面出现细窄的接缝或密度不连续。机制上，这是因为 interp(T_xy,x) 与 interp(T_xz,x) 在 y=0 或 z=0 的共享坐标上被拼接进同一个 MLP，MLP 无法区分“这是冗余一致的结果”还是“这是两张平面冲突的结果”，只能被动拟合冲突。系统代价是：一旦出现接缝，靠增加通道数无法消除，因为冲突是坐标级的，不是容量级的；必须回到平面间的一致性约束（例如在交线上加一致性损失，或强制三平面共享同一插值网格）。具体例子：在 N=256、通道 32 的配置下，若把 T_xz 单独上采样到 512 而其余保持 256，查询沿 y 轴移动时，interp(T_xz,x) 的采样频率与 interp(T_xy,x) 不匹配，拼接向量在高频区域出现相位差，MLP 解码出的密度在薄壳上抖动。

第二类失效是固定拓扑。三平面把 3D 空间压成三张 2D 图，等价于假定场景的支撑域可以被三个正交投影无歧义地覆盖。对于单物体、近似凸或星形拓扑的物体，这个假定成立；但对于多部件、带孔洞、或部件间存在遮挡关系的场景，投影会丢失沿投影方向的前后顺序。机制上，interp(T_xy,x) 只取 (x,y) 坐标，完全丢弃 z；两个在 z 上分离但 (x,y) 相同的点，在 T_xy 上得到同一个特征，只能靠 T_xz 和 T_yz 的拼接来区分。当部件在三个投影方向上都不分离时（例如一个环套在另一个环内，且两环在三个正交方向上的投影都重叠），三平面无法表达“谁在前谁在后”，MLP 只能输出平均密度，导致部件融合。系统代价是：部件编辑需要重新训练或至少重新优化平面，因为拓扑信息被编码在平面的全局纹理里，没有显式的部件句柄。具体例子：EG3D 生成 512×512 人脸时，五官的拓扑由训练数据固定；若要在生成后单独拉长鼻子，必须找到平面上对应鼻子的纹理区域并做局部编辑，但该区域同时承载了脸颊和眼窝的投影，局部编辑会牵连邻域。

第三类失效是几何真值弱。三平面本身只是特征图，密度/颜色/SDF 由小 MLP 解码，训练信号来自渲染损失（多视角光度一致性）而非显式 3D 监督。机制上，F(x) 的几何正确性依赖 MLP 在平面特征的拼接空间里学到“密度随坐标如何变化”，但渲染损失只约束沿射线的积分结果，不约束空间中任意点的密度。对于薄结构、透明表面、或高频细节，射线积分对密度的局部误差不敏感，MLP 可以输出“看起来对”但几何上错误的密度场。系统代价是：几何评估（如 Chamfer 距离、法线一致性）在无真值监督时会偏离；增加平面分辨率只能提高特征的空间频率，不能补上缺失的 3D 约束。具体例子：N=256、通道 32 的三平面约 630 万参数，同分辨率体素是 5.4 亿，差 85 倍；参数少意味着平面必须用冗余编码共享结构，但共享的前提是训练信号足够强，弱监督下冗余会退化为模糊。

二 · 系统取值：分辨率、通道与平面数的取舍

三平面的系统取值不是自由超参，而是被显存、带宽和 2D 卷积感受野共同约束的。核心量是平面分辨率 N 与通道 C：参数量为 3N²C，而体素为 N³C，比值 N/3。在 N=256 时，三平面约 630 万参数，体素约 5.4 亿，差 85 倍；这个差距来自维度降阶，不是压缩技巧。机制上，2D 卷积在 N×N 网格上做局部聚合，感受野随层数增长；三平面把 3D 的邻域关系拆成三个 2D 邻域，卷积核在每张平面上独立学习，再通过 MLP 拼接融合。系统代价是：N 增大时，三平面参数量按 N² 增长，而体素按 N³ 增长，所以三平面在中等分辨率下优势最大；当 N 继续增大，三平面的显存优势仍在，但 2D 卷积的计算量按 N² 增长，训练时间成为新瓶颈。具体例子：EG3D 用三平面生成 512×512 人脸，单卡可训；若把 N 提到 1024，三平面参数约 3×1024²×32≈1 亿，仍在单卡范围，但 2D 卷积的激活显存和训练步时显著上升。

通道数 C 的取值受 MLP 输入维度约束：查询时拼接三个插值结果，输入维度是 3C，MLP 第一层必须接受这个维度。机制上，C 太小则三张平面的特征表达能力不足，拼接后的 3C 维向量无法区分空间中的细微差别；C 太大则 MLP 第一层参数量按 3C×H 增长（H 为隐藏宽度），且三平面的显存按 C 线性增长。系统代价是：C 与 N 的乘积决定平面显存，C 与 H 的乘积决定 MLP 显存，两者需要联合调；单独调一个会把瓶颈推到另一个。具体例子：N=256、C=32 时平面约 630 万参数，若把 C 提到 64，平面翻倍到约 1260 万，MLP 输入从 96 维变 192 维，第一层参数量翻倍；此时若 H 不变，MLP 容量相对输入维度被稀释，解码精度不一定提升。

平面数固定为三，这是正交分解的最小完备集：xy、xz、yz 三张平面覆盖三个坐标轴方向，任意 3D 点都能在每张平面上找到投影。机制上，少于三张则某些坐标组合无法被覆盖（例如只有 xy 和 xz，则 y 与 z 的相对关系只能靠 MLP 外推）；多于三张则引入额外冗余，参数量按平面数线性增长，但覆盖信息并不增加。系统代价是：三平面之间的冗余是“有益的冗余”，帮助 2D 卷积学习共享结构；但若增加到四张或更多，冗余变成“无约束的冗余”，平面间一致性难以维持，训练中容易出现某张平面被主导、其余平面退化为噪声。具体例子：在 N=256、C=32 下，三平面约 630 万参数；若加到六张平面（例如加入对角平面），参数翻倍到约 1260 万，但查询时拼接维度变为 6C，MLP 第一层同步膨胀，且对角平面与正交平面在交线上的插值一致性没有理论保证。

三 · 与相邻理论的差别：体素、隐式 MLP、哈希网格

与体素表示相比，三平面的差别不在“是否离散”，而在“离散在哪个维度”。体素是 N³ 的三维网格，每个格点存特征，查询时做三线性插值；三平面是 3N² 的二维网格，查询时做三次双线性插值再拼接。机制上，体素的三线性插值在 3D 邻域内聚合 8 个格点，三平面则在三个 2D 邻域内各聚合 4 个格点，共 12 个插值结果，再经 MLP 融合。系统代价是：体素的显存按 N³ 增长，三平面按 N² 增长；但体素的查询是纯插值，无需 MLP 融合，三平面必须带一个小 MLP，增加了推理时的计算和参数。具体例子：N=256、C=32 时，体素约 5.4 亿参数，三平面约 630 万，差 85 倍；但三平面的查询路径包含三次 grid_sample 和一次 MLP 前向，体素只有一次三线性插值。

与纯隐式 MLP 相比，三平面的差别在于“特征从哪来”。纯隐式 MLP 直接把坐标 x 送进 MLP，所有空间结构编码在 MLP 权重里；三平面先用 2D 卷积在平面上生成特征，再把插值结果送进小 MLP。机制上，纯隐式 MLP 的容量全在权重里，训练时没有 2D 卷积的局部归纳偏置；三平面把大部分容量放在平面上，2D 卷积天然具备平移等变性和局部性，小 MLP 只做拼接解码。系统代价是：纯隐式 MLP 难以用成熟的 2D 卷积训练流程，收敛慢且对初始化敏感；三平面可以复用 2D 生成器的架构（如 StyleGAN 的卷积主干），训练更稳定，但平面分辨率固定了空间频率上限，纯隐式 MLP 理论上可以表达任意高频。具体例子：EG3D 用三平面生成 512×512 人脸，单卡可训；纯隐式 MLP 在同等分辨率下需要更大的 MLP 和更长的训练，且没有 2D 卷积的局部先验。

与哈希网格（如 Instant-NGP 一类多分辨率哈希编码）相比，三平面的差别在于“分辨率是否多级”。哈希网格用多级不同分辨率的哈希表编码空间，查询时插值多级特征再拼接；三平面是单级（或少数几级）的正交平面。机制上，哈希网格的多级结构让高频细节由高分辨率级承载、低频由低分辨率级承载，参数量按级数增长；三平面只有一级 N×N，高频细节靠 N 增大来承载。系统代价是：哈希网格的参数量可控（哈希表大小可调），但哈希冲突引入噪声，且多级插值增加查询开销；三平面无哈希冲突，查询是确定性的三次双线性插值，但 N 增大时参数量按 N² 增长，且单级平面难以同时兼顾低频与高频。具体例子：N=256、C=32 的三平面约 630 万参数；若用多级哈希网格达到同等高频表达能力，需要多个分辨率级，每级哈希表大小可独立设置，总参数量可以更小，但查询路径更长。

四 · 练习：从公式到系统判断

练习一：给定平面分辨率 N 与通道 C，写出三平面参数量与同分辨率体素参数量的比值，并判断在 N=256、C=32 时该比值。要求用公式 3N²C 与 N³C 推导，不代入实验数字之外的数值。参考思路：比值是 3N²C / N³C = 3/N，在 N=256 时为 3/256，即体素参数量约为三平面的 N/3 倍；给定事实中 N=256、C=32 时三平面约 630 万、体素约 5.4 亿、差 85 倍，与 256/3 的量级一致。此练习的目的是让读者把“降一个维度”翻译成参数量的幂次差，而不是记住一个数字。

练习二：写出查询函数的伪代码思路，并指出其中哪一步引入了三平面间的一致性约束。参考思路：查询时分别对三张平面做 grid_sample，取 x[..., :2]、x[..., [0,2]]、x[..., 1:]，拼接后送 MLP；一致性约束不在查询代码里，而在训练时的平面间冗余：同一 3D 点的三个插值结果被拼接进同一个 MLP，MLP 被迫学习“三组特征如何一致地解码”，这就是冗余帮助 2D 卷积学习共享结构的机制。练习要求读者区分“查询路径”与“训练约束”，因为失效条件中的接缝问题正来自两者不匹配。

练习三：给定一个多部件场景（例如两个环互相套叠，且在三个正交方向上的投影都重叠），判断三平面能否表达前后遮挡关系，并给出至少一种缓解方案。参考思路：三平面在三个投影方向上都丢失了沿投影方向的前后顺序，当两个部件在三个方向上都不分离时，F(x) 无法区分谁在前，MLP 只能输出平均密度，导致部件融合；缓解方案包括引入显式的部件句柄（例如在平面上加部件标签通道）、或在训练中加入沿射线的深度监督，让 MLP 学到前后关系。此练习的目的是让读者把“固定拓扑”的失效条件落到具体几何构型上。

练习四：比较三平面与哈希网格在“高频细节承载”上的机制差别，并判断在 N=256、C=32 的配置下，若目标场景包含大量高频薄结构，应优先调 N 还是调 C。参考思路：三平面是单级 N×N，高频细节靠 N 增大来承载；哈希网格是多级，高频由高分辨率级承载。在 N=256、C=32 下，若高频不足，优先调 N，因为 N 直接决定平面特征的空间频率上限；调 C 只增加每格的特征维度，不增加空间频率。但调 N 的代价是参数量按 N² 增长、2D 卷积计算量按 N² 增长，需要同时评估训练步时。此练习的目的是让读者把“分辨率与通道的取舍”从表格记忆变成机制判断。

五 · 工程判断：三平面何时该用、何时不该用

三平面的适用边界由三个条件共同决定：场景的支撑域能被三个正交投影近似无歧义地覆盖、训练信号足够强到约束平面特征、以及目标分辨率下 N² 的计算量在预算内。机制上，第一个条件对应“固定拓扑”的失效边界：单物体、近似凸或星形拓扑的场景满足，多部件带遮挡的场景不满足；第二个条件对应“几何真值弱”的失效边界：多视角光度一致性强的场景满足，弱监督或单视角场景不满足；第三个条件对应系统取值：N 增大时 2D 卷积计算量按 N² 增长，训练步时成为瓶颈。系统代价是：三个条件中任一不满足，三平面的优势会被抵消——拓扑不满足则部件融合，监督不满足则几何模糊，计算不满足则训练不可行。具体例子：EG3D 用三平面生成 512×512 人脸，单卡可训，正是因为人脸是单物体、近似星形拓扑、且有多视角光度监督；若换成多物体室内场景，三平面的固定拓扑假定失效，需要引入额外的场景分解或部件句柄。

与相邻理论的选择也不是“谁更先进”，而是“谁的归纳偏置匹配任务”。体素适合需要显式 3D 邻域聚合的任务（如体积渲染的物理模拟），代价是 N³ 显存；纯隐式 MLP 适合需要任意高频表达且训练预算充足的任务，代价是收敛慢；哈希网格适合需要多级细节且参数量可控的任务，代价是哈希冲突噪声和查询开销；三平面适合需要复用 2D 卷积训练流程、且场景拓扑简单的生成任务，代价是固定拓扑和平面间一致性约束。机制上，这四种表示的差别可以统一到“特征离散在哪个维度、查询时如何插值、融合时用什么模块”三个问题上；三平面的答案是“离散在三个 2D 维度、三次双线性插值、小 MLP 拼接融合”。工程判断的落点不是选一个“最好”的表示，而是先确认任务的拓扑复杂度、监督强度和分辨率预算，再选匹配的离散维度。

最后落到一个具体机制：三平面的冗余不是缺陷，而是 2D 卷积学习共享结构的通道。三张平面在交线上的插值一致性，迫使 MLP 在拼接空间里学到“同一空间点的三种投影如何对应同一个密度值”，这个约束在训练中起到正则化作用；但当冗余被破坏（分辨率不一致、插值核不同、单独微调），一致性约束消失，接缝出现。工程上判断三平面是否可用的一个可操作检查是：在训练后沿三张平面的交线采样查询 F(x)，观察密度/颜色是否连续；若连续，冗余被正确利用；若不连续，说明平面间一致性未被约束，需要回到训练目标或平面配置。这个检查不依赖实验数字，只依赖查询函数的机制，可以作为三平面部署前的系统自检。
