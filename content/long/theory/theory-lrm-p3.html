一 · 失效条件：三平面预测在哪些输入上必然退化

LRM 的推理路径是「一次前向」，但这不等于它在所有输入上都可靠。失效条件可以从表示、几何、数据三个层面拆开看，每一层都有明确的机制，而不是笼统的「效果不好」。

第一层是表示层面的固有上限。三平面把 3D 特征压到三个正交的二维平面上，任何一条穿过空间的光线，其采样点的特征都由三个平面在对应坐标上的双线性插值组合而成。这意味着三平面在某个方向上的表达能力，受限于该方向平面上的特征分辨率。对于沿平面法向变化剧烈的结构，比如薄片、镂空、细杆，平面上的二维特征无法区分同一投影位置上的前后两个表面，体渲染时密度场会在两者之间产生「糊」的过渡带。这不是训练不充分的问题，而是三平面表示的秩约束：三个平面张成的特征空间对某些高频 3D 模式是欠定的。工程判断是：当目标物体的厚度接近或小于三平面单像素对应的空间尺度时，重建必然丢失该结构。

第二层是几何层面的可见性缺失。LRM 的输入是单张图，编码器只能看到朝向相机的那一面。背面的细节完全依赖训练数据中的先验分布。Objaverse 这类数据集里，物体类别分布不均，常见类别（椅子、桌子、动物）的背面统计规律被模型记住，罕见类别或非自然物体（机械零件、扫描件）的背面就会退化为「合理但错误」的猜测。机制上，cross-attention 把图像 token 分配到三平面 token 时，没有来自背面的观测约束，解码器只能输出条件分布的条件均值，即最「典型」的背面。失败模式是：正面渲染损失很低，转到背面渲染时出现对称性错误、缺失部件或材质漂移。具体例子：输入一张只拍到正面的单椅图，模型可能生成一个背面带有不存在横撑的椅子，因为训练集中该类椅子的背面横撑出现频率高。

第三层是网格提取的分辨率损失。三平面本身是连续的，但下游若要走网格，需要把密度场离散化为体素再做 marching cubes。三平面分辨率是 64×64，对应到 3D 空间的有效体素分辨率受平面采样率限制。薄结构和尖锐边缘在体素化时被平滑，提取出的网格出现圆角或断裂。这是管线层面的代价，不是 LRM 本身的错，但工程上必须计入：如果下游需要高精度网格，三平面到网格这一步的损失往往大于预测本身的误差。

第四层是训练成本的隐性门槛。50 万物体、24 层 Transformer、16 视角渲染损失，这套配置的训练需要大量 GPU 时。失效条件在这里表现为：小规模数据微调时，模型迅速过拟合到少数类别，背面先验退化，泛化到新类别时渲染损失飙升。工程判断是：LRM 的「一次前向」优势只在训练分布覆盖的类别上成立，分布外输入的可靠性由训练集覆盖面决定，而不是由推理速度决定。

二 · 系统取值：分辨率、视角数、层数与推理预算的耦合

LRM 的系统参数不是独立可调的，它们通过渲染损失和 Transformer 容量耦合在一起。理解这种耦合，才能在实际部署时做出正确的取舍。

三平面分辨率决定了表示的上限。给定平面分辨率 $R$（本例 64），三平面总参数量约为 $3\times R\times R\times C$，其中 $C$ 是每平面特征通道数（本例 32）。提高 $R$ 会线性增加显存和渲染采样成本，但渲染损失的梯度回传要经过体渲染的积分，采样点数量随 $R$ 增长而增长，训练吞吐下降。反过来，降低 $R$ 会让薄结构直接消失。系统取值的第一条判断是：$R$ 应匹配目标物体的最小特征尺度与渲染分辨率的比值，而不是盲目追高。

视角数决定了监督信号的覆盖。本例渲染 16 个视角与真值算 MSE+LPIPS。视角太少，背面和侧面的梯度信号不足，模型退化为只拟合正面；视角太多，每个训练步的渲染成本线性上升。机制上，渲染损失是对视角求和的，$\mathcal{L}=\sum_{v}\|\mathrm{VolumeRender}(\mathbf{T},\mathbf{c}_v)-I_v\|^2$，视角集合 $\{c_v\}$ 的分布决定了三平面哪些区域收到梯度。工程取值是：视角应环绕物体均匀分布，且包含至少一个背面视角，否则背面三平面区域的梯度为零，完全由先验填充。

Transformer 层数决定了图像 token 到三平面 token 的映射容量。本例 24 层，输入 1024 个 DINO token，输出 3×64×64×32 的三平面。层数不足时，cross-attention 无法把细粒度的图像特征分配到正确的平面位置，表现为渲染图模糊、纹理错位。层数过多时，训练成本上升且容易过拟合到训练集的纹理统计。系统取值的第二条判断是：层数应与 token 数和平面 token 数的比值匹配，本例中 1024 输入 token 对 12288 平面 token，解码器需要足够的层数完成这种「扩维」映射。

推理预算方面，本例推理约 10 秒。这个数字由 ViT 前向、24 层 Transformer 解码、三平面体渲染三部分组成。体渲染 16 个视角在推理时若只渲染少量视角用于展示，时间可压缩；但若下游需要多视角一致性检查，渲染成本不可忽略。系统取值的第三条判断是：推理时间的主要项是 Transformer 解码而非渲染，因此压缩层数比压缩渲染视角更能降低延迟，但压缩层数会直接损害映射质量。

三 · 与相邻理论的差别：LRM 不是 NeRF，也不是前馈重建的普通回归

把 LRM 和相邻方法放在一起比较，差别不在「是否用 Transformer」，而在「监督信号作用在哪个空间」。

与 NeRF 的差别是优化对象的不同。NeRF 对每个场景单独优化一个 MLP，损失是渲染图与真值的差异，优化变量是网络权重。LRM 的损失形式相同，$\mathcal{L}=\sum_{v}\|\mathrm{VolumeRender}(\mathbf{T},\mathbf{c}_v)-I_v\|^2$，但优化变量是编码器参数 $\theta$，三平面 $\mathbf{T}$ 是前向的输出而非优化变量。机制上，NeRF 的梯度从渲染图回传到该场景的 MLP，LRM 的梯度从渲染图回传到 Transformer，再通过 cross-attention 回传到图像 token 的映射。这意味着 LRM 学的是「从图像到 3D 的映射」，而不是「某个场景的 3D」。代价是：NeRF 对单场景可以过拟合到极高精度，LRM 的精度受训练分布约束；收益是：LRM 推理一次前向，NeRF 需要逐场景优化。

与前馈重建（如单图深度估计加网格生成）的差别是表示的可微性。普通前馈方法直接回归深度图或体素网格，损失作用在输出空间上，梯度不经过渲染。LRM 的三平面是可微的 3D 表示，渲染损失把 2D 图像误差转化为 3D 表示的梯度，这使得训练信号能约束三平面的所有区域，而不仅是可见表面。机制上，体渲染的积分对三平面采样点求导，背面区域即使没有直接观测，也能通过多视角渲染损失间接收到梯度（当视角集合包含背面时）。这是 LRM 与普通回归的关键差别：渲染损失是 3D 一致的，而逐像素回归不是。

与三平面 NeRF 变体的差别是推理模式。三平面 NeRF 仍然逐场景优化三平面，LRM 把三平面变成预测目标。公式上，LRM 的定义是 $\mathbf{T}=\mathrm{Transformer}_\theta(I,\mathbf{c})$，三平面是函数输出；三平面 NeRF 的三平面是优化变量。这个差别决定了系统代价：LRM 的训练成本一次性投入，推理成本固定；三平面 NeRF 的训练成本按场景计，推理成本也按场景计。

与通用 3D 生成模型（扩散类）的差别是监督信号。扩散类方法在 3D 表示空间上加噪去噪，训练目标是去噪得分；LRM 的训练目标是渲染一致性。机制上，LRM 不需要 3D 真值，只需要多视角渲染图与真值的差异，这使得它能利用 Objaverse 这类多视角渲染数据训练，而不需要显式的 3D 标注。代价是：渲染损失对视角覆盖敏感，视角不足时背面先验主导；扩散类方法在 3D 表示空间上直接建模，对视角覆盖的依赖不同。

工程判断是：LRM 的定位是「把重建变成预测」的映射学习器，它的相邻理论差别集中在监督空间（渲染空间 vs 输出空间）和优化对象（编码器 vs 场景表示）两个维度上。选型时先问「监督信号作用在哪个空间」，再问「优化对象是一次性还是逐场景」，这两个问题能区分 LRM 与大多数相邻方法。

四 · 失败模式的诊断路径：从渲染图反推系统取值

实际部署 LRM 时，失败模式不会以「失效条件」的标签出现，而是以渲染图上的具体症状出现。诊断路径是从症状反推系统取值，而不是从理论反推。

症状一：正面渲染清晰，背面渲染出现对称性错误或缺失部件。诊断指向视角覆盖不足或训练分布偏差。检查视角集合是否包含背面视角，检查训练集类别分布是否覆盖输入类别。若视角集合完整但背面仍错，则是数据先验问题，需要扩充训练集或引入背面监督。机制上，背面三平面区域的梯度来自背面视角的渲染损失，若该视角缺失，梯度为零，三平面背面区域只受正面视角的间接约束，退化为条件均值。

症状二：渲染图整体模糊，纹理错位。诊断指向 Transformer 层数不足或平面通道不足。检查 token 到平面 token 的映射是否完成：1024 输入 token 对 12288 平面 token，若层数不足，cross-attention 无法把细粒度特征分配到正确位置。机制上，cross-attention 的注意力权重决定了每个图像 token 贡献到哪些平面 token，层数不足时注意力分布过于平滑，平面特征被平均化，渲染图失去高频细节。

症状三：薄结构消失或边缘圆角。诊断指向三平面分辨率不足或网格提取分辨率不足。检查 $R$ 与目标最小特征尺度的比值，检查 marching cubes 的体素分辨率。机制上，三平面在平面法向上的表达能力受 $R$ 限制，薄结构在双线性插值时被平滑；网格提取的体素化进一步平滑。工程判断是：若下游需要薄结构，提高 $R$ 的收益大于提高网格分辨率，因为三平面是源头。

症状四：训练损失下降但验证渲染损失不降。诊断指向过拟合到训练集纹理统计。机制上，Transformer 记住了训练集的纹理分布，cross-attention 把图像 token 映射到平面 token 时依赖训练集的统计规律，分布外输入时映射错位。工程判断是：增加数据多样性比增加层数更有效，因为失败模式是分布偏移而非容量不足。

诊断路径的伪代码思路是：给定渲染图 $I_{\text{render}}$ 与真值 $I_{\text{gt}}$，计算分视角的误差图，定位误差集中在正面、背面还是边缘；正面误差指向映射容量，背面误差指向视角覆盖与先验，边缘误差指向分辨率。这个分视角误差图是诊断的起点，而不是整体 MSE。

五 · 练习：用可复现的步骤检验边界

练习的目的是把上述失效条件变成可观测的现象，而不是停留在定性描述。以下练习只使用给定事实中的数字和机制，不引入外部实验数据。

  • 练习一：视角消融。用本例的 16 视角配置训练，然后分别去掉背面视角、去掉侧面视角，观察背面渲染误差的变化。预期现象：去掉背面视角后，背面渲染误差显著上升，正面误差不变。机制解释：背面三平面区域的梯度来自背面视角的渲染损失，视角缺失即梯度缺失。这个练习检验的是「视角覆盖决定背面先验」这一失效条件。
  • 练习二：分辨率消融。固定其他参数，把三平面分辨率从 64 降到 32，观察薄结构（如细杆、薄片）的渲染图。预期现象：薄结构在渲染图中消失或变成糊状。机制解释：三平面在平面法向上的表达能力受 $R$ 限制，$R$ 降低时双线性插值的平滑尺度变大。这个练习检验的是「表示层面的秩约束」。
  • 练习三：层数消融。固定其他参数，把 Transformer 层数从 24 降到 12，观察纹理错位。预期现象：渲染图整体模糊，纹理位置偏移。机制解释：cross-attention 的层数不足时，1024 输入 token 到 12288 平面 token 的映射无法完成，注意力分布过于平滑。这个练习检验的是「映射容量」这一系统取值。
  • 练习四：分布外输入。用训练集未覆盖的类别（如机械零件）做推理，观察背面渲染。预期现象：背面出现「合理但错误」的猜测，正面渲染仍然清晰。机制解释：背面细节靠数据先验，分布外输入的背面退化为条件均值。这个练习检验的是「数据先验主导背面」这一失效条件。
  • 练习五：网格提取分辨率。把三平面渲染的密度场用不同体素分辨率做 marching cubes，观察边缘圆角。预期现象：体素分辨率低于三平面分辨率时，边缘圆角加剧。机制解释：网格提取的分辨率损失叠加在三平面分辨率损失之上。这个练习检验的是「管线层面的代价」。

每个练习的观测指标是分视角渲染误差图，而不是整体 MSE。分视角误差图能定位误差集中在正面、背面还是边缘，从而对应到具体的系统取值。练习的工程意义是：把「失效条件」从理论标签变成可测量的症状，再通过症状反推参数调整方向。这套诊断路径与第三节的相邻理论差别是互补的：差别告诉你 LRM 的定位，诊断路径告诉你 LRM 在具体输入上的边界。

最后一个练习的落点是：三平面到网格这一步的损失往往被低估，因为渲染图看起来正常，但下游网格出现圆角或断裂。工程判断是：若下游是渲染展示，三平面直接体渲染即可，不必走网格；若下游是几何编辑或仿真，网格提取的分辨率必须与三平面分辨率匹配，否则管线损失会掩盖预测本身的误差。这个判断把系统取值、失效条件与下游需求三者绑在一起，是 LRM 部署时的实际决策点。
