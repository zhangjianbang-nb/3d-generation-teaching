一 · 一句话背后的结构性翻转

把 SDS 与 VSD 的差别压缩成一句话，通常会说「SDS 把 3D 渲染当成一个点，VSD 把 3D 参数看成一个分布」。这句话之所以不是修辞，是因为它对应一个可检验的结构性翻转：优化对象从单个参数向量 θ 变成参数空间上的概率测度 q(θ)。在 SDS 里，每一次梯度更新都只服务于当前这一个 θ，渲染图 x 是 θ 的确定性函数，扩散模型给出的噪声残差直接当作 θ 的下降方向。于是整条优化轨迹是一条线，终点是一个点，采样多次只要初始化和随机种子接近，落点就接近。VSD 把 θ 视为从 q 中抽出的一个粒子，梯度不再只问「这个 θ 该往哪走」，而是问「整个 q 该往哪搬」。这个翻转带来的第一个直接后果是：单条轨迹的终点不再重要，重要的是粒子群的散布形状。

机制上，这个翻转靠的是在冻结的文本条件扩散模型之外，再维护一个「粒子模型」ε_ψ。冻结模型 ε_φ 编码的是文本分布 p(x|y) 的得分，粒子模型编码的是当前 3D 分布经渲染投影后的得分。两个得分相减，得到的是把 q 推向 p 的方向。这里的关键在于粒子模型不是固定的：它随 q 一起更新，因此它近似的是一个移动目标。这使 VSD 在结构上接近对抗训练——一个模型负责提供目标分布的梯度，另一个模型负责估计当前分布的梯度，二者差值驱动参数更新，而被更新的分布又反过来改变第二个模型的训练数据。

用公式表达这个翻转最清楚。SDS 的更新可以写成对单个样本的噪声残差期望，而 VSD 的梯度是：

$$\nabla_\theta\mathcal{L}_{\mathrm{VSD}}=\mathbb{E}\!\left[w(t)\big(\epsilon_\phi(\mathbf{x}_t;y,t)-\epsilon_\psi(\mathbf{x}_t;c,t)\big)\frac{\partial \mathbf{x}}{\partial\theta}\right]$$

其中 ε_φ 是冻结的文本条件去噪网络，ε_ψ 是用当前渲染图训练的粒子模型，w(t) 是噪声水平权重，∂x/∂θ 是渲染器对 3D 参数的雅可比。注意这个式子里没有任何一项要求 θ 是单点：期望是在 q 下取的，粒子模型 ε_ψ 的输入 x_t 来自 q 的渲染样本。把期望展开成对粒子群的求和，就得到分布级别的更新。系统代价也随之出现：每步不仅要前向冻结模型，还要前向粒子模型并反向更新粒子模型，显存里同时驻留两套去噪网络和渲染中间量。一个具体例子是粒子 LoRA rank=64：每步用当前渲染图对粒子模型做一次去噪训练，冻结模型预测噪声 0.8、粒子预测 0.5，差 0.3 就是更新方向；粒子越准，这个差值越接近真实分布梯度，多样性越好。反过来，如果粒子模型欠拟合，差值里混入的是估计误差而不是分布差，更新方向就被污染。

二 · 严格定义：KL 梯度、两个得分与对抗式最小化

严格地说，VSD 定义的是一个变分目标，而不是一条启发式规则。设 q(θ) 为 3D 参数上的当前分布，p(θ|y) 为文本条件所诱导的目标分布。VSD 最小化二者之间的 KL 散度。对 KL 关于分布参数求变分梯度，得到 E_q[∇log q − ∇log p]。这一项是定义的核心：它说明推动分布的不是某个标量损失，而是两个对数密度的差。第一项 ∇log q 是当前分布的得分，第二项 ∇log p 是目标分布的得分。谁能提供这两个得分，谁就能驱动 q 向 p 移动。

VSD 的做法是把这两个得分分别外包给两个去噪网络。∇log p 由冻结的文本条件扩散模型 ε_φ 给出，因为扩散模型在噪声水平 t 上的噪声预测与得分成正比；∇log q 由粒子模型 ε_ψ 近似，因为粒子模型的训练数据就是当前 q 的渲染样本。于是 KL 的变分梯度被实例化为噪声预测之差，再乘上渲染雅可比传回 θ。这就是上面那条公式的来源，也是「两个得分相减」这一直觉的严格版本。需要注意，ε_ψ 的条件输入是 c，通常取空条件或与渲染配置相关的条件，它与 ε_φ 的文本条件 y 不是同一个东西；二者的差值才有意义，单独看任何一个都不构成 VSD 的更新。

伪代码层面，一次 VSD 步可以写成：

  • 用当前 θ 渲染出图像 x = render(θ)；
  • 对 x 加噪得到 x_t，送入冻结模型得 ε_φ(x_t;y,t)，送入粒子模型得 ε_ψ(x_t;c,t)；
  • 以 (ε_φ − ε_ψ) 乘权重 w(t) 与雅可比 ∂x/∂θ，得到 θ 的下降方向；
  • 用当前渲染图 x 对粒子模型做一次去噪训练，使其跟上 q 的最新位置。

这个循环的对抗性体现在最后一步：粒子模型不是预训练后冻结的，它每步都被 q 的新样本更新。因此 q 移动，粒子模型跟着移动，二者形成一种最小化—跟踪的动态。失败模式也在这里：如果粒子模型更新太快，它会过度拟合当前少数渲染样本，∇log q 的估计方差变大，梯度方向抖动；如果更新太慢，粒子模型滞后于 q，差值里混入的是旧分布的得分，q 被推向一个已经不存在的位置。这两种失配都不会报错，只会表现为生成结果的多样性异常或过饱和回潮。一个具体判断是看粒子模型在留出的渲染图上的去噪残差：残差持续偏大说明欠拟合，残差在训练样本上极小而在留出样本上偏大说明过拟合，两者都要求调整粒子模型的学习率或更新频率。

三 · 为什么需要：单点假设带来的三个具体病症

需要 VSD 的理由不是「分布听起来更高级」，而是单点假设在工程上会产生三个可复现的病症。第一是模式塌缩：SDS 的梯度只对当前 θ 负责，优化会收敛到目标分布中某个高密度点附近，粒子群若从相近初始化出发，会挤向同一处，生成结果的多样性低于文本所描述的分布。第二是过饱和：噪声残差被直接当作参数更新方向，缺少对当前分布密度的校正，优化容易把渲染推向扩散模型高置信但视觉上过锐的区域，表现为颜色饱和、纹理重复。第三是对初始化与随机种子的敏感性：单点优化没有分布级别的约束，不同种子给出的是同一目标下的不同落点，而不是同一分布下的不同样本。

VSD 针对这三个病症的机制是同一条：用 ∇log q 抵消 ∇log p 中「只往高密度挤」的分量。当 q 已经覆盖了目标分布的某个模式，粒子模型在该处的得分与冻结模型接近，差值变小，更新自然减弱；当 q 遗漏了某个模式，粒子模型在该处的密度低，∇log q 与 ∇log p 的差把粒子推向遗漏区域。这就是多样性得以保留的原因。用公式看，KL 梯度 E_q[∇log q − ∇log p] 在 q 与 p 匹配时为零，在 q 过窄时非零且指向展宽方向。SDS 缺少的正是 −∇log q 这一项，所以它只有「往 p 挤」的力，没有「按 q 的实际密度校正」的力。

代价是显式的：VSD 需要额外一个粒子模型，显存与时间开销都高于 SDS；超参也更多，包括粒子模型的学习率、更新频率、rank、条件输入 c 的选择、噪声权重 w(t) 的形状。这些超参没有一个是装饰性的：rank 决定粒子模型能表达多复杂的得分，更新频率决定跟踪滞后，w(t) 决定不同噪声水平上两个得分差的相对权重。一个具体例子是 rank=64 的粒子 LoRA：rank 太低时粒子模型无法区分 q 的多个模式，差值退化为常数偏移，多样性改善有限；rank 过高而样本少时粒子模型过拟合，梯度方差上升。工程判断因此不是「要不要上 VSD」，而是「粒子模型的容量与更新节奏能否跟上 q 的移动速度」。

四 · 常见误解之一：VSD 只是给 SDS 加了个正则项

最常见的误解是把 VSD 读成「SDS 加一个正则」。按这种读法，ε_ψ 被当成一个固定的先验网络，差值被当成对 SDS 梯度的惩罚。这个读法在公式上似乎成立，因为确实出现了两项相减；但在机制上它漏掉了最关键的一点：ε_ψ 是用当前渲染图训练的，它随 q 更新。固定正则项不会随被优化的分布移动，因此它无法提供 ∇log q；只有随 q 更新的粒子模型才能近似当前分布的得分。把 ε_ψ 冻结，VSD 就退化为一个带偏置的 SDS，偏置的方向由冻结时的 q 决定，之后 q 移动，偏置不再对应真实密度，多样性改善随之消失。

这个误解的工程后果是超参配置错误：如果按「正则项」理解，会倾向于把粒子模型的学习率设得很低以求稳定，结果粒子模型长期滞后，差值里主要是旧分布的得分，更新方向系统性偏移。正确的理解要求把粒子模型视为对抗中的另一方，它的更新节奏是超参，不是可以关掉的开关。伪代码里 particle.update(x) 这一行不是可选项，它和 θ 的更新同属一个循环。一个可观察的判别方法是：把粒子模型的更新关掉，若生成多样性没有明显变化，说明粒子模型本来就没跟上 q；若多样性明显下降，说明它确实在提供 ∇log q。这个对照不需要实验数字，只需要看同一文本下多次采样的散布。

五 · 常见误解之二：两个噪声预测相减就是「去噪」

第二个误解是把 ε_φ − ε_ψ 当成一次去噪操作，以为差值直接给出干净图像的方向。实际上差值给出的是参数 θ 的更新方向，中间隔着渲染雅可比 ∂x/∂θ。噪声预测之差是在图像空间定义的量，它要经过雅可比才能变成 3D 参数的梯度；雅可比的结构决定了哪些参数方向被放大、哪些被抑制。渲染器对不同参数（几何、材质、光照）的敏感度不同，同一个图像空间残差传回参数空间后，各分量的权重并不相等。忽略雅可比，就会把 VSD 误读成「在图像上做两次去噪再相减」，从而低估渲染器在整条链路中的位置。

这个误解还会导致对失效条件的误判。当渲染器不可微或雅可比病态时，图像空间的差值再准，传不回参数空间也是无效更新；此时表现为损失下降但渲染结果不变，或者参数剧烈震荡。系统代价在这里体现为渲染中间量的存储：反传需要保留 x 对 θ 的依赖图，显存占用随渲染分辨率和参数规模上升。一个具体例子是粒子 LoRA rank=64 配合高分辨率渲染：冻结模型预测 0.8、粒子预测 0.5，差 0.3 在图像空间是一个标量场，但传到 θ 上时，几何参数与材质参数拿到的分量不同，若雅可比在某处接近奇异，该处的 0.3 会被放大成不稳定步长。工程上因此需要对雅可比做检查或对参数分组设不同学习率，而不是把差值直接乘一个全局 lr。

六 · 常见误解之三：粒子模型越准越好，与采样无关

第三个误解是认为粒子模型的精度是单调收益：越准越好，且与最终采样策略无关。按 KL 梯度的定义，粒子模型越准，E_q[∇log q − ∇log p] 越接近真实变分梯度，这似乎支持「越准越好」。但粒子模型的精度是在当前 q 的样本上定义的，q 本身在移动，精度是一个移动目标上的瞬时量。过度追求单步精度会让粒子模型过拟合当前少量渲染样本，∇log q 的方差上升，梯度噪声增大，反而损害分布级别的收敛。精度与稳定性之间存在权衡，这个权衡由粒子模型的容量、更新频率与每步样本数共同决定。

与采样无关的说法也不成立。VSD 优化的是分布 q，最终要从 q 中采样得到具体的 3D 资产。粒子群的散布、粒子模型的条件输入 c、噪声权重 w(t) 都会影响采样时各模式的相对权重。若粒子模型在某些区域欠拟合，q 在这些区域的密度被低估，采样会避开这些区域，即使文本描述了它们。因此「粒子越准越好」应改为「粒子模型在 q 覆盖的区域上足够准，且其误差不系统性地偏向某个模式」。工程判断是看粒子群在参数空间的分簇是否与文本描述的模式对应，而不是只看单步去噪残差。失效条件在这里汇合：额外粒子模型带来显存与时间开销，超参多带来调参负担，二者都不是靠提高粒子精度能消除的；它们是分布级优化的固有成本，需要在系统层面预算，而不是在算法层面回避。
