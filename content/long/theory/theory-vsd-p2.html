二 · 从 KL 到噪声差：VSD 梯度的逐步推导

VSD 的推导起点是一个分布层面的目标，而不是单点重建目标。设 3D 参数为 θ，其当前分布为 q(θ)，文本条件目标分布为 p(θ|y)。我们希望最小化两者之间的 KL 散度。写成期望形式，KL(q‖p) 对 q 的梯度是 E_q[∇log q(θ) − ∇log p(θ|y)]。这个式子的含义很直接：如果某个 θ 在当前分布 q 下出现得多（∇log q 大），而文本分布 p 并不偏好它（∇log p 小），梯度就会把它往外推；反之则把它往里拉。注意这里梯度是对 θ 求的，不是对渲染图 x 求的，因此必须通过链式法则把图像空间的得分传回参数空间。

关键一步是把 θ 空间的得分换成图像空间的噪声预测差。扩散模型在噪声水平 t 上给出的 ε_φ(x_t;y,t) 与 ∇log p_t(x_t|y) 成比例（差一个负的尺度因子），这是去噪得分匹配的标准结论。同理，粒子模型 ε_ψ(x_t;c,t) 近似 ∇log q_t(x_t)，其中 c 是粒子模型自己的条件输入（在 VSD 中通常就是渲染图本身或空条件，取决于实现）。于是 θ 空间的两个得分分别被替换为两个噪声预测，再乘以渲染雅可比 ∂x/∂θ。整个替换链条是：KL 梯度 → θ 空间得分差 → 图像空间得分差 → 噪声预测差 → 雅可比回传。每一步都只是变量替换，没有引入新的近似假设，唯一的近似来自粒子模型对 q 的拟合精度。

$$\nabla_\theta\mathcal{L}_{\mathrm{VSD}}=\mathbb{E}\!\left[w(t)\big(\epsilon_\phi(\mathbf{x}_t;y,t)-\epsilon_\psi(\mathbf{x}_t;c,t)\big)\frac{\partial \mathbf{x}}{\partial\theta}\right]$$

逐符号解释这张公式。ε_φ 是冻结的文本条件扩散模型，参数 φ 不更新；ε_ψ 是粒子模型，参数 ψ 随训练更新；x_t 是渲染图 x 加噪到时刻 t 的结果；w(t) 是噪声水平权重，用来平衡不同 t 上的梯度量级；∂x/∂θ 是渲染器对 3D 参数的雅可比，把图像空间的更新方向转成参数空间的更新方向。期望 E 同时对噪声采样、时刻 t 采样和当前 θ 分布采样。整个括号内的差 (ε_φ − ε_ψ) 就是“文本模型认为该往哪去”减去“当前 3D 分布认为该往哪去”，剩下的部分才是真正把分布推向文本的净方向。

一个必须说清的机制细节：粒子模型不是固定目标，它每步都在跟着 q 变。这使 VSD 的目标函数不是静态的，而是一个随 θ 演化的对抗式最小化。如果把粒子模型冻结在初始状态，那么 ε_ψ 近似的是初始分布 q_0，梯度会把 θ 拉向“远离 q_0 且靠近 p”的方向，但随着 θ 移动，ε_ψ 越来越不准，梯度会失真。粒子模型必须用当前渲染图在线更新，才能让 ∇log q 始终对准当前的 q。这也是 VSD 与 SDS 在实现上的分水岭：SDS 只有一个冻结模型，VSD 有两个模型且其中一个在动。

系统代价在这里第一次显现。粒子模型要在线训练，意味着每步除了前向渲染和冻结模型前向之外，还要多一次粒子模型前向、一次反向传播和一次参数更新。显存上要同时驻留冻结扩散模型和粒子模型（后者常用 LoRA 形式以控制参数量），时间上每步的开销至少翻倍。失败模式也很具体：如果粒子模型更新太快，它会过拟合当前单张渲染图，ε_ψ 退化成对单点的记忆，分布信息丢失，VSD 退化为 SDS；如果更新太慢，ε_ψ 滞后于 q，梯度方向系统性偏移，生成结果出现重复纹理或局部塌缩。这个“快慢”没有普适取值，只能靠监控粒子模型在留出渲染图上的去噪误差来判断。

三 · 数值例子：0.8 与 0.5 之差如何变成更新方向

用一个最小例子把公式跑一遍。设某步渲染出图 x，加噪到 t 后送入两个模型。冻结文本模型预测噪声 ε_φ = 0.8（在某个像素通道上），粒子模型预测 ε_ψ = 0.5。差为 0.3。这个 0.3 不是抽象数字，它表示：文本模型认为该像素当前被噪声污染的程度比粒子模型（即当前 3D 分布）所认为的更深，因此文本模型倾向于更强的去噪，也就是把该像素往文本描述的方向拉。梯度更新沿这个差乘以雅可比的方向走，θ 被推着让渲染结果更接近文本模型所偏好的去噪目标。

把这个例子放到粒子 LoRA 的配置上：rank=64，每步用当前渲染图训练一次去噪。rank=64 意味着粒子模型的可训练参数被压在一个低秩子空间里，它不可能记住全部图像细节，只能捕捉当前分布的主要得分方向。这正好匹配 VSD 的需要——粒子模型要近似的是分布的整体梯度，而不是单张图的精确噪声。每步训练一次去噪，意味着粒子模型在每次 θ 更新后立刻吸收新的渲染图，保持 ε_ψ 与 q 的同步。如果改成每十步才更新一次粒子模型，那么在中间九步里 ε_ψ 描述的是旧的 q，差 (ε_φ − ε_ψ) 会混入“旧分布残留”，表现为生成结果在几个模式之间来回跳。

再看 w(t) 的作用。不同 t 上的噪声预测差量级不同：t 很大时图像接近纯噪声，两个模型都只能给出粗粒度判断，差值的信噪比低；t 很小时图像接近清晰，粒子模型容易过拟合到具体纹理，差值被细节主导。w(t) 就是用来压掉这两端的权重，让梯度主要来自中间噪声水平。工程上常见的做法是给 w(t) 一个钟形或分段常数形状，但具体形状依赖渲染器和数据，不能照搬。失败模式是 w(t) 设置不当导致某一端主导：若大 t 权重过高，梯度方向抖动大，θ 更新不稳定；若小 t 权重过高，粒子模型过拟合细节，多样性下降。

多样性从这个例子里可以直接读出。粒子越准，ε_ψ 越接近真实的 ∇log q，差 (ε_φ − ε_ψ) 越接近真实的分布梯度，θ 的更新就越能覆盖 p(θ|y) 的多个模式，而不是塌缩到单点。反之，若粒子模型欠拟合，ε_ψ 系统性偏小或偏大，差值被偏置，所有 θ 被推向同一个方向，多样性丢失。这就是为什么 VSD 的多样性不是靠额外正则项买来的，而是靠粒子模型的拟合质量自然得到的。代价是：要维持粒子模型的拟合质量，就得付出在线训练的开销，并且要仔细调粒子模型的学习率、更新频率和 rank。

四 · 伪代码思路：一次 vsd_step 里发生了什么

把上面的推导落成一次迭代。伪代码的核心是四步：渲染、双模型前向、参数更新、粒子更新。渲染得到 x；对 x 加噪得到 x_t；冻结模型给出 ε_φ，粒子模型给出 ε_ψ；用差值乘雅可比更新 θ；最后用当前 x 更新粒子模型。顺序不能乱：粒子更新必须在 θ 更新之后或至少用更新前的 x，否则 ε_ψ 描述的是更新后的分布，而梯度用的是更新前的 q，两者错位。工程实现里通常在同一步内先算梯度再更新粒子，保证一致性。

雅可比 ∂x/∂θ 是伪代码里最容易被低估的一项。对显式 3D 表示（网格、点云），雅可比可以通过渲染器的可微实现自动求导得到；对隐式表示（NeRF 类），雅可比要穿过体积渲染的积分，计算量大且数值上容易不稳定。失败模式是雅可比近似误差：若用有限差分近似雅可比，步长选大了方向偏，选小了被浮点噪声淹没，梯度更新出现高频抖动。系统代价上，雅可比回传是每步计算量的大头，尤其在高分辨率渲染下，反向传播的显存占用与分辨率成正比。

伪代码思路可以写成如下结构（文字描述，不展开为代码块）：输入 θ、粒子模型、文本 y；渲染 x = render(θ)；采样 t 和噪声，构造 x_t；计算 eps_phi = diffusion(x_t, y, t)；计算 eps_psi = particle(x_t, c, t)；计算梯度 g = w(t) * (eps_phi − eps_psi) * jacobian(x, θ)；更新 θ ← θ − lr * g；用 x 和同样的 t 采样更新 particle。注意粒子模型的输入 c 在不同实现里可能是渲染图、空条件或文本，这决定了 ε_ψ 近似的是 q(x) 还是 q(x|y)，前者对应无条分布的得分，后者对应条件分布的得分，两者在公式里的位置不同，不能混用。

超参多是这套伪代码的固有代价。至少涉及：θ 的学习率、粒子模型的学习率、粒子更新频率、粒子 rank、w(t) 的形状、每步采样的 t 分布、每步渲染的视角数。这些超参之间耦合：粒子学习率大时更新频率要降，否则粒子震荡；w(t) 偏重大 t 时 θ 学习率要降，否则更新不稳。没有一组通用取值，调参只能靠观察两个信号：粒子模型在留出视角上的去噪误差（衡量 ε_ψ 是否准），以及生成结果的多样性（衡量梯度是否覆盖多个模式）。前者升说明粒子滞后，后者降说明粒子过拟合。

五 · 失效条件的机制解释：为什么这套推导会崩

第一个失效条件是额外粒子模型带来的显存压力。冻结扩散模型本身已经占据大量显存，再叠加一个 rank=64 的 LoRA 粒子模型和它的优化器状态，显存占用显著上升。在高分辨率渲染下，雅可比回传的激活值又占一块，三者叠加容易触发显存上限。机制上的后果不是简单的报错，而是被迫降低 batch 或分辨率，进而降低梯度的估计质量，噪声差 (ε_φ − ε_ψ) 的方差变大，θ 更新抖动。这是一个连锁失效：显存限制 → 估计质量下降 → 梯度不稳 → 生成质量下降。

第二个失效条件是时间开销。每步两次模型前向加一次粒子反向，相比 SDS 的单次前向，单步时间明显增加。机制上，粒子模型的在线训练把“生成”变成了“生成加训练”的交替过程，训练部分的收敛速度决定了整个流程能否在可接受步数内完成。若粒子模型收敛慢，它在整个生成过程中都处于欠拟合状态，ε_ψ 系统性偏离 ∇log q，梯度被偏置，表现为生成结果偏向某个局部模式。时间开销与粒子 rank 直接相关：rank 越大，粒子拟合能力越强但每步训练越慢，rank 越小越快但欠拟合风险越高。

第三个失效条件是超参耦合导致的退化。前面说过粒子更新过快会退化为 SDS：ε_ψ 过拟合当前单张渲染图，差值 (ε_φ − ε_ψ) 变成“文本模型减单图记忆”，分布信息被抹掉，多样性与 SDS 无异。这个退化不是渐进的，而是有阈值的：当粒子模型的有效容量足以记住单张图时，它就不再近似分布。rank=64 是一个经验上的折中，容量不足以记住整图但足以捕捉主要得分方向。失效的另一个方向是粒子更新过慢，ε_ψ 滞后，梯度方向系统性偏移，生成结果出现重复结构。两个方向都指向同一个工程判断：粒子模型的拟合精度必须与 θ 的移动速度匹配，而这个匹配只能通过监控留出视角的去噪误差来维持。

还有一个容易被忽略的失效点：条件输入 c 的选择。若粒子模型用文本条件训练，它近似的是 q(x|y)，那么公式里的 ε_ψ 就不是无条分布的得分，KL 推导中的 ∇log q 被替换成了 ∇log q(·|y)，目标函数悄悄变成了条件分布之间的比较，梯度含义改变。若粒子模型用空条件或渲染图自身训练，它近似的是无条 q(x)，与推导一致。这个选择不改变公式外形，但改变公式含义，是实现中最容易出错的地方之一。工程上要在代码里显式标注 c 的来源，避免在换实现时把两种语义混用。

六 · 工程判断：推导给出的可检验信号

推导的价值不在于公式好看，而在于它给出了可检验的量。第一个可检验量是 ε_ψ 的拟合误差：在留出视角上，用当前粒子模型对渲染图加噪后做去噪，比较预测噪声与注入噪声的差。这个误差直接对应 ∇log q 的近似精度，误差小说明粒子准，VSD 接近真实分布梯度。第二个可检验量是差值 (ε_φ − ε_ψ) 的统计特性：若其均值系统性偏离零且方差小，说明梯度方向一致但可能偏置；若方差大，说明粒子与文本模型冲突严重，θ 更新不稳。这两个量都可以在训练循环里低成本地记录，不需要额外实验。

从推导还能读出一个结构性判断：VSD 的多样性上限由粒子模型的容量决定，而不是由冻结模型决定。冻结模型给出的是文本分布的方向，粒子模型给出的是当前分布的方向，两者相减后剩下的净方向能覆盖多少模式，取决于粒子模型能否准确描述 q 的多峰结构。rank=64 的 LoRA 能描述多少峰，取决于数据本身的复杂度，没有先验答案。工程上的做法是先用小 rank 跑通流程，观察多样性是否随 rank 增加而提升，若提升饱和则说明粒子容量已够，若继续提升则说明之前欠拟合。这个判断不需要知道真实分布，只需要比较不同 rank 下的生成多样性。

最后一个工程判断关于雅可比。推导里 ∂x/∂θ 是精确的链式法则项，但实现里它常被近似。判断近似是否可接受的标准不是看单步梯度，而是看多步累积后 θ 是否收敛到稳定区域。若雅可比近似误差大，θ 会在最优点附近持续抖动，表现为渲染结果的细节在高频上变化而整体结构不变。这时降低 θ 学习率只能压住抖动，不能消除偏置，正确的做法是提高雅可比的计算精度或改用可微渲染的精确反向。这个判断把推导里的一个符号变成了调试时的具体观察对象：抖动频率对应雅可比误差的量级，结构漂移对应粒子模型的偏置。
