一 · 一句话的物理含义：沿视线做加权平均

把体渲染压缩成一句话，并不是修辞上的简化，而是把整条渲染管线还原成一个可执行的心智模型：从相机原点 o 出发，沿方向 d 射出一条射线 r(t) = o + td，在射线上取若干采样点，逐点询问三维场「这里的密度 σ 是多少、朝这个方向发出的颜色 c 是多少」，然后按「近处遮挡远处」的规则把这些贡献累加成一个标量颜色值。这句话里藏着三个独立的子问题：查询（场如何被访问）、加权（透射率如何衰减）、累加（离散求和如何逼近积分）。工程上任何一个体渲染系统的性能与画质差异，几乎都能归因到这三个子问题的不同取舍。

「加权平均」这个说法需要精确化。它不是对颜色做算术平均，而是以透射率 T(t) 为权重的加权和，且权重之和小于等于 1——剩余的部分代表光线穿透场后到达背景的那部分能量。这一点是体渲染与普通表面渲染的分水岭：表面渲染的像素颜色来自唯一一个可见表面点，而体渲染的像素颜色是整条射线上所有发光与吸收介质的合成结果，像素背后没有「一个点」，只有一段区间。

举一个可以直接手算的例子。一条射线取 64 个点，前 10 个点密度为 0，第 11 个点 σ = 50、δ = 0.01。该点的不透明度 α = 1 − exp(−50 × 0.01) = 1 − exp(−0.5) ≈ 0.39。由于前 10 个点密度为零，到达该点的透射率为 1，若该点颜色为红，像素首先获得 0.39 的红；剩余透射率 0.61 继续向后传递，后面的点按 0.61 的折扣叠加。这个例子说明两件事：其一，α 不是密度本身，而是密度与步长的乘积经过指数饱和后的结果；其二，透射率是逐点连乘的，任何一个高密度采样点都会永久性地削减后续所有点的可见度。

二 · 严格定义：积分形式与各项的职责

连续形式的体渲染积分写成：

$$C(\mathbf{r})=\int_{t_n}^{t_f}T(t)\,\sigma(\mathbf{r}(t))\,\mathbf{c}(\mathbf{r}(t),\mathbf{d})\,\mathrm{d}t,\qquad T(t)=\exp\!\left(-\int_{t_n}^{t}\sigma(\mathbf{r}(s))\,\mathrm{d}s\right)$$

四个符号各有明确职责。σ 是体积密度，单位是长度的倒数，量纲上必须与 dt 相乘才能成为无量纲的光学厚度；c 是颜色，通常是 RGB 三通道，且允许依赖观察方向 d，这正是各向异性发光介质（例如带视角相关高光的云雾）能被表达的原因；T 是透射率，定义为从近端 t_n 到当前点 t 的密度积分的负指数，取值在 (0, 1] 内单调不增；C 是最终像素值，是一个与射线一一对应的标量三元组。注意积分上下限 t_n 与 t_f 不是数学装饰：它们把无限长的射线截断到有意义的一段，近端截断避免相机所在位置的介质被计入，远端截断避免无界场的积分发散，同时它们直接决定了采样预算该花在哪里。

透射率的指数形式不是任意选择。若把介质建模为一串相互独立的吸收事件，则光线在穿过厚度 Δt、密度 σ 的一小段后未被吸收的概率为 exp(−σΔt)，这一形式保证了可加性：穿过两段的透射率等于两段透射率之积，即 T(t₂) = T(t₁)·exp(−∫σ)。可加性是整个体渲染能够被离散化并保持物理一致性的根基，也是反向传播时梯度能沿射线正确分配的前提。

把积分区间切成 N 段，每段内假定密度近似为常数，一段的光学厚度为 σ_i δ_i，该段的不透明度为 α_i = 1 − exp(−σ_i δ_i)，按从前到后的 alpha 合成规则累加，就得到离散体渲染公式：

这个式子的结构值得逐项核对：T_i 只依赖第 i 段之前的所有段，因此计算可以严格按前向顺序单遍完成，无需存储整条射线的中间量；α_i 只依赖本段的 σ 与 δ，因此每段的颜色贡献可以独立求出再乘以前缀透射率。当 δ 趋于 0 时，离散和收敛到连续积分——这是该离散化被称为「近似」而非「另一种模型」的理由。工程上 δ 不可能趋于 0，于是所有离散体渲染的伪影本质上都是这个极限没有取到所留下的残差。

三 · 为什么需要它：可微性与 2D 监督的反传通道

体渲染积分存在的核心理由不是「画得好看」，而是它把「3D 场 → 2D 像素」这个过程写成了一个对场参数可微的公式。只要 σ 与 c 由某个参数化表示（多层感知机、体素网格、高斯集合、哈希编码加小网络）给出，那么像素误差对场参数的梯度就可以通过这条积分链一路回传：像素颜色对某段颜色的偏导是 T_i α_i，对某段密度的偏导则同时包含「本段变浓使自身贡献增加」与「本段变浓使后续所有段被削弱」两项。第二项是体渲染梯度里最容易被忽视的部分，它让密度参数在优化早期就能收到来自远处像素的抑制信号，而不是等到颜色参数先拟合出形状后才被动调整。

正因为这条通道存在，才有可能只用一组多视角 2D 图像监督一个 3D 场，而不需要任何 3D 真值。这是神经辐射场类方法能够成立的前提：监督信号在 2D，参数在 3D，中间唯一的桥梁就是体渲染积分。反过来，如果渲染过程不可微（例如硬表面光栅化中的可见性判断是离散的），2D 误差就无法稳定地分配到 3D 参数上，优化会停在可见性边界反复跳变的状态。

可微性也带来了明确的系统代价。每条射线要查询 N 次场函数，每次查询可能是一次多层感知机前向，于是单像素成本与 N 成正比，而整帧成本与「像素数 × N」成正比。这就是为什么早期实现必须靠分层采样压缩 N：先用粗采样定位密度集中的区间，再在该区间内做细采样。给定事实中 NeRF 采用 64 粗 + 128 细的采样配置，正是这一代价结构的直接产物——粗阶段用较少查询找到可能有物体的区间，细阶段把查询预算集中投进去，避免在空区间上浪费前向计算。

另一个代价来自梯度本身的方差。由于 T_i 是前缀连乘，靠近相机的采样点对最终像素的影响被放大，靠近远端的点影响被指数压低，梯度在射线方向上呈严重的不均衡分布。工程上的表现是：优化初期相机近处的伪影（浮絮、雾状壳层）收敛得比远处结构快得多，且一旦近处形成高密度「遮挡墙」，远端梯度会被压到接近零，重建就此停滞。这不是调参能彻底解决的问题，而是积分结构自带的失效模式，通常需要靠密度正则、噪声注入或采样分布调整来缓解。

四 · 常见误解之一：像素颜色等于某个表面点的颜色

最普遍的误解是把体渲染的输出当成「找到了一条射线上的表面，然后取该表面的颜色」。在体渲染里不存在「找到表面」这一步：密度场是连续的，没有内建的可见性判定，像素值是整段区间上所有非零密度点的加权和。一个密度为 50、步长为 0.01 的点给出 α ≈ 0.39，意味着这个点只贡献了 39% 的不透明度，仍有 61% 的光线穿过去看到后面的东西。只有当 σδ 足够大时 α 才逼近 1，介质才表现得像不透明表面。换句话说，「表面感」是从高密度区域自然涌现的视觉效果，而不是渲染器显式提取的几何对象。

这个误解会直接导致错误的工程判断。若开发者按表面渲染的思维去调参，会倾向于把密度推到极大值以求「干净」的边缘，结果得到的是硬边、锯齿状的壳层，且梯度在壳层内部几乎为零，细节无法继续优化。正确的做法是理解 α 的饱和曲线：α 对 σδ 的响应在低值区近似线性，在高值区指数饱和，因此形状的精细程度主要取决于中等密度区间的分布，而不是把密度推向极端。

与之配套的第二个误解是「提取网格是免费的」。既然密度场没有明确表面，那么用等值面提取（如 marching cubes）把密度场转成三角网格，就必然要在没有明确表面的场上强行定义一个阈值，噪声被放大成碎片化的面片，薄结构被阈值直接抹掉。给定事实把「密度场无明确表面，提取网格噪声大」列为失效条件，正是这个误解的代价：体渲染的优势恰恰在于它不需要表面，一旦退回到表面表示，就同时失去了体积细节和可微性的一部分优势。

五 · 常见误解之二：采样越密越接近真值，以及薄结构的漏检

第二个误解是认为只要把 N 调大，离散和就必然更接近连续积分，画质单调提升。数学上收敛性成立，但工程上不成立：N 增大使单像素成本线性上升，而误差的下降并不是均匀的。误差主要来自密度在段内被近似为常数这一假设，当射线穿过密度剧烈变化的区域（薄片、丝状结构、边界）时，段内常数假设失效，增大 N 只是把失效区间切得更碎，并不会自动把漏掉的薄结构找回来。

薄结构漏检的机制很具体：若某层薄结构的厚度远小于采样步长 δ，且采样点恰好落在结构两侧的空隙中，则该结构对整条射线的贡献为零，无论 N 多大都无法补救——因为采样点根本没有落在结构内部。这是纯离散采样固有的失效条件，给定事实明确列出「离散采样会漏掉薄结构」。缓解手段不是盲目加 N，而是改变采样分布：让采样点密度与预期密度相关（分层采样、重要性采样），或引入抖动使采样点在多次迭代中随机偏移，让薄结构在期望意义上被覆盖到。

下面的伪代码把这一节的机制固定下来，它同时暴露了三个工程接口：采样位置 ts、密度查询 sigma_fn、颜色查询 color_fn。

def render(ray, sigma_fn, color_fn, N=64):
ts = linspace(t_n, t_f, N)
T = 1.0; C = 0.0
for i, t in enumerate(ts):
  s = sigma_fn(ray(t)); c = color_fn(ray(t))
  a = 1 - exp(-s * dt)
  C += T * a * c
  T *= (1 - a)
return C

这段代码里有两个容易被忽略的细节。其一，dt 必须是相邻采样点的实际间距，若 ts 非均匀，dt 需逐点计算，否则 α 会系统性偏大或偏小；其二，循环中 T 的更新用的是 (1 − a) 而不是 exp(−σδ)，两者在数学上等价，但前者在数值上更稳定，且与 alpha 合成的硬件语义一致。失效模式也很清楚：当射线穿过高密度区时 T 迅速衰减到机器精度以下，后续循环仍在做无意义的查询与累加，这是纯算力浪费，工程上通常以 T 小于某个阈值时提前终止来截断。

六 · 常见误解之三：显式表示与采样是同一件事

第三个误解是把「体渲染必须逐点采样」当成不可动摇的前提，从而认为所有体积表示都必然付出每像素 N 次查询的代价。事实上积分形式与场的表示方式是解耦的：积分只要求能对任意点求 σ 与 c，并不要求逐点查询。显式高斯泼溅类方法把场表示为一组带位置、协方差、颜色与不透明度的高斯基元，渲染时把这些基元按深度排序后投影到屏幕并做 alpha 合成，从而绕开了沿射线逐点查询的循环。给定事实指出这类方法「用显式高斯替代采样，渲染快两个量级」，这个量级差异的来源不是数学近似更粗糙，而是计算结构从「每像素 N 次场查询」变成了「每像素与投影覆盖它的基元数成正比」，而后者通常远小于 N。

这个对比给出的工程判断是：体渲染积分是问题的定义，采样只是求解它的一种手段。当场的表示是隐式的、只能被查询时，逐点采样几乎是唯一选择，代价结构由 N 决定；当场的表示是显式的、可以被投影和排序时，积分可以被解析地或近似解析地求出，代价结构由基元数量与屏幕覆盖率决定。两种路线的画质差异往往来自表示能力与优化难度，而不是积分本身——积分公式是同一个。

由此可以归纳出本部分要立的判断标准：评价一个体渲染实现，先问它的场表示是什么、采样预算花在哪里、透射率前缀是否被正确维护，再问它的画质。只盯着 N 的大小或只盯着网络结构，都无法解释系统行为。密度越大、间距越大，α 越接近 1，表面越不透明——这条饱和关系是理解一切体渲染参数取舍的出发点，也是后续讨论采样策略与梯度分配时反复要回到的机制。
