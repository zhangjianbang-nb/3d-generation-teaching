一 · 离散化的三个失效面：漏采、混叠与无表面

体渲染公式在连续域里是精确的，但工程实现永远落在离散采样上。失效不是"精度不够"这种笼统说法，而是三个可以分别定位的机制。

第一个是漏采。离散和用 N 个点近似积分，等价于假设每段 δ 内密度与颜色为常数。若某段内存在厚度远小于 δ 的高密度薄片，采样点恰好落在薄片之外，该段的 σ 被估成接近 0，α_i=1−exp(−σ_iδ_i) 也随之接近 0，薄片在像素里彻底消失。注意这不是"变淡"，而是零贡献：透射率 T_i 不衰减，后面的点照常叠加，像素结果与薄片不存在时完全一致。薄结构的可见性取决于采样相位，而不是它的光学厚度。

第二个是混叠。当 δ 与场景中的密度变化尺度可比时，采样点的微小位移会让 α_i 在 0 与接近 1 之间跳变，相邻像素因此出现高频闪烁。体渲染没有像表面渲染那样的几何抗锯齿手段，α 合成的非线性（T 的连乘）让抖动无法用简单的多点平均消掉：平均 α 不等于 α 的平均，因为 T 是乘积链。

第三个是无表面。密度场 σ(x) 是连续标量场，等值面提取（marching cubes 之类）要把 σ 阈值化成网格，阈值取高则细结构断裂，取低则整片雾状区域被误判为实体，网格顶点噪声大、拓扑不稳定。体渲染绕开了网格提取，代价是把"表面在哪里"这个问题彻底交给积分：像素颜色是沿射线所有贡献的加权和，没有任何一个变量直接回答"命中点在哪"。

三个失效面共享同一个根源：积分对采样密度的要求由场景中最薄的结构决定，而最薄结构的尺度在渲染前未知。固定 N 的采样策略必然在某个场景上失效，这就是自适应采样的动机。

二 · 重要性采样与粗细两阶段：把样本花在有贡献的区间

均匀采样把 N 个点平铺在 [t_n, t_f] 上，绝大多数样本落在空区或已完全不透明的区，对 C(r) 的贡献接近零。重要性采样的目标是让样本密度正比于被积函数 T(t)σ(t)c(t,d) 的模，但 T(t) 本身依赖 σ 的积分，无法先验得知，于是采用两阶段近似。

粗阶段用较少样本均匀铺满区间，得到一条粗略的权重曲线。对每个粗样本计算离散权重 w_i=T_i(1−exp(−σ_iδ_i))，这些 w_i 之和近似为 1（在不透明场景中），可视为分段常数概率密度。细阶段按此密度逆变换采样：把 w_i 归一化成累积分布，对每个细样本在对应段内均匀取位置。伪代码思路如下：

$$p_i=\frac{w_i}{\sum_j w_j},\qquad u\sim U(0,1),\quad \text{在累积分布上反解出段号 } i,\ t= t_i+\xi\,\delta_i$$

细样本的 α 与 T 重新按原始公式计算，而不是复用粗阶段的权重，否则会引入粗采样的偏差。两阶段的总代价是 N_coarse+N_fine 次 σ 与 c 的网络求值，粗阶段的作用仅是"指出哪里值得细看"。

系统代价体现在两处。其一，粗阶段若漏掉薄结构，细阶段不会凭空找回它——重要性采样只能加密已有权重的位置，不能发现权重为零的区域。其二，两阶段的样本数分配是超参数，粗样本太少则权重曲线失真，细样本全落在错误区间；粗样本太多则失去节省算力的意义。这是一个没有普适最优值的权衡，只能按场景的深度复杂度调。

具体例子：一条穿过烟雾的射线，前 10 个采样点 σ=0，第 11 个点 σ=50、δ=0.01，α≈0.39。粗阶段若恰好采到该点，w 集中在第 11 段，细阶段会把大部分样本压进这一小段 δ 内，像素颜色被精确估计；粗阶段若跨过该点，权重曲线整体接近零，细阶段均匀铺开，0.39 的红被摊薄到多个样本上，结果依赖采样相位。同一个场景，两种粗采样相位给出不同的像素值，这是体渲染中"结果不可复现"的典型来源。

三 · 系统取值：显式表示与隐式场的两条路线

采样策略之外，第二个系统级决策是"σ 和 c 从哪来"。这决定了渲染成本的数量级。

隐式路线把 σ、c 交给一个神经网络，输入是空间坐标（和方向），输出密度与颜色。渲染一个像素需要沿射线做 N 次前向推理，每次推理是一次多层感知机求值。粗 64 加细 128 的配置意味着单像素约 192 次网络前向，一张图百万像素就是上亿次推理。这个成本结构决定了隐式路线必须靠批处理、缓存和降分辨率来摊薄，训练时的反向传播还要再乘一次。失效模式是网络容量与场景细节的错配：网络在薄结构处输出平滑的密度，采样再密也恢复不出被网络抹掉的细节。

显式路线用一组带位置、协方差、不透明度和颜色参数的高斯原语直接表示场，渲染时把高斯投影到屏幕并按深度排序做 alpha 合成。它不做沿射线的点采样，而是把"沿射线的积分"改写成"对投影后原语的排序合成"。样本数从每像素上百次降到每像素命中的原语数，且原语数由场景复杂度而非采样超参数决定。给定事实给出的量级是：显式高斯替代采样后渲染快两个量级。两个量级不是渐进收益，而是成本结构的改变——从"每像素固定 N 次求值"变成"每像素与可见原语数成正比"。

维度隐式场 + 采样显式高斯
每像素求值次数N_coarse+N_fine 次网络前向命中的投影原语数
成本随场景变化近似固定，与细节无关随原语数与重叠度增长
薄结构受采样相位与网络平滑双重影响由原语尺度决定，可显式调小
内存网络权重，与场景规模弱相关原语参数，随场景线性增长

显式路线的代价转移到了排序与内存：原语按深度排序在视点变化时需要重排，重叠严重时每像素合成的原语数上升，两个量级的优势在极端重叠场景会被侵蚀。隐式路线的代价则是每次求值的固定开销无法随场景简化而下降，空区采样照样要跑网络。

四 · 与相邻理论的边界：表面渲染、体积雾与辐射传输

体渲染积分与三个相邻理论容易混淆，差别在于"贡献沿射线如何分布"。

与表面渲染的差别在 δ 的角色。表面渲染假设不透明度集中在零测度的曲面上，α 只有 0 和 1 两种极限，深度由最近的命中面决定，遮挡是布尔运算。体渲染把不透明度摊在正测度的区间上，α_i=1−exp(−σ_iδ_i) 随 δ 连续变化，遮挡是乘性的透射率衰减。当 δ→0 且 σ→∞ 而乘积 σδ 有限时，离散和收敛到连续积分，此时体渲染退化为沿射线的冲激叠加，才与表面渲染的极限一致。工程上两者的混合（半透明表面加体积雾）必须分别处理：表面用深度排序，雾用积分，交界处的排序错误会产生可见的合成瑕疵。

与体积雾的差别在物理完备性。图形学里的雾常写成 C=C_surface·T+C_inscatter 的经验式，T 用距离的指数衰减，inscatter 用常数环境色。体渲染积分是它的推广：σ 和 c 都是空间与方向的函数，T 由 σ 的路径积分定义而非预设的指数形式。雾模型是体渲染在均匀介质、单次散射、常色假设下的特例。把雾模型直接套到非均匀密度场会系统性低估近处高密度区的遮挡。

与辐射传输方程的差别在散射的处理。完整的辐射传输要解沿方向的微分-积分方程，包含多次散射的入射辐射项 L_i。体渲染积分 C(r)=∫Tσc dt 实质是单次散射加自发光近似：c(r(t),d) 被视为该点的出射辐射，不再展开成对其他方向的积分。这个近似在光学薄介质中成立，在光学厚介质（多次散射主导）中会低估亮度并错判颜色。失效条件是光学厚度 τ=∫σ dt 增大到与 1 可比以上时，单次散射假设开始偏离；具体偏离幅度取决于反照率，不能用一个阈值概括。

具体例子：同一密度场，用雾模型渲染得到的是均匀衰减加常色叠加；用体渲染积分渲染，近处 σ=50 的薄层贡献 0.39 的红并挡掉 0.61 的透射率，远处颜色被压暗。两者在薄层位置的像素值不同，差异正比于薄层的光学厚度。

五 · 练习：从公式到可验证的工程判断

练习的设计目标是让每个结论都能被手算或小规模实验证伪，而不是停留在公式改写。

  • 练习一（漏采判据）：给定一条射线、固定 N 与 δ，构造一个厚度为 δ/10、σ 使 α 接近 1 的薄片，计算它在多少个采样相位下被完全漏掉。结论应写成"可见概率与 δ/薄片厚度之比"的关系，而不是具体百分比。
  • 练习二（α 的非线性）：取两个相邻采样点，分别计算"先各自算 α 再平均"与"先平均 σ 再算 α"的结果，证明两者不等，并给出不等号方向随 σδ 变化的趋势。这是混叠无法用线性平均消除的直接证据。
  • 练习三（两阶段预算）：在固定总样本数 N_coarse+N_fine 下，扫描粗样本占比，观察像素估计的方差。找出方差开始上升的拐点，解释它对应粗权重曲线的分辨率极限。
  • 练习四（路线对比）：对同一场景分别用隐式场采样与显式原语合成实现，固定输出分辨率，比较每像素求值次数与薄结构的可见性。预期结论是显式路线在薄结构上更稳定，隐式路线在空区浪费求值。
  • 练习五（散射边界）：构造光学厚度从薄到厚的序列，比较单次散射体渲染与包含二次散射项的参考解，记录偏离开始可见的位置。结论写成"偏离随 τ 单调增长"，不给具体阈值。

每个练习都要求给出伪代码级别的实现思路与一个可观测的失败模式，例如练习一中"薄片可见性随相机微小移动跳变"就是漏采的直接观测信号。练习的目的不是复现某个数字，而是建立"公式的哪一项在什么条件下失效"的对应关系。

工程判断落在这里：体渲染积分的可靠性由采样密度与场景最薄结构的比值决定，而这个比值在渲染前不可知；因此任何固定 N 的实现都必须附带一个可观测的失败信号（像素随相位抖动、薄结构闪烁、粗细阶段权重曲线塌缩），否则失效是静默的。显式表示把这个问题转成原语尺度与排序成本，隐式表示把它转成网络平滑与采样预算，两条路线的选择取决于场景中最薄结构的尺度是否已知——已知则显式，未知则必须为隐式路线付出自适应采样的系统代价。
