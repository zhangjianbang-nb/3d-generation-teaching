二 · 从渲染到噪声：符号链条与雅可比的落点

要读懂 SDS 的梯度式，先把符号链条拆成四段。第一段是参数 θ，它可以是 NeRF 的密度与颜色 MLP 权重、高斯泼溅的均值/协方差/球谐系数，也可以是网格顶点的位移场。第二段是渲染函数 x = R(θ)，它把 θ 映射成一张 H×W×3 的图像；这一步是确定性的、可微的（或近似可微的），并且是整个 SDS 里唯一与 3D 表示强耦合的部分。第三段是前向加噪 x_t = √ᾱ_t·x + √(1−ᾱ_t)·ε，其中 ε∼N(0,I)，t 从离散或连续噪声日程里采样。第四段是冻结的 2D 扩散网络 ε_φ(x_t;y,t)，它输出对噪声的估计，y 是文本条件。

把这四段串起来，SDS 的更新方向就是「图像空间的噪声残差」乘上「图像对参数的雅可比」。噪声残差 ε_φ−ε 是一个与 x 同形状的张量，量纲上是噪声，不是像素；雅可比 ∂x/∂θ 则把每个像素的微小扰动线性映射回参数空间。两者相乘得到的是 θ 空间的一个向量，其维度与 θ 相同。这个乘法在实现上不是显式构造雅可比矩阵，而是反向传播：把 ε_φ−ε 当作渲染图 x 的伴随梯度（adjoint），对渲染器做一次反向即可得到 ∂x/∂θ 的转置作用。这就是为什么 SDS 能塞进任何可微渲染管线——它只要求渲染器支持对 x 求导，不要求对扩散模型求导。

$$\nabla_\theta\mathcal{L}_{\mathrm{SDS}}=\mathbb{E}_{t,\epsilon}\!\left[w(t)\big(\epsilon_\phi(\mathbf{x}_t;y,t)-\epsilon\big)\frac{\partial \mathbf{x}}{\partial\theta}\right]$$

权重 w(t) 的作用是平衡不同噪声等级下的残差量级。扩散模型在不同 t 上的噪声预测误差尺度并不一致：t 很小时 x_t 几乎就是原图，ε_φ 的残差主要反映高频细节；t 很大时 x_t 接近纯噪声，残差反映的是语义层面的方向。w(t) 通常取与信噪比相关的标量函数，工程上常直接取 1 或按日程做归一化，具体形式取决于所用扩散模型的训练配置。注意 w(t) 是标量，不改变梯度的方向，只改变其模长，因此它影响的是优化步长的有效尺度，而不是「往哪走」。

一个具体的数值例子：渲染一张 64×64 的图，取 t=500，扩散模型给出 ε_φ，真实噪声 ε 已知。若两者逐元素差的范数对应到某个像素上的差值为 0.3，w=1，那么该像素的伴随梯度就是 0.3。渲染器反向传播把这个 0.3 分摊到影响该像素的所有参数上：对 NeRF 而言，是沿该像素射线采样点上 MLP 权重的梯度；对高斯泼溅而言，是参与该像素混合的高斯球的均值与颜色梯度。一次更新后，渲染图的纹理向文本描述靠拢。整个流程重复约 15k 步，单资产耗时约 1.5 小时——这个量级说明 SDS 的代价主要不在单步计算，而在步数与每步的渲染+反向开销。

三 · 为什么它不是严格得分：省略项与有偏性

严格意义上的得分匹配会要求更新方向正比于 log p(x|y) 对 x 的梯度，再经链式法则传到 θ。扩散模型在噪声等级 t 上给出的 ε_φ 与得分的关系是 ε_φ ≈ −√(1−ᾱ_t)·∇_x log p_t(x_t)。若把这一项原样代入，得到的应是图像空间得分经雅可比传导的结果。SDS 的实际式子用的是 ε_φ−ε，而不是单纯的 ε_φ，也不是带系数的得分。这个差值在期望意义上近似于「当前噪声样本下模型认为的噪声与真实噪声之差」，它把扩散模型的预测与采样噪声做了对照，相当于用一次蒙特卡洛采样估计得分方向。

省略的项主要有两类。其一是得分对 x_t 的显式依赖在链式法则中产生的额外项：严格推导中，∇_θ log p_t(x_t) 会包含 ∂x_t/∂x 与 ∂x/∂θ 的复合，而 SDS 直接把 ε_φ−ε 当作 x 的伴随，跳过了对 x_t 分布的进一步展开。其二是不同 t 上的加权积分在期望上应保持一致，但 SDS 用单次 t 采样做随机估计，方差不为零。这两点合起来意味着 SDS 梯度不是任何显式标量损失的精确梯度，它是一个有偏的随机方向。工程上的判断是：偏差在「把渲染图推向高概率区域」这一粗粒度目标上足够小，因为扩散模型的噪声预测在语义层面提供了稳定的方向信号，而雅可比保证了这个信号能落到正确的参数上。

有偏性的一个具体失败模式是过饱和与多面。当文本条件较强、w(t) 较大时，残差信号会持续把颜色推向扩散模型偏好的高对比区域，渲染图出现不自然的饱和；当 3D 表示存在多视角不一致（例如 NeRF 的密度场在薄结构处欠约束），雅可比会把不同视角的残差叠加到同一批参数上，导致某些面被过度优化、另一些面被忽略。这不是数值 bug，而是有偏梯度在多视角平均下的结构性后果。另一个失败模式是「每资产数十分钟到数小时」的代价：15k 步、每步一次前向渲染加一次扩散前向加一次渲染反向，单步开销由分辨率和 3D 表示决定，步数由收敛决定，两者相乘就是墙钟时间。分辨率从 64×64 提到更高时，扩散前向与渲染反向都按像素数增长，时间随之上升。

四 · 伪代码思路：一次 sds_step 的数据流

把上面的链条写成伪代码，重点不在语法，而在每一步的张量形状与谁对谁求导。渲染得到 x，形状 H×W×3；采样 t 与 ε，形状同 x；加噪得到 x_t；扩散模型输出 ε_φ，形状同 x；残差 g_img = (ε_φ−ε)·w(t)，形状同 x；然后以 g_img 为伴随对渲染器反向，得到 θ 的梯度；最后做一步优化器更新。关键点是扩散模型在前向之后就冻结，不参与反向；反向只穿过渲染器。

  • 输入：θ（3D 参数）、y（文本）、冻结的 ε_φ、可微渲染器 R、噪声日程、权重 w(t)、学习率 lr。
  • 第 1 步：x ← R(θ)，保留计算图，因为后面要对 θ 反向。
  • 第 2 步：t ← 采样，ε ← 采样标准正态，x_t ← √ᾱ_t·x + √(1−ᾱ_t)·ε。
  • 第 3 步：ε_φ ← ε_φ(x_t; y, t)，此步不建图或建图后截断。
  • 第 4 步：g_img ← w(t)·(ε_φ−ε)，作为 x 的伴随梯度。
  • 第 5 步：对渲染器反向，g_θ ← ∂x/∂θᵀ·g_img；θ ← θ − lr·g_θ。

这个数据流有一个容易踩的坑：x_t 的构造里 x 是带梯度的，但 ε 是常数，√ᾱ_t 与 √(1−ᾱ_t) 是标量。若实现时把 x_t 整个 detach 再送进扩散模型，残差仍然可用，因为残差只需要 ε_φ 与 ε 的差，不需要对 x_t 求导；但若误把残差对 x_t 求导再传回 x，就会多出一条本不该有的路径，导致梯度量级失真。正确做法是把 ε_φ−ε 当作常数伴随，只让它穿过渲染器。另一个坑是 t 的采样分布：若 t 总取很大值，残差主要反映语义、细节信号弱，纹理收敛慢；若总取很小值，残差被高频噪声主导，容易过拟合到单视角。实践中按日程均匀或按信噪比加权采样，是控制这一权衡的具体机制。

系统代价上，一次 sds_step 的显存峰值出现在渲染图 x 与扩散前向的中间激活同时存在时。若分辨率高、扩散模型大，扩散前向的激活可能超过渲染图本身；此时可以把扩散前向放在 no_grad 下、只保留输出 ε_φ，显存回落到渲染图加残差的量级。时间上，扩散前向通常是单步的大头，渲染反向次之；15k 步、1.5 小时的数字对应的就是这种配比。若把分辨率翻倍，像素数变四倍，扩散前向与渲染反向都随之增长，墙钟时间大致按像素数放大，这是工程上选择 64×64 起步、再逐步提高分辨率的直接原因。

五 · 数值例子里的三个量级判断

回到 64×64、t=500、残差 0.3、w=1 的例子，可以做三个量级判断。第一，残差 0.3 在像素值归一化到 [−1,1] 或 [0,1] 的尺度上不是小量，它意味着扩散模型认为当前噪声与真实噪声有可观的差异；乘上雅可比后，单次更新对纹理的推动是可见的，这正是 SDS 能在较少步数内改变外观的原因。第二，w=1 时梯度的模长由残差与雅可比的乘积决定，雅可比的尺度取决于渲染器对参数的敏感度：NeRF 的 MLP 权重梯度通常较小，高斯泼溅的均值梯度较大，因此同一 w 在不同表示上的有效步长不同，学习率需要按表示调整。第三，15k 步、1.5 小时意味着单步约 0.36 秒量级（按 1.5 小时/15k 估算），这个量级与「一次渲染+一次扩散前向+一次渲染反向」在中等分辨率下的开销相符，说明瓶颈不在优化器，而在前向与反向的重复。

这三个判断对应三个工程取值。残差量级决定了是否需要梯度裁剪：当文本条件强、残差持续偏大时，裁剪可以防止单步把参数推过头，避免过饱和。雅可比尺度决定了学习率与 w(t) 的联合调节：若换 3D 表示而不换学习率，有效步长会漂移。单步时间决定了步数预算：在固定墙钟预算下，提高分辨率会减少可执行步数，收敛与细节之间需要取舍。这些取值不是超参数玄学，而是从公式里的三个因子（残差、雅可比、单步开销）直接推出来的。

量来源工程影响
残差 ε_φ−ε扩散模型预测与采样噪声之差决定单步推动力，过大需裁剪防过饱和
雅可比 ∂x/∂θ渲染器对参数的敏感度决定有效步长，换表示需重调学习率
w(t)噪声日程权重平衡语义与细节信号，影响收敛速度
单步开销渲染前向+扩散前向+渲染反向决定墙钟时间与可执行步数

表格里四行的关系是乘性的：残差乘雅可比得到梯度，梯度乘学习率得到参数更新，更新次数乘单步开销得到总时间。任何一行失控都会在结果上表现为具体的失败模式——残差失控表现为过饱和，雅可比失控表现为某些面被过度优化，w(t) 失控表现为细节或语义单边倾斜，单步开销失控表现为预算内步数不足、收敛不完全。把这些量级判断写进调试流程，比反复试学习率更能定位问题出在公式的哪一段。

六 · 有偏梯度在多视角下的叠加行为

SDS 的期望是对 t 与 ε 取的，但实现中每个视角的渲染图各自产生一份残差，雅可比把各视角的残差叠加到共享的 θ 上。这个叠加不是简单的平均：不同视角对同一参数的敏感度不同，薄结构、遮挡边界、高光区域的雅可比行范数差异很大，残差大的视角会在叠加中占主导。结果是参数更新方向偏向「当前残差最大的视角」，而不是所有视角的均衡改进。这是有偏梯度在多视角平均下的具体机制，也是多面与过饱和的结构性来源之一。

一个具体的例子：一个薄片结构在两个视角下可见，在第三个视角下被遮挡。前两个视角的残差通过雅可比传到薄片参数上，第三个视角的雅可比在该参数上接近零，不贡献梯度。若前两个视角的文本条件一致，薄片会被推向高概率外观；但若两个视角的残差方向相反（例如一个视角认为应更亮、另一个认为应更暗），叠加后的梯度可能相互抵消，薄片停在中间状态，表现为「多面」——不同视角看到的外观不一致。这不是优化没收敛，而是有偏梯度在视角间不一致时的必然折中。

工程上的应对不是消除有偏性（那需要严格得分，代价高且不一定可算），而是控制叠加的权重。常见机制包括：按视角的雅可比范数做归一化，避免大范数视角主导；在残差上做裁剪，限制单视角的推动力；在训练日程上先宽后窄地采样视角，让共享参数先被多视角共同约束、再被单视角细化。这些机制都不改变 SDS 的公式，只改变期望的采样方式，因此不引入新的偏差来源，只是把已有偏差的叠加行为调得更可控。最终落点仍是那个乘性链条：残差、雅可比、权重、步数，四者中任何一个的采样方式改变，都会在渲染结果上留下可辨认的痕迹。
