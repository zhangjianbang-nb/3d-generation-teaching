一 · 稀疏体素的数据布局与访存代价

SLAT 的“结构化”落在两件事上：一张记录活跃体素坐标的索引表，以及一块按索引排布的局部特征张量。索引表通常是 int32 三元组 (i,j,k)，特征张量形状为 [N, C]，N 是活跃体素数，C 是每体素通道数。关键在于 N 远小于稠密网格的 D³，因此显存与算力都按稀疏度缩放。设稠密分辨率为 D、稀疏率为 s（活跃体素占 D³ 的比例），则特征显存近似为：

$$M_{\text{feat}} \approx s\,D^{3}\,C\,b,\qquad M_{\text{dense}} = D^{3}\,C\,b$$

其中 b 是每元素字节数。这个式子的工程含义是：稀疏化把显存从“分辨率的三次方”压到“分辨率三次方乘以稀疏率”，但索引表本身仍随 N 线性增长，且坐标排序、去重、邻居查询都是额外开销。真正的坑不在理论复杂度，而在访存模式：3D DiT 的注意力与卷积核需要按空间邻域取特征，若特征按任意顺序紧凑排列，邻域访问就退化成随机 gather，GPU 上的合并访存失效，有效带宽可能掉一个量级。工程上的标准做法是保持体素按 Morton 序（Z-order）或按层优先的线性序排列，使空间近邻在内存中也近邻，从而把 gather 变成半连续访问。代价是每次增删体素都要重排索引，训练中若动态裁剪体素，重排成本会进入每步开销。

具体例子：当 D 取较大值、s 处于较低水平时，稠密张量会直接撑爆单卡，而稀疏张量可以落在单卡内；但一旦把邻域半径调大，gather 的索引缓冲与临时激活就会迅速膨胀，成为新的显存瓶颈。失败模式是“显存看似够用，实际在邻域算子处 OOM”，因为临时缓冲没有计入静态估算。调参时的第一个判断是：先固定邻域半径与体素排序策略，再谈分辨率，否则分辨率一升，访存与临时缓冲同时恶化，无法归因。

二 · 3D DiT 在潜空间上的计算图与整流流采样

SLAT 上的扩散不是逐体素独立去噪，而是在稀疏 token 序列上跑 DiT。序列长度等于活跃体素数 N，每个 token 是 C 维局部特征。DiT 的块由自注意力与逐 token 的 MLP 组成，注意力复杂度为 O(N²C)，这是整个管线里最硬的一项。设层数为 L、注意力头数为 H、每头维度为 d，则单层注意力的计算量近似为：

$$\text{FLOPs}_{\text{attn}} \approx L \cdot N^{2} \cdot C \cdot \left(3 + \tfrac{C}{H d}\right)$$

系数里的 3 对应 Q、K、V 三次投影，后一项是输出投影的相对开销。这个式子说明：N 翻倍，注意力成本四倍；C 翻倍，成本约两倍。于是工程上优先压 N（更激进的体素裁剪、更粗的初始分辨率），其次才是压 C。整流流的训练目标是回归速度场，给定配对 (z₀, ε)，采样 t 构造 z_t = z₀ + (1−t)ε，网络输出 v_θ(z_t,t) 拟合 ε − z₀，损失为均方误差。推理时用 Euler 或高阶积分器从 t=1 走到 t=0，步数 K 决定采样成本，每步一次前向。伪代码思路如下（文字描述，不写代码块）：对每个采样步，取当前 z_t 与时间嵌入，过 DiT 得 v，按步长更新 z_{t−Δ}；由于 z 是稀疏结构，更新只作用于活跃体素，坐标表在整个采样过程中保持不变，除非显式做体素增删。这一点很关键：坐标固定意味着采样阶段没有拓扑变化，解码器拿到的是一张静态稀疏特征图，简化了后续解码。

系统代价在于训练与推理的不对称：训练每步要对整批样本做一次前向加反向，反向的激活显存约为前向的数倍；推理虽无反向，但 K 步前向叠加，且每步都要重算注意力。失败模式是时间步嵌入与稀疏 mask 的对齐错误——若某样本的活跃体素在批内被 padding 到统一长度，mask 未正确屏蔽 padding token，注意力会把无效位置混入，表现为训练损失正常下降但采样结果出现结构性噪声。具体例子：批内样本稀疏度差异大时，padding 比例高，注意力矩阵里大量无效位置参与 softmax，等效于给有效 token 注入了噪声；解决办法是按稀疏度分桶或使用变长序列的打包格式。

三 · 多视图编码到 SLAT 的构建链路与通信开销

构建链路是：多视图图像经视觉编码器提特征，再通过跨视图的几何一致性把特征反投影到体素栅格，得到每个活跃体素的局部特征。这一步的工程核心是反投影的散射（scatter）操作：每个视图像素携带的射线要与体素栅格求交，命中的体素累加特征。散射是写冲突密集的操作，多视图并发写入同一体素时需要原子加或分视图缓冲后归并。设视图数为 V、每视图像素数为 P、命中体素数均值为 h，则散射的写操作量约为 V·P·h，而归并阶段还要一次 N·C 的规约。分布式训练时，若视图编码器与体素构建分在不同设备，特征张量要在设备间传输，通信量为 N·C·b 每步，加上索引表的 N·3·4 字节。当 N 较大、C 较宽时，这一步的 all-gather 或 point-to-point 传输会成为步时的主要成分。

具体机制上，常见做法是把体素栅格按空间块切分到不同 rank，每个 rank 只负责自己块内的体素，跨块邻域通过 halo 交换补齐。halo 交换的通信量与块表面积成正比，而非体积，这是分块的优势；但块边界处的体素若被裁剪，会导致邻域特征不一致，表现为解码后块边界出现接缝。失败模式正是接缝：训练时若各 rank 独立裁剪体素，边界处的活跃集合不匹配，注意力在跨块邻域上取到零填充，解码出的几何在块边界处断裂。工程判断是：裁剪决策必须全局一致，或在边界带保留冗余体素，用少量显存换一致性。

另一个代价是预处理管线本身。多视图输入要做相机参数对齐、深度或视差估计、遮挡判断，这些步骤在 CPU 或独立模型上跑，与训练主循环异步。若预处理吞吐低于训练吞吐，GPU 会周期性空转，表现为步时抖动。具体例子：当视图数增加时，散射写冲突与归并成本线性上升，而体素覆盖率提升有限，边际收益递减；调参顺序上应先固定视图数与分辨率，测出预处理与主循环的吞吐比，再决定是否加视图。

四 · 解码器的分支代价：高斯、网格与辐射场

SLAT 的统一性体现在解码器可插拔：同一张稀疏特征图，接不同解码头得到 3DGS、网格或辐射场。工程上这不是免费的，三条分支的计算与显存特征完全不同。高斯分支输出每体素对应的位置偏移、尺度、旋转、不透明度与球谐系数，输出维度高，且要做致密化与裁剪，显存峰值出现在致密化阶段；网格分支通常走符号距离场或有向距离场的等值面提取，计算瓶颈在栅格查询与 Marching 类算法的遍历，输出是拓扑结构，对体素分辨率的依赖最强；辐射场分支输出密度与颜色，渲染时要沿射线积分，成本随采样点数线性增长。

设高斯分支每体素输出维度为 C_g，则解码头输出张量为 N·C_g，若再叠加球谐阶数，维度进一步上升。等值面提取的成本可定性描述为与查询栅格点数成正比，而查询栅格通常比 SLAT 体素更密，于是解码阶段的分辨率往往高于潜变量分辨率，这正是“稀疏体素分辨率限制细节”的落点：潜空间粗，解码器再密也只能插值，无法恢复未编码的高频几何。失败模式是分支间的不一致：高斯分支致密化后点数暴涨导致 OOM，而网格分支在同一 N 下轻松通过，说明显存预算必须按分支分别设定，不能共用一套批大小。具体例子：同一批样本，高斯解码在致密化后点数远超输入体素数，显存峰值出现在这一步；工程上要么限制致密化上限，要么把解码分批流式输出。

调参顺序上，解码分支应最后调：先保证潜空间采样质量，再固定采样步数，最后才调解码器的致密化阈值与等值面分辨率。反过来先调解码，会把潜空间的缺陷误判为解码参数问题。

五 · 训练管线的阶段划分与显存预算

训练管线至少三段：多视图编码器（可冻结或微调）、SLAT 构建、3D DiT 整流流训练。段与段之间的耦合点是特征分布：编码器若冻结，SLAT 特征的尺度固定，DiT 的学习率与归一化层要匹配该尺度；若联合微调，编码器的梯度要穿过散射与索引操作，反向传播在 scatter 处需要对应的 gather，显存与计算都翻倍。工程上通常先冻结编码器训 DiT，收敛后再小学习率解冻，这是一条明确的阶段顺序，而不是并行调参。

显存预算可按项列出：特征张量 N·C·b、注意力临时缓冲（与 N² 或分块后的 N·B 成正比，B 为块大小）、DiT 激活（随层数线性增长）、优化器状态（Adam 类为参数量的数倍）。设 DiT 参数量为 P，则优化器状态约为 k·P·b，k 为常数因子。总显存近似为：

$$M_{\text{total}} \approx N C b + \alpha N B b + \beta L P b + k P b$$

其中 α、β 是与实现相关的系数。这个式子的用途是定位瓶颈：当 N 增大时前两项主导，此时应改分块注意力或降 N；当 P 增大时后两项主导，此时应改梯度检查点或参数分片。失败模式是“加卡不加速”：若瓶颈在单样本内的注意力 N²，数据并行只是复制了同样的瓶颈，吞吐不升；只有序列并行或分块注意力才能切开这一项。具体例子：批大小翻倍时若步时增长超过两倍，说明注意力缓冲已进入显存压力区，分配器开始碎片化，此时应降批大小并开梯度累积，而不是继续加卡。

六 · 工程坑的排查顺序与可复现性

排查顺序应按“数据—结构—模型—解码”四级走。第一级查多视图对齐：相机参数、坐标系手性、归一化尺度三者任一错位，都会让 SLAT 特征在空间上系统性偏移，表现为几何整体旋转或缩放，而损失曲线看不出异常。第二级查稀疏结构：索引去重、Morton 排序、裁剪一致性，任一环节出错都会让邻域算子取到错误体素，表现为局部噪点或块接缝。第三级查 DiT 的时间步与 mask 对齐，前文已述。第四级查解码分支的阈值与分辨率，表现为细节丢失或点数爆炸。

可复现性上，稀疏管线有两个隐蔽来源：一是散射的原子加在浮点下不满足结合律，多视图累加顺序不同会导致特征末位差异，经训练放大后表现为不同随机种子下结果漂移；二是体素裁剪若依赖运行时统计（如按特征范数阈值裁剪），则裁剪集合随批内其他样本变化，破坏了样本独立性。工程判断是：散射改为确定性归并（按视图固定顺序），裁剪阈值改为全局固定或按样本独立计算，用少量效率换可复现。具体例子：同一输入在不同卡数下训练，若归并顺序随分片方式变化，特征会有微小差异，短训练看不出，长训练后采样结果出现可见差别；这不是随机性，而是实现顺序的确定性缺失。

最后落在一条具体机制上：SLAT 的系统成本由 N（活跃体素数）与注意力分块方式共同决定，前者由稀疏率与分辨率锁定，后者由实现选择。工程上真正可控的杠杆是分块大小与体素排序——分块大小决定注意力缓冲的峰值，排序决定邻域 gather 的带宽效率。把这两个量固定并记录在配置里，才能让分辨率、批大小、采样步数的调参有意义；否则每次改动都在同时移动多个隐变量，失败无法归因。
