一 · 问题的形式化：从单视图到条件分布

单图生 3D 的困难不在于“没有 3D 数据”，而在于“没有背面观测”。给定一张 RGB 图像 x，它只覆盖物体表面可见的那一半，剩余半球在几何上完全未知。传统多视图立体依赖重叠视差，单图情形下视差为零，三角化失效；而纯生成式方法若直接回归体素或隐式场，又缺乏足够强的 2D 先验约束，容易产生“正面像、背面糊”的退化。Zero-1-to-3 把这个问题重新表述为一个条件分布建模问题：不去直接预测 3D，而是学习

$$p\left(x'\mid x,\Delta R,\Delta T\right)$$

其中 x 是参考视图，x' 是目标视图，ΔR、ΔT 是目标相机相对参考相机的旋转与平移。这个表述的关键转折是：把“3D 未知”转嫁为“新视角未知”，而新视角生成恰好是 2D 扩散模型已经擅长的事。只要模型能在任意相对位姿下生成可信视图，多视图之间就隐含了物体的 3D 结构，后续交给 NeRF 或网格重建即可。问题因此从“预测几何”变为“预测几何的二维投影序列”，这是一个可训练性更好的目标。

形式化上还需明确相机约定。设参考相机外参为 (R, T)，目标相机为 (R', T')，则相对变换写作

$$\Delta R=R'R^{-1},\qquad \Delta T=T'-T$$

这里 ΔR 是旋转矩阵之差（严格说是相对旋转），ΔT 是平移差。注意 ΔT 并非在目标坐标系下表达，而是直接在世界坐标中相减，这意味着网络必须同时消化旋转与平移两种异质量。工程上这是一个隐患：旋转属于 SO(3) 流形，平移属于欧氏空间，二者直接拼接送入同一嵌入层会造成尺度与拓扑的不匹配。Zero-1-to-3 的做法是将 ΔR 展平为 9 维向量、ΔT 取 3 维，共同映射到高维嵌入，再通过 cross-attention 注入。这一选择牺牲了旋转的流形结构，换来的是实现简单，代价是位姿泛化在极端角度上出现偏差。

一个具体例子：参考视图为物体正前方（方位角 0°），目标视图取方位角 180°（正后方）。此时 ΔR 对应绕竖直轴旋转 π，ΔT 若相机绕物体公转则不为零。模型必须仅凭正面纹理推断背面——这是纯生成，没有几何约束可用。失败模式在此处最典型：背面纹理常出现“正面纹理的镜像复制”或过度平滑，因为训练数据中背面与正面的统计相关性弱，模型倾向于用先验均值填补。

二 · 核心思想：把位姿当作扩散模型的外生条件

Zero-1-to-3 的核心不是发明新的扩散结构，而是“条件注入点的选择”。预训练图像扩散模型（以 Stable Diffusion 一类 latent diffusion 为代表）已经具备强大的图像先验，其 UNet 的 cross-attention 层原本用于注入文本嵌入。Zero-1-to-3 复用同一接口：把参考图经 CLIP 类图像编码器得到 token 序列，把位姿嵌入作为另一组 token，二者拼接后共同作为 cross-attention 的 key/value。这样做的机制优势在于，cross-attention 是全局的，目标视图的每个空间位置都能查询参考图的任意区域与位姿信息，天然支持“从可见区域外推到不可见区域”。

用伪代码表达训练时的前向流程：

  • 从 Objaverse 渲染同一物体的多视图，随机取一对 (参考视图 x, 目标视图 x')，并记录两相机外参；
  • 计算 ΔR、ΔT，展平后经 MLP 得到位姿嵌入 epose；
  • 参考图 x 经图像编码器得到 eimg，与 epose 拼接为条件序列 c；
  • 对 x' 加噪得到 x't，UNet 在 c 的 cross-attention 条件下预测噪声 εθ(x't, t, c)；
  • 损失为 ‖ε − εθ‖²，仅对目标视图的 latent 计算。

这里有一个容易被忽略的机制细节：参考图与目标图共享同一物体的身份信息，但网络不能把参考图当作“待去噪目标”的一部分，否则会退化为自编码复制。因此参考图只走条件分支，不进入去噪分支，二者在 latent 空间是分离的。这一分离是零样本新视角合成的前提——模型学到的是“给定身份与位姿，生成对应投影”，而非“记住某个物体”。

系统代价随之而来：条件序列长度增加。参考图 token 加位姿 token 使 cross-attention 的 key/value 长度显著上升，注意力计算量随序列长度线性增长，显存占用同步上升。在训练分辨率提升时，这一开销成为瓶颈，迫使实现采用 latent 空间扩散而非像素空间扩散。失败模式则体现在条件冲突：当参考图质量差（遮挡、强反光）时，图像 token 与位姿 token 的注意力权重分配失衡，模型可能忽略位姿、退化为“生成参考图的近似副本”，表现为多视角采样时视角变化不明显。

三 · 公式逐步解释：条件扩散的三层分解

把 x'=fθ(x, ΔR, ΔT) 展开，需要区分三个层次：数据分布层、条件注入层、采样层。第一层是训练分布，即 Objaverse 渲染的多视图对。渲染数据的特点是光照与材质受控、背景干净、视角覆盖均匀，这使条件分布 p(x'|x,ΔR,ΔT) 在训练覆盖范围内近似良定；但真实单图输入的光照、背景、遮挡与渲染分布存在域 gap，这是零样本迁移的主要误差源。

第二层是条件注入的数学形式。cross-attention 的输出为

$$\mathrm{Attn}(Q,K,V)=\mathrm{softmax}\!\left(\frac{QK^{\top}}{\sqrt{d}}\right)V$$

其中 Q 来自目标视图的去噪 latent，K,V 来自条件序列 c=[eimg; epose]。位姿信息通过 K 影响注意力权重分布，从而调制 V 的聚合。换句话说，位姿不是加性偏置，而是乘性（通过 softmax 权重）地改变目标特征对参考特征的读取方式。这解释了为什么位姿嵌入的维度与位置编码方式会影响泛化：若 epose 与 eimg 在数值尺度上差异过大，softmax 会偏向其中一方，造成条件失衡。

第三层是采样。推理时给定单图与一组目标位姿，独立地对每个位姿运行去噪轨迹，得到多张视图。注意这里是“独立采样”，不是联合采样——模型没有显式建模视图之间的相关性。因此公式 x'=fθ(x,ΔR,ΔT) 描述的是边缘分布，而非联合分布 p(x'1,…,x'n|x)。这一数学差别直接导致视角间一致性不足：每个视图各自采样，噪声轨迹独立，纹理细节在相邻视角间可能漂移。工程上的缓解手段是共享初始噪声或采用确定性采样（如 DDIM），但这只是降低方差，不改变边缘采样的本质。

具体例子：绕物体采样 12 个方位角，若每个视角独立用随机种子，背面纹理在不同视角间会出现接缝；若固定种子并配合 DDIM，接缝减弱但仍有几何级的不一致，重建时表现为表面高频噪声。这是后续重建模型必须容忍的输入误差。

四 · 与相邻算法的数学差别：条件变量与监督信号的错位

与 DreamBooth 类“身份定制”方法相比，Zero-1-to-3 的条件变量多了一个位姿维度。DreamBooth 学习的是 p(x|identity)，位姿被边缘化掉；Zero-1-to-3 学习的是 p(x'|identity, pose)，位姿是显式条件。数学上这意味着后者的条件空间维度更高，需要更多监督对来覆盖 SO(3)×R³ 的子流形。Objaverse 的多视图渲染正是为此提供成对监督：每个物体贡献多对 (参考, 目标, 相对位姿)，使条件分布在不同位姿上都有样本。

与 NeRF 类重建方法相比，差别在于监督信号的位置。NeRF 直接优化体密度与颜色场，使渲染图像匹配观测，几何是显式变量；Zero-1-to-3 不显式建模几何，几何只作为多视图一致性的隐含结果。数学上前者是“以 3D 为参数的逆渲染”，后者是“以 2D 条件分布为目标的生成”。这带来一个关键差别：Zero-1-to-3 的误差不满足多视图几何约束（极线约束），因为每个视图独立生成，像素间没有三角化关系；而 NeRF 的误差被体渲染积分强制耦合。因此把 Zero-1-to-3 的输出交给 NeRF 重建时，重建模型实际上在做“一致性正则化”，把不一致的视图拉回可行几何。

与纯 2D 新视角合成（如基于单应变换的 warping）相比，差别在于是否依赖显式几何。Warping 方法用深度图做前向映射，遮挡区域出现空洞，数学上是确定性的几何变换；Zero-1-to-3 用生成填补空洞，数学上是采样自条件分布。前者失败模式是空洞与拉伸，后者失败模式是幻觉纹理与视角漂移。二者互补：warping 提供几何锚点，生成提供外观先验，但 Zero-1-to-3 本身不包含 warping 分支，因此不具备几何硬约束。

表中“几何约束”一列的差别是数学本质：Zero-1-to-3 的条件分布不编码极线几何，因此它的多视图输出不能直接用于三角化；而 NeRF 的光度损失天然把不同视图的同一表面点耦合到同一体素上。这一错位解释了为什么 Zero-1-to-3 必须“生成一圈视角再交重建”——单张生成视图不足以约束几何，必须靠数量与覆盖换取重建模型的鲁棒性。

还有一个数学细节值得指出：ΔR=R'R-1 的定义依赖参考相机外参 R 的可逆性，旋转矩阵恒可逆，故无奇异；但 ΔT=T'-T 在世界坐标下相减，若相机绕物体公转，ΔT 的量级与物体尺度相关，网络若不归一化平移，会在不同尺度物体上泛化失败。这是位姿泛化偏差的一个具体来源：训练集中物体尺度分布有限，平移量未归一化时，模型把平移数值与绝对尺度绑定，遇到尺度差异大的输入即产生视角错位。

五 · 条件注入的工程实现与代价核算

把位姿嵌入注入 cross-attention 有两种实现路径：拼接式与加性式。拼接式把 epose 作为额外 token 追加到图像 token 序列后，注意力可学习地在图像与位姿之间分配权重；加性式把位姿嵌入加到每个图像 token 上，等价于对条件做全局偏置。Zero-1-to-3 采用拼接式，理由是位姿是全局量，不应污染每个图像 token 的局部语义。代价是序列变长，注意力矩阵从 N×N 变为 N×(N+M)，M 为位姿 token 数。在 latent 分辨率 64×64（token 数约 4096）时，M 虽小，但每层 cross-attention 都重复这一开销，累计显存与算力不可忽略。

训练数据的构造同样有代价。Objaverse 渲染需要为每个物体采样多视角、多光照，渲染成本与视角数线性相关；且必须保证参考视图与目标视图属于同一物体、同一材质状态，否则条件分布被污染。工程上通常固定光照、随机方位角与俯仰角，使位姿覆盖均匀。失败模式是“位姿标签噪声”：若渲染时相机外参记录有误，ΔR 与图像内容错配，模型会学到错误的位姿-外观映射，表现为推理时视角旋转方向反直觉。

推理阶段的代价核算是多视图采样的组合爆炸。生成 n 个视角需要 n 次完整去噪轨迹，每次轨迹 T 步，总算力约为单图生成的 n 倍。若 n 取一圈 12 视角、T 取 50 步，则相当于 600 次 UNet 前向。这是“生成一圈再重建”流程的主要时间成本。优化手段包括：降低 T（用 DDIM 或蒸馏）、共享条件编码（参考图编码只算一次）、批量并行采样。但降低 T 会牺牲细节，批量并行受显存限制，二者都是工程权衡而非数学改进。

一个具体例子：单张 512×512 参考图，生成 12 个方位角视图，若每视图 50 步、批量 4，则需 3 个批次共 150 次前向传播量级；随后 NeRF 重建需在 12 视图上优化体场，迭代数百至上千步。整个流水线的瓶颈往往不在生成而在重建的一致性收敛——因为生成视图不满足极线约束，重建优化需要在光度损失之外加入正则，否则表面出现重影。

六 · 失败模式的机制归因

视角间一致性不足的机制归因是边缘采样。公式 x'=fθ(x,ΔR,ΔT) 对每个 ΔR,ΔT 独立求值，模型没有机制强制相邻视角的纹理在同一表面点上取值相同。扩散模型的随机性来自初始噪声与采样轨迹，两个视角即使位姿接近，噪声实现不同，生成结果在细节上分叉。数学上这是联合分布缺失：边缘分布一致不等于联合分布一致。工程判断是：要提升一致性，要么改采样为联合（代价高、结构复杂），要么在重建阶段用几何约束把边缘样本拉回一致流形。

位姿泛化偏差的机制归因是条件编码的流形失配。ΔR 展平为 9 维后送入 MLP，旋转的 SO(3) 结构（正交、行列式为 1）在欧氏嵌入中不被保持，网络只能从数据中隐式学习流形约束。训练位姿覆盖不足的角度区间上，嵌入外推失效，表现为视角旋转量估计偏差。具体例子：训练集中俯仰角多在 ±30° 内，推理时要求 60° 俯视，模型可能生成接近水平视角的图像，因为嵌入落在训练分布之外，MLP 输出退化为均值附近。

分辨率有限的机制归因是 latent 扩散的下采样。为控制注意力开销，扩散在低分辨率 latent 上进行，细节由解码器恢复。位姿条件影响的是全局布局，细节纹理则依赖参考图 token 的局部读取；当目标视角远离参考视角时，可见纹理少，解码器只能依赖先验，输出趋于平滑。这是信息论意义上的必然：单图提供的像素数固定，背面像素必须由先验生成，分辨率越高，先验需要填补的高频细节越多，失真越明显。

把这三类失败放在一起看，它们的共同根源是“条件分布被边缘化地学习与采样”。Zero-1-to-3 的数学贡献在于把 3D 问题转成可训练的条件 2D 生成，其工程价值在于为重建提供背面先验；但它的公式结构决定了它不提供几何硬约束，多视图一致性必须由下游重建承担。因此判断一个 Zero-1-to-3 流水线是否可靠，不应看单张生成图的视觉质量，而应看多视图在极线意义下的残差——残差大则重建必不稳，这是比 FID 类指标更贴近几何的工程判据。
