一 · 问题定义：三种表示各自为政的代价

在 SLAT 出现之前，3D 生成的实际工程管线通常被迫在三种主流表示之间做取舍：三平面（triplane）把空间压成三张正交特征图，高斯泼溅（3DGS）用一组带协方差与不透明度的各向异性椭球近似辐射场，显式网格则用顶点与面片承载可编辑的表面。三者各自服务于不同的下游：三平面擅长给 NeRF 类解码器提供连续查询，高斯擅长实时可微渲染，网格擅长进入传统 DCC 与引擎管线。问题不在于哪一种表示更好，而在于它们的数据布局、分辨率语义与解码接口互不兼容。

这种不兼容在系统层面表现为三重代价。其一是训练代价：为三平面扩散训练一个去噪网络，网络必须学会在三个 2D 特征平面上做全局一致性推理，任何一处平面伪影都会在体渲染时被放大；为高斯扩散训练，则要处理无序、变长的点集，扩散过程的噪声调度必须定义在置换不变的集合上，采样后还要做致密化与剪枝。其二是输出代价：一个只为三平面训练的模型无法直接产出高斯，反之亦然，想做多格式输出就得维护多套权重与多套采样器。其三是质量代价：三平面在薄结构（叶片、栏杆、细线）上因平面分辨率共享而糊化，高斯在无纹理区域因缺乏表面对齐约束而漂浮，网格在拓扑剧烈变化处（毛发、镂空）难以保持流形性。

SLAT 的问题陈述因此不是“哪种表示最好”，而是“能否构造一个中间潜变量，使三种表示都成为它的确定性或可学习解码”。这个提法把表示之争降级为解码器之争：只要潜变量本身携带足够的几何与外观信息，且其结构允许不同解码器以各自的方式读取，统一性就成立。关键约束是潜变量必须结构化——不能是全局向量，否则解码器无法恢复空间局部性；也不能是稠密体素网格，否则算力随分辨率立方增长。

一个具体的失败模式可以说明稠密方案的代价：若把场景放进 256³ 的稠密特征网格，每 voxel 32 通道，单精度下光潜变量本身就是 256³×32×4 字节，量级在数百 MB 到 GB；扩散采样要在这样的张量上反复前向，显存与带宽都不可接受。稀疏化是唯一现实的出路，但稀疏化立刻带来新问题：稀疏位置如何确定、稀疏特征如何与扩散过程的连续噪声共存、解码器如何在稀疏支撑之外做插值。SLAT 的全部机制设计都围绕这三个问题展开。

二 · 核心思想：稀疏体素作为结构与特征的复合体

SLAT 的核心是把 3D 资产写成二元组：支撑集与特征。支撑集是一组稀疏体素坐标，只覆盖资产表面附近的窄带；每个被激活的体素携带一个局部特征向量。用符号表示，潜变量为

$$\mathcal{Z}=\{(\mathbf{p}_i,\mathbf{f}_i)\}_{i=1}^{N},\quad \mathbf{p}_i\in\mathbb{Z}^3,\ \mathbf{f}_i\in\mathbb{R}^{C}$$

其中 N 远小于同分辨率稠密网格的体素数，C 是特征通道数。这个定义看似简单，但它同时解决了前述三个问题：支撑集给出空间局部性，特征给出外观与几何线索，稀疏性把算力从立方降到与表面积成正比。更重要的是一种语义上的分离——结构（哪里有事）与内容（那里是什么）被拆成两个可分别处理的量。扩散只需要在内容上做，结构可以在前处理阶段由多视图几何确定并固定，从而避免让去噪网络去学习“哪里应该有体素”这种离散且不可微的决策。

这一分离带来一个直接的方法论后果：扩散过程定义在特征场上，而支撑集是条件而非变量。也就是说，给定支撑集，潜变量退化为一个变长但顺序固定的特征矩阵；去噪网络只需在这个矩阵上做局部与全局混合。这与稠密卷积扩散的差别在于感受野的组织方式：稠密网格上可以用 3D 卷积或窗口注意力，稀疏支撑上则必须用稀疏卷积或基于体素邻接的注意力，且要处理空体素不参与计算的事实。

结构化还带来一个解码上的便利：不同解码器可以读取同一份 (p, f) 而采用不同的读取算子。高斯解码器把每个体素特征映射为一组高斯参数（中心偏移、协方差、颜色、不透明度），网格解码器把体素特征投射到查询点上做三线性插值后走 SDF 或占用头，辐射场解码器则在任意查询点做邻域特征聚合。三者共享同一潜变量，差别只在读取方式。这就是“统一表示支持多格式输出”的机制来源，而不是靠多个模型拼接。

系统代价方面，稀疏结构省算力，但省的是计算而非工程复杂度。稀疏张量的索引管理、邻域查询、批处理时的变长填充，都会引入额外的内核与同步开销；当 N 在不同样本间波动很大时，批处理效率下降。一个具体例子：同一批次里既有稀疏的小物体（支撑集体素数少）又有大面积场景（体素数多），若按最大 N 填充，则小样本的算力被浪费；若按样本分组，则批次利用率下降。这是稀疏表示固有的负载不均衡问题，SLAT 并未消除它，只是把它从立方级降到表面积级。

三 · 公式逐步解释：整流流在稀疏特征上的定义

SLAT 的扩散采用整流流（rectified flow）形式，其前向加噪与速度场定义为

$$\mathbf{z}_{t}=\mathbf{z}_0+(1-t)\epsilon,\qquad v_\theta(\mathbf{z}_t,t)=\epsilon-\mathbf{z}_0$$

逐项解释。$\mathbf{z}_0$ 是干净潜变量，即由多视图编码得到的稀疏体素特征集合；$\epsilon$ 是与 $\mathbf{z}_0$ 同形状的标准高斯噪声；$t\in[0,1]$ 是时间参数，$t=0$ 对应干净数据，$t=1$ 对应纯噪声。第一式是一条直线插值：从 $\mathbf{z}_0$ 出发，沿 $\epsilon-\mathbf{z}_0$ 方向匀速走到 $\epsilon$。第二式说明这条直线的方向向量恰好就是速度场的目标，且它与 $t$ 无关——这是整流流区别于标准 DDPM 的核心：概率流被拉直成常速度直线，因而采样可以用更少的步数，且数值积分更稳定。

训练时，网络 $v_\theta$ 接收 $\mathbf{z}_t$ 与 $t$，回归上述速度。损失是带时间权重的均方误差：

$$\mathcal{L}(\theta)=\mathbb{E}_{\mathbf{z}_0,\epsilon,t}\left[w(t)\,\|v_\theta(\mathbf{z}_t,t)-(\epsilon-\mathbf{z}_0)\|^2\right]$$

这里 $w(t)$ 是时间权重，用于平衡不同噪声水平上的梯度量级；在直线路径上，$t$ 接近 1 时 $\mathbf{z}_t$ 几乎全是噪声，回归目标 $\epsilon-\mathbf{z}_0$ 的方差较大，需要相应权重。推理时从 $\epsilon$ 出发，沿学习到的速度场反向积分：

$$\mathbf{z}_{t-\Delta t}=\mathbf{z}_t-\Delta t\,v_\theta(\mathbf{z}_t,t)$$

由于目标是常速度直线，理想情况下一步即可从 $t=1$ 走到 $t=0$；实际因网络误差，需要若干步离散积分，步长与步数是速度与质量的折中。

把这个公式放到稀疏结构上，需要一处关键的工程处理：$\epsilon$ 只在支撑集上有定义。也就是说，噪声被采样在与 $\mathbf{z}_0$ 相同的稀疏坐标上，而不是在稠密网格上采样后掩码。这保证了 $\mathbf{z}_t$ 始终是稀疏的，去噪网络的计算量始终与 N 成正比。代价是：支撑集在扩散过程中固定不变，网络无法在采样时“生长”出新的体素。若前处理阶段的支撑集漏掉了某些薄结构，扩散阶段无法补救，这是稀疏分辨率限制细节这一不足的直接机制来源。

一个具体例子可以说明直线路径的数值意义：若用 8 步离散积分，每步 $\Delta t=0.125$，则 $\mathbf{z}_t$ 的轨迹是 8 段折线；由于真实速度场被训练成近似常向量，折线与直线的偏差主要来自网络在中间 $t$ 上的误差，而非路径曲率。这解释了为什么整流流能在较少步数下保持质量，也解释了为什么训练时 $w(t)$ 的选取会直接影响少步采样的表现——中间时刻的误差在少步积分中没有被平均掉。

失败模式方面，整流流对 $\mathbf{z}_0$ 的尺度敏感。若多视图编码器输出的特征范数在不同样本间差异大，直线路径的端点 $\epsilon$ 与 $\mathbf{z}_0$ 的量级不匹配，网络在不同样本上看到的速度目标方差不同，训练不稳定。工程上通常对 $\mathbf{z}_0$ 做逐通道归一化，但这会削弱特征中携带的绝对强度信息，进而影响解码器对不透明度或粗糙度的判断。这是一个表示归一化与信息保真之间的真实取舍。

四 · 与相邻算法的数学差别：从集合扩散到结构化场扩散

与高斯泼溅扩散相比，SLAT 的差别首先在状态空间。高斯扩散的状态是一个置换不变的集合 $\{(\boldsymbol{\mu}_j,\Sigma_j,\mathbf{c}_j,\alpha_j)\}$，扩散过程必须定义在集合上，噪声注入要保证置换等变，网络要处理无序输入，采样后还要做致密化与剪枝这类离散后处理。SLAT 的状态是带坐标索引的特征矩阵，坐标固定、顺序由索引决定，因此扩散退化为标准的张量扩散，无需置换等变约束，也无需采样后的离散清理。数学上，前者是集合上的生成模型，后者是固定图结构上的场生成模型。

与三平面扩散相比，差别在支撑的几何语义。三平面把 3D 查询映射为三个 2D 坐标的平面特征拼接，其分辨率语义是“平面像素”，空间局部性由平面坐标隐式给出，但三个平面之间的一致性没有任何硬约束，网络必须靠数据学习一致性。SLAT 的支撑是显式 3D 坐标，邻域关系由体素邻接直接给出，局部性是被结构保证的而非被学习得到的。代价是 SLAT 的支撑集本身需要由多视图几何确定，这一步引入了几何前处理的误差；三平面则不需要显式的支撑集，任何空间位置都可查询，因而在支撑集之外的区域不会出现“空洞”。

与稠密体素扩散相比，差别在计算图。稠密体素扩散的算子是 3D 卷积或窗口注意力，计算量随分辨率立方增长，且空区域也参与计算；SLAT 的算子只作用于被激活体素，计算量随激活体素数线性增长。但稀疏算子失去了稠密卷积的规整内存访问模式，实际加速比通常小于理论体素比。一个具体例子：在薄壳类资产上，表面窄带的体素数约为同分辨率稠密网格的百分之几量级，理论算力节省显著；但由于稀疏索引的间接寻址与邻域收集，实际吞吐提升会被内存延迟部分抵消，尤其在 N 较小时并行度不足。

三者在“条件如何进入网络”上也有数学差别。三平面扩散常把图像条件通过交叉注意力注入，条件与潜变量的交互是全局的；高斯扩散常把条件编码为每点特征并与点特征拼接，交互是局部的；SLAT 走的是 3D DiT 路线，条件（多视图特征）与稀疏潜变量在 Transformer 块中通过注意力交互，既有局部邻域注意力也有全局 token。这使 SLAT 的条件注入在表达能力上接近三平面，在空间局部性上接近高斯，但代价是注意力在变长稀疏序列上的实现复杂度，以及显存随 token 数增长的平方项——这是显存需求高这一不足的机制来源之一。

五 · 机制推导中的两个硬约束

第一个硬约束是支撑集与特征的耦合方式。SLAT 从多视图输入构建稀疏体素特征，这一步的机制是：多视图图像经编码器得到 2D 特征，再按相机参数反投影到 3D 空间，在表面窄带内聚合为体素特征。反投影的精度受限于深度估计或视觉外壳的精度，窄带宽度是一个超参数：太窄则薄结构漏检，太宽则体素数膨胀且特征被稀释。这个超参数没有自适应机制，是训练管线复杂这一不足的具体落点——不同资产类别需要不同的窄带宽度，而宽度一旦固定，就在整个数据集上生效。

第二个硬约束是解码器与潜变量的对齐。高斯解码器把体素特征映射为高斯参数时，需要决定一个体素对应多少个高斯；网格解码器在查询点做三线性插值时，需要决定支撑集之外的查询如何处理。这两个决定都不是由扩散过程学习的，而是由解码器训练阶段单独确定的。因此“统一表示”在工程上意味着三套解码器要分别训练、分别调参，且它们的训练数据分布必须与 SLAT 的分布匹配。若解码器训练用的潜变量分布与扩散采样出的分布有偏移，解码质量下降，而这种偏移在稀疏支撑的边缘处最明显。

一个具体失败模式：扩散采样在支撑集边缘体素上产生范数偏大的特征（因为边缘体素的邻域聚合不完整，训练时其速度目标方差偏大），高斯解码器把这些特征解读为高不透明度的大椭球，导致渲染出现漂浮的“雾团”。这不是扩散公式的错误，而是支撑集边缘的统计不一致在解码阶段的放大。工程上的缓解方式是在训练时对边缘体素降权，或在解码前对边缘特征做邻域平滑，两者都会牺牲边缘细节。

这两个硬约束共同说明：SLAT 的统一性是接口层面的统一，不是训练层面的统一。潜变量是共享的，但潜变量的产生（多视图编码与稀疏化）与消费（三套解码器）各自有独立的工程决策。这带来管线复杂度，也带来灵活性——可以替换任一解码器而不重训扩散，可以替换多视图编码器而不重训解码器（只要特征分布对齐）。这种模块化是 SLAT 在工程上可用的关键，也是其训练管线复杂的根源。

把机制推导收束到一个工程判断上：SLAT 的设计选择是用结构显式化换取扩散问题的简化。支撑集固定使扩散退化为固定图上的场生成，从而避开集合扩散的置换约束与稠密扩散的立方算力；代价是把几何决策前移到多视图前处理，并把多格式输出的负担后移到解码器训练。这个取舍是否划算，取决于前处理的几何精度是否足以支撑目标分辨率——当资产细节尺度接近体素尺寸时，支撑集的漏检无法被扩散补救，稀疏分辨率限制细节这一不足就从定性描述变成可测量的质量上限。
