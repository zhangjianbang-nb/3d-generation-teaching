一 · 与 SDS 的逐项对比：单点假设的代价

SDS 与 VSD 的差别不能停留在“一个用固定噪声预测、一个用可学习噪声预测”这种描述上。真正决定两者行为分叉的，是 SDS 把 3D 渲染分布 \(q_\theta(x)\) 当作狄拉克点 \(\delta(x-x_0)\) 来处理，而 VSD 显式维护一个近似 \(q_\theta\) 的粒子分布。这个假设差异会在梯度场上留下可观测的痕迹。

SDS 的更新方向是 \(\epsilon_\phi(x_t;y,t)-\epsilon\)，其中 \(\epsilon\) 是采样时注入的固定高斯噪声。对同一组 3D 参数、同一相机、同一随机种子，这个方向是确定的：它把渲染图往“更像文本条件分布的高概率区域”推，但推力只作用在一个样本点上。结果是，优化过程会把所有随机性收敛到扩散模型条件均值附近，多样性被压掉，同时高频细节被过度锐化，出现典型的过饱和与“塑料感”。VSD 的更新方向是 \(\epsilon_\phi(x_t;y,t)-\epsilon_\psi(x_t;c,t)\)，第二项来自粒子模型，它携带了当前 3D 分布自身的统计信息。当 3D 分布已经覆盖了某个模式，粒子模型在该区域的噪声预测会与冻结模型接近，差值趋近于零，梯度自然减弱；当 3D 分布遗漏了某个模式，粒子模型在该区域的预测偏离冻结模型，差值给出指向缺失模式的修正。这就是分布匹配与单点匹配在梯度层面的可分辨差异。

代价方面，SDS 只需要一次冻结扩散前向，显存占用基本由扩散模型和渲染器决定；VSD 需要同时驻留冻结模型与粒子模型，并且粒子模型要参与反向传播（至少在其输出端参与梯度计算），显存大致翻倍，单步时间也因两次前向而增加。更隐蔽的代价是训练稳定性：SDS 的梯度方向不随 3D 分布变化而自适应，学习率调大后容易过冲；VSD 的梯度幅度随粒子模型与冻结模型的差距动态变化，接近收敛时梯度自动变小，但也意味着粒子模型训练滞后时会给出错误方向的修正。

具体例子：同一文本提示下优化一个 NeRF 场景，SDS 在多次随机初始化后往往收敛到几乎相同的几何布局与配色，改变随机种子只带来轻微纹理抖动；VSD 在相同设置下，不同粒子（不同 LoRA 初始化或不同 3D 初始化）会落到不同的合理布局上，例如“一只戴帽子的猫”可能分别生成正面坐姿与侧身姿态。这不是随机噪声的差别，而是梯度场是否包含分布级修正项的差别。

二 · 与相邻蒸馏族的对比：DDS、SJC、ISM 的定位差异

把 VSD 放进蒸馏算法谱系里，需要抓住“蒸馏目标是什么分布”这一维度。SDS 蒸馏的是条件扩散模型的单点得分；VSD 蒸馏的是 3D 分布与条件分布之间的 KL；DDS（Delta Denoising Score）走的是另一条路：它不引入可学习粒子，而是用同一张图在不同条件下的噪声预测之差作为更新方向，本质是把“条件差异”当作梯度信号，省掉了粒子模型但也没有分布级修正。SJC（Score Jacobian Chaining）则把扩散得分沿渲染雅可比链式传播，强调把 2D 得分提升到 3D 参数空间，其分布假设仍是单点。ISM（Interval Score Matching）关注的是沿扩散轨迹的区间匹配，用轨迹上的积分关系替代单步差值，减少单步噪声预测的方差，但它同样不维护 3D 分布的显式近似。

从公式结构看，VSD 是唯一在梯度里出现两个可学习/可查询得分之差的方案：\(\epsilon_\phi\) 冻结、\(\epsilon_\psi\) 随 3D 分布更新。DDS 的差值两项都来自冻结模型，只是条件不同；SJC 的梯度是 \(\nabla_x \log p(x|y)\) 经雅可比 \(\partial x/\partial\theta\) 传播；ISM 则在时间区间上做积分。这决定了它们的失效模式不同：DDS 对条件差异敏感，条件弱时梯度信号弱；SJC 的雅可比链在复杂渲染器上容易放大噪声；ISM 的区间积分需要额外的采样点，计算量上升。VSD 的失效则集中在粒子模型这一侧。

系统代价上，DDS 与 SJC 都不需要额外训练模型，显存与 SDS 同级；ISM 需要多次沿轨迹采样，时间开销介于 SDS 与 VSD 之间；VSD 的粒子模型训练是持续进行的，它不是一个预训练好就冻结的模块，而是与 3D 参数交替更新。这意味着 VSD 的训练循环里有两个学习率、两个优化器状态，工程复杂度最高。具体例子：在同样的单卡显存预算下，SDS 可以跑较大分辨率的渲染批次，VSD 往往需要降低批次或分辨率来容纳粒子模型，否则会在粒子模型反向传播时触发显存不足。

三 · 失效条件：粒子模型滞后与分布错配

VSD 的第一个失效条件是粒子模型训练滞后于 3D 分布。粒子模型的目标是近似当前 \(q_\theta\) 的得分，但 \(q_\theta\) 每步都在变。如果粒子模型的学习率过低或更新频率过低，它描述的是几步之前的分布，梯度里的第二项 \(\epsilon_\psi(x_t;c,t)\) 就与当前渲染图不匹配，差值不再指向真实的分布修正方向。表现是优化后期出现纹理震荡或几何细节反复横跳，因为梯度在“修正旧分布”和“修正新分布”之间来回切换。

第二个失效条件是粒子数量或粒子模型容量不足。VSD 用粒子近似整个 3D 分布，若粒子太少，近似退化为少数几个模式，多样性提升有限；若粒子模型容量太小（例如 LoRA 秩过低），它无法覆盖渲染图的条件分布，差值项变成系统性偏差，导致所有样本被推向同一个错误方向。这与 SDS 的多样性塌缩不同：SDS 是梯度里根本没有分布项，VSD 是分布项被低容量模型压扁。

第三个失效条件是噪声调度与权重 \(w(t)\) 失配。VSD 的梯度公式里 \(w(t)\) 控制不同噪声水平上的修正强度。若 \(w(t)\) 在高噪声段过大，粒子模型在高噪声段预测本身就不稳定，差值噪声被放大，3D 几何出现大尺度漂移；若 \(w(t)\) 在低噪声段过大，纹理细节被过度修正，出现过锐化。SDS 同样有 \(w(t)\)，但 VSD 多了一个噪声预测源，两个模型在不同噪声段的误差特性不同，权重需要重新校准。

伪代码思路可以说明滞后问题的位置：

$$\text{for each step: } x=\text{render}(\theta);\ t\sim p(t);\ x_t=\text{noise}(x,t);\ \hat\epsilon_\phi=\epsilon_\phi(x_t;y,t);\ \hat\epsilon_\psi=\epsilon_\psi(x_t;c,t);\ g=w(t)(\hat\epsilon_\phi-\hat\epsilon_\psi)\partial x/\partial\theta;\ \theta\leftarrow\theta-\eta_\theta g;\ \psi\leftarrow\psi-\eta_\psi\nabla_\psi\|\epsilon_\psi(x_t;c,t)-\epsilon\|^2$$

注意 \(\psi\) 的更新用的是注入噪声 \(\epsilon\) 作为去噪目标，而 \(\theta\) 的更新用的是两个模型预测之差。若 \(\eta_\psi\) 远小于 \(\eta_\theta\)，粒子模型跟不上；若 \(\eta_\psi\) 过大，粒子模型过拟合到单批渲染图，失去分布近似能力。这个双学习率结构是 VSD 复现门槛高的直接来源。

具体例子：优化一个带反光材质的物体时，粒子模型若秩过低，无法区分“反光”与“过曝”两种高亮模式，差值项会把所有高亮区域统一推向过曝方向，最终渲染图失去材质层次。这不是 SDS 的过饱和，而是粒子模型容量不足导致的模式混淆。

四 · 选型建议：按分布需求与预算决策

选型的第一问是：任务是否需要多模式输出。若只需要一个确定性的高质量结果，例如单视角展示或固定姿态的产品模型，SDS 或 DDS 的性价比更高，因为它们不需要粒子模型，显存与调参负担小。若任务需要多样性，例如批量资产生成、概念探索、需要覆盖多个合理布局的场景合成，VSD 的分布匹配项是必要的，SDS 的单点梯度无法提供这种覆盖。

第二问是预算。VSD 的额外开销来自粒子模型的训练与双前向。若显存紧张，可以降低渲染分辨率或批次，但这会削弱粒子模型对细节的近似能力；若时间预算紧张，可以减少粒子模型更新频率，但要接受滞后带来的震荡风险。一个工程判断是：当粒子模型参数量相对冻结模型很小（如 LoRA）时，显存增量主要来自激活值而非权重，降低批次比降低秩更有效。

第三问是超参可调空间。VSD 至少涉及 \(\eta_\theta\)、\(\eta_\psi\)、粒子更新频率、粒子数量/秩、\(w(t)\) 五个旋钮。复现时应先固定 \(w(t)\) 与 SDS 一致，再调 \(\eta_\psi\) 使粒子模型损失在合理范围内下降，最后调 \(\eta_\theta\)。若一开始就同时调多个参数，失效模式会互相掩盖：粒子滞后表现为纹理震荡，权重失配表现为几何漂移，两者很难从最终渲染图区分。

第四问是失败回退路径。若 VSD 训练中出现持续震荡，先检查粒子模型损失是否仍在下降；若损失停滞，说明粒子模型容量或学习率有问题，回退到增大秩或提高 \(\eta_\psi\)；若损失正常但渲染震荡，检查 \(w(t)\) 在高噪声段是否过大。若多样性没有提升，检查粒子数量是否太少，或粒子初始化是否全部相同——全部相同的粒子等价于单点，VSD 退化为 SDS 的变体。

具体例子：一个团队在单卡上做文本到 3D 资产，最初用 SDS 得到的结果多样性差，改用 VSD 后发现显存不足，于是把渲染批次减半、LoRA 秩保持不变，结果粒子模型在小批次上过拟合，差值项噪声变大。正确的调整是保持批次、降低渲染分辨率并提高粒子更新频率，让粒子模型在更多样本上近似分布，而不是在少数样本上过拟合。

五 · 三道练习：从公式到工程判断

练习一（梯度场分析）：给定同一组 3D 参数与相机，分别写出 SDS 与 VSD 的梯度表达式，并说明当 3D 分布已经覆盖某个模式时，VSD 的第二项为何趋近于零。要求指出粒子模型在该模式下应满足什么条件，以及若粒子模型滞后，这一项会如何偏离。此题检验对“分布匹配”与“单点匹配”在梯度层面差异的理解。

练习二（失效诊断）：某次 VSD 训练中，渲染图在迭代后期出现纹理反复横跳，粒子模型损失仍在缓慢下降，\(w(t)\) 与 SDS 默认一致。请列出至少两个可能原因，并给出对应的调整顺序。要求区分“粒子滞后”与“粒子过拟合”两种情形，并说明如何通过观察粒子模型在不同噪声段的预测误差来区分它们。

练习三（选型设计）：给定一个需要生成多个合理布局的室内场景任务，显存只允许驻留一个扩散模型加一个 LoRA，时间预算允许每步两次前向。请设计 VSD 的关键超参初始值策略（粒子数量/秩、\(\eta_\psi\) 与 \(\eta_\theta\) 的相对关系、粒子更新频率），并说明若多样性仍不足，应优先调整哪个旋钮、为什么不是直接增大 \(\eta_\theta\)。此题检验把分布需求翻译成工程配置的能力。

三道练习的共同点是：都不要求复述公式推导，而要求把公式里的每一项对应到可观测的训练现象。VSD 的工程难点不在写出梯度，而在判断梯度里的第二项是否可信。粒子模型是一个随 3D 分布移动的目标，它的可信度取决于更新频率、容量与噪声段权重三者的匹配。当这三者失配时，VSD 不会像 SDS 那样稳定地收敛到过饱和结果，而是表现出更难诊断的震荡与模式混淆。

一个可操作的判断是：在训练日志里同时记录粒子模型在不同 \(t\) 段的去噪损失与 3D 渲染的梯度范数。若高噪声段粒子损失上升而梯度范数同时增大，说明粒子模型在高噪声段失配，差值项被噪声主导；若低噪声段粒子损失正常但渲染细节过锐，说明 \(w(t)\) 在低噪声段权重过大。把这两个信号分开观察，比只看最终渲染图更能定位失效条件。

最终落在机制上：VSD 的梯度是一个差分成对的结构，冻结模型提供条件分布的方向，粒子模型提供当前 3D 分布的基准。两者的可信度必须匹配，否则差值不再表示分布修正，而表示两个不同误差源的叠加。工程上，这意味着粒子模型的更新节奏不是附属超参，而是与 3D 优化同等重要的控制量；选型时若无法保证粒子模型跟上 3D 分布的变化，VSD 的分布匹配优势就无法兑现，此时退回 SDS 并接受多样性损失，是比强行调参更可靠的判断。
