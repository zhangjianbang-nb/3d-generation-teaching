一 · 问题定位：分辨率、显存与 2D 卷积之间的三角矛盾

Triplane 生成器要解决的不是“能不能生成 3D”这件事，而是“在有限显存下把 3D 表示的分辨率推到 2D 生成器已经习惯的量级”这件事。把 3D GAN 的表示选择摊开看，会看到一个三方约束：体素表示把空间离散成 \(N^3\) 个体素，显存与计算随边长立方增长；纯隐式表示（coord-MLP）把整个场景压进一个 MLP，参数量与空间分辨率解耦，但每个采样点都要过一遍网络，渲染一张图要查询几十万到上百万次，训练吞吐被压死；而 2D 卷积生成器已经在图像域证明了高效——特征图上的卷积核共享、局部感受野、层次化上采样，单位显存能换到的有效像素远高于 3D 卷积。

于是问题被重述为：能不能构造一种 3D 表示，让“生成”这一步完全发生在 2D 特征图上，由 2D 卷积承担，而“查询”这一步足够便宜，使得体渲染可以在可接受的时间内完成？Triplane 的答案是：把 3D 场分解为三张正交的 2D 特征图，让 2D 卷积生成它们，查询时做三次双线性插值再拼接。这里的关键取舍是——用“表达冗余”换“生成效率”。三平面并不像体素那样一一对应空间中的体素格，它把同一个 3D 点投影到三个平面上各取一次特征，三个投影之间必然存在信息重叠；这种重叠不是缺陷，而是让 2D 卷积的归纳偏置（平移不变、局部性）能够约束 3D 一致性的代价。

具体机制上，体素表示的一次前向是 3D 卷积在 \(N\times N\times N\) 张量上滑动，核大小 \(k\) 的 3D 卷积单层计算量约为 \(k^3 N^3 C_{in}C_{out}\)；三平面表示则是三张 \(N\times N\) 的 2D 特征图，单层 2D 卷积计算量约为 \(3 k^2 N^2 C_{in}C_{out}\)。两者相差一个 \(kN\) 量级的因子，这就是 Triplane 能把平面分辨率推到远高于体素边长的原因。代价是：三平面只能表达“沿三个轴向投影后不冲突”的场，对于沿某个轴高度重复的结构（例如一根贯穿整个空间的细杆），三个平面上的投影会互相干扰，重建时出现伪影。

一个具体的失败模式：当物体包含薄壁结构（例如杯壁、叶片）时，xy 平面上的投影会把前后两层壁叠在同一像素上，插值得到的特征是两个壁的混合，MLP 解码时无法区分前后，体渲染出现“鬼影”或壁厚错误。这不是训练不充分，而是三平面投影本身的信息坍缩——同一投影射线上的所有点共享同一组平面坐标，特征必然被平均。工程判断是：三平面适合“整体形状 + 中等细节”的物体级生成，不适合需要精确薄壁或内部结构的场景。

二 · 核心思想：把 3D 场拆成三个 2D 生成问题

核心思想可以一句话说清：3D 场 \(F(\mathbf{x})\) 不直接由 3D 网络生成，而是分解为三张 2D 特征图 \(T_{xy}, T_{xz}, T_{yz}\)，每张图由一个 2D 卷积生成器从同一个隐向量 \(\mathbf{z}\) 生成；查询任意 3D 点 \(\mathbf{x}=(x,y,z)\) 时，把该点分别投影到三个平面上取特征，拼接后送一个小 MLP 解码出密度与颜色。

这个分解的数学结构是：

$$G(\mathbf{z})=\mathrm{TriPlane}_\theta(\mathbf{z}),\qquad F(\mathbf{x})=\mathrm{MLP}\!\left(\mathrm{interp}(T_{xy},\mathbf{x}),\mathrm{interp}(T_{xz},\mathbf{x}),\mathrm{interp}(T_{yz},\mathbf{x})\right)$$

逐项解释。\(\mathrm{TriPlane}_\theta(\mathbf{z})\) 是一个 2D 卷积骨干（例如 StyleGAN 类的生成器），输出三张 \(H\times W\times C\) 的特征图，三张图共享同一个 \(\mathbf{z}\)，因此它们在统计上是相关的——这是 3D 一致性的来源之一。\(\mathrm{interp}(T_{xy},\mathbf{x})\) 表示把 \(\mathbf{x}\) 的 \((x,y)\) 坐标映射到 \(T_{xy}\) 的像素网格上做双线性插值，得到 \(C\) 维特征；同理 \((x,z)\) 取 \(T_{xz}\)，\((y,z)\) 取 \(T_{yz}\)。三次插值得到 \(3C\) 维向量，拼接后送入 MLP。MLP 通常很浅（两三层），输出标量密度 \(\sigma\) 和颜色 \(\mathbf{c}\)。

为什么这个结构能保证 3D 一致性？因为三个平面不是独立生成的——它们由同一个隐向量经同一个骨干生成，骨干的 2D 卷积在三个平面上共享权重或至少共享隐码，使得平面之间的特征分布被联合约束。更准确地说，一致性不是靠显式的 3D 监督获得的，而是靠“同一个 \(\mathbf{z}\) 必须同时解释三张平面”这一结构约束逼出来的：如果三张平面描述的 3D 场不自洽，2D 判别器在任意视角渲染出的图像上都会暴露矛盾，梯度回传会惩罚这种不自洽。这就是“2D 卷积负责生成，三平面共享约束负责一致性”的含义。

系统代价在于：三张平面特征图的分辨率是 \(H\times W\)，而 3D 空间的有效分辨率受限于平面分辨率与投影几何。当相机视角接近某个平面的法向时，该平面提供的特征最丰富；当视角接近掠射角时，三个平面的插值都退化，细节丢失。具体例子：俯视一个物体时，xy 平面贡献最大，xz 与 yz 平面上的投影被压缩，插值误差放大，俯视图的细节明显弱于正视图。这是三平面表示的视角各向异性，工程上需要通过相机分布采样来平衡——训练时相机不能只集中在某一侧。

三 · 公式逐步推导：从隐向量到体渲染的每一步

把流程拆成五步，每步给出输入输出与计算形态。

第一步，隐向量到三平面。\(\mathbf{z}\in\mathbb{R}^{d}\) 经 2D 卷积骨干上采样，输出三张特征图 \(T_{xy},T_{xz},T_{yz}\in\mathbb{R}^{H\times W\times C}\)。这一步的计算量与 2D GAN 生成一张 \(H\times W\) 图像相当，只是通道数乘以三。显存占用约为 \(3HWC\) 个浮点数，对比体素表示的 \(N^3 C\)，当 \(H=W=N\) 时三平面显存是体素的 \(3/N\) 倍——这是 Triplane 显存优势的来源。

第二步，3D 点投影与插值。给定 \(\mathbf{x}=(x,y,z)\)，归一化到 \([0,1]\) 后分别取 \((x,y)\)、\((x,z)\)、\((y,z)\) 作为平面坐标，双线性插值：

$$\mathrm{interp}(T,\mathbf{x})=\sum_{i\in\{0,1\}}\sum_{j\in\{0,1\}} w_i w_j\, T\!\left[\lfloor u\rfloor+i,\ \lfloor v\rfloor+j\right]$$

其中 \(u,v\) 是平面坐标乘以平面边长后的浮点位置，\(w_i,w_j\) 是距离权重。三次插值共 \(3\times 4=12\) 次采样、\(3C\) 维输出。这一步是纯查表，没有矩阵乘，代价低但访存密集——体渲染每张图要查询数十万点，插值的随机访存是训练吞吐的瓶颈之一。

第三步，拼接与 MLP 解码。\(3C\) 维向量送入 MLP，输出 \(\sigma\) 与 \(\mathbf{c}\)。MLP 的输入维度是 \(3C\)，隐藏层通常与 \(C\) 同量级，层数两到三。这里有一个设计细节：密度 \(\sigma\) 应当只依赖几何，颜色 \(\mathbf{c}\) 还依赖视角方向 \(\mathbf{d}\)，因此常见做法是 MLP 先输出 \(\sigma\) 与一个视角无关的特征，再拼接 \(\mathbf{d}\) 经一个小头输出 \(\mathbf{c}\)。公式里省略了 \(\mathbf{d}\)，但工程实现中必须显式处理，否则生成结果没有镜面反射等视角相关效果。

第四步，体渲染。沿相机射线积分：

$$\hat{C}(\mathbf{r})=\int_{t_n}^{t_f} T(t)\,\sigma(\mathbf{r}(t))\,\mathbf{c}(\mathbf{r}(t),\mathbf{d})\,dt,\qquad T(t)=\exp\!\left(-\int_{t_n}^{t}\sigma(\mathbf{r}(s))\,ds\right)$$

离散化后是标准的 alpha 合成，每个像素采样 \(N_s\) 个点，每点一次三平面查询加一次 MLP。渲染一张 \(R\times R\) 图像的计算量约为 \(R^2 N_s\) 次查询，这是整个流程最重的部分。

第五步，2D 判别器对抗训练。渲染出的图像与真实图像（或相机分布下的真实多视图）一起送入 2D 判别器，判别器只看单张 2D 图像，不看 3D 结构。梯度经体渲染回传到三平面与 MLP。可加姿态条件：把相机参数作为条件输入生成器与判别器，使生成器学会在指定视角下渲染。

失败模式：因为判别器是 2D 的，几何真值弱，生成器可能学会“在训练相机分布内渲染正确、分布外视角崩塌”的解。具体例子：训练相机只覆盖前半球，生成器可能把背面渲染成正面特征的镜像，因为 2D 判别器从未见过背面图像，没有梯度纠正它。这不是三平面独有的问题，但三平面的对称性冗余会放大它——三个平面在镜像变换下容易产生近似解，网络倾向于走这条捷径。

四 · 与体素表示、纯隐式表示的数学差别

与体素表示的差别在参数化方式。体素把场写成离散张量 \(V\in\mathbb{R}^{N^3\times C}\)，查询是最近邻或三线性插值，表达是“空间格点一一对应”。三平面把场写成三张 2D 张量的组合，查询是三次投影插值再拼接。数学上，体素是 3D 空间上的完整基展开，三平面是三个 2D 子空间上的投影叠加。三平面丢失了“同一投影射线上不同点的区分能力”——这是秩的损失。体素没有这个损失，但代价是 \(N^3\) 的参数量与计算量。用线性代数的语言：三平面把 3D 场限制在“三个 2D 函数之和”的子空间内，这个子空间的维度是 \(3N^2C\)，远小于体素的 \(N^3C\)，因此表达力有上限，但对物体级生成足够。

与纯隐式表示（coord-MLP）的差别在计算形态。纯隐式把整个场编码进 MLP 权重，查询是一次前向，没有显式空间结构；三平面把空间结构显式化到特征图上，MLP 只做局部解码。数学上，纯隐式是 \(F(\mathbf{x})=\mathrm{MLP}(\mathbf{x})\)，输入是坐标本身；三平面是 \(F(\mathbf{x})=\mathrm{MLP}(\mathrm{interp}(T,\mathbf{x}))\)，输入是坐标处的特征。前者让 MLP 承担全部空间记忆，后者让 2D 卷积承担空间记忆、MLP 只承担局部语义。这带来两个后果：其一，三平面的 MLP 可以很浅，查询便宜；其二，三平面的空间记忆是“卷积归纳偏置”的，具有平移不变性，而纯隐式的空间记忆是“坐标编码”的，需要位置编码才能表达高频细节。

表格对比三种表示的关键量：

表示参数/显存形态单点查询代价表达力约束生成骨干
体素\(N^3C\)三线性插值，\(O(1)\)无投影坍缩，但受格点分辨率限制3D 卷积，计算量大
纯隐式MLP 权重，与分辨率解耦一次 MLP 前向，\(O(\text{层数}\times\text{宽度}^2)\)无显式空间结构，高频细节依赖位置编码无空间骨干，全靠 MLP

具体例子说明差别：生成一个带把手的杯子。体素表示需要 \(N\) 足够大才能分辨把手与杯壁之间的空隙，\(N\) 每翻倍显存翻八倍；纯隐式表示可以无限查询，但训练时每个点都要过 MLP，渲染一张图的时间随采样数线性增长；三平面表示用三张 \(H\times W\) 图，把手在 xy 与 xz 平面上的投影都能提供特征，但 yz 平面上的投影会把把手与杯壁叠在一起，MLP 需要靠三组特征的组合来消歧——这正是三平面“冗余换效率”的典型场景。

五 · 对称性冗余与固定拓扑：表达层的两个硬约束

三平面表达有两个结构性约束，工程上必须正视。第一个是交换对称性冗余：三张平面在坐标轴置换下是对称的，\((x,y)\leftrightarrow(y,x)\) 对应 xy 平面自身的转置，而三个平面之间的角色在轴置换下互换。这意味着网络可以学到多组等价的平面配置，参数空间中存在平坦方向，训练时表现为收敛后平面之间的特征分布高度相似、区分度低。具体机制：如果 MLP 对三组特征的处理是对称的（例如简单拼接后过共享层），那么任意交换两张平面而不改变输出，梯度无法区分三张平面的分工，网络倾向于让三张平面学近似相同的特征，浪费表达容量。工程上的缓解手段是给每张平面加可学习的平面标识嵌入，或让 MLP 的第一层对三组特征使用不同的权重块，打破对称。

第二个是固定拓扑。三平面生成器输出的是三张固定尺寸的特征图，物体的拓扑（连通分量数、亏格）由特征图的连续值隐式决定，没有显式的部件结构。这带来两个后果：其一，难以做部件编辑——你无法“选中把手”并单独修改它，因为把手不是结构化的实体，只是特征图上的一片区域；其二，拓扑变化（例如从实心体变成带孔结构）需要特征图上的大面积协同变化，训练信号稀疏时容易失败。具体例子：训练集中杯子有把手，测试时要求生成无把手杯子，三平面生成器没有“把手开关”这样的结构变量，只能靠隐空间插值碰运气，结果往往是把手半消失、留下残影。

这两个约束的代价是定性的：对称性冗余浪费容量、拖慢收敛；固定拓扑限制编辑能力。它们不是实现 bug，而是三平面参数化的固有属性。工程判断是：如果任务需要部件级编辑或拓扑变化，三平面不是合适的表示，应当考虑结构化表示（例如部件分解的隐式场）或带显式拓扑变量的生成模型。如果任务是大规模物体级生成、追求分辨率和吞吐，三平面的这两个约束可以接受，代价是放弃精细编辑。

最后落到一个具体机制上：三平面的一致性约束本质上是“同一隐向量必须同时解释三张平面在任意相机下的渲染”，这个约束的强度取决于相机分布的覆盖度。相机分布越均匀，三张平面被迫分工越明确，对称性冗余越难被利用；相机分布越集中，网络越容易找到“只在一侧自洽”的捷径解。因此训练三平面生成器时，相机采样策略不是超参数细节，而是决定几何质量的核心机制——它直接控制了三平面共享约束的信息量。
