一 · 与单阶段一体化生成的逐项对比

把形状-材质双 DiT 放回相邻算法的坐标系里，最直接的参照是单阶段一体化生成：一个骨干网络同时回归几何隐表示与材质通道，共享同一套注意力与同一份条件编码。双 DiT 的差别不在“多了一个网络”这种表面描述，而在梯度路径的分离程度。单阶段模型中，几何损失与材质损失反传进同一组参数，形状分支的高频几何梯度与材质分支的低频反射率梯度在共享权重上叠加，形成一种隐式的梯度干涉：几何收敛快时会把共享特征拉向边缘与法线方向，材质收敛慢时又要求特征保留大尺度光照一致性，两者在同一层上争夺表示容量。双 DiT 用两个独立参数集切断这条干涉路径，形状 DiT 只被 $\mathcal{L}_{\mathrm{shape}}$ 驱动，材质 DiT 只被 $\mathcal{L}_{\mathrm{PBR}}$ 驱动，联合目标 $\mathcal{L}=\mathcal{L}_{\mathrm{shape}}+\lambda\mathcal{L}_{\mathrm{PBR}}$ 中的 $\lambda$ 退化为一个纯粹的后处理式加权，而不再是训练动力学里的耦合系数。

这种分离带来的具体机制是容量分配的自由度。单阶段模型要在同一组通道里同时表达 SDF 的零水平集细节与 UV 空间的三通道材质场，通道预算被迫折中；双 DiT 可以让形状分支按稀疏体素/VecSet 的分辨率需求扩张，让材质分支按 UV 贴图的纹素密度扩张，两条 scaling 曲线互不牵制。代价是条件编码必须被复制或共享：图像条件编码器若共享，则两个分支的反传仍会在编码器处汇合，干涉只是被推迟到条件端；若完全独立，则条件编码的参数量与显存翻倍，且两分支对同一张输入图像的理解可能出现漂移——形状分支学到的“这是什么物体”和材质分支学到的“这是什么材质”不再被强制对齐，合成时可能出现几何与贴图语义不匹配的资产。

失败模式在这里很具体：当输入图像存在强镜面高光时，单阶段模型倾向于把高光烘进反照率，因为它无法区分“亮”是几何朝向还是材质反射；双 DiT 的材质分支在 UV 空间扩散时同样缺乏显式的光照解耦监督，$\mathcal{L}_{\mathrm{PBR}}$ 只约束 $\hat{a},\hat{r},\hat{m}$ 与监督值的逐通道平方误差，若监督数据本身来自含高光的渲染，反照率就会被污染。此时形状分支输出正确的法线与粗糙度几何，材质分支却给出带高光斑的反照率贴图，合成渲染在引擎里表现为“几何正确但材质发花”。这是数据限制而非结构缺陷，但它说明双 DiT 的解耦只解耦了参数，没有解耦光照物理。

二 · 与“先几何后材质”串行管线的对比

另一类相邻做法是串行两阶段：先用一个几何生成器出网格，再把网格的渲染图喂给一个材质预测器。它与双 DiT 的表面结构相似——都是两段——但条件流的方向不同。串行管线中，材质阶段的输入是形状阶段输出的渲染或几何缓冲，条件是被几何“污染”过的；双 DiT 中，两个分支共享的是原始图像条件，形状输出不进入材质分支的输入路径，材质 DiT 在 UV 空间独立扩散。这个差别决定了两类方法的误差传播方式。

串行管线的失效是级联式的：几何阶段的任何缺陷——缺失的凹槽、错误的拓扑、Marching Cubes 产生的非流形边——都会通过渲染缓冲进入材质阶段，材质预测器会试图用贴图去“解释”几何错误，例如把本该是凹槽的阴影区域涂成深色反照率。误差不可逆，因为材质阶段没有机会质疑几何。双 DiT 的失效是并行式的：形状分支与材质分支各自失败，失败在合成环节才暴露。形状分支的 UV 展开失败（接缝错位、重叠岛）会让材质 DiT 在错误的 UV 布局上扩散，贴图与几何的对应关系错位；但材质分支本身不受几何拓扑影响，它只是在 UV 空间做扩散，几何错误不会改写它的条件编码。

从系统代价看，串行管线只需一次几何前向加一次材质前向，显存峰值出现在材质阶段读取几何缓冲时；双 DiT 需要同时或顺序持有两个 DiT 的激活，若并行执行则显存峰值是两个分支之和，若顺序执行则总延迟是两段之和且中间要落盘 SDF 与 UV 布局。工程上更常见的做法是顺序执行：形状 DiT 出 SDF，Marching Cubes 出网格，UV 展开写出一份布局文件，材质 DiT 读布局文件在 UV 空间扩散。这条路径的失败点集中在 UV 展开：展开算法对高 genus 或薄壁结构容易产生重叠岛，重叠区域的纹素被两个面共享，材质扩散时同一纹素收到来自不同面的梯度，收敛到折中的颜色，渲染时表现为接缝处的色块。

具体例子：一个带镂空花纹的薄壁灯罩，形状分支能出高分辨率 SDF 并成功 Marching Cubes，但 UV 展开在镂空边缘产生大量细碎岛，材质 DiT 在这些岛上的纹素密度不足，反照率出现模糊；串行管线则会在几何阶段就把镂空边缘渲染成锯齿，材质阶段把锯齿烘成暗边。两者的失败外观不同，但都指向同一个工程判断：几何分辨率与 UV 布局质量是材质真实感的前置条件，双 DiT 没有消除这个前置条件，只是把它从梯度耦合问题转移成了管线接口问题。

三 · 失效条件清单

双 DiT 的失效可以按触发条件归类，每一类都对应一个可观测的信号，便于在部署时做前置检查。

  • UV 展开失败。触发条件：高 genus 拓扑、薄壁、大量独立部件。信号：UV 岛数量异常膨胀、岛间重叠率超阈值、接缝长度占比过高。后果：材质 DiT 在错误布局上扩散，贴图与几何错位，合成渲染出现接缝色块或纹理拉伸。这是管线中最难自动检测的一环，因为展开算法本身不返回置信度。
  • 材质监督数据的光照污染。触发条件：训练数据含强镜面高光、含烘焙阴影的反照率。信号：材质分支输出的反照率在几何朝向亮面出现系统性亮斑，粗糙度通道与反照率通道相关性异常。后果：$\mathcal{L}_{\mathrm{PBR}}$ 的逐通道平方误差在污染样本上给出低损失但物理错误的解，模型学会把光照烘进材质。
  • 条件语义漂移。触发条件：两个分支的条件编码器完全独立且训练数据分布不一致。信号：形状分支生成的物体类别与材质分支的材质类别在合成资产上不匹配，例如金属几何配了布料反照率。后果：单看每个分支的损失都正常，合成后才暴露，属于典型的接口失效。
  • 分辨率错配。触发条件：形状分支的体素分辨率与材质分支的 UV 纹素密度不匹配。信号：几何边缘锐利但贴图在边缘处模糊，或贴图锐利但几何边缘呈阶梯状。后果：渲染时视觉质量被短板决定，scaling 的收益被抵消。
  • λ 失衡。触发条件：$\lambda$ 设置使 $\mathcal{L}_{\mathrm{PBR}}$ 在联合目标中占比过低或过高。信号：材质通道收敛慢于形状通道，或形状通道被材质梯度拖慢。后果：虽然两分支参数独立，但若共享条件编码器，$\lambda$ 仍会通过编码器反传影响形状分支的特征，失衡时形状质量下降。

这些失效条件的共同点是：它们都不表现为训练损失的异常，而表现为合成资产的物理不合理。因此评估双 DiT 不能只看两个分支各自的验证损失，必须走完整管线做渲染级评估，检查接缝、光照一致性、材质与几何的语义匹配。这也是两阶段管线复杂性的真实代价：评估面从单模型扩展到整条管线，每个接口都是潜在的失效点。

四 · 选型建议

选型的第一问不是“哪个模型更强”，而是“输出要不要直接进引擎”。若下游是离线渲染或需要 PBR 资产的资产库，双 DiT 的输出形态——网格加 UV 空间反照率/粗糙度/金属度贴图——省去了从隐表示拆解材质的后处理，且形状与材质各自 scaling 的收益在高质量资产上可观测。若下游只需要几何或只需要预览图，单阶段一体化或纯几何生成器的管线更短，双 DiT 的 UV 展开与合成环节是纯开销。

第二问是数据条件。材质分支的真实感受限于 PBR 监督数据的覆盖：若目标品类的材质（例如特定织物、涂层金属）在监督数据中缺失，材质 DiT 只能外推到相近材质，$\mathcal{L}_{\mathrm{PBR}}$ 的低损失不代表物理正确。此时选串行管线并用目标品类的渲染图做材质微调，比强行用双 DiT 更可控，因为串行管线的材质阶段可以直接以几何渲染为条件做域适应。反之，若监督数据覆盖充分且品类多样，双 DiT 的独立 scaling 更能吃到数据量红利。

第三问是拓扑复杂度。UV 展开的失败率随拓扑复杂度上升，高 genus、薄壁、大量独立部件的资产在双 DiT 管线下需要额外的展开后处理与人工检查。若资产品类集中在类目单一、拓扑简单的物体（例如家具、容器），展开失败可控；若品类是镂空、薄壁、多部件装配体，展开环节应作为独立的质量门禁，失败时回退到体素纹理或三平面投影作为材质载体，而不是让材质 DiT 在坏布局上硬扩散。

第四问是训练预算与迭代节奏。双 DiT 的两套参数意味着两套优化器状态、两份激活、两次前向，训练吞吐低于单阶段；但两个分支可以独立训练、独立调参、独立回滚，形状分支收敛后可以冻结，只迭代材质分支。工程上这降低了联合调参的维度：单阶段模型的几何与材质超参纠缠，改一个学习率会同时扰动两条损失；双 DiT 把这种纠缠拆成两个可分别调试的子系统，代价是管线接口的维护成本。选型时应把“调参自由度”与“接口维护成本”放在同一张表上权衡，而不是只看单次前向的算力。

五 · 三道练习

练习一：梯度干涉的定量观察。构造一个单阶段模型与一个双 DiT，在相同数据上训练到形状损失收敛。固定形状分支，只对材质损失做一次反传，记录共享条件编码器（若存在）上梯度范数的变化；再在完全独立编码器的双 DiT 上重复。要求给出两次梯度范数的比值，并解释该比值与 $\lambda$ 的关系。此题的目的是把“解耦”从定性描述变成可测量的量，读者应能写出反传路径上梯度汇合点的位置。

练习二：UV 展开失败的检测器。给定一批网格与对应的 UV 布局，设计一个不依赖人工检查的失败信号：统计岛数量、岛间重叠面积占比、接缝长度与表面积之比，并给出一个判定阈值。然后用一个高 genus 网格与一个简单容器网格验证该信号能否区分。要求写出伪代码思路：遍历面片、并查集合并 UV 连通分量、计算包围盒重叠、累计接缝边。此题对应管线中最难自动检测的一环，目的是让读者意识到材质 DiT 的质量上限被展开算法钳制。

练习三：λ 的选型实验设计。在联合目标 $\mathcal{L}=\mathcal{L}_{\mathrm{shape}}+\lambda\mathcal{L}_{\mathrm{PBR}}$ 中，$\lambda$ 的取值会通过共享编码器影响形状分支。设计一个实验：固定形状分支的验证指标（例如 Chamfer 距离或法线一致性），扫描 $\lambda$，观察形状指标随 $\lambda$ 的变化曲线，找出形状指标开始退化的临界点。要求说明为什么在完全独立编码器的双 DiT 上该曲线应近似平坦，并给出两种编码器配置下的预期差异。此题的目的是把“λ 失衡”这一失效条件转化为可操作的调参流程：先确定编码器共享策略，再定 $\lambda$，而不是反过来。

三道练习的共同指向是：双 DiT 的工程判断落在接口上，而不是落在单个分支的指标上。形状分支的 Chamfer 距离与材质分支的逐通道误差都可以做得很漂亮，但合成资产的接缝、光照一致性、语义匹配才是选型的真实依据。把评估从分支级提升到管线级，把失效条件写成可检测的信号，把 $\lambda$ 与编码器共享策略绑定成一组联合决策——这是双 DiT 从论文机制走向可部署资产管线的最后一段路。管线里每一个接口的失败模式都比模型内部的数学差别更决定最终资产能否进引擎，工程判断应优先落在 UV 展开的质量门禁与材质监督数据的光照解耦上，因为这两处是 $\mathcal{L}_{\mathrm{PBR}}$ 的平方误差无法感知、却直接决定渲染结果的地方。
