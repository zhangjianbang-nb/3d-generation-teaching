一 · 从三平面瓶颈到高斯参数直出

前馈重建模型长期被一个结构性矛盾卡住：网络内部表示与最终渲染器之间隔着一层转换。以三平面（triplane）为代表的隐式表示，把场景压缩成三张正交特征图，查询时用坐标插值得到密度与颜色，再交给体渲染积分。这条路径的问题不在表达能力，而在输出接口。体渲染要求沿射线做大量采样，每个采样点都要查特征、过小 MLP，渲染一张图的计算量与采样数线性相关；更麻烦的是，三平面本身不携带显式的表面位置，要拿到网格必须跑 marching cubes，等值面阈值的选择、特征分辨率的上限、密度场的模糊性都会在提取阶段引入损失。工程上这意味着训练目标（体渲染像素损失）与交付物（网格或可实时渲染的资产）之间存在一道无法用梯度跨越的鸿沟。

前馈高斯输出头的核心判断是：既然最终要的是可微光栅化能吃的显式图元，就不要让网络输出隐式场再转换，而是让 Transformer 直接回归 3D 高斯参数集合。形式化地，给定 K 个视图图像及其相机参数，网络一次前向输出高斯集合：

$$\mathcal{G}=\mathrm{Transformer}_\theta(I_{1:K},\mathbf{c}_{1:K}),\qquad \hat{I}=\mathrm{Rasterize}(\mathcal{G},\mathbf{c}')$$

这里 $\mathcal{G}=\{(\boldsymbol{\mu}_i,\Sigma_i,\alpha_i,\mathbf{sh}_i)\}_{i=1}^{N}$，每个高斯携带均值、协方差、不透明度与球谐颜色系数。第一个式子说明网络是唯一的重建主体，第二个式子说明渲染器是固定的、可微的、与网络解耦的。关键变化在于：渲染不再需要沿射线采样，光栅化把每个高斯投影到屏幕、按深度排序、做 alpha 混合，计算量正比于高斯数量而非采样密度。梯度从渲染图像经光栅化回传到高斯参数，再回传到 Transformer 权重，端到端一次完成。

这个设计与 NeRF 系前馈模型（如 pixelNeRF、通用 NeRF 前馈）的数学差别是根本性的。NeRF 系输出的是一个连续函数 $f(\mathbf{x},\mathbf{d})\to(\sigma,\mathbf{c})$，渲染算子是沿射线的积分 $\hat{C}=\int T(t)\sigma(t)\mathbf{c}(t)dt$ 的离散近似，网络与渲染器通过采样点耦合，采样策略（分层、重要性）成为系统的一部分。高斯头输出的是有限个离散图元，渲染算子是排序加混合的解析近似，网络与渲染器通过图元参数耦合，不存在采样预算这个超参数。代价是网络必须自己决定“哪里放高斯、放多少”，这是一个离散的、非凸的分配问题，而 NeRF 把这个决定推给了渲染时的采样密度。

二 · 多视图 token 化与相机嵌入的编码机制

输入侧的处理决定了 Transformer 能看到什么。流程是 2–4 个视图，每个视图被切成 patch，patch 经线性投影变成 token，同时叠加相机嵌入。相机嵌入不是可选项：没有它，网络无法区分“同一物体在不同视角下的外观”与“不同物体”，也无法把 2D patch 的位置反投影到 3D 空间。工程实现上，相机嵌入通常把相机中心、旋转（或射线方向）编码成与 patch token 同维的向量，加到每个 token 上或作为交叉注意力的 key。这一步的数学含义是给每个 token 标注它在世界坐标系中的“出生地”，让后续注意力能在几何上对齐不同视图的观测。

设第 k 个视图有 $P$ 个 patch token $\mathbf{t}_{k,p}\in\mathbb{R}^{d}$，相机嵌入 $\mathbf{e}_k\in\mathbb{R}^{d}$，则送入编码器的序列是 $\{\mathbf{t}_{k,p}+\mathbf{e}_k\}$，长度为 $K\cdot P$。Transformer 编码器在这个序列上做自注意力，其效果是跨视图匹配：同一个 3D 点在不同视图里的 patch 会通过注意力互相“认领”，形成对该点的多视图一致性表征。这一步隐含了一个几何假设——patch 的感受野要足够覆盖对应点，且相机嵌入要足够精确，否则注意力会匹配到错误的 patch 上。

解码侧的结构选择直接决定高斯参数的生成方式。常见做法是让解码器输出一组“高斯 query”，每个 query 通过交叉注意力从编码器 token 中聚合信息，再经 MLP 头分裂出四个量：均值 $\boldsymbol{\mu}\in\mathbb{R}^3$、协方差参数、不透明度 $\alpha\in[0,1]$、球谐系数 $\mathbf{sh}$。协方差不直接回归矩阵元素，而是回归旋转四元数 $\mathbf{q}$ 与缩放 $\mathbf{s}\in\mathbb{R}^3$，再组装 $\Sigma=R(\mathbf{q})\,\mathrm{diag}(\mathbf{s}^2)\,R(\mathbf{q})^\top$，这样保证 $\Sigma$ 恒为正定，避免训练中出现非法的协方差导致光栅化数值爆炸。这是一个纯粹的参数化技巧，但它是系统能稳定训练的前提之一。

这里出现第一个系统代价：token 数量与显存。序列长度是 $K\cdot P$，自注意力的计算与显存是 $O((KP)^2)$ 量级。视图数从 2 增到 4，序列翻倍，注意力矩阵翻四倍。高分辨率 patch 化会进一步放大这个量级，而 patch 太小则感受野不足、跨视图匹配失效。工程上必须在“patch 分辨率—视图数—批大小”三者之间做取舍，这不是调参问题，是显存墙的直接约束。

三 · 高斯参数头的逐步数学解释

把参数头拆开看，每个输出量的数学角色不同，训练时的梯度路径也不同。均值 $\boldsymbol{\mu}_i$ 决定高斯在世界空间的位置，它经相机投影变换进入屏幕空间：给定相机参数 $\mathbf{c}'$，投影得到屏幕坐标 $\mathbf{u}_i=\pi(\boldsymbol{\mu}_i,\mathbf{c}')$ 与深度 $z_i$。协方差 $\Sigma_i$ 经投影的雅可比 $J$ 变换为屏幕空间协方差 $\Sigma_i'=J\Sigma_i J^\top$（实际实现取二维切片），这个变换决定了高斯在屏幕上的椭圆形状与覆盖范围。不透明度 $\alpha_i$ 与屏幕空间 alpha 混合直接相关，球谐 $\mathbf{sh}_i$ 则按视角方向 $\mathbf{d}$ 求值得到颜色 $\mathbf{c}_i=\mathrm{SH}(\mathbf{sh}_i,\mathbf{d})$。

光栅化的前向是沿像素做加权求和。对像素 $\mathbf{p}$，把覆盖它的高斯按深度排序，做前向到后向的 alpha 合成：

$$\hat{C}(\mathbf{p})=\sum_{i\in\mathcal{N}(\mathbf{p})}\mathbf{c}_i\,\alpha_i'(\mathbf{p})\prod_{j

其中 $\alpha_i'(\mathbf{p})=\alpha_i\exp\bigl(-\tfrac{1}{2}(\mathbf{p}-\mathbf{u}_i)^\top\Sigma_i'^{-1}(\mathbf{p}-\mathbf{u}_i)\bigr)$ 是高斯在像素处衰减后的有效不透明度，$\mathcal{N}(\mathbf{p})$ 是按深度排序后覆盖该像素的高斯集合。这个式子是标准 3DGS 光栅化的形式，其可微性来自每一项对 $\boldsymbol{\mu}_i,\Sigma_i,\alpha_i,\mathbf{c}_i$ 的解析导数。训练损失通常是渲染图与真值图的 L1 加 SSIM 组合，梯度经上式回传到每个高斯参数，再经参数头回传到 Transformer。

逐步看梯度路径，会发现一个结构性差异：$\boldsymbol{\mu}_i$ 的梯度同时受“投影位置是否对准”和“深度排序是否正确”影响，后者是离散的、不可微的排序操作，实现上用近似排序或停止梯度处理；$\Sigma_i'$ 的梯度决定高斯的“锐度”，过大会让单个高斯覆盖过多像素、梯度弥散，过小则覆盖不足、出现空洞；$\alpha_i$ 的梯度与遮挡关系耦合，前向高斯的 $\alpha$ 增大会压低后面高斯的贡献，形成竞争。这意味着参数头的四个输出不是独立学习的，它们在光栅化方程里强耦合。一个具体的失败模式是：网络倾向于把 $\alpha$ 推向饱和、把 $\Sigma$ 推向很小，用大量小高斯“贴”出图像，渲染损失降下去了，但几何是碎的、高斯数是爆的，换视角就露馅。这是渲染损失与几何正确性之间的错配，也是稀疏视图下几何不稳的根源之一。

与相邻算法的数学差别可以列成一张对照表：

维度三平面 + 体渲染前馈高斯输出头
网络输出特征图，查询时插值显式高斯参数集合
渲染算子沿射线积分，采样近似投影排序 + alpha 混合
计算量驱动采样数 × 分辨率高斯数 × 覆盖像素
几何提取marching cubes，有阈值损失高斯即几何，无提取步骤
梯度路径网络—采样点—积分网络—图元参数—光栅化
离散决策采样策略（外部）高斯分配（网络内部）

这张表里最关键的一行是最后一行。三平面把“在哪里采样”交给渲染器，网络只负责连续场；高斯头把“在哪里放图元”收进网络，渲染器变成无决策的固定算子。数学上这是把一个大范围的非凸优化从渲染时前移到训练时，用端到端梯度替代手工采样策略。收益是推理时一次前向、实时渲染；代价是网络必须学会一个离散分配问题，而渲染损失对这个问题的监督是弱的——它只监督“看起来像”，不监督“高斯是否落在真实表面上”。

四 · 端到端训练回路与失败模式

训练回路的伪代码思路如下：对每个场景，采样 2–4 个输入视图与 1 个目标视图；输入视图 patch 化并加相机嵌入，过 Transformer 编码器；高斯 query 经解码器交叉注意力聚合，过参数头得到 $\mathcal{G}$；用目标视图相机参数光栅化 $\mathcal{G}$ 得 $\hat{I}$；计算 $\mathcal{L}=\|\hat{I}-I_{\text{gt}}\|_1+\lambda\,\mathrm{SSIM}(\hat{I},I_{\text{gt}})$；反向传播经光栅化到参数头到 Transformer。整个回路没有体渲染采样，没有 marching cubes，没有第二阶段优化，一次前向出资产。

这个回路的失败模式有三个具体的工程形态。第一是显存：Transformer 注意力是 $O((KP)^2)$，光栅化要对每个高斯做投影与排序，高斯数 $N$ 大时排序的显存与带宽成为瓶颈；训练时还要保留光栅化的中间量用于反向，显存占用随 $N$ 与分辨率同时增长。第二是稀疏视图几何不稳：2–4 个视图的基线有限，跨视图注意力能匹配到的对应点少，网络容易用“外观捷径”而非几何来解释像素——把高斯贴在视锥内的任意位置，只要投影后颜色对得上，损失就低。第三是高斯数限制细节：参数头输出的高斯数是固定的（由 query 数决定），复杂场景需要的高斯密度超过这个上限时，细节被平均掉，表现为高频纹理模糊或薄结构丢失。

举一个具体例子说明三者的耦合。假设输入是两个相隔较远的视图，目标视图在两者之间。网络若把某个高斯放在错误的深度上，它在两个输入视图的投影可能都落在低纹理区域，渲染损失对该高斯的梯度接近于零，这个高斯就“漂”在那里；换到目标视图，它可能突然遮挡住正确的高斯，产生鬼影。这不是训练不充分，是渲染损失在稀疏视图下对深度的监督信号本身不足。工程上的应对不是加训练步数，而是加视图、加几何先验（如深度监督、多视图一致性正则），或者限制高斯的空间分布范围。这解释了为什么该算法把输入视图数标在 2–4 这个窄区间：少于 2 无法三角化，多于 4 则显存与注意力成本陡增，而几何稳定性并不随视图数线性改善。

另一个具体例子是协方差参数化的数值行为。若参数头回归的缩放 $\mathbf{s}$ 出现极端值（某个分量趋近零），$\Sigma$ 接近奇异，投影后的 $\Sigma'^{-1}$ 数值爆炸，$\alpha'$ 在像素上变成近似阶跃函数，梯度出现尖峰，训练发散。实现上通常对 $\mathbf{s}$ 做下界裁剪或对 $\Sigma'$ 加正则项，这是参数化选择带来的系统代价，不是算法思想的问题，但它决定了这套机制能否在工程上跑通。与之相对，三平面的特征插值是平滑的，不会出现这种奇异性，但代价是表达高频细节时需要提高特征分辨率，显存同样吃紧。两条路径的失败模式不同，约束却是同一类：显存与几何监督的稀缺。

五 · 与相邻算法差别的机制层解释

把高斯头与基于点的前馈重建（如点云预测加泼溅渲染）对比，差别在于图元是否带可学习的各向异性。点泼溅的图元是各向同性的圆盘，协方差固定，网络只需回归位置与颜色；高斯头的协方差是网络输出，意味着网络要同时学“位置”和“形状”。这多出来的自由度提升了细节锐度——薄结构可以用扁长高斯贴合——但也让优化 landscape 更复杂，因为形状与位置的梯度通过投影雅可比耦合。数学上，点泼溅的渲染方程是高斯方程在各向同性下的特例，高斯头是它的严格推广，推广的代价是参数空间的维度增加与训练不稳定性的增加。

与基于网格的前馈重建（如直接回归网格顶点）对比，差别在于拓扑是否显式。网格回归要面对拓扑固定的问题：顶点数固定、连接关系固定，复杂拓扑需要变形或细分，前馈一次预测很难处理。高斯集合没有连接关系，是一组无拓扑的图元，天然适应任意拓扑，代价是没有显式的表面连续性，渲染时依赖高斯的重叠来“糊”出连续表面。这解释了为什么高斯头在细节锐度上有优势而在几何规整性上弱于网格方法：前者用密度换拓扑自由，后者用拓扑换表面规整。

与三平面的数学差别还可以从函数类的角度看清。三平面定义的是一个连续函数类，其表达能力受特征分辨率与插值方式限制，高频细节需要高分辨率特征图，显存随分辨率平方增长。高斯头定义的是一个有限离散图元集合，其表达能力受高斯数限制，细节需要更多高斯，显存随高斯数线性增长（加上排序的带宽）。两者都是“用资源换细节”，但 scaling 的曲线不同：三平面是分辨率平方，高斯是数量线性。在同等显存下，高斯头能堆更多“有效自由度”在表面附近，这是它在细节锐度上占优的机制层原因；但高斯数的上限是硬的，超过上限细节就丢，而三平面可以通过提高分辨率渐进改善。这个差别决定了两种算法适合的场景不同，也决定了高斯头必须把“高斯数限制细节”列为不足。

最后落到一个工程判断上：高斯头的端到端回路把渲染器变成固定算子，网络承担了全部几何决策，这使得系统的可预测性集中在“参数头输出是否合理”这一点上。调试时最有效的观测不是渲染损失曲线，而是高斯参数的分布——均值是否聚集在表面附近、协方差是否出现极端各向异性、不透明度是否饱和。这些分布直接对应光栅化方程的每一项，比损失曲线更能定位失败模式。参数头的四个输出在方程里强耦合，任何一个量的分布异常都会以渲染伪影的形式表现出来，而伪影的形态（鬼影、空洞、模糊）反过来指示是哪个量的监督出了问题。
