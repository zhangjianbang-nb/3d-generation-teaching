一 · 与序列式重拓扑的逐项对照

把相邻网格 token 重拓扑放回它所属的序列生成家族里，最直接的参照是“逐面独立 token”的朴素方案：每个面用三个顶点索引的离散 token 表示，解码器自回归地吐出 F 组三元组。两者的差别不在解码器骨架，而在 token 的语义边界。朴素方案里，第 i 个面与第 i−1 个面在 token 空间上完全无关，模型必须自己学会“相邻面共享一条边”这一约束；而相邻 token 编码把这条约束硬编码进词表：每个面 token 只声明“从上一条边往哪一侧长出第三个顶点”，于是共享边成为语法的一部分，而不是需要学习的统计规律。

这个差别可以用一个简单的计数刻画。设输出网格有 F 个面、V 个顶点、E 条边，欧拉公式给出 V − E + F = 2 − 2g（g 为亏格）。朴素方案每个面需要 3 个顶点索引 token，总 token 数 $$L_{\mathrm{naive}}=3F$$；相邻方案每个面只需 1 个“转向 + 长度”token（外加首面的启动 token），总 token 数 $$L_{\mathrm{adj}}=F+O(1)$$。在面数相同的条件下，序列长度缩到约三分之一。这不是常数级优化，而是直接改变了自回归解码的可行域：注意力代价随序列长度平方增长，F 从数千降到数百量级时，单样本解码从“必须分块”变成“可以整段跑”。

代价也随之转移。朴素方案的词表是顶点索引，规模随 V 线性增长，词表嵌入层显存与 V 成正比；相邻方案的词表是局部的转向与边长量化桶，规模固定，与输入网格顶点数解耦。但相邻方案把误差累积的路径拉长了：一个面的第三个顶点位置由前一条边和转向共同决定，若前一个面的边长量化偏了一档，后续所有复用该边的面都会继承这个偏差。这是“复用边”这一机制的内禀失败模式——拓扑连续性换来了几何误差的链式传播。工程上的缓解手段是在训练时对边长量化桶做抖动增广，让模型见到同一拓扑在不同量化档位下的样本，从而降低对单档误差的过拟合。

具体例子：一个由布尔运算产生的硬表面零件，原始输出约两万面、大量退化三角形与 T 型接缝。朴素序列方案在解码到第几百个面时就开始出现自交，因为模型没有任何机制阻止新面穿过已有面；相邻方案由于每个新面必须挂在上一条边上，自交只能发生在“转向角过大”的情形，而转向角是词表里的离散量，越界即被截断，输出天然是一张连通的、可定向的流形片。代价是零件上的锐利倒角被量化桶抹平——细节丢失正是这套编码的结构性代价，而非训练不足。

二 · 与隐式场重拓扑的对照

另一条主流路线是隐式场重拓扑：先训一个符号距离场或占用场拟合输入，再用 marching cubes 或 dual contouring 提取等值面，最后做简化与四边形化。它与相邻 token 方案的分歧点在“拓扑从哪里来”。隐式场方案的拓扑由等值面提取的网格分辨率决定，分辨率越高越贴近输入，但面数随分辨率立方增长；相邻 token 方案的拓扑由自回归序列的生成顺序决定，面数由模型自己“决定”停在哪里，天然满足 $$|\mathcal{M}_{\mathrm{out}}|\ll|\mathcal{M}_{\mathrm{in}}|$$ 的目标。

隐式场方案的优势是几何保真度可控：给定足够分辨率，薄壁、尖角、细小孔洞都能被等值面捕获，误差上界由采样步长给出。相邻 token 方案的劣势恰在此处——它输出的是面片序列，几何精度受限于边长量化桶与转向离散化，薄壁结构若窄于最小边长桶，会在序列生成中被“跳过”，表现为输出网格上出现本不该有的连通桥。这是一个可判定的失效条件：当输入网格的最小特征尺寸小于量化桶下界时，重拓扑必然丢特征。工程上应在预处理阶段测量输入的特征尺寸分布，若下四分位数低于桶下界，就应先做一次保特征的降采样或直接切换到隐式场路线。

系统代价的对比同样清晰。隐式场方案需要一次前向场查询加一次等值面提取，显存峰值由体素网格尺寸主导，通信量小但计算密集；相邻 token 方案是自回归解码，显存峰值由 KV 缓存主导，随序列长度线性增长，且解码不可并行——第 i 个面依赖第 i−1 个面的边。这意味着在批量推理时，相邻方案的吞吐受限于最长序列，短网格会被长网格拖住。实践中的做法是按输入面数分桶批处理，把序列长度接近的样本放进同一批，避免一个两万面的输入拖垮整批。

具体例子：一个扫描得到的人像头部，表面有大量高频噪声与细小褶皱。隐式场方案在中等分辨率下会把噪声平滑成团块，丢失皮肤纹理的起伏；相邻 token 方案对输入噪声敏感，噪声点云会让编码器特征抖动，解码器在若干位置生成方向错误的转向 token，输出出现局部翻折。两者都不是“更好”，而是失效方向不同：前者丢高频几何，后者丢拓扑稳定性。选型时应先问“输入是干净 CAD 还是含噪扫描”，而不是问“哪个算法更强”。

三 · 与学习式四边形化的对照

第三条参照线是直接预测四边形网格的学习式方法：网络输出每个顶点的位置与四边形连接表，或用面片图神经网络迭代细化。相邻 token 方案输出的是三角形面片序列，四边形化需要后处理配对。两者的核心差异在“连接表的生成方式”。学习式四边形化把连接表当作一个全局的图结构一次性回归，输出维度固定，无法自适应面数；相邻 token 方案把连接表拆成一条链，链长由停止 token 决定，面数自适应。对于面数爆炸的生成模型输出，自适应这一点是决定性的——你无法预先知道该简化到多少面。

但链式生成有一个结构性弱点：它只能生成“带状”遍历顺序下的拓扑，对于需要非局部连接的结构（例如一个环面上的把手，其连接跨越了序列上相距很远的位置），链式编码必须绕远路，序列长度随之膨胀。设网格的带宽为 b（按面邻接图的最优线性排列的最大跨度），链式编码的序列长度至少为 F，但有效信息量受 b 影响：b 越大，复用边的局部性假设越不成立，转向 token 的预测越依赖长程上下文，解码器的注意力负担越重。这是序列长度仍是瓶颈这一不足的精确来源，而不是笼统的“长序列难训”。

失败模式可以这样判定：对一个高亏格、多把手的网格，若链式解码在某个把手处反复生成回退 token（转向角指向已访问边），说明局部编码无法表达该处的非局部连接，输出会缺失把手或把两个把手错误合并。工程上的兜底是检测输出网格的亏格：若与输入亏格不符，判定为拓扑失败，回退到隐式场路线或人工干预。这个检测很便宜，只需一次欧拉示性数计算，应作为流水线的强制校验点。

具体例子：一个机械支架，带三个减重孔，亏格为三。链式解码在第一个孔处顺利绕行，到第二个孔时因序列上下文已被前一个孔的边占用，转向 token 找不到合法的未访问边，输出把两个孔合并成一条槽。这不是训练数据不足，而是编码的表达上界。选型判断因此很直接：亏格低、结构以带状展开为主的资产（角色、道具、建筑构件）适合相邻 token 路线；亏格高、连接高度非局部的资产（复杂机械、拓扑优化的多孔结构）应优先隐式场或混合路线。

四 · 失效条件清单与判定顺序

把上述失效模式整理成可执行的判定顺序，比罗列优缺点更有工程价值。判定应在推理前、推理中、推理后三个阶段分别进行，每一阶段都有明确的量化门槛与回退动作。

  • 推理前：测量输入的最小特征尺寸与噪声水平。最小特征尺寸低于边长量化桶下界，判为几何丢失高风险；点云法向方差超过阈值，判为噪声敏感高风险。两者任一命中，先做预处理或切换路线。
  • 推理前：计算输入亏格与面数的比值。亏格相对面数偏高（非局部连接密集），判为链式表达上界风险，准备隐式场兜底。
  • 推理中：监控解码的停止 token 位置与回退 token 频率。回退频率在某段窗口内持续偏高，说明局部编码在该区域失效，可提前截断并标记该样本。
  • 推理后：校验输出亏格与输入亏格是否一致、输出是否单连通、是否存在自交。任一不满足，判为拓扑失败，回退。
  • 推理后：校验输出面数是否落在目标区间。若远低于目标，说明模型过度简化，细节丢失超出可接受范围。

这套判定的代价是每个样本多出若干次几何统计，相对自回归解码本身可以忽略；但它把“事后发现输出不能用”变成“事前分流”，避免了整批重跑。需要强调的是，这些门槛不是拍脑袋的常数，而应由目标资产的容差反推：动画绑定要求四边形主导与均匀边长，渲染要求无自交与法向一致，两者对应的门槛不同，应在流水线配置里显式区分。

一个具体的失败链：含噪扫描输入 → 编码器特征抖动 → 解码器在平坦区域生成错误转向 → 输出出现局部翻折 → 绑定阶段权重扩散异常。若在推理前做了噪声判定并先做一次保特征平滑，这条链在第一步就被切断。反之，若只做事后校验，翻折网格已经进入下游，返工成本落在绑定环节而非重拓扑环节，这是典型的代价错配。

五 · 选型建议与三道练习

选型的核心不是比较算法强弱，而是匹配输入分布与下游用途。给定事实中的优势与不足已经划出了适用边界：面数大幅降低、拓扑适合动画渲染、可接任意生成模型输出，这三点指向“生成模型产出的、面数爆炸的、需要进入美术流水线的资产”。不足中的重拓扑丢细节、序列长度瓶颈、对输入噪声敏感，则划出了不适用区：高保真扫描、高亏格结构、强噪声输入。

输入/用途首选路线理由必须加的校验
生成模型输出的角色/道具，面数爆炸相邻 token 重拓扑面数自适应降低，拓扑连续，可直接绑定亏格一致性、自交检测
干净 CAD 硬表面，需保留锐边相邻 token + 特征保持预处理链式编码保拓扑，锐边需在量化前锁定最小特征尺寸 vs 桶下界
含噪扫描，高保真需求隐式场重拓扑几何保真可控，噪声被等值面平滑分辨率与薄壁捕获
高亏格、非局部连接结构隐式场或混合路线链式编码表达上界不足亏格与把手完整性

三道练习用于把上述判断落到手上。练习一：取一个面数超过一万的生成模型输出，分别用逐面独立 token 与相邻 token 两种编码统计序列长度与解码显存峰值，验证 $$L_{\mathrm{adj}}\approx L_{\mathrm{naive}}/3$$ 的量级关系，并记录相邻方案中误差沿复用边传播的具体位置。练习二：构造一个亏格为二的小网格，人为把两个把手靠近到小于边长量化桶的距离，观察链式解码是否合并把手，并写出你的亏格校验代码路径。练习三：给同一含噪输入分别跑相邻 token 与隐式场两条路线，用最小特征尺寸、自交数、亏格偏差三个指标做对照表，据此为你自己的资产库写一条选型规则——规则必须包含一个可计算的阈值，而不是“看情况”。

最后落在工程判断上：相邻网格 token 重拓扑的价值不在单点精度，而在把“拓扑合法性”从学习目标变成解码语法，使输出天然可绑定、可渲染。它的失效边界由量化桶下界与链式表达上界共同划定，前者决定几何细节的保留下限，后者决定非局部拓扑的可表达范围。任何把它用于高亏格或亚桶尺度特征的尝试，都会在这两条边界上撞墙；而在这两条边界之内，它是当前把生成模型输出接入美术流水线的最短路径。
