一 · 问题的形式化：为什么顶点色与三平面纹理进不了引擎

生成模型（尤其是基于隐式场或高斯泼溅的 3D 生成器）输出的颜色表示，与实时渲染引擎所需的材质表示之间存在结构性错位。顶点色把颜色绑定在顶点上，其分辨率由网格细分密度决定：一个十万面片的网格，顶点色能表达的细节上限就是顶点间距，一旦镜头推近，颜色块会随三角形插值而糊化。三平面纹理把颜色存在三张正交平面上，采样时按坐标投影混合，它本质是隐式场的伴随表示，没有 UV 参数化，也就没有纹理寻址的概念。引擎的像素着色管线要求的是每个片元能通过 (u,v) 查到一张贴图的纹素，这个 (u,v) 来自网格的 UV 属性，与顶点位置无关。因此问题不是“颜色不够好”，而是“颜色没有可寻址的坐标系统”。

把这个问题写成约束形式：给定生成网格 $M=(V,F)$ 与表面颜色场 $C:\mathbb{R}^3\to\mathbb{R}^3$，需要构造参数化 $\phi:M\to[0,1]^2$ 与贴图组 $T=\{T_a,T_r,T_m,T_n\}$，使得对任意表面点 $p$，引擎按 $\phi(p)$ 采样得到的反照率、粗糙度、金属度、法线，与原始外观在目标光照下一致。这里有两个独立难点：$\phi$ 必须是单射且低畸变的分段线性映射，否则贴图会出现重叠或拉伸；$T$ 的通道语义必须与光照解耦，否则贴图只在生成时的光照下正确，换环境光就崩。顶点色方案在这两个难点上都不成立——它没有 $\phi$，也没有通道语义，只有一个被烘焙了光照的 RGB 三元组。

具体例子：一个由隐式场提取的椅子网格，扶手处曲率大、顶点稀疏，顶点色在该处只有四个顶点参与插值，反照率细节完全丢失；而引擎的 PBR 管线期望扶手有一张 1024² 的粗糙度贴图来表现磨砂金属的微观高光断裂。两者之间的差距不是后处理能补的，必须重建参数化并重新采样材质。

二 · 核心思想：反投影 + 扩散补全的两段式分解

该算法的核心是把“生成外观”与“生成材质”拆成两个可分别求解的子问题。第一段是几何侧：对生成网格做 UV 展开，得到参数化 $\phi$；随后在多个视角下渲染网格，把渲染得到的颜色按 $\phi$ 反投影回 UV 空间，得到一张稀疏、带洞的初始贴图。第二段是材质侧：把这张带洞贴图当作条件，用扩散模型在 UV 空间补全反照率、粗糙度、金属度通道，并在训练中施加光照解耦约束，使补全出的通道不携带生成时的环境光。

反投影的机制值得展开。设视角 $k$ 的相机投影为 $\pi_k$，渲染得到像素颜色 $I_k$。对每个可见片元，其重心坐标给出表面点 $p$，参数化给出 $(u,v)=\phi(p)$，于是把 $I_k(\pi_k(p))$ 写入 UV 贴图的 $(u,v)$ 位置。多视角叠加后，被至少一个视角覆盖的纹素获得观测值，未被覆盖的纹素留空。覆盖率的公式可写为

$$\mathrm{cov}(u,v)=\frac{1}{N_k}\sum_{k=1}^{N_k}\mathbb{1}\left[\exists p:\phi(p)=(u,v),\ p\ \text{visible in view}\ k\right]$$

覆盖率低的区域正是补全网络要填的洞。这里的关键工程判断是：反投影得到的观测值本身带有生成时的光照，直接当反照率用会把阴影和高光烘死。所以第二段的扩散模型不是简单的图像修复，而是带通道语义的条件生成——它以观测值为条件，但输出的反照率通道要去掉观测值里的光照分量。

失败模式出现在两段的衔接处。若 UV 展开在某个区域产生了重叠（$\phi$ 非单射），反投影会把两个不同表面点的颜色写到同一纹素，扩散模型收到的是自相矛盾的条件，补全结果出现鬼影。若展开产生严重拉伸，纹素密度在拉伸方向骤降，反投影观测稀疏到无法约束扩散采样，补全退化为纯先验幻觉，材质与几何脱节。这两种失败都不是扩散模型能修的，源头在参数化质量。

三 · 损失函数逐项拆解：$\mathcal{L}_{\mathrm{PBR}}$ 在约束什么

给定公式

$$\mathcal{L}_{\mathrm{PBR}}=\sum_{v\in\mathcal{V}}\left\|\hat{\mathbf{a}}(u_v,v_v)-\mathbf{a}_v\right\|^2+\left\|\hat{r}_v-r_v\right\|^2+\left\|\hat{m}_v-m_v\right\|^2$$

逐项看。$\mathcal{V}$ 是带材质标注的顶点或表面采样点集合，$(u_v,v_v)=\phi(v)$ 是其在 UV 空间的坐标。$\hat{\mathbf{a}}$、$\hat{r}$、$\hat{m}$ 是网络在 UV 坐标处预测的反照率（三通道）、粗糙度（标量）、金属度（标量）；$\mathbf{a}_v$、$r_v$、$m_v$ 是监督目标。三项都是 L2，意味着三个通道被同等加权、独立回归。这个设计隐含一个假设：三个通道在 UV 空间是空间对齐的，同一个 $(u,v)$ 处的反照率、粗糙度、金属度描述同一个表面微元。这正是 UV 参数化带来的好处——顶点色方案无法保证这种对齐，因为颜色和材质若分别存在顶点上，插值核不同会导致通道错位。

公式里没有法线项，也没有光照项。这不是遗漏，而是分工：法线由几何侧从网格法线烘焙得到，不需要学习；光照解耦不写在 $\mathcal{L}_{\mathrm{PBR}}$ 里，而是通过训练数据的构造（同一材质在不同光照下的多组观测）隐式约束。换句话说，$\mathcal{L}_{\mathrm{PBR}}$ 只保证“通道值对”，不保证“通道语义对”。语义正确性依赖数据侧的解耦设计，这是该算法最脆弱的一环。

系统代价：三项 L2 在 UV 空间等权，但三个通道的可学习性差异很大。反照率是高频三通道信号，需要网络容量；粗糙度和金属度是低频标量，过早收敛后会主导梯度、压制反照率的学习。工程上常见的处理是对粗糙度、金属度项降权或做梯度归一化，但公式本身不体现这一点，直接照公式实现会在反照率细节上欠拟合。具体例子：金属把手与塑料把手在反照率上可能几乎相同（都是灰色），区别全在金属度通道；若金属度项收敛过快，网络会把两者预测成同一材质，重光照时金属把手失去环境反射，塑料把手错误地出现镜面反射。

四 · 与相邻算法的数学差别：三平面、顶点色、纯图像修复

与三平面表示相比，差别在定义域。三平面把信号定义在三个正交平面上，采样算子是投影加混合：$C(p)=\sum_i w_i(p)\,T_i(\pi_i(p))$，其中 $\pi_i$ 是到第 $i$ 个平面的正交投影。这个算子是多对一的，不同空间点可以映射到同一纹素，因此三平面天然允许重叠，不需要单射约束。UV 参数化恰恰相反，$\phi$ 必须是单射（或有受控重叠），采样算子是 $T(\phi(p))$，寻址依赖网格拓扑。数学后果是：三平面无法直接表达“接缝”和“UV 岛”，而引擎的纹理管线以 UV 岛为单位做 mipmap、各向异性过滤和流式加载。把三平面转成 UV 贴图，本质是把一个多对一的投影表示重采样成一个一对一的参数化表示，信息损失发生在重叠区被强制拆分的时刻。

与顶点色相比，差别在插值核与分辨率解耦。顶点色的采样是重心插值 $C(p)=\sum_{j\in\text{tri}} \lambda_j C_j$，分辨率锁定在顶点密度上；UV 贴图的采样是双线性纹素查询，分辨率由贴图尺寸决定，与网格密度无关。这个解耦让同一网格可以承载远超顶点数的材质细节，代价是需要一次参数化计算和一次反投影重采样。数学上，顶点色是定义在顶点集合上的离散信号，UV 贴图是定义在二维连续域上的离散信号，两者之间的转换是一次带洞的、非均匀的重新采样，洞的分布由 $\phi$ 的畸变和视角覆盖共同决定。

与纯图像修复（inpainting）相比，差别在条件结构。图像修复的条件是同一图像内的已知像素，空间邻域连续；UV 空间补全的条件是反投影观测，其空间邻域在 UV 岛边界处断裂，且观测值带有光照污染。因此扩散模型不能直接套用自然图像先验，必须在训练中见过“带光照的观测 → 去光照的材质通道”这一映射。失败模式：若直接用自然图像修复模型补 UV 贴图，模型会把观测里的阴影当作反照率的一部分延续到洞里，补全出的贴图在重光照下出现固定的暗斑，且暗斑位置随生成时的光照方向漂移，无法通过后处理去除。

五 · 光照解耦的训练机制与它的不彻底性

光照解耦的机制是构造配对数据：同一材质在不同环境光照下渲染出多组观测，网络以观测为输入、以材质通道为目标，学习把光照分量从观测中剥离。设观测 $I=L\cdot\mathbf{a}+S$（$L$ 为光照算子，$S$ 为镜面项），网络要预测 $\mathbf{a}$、$r$、$m$ 而非 $I$。这个映射在数学上是欠定的：给定单个观测 $I$，满足 $I=L\cdot\mathbf{a}+S$ 的 $(\mathbf{a},L,S)$ 有无穷多组解。解耦的可行性完全依赖训练分布覆盖了足够多的 $L$，使网络学到“哪些变化随光照变、哪些不随”。

不彻底性由此而来。若测试时的光照落在训练分布之外（例如极端的彩色环境光、强方向性的轮廓光），网络没有见过对应的剥离模式，会把部分光照残留进反照率。公式上，$\mathcal{L}_{\mathrm{PBR}}$ 不惩罚这种残留，因为监督目标 $\mathbf{a}_v$ 只在训练分布内定义。工程后果是：输出的贴图在标准 HDRI 下看起来正确，换一张没见过的 HDRI 就出现色偏。具体例子：训练数据以中性白环境光为主，测试时用暖色日落光渲染，补全出的反照率偏冷（网络把暖光当作应剥离的分量过度补偿），重光照后物体比预期更蓝。

另一个不彻底性来自镜面项 $S$ 与粗糙度的耦合。粗糙度低的表面，镜面项集中在高光处，反投影观测在高光区饱和；网络在这些饱和纹素上无法区分“亮反照率”与“强高光”，倾向于把饱和值压进反照率，导致该区域反照率偏高、粗糙度偏低。这是观测的动态范围限制造成的，不是网络容量问题。系统代价是：高光密集的材质（抛光金属、湿润表面）在解耦后普遍出现反照率过亮、粗糙度偏低的偏差，且偏差随高光强度单调增长。

工程判断落在数据侧而非损失侧：要让解耦更彻底，必须扩大光照分布的覆盖并控制观测的动态范围（例如用多曝光合成避免饱和），而不是在 $\mathcal{L}_{\mathrm{PBR}}$ 里加正则项。损失函数只约束通道值，光照语义的正确性由训练分布的广度决定，这是该算法在数学结构上的固有分工。
