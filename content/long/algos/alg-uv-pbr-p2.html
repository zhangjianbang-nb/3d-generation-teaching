一 · UV 展开子系统的复杂度与失败面

把 UV 展开放进整条生成流水线之后，它不再是一个离线美术工具，而是一个必须对任意拓扑给出确定性结果的子系统。工程上要区分两种复杂度：展开算法本身的复杂度，以及为了得到“可接受展开”而反复重试的期望复杂度。前者通常是网格面数与割缝长度的近线性量级，后者才是真正的成本大头，因为生成模型输出的网格常常带有非流形边、退化三角形、自相交薄片和孤立小岛，任何一条都会让展开器返回失败或给出重叠严重的参数化。

一个可落地的判定思路是：把展开视为带约束的优化，目标是最小化保角失真与面积失真的加权和，约束是割缝集合必须使网格拓扑等价于圆盘。写成伪代码思路大致是：先做连通分量分解，对每个分量检测亏格与边界环数；若亏格大于零或边界环数不等于一，则求解割缝树把拓扑约化为圆盘；再对约化后的网格做参数化求解；最后做重叠检测与纹素密度归一化。重叠检测这一步不能省，因为参数化求解器在数值退化时可能给出局部翻转的三角形，而翻转在光栅化阶段表现为纹理撕裂，肉眼可见但不会抛异常。

$$\mathcal{E}_{\mathrm{UV}}=\sum_{t\in\mathcal{T}} A_t\left(\left\|\mathbf{J}_t\right\|_F^2+\left\|\mathbf{J}_t^{-1}\right\|_F^2\right)+\lambda\sum_{e\in\mathcal{S}}\left\|\mathbf{u}_a-\mathbf{u}_b\right\|^2$$

式中第一项是三角形雅可比矩阵的保角与面积联合惩罚，第二项对割缝两侧的 UV 距离施加惩罚以抑制割缝过度碎裂，$\lambda$ 控制碎裂倾向。工程上的代价在于：割缝越多，接缝处的反投影采样越容易出现跨缝插值错误，材质扩散补全阶段还必须把接缝两侧视为弱相关区域，否则补全网络会把不连续的颜色抹平，造成贴图在接缝处出现模糊带。

具体例子：一个由隐式场提取的网格，表面布满厚度接近零的薄片结构。展开器在薄片处计算雅可比时条件数爆炸，参数化求解迭代不收敛，返回的 UV 中薄片两侧三角形互相覆盖。此时若直接进入反投影，薄片区域会采到错误视图的颜色，最终 PBR 贴图在该处呈现错误的金属度。失败模式不是崩溃，而是“看起来能渲染但物理量错”，这类错误在下游引擎的光照计算中会被放大。因此工程上必须设置展开质量门限：翻转三角形比例、割缝总长度与表面积之比、纹素密度方差，三项任一越界即触发重试或退回三平面纹理路径。

二 · 多视图反投影的显存与带宽账

反投影阶段把多视图渲染结果写回 UV 空间，本质是一次带可见性判断的散射写操作。每个视图需要一张深度缓冲、一张法线缓冲和若干张材质缓冲；对每个可见像素，通过视图投影矩阵与逆 UV 映射找到对应的纹素坐标，再做深度比较决定是否写入。显存占用的主体不是 UV 贴图本身，而是视图缓冲组与可见性缓冲。若分辨率取 $R\times R$、视图数为 $N$、每像素携带反照率三通道加粗糙度与金属度共五通道，则视图侧缓冲的字节量近似为 $N\cdot R^2\cdot(3+1+1+3)$，其中最后三项是深度与法线所需的浮点通道。

带宽压力出现在两个方向：一是多视图渲染时对网格的重复遍历，二是反投影时对 UV 纹素的随机写。随机写的缓存命中率取决于 UV 布局的局部性，而 UV 展开恰恰倾向于把空间上相邻的表面映射到 UV 上不相邻的区域，这使写操作呈现散列特征。工程上的缓解手段是把反投影改为按 UV 纹素驱动：对每个 UV 纹素，反查其在三维表面上的位置，再判断该位置在哪些视图中可见，从可见视图中加权取色。这样写操作变成顺序写，代价是每个纹素要做 $N$ 次可见性查询，计算量上升但访存模式友好。

具体例子：一个包含大量细小零件的机械模型，UV 图集被切成数百个小岛。按像素驱动的散射写在每个小岛边界处产生大量缓存失效，反投影耗时随岛数增长而非随面积增长。改为纹素驱动后，每个岛内部的纹素连续处理，边界纹素单独处理，整体访存局部性显著改善。失败模式则是可见性判断的精度问题：深度比较使用浮点缓冲时，薄壁结构的前后表面深度差小于精度，导致背面颜色渗到正面，表现为贴图上出现鬼影。工程上需要按模型尺度设定深度偏移，并对可见视图数做上限截断，避免单个纹素累积过多视图造成过度平滑。

三 · 材质扩散补全的采样步数与一致性代价

材质扩散补全在 UV 空间上运行，输入是反投影得到的稀疏或不完整材质图，输出是完整的反照率、粗糙度、金属度三组贴图。它与图像补全的关键差别在于：UV 空间没有透视投影带来的尺度变化，但有接缝、岛间空白和纹素密度不均。扩散模型的采样步数直接决定显存峰值与延迟，因为在注意力机制中，序列长度与 UV 分辨率平方成正比。若把 UV 图集视为单张 $R\times R$ 图像送入扩散网络，注意力矩阵的显存为 $O(R^4)$ 量级，这是不可接受的；工程上必须采用分块或卷积化的架构，把感受野限制在局部，再通过多尺度下采样获得全局一致性。

一致性代价体现在两个层面。其一是岛间一致性：不同 UV 岛在三维表面上可能相邻，但在 UV 上被割缝隔开，扩散网络若只看 UV 邻域，会把相邻表面补成不同材质，渲染时接缝处出现突变。其二是多通道一致性：反照率、粗糙度、金属度若分别独立扩散，三者之间的物理相关性会丢失，例如金属区域应当具有低反照率与高金属度，独立采样可能生成高反照率的金属，违反能量守恒的直觉。工程上的做法是把三通道拼成一张多通道张量联合扩散，并在损失中加入跨通道相关项。

$$\mathcal{L}_{\mathrm{cons}}=\sum_{e\in\mathcal{S}}\left\|\mathbf{c}_{e^{+}}-\mathbf{c}_{e^{-}}\right\|^2+\beta\sum_{v}\left\|\hat{m}_v\cdot\hat{\mathbf{a}}_v\right\|^2$$

第一项惩罚割缝两侧材质通道的差异，第二项惩罚金属度与反照率的病态组合。具体例子：一个角色模型的头发区域在 UV 上被切成多条细长岛，独立扩散时每条岛生成略微不同的粗糙度，渲染时头发呈现条带状高光断裂。联合扩散加割缝一致性项后，条带消失，代价是采样步数增加、单次生成延迟上升。失败模式是过度平滑：一致性权重过大时，扩散网络倾向于把所有岛补成相同材质，丢失局部细节，表现为整张粗糙度贴图趋于常数。

四 · 光照解耦的训练目标与残留耦合

光照解耦的目标是把反投影得到的、含 baked 光照的颜色分解为反照率与光照两部分，使输出的 PBR 贴图在重光照下仍然正确。训练上的核心是构造配对数据：同一表面在不同光照条件下的渲染结果，其反照率与材质参数不变，只有光照项变化。网络需要学习一个映射，使得在给定单张含光照图像时，预测的反照率不随光照变化。这本质上是一个欠定问题，因为单张图像中反照率与光照的乘积不可唯一分解，必须依赖先验。

工程实现上通常采用双分支结构：一个分支预测反照率与材质参数，另一个分支预测光照场（球谐系数或环境图），两者相乘重建输入图像，重建损失约束一致性，而解耦损失则通过对同一表面施加不同光照的配对样本来施加。伪代码思路是：对每个训练样本，采样两组光照，分别渲染得到两张输入；网络对两张输入预测的材质参数应当一致，而光照分支应当不同；损失由重建项与材质一致性项组成。系统代价在于配对数据的构造需要可微渲染器，渲染成本与样本量线性相关，且渲染器的材质模型必须与目标引擎一致，否则解耦学到的先验在引擎中不成立。

残留耦合是这条流水线最典型的失败模式。当输入图像中存在强烈的阴影或高光时，网络倾向于把阴影解释为反照率变暗，把高光解释为反照率变亮，因为单张图像无法区分二者。结果是输出的反照率贴图带有 baked 阴影，重光照时阴影会随光照方向移动而出现“双重阴影”。具体例子：一个在强侧光下生成的模型，其背光面在反照率贴图中被压暗；换到正面光照后，背光面仍然偏暗，与新的光照方向矛盾。工程上的缓解是引入材质先验约束，例如限制反照率的动态范围、对粗糙度施加平滑先验、在解耦损失中加入梯度域的一致性项，使阴影边缘不被误判为材质边缘。

五 · 工程坑与调参顺序

把这条流水线落地时，坑的分布有明显规律：多数问题不在扩散模型本身，而在几何与 UV 的接口处。第一类坑是纹素密度不均，UV 展开器为了降低失真会把大三角形分配更多 UV 面积，导致贴图在不同区域的有效分辨率差异巨大，扩散补全在小纹素区域欠采样、在大纹素区域过平滑。工程上需要在展开后做纹素密度归一化，把每个三角形的 UV 面积按其三维面积比例重分配，代价是失真上升，需要在失真与密度均匀之间取折中。

第二类坑是反投影的可见性阈值。深度比较的偏移量若按全局常数设定，在尺度差异大的模型上会失效：大尺度部件需要大偏移，小尺度部件需要小偏移。工程上应按局部包围盒尺度自适应设定偏移，并对每个纹素记录可见视图数，视图数过少的纹素标记为待补全区域，交给扩散阶段处理，而不是强行用单视图颜色填充。

第三类坑是通道顺序与色彩空间。反照率通常需要 sRGB 编码，而粗糙度与金属度是线性标量，若把五通道统一按 sRGB 处理，粗糙度会出现非线性压缩，渲染时高光宽度错误。工程上必须在输出阶段分离色彩空间，反照率走 sRGB，粗糙度与金属度保持线性，并在引擎导入时正确标注。

调参顺序应当由几何向材质推进，因为上游误差会被下游放大且难以归因。先固定展开参数，用翻转比例与纹素密度方差作为门限筛掉坏网格；再调反投影的深度偏移与视图数上限，用鬼影面积作为指标；然后调扩散的分块尺寸与一致性权重，观察接缝处的材质跳变；最后才调解耦损失的权重，用重光照下的阴影一致性作为判据。反过来先调解耦会掩盖几何问题，因为解耦网络会把接缝错误吸收进光照分支，表面上重建损失下降，实际贴图质量更差。

一个具体的调参陷阱：当展开失败率高时，直觉是放宽失真权重让展开器更容易成功，但这会加剧纹素密度不均，进而让扩散补全在小纹素区域产生噪点，最终表现为粗糙度贴图的颗粒感。正确的做法是保持失真权重、改为对失败网格做局部重网格化或退回三平面路径，把问题挡在展开阶段而不是让下游吸收。系统判断的标准是：若某网格的翻转比例超过门限且重试两次仍不下降，则该网格不适合走 UV 路径，应直接标记为不支持，而不是继续调下游参数。
