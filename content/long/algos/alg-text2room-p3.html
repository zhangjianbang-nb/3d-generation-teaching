一 · 与单图深度重建的逐项对比

把迭代式房间网格补全和“单图深度估计 + 一次性反投影”放在一起看，差别不在深度网络本身，而在几何证据的累积方式。单图方案只做一次前向：给定图像 I，网络输出深度 D，按相机内参 K 反投影得到点云或网格，流程即结束。它的几何完全由那一次预测决定，未被观测到的区域没有任何顶点，房间背面、相机背后、家具遮挡处一律是空洞。迭代式方案把这一次反投影当作起点，此后每一次相机移动都产生新的观测，新观测被融合进同一个全局网格，未被观测的区域由 2D 扩散先验临时填充，再被后续真实观测覆盖或修正。

具体机制上的差别体现在融合算子。单图方案等价于 M = BackProject(D, I, c)，一次成型；迭代式方案执行的是增量并集：

$$\mathcal{M}_{t+1}=\mathcal{M}_t\cup\mathrm{BackProject}\!\left(D_t,I_t,\mathbf{c}_t\right)$$

并集不是简单的顶点堆叠，它要求新反投影的几何与已有网格在重叠区对齐，否则会出现双层墙面、Z-fighting 和法向翻转。工程上这通常靠截断符号距离场（TSDF）或体素融合完成：新深度沿射线写入，权重按视角距离和入射角衰减，重叠区做加权平均。单图方案没有这一步，因此也不存在“对齐”这个失败模式，但它把全部风险压在深度预测的尺度与畸变上——预测偏 5%，整面墙就偏 5%，且无法自我纠正。

系统代价方面，单图方案显存占用近似常数，一次推理即可交付，适合快速预览；迭代式方案的显存随网格分辨率与已融合体素数量增长，每轮还要额外承担一次渲染（从当前网格渲染新视角的洞）和一次 2D 扩散采样。扩散采样是主要延迟来源：补洞区域越大、分辨率越高，采样步数带来的开销越显著。失败模式也截然不同：单图方案的典型失败是深度不连续处的“飞点”和薄结构丢失；迭代式方案的典型失败是长距离漂移，即相机绕行一圈回到起点时，新观测与最初观测在重叠区对不上，融合权重无法消解这种系统性偏差。

一个具体例子：对一张只拍到房间一角、可见一张书桌和半面墙的照片，单图方案能给出书桌的完整点云和那半面墙，但房间其余三面墙、地板延伸部分全是空。迭代式方案从同一张图出发，先把相机向右平移一个身位，渲染当前网格时右侧出现大片空洞，用 2D 扩散以“室内房间”先验补出墙面与地板纹理，反投影融合；再向前移动，补出书桌背面与墙角。若相机最终绕回起点，最初那半面墙的观测会与新观测在重叠区竞争，漂移在此暴露。

二 · 与场景补全/室内布局估计的对比

室内布局估计（room layout estimation）走的是另一条路线：从单张或少量全景图推断房间的曼哈顿结构——若干平面、若干正交方向、边界框，输出是参数化的长方体或平面集合，而不是稠密网格。它与迭代式补全的数学差别在于假设空间：布局估计把解限制在“轴对齐平面 + 少量开口”的低维流形上，因此对遮挡和噪声鲁棒，泛化到未见房间类型时不易崩，但无法表达非平面几何——斜靠的椅子、弧形沙发、堆叠的杂物。迭代式补全的解空间是稠密体素/网格，表达力强，代价是需要 2D 扩散先验在空洞处“编造”合理的几何与纹理，编造结果与真实观测之间没有一致性约束，只能靠后续观测覆盖。

机制上，布局估计通常先做语义分割或边缘检测，拟合消失点，再用优化求解平面参数；迭代式补全则在每轮做“渲染洞 → 扩散补洞 → 反投影 → 融合”的闭环。前者的误差是参数误差，可解释、可约束；后者的误差是几何与纹理的联合误差，扩散模型生成的墙面纹理在反投影后可能带有不符合透视的尺度，融合时表现为局部鼓起或凹陷。

系统代价对比：布局估计的推理成本低，输出紧凑，适合下游的路径规划与碰撞检测；迭代式补全的输出是稠密网格，存储与渲染成本高，且需要维护融合权重场。失败条件上，布局估计在非曼哈顿场景（斜墙、圆形房间）直接失效；迭代式补全在扩散先验与真实场景分布不匹配时失效——例如生成的是住宅卧室先验，实际是实验室，补出的洞在语义上合理但几何上错误，且这种错误不会被融合权重自动识别，因为权重只看几何重叠，不看语义。

具体例子：一个只有一扇窗和一面斜墙的阁楼。布局估计会强行拟合出正交长方体，斜墙被压平或丢弃；迭代式补全会保留斜墙的真实观测，但在斜墙背后的空洞处，2D 扩散按“普通房间”先验补出垂直墙面，反投影后与斜墙形成夹角，融合后在夹角处产生自交三角形。这个自交不会报错，只会让后续渲染出现黑边。

三 · 与整体 3D 生成的对比

文本到 3D 或图像到 3D 的整体生成方案（如基于多视图扩散再重建、或直接生成三平面/隐式场）一次性产出完整场景，不依赖相机逐步移动。它与迭代式补全的核心分歧在于“观测从哪来”：整体生成的所有视图都是模型想象的，彼此之间靠多视图一致性约束或注意力共享来对齐；迭代式补全的视图一半来自真实渲染（当前网格），一半来自扩散补全，真实观测锚定了几何，想象只填洞。

数学上，整体生成通常优化一个多视图一致性损失，例如不同视角渲染结果的感知距离或极线约束残差；迭代式补全没有全局优化目标，它是贪心的：每轮只保证当前视角的补洞在 2D 上合理，融合后不保证全局最优。这带来一个具体机制差异——整体生成可以做全局重投影误差最小化，漂移被摊到所有视图上；迭代式补全的漂移是局部累积的，早期误差无法被后期观测回溯修正，因为融合是单向并集，没有回环优化。

系统代价：整体生成需要同时持有多个视图的扩散采样，显存峰值高，且多视图一致性约束要求视图间有足够重叠，视图数量增加时通信与同步成本上升；迭代式补全的显存峰值出现在网格分辨率提高时，扩散采样是串行的，单轮成本可控，但总轮数随房间规模线性增长。失败模式：整体生成在多视图不一致时产生“鬼影”几何，多个视图的墙面互相穿插；迭代式补全在长距离漂移后产生“双墙”，即同一面墙被融合成两层薄壳，中间夹着未观测的空隙。

具体例子：生成一间带走廊的公寓。整体生成方案一次给出整套户型，走廊与房间的衔接处若多视图不一致，会出现门框悬空；迭代式补全方案从客厅出发，穿过走廊时相机移动距离长，走廊尽头的新观测与客厅起始观测在全局坐标系中的偏差累积，回到客厅时门框位置偏移，融合后门框出现重影。前者是一次性错误，后者是过程性错误，排查手段不同：前者查多视图注意力图，后者查每轮融合的重叠区残差。

四 · 失效条件清单

第一类失效是长距离漂移。机制上，每轮融合只在新观测与已有网格的重叠区做局部对齐，没有全局位姿图优化或回环检测。相机移动路径越长、重叠区越窄，局部对齐的残差越容易单向累积。判据是回环处的重叠残差：若同一面墙在起点与回环点的融合权重差异超过阈值，说明漂移已不可忽略。缓解手段是引入回环约束或定期做全局重投影优化，代价是额外的优化求解与内存。

第二类失效是补洞先验错配。2D 扩散模型在空洞处生成的内容服从其训练分布，若实际场景超出分布（工业管道、异形家具），补出的几何在语义上通顺但尺寸与透视错误。机制上，反投影把 2D 像素按估计深度映射到 3D，深度本身也是扩散或单目估计的产物，两层误差相乘。判据是补洞区域与相邻真实观测的接缝处出现纹理拉伸或法向突变。缓解手段是缩小补洞步长、增加真实观测比例，或引入几何先验约束反投影深度。

第三类失效是显存墙。网格分辨率提高时，体素数量按立方增长，融合权重场与法向场同步膨胀；扩散采样在高分辨率补洞时也需要更大的特征图。机制上，显存峰值由“网格体素 + 当前渲染缓冲 + 扩散中间激活”三者叠加决定。判据是分辨率翻倍后单轮耗时与显存占用是否超线性增长。缓解手段是分块融合、稀疏体素结构、或在粗分辨率下补洞再上采样。

第四类失效是薄结构与镜面。单目深度在薄板、玻璃、镜面上预测不稳，反投影后薄结构断裂，镜面则把对面几何错误地反投影到镜后。迭代式补全的融合无法区分“真实观测”与“镜面反射的伪观测”，伪观测会被当作真实几何并入网格，后续扩散在此基础上继续补洞，错误被放大。判据是镜面区域后方出现不该存在的几何。缓解手段是语义掩码剔除镜面与透明区域，代价是这些区域重新变成洞，需要扩散先验填充。

五 · 选型建议

按交付目标选型，而不是按算法新旧选型。若目标是快速预览一个房间的粗略形状、下游只做布局级推理，单图深度重建加布局拟合足够，成本最低，失败可解释。若目标是可漫游的稠密场景且允许离线多轮计算，迭代式补全合适，但必须接受漂移风险并预留回环优化或人工修正的环节。若目标是整套户型的一次性生成、不要求与真实照片对齐，整体 3D 生成更直接，代价是多视图一致性的调参成本。

方案几何证据来源主要成本典型失效适用场景
单图深度重建单次预测常数显存、单次推理飞点、薄结构丢失快速预览、布局级下游
布局估计平面拟合低非曼哈顿场景失效路径规划、碰撞检测

工程判断上，先问三个问题：观测是否必须与真实照片几何对齐？若是，迭代式补全或单图重建是候选，整体生成出局。场景是否超出扩散先验分布？若是，补洞比例必须压低，宁可留洞也不要错补。显存预算是否支持目标分辨率？若否，先降分辨率跑通闭环，再分块提升，而不是先调扩散步数。调参顺序上，融合权重与重叠区阈值优先于扩散步数，因为漂移主要由融合策略决定，扩散只影响补洞观感。

六 · 三道练习

练习一：漂移判据的构造。给定一条环形相机路径，每轮融合后记录重叠区残差。要求写出一个可计算的判据，区分“局部噪声”与“系统性漂移”，并说明该判据在什么条件下会误报。提示：比较回环点与起点的残差分布，若残差均值随路径长度单调上升且方差稳定，倾向系统性漂移；若方差随重叠面积缩小而增大，倾向局部噪声。误报条件是重叠区本身太窄，统计量不足。

练习二：补洞先验错配的检测。构造一个场景，其真实几何超出扩散模型训练分布（例如倾斜天花板的阁楼）。要求设计一个接缝检测流程：在补洞区域与真实观测的交界处提取法向与纹理梯度，给出一个阈值判定“接缝异常”，并说明该流程为何无法检测语义层面的错配。提示：几何接缝检测只看连续性，语义错配表现为“几何连续但物体类别错误”，需要额外的语义一致性检查。

练习三：显存与分辨率的取舍。给定目标房间尺寸与显存上限，要求写出一个分块融合的伪代码思路：按空间划分体素块，每轮只激活当前相机可见的块，扩散补洞在块边界处做重叠带以消除接缝。说明重叠带宽度与显存节省之间的权衡，以及块边界处融合权重如何避免双层薄壳。提示：重叠带太窄会在边界产生空洞，太宽则显存节省打折；权重在边界处应连续衰减而非硬切。

三道练习的共同指向是：迭代式补全的可靠性不取决于扩散模型多强，而取决于融合策略是否能在重叠区识别并抑制系统性误差。把回环残差、接缝连续性、块边界权重这三个量做成可观测的工程指标，比调采样步数更能决定最终网格能否漫游。
