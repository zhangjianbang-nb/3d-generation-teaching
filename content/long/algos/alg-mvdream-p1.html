一 · 问题的数学表述：为什么逐视角独立生成必然失配

把单视图扩散模型逐视角调用四次，等价于在四个条件独立的分布上各采样一次。设文本条件为 $y$，第 $i$ 个相机位姿为 $c_i$，则逐视角方案建模的是 $p(x_i \mid y, c_i)$ 的乘积，而真正想要的是联合分布 $p(x_1,x_2,x_3,x_4 \mid y, c_1,c_2,c_3,c_4)$。两者之间的差距不是采样噪声，而是结构性的：联合分布里含有视角间的互信息 $I(x_i;x_j \mid y)$，乘积分布把它全部丢弃。只要同一物体在不同视角下必须共享同一个三维实体，这个互信息就不为零，逐视角采样就必然在纹理走向、部件位置、轮廓剪影上产生互不相容的细节。

更具体地说，失配发生在三个层次。其一是低频几何：同一块面在不同视角下的可见面积与朝向必须满足多视图几何约束，独立采样无法保证极线一致性。其二是中频结构：把手、轮子、纽扣这类部件在四个视角里必须出现在同一空间位置，独立采样会让它们各自漂移。其三是高频纹理：同一片材质在不同视角下的明暗与纹理相位需要连续，独立采样会给出互相矛盾的图案。扩散模型的去噪过程对每一个像素都做局部决策，没有任何一项损失强制它满足跨图像的几何约束，因此误差在四个视角上独立累积。

从工程角度看，这个问题的代价可以直接度量：把四张独立生成的图送入神经辐射场或高斯泼溅重建，优化器会试图同时满足四组互相冲突的监督信号，结果是几何被平均化、纹理被模糊化，或者优化在视角交界处产生明显的接缝。重建质量的下降并非来自重建算法本身，而是来自输入图像之间缺乏一致性这一上游缺陷。多视图自注意力扩散的全部动机，就是把一致性从后处理阶段提前到生成阶段，让模型在去噪的每一步都看到其他视角。

二 · 核心机制：把四个视角拼成一个序列

该算法的核心操作极其朴素：不改变扩散模型的主干，而是改变输入的组织方式。四个视角的图像各自经过 patch 化，得到四组 token，然后把它们按视角顺序拼接成一个长序列送入同一个 Transformer。序列长度是单视图的四倍，注意力矩阵的规模相应扩大。关键在于注意力掩码的设计：这里不做视角内的块对角掩码，而是允许全序列两两可见，于是第 $i$ 个视角的每个 patch 都能直接查询第 $j$ 个视角的任意 patch。

为了让模型知道每个 token 属于哪个视角、从哪个方向看过去，每个 patch 的嵌入上叠加了一个位姿嵌入。位姿嵌入由相机参数编码而来，与 patch 内容嵌入逐元素相加，使得同一块表面在不同视角下的 token 在特征空间里既保留内容差异，又携带明确的观测方向信息。这样，注意力机制可以在“我知道你是从另一个方向看同一块区域”的前提下做信息交换，而不是盲目地混合四组无关特征。

训练信号来自三维多视图数据：同一物体的四个视角图像作为一组监督目标，模型在一次前向中同时预测四张图上的噪声，损失是四张图上的去噪损失之和。这个损失结构本身就在强迫模型学习跨视角相容的解：如果模型对视角 1 预测的纹理与视角 2 预测的纹理互相矛盾，两组损失无法同时降低，梯度会把参数推向能同时解释四张图的解。换句话说，一致性不是通过额外的正则项显式加入的，而是通过“一次生成四张、四张都要对”这一损失结构隐式涌现的。

推理时的流程是：输入文本与四个相机位姿，四个视角的 patch 序列拼接后进入去噪循环，每一步注意力都在全序列上计算，最终一次输出四张图像。由于四张图共享同一组去噪轨迹，它们在高噪声阶段就通过注意力互相约束了布局，而不是等到低噪声阶段才各自补细节。这一点与“先各自生成再对齐”的后处理路线有本质区别：后处理只能修正已经定型的内容，而联合去噪可以在内容尚未确定时就协商出一致的结构。

三 · 公式逐步解释：偏置项如何编码视角关系

注意力公式写作

$$\mathrm{Attn}(Q,K,V)=\mathrm{softmax}\!\left(\frac{QK^{\top}}{\sqrt{d}}+b_{\mathrm{view}}\right)V$$

逐项拆解。 $QK^{\top}$ 是标准的查询—键相似度矩阵，形状为序列长度乘序列长度；由于序列由四个视角拼接而成，这个矩阵天然分成十六个块，对角线上的四个块是视角内注意力，非对角线上的十二个块是跨视角注意力。除以 $\sqrt{d}$ 是常规的缩放，防止维度增大后点积数值过大导致 softmax 饱和。

真正承载多视图语义的是 $b_{\mathrm{view}}$ 这一项。它是一个加在相似度上的偏置矩阵，其取值由 token 所属的视角对决定。对同一视角内的 token 对，偏置取一个基准值；对不同视角的 token 对，偏置取另一个值，且可以按视角对的相对位姿关系进一步区分。这个设计的数学含义是：在 softmax 之前改变不同视角对之间的相对权重，从而控制跨视角信息流动的强度。若偏置对跨视角对取较大的负值，模型倾向于退回逐视角独立生成；若取零或正值，跨视角注意力被鼓励。可学习的偏置让模型自己决定在去噪的不同阶段、不同空间位置上应该多大程度地参考其他视角。

从梯度角度看，$b_{\mathrm{view}}$ 的梯度直接来自四视图损失之和。当某两个视角之间的信息交换有助于降低整体损失时，对应偏置会被推高；当交换引入矛盾时，偏置会被压低。因此这个偏置矩阵实际上是一个可学习的“视角通信调度器”，它把“哪些视角应该互相看、看多少”这件事从手工设计变成了数据驱动的参数。

还有一个容易被忽略的细节：softmax 是在整行上归一化的，这意味着一个视角内 token 的注意力预算会被跨视角 token 分流。序列变长四倍后，单个 token 的注意力分布被摊薄，视角内注意力的有效权重下降。这正是偏置项存在的另一个理由——它需要在“让模型看到别的视角”和“不让模型丢失本视角细节”之间维持平衡。若偏置设置不当，模型会出现两种典型失败：跨视角权重过高导致四个视角输出趋于同质化、丢失各自的视角特征；跨视角权重过低则退化为独立生成，一致性收益消失。

四 · 与相邻算法的数学差别：联合分布、条件注入与序列拼接

与逐视角独立扩散的差别已经在第一节给出分布层面的刻画，这里进一步落到实现层面。独立扩散的每个去噪步骤只在一个视角的 token 序列上计算注意力，其注意力矩阵是块对角的；多视图自注意力扩散的注意力矩阵是全连接的，跨视角块的数值由 $b_{\mathrm{view}}$ 调制。前者的计算量随视角数线性增长，后者的注意力计算量随视角数平方增长——这是联合建模的直接系统代价。

与“先验注入”类方法（例如把一张参考视图的特征作为条件喂给其余视图的生成）的差别在于信息流向。条件注入是单向的：参考视图影响被生成视图，反之不成立，因此参考视图自身的错误无法被其他视角纠正。多视图自注意力是全双工的：四个视角在每一层、每一步都互相读写，任何一个视角的早期决策都会被其余三个视角审视并修正。数学上，条件注入建模的是 $p(x_2,x_3,x_4 \mid x_1,y)$，联合自注意力建模的是 $p(x_1,x_2,x_3,x_4 \mid y)$，后者不指定哪个视角是“真理来源”，因而对称性更好，也不会把参考视图的幻想错误固化成全局约束。

与视频扩散的差别值得单独说。视频扩散同样把多帧拼成序列做时空注意力，形式上与多视图序列拼接同构，但两者的几何含义不同。视频的帧间关系由时间连续性与运动先验约束，相邻帧的内容差异小，注意力可以依赖局部时间窗口；多视图的视角间关系由相机位姿约束，视角间的内容差异可能很大（例如正面与背面），不存在“相邻帧更相似”的平滑先验。因此多视图模型必须依赖位姿嵌入来建立几何对应，而不能照搬视频模型的时间位置编码。把视频扩散直接用于多视图生成，会在视角跨度大的位置上出现对应关系错乱，这是几何约束缺失导致的失败模式。

与三维原生生成（直接在体素、点云或辐射场上做扩散）的差别在于表示。三维原生扩散在三维表示上定义噪声过程，几何一致性由表示本身保证，但三维表示的分辨率与计算成本随体积增长迅速，且高质量三维训练数据稀缺。多视图自注意力扩散把三维一致性问题转化为二维序列上的注意力问题，用二维主干的成熟架构与预训练权重换取工程可行性，代价是一致性只能通过数据学习而非结构保证，因而在训练分布之外的视角组合上仍会失效。

五 · 系统代价与失败模式：四倍序列带来的连锁反应

序列长度变为四倍，注意力矩阵的元素数变为十六倍。以标准 Transformer 的复杂度计，注意力计算量随序列长度平方增长，显存占用同样随注意力矩阵平方增长。这是该算法最直接的系统代价：在相同分辨率与相同主干深度下，训练与推理的显存需求显著高于单视图模型，批量大小被迫压缩，梯度累积步数增加，训练吞吐下降。工程上常见的缓解手段是切分注意力计算、使用内存高效的注意力实现、或在低分辨率阶段先做联合去噪再在高分辨率阶段分视角细化，但这些手段都会改变跨视角信息交换的粒度，需要重新验证一致性收益。

视角数固定为四是另一个结构性约束。序列拼接的组织方式与位姿嵌入的维度都是按四视角设计的，增加到更多视角意味着序列更长、注意力代价更高，且训练数据需要覆盖更多视角组合。更少视角则浪费了联合建模的容量。这个固定值不是数学上的必然，而是训练数据组织与计算预算折中的结果；它使得算法在面对任意视角数的下游需求时缺乏弹性，通常需要插值或分组调用。

背面细节的幻想是质量层面的失败模式。四个视角覆盖了物体的部分表面，未被任何视角观测到的区域（例如正对背面相机的遮挡区、顶部或底部的盲区）没有任何监督信号，模型只能依据先验填充。联合注意力能保证已观测区域之间的一致性，却无法保证未观测区域与已观测区域的几何相容，因为注意力只能在已有 token 之间交换信息，不能凭空创造被遮挡表面的证据。当四个视角的覆盖存在较大空隙时，重建阶段会把这些幻想细节当作真实观测使用，产生几何上的“补丁”结构。

训练依赖多视图三维数据是数据层面的失败模式。联合去噪损失要求同一物体的四个视角图像严格配准、位姿精确、光照一致，这类数据的采集成本高、规模有限。数据分布之外的物体类别、材质、尺度会让模型退回先验幻想，一致性收益随之衰减。此外，位姿嵌入的精度直接决定跨视角注意力的对应质量：位姿标注若有偏差，注意力会在错误的 patch 对之间建立联系，模型学到的是错误的几何对应，这种错误在训练损失上不易暴露，却会在推理时表现为系统性的视角间错位。

一个具体的失败链条可以这样描述：输入文本描述一个带把手的杯子，四个相机位姿覆盖正面、左侧、右侧与背面。联合去噪在早期步骤通过跨视角注意力协商出杯身与把手的大致布局，四张图在这一阶段是相容的。进入低噪声阶段后，背面视角的把手内侧区域没有任何其他视角能提供证据，模型依据“把手通常是环状”的先验填充内侧纹理，而正面视角在同一空间位置看到的是杯身外壁。两个视角的预测在三维空间中占据不同深度，重建时优化器无法同时满足，最终在把手与杯身的连接处产生几何撕裂。这个链条说明：一致性机制的作用范围严格受限于观测覆盖，注意力交换不能替代真实观测。

六 · 工程判断：一致性收益与计算预算的兑换率

把该算法放进三维生成流水线时，需要判断的核心问题是：多视图一致性的收益是否值得四倍序列带来的计算开销。判断依据不是定性的“效果更好”，而是下游重建对输入一致性的敏感度。若下游是神经辐射场或高斯泼溅这类需要多视图光度一致的重建器，输入图像的微小失配会被优化器放大成几何误差，此时联合生成的一致性收益直接转化为重建质量的提升，计算开销是值得的。若下游只需要单张参考图做图生 3D（例如接 Zero-1-to-3 这类以单图为条件的新视角合成模型），多视图联合生成的价值主要体现在提供一组互相一致的训练或验证视图，而非直接作为重建输入，此时开销的合理性取决于流水线是否真的需要四视图。

另一个判断维度是视角覆盖与物体对称性。对于近似对称的物体，四个视角的观测冗余度高，跨视角注意力有充足证据做一致性约束，失败模式主要落在背面盲区。对于强不对称物体（例如一侧有独特结构的机械件），四个视角可能恰好错过关键结构，联合注意力无法弥补观测缺失，此时应优先调整相机位姿采样策略而不是增加视角数。位姿采样的设计——四个相机如何环绕、仰角如何分布、是否覆盖顶部——对最终一致性的影响，往往大于注意力偏置的超参数调整。

在实现层面，偏置矩阵 $b_{\mathrm{view}}$ 的初始化与学习率需要与主干参数分开考虑。若偏置初始值让跨视角权重过低，模型在训练早期退化为独立生成，四视图损失之和无法提供有效的跨视角梯度，偏置永远学不到应有的值；若初始值过高，模型早期输出趋于同质化，视角特征被抹平，损失同样难以降低。合理的做法是让偏置从一个中性值出发，依靠损失梯度自行分化，并在训练监控中观察跨视角注意力权重的分布是否随训练步数上升——这个分布是判断联合建模是否真正生效的直接指标，比总体损失曲线更灵敏。

最后落到一个具体的机制判断上：该算法的本质是用序列拼接把“多视图一致性”这一三维约束编码进二维注意力的连接结构，用可学习的视角偏置调节信息流强度，用四视图联合损失提供梯度。它的能力边界由观测覆盖决定，它的成本边界由序列长度的平方决定。工程上真正需要设计的不是注意力公式本身，而是相机位姿采样、视角数选择与下游重建器的匹配关系——这三者决定了四倍计算预算换来的是一致的几何，还是一组互相矛盾的幻想。
