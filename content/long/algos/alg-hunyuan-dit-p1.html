一 · 问题定义：单阶段生成器的容量耦合

形状-材质双 DiT 要解决的不是“能不能生成一个带贴图的三维模型”，而是“为什么单阶段模型在几何分辨率与 PBR 材质质量上会互相拖累”。在单阶段扩散架构里，同一个去噪网络同时承担两件性质完全不同的工作：一件是在三维空间里确定表面在哪里、法线朝哪、拓扑是否闭合；另一件是在表面参数化之后确定每个纹素的反照率、粗糙度、金属度。这两件事的监督信号来自不同模态，梯度尺度不同，收敛速度不同，却共享同一组参数与同一个容量预算。工程上的直接后果是：把网络加宽以提升几何细节时，材质分支会分到大量与几何无关的容量；反过来，为了让材质更真实而增加材质监督权重，几何的高频细节会被平滑掉。这就是容量耦合，它不是训练技巧问题，而是单阶段参数化本身的结构性问题。

更具体地看，单阶段模型通常把几何表示为某种隐式场或体素占据，把材质表示为附着在表面上的属性。若几何用低分辨率体素网格表示，材质再精细也只能落在被量化的表面上，UV 展开的接缝与拉伸会直接吃掉材质的高频信息；若几何用高分辨率稀疏体素，去噪网络的空间注意力成本随有效体素数增长，材质分支又被绑在同一张计算图上，显存与算力被迫在两者之间做零和分配。设几何有效体素数为 $N_g$、材质纹素数为 $N_m$，单阶段注意力近似成本为 $O((N_g+N_m)^2)$，而双分支若各自独立则为 $O(N_g^2)+O(N_m^2)$。当 $N_g$ 与 $N_m$ 都很大时，后者的交叉项消失带来的节省是数量级上的，这不是常数优化，而是把两个规模问题解耦成两个可分别 scaling 的子问题。

失败模式在单阶段管线里表现为典型的两类退化。第一类是几何过平滑：材质监督的梯度通过共享参数回传到几何分支，等价于对几何隐式场施加了一种与视角相关的正则，导致尖锐边缘与薄壁结构被抹平。第二类是材质“烘焙错误”：几何在训练早期尚未收敛时，材质分支已经在错误的表面上学习纹理分布，最终 UV 展开后出现纹理在接缝处断裂、金属度在曲率大的区域被错误平均。一个具体例子是带细密铆钉的金属箱：单阶段模型往往把铆钉几何生成成模糊的凸起，同时把铆钉周围的粗糙度学成一片均匀值，因为网络没有足够的独立容量去同时表达“铆钉是几何凸起”和“铆钉边缘有高光变化”这两件事。

二 · 核心思想：两个 DiT 的职责切分与共享条件

双 DiT 的核心是把一次联合去噪拆成两次条件去噪，并让两次去噪共享同一个图像条件编码，但不共享参数。形状 DiT 的输出空间是几何表示，材质 DiT 的输出空间是 UV 空间的 PBR 贴图。共享图像条件的作用是保证两个分支对同一张参考图给出一致的语义解释：形状分支从图中读出物体的轮廓、部件构成与大致比例，材质分支从图中读出颜色、光泽与材质类别。独立训练的作用是让两个分支各自拥有完整的容量预算，几何的 scaling 不与材质的 scaling 争夺参数。

这里的关键设计是“条件共享、参数不共享、训练解耦”。条件共享通过一个冻结或半冻结的图像编码器实现，两个分支各自接一个条件注入模块（例如 cross-attention 或 AdaLN 调制），把同一组图像 token 映射到各自的特征空间。参数不共享意味着形状 DiT 的每一层与材质 DiT 的每一层是两套独立的权重，梯度不会跨分支回传。训练解耦意味着两个分支可以分别安排数据配比、分辨率课程与学习率调度：形状分支可以在高分辨率稀疏体素上做由粗到细的课程，材质分支可以在 UV 空间做纹素级监督，二者的 batch 组成不必对齐。

这种切分带来一个直接的系统代价：两阶段管线引入了分支间的接口，即网格与 UV 展开。形状分支输出 SDF 后经 Marching Cubes 得到网格，网格必须经过 UV 展开才能进入材质分支的 UV 空间扩散。这个接口不是可微的，UV 展开的失败会直接截断整条管线。一个具体失败模式是薄片结构或高亏格拓扑：Marching Cubes 产生的网格在薄壁处出现非流形边，UV 展开算法在这些边上产生重叠岛或极端拉伸，材质 DiT 在拉伸区域学到的纹素密度与实际表面面积不匹配，合成渲染时出现明显的纹理拉伸条纹。工程上这要求形状分支在训练时对薄壁与高曲率区域施加额外的几何正则，或者在上游就约束 SDF 的梯度模长接近 1，以减少 Marching Cubes 的退化面。

另一个代价是条件一致性风险。两个分支独立训练，图像条件编码器若在形状分支上被微调而在材质分支上冻结，同一张图在两个分支的特征分布会漂移，导致形状与材质对图像的解释不一致：形状生成了一个哑光陶瓷杯，材质却给出了金属反射。缓解手段是共享条件的编码器保持冻结，或者对两个分支使用同一版本的编码器并在训练后做一次联合校准，但校准本身又引入了额外的管线阶段。

三 · 公式逐步解释：损失分解与 PBR 监督

给定损失写作

$$\mathcal{L}=\mathcal{L}_{\mathrm{shape}}+\lambda\mathcal{L}_{\mathrm{PBR}},\qquad \mathcal{L}_{\mathrm{PBR}}=\|\hat{a}-a\|^2+\|\hat{r}-r\|^2+\|\hat{m}-m\|^2$$

第一项 $\mathcal{L}_{\mathrm{shape}}$ 是形状分支的去噪目标，作用在 SDF 或稀疏体素表示上。它约束的是几何场的数值：在表面附近 SDF 接近零，在内外两侧符号正确，梯度模长在表面附近接近单位。由于形状分支用 VecSet 或稀疏体素扩散，$\mathcal{L}_{\mathrm{shape}}$ 实际上是对有效体素集合上的预测值与真值做回归，空白区域不参与损失，这正是稀疏表示能 scaling 到高分辨率的原因。$\mathcal{L}_{\mathrm{shape}}$ 的梯度只回传到形状 DiT，不进入材质分支。

第二项 $\lambda\mathcal{L}_{\mathrm{PBR}}$ 是材质分支的监督，$\lambda$ 是权重系数，用于平衡两个分支的损失尺度。$\mathcal{L}_{\mathrm{PBR}}$ 由三个平方误差组成：$\hat{a}$ 与 $a$ 是预测与真值的反照率，$\hat{r}$ 与 $r$ 是粗糙度，$\hat{m}$ 与 $m$ 是金属度。这三项都在 UV 空间逐纹素计算，因此损失的空间分辨率由 UV 贴图分辨率决定，与几何分辨率解耦。注意这里没有显式写出法线贴图项，因为法线可以从几何求导得到，材质分支只需负责与光照响应直接相关的三个通道。三个通道的误差等权相加是一个工程简化：反照率的动态范围最大，粗糙度与金属度是低动态范围标量，等权意味着反照率的绝对误差在总损失中占主导，实际训练中若发现粗糙度欠拟合，需要单独调权而不是改 $\lambda$。

$\lambda$ 的选择本身是一个系统代价点。$\lambda$ 过大时，材质分支的梯度在联合校准阶段会压制形状分支的微调，几何细节退化；$\lambda$ 过小时，材质分支欠拟合，合成渲染的光泽与颜色偏差明显。由于两个分支独立训练，$\lambda$ 主要出现在联合校准或端到端微调阶段，而不是主训练阶段。一个具体例子是：在只做分支独立训练时，$\lambda$ 不参与优化，两个分支各自收敛；当需要把两个分支的输出对齐到同一渲染目标时，才引入渲染损失与 $\lambda\mathcal{L}_{\mathrm{PBR}}$ 的联合项，此时 $\lambda$ 实际上是在“材质监督”与“渲染一致性”之间做权衡。

公式还隐含了一个可微性边界：$\mathcal{L}_{\mathrm{PBR}}$ 作用在 UV 空间，而 UV 空间与三维表面的映射由 UV 展开给定，这个映射在训练材质分支时被视为固定。若 UV 展开改变，材质分支的监督目标整体重排，已训练的纹素级先验失效。这就是为什么管线把 UV 展开放在形状分支之后、材质分支之前，并且要求形状分支先收敛再展开，以避免展开结果随几何训练抖动而反复变化。

四 · 与相邻算法的数学差别：联合扩散 vs 分支扩散

与单阶段联合扩散相比，双 DiT 的数学差别在于去噪过程的因子分解。单阶段模型建模的是联合分布 $p(x_g, x_m \mid c)$，其中 $x_g$ 是几何表示、$x_m$ 是材质表示、$c$ 是图像条件，去噪网络同时预测两者的噪声。双 DiT 建模的是两个条件分布的乘积 $p(x_g \mid c)\,p(x_m \mid c, x_g)$，但工程实现上材质分支并不显式以 $x_g$ 为条件输入，而是以 UV 展开后的网格为几何载体，把 $x_g$ 的影响压缩进 UV 参数化与渲染阶段。这意味着双 DiT 牺牲了联合分布中的跨模态相关性：单阶段模型可以在去噪过程中让材质梯度影响几何，双 DiT 则把这种耦合推迟到合成渲染。代价是跨模态一致性变弱，收益是两个子问题可以独立 scaling。

与“先生成几何、再用图像到材质的方法补贴图”的串行管线相比，双 DiT 的差别在于材质分支仍是扩散模型而非确定性回归。串行管线中材质预测是一次前向，无法表达多峰分布；双 DiT 的材质分支保留随机性，可以在同一几何上采样出不同的材质解释，这对数据中存在多种合理材质的情况是必要的。数学上，串行管线建模的是 $p(x_m \mid x_g, c)$ 的点估计，双 DiT 建模的是该分布的样本，采样成本更高但覆盖更广。

与同样采用双分支的几何-纹理分离方法相比，双 DiT 的差别在于两个分支共享图像条件但独立训练，而不是在同一个去噪时间步上交替更新。交替更新仍然要求两个分支的时间步对齐，且梯度可能跨分支泄漏；独立训练则允许两个分支使用不同的噪声调度与不同的分辨率课程。一个具体例子是：形状分支可以在高分辨率稀疏体素上用较长的噪声调度以覆盖大尺度拓扑，材质分支可以在 UV 空间用较短的调度以聚焦纹素级高频，二者时间步不对齐在独立训练下是允许的，在交替更新下则会造成去噪轨迹不一致。

数学上还有一个差别体现在损失的梯度路径。单阶段模型的梯度路径是 $\partial\mathcal{L}/\partial\theta$ 同时经过几何与材质两条子路径，参数共享导致两条路径的梯度相加，可能出现方向冲突。双 DiT 中 $\mathcal{L}_{\mathrm{shape}}$ 只经过形状参数，$\mathcal{L}_{\mathrm{PBR}}$ 只经过材质参数，梯度路径不相交，冲突被消除，但跨模态一致性也不再由梯度保证，而由共享条件与合成渲染阶段保证。这是一个明确的工程取舍：用一致性保证的弱化换取容量分配的独立性。

五 · 机制推导中的失败模式与工程判断

把上述机制推到极端，会看到三个结构性失败模式。第一是条件漂移：共享图像条件在两个分支上被不同地解释，形状与材质语义不一致。第二是 UV 接口断裂：Marching Cubes 与 UV 展开的不可微接口在薄壁、高亏格、非流形处失效，材质监督落在错误的纹素上。第三是材质数据瓶颈：$\mathcal{L}_{\mathrm{PBR}}$ 的三通道监督依赖带 PBR 标注的数据，这类数据的真实感与覆盖度有限，材质分支容易在训练集未覆盖的材质类别上退化为平均色。三者都不是靠调 $\lambda$ 能解决的，前者需要条件编码器的一致性约束，中者需要几何正则与展开鲁棒性，后者需要数据侧的扩充或渲染损失作为弱监督补充。

工程判断上，双 DiT 的合理性来自一个可检验的 scaling 假设：几何质量随形状分支的容量与分辨率单调提升，材质质量随材质分支的容量与 UV 分辨率单调提升，且两者互不干扰。这个假设在分支独立训练时容易验证，在联合校准时会被 $\lambda$ 与渲染损失扰动。因此管线设计上应把联合校准限制在少量步数，避免破坏已收敛的分支先验。一个具体机制是：联合校准阶段冻结形状分支的大部分层，只放开与表面法线相关的浅层，让渲染损失主要修正材质与几何的接触区域，而不是重写几何。

另一个工程判断是关于 Marching Cubes 的分辨率选择。形状分支输出 SDF 后，Marching Cubes 的网格分辨率决定了后续 UV 展开的拓扑复杂度与材质分支的纹素密度上限。分辨率过高会让 UV 展开在薄壁处产生大量小岛，材质 DiT 的 UV 空间扩散在这些小岛上缺乏足够的纹素上下文；分辨率过低则丢失几何高频，材质再精细也无处附着。这个权衡不是定性的，而是由 $N_g$ 与 $N_m$ 的相对规模决定：当材质 UV 分辨率远高于几何网格分辨率时，几何成为瓶颈，应优先提升 Marching Cubes 分辨率而不是材质分支容量。

最后落在具体机制上：双 DiT 的整个推导可以压缩为一条接口链——图像条件编码 → 形状 DiT 去噪 SDF → Marching Cubes 出网格 → UV 展开 → 材质 DiT 在 UV 空间去噪 PBR → 合成渲染。链上每一环的不可微性或分布漂移都是失败模式的来源，而双 DiT 的收益正是把这条链上原本耦合在同一张计算图里的两个规模问题拆开，让几何分辨率与材质分辨率各自成为可独立调节的工程旋钮。判断一个实现是否真正吃到了这个收益，只需看两个分支的容量与分辨率是否能独立变化而不引起另一分支的质量退化。
