一 · 从单点假设到分布假设：SDS 的病根在哪

Score Distillation Sampling（SDS）把一次 3D 优化看成对一个固定文本提示的“单点蒸馏”：给定参数 θ，渲染出图像 x=g(θ)，加噪得到 x_t，用冻结的文本条件扩散模型 ε_φ 预测噪声，再把（ε_φ−ε）乘上 ∂x/∂θ 作为梯度。它隐含的假设是：存在一个最优 3D 表示 θ*，使得渲染分布恰好落在文本条件分布的一个高概率点上。这个假设在数学上等价于把目标分布 p(x|y) 当作 delta 分布来处理，于是优化过程只会把样本往某个“最像”的模式上推。

单点假设带来两个可观测的病理。其一是模式坍缩：当文本条件分布本身是多峰的时候（例如“一只戴帽子的猫”既可以对应多种帽子、姿态、材质），SDS 的梯度方向由冻结模型在 x_t 上的噪声预测主导，而该预测是对整个条件分布的期望意义上的去噪方向，多个模式的平均会把样本拉向峰之间的低概率谷地，最终收敛到少数几个过饱和、对比度被拉爆的“典型解”。其二是过饱和：SDS 的梯度幅度与 ε_φ−ε 的差成正比，而冻结模型在低噪声时刻给出的修正往往偏大，导致渲染图像的高频细节被反复放大，颜色通道被推向边界。

把问题形式化：设 3D 参数服从分布 q(θ)，渲染诱导出图像分布 q(x)=∫q(θ)δ(x−g(θ))dθ。SDS 实际优化的是 E_{q(θ)}[L_single]，其中 L_single 只依赖单个样本与冻结模型的距离，缺少对 q(x) 整体形状的约束。要修复它，必须让蒸馏目标从“单样本对齐”变成“分布对齐”，即最小化 q(x) 与 p(x|y) 之间的 KL 散度。Variational Score Distillation（VSD）的核心动作就是把 θ 从确定性变量升格为随机变量，并引入一个可学习的近似分布去估计 q(x) 的得分。

二 · 用粒子近似分布：LoRA 作为得分估计器

VSD 的第一个机制是“粒子化”。它不再维护单个 θ，而是维护一组 3D 粒子 {θ_i}，或者等价地维护一个低秩适配器（LoRA）ψ，使得不同粒子共享同一个基础 3D 表示、只在低维子空间内变化。粒子集合诱导出的经验分布 q̂(x)=1/N Σ_i δ(x−g(θ_i)) 就是对 q(x) 的蒙特卡洛近似。粒子数量 N 是显存与多样性的直接 trade-off：N 越大，经验分布越接近真实 q，但每一步都要渲染 N 张图并做 N 次前向，代价线性增长。

第二个机制是用 LoRA 学一个“得分修正项” ε_ψ。冻结扩散模型 ε_φ(x_t;y,t) 给出的是文本条件分布 p(x|y) 的得分（经 Tweedie 公式与噪声尺度换算），而 ε_ψ(x_t;c,t) 则以渲染图为训练数据、以粒子分布为条件 c，去拟合当前 3D 分布 q(x) 的得分。关键在于：ε_ψ 不是从头训练的扩散模型，而是一个挂在冻结模型上的低秩分支，它只学习“当前粒子分布相对于文本分布的偏移”。这样，两个噪声预测之差就近似了 q(x) 与 p(x|y) 的得分差。

为什么得分差能驱动分布匹配？扩散模型的得分与噪声预测的关系是 ∇_{x_t} log p_t(x_t) = −ε(x_t;t)/σ_t（σ_t 为噪声尺度）。因此两个模型在同一 x_t 上的噪声预测之差，正比于两个分布对数密度的梯度之差。沿这个方向更新 θ，等价于沿 KL(q‖p) 对样本的泛函导数下降。这就是 VSD 把“蒸馏”变成“变分推断”的数学支点：不是让样本更像某个点，而是让整个粒子云的对数密度梯度与目标分布的梯度对齐。

系统代价在这里第一次显现。LoRA 分支虽然参数量小，但它需要在每个训练步对渲染图做一次带噪去噪训练（前向 + 反向），并且要与 3D 优化共享同一批渲染结果。显存上，冻结模型与 LoRA 分支同时驻留，加上 N 个粒子的渲染缓冲，峰值显存比 SDS 高出可观的一截；时间上，每步多出一次 LoRA 反向传播，训练步速下降。失败模式是：若 LoRA 容量过低（秩太小），ε_ψ 无法覆盖粒子分布的多个模式，得分差退化为常数偏移，粒子云重新坍缩；若秩过高，ε_ψ 会过拟合到单张渲染图，把噪声当成分布信号，梯度方差爆炸。

三 · 公式逐项拆解：每一项在做什么

VSD 的梯度写作：

$$\nabla_\theta\mathcal{L}_{\mathrm{VSD}}=\mathbb{E}\!\left[w(t)\big(\epsilon_\phi(x_t;y,t)-\epsilon_\psi(x_t;c,t)\big)\frac{\partial x}{\partial\theta}\right]$$

逐项看。x_t 是渲染图 x=g(θ) 经前向加噪得到的样本，t 从训练噪声调度中采样，w(t) 是时间权重，通常取与扩散训练损失一致的加权（低噪声时刻权重高，因为细节修正更重要）。ε_φ(x_t;y,t) 是冻结文本条件模型在提示 y 下的噪声预测，代表“文本想要的方向”。ε_ψ(x_t;c,t) 是粒子模型在条件 c（当前粒子分布）下的噪声预测，代表“当前 3D 分布已经是什么样”。两者相减，得到的是“从当前分布指向文本分布”的修正方向。

∂x/∂θ 是渲染过程对 3D 参数的雅可比，把图像空间的修正映射回参数空间。它与 SDS 中的对应项形式相同，但因为前面的差项现在是分布级的，整个梯度的语义从“把这张图推向文本”变成“把粒子云的对数密度推向文本分布”。期望 E 同时对 t、噪声 ε、以及粒子采样（若每次只取一个粒子）求平均；实际实现中常对每个粒子独立采样 t 与 ε，再对 N 个粒子的梯度取平均，以降低方差。

一个具体的数值直觉：设某步 t 下，冻结模型预测 ε_φ=+0.8（沿某通道），粒子模型预测 ε_ψ=+0.3，差为 0.5，乘 w(t)=0.6 得 0.3，再乘雅可比中该通道对应的偏导（例如 0.02），该参数分量的更新量为 0.006。若粒子模型预测变成 −0.2，差变为 1.0，更新量翻倍——这说明当粒子分布偏离文本分布越远，修正越强；当两者接近，差趋近于零，优化自然收敛。这正是 KL 下降的微观表现，而不是 SDS 中那种“越优化越饱和”的正反馈。

失败模式藏在 w(t) 与 t 的采样分布里。若 t 过度偏向高噪声，差项主要由粗粒度结构决定，细节模式得不到区分，粒子云会在语义层面正确但纹理层面坍缩；若过度偏向低噪声，ε_ψ 在单张图上的拟合误差被放大，梯度噪声主导，3D 表示出现高频抖动。工程上需要按扩散模型原本的训练噪声分布采样 t，并让 w(t) 与 ε_φ 的训练目标一致，否则公式中的“得分差”不再是同一尺度的量，KL 的解释失效。

四 · 与 SDS、与相邻算法的数学差别

与 SDS 的差别可以压缩成一句话：SDS 的差项是 ε_φ−ε（ε 是注入的随机噪声，与参数无关），VSD 的差项是 ε_φ−ε_ψ（ε_ψ 依赖当前分布）。SDS 中，期望意义下 E[ε_φ−ε]=0 当且仅当 x_t 的边缘分布等于扩散模型在时刻 t 的边缘分布，但单样本梯度并不保证这一点，因为 ε 是外生噪声，梯度方向不包含分布形状的信息。VSD 把外生噪声换成内生估计 ε_ψ，使得差项成为两个分布得分之差的估计量，梯度因而携带了 q(x) 的形状信息。数学上，SDS 优化的是单样本重构误差的上界，VSD 优化的是 KL(q‖p) 的随机估计。

与 DreamFusion 类方法的另一处差别在于“谁被训练”。DreamFusion/SDS 只训练 θ，扩散模型完全冻结；VSD 同时训练 θ 与 ψ，形成类似 GAN 的双时间尺度博弈：ψ 想准确描述当前 q(x)，θ 想移动 q(x) 去匹配 p(x|y)。这不是对抗性的零和博弈，因为 ψ 的目标是最小化自己对 q 的拟合误差，而不是区分真假；但当 ψ 更新过快时，它会“追上”θ 的新分布，使差项迅速缩小，θ 的梯度信号减弱，出现优化停滞。工程上通常让 ψ 的学习率低于 θ，或对 ψ 做指数滑动平均，以维持差项的非零动态范围。

与纯变分推断（如用扩散先验做后验采样）的差别在于条件 c。VSD 的粒子模型以渲染图为训练数据，条件 c 实际上是“当前粒子集合的身份”，它让 ε_ψ 学会的是 q(x) 的条件得分而非无条件得分。若把 c 去掉，ε_ψ 退化为一个无条件扩散模型，差项变成“文本条件得分减无条件得分”，那是 classifier-free guidance 的形式，不再随 3D 分布更新，多样性收益消失。这个细节是 VSD 与“拿 CFG 当蒸馏目标”的数学分水岭。

五 · 训练循环中的机制耦合与系统代价

把流程写成伪代码思路：初始化 N 个 3D 粒子与 LoRA ψ；循环内，对每个粒子渲染 x_i=g(θ_i)，采样 t_i 与 ε_i，构造 x_{t,i}；冻结模型给出 ε_φ(x_{t,i};y,t_i)，粒子模型给出 ε_ψ(x_{t,i};c,t_i)；对每个粒子计算差项乘雅可比，平均后更新 θ；随后用同一批渲染图（可重新加噪）对 ψ 做去噪训练，最小化 ‖ε_ψ(x_t;c,t)−ε‖²；按调度更新学习率与粒子重采样。注意 θ 更新与 ψ 更新共享渲染，但 ψ 的梯度不回传到 θ，形成两个独立的反向图。

耦合带来的系统代价有三处。第一是显存：N 个粒子的渲染缓冲、冻结模型激活、LoRA 分支激活同时存在，若 N 取较大值且分辨率不低，峰值显存会显著超过 SDS 的单粒子配置；工程上常用梯度检查点与分粒子串行前向来换显存。第二是时间：每步两次反向（θ 与 ψ），加上 N 次渲染，步速下降明显；若 ψ 更新频率低于 θ（例如每 k 步更新一次），可以摊薄开销，但会让差项在 k 步内“过时”，引入偏差。第三是超参：N、LoRA 秩、ψ 学习率、w(t) 形式、t 采样分布、粒子重采样阈值，每一个都影响收敛与多样性，复现门槛高。

一个具体例子说明耦合失败：若粒子重采样过于激进（每隔几步就把低密度粒子替换为高密度粒子附近的新样本），粒子云会被人为压缩，q̂(x) 退化为少数模式，ε_ψ 学到的分布变窄，差项在窄分布上接近零，θ 停止移动，最终输出虽然干净但多样性丢失——这正是 VSD 想修复的 SDS 病症以另一种形式复发。反过来，若完全不重采样，低密度粒子长期停留在低概率区域，ε_ψ 被这些离群样本拉偏，差项方向失真，渲染出现局部伪影。重采样阈值因此是机制层面的关键旋钮，而不是可有可无的工程细节。

另一个代价来自 ψ 的条件 c 的设计。若 c 只是粒子索引的嵌入，ψ 需要从索引推断分布身份，容量不足时会把不同粒子的渲染混为一谈；若 c 是粒子参数的摘要向量，则 ψ 的输入维度随 3D 表示变化，迁移到新表示时需要重新设计。这两种设计都增加了实现复杂度，也是 VSD 复现门槛高于 SDS 的直接原因。

六 · 公式背后的工程判断

回到公式本身：∇_θ L_VSD 的期望里同时含有对 t 的采样与对粒子的采样。方差控制的关键在于让差项在粒子间可比：若不同粒子用不同的 t，差项的尺度不一致，平均后的梯度会被高噪声时刻的粒子主导。稳妥做法是对同一批粒子共享 t 的采样（或分层采样），使差项在同一噪声尺度上比较，这与扩散训练中 batch 内共享 t 的做法同源。另一个判断是 w(t) 的选择必须与 ε_φ 的训练损失权重一致，否则“得分差”的尺度被扭曲，KL 的解释只剩定性意义。

从机制上看，VSD 把蒸馏从“单点回归”改造成“分布得分匹配”，其正确性依赖两个近似同时成立：粒子云足够密以代表 q(x)，LoRA 足够准以估计 q(x) 的得分。任一近似失效，差项就不再是 KL 梯度的无偏估计，优化会退化为带偏的 SDS 或带噪的模式搜索。工程上因此需要监控两个量：粒子间的渲染差异（多样性代理）与 ψ 的去噪损失（拟合质量代理）。前者长期趋零说明粒子云坍缩，后者长期不降说明 ψ 容量或学习率失配。这两个监控量比最终渲染的视觉评分更早暴露机制故障，是判断 VSD 是否在“按公式工作”的直接依据。
