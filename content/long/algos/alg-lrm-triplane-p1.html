一 · 从 SDS 的优化瓶颈到前馈摊销

LRM Triplane Transformer 要解决的问题不是“如何把三维重建做得更精细”，而是“为什么每次拿到一张图都要重新跑一遍优化”。在它之前，以 SDS（Score Distillation Sampling）为代表的路线把二维扩散模型的先验蒸馏进一个可微的三维表示：每个资产都要初始化一套参数（NeRF、网格或三平面），反复前向渲染、反向传播扩散损失，迭代到收敛。这条路线的问题在于成本结构——优化发生在推理时，且是逐资产的。换一张输入图，整套迭代重来一遍，耗时以几十分钟计，且结果质量对初始化、学习率、迭代步数敏感。工程上这意味着它无法作为批量服务部署：请求是串行昂贵的，延迟不可预测，GPU 占用被单个资产长期锁定。

LRM 的核心判断是把这个“逐资产优化”换成“一次性摊销”。它不再在推理时求解一个逆问题，而是训练一个前馈网络，把“单图到三维”的映射本身学成一个函数。训练阶段一次性付出代价：用大量多视图渲染数据，让网络学会从一张图直接回归出三维表示；推理阶段只做一次前向。这个转换的数学本质是把隐式的、迭代式的优化算子替换为显式的、参数化的回归算子。设单图为 $I$、相机为 $\mathbf{c}$、目标三维表示为 $\mathbf{T}$，SDS 求解的是 $\mathbf{T}^\*=\arg\min_{\mathbf{T}}\mathcal{L}_{\text{SDS}}(\mathbf{T},I)$，每个 $I$ 都要解一次；LRM 学的是 $\mathbf{T}=f_\theta(I,\mathbf{c})$，参数 $\theta$ 在训练集上一次性拟合，推理时只做函数求值。代价从“每资产迭代”变成“每资产一次前向”，但代价被转移到了训练：需要覆盖足够多样本的监督信号，否则 $f_\theta$ 只能给出训练分布内的合理猜测。

这个转换有一个必须交代的中间表示选择。前馈网络不能直接输出网格或体素，因为输出维度固定、分辨率一高就爆炸，且难以端到端可微渲染。LRM 选择三平面（triplane）作为输出空间：把三维空间分解为三个正交平面上的二维特征场，查询任意三维点时从三个平面双线性采样并组合。三平面把三维特征场的存储从 $O(N^3)$ 降到 $O(3N^2)$，同时保留了对任意视角可微渲染的能力。这个选择不是装饰性的：它决定了网络输出头的形状、渲染器的实现方式，也决定了后面网格提取的分辨率上限。

一个具体的失败模式可以说明为什么不能省掉相机调制。若输入图不带相机参数，网络只能学到“某个典型视角下的物体长什么样”，当输入视角偏离训练分布（俯视、仰视、近距离特写）时，输出的三平面会把物体摆到错误的世界坐标朝向，渲染出的新视角出现整体旋转错位。LRM 因此在编码阶段注入相机参数 $\mathbf{c}$，让网络知道“这张图是从哪个方向看的”，从而把图像证据放到正确的三维位置上。这是它与纯图像到图像回归任务的数学差别之一：输入不只是像素，还有像素的观测几何。

二 · 编码与解码：ViT token 到三平面的映射

前向流程的第一段是图像编码。输入图 $I$ 过 DINO ViT，切成 patch token 序列。ViT 的输出不是单个全局向量，而是一组保留了空间位置的 token，这很关键：三平面需要的是空间分布的证据，而不是一个被池化掉的语义摘要。DINO 预训练带来的好处是特征对光照、材质变化有一定不变性，且在小数据上比从头训练更稳；但代价是编码器本身是一个外部依赖，其感受野和 patch 粒度决定了网络能分辨的最小图像结构，细小的几何凹槽在 patch 级别可能已经被平均掉。

第二段是相机调制。相机参数 $\mathbf{c}$（外参朝向、内参视场）被编码后注入 token 序列，常见做法是把相机嵌入加到 token 上或作为额外的条件 token 参与注意力。这一步的机制意义是建立“图像像素—世界坐标”的对应：网络必须知道图像平面的哪个方向对应世界坐标的哪个轴，才能把看到的一侧正确铺到三平面上。若把这一步去掉，网络只能依赖数据中的视角先验做隐式推断，遇到分布外视角就会系统性出错。

第三段是 Transformer 解码器输出三平面。解码器以 token 为条件，通过 cross-attention 把图像证据读入一组可学习的平面查询（plane queries），每个查询对应三平面中某个位置的特征向量。写成公式即：

$$(\mathbf{T}_{xy},\mathbf{T}_{xz},\mathbf{T}_{yz})=\mathrm{Transformer}_\theta(I,\mathbf{c})$$

这里 $\mathbf{T}_{xy},\mathbf{T}_{xz},\mathbf{T}_{yz}$ 分别是三个正交平面上的特征图，每个都是二维网格。cross-attention 的机制是：平面查询作为 query，图像 token 作为 key/value，注意力权重决定“这个平面位置应该从图像的哪些 patch 取证据”。这比直接把图像特征 warp 到平面上更灵活——网络可以学到跨视角的补全，例如从可见的一侧推断被遮挡的另一侧的大致形状，因为注意力可以跨越图像上的局部区域去聚合上下文。

系统代价在这里出现：三平面的空间分辨率是超参数，分辨率越高，平面查询越多，cross-attention 的计算量按查询数线性增长，解码器的显存占用也随之上升。工程上这是一个明确的权衡点——分辨率不足会导致高频几何丢失，分辨率过高会让训练 batch 变小、收敛变慢。另一个失败模式是注意力坍缩：如果训练数据中物体朝向过于单一，平面查询可能学会只从图像中央的 patch 取证据，导致边缘区域的平面特征退化为常数，渲染出的新视角在轮廓处出现模糊或空洞。

用一个具体例子说明这条链路的必要性：输入是一张只看到椅子正面的图。ViT token 编码了椅面、椅腿、靠背的正面纹理；相机调制告诉网络这是从正前方看的；解码器的平面查询在 $\mathbf{T}_{xz}$（侧视平面）上需要生成“椅腿向后延伸”的特征，而图像里根本没有这个证据。网络只能靠训练数据中学到的椅子先验去补。这正是 LRM 的能力边界：可见面由图像证据决定，背面由数据先验决定。前者随输入变化，后者只随训练分布变化。

三 · 体渲染与多视图监督：损失如何约束三平面

三平面本身不是最终产物，它必须能渲染成图才能被监督。渲染器对任意视角 $\mathbf{c}'$ 沿射线采样三维点，每个点 $\mathbf{x}=(x,y,z)$ 在三平面上分别双线性采样得到 $\mathbf{f}_{xy},\mathbf{f}_{xz},\mathbf{f}_{yz}$，拼接后过一个小 MLP 解码出密度与颜色：

$$\sigma(\mathbf{x}),\mathbf{a}(\mathbf{x})=\mathrm{MLP}\big(\mathrm{interp}(\mathbf{T}_{xy},x,y)\oplus\mathrm{interp}(\mathbf{T}_{xz},x,z)\oplus\mathrm{interp}(\mathbf{T}_{yz},y,z)\big)$$

再沿射线做体积累积得到像素颜色，整张图即 $\hat{I}=\mathrm{VolumeRender}(\mathbf{T},\mathbf{c}')$。这里的机制要点是：三平面是特征，不是最终几何；MLP 是共享的、与视角无关的解码器，它把三个平面的特征融合成局部密度与颜色。共享 MLP 意味着三个平面必须在语义上对齐——同一个三维点从三个平面取到的特征要能拼成一个自洽的局部描述，否则 MLP 无法学到稳定的解码。这个约束是隐式的，但它是三平面表示能工作的前提。

训练信号来自 Objaverse 渲染的多视图数据：每个资产有若干已知相机下的真值渲染图。损失是渲染图与真值之间的 MSE 加感知损失（LPIPS 类）。写成目标函数：

$$\mathcal{L}(\theta)=\sum_{v}\Big\|\hat{I}_v-I_v\Big\|_2^2+\lambda\,\mathcal{L}_{\text{perc}}(\hat{I}_v,I_v)$$

MSE 约束像素级颜色与轮廓，感知损失约束高频纹理与结构相似性。多视图的意义在于：同一组三平面要在多个不同视角下都渲染正确，这迫使平面特征在三维上自洽，而不是只拟合输入视角。若只用输入视角的渲染做监督，网络会退化成“把输入图贴到某个平面上”，新视角渲染必然崩坏。多视图监督是把“单图输入”与“三维一致性”连接起来的唯一桥梁。

系统代价在这里最重：训练需要大量多视图渲染数据，渲染本身要跑可微体渲染，每条射线多次采样、每个样本多视角，计算量远大于纯图像训练。失败模式也很具体：如果多视图覆盖的视角范围偏窄（例如只渲染水平环绕、缺少俯仰），网络在俯视角上会输出错误的三平面——平面特征在垂直方向上缺乏约束，渲染出的顶视图出现拉伸或塌陷。另一个失败模式是感知损失权重过大：LPIPS 会奖励纹理锐利，但可能让密度场出现高频噪声，提取网格时产生碎片。

四 · 与相邻算法的数学差别：优化算子 vs 回归算子

把 LRM 与 SDS 路线并排看，差别不在表示层（两者都可以用三平面或 NeRF），而在求解结构。SDS 的目标是

$$\mathbf{T}^\*=\arg\min_{\mathbf{T}}\ \mathbb{E}_{\mathbf{c}'}\big[\mathcal{L}_{\text{diff}}(\mathrm{render}(\mathbf{T},\mathbf{c}'),y)\big]$$

其中 $y$ 是文本或图像条件，$\mathcal{L}_{\text{diff}}$ 是扩散模型的分数蒸馏损失。这是一个逐样本的优化问题，解的质量取决于迭代次数与步长，且没有 amortization——不同输入之间不共享计算。LRM 的目标是

$$\theta^\*=\arg\min_{\theta}\ \sum_{i}\sum_{v}\big\|\mathrm{VolumeRender}(f_\theta(I_i,\mathbf{c}_i),\mathbf{c}_{iv})-I_{iv}\big\|^2$$

这是一个跨样本的回归问题：参数 $\theta$ 在所有训练资产上共享，推理时 $\mathbf{T}=f_\theta(I,\mathbf{c})$ 是一次前向。数学上，SDS 解的是“给定 $I$ 求 $\mathbf{T}$”的逆问题，LRM 学的是“从 $I$ 到 $\mathbf{T}$”的映射。前者的误差来自优化不收敛与先验偏差，后者的误差来自回归均值化与训练分布覆盖不足。

与另一类相邻算法——纯图像到三维的回归网络（例如直接输出体素或点云）——的差别在于输出表示的可微渲染性。直接输出体素的网络难以端到端渲染新视角，监督只能落在三维真值上，而三维真值稀缺且获取昂贵；LRM 输出三平面，监督落在二维渲染图上，数据来源是渲染的多视图，规模可以做大。这是它“可扩展到大模型与大数据”的数学基础：监督信号在二维，输出表示在三维，两者通过可微渲染连接。

与 NeRF 逐场景优化的差别同样在摊销。NeRF 的每场景训练是 $\mathbf{T}^\*=\arg\min_{\mathbf{T}}\sum_v\|\mathrm{render}(\mathbf{T},\mathbf{c}_v)-I_v\|^2$，需要该场景的多视图；LRM 在推理时只有单图，多视图信息被压缩进了 $\theta$。这意味着 LRM 的精度上限受训练分布约束：它不能超过“见过的相似物体”的先验。一个具体例子：训练集里没有细长悬臂结构，推理时输入一张悬臂图，三平面在悬臂末端会给出模糊的密度，因为网络没有学到“细长结构在三个平面上如何保持一致”的模式。这不是渲染器的问题，是回归算子的均值化偏差。

还有一层差别在相机条件的角色。SDS 与 NeRF 优化中，相机是渲染算子的参数，不进入表示本身；LRM 中相机 $\mathbf{c}$ 进入编码器，成为映射 $f_\theta$ 的自变量。这使 LRM 对输入视角敏感——同一物体从不同视角拍，输出的三平面朝向不同但应一致地描述同一三维形状。这个一致性不是自动获得的，需要训练数据中同一资产的多视角样本教会网络“视角变化不改变三维形状”。若数据中每个资产只给一个视角，网络会把视角信息错误地编码进形状，导致推理时换视角输入输出形状漂移。

五 · 推理链路与网格提取的代价

推理时链路很短：输入图过 ViT，相机调制，Transformer 解码出三平面，一次前向结束。要得到可用的三维资产，还需从三平面提取网格。常见做法是在三平面上查询密度场，跑 marching cubes 之类的等值面提取。这一步的代价是分辨率损失：三平面是二维网格，其有效分辨率由平面分辨率决定，等值面提取的网格精度不会超过平面采样精度。细薄结构（叶片、线缆）在平面分辨率不足时会被抹掉或断裂，因为密度场在平面上的采样间隔大于结构厚度。

另一个代价是背面细节的不可控性。三平面的背面特征完全由数据先验填充，推理时没有任何来自输入图的证据。工程判断是：LRM 适合“单图快速出粗模”的场景——预览、批量资产生成、游戏与电商的草模；不适合“单图高保真还原”的场景——文物数字化、工业检测，因为背面与遮挡区域的误差不可预测且不可修正。若要修正，只能在输出后接一个逐资产优化或补拍多视图，这又回到了 SDS 的成本结构。

网格提取的分辨率损失可以用一个具体机制说明：三平面在 $x$ 方向的采样间隔为 $\Delta x$，若某结构的厚度小于 $\Delta x$，密度场在离散采样上无法形成闭合等值面，提取结果出现孔洞。提高平面分辨率可以缓解，但解码器的查询数与显存按分辨率平方增长，训练成本随之上升。这是一个明确的工程权衡点，而不是可以免费消除的误差。

最后落在机制上：LRM 把三维重建从“推理时求解”变成“训练时回归”，代价从每资产迭代转移到一次性训练与数据覆盖；三平面是使这个转换可行的中间表示，因为它同时满足输出维度可控与端到端可微渲染两个条件。它的能力边界由训练分布决定，可见面由图像证据决定，背面由先验决定，网格精度由平面分辨率决定。这三条边界是后续工程选型的判断依据。
