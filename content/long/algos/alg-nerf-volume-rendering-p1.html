一 · 问题的数学形状：从 2D 像素反推 3D 场

NeRF 要解决的问题可以写成一句很精确的话：给定一组相机位姿已知的 2D 图像，求一个连续函数，使得沿任意相机射线对该函数做体渲染积分所得的颜色，与对应像素观测一致。这里的未知量不是体素网格、不是点云、也不是多平面图像，而是一个定义在连续三维坐标上的映射。把场景写成 \(F_\Theta:(\mathbf{x},\mathbf{d})\mapsto(\sigma,\mathbf{c})\)，其中 \(\mathbf{x}\in\mathbb{R}^3\) 是空间点，\(\mathbf{d}\in S^2\) 是观察方向，\(\sigma\) 是体密度，\(\mathbf{c}\) 是视角相关颜色。参数 \(\Theta\) 是 MLP 的权重。

这个设定之所以不同于此前的体素或网格表示，在于它把「场景」与「分辨率」解耦了。体素表示的内存随边长三次增长，网格表示的分辨率一旦固定就无法在查询时细化；而连续函数表示在任意精度上都能被采样，内存只与网络宽度和深度有关。代价是：每次查询都要跑一次前向网络，采样密度直接换算成计算量。

问题的难点在监督信号的维度错配。观测是 2D 的像素值，未知是 3D 的密度与颜色场，二者之间隔着一个积分算子。若积分不可微，2D 像素的误差就无法变成 3D 场的梯度，整个问题只能靠多视角几何匹配或体素 carving 之类的离散手段求解。NeRF 的核心贡献正是把这个积分写成对 \(\Theta\) 可微的形式，让 photometric loss 的梯度穿过射线上的每一个采样点回到 MLP。

具体机制上，一条射线由相机光心 \(\mathbf{o}\) 和方向 \(\mathbf{d}\) 参数化：\(\mathbf{r}(t)=\mathbf{o}+t\mathbf{d}\)，\(t\) 从近端 \(t_n\) 到远端 \(t_f\)。像素颜色是这条射线上所有点的密度加权颜色之和。这个求和不是启发式的 alpha 混合，而是从辐射传输方程在一维无散射介质假设下严格退化出来的。下面的推导会把每一步的假设写清楚，因为工程实现里所有的失败模式几乎都能追溯到某个假设被违反。

二 · 核心思想：把积分写成可微的离散求和

连续形式的体渲染积分是：

$$C(\mathbf{r})=\int_{t_n}^{t_f}T(t)\,\sigma(\mathbf{r}(t))\,\mathbf{c}(\mathbf{r}(t),\mathbf{d})\,dt,\qquad T(t)=\exp\!\left(-\int_{t_n}^{t}\sigma(\mathbf{r}(s))\,ds\right)$$

逐项解释。\(T(t)\) 是从近端 \(t_n\) 到 \(t\) 的透射率，物理含义是光线走到 \(t\) 处还没被吸收或散射掉的概率。它的指数里是密度沿路径的累积积分，密度越大、路径越长，透射率衰减越快。\(\sigma(\mathbf{r}(t))\) 是 \(t\) 处的消光系数，决定该点对最终颜色的贡献权重。\(\mathbf{c}(\mathbf{r}(t),\mathbf{d})\) 是该点朝观察方向发出的颜色，允许依赖 \(\mathbf{d}\) 是为了表达镜面高光和视角相关的外观。三项相乘再积分，就是沿射线收集到的辐射亮度。

这个式子成立的前提是无散射、无自发光以外的二次光源贡献，即介质只吸收和发射。对 NeRF 所面对的不透明或半透明场景，这个近似足够用；对参与介质（烟、雾）需要加入散射项，那是后续工作的范围。工程上必须意识到：公式里的 \(\sigma\) 同时扮演「存在概率」和「不透明度」两个角色，这是 NeRF 用单一标量表达几何的根本原因，也是它难以表达薄表面与体积混合场景的原因。

离散化采用分层采样。把 \([t_n,t_f]\) 分成 \(N\) 个区间，在每个区间内均匀抽一个点：

$$t_i\sim\mathcal{U}\!\left[t_n+\frac{i-1}{N}(t_f-t_n),\;t_n+\frac{i}{N}(t_f-t_n)\right],\quad i=1,\dots,N$$

然后定义相邻采样点间距 \(\delta_i=t_{i+1}-t_i\)，离散透射率为 \(T_i=\exp\!\left(-\sum_{j=1}^{i-1}\sigma_j\delta_j\right)\)，离散颜色为：

$$\hat{C}(\mathbf{r})=\sum_{i=1}^{N}T_i\left(1-\exp(-\sigma_i\delta_i)\right)\mathbf{c}_i$$

注意这里把连续式里的 \(\sigma_i\delta_i\) 换成了 \(1-\exp(-\sigma_i\delta_i)\)，这是 alpha 合成形式的精确离散对应：一个区间内的不透明度等于 \(1\) 减去该区间透射率。当 \(\sigma_i\delta_i\) 很小时两者近似相等，但当密度大或步长大时，指数形式保证不透明度不会超过 1，这是数值稳定的关键。伪代码思路如下：对每条射线生成 \(N\) 个 \(t_i\)；对每个 \(t_i\) 计算 \(\mathbf{x}_i=\mathbf{o}+t_i\mathbf{d}\)；把 \(\mathbf{x}_i\) 和 \(\mathbf{d}\) 送入 MLP 得到 \(\sigma_i,\mathbf{c}_i\)；按上式累加得到 \(\hat{C}\)；与真实像素算 MSE；反向传播时梯度经由 \(T_i\) 和 \(\mathbf{c}_i\) 两条路径回传到 MLP 参数。

可微性来自两处：\(\hat{C}\) 对 \(\sigma_i\) 和 \(\mathbf{c}_i\) 的依赖是初等函数复合，对 \(\Theta\) 的依赖经由 MLP 前向也是初等函数复合，因此整条链没有不可导的离散决策。分层采样中的随机性只影响采样位置，不影响梯度对参数的连续性。这一点是 NeRF 与基于体素 carving 的方法的分水岭：后者在可见性判断上做硬决策，梯度断掉；前者把所有决策软化为密度值，梯度全程畅通。

三 · 公式逐步推导：从辐射传输到 alpha 合成

第一步，写出一维辐射传输方程。沿射线方向，辐射亮度 \(L\) 的变化由吸收和发射决定：\(\frac{dL}{dt}=-\sigma L+\sigma L_e\)，其中 \(L_e\) 是介质自身的发射亮度。把 \(\sigma\mathbf{c}\) 视作 \(L_e\) 的替身，解这个一阶线性常微分方程，得到 \(L(t)=L(t_n)T(t)+\int_{t_n}^{t}T(s)\sigma(s)\mathbf{c}(s)\,ds\)。假设近端没有入射光，即 \(L(t_n)=0\)，就得到上面的积分式。这一步说明：NeRF 的颜色公式不是拼凑的混合规则，而是线性常微分方程的解析解。

第二步，把积分拆成区间和。将 \([t_n,t_f]\) 切成 \(N\) 段，第 \(i\) 段内假设 \(\sigma\) 和 \(\mathbf{c}\) 为常数 \(\sigma_i,\mathbf{c}_i\)。第 \(i\) 段对颜色的贡献是 \(\int_{t_i}^{t_{i+1}}T(t)\sigma_i\mathbf{c}_i\,dt\)。段内 \(T(t)=T_i\exp(-\sigma_i(t-t_i))\)，代入积分得 \(T_i\mathbf{c}_i\left(1-\exp(-\sigma_i\delta_i)\right)\)。对所有段求和即得离散式。这一步的近似误差来自段内常数假设：当 \(\sigma\) 在段内剧烈变化时，误差随 \(\delta_i\) 线性增长。这就是为什么采样点数量 \(N\) 直接决定渲染质量，也是为什么后续工作要用重要性采样把点集中到密度大的区域。

第三步，检查梯度的数值行为。对 \(\sigma_i\) 求偏导，会同时出现在 \(T_i\) 的指数里和 \(1-\exp(-\sigma_i\delta_i)\) 的项里，前者让梯度随深度指数衰减。当一条射线穿过很多高密度点时，远端点的梯度会被压到极小，这就是「梯度消失沿射线」的失败模式。工程上的表现是：遮挡关系学得慢，远处的几何在训练早期几乎不动。缓解手段包括增大 \(\delta_i\) 让指数衰减变缓、或者用重要性采样减少无效点。

第四步，位置编码。MLP 对低频函数有频谱偏置，直接输入 \((x,y,z)\) 时网络倾向于学出平滑的场，高频细节被抹掉。位置编码把每个坐标映射到一组正弦基：

$$\gamma(p)=\left(\sin(2^0\pi p),\cos(2^0\pi p),\dots,\sin(2^{L-1}\pi p),\cos(2^{L-1}\pi p)\right)$$

对三个坐标分别做编码后拼接，再送入 MLP。这一步不改变积分公式，但改变了 \(\sigma,\mathbf{c}\) 作为坐标函数的表达能力。它的代价是输入维度从 3 涨到 \(3\times 2L\)，第一层参数量和前向计算量随之上升。\(L\) 取得过大时，网络会对高频噪声过拟合，表现为渲染中出现高频条纹。

一个具体例子：假设一条射线穿过一个密度为 \(\sigma=10\)、厚度为 \(\delta=0.1\) 的薄片，则 \(1-\exp(-1)\approx0.632\)，该薄片贡献约 63% 的不透明度；若厚度翻倍到 0.2，不透明度升到 \(1-\exp(-2)\approx0.865\)。这说明密度与厚度的乘积才是有效不透明度，单看 \(\sigma\) 无法判断遮挡强弱。工程上调参时若只改 \(\sigma\) 的量级而不改采样间距，遮挡关系会以非预期的方式变化。

四 · 与相邻算法的数学差别

与体素场方法（如早期的神经体积渲染）相比，差别在表示的连续性。体素方法把场景离散成网格，查询是查表加三线性插值，梯度只流向被插值到的八个顶点。NeRF 的查询是连续函数求值，梯度流向整个 MLP 参数，空间上不存在「网格边界」这种人为不连续。代价是每次查询的计算量远大于查表，且无法用空间数据结构加速（后续的哈希编码、八叉树才补上这一课）。

与多平面图像（MPI）相比，差别在采样维度。MPI 把场景表示为若干固定深度的平面，每个平面一张 RGBA 图，渲染时按深度合成。它的积分是沿深度方向的离散 alpha 合成，深度分辨率被平面数量锁死。NeRF 的积分沿连续 \(t\) 进行，采样点位置可随射线自适应，深度分辨率不受固定层数限制。代价是 MPI 可以用 2D 卷积高效渲染，NeRF 必须对每条射线逐点跑 MLP。

与光场方法相比，差别在几何的显式程度。光场直接参数化射线颜色，不显式表达密度，因此无法做新视角的几何一致性约束，也无法输出可编辑的几何。NeRF 通过 \(\sigma\) 显式表达占据，颜色是密度的加权和，因此可以用密度做几何提取（marching cubes），也可以把密度当作可编辑的量。代价是密度与颜色耦合在一个网络里，编辑密度会连带改变颜色。

与基于符号距离场（SDF）的方法相比，差别在表面假设。SDF 假设场景由薄表面构成，渲染时找零交叉点再做表面着色，积分被替换为单点求值。NeRF 假设场景是体积介质，积分覆盖整条射线。前者对薄表面更锐利、渲染更快，但对毛发、烟雾、半透明材质表达困难；后者对体积现象自然，但表面边界会因为密度渐变而显得模糊。数学上，SDF 的渲染是狄拉克 delta 形式的积分退化，NeRF 是有限宽度的体积积分，二者的不透明度曲线形状不同。

方法表示积分形式梯度路径主要代价
NeRF连续 MLP沿射线体积积分经密度与颜色全程可微每射线数百次 MLP 查询
体素场离散网格三线性插值求和仅流向邻近顶点内存随分辨率三次增长
MPI固定深度平面离散 alpha 合成经平面 RGBA 可微深度分辨率被层数锁死
SDF连续标量场零交叉点单点着色经表面点可微薄表面假设，体积现象难表达

这张表的每一行都对应一个工程判断：需要体积现象就选积分形式，需要锐利表面就选 SDF 形式，需要实时渲染就选预计算结构。NeRF 的位置在中间：它用积分换来了对体积现象的自然表达和 2D 监督的直接可用性，代价是计算密度。

五 · 失败模式与系统代价的数学根源

第一个失败模式是细节模糊，根源在 MLP 的频谱偏置加上积分平滑。积分本身是一个低通算子：沿射线对 \(\sigma\mathbf{c}\) 做加权平均，高频的密度变化会被相邻点的贡献稀释。即使位置编码把高频信息送进网络，积分这一步仍会把细小的几何边缘抹成渐变。工程表现是：薄结构（栏杆、树枝）渲染成半透明糊状，边缘不锐利。缓解手段是提高采样密度让积分更接近真实积分，或者改用 SDF 式的表面求交。

第二个失败模式是训练慢，根源在每条射线 \(N\) 次 MLP 前向。计算量是「像素数 × 射线采样数 × 每次前向的浮点运算」。像素数由图像分辨率决定，采样数由场景深度范围决定，前向运算由网络宽度和位置编码维度决定。三者相乘，单次迭代的成本远高于 2D 卷积网络。渲染时同样要对每个像素跑一遍，无法像光栅化那样并行到 GPU 的固定管线。这是 NeRF 早期难以实时化的根本原因，也是后续用哈希编码、缓存、蒸馏来压缩查询成本的原因。

第三个失败模式是沿射线的梯度衰减。前面推导过，\(T_i\) 的指数形式让深部点的梯度被压小。当场景有强遮挡时，被遮挡区域的密度几乎收不到梯度，学得极慢。工程表现是：训练初期只学到近处表面，远处几何在很长时间里保持随机初始化状态。缓解手段包括在训练早期用较大的采样间距、或者用分层采样把点集中到当前密度估计高的区域。

第四个失败模式是视角相关颜色的过拟合。\(\mathbf{c}\) 依赖 \(\mathbf{d}\) 让网络能表达高光，但也让网络有机会用视角相关颜色去「解释」本该由几何解释的亮度变化。当训练视角稀疏时，网络可能学出错误的视角相关外观，在新视角下产生鬼影。这是可微渲染的经典病：监督信号不足时，网络会用表达能力去拟合观测而非真实几何。

一个具体例子：假设场景中有一个镜面球。NeRF 可以用视角相关颜色让球面在不同视角下呈现不同亮度，但它无法表达球面反射出的其他物体，因为反射需要沿反射方向再做一次射线积分，而 NeRF 的积分只沿相机射线进行一次。这就是「静态场景，难处理反射」的数学根源：单次积分无法表达二次反弹。要表达反射，需要递归的射线追踪，那是后续工作的范围。

系统代价的另一个来源是采样策略与积分精度的耦合。均匀采样在空旷区域浪费大量查询，在密度大的区域采样不足。重要性采样用粗网络先估计密度分布，再在密度高的区间加密采样，代价是要跑两次网络。这个两级结构把单次查询成本翻倍，但换来了同等采样数下更低的积分误差。工程上要判断的是：当场景大部分是空的时候，两级采样的收益大于成本；当场景密度均匀时，收益有限。

六 · 可微性是这套机制的全部赌注

把整条链路再检查一遍：像素误差对 \(\hat{C}\) 求导，\(\hat{C}\) 对 \(\sigma_i,\mathbf{c}_i\) 求导是解析的，\(\sigma_i,\mathbf{c}_i\) 对 \(\Theta\) 求导经由 MLP 的反向传播是解析的。整条链上没有采样位置的梯度，因为采样位置被视为随机变量，其分布不依赖 \(\Theta\)；这一点在数学上是把采样当作蒙特卡洛估计的样本，梯度只对样本的函数值求导，不对样本位置求导。这个选择让实现简单，但也意味着网络无法通过学习去移动采样点，采样策略必须由外部启发式决定。

这个可微性赌注的回报是：不需要 3D 监督，不需要多视角立体匹配，不需要显式的几何先验，仅凭 2D 像素的 MSE 就能优化出 3D 场。代价是优化问题的非凸性和监督的稀疏性：每条射线只提供一个标量监督，却要约束沿途数百个点的密度和颜色，解的空间远大于约束的数量。网络能收敛，靠的是 MLP 的隐式平滑先验和位置编码的频率结构，而不是约束的充分性。这就是为什么 NeRF 在视角稀疏时会失败，也是为什么后续工作要加入深度监督、语义监督或几何正则。

工程判断落在这一点上：NeRF 体渲染积分的价值不在于公式本身（辐射传输方程是几十年前的成果），而在于把公式写成对网络参数可微的形式，从而把 2D 监督接进 3D 表示。任何后续改进——更快采样、更强编码、更好正则——都是在不破坏这条可微链路的前提下，降低它的计算代价或补足它的监督稀疏性。判断一个改进是否属于这个家族，标准就是看它是否保留了「沿射线积分、对参数可微、用 2D 光度损失」这三件事。
