一 · 与“逐顶点序列化”的逐项对比

把网格变成 token 序列，最直觉的相邻方案是逐顶点序列化：按某种顶点顺序（例如按索引、按空间排序或按谱聚类顺序）把每个顶点的坐标写成一串 token，再让 Transformer 学下一个顶点。网格序列化 tokenization 与它的第一处差别在“序列的原子是什么”。逐顶点方案的原子是顶点，序列长度正比于顶点数 |V|；网格序列化方案的原子是面片，序列长度正比于面片数 |F|。对封闭的流形三角网格，欧拉公式给出 |V| − |E| + |F| = 2 − 2g（g 为亏格），而三角网格满足 3|F| = 2|E|，代入可得 |F| ≈ 2|V|。也就是说，面片原子在数量上比顶点原子多出约一倍，序列更长。这是网格序列化在长度上的固有代价，不是实现问题。

第二处差别在“邻接信息是否显式进入 token”。逐顶点方案里，一个顶点的邻居是谁，只能靠模型从已生成的坐标序列里隐式推断；而网格序列化的每个 token 显式携带邻接面索引 $\mathcal{N}_i$，量化公式为

其中 $v_i$ 是该面片的顶点坐标，$\mathcal{N}_i$ 是它的邻接面在序列中的位置。邻接索引是离散的、结构性的，模型不需要从坐标的连续性去猜拓扑，这直接解释了为什么该方法的生成拓扑较干净。代价是 token 的字母表被拆成两个子空间（坐标码本与邻接索引），解码器必须同时学两种分布，且邻接索引的取值范围随序列增长而扩大，词表规模与序列长度耦合。

第三处差别在失败模式。逐顶点方案最典型的失效是“顶点漂浮”：模型生成了坐标合理但彼此不共享边的点云，无法组成面。网格序列化的典型失效则是“邻接索引越界或指向已闭合区域”：DFS 遍历在回退时依赖栈，一旦模型在某个面片处生成了指向尚未访问分支的邻接索引，后续遍历无法闭合，产生非流形边或孔洞。前者是几何失败，后者是拓扑失败，两者的修复成本不同：前者可以靠后处理三角化补救，后者往往需要重新采样。

具体例子：一个由 8 个顶点构成的立方体表面（每个面拆成两个三角形，共 12 个面片）。逐顶点方案产生 8 个 token；网格序列化产生 12 个 token，且每个 token 里还带有 3 个邻接面索引。序列长度比是 12:8，但网格序列化的每个 token 信息量更大。若把两者都压到同一上下文窗口，逐顶点方案能覆盖更大的网格，网格序列化则在中等规模网格上就触及长度上限。这就是“序列长，长网格难生成”这条不足的直接来源。

二 · 与“面片集合 + 位置编码”方案的对比

另一类相邻做法是放弃序列化，直接把面片集合当作无序集合输入：每个面片独立编码为 token，配上某种位置或邻接编码，用集合式的 Transformer（无因果掩码或双向注意力）一次性预测整个集合。网格序列化与它的核心分歧在于“生成过程是否有序”。集合方案天然并行，一次前向就能输出全部面片，推理步数为常数；网格序列化是自回归的，推理步数正比于面片数 N，每步只出一个 token。这是系统代价上最硬的一条：集合方案的推理延迟与网格规模弱相关，网格序列化的延迟随 N 线性增长，且每步都要维护 KV 缓存。

集合方案的机制缺陷是“集合无因果顺序，模型学不到面片之间的依赖方向”。两个面片共享一条边，这个约束是对称的，但集合式注意力无法表达“先生成 A 再生成 B”的构造顺序，生成结果容易出现重叠面片或裂缝。网格序列化用 DFS 遍历把对称的邻接关系强行定向为一条访问路径，$p(\mathcal{M})=\prod_i p(t_i\mid t_{

失效条件方面，集合方案在面片数很大时注意力矩阵是 $O(N^2)$，显存先崩；网格序列化在面片数很大时序列长度先崩，两者撞的是不同的墙。集合方案还有一个隐蔽失败：当训练集中同一形状的面片排列顺序不一致时，模型被迫学排列不变性，收敛慢且生成结果的面片朝向混乱。网格序列化的 DFS 顺序由邻接关系唯一决定（在给定起点和分支选择规则下），排列歧义被消掉，这是它在小数据下仍能学到干净拓扑的原因之一。

具体例子：一个带 6 个部件的机械模型，每个部件约数百面片。集合方案可以一次输出所有部件面片，但部件之间的邻接关系在集合表示里是稀疏且不规则的，模型很难保证部件接缝处面片对齐；网格序列化按 DFS 逐部件遍历，部件边界处的邻接索引自然把两个部件串起来，接缝一致性由序列的连续性保证。代价是总序列长度是各部件面片数之和，长模型直接超出上下文窗口。

三 · 与“隐式场 / 神经 SDF”的对比

隐式场方案不产生 token 序列，而是学一个连续函数 $f_\theta(x,y,z)\to$ 占据值或符号距离，再用 marching cubes 等算法提取网格。网格序列化与它的对比要落在“输出表示”上：前者输出离散 token 序列，拓扑由序列的邻接索引决定；后者输出连续标量场，拓扑由等值面提取算法的网格分辨率决定。隐式场的优势是分辨率可调、不受序列长度限制，能表达任意复杂拓扑；网格序列化的优势是拓扑显式、面片数可控、生成结果直接是带邻接的网格，不需要后处理提取。

机制上，隐式场把“拓扑”隐式地编码在标量场的零等值面里，模型不需要显式决定哪个面片接哪个面片；网格序列化把拓扑显式地写进每个 token 的邻接索引 $\mathcal{N}_i$，模型必须逐面片决定连接关系。这带来一个关键失效差异：隐式场在薄壁、细杆等结构上容易因采样分辨率不足而丢失或粘连，失败是“几何分辨率”型的；网格序列化在长序列上容易因自回归误差累积而断开邻接，失败是“拓扑一致性”型的。前者调分辨率，后者调序列长度与采样策略，工程手段完全不同。

系统代价上，隐式场推理需要在一个三维网格上逐点求值再提取等值面，计算量正比于分辨率立方，显存峰值出现在提取阶段；网格序列化推理是逐 token 自回归，计算量正比于面片数，显存峰值出现在 KV 缓存。两者都不便宜，但瓶颈位置不同：隐式场是空间采样瓶颈，网格序列化是序列长度瓶颈。选型时若目标网格面片数上万，网格序列化的上下文窗口先成为硬约束；若目标只是中等面片数但拓扑极复杂（多孔、自交），隐式场的分辨率可调性更稳。

具体例子：生成一个内部有大量孔洞的支架结构。隐式场只要分辨率够高就能表达孔洞连通性，但提取出的网格面片数不可控，可能远超下游渲染预算；网格序列化的面片数由序列长度直接决定，预算可控，但 DFS 遍历在孔洞密集处分支多、回退频繁，邻接索引的预测难度上升，容易出现孔洞边缘未闭合。这是一个典型的“预算可控 vs 拓扑稳健”的取舍。

四 · 失效条件清单与触发边界

把失效条件按触发边界列清楚，比笼统说“不足”更有工程价值。第一类是长度失效：序列长度 N 正比于面片数，而自回归注意力的计算与显存随 N 增长，KV 缓存随 N 线性增长。触发边界是“目标网格面片数超过训练时见过的最大序列长度”，此时模型对长距离邻接索引的预测准确率下降，DFS 回退栈变深，闭合失败概率上升。工程上表现为生成网格出现悬挂面片或未闭合边界。

第二类是量化失效：$t_i=\mathrm{quantize}(v_i,\mathcal{N}_i)$ 中的坐标量化把连续顶点坐标压到离散码本，码本分辨率决定了可表达的最小几何细节。触发边界是“目标网格的特征尺寸接近或小于量化步长”，此时薄壁厚度、尖锐倒角被抹平，相邻面片的顶点坐标量化到同一格点，产生退化三角形。这是量化损失细节的直接机制，不是训练不足。

第三类是数据规模失效：训练数据规模有限时，模型见到的邻接模式（尤其是高亏格、非流形、带边界的情形）覆盖不全，DFS 遍历在训练中未出现的分支结构上外推失败。触发边界是“目标网格的局部邻接度或亏格超出训练分布”，表现为邻接索引预测出训练中不存在的连接模式。

第四类是遍历顺序失效：DFS 的起点选择和分支选择规则若在训练与推理间不一致，序列的构造语义漂移，模型学到的 $p(t_i\mid t_{

具体例子：一个薄壁壳体，壁厚与量化步长同量级。生成结果里内外两层表面被量化到同一批格点，面片互相穿插，邻接索引指向错误分支。这不是模型没学会，而是量化步长与几何特征尺度不匹配，属于第二类失效，调码本比调采样温度有效。

五 · 选型建议：按约束排序而不是按指标排序

选型时不要问“哪个算法更好”，要问“哪条约束先撞墙”。把约束按硬度排序：第一硬约束是输出必须是带邻接的网格且拓扑要干净，此时网格序列化是少数直接满足的方案，隐式场需要后处理提取、集合方案拓扑不稳。第二硬约束是面片数预算，网格序列化的序列长度直接对应面片数，预算可控性最好；隐式场的面片数由提取分辨率间接决定，不可控。第三硬约束是推理延迟，网格序列化逐 token 自回归，延迟随面片数线性增长，是它最弱的一环；集合方案与隐式场在这一项上更优。

据此给出分场景判断。部件级、中等面片数、要求拓扑干净且可编辑的场景，网格序列化是首选，因为它的 token 显式携带邻接，生成结果可直接进入下游网格处理管线，且可扩展到部件级拼接。超大面片数、只要求几何近似不要求拓扑精确的场景，隐式场更稳，分辨率可调且不受序列长度限制。要求低延迟批量生成的场景，集合式方案或隐式场更合适，网格序列化的自回归步数是硬伤。

还有一条常被忽略的选型维度：训练数据可得性。网格序列化依赖带邻接信息的网格语料，且 DFS 遍历要求网格是流形或近流形；若数据里大量是非流形、带自交的扫描网格，遍历会频繁失败，预处理成本高。隐式场对输入拓扑的要求更宽松，扫描数据可直接转成占据样本。数据管线成本应计入选型，而不是只看模型指标。

具体例子：一个需要在线交互式编辑的建模工具，用户每次修改后要重新生成局部网格。网格序列化的全序列重生成延迟不可接受，但可以把编辑区域限制在局部面片、只对该子图做 DFS 序列化与自回归，序列长度骤降，延迟回到可接受区间。这说明选型不是二选一，而是把算法的失效边界当作设计约束去切分问题。

六 · 三道练习

练习一（长度与预算）：给定一个三角网格，顶点数 |V| 与面片数 |F| 满足 |F| ≈ 2|V|。设上下文窗口为 N_max，写出该网格能否被单序列覆盖的判定条件，并说明当 |F| > N_max 时，按部件切分后每个子序列需要额外携带哪些跨部件邻接信息才能保证接缝闭合。要求给出判定不等式与切分后 token 结构的文字描述，不要求具体数字。

练习二（量化边界）：设坐标量化步长为 $\delta$，网格最小特征尺寸为 $s$。写出量化不产生退化三角形的必要条件，并分析当 $s$ 接近 $\delta$ 时，$t_i=\mathrm{quantize}(v_i,\mathcal{N}_i)$ 中坐标子空间与邻接子空间分别出现什么失效。要求给出不等式并分别说明两个子空间的失效机制。

练习三（遍历一致性）：设计一个实验，验证“推理时 DFS 分支选择规则与训练时不一致会导致系统性拓扑错乱”这一失效条件。要求写出控制变量（固定网格、固定模型权重、只改分支选择规则）、观测量（邻接索引越界率、非流形边数量、闭合失败率）与判定标准（规则不一致组的观测量显著高于一致组），并说明为什么这个实验能排除量化失效的干扰。

三道练习的共同指向是：网格序列化的每一个优势都对应一条失效边界，工程判断的价值在于把边界量化成可检验的条件，而不是停留在“序列长、量化有损”的定性描述上。练习二的量化不等式与练习一的长度不等式合起来，就是该算法能否用于某个具体网格的第一道门槛。
