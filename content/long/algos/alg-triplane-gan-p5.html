一 · 对照对象与任务边界：为什么只选这两个邻居

要给出有意义的选型判据，先要把“同一任务”钉死。Triplane 生成器要解决的是：给定隐向量，直接产出一个可微、可渲染、可多视角一致的 3D 物体表示，并用 2D 监督信号完成对抗训练。在这个任务定义下，真正可比的邻居只有两类：一类是把 3D 场塞进规则网格的体素/稠密表示路线，另一类是彻底放弃显式网格、用坐标网络直接回归隐式场的纯隐式路线。前者代表“把 2D 卷积的算力优势搬到 3D 但被立方复杂度反噬”，后者代表“参数少、拓扑自由但训练慢且难以高分辨率”。Triplane 恰好卡在两者中间：用三张 2D 特征图承载 3D 信息，把 3D 一致性从“结构保证”降级为“共享约束 + 判别器压力”。因此本部分的对照不是泛泛比较生成质量，而是比较三者在同一任务约束下的机制代价、失效模式与最小复现路径。

需要强调的是，这三条路线共享同一套训练外壳：体渲染把特征变成像素，2D 判别器在相机分布上给梯度。差别全部落在“3D 信息存在哪里、怎么被查询、查询代价如何随分辨率增长”。选型判据必须围绕这三个问题展开，而不是围绕某个指标排名。下面先给出三者的结构对照表，再逐项拆解机制。

维度Triplane体素/稠密网格纯隐式坐标网络

这张表已经暴露了选型的核心矛盾：Triplane 用“平面数量固定为三”换来了平方级而非立方级的显存增长，代价是表达冗余与拓扑刚性；纯隐式用“无网格”换来了拓扑自由，代价是高频细节的收敛速度；体素用“结构即一致性”换来了查询简单，代价是分辨率一上去就爆显存。任何选型判断都必须在这三组交换里做取舍，而不是指望某条路线全面占优。

二 · 与体素/稠密表示对照：立方复杂度的硬墙与插值语义差异

体素路线的机制极其直白：生成器输出一个形状为 D×H×W×C 的三维特征张量，查询点 𝐱 落在网格单元内，做三线性插值取出特征，再送解码器。它的 3D 一致性是结构自带的——相邻体素共享面、边、角，插值在三个轴上连续，不需要额外的跨平面约束。这正是 Triplane 缺失的东西：三张平面各自独立插值后拼接，平面之间没有显式的共享项，一致性只能靠训练信号压出来。因此体素在“几何自洽”上天然占优，而 Triplane 在“显存随分辨率增长”上天然占优。

把代价写成公式就一目了然。设每平面边长为 N、通道数为 C，体素特征张量的元素数为 N³C，Triplane 为 3N²C。两者之比为 N/3。当 N 从 64 涨到 256 时，这个比值从约 21 涨到约 85——也就是说，同样的通道预算下，体素的显存占用比 Triplane 高出一到两个数量级。这不是常数因子，而是随分辨率线性拉开的差距。工程上这意味着体素路线在较高分辨率下必须切块、分块渲染或降通道，而 Triplane 可以把省下来的显存直接换成更大的 N 或更宽的 C。

$$\text{Mem}_{\text{voxel}} = N^3 C,\qquad \text{Mem}_{\text{tri}} = 3N^2 C,\qquad \frac{\text{Mem}_{\text{voxel}}}{\text{Mem}_{\text{tri}}} = \frac{N}{3}$$

插值语义的差异则是更隐蔽的坑。体素的三线性插值在一个统一的三维网格上做，八个角点属于同一个张量，权重分配天然对称。Triplane 的三次双线性插值各自独立：interp(T_{xy},𝐱) 只用 x,y 坐标，interp(T_{xz},𝐱) 只用 x,z，interp(T_{yz},𝐱) 只用 y,z。这意味着沿 z 轴移动时，只有 xz 与 yz 两张平面变化，xy 平面完全不动。如果三张平面在训练中没有被约束到一致，就会出现“沿某轴移动时特征突变或停滞”的伪影。体素没有这个问题，因为任何轴向移动都会改变八个角点的权重。这就是 Triplane 的对称性冗余在机制层面的来源：三张平面两两共享一个轴，信息被重复编码，但重复的部分不保证一致。

失效模式的具体例子：在体素路线里，如果把 N 提到 256 且通道保持 32，单精度下特征张量就是 256³×32×4 字节，量级在数 GB 到十几 GB，单卡训练直接不可行，必须引入梯度检查点或分块。而在 Triplane 里，同样 N=256、C=32，三平面合计 3×256²×32×4 字节，量级降到数百 MB，单卡可以容纳，还能留出空间给判别器和渲染采样。这个对比不是实验室数字，而是由公式直接推出的量级判断。选型判据由此明确：当目标分辨率对应的 N/3 超过显存预算的容忍倍数时，体素路线出局；当任务要求强几何自洽且分辨率不高时，体素的插值语义优势值得保留。

最小复现坑在体素一侧是“插值边界”：三线性插值在网格边界外必须 clamp 或零填充，不同实现的选择会改变渲染边缘的行为，复现时若不对齐边界策略，损失曲线会对不上。在 Triplane 一侧则是“平面顺序与坐标映射”：三张平面分别对应 xy、xz、yz，拼接顺序必须与 MLP 输入维度严格一致，任何一张平面的坐标轴交换都会让训练看似收敛但渲染出旋转错误的物体。这个坑在复现时最容易出现，因为三张平面在代码里往往是三个同形状张量，形状检查抓不住语义错误。

三 · 与纯隐式坐标网络对照：拓扑自由度与高频收敛的交换

纯隐式路线的机制是：一个 MLP 直接吃坐标 𝐱（常配位置编码），输出密度与颜色，没有任何显式网格。它的 3D 信息全部压在权重里，因此拓扑完全自由——可以表示任意连通性、任意部件拆分，不需要担心平面拓扑固定带来的编辑困难。Triplane 的固定拓扑正是它的短板：三张平面一旦生成，物体的空间结构就被这三张图的笛卡尔积约束住了，想做“拆下某个部件单独编辑”这类操作，必须重新设计平面布局或引入额外的分解结构，而不能像纯隐式那样靠修改局部坐标区域的输出实现。

代价在收敛速度上。纯隐式的查询是一次 MLP 前向，计算量与分辨率无关，但要让 MLP 拟合出高频几何细节，需要大量采样点和较长的训练。Triplane 把高频细节的承载从 MLP 权重转移到了 2D 特征图上：平面特征由 2D 卷积生成，卷积核天然擅长局部高频模式，MLP 只负责把拼接特征解码成密度与颜色，容量需求小得多。这就是 Triplane 能在较少训练步数内出高分辨率结果的结构原因——高频在 2D 卷积里，不在坐标 MLP 里。纯隐式则相反，高频必须由 MLP 的谱偏置慢慢学出来，收敛慢是结构性的，不是调参能完全消除的。

$$F_{\text{implicit}}(\mathbf{x}) = \mathrm{MLP}\!\left(\gamma(\mathbf{x})\right),\qquad F_{\text{tri}}(\mathbf{x}) = \mathrm{MLP}\!\left(\mathrm{interp}(T_{xy},\mathbf{x}),\mathrm{interp}(T_{xz},\mathbf{x}),\mathrm{interp}(T_{yz},\mathbf{x})\right)$$

伪代码层面的差别在于查询路径的长度。纯隐式：坐标 → 位置编码 → 若干全连接层 → 密度/颜色，每一步都是稠密矩阵乘，单点查询的 FLOPs 固定但层数多。Triplane：坐标 → 三次双线性插值（各取四个角点加权）→ 拼接成定长向量 → 小 MLP → 密度/颜色。插值本身是廉价的加权和，MLP 层数可以很浅，因此单点查询更快，且特征图的分辨率提升只增加插值索引的粒度，不增加 MLP 宽度。这个差异在体渲染的密集采样下被放大：每条射线几十到上百个采样点，查询成本直接决定训练吞吐。

失效模式方面，纯隐式的典型失败是“高频欠拟合”：训练损失下降但渲染结果偏平滑，边缘发糊，加大 MLP 宽度或位置编码频率能缓解但会拖慢收敛。Triplane 的典型失败是“平面间不一致”：由于三张平面独立插值，物体在跨平面轴向移动时可能出现特征跳变，表现为渲染中的条带状伪影或视角切换时的闪烁。前者是容量与收敛的权衡，后者是一致性约束不足的产物。选型判据：若任务需要部件级编辑、拓扑自由、或物体类别跨度极大（单一平面布局难以覆盖），纯隐式更合适；若任务追求高分辨率、快速收敛、且物体属于同一大类（平面布局可共享），Triplane 更合适。

最小复现坑在纯隐式一侧是位置编码的频率选择与归一化坐标范围必须匹配，否则高频要么学不出来要么过拟合噪声；在 Triplane 一侧则是“插值对齐”——双线性插值的像素中心约定（align_corners 之类）必须与平面生成时的坐标映射一致，否则三张平面之间会出现半像素级的错位，训练能收敛但渲染有轻微重影。这个坑不会让损失爆炸，只会让结果“看起来差一点”，因此最难排查。

四 · 选型判据：把三个交换写成可执行的判断顺序

把前两节的对照压缩成可执行的判断顺序，避免在项目里凭感觉选型。判断应按以下优先级进行，每一步都是一个硬约束，不满足就直接排除对应路线。

  • 第一步看分辨率与显存：估算目标 N 下的 N³C 与 3N²C，若体素占用超过单卡预算的容忍上限（需要考虑判别器、渲染采样、优化器状态的额外开销），体素路线排除。
  • 第二步看几何自洽要求：若任务对跨视角几何一致性有硬性要求且无法用额外 3D 监督补足，体素的插值语义优势值得保留；若可以接受用 2D 判别器压力换取分辨率，Triplane 进入候选。
  • 第三步看拓扑与编辑需求：若需要部件级编辑、任意拓扑、或类别跨度极大，纯隐式优先；若物体属于同一大类且平面布局可共享，Triplane 的固定拓扑不构成障碍。
  • 第四步看收敛预算：若训练步数与采样密度受限，Triplane 的高频承载在 2D 卷积里，收敛更快；纯隐式需要更长的训练预算来拟合高频。
  • 第五步看监督信号：三条路线都依赖 2D 判别器时，Triplane 与纯隐式的一致性完全靠训练压出来，体素自带结构一致性；若有可用的 3D 真值，体素与纯隐式都能直接吃 3D 监督，Triplane 则需要把 3D 监督映射回三平面特征，多一层工程。

这五步的顺序不能随意调换。显存是硬墙，先排除不可行的路线；几何自洽与拓扑自由度是任务属性，决定候选集；收敛预算与监督信号是工程约束，决定最终取舍。把顺序倒过来，先比生成质量再回头看显存，往往会在项目中期发现路线不可行而返工。判据的本质是：三条路线没有全面优劣，只有在给定任务约束下的可行域大小不同。

具体例子：若任务是“单类物体、高分辨率、单卡训练、无 3D 真值”，五步判断会依次排除体素（显存）、保留 Triplane（分辨率与收敛）、排除纯隐式（收敛预算不足），最终落在 Triplane。若任务是“多类物体、需要部件编辑、训练预算充足”，则会排除体素（显存与拓扑）、排除 Triplane（固定拓扑）、落在纯隐式。这两个例子说明判据不是排名，而是约束求解。

五 · 最小复现坑清单：三条路线各自最容易翻车的地方

复现的最小路径不是把论文公式抄一遍，而是把“会让结果对不上但不会报错”的坑先列出来。以下按路线分组，每条都是机制层面的具体问题，不是泛泛的调参建议。

  • Triplane：三张平面的坐标轴映射与拼接顺序必须与 MLP 输入维度严格对应；平面顺序错位不会报形状错误，只会让渲染结果旋转错误。
  • Triplane：双线性插值的像素中心约定必须与平面生成的坐标归一化一致；半像素错位会导致三平面之间轻微重影，损失曲线正常但结果偏差。
  • Triplane：三平面共享约束的强度需要与判别器压力匹配；约束太弱会出现跨平面轴向的特征跳变，表现为条带伪影。
  • 体素：三线性插值的边界策略（clamp 还是零填充）必须统一；边界策略不一致会改变渲染边缘行为，损失曲线对不上。
  • 体素：分辨率提升时通道数往往需要同步调整，否则显存爆掉或表达不足；这个权衡没有公式解，只能按预算试。
  • 纯隐式：位置编码的频率范围必须与归一化坐标范围匹配；频率过高会拟合噪声，过低则高频学不出来。
  • 纯隐式：MLP 深度与宽度的配比影响收敛速度；过深会导致训练初期梯度不稳定，过浅则容量不足。

这些坑的共同特征是“不报错、只偏差”。复现时最有效的排查手段不是看损失，而是固定一个已知视角与已知隐向量，逐项改变一个变量（平面顺序、插值约定、边界策略、频率范围），观察渲染结果的系统性变化。若改变某个变量后结果出现整体旋转、重影或条带，就定位到了对应的坑。这个排查顺序本身就是最小复现路径：先把结构对齐，再谈训练调参。

还有一个跨路线的坑：体渲染的采样策略与特征查询的对齐。三条路线都依赖沿射线采样查询特征，若采样点分布与特征分辨率不匹配（例如平面分辨率高但采样过疏），高频细节会在渲染阶段被平均掉，表现为“训练损失低但渲染糊”。这不是路线本身的失效，而是采样与表示的耦合问题，复现时必须在固定采样策略下比较三条路线，否则对照结论会被采样差异污染。

六 · 工程判断落点：一致性来源决定路线选择

把三条路线的差别收敛到一个判断上：3D 一致性从哪里来。体素的一致性来自结构——三线性插值在统一网格上连续，不需要训练信号去压。Triplane 的一致性来自共享约束与判别器压力——三张平面独立插值，一致性是训练出来的，不是结构保证的。纯隐式的一致性来自坐标网络的连续性——MLP 对坐标连续，但高频细节的收敛依赖训练预算。这个“一致性来源”的差别，比任何单项指标都更能决定路线选择：若任务不能容忍一致性靠训练压出来（例如需要强几何自洽且监督信号弱），体素的结构一致性是硬优势；若任务能接受用 2D 判别器换分辨率，Triplane 的平方级显存优势是硬优势；若任务需要拓扑自由且训练预算充足，纯隐式的无网格结构是硬优势。

落到具体机制上，Triplane 的工程判断可以写成一句话：当目标分辨率对应的体素显存超过预算、且物体类别可用共享平面布局覆盖时，选 Triplane，并把工程重心放在三平面的一致性约束与插值对齐上，而不是放在 MLP 容量上。这句话把选型判据与复现坑连在了一起——选 Triplane 就意味着接受“一致性靠训练压出来”这个前提，因此复现时必须优先验证三平面之间没有系统性错位，否则训练再久也压不出一致性。
