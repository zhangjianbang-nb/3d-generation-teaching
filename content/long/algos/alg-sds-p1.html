一 · 问题设定：没有 3D 监督，梯度从哪里来

文生 3D 的困难不在于网络结构，而在于监督信号的缺席。图像领域有海量「图—文本」对，3D 领域没有同等规模的「形状—文本」对：三维资产的生产成本高、格式不统一、版权边界模糊，公开数据集在数量与多样性上都远不足以训练一个从零开始的 3D 生成模型。于是问题被重新表述为：能否不训练 3D 模型，而是借用一个已经训练好的 2D 扩散模型，把它的图像先验「蒸馏」进一个 3D 表示里？

形式化地说，设 3D 表示为参数 θ（可以是 NeRF 的密度与颜色场、体素网格、高斯集合或网格顶点），可微渲染器 g 在相机 c 下产生图像 x = g(θ, c)。我们希望找到一个 θ，使得从任意视角渲染出的 x 都像是一张「符合文本提示 y 的真实照片」。若有一个可微的、能判断图像是否符合 y 的打分函数 S(x; y)，问题就是最大化期望得分：

$$\theta^{*}=\arg\max_{\theta}\;\mathbb{E}_{c\sim p(c)}\,S\big(g(\theta,c);y\big)$$

关键难点是 S 不可得。判别器式的对抗训练需要可训练的判别网络与稳定的对抗博弈；而扩散模型只提供另一种东西——噪声预测器 ε_φ(x_t; y, t)。它不直接输出「这张图好不好」的标量，但它隐含了一个得分函数。SDS 的全部技巧，就是把噪声预测器的输出改写成对 θ 的梯度。

这里有一个容易忽略的工程事实：优化变量是 3D 参数，而扩散模型只见过 2D 图像。因此梯度必须穿过渲染器回传，∂x/∂θ 成为整条链路的瓶颈。任何不可微的渲染环节（离散体素的可见性跳变、网格拓扑改变、光栅化的硬边）都会让梯度断裂或带噪，这决定了后续所有实现都必须选择可微渲染器，代价是显存与渲染时间随分辨率上升。

二 · 核心思想：把「预测噪声减实际噪声」当作更新方向

扩散模型的前向过程把干净图像 x 逐步加噪：

$$x_{t}=\alpha_{t}x+\sigma_{t}\epsilon,\qquad \epsilon\sim\mathcal{N}(0,I)$$

其中 α_t、σ_t 由噪声调度给定，t 越大图像越接近纯噪声。训练好的网络 ε_φ 学会在给定 x_t、文本 y 与时间步 t 时估计当初注入的噪声 ε。若 x 是一张「扩散模型认为合理」的图像，那么 ε_φ(x_t;y,t) 应当与真实的 ε 高度一致；反之，若 x 偏离了条件分布的高概率区域，预测噪声就会系统性偏离实际噪声。

于是残差 ε_φ − ε 提供了一个方向信号：它指向「把 x 修改成模型更认可的样子」所需的像素级改动。SDS 的做法是把这一残差当作图像 x 的「梯度」，再经雅可比 ∂x/∂θ 链式回传到 3D 参数。整个流程不需要对扩散模型反传，网络权重 φ 全程冻结，只做前向推理。

这一思想与「用分类器梯度做引导」同源，但实现上更廉价：分类器引导需要对噪声图像求梯度，反传穿过整个分类器；SDS 直接把噪声预测的残差当作梯度用，省掉了一次反传。代价是这个「梯度」在数学上并不精确——它不是任何显式损失的真实梯度，而是一个有偏的替代量。SDS 论文对此的处理是：承认它不是得分，但论证其期望方向足以把渲染图推向高概率区域，并在实验中显示优化能收敛到可辨识的 3D 结构。

一个具体的机制细节：SDS 在每次迭代中随机采样相机 c 与时间步 t，而不是固定视角或固定噪声水平。随机相机保证 3D 表示在各个方位都受到约束，避免只优化单一视角导致「贴片式」几何；随机 t 则让不同噪声尺度共同作用——大 t 约束全局布局与语义，小 t 约束纹理细节。若固定 t 为某个中间值，常见失败是几何轮廓合理但表面细节糊成一片，因为小噪声尺度提供的高频约束从未被采样到。

三 · 公式逐步拆解：每一项在做什么

SDS 的梯度表达式为：

$$\nabla_\theta\mathcal{L}_{\mathrm{SDS}}=\mathbb{E}_{t,\epsilon}\!\left[w(t)\big(\epsilon_\phi(x_t;y,t)-\epsilon\big)\frac{\partial x}{\partial\theta}\right]$$

逐项看。最外层期望 𝔼_{t,ε} 表示对时间步与注入噪声采样，实践中每步只采一个 t 与一个 ε，用随机梯度下降的常规做法近似期望。x_t 是由当前渲染图 x 加噪得到，注意 x 依赖 θ，因此 x_t 也依赖 θ，但 SDS 在计算时把 x_t 视为常量、只对 x 求偏导，这是该近似最核心的简化。

ε_φ(x_t;y,t) 是冻结扩散模型在条件 y 下的噪声预测。它是唯一携带「图像先验」的项：模型见过的图像分布决定了它认为哪些噪声模式是合理的。ε 是实际注入的噪声，作为对照基线。两者相减得到逐像素、逐通道的残差张量，其量纲与噪声相同。

w(t) 是时间步权重，用于平衡不同噪声尺度对梯度的贡献。扩散模型的噪声预测误差在不同 t 上方差差异很大：t 接近 0 时预测容易，残差小；t 接近纯噪声时预测困难，残差大且方向不稳。若不加权，大 t 的噪声会淹没小 t 的细节信号。w(t) 的具体形式在实现中常取与信噪比相关的函数，工程上它是最容易被忽视却影响收敛的旋钮之一：权重偏向大 t 会得到语义正确但表面粗糙的结果，偏向小 t 则容易在早期就锁死错误的全局结构。

∂x/∂θ 是渲染器的雅可比，把图像空间的残差翻译成 3D 参数的更新。这一项决定了 SDS 能否接任意表示：只要渲染器可微，NeRF、高斯泼溅、SDF 网格都能用同一套梯度。反过来，雅可比的病态程度直接决定优化稳定性——薄结构、透明表面、镜面反射处的 ∂x/∂θ 数值极端，梯度容易爆炸或消失。

条件增强（CFG）在 SDS 中被用于增强文本对齐：把有条件预测与无条件预测相减，再按尺度缩放。写作 ε_φ^cfg = ε_φ(x_t;y,t) + s·(ε_φ(x_t;y,t) − ε_φ(x_t;∅,t))，其中 s 为引导尺度。这放大了「文本所要求的方向」，但也放大了噪声预测的偏差。工程后果是：s 偏大时颜色过饱和、纹理在高频处粘连成块；s 偏小时文本约束不足，生成物退化为与提示无关的通用形状。这一敏感性是 SDS 类方法最常被报告的操作难点。

四 · 与相邻算法的数学差别

把 SDS 与三类相邻方法并置，差别在「梯度来源」与「是否需要反传穿过模型」上最清楚。

方法梯度来源是否反传穿过生成模型主要代价
分类器引导分类器对 x_t 的真实梯度是需额外训练分类器，反传开销大
扩散后验采样似然项的真实梯度是每步多次前向，采样慢
对抗式 3D 生成判别器提供的对抗梯度是（判别器可训）对抗博弈不稳定，需调平衡
SDS噪声预测残差（近似梯度）否（模型冻结，仅前向）梯度有偏，需大量迭代

与分类器引导的数学差别最本质：分类器引导的梯度是某个显式对数似然项的梯度，方向可信但需要额外监督；SDS 的残差不是任何损失函数的梯度，它更像一个「得分方向的估计量」。SDS 论文的推导把去噪得分匹配的损失对 x 求导，得到的形式恰好是 w(t)(ε_φ − ε)，再乘雅可比——也就是说，SDS 梯度是「去噪损失对图像 x 的梯度」经链式法则的近似，省略了 ε_φ 对 x_t 的依赖项。省略这一项正是偏差的来源，也是它便宜的原因。

与对抗式方法的差别在于稳定性来源：对抗训练同时更新生成器与判别器，两者能力必须匹配，否则梯度消失或模式崩塌；SDS 的「判别器」是一个冻结的、已经收敛的扩散模型，不参与博弈，因此没有对抗失衡问题，但也就失去了随生成分布自适应调整判别标准的能力。这解释了 SDS 的典型失败模式：当 3D 表示的表达能力超出扩散模型先验覆盖的范围时，残差信号不再有意义，优化会在过饱和与多面体（Janus 问题，即同一资产在不同视角下出现重复或矛盾的面）之间震荡。

一个具体例子可以说明偏差的工程后果：优化一个 NeRF 表示生成「一只戴帽子的猫」时，早期迭代相机随机、t 偏大，残差主要驱动全局轮廓；当轮廓稳定后，若 w(t) 未随训练进程调整，大 t 的残差仍占主导，帽檐与猫耳的边界会被反复推拉，表现为几何在两次迭代间跳动。工程上的应对不是改公式，而是调度 w(t) 与 CFG 尺度随步数退火，让优化从「语义布局」逐步过渡到「细节纹理」。

五 · 系统代价与失败模式的机制根源

SDS 的计算结构决定了它的成本画像：每步需要一次可微渲染（前向 + 对 θ 的反传）、一次加噪、一次冻结扩散模型的前向。渲染分辨率越高，∂x/∂θ 的存储与计算越大；扩散模型前向虽不反传，但 UNet 在每步都要跑一遍，且 CFG 需要两次前向（有条件与无条件）。因此单资产优化动辄数十分钟到数小时，瓶颈通常在渲染与 UNet 前向的串行叠加，而非梯度计算本身。

失败模式可以按机制归类。多面问题源于随机相机与单视角监督的组合：每个视角独立地把渲染图推向「像一张合理照片」，但不同视角之间没有显式的 3D 一致性约束，模型可以在不同方位「各自为政」，产生正面与背面都合理、拼在一起却矛盾的几何。过饱和源于 CFG 放大的残差：引导尺度把噪声预测的偏差一并放大，优化把颜色推向极端值以降低残差。纹理粘连则源于小 t 阶段的残差在高频处缺乏空间分辨力，相邻像素的更新方向趋同，细节被抹平。

这些失败不是实现 bug，而是近似梯度的结构性后果。SDS 的残差在期望意义上指向高概率区域，但单次采样的方差大，且省略项带来的偏差随 x 偏离先验的程度增大。工程判断因此落在两个旋钮上：一是 w(t) 与 CFG 尺度的调度策略，二是相机采样分布（是否覆盖极端视角、是否与几何先验匹配）。前者决定优化能否从粗到细收敛，后者决定 3D 一致性是否被充分约束。把这两者当作超参数随手设定，是 SDS 类流程在复现时最常见的失败来源。
