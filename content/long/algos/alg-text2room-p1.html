一 · 问题的形式化：从单视角观测到全局网格的状态估计

迭代式房间网格补全要解的，是一个在观测受限条件下的场景状态估计问题。输入是一张（或少量）室内照片，输出是一个可漫游、几何闭合的三维房间网格。难点不在于单张图的深度估计本身，而在于：单张图只覆盖房间的一个锥形视域，其余表面从未被观测。任何生成模型都必须对未观测区域做出先验假设，并且这些假设要随着相机移动被不断修正，否则局部合理的补洞会在全局拼接时互相矛盾。

把问题写成状态估计的形式更清楚。设全局网格为 $\mathcal{M}_t$，相机在第 $t$ 步的位姿为 $\mathbf{c}_t=(\mathbf{R}_t,\mathbf{t}_t,\mathbf{K})$，观测到的颜色图为 $I_t$，深度图为 $D_t$。算法并不直接优化一个隐式辐射场，而是维护一个显式的、可渲染的三角网格。每一步做两件事：从当前网格在 $\mathbf{c}_t$ 处渲染出带洞的视图，用 2D 扩散模型把洞补上，再把补出来的像素反投影回三维并与旧网格融合。这里的关键是“渲染—补全—反投影”构成一个闭环，补全的输入不是原始照片，而是当前网格的渲染结果，因此补全必须与已有几何保持一致，否则融合阶段会产生重影或穿插。

这个闭环带来一个结构性约束：网格既是生成的目标，也是下一步生成的条件。$\mathcal{M}_t$ 的误差会通过渲染进入 2D 扩散的输入，再通过反投影写回 $\mathcal{M}_{t+1}$。误差不会被自动消除，只会被累积或放大。这正是长距离漂移的根源，也是理解该算法全部工程取舍的起点。

具体例子：从一张看向房间角落的照片出发，深度估计给出两面墙和地板的局部几何，反投影得到一块 L 形网格。相机向右平移并转向，渲染时右侧墙面出现大片空洞；2D 扩散依据左侧墙的纹理风格补出右侧墙的颜色与结构；反投影后，新墙面被缝合进网格。此时若左侧墙的深度存在系统性偏大，新墙面就会沿法向偏移，缝合处的墙角线出现折角——这就是一次可观察的漂移事件。

二 · 核心思想的数学表述：网格并集算子与反投影的耦合

算法的更新式只有一行：

$$\mathcal{M}_{t+1}=\mathcal{M}_t\cup\mathrm{BackProject}\!\left(D_t,I_t,\mathbf{c}_t\right)$$

逐步拆解。$\mathrm{BackProject}$ 把像素坐标 $\mathbf{p}=(u,v)$ 与深度 $d=D_t(u,v)$ 映射到相机坐标系：

$$\mathbf{X}_c=d\cdot\mathbf{K}^{-1}\begin{bmatrix}u\\v\\1\end{bmatrix},\qquad \mathbf{X}_w=\mathbf{R}_t^{\top}\left(\mathbf{X}_c-\mathbf{t}_t\right)$$

再把相邻像素对应的三维点连成三角形，得到局部网格片 $\mathcal{P}_t$。$\cup$ 不是简单的集合相加，而是一个带冲突消解的融合算子：对重叠区域，需要判断新观测是替换旧几何、还是仅补充纹理。工程上通常做法是：对每个体素或网格顶点维护一个置信度或观测计数，新观测按可见性加权写入；当新旧几何的法向或深度差异超过阈值时，标记为冲突并优先保留被更多视角支持的版本。

这里有一个容易被忽略的数学差别：$\cup$ 不是可交换的。先补 A 面再补 B 面，与先补 B 面再补 A 面，得到的网格在缝合处不同，因为第二次补全的条件是第一次补全后的渲染结果。迭代顺序因此成为算法的一部分，而不是实现细节。这也解释了为什么流程被固定为“渲染当前视角的洞→补洞→融合”，而不是一次性补全所有洞再统一融合。

系统代价：融合算子需要维护每顶点或每体素的观测统计，显存随场景规模线性增长。当房间面积增大、网格分辨率提高时，冲突检测的邻域查询成为瓶颈。失败模式是“缝合缝”：两个网格片在边界处顶点不重合，渲染时出现细缝或 z-fighting。具体例子：地板与墙面的交界处，若地板网格在补全时被扩散模型补出了略微外扩的边界，反投影后与墙网格重叠，融合时若不处理，漫游视角下会看到一条闪烁的接缝。

三 · 与单图深度补全的数学差别：条件分布的不同

单图深度补全（如深度图修复、单目度量深度估计）优化的是 $p(D\mid I)$，即在给定单张图像的条件下推断深度。它的输出是一张与输入图像像素对齐的深度图，误差以像素为单位度量，且不需要考虑视角变化后的自洽性。迭代式房间网格补全优化的是另一个对象：$p(\mathcal{M}_{t+1}\mid \mathcal{M}_t, I_t, \mathbf{c}_t)$，即在已有网格和当前相机位姿的条件下扩展网格。条件里包含 $\mathcal{M}_t$，这意味着生成分布被历史几何约束；条件里包含 $\mathbf{c}_t$，这意味着同一个未观测区域在不同视角下会被反复条件化。

数学上的关键差别在于约束的类型。单图深度补全的约束是图像域的平滑性与边缘一致性；网格补全的约束是三维域的可渲染一致性：补出来的像素反投影后，必须在新视角下渲染时不产生与旧几何的矛盾。这等价于要求补全结果落在 $\mathcal{M}_t$ 的可见性锥内，即补出的表面不能遮挡已被观测且置信度高的几何。2D 扩散模型本身不知道这个约束，它只知道二维图像的局部统计；约束是通过“渲染带洞视图”这一输入构造隐式施加的——洞的形状本身就编码了已有几何的边界。

失败模式由此产生：当洞的形状具有歧义（例如一个矩形洞既可能是缺失的墙面，也可能是通向另一个房间的门洞），2D 扩散会依据纹理先验选择一个解释，而这个解释未必与全局几何一致。具体例子：渲染视图中央出现一个竖直长条洞，扩散模型可能补成一扇关闭的门；但相机继续移动后，该位置实际应是一个开放走廊，补出的门几何与后续观测冲突，融合阶段只能丢弃或覆盖，造成一次不可逆的几何错误。系统代价是：这类错误无法通过增加采样步数消除，只能通过改变相机轨迹、让该区域被重新观测来修正。

四 · 与神经辐射场/隐式生成的数学差别：显式网格作为记忆

与基于 NeRF 或隐式场的场景生成相比，本算法把“记忆”放在显式网格里，而不是网络权重里。隐式方法通常优化一个连续函数 $F_\theta(\mathbf{x},\mathbf{d})\to(\sigma,\mathbf{c})$，场景信息分布在参数 $\theta$ 中，新视角渲染是沿射线积分：

$$\hat{C}(\mathbf{r})=\int_{t_n}^{t_f}T(t)\,\sigma(\mathbf{r}(t))\,\mathbf{c}(\mathbf{r}(t),\mathbf{d})\,dt,\qquad T(t)=\exp\!\left(-\int_{t_n}^{t}\sigma(\mathbf{r}(s))\,ds\right)$$

隐式表示的优点是连续、可微、对视角变化平滑；缺点是每次扩展都要重新优化或微调参数，且旧区域的几何会被新梯度更新无意中改变，产生“遗忘”。显式网格则把几何固定为顶点与面片，扩展时只做局部并集，旧几何默认不变。这使得迭代式补全的每一步都是增量的、可审计的：哪一块几何来自哪一次观测，理论上可以追溯。

代价也很明确。显式网格的分辨率是离散的，补全时反投影产生的几何必须被量化到网格顶点，量化误差在多次迭代后累积。隐式方法没有这个量化步骤，但它的漂移表现为参数漂移，更难定位。另一个差别是补全信号的来源：隐式生成通常用 3D 一致性损失或分数蒸馏来约束新视角，而本算法用 2D 扩散在渲染图上补洞，约束只作用在二维像素域，三维一致性靠反投影与融合算子事后保证。这使算法无需 3D 场景数据，但也意味着 3D 一致性是“拼”出来的，不是“优化”出来的。

具体例子：一个带凹凸线脚的墙面，隐式方法可以用连续密度场平滑表达线脚的截面；显式网格在低分辨率下会把线脚量化成锯齿，补全时扩散模型在二维上画出平滑线脚，反投影后却被网格分辨率截断，融合后线脚在漫游中呈现阶梯状。系统代价是分辨率与显存的双重压力：提高分辨率能缓解锯齿，但融合算子的邻域查询和显存占用同步上升，场景规模受显存限制这一不足正来自此处。

五 · 迭代次数与漂移的定量关系：误差传播的链式结构

把更新式展开，$\mathcal{M}_t$ 是 $t$ 次反投影与融合的复合结果。设每次反投影的几何误差为 $\epsilon_t$（由深度估计误差与扩散补全的二维误差共同决定），融合算子对误差的传递近似为恒等（旧几何不被修正），则总误差近似为各步误差的累积：

$$\mathcal{E}_t\approx\sum_{k=1}^{t}\epsilon_k+\sum_{k=1}^{t}\delta_k$$

其中 $\delta_k$ 是第 $k$ 步融合时因新旧几何冲突而产生的缝合误差。这个式子说明两件事：误差随迭代次数单调不减；$\delta_k$ 依赖 $\mathcal{M}_{k-1}$ 的误差，因此是二阶累积项。工程上的直接推论是：不能靠“多迭代几次”提升质量，迭代只扩展覆盖范围，不修正已有误差。相机轨迹的设计因此比补全模型的采样步数更重要——轨迹应尽量让已补全区域被再次观测，用新观测覆盖旧误差，而不是一味向前推进。

失败模式：长距离漂移在闭合回路时暴露得最明显。当相机绕房间一周回到起点，渲染起点视角时，当前网格在起点的几何与最初观测的几何出现偏移，表现为墙角错位或地板高度不一致。此时融合算子面对两组互相矛盾的几何，若置信度统计没有正确区分“早期观测”与“后期补全”，可能保留错误版本。具体例子：绕行一周后，起点处的门框在网格中偏移了半个门宽，漫游经过时门框与墙面穿插。系统代价是：修正这类漂移需要全局回环优化或重新观测，而算法本身只提供增量并集，不提供全局平差。

伪代码层面的判断逻辑可以写成：对每个新视角，先渲染可见性掩码，仅对掩码内为空的像素调用 2D 扩散；反投影后，对每个新面片查询邻域内旧面片的支持计数，若新面片与高支持旧面片法向夹角超过阈值，则丢弃新面片并标记该区域待重观测。这个逻辑把“补全依赖 2D 先验”的不足转化为一个可检测的冲突信号，但检测本身不解决冲突，只是阻止错误扩散。

六 · 工程判断：何时该用网格并集，何时不该

从数学结构看，迭代式房间网格补全适合“观测稀疏但先验强”的场景：室内房间的墙面、地板、天花板具有强结构先验，2D 扩散模型在补洞时能给出合理的纹理与布局，反投影后的几何虽然不精确，但足以支撑漫游与后续观测。它不适合“几何精度要求高”或“场景规模大”的任务：前者受量化误差与缝合误差限制，后者受显存与融合算子复杂度限制。

与相邻算法的选择可以按条件分布来判：若任务只要求单视角深度或新视角合成，且允许隐式表示，则优化 $p(D\mid I)$ 或 $F_\theta$ 更直接；若任务要求可编辑、可审计的显式几何，且能接受迭代扩展带来的漂移，则网格并集更合适。本算法的独特之处在于把 2D 生成先验当作三维补全的提议分布，再用显式融合做接受检验——这是一个“提议—检验”结构，而不是端到端优化。理解这一点，就能理解它的优势（无需 3D 数据）与不足（漂移、依赖 2D 先验、显存受限）为何是同一设计的两面。

具体机制上的工程判断是：融合算子的冲突阈值应随迭代次数自适应收紧。早期迭代几何置信度低，阈值放宽以允许补全；后期迭代已有较多观测，阈值收紧以保护已观测几何不被补全结果覆盖。这个策略不消除漂移，但能把漂移限制在未被再次观测的区域，而不是污染整个网格。代价是需要维护每区域的观测计数，显存开销进一步上升，这是场景规模受显存限制的直接体现。
