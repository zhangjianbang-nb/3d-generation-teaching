一 · 从“论文说了什么”到“配方里到底写了什么”

读 SDS 家族的论文，最容易犯的错误是把摘要里的动机当成机制，把对比表里的“解决了”当成事实。真正决定一个方法能不能复现的，是配方：优化目标里到底有几项、每项的权重怎么随 t 变化、相机怎么采样、CFG 取多少、初始化是什么、精修阶段换不换表示。这些细节大多不在正文，而在附录和开源配置里。本部分的任务不是复述各方法的宣传语，而是把“证据”拆成三层：目标函数层的改动、系统层的代价、以及失败模式层的可观察现象。三层对不上，就说明论文的叙事和实现之间有缝。

先建立一个判据。任何 SDS 变体都可以写成同一个骨架：对渲染图 x 加噪得到 x_t，送进某个打分器，得到一个“应该往哪走”的方向，再经渲染雅可比回传。差别只在打分器是什么、噪声日程怎么定、以及是否引入额外的状态。用这个骨架去套，就能把“核心改动”一栏翻译成可检验的问题：打分器换成了什么？它依赖哪些额外输入？这些输入在训练时从哪来？

$$\nabla_\theta \mathcal{L}_{\mathrm{SDS}}=\mathbb{E}_{t,\epsilon}\left[w(t)\left(\epsilon_\phi(\mathbf{x}_t;y,t)-\epsilon\right)\frac{\partial \mathbf{x}}{\partial \theta}\right]$$

这个式子里，ε_φ 是噪声预测网络，ε 是实际加入的噪声，w(t) 是权重，∂x/∂θ 是渲染对参数的雅可比。注意它没有“正确性”保证：它只是把 2D 模型在 x_t 处的去噪方向投影到 3D 参数空间。所有后续方法的改动，本质上都是在修正这个投影的偏差，或者降低它的方差。判据因此可以写得很具体：一个方法若声称解决了多面问题，就必须在打分器或目标里引入跨视角的耦合项；若声称解决了过饱和，就必须解释 CFG 与 w(t) 的交互如何被改变；若声称加速，就必须说明是减少了每步的渲染开销还是减少了步数。

一个具体例子：把 DreamFusion 的配方原样跑在一个“孔雀”提示上，相机只绕正面半球采样，背面永远不被渲染。此时损失对背面参数没有梯度，背面几何停留在初始化状态，或由正面视角的伪影外推成薄壳。这不是调参能救的，是采样分布与目标函数共同决定的失败模式。论文里“多面”现象的描述，对应的正是这种“每个相机独立打分、视角间无耦合”的结构性缺陷。

二 · 配方差异：SJC、Magic3D、VSD 各自改了什么

SJC 的改动点在“得分落在训练分布”。原始 SDS 把加噪后的渲染图直接送进扩散模型，但渲染图的统计特性与自然图像不同，尤其在低噪声阶段，模型见到的 x_t 可能落在训练分布之外，去噪方向因此不可信。SJC 用加噪与 PAAS 把渲染图拉回训练分布附近，使打分器工作在它熟悉的位置。代价是每次打分要多做一次扰动与校正，单步开销上升；失败模式是当扰动强度与噪声日程不匹配时，校正后的图仍然偏离，表现为纹理细节被抹平或几何边缘抖动。

Magic3D 的改动在系统层：粗 NeRF 先出低频几何与颜色，再用 DMTet 精修出高分辨率细节。两阶段的好处是粗阶段用低分辨率渲染，单步便宜，能把相机覆盖和整体形状先定下来；精修阶段换表示，用可微网格提取拿到更锐利的表面。代价是两阶段之间的接口：粗 NeRF 的密度场转成 DMTet 的初始化时，阈值和网格分辨率的选择会直接影响精修能否收敛；两阶段各自有学习率和权重，调参空间翻倍。失败模式是粗阶段已经把错误结构固化，精修阶段只能在错误拓扑上贴细节，表现为“远看像、近看糊”或局部凹陷。

VSD 的改动在目标函数：不再把 3D 参数当成一个点去拟合 2D 先验，而是引入粒子模型去修正“当前 3D 分布”。直观地说，它不只问“这张图像不像提示”，还问“这个 3D 样本在整体分布里是否合理”，从而缓解过饱和与多样性塌缩。代价是粒子带来的额外前向与存储，单步成本高于 SDS；失败模式是粒子数不足时，分布估计的方差反而让优化抖动，表现为颜色在不同视角间跳变。

这张表要当“待验证的假设”读，而不是“结论”读。每一行的“解决的问题”都对应一个可观察量：多面看正背面的结构是否矛盾，过饱和看颜色通道是否被推到极值，慢看单资产的实际耗时量级。表格没有给出数字，因为不同实现、不同硬件、不同提示的差异足以让任何单一数字失去意义。工程判断应落在“改动是否引入了新的耦合或新的成本”上，而不是“哪一行更好”。

三 · 解耦与加速：Fantasia3D、TextMesh、DreamGaussian 的取舍

Fantasia3D 把几何与外观拆成两个阶段：先优化几何，再优化外观。动机很直接——如果颜色和纹理同时参与优化，纹理可以“掩盖”几何错误，比如用高频花纹遮住凹凸不平的表面，损失看起来很低，但形状是错的。解耦之后，几何阶段只用地形/法线类监督，外观阶段固定几何再贴材质。代价是两阶段的误差会叠加：几何阶段的偏差在外观阶段无法被纠正，表现为贴图与表面法线不匹配、边缘出现拉伸。失败模式是几何阶段过度平滑，外观阶段只能用纹理伪造细节，最终资产在重光照下露馅。

TextMesh 直接优化网格，而不是隐式场。好处是输出天然是可编辑、可导出的三角面，不需要后处理提取等值面；坏处是网格的拓扑在优化中可能退化，出现自交、翻面或细长三角形，渲染雅可比在这些区域不稳定。它的失败模式很典型：优化早期网格较粗，梯度把顶点推向错误位置，形成“尖刺”；后续迭代无法自动修复拓扑，只能在尖刺上继续贴纹理。

DreamGaussian 用 3DGS 把时间压到分钟级。3DGS 是显式基元加光栅化，渲染快、梯度路径短，配合少步 SDS 可以大幅减少每步开销。代价是几何粗糙：高斯基元的空间分布不像隐式场那样有清晰的等值面，提取网格时容易出现空洞或粘连。失败模式是薄结构（叶片、羽毛、细杆）丢失，或相邻基元融合成团块。这里的工程判断是：如果下游需要干净网格，3DGS 阶段只能当“快速预览”，必须接一个网格精修；如果下游只要渲染图，分钟级就是真实收益。

这几种取舍可以用一个统一的代价模型来看：单步成本 ≈ 渲染成本 + 打分器前向成本 + 反传成本。隐式场渲染要沿射线积分，成本随采样数上升；3DGS 光栅化成本随基元数上升但常数小；网格渲染成本低但拓扑维护成本高。少步 SDS 减少的是迭代次数，不改变单步成本；解耦改变的是阶段数，不改变单阶段成本。任何“加速”声明都要问清楚它砍的是哪一项，否则无法判断是否可迁移到自己的管线。

四 · 方差与反演：ISM、LucidDreamer 的区间得分

ISM 与 LucidDreamer 都围绕“区间得分”做文章。SDS 的梯度是单点估计：在某个噪声水平 t 上取一次去噪方向，方差大，尤其在高噪声阶段，方向抖动会让几何在不同迭代间来回摆。区间得分的思想是在一段噪声区间上做积分或反演，用多个噪声水平的信息构造更稳的方向，降低方差。LucidDreamer 用区间得分稳几何，代价是反演成本：要对渲染图做 DDIM 反演，找到它在噪声空间中的对应点，再在该点附近取方向。反演本身需要多步迭代，单次打分的前向次数上升。

失败模式有两类。第一类是反演不准确：DDIM 反演是近似可逆的，步数不足时反演出的 x_t 与真实加噪路径偏离，区间得分的方向因此有系统偏差，表现为几何细节被过度平滑。第二类是区间宽度选择：区间太窄，方差降不下来；区间太宽，方向被多个噪声水平的平均抹平，高频细节丢失。工程上这相当于在“稳”和“锐”之间取一个折中，而这个折中没有理论最优，只能按资产类型调。

一个具体例子：优化一个带细长腿的椅子。高噪声阶段的方向决定整体比例，低噪声阶段的方向决定腿的粗细与连接。若区间得分把高低噪声混在一起平均，腿可能被加粗成块状；若只用低噪声，早期比例容易崩。ISM 类方法的实际配方通常要按 t 分段设置区间，这正是“论文里一句话、配置里一张表”的典型缝隙。

把方差问题写成式子会更清楚。SDS 的梯度估计是 g = w(t)(ε_φ − ε)∂x/∂θ，其方差来自 ε 的采样与 t 的采样。区间得分把 g 替换为对 t 的加权积分，方差下降的代价是积分内的相关性被引入，若各 t 的方向不一致，积分结果可能偏离任一单点方向。这不是“更准”，而是“更稳但可能更有偏”。判断一个方法是否值得用，要看你更怕抖动还是更怕偏差。

五 · 反例与失败案例：Janus、过饱和、纹理粘连

Janus 问题是 SDS 最著名的反例：正面和背面各自长出合理的脸，但两张脸朝向矛盾。机制上，每个随机相机独立地让 2D 先验打分，先验只看到单张图，不知道这张图对应物体的哪一侧，也不知道另一侧长什么样。于是“正面像孔雀”和“背面像孔雀”可以同时被满足，而二者在 3D 上不相容。这不是先验的错，是目标函数缺少跨视角一致性项。任何声称解决多面的方法，必须在目标里显式加入视角间耦合，或把相机条件喂给打分器，否则只是把矛盾推迟到精修阶段。

过饱和的机制与 CFG 直接相关。CFG 放大条件方向与无条件方向之差，等价于把去噪方向推向“更符合提示”的极端。在 2D 生成里这提升了对齐度，但在 SDS 里，放大的方向经雅可比回传后会把颜色通道推到极值，表现为高饱和、塑料感。工程上的表现是：CFG 调高，提示对齐变好，但颜色崩；CFG 调低，颜色正常，但对齐变差。这个 trade-off 没有免费的解，VSD 类方法通过分布修正缓解，但代价是粒子成本。

纹理粘连是另一个可观察失败：相邻表面（比如翅膀与身体、手指之间）的纹理被拉成一片，边界模糊。机制是渲染分辨率与采样不足，导致雅可比在边界处把不同表面的梯度混在一起；也可能是 3D 表示本身的空间分辨率不够，隐式场在薄区域没有足够带宽区分两个表面。失败模式在 3DGS 上更明显：基元重叠时，光栅化把颜色混合，梯度无法分离两个基元的贡献。修复通常靠提高分辨率或加不透明度正则，但两者都增加成本。

还有一个常被忽略的反例：相机分布只覆盖正面时，背面不是“没优化”，而是被正面视角的伪影外推成薄壳。这种薄壳在旋转展示时突然消失或翻转，用户感知为“模型坏了”，但在训练损失上几乎看不出来。这说明损失曲线不能作为质量判据，必须用覆盖全视角的验证渲染来检查。工程判断是：把相机覆盖当作一等公民，先于 CFG 和 w(t) 调。

六 · 工匠笔记的调参顺序与工程判断

给定事实里的调参顺序是：先相机分布（覆盖所有视角），再 CFG（贴文本但别过饱和），再 w(t)（平衡高低频），最后才是步数。这个顺序有明确的因果依据。相机分布决定梯度覆盖哪些参数，覆盖不到的参数不会被优化，调 CFG 和 w(t) 都救不了。CFG 决定方向的幅度，过大会把颜色推到极值，过小则提示对齐不足。w(t) 决定不同噪声水平的权重，高噪声管全局结构，低噪声管细节，权重失衡会让几何或纹理单方面崩。步数放在最后，因为前三个没调好时，增加步数只是把错误结构优化得更彻底。

把这个顺序写成伪代码思路：先枚举相机方位角与仰角，确保球面覆盖，检查每个视角的渲染是否都有非零梯度；再固定相机，扫 CFG 的几个档位，观察颜色通道的最大值与提示对齐的主观评分；再固定 CFG，按 t 分段调 w(t)，观察高低频细节的平衡；最后才增加迭代步数，确认损失下降但验证渲染不退化。每一步都要有可观察量，而不是凭感觉。

系统代价要提前算清。全视角覆盖意味着每步要渲染多个相机，单步成本乘以相机数；CFG 需要两次前向（条件与无条件），打分器成本翻倍；w(t) 分段调参意味着多组实验，实验成本上升；步数增加是线性成本。这四项叠加，使 SDS 的实际耗时远高于“单步渲染加一次前向”的朴素估计。DreamGaussian 之所以能压到分钟级，是因为它同时砍了表示成本（3DGS）和步数（少步 SDS），而不是只砍其中一项。

最后落到一个工程判断：SDS 仍然是没有 3D 数据时最便宜的路径，但它的偏差是结构性的，不是调参能消除的。相机覆盖、CFG、w(t) 能缓解症状，但不能让 2D 先验自己对齐视角。若下游需要多面一致、可重光照、可编辑的资产，就必须在管线里显式加入一致性建模——多视图扩散、跨视角耦合项、或前馈重建——而不是指望 SDS 的随机相机采样碰巧收敛到一致解。判断一个 SDS 变体是否值得引入，看它是否把“一致性”从隐式期望变成显式项，以及这个显式项的成本是否在你的预算内。
