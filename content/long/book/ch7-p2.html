一 · 从像素到潜变量：ViT 切 token 与查询机制

前馈重建的第一段数据流不是「把图丢进网络等它吐出 3D」，而是把一张或多张 RGB 图变成一组定长 token，再让一组可学习的查询向量去「读」这些 token。输入图先被切成不重叠的 patch，每个 patch 线性投影成一个向量，加上位置编码，构成图像 token 序列。ViT 主干在这些 token 上做自注意力，输出的是「这张图里有什么、在哪」的上下文表示，而不是像素级特征图。关键在于第二阶段：模型并不直接从这个序列回归 3D，而是引入一组固定的查询 token（query token），让它们对图像 token 做交叉注意力。查询 token 的数量是超参数，与输入分辨率解耦；每个查询负责潜变量空间里的一块区域。这样做的工程后果是：输入图分辨率提高，图像 token 数按 patch 面积平方增长，自注意力代价随之上升；而查询数不变，解码端的规模稳定。换句话说，编码端是「可变成本」，解码端是「固定成本」。

形式化地，设输入图 $\mathbf{I}$ 切成 $N$ 个 patch，图像 token 为 $\mathbf{X}\in\mathbb{R}^{N\times d}$，查询为 $\mathbf{Q}\in\mathbb{R}^{M\times d}$。交叉注意力的输出为：

$$\mathbf{Z}=\mathrm{softmax}\!\left(\frac{(\mathbf{Q}\mathbf{W}_q)(\mathbf{X}\mathbf{W}_k)^\top}{\sqrt{d}}\right)(\mathbf{X}\mathbf{W}_v)$$

$\mathbf{Z}\in\mathbb{R}^{M\times d}$ 就是潜变量的「种子」。注意这里的注意力权重矩阵是 $M\times N$：$M$ 固定、$N$ 随分辨率涨，所以显存峰值出现在这一步，而不是在 ViT 主干里。工程上常见的失败模式是：把输入图从训练分辨率临时拉高到 2 倍做推理，图像 token 数变成 4 倍，交叉注意力矩阵变成 4 倍，显存直接爆掉，而输出质量并不会线性提升——因为查询数没变，潜变量的信息带宽被 $M$ 卡死了。这是一个典型的「输入端加钱、瓶颈端没加」的错配。

具体例子：一张 512×512 的图，patch 取 16×16，得到 $32\times32=1024$ 个图像 token；若查询数取 1024，注意力矩阵是 $1024\times1024$，尚可接受。若把输入换成 1024×1024，token 数变 4096，矩阵变 $1024\times4096$，中间激活翻四倍。此时正确做法不是硬扛，而是要么提高查询数（改模型、要重训），要么在低分辨率上做前馈、把细节交给后续的网格细化或纹理超分模块。前馈模型的分辨率上限，本质上是查询数与潜变量分辨率的函数，不是输入图的函数。

二 · 三平面潜变量：把 3D 降成三张 2D 特征图

查询 token 解码后得到的不是体素，也不是点云，而是三张正交平面特征图：XY、XZ、YZ 三个平面，每张是 $R\times R\times C$ 的张量（$R$ 为平面分辨率，$C$ 为通道数）。任意三维点 $\mathbf{p}=(x,y,z)$ 的特征由三次双线性采样再聚合得到：

$$\mathbf{f}(\mathbf{p})=\mathrm{agg}\!\left(\mathrm{interp}(\mathbf{F}_{xy},x,y),\ \mathrm{interp}(\mathbf{F}_{xz},x,z),\ \mathrm{interp}(\mathbf{F}_{yz},y,z)\right)$$

聚合方式可以是拼接后过一个小 MLP，也可以是逐元素相加或相乘。这个设计的核心是把「3D 查询」变成「3 次 2D 查表」：显存从 $O(R^3)$ 降到 $O(R^2)$，而表达能力靠通道数 $C$ 和 MLP 补回来。代价是轴向对齐的偏置——三平面在坐标轴方向上分辨率均匀，但对角线方向的细节被三个平面的采样误差共同稀释。薄结构（叶片、栏杆、发丝）在这种表示下最容易丢，因为它们在某个平面上投影面积很小，双线性插值会把它们抹成半透明。

三平面之后接的是一个小型解码器：给定 $\mathbf{f}(\mathbf{p})$，输出该点的密度 $\sigma$ 与颜色 $\mathbf{c}$（或 SDF 值）。渲染时沿射线积分，损失是对多视图 RGB 的 $L_2$：

$$\mathcal{L}=\sum_{v}\|\hat{\mathbf{I}}_v-\mathbf{I}_v\|_2^2,\qquad \hat{\mathbf{I}}_v=\int_{t_n}^{t_f}T(t)\,\sigma(\mathbf{r}(t))\,\mathbf{c}(\mathbf{r}(t))\,\mathrm{d}t$$

这里有一个容易忽视的机制细节：前馈模型训练时，监督信号来自「渲染出来的图」，而不是 3D 真值。也就是说，梯度要穿过体渲染积分才能回到三平面特征图。体渲染是可微的，但它的梯度在低密度区域非常小，薄结构处的梯度信噪比差；模型于是倾向于把不确定的区域渲染成「雾」，而不是锐利表面。这就是为什么很多前馈三平面模型的渲染图看着柔和、一提取网格就发现表面糊成一团。失败模式具体表现为：提取等值面时阈值稍高就出现空洞，稍低就出现粘连的团块，且阈值在不同物体间不通用。

具体例子：一个带细长把手的杯子。把手在 XY 平面上投影成一条细线，在 XZ、YZ 平面上投影成窄条。三平面分辨率 $R=256$ 时，一个像素对应物体尺度的约 1/256，把手直径若只有 3 个像素宽，双线性采样在三个平面上都会把它平均掉，解码器收到的特征更像「背景 + 一点边缘」，于是渲染时把手呈半透明，网格提取时直接消失。工程上的补救不是调阈值，而是提高 $R$ 或换表示（高斯、网格），因为这是表示本身的带宽问题。

三 · 高斯输出头：从特征图到显式基元

GS-LRM 一类模型把输出头从「密度+颜色解码器」换成「高斯参数回归」。查询 token 不再解码成平面特征图再逐点查询，而是每个查询直接回归一组高斯的属性：中心 $\boldsymbol{\mu}$、协方差（用缩放 $\mathbf{s}$ 与旋转四元数 $\mathbf{q}$ 参数化）、不透明度 $\alpha$、球谐颜色系数。前向一次得到 $K$ 个高斯，$K$ 等于查询数或查询数的整数倍。渲染用泼溅光栅化，把每个高斯投影到屏幕、按深度排序、做 alpha 混合。这条路径的好处是渲染快、显式、可直接进实时管线；坏处是「漂浮物」——回归出的高斯中心可以落在物体表面之外，因为训练损失只约束渲染像素，不约束高斯的空间分布。

协方差矩阵的构造是：

$$\boldsymbol{\Sigma}=\mathbf{R}(\mathbf{q})\,\mathrm{diag}(s_x^2,s_y^2,s_z^2)\,\mathbf{R}(\mathbf{q})^\top$$

训练时需要对 $\boldsymbol{\Sigma}$ 做正则（例如限制缩放的上界），否则模型会学会用极扁或极大的高斯去「作弊」拟合像素，导致几何退化。这是一个系统代价：高斯输出头的损失函数里必须加几何先验项，而这些项的权重是手工调的，换数据域就要重调。失败模式具体表现为：单图输入时，背面没有任何监督，模型会把高斯撒在正面附近形成一层「壳」，从侧面看就是漂浮的碎片；多视图输入能缓解，但视图覆盖不到的区域仍然靠先验猜。

具体例子：一个毛绒玩具的单图重建。正面纹理丰富，高斯密集且贴合；背面无监督，模型回归出一片稀疏、半透明的高斯云，位置偏离真实背面几厘米。渲染旋转视角时，背面出现「鬼影」和闪烁——因为高斯的深度排序在视角变化时发生跳变。这不是渲染器 bug，是几何本身不确定。工程判断：高斯输出适合「看一眼、快速出资产、允许轻微瑕疵」的场景；要进引擎做碰撞或动画，必须再做一轮网格化与清理，而网格化又会引入新的分辨率损失。

四 · 可微网格与等值面：从潜变量到三角面

MeshLRM 一类模型把输出落到网格上。常见做法是在三平面或体素特征上定义一个隐式场（SDF 或占据概率），再用可微等值面提取（如 DMTet）把隐式场变成顶点位移与面片连接。DMTet 的机制是：在一个粗四面体网格上，每个顶点带一个 SDF 值，根据符号变化确定表面穿过哪些边，把交点连成三角面；顶点的位置作为可学习参数，通过渲染损失反传梯度。这样梯度可以从渲染图一路回到顶点坐标，网格拓扑在训练中被固定为「粗网格的子集」，不会产生非流形边——这是它相对 marching cubes 的优势。

等值面提取的分辨率决定了细节上限。设粗网格分辨率为 $G$，则能表达的最小特征尺度约为物体尺度的 $1/G$。公式上，表面提取等价于求解：

$$\mathcal{S}=\{\mathbf{p}\mid f(\mathbf{p})=0\},\qquad f\approx\text{SDF 或占据场的插值}$$

工程代价是显存与拓扑：$G$ 提高一档，四面体数量按立方增长，反传时的中间激活也按立方增长。失败模式是「薄结构穿透」——当薄片厚度小于一个网格单元时，SDF 在两侧顶点上的符号可能相同，等值面直接跳过它，网格上出现洞。另一个失败模式是拓扑错误：两个本应分离的部件在粗网格上被连成一体，因为它们的 SDF 在同一个单元内符号变化被合并了。这类错误无法靠调损失修，只能提高 $G$ 或换表示。

具体例子：一副眼镜的单图重建。镜框是细环，镜片是薄片。$G=128$ 时，镜框在若干处断开，镜片边缘出现锯齿状缺口；$G=256$ 时环闭合，但显存占用翻数倍，训练时 batch size 被迫降到很小，优化不稳定。这就是「可微网格受等值面分辨率限制」的具体含义：它不是精度不够，是分辨率与显存、拓扑稳定性三者互相拉扯。工程上常见的折中是：前馈出粗网格，再用一个细化网络或优化式后处理补细节，把「一次前向」拆成「前向 + 轻量优化」。

五 · 走通一个例子：单图到三平面到渲染到网格

取一张 512×512 的椅子照片，白底、四分之三视角。数据流如下。第一步，patch 化：16×16 patch 得 1024 个图像 token，ViT 主干输出上下文表示。第二步，交叉注意力：1024 个查询 token 读取图像 token，得到潜变量种子。第三步，解码：种子重排成三张 $256\times256\times C$ 的平面特征图。第四步，渲染监督（训练时）或前向推理（部署时）：沿相机射线采样，每点做三次双线性采样、聚合、过 MLP 得密度与颜色，体渲染积分出 RGB。第五步，网格提取：在 $128^3$ 的粗网格上查询 SDF，用 DMTet 提取三角面，得到带顶点颜色的网格。

这条链上每一段都有可观测的失败点。patch 化阶段：如果输入图有强透视，patch 的位置编码无法表达「这个 patch 在物体背面」，模型只能靠语义猜，背面细节全靠先验。交叉注意力阶段：查询数不足时，潜变量带宽不够，椅腿这种细长结构被压缩掉。三平面阶段：$R=256$ 时椅腿直径若小于 2 个像素，采样被平均掉。渲染阶段：体渲染梯度在椅腿处信噪比低，模型倾向渲染成雾。网格阶段：$G=128$ 时椅腿可能断开，$G=256$ 时显存吃紧。整条链的瓶颈不在单一环节，而在「信息带宽逐级递减」：图像 token 多，查询少，平面分辨率有限，网格分辨率更有限。

工程判断因此变得具体：如果目标是「快速预览」，停在第四步，输出三平面渲染或高斯泼溅，0.5 秒量级的速度（TripoSR 一类）足够，瑕疵可接受。如果目标是「进引擎」，必须走完第五步并检查：UV 接缝是否存在、法线方向是否一致、三角面数是否在预算内、是否有非流形边。前馈模型给出的网格通常没有 UV，顶点颜色不能直接当 PBR 材质用；要重光照，还得做 UV 展开与材质分解，这是第八卷与第九卷的活。把这条链走通一次，就能看清「一次前向出 3D」的真实含义：它出的是一份「带先验的初稿」，不是成品。初稿的质量由训练数据分布决定——见过的物体类别越密集，先验越强，背面猜得越准；长尾物体、透明材质、没见过的结构，初稿就会错，而且错得系统化，不是随机噪声。

最后一个机制细节值得记住：三平面、高斯、网格三种输出共享同一个编码器骨架（ViT + 交叉注意力查询），差别只在解码头与监督信号。这意味着换输出表示不需要重训编码器，工程上可以把「表示选择」当成一个可替换模块。代价是各表示的失败模式不同，评估时必须分别建检查项：三平面看薄结构与阈值敏感性，高斯看漂浮物与视角跳变，网格看拓扑与非流形边。用同一套「像不像」的指标评三种表示，会漏掉它们各自的结构性缺陷。
