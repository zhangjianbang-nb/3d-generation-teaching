一 · 训练回路：一次迭代里究竟发生了什么

SDS 的训练回路看起来短得可疑：采样一个相机、渲染一张图、加噪、送进扩散模型、取噪声预测残差、乘雅可比、反传。但这条短回路里塞着三个互相牵制的子系统——可微渲染器、噪声调度器、扩散先验——任何一个环节的配置错误都会以「几何崩坏」而不是「报错」的形式表现出来，这使得调试必须靠对中间量的观察而不是靠异常栈。

把一次迭代摊开：给定当前 3D 参数 θ（NeRF 密度与颜色、DMTet 顶点与 SDF、3DGS 的位置与协方差与球谐系数），采样相机位姿 c 与光照/背景条件，渲染出低分辨率图像 x = R(θ, c)。采样时间步 t 与噪声 ε，构造 x_t = α_t x + σ_t ε。文本条件 y 经 CFG 得到两个噪声预测，组合成 ε_φ(x_t; y, t)。残差 δ = ε_φ − ε 是一个与 x 同形状的张量。关键在于最后一步不是把 δ 当作像素梯度直接反传，而是乘上 ∂x/∂θ——渲染雅可比。这个雅可比在 NeRF 里是体渲染积分对密度与颜色的偏导，在 3DGS 里是光栅化对高斯参数的偏导，在网格里是可微光栅化对顶点位置的偏导。

$$\nabla_\theta \mathcal{L}_{\mathrm{SDS}}=\mathbb{E}_{t,\epsilon}\left[w(t)\left(\epsilon_\phi(\mathbf{x}_t;y,t)-\epsilon\right)\frac{\partial \mathbf{x}}{\partial \theta}\right]$$

工程上要意识到：δ 本身没有物理量纲意义，它只是一张「往哪个像素方向改会更像文本描述」的图；真正决定 3D 怎么动的是雅可比。雅可比把 2D 的像素级建议翻译成 3D 参数级更新，翻译过程是有损的——一个像素的改动可以对应无数种深度上的密度重排，SDS 不区分它们，于是深度歧义被留给了先验的统计偏好。这就是为什么同一句 prompt 在不同初始化下会长出厚度完全不同的物体：先验只约束「看起来像」，不约束「有多厚」。

权重 w(t) 是第二个易错点。它按噪声等级给残差加权，高噪声步对应低频结构、低噪声步对应高频纹理。若 w(t) 在高噪声段权重过大，几何会先被粗粒度地定下来，但纹理细节永远追不上；若低噪声段权重过大，纹理先饱和、几何反而被纹理「粘」住无法大改。实际调参时 w(t) 的形状比绝对步数更影响成败，因为步数只决定预算，w(t) 决定预算花在哪个频段。

失败模式在这一层最典型的表现是「梯度爆炸式过饱和」：当 CFG 引导系数被拉高，ε_φ 的残差幅度随之放大，雅可比把这股放大的信号原样送进颜色参数，颜色通道迅速跑出 [0,1] 区间，渲染图变成高对比度的塑料质感。这不是数值 bug，而是引导强度与 w(t) 没有联合校准的必然结果。系统代价是可量化的：每步要跑一次（CFG 下是两次）扩散前向，分辨率越高、步数越多，扩散前向的占比越大；在粗 NeRF 阶段扩散前向往往是瓶颈，而在 3DGS 阶段光栅化与雅可比反传开始与扩散前向平分秋色。

一个具体例子：优化一只孔雀。相机分布若只覆盖正面 ±30°，正面会迅速长出尾羽的扇形结构与眼斑纹理，但背面因为从未被渲染过，密度场在无梯度区域自由漂移，最终背面要么是空壳要么是正面结构的镜像糊块。这不是优化不收敛，而是目标函数在背面根本没有定义——SDS 的期望是对采样相机取的，未采样的视角不贡献任何梯度。所以相机分布不是「数据增强」，它是目标函数的定义域。

二 · 推理侧：从参数场到可交付资产

SDS 优化结束时手里只有参数 θ，用户要的是网格或高斯。这一步的代价常被低估：NeRF 转网格需要在一组密集采样点上求等值面（marching cubes 或 DMTet 的可微提取），分辨率每翻一倍，采样点数量按立方增长，提取时间与内存同步上涨。密度场若在训练中从未被约束成「干净表面」，等值面会带出大量悬浮碎片与内部空洞，后处理要额外花时间做连通分量过滤与孔洞填补。

DMTet 路线把提取变成可微的：维护一组顶点与 SDF 值，用可微的四面体剖分把 SDF 转成网格，再对网格做光栅化渲染。好处是几何与渲染在同一张图里端到端可训，坏处是网格拓扑在优化中会翻转、坍缩，需要定期做边折叠与顶点分裂来维持质量，这些操作本身不可微，只能以「重参数化」的方式插入训练循环，插入频率与阈值成为新的超参。Magic3D 的两阶段正是把这件事拆开：粗 NeRF 阶段用低分辨率 SDS 定大局，DMTet 精修阶段用高分辨率 SDS 补细节，两阶段之间要做一次提取与初始化，调参面从一套变成两套，两阶段的目标不一致时（粗阶段偏爱胖几何、精修阶段偏爱薄壳）会出现细节与轮廓打架。

3DGS 路线绕开了等值面：高斯本身就是显式基元，优化完直接光栅化，不需要提取。DreamGaussian 把这条路的优势兑现成分钟级产出，代价是几何粗糙——高斯没有拓扑约束，密度可以任意堆积，表面连续性靠不透明度与尺度间接维持，放大看会看到高斯「绒毛」而非干净表面。要把高斯变成网格，仍需做一次泊松重建或 TSDF 融合，这一步又把时间与质量拉回与 NeRF 提取类似的量级。

推理侧还有一个隐性代价：多视角一致性检查。SDS 训练出的资产在训练相机分布内看起来合理，一旦用户从没见过的角度渲染，Janus 问题就暴露——正面与背面各自合理但拼在一起是两张脸。工程判断是：交付前必须做环绕渲染抽检，把 8 到 12 个均匀分布的视角渲一遍，人工或自动比对轮廓与纹理连续性。这个检查不能省，因为 SDS 的损失曲面在视角之间是断开的，优化器没有动机去缝合它们。

失败模式在推理侧最典型的是「纹理粘在几何上」：当几何在精修阶段还在变动，而纹理已经收敛到某个高频解，后续的几何微调会把纹理拉伸成条纹或把细节抹平。Fantasia3D 的解耦正是针对这一点：几何阶段只优化法线与密度、用与纹理无关的扩散条件，外观阶段冻结几何只学材质。解耦的代价是两阶段误差累积——几何阶段的偏差会被外观阶段当成既定事实去贴纹理，纹理再合理也救不回错误的轮廓。

三 · 方差：随机相机与随机时间步带来的估计噪声

SDS 的期望是对 (t, ε, c) 三者取的，实践中每次迭代只采一个样本，于是梯度是单样本蒙特卡洛估计，方差天然很大。方差来源有三：时间步 t 的采样分布、噪声 ε 的随机性、相机 c 的随机性。三者中相机带来的方差最致命，因为它不是零均值噪声——不同视角给出的残差方向系统性不同，单样本估计会在视角之间来回拉扯，表现为几何在迭代中「呼吸」：这一百步胖一点，下一百步瘦一点，损失曲线震荡而不下降。

ISM（区间得分匹配）的思路是用 DDIM 反演构造一条从 x 到 x_t 的确定性轨迹，在轨迹的两个端点之间取「区间得分」，把单点估计换成沿轨迹的积分估计，从而把 ε 的随机性从梯度里挤出去。代价是反演本身要跑一次反向扩散，每步的扩散前向次数翻倍，训练时间相应上涨。LucidDreamer 用同一套区间得分来稳几何，效果体现在轮廓不再随迭代抖动，但反演成本让高分辨率阶段的预算变得紧张。

VSD 换了一个角度：不把先验当成固定的打分函数，而是维护一个粒子模型（一组当前 3D 样本的渲染图）来估计「当前 3D 分布」的得分，再用它去修正 2D 先验的偏差。这相当于把单点估计换成分布估计，方差下降的同时带来多样性——不同随机种子能长出不同结构而不是收敛到同一个模式。代价是粒子模型的训练开销：每步要额外更新一个图像扩散模型（或用 LoRA 微调），显存与算力都要为它让路。ProlificDreamer 的过饱和问题被缓解，正是因为分布估计抑制了单点残差的幅度爆炸。

SJC 的处理更朴素：把渲染图加噪到扩散模型训练分布覆盖的噪声等级，再用 PAAS 让得分落回训练分布内。它解决的是「渲染图与自然图像分布不匹配」导致的先验失准——渲染图往往过于干净或背景纯色，扩散模型对这类输入给出的残差方向不可靠。加噪是一种分布对齐的粗糙手段，代价是有效信号被噪声稀释，需要更多步数才能收敛。

系统代价的统一表述：方差下降的每一条路都要用算力换。单样本 SDS 最便宜但最抖，ISM 用反演换稳定，VSD 用粒子换多样性与去饱和，SJC 用加噪换分布对齐。选型时要把「可接受的抖动」与「可支付的算力」放在同一张表上权衡，而不是默认越新越好。

四 · 视角一致性：为什么 2D 先验自己不会对齐

Janus 问题的根源不在优化器，而在目标函数的可分解性。SDS 的期望对每个相机独立取，损失是各视角损失的加权和，没有任何一项跨视角耦合。数学上，若把 3D 参数按视角可见性分块，每个视角的梯度只作用于它可见的那部分参数，不可见部分在该视角下梯度为零。于是「正面合理」与「背面合理」是两个可以同时满足的独立约束，它们的交集可以是一个物理上不可能的形状——两张脸共享一个后脑勺。

工程补丁分两类。第一类是在渲染侧加耦合：多视图扩散（MVDream、SyncDreamer）把一次前向变成一组同步视角的联合去噪，跨视角注意力在去噪过程中强制共享结构信息，残差因此带上了跨视角一致性。代价是扩散模型本身要换成多视图版本，显存按视角数增长，且多视图模型只在固定视角网格上训练，相机分布必须与之对齐，否则一致性约束在分布外失效。第二类是在优化侧加耦合：把相邻视角的渲染图做光度或特征一致性正则，或者用视频扩散的时间维当作视角维。这类正则的权重难调——权重太小不起作用，权重太大把几何压成过度平滑的球。

具体例子：优化一把椅子。四条腿在正面视角下是四条竖线，在侧面视角下是四条斜线，两个视角各自都能被 2D 先验打高分，但若没有跨视角约束，优化器可以让正面长出四条腿、侧面长出另外四条腿，渲染任一视角都合理，环绕一圈却发现腿的数目在变。修复方式不是加大步数，而是把相机分布改成螺旋上升的连续轨迹并在相邻帧之间加一致性项，让「腿的数目」成为跨视角共享的量。

系统代价：一致性约束让每步的渲染次数从 1 涨到 k（k 为联合视角数或轨迹窗口长度），雅可比反传的图规模同步膨胀。更隐蔽的代价是优化景观变复杂——跨视角耦合项引入了新的局部极小（例如所有视角一致地错），调试时不能只看单视角损失，必须看环绕渲染的差异图。

失败模式的另一种形态是「纹理缝合线」：两个视角各自收敛到不同的纹理配色，交界处出现硬边。这不是几何问题而是颜色参数在视角边界上的不连续，根源仍是独立打分。解耦几何与外观（Fantasia3D）能缓解，因为外观阶段可以在固定几何上做跨视角的颜色一致性优化，但两阶段误差会让缝合线以另一种形式回来。

五 · 工程调参：顺序比数值更重要

SDS 的超参不是并列的，它们有依赖顺序。工匠笔记给出的顺序是：相机分布 → CFG → w(t) → 步数。这个顺序的合理性在于每一层都定义了下一层的问题域。相机分布决定目标函数的定义域，定义域错了后面全错；CFG 决定残差幅度与文本贴合度，幅度没校准就调 w(t) 等于在错误的尺度上做频段平衡；w(t) 决定预算在高低频之间的分配，频段没分配好就加步数只是把错误的解算得更精细。

相机分布的具体做法：覆盖所有视角不是「均匀撒点」那么简单，要保证每个视角被采到的概率不为零且相邻视角有重叠，否则视角之间出现梯度真空带。常见配置是围绕物体的球面螺旋加少量俯仰变化，俯仰范围要覆盖用户可能观看的角度。只绕正面转的配置在背面必然崩，这不是概率问题而是定义域问题。

CFG 的校准要看渲染图的颜色直方图：引导系数拉高时颜色分布向两端挤压，中间调消失，这就是过饱和的前兆。工程判断是先把 CFG 调到文本贴合可接受的最低值，再靠 w(t) 补细节，而不是靠 CFG 硬拉。CFG 过高的另一个代价是残差方向变得极端，雅可比反传后几何出现尖刺与自交。

w(t) 的校准要看两个阶段的损失下降速度：高噪声段损失降得快说明几何在被粗粒度地定形，低噪声段降得慢说明纹理追不上。若低噪声段长期不降，要么是分辨率不够（雅可比太粗），要么是 w(t) 在该段权重过低。步数的边际收益在 w(t) 校准后才会显现，未校准前加步数往往只是延长震荡。

失败模式的系统表述：调参顺序颠倒的典型症状是「越调越差」——先加步数再调 CFG，会发现步数增加后过饱和更严重；先调 w(t) 再调相机，会发现换相机分布后之前的 w(t) 全部失效。原因是每一层都在改变梯度的统计特性，下层参数的最优值依赖上层的选择。工程上要把调参记录成有序的配置树，而不是一堆散落的超参。

层级决定什么调错的症状代价
相机分布目标函数定义域背面空壳或镜像糊块未采样视角零梯度
CFG残差幅度与文本贴合颜色过饱和、几何尖刺残差放大后雅可比反传失控
w(t)高低频预算分配几何定了纹理追不上，或纹理粘住几何频段错配导致步数边际收益归零
步数总预算震荡不收敛扩散前向次数线性上涨

把这张表读成依赖图而不是清单：相机分布是根，CFG 是干，w(t) 是枝，步数是叶。任何一层改动都要向下重新校准，否则上层的最优解在下层变成次优。这也是为什么 SDS 的复现难度高——论文给的是一组数值，而工程要的是一棵配置树。

六 · 何时该停：失败模式的识别与止损

SDS 不会报错，它只会安静地产出坏资产。识别失败模式要靠中间量而不是最终图。三个可观测信号：环绕渲染的视角间差异、颜色直方图的饱和度、几何提取后的连通分量数。视角间差异在训练中若持续不降，说明跨视角耦合缺失或相机分布有洞；饱和度在训练后期若单调上升，说明 CFG 与 w(t) 的联合校准失效；连通分量数若在精修阶段上升，说明几何在被纹理拉扯出碎片。

止损的判断标准是「边际收益是否为正」：连续若干步的环绕差异不再下降而单视角损失仍在降，说明优化器在过拟合单视角，继续训练只会加深 Janus。此时应停下来改相机分布或加一致性项，而不是加步数。另一个止损信号是提取时间占比：当等值面提取的耗时超过扩散前向，说明分辨率已经超出当前几何质量能支撑的范围，再提分辨率只是把噪声提取得更精细。

具体例子：优化一只猫。训练到中途发现正面胡须清晰、背面是一团无结构的密度，环绕差异图在背面区域全红。此时正确的动作是把相机分布向背面扩展并降低 CFG，让背面先长出粗结构再补纹理；错误的动作是加步数，因为背面根本没有梯度来源，加步数只会让正面过拟合到过饱和。

系统代价的最后一层是「补丁的补丁」：每加一个一致性补丁就引入一组新超参，补丁之间可能互相抵消。SJC 的加噪与 VSD 的粒子模型同时使用时，加噪稀释了粒子模型要估计的分布信号，粒子模型的修正效果被削弱。工程判断是补丁要按失败模式配对，不要堆叠——先定位是方差问题、分布对齐问题还是一致性问题，再选对应的单一路径，而不是把所有方法都打开。

最终落在机制上：SDS 的偏差不是可以通过调参消除的数值误差，而是「独立视角打分」这一目标函数结构的必然产物。所有工程补丁都在做同一件事——把缺失的跨视角耦合显式地加回目标函数，或用分布估计替换单点估计来压低方差。能走多远取决于补丁与失败模式的匹配精度，而不取决于算力堆叠。当补丁开始互相抵消时，说明该换目标函数的结构而不是继续加补丁——这正是后续多视图扩散与前馈工厂要接手的地方。
