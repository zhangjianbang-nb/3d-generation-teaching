一 · 一个没有照片的下午

设想一个具体的工程现场。你手上有一段文本：「一只站在枯枝上的孔雀，尾羽半开，青铜色，逆光」。没有这只孔雀的任何照片，没有多视图采集，没有 Objaverse 里能检索到的近似资产。你要在几小时内产出一个可渲染、可导出、可进引擎的 3D 资产。前四卷的所有工具在这一刻同时失效：可微渲染需要多视图图像来反推几何，哈希编码与 3DGS 需要一组已知相机位姿的观测，SDF 与 NeuS 需要带掩码的图像序列来定义表面，三平面与隐式函数生成器需要大规模 3D 数据训练出来的先验。它们共同的隐含前提是「监督来自这个物体本身的观测」。而现在，这个前提被抽走了。

这不是一个假想的极端案例，而是文本到 3D 的常态工况。工程上真正的问题不是「能不能渲染」，而是「损失函数的右边写什么」。渲染器把参数 θ 映射成一张图 x = g(θ, c)，c 是相机；可微渲染保证 ∂x/∂θ 可算。但损失 L(x, x_gt) 里的 x_gt 不存在。没有目标图像，梯度链条在最后一步断掉。第五卷整卷要回答的就是这一个问题：在没有该物体照片的情况下，监督信号从哪里来，又以什么代价获得。

DreamFusion 给出的回答是把监督外包给一个预训练的 2D 扩散模型。渲染出一张图，加噪，送进扩散模型，模型在文本条件 y 下预测噪声 ε_φ(x_t;y,t)；预测噪声与注入噪声之差，就是「这张图往哪个方向改会更像一只孔雀」的指示。这个指示不需要经过扩散模型反向传播——SDS 的关键工程决策是把它当作一个固定的、无参数的梯度源，只借用它的输出向量，再乘上渲染雅可比 ∂x/∂θ 回传给 3D 参数。于是监督从「这个物体的照片」变成了「2D 模型对『像不像孔雀』的判断」，而后者是从海量图文对里学来的。

$$ \nabla_\theta \mathcal{L}_{\mathrm{SDS}}=\mathbb{E}_{t,\epsilon}\left[w(t)\left(\epsilon_\phi(\mathbf{x}_t;y,t)-\epsilon\right)\frac{\partial \mathbf{x}}{\partial \theta}\right] $$

这个式子里每一项都值得工程上盯住。ε 是注入的高斯噪声，ε_φ 是模型预测，两者之差是一个与 x 同维的向量，量纲上是「像素级的修正方向」；w(t) 是噪声等级 t 的权重，决定高低频谁说话；∂x/∂θ 是渲染器雅可比，把像素空间的修正翻译成参数空间的修正。注意它没有 U-Net 的反向传播，没有二阶导，也没有对扩散模型参数的更新——扩散模型全程冻结。这就是为什么它便宜：一次前向，一次雅可比向量积，一次参数更新。这也是为什么它必然有偏：一个冻结的 2D 评判者，只能对单张图说「像」，无法对一组图说「彼此一致」。

二 · 上一卷的答案为什么不够

第四卷的答案是原生 3D 生成：在三平面、点云、隐式函数上训练生成模型，直接从 3D 数据分布里采样。这条路在封闭类别上工作得很好，EG3D 式的三平面 GAN 能给出干净、视角一致、可渲染的结果。它的代价藏在数据里：生成器的上限由 3D 数据的规模和覆盖决定。Objaverse 这类资产库能覆盖常见物体，但对「青铜色半开尾羽的孔雀」这种长尾描述，检索不到、训练分布里也没有。更麻烦的是 3D 数据与文本的对齐远弱于图文对：图文对是数十亿量级、噪声大但覆盖广；带文本标注的 3D 资产是另一个数量级，且标注质量参差。原生 3D 生成器的条件分布 p(x_3d | y) 在长尾文本上几乎是空的。

第二卷与第三卷的答案同样不够。3DGS 与 NeuS 是表示与重建工具，它们把「已知观测」转成「可渲染资产」的效率极高，但不生产观测。哈希编码解决的是速度，SDF 与 Eikonal 正则解决的是表面干净程度，两者都不回答监督来源。第一卷一整卷建立的可微渲染链条，恰恰是把这个问题暴露得最清楚的部分：链条越完整，断在损失函数上的那一环越刺眼。

于是出现一个结构性判断：当 3D 数据不足、图文数据过剩时，最便宜的路径不是去补 3D 数据，而是把 2D 先验「借」过来。这就是 SDS 的经济学。它把监督成本从「采集/标注 3D」转移到「前向一次 2D 扩散模型」，前者是资本与时间密集型，后者是算力密集型且边际成本低。工程上这意味着：你可以在没有该物体任何观测的情况下开始优化，只需要一张文本和一台能跑扩散模型的机器。

但「借」是有利息的。2D 扩散模型是在单张图上训练的，它的评分函数定义在单图分布上，对「一组图是否属于同一个 3D 物体」没有任何概念。SDS 每次迭代随机采一个相机 c，独立地让 2D 先验给这一张图打分，然后把梯度回传。不同相机之间没有共享的约束项，没有跨视图的注意力，没有几何一致性损失。于是优化过程等价于让每个视角各自找一个「局部合理」的解，而这些局部解不必拼成一个整体。

三 · 胎记：Janus 与过饱和是怎么长出来的

把上面的机制推到底，就能预测失败模式，而不是事后解释。设相机分布 p(c) 在正面密集、背面稀疏。正面视角的梯度会把正面的几何与纹理推向「像孔雀」，背面视角偶尔被采样时，2D 先验看到的是一张它没见过的、信息不足的图，它给出的修正方向更弱、更模糊，甚至被正面已经成形的结构带偏。结果是正面精细、背面塌陷或长出与正面矛盾的第二个头——这就是 Janus 问题，两张脸。它不是调参失误，而是「每个相机独立打分、视角间无一致性约束」这一机制的直接产物。

过饱和是另一个可预测的产物。Classifier-free guidance 的尺度拉高时，扩散模型的条件得分被放大，采样结果更贴文本，但分布被推离训练分布，颜色饱和度上升、纹理细节被过度强化。SDS 把这个放大的得分直接当梯度用，等于在每次更新中都朝「更贴文本、更远离自然图像分布」的方向多走一步。多步累积后，颜色过饱和、纹理粘在一起、表面出现高频噪声。工程上的表现是：CFG 调高，文本贴合度上升，但资产的物理合理性下降；CFG 调低，颜色正常但语义漂移。

还有一个更隐蔽的失败模式：方差。SDS 的梯度是蒙特卡洛估计，每次只采一个 t 和一个 ε，单步梯度噪声很大。噪声本身不可怕，可怕的是它与视角采样耦合——不同相机采到的 t 不同，梯度尺度不同，优化轨迹在参数空间里抖动。抖动在低维参数（比如整体颜色）上表现为震荡，在高维参数（比如高频纹理）上表现为伪影累积。这解释了为什么 SDS 优化出来的资产常常「远看像、近看脏」。

失败模式机制来源工程表现
Janus 双面相机独立打分，无跨视图约束正面/背面结构矛盾
颜色过饱和CFG 放大得分，分布外推饱和度异常、纹理粘连
高频伪影单样本蒙特卡洛梯度方差近看脏、表面噪声
背面塌陷相机分布不覆盖背面几何缺失或模糊

一个具体例子足以说明相机分布的决定性。若相机只绕正面 ±60° 旋转，背面从未被渲染，那么背面参数从未收到任何梯度，它保持初始化状态——通常是一团模糊的低密度区域。导出网格时，背面要么是破洞，要么是被正面结构外推出来的错误闭合。这不是「优化不充分」，而是「监督从未到达」。反过来，若相机均匀覆盖全球，背面会收到梯度，但每个视角仍然独立打分，Janus 风险不降反升：两个视角都能自圆其说，却没有一项损失要求它们说的是同一个物体。

四 · 工程补丁的形状：从 SDS 到家族

SDS 家族的方法差异，本质上是对上述三类胎记的不同补法，而不是对 SDS 公式的否定。理解这一点，比记住方法名单更重要。

SJC 的思路是把渲染图拉回扩散模型的训练分布。它用加噪与 PAAS（Perturbed-Attention Score）一类手段，让得分估计落在模型见过的噪声等级上，减少分布外推带来的过饱和与方差。它补的是「得分不可信」这一项，但没有引入跨视图约束，Janus 仍在。

Magic3D 的思路是分阶段降维：先用粗 NeRF 快速定下大形与语义，再用 DMTet 做高分辨率细节精修。粗阶段用低分辨率渲染，梯度便宜、视角覆盖容易做全；精修阶段在已有几何上做局部细化，搜索空间小。它补的是「高分辨率下 SDS 方差爆炸」这一项，代价是两阶段调参和阶段间的误差传递——粗阶段定错的大形，精修阶段很难纠正。

VSD 的思路是把「单点」换成「分布」。它引入一个粒子模型来近似当前 3D 分布，用粒子模型与 2D 先验的得分差来修正梯度。这直接针对 SDS 的过饱和与多样性塌缩：SDS 把每个样本都推向条件分布的众数，VSD 则让样本在分布内散开。代价是粒子成本——每个粒子都要渲染、加噪、前向，算力随粒子数线性上涨。

ISM 的思路是降方差。它用 DDIM 反演构造一个区间得分，把「从噪声到图像」的整条轨迹上的得分累积起来，而不是只取单点 t 的估计。单步蒙特卡洛的方差被区间平均压下去，几何更稳。代价是反演本身的计算量与实现复杂度：反演要求可逆的采样过程，工程上要小心数值误差累积。

Fantasia3D 的思路是解耦。它把几何与外观分开优化，避免纹理「掩盖」几何错误——SDS 的一个隐蔽问题是，2D 先验可以被高频纹理解释掉，于是几何的缺陷被纹理补偿，表面看起来对但形状是错的。解耦后几何只由几何项监督，纹理只由外观项监督。代价是两阶段之间的耦合误差：几何阶段的偏差会限制外观阶段的上限。

TextMesh 直接优化网格，把表示从隐式场换成显式三角面，省去等值面提取的误差与时间。DreamGaussian 用 3DGS 作为表示，把优化时间压到分钟级——高斯泼溅的光栅化比体渲染快，梯度回传便宜，但它对几何的约束弱，导出的网格往往粗糙，需要后续精修。LucidDreamer 用区间得分稳几何，与 ISM 同源，针对的是几何抖动。

把这些补丁排成一条线，能看到一个清晰的工程判断：每个方法都在用额外结构换某一项失败模式的缓解，而没有一项能同时消掉全部三项。相机覆盖、CFG 尺度、w(t) 权重、步数，这四个旋钮的调节顺序本身就是对胎记的排序——先保证监督到达所有视角，再控制分布外推，再平衡高低频，最后才谈收敛步数。顺序错了，后面所有调参都是在补偿前面的结构性缺陷。

五 · 这一卷要盯住的那条边界

把 SDS 放在全书结构里看，它的位置是「没有 3D 数据时最便宜的路径」，而不是「文本到 3D 的终局」。第六卷的多视图扩散会换一种监督：不是让 2D 先验逐视角独立打分，而是直接生成一组彼此一致的多视图图像，把一致性写进生成过程本身。第七、八卷的前馈工厂则换另一种：用大规模 3D 数据训练一次前向网络，把推理成本压到单次前向。这两条路都在回应 SDS 暴露出的同一个结构性缺口——一致性必须显式建模。

这不是一句口号，而是一个可检验的机制判断。SDS 的梯度里没有任何一项同时依赖两个相机：∇θL 对每个 c 独立求期望，跨视图的信息只在参数 θ 里间接汇合，而 θ 是一个共享的表示，它没有被告知「这两个视角必须属于同一物体」。要让一致性显式化，要么在损失里加跨视图项（比如多视图渲染后互相做光度或特征一致性），要么在生成过程里让多个视图共享注意力（多视图扩散），要么在数据里让模型见过「同一物体的多视图」（前馈重建模型）。三条路都要求额外的结构，而结构都要付费：跨视图损失要多次渲染，多视图扩散要改网络与采样，前馈模型要 3D 数据。

所以这一卷要记住的不是「SDS 过时了」。SDS 仍然是没有 3D 数据时最便宜的入口，它的公式简单到可以在几十行代码里实现，它的监督来源广到可以覆盖任意文本描述。它的偏差也不是缺陷清单，而是一张地图：它精确地标出了「有偏的 2D 先验 + 工程补丁」能走多远，以及在哪一步必须换工具。当你的任务要求背面也讲得通、要求多视角一致、要求资产能进引擎重光照，SDS 的补丁就会撞到天花板；这时需要的不是继续调 CFG，而是换监督结构。

回到那个下午的孔雀。用 SDS，你会在几十分钟内得到一个正面像孔雀、背面可能是另一只孔雀的东西，颜色偏青铜但饱和过头，导出网格有高频噪声。它可用作概念稿，不可用作最终资产。这个判断不来自实验数字，而来自公式本身：每个随机相机独立地让 2D 先验打分，视角之间没有一致性约束。只要这一行公式不变，Janus 的风险就在；只要 CFG 放大得分，过饱和的风险就在；只要梯度是单样本蒙特卡洛，方差就在。工程的下一步不是把这三个风险调小，而是决定哪一个必须被结构性地消除——而这个决定，正是后面几卷的分岔口。
