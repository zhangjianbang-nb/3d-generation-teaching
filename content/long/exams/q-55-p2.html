一 · 变体一：把「堆量不涨点」换成「堆量涨点但涨得不对」

第一个变体把原题的因果方向调转：不再问「为什么不涨」，而是给定一个「指标确实在涨」的观测，问涨的是不是真能力。这个变体的杀伤力在于，它逼答题者区分「评测分数上升」与「模型能力上升」两件事。原题里「评测集与训练集分布重叠导致虚高」只是一条并列原因，在变体里它被提升为主线索。

具体机制是分布重叠的三种形态。其一是资产级重叠：同一个三维资产以不同文件格式、不同简化级别、不同纹理分辨率在多个公开数据集中反复出现，训练集与评测集各自抽到同一资产的不同副本，模型在评测时实际上是在做近邻检索而非泛化。其二是类别级重叠：评测集的类别词表被训练集的类别长尾完全覆盖，且评测采样偏向头部类别，于是分数反映的是头部类别的拟合度。其三是视角级重叠：渲染评测时使用的相机方位角、仰角、焦距分布与训练渲染管线一致，模型学到的是「这个渲染器下的这个视角」的先验，换渲染器或换视角采样策略分数即塌。

可以用一个去重后的有效样本量来刻画第一类问题。设原始资产集合为 $A$，按几何哈希与纹理感知哈希做等价类划分，得到等价类集合 $\{C_i\}$，则有效规模为

$$N_{\text{eff}}=\sum_{i}\mathbf{1}\left[\left|C_i\right|\ge 1\right]\cdot w\left(\left|C_i\right|\right),\qquad w(n)=\frac{1}{1+\log n}$$

其中 $w(n)$ 对重复度高的等价类降权。这个式子的工程含义是：名义规模 $|A|$ 与有效规模 $N_{\text{eff}}$ 之间可以差出一个数量级，而论文里报告的往往是前者。系统代价在于，等价类划分本身需要跨数据集的全量比对，几何哈希对非刚性变形与拓扑改动不稳健，纹理感知哈希对重光照与重烘焙敏感，做严了会把合法变体误判为重复，做松了漏掉大量近似副本；这条流水线的算力与人工复核成本常常超过训练本身。

具体例子：某次三维资产生成评测中，训练侧混入了与评测集同源但经过减面与重拓扑处理的副本，评测 Chamfer 距离显著优于同架构的干净基线，但把评测集替换为独立采集的扫描数据后优势消失。这个例子不需要具体数字，它说明的是：变体题要求答题者把「涨点」拆成「涨在哪个分布上」，并给出可执行的去重与分布审计手段，而不是笼统地说「要注意数据质量」。

二 · 变体二：把 2D 与 3D 的对比换成「2D 预训练能否替代 3D 数据」

第二个变体问：既然 3D 数据采集难、许可乱，能否用大规模 2D 图像预训练来补足，从而绕开 3D 数据的规模瓶颈？这是一个典型的迁移学习追问，答题者若只回答「可以/不可以」而不给出表示层面的分析，就会被判为答非所问。

机制上要区分两种迁移。第一种是表征迁移：2D 编码器提供的是以像素网格为定义域的多尺度特征，它对遮挡、光照、材质有强先验，但缺少显式的三维几何约束。把它接到三维生成管线时，通常作为多视图渲染的条件编码器或作为神经场的特征蒸馏源，此时 2D 先验提供的是「外观合理性」，不提供「几何可闭合性」。第二种是监督迁移：用 2D 图像的单目深度、法线、分割等中间任务作为辅助损失，把几何信号以弱监督形式注入。这条路径的代价是中间任务的标注偏差会被继承，单目深度在透明、反光、薄结构上系统性失准，而这些恰是三维资产质量分级的重点区域。

可以用一个损失分解来表达这种混合监督的取舍：

$$\mathcal{L}=\mathcal{L}_{\text{3D}}+\lambda_1\mathcal{L}_{\text{mv}}+\lambda_2\mathcal{L}_{\text{depth}}+\lambda_3\mathcal{L}_{\text{reg}}$$

其中 $\mathcal{L}_{\text{mv}}$ 是多视图一致性损失，$\mathcal{L}_{\text{depth}}$ 是单目深度蒸馏，$\mathcal{L}_{\text{reg}}$ 是几何正则（如法线平滑、水密性惩罚）。系统代价在于，$\lambda$ 的调节不是超参搜索问题而是数据配比问题：当 3D 监督稀少时，$\mathcal{L}_{\text{mv}}$ 会主导优化，模型倾向于生成「从多数视角看都对、但拓扑不闭合」的资产，这类资产在下游仿真、碰撞检测、3D 打印中直接不可用，而在渲染评测中分数很高。这就是典型的失败模式：指标与可用性脱钩。

具体例子：一个以多视图渲染损失为主、3D 监督为辅的生成器，在渲染评测上表现稳定，但导出为网格后存在大量非流形边与自相交面，需要额外的重网格化与布尔修复才能进入资产库。这个例子说明 2D 预训练能补「外观规模」，补不了「几何规模」，而后者恰恰是 3D 数据 scaling 的核心稀缺项。答题者若能把「补什么、不补什么」讲清，这一变体就拿住了。

三 · 变体三：把「数据 scaling」换成「表示统一是否等价于数据 scaling」

第三个变体针对参考答案里「表示统一」这一条：如果把网格、点云、神经场统一到一种中间表示，是否等于变相扩大了数据规模？这是一个把数据工程问题转化为表示工程问题的追问，考察答题者是否理解「统一表示」的收益与信息损失。

机制上，统一表示通常走三条路：其一是体素化或稀疏体素，把连续几何离散到规则栅格，收益是卷积友好、易于批处理，代价是分辨率与显存的三次方关系，薄壳与细结构在低分辨率下丢失；其二是隐式场采样，把资产转成带符号距离或有向距离的采样点集，收益是与神经场管线同构，代价是采样策略引入的偏差，靠近表面的采样密度决定了几何保真度；其三是多视图加几何缓冲，把资产渲染成带深度与法线的视图集合，收益是直接复用 2D 主干，代价是视角覆盖不全导致的背面缺失。三条路都不是无损的，统一表示的过程本身就是一次有损压缩，压缩率决定了「统一后规模」的真实增量。

可以用一个信息保留率来刻画：设原始资产在统一表示下的重建误差为 $\epsilon$，质量分级阈值为 $\tau$，则只有满足 $\epsilon\le\tau$ 的样本才计入有效规模，

$$N_{\text{unify}}=\left|\left\{a\in A:\ \epsilon\left(a\right)\le\tau\right\}\right|$$

系统代价在于，$\epsilon$ 的估计需要参考重建管线，而参考管线本身有偏；对薄结构、开放曲面、内部空腔，体素与隐式采样的误差分布差异极大，用单一阈值会把某一类资产系统性排除，造成类别分布的二次偏斜。失败模式是：统一表示后训练集在数值上变大，但类别多样性反而下降，长尾类别被压缩阈值筛掉，模型在长尾上的表现比统一前更差。

具体例子：把一批含薄壁与镂空结构的资产统一到中等分辨率稀疏体素后，薄壁在栅格化时被并入实体，重建误差超过阈值而被剔除，最终训练集只剩实心块状资产，生成器对镂空结构的建模能力退化。这个例子说明「表示统一」不是免费的规模扩张，它是一次带类别偏见的过滤，答题者必须把过滤准则与多样性保护一起讲，否则这一变体只能拿到一半分。

四 · 五个追问：从数据来源追到评测协议

追问一：3D 数据的「许可乱」具体乱在哪一层？要点是区分资产版权、扫描数据的使用授权、以及衍生表示的再分发权。同一资产在原始网格上许可宽松，但其扫描纹理可能来自受限制的摄影测量，转换到神经场表示后是否构成衍生作品在实务中并无统一答案。答题者若只说「注意许可」而不指出许可在表示转换处断裂，就是空答。

追问二：类别长尾在 3D 里为什么比 2D 更严重？机制是 3D 资产的类别分布由采集场景决定，室内扫描天然偏向家具与房间结构，工业件与生物形态稀缺，而 2D 互联网图像的长尾至少还有大量用户生成内容托底。追问的落点是：长尾不能靠堆量解决，只能靠定向采集或合成，而定向采集的单位成本远高于 2D。

追问三：质量分级用什么信号？可用的信号包括拓扑健康度（流形性、自相交、法线一致性）、UV 与纹理的有效覆盖率、尺度与朝向的规范性、以及渲染一致性。追问的落点是：这些信号彼此不完全相关，单一分数会把「拓扑好但纹理差」与「纹理好但拓扑烂」混为一谈，分级必须是多维的而非标量。

追问四：评测虚高如何被工程化地检测？手段是分布审计：对训练集与评测集做资产级近邻检索、类别词表覆盖比对、渲染参数分布比对。追问的落点是：审计要在训练前做，而不是在分数异常后再补，因为后者无法区分「模型强」与「泄漏」。

追问五：清洗的边际收益在哪里饱和？机制是清洗流水线的召回率与精确率权衡：去重越严，误删越多，有效规模先升后降；许可过滤越严，剩余类别越偏。追问的落点是：清洗强度存在一个由多样性约束决定的上界，超过上界后继续清洗只会加剧类别偏斜，而不是提升有效规模。

五 · 扣分点与常见错误：从「越多越好」到「泄漏不自知」

扣分点集中在两处，与原题评分标准一致：差异占一半，为何不涨点占一半。差异部分的扣分常见于只列「采集难、格式杂」而不落到表示层，例如没有指出 2D 的像素网格是天然统一表示而 3D 没有对应物；或只提「标注贵」而不区分几何标注、语义标注、物理属性标注的成本结构差异。为何不涨点部分的扣分常见于把四条原因并列罗列而不建立优先级，尤其是没有把「评测泄漏」从「数据质量」中独立出来。

错误类型典型表述为何扣分纠正方向
规模万能论数据越多模型一定越好忽略有效规模与重复度引入去重后的有效样本量
许可盲区公开数据集可以直接用忽略表示转换处的许可断裂按资产、纹理、衍生表示分层审许可
泄漏不自知分数高说明方法好未做训练评测分布审计训练前做近邻与类别覆盖比对
长尾忽视堆量能覆盖所有类别采集场景决定类别分布定向采集或合成补长尾
分级标量化用一个质量分筛数据多维质量信号不可合并拓扑、纹理、尺度分开分级

这些错误的共同结构是：把数据工程当成采购问题而非表示与分布问题。工程判断上，一个可执行的检查清单是：先算有效规模再看名义规模，先审许可断裂再看可用性，先做分布审计再看分数，先看类别覆盖再看总量。四步顺序不能颠倒，因为后一步的结论依赖前一步的过滤结果。

六 · 教学建议：用可复算的小实验替代口头结论

教学上最有效的手段是让读者亲手复算一次有效规模与分布偏移，而不是记住结论。建议设计三个小实验。实验一：给定一个小型资产集合，要求学员实现几何哈希去重并计算 $N_{\text{eff}}$，观察名义规模与有效规模的差距，并讨论哈希粒度对误删率的影响。实验二：构造一个训练集与评测集存在资产级重叠的对照，要求学员在训练前用近邻检索检测重叠并报告检出率，体会「泄漏检测是训练前动作」这一工程纪律。实验三：对同一批资产分别做体素化与隐式采样，统计不同结构类型（薄壁、镂空、实心）的重建误差分布，让学员看到统一表示带来的类别偏斜。

讲授顺序建议从「差异」入手而非从「原因」入手：先让学员描述 2D 与 3D 在表示、采集、标注上的具体不同，再由这些不同推导出规模瓶颈，最后才引入评测泄漏这一非数据质量因素。这样安排的原因是，学员容易把「不涨点」全部归因于数据脏，而漏掉评测协议本身的问题；先建立表示层的直觉，再讲协议层，扣分点自然被覆盖。

评价学员答案时，建议采用两栏打分：左栏看是否给出了可执行的清洗与审计手段（去重准则、许可分层、分级维度），右栏看是否建立了原因之间的优先级与相互作用（例如许可过滤如何加剧类别偏斜，去重如何与长尾冲突）。只填满左栏的答案在「差异」上得分而在「为何不涨点」上失分，只填满右栏的答案反之。两栏都空而只复述题干者，按未作答处理。

最后落到一个具体机制上：3D 数据 scaling 的真正瓶颈不是采集总量，而是「在许可、表示、分布三重约束下可被有效计入训练的有效规模」，而这个量只能通过去重、许可分层、多维质量分级与训练前分布审计四道工序逐级估计出来；任何一道工序缺失，名义规模就会以虚高的形式进入论文与评测，而模型能力并不会随之上升。
