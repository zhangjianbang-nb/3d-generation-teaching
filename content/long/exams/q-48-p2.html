一 · 变体一：把“从前往后”改成“从后往前”

最直接的变体是把合成方向翻转：给定同一组采样点，要求写出从后往前的递推形式，并说明它与从前往后形式为何等价。参考公式 C=Σ_i T_i (1−exp(−σ_i δ_i)) c_i 中，T_i=exp(−Σ_{j<i} σ_j δ_j) 只累计 i 之前的遮挡，因此天然对应从前往后遍历：每到一个样本，先用当前累计透射率乘以该样本的不透明度 alpha_i=1−exp(−σ_i δ_i)，再把该样本的贡献累加进结果，最后用 exp(−σ_i δ_i) 衰减累计透射率。从后往前则需要把“前面挡了多少”改写为“后面还剩多少可见”，即维护一个从尾部开始累计的透射率，递推时先衰减再合成，索引方向与累乘顺序相反。

等价的代数依据是乘法的结合律与指数可加性：exp(−Σ_{j<i} σ_j δ_j) 可以拆成若干段指数的乘积，从前往后是逐步右乘，从后往前是逐步左乘，两种遍历得到的是同一组因子的不同结合顺序。工程上这不是纯数学游戏：从后往前合成在“已知不透明背景、需要做前景覆盖”的合成管线里更自然，例如把体渲染结果与已有不透明几何做深度合成时，从远到近的覆盖顺序与画家算法一致；而从前往后合成更适合早停（early termination），因为累计透射率一旦低于阈值就可以停止采样，省掉剩余样本的着色与求值。

系统代价体现在早停阈值的取舍上。设阈值为 ε，当 T_i<ε 时终止，则被丢弃的尾部贡献上界约为 ε 乘以剩余样本颜色的量级；ε 取太小则早停失效、采样成本回升，取太大则暗部与远景被系统性削掉，表现为背景发灰或高光边缘出现断层。一个具体例子是云层渲染：相机穿入云体后前几个样本的 σ 很大，T 迅速衰减，从前往后遍历在很短的区间内就能触发早停，而从后往前遍历必须先走完整个采样区间才能确定前端的遮挡，早停收益基本消失。变体题因此常追问“哪种遍历更适合你的场景”，答案取决于遮挡分布是否集中在前端。

伪代码思路可以写成两段对称的循环：从前往后版本维护 T 初值为 1，循环体内先算 alpha 再累加 T·alpha·c，最后 T←T·(1−alpha)；从后往前版本维护 T 初值为 1，循环体内先算 alpha，累加 T·alpha·c 后 T←T·(1−alpha)，但索引从 N−1 递减。注意两版中 alpha 的定义完全相同，差别只在累乘发生的时刻相对于累加的时刻，这一点在批改时是高频扣分点：不少答卷把从后往前版本的衰减写在了累加之前，导致第一个被处理的样本被错误地乘以了自身的不透明度衰减。

二 · 变体二：采样间隔不均匀时的离散化

原始公式默认 δ 是常数，但真实采样器几乎不会等距采样：分层采样、重要性采样、自适应细分都会产生不等长的 δ_i。变体题要求给出非均匀间隔下的合成公式，并说明为什么不能简单把 δ 提到求和号外。正确写法是把每个样本的 δ_i 与其 σ_i 绑定：alpha_i=1−exp(−σ_i δ_i)，T_i=exp(−Σ_{j<i} σ_j δ_j)，其中每一项的乘积都用自己的 δ_j。若把 δ 当作公因子提出，等价于假设所有区间等长，在密度沿视线剧烈变化时会产生系统性偏差：前端密集区间被低估、后端稀疏区间被高估，最终颜色向背景色偏移。

机制上，δ 是黎曼和中的区间宽度，σδ 是该区间内的光学厚度，exp(−σδ) 是该区间内的透射率。非均匀采样下，光学厚度是可加的：把一段长区间拆成两段短区间，透射率相乘等于原区间的透射率，这正是指数函数把加法变成乘法的性质。因此离散公式对任意分割都保持一致，只要每个子区间的 σ 取其代表值。这个性质是自适应细分能够安全工作的前提：细分只是改变了 δ 的划分，不改变物理量。

$$T_i=\exp\!\Big(-\sum_{j<i}\sigma_j\,\delta_j\Big),\qquad \alpha_i=1-\exp(-\sigma_i\,\delta_i)$$

系统代价出现在自适应细分的预算控制上。设总采样预算为 N，若在某区间反复二分，δ 变小、单样本的光学厚度变小、alpha 趋近于 σδ 的线性区，此时 1−exp(−σδ) 与 σδ 的相对误差随 δ 减小而减小，但样本数增加带来的求值成本是线性的。一个具体例子是体积雾中的高光边缘：密度梯度大的区域需要更小的 δ 才能避免 alpha 饱和造成的条带，而均匀区域可以用大 δ。若实现时把 δ 固定为全局常数，就会在梯度区出现明显的分层伪影，表现为同心环状的亮度跳变。

另一个失败模式是 δ 与 σ 的单位不一致。σ 通常以“每单位长度”定义，δ 必须以同一长度单位给出；若相机空间与世界空间存在缩放，δ 未随缩放调整，则光学厚度整体偏移，表现为雾的浓度随镜头距离整体变浓或变淡。批改时若答卷只写“δ 是采样间隔”而不说明它与 σ 的单位配对关系，通常只给部分分。

三 · 变体三：把 T 改写成“可见性”并处理背景项

第三个变体引入背景：场景中存在一个不透明的远景或环境光，要求把背景贡献并入合成公式，并解释 T 在其中的角色。标准做法是在求和之后追加一项 T_N·c_bg，其中 T_N=exp(−Σ_{j<N} σ_j δ_j) 是走完全部样本后剩余的透射率，c_bg 是背景颜色。这一项不是可有可无的装饰：当所有样本的 σ 都趋于零时，求和项消失，结果必须退化为 c_bg，否则渲染出的天空会变黑。T 在这里的物理含义仍然是“从相机到该处未被遮挡的概率”，只不过终点从第 i 个样本换成了背景平面。

机制上，背景项与前景项共享同一个透射率链条：第 i 个样本的贡献被前面所有样本衰减，背景的贡献被全部样本衰减。因此合成顺序必须是“先累加前景、再乘背景”，若把背景项写在循环内部，会导致背景被重复计入或被后续样本错误衰减。一个具体例子是体积光穿过窗口照射到远处墙面：墙面颜色作为 c_bg，窗口附近的尘埃样本作为前景，若背景项位置写错，墙面会在尘埃密集处出现不自然的增亮，因为背景被每个样本各加了一次。

系统代价是背景项对早停的影响。若启用早停，T 降到阈值以下时循环终止，此时剩余透射率已接近零，背景项可以安全省略；但若阈值取得偏大，省略背景项会让远景整体偏暗，而保留背景项又需要把 T 的实际值传出去，增加了接口复杂度。工程判断是：早停阈值应与背景项是否保留一起决定，二者不能独立调参。另一个失败模式是把 T 当作“透明度”直接用于 alpha 混合：T 是透射率，表示光能穿过的比例，而 alpha 混合中的不透明度是 1−T，二者互为补数，混用会导致前景与背景的权重颠倒。

变体题常要求写出“T 趋近于 0 和趋近于 1 两个极限下的行为”。T→0 时前景完全遮挡，结果趋近于前景颜色的加权和，背景项消失；T→1 时无遮挡，结果趋近于 c_bg。这两个极限是检查公式符号错误的最快手段：若答卷在 T→1 时结果仍带有前景贡献，说明漏乘了 (1−exp(−σδ)) 因子或把 T 与 alpha 弄反。

四 · 五个追问：从公式到实现细节

追问一：为什么用 1−exp(−σδ) 而不是 σδ 作为不透明度？回答要点是指数形式来自比尔–朗伯定律的积分，σδ 只是光学厚度的一阶近似；当 σδ 较大时线性近似会超过 1，产生负透射率，而指数形式天然落在 [0,1]。追问二：T 与 alpha 的关系是什么？T 是透射率、alpha 是不透明度，alpha=1−T 仅在单区间意义下成立，跨区间时 T 是多个 (1−alpha) 的连乘。追问三：σ 的量纲与颜色 c 的关系？σ 是每单位长度的消光系数，c 是单位光学厚度上的辐射贡献，二者相乘再乘 δ 才得到该区间的颜色增量。追问四：为什么合成必须从前往后而不能随意顺序？因为 T_i 依赖所有 j<i 的累计，顺序改变会改变“谁遮挡谁”的因果结构。追问五：离散公式在 δ→0 时是否收敛到连续积分？是，因为 alpha≈σδ、T 的乘积取对数后趋于积分，这正是黎曼和的极限。

每个追问都对应一个可观测的失败模式。追问一若答错，实现中会出现 alpha 大于 1 的截断，表现为高密度区域颜色饱和成纯色块；追问二若答错，混合时会用 T 直接乘前景色而漏掉背景权重，表现为背景透过前景“泄漏”；追问三若答错，会把 σ 当成颜色直接参与插值，导致密度场与颜色场耦合、调参时浓度与色调无法分离；追问四若答错，会出现前后景贡献互换，典型现象是近处物体被远处雾“染”上颜色；追问五若答错，会在自适应细分时认为细分不改变结果，从而跳过必要的收敛检查。

追问的评分权重通常低于主公式，但它们是区分“背下公式”与“理解机制”的分水岭。一个具体例子是：答卷能写出 C=Σ T_i alpha_i c_i，却在追问二中说“T 就是透明度”，这种自相矛盾在判分时应扣掉 T 含义部分的分，因为主公式里的 T 与 alpha 是两个不同因子，混为一谈说明并未真正理解连乘结构。

五 · 扣分点与常见错误清单

扣分点按评分标准拆成两半：公式 50%、T 含义 50%。公式侧的扣分点包括：漏写 δ（写成 exp(−σ) 或 alpha=1−exp(−σ)）；把求和写成积分却未说明离散化；把 T_i 写成 exp(−σ_i δ_i) 而漏掉 j<i 的累计；把 alpha 写成 σδ 而未取指数；合成顺序写成从后往前却未调整衰减时刻。T 含义侧的扣分点包括：把 T 说成透明度或不透明度；把 T 说成“被遮挡的概率”而非“未被遮挡的概率”；把 T 与 alpha 的关系说成恒等而非互补；未说明 T 随距离单调不增。

错误写法错在哪可观测后果
T_i=exp(−σ_i δ_i)漏掉前面所有样本的累计远处物体不被近处雾衰减，景深错乱
alpha=σδ线性近似，未取指数高密度区 alpha>1，颜色截断成色块
T 即透明度与 alpha 互补关系颠倒前景背景权重互换，背景泄漏
漏写 δ光学厚度缺区间宽度浓度随采样密度变化，调参失效
σ 当颜色密度与辐射混淆浓度与色调耦合，无法独立调节

常见错误里最隐蔽的是“漏掉 δ 但数值上仍能跑通”。当 δ 被固定为 1 时，漏写 δ 与写对 δ 在数值上完全一致，测试用例无法暴露；一旦采样器改为非均匀间隔，浓度就会随采样密度漂移，表现为同一场景在不同分辨率下雾的浓淡不同。这类错误在批改时应要求答卷明确写出 δ 的定义与单位，而不是只看公式外形。另一个隐蔽错误是把 T 的初值写成 0 而非 1：T 是透射率，起点必须是全透过，写成 0 会让所有前景贡献归零，只剩背景项。

系统代价层面，扣分点往往对应真实的性能或画质缺陷。例如把 alpha 写成 σδ 的实现，在密度场做插值时会在区间边界产生不连续，因为线性近似在 δ 跳变处不满足乘法可加性；而正确写法下，透射率的连乘性质保证了任意细分下结果一致，这正是自适应采样能够安全提速的代数基础。工程判断是：公式外形正确只是及格线，能否说清每个因子在细分、早停、背景合成三种操作下的行为，才是满分与良好的分界。

六 · 教学建议：从符号到可运行的心智模型

教学上应先建立“光学厚度可加、透射率可乘”的心智模型，再引入公式符号。具体做法是让学生手算三个样本的合成：给定 σ=(0.5, 2.0, 0.1)、δ=(0.2, 0.2, 0.2)、c=(1, 0, 0)，先算每个 alpha，再逐步更新 T，最后核对 T 是否单调下降、结果是否落在 [0,1]。这个手算例子能同时暴露漏 δ、漏累计、T 初值错误三类问题，且不需要任何渲染器。第二步是让学生把同一组数据改成非均匀 δ，验证结果对分割不变，从而理解 δ 必须与 σ 配对。

第三步是引入早停与背景项的对照实验：同一场景分别开启和关闭早停，观察远景亮度差；再把背景项写在循环内外各一次，观察是否出现重复计入。教学建议强调“先写对再写快”：早停是优化，若在公式未写对时引入早停，会把公式错误掩盖成画质问题，学生难以定位。第四步是让学生用“T→0 与 T→1”两个极限自检公式，这是成本最低的正确性检查。

评分演练应与扣分点一一对应：给出若干答卷片段，让学生按公式 50%、T 含义 50% 打分，并说明扣分依据。典型片段包括“T 是透明度”“alpha=σδ”“漏写 j<i”三种，分别对应 T 含义、公式、公式三处扣分。教学上要强调扣分不是文字游戏：把 T 说成透明度，在实现中就会写出 1−T 的混合权重，这是可运行代码里的真实 bug，而不是术语口误。最后应要求学生用一句话说清“T 是从相机到该处未被遮挡的概率，alpha 是该区间的不透明度，二者互补但不等同”，这句话能同时覆盖主公式与追问二的核心。

对工程背景的读者，教学落点应放在“公式的每个因子都对应一次可观测的操作”：δ 对应采样器的区间划分，σ 对应密度场的查询，exp 对应透射率衰减，累乘对应遍历顺序，背景项对应合成管线的末端。任何一个因子写错，都能在渲染结果里找到对应的伪影类型。这种“符号—操作—伪影”的三元映射，比背诵公式更能支撑后续的变体题与追问。
