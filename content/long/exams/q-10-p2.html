一 · 变体一：把 SDS 写成“逐视角得分之和”

第一个变体题把参考答案里的期望写成显式的求和形式：给定一组随机采样的相机位姿 {c_i}，SDS 损失近似为每个视角的 2D 得分项之和，梯度则是这些项对参数的雅可比回传之和。写成公式是

$$\nabla_\theta L_{\text{SDS}} \approx \frac{1}{N}\sum_{i=1}^{N} w(t_i)\,\big(\varepsilon_\phi(x_t^{(i)};y,t_i)-\varepsilon^{(i)}\big)\,\frac{\partial x^{(i)}}{\partial \theta}$$

这里 x^{(i)} 是相机 c_i 下渲染出的图像，ε^{(i)} 是该视角独立采样的噪声，t_i 是各视角独立采样的扩散时间步。这个变体的考点不在公式外形，而在于它把“期望”拆成了可数的样本，从而暴露一个机制事实：求和号内部没有任何跨视角的耦合项。每个加数只依赖自己那一个视角的图像和噪声，梯度回传时也只经过自己那条渲染雅可比链。换句话说，损失函数的计算图是 N 条互不相连的分支，只在参数 θ 处汇合。汇合点共享的是同一套几何与外观参数，但每条分支给出的下降方向是各自独立的“让这个视角更像 2D 先验”的方向，没有任何一项在惩罚“视角 A 的结构与视角 B 的结构不一致”。

这个变体的评分重点在于能否指出：即便 N 趋于无穷、覆盖整个视角球面，逐视角得分之和仍然不等于一个 3D 一致性目标。原因是对每个视角取期望后得到的是边缘分布层面的匹配，而不是联合分布层面的匹配。用公式语言说，SDS 优化的是 ∏_i p_φ(x^{(i)}|y) 的对数对 θ 的梯度，而一个真正的 3D 先验应当优化 p_φ({x^{(i)}}|y)，后者含有跨视角的互信息项。缺少互信息项，就是“两张脸”在目标函数层面的根源。系统代价方面，这个变体还引出一个工程后果：N 越大，单步训练的计算量线性增长，因为每个视角都要跑一次 2D 扩散网络的前向与反向，显存里同时驻留 N 份 x_t 与激活。实践中把 N 压到很小（例如每步只采一两个视角）正是 Janus 高发的原因之一，因为参数在两次更新之间被拉向互相冲突的方向。

具体例子：假设某一步采样到正面相机 c_1 与背面相机 c_2。正面分支的梯度把参数推向“在正面长出五官”，背面分支的梯度把参数推向“在背面也长出五官”。由于两条分支共享 θ，参数更新是两者之和，几何体在正反两面都被加上类似五官的凸起与纹理，而没有任何一项梯度去惩罚“一个头不该有两套五官”。训练若干步后，渲染正面像脸、渲染背面也像脸，损失却很低，因为每个视角单独看都符合 2D 先验。

二 · 变体二：加入 CFG 后的梯度与“缓解不根治”

第二个变体要求在 SDS 梯度里显式写出无分类器引导（CFG）的项，并解释为什么提高引导系数不能消除多面。带 CFG 的噪声预测通常写成

$$\hat{\varepsilon}_\phi(x_t;y,t)=\varepsilon_\phi(x_t;\varnothing,t)+s\,\big(\varepsilon_\phi(x_t;y,t)-\varepsilon_\phi(x_t;\varnothing,t)\big)$$

把它代入 SDS 梯度，得到的是两项噪声预测之差的线性组合再乘渲染雅可比。机制上，CFG 做的是在“无条件预测”和“有条件预测”之间做外推，放大条件方向上的差异，让样本更贴合提示词。它改变的是每个视角内部的条件强度，不改变视角之间的耦合结构。也就是说，CFG 作用在求和号内部的单个加数上，而 Janus 的成因在求和号外部——缺少跨视角一致性项。因此提高 s 只会让每个视角更“用力地”贴合提示词，正面更像个正脸、背面更像个后脑勺上的脸，冲突反而可能被放大而非消除。

系统代价上，CFG 让每步的 2D 网络前向次数翻倍（有条件与无条件各一次），显存与算力开销上升；当 s 调得过高，单视角图像会出现过饱和、纹理过锐、几何过度外扩，这些伪影经雅可比回传后会污染 3D 参数，表现为几何表面出现高频噪声或颜色溢出。这是一个典型的失败模式：训练损失下降，但渲染结果的几何质量变差。评分时，能否说清“CFG 是逐视角的条件锐化，不是跨视角的一致性约束”是这一变体的核心判分点。

具体例子：把 s 从常规值提高到较大值，正面视角的提示词“一张脸”被强化，背面视角若也被采到并给出相似提示，背面同样被强化出五官；由于两个视角的梯度都变强，参数被更快地拉向“两面都有脸”的折中解。工程判断是：CFG 属于单视角质量旋钮，多面问题要靠多视图先验或跨视角一致性损失来处理，二者不在同一层。

三 · 变体三：把 ∂x/∂θ 拆成几何与外观两条链

第三个变体追问渲染雅可比 ∂x/∂θ 的内部结构：当 θ 同时包含几何参数（顶点位置、密度场、形变）与外观参数（颜色、法线、材质）时，这一项应当拆成两条偏导链。用链式法则写成

$$\frac{\partial x}{\partial \theta}=\frac{\partial x}{\partial G}\frac{\partial G}{\partial \theta_g}+\frac{\partial x}{\partial A}\frac{\partial A}{\partial \theta_a}$$

其中 G 是几何中间量（例如射线上的采样点位置、表面法线），A 是外观中间量（例如着色网络的输出）。机制上，SDS 的噪声预测误差是一个标量（或每像素一个残差），它通过这两条链分别把“形状不对”和“颜色不对”的信号回传。几何链的梯度会移动表面，使渲染图的轮廓与 2D 先验的轮廓对齐；外观链的梯度会改颜色，使纹理统计量接近先验。两条链共享同一个残差，因此存在信用分配问题：残差究竟该归咎于形状还是颜色，SDS 本身并不区分。

这个变体暴露的系统代价是几何与外观的耦合震荡。若外观链学习过快，模型可以用颜色去“补偿”形状错误，例如用暗色阴影伪装出凹陷，使单视角残差变小，但几何本身没有修正；一旦换视角，补偿失效，残差反弹。失败模式表现为：训练损失在某视角上很低，换一个相机就崩。具体例子是正面的五官既可以用几何凸起实现，也可以用纹理贴图伪造，SDS 对两者一视同仁，于是参数可能选择更省力的纹理方案，导致侧面看时五官是“画上去的”而非“长出来的”，这正是多面问题在几何—外观耦合层面的一个变体表现。

评分上，能否指出“∂x/∂θ 不是单一标量，而是几何与外观两条链的叠加，SDS 不提供信用分配”是这一变体的关键。工程上常见的应对是给几何链与外观链设置不同的学习率，或分阶段训练（先几何后外观），但这只是调参层面的缓解，不改变 SDS 目标本身缺少 3D 一致性的本质。

四 · 五个追问：从公式到系统边界

追问一：SDS 的期望是对什么取的？答案是同时对相机位姿、扩散时间步 t、注入噪声 ε 取期望。三者独立采样，意味着每次更新面对的是一个随机视角、随机噪声水平的 2D 打分器。这个随机性本身是一种正则，让参数不至于死盯一个视角，但它不构成一致性约束——随机采样只是让冲突在不同步之间轮换出现，而不是消除冲突。

追问二：w(t) 的作用是什么？它是时间步权重，调节不同噪声水平下残差的相对重要性。机制上，不同 t 对应不同尺度的结构：高噪声对应粗粒度布局，低噪声对应细节纹理。权重设计决定了梯度里“大形状”与“小细节”的比例。若权重偏向低噪声，细节先被拟合，粗粒度几何可能长期不一致；若偏向高噪声，布局先定，细节后补。这是一个超参数层面的取舍，与多面问题正交，但会影响多面出现的早晚与形态。

追问三：为什么说 SDS 不是 3D 真值？因为 ε_φ 是在 2D 图像上训练的噪声预测网络，它的输入是单张渲染图加文本条件，输出是对该图噪声的估计。它从未见过这个 3D 物体的多视图联合分布，也没有能力判断“正面与背面是否属于同一物体”。SDS 把这个 2D 打分器的梯度当作伪监督，伪监督的正确性只在单视角意义上成立。

追问四：多视图先验能根治吗？不能。多视图先验把若干视角的图像同时送入一个能感知视角关系的网络，让打分器在训练时见过跨视角相关性，从而在梯度里引入弱耦合。它缓解 Janus，因为打分器开始“记得”背面应与正面协调；但耦合是统计性的、软性的，不是硬约束，遇到训练分布外的视角组合仍可能失效。系统代价是多视图网络更大、每步要渲染并编码多个视角，显存与算力显著上升。

追问五：如果给损失加一个显式的跨视角一致性项会怎样？这已经超出 SDS 的定义，属于在 SDS 之外加正则。机制上它直接惩罚不同视角渲染结果在重叠区域的差异，或惩罚几何在多视图下的重投影误差。代价是需要可微渲染支持多视角联合优化，且一致性项的权重难以平衡——权重过大压制单视角细节，权重过小不起作用。这说明“根治”需要改变目标函数的结构，而不是调 SDS 内部的旋钮。

五 · 扣分点与常见错误对照

评分标准给的是公式 50%、多面机制 50%，扣分点集中在四处：SDS 梯度公式写错或漏项；没有把 2D 得分与渲染雅可比串起来；没有从逐视角独立推到 Janus；把 CFG 或随机相机当成根治手段。下表把常见错误与对应的扣分逻辑对齐，便于阅卷时快速定位。

常见错误错在哪扣分归属
把 SDS 当成 3D 监督误认为 ε_φ 提供 3D 真值，忽略它只是 2D 图像先验机制部分
漏掉 ∂x/∂θ只写噪声残差，没写残差如何经渲染回传到参数公式部分
以为提高 CFG 能解决多面把逐视角条件锐化误当成跨视角一致性机制部分
把随机相机当成一致性来源随机采样只轮换冲突，不产生耦合项机制部分
公式里丢掉 w(t)忽略时间步权重对梯度尺度的影响公式部分

其中“漏掉 ∂x/∂θ”是最典型的公式扣分：只写 ε_φ−ε 等于把 SDS 描述成一个图像空间的损失，而 SDS 的关键恰在于这个残差要穿过渲染器回到 3D 参数。没有雅可比，梯度无从定义。“把 SDS 当成 3D 监督”则是最典型的机制扣分：一旦这样理解，就无法解释为什么单视角都对、合起来却长出两张脸。两类错误往往同时出现，因为把 2D 打分误当 3D 真值的人，通常也不会在意残差如何回传。

还有一个隐性扣分点是“只定性说多面，不给机制链”。完整机制链应当是：随机相机 → 每个视角独立打分 → 求和号内无耦合 → 参数被拉向互相冲突的方向 → 正面与背面各自合理但互不相容。缺任何一环，机制部分都难以拿满。具体例子可以举 Janus：正面渲染符合“一张脸”的提示，背面渲染也符合，但两者不是同一个头，这正是机制链末端的可观察现象。

六 · 教学建议：把“两张脸”讲成计算图问题

教学上最有效的切入不是先讲公式，而是先画计算图：N 条从相机到渲染图、再到 2D 网络、再到残差的分支，全部汇合到同一组 θ。让读者亲眼看到分支之间没有横线相连，Janus 就不再是玄学，而是计算图拓扑的直接后果。随后再把每条分支写成 w(t)(ε_φ−ε)∂x/∂θ，公式就有了落脚点。这个顺序能把“公式 50% + 机制 50%”的评分结构对应到讲解结构上：图讲机制，式子讲公式。

第二个建议是让学生亲手做“加一项”的思想实验：如果在求和号外再加一个跨视角重投影一致性项，梯度里会多出什么？答案是多出一条连接两条分支的偏导链，参数更新开始同时受两个视角的约束。这个实验不要求实现，只要求写出多出来的那一项，就能让学生理解“缓解”与“根治”的差别在于目标函数是否含跨视角耦合。系统代价也要讲清楚：多一条链意味着多一次渲染与多一份显存，训练步速下降。

第三个建议是把常见错误做成对照练习：给出一个只写残差、不写雅可比的“答案”，让学生指出它为什么无法定义梯度；给出一个“提高 CFG 即可”的论断，让学生指出 CFG 作用在求和号内部。教学判断是：能识别这两类错误，就说明读者已经区分了“单视角打分”与“跨视角一致性”两个层次，也就掌握了本题的核心。最后落到工程判断上：SDS 的梯度是一组逐视角伪监督的叠加，它的失败模式由计算图的断开处决定，修补必须发生在断开处，而不是在单个分支内部调参。
