一 · 变体一：把“三通道”换成“三张单通道贴图”

第一个变体题通常这样问：既然 base color、metallic、roughness 是三个物理量，为什么不把它们各存成一张灰度图，而是把 metallic 和 roughness 打包进同一张 RGB 的 B、G 通道？这个变体考察的是考生是否理解“通道语义”与“采样带宽”的区别。机制上，GPU 采样一张纹理的代价主要由纹理读取次数与缓存行决定，而不是由“这张图里塞了几个物理量”决定。把 metallic 放进 B、roughness 放进 G、AO 放进 R，一次 texture2D 采样就同时拿到三个标量，片元着色器里只需一次采样指令；若拆成三张单通道图，就是三次采样、三次地址计算、三次缓存查找。在延迟渲染的 G-buffer 写入阶段，这种差异会直接体现在每像素的指令数与带宽上。

用公式表达采样代价的差异：设单次纹理采样的平均代价为 $$C_s = C_{addr} + C_{cache} + C_{filter}$$，其中地址计算、缓存命中/缺失、过滤各占一部分。打包方案的总代价是 $$C_{packed} = C_s + C_{unpack}$$，拆分为 $$C_{split} = 3C_s$$。只要 $$C_{unpack} < 2C_s$$，打包就更划算，而通道拆分（swizzle）通常只是一两条 ALU 指令，远小于两次额外采样。这就是行业普遍采用 ORM（Occlusion-Roughness-Metallic）打包的工程理由。

系统代价在于分辨率与压缩的耦合。metallic 在绝大多数材质里是二值的（0 或 1），把它和连续变化的 roughness 塞进同一张图，会让整张图的熵升高，BC7/ASTC 的块压缩更难在低比特率下保持 roughness 的平滑梯度，容易出现块状条带。失败模式很具体：一块金属与塑料交界的区域，压缩把 metallic 的硬边糊成中间值，渲染出来就是“半金属”的灰边，物理上不存在这种材质。例子：一把枪的机匣是金属、护木是聚合物，若两者共用一张 1K 的 ORM 图并压到低比特率，交界处的 metallic 会被插值成 0.4 左右，BRDF 的 F0 随之偏移，高光颜色既不象金属也不象塑料。

追问会顺势压过来：那为什么 base color 不也打包进去？答案是色彩空间与精度需求不同。base color 是 sRGB 编码的三通道颜色，需要较高比特率保真；metallic/roughness 是线性标量，对绝对精度要求低但对梯度连续性要求高。混在一张图里会让编码器在“保颜色”与“保梯度”之间被迫折中，这是语义分层而非节省通道的问题。

二 · 变体二：给出“已有 RGB 贴图”的迁移路径

第二个变体是工程题：手上只有一张传统 workflow 的 RGB 漫反射贴图，如何迁移到 PBR？这题考的是对 delighting 与参数反演的次序判断。机制上，传统贴图里烘进了三样东西：环境光遮蔽、方向性阴影、以及高光/反射的近似。迁移的第一步不是猜 metallic，而是先把光照成分剥离，得到近似反照率。一个可操作的伪代码思路是：对输入图 I，用低频光照估计 L（例如大核高斯或引导滤波），做 $$\hat{A} = I / L$$，再对 $$\hat{A}$$ 做色域压缩与去饱和校正，避免除零导致的高光爆炸。随后用亮度与局部对比度给出 roughness 的初值：高频细节多、镜面反射弱的区域倾向于高 roughness，反之偏低。

系统代价是这一步本质上是欠定问题。单张 LDR 图丢失了动态范围，暗部被压到接近零，除法会把噪声放大；高光区已经饱和，$$I/L$$ 无法恢复被截断的能量。失败模式是“暗部发花、高光发灰”：阴影里的反照率估计出随机噪点，高光处的 base color 被压成不自然的深色。例子：一张木桌的旧贴图，桌腿背光面几乎全黑，delighting 后 base color 出现斑驳的伪纹理；桌面高光处则被误判为深色漆面，换到强光环境下整张桌子显得脏。

更关键的是 metallic 无法从单张颜色图可靠反演。金属的反照率即 F0，绝缘体的 F0 约为 0.04，二者在颜色上的表现可以高度相似——一块抛光的黄铜和一块黄色喷漆在漫反射图里可能几乎一样。判据只能来自上下文：边缘高光的颜色是否随视角变化、反射是否带有环境颜色。追问会问：那能不能用一张 mask 手工标注 metallic？可以，但这把问题从“自动估计”变成“人工语义分割”，代价是产能。工程判断是：迁移路径必须接受“估计有歧义”，把 delighting 的输出当作初稿而非真值，靠美术在关键材质上手工校正 metallic 与 roughness，而不是追求全自动。

三 · 变体三：实时渲染里“省掉 metallic”会怎样

第三个变体是反向题：如果引擎为了省带宽，把 metallic 固定为 0，只保留 base color 与 roughness，画面会坏在哪里？机制上，metallic 决定的是 BRDF 中漫反射项与镜面项的能量分配。绝缘体的漫反射权重是 $$k_d = (1 - F)(1 - metallic)$$，镜面 F0 为 $$F_0 = 0.04(1 - metallic) + baseColor \cdot metallic$$。当 metallic 被强制为 0，所有金属都会按绝缘体处理：F0 恒为 0.04，镜面高光变成无色的白，金属本该有的带色反射（黄铜的金色高光、铜的橙红高光）全部丢失，同时漫反射项被错误地保留，金属表面会显得“发灰、发闷”，像蒙了一层粉。

系统代价体现在美术返工与材质库分裂。省掉一张通道看似节省 1/4 的纹理带宽，但代价是所有金属材质需要靠额外的高光颜色贴图或自定义 shader 打补丁，材质图层的数量反而上升。失败模式是“金属不金属”：一把剑的刃口在强光下只剩白色亮点，没有金属特有的彩色反射与菲涅耳边缘。例子：在只保留 base color 与 roughness 的管线里渲染一枚金币，金币的漫反射底色是黄的，但高光永远是白的，转动时缺少随视角变化的暖色反射，观感接近塑料玩具。

追问会追问：那能不能用 roughness 间接编码 metallic？不能，二者语义正交。roughness 控制高光锐利度，metallic 控制高光颜色与漫反射有无，一个高 roughness 的金属和一个低 roughness 的绝缘体可以在某些角度下产生相似的模糊高光，但前者高光带底色、后者不带。把两者压进一个标量必然产生不可分辨的材质对，这是信息论层面的损失，不是调参能弥补的。

四 · 五个追问的应答骨架

追问一：base color 能不能包含光照？应答要点是“可重光照”这一前提。若 base color 含光照，BRDF 的输入就与光照耦合，换一套环境光后材质响应不再成立，等于把渲染方程里的 $$L_o = \int f_r L_i \cos\theta \, d\omega$$ 中的 $$f_r$$ 与 $$L_i$$ 混在一起，积分无法分离。机制上，PBR 管线要求材质参数与光照解耦，才能在同一材质上叠加不同的 IBL、点光、方向光。

追问二：delighting 是否无损？应答要落在“欠定”上。单图去光照没有唯一解，暗部信噪比低、高光被截断，估计出的反照率带有系统性偏差。代价是必须接受人工校正环节，失败模式是暗部噪点与高光色偏。

追问三：metallic 为什么常常是二值？应答要点是物理上金属与绝缘体是两类介质，中间值只在过渡区（氧化、污渍、涂层）才有意义。把 metallic 当连续量随意调，会产生物理上不存在的“半金属”，其 F0 既不是 0.04 也不是金属反照率，高光颜色错乱。

追问四：roughness 与 glossiness 的关系？应答要点是二者互为反向映射，但映射是非线性的。若管线内部用 glossiness，转 roughness 时需要按感知曲线重映射，直接取 $$r = 1 - g$$ 会让中间调的高光宽度失真，失败模式是“高光要么太尖要么太糊”。

追问五：AO 贴图算不算 PBR 的一部分？应答要点是 AO 是遮蔽近似，不是 BRDF 参数，它乘在漫反射与环境光上，不能替代 metallic/roughness。把 AO 烘进 base color 正是“RGB 烘死光照”的典型错误，换光照后阴影方向就错了。

五 · 扣分点与常见错误的对应表

评分标准给出三通道 60%、为何不能 RGB 40%，扣分点就围绕这两块展开。下表把常见错误映射到扣分位置与可观测的失败现象，便于阅卷时快速定位。

常见错误扣分位置可观测失败
以为 RGB 就是 PBR为何不能 RGB（40%）换光照后颜色错、阴影方向固定
忽略 metallic/roughness三通道（60%）金属无彩色高光、高光宽度单一
以为 delighting 无损机制解析暗部噪点、高光色偏
把 AO 当 BRDF 参数三通道（60%）遮蔽被烘死、环境光响应错误
metallic 随意取中间值三通道（60%）半金属灰边、F0 偏移

机制上，这些错误共享一个根因：把“看起来对”当成“物理上对”。RGB 贴图在原始光照下确实好看，但它把 $$f_r$$ 与 $$L_i$$ 的乘积烘死成一张图，任何重光照都会暴露耦合。系统代价是资产无法复用：同一材质在不同场景需要重新烘一张图，产能随场景数线性增长。例子：一个角色在室内暖光下烘好的 RGB 贴图，搬到室外冷光场景，皮肤会显得蜡黄，因为暖光已被烘进反照率。

另一个高频扣分点是只答“三通道是什么”而不答“三者如何共同决定 BRDF”。满分答案必须把三者串到渲染方程上：base color 进入漫反射项与金属 F0，metallic 分配漫反射/镜面能量，roughness 决定微表面分布的宽度。缺了这层串联，三通道就只是三个名词，拿不到机制分。

六 · 教学建议：用可重光照实验替代背诵

教学上最有效的手段是让学生亲手做一次“换光照”实验，而不是背三通道定义。具体机制：给同一套材质准备两套环境光——一套暖色室内 IBL，一套冷色户外方向光——分别渲染 RGB 贴图方案与 PBR 方案。RGB 方案在切换光照后颜色整体偏移、阴影方向固定；PBR 方案的颜色与高光随光照正确变化。这个对比把“可重光照”从抽象前提变成可见现象，学生自己就能说出为什么 RGB 不行。

第二个教学动作是让学生做一次 delighting 并标注失败区域。给出暗部与高光两块区域，要求指出估计偏差的来源：暗部是信噪比不足，高光是动态范围截断。伪代码层面可以让学生写出 $$\hat{A} = I / L$$ 的除零保护与 clamp 逻辑，理解为什么“无损”是错觉。代价讨论要落到产能：全自动迁移不可靠，必须留人工校正环节，这是工程判断而非理论缺陷。

第三个动作是设计一个“省掉 metallic”的对照渲染，让学生亲眼看到金属失去彩色高光。失败模式要具体到材质：金币、黄铜把手、不锈钢水槽，三者在高光颜色上的差异只有在 metallic 存在时才能区分。教学判断是：PBR 的价值不在单张图好看，而在材质参数与光照解耦后可复用；任何把光照烘进颜色的捷径，都会在换光照时以可见的方式付出代价。

最后要提醒阅卷侧的判断：考生若能把三通道、BRDF、可重光照、delighting 四者串成一条因果链，即使表述朴素也应给高分；若只罗列名词而说不出耦合关系，即便字数多也应压在及格档。这条判断标准本身就是对“机制优先于术语”的教学导向。
