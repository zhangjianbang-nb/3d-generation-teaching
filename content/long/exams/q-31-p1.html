一 · 三档答案的判分骨架

这道题在评分表上被切成两块：SLAT 结构占 50%，多解码占 50%。这个对半切分本身就是一条信息——出题人不认为“能背出 SLAT 全称”就算过关，也不认为“能说出三种输出格式”就算过关。两半必须各自立住，任何一半塌掉，总分就掉到及格线以下。把这条规则翻译成三档答案，边界就非常清楚。

及格档的判据是“两块都点到，但都不深”。考生需要说出 SLAT 是稀疏体素加每个体素上的三平面特征，需要说出它经 3D DiT 用 rectified flow 去噪，需要说出同一套潜变量可以解成高斯、网格、辐射场。三句话齐了，50%+50% 的结构分就拿到了。但及格档允许含糊：说不清“稀疏”到底稀疏在哪、说不清三平面是局部还是全局、说不清三种解码器为什么误差不同，都还能过。

良好档要求把“结构化”三个字拆开。稀疏体素回答的是“哪里有内容”，局部三平面回答的是“那里长什么样”，这两个子句必须被显式区分开，而不是揉成一句“SLAT 是体素加特征”。同时良好档要意识到 3D DiT 与 rectified flow 是配套的：DiT 提供在稀疏结构上做去噪的主干，rectified flow 提供从噪声到数据的直线化传输路径。少讲其中任何一个，机制解析就不完整。

满分档在良好档之上再加两层。第一层是数字底账：能定性说明稀疏体素带来的显存与计算节省来自“只处理有内容的格子”，而不是靠降分辨率；能说明 SLAT 分辨率本身构成细节上限。第二层是失败模式：能指出三套解码器各自有误差，且误差来源不同，因此“一套潜变量多解码”不等于“三种输出质量相同”。满分答案必须主动否定“所有解码器质量相同”这个常见错误，而不是等评分人来找。

三档之间的差距不在字数，而在“是否把判分点变成可检验的陈述”。及格档的陈述是名词堆叠，良好档的陈述带因果关系，满分档的陈述带代价与边界。评分演练时，最容易被误判为满分的是那种把四个判分点复述一遍、却没有一处否定性陈述的答案——它看起来面面俱到，实际上没有回答“为什么一套潜变量能解成三种东西”里的“为什么”。

二 · 机制解析：稀疏体素与局部三平面如何分工

SLAT 的名字里，“Structured”是定语，“LATent”是中心词。结构化体现在两级：第一级是稀疏体素，它是一张 occupancy 式的空间索引，只记录哪些格子有内容；第二级是每个被激活体素上的三平面特征，它把该体素邻域的细节压到三个正交平面上。两级的分工可以用一句话概括：体素管“在哪”，三平面管“是什么”。

这个分工的直接后果是特征存储不随包围盒体积线性增长，而随表面附近被激活的体素数增长。设包围盒被划成 N³ 个格子，其中被激活的体素数为 K，每个体素存三张尺寸为 r×r 的平面特征图，通道数为 C，则潜变量的特征张量规模近似为：

$$ \text{FeatureCount} \approx K \cdot 3 \cdot r^{2} \cdot C,\qquad K \ll N^{3} $$

公式里真正起作用的是 K≪N³ 这个不等式。它说明稀疏结构不是“把体素变小”这种暴力手段，而是把计算与存储从体积量级压到表面量级。这也是为什么不能把 SLAT 当成普通稠密体素：稠密体素的特征量随 N³ 走，稀疏体素随 K 走，两者在同样的视觉分辨率下代价差一个量级。考生若把 SLAT 说成“普通体素加三平面”，等于丢掉了整个稀疏索引层，判分点上直接失分。

三平面为什么是“局部”的，也需要讲清。每个体素自带一组小平面，而不是整场景共享一组大平面。共享大平面的问题是分辨率被场景尺度摊薄，远处细节和近处细节抢同一张图；局部三平面把细节预算分配给每个体素，代价是体素之间不共享特征，潜变量的总规模由 K 决定。这是一个明确的取舍：局部性换细节保真，稀疏性换可扩展性。

3D DiT 在这一结构上做去噪。DiT 主干要处理的 token 不是稠密网格上的全部格子，而是被激活体素对应的结构化 token；rectified flow 则规定从噪声到数据的传输路径尽量走直线，减少采样步数。二者配套的逻辑是：稀疏结构让 token 数可控，直线化传输让少步采样可行，合起来才使“在 SLAT 空间生成”具备工程可用性。只讲 DiT 不讲 rectified flow，机制解析就断了一环；只讲 flow 不讲 DiT 处理的是稀疏 token，则等于把结构化潜变量又退回稠密张量。

一个具体例子可以检验理解：场景中有一面薄墙和墙后的一把椅子。稀疏体素只在墙面和椅子表面附近激活，墙与椅子之间的空气格子不占特征预算；墙面体素的三平面编码墙的纹理与边缘，椅子体素的三平面编码椅背曲线。若换成稠密体素，墙与椅子之间的空腔也要分配特征，浪费的正是 K≪N³ 省下来的那部分。这个例子同时暴露一个失败模式：当薄结构厚度小于体素尺寸时，稀疏索引可能漏激活或错激活，细节在潜变量阶段就已丢失，后续任何解码器都补不回来。

三 · 多解码的机制与误差来源

“一套潜变量解成三种表示”不是三个解码器读同一份数据那么简单，而是三种解码器对同一份结构化特征做不同的解释。高斯解码面向实时渲染，输出的是可光栅化的高斯原语；网格解码面向引擎资产，输出的是顶点与面片；辐射场解码面向高质量渲染，输出的是沿射线查询的密度与颜色。三者的输出语义不同，误差也就不同源。

高斯解码的误差主要来自原语拟合：三平面特征要被压成有限个高斯椭球，高频细节和薄结构在拟合中容易被抹平。网格解码的误差主要来自拓扑提取：从特征场到等值面的过程要做空间离散，薄壁、细杆、开放边界在提取时容易出现孔洞或粘连。辐射场解码的误差主要来自采样与积分：它保留了最多的连续信息，但渲染代价高，且对特征场的分辨率同样敏感。三种误差不是同一个误差的不同量级，而是三种不同性质的失真。

因此“一套潜变量多解码”的正确表述必须带条件：共享的是潜变量，不共享的是误差谱。判分点里“高斯/网格/辐射场”这一条，及格档只要求列出三者，良好档要求说明各自面向的下游用途，满分档要求指出三者质量不等价。常见错误“以为所有解码器质量相同”正是踩在这一条上：它把“同一潜变量”误读成“同一保真度”。

工程上这个结构带来一个具体的调度问题。生成阶段只跑一次 3D DiT 去噪，得到 SLAT；解码阶段按下游需求选解码器。若同一资产既要进引擎又要出高质量渲染图，就要跑两次解码，潜变量只算一次。省下的是生成算力，付出的是解码算力与两次解码之间的一致性风险——高斯版和网格版在同一处薄结构上可能给出不同形状，因为两种解码器对同一特征的离散方式不同。这个风险无法靠提高 SLAT 分辨率消除，它来自解码器语义差异。

还有一个失败模式值得单独指出：把 SLAT 分辨率当成唯一质量旋钮。提高体素分辨率或三平面尺寸确实能提升细节上限，但当分辨率超过下游解码器能表达的粒度时，增益会被解码器吃掉。高斯解码的原语数量、网格解码的提取精度、辐射场的采样密度，各自构成瓶颈。调参时若只盯 SLAT 分辨率而不看解码器容量，就会出现“潜变量更细、输出没变好”的典型现象。

四 · 数字底账：稀疏性省了什么，分辨率限了什么

题目给定事实里没有具体实验数字，因此底账只能定性记账，但定性记账也要记到项上，不能一句“更高效”糊过去。稀疏体素省下的账目至少有三项：特征存储、去噪时的 token 数、解码时的查询范围。三项都随激活体素数 K 走，而不是随包围盒格子数 N³ 走。

第一项是特征存储。稠密方案要为每个格子预留三平面特征，稀疏方案只为激活体素分配。省下的比例取决于表面占比：物体越“壳状”、包围盒越空，省得越多；物体越“实心”、包围盒越紧，省得越少。这意味着稀疏结构的收益不是常数，它随场景几何变化。考生若把稀疏性说成“总是省一个固定比例”，就是把定性账目编成了假数字。

第二项是去噪 token 数。3D DiT 的注意力代价随 token 数增长，token 数由激活体素决定。稠密方案下 token 数被包围盒分辨率锁死，稀疏方案下 token 数随内容量浮动。代价是 token 集合不规则，批处理与并行调度更复杂——这是稀疏结构在系统层面的真实开销，不能只记收益不记代价。

第三项是解码查询范围。辐射场解码沿射线查询特征，稀疏结构让查询跳过空区；但跳过空区需要额外的索引查找，索引本身有开销。当 K 接近 N³ 时，索引开销可能超过跳过空区省下的查询，稀疏结构退化为负收益。这是一个明确的失败边界：稀疏不是无条件更优。

分辨率限制的账目则落在另一侧。SLAT 的体素尺寸与三平面尺寸共同构成细节上限：小于体素尺寸的结构无法被稳定激活，小于三平面像素对应尺度的纹理无法被编码。这个上限在潜变量阶段就写死了，解码器只能逼近不能突破。因此“SLAT 分辨率限制细节”不是一句套话，它是一条硬约束：任何解码器的高频输出都受潜变量带宽约束。把这条约束和多解码误差叠在一起，就得到完整判断——质量上限由 SLAT 分辨率定，质量实现由解码器定，两者不能互相替代。

五 · 评分演练：三段答案对照

下面用同一道题的三段作答做演练，每段都按判分点逐条核对，指出它落在哪一档、为什么。

第一段（及格档）："SLAT 是稀疏体素加三平面特征的结构化潜变量，用 3D DiT 和 rectified flow 去噪，可以解码成高斯、网格和辐射场。"核对：稀疏体素+局部三平面——点到但未区分两级分工；3D DiT+rectified flow——点到但未说明二者配套；一套潜变量多解码——点到；高斯/网格/辐射场——点到。四点到齐，结构分与多解码分都拿到基础分。扣分处在于“局部”二字缺失、三种解码器质量差异未提。这段能过，但不能高。

第二段（良好档）："SLAT 用稀疏体素索引有内容的格子，每个激活体素带一组局部三平面编码细节，因此特征量随激活体素数而非包围盒体积增长。3D DiT 在被激活体素的结构化 token 上去噪，rectified flow 提供直线化传输以减少采样步数。同一 SLAT 可分别解成高斯用于实时渲染、网格用于引擎资产、辐射场用于高质量渲染。"核对：两级分工清楚，DiT 与 flow 的配套说清，三种用途说清。缺的是误差谱与分辨率上限：没有指出三种解码器误差不同源，也没有指出 SLAT 分辨率构成细节硬上限。这段落在良好档上沿，离满分差一处否定性陈述。

第三段（满分档）：在第二段基础上加两句——"三种解码器共享潜变量但不共享误差：高斯受原语拟合限制，网格受拓扑提取限制，辐射场受采样限制，因此输出质量不等价；SLAT 的体素与三平面尺寸在潜变量阶段就设定了细节上限，解码器只能逼近。"再加一句边界——"稀疏性在 K 接近 N³ 时索引开销可能吃掉收益。"核对：四判分点全中，且每点都带机制或代价；主动否定“所有解码器质量相同”；给出分辨率硬约束与稀疏性失效边界。这段满足满分判据。

演练的结论可以落到一条可操作的评分动作上：阅卷时先找四个判分点是否各自成句，再找是否存在至少一处否定性陈述（否定“普通体素”、否定“解码器等价”、否定“稀疏无条件更优”任一即可），最后看数字底账是否只用了定性表述而没有编造比例。三条都过给满分，缺第三条降良好，缺第二条降及格，判分点不成句则不及格。这条动作把 50%+50% 的评分表变成了可复现的流程，也解释了为什么名词堆叠式答案拿不到高档——它缺的正是否定性陈述这一层。
