一 · 变体题的设计逻辑与三档改写

原题问的是「SDS 为什么有偏、偏差来自哪两个近似」，这是一个要求把机制拆成两层并各自定位的题。变体题不是换措辞重复同一问，而是改变约束条件，检验答题者是否真的把两层偏差理解成可分离的结构。下面三个变体分别从「反事实」「责任分配」「边界条件」三个方向切入，每一个都要求答题者重新组织因果链，而不是背原答案。

变体一（反事实型）：如果把 SDS 中的单次噪声采样换成对噪声的多次采样平均，偏差会消失吗？这个变体逼迫答题者把第二层近似从「存在」推进到「可削弱但不可消除」。正确回答必须指出：多样本平均只压低第二层近似带来的估计方差，使梯度更接近当前 3D 分布在噪声图上的期望得分；但第一层近似——把 2D 条件得分当作 3D 边缘分布的得分——完全不因采样次数改变。因此偏差不会消失，只会从「高方差 + 系统性偏移」退化为「系统性偏移」。错误回答的典型形态是把「方差减小」直接等同于「偏差减小」，混淆了估计量的方差与偏差两个不同属性。

变体二（责任分配型）：有人说 SDS 的过饱和主要怪 CFG 的高引导系数，这个归因是否成立？这个变体对应原题「常见错误」里的一条。答题者需要把 CFG 放大与两层近似分开：CFG 放大的是 2D 得分本身，它让条件得分偏离无条件得分更远，从而加剧过饱和的外观，但它不是偏差的来源；即便把引导系数调到温和值，第一层近似仍在，过饱和只是减弱而非消失。把 CFG 当主因，等于把「放大器」误认成「信号源」。

变体三（边界条件型）：在什么条件下 SDS 家族方法可以被视为接近无偏？这个变体考的是对「真 3D 监督」这一判据的严格使用。参考答案的解析已经给出结论：VSD 修正第二层，第一层仍在，所以任何 SDS 家族方法都不是真 3D 监督。因此正确回答必须否定「存在某个超参数配置使其无偏」的说法，只能给出「当 2D 先验与 3D 真值在特定视角、特定材质、特定几何复杂度下高度一致时，第一层近似的实际偏移变小」这种有条件收敛的表述，并且明确这是数据分布层面的巧合，不是算法层面的无偏。

三档改写对应评分标准的两层各 50%。及格档：能说出两个近似各自是什么，但不区分「方差」与「偏差」，或把 CFG 混入偏差来源。良好档：两层分离清楚，能指出多样本平均只作用于第二层，但对第一层的不可消除性只作断言不作机制说明。满分档：两层各自给出机制、给出可操作的判别（例如用多样本平均观察梯度方差下降但渲染结果仍过饱和），并明确 SDS 家族的统一上限。下表把三个变体与三档的对应关系固定下来，便于教学时逐格核对。

变体及格档表现良好档表现满分档表现

二 · 五个追问的递进结构

追问的作用是把一个已经答对的答案继续往下压，压到答题者必须动用原答案之外的结构。下面五个追问按递进排列，前两个针对第二层近似，第三、四个针对第一层近似，第五个针对两层叠加后的系统代价。每个追问都配一个必须出现的机制点和一个必须避免的失败模式。

追问一：单次噪声采样估计期望，方差大在优化上表现为什么？机制点：SDS 的梯度是随机梯度，单样本估计使每一步的方向带有高方差，优化轨迹在损失面上抖动，表现为同一提示词下多次运行的几何细节不一致、局部出现过饱和斑块。失败模式：只答「不稳定」而不落到「梯度方差→轨迹抖动→细节不一致」的链条上。这里可以写出梯度的形式化结构：

$$\nabla_\theta \mathcal{L}_{\mathrm{SDS}} = \mathbb{E}_{t,\epsilon}\left[ w(t)\left( \epsilon_\phi(x_t, y, t) - \epsilon \right) \frac{\partial x}{\partial \theta} \right]$$

其中期望在实现时被单次 \((t,\epsilon)\) 采样替代，方差的来源正是这个替代。追问二：多样本平均为什么不能把第二层偏差压到零？机制点：即便期望估计得再准，它逼近的是「当前 3D 分布在噪声图上的得分」，而这个得分本身是被 2D 先验投影出来的量；平均只让估计量收敛到投影得分，不改变投影得分与 3D 真值得分之间的系统差。失败模式：把「估计得更准」说成「估计得更对」。这里要区分统计误差与模型误差：前者随样本数下降，后者是近似本身的结构性残差。

追问三：第一层近似里，「2D 先验不等于 3D 真值」具体在哪些维度上错位？机制点：2D 先验只在被观测视角上给出条件分布，它对未见视角、背面几何、遮挡关系没有直接约束；当优化把 2D 得分当成 3D 投影得分使用时，多视角之间的一致性只能靠 3D 表示自身的耦合被动维持，而不是被显式监督。失败模式：笼统说「2D 信息不全」而不指出「视角覆盖」与「遮挡一致性」这两个具体错位维度。追问四：为什么说 VSD 修正了第二层却没碰第一层？机制点：VSD 引入粒子模型，用当前 3D 分布的渲染结果去构造一个可比的得分目标，从而把「单样本估计当前分布」换成「用粒子模型显式承载当前分布」，这直接针对第二层；但粒子模型的监督信号仍来自 2D 先验，第一层的投影关系原封不动。失败模式：把 VSD 说成「更接近真 3D 监督」，这与解析给出的判据直接冲突。

追问五：两层叠加后，系统代价如何在工程上被观察到？机制点：过饱和来自 2D 先验在高引导下的得分放大与第一层投影偏移的叠加；多面（同一物体在不同视角下呈现互相矛盾的面片结构）来自第一层缺少跨视角显式约束；几何不准来自第二层高方差导致的细节抖动与第一层系统性偏移的共同作用。失败模式：把三个症状各自归给单一原因，而不展示「哪个症状主要由哪一层贡献」。下表把五个追问与机制点、失败模式对齐。

追问必须出现的机制点必须避免的失败模式
单样本方差在优化上的表现随机梯度→轨迹抖动→细节不一致只答「不稳定」
多样本平均的上限收敛到投影得分，不改投影本身混淆统计误差与模型误差

三 · 扣分点的颗粒度

评分标准写的是「两层偏差各 50%」，这个比例在阅卷时需要被拆成可核对的颗粒，否则「各 50%」会退化成「提到两层就给分」。扣分点的设计原则是：每一层内部再分「命名」「机制」「后果」三个颗粒，缺一个颗粒扣该层的一部分，而不是整层清零。这样既能守住两层各半的总结构，又能区分「背了名词」与「讲清机制」。

第一层的三个颗粒：命名——明确指出「2D 得分被当成 3D 投影得分」；机制——说明 2D 先验只在观测视角有约束、未见视角与遮挡关系无显式监督；后果——把过饱和、多面、几何不准中至少两个症状归因到这一层。第二层的三个颗粒：命名——明确指出「单次噪声样本估计期望」；机制——说明方差大且忽略当前 3D 分布（这两点是并列的，不能只写一个）；后果——说明梯度抖动如何表现为细节不一致或局部斑块。常见扣分形态有四种：只写第一层不写第二层，扣满 50%；把 CFG 写进偏差来源，属于概念污染，在第一层颗粒上扣；把「方差大」与「忽略当前分布」合并成一句，视为机制颗粒不完整；把 VSD 说成消除偏差，属于与解析判据冲突，在追问四的对应颗粒上扣。

扣分点还需要处理一种「正确但错位」的答案：答题者把两层都写了，但把第二层的后果写成「过饱和」，而把第一层的后果写成「方差大」。这属于颗粒错配，症状与层的对应关系反了。阅卷时应按颗粒逐一核对，而不是按段落整体印象给分。下面的伪代码思路给出一个可操作的核对流程，用于教学时让学生自查：

  • 读答案，标出所有出现的「近似」表述，数是否为两个；若只有一个，第二层或第一层缺失，按缺失层扣。
  • 对每个近似，检查是否有「为什么它是近似」的机制句，而不只是「存在一个近似」的断言句。
  • 检查症状归因：过饱和、多面、几何不准是否被分配到正确的层，出现交叉即错配。
  • 检查是否出现「无偏」「消除偏差」「真 3D 监督」等与解析判据冲突的表述，出现即在该颗粒扣。

这套流程的价值在于把「各 50%」变成可复现的判分动作。一个具体例子：某答案写「SDS 有偏是因为 CFG 放大了 2D 得分，而且单次采样方差大」，这句话里第二层的命名颗粒拿到了，但第一层的命名颗粒被 CFG 替代，属于概念污染；同时「忽略当前 3D 分布」这个并列机制点缺失。按颗粒核对，该答案在第一层扣命名与机制两个颗粒，在第二层扣机制的一个并列点，总分落在良好档下沿而不是满分档。

四 · 常见错误的成因分类

原题列出的三条常见错误——以为 SDS 无偏、只归因于 CFG、忽略单样本方差——不是三个孤立的误解，而是三种不同的认知成因。教学时按成因分类处理，比逐条纠正更有效，因为成因决定了错误会在变体题里以什么形态复发。

成因一：把「优化目标可收敛」误读为「优化目标无偏」。SDS 的损失确实可以被优化到收敛，收敛点附近渲染结果看起来像那么回事，这让答题者产生「既然能收敛，目标就是对的」的推断。这个推断混淆了「优化可行性」与「统计无偏性」：一个带系统性偏移的目标同样可以被稳定优化，收敛到的是偏移后的解，而不是真值。这类答题者在变体三（边界条件）上最容易复发，会把「调参后效果变好」说成「接近无偏」。

成因二：把最显眼的超参数当成偏差主因。CFG 的引导系数是 SDS 流程里最直观可调的旋钮，调高它过饱和立刻变重，于是因果直觉把「可观测的相关」当成「偏差的来源」。这类答题者在变体二（责任分配）上会坚持 CFG 主因，即便被提示「调低 CFG 后几何偏移仍在」也难以改口，因为他们的因果模型里没有「两层近似」这个中间结构，只有一个「旋钮—症状」的直接映射。

成因三：把期望符号当成已经处理好的数学装饰。SDS 的公式里写着期望 \(\mathbb{E}_{t,\epsilon}\)，实现时用单次采样替代，这个替代在代码里往往只是一次随机数调用，视觉上不显眼，于是被当成实现细节而非近似。这类答题者能背出公式，却在追问一（方差在优化上的表现）上答不出「随机梯度→轨迹抖动」的链条，因为他们从未把期望符号与实现之间的缝隙当成一个需要解释的对象。

三种成因对应三种教学干预：对成因一，用「带偏移的目标也能收敛」的反例逼出「收敛≠无偏」的区分；对成因二，用「调低 CFG 后症状减弱但几何偏移仍在」的反事实逼出「放大器≠信号源」的区分；对成因三，用「把期望展开成多样本平均后方差下降但偏差不变」的对照逼出「统计误差≠模型误差」的区分。这三种干预都要求答题者动手改写因果链，而不是记住一句纠正话术。失败模式在于：教学者只给出正确表述而不给出反事实对照，答题者会在原题上答对、在变体上复发。

五 · 教学建议：从背答案到拆结构

这道题的满分答案只有几句话，但它承载的结构是「两层近似 + 各自机制 + 症状归因 + 家族上限」。教学的目标不是让学生复述这几句话，而是让学生能在变体题里重新组装这个结构。可行的做法是把答案拆成一张结构表，让学生先填表再成文，表里的每一格都对应一个扣分颗粒，这样写作时不会漏层，也不会错配症状。

第一轮教学：给出原题，要求学生只填结构表，不写完整答案。表的行为两层近似，列为命名、机制、后果。教师核对表格，重点看第二层的「机制」列是否同时写了「方差大」与「忽略当前分布」两个并列点，以及「后果」列是否把症状分到了正确的层。第二轮：给出三个变体，要求学生在结构表上标注「这个变体动的是哪一层、哪一格」，例如反事实变体动的是第二层的机制格，责任分配变体动的是第一层的命名格（因为 CFG 污染了命名）。第三轮：给出五个追问，要求学生在不改变结构表的前提下，为每个追问指出它压的是哪一格，并写出该格必须出现的机制句。

这种教法的系统代价是时间：三轮下来比直接讲答案慢得多，但它换来的是一种可迁移的能力——学生在遇到「SDS 家族新方法是否解决了偏差」这类新问题时，能自己定位「新方法动的是哪一层」，而不是等教师给结论。一个具体例子：面对一个声称「用多视角一致性损失消除 SDS 偏差」的新方法，受过三轮训练的学生会先问「这个损失作用在第二层的估计方差上，还是作用在第一层的投影关系上」，然后判断它至多削弱第二层，不能消除第一层，从而守住「非真 3D 监督」的判据。

教学建议里还要处理一个反模式：把「两层各 50%」当成字数分配，要求学生第一层写一半篇幅、第二层写一半篇幅。这会导致学生为了凑比例而在第一层堆砌症状描述，反而稀释了机制句。正确的做法是按颗粒给分而不是按篇幅给分，并在批改时明确告诉学生：一段话只要同时命中命名、机制、后果三个颗粒，就拿到该层满分，篇幅不是判据。这样学生才会把注意力放在「机制句是否到位」上，而不是「哪层写得多」上。

最后一轮应落在判别动作上：给学生一段真实的 SDS 家族方法描述（只给机制描述，不给结论），要求学生在限定时间内写出「它动了哪一层、哪一格、因此偏差的上限是什么」。这个动作把整道题的结构压缩成一个可执行的判断：先定位层，再定位格，最后给出上限。能稳定完成这个动作的学生，在原题、变体题、追问三个层面上都不会出现层缺失或症状错配，因为他们的答题起点不是「背两句答案」，而是「先建两层、再填颗粒」的结构化流程。
