一 · 变体题：把“差别题”改写成三种考法

原题问的是“核心差别 + 为什么能缓解”，判分权重是核心差别 50%、改善机制 50%。这个结构一旦被记住，命题人只要挪动重心，就能生成三种难度不同的变体。第一种是机制倒置题：不问“VSD 比 SDS 多了什么”，而问“如果把 VSD 的粒子模型冻结，它会退化成什么”。正确回答必须指出：冻结 ε_ψ 后，减号项变成一个与 3D 参数无关的常量偏移，梯度只剩 ε_φ 的方向，等价于 SDS 的“直接拿 2D 得分当 3D 得分”，于是过饱和与模式坍塌重新出现。这个变体考的是对 (ε_φ − ε_ψ) 结构的理解，而不是背诵名词。

第二种是反例题：给出一个错误说法——“VSD 的优势来自多训练了一个网络，容量更大所以效果更好”——要求考生反驳。反驳的落点是：多一个网络只是实现手段，真正的差别在于这个网络被当作“当前 3D 分布在 2D 投影下的得分估计”来用，从而在梯度里引入扣除项；如果只增加容量而不改变梯度的减法结构，拉向文本的力仍然没有对照项，过饱和不会因为参数量而自动消失。这里必须点出“减号”而不是“参数”。

第三种是迁移题：把同样的逻辑搬到“多视角一致性”或“材质生成”场景，问“是否也需要一个当前分布得分估计”。答题要点是识别出共性：只要目标是在 2D 监督信号下约束 3D 分布，且监督信号与 3D 参数之间存在“投影—反投影”的信息缺口，就需要一个随 3D 参数更新的模型去近似当前分布在观测空间下的得分，否则梯度会单边拉向条件信号。三种变体共用同一套判分骨架，但各自把权重压在“减号项”“冻结退化”“迁移识别”上，考生若只会复述参考答案，会在反例题和冻结题上失分。

$$\nabla_\theta \mathcal{L}_{\text{SDS}} = \mathbb{E}\left[ w(t)\,(\varepsilon_\phi(\mathbf{x}_t; y) - \varepsilon)\, \frac{\partial \mathbf{x}}{\partial \theta} \right]$$

上式是 SDS 的梯度形状，其中没有“当前分布”的对照项；VSD 把它改成 (ε_φ − ε_ψ)，ε_ψ 随 θ 一起更新。变体题的所有追问都围绕这个对照项是否存在、是否更新、是否被正确解释展开。系统代价方面，冻结 ε_ψ 的退化版本在工程上表现为：训练早期看似收敛快，但多视角渲染的饱和区域扩大、视角间纹理漂移，且这种漂移不会随训练步数自行消失，因为梯度里缺少把分布拉回自身的力。

二 · 追问一至三：减号项、更新节奏与“多一个网络”的误读

追问一：减号项到底扣的是什么？ 答：扣的是“当前 3D 分布投影到 2D 后已经具有的得分”。如果不扣，梯度只告诉参数“往文本条件的方向走”，而不告诉它“你已经走到了哪里”，于是同一文本条件下所有样本被推向同一个高饱和极值，多样性被压扁。扣掉之后，梯度是文本得分与当前分布得分之差，相当于每一步只走“尚未被当前分布解释的那部分”。判分时，只写“减去噪声”或“减去随机项”属于概念错误，因为 ε_ψ 不是噪声预测器，而是当前分布的得分估计。

追问二：ε_ψ 的更新节奏为什么必须跟 3D 参数同步？ 答：ε_ψ 近似的是“当前 3D 分布在 2D 投影下的得分”，当前分布随 θ 每一步都在变，若 ε_ψ 更新滞后，减号项扣的是旧分布的得分，梯度就会出现系统性偏差：旧分布已经离开的区域仍被当作“已解释”而扣除，新分布尚未覆盖的区域被过度拉向文本，表现为过饱和回潮与局部模式坍塌。工程上这对应一个失败模式——粒子模型的学习率过低或更新间隔过大时，训练损失曲线仍然下降，但渲染结果的视角一致性和多样性指标恶化，且这种恶化在损失上不可见。

追问三：“VSD 只是多训一个网络”错在哪里？ 答：错在把实现手段当成机制。多训一个网络可以发生在任何方法里，但只有当这个网络的输出被放进梯度的减法位置、并被解释为当前分布的得分估计时，它才构成 VSD。判分点要求考生说出“减号”和“随 3D 参数更新”两个条件；只说“多一个模型”“集成”“蒸馏”均不得分。具体例子：若把 ε_ψ 换成一个固定的大模型（不随 θ 更新），网络更多、容量更大，但梯度退化为 SDS 形状，过饱和与多样性差依旧，这说明容量不是差别所在。

  • 减号项扣的是当前分布得分，不是噪声、不是正则项。
  • ε_ψ 必须随 θ 更新，滞后即产生系统性梯度偏差。
  • “多一个网络”是手段，减法位置与更新关系才是机制。

系统代价上，同步更新意味着每步训练要跑两个网络的前向与反向，显存与算力开销上升；若为了省算力而降低 ε_ψ 的更新频率，省下的算力会以多样性下降和过饱和回潮的形式“还回去”，这是典型的“省在算力、赔在质量”的失败模式。

三 · 追问四至五：KL 视角与“多样性提升”的归因

追问四：变分视角下 VSD 最小化的是什么？ 答：最小化 3D 分布与文本条件 2D 分布之间的 KL。这个视角的价值在于解释减号项的来源：KL 对 3D 参数的梯度天然包含“当前分布得分”这一项，ε_ψ 就是对它的估计。因此 VSD 不是“拉向文本 + 随手减一个东西”，而是 KL 梯度的一个可实现的近似。判分时，考生若只写“KL 散度”而不说明“ε_ψ 是当前分布得分估计”，只拿到一半；必须把 KL 的两项与梯度的两项对应起来。

$$\nabla_\theta \mathrm{KL}\left(q_\theta(\mathbf{x}_{0:3D}) \,\|\, p(\mathbf{x}_{2D}\mid y)\right) \;\approx\; \mathbb{E}\left[(\varepsilon_\phi - \varepsilon_\psi)\,\frac{\partial \mathbf{x}}{\partial \theta}\right]$$

追问五：多样性提升应归因于什么？ 答：归因于减号项抑制了“所有样本被同一文本得分拉向同一极值”的单边拉力，而不是归因于粒子模型本身的随机性。若考生答“因为粒子模型带来随机采样所以多样”，属于归因错误：随机性在 SDS 里也有（噪声采样），多样性差恰恰是因为梯度缺少对照项。正确链条是：KL 梯度含当前分布项 → ε_ψ 估计该项 → 梯度变为差值 → 单边拉力被抵消 → 过饱和减轻、模式坍塌减轻、多样性提升。这条链条上任何一环缺失，改善机制部分即扣分。

失败模式举例：把 ε_ψ 训练得很准但只在离线阶段预训练、不随 θ 更新，此时 KL 的当前分布项被固定在一个历史分布上，梯度差值扣错了对象，表现为早期多样性尚可、后期逐渐坍缩回少数饱和模式。这说明“估计得准”不等于“估计得对”，对的是“当前”分布。系统代价方面，KL 视角要求实现者同时维护两个得分网络的前向图，反向传播要穿过 ε_ψ 对 θ 的依赖（若采用 stop-gradient 则需说明其近似性），否则梯度图与理论不一致，训练出现难以定位的漂移。

追问正确落点典型失分答法
减号项扣什么当前 3D 分布在 2D 投影下的得分扣噪声 / 扣正则
更新节奏随 θ 同步，滞后即偏差预训练一次即可
多一个网络减法位置 + 同步更新才是机制容量更大所以更好
KL 视角两项对应梯度两项只写 KL 名词
多样性归因差值抵消单边拉力粒子模型自带随机性

四 · 扣分点：从判分骨架反推失分位置

评分标准写得很清楚：核心差别 50%，改善机制 50%。把这两个 50% 拆开，扣分点就落在四个位置。第一，核心差别只写“VSD 多了粒子模型”，不写“SDS 忽略当前 3D 分布”，扣核心差别的一半，因为缺少对 SDS 缺陷的陈述，差别就成了单向描述而非对照。第二，梯度写成 ε_φ + ε_ψ 或漏掉减号，直接扣改善机制的大头，因为减号是机制的核心，符号错误意味着机制理解错误，不能按笔误处理。第三，把 ε_ψ 说成固定不变，扣改善机制的一部分，因为“随 3D 参数一起更新”是偏差被纠正的前提，冻结即退化。第四，改善机制只写“效果更好”而不写链条，即缺少“差值 → 抵消单边拉力 → 过饱和/坍塌减轻 → 多样性提升”的因果链，按未答改善机制处理。

还有一类隐性扣分：把 KL 视角与梯度结构割裂。考生若在核心差别里写了 KL，却在梯度里写不出两项对应，评卷人会认为 KL 是贴上去的名词，不给分。另一种是把“多样性提升”写成“随机性提升”，这属于归因错误，即使核心差别全对，改善机制也会被压到低档。扣分点的设计意图是：这道题不是名词题，而是结构题，符号、更新关系、因果链三者缺一即降档。

  • 缺“SDS 忽略当前 3D 分布”——核心差别减半。
  • 漏减号或写成加号——改善机制大幅扣分。
  • ε_ψ 固定不变——改善机制扣分。
  • 无因果链、只写“更好”——改善机制按未答处理。
  • KL 与梯度脱节、多样性归因于随机——隐性降档。

具体例子：一份答卷写“VSD 多了一个粒子模型，所以多样性更好，梯度是 ε_φ 减去 ε_ψ，粒子模型跟着训练”。这份答卷核心差别只拿到“多一个模型”的表层，缺 SDS 缺陷陈述；改善机制有减号和更新，但缺因果链，落在良好档而非满分档。系统代价视角下，扣分点对应的是工程上真实会犯的错：漏减号的实现会退化为 SDS，冻结 ε_ψ 的实现会在后期坍缩，二者都不是理论瑕疵而是可复现的训练失败。

五 · 常见错误与教学建议：把结构题教成结构

常见错误可以归成三类。第一类是名词化错误：把 VSD 记成“SDS + 粒子模型”的加法式，于是答题时只列组件不列关系，遇到反例题（冻结退化）立刻失守。第二类是符号错误：梯度写成加号、或把 ε_ψ 当成噪声项，这类错误在变体题里会被放大，因为冻结题和 KL 题都要求符号正确。第三类是归因错误：把多样性提升归给随机采样或网络容量，把过饱和减轻归给“训练更久”，这类答案在追问五上必然失分。三类错误的共同根源是把这道题当记忆题，而它实际考的是“减法结构 + 同步更新 + KL 对应”的三件套。

教学建议 accordingly 落在三个动作上。动作一：画梯度图。让学生把 SDS 与 VSD 的梯度并排画出来，标出减号位置和 ε_ψ 对 θ 的依赖箭头，图上缺箭头即视为未掌握同步更新。动作二：做冻结实验的思想实验。要求学生口述“冻结 ε_ψ 后梯度变成什么、训练会出现什么现象”，把退化解与 SDS 对齐，这是检验是否真懂减号的最快方式。动作三：用 KL 两项对梯度两项做映射练习，映射不上就说明 KL 是背的。三个动作都指向同一判分骨架：核心差别看“SDS 缺什么 + VSD 补什么”，改善机制看“减号 + 同步 + 因果链”。

教学上还要强调失败模式的可观测性：漏减号的实现，损失曲线正常但渲染饱和区域扩大；冻结 ε_ψ 的实现，早期正常、后期视角漂移与模式坍缩。把这两个现象与两类错误一一挂钩，学生在考场外也能自查。具体例子：课堂练习给出一段伪代码，其中 ε_ψ 用 stop-gradient 且更新间隔为 N 步，要求学生判断它偏离 VSD 的程度并写出退化方向；正确回答要指出 stop-gradient 是对“ε_ψ 对 θ 依赖”的近似切断，更新间隔过大则减号项扣的是旧分布，二者叠加会使梯度在后期偏向单边拉力。这类练习把符号、更新、因果链三件事同时压在一段代码上，比背诵参考答案更接近工程判断。

$$\varepsilon_\psi \leftarrow \mathrm{update}\left(\varepsilon_\psi;\ \theta\right)\ \text{每步或近同步},\qquad \text{若冻结则}\ \nabla_\theta \to \mathbb{E}\left[\varepsilon_\phi \cdot \partial_\theta \mathbf{x}\right]$$

最后落在工程判断上：这道题的满分答案不是把“粒子模型”四个字写上去，而是让评卷人看到减号的位置、ε_ψ 与 θ 的同步关系、以及从 KL 两项到梯度两项的映射；三者构成一个可检查的结构，任何一处断裂都会在变体题、追问和扣分点上被放大。教学与备考都应以这个结构为单位，而不是以名词为单位。
