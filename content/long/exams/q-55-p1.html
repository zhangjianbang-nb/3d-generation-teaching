一 · 三档答案的分层：从“背结论”到“建账本”

这道题在评分标准里被切成两半：3D 与 2D 的数据差异占 50%，为什么堆量不涨点占 50%。这个对半切法本身就是判分的第一层信息——它明确告诉你，只答“3D 数据难搞”而不解释“为什么规模上去了指标不动”，最多拿到一半分。三档答案的差别不在于谁多写了几百字，而在于谁把这两半各自拆成了可验证的机制链。

及格档的典型形态是并列式罗列：采集难、格式杂、许可乱、标注贵，再加一句“所以数据越多不一定越好”。这种答案能命中判分点里的关键词，但每个点都是孤立的断言，没有因果连接。它的问题不是错，而是不可检验——阅卷人无法判断作者是否理解“格式杂”为什么会传导到训练目标上。

良好档会在罗列之上补一条因果链：因为 3D 没有统一的像素网格，网格、点云、神经场三种表示各自携带不同的几何先验，混在一起训练时模型容量被表示差异消耗，于是增加数据量带来的边际收益被表示不一致抵消。这条链已经触及机制，但往往停在定性描述，缺少“账”的概念——没有说明清洗、去重、许可过滤各自吃掉多少有效样本，也没有说明评测集与训练集分布重叠如何制造虚高。

满分档的特征是三层结构：第一层给出差异的结构化对比（表示、采集、许可、标注四个维度各自的性质），第二层给出“堆量不涨点”的四条独立机制并指明它们的作用位置（数据侧、分布侧、法律侧、评测侧），第三层给出一个可操作的判断——有效 scaling 的前提是清洗与表示统一，量的增长只有在质的分级之后才转化为有效样本数。满分答案不追求覆盖所有细节，而是让每一条判分点都挂在一个机制上，并且明确指出哪一条是瓶颈。

一个具体的分层例子：面对“许可乱”这个点，及格档写“3D 资产许可复杂”；良好档写“许可复杂导致可用子集小于名义规模”；满分档写“许可过滤是一个乘性因子，它作用在去重之后、质量分级之前，因此许可受限不是‘少一点数据’，而是把长尾类别整段切掉，直接改变类别分布的形状”。三句话的信息量差异，就是三档的分水岭。

二 · 差异的机制解析：表示不统一是根因

2D 与 3D 的第一性差异是表示空间是否被规范化。2D 图像落在统一的像素网格上，一张图和另一张图共享同一套坐标语义，缩放、裁剪、色彩空间都有行业惯例。这意味着 2D 数据的“量”可以直接相加：多一张图就是多一个同构样本。3D 不具备这个性质。网格是顶点加面片的组合结构，点云是无序坐标集合，神经场是隐式函数参数化，三者的自由度、拓扑约束、采样密度语义完全不同。

这种不统一会直接进入训练目标。以重建类目标为例，损失函数通常写成对表面采样点的距离度量：

$$L=\frac{1}{N}\sum_{i=1}^{N}\left\|\hat{s}(x_i)-s(x_i)\right\|_2^2+\lambda\,\mathrm{Reg}(\theta)$$

其中 $\hat{s}$ 是模型预测的表面采样，$s$ 是监督信号。当监督信号来自网格时，采样点分布在面片上，密度由面片面积决定；来自点云时，密度由扫描仪视角决定，存在遮挡空洞；来自神经场时，采样是人为设定的。同一个 $L$ 在不同表示下度量的是不同的几何量，混训时梯度方向互相拉扯，模型被迫在表示差异上分配容量。这就是“格式杂”真正的代价：它不是数据管理问题，而是优化目标的不一致问题。

第二个机制是采集路径的差异。2D 图像有天然的互联网规模语料——网页、社交媒体、商品图，拍摄成本趋近于零。3D 资产的获取要么依赖专业扫描设备（成本高、视角受限、需要多视角配准），要么依赖人工建模（小时级人力），要么依赖合成管线（需要场景布置与渲染）。三条路径都做不到“抓取即得”，因此 3D 的名义规模增长曲线比 2D 陡峭得多，且增长主要来自合成与众包上传，质量方差随之放大。

第三个机制是标注成本的量级差异。2D 的类别标注是单点决策，一张图一个标签；3D 的标注需要几何一致性——部件分割要在三维空间闭合，语义标签要跨视角一致，物理属性（材质、可动性）需要额外推断。标注一个 3D 资产的成本不是 2D 的线性外推，而是带几何约束的组合任务。这导致 3D 数据集的类别覆盖天然偏向常见物体，长尾类别在规模扩张中被稀释而不是被补齐。

一个具体例子可以说明表示不统一的系统代价：把网格数据与点云数据混合训练一个隐式表面模型，若不做重采样对齐，网格的面片密度在高曲率区域远高于点云，模型会在这些区域过拟合面片分布，而在点云的稀疏区域欠拟合。表现为验证集上整体 Chamfer 距离不降反升——数据量增加了，指标却退化了。这不是“数据越多越差”的玄学，而是损失函数在异质监督下失去了可比性。

三 · 数字底账：把“有效样本数”算成乘性链条

“堆量不涨点”要讲清楚，必须把名义规模与有效规模分开记账。有效样本数不是一个标量，而是一条乘性链条，每一环都是一个过滤器：

$$N_{\text{eff}}=N_{\text{raw}}\times f_{\text{dedup}}\times f_{\text{license}}\times f_{\text{quality}}\times f_{\text{balance}}$$

四个因子分别对应去重、许可过滤、质量分级、类别平衡。它们的乘积决定了真正进入训练的样本量。关键在于：这四个因子不是独立的，顺序也不能随意交换。去重必须在前，因为重复资产会污染质量评分的统计量；许可过滤必须在质量分级之前，因为不可用资产不应占用分级人力；类别平衡是最后一步，它改变的是分布形状而非样本总量。

用定性方式描述这条链的行为：当原始规模从 $N$ 增长到 $2N$ 时，如果新增部分主要来自众包上传，那么 $f_{\text{dedup}}$ 会下降（重复率上升），$f_{\text{quality}}$ 也会下降（低质资产比例上升），而 $f_{\text{license}}$ 可能不变或恶化。结果是 $N_{\text{eff}}$ 的增长远小于 2 倍，甚至可能因为分布偏移而低于原来的有效规模。这就是“堆量”失效的算术解释——不是规模无用，而是规模的增长被过滤器的衰减吃掉了。

第二个账目是评测侧的虚高。评测集与训练集分布重叠会制造指标幻觉。设评测集为 $E$，训练集为 $T$，若 $E\cap T$ 非空且重叠部分属于容易拟合的常见类别，则评测指标会被系统性抬高。这种抬高不是模型能力的真实增长，而是记忆效应。工程上的判断方法是做重叠检测：对评测样本做近邻检索，若在训练集中找到高相似度匹配，则该样本应从评测中剔除或单独统计。忽略这一步，就会把“数据泄漏”误读为“scaling 有效”。

第三个账目是长尾类别的有效覆盖。类别长尾意味着头部类别占据大部分样本，规模扩张时头部增长快于尾部。若用类别平衡因子 $f_{\text{balance}}$ 衡量，它随规模扩张而下降。因此“多样性”不是规模的自然副产品，而是需要主动采样的目标。Objaverse/XL 的意义正在于此：它把量做上去了，证明了大规模 3D 资产集合的可行性，但质与多样性仍是瓶颈——量的增长没有自动转化为类别覆盖的增长。

一个具体例子：假设一条管线对原始资产做去重（相似度阈值）、许可白名单过滤、人工质量分级三档（可用/待修/废弃）、再按类别配额采样。若原始规模翻倍但新增部分重复率高、许可混杂，则去重与许可两道过滤器会吃掉大部分增量，质量分级的人力成本却随规模线性上升。此时工程判断不是“继续堆量”，而是先修去重与许可的自动化程度，把 $f_{\text{dedup}}$ 与 $f_{\text{license}}$ 拉回可接受区间，再谈规模。

四 · 评分演练：把判分点映射到机制句

评分标准的两半结构决定了答题的组织方式。差异部分需要覆盖四个维度：表示、采集、许可、标注。每个维度写一句“性质差异”，再写一句“传导到训练的后果”。不涨点部分需要覆盖四条机制：重复与低质、类别长尾、许可受限、评测重叠。每条机制写一句“作用位置”，再写一句“为什么规模增长被抵消”。

演练一：差异维度的满分写法。表示维度不能只写“3D 有多种格式”，而要写出“表示不统一导致监督信号的几何语义不一致，混训时损失函数失去可比性”。采集维度不能只写“采集难”，而要写出“三条获取路径（扫描、建模、合成）各自的成本结构与质量方差”。许可维度要写出“许可过滤是乘性因子，作用在去重之后，会整段切掉长尾类别”。标注维度要写出“几何一致性约束使标注成本非线性于 2D”。

演练二：不涨点维度的满分写法。重复与低质要写成“新增规模主要来自众包，重复率与低质比例随规模上升，去重与质量因子衰减吃掉增量”。类别长尾要写成“头部增长快于尾部，平衡因子随规模下降，多样性需主动采样”。许可受限要写成“可用子集小于名义规模，且切掉的是长尾段”。评测重叠要写成“训练评测分布重叠制造记忆效应，指标虚高不是能力增长”。

演练三：常见错误的扣分位置。“以为数据越多一定越好”错在把名义规模当有效规模，缺乘性链条。“忽略许可”错在漏掉一个乘性因子，且没意识到它改变分布形状。“忽略评测泄漏”错在把虚高当增长，缺重叠检测这一步。这三类错误各自对应判分点上的一个空缺，扣分是结构性的而非表述性的。

演练四：如何用一句话锁定瓶颈。满分答案的收尾不是罗列，而是判断：在当前管线下，瓶颈是去重自动化不足还是许可白名单覆盖不够，决定了下一步该修哪一环。这个判断把“清洗比堆量重要”从口号变成工程决策——清洗的哪一步重要，取决于哪一环的因子衰减最严重。

演练五：表格化对照。把三档答案在四个判分点上的表现列成表，可以看出分差来自机制句的有无，而非字数。

判分点及格档良好档满分档
采集难/格式杂罗列现象给出因果链指出表示不统一传导到损失函数
许可/标注提及存在说明可用子集变小把许可写成乘性因子并指出切掉长尾
重复/低质/长尾并列三条说明规模扩张被抵消给出有效样本数乘性链条与平衡因子衰减
评测虚高一句带过说明分布重叠给出重叠检测与记忆效应的区分

这张表的用法不是背，而是自查：写完答案后逐行对照，若某一行停在“及格档”列，说明该判分点只有断言没有机制，需要补一句传导路径。评分演练的本质是把判分点翻译成机制句，再用机制句检查自己的答案是否每一半都站得住。

最后一个工程判断落在乘性链条的顺序上：去重与许可过滤是低成本高杠杆的两环，质量分级是人力密集的一环，类别平衡是分布修正的一环。当规模扩张时，先修前两环的自动化，再谈分级与平衡，才是把“堆量”转化为“有效 scaling”的实际路径。这条路径的判断依据不是数据总量，而是四个因子的乘积——哪一环衰减最严重，哪一环就是当前的真瓶颈。
