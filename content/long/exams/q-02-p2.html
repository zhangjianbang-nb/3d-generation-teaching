一 · 变体题的设计逻辑与三档改法

变体题不是把原题换个说法，而是沿着“判分点”改变约束，让考生的答案从背诵公式转为推导。原题的四个判分点是协方差分解、投影公式、深度排序加 alpha 合成、致密化与剪枝。变体题应当只动其中一个或两个判分点，其余保持稳定，否则无法区分考生是真正理解机制还是只会套模板。下面给出三个变体，每个都对应一个明确的改动轴。

变体 A 改“投影公式的输入”。原题给的是世界空间协方差 Σ=RSSᵀRᵀ，问投影后的 Σ'。变体 A 把问题倒过来：给定屏幕空间 2D 椭圆的长短轴与旋转角，问如何反推该高斯在世界空间的最小协方差方向，并说明为什么反推不唯一。这个变体考的是考生是否理解 J W Σ Wᵀ Jᵀ 是一个降维映射：3×3 的 Σ 经过 2×3 的 J W 变成 2×2 的 Σ'，映射的零空间对应沿视线方向的尺度，该分量在投影中丢失。及格档只答出“反推不唯一，因为深度方向信息丢失”；良好档写出 Σ'=J W Σ Wᵀ Jᵀ 并指出 J W 的秩为 2、核为一维；满分档进一步说明工程上如何用多视角约束补回该自由度，例如同一高斯在两个视角下的 Σ' 联立，或用深度排序中的深度值作为额外约束。

变体 B 改“排序的必要性”。原题问“为什么必须按深度排序”，变体 B 追问：如果两个高斯的屏幕椭圆重叠且深度接近，排序键取质心深度是否足够？什么情况下会出错？这考的是 alpha 合成的不可交换性与排序键的粒度。及格档答“alpha 合成不可交换，必须排序”；良好档指出质心深度对长条形椭球不够，一个沿视线方向拉长的高斯，其前端与后端深度差很大，用质心深度会把前后关系判反；满分档给出修正思路：按每个片元（fragment）的深度而非高斯质心深度排序，或在光栅化时对椭圆覆盖区域做逐片元深度测试，代价是每像素多一次比较与可能的排序开销。

变体 C 改“数量控制”。原题问致密化与剪枝，变体 C 问：致密化在什么梯度条件下触发，剪枝在什么不透明度条件下触发，两者同时进行时如何避免震荡？及格档答出“梯度大则分裂、不透明度低则删除”；良好档说明分裂是把一个高斯克隆或拆成两个，拆分时协方差按采样方向缩小，不透明度按比例调整以保持能量；满分档指出震荡的根源是分裂后新高斯梯度暂时变大又被再次分裂，工程上用“梯度阈值随迭代次数衰减”与“分裂后冷却若干步”抑制，代价是超参数增多、训练对学习率更敏感。

三个变体的共同设计原则是：每个变体只移动一个判分点，且移动后仍能用原题的公式链回答。这样评分时可以沿用原题的比例，只在对应判分点上加减，避免评分标准漂移。

二 · 五个追问的递进结构

追问的作用是在考生给出标准答案后，检验其答案的边界。五个追问按“机制—公式—代价—失败模式—工程判断”递进，每个都要求考生在已有答案上再加一层，而不是重复原答案。

追问 1：Σ=RSSᵀRᵀ 中 S 为什么是对角阵，R 为什么是旋转？这问的是分解的物理含义。S 的对角元是三个主轴上的尺度，R 把主轴旋转到世界坐标的方向。考生若只写公式而不解释 S 与 R 的角色，说明其把分解当成了符号记忆。良好回答应指出：各向异性来自 S 的三个对角元不相等，若 S 退化为标量单位阵，高斯就是球，投影后是圆，遮挡关系仍存在但外观退化。

追问 2：J 是投影雅可比，它在透视投影下随深度变化，那么 Σ' 是否随高斯深度改变？这问的是投影的局部线性化。J 在透视投影下包含 1/z 因子，因此同一世界空间协方差在不同深度下投影出的屏幕椭圆大小不同，这正是“近大远小”的来源。考生应说明 EWA 光栅化正是在每个高斯处取局部 J 做仿射近似，而不是全局一个矩阵。

追问 3：alpha 合成从前往后累加，公式是什么，为什么不可交换？合成式为 C=Σᵢ cᵢ αᵢ Πⱼ<ᵢ(1−αⱼ)，其中 cᵢ 是球谐颜色，αᵢ 是该片元的不透明度。乘积项 Π(1−αⱼ) 依赖顺序，交换两个高斯会改变遮挡衰减，因此不可交换。考生若只答“不可交换”而不写出透过率乘积，说明其没抓住不可交换的数学根源。

追问 4：排序的代价是什么？对 N 个高斯做深度排序是 O(N log N)，但每帧都要重排，因为视角变化后深度顺序改变。工程上常用桶排序或按 tile 分块后局部排序，把全局排序降为每 tile 的小规模排序。失败模式是：排序键用质心深度时，长条形高斯跨 tile 会导致同一高斯在不同 tile 中排序位置不一致，产生接缝。

追问 5：致密化与剪枝如何影响排序代价与显存？高斯数量增加会同时抬高排序的 N log N 与显存占用，剪枝则降低两者但可能删掉贡献小的薄结构。工程判断是：致密化阈值应随训练进度收紧，剪枝不透明度阈值不能设得过高，否则会把半透明边缘（如毛发、烟雾）整片删掉，表现为边缘闪烁。

五个追问的评分可以按“是否给出机制、是否给出公式、是否指出代价或失败模式”三档记分，每个追问独立判分，避免一个追问失手拖垮整题。

三 · 扣分点与判分点的对应表

扣分点必须挂在判分点上，否则考生不知道错在哪。原题评分标准是投影公式与排序各 40%，致密化与剪枝 20%。下表把常见失分映射到判分点与变体，便于阅卷时快速定位。

失分表现对应判分点涉及变体扣分理由
把高斯写成无朝向的点，只给 μ 与 α协方差分解A丢失 S 与 R，无法解释各向异性椭圆
投影只写“乘以视角矩阵”，不写 J投影公式A、B缺少透视局部线性化，Σ' 无法随深度变化
写出 Σ'=J W Σ Wᵀ Jᵀ 但维度写错投影公式AW 为 4×4 齐次、J 为 2×3，维度错说明未理解降维
说“排序是为了性能”而非正确性排序加合成B排序是正确遮挡的前提，不是优化手段
合成式漏掉透过率乘积排序加合成B无法说明不可交换的数学根源
认为高斯数量训练前后不变致密化与剪枝C否定数量自适应，无法解释薄结构补点

阅卷时的操作顺序是：先看投影公式是否含 J W Σ Wᵀ Jᵀ 与维度，再看排序是否与 alpha 合成的透过率乘积绑定，最后看数量控制是否给出触发条件与代价。三项各自独立，不因一项正确而豁免另一项。变体题在此基础上只替换对应判分点的问法，扣分理由沿用同一张表，保证不同变体之间可比。

四 · 常见错误的三类根源

常见错误不是零散的粗心，而是三类认知根源。第一类是把 3DGS 当成点云渲染的变体：考生把高斯视为带颜色的点，于是写不出 Σ 的分解，也解释不了椭圆的长短轴。根源在于没有建立“高斯是各向异性椭球”的图像。纠正方式是要求考生画出 S 取不同对角元时投影椭圆的变化，并指出 S 退化时椭圆退化为圆。

第二类是把排序当成渲染管线的常规优化。考生知道要排序，但说不出不排序会怎样。根源在于没有把 alpha 合成的不可交换性与遮挡正确性联系起来。纠正方式是给一个两高斯重叠的具体例子：前高斯 α=0.5、后高斯 α=0.5，按前到后合成得到 0.5c₁+0.25c₂，交换后得到 0.5c₂+0.25c₁，颜色明显不同，从而说明排序不是性能问题而是正确性问题。

第三类是把高斯数量当成固定超参数。考生能背出致密化与剪枝的名词，但说不清触发条件与代价。根源在于把训练看成一次性优化而非自适应过程。纠正方式是要求考生写出致密化的伪代码思路：对每个高斯累计梯度范数，超过阈值则分裂为二，分裂时沿梯度方向采样两个子高斯、协方差按比例缩小、不透明度按能量守恒调整；同时每若干步按不透明度剪枝，并说明分裂后冷却若干步以避免震荡。

三类错误对应三个判分点，且都与变体题一一对应：第一类在变体 A 暴露，第二类在变体 B 暴露，第三类在变体 C 暴露。教学上可以把三个变体作为诊断题，先让学生做变体，再回到原题，错误根源会比直接做原题更早显现。

五 · 教学建议：从公式链到工程判断

教学不应从“3DGS 是什么”讲起，而应从公式链讲起：μ 与 Σ=RSSᵀRᵀ 定义椭球，Σ'=J W Σ Wᵀ Jᵀ 把它压到屏幕，排序加 alpha 合成决定遮挡，致密化与剪枝决定数量。四步是一条链，每一步的输出是下一步的输入，考生只要记住链的接口就能复现答案，而不必背整段文字。

具体教学动作有三个。第一，让学生手算一个 2D 简化例子：给定 S=diag(2,1)、R 为 45° 旋转、W 为单位阵、J 为沿 x 方向的投影，算出 Σ' 并画出椭圆。这个练习把分解与投影连起来，且不需要 3D 直觉。第二，让学生写排序加合成的伪代码：按深度排序，维护累计透过率 T，每步 C+=T·α·c，T·=(1−α)，并交换两个高斯展示结果不同。第三，让学生给致密化写触发条件与冷却逻辑，并讨论阈值衰减对训练稳定性的影响。

评估上，建议把原题与三个变体做成一组，原题占主要分值，变体各占小分值，五个追问作为口头追测。这样既能测公式记忆，也能测边界理解。对于工程背景的读者，还应强调系统代价：排序的 O(N log N) 与每帧重排、致密化带来的显存增长、逐片元深度测试的每像素开销。这些代价不是附加知识，而是判断“何时该用桶排序、何时该收紧致密化阈值”的依据。

最后落到一个工程判断上：当场景中出现长条形高斯跨 tile 导致的排序接缝时，优先修正的是排序键的粒度而非提高高斯数量；因为增加数量只会放大 N log N 与显存代价，而逐片元深度或按 tile 局部排序直接消除接缝的根源。这个判断把公式链、失败模式与系统代价串在一起，也是本部分要求考生在满分档之外应具备的工程直觉。
