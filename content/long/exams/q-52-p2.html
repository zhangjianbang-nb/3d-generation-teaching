二 · 变体一：把「一致性」换成「可控性」再问一遍

原题问的是多视图一致性有哪几条实现路径，变体题常把它翻转成：如果目标不是「多视图看起来一致」，而是「用户给定的姿态、视角、局部编辑必须被尊重」，三条路径的排序会怎样变化。这个翻转不是文字游戏，它直接改变约束的作用点。共享注意力作用在 token 交互层，它对「条件」的响应是软性的：跨视角自注意力让不同视角的 token 互相看见，但没有任何一项损失强制某个视角必须落在指定姿态上。共享 3D 体积作用在表示层，代价体把多视图投影到同一个体素网格里做聚合，姿态一旦写进投影矩阵，就变成硬性的几何事实。共享几何中间量作用在中间产物层，法线图或法线桥把几何先验外化成一个可检查的张量，可控性体现在你可以直接编辑或替换这个中间量。

把可控性拆成三个可测维度会更清楚：姿态遵循度、局部编辑传播范围、条件冲突时的退化行为。姿态遵循度上，体积路径最强，因为投影矩阵是显式的，视角错了投影就错，聚合结果直接崩坏而不是悄悄偏移；注意力路径最弱，它倾向于把冲突「平均掉」，生成一个谁都不完全像的折中视图。局部编辑传播上，几何中间量路径最可控，改一张法线图的局部区域，影响面被中间量的空间结构限住；体积路径的编辑会通过代价体聚合扩散到相邻体素，传播范围难以精确界定。条件冲突时，注意力路径表现为语义漂移，体积路径表现为空洞或重影，中间量路径表现为法线与 RGB 不一致的接缝。

机制上可以用一个带条件项的注意力公式说明差异。设第 i 个视角的 token 为 Xi，跨视角注意力写作：

$$X_i' = \mathrm{Softmax}\!\left(\frac{Q_i K_{-i}^{\top}}{\sqrt{d}} + b(c_i)\right) V_{-i}$$

其中 b(ci) 是由条件 ci（姿态、编辑掩码）导出的加性偏置。这个偏置只能调制注意力权重，不能保证输出满足硬约束；一旦 b 的尺度设得过大，softmax 饱和，跨视角信息被切断，一致性反而下降。这就是注意力路径在可控性上的系统代价：条件强度与一致性强度在同一组参数上互相拉扯，没有解耦的自由度。

失败模式很具体。假设用户要求把某个物体的正面视角固定为参考图、只允许背面自由生成，同时给出一个明确的俯仰角。注意力路径下，背面视角会向参考图的纹理统计靠拢，俯仰角只被近似遵守，生成结果的轮廓与指定姿态存在可见偏差；体积路径下，俯仰角被投影矩阵锁死，但代价体的分辨率决定了背面细节的上限，俯仰角一大，投影覆盖的体素变稀疏，背面出现块状伪影；中间量路径下，法线桥能精确表达俯仰带来的朝向变化，可一旦参考图与法线预测在遮挡边界上冲突，接缝处的 RGB 与法线互相矛盾，需要额外的融合步骤。三个失败模式对应三种不同的返工成本：调注意力偏置、提体积分辨率、修中间量接缝。

工程判断落在「约束写在哪一层」这个问题上。若产品需求以姿态硬约束为主，选体积路径并把分辨率预算前置；若需求以局部编辑为主，选中间量路径并为中间量单独设一套质检；若需求只是「多视图别太打架」且算力紧张，注意力路径仍是合理起点，但必须接受它无法承诺硬约束。变体题真正考的是：能不能把「一致性」这个词拆成约束层级，而不是背三条路径的名字。

三 · 变体二：单视图输入下的路径退化

原题默认多视图输入，变体题把输入砍到一张图，问三条路径各自退化成什么。这不是简单删掉几个视角，而是共享对象消失后的结构性变化。共享注意力的前提是至少两个视角的 token 序列并存，单视图下跨视角注意力退化为自注意力，一致性约束凭空消失，模型只能靠先验「想象」其他视角。共享 3D 体积的前提是多视图投影到同一代价体，单视图下代价体只剩一条投影射线上的证据，体素聚合退化为沿射线的置信度填充，未被覆盖的体素全靠先验补。共享几何中间量的前提是中间量可从多视图互相校验，单视图下法线预测没有第二视角做交叉验证，中间量的准确性完全依赖单图估计器的泛化能力。

退化程度可以用覆盖度来量化。设代价体分辨率为 N3，单视图投影覆盖的体素数为 C，则有效证据比例为：

$$\rho = \frac{C}{N^3}, \qquad C \approx N^2 \cdot \frac{\Delta}{\cos\theta}$$

其中 Δ 是沿射线方向的采样厚度，θ 是视线与表面法线的夹角。这个式子说明两件事：单视图下 ρ 随分辨率立方级下降，提分辨率不能挽救覆盖率；θ 越大（越斜视），单条射线穿过的体素越多，证据越稀。因此体积路径在单视图下的系统代价不是显存，而是证据稀疏导致的背面空洞，且这个空洞无法通过增加采样密度填补，只能靠生成先验。

注意力路径的退化更隐蔽。单视图自注意力仍然能产出「合理」的背面，但合理性与一致性脱钩：没有第二视角来惩罚错误，模型输出的背面在语义上自洽、在几何上与正面矛盾。典型失败是正面有凹陷结构、背面被生成成凸起，单看每个视角都像那么回事，拼起来才发现轮廓对不上。中间量路径的退化表现为误差放大：单图法线估计在遮挡边界和低纹理区域的误差，会通过法线桥直接传导到 RGB 生成，且没有第二视角的法线做一致性校正，误差不会被平均掉，只会被固化。

具体例子：输入一张正面偏左的物体照片，要求生成背面。体积路径下，代价体在背面区域的证据比例极低，聚合结果接近先验均值，背面呈现过度平滑的「塑料感」；注意力路径下，背面纹理会复制正面的统计特征，出现不合理的对称重复；中间量路径下，法线桥把正面的朝向延续到背面，若物体本身不对称，背面法线场会出现系统性偏转，RGB 与法线在轮廓处错位。三种退化对应三种补救：体积路径需要引入额外的先验生成器补空洞，注意力路径需要显式的对称性检测来抑制复制，中间量路径需要为单图法线估计单独设置信度门控。

变体题的教学价值在于逼读者承认：三条路径的一致性强度是相对于「多视图」这个前提定义的，前提一撤，强度排序不再成立，代价结构也完全换了一套。答题时若仍按原题的三档排序照搬，就是没有识别出前提变化。

四 · 变体三：一致性指标本身能不能被伪造

第三个变体题问：如果只用多视图渲染的像素级一致性作为验收指标，三条路径分别会以什么方式「刷分」。这是一个指标对抗问题，考的是对度量与机制之间缝隙的敏感度。像素级一致性通常用渲染视图之间的光度误差或感知距离衡量，它奖励「看起来一样」，不奖励「几何正确」。三条路径都能在这个指标下取得好看的数值，但刷分方式不同。

注意力路径的刷分方式是纹理平均化。跨视角注意力倾向于把不同视角的 token 拉向共同均值，渲染出来的多视图在低频频段高度一致，高频细节被抹平。光度误差因此下降，但物体表面变得模糊，几何细节丢失。这是一种「以信息量为代价换一致性分数」的交易，指标看不出信息量损失，因为度量本身不惩罚模糊。

体积路径的刷分方式是分辨率妥协。代价体分辨率越低，聚合越平滑，多视图投影到同一体素网格后的差异越小，渲染一致性越高。把分辨率降到某个阈值以下，光度误差会显著改善，但背面细节和薄结构完全消失。指标改善的方向与可用性下降的方向一致，这是最危险的一类刷分：分数与质量反相关。

中间量路径的刷分方式是中间量自洽但几何错误。法线桥强制 RGB 与法线一致，若法线本身是错的（比如把凹面预测成凸面），RGB 会忠实地跟随错误法线，多视图渲染在法线场内部高度自洽，光度误差很低，但渲染出的物体与真实几何不符。指标测的是「RGB 与法线是否一致」，不是「法线与真实几何是否一致」，缝隙就在这里。

可以用一个分解式说明指标的可伪造性。设渲染一致性损失为 Lcons，真实几何误差为 Egeo，两者并不单调相关：

$$L_{\mathrm{cons}} = \underbrace{L_{\mathrm{geo}}}_{\text{几何误差}} + \underbrace{L_{\mathrm{app}}}_{\text{外观误差}} - \underbrace{L_{\mathrm{amb}}}_{\text{歧义抵消}}$$

其中 Lamb 是歧义带来的抵消项：当多条路径都收敛到同一个「合理但错误」的解时，视图之间的差异被抵消，Lcons 下降而 Lgeo 不变。这正好对应解析里那句话：一致性不等于真实。三条路径都可能生成合理但错误的背面，而像素级一致性指标对此完全失明。

工程上的对策是把验收拆成两层：一致性指标只用于筛掉明显崩坏的样本，真实性必须用独立的几何探针，比如从渲染网格重投影回输入视角检查轮廓对齐、检查薄结构是否保留、检查背面法线与正面法线在轮廓处的连续性。具体例子：一个带把手的杯子，体积路径在低分辨率下把手被聚合掉，多视图渲染一致但把手消失；注意力路径把手被纹理平均成模糊团块；中间量路径把手法线被预测成平面，RGB 跟随平面。三种情况下光度误差都低，只有几何探针能发现问题。

这个变体题的扣分点在于：只回答「一致性指标不够」而不指出三条路径各自的刷分机制，等于没答。评分时看的是能否把指标缝隙与具体机制对应起来，而不是泛泛地说指标有局限。

五 · 五个追问的应答骨架

追问一：共享注意力和共享体积能否叠加使用。应答要点是叠加的代价不是加法而是乘法：注意力在 token 层做软约束，体积在表示层做硬聚合，两者串联时，注意力先抹平视角差异，体积再聚合，硬约束的效果被前置的软约束削弱；并联时两套损失争夺梯度，需要显式的权重调度。叠加能提升一致性上限，但显存与训练稳定性同时恶化，属于「有收益但边际递减」的组合。

追问二：几何中间量路径的中间量选法线还是深度。应答要点是法线表达朝向、深度表达位置，法线对纹理不敏感、对遮挡边界敏感，深度对绝对尺度敏感、对薄结构敏感。法线桥的强项是几何约束直接作用在着色上，弱项是法线估计在低纹理区不稳；深度作为中间量的强项是可直接重投影校验，弱项是单图深度尺度歧义。选择取决于下游是否要做重投影一致性检查。

追问三：视图数量增加是否单调提升一致性。应答要点是否定的，存在两个反向机制：一是视角间基线过大时，跨视角注意力找不到对应 token，注意力权重弥散，一致性反而下降；二是代价体在视角增多后，投影覆盖重叠区出现证据冲突，聚合需要更复杂的可见性判断，冲突处理不当会引入重影。解析里「视图越多、共享越显式，一致性越好，代价也越大」是有条件的，条件就是视角分布与可见性处理跟得上。

追问四：三条路径能否互相校验。应答要点是可以构造交叉校验：用体积路径产出的粗几何去约束注意力路径的采样范围，用中间量路径的法线去检查体积路径聚合结果的朝向一致性。交叉校验的代价是三条流水线同时运行，算力翻倍，收益是能把「合理但错误」的背面筛出来，因为三条路径的错误模式不同，同时犯同一个错误的概率低于单条路径。

追问五：如果只允许选一条路径上线，判断依据是什么。应答要点是把需求拆成硬约束比例与算力预算两个轴：硬约束比例高、算力充足选体积；硬约束比例低、需要局部编辑选中间量；两者都不突出、追求吞吐选注意力。判断依据不是路径的「先进程度」，而是约束写在哪一层与预算是否匹配。追问的扣分点在于给出排序却不给条件，或给条件却不落到具体机制。

六 · 扣分点、常见错误与教学建议

扣分点按评分标准的四块展开。三条路径各占 25%，边界占 25%。路径块的扣分集中在「只报名字不讲机制」：写「共享注意力」却不说明它作用在 token 交互层、不说明 softmax 权重只能做软调制，这一块最多拿一半。体积块常见扣分是只提「显存大」而不提分辨率对覆盖率的立方级影响，或把代价体说成「隐式表示」——它是显式体素网格上的聚合，不是神经隐式场。中间量块常见扣分是把法线桥说成「后处理」，它是在生成过程中作为条件注入的中间产物，不是渲染后的修补。

边界块的扣分最重，因为解析明确写了「一致性不等于真实」。只答三条路径不答这句，边界块直接归零。答了这句但没给出「合理但错误」的具体形态，比如没指出背面幻想、没指出薄结构消失、没指出法线与 RGB 自洽但几何错误，边界块只能拿部分。评分演练里已经展示过三档答案的差异，这里要补的是错误清单。

常见错误一：以为注意力等于硬约束。跨视角自注意力是软约束，它的权重可以被条件偏置调制，也可以被数据分布主导，没有任何一项损失强制某个视角必须满足指定几何。把 softmax 权重当成硬投影是概念错误，会在可控性追问下暴露。

常见错误二：忽略背面幻想。三条路径在单视图或稀疏视图下都会生成「合理但错误」的背面，这是生成先验的必然产物，不是 bug。答题时若不提背面幻想，等于没有触及一致性≠真实的核心。背面幻想的具体形态包括：对称复制正面纹理、把凹面填成凸面、薄结构被平滑掉、遮挡边界处的法线与 RGB 错位。

常见错误三：以为视图越多一定越好。视图增多带来基线增大与证据冲突两个反向机制，一致性不是视图数的单调函数。正确表述是：视图数增加在可见性处理跟得上的前提下提升一致性上限，代价是聚合复杂度与显存上升；处理跟不上时，一致性会被冲突拖低。

教学建议落在三个可操作的点上。第一，把三条路径画成一张约束层级图：token 层、表示层、中间产物层，每层标注约束强度与代价类型，让读者看到排序不是凭感觉而是由作用层决定的。第二，用一个统一的失败案例贯穿三条路径，比如带把手的杯子在单视图下的背面生成，让读者对比三种退化形态，这比分别举例更能暴露差异。第三，把验收指标拆成一致性与真实性两层，强制读者为每条路径设计一个几何探针，探针设计不出来就说明没真正理解该路径的约束作用点。

最后落到一个工程判断：三条路径的选择不是「哪条更强」，而是「约束写在哪一层、预算是否匹配、验收能否穿透指标缝隙」。共享注意力便宜但只承诺软一致，共享体积硬但把分辨率与覆盖率绑死，共享几何中间量精确但把准确性外包给中间量估计器。任何一条路径上线前，都必须回答同一个问题：当一致性指标很好看时，用什么独立探针证明它不是「合理但错误」。
