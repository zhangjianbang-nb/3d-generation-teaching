一 · 题目定位与判分骨架

q-50 属于第 4 层 theory 题，问句只有一句：「SDS 为什么是『有偏』的？偏差来自哪两个近似？」这句话里藏着两个必须同时满足的约束：其一，必须给出「有偏」的定性结论，而不是把 SDS 描述成某种近似无偏的蒸馏；其二，必须把偏差拆成两个可命名的近似，而不是笼统归因于「2D 先验不够好」。评分标准写明「两层偏差各 50%」，这意味着只答对一层、另一层用模糊话带过，上限就是一半分。判分点列出四项：2D 得分≠3D 得分、单样本估计方差、忽略当前分布、过饱和/多面。前两项对应两层近似，后两项是叠加后的可观测后果。常见错误三条：以为 SDS 无偏、只归因于 CFG、忽略单样本方差。这三条错误恰好对应三种典型的失分路径，后面会逐一拆开。

先把答案的骨架摆出来，再往里填机制。及格档的骨架是：SDS 用 2D 扩散模型在噪声图上的得分替代 3D 分布投影的得分，这是第一层近似；用单次噪声样本估计期望，这是第二层近似；两层叠加导致过饱和、多面、几何不准。良好档要在此基础上说清「为什么 2D 得分不能直接当 3D 得分」以及「单样本估计的方差为什么大、忽略了什么」。满分档还要能指出 VSD 修正的是第二层而非第一层，因此 SDS 家族任何方法都不构成「真 3D 监督」，并且能解释 CFG 只是放大已有偏差而不是偏差的来源。

这里有一个容易被忽略的判分细节：题目问的是「为什么有偏」，而不是「SDS 怎么工作」。所以答案的重心必须落在偏差的来源上，而不是把 SDS 的更新公式从头推导一遍。推导可以作为机制解析的一部分出现，但它服务于「偏差从哪来」这个问句，不能变成公式展览。评分标准把两层偏差各占 50%，实际上是在强制答案具备对称结构：两层都要有命名、有机制、有后果，不能一层详写一层一笔带过。

二 · 第一层近似：2D 得分不等于 3D 得分

第一层近似的准确表述是：SDS 把 2D 扩散模型在噪声图上的得分，当成 3D 分布投影的得分。这里的关键词是「投影」。给定一个 3D 场景或 3D 资产，从某个相机视角渲染出 2D 图像，这个渲染过程是一个投影算子。3D 分布在这个投影下的边缘分布，才是 2D 扩散模型应当建模的对象。但 2D 扩散模型是在真实 2D 图像集上训练的，它学到的是自然图像分布的得分场，而不是「某个 3D 分布在当前视角下的投影分布」的得分场。两者之间的差距就是第一层偏差。

用公式把这件事写清楚。设 3D 变量为 \(x\)，相机参数为 \(c\)，渲染算子为 \(R(\cdot;c)\)，则投影后的 2D 变量为 \(y=R(x;c)\)。3D 分布在投影下的边缘分布记为 \(p_{3D}(y\mid c)\)，而 2D 先验记为 \(p_{2D}(y)\)。SDS 的更新方向本质上是拿 \(\nabla_y \log p_{2D}(y)\) 去替代 \(\nabla_y \log p_{3D}(y\mid c)\)。这两个得分场的差，就是第一层偏差的数学位置：

$$\Delta_1(y,c)=\nabla_y\log p_{2D}(y)-\nabla_y\log p_{3D}(y\mid c)$$

这个差值不会因为优化步数增加而消失，也不会因为换一个更强的 2D 模型而自动归零，因为 \(p_{2D}\) 和 \(p_{3D}(\cdot\mid c)\) 是两个不同的分布。2D 先验里包含了大量与当前 3D 实例无关的图像统计规律，比如纹理的局部对比度、边缘的锐利程度、物体轮廓的典型比例。这些规律在真实图像上是对的，但把它们当作某个具体 3D 分布在特定视角下的投影分布，就是一次概念替换。替换的代价是：优化过程会被拉向「看起来像自然图像」的区域，而不是「与当前 3D 几何一致」的区域。

具体例子：一个多面体资产在某个视角下应当呈现清晰的棱边和受光面，但 2D 先验见过的大量自然图像里，类似轮廓往往伴随柔和的阴影过渡和较高的局部对比度。于是 SDS 的更新会把渲染结果往「高对比、边缘锐利、表面饱和」的方向推。棱边被强化到超出几何允许的程度，面与面之间的过渡被压扁，结果就是多面感和过饱和。这不是优化器的问题，而是第一层近似在得分场层面就把目标带偏了。

系统代价方面，第一层偏差是结构性的：它不随采样数量增加而减小，也不随粒子模型引入而消除。VSD 引入粒子模型修正的是第二层近似，但 2D 到 3D 的第一层偏差仍在。所以任何 SDS 家族方法都不是「真 3D 监督」。这句话是判分点里「2D 得分≠3D 得分」的落点，也是满分档必须点明的边界。工程判断上，这意味着不能把 SDS 家族的训练损失当作 3D 真值的无偏估计来用；它能提供有用的梯度信号，但这个信号的期望方向本身带有系统性偏移。

失败模式上，第一层偏差最典型的可观测后果是「多面」。当 2D 先验对棱边和面片对比的偏好强于当前 3D 几何的实际约束时，优化会把本应连续过渡的区域推向离散的面片化外观。另一个后果是几何不准：2D 先验不携带深度、法线、遮挡关系的一致性约束，它只看单张渲染图，因此无法判断某个亮区是来自真实受光面还是来自错误的法线朝向。这两类后果与第二层偏差叠加后，会进一步放大成过饱和。

三 · 第二层近似：单样本估计期望，方差大且忽略当前分布

第二层近似的准确表述是：用单次噪声样本估计期望，方差大且忽略当前 3D 分布。SDS 的更新方向在理想情况下应当是对噪声样本求期望，即对 \(\nabla_y \log p_{2D}(y+\sigma\epsilon)\) 在 \(\epsilon\) 上的期望。但实际实现里每次只采一个 \(\epsilon\)，用这一个样本的得分作为期望的估计。这就是蒙特卡洛估计的退化形式：样本数为 1。

把估计写出来。设噪声水平为 \(\sigma\)，噪声样本为 \(\epsilon\sim\mathcal{N}(0,I)\)，单样本估计为 \(g(\epsilon)=\nabla_y\log p_{2D}(y+\sigma\epsilon)\)，真实期望为 \(\bar{g}=\mathbb{E}_{\epsilon}[g(\epsilon)]\)。单样本估计的误差是 \(g(\epsilon)-\bar{g}\)，其协方差为 \(\mathrm{Cov}(g(\epsilon))\)，量级不随优化进程衰减。方差大的直接后果是更新方向抖动：相邻两步的梯度方向可能差异显著，优化轨迹在目标附近来回摆动，而不是稳定收敛。

$$\hat{g}=g(\epsilon),\quad \mathbb{E}[\hat{g}]=\bar{g},\quad \mathrm{Var}(\hat{g})=\mathrm{Var}(g(\epsilon))\gg 0$$

更关键的是「忽略当前 3D 分布」。理想的期望应当以当前 3D 分布为条件，即 \(\mathbb{E}_{\epsilon\sim p_{3D}(\cdot\mid c)}[\cdot]\)，因为噪声样本应当从当前 3D 实例的投影分布中抽取。但实际实现里噪声样本来自标准高斯，与当前 3D 分布无关。这就导致估计的期望不是「当前 3D 分布下的期望」，而是「各向同性噪声扰动下的期望」。两者在优化早期差距不大，因为当前 3D 分布还很模糊；但在优化后期，当前 3D 分布已经收敛到某个具体形状，噪声样本仍然无视这个形状，估计出的得分方向就会与当前实例的真实需求脱节。

具体例子：优化进行到中后期，当前 3D 资产已经具备大致合理的轮廓，此时理想的做法是从这个轮廓的投影分布附近采样噪声，让得分场在「当前实例附近」提供细粒度修正。但单样本高斯扰动可能把渲染图推到离当前实例很远的区域，2D 先验在那个区域的得分方向与当前实例的修正需求无关，于是更新把资产拉向另一个「看起来合理但与当前实例不一致」的形态。表现出来就是多面：不同步的更新把不同区域推向不同的局部最优，面与面之间缺乏全局一致性。

系统代价方面，第二层偏差是可修正的，这正是 VSD 的切入点。VSD 引入粒子模型，用粒子来近似当前 3D 分布，从而把「忽略当前分布」这一项补上；同时粒子模型可以对多个噪声样本做聚合，降低单样本方差。但修正第二层不等于消除第一层：粒子模型再准，它逼近的仍然是 2D 先验下的得分场，而不是 3D 真值的得分场。所以 VSD 缓解的是抖动和多面，过饱和与几何不准仍然受第一层偏差支配。工程上判断一个 SDS 家族方法是否「更接近真 3D 监督」，不能只看它是否用了粒子模型，还要看它是否对第一层偏差做了任何结构性处理；按给定事实，答案是没有。

失败模式上，第二层偏差最典型的可观测后果是训练不稳定和细节抖动。单样本方差大意味着损失曲线抖动、梯度范数波动，优化器需要更小的学习率或更多的累积步来压制，但累积步只是把多个单样本估计平均，并没有改变「噪声样本不来自当前 3D 分布」这一事实。另一个后果是过饱和：方差大的更新容易把某些像素或面片反复推高，2D 先验对高对比区域的得分又倾向于强化这种推高，两者叠加就把颜色和亮度推到饱和。

四 · 两层叠加的数字底账与可观测后果

两层偏差不是并列关系，而是叠加关系。第一层偏差给出一个系统性偏移的方向，第二层偏差在这个方向上叠加随机抖动。用一张表把「偏差层—机制—可观测后果—是否可被 VSD 修正」对齐，是答案里最容易被评分者抓住的结构。

偏差层机制可观测后果VSD 是否修正
第一层2D 先验得分替代 3D 投影得分过饱和、几何不准否
第二层单样本估计期望、噪声样本不来自当前 3D 分布多面、抖动是（粒子模型）
叠加系统性偏移 + 随机抖动过饱和与多面同时出现部分缓解

数字底账要落在「50% + 50%」这个评分结构上，而不是编造实验数字。给定事实里没有给出任何定量实验结果，所以这里只能做定性表述：两层偏差各占评分的一半，意味着答案必须对两层都给出可命名的机制，不能把「单样本方差」写成「采样噪声大」这种不具判分点对应关系的模糊说法。判分点里的「忽略当前分布」是第二层的关键限定词，只写「方差大」而不写「忽略当前分布」，第二层就只能拿一半里的部分分。

可观测后果的对应关系也要写准。过饱和主要来自第一层：2D 先验对高对比、高饱和区域的偏好被当作 3D 投影的得分，优化把颜色和亮度推向先验偏好的极值。多面主要来自第二层：单样本方差导致不同区域被推向不同局部最优，面片之间缺乏一致性。几何不准则是两层共同作用：第一层不携带深度与法线约束，第二层又让更新方向抖动，几何细节无法稳定收敛。把「过饱和/多面」两个判分点分别挂到两层上，是满分档与良好档的分界线之一。

具体例子：一个包含曲面和平面混合的资产，在优化中后期，平面区域被第一层偏差推向过饱和的高对比外观，曲面区域被第二层偏差推向面片化的多面外观，两者同时出现，最终资产既不像真实几何，也不像自然图像。这个例子说明两层偏差不是「先解决一层再解决另一层」的串行关系，而是在同一优化轨迹上同时起作用。

系统代价上，叠加偏差带来的工程后果是：不能通过单纯增加采样数来消除偏差。增加采样数只能压低第二层的方差，第一层的系统性偏移原样保留。也不能通过换更强的 2D 模型来消除偏差，更强的 2D 模型只会让第一层的偏移更「自信」，把资产更坚定地拉向 2D 先验偏好的区域。工程判断是：SDS 家族的损失函数应当被当作「有偏的正则项」使用，而不是「无偏的 3D 监督」使用；在需要几何精度的环节，必须引入真正的 3D 约束或后处理，而不能指望 SDS 自己收敛到真值。

五 · 评分演练：三档答案的写法与失分点

及格档的写法：直接给出两层近似的命名，第一层写「2D 得分不等于 3D 得分」，第二层写「单样本估计方差大」，然后列出过饱和、多面、几何不准三个后果。这样写能拿到两层各 50% 的命名分，但第二层缺少「忽略当前分布」这个限定，后果与偏差层的对应关系也没有展开，所以上限在及格到良好之间。及格档最常见的失分是把第二层写成「采样噪声」，这个词不构成判分点，评分者无法把它对应到「单样本估计方差」。

良好档的写法：在及格档基础上，第一层补上「投影」的概念，说明 2D 先验建模的是自然图像分布而不是 3D 投影分布；第二层补上「噪声样本不来自当前 3D 分布」，说明单样本估计的期望不是当前分布下的期望。后果部分把过饱和挂到第一层、多面挂到第二层。良好档的失分点通常是：没有点明第一层偏差不随采样数增加而消失，或者没有点明 VSD 只修正第二层。这两点缺一个，就从良好档掉回及格档。

满分档的写法：在良好档基础上，给出第一层的公式位置 \(\Delta_1(y,c)\)，说明这是两个得分场之差；给出第二层的估计式 \(\hat{g}=g(\epsilon)\) 与方差项，说明方差量级不随优化衰减；点明 VSD 修正第二层但第一层仍在，因此 SDS 家族不是真 3D 监督；点明 CFG 只是放大已有偏差而不是偏差来源。满分档还要能处理常见错误：如果答案把偏差归因于 CFG，评分者会认为没有抓住两层近似；如果答案说 SDS 无偏，直接判为概念错误。

评分演练的具体做法：拿一份只写了「SDS 有偏，因为 2D 先验不准」的答案，按判分点逐项核对——「2D 得分≠3D 得分」有对应表述但没展开，「单样本估计方差」缺失，「忽略当前分布」缺失，「过饱和/多面」只提了过饱和。四项判分点命中一项半，两层偏差只答了一层，得分上限一半。再拿一份写了「两层：2D 先验不等于 3D 真值；单样本估计方差大且忽略当前分布；后果是过饱和和多面」的答案，四项判分点全部命中，两层各 50% 的结构完整，但没有点明 VSD 只修正第二层，属于良好档的上沿。满分档需要在良好档基础上再加「第一层不可修正、SDS 家族非真 3D 监督」这一句边界判断。

失分点的工程含义也值得写进演练：评分标准把两层各占 50%，实际上是在检验答题者是否理解「偏差有两个独立来源」这一结构。只答一层的人，往往在工程上也会犯同样的错误——以为换个采样策略或加个 CFG 调参就能消除偏差。评分演练的目的不是猜分数，而是把「两层独立、一层可修正一层不可修正」这个判断固化下来，因为它在工程决策上直接对应「哪里可以靠算法改进、哪里必须靠外部 3D 约束」。

六 · 机制落点：偏差的来源与不可消除的边界

把两层偏差放回 SDS 的更新机制里看，偏差的来源就清楚了。SDS 的更新方向是 2D 得分场在噪声图上的取值，减去噪声项，再乘一个系数。这个方向在期望意义上等于 2D 先验得分场的一个平滑版本，而不是 3D 分布投影得分场。第一层偏差就发生在「得分场替换」这一步：替换发生在期望之前，所以它不是采样误差，而是目标函数本身的偏移。第二层偏差发生在「期望估计」这一步：用单样本代替期望，且样本分布不是当前 3D 分布，所以它是估计误差叠加分布错配。

这两步的先后顺序决定了修正的边界。第一层在期望之前，所以任何对期望估计的改进（增加样本、引入粒子模型、降低方差）都无法触及它；第二层在期望估计内部，所以粒子模型、多样本聚合、重要性采样这些手段可以修正它。VSD 引入粒子模型，修正的正是第二层：粒子模型逼近当前 3D 分布，让噪声样本的分布与当前实例对齐，同时对多个样本做聚合降低方差。但粒子模型逼近的仍然是 2D 先验下的得分场，第一层的得分场替换没有被触碰。这就是「任何 SDS 家族方法都不是真 3D 监督」的机制依据。

具体例子：在优化后期，粒子模型已经把当前 3D 分布逼近得相当准，第二层偏差被压到很小，更新方向稳定，多面感明显减弱。但过饱和仍然存在，因为 2D 先验对高对比区域的偏好在第一层就已经进入得分场，粒子模型只是让这个偏好被更稳定地执行，而不是消除它。工程上看到的现象是：换用 VSD 后训练更稳、多面减少，但颜色饱和度和几何精度没有本质改善。这个现象正好对应两层偏差的可修正性差异。

失败模式上，如果工程上把 VSD 当作「消除 SDS 偏差」的方案，就会在需要几何精度的任务上反复失望。正确的判断是：VSD 解决的是第二层的抖动与分布错配，第一层的系统性偏移必须靠外部 3D 约束（多视角一致性、深度监督、几何后处理）来压制。评分标准里「两层偏差各 50%」的结构，实际上也是在提示这个工程判断：两层各有各的修正手段，不能互相替代。答案落在「第一层不可被 SDS 家族自身修正」这个机制判断上，比任何笼统的「SDS 有偏」都更接近题目的问句。
