一 · 三档答案的骨架：从“名词复述”到“梯度结构”

这道题问的是 VSD 与 SDS 的核心差别，以及它为什么能缓解过饱和与多样性差。评分标准把分数切成两半：核心差别占 50%，改善机制占 50%。这意味着只答出“VSD 多了一个粒子模型”最多拿到一半里的部分分，而完全说不清“为什么这样就能改善”则另一半直接归零。三档答案的差别，本质上不是文采差别，而是答案里是否出现了可被判分点识别的结构。

及格档答案的典型形态是名词对照：SDS 用 2D 扩散模型的得分直接指导 3D，VSD 额外引入一个粒子模型 ε_ψ，因此更稳定、多样性更好。这段话每个词都对，但它没有回答“核心差别”是什么——它只说了 VSD 多了一个组件，没有说这个组件在梯度里扮演什么角色。判分点里的“SDS 忽略当前 3D 分布”和“梯度含 (ε_φ−ε_ψ)”都没有出现，改善机制部分也只有定性形容词。按 50%+50% 的切分，这类答案通常只能拿到核心差别的一半和改善机制的零头。

良好档答案会补上减号项：SDS 把 2D 扩散的得分当成 3D 分布的得分，忽略了“当前 3D 分布”这一项；VSD 用 ε_ψ 近似当前 3D 分布在 2D 投影下的得分，梯度变成 ε_φ 减 ε_ψ。到这里核心差别的两个关键判分点已经齐了。但良好档往往在改善机制上停住：说“偏差被纠正、过饱和减轻”，却不解释偏差从哪来、为什么粒子模型随 3D 参数一起更新就能纠正它。改善机制那 50% 只拿到一部分。

满分档答案在这之上再加两层。第一层是变分视角：VSD 最小化 3D 分布与文本条件 2D 分布之间的 KL，ε_ψ 是当前分布的得分估计，所以梯度不是一味拉向文本，而是拉向文本的同时扣除已有分布。第二层是把“粒子模型随 3D 参数一起更新”讲成机制而非附注：ε_ψ 若固定不变，减号项就变成一个静态偏置，无法跟踪当前 3D 分布的变化，纠正偏差的能力就退化了。这两层分别对应判分点里的“KL/变分视角”和常见错误里的“以为粒子模型固定不变”。满分档的特征是：五个判分点全部显式出现，且减号项被解释成“扣除已有分布”而不是“两个网络相减”。

档位核心差别（50%）改善机制（50%）典型缺口
及格只说“多一个粒子模型”只有“更稳定/多样性好”无减号项、无 KL 视角
良好点出忽略当前 3D 分布、写出 ε_φ−ε_ψ说“偏差被纠正”但不讲机制粒子模型更新被当成附注
满分差别 + 减号项语义KL 视角 + 粒子模型随参数更新无（五点齐全）

这张表的用处不是给人贴标签，而是给写作者一个自检清单：把左列当成必须出现的判分点，把右列当成必须解释清楚的因果链。及格档到良好档的跃迁靠“补名词”，良好档到满分档的跃迁靠“补因果”。

二 · 机制解析：SDS 的得分错位与 VSD 的减号语义

SDS 的做法是把 2D 扩散模型 ε_φ 的得分直接当成 3D 分布的得分来用。用公式写，SDS 的梯度方向近似为“文本条件得分减去噪声预测”，即把 ε_φ 当作 ∇log p_3D 的估计。问题在于 ε_φ 是在 2D 图像分布上训练的，它估计的是“给定文本条件下 2D 图像的得分”，而不是“当前 3D 分布在 2D 投影下的得分”。这两者之间差了一项：当前 3D 分布本身。SDS 把这个差值当成零，于是梯度只包含“拉向文本”的力，没有“扣除当前分布”的力。

$$\nabla_\theta \mathcal{L}_{\text{SDS}} \approx \mathbb{E}\left[(\epsilon_\phi(\mathbf{x}_t; y) - \epsilon)\right]$$

这个表达式里没有出现任何描述“当前 3D 分布”的量。当 3D 参数 θ 把一个粒子推到文本得分高的区域时，SDS 不会因为“这个区域已经被大量粒子占据”而减小推力，于是粒子持续被推向同一批高得分方向，结果是过饱和：颜色、密度、几何细节被过度强化；同时模式坍塌：不同初始化的粒子收敛到少数几个文本高分模式，多样性下降。这不是训练不稳定，而是目标函数本身缺了一项。

VSD 的修正是引入粒子模型 ε_ψ 来近似“当前 3D 分布在 2D 投影下的得分”。梯度变成文本得分与当前分布得分之差：

$$\nabla_\theta \mathcal{L}_{\text{VSD}} \approx \mathbb{E}\left[(\epsilon_\phi(\mathbf{x}_t; y) - \epsilon_\psi(\mathbf{x}_t))\right]$$

减号项 ε_ψ 的语义不是“减去一个网络输出”，而是“扣除当前分布已经解释掉的得分”。当某个方向已经被当前 3D 分布覆盖，ε_ψ 在该方向的得分就高，ε_φ−ε_ψ 就小，推力自动减弱；当某个文本要求的方向尚未被当前分布覆盖，ε_ψ 低，差值大，推力保留。这就是“拉向文本同时扣除已有分布”的机制。过饱和被缓解，是因为高得分区域不再被无条件强化；多样性提升，是因为未被覆盖的模式仍保有推力，粒子不会全部挤向同一批模式。

从变分视角看，VSD 最小化的是 3D 分布与文本条件 2D 分布之间的 KL。KL 的形式要求同时出现“目标分布”和“当前分布”两项，SDS 只保留了目标项，VSD 用 ε_ψ 把当前分布项补了回来。这个视角解释了为什么减号项不可省略：去掉它，KL 就退化成单向拉拽。常见错误“以为 VSD 只是多训一个网络”正是漏掉了这层语义——多一个网络是手段，补上当前分布项才是目的。

系统代价在这里出现：ε_ψ 需要随 3D 参数 θ 一起更新。若 ε_ψ 固定不变，它近似的是某个历史时刻的 3D 分布，减号项变成静态偏置，无法跟踪当前分布的变化，偏差纠正能力退化，过饱和与坍塌会重新出现。这正是常见错误“以为粒子模型固定不变”的代价。工程上这意味着每个训练步要多一次粒子模型的更新，显存与算力开销高于 SDS；但换来的是梯度里多了一项可解释的修正力。

三 · 数字底账：题目给定的量化结构

这道题没有给出实验数字，所有量化信息都来自评分标准与判分点的结构。把这些结构当成“底账”来记，比记任何定性形容词都可靠。

  • 评分切分：核心差别 50%，改善机制 50%。两半等权，意味着任何一半缺失都直接损失一半分数。
  • 判分点共五个：SDS 忽略当前 3D 分布；VSD 加粒子模型 ε_ψ；梯度含 (ε_φ−ε_ψ)；KL/变分视角；多样性/过饱和改善。
  • 常见错误共三个：以为 VSD 只是多训一个网络；漏掉减号项；以为粒子模型固定不变。
  • 题目层级：第 4 层 / paper，说明这是论文级深读题，答案需要覆盖机制而非仅复述结论。

把五个判分点与两半评分对齐：前两个判分点落在核心差别半区，后三个落在改善机制半区。这意味着“梯度含 (ε_φ−ε_ψ)”虽然写在核心差别里，但它同时是改善机制的解释工具——减号项既是差别，也是机制。写答案时若把减号项只当成“差别”一笔带过，改善机制半区就会失去最有力的论据。

判分点所属半区缺失后果
SDS 忽略当前 3D 分布核心差别差别退化为“多一个网络”
VSD 加 ε_ψ核心差别无法说明修正手段
梯度含 (ε_φ−ε_ψ)核心差别 / 机制桥梁减号语义丢失，机制半区失据
KL/变分视角改善机制机制停留在定性描述
多样性/过饱和改善改善机制无法回答“为什么能缓解”

三个常见错误与判分点一一对应：第一个错误对应“VSD 加 ε_ψ”被误读为纯工程增量；第二个错误对应“梯度含 (ε_φ−ε_ψ)”的减号被漏写；第三个错误对应“粒子模型随 3D 参数一起更新”这一机制被忽略。评分演练时，可以把这三个错误当成反向检查表：答案里若出现“只是多训一个网络”“两个网络相减”“粒子模型预训练后冻结”这类表述，就直接对应到失分点。

还有一个隐含的底账：题目问的是“核心差别”与“为什么能缓解”，两个问句对应两半评分。答案若只回答第一个问句，第二个问句用“因此更好”带过，改善机制半区就没有实质内容。满分答案的结构应当是“差别 → 减号语义 → KL 视角 → 粒子模型更新 → 改善结果”的因果链，而不是两个并列的段落。

四 · 评分演练：三段答案的逐点对照

下面用三段不同档位的答案做逐点对照，展示判分点如何在实际文本里被识别或漏掉。三段答案都只围绕题目给定的内容，不引入外部事实。

第一段（及格档）：“SDS 直接用 2D 扩散模型指导 3D，VSD 多了一个粒子模型，所以 VSD 效果更好，过饱和和多样性差的问题得到缓解。”逐点对照：核心差别半区只命中“VSD 加 ε_ψ”的字面，未出现“SDS 忽略当前 3D 分布”，未出现减号项；改善机制半区只有“效果更好”和结果名词，没有 KL 视角，也没有粒子模型更新的机制。判定：核心差别部分得分，改善机制接近零。

第二段（良好档）：“SDS 把 2D 得分当成 3D 得分，忽略了当前 3D 分布这一项；VSD 引入 ε_ψ 近似当前 3D 分布在 2D 投影下的得分，梯度是 ε_φ 减 ε_ψ。粒子模型随 3D 参数更新，偏差被纠正，所以过饱和减轻、多样性提升。”逐点对照：核心差别半区三点齐全（忽略当前分布、加 ε_ψ、减号项）；改善机制半区出现了“粒子模型随参数更新”和结果，但 KL/变分视角缺失，“偏差被纠正”没有展开成“扣除已有分布”的语义。判定：核心差别满分，改善机制部分得分。

第三段（满分档）：“SDS 的梯度只有拉向文本的力，因为 ε_φ 估计的是文本条件 2D 得分，而不是当前 3D 分布在 2D 投影下的得分，当前分布项被当成零。VSD 用 ε_ψ 补上这一项，梯度为 ε_φ−ε_ψ；减号不是两个网络相减，而是扣除当前分布已经解释掉的得分：已被覆盖的方向推力减弱，未被覆盖的方向推力保留。从变分视角看，这等价于最小化 3D 分布与文本条件 2D 分布的 KL，KL 要求目标项与当前项同时出现。ε_ψ 随 3D 参数一起更新，才能跟踪当前分布；若固定不变，减号项变成静态偏置，纠正能力退化。因此过饱和与模式坍塌减轻，多样性提升。”逐点对照：五个判分点全部显式出现，减号语义被解释，粒子模型更新被讲成机制而非附注，三个常见错误均被反向排除。判定：两半均满分。

判分点及格段良好段满分段
SDS 忽略当前 3D 分布缺有有（并解释为零项）
VSD 加 ε_ψ字面有有（并说明近似对象）
梯度含 (ε_φ−ε_ψ)缺有有（并解释减号语义）
KL/变分视角缺缺有
多样性/过饱和改善结果名词有因果雏形有完整因果链

演练的结论可以落到一个可操作的自检顺序：先检查减号项是否写出，再检查减号是否被解释为“扣除当前分布”，再检查 KL 视角是否出现，最后检查粒子模型更新是否被写成机制。这个顺序对应从良好档到满分档的跃迁路径，也对应评分标准里两半的权重分配。

五 · 失分模式与工程判断

三个常见错误各自对应一种可识别的失分模式。第一种，“以为 VSD 只是多训一个网络”：答案把 ε_ψ 描述成附加组件，没有说明它近似的是“当前 3D 分布在 2D 投影下的得分”，于是核心差别半区失去“忽略当前分布”的对照，改善机制半区也失去解释对象。第二种，“漏掉减号项”：答案写成“VSD 用两个得分共同指导”，没有写出 ε_φ−ε_ψ 的差，减号语义丢失，判分点“梯度含 (ε_φ−ε_ψ)”直接缺失，同时改善机制失去最有力的论据。第三种，“以为粒子模型固定不变”：答案把 ε_ψ 当成预训练后冻结的评估器，忽略了“随 3D 参数一起更新”这一机制，偏差纠正的因果链断裂，改善机制半区退化为定性断言。

这三种失分模式的共同点是：它们都不是事实错误，而是结构缺失。答案里的每个名词都正确，但判分点要求的“对照项”“减号”“更新机制”没有出现。评分标准按判分点给分，因此结构缺失直接转化为分数损失，而不是“表达不够好”的扣分。工程背景的读者容易犯第一种错误，因为“多训一个网络”在工程上是最直观的描述；也容易犯第三种错误，因为把评估模型冻结在工程上更省算力。这两种直觉恰好与 VSD 的机制相反：ε_ψ 的价值不在于它是一个网络，而在于它跟踪当前分布；冻结它就等于放弃跟踪。

从系统代价看，VSD 的减号项要求 ε_ψ 与 3D 参数同步更新，这带来每步额外的更新开销与显存占用。工程判断在这里不是“VSD 更贵所以更好”，而是“减号项的有效性依赖于 ε_ψ 的跟踪能力，跟踪能力依赖于同步更新”。若为了省算力冻结 ε_ψ，减号项就退化为静态偏置，过饱和与坍塌会重新出现——这时省下的算力换来的是目标函数的缺陷。反过来，若同步更新但漏写减号项，ε_ψ 就变成一个未被使用的网络，开销白付。两种失败都说明：VSD 的机制不是“加一个网络”，而是“加一个随参数更新的当前分布估计，并在梯度里减去它”。

评分演练的最终落点是一个工程判断：答案的满分结构，与系统的正确配置，是同一件事的两种表述。梯度里的减号项对应训练循环里的同步更新，KL 视角对应目标函数的完整性，粒子模型的跟踪能力对应减号项的有效性。写答案时若能把这三条对齐，判分点自然齐全；配置系统时若能把这三条对齐，过饱和与多样性差才会真正缓解。
