一 · 三档答案的分野：从名词罗列到机制闭环

这道题问的是「LRM 的架构主干是什么，它为什么能一次前向而不是逐物体优化」。同一个问题，三档答案的差别不在字数，而在是否把「架构」与「为什么能一次前向」这两半接上。评分标准写得很直白：架构 50%，amortized 50%。也就是说，只答对前半段，最多拿一半。

及格档答案的典型形态是名词罗列：ViT、Transformer、cross-attention、三平面、NeRF、渲染损失，六个词都出现了，顺序也对，但每个词之间没有因果连接。读者看完知道 LRM 用了这些组件，却不知道图像 token 是怎么变成三平面 token 的，也不知道为什么这套流程不需要在推理时对每个物体做优化。这种答案能拿到架构分的大部分，但 amortized 那一半基本为零，因为它没有回答「为什么」。

良好档答案会在及格档基础上补上流程：输入图经 ViT 切成 token，Transformer 用 cross-attention 把图像 token 映射到三平面 token，三平面解码成 NeRF 或网格，渲染多视角与真值比对。它还会提到模型在约 50 万物体上训练。这已经是一条完整的推理链路，架构分基本拿满。但它仍然可能停在「描述流程」的层面，没有点破 amortized 的含义：优化过程被蒸进了权重，推理时的一次前向就是在替每个物体做那场原本要迭代的优化。缺了这一句，amortized 分只能拿一半左右。

满分档答案的结构是「架构 + 机制 + 代价」三段闭环。它先说清主干：ViT 切 token，cross-attention Transformer 把图像 token 映射到三平面 token，三平面解码成 NeRF/网格，多视角渲染与真值比对构成训练信号。然后它把 amortized 讲透：训练阶段在约 50 万物体上反复做「图像→三平面」的监督，模型学到的是这个映射的先验，于是推理时一次前向就等价于一次被压缩过的优化。最后它主动交代代价：训练数据的规模与质量决定上限，输出分辨率受三平面分辨率限制。三段都到位，两个 50% 才都拿满。

三档的分野可以压成一句话：及格档答「用了什么」，良好档答「怎么串起来」，满分档答「为什么这样串起来就省掉了优化，以及省掉之后付了什么代价」。阅卷时最容易出现的失分不是写错组件，而是把「一次前向」当成一个不需要解释的事实直接陈述，等于把 50% 的分数让出去。

二 · 机制解析：cross-attention 如何把图像 token 压成三平面 token

要讲清架构，必须讲清 cross-attention 在这一步的角色。ViT 把输入图切成 patch，每个 patch 经过线性投影和位置编码成为一个图像 token，得到一组图像侧的特征序列。三平面侧则维护一组可学习的平面 token，分别对应三个正交平面。Transformer 的 cross-attention 让平面 token 作为 query，图像 token 作为 key 和 value：每个平面 token 去图像 token 集合里检索与自己相关的外观证据，把检索结果聚合回自身。这样，平面 token 不再是脱离图像的自由变量，而是被图像证据约束住的表征。

这个设计的机制含义是：三平面不是从图像里「切」出来的，而是被图像「查询」出来的。图像 token 提供证据，平面 token 提供结构先验，cross-attention 是两者之间的桥。多层堆叠之后，平面 token 逐步吸收多尺度的图像信息，最终每个平面 token 都携带了它在三个正交平面上应该呈现的局部外观。这就是「图像→三平面」映射在网络内部的实现方式。

$$\text{Attn}(Q_p, K_i, V_i)=\mathrm{softmax}\!\left(\frac{Q_p K_i^{\top}}{\sqrt{d}}\right)V_i$$

公式里 \(Q_p\) 是平面 token 的查询，\(K_i\) 与 \(V_i\) 是图像 token 的键与值，\(d\) 是通道维度。softmax 之后的权重矩阵刻画了「每个平面 token 从哪些图像 token 取信息」。这个矩阵不是手工设计的，而是在约 50 万物体的训练中由多视角渲染损失反推出来的。换句话说，cross-attention 的注意力模式本身就是被蒸进权重的那部分「优化经验」。

三平面解码这一步决定了输出的表达形式。三平面把三维空间中的一点投影到三个正交平面上，分别采样三个平面的特征并做聚合，得到该点的特征向量，再送入一个小网络预测密度与颜色，这就是 NeRF 头的做法；若要走网格路线，则在三平面上做等值面提取。两条路线共享同一组三平面 token，区别只在解码器的输出形式。渲染阶段从预测的几何与外观出发，在多个视角下合成图像，与真值比对，构成训练损失。

这里有一个容易被忽略的机制细节：多视角渲染损失是整套架构的监督信号，而不是推理时的步骤。训练时它把「三平面是否真的能解释多视角观测」这一约束压进平面 token；推理时没有真值，也就不需要这个损失，一次前向直接产出三平面。把训练信号误当成推理流程，是机制解析里最常见的错位。

失败模式在这一层也很具体。cross-attention 的容量与平面 token 的数量共同决定了映射的表达能力：平面 token 太少，注意力只能抓到粗粒度证据，细部外观在聚合时被平均掉；层数太浅，平面 token 来不及吸收多尺度信息，映射退化成近似查表。这类失败不会在训练损失上立刻暴露，因为渲染损失对粗粒度错误同样敏感，模型会优先拟合大结构，细部误差被掩盖。工程上的判断是：当渲染结果整体轮廓正确但局部纹理发糊时，先怀疑平面 token 的容量与 cross-attention 的深度，而不是先怀疑训练数据。

三 · amortized 的机制：优化如何被蒸进权重

「一次前向」之所以成立，核心在 amortized 这个词。逐物体优化的做法是：给定一张图，为这个物体单独初始化一组三平面参数，然后反复渲染、比对、反传，迭代到收敛。每个物体都要跑一遍这个循环，时间随物体数量线性增长。amortized 的做法是把这场循环搬到训练阶段：在约 50 万物体上，每个物体都提供「图像 + 多视角真值」，网络反复学习「看到这张图，三平面应该长什么样」。训练结束后，权重里存的是这个映射的统计规律，推理时一次前向就是把这个规律应用到新图上。

用优化的语言说，逐物体优化是在解一个以三平面为变量的逆问题，amortized 则是训练一个函数，把「解逆问题」这件事本身学成一个前向映射。前者每次都要重新求解，后者把求解过程摊薄到训练集上，推理时只做一次函数求值。这就是「amortized」的字面含义：成本被分摊了。

伪代码层面，两种范式的差别一目了然。逐物体优化的循环是：初始化参数，重复「渲染多视角 → 与真值比对 → 反传更新」直到收敛，输出该物体的三平面。amortized 的推理是：图像过 ViT 得 token，cross-attention 得三平面 token，解码得 NeRF/网格，输出。前者循环体内是优化，后者循环体在训练阶段已经跑完，推理阶段只剩前向。

这个机制有一个必须讲清的边界：amortized 不是「不需要 3D 数据」。恰恰相反，它把对 3D 的依赖从推理阶段整体搬到了训练阶段。约 50 万物体的多视角真值就是这场「预优化」的燃料。没有这批数据，权重里就没有可被摊薄的优化经验，一次前向也就无从谈起。常见错误里「以为一次前向不需要 3D 数据」正是踩在这个边界上：把推理时的轻量误读成训练时的无依赖。

系统代价在这里第一次显形。逐物体优化的代价是推理时间随物体数线性增长，但每个物体都能被单独拟合到较高精度；amortized 的代价是训练数据规模与质量决定上限，推理变快的同时，模型只能输出它见过的分布内的合理三平面。遇到训练分布外的物体，一次前向给出的三平面可能结构合理但细节失真，而且没有逐物体优化那样的补救机会——除非退回优化范式，那就等于放弃了 amortized 的速度优势。这是一个明确的取舍，不是可以两头都占的免费午餐。

四 · 数字底账：50 万物体与三平面分辨率

题目给定的事实里只有两个硬数字：约 50 万物体的训练规模，以及三平面分辨率对输出的限制。前者是 amortized 能够成立的数据底账，后者是架构的表达上限。两个数字一个管「学得够不够」，一个管「表达得细不细」，正好对应评分标准的两半。

底账项作用位置不满足时的失败模式
约 50 万物体训练amortized 的预优化燃料映射先验不足，一次前向退化为粗近似
三平面分辨率三平面解码的表达上限细部纹理被平面采样粒度抹平
多视角渲染损失训练阶段的监督信号三平面无法解释多视角观测，几何与外观脱节

50 万这个数字的意义不在绝对大小，而在它支撑的统计覆盖。amortized 要求模型见过足够多样的「图像→三平面」配对，才能把映射的先验学到可用的程度。物体数量少，映射就偏向记忆而非泛化，遇到新图时一次前向的输出会明显偏向训练集中相似的样本。这里不能编造具体的阈值，只能定性地说：训练规模与质量决定上限，规模不足时 amortized 的收益会被映射误差吃掉。

三平面分辨率的账更直接。三平面把三维空间压到三个二维平面上，每个平面是一张固定分辨率的特征图。空间中的一点通过投影到三个平面并采样来取特征，采样粒度就是平面分辨率。分辨率不够时，相邻空间点落在同一个像素上，特征无法区分，解码出的几何与外观在细部上被抹平。这不是训练能修复的问题，而是表达容量的硬上限：无论权重学得多好，三平面本身存不下比它分辨率更细的信息。

两个数字的耦合关系值得单独说。训练规模决定映射的准确度，三平面分辨率决定映射的输出精度，两者是乘法关系而非加法关系。分辨率不足时，再多的训练数据也只能把粗粒度的三平面学得更准，细部仍然丢失；训练规模不足时，再高的分辨率也只能存下没被学好的映射，高分辨率反而放大了误差的可见度。工程判断因此是：先确认分辨率是否匹配目标细节尺度，再评估训练规模是否支撑该分辨率下的映射学习，顺序反了就会在错误的一层上堆资源。

渲染损失在这张底账里是监督项而非容量项。它不提供表达能力，只提供约束方向。多视角比对把「三平面必须能解释不同视角的观测」这一要求压进训练，缺少它，三平面可能拟合单视角而在其他视角崩坏。它的失败模式是几何与外观脱节：平面 token 学到了颜色却学错了密度，渲染出的多视角图像在轮廓上对不上真值。

五 · 评分演练：按 50/50 拆解一份满分答案

演练的价值在于把评分标准还原成可检查的句子。架构 50% 对应的是「主干链路是否完整且顺序正确」，amortized 50% 对应的是「是否讲清一次前向为何等价于被蒸进的优化，以及代价」。下面按这两个维度逐句检查一份满分档答案的构成。

架构半边需要覆盖四个环节，缺一扣分。第一，输入图经 ViT 切成 token；第二，Transformer 的 cross-attention 把图像 token 映射到三平面 token；第三，三平面解码成 NeRF/网格；第四，渲染多视角与真值比对。这四个环节构成一条闭环，前三个是推理链路，第四个是训练信号。演练时要特别检查考生有没有把第四个环节错放到推理阶段——把渲染损失说成推理步骤，等于把训练监督误读成推理流程，架构分的完整性会受损。

amortized 半边需要三句话。第一句点明机制：优化过程被蒸进权重，推理时一次前向就是在替每个物体做那场原本要迭代的优化。第二句给出数据底账：模型在约 50 万物体上训练，学会了「图像→三平面」的先验。第三句交代代价：训练数据规模与质量决定上限，输出分辨率受三平面分辨率限制。三句缺一，这半边就不完整。只写第一句是「知道概念」，加上第二句是「知道燃料」，三句齐全才是「知道边界」。

  • 检查点一：是否明确写出 ViT 切 token 与 cross-attention 映射这两个动作，而不是只写「用了 Transformer」。
  • 检查点二：是否把三平面作为中间表征明确点出，而不是从图像直接跳到 NeRF。
  • 检查点三：是否把多视角渲染损失定位在训练阶段。
  • 检查点四：是否用「蒸进权重」或等价表述解释一次前向的来源，而不是把一次前向当成无需解释的事实。
  • 检查点五：是否给出约 50 万物体的训练规模，并把它与先验学习挂钩。
  • 检查点六：是否主动写出三平面分辨率的上限与数据规模的上限这两个代价。

常见错误的扣分位置可以精确定位。「以为 LRM 是逐物体优化」直接击穿 amortized 半边：它把推理范式说反了，等于承认一次前向不成立。「忽略三平面分辨率上限」扣的是代价那一句，amortized 半边从三句退成两句。「以为一次前向不需要 3D 数据」扣的是数据底账那一句，同时暴露出对 amortized 机制的误解——把推理的轻量误读成训练的无依赖。三种错误都落在 amortized 半边，说明这半边的失分风险远高于架构半边，因为架构是描述性的，amortized 是解释性的。

演练的收尾动作是自检句式：把答案里每一个「所以」都找出来，看它前面是否有机制支撑。写「所以推理时一次前向即可」之前，必须有一句说明优化被蒸进了权重；写「所以输出分辨率有限」之前，必须有一句说明三平面是固定分辨率的二维特征图。没有支撑的「所以」就是评分标准里那 50% 正在漏掉的地方。一份满分答案的特征不是写得多，而是每个因果连接都能在文本里找到它的机制前件。

六 · 工程判断：架构选择与代价的对应关系

把这道题放回工程语境，架构主干的选择本身就是一组代价决策。选 ViT 切 token，意味着图像被离散成 patch 序列，分辨率与 patch 大小共同决定 token 数量，token 数量又决定 cross-attention 的计算量。选三平面作为中间表征，意味着三维表达被压成三张二维特征图，表达上限由平面分辨率锁定，换来的是解码与渲染的规整性。选多视角渲染损失作为监督，意味着训练需要多视角真值，数据采集成本被前置。每一个选择都在回答「用什么换什么」。

amortized 的工程判断更尖锐：它把成本从推理搬到训练，因此适合推理侧对延迟敏感、训练侧能承担大规模数据的场景。反过来，如果目标物体的分布与训练集偏离很远，或者需要逐物体的高精度拟合，amortized 的一次前向就给不出可补救的结果，退回逐物体优化又丢掉速度优势。这个取舍不是模型内部的细节，而是部署层面的判断：先问推理侧要不要快，再问训练侧有没有约 50 万量级的多视角数据，两个答案都指向 amortized 时才选它。

三平面分辨率的判断则落在输出侧。目标应用需要的细节尺度决定了平面分辨率的下限，而平面分辨率又反过来约束训练规模的有效性——分辨率越高，映射要学的输出越细，需要的监督越密。工程上不能只调其中一个旋钮，因为两者是乘法关系。一个具体的判断顺序是：先从目标细节尺度反推所需的三平面分辨率，再评估在该分辨率下「图像→三平面」映射需要多少物体才能学到可用精度，最后才决定是否采用 amortized 范式。顺序颠倒，就会在分辨率不足时误以为数据不够，或在数据不足时误以为分辨率不够。

最后落在机制上：LRM 的一次前向之所以成立，是因为 cross-attention 把图像证据查询进三平面 token，而这场查询的注意力模式是在约 50 万物体的多视角渲染监督下被蒸进权重的；它的代价同时写在两个地方——权重里能蒸进多少先验由训练数据的规模与质量决定，三平面能解码出多细的结构由平面分辨率决定。工程判断的落点因此不是「LRM 快不快」，而是「这批数据能不能蒸出可用的先验，这个分辨率能不能解出目标细节」，两个问题都答是，一次前向才是一次可用的前向。
