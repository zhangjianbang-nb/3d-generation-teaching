一 · 三档答案的分层结构

这道题在评分表上被拆成两个权重块：三通道语义占 60%，为什么不能只用一张 RGB 贴图占 40%。这个比例本身就是答案分档的依据——及格档只答对 60% 块的一半，良好档把 60% 块答满但 40% 块流于口号，满分档两块都落到机制层面。判分点列了五个关键词：base color、metallic、roughness、BRDF、RGB 烘死光照、可重光照、delighting。注意这五个判分点并非平权，前三个属于“三通道”块，后三个属于“为何不能 RGB”块，其中 delighting 是连接两块的枢纽。

及格答案的典型形态是逐词翻译：base color 是颜色，metallic 是金属度，roughness 是粗糙度。三个词都对，但每个词都没有落到“这个通道在 BRDF 里扮演什么角色”上。它拿到 60% 块里的一半左右，40% 块几乎为零，因为“不能只用 RGB”被答成“因为 PBR 需要更多信息”，这是同义反复。

良好答案会把三个通道各自对应的物理量说清楚：base color 是反照率，不含光照；metallic 是金属与绝缘体的插值权重；roughness 决定高光瓣的锐利程度。它还会指出三者共同参数化同一个 BRDF，缺一不可。40% 块上，良好答案能说出“RGB 贴图会把光照烘进颜色”，但说不清“烘进去之后为什么换光照就错”，也说不清 delighting 的代价。这就是良好与满分的分界。

满分答案多出两层：第一层是把“烘死光照”展开成可重光照的失效机制——颜色通道一旦混入入射光照，任何一次光照变更都会让这个通道的语义从反照率退化为“某次光照下的观测量”，重光照时无法解耦；第二层是承认 PBR 估计本身有歧义，delighting 不是无损逆运算，暗部与高光处信息已被截断或饱和，反解出的 base color 带系统性偏差。满分答案不回避这个代价，反而用它来解释为什么工程上必须保留多通道而不是单张 RGB。

档位三通道块（60%）RGB 块（40%）典型缺口
及格三个词各一句，无 BRDF 关联同义反复无机制、无代价
良好三通道语义准确，点出共同决定 BRDF说出烘死光照，未展开失效链delighting 代价缺失

这张表的作用不是给读者贴标签，而是让写答案的人在动笔前就知道每一档缺什么。及格到良好的跃迁靠“把词变成物理量”，良好到满分的跃迁靠“把结论变成机制链”。评分演练时，先数判分点命中数，再看命中点是否带机制，两步就能定位档位。

二 · 三通道如何参数化同一个 BRDF

要答满 60% 块，必须把三个通道放进同一个 BRDF 表达式里，而不是并列罗列。以 Cook-Torrance 形式的微表面 BRDF 为例，反射项可写成漫反射与镜面反射的加权和：

$$f_r(\omega_i,\omega_o)= \frac{1-\mathrm{metallic}}{\pi}\,\mathrm{baseColor} + \frac{D(h)\,F(\omega_i,h)\,G(\omega_i,\omega_o)}{4\,(\omega_i\cdot n)(\omega_o\cdot n)}$$

这里 metallic 以两种方式出现：它作为漫反射项的乘子 $(1-\mathrm{metallic})$，金属不产生漫反射；它同时进入菲涅耳项 $F$，把 F0 从绝缘体的固定低反射率插值到 base color 本身。也就是说 metallic 不是一个“外观滑块”，而是同时切换漫反射是否存在、以及镜面反射的底色取自哪里。roughness 则进入法线分布函数 $D(h)$：roughness 越小，$D$ 越尖锐，高光瓣越窄；roughness 越大，$D$ 越平坦，高光铺开成宽而弱的亮区。base color 在绝缘体上只喂给漫反射项，在金属上则喂给 $F_0$，这就是为什么同一个颜色通道在两种材质语义下含义不同。

伪代码层面，一次着色可以写成：读取 baseColor、metallic、roughness 三个标量/向量；用 metallic 插值 F0；用 roughness 求 $D$ 与 $G$；把漫反射项按 $(1-\mathrm{metallic})$ 缩放；相加后乘入射辐照度。三个通道各自只控制这条流水线的一个环节，缺任何一个环节，BRDF 就无法闭合。这正是“三者共同决定 BRDF”的准确含义——不是三个独立属性拼在一起，而是三个参数共同张成一个连续材质空间。

系统代价在这里第一次出现：三通道意味着三张纹理的采样与带宽。按工程惯例，base color 通常是三通道 8 位，metallic 与 roughness 常被打包进一张两通道纹理（金属度占一通道、粗糙度占一通道），以节省采样次数。这个打包不是审美选择，而是采样带宽与缓存命中的直接约束——每多一次纹理采样，片元着色器就多一次内存访问，在大量像素覆盖时成为瓶颈。失败模式是打包时通道错位：把 roughness 写进 metallic 的通道，材质会呈现“金属但高光极锐”或“绝缘但高光全糊”的矛盾外观，且这种错误在单一光照下不易察觉，换光照才暴露。

具体例子：一把不锈钢勺与一只陶瓷杯。勺的 metallic 接近 1，base color 直接成为镜面反射的底色，roughness 低则映出清晰环境；杯的 metallic 为 0，base color 只影响漫反射，roughness 中等则高光是一团柔和的亮斑。若把两者的 base color 互换而保留 metallic/roughness，勺会变成“有颜色的金属镜”，杯会变成“灰白陶瓷”，外观立刻错位——这说明 base color 的语义被 metallic 绑定，三者不可拆开单独讨论。

三 · RGB 烘死光照的失效链

40% 块的核心不是“RGB 信息不够”，而是“RGB 把光照烘进颜色后，通道语义被污染”。设一张输入图某像素的观测值为 $C_{obs}$，它近似等于反照率与入射光照的乘积再叠加高光：

$$C_{obs} \approx \mathrm{baseColor}\cdot E + \mathrm{specular}$$

如果直接把 $C_{obs}$ 当作 base color 存进 RGB 贴图，那么贴图里存的是“某次光照下的观测量”，而不是“与光照无关的反照率”。换一个光照 $E'$，正确结果应是 $\mathrm{baseColor}\cdot E'$，但贴图只能给出 $C_{obs}\cdot E'$，多乘了一次旧光照 $E$。这就是“换光照就错”的机制：错误不是随机噪声，而是系统性地把旧光照当作反照率的一部分重复计入。阴影被烘进颜色后，重光照时阴影区域会带着旧阴影的暗度再被新光照照亮，形成“阴影叠阴影”的双重暗化。

高光被烘进颜色是另一条失效支路。高光是视角与光照相关的项，不是表面属性。把它写进 RGB 后，重光照会在新视角下再生成一次高光，而旧高光仍留在颜色里，结果是高光位置错误、强度叠加。金属材质上这条支路尤其致命：金属的 base color 本应作为 $F_0$ 参与镜面反射，若颜色里已含旧高光，$F_0$ 被高光污染，反射底色就不再是材料本身的颜色。

可重光照的前提因此可以精确表述：只有当颜色通道与光照解耦，即通道语义是反照率而非观测量，重光照才是对 BRDF 的重新求值；否则重光照只是把旧观测再乘一次新光照，得到的是两次光照的卷积而非一次求值。判分点里的“可重光照”正是这条前提的缩写。失败模式在工程上表现为：同一套材质在白天与夜晚两套光照下渲染，RGB 方案的颜色会随光照整体偏移，且偏移方向与旧光照方向相关，无法通过调参校正。

具体例子：一张在正午阳光下拍摄的砖墙，RGB 贴图里砖缝的阴影是深色。把它放到黄昏侧光下重光照，砖缝会同时带有正午阴影的暗和黄昏侧光的明暗过渡，砖缝看起来比实际更深、更脏。若换成解耦后的 base color 加 metallic/roughness，砖缝只是反照率略低，黄昏侧光会自然地在砖缝里投下新的阴影，两者不叠加。

四 · delighting 的收益与歧义代价

delighting 是把输入图的光照去掉、反解出 base color 的过程，它是“可重光照”从口号变成可执行步骤的枢纽。其思路可写成伪代码：估计每个像素的入射光照（从阴影、高光分布或先验中推断），用观测值除以估计光照，得到反照率估计；对高光区域先分离镜面项再反解漫反射底色。判分点把 delighting 单列，是因为它同时连接两块：没有它，RGB 块只能停在“烘死光照”的定性判断；有了它，才能说清“解耦是有代价的”。

代价的第一层是歧义。给定一个观测值 $C_{obs}$，满足 $\mathrm{baseColor}\cdot E = C_{obs}$ 的 $(\mathrm{baseColor}, E)$ 组合有无穷多组，delighting 必须引入先验才能选出唯一解。先验选错，反解出的 base color 就带系统性色偏。第二层是信息截断：暗部像素值接近零，除以一个很小的估计光照会放大噪声，反解出的反照率在暗部剧烈抖动；高光区域像素饱和，镜面项与漫反射项混在一起无法分离，反解出的底色偏亮或偏灰。这两处正是解析里点名的“暗部/高光处易失真”。

因此“以为 delighting 无损”是常见错误中最隐蔽的一条。它不像“以为 RGB 就是 PBR”那样一眼可辨，而是在答案里以“先 delighting 再重光照即可”的轻描淡写出现。满分答案必须在这里刹车：delighting 是有损逆问题，暗部与高光处的反照率估计不可信，工程上要么接受这些区域的偏差，要么用多视角/多曝光输入来约束解。系统代价是采集端成本——单张图 delighting 的歧义无法靠算法消除，只能靠额外观测压缩解空间。

具体例子：一张逆光拍摄的树叶，叶面高光饱和、叶背几乎全黑。delighting 后，叶面反照率被高光拉高，叶背反照率被噪声污染。重光照到柔和正面光下，叶面显得过亮、叶背显得斑驳。这不是算法实现差，而是输入观测在该区域的信息量不足，任何 delighting 都无法无损恢复。

五 · 评分演练：从判分点到档位

演练的目的是把判分点变成可操作的检查清单。第一步，数命中：三通道块是否点到 base color 的反照率语义、metallic 的金属/绝缘体插值、roughness 的高光锐利度，以及三者共同决定 BRDF；RGB 块是否点到烘死光照、可重光照失效、delighting 及其代价。第二步，看每个命中点是否带机制：说“metallic 控制金属度”只算命中词，说“metallic 同时切换漫反射是否存在与 F0 来源”才算带机制。第三步，看两块是否自洽：RGB 块的失效链必须能回指三通道块里某个通道的语义被污染，否则两块是拼贴而非论证。

以一份良好档答案为例：它写“base color 是反照率，metallic 决定是不是金属，roughness 决定高光粗细，三者一起决定 BRDF；RGB 贴图会把光照烘进去，所以不能只用 RGB”。逐条对照：三通道块四个点全中且带部分机制，得满；RGB 块只中“烘死光照”一个点，且无失效链、无 delighting，40% 块拿不到一半。总分落在良好档下沿。改进路径很明确：补上“换光照时旧光照被重复计入”的机制句，补上 delighting 的歧义代价，就能越过满分线。

再以一份及格档答案为例：它写“base color 是颜色，metallic 是金属度，roughness 是粗糙度；PBR 需要更多信息所以不能只用 RGB”。三通道块三个词各一句、无 BRDF 关联，拿一半；RGB 块是同义反复，接近零。它的缺口不是知识量，而是没有把词翻译成物理量、没有把结论翻译成机制。评分演练的价值就在这里：它让写作者看到，从及格到满分不是加字数，而是加两层翻译。

演练还要防止一种伪满分：答案堆了很多术语，但术语之间没有因果连接，delighting 被提及却未说明其有损性，可重光照被提及却未说明其前提是通道与光照解耦。这种答案在词面上命中全部判分点，却在机制检查上全线失守。判分点的设计本意就是筛掉这种词面命中——每个判分点都对应一个可追问的“为什么”，答不出为什么，就不算真命中。

六 · 数字底账与工程判断

本题给定的数字只有评分权重：三通道 60%，RGB 40%。这两个数字不是装饰，它们决定了答案的重心分配。60% 块要求三个通道各自说清语义并落到 BRDF，意味着这部分需要三段实质内容；40% 块要求失效链与代价，意味着这部分不能只有一句结论。按字数分配，三通道块应占答案主体，RGB 块应占足以展开机制链的篇幅，两者比例大致贴合 60/40，而不是平均用力。

数字底账还有一层：判分点共五个关键词，其中三个属 60% 块、两个属 40% 块（delighting 跨接两块）。这意味着 60% 块的关键词密度更高，漏掉任何一个都会明显拉低该块得分；40% 块关键词少，但每个关键词背后的机制链更长，漏掉 delighting 就等于丢掉整条代价论证。工程判断由此得出：写答案时先保证三通道块三个词全部带机制，再集中篇幅把 RGB 块的失效链写透，最后用 delighting 的有损性收口。

工程判断的另一面是取舍：当篇幅受限时，宁可少写一个通道的修饰性描述，也不能省掉“三者共同决定 BRDF”这句连接，因为它是 60% 块从“三个词”升格为“一个参数化系统”的标志；同样，宁可压缩 delighting 的步骤描述，也不能省掉“暗部/高光处易失真”这句代价，因为它是 40% 块从“结论”升格为“机制”的标志。这两句是档位跃迁的支点，其余内容围绕它们展开。

最后落到具体机制上：评分演练的终点不是给出一个分数，而是让写作者在动笔前就能预判自己的答案会在哪一句上失分。三通道块失分通常发生在“只列词不连 BRDF”，RGB 块失分通常发生在“只说烘死不说不解耦的代价”。把这两处补上，答案就从词面命中变成机制命中；补不上，权重再清楚也只是数字，不会自动变成分数。
