一 · 变体题：把「可微光栅化」这条链路拆开考

变体题的设计目的不是换一个模型名字重问一遍，而是把参考答案里那条四段链路（显式网格输出 → 可微光栅化 → 2D 判别器 → 梯度回传）中的某一段抽出来单独加压，看读者是否真的理解每一段各自承担什么职责。下面三个变体都只改动链路中的一个环节，其余事实保持不变。

变体 A：把判别器换成 3D 判别器。题目问：如果给 GET3D 配一个直接吃网格的 3D 判别器，是否就不再需要可微光栅化？正确答案是否定的，但理由必须落在机制上：3D 判别器要工作，前提是它自己也得对顶点与面片可微，而点云/网格上的卷积与池化在非均匀拓扑上代价极高，且判别器一旦不可微，梯度就断在判别器一侧，生成器拿不到任何信号。可微光栅化之所以不可替代，是因为它把「3D 结构」翻译成「2D 像素」这一动作本身是可微的，从而让一个成熟的 2D 卷积判别器可以直接复用。这里的系统代价是：换成 3D 判别器意味着放弃 2D 图像领域已经验证过的判别器架构与训练稳定性，重新面对稀疏、无序、拓扑可变的 3D 数据，训练方差显著上升。这个变体考的正是「可微渲染链路 60%」这一判分权重背后的因果，而不是「有没有 3D 判别器」这种表面判断。

变体 B：只生成几何、不生成纹理。题目问：去掉纹理分支后，这套无 3D 监督的训练还能不能成立？答案是可以成立，但监督信号被削弱。几何分支输出顶点与面片，经光栅化得到的是无纹理的着色图或深度图，2D 判别器仍能判断轮廓与表面朝向是否像真实物体，梯度仍能回传到顶点。然而纹理分支的存在使得渲染图带有颜色与材质细节，判别器能据此区分「形状对但表面假」的样本，从而给几何分支提供更细的约束。去掉纹理分支的失败模式是：几何可能在轮廓层面收敛，但表面细节（凹陷、薄片、内部结构）缺乏来自颜色的间接监督，容易出现「剪影正确、内部塌陷」的退化。这个变体直接对应判分点中的「几何/纹理双分支」，答不出双分支各自被谁监督，就说明只记住了名词。

变体 C：把光栅化换成体素渲染或神经渲染。题目问：可微光栅化是不是唯一选择？答案是不是，但替换的代价必须说清楚。体素渲染的梯度要经过离散化的体素网格，分辨率一高显存就爆；神经渲染（如可微的隐式场渲染）虽然可微，但它的输出不是显式网格，而是隐式表示，这与题目要求的「显式网格」直接冲突——要让隐式表示变成网格，还得额外做一次等值面提取，而这一步通常不可微，梯度在此断裂。因此变体 C 的真正考点是：可微光栅化的价值不仅在于「可微」，还在于它的输出直接就是题目要的显式网格，中间没有不可微的转换步骤。系统代价方面，任何替换方案都要么牺牲显式性，要么牺牲可微性，二者不可兼得。

$$\mathcal{L}_{G}=\mathbb{E}_{z}\left[-\log D\big(\mathrm{Raster}(G(z))\big)\right],\quad \frac{\partial \mathcal{L}_{G}}{\partial V}=\frac{\partial \mathcal{L}_{G}}{\partial I}\cdot\frac{\partial I}{\partial V}$$

上式里 $$\mathrm{Raster}(\cdot)$$ 把顶点 $$V$$ 与纹理映射成图像 $$I$$，第二项的存在就是「光栅化可微」的全部含义：若 $$\partial I/\partial V$$ 不存在，生成器对顶点的更新为零。三个变体都在追问这一项是否成立、由谁提供、代价是什么。

二 · 五个追问：从「是什么」压到「为什么这样设计」

追问的设计遵循一条原则：每个追问都必须能用一个具体机制回答，答成「因为论文这么写的」即为不合格。以下五个追问按难度递增排列。

  • 追问 1：梯度究竟回传到哪些参数？必须答出顶点坐标、面片连接关系（若可微）、纹理图/纹理坐标三类，并指出面片拓扑的离散性使得「面片连接」通常不参与梯度，梯度主要落在顶点位置与纹理值上。答成「回传到整个网络」是空话。
  • 追问 2：2D 判别器看到的是单视角还是多视角？这决定了监督的几何完备性。单视角下，判别器只能约束该视角可见的表面，背面与自遮挡区域缺乏直接监督，靠生成器的先验与多视角采样间接补足；多视角采样则让同一网格在不同视角被渲染、被判别，梯度累加后覆盖更完整的表面。回答要落到「视角采样策略影响哪些表面被监督」这一机制上。
  • 追问 3：为什么判别器不能直接吃网格的顶点列表？因为顶点列表是无序集合，同一个网格可以有无数种顶点排列，判别器对排列敏感就会把「排列不同」误判为「形状不同」，从而给出无意义的对抗信号。光栅化把无序的顶点集合变成有序的像素网格，消除了这一对称性，这才是它作为「接口」的真正作用。
  • 追问 4：训练不稳定时，问题更可能出在链路哪一段？要能定位：若渲染图与真实图在颜色分布上差异过大，判别器过早饱和，梯度消失，问题在纹理分支的初始化与判别器的容量匹配；若渲染图轮廓抖动剧烈，问题在顶点梯度的尺度与光栅化的近似误差（如边缘像素的梯度近似）。回答必须指向具体环节，而不是「调学习率」。
  • 追问 5：这套方法能扩展到带关节的物体吗？可以，但需要把关节参数纳入可微链路：关节旋转改变顶点位置，只要这一变换对关节角可微，梯度就能经光栅化回传到关节参数。失败模式是关节运动导致自遮挡剧变，单视角判别器无法区分「关节转错」与「纹理错」，需要多视角或额外约束。

这五个追问的共同结构是：先问「哪些量参与梯度」，再问「监督覆盖哪些表面」，再问「接口为什么必须是这个形式」，最后问「故障定位与扩展边界」。能把这条结构说清楚，说明读者掌握的是链路而非名词。

三 · 扣分点：评分标准如何落到具体答卷上

评分标准给定为「可微渲染链路 60%，无 3D 监督 40%」。这两个权重不是随意分配的，它们对应两类完全不同的能力：前者考「机制是否讲通」，后者考「问题定位是否准确」。下表把常见答卷表现映射到扣分位置。

答卷表现命中判分点扣分位置与理由
只写「用 2D 判别器监督」，不提光栅化可微缺可微光栅化链路 60% 中扣掉核心项：没有梯度通路，2D 监督无法到达 3D
写「需要 3D 数据集做真值」违背无 3D 监督40% 中扣掉全部：把题目的前提条件答反了
写「光栅化不可微，所以用近似」误判光栅化性质链路项扣分：可微光栅化正是该方法成立的前提，不是近似替代
只提几何分支，不提纹理分支缺双分支判分点「几何/纹理双分支」未命中，链路项部分扣分
答出四段链路但说不出梯度回传到顶点与纹理链路讲通但落点模糊链路项小幅扣分：机制方向对，但未落到参数级
把「显式网格」答成「隐式场」输出形式错误判分点「显式网格输出」未命中，链路项扣分

扣分点的设计逻辑是：链路 60% 覆盖「输出形式、可微性、判别器、双分支」四个判分点，每个点都对应一个可验证的机制陈述；无 3D 监督 40% 只覆盖一个判断——训练信号是否来自 2D 图像而非 3D 真值。这意味着即使读者把链路讲得极细，只要在「是否需要 3D 数据」上答错，仍然丢掉四成权重。反过来，只答对「不需要 3D 数据」而链路空白，也只能拿到四成。两个权重共同构成一个不可偏废的结构。

一个具体的扣分例子：答卷写「GET3D 用 3D 卷积判别器判断网格真假，所以不需要 3D 真值」。这句话前半段引入了题目事实中不存在的 3D 判别器，后半段的「不需要 3D 真值」虽然方向正确，但支撑它的机制是错的——不需要 3D 真值的原因是监督来自 2D 渲染图，而不是因为有了 3D 判别器。这种答卷在链路项上因引入错误机制被扣，在无 3D 监督项上因因果错位只能拿到部分分。

四 · 常见错误：三类误解的成因与纠正路径

给定事实列出三个常见错误：以为需要 3D 数据集、以为光栅化不可微、忽略纹理分支。这三者不是孤立的记忆漏洞，而是三种不同的认知成因，纠正路径也各不相同。

第一类：以为需要 3D 数据集。成因是把「生成 3D」与「用 3D 监督」混为一谈。纠正的关键是让读者区分「输出空间」与「监督空间」：输出是 3D 显式网格，监督是 2D 渲染图，二者可以不同。一个具体的检验方法是问：如果把所有 3D 真值删掉，训练还能不能跑？答案是能，因为损失函数里只出现渲染图与真实图的对抗项，没有任何一项比较预测网格与真值网格。这类错误的系统代价在工程上非常实际：若真按「需要 3D 数据集」去准备数据，采集与标注成本会高出数个量级，而方法本身恰恰是为了绕开这一成本。

第二类：以为光栅化不可微。成因是把「光栅化是离散的像素归属判定」与「不可微」等同。事实上像素归属（哪个三角形覆盖哪个像素）是离散的，但像素颜色对顶点位置与纹理值的依赖是连续的，可微光栅化正是对这一连续依赖求导。纠正路径是让读者写出 $$\partial I/\partial V$$ 这一项并解释它在边缘像素处的近似处理——边缘处像素归属会跳变，梯度需要做软化或忽略，这是工程上的近似，但不改变「整体可微」这一定性。失败模式是：若读者坚持光栅化不可微，就会去寻找「替代的可微渲染器」，从而偏离题目要求的显式网格输出。

第三类：忽略纹理分支。成因是把「网格」等同于「几何」，把纹理当成附属品。纠正要落到监督机制上：纹理分支输出的纹理值参与渲染，渲染图的颜色分布是判别器判断真假的重要依据，因此纹理分支同样接收梯度。忽略它的后果是答卷在「双分支」判分点上失分，更深层的后果是无法解释「为什么判别器能约束表面细节」。一个具体例子：两个几何相同但纹理不同的网格，渲染后判别器给出不同判断，这说明纹理分支确实在被监督，而不是装饰。

  • 三类错误的共同点：都把链路中的某一环替换成了「想当然」的默认假设。
  • 纠正的共同方法：回到损失函数，看每一项实际比较的是什么量。
  • 工程判断：能说清「损失里没有 3D 真值项」的读者，第一类错误自然消失。

五 · 教学建议：如何让读者自己把链路讲出来

教学上最有效的做法不是复述参考答案，而是设计一组「断链实验」，让读者自己发现每一环的必要性。具体做法是给出四个删减版本，每个版本删掉链路中的一环，让读者判断训练是否还能成立、失败模式是什么。

删减 1：去掉可微性，把光栅化当成黑盒。读者应判断出梯度断在渲染处，生成器收不到信号，训练退化为随机采样。删减 2：去掉 2D 判别器，只保留渲染。读者应判断出没有任何真假判断，损失为空，生成器无目标。删减 3：去掉纹理分支。读者应判断出几何仍可被轮廓监督，但表面细节失去颜色约束。删减 4：去掉显式网格输出，改为隐式场。读者应判断出输出形式与题目要求冲突，且隐式转网格的提取步骤不可微。四个删减版本合起来，正好覆盖四个判分点，读者在判断每个版本失败模式的过程中，实际上已经把链路讲了一遍。

第二个教学手段是「参数级追问」：要求读者指出梯度具体落在哪些参数上，并画出从损失到参数的路径。路径必须是：损失 → 渲染图 → 光栅化 → 顶点/纹理 → 生成器参数。任何在这一路径上出现「然后梯度就传回去了」这种跳跃的表述，都说明读者没有真正掌握中间环节。教师可以要求读者在路径的每一段标注该段的输入输出张量形状，形状对不上就说明链路理解有缺口。

第三个手段是「代价对照」：让读者比较「有 3D 监督」与「无 3D 监督」两条路线的工程代价。有 3D 监督需要 3D 真值数据，采集成本高但监督直接；无 3D 监督只需要 2D 图像，数据易得但监督是间接的，依赖可微渲染这一中间层，且渲染的近似误差会引入训练噪声。这个对照能让读者理解「无 3D 监督」不是免费的，它用渲染链路的工程复杂度换取了数据成本。教学上应强调：题目问的是「怎么学会」，答案的重点在机制而非「省了数据」这一结果。

最后，教学应避免让读者背诵「四段链路」的标签。有效的检验是给一个具体场景：假设判别器对某类物体的渲染图始终判真，生成器不再收到有效梯度，问读者应检查链路哪一段。合格的回答会指向纹理分支的初始化或视角采样覆盖不足，而不是笼统地说「模型不收敛」。这种场景化追问能把「机制解析」从名词记忆转化为故障定位能力，也正是评分标准中链路权重高于无监督权重的教学依据。

从工程判断的角度收束：这套方法的可靠性完全建立在「渲染图对顶点与纹理可微」这一条性质上，任何教学与考核都应围绕这条性质展开——删掉它，2D 判别器的梯度就到不了 3D；保留它，无 3D 真值的训练才成立。变体题、追问、扣分点与常见错误，本质上都是对这条性质的反复施压。
