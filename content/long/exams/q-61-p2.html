一 · 变体一：把「面片词表」换成「顶点词表」

第一个变体题通常这样问：如果把 MeshGPT 的面片级 VQ 词表换成顶点级词表，即每个 token 对应一个顶点坐标的量化码，故事里的「木工房」会变成什么？判分时要看考生是否意识到，面片 token 与顶点 token 的差别不在编码格式，而在拓扑约束的承载方式。面片 token 天然携带三个顶点的连接关系，一个 token 解码出来就是一个三角面，序列本身即拓扑；顶点 token 只给出点的位置，边与面必须由后续的组装规则推断，于是「榫卯」这一层就从词表内部转移到了词表外部的后处理。

机制上，面片 VQ 的编码器把每个面的几何与法向特征映射到码本索引，解码器按自回归顺序逐面输出，已生成的面通过共享顶点形成局部上下文。换成顶点词表后，自回归序列变成点云式的坐标串，模型必须额外学习「哪些点连成面」的隐式规则，等价于把拓扑生成拆成两步：先出点，再猜面。公式上可以写成两步似然：

$$p(M)=\sum_{T}p(V\,|\,T)\,p(T),\quad p(T)=\prod_{i}p(t_i\,|\,t_{

其中 \(V\) 是顶点序列，\(T\) 是拓扑（面）序列。面片词表把 \(p(T)\) 吸收进 token 语义，顶点词表则把它显式外置，第二步的搜索空间随顶点数组合爆炸。系统代价很直接：顶点数 \(n\) 对应的候选三角面数量级为 \(O(n^3)\)，即便用启发式剪枝，后处理耗时也会压过自回归解码本身；更糟的是，顶点量化误差会在连面阶段被放大，出现悬空边或非流形面。具体例子：一个约几百个面的椅子扶手，面片词表下序列长度与面数同阶，顶点词表下点序列虽短，但连面阶段需要判定每个点的邻域，工程上往往退化为「先 Delaunay 再修补」，拓扑顺滑度反而下降。因此该变体的满分回答必须指出：词表粒度决定拓扑是「内生」还是「外挂」，换粒度不是免费的语言替换。

二 · 变体二：把「榫卯共享边」推广到多分辨率

第二个变体追问 AMT 的相邻网格 tokenization 能否跨分辨率复用。AMT 的核心是相邻面共享边、只写新顶点：序列在遍历相邻面时，已出现的边不再重复编码，新面只贡献它带来的新顶点索引。这一机制使 token 序列长度近似正比于「新增顶点数 + 面数」，而不是三倍面数的顶点冗余。变体题要求考生把这一共享边规则放到层次化网格上，问：粗层与细层之间如何共享边而不破坏 token 的唯一性？

可接受的机制是「边句柄继承」：粗层每条边分配稳定句柄，细层细分时，子边继承父边句柄并附加细分序号，token 写成（父句柄，子序号，新顶点）。这样跨层引用不需要重新编号，解码器可以在任意层落地。伪代码思路为：

  • 对粗层网格做一次 AMT 遍历，记录每条边的句柄与两端顶点；
  • 细分时对每条父边生成两个子边 token，父句柄作为前缀；
  • 解码时按前缀查表恢复邻接，未命中则回退到全局顶点表。

系统代价出现在句柄表的规模与失效处理：句柄随层数增长，若细分规则不统一（例如不同区域用不同细分模式），父子对应关系会出现多义，解码器必须携带一张版本化的边表，内存开销与层数成正比。失败模式是「句柄漂移」：同一几何边在不同分支被分配不同句柄，联合解码时产生重复面。具体例子：一个带雕花的桌腿，粗层是六边形柱，细层在雕花处局部加密，若雕花区与柱身区使用不同的细分模板，共享边在交界处必须显式对齐，否则接缝出现 T 形顶点。满分回答要落到「共享边的前提是全局一致的边命名」，而不只是复述 AMT 的省 token 效果。

三 · 变体三：把「组装台」改成串行部件生成

第三个变体问：PartCrafter 的组合式潜变量若改成串行生成，即先出部件 A 的潜变量、再以其为条件出部件 B，会失去什么？参考机制是按部件独立生成再联合去噪，部件潜变量在同一个去噪过程里互相可见，全局关系（接触面、遮挡、比例）在每一步都被约束。串行化把联合去噪拆成条件链，公式从联合分布变成链式分解：

$$p(z_1,\dots,z_k)\;\rightarrow\;p(z_1)\prod_{i=2}^{k}p(z_i\,|\,z_{

链式分解本身不损失表达能力，但采样时误差会累积：前一部件的潜变量一旦偏离，后续部件被条件锁定在错误上下文里，且没有回修机会。联合去噪的每一步都能看到所有部件的噪声估计，相当于隐式的全局一致性约束；串行链则把一致性降级为单向条件。系统代价是采样步数乘以部件数，且需要为每个条件阶段维护独立的去噪网络输入，显存随部件数线性上涨。失败模式是「接触面悬空」：先生成的底座若略微偏小，后生成的立柱按条件贴附，接缝处出现缝隙，而联合去噪会在早期步骤就把两者拉近。

具体例子：一张三抽屉柜，抽屉与柜体的滑轨接触面是弱约束，串行生成时柜体先定型，抽屉只能被动适配，滑轨间隙无法回退修正；联合去噪则在噪声阶段就交换接触面附近的梯度信息。判分点在于考生是否说出「组合潜变量的价值在联合去噪的全局可见性，而非部件拆分本身」，只答「分部件生成更简单」属于把工程便利误当机制优势。

四 · 五个追问的落点

追问一：MeshGPT 的自回归顺序能否任意？回答要点是顺序影响上下文质量，面片序列按空间邻近遍历时，已生成面提供的共享顶点上下文最丰富；随机顺序会让模型频繁遇到未定义顶点，被迫依赖位置先验。追问二：AMT 的「只写新顶点」在非流形输入上如何退化？要点是共享边假设邻接面成对出现，非流形边被多个面共享时，句柄冲突需要拆分为多条逻辑边，token 数上升。追问三：PartCrafter 的部件划分由谁决定？要点是划分来自输入分割或语义先验，潜变量维度按部件分配，划分错误会直接表现为部件间穿插。追问四：三篇论文的边界在哪？要点是 MeshGPT 解决「面序列的紧凑表示」，AMT 解决「相邻面冗余」，PartCrafter 解决「多部件联合一致性」，三者分别作用于词表、序列编码、潜变量三层。追问五：若下游要动画，哪一层最敏感？要点是拓扑顺滑度与部件清度，AMT 的共享边减少接缝，PartCrafter 的部件潜变量便于绑定骨骼，而面片词表的顺序稳定性影响蒙皮权重的一致性。

每个追问都要求给出机制而非结论。例如追问三若只答「按语义分」，没有说明潜变量如何按部件分配、联合去噪如何交换信息，就只拿到一半分。追问四的边界判断最容易失分：把 AMT 说成「更好的 MeshGPT」是错的，两者优化的是不同层级的冗余。

五 · 扣分点与常见错误

扣分点按评分标准拆开：三个映射各占三成，边界判断占一成。常见错误集中在四处。其一，把 MeshAnything 当成 QEM 简化：QEM 是保拓扑的几何压缩，输出仍是原网格的近似；AMT 是自回归生成新网格，输出拓扑可以不同于输入，二者目标函数不同。其二，忽略 AMT 的共享边：只答「相邻面 tokenization」而不说「已出现的边不重复写、只写新顶点」，等于没答到机制。其三，以为部件生成不需要全局关系：PartCrafter 的联合去噪正是全局关系的载体，拆开讲独立生成会丢掉一致性约束。其四，把重拓扑等同于简化：重拓扑追求的是下游可用的拓扑结构（四边形走向、边环、部件边界），面数下降只是副产品。

错误失分机制纠正落点
MeshAnything=QEM混淆几何近似与拓扑重写输出拓扑可变，非保拓扑压缩
漏说共享边未命中 AMT 的核心省冗余手段相邻面共享边、只写新顶点
部件独立即无全局忽略联合去噪的全局可见性潜变量在同一步去噪中互相约束
重拓扑=简化把下游需求误读为面数指标拓扑顺滑与部件清才是目标

系统代价层面，这些错误往往对应真实的工程误判：按 QEM 思路调参会让生成网格的边环断裂，动画绑定阶段出现权重跳变；忽略共享边会让 token 序列膨胀，自回归上下文窗口被迫截断，长序列尾部质量下降；把部件生成当独立任务会让接触面在渲染时出现 z-fighting。

六 · 教学建议与判分演练

教学上建议把三个映射做成「一层一机制一代价」的对照卡：词表层讲面片 token 如何把拓扑内生进序列，代价是码本容量与序列长度；序列层讲共享边如何把冗余压到新增顶点，代价是边句柄的全局一致性；潜变量层讲联合去噪如何维持部件间关系，代价是显存与采样步数。每张卡必须配一个失败模式和一个具体物件例子，避免考生背结论。

判分演练可以给一段考生答案做逐句标注：出现「VQ 面片 token + 自回归」记词表分；出现「相邻面共享边、只写新顶点」记序列分；出现「按部件独立生成再联合去噪」记潜变量分；出现「重拓扑不是几何简化」记边界分。若考生写「MeshGPT 用顶点量化」，词表分扣；写「AMT 减少面数」，序列分扣，因为省的是 token 冗余而非面数；写「PartCrafter 先分部件再拼」，潜变量分扣，因为漏了联合去噪。教学时让学生用同一物件（如带榫的方凳）分别走三条机制，观察哪一层先失效：面片词表在长序列尾部失稳，AMT 在非流形边处句柄冲突，PartCrafter 在弱接触面处缝隙累积。这样把「三档答案」的抽象标准落到可观察的系统行为上。
