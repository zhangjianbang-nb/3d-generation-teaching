一 · 变体题的设计逻辑：把单点知识拆成可迁移的判断

原题问的是“随机相机、CFG、w(t) 各起什么作用，去掉一个会怎样”，这是一个典型的“三件套职责划分”题。变体题的价值不在于换措辞，而在于改变约束条件，迫使答题者从“背职责”转向“做工程判断”。围绕同一组事实，可以构造三个方向不同的变体，每个变体都只移动一个变量，其余保持不变，这样评分时才能把差异归因到具体机制上。

变体一：把“去掉一个”改成“只保留一个”。原题是减法，变体是极端减法。只保留随机相机、去掉 CFG 与 w(t)，结果是视角覆盖仍在，但文本条件不再被放大，生成结果与提示的贴合度下降；同时不同噪声水平的梯度不再被加权，高低频贡献失衡。只保留 CFG，则视角覆盖不足，背面崩坏的风险立刻暴露，因为每个视角没有被 2D 先验独立约束。只保留 w(t)，则文本不听话且视角覆盖不足，两个失败模式叠加。这个变体的判分点在于：答题者必须说明“保留的那一个能救什么、不能救什么”，而不是简单罗列三者功能。

变体二：把“去掉一个”改成“调换调参顺序”。原题解析给出的顺序是先相机分布、再 CFG、再 w(t)。变体问：如果先调 CFG 再调相机分布，会出什么问题？机制上，CFG 放大的是文本条件对梯度的贡献，它不改变视角采样分布。若相机分布尚未覆盖足够视角，先把 CFG 拉高，会让少数被采样到的视角产生更强的文本驱动梯度，优化更集中地偏向这些视角，视角间的不均衡被放大而非缓解。系统代价是：调参迭代次数增加，因为每次改相机分布都要重新校准 CFG，先前调好的 CFG 值不再处于合适区间。具体例子：一个场景先以固定正面视角把 CFG 调到较高值，随后加入随机相机，会发现背面视角在强文本梯度下出现结构撕裂，必须回退 CFG 重新调。

变体三：把“三者作用”改成“三者能否互相替代”。这是一个边界判断题。随机相机约束的是视角覆盖，CFG 约束的是文本贴合，w(t) 约束的是噪声尺度上的梯度平衡，三者的作用维度正交，不能互相替代。用提高 CFG 去弥补相机覆盖不足，只会让已有视角更贴文本，无法生成未覆盖视角的约束；用加密相机分布去弥补 w(t) 缺失，只能增加视角数量，不能修正高低频梯度比例。判分时，能指出“正交不可替代”并给出一个具体替代失败的场景，才算触及边界。

变体移动的变量考查的能力典型失败回答
只保留一个减法到极端区分“能救”与“不能救”把三者功能并列复述，不说明保留项的局限
调换顺序调参次序理解变量间的耦合认为顺序无关，只要最终都调到位

二 · 五个追问：从职责划分逼到有偏性边界

追问一：三者都是工程补丁，那 SDS 的有偏性到底体现在哪里？这是原题解析里“不能根治 SDS 的有偏性”一句的展开。SDS 的梯度来自 2D 扩散先验对渲染图像的打分，它并不直接约束 3D 几何的一致性。随机相机让每个视角都被 2D 先验约束，缓解的是视角覆盖不足带来的背面崩，但 2D 先验本身对多视角一致性的判断是间接的，所以补丁只能压低某类失败的发生率，不能消除梯度与真实 3D 分布之间的偏差。回答这个追问，必须把“补丁作用”与“有偏性来源”分开说，不能把两者混为一谈。

追问二：CFG 放大文本条件，放大倍数过高时系统代价是什么？机制上，CFG 通过放大条件项与无条件项的差值来增强文本驱动。倍数过高时，梯度中文本条件的贡献压过图像先验的贡献，优化会过度拟合提示中的语义，牺牲几何合理性。系统代价表现为：渲染结果在文本描述的部位过度强化，而未被文本提及的区域出现结构塌陷或颜色过饱和。具体例子：提示强调“金属质感”，CFG 过高时金属区域被过度锐化，周围非金属区域的边界出现不自然的硬边。这正是“以为 CFG 越高越好”这一常见错误的根源。

追问三：w(t) 按噪声水平加权，如果把 w(t) 当常数会怎样？机制上，不同噪声水平对应不同尺度的图像结构，高噪声阶段主导低频布局，低噪声阶段主导高频细节。w(t) 的作用是平衡这两类梯度。当成常数处理，等于放弃尺度平衡，结果是高低频梯度比例固定，无法随噪声水平调整。失败模式有两种：常数偏向高频时，低频布局尚未稳定就被细节梯度干扰，出现整体结构模糊；常数偏向低频时，高频细节得不到足够梯度，细节糊。回答时必须给出“细节糊或噪”这一对失败方向，而不是只说“效果变差”。

追问四：随机相机分布本身怎么选，覆盖不足与覆盖过密各自的代价是什么？覆盖不足直接导致视角覆盖不够、背面崩，这是原题已给的失败模式。覆盖过密的代价不在原题事实里，但可以从机制推出：相机采样过密会增加每次迭代的渲染与反传开销，且相邻视角的 2D 先验约束高度相关，边际信息增益递减。工程判断是：相机分布要先保证视角覆盖的广度，再考虑密度，因为广度对应的是“有没有约束”，密度对应的是“约束重复多少次”。这个追问考查的是答题者能否把“覆盖”拆成广度与密度两个维度。

追问五：调参顺序为什么是先相机分布、再 CFG、再 w(t)？机制上，相机分布决定梯度来自哪些视角，是梯度来源的结构性约束；CFG 决定文本条件在梯度中的权重；w(t) 决定不同噪声水平的梯度比例。后两者都是在既定梯度来源上做加权，所以必须先固定来源，再调权重。若顺序颠倒，每次改相机分布都会让先前调好的 CFG 与 w(t) 失去参考基准，调参变成反复回退。系统代价是调参轮次增加，且难以判断失败是来自覆盖不足还是权重失当。具体例子：先调 w(t) 再换相机分布，会发现原本平衡的尺度比例在新视角分布下不再平衡，必须重调。

三 · 扣分点：评分标准如何落到具体回答上

评分标准给出三者作用各 30%、边界 10%。这个比例意味着：只答出三者功能而完全不提“不能根治有偏性”，最高只能拿到 90% 的分；而三者作用中任何一项缺失或说错，直接损失 30%。扣分点要按“缺失、错位、越界”三类来拆。

缺失类扣分：没有提到随机相机覆盖视角，或没有提到 CFG 贴文本，或没有提到 w(t) 平衡尺度。这三项各占 30%，缺一项即扣对应比例。常见形态是答题者把随机相机说成“增加多样性”而不落到“每个视角都被 2D 先验约束”，这属于表述不到位，按缺失处理，因为“多样性”没有点出约束机制。

错位类扣分：把三者的作用张冠李戴，例如说 CFG 负责视角覆盖、随机相机负责文本贴合。这种错位比缺失更严重，因为它显示答题者没有建立职责与机制的对应关系。评分时应按对应项全额扣除，并且不能因为“提到了三个词”而给部分分。

越界类扣分：声称三者可以根治 SDS 的有偏性，或声称提高 CFG 可以替代相机覆盖。这类回答触碰了边界项，扣 10%，同时可能连带影响三者作用的得分，因为越界表述往往伴随对作用范围的误解。边界项的 10% 看似小，但它是区分“及格”与“满分”的关键：及格答案能把三者说清，满分答案还必须说清三者的局限。

扣分类型触发条件扣分比例是否连带
缺失三者作用缺一项或表述未落到机制对应项 30%否
错位作用与机制张冠李戴对应项全额可能影响相邻项
越界声称可根治有偏性或可互相替代边界 10%可能连带作用项

四 · 常见错误：三个错误各自的机制根源

错误一：以为 CFG 越高越好。根源在于把 CFG 当成“文本贴合度的单调旋钮”。机制上，CFG 放大的是条件项与无条件项的差值，它在低倍数区间确实提升贴合度，但超过某个区间后，文本梯度压过图像先验梯度，几何合理性被牺牲。系统代价是结构塌陷与过饱和。具体例子：提示里同时出现“光滑”与“粗糙”两种材质描述，CFG 过高时模型会强行在相邻区域制造强烈对比，边界出现不自然的硬边。正确判断是：CFG 要在相机分布固定后调，且以“文本贴合但不破坏几何”为上限。

错误二：忽略相机分布。根源在于把随机相机当成“数据增强”式的可选技巧，而不是梯度来源的结构性约束。机制上，相机分布决定哪些视角被 2D 先验约束，覆盖不足时未被采样的视角没有梯度来源，优化只能靠已采样视角的泛化，背面崩就是这种泛化失败的表现。系统代价是：即使 CFG 与 w(t) 都调好，视角覆盖不足仍会让结果在未覆盖区域崩坏，且这种崩坏不能靠调权重修复。具体例子：固定正面视角训练，背面在渲染时出现几何撕裂，此时提高 CFG 只会让正面更贴文本，背面依旧崩。

错误三：把 w(t) 当常数。根源在于把“按噪声水平加权”误解为“一个全局缩放系数”。机制上，w(t) 是噪声水平的函数，不同噪声水平对应不同尺度，常数化等于放弃尺度平衡。失败方向有两个：偏向高频导致低频布局未稳就受细节干扰，整体模糊；偏向低频导致高频细节梯度不足，细节糊。具体例子：把 w(t) 设为常数且偏大，早期高噪声阶段被过度加权，低频布局反复震荡，最终渲染出现整体噪感。正确做法是让 w(t) 随噪声水平变化，先稳低频再补高频。

  • CFG 错误的核心是“单调假设”，忽略了文本梯度与图像先验梯度的竞争。
  • 相机分布错误的核心是“可选假设”，忽略了梯度来源的结构性。
  • w(t) 错误的核心是“常数假设”，忽略了尺度与噪声水平的对应。

五 · 教学建议：把三件套讲成一条调参链

教学上最容易犯的错是分三节讲三个变量，每节讲一个功能，结果学生记住了三个词却不知道它们如何耦合。更有效的组织方式是把三者讲成一条调参链：先固定梯度来源（相机分布），再调文本权重（CFG），再调尺度比例（w(t)），每一步都问“上一步没固定时，这一步调了会怎样”。这样讲，变体二“调换顺序”就自然成为课堂练习，而不是额外负担。

具体教学动作可以设计成三步。第一步，让学生用“只保留一个”的变体做口头推演，每人只说“保留项能救什么、不能救什么”，迫使区分职责边界。第二步，给出一个失败渲染案例（视角覆盖不足导致背面崩），让学生判断应该先动哪个变量，正确答案是先动相机分布，因为这是梯度来源问题，调 CFG 与 w(t) 都不能补上未覆盖视角的约束。第三步，让学生写出“三者不能根治有偏性”的一句话解释，作为边界项的训练。三步都围绕同一组事实，不引入新数字，符合事实约束。

批改建议：对“缺失”类回答，要求补写机制而非补写名词；对“错位”类回答，要求画出“变量—机制—失败模式”的对应表；对“越界”类回答，要求指出补丁作用与有偏性来源的区别。这样批改能把评分标准的三档落到可操作的动作上，而不是停留在给分。

还有一个教学要点：不要把“调参顺序”讲成固定教条，而要讲成“依赖关系”。相机分布是 CFG 与 w(t) 的参考基准，所以先定；CFG 影响梯度中文本项的权重，w(t) 影响尺度比例，两者都在既定来源上加权，所以后调。学生理解了依赖关系，遇到变体三“能否替代”时就能自己推出“正交不可替代”，而不是背结论。

最后落到一个工程判断：三件套的调参链之所以有效，是因为它把“梯度来源—文本权重—尺度比例”三层依赖显式化，任何一层未固定就调下一层，都会让调参变成反复回退。教学的任务不是让学生记住三个功能，而是让他们在看到一个失败渲染时，能判断失败发生在哪一层，并知道该层对应的变量是什么。这个判断能力，正是变体题与追问要逼出来的东西。
