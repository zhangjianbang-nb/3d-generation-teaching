一 · 题目定位与三档答案的分层标准

这道题位于第 3 层 paper 档，问的是 SJC 中「扰动」的作用及其与 SDS 的关系。它的判分结构被明确切成两块：扰动目的占 50%，与 SDS 的关系占 50%。这个对半开的比例本身就是信号——出题人认为「为什么必须加噪」和「它和 SDS 是什么血缘」是同等权重的两件事，任何一半空缺都只能拿到一半分。把三档答案拆开看，及格、良好、满分之间的差别不在字数，而在是否把「训练分布」这个核心约束说透。

及格档的答案通常这样写：SJC 的扰动是为了让渲染图变成带噪图，因为扩散模型在噪声图上训练，直接问干净图不行；它和 SDS 一样都是用 2D 先验指导 3D。这段话覆盖了两个判分点的关键词，但每个点都停在结论层面，没有机制。它能拿到「扰动目的」的一半和「与 SDS 关系」的一半，合计约 50%–60%。

良好档会补上机制链条：扩散模型的前向过程定义了从干净图到纯噪声的马尔可夫链，模型只在某个噪声水平区间内见过数据，所以干净渲染图落在训练分布之外；SJC 先按前向过程把渲染图加噪到 x_t，再让模型在 x_t 上预测得分。它也会点出 PAAS 对多个噪声样本取平均来降方差，以及得分要经雅可比回传到 3D 参数。这一档能拿到 75%–85%，扣分点往往在「同族」的论证上——只说「都是 SDS」而不说清「同族」指什么。

满分档必须做三件事：第一，把「得分是噪声图的函数」这句话展开成分布论证，说明为什么干净图是分布外样本；第二，把 PAAS 的降方差机制写成可检验的估计量结构，而不只是「平均一下」；第三，把「同族」落到数学形式上——两者都是把 2D 得分经雅可比提升到 3D，只是推导路径不同。满分答案还会主动处理常见错误，比如噪声水平 t 的选择、CFG 是否仍然需要。

档位扰动目的与 SDS 关系典型缺口
及格说出「要加噪、否则分布外」说出「都是 2D 指导 3D」无机制、无公式
良好前向过程 + x_t + PAAS 降方差雅可比回传 + 同族表述同族论证空泛
满分分布论证 + 估计量结构 + t 选择形式同族 + 推导路径差异 + CFG几乎无

这张表的用法不是背，而是自检：写完答案后逐格对照，看自己在哪一格是空的。多数失分不是写错，而是某一格根本没写。

二 · 扰动目的的机制解析：为什么干净图是分布外样本

要讲清扰动，先要讲清扩散模型学到的是什么。前向过程把数据 x_0 逐步加噪：

$$x_t = \sqrt{\bar\alpha_t}\,x_0 + \sqrt{1-\bar\alpha_t}\,\epsilon,\quad \epsilon\sim\mathcal{N}(0,I)$$

这里 $\bar\alpha_t$ 是累积噪声调度系数，随 t 增大而衰减到接近零。训练时，模型在每一个 t 上接收的是「被污染到该噪声水平」的样本，学习的是条件得分 $\nabla_{x_t}\log p_t(x_t)$。关键点在于：模型从未在 $\sqrt{\bar\alpha_t}=1$ 的干净样本上被训练过——即便 t 取很小的值，输入也总带着一点噪声。因此，把一张干净渲染图直接喂给模型问得分，等于让模型在一个它训练时从未见过的输入分布上做外推。这就是「落在训练分布外」的准确含义，不是比喻。

外推的后果不是简单的精度下降，而是得分方向失真。模型在分布外区域的输出没有训练信号约束，可能给出与真实对数密度梯度无关的向量；把这个向量当作 3D 参数的更新方向，优化会朝错误方向走，表现为渲染图纹理漂移、几何塌陷或颜色过饱和。这是一个系统性的失败模式，不是偶发噪声。

SJC 的解法是显式地把渲染图映射回训练分布内：先按前向过程对渲染图加噪到某个 t，得到 x_t，再让模型在 x_t 上预测得分。这样输入就落在模型见过的噪声水平上，得分估计才有意义。解析里那句「得分是噪声图的函数」正是这个意思——得分不是干净图的属性，而是 $(x_t, t)$ 的联合函数，问得分时必须同时给出噪声水平。

具体例子：假设渲染图是一张纯色墙面，模型在训练中见过大量带中等噪声的墙面纹理。直接把干净墙面送进去，模型可能把它误判为「极低噪声下的异常样本」，给出的得分指向「增加纹理」；而先加噪到中等 t，模型识别出这是正常的墙面噪声样本，得分指向「去噪回墙面」，方向就对了。同一个 3D 场景，加噪与否导致更新方向相反。

系统代价在这里体现为一次额外的前向采样：每个优化步都要对渲染图做一次加噪，还要为 PAAS 采样多个噪声样本。噪声样本数 k 增大，单步计算量线性上升，显存占用也随 batch 增大。这是用计算换分布正确性的典型交易。

三 · PAAS 的降方差机制与估计量结构

PAAS 即 perturb-and-average score，字面就是「扰动再平均」。单次加噪得到的得分估计是一个随机变量，因为噪声 $\epsilon$ 是采样的。若只用一次采样，得分估计的方差会直接注入 3D 更新方向，造成优化轨迹抖动。PAAS 的做法是对同一个渲染图采多个噪声样本，分别加噪、分别问得分，再取平均：

$$\hat{s}(x_0)=\frac{1}{k}\sum_{i=1}^{k}\nabla_{x_{t_i}}\log p_{t_i}(x_{t_i}),\quad x_{t_i}=\sqrt{\bar\alpha_{t_i}}\,x_0+\sqrt{1-\bar\alpha_{t_i}}\,\epsilon_i$$

这是蒙特卡洛估计的标准结构：k 个独立样本的均值，其方差是单样本方差的 $1/k$。也就是说，噪声样本数翻倍，得分估计的标准差降到约 $1/\sqrt{2}$。这不是「平均一下更稳」的模糊说法，而是有明确收敛率的估计量设计。

但 PAAS 不只是降方差，它还承担了「覆盖噪声水平」的职责。如果所有样本都取同一个 t，平均只降低采样噪声，不改变分布覆盖；实际实现中 t 也在一个区间内采样，使平均同时跨越多个噪声水平。这带来一个设计问题：t 的区间怎么选。t 太小，输入仍接近干净图，分布外问题没解决；t 太大，输入接近纯噪声，得分几乎不含原图信息，更新方向退化为随机。所以 t 的选择是 SJC 的一个真实超参数，忽略它正是常见错误之一。

失败模式：k 取得太小（比如 1 或 2），方差降不下来，优化在高频纹理上抖动；k 取得太大，单步代价线性增长，在有限算力下优化步数被迫减少，收敛变慢。这是一个需要权衡的系统代价，而不是越大越好。

具体例子：优化一个带细密条纹的物体表面。单样本得分估计在「条纹加密」和「条纹减淡」之间来回跳，渲染结果出现摩尔纹闪烁；把 k 提到 8 并让 t 覆盖中等噪声区间后，平均得分稳定指向「保持条纹间距」，闪烁消失。这里的关键不是 k 的具体数值，而是「平均跨越了噪声水平」这一结构。

四 · 与 SDS 的同族关系：雅可比是共同骨架

判分点的另一半是「与 SDS 同族」。同族不是「名字相似」或「都用于 3D 生成」，而是数学形式上的血缘：两者都把 2D 图像模型的得分，经雅可比矩阵提升为 3D 参数的梯度。

设 3D 参数为 $\theta$，渲染函数为 $g(\theta)$ 输出图像 $x_0$。2D 模型给出的是图像空间的对数密度梯度 $s=\nabla_{x}\log p(x)$。要把这个梯度变成对 $\theta$ 的更新，需要链式法则：

$$\nabla_\theta \log p(g(\theta)) = J_g^{\top}\,s,\quad J_g=\frac{\partial g(\theta)}{\partial\theta}$$

$J_g^{\top}$ 就是把图像空间得分回传到 3D 参数的雅可比转置。SDS 和 SJC 都建立在这个式子上：SDS 通过加噪-去噪的分数蒸馏形式导出这个梯度，SJC 通过「加噪后问得分再平均」导出同一个梯度。推导路径不同——SDS 从蒸馏目标出发，SJC 从得分是噪声图函数这一观察出发——但落点相同。这就是「同族」的准确含义：共享雅可比回传骨架，差异在前向构造与估计方式。

这个形式还解释了一个常见错误的来源：以为 SJC 不需要 CFG。CFG（无分类器引导）作用在 2D 模型的得分上，通过调节条件与无条件得分的差值来增强条件性。既然 SJC 用的是同一个 2D 得分，CFG 就仍然在链条里，只是它作用在 $s$ 这一层，再经雅可比放大到 3D。忽略 CFG 等于丢掉了条件控制，生成结果会失去文本或图像条件的约束。

系统代价：雅可比 $J_g$ 的维度是「图像像素数 × 3D 参数数」，显式构造不可行，实际实现用自动微分或向量-雅可比积完成。每次回传都要穿过渲染器，渲染器的可微性成为硬约束；渲染分辨率越高，回传代价越大。这是同族骨架带来的共同工程负担。

具体例子：一个可微的体渲染器，参数是密度场和颜色场。2D 模型在加噪渲染图上给出「增加边缘对比」的得分，雅可比把这个图像空间的向量映射成密度场在边缘处的梯度，更新后边缘变锐。SDS 和 SJC 在这一步的行为一致，差别只在得分估计的方差与分布覆盖。

五 · 数字底账与评分演练

本题可用的数字只有评分比例：扰动目的 50%，与 SDS 关系 50%。所有机制性数字——噪声样本数 k、噪声水平 t 的区间、雅可比维度——题目没有给出，因此只能定性表述，不能编造具体数值。写答案时若出现「k 取 8」「t 在 0.2 到 0.8 之间」这类数字，必须标明是示例而非题目给定，否则会被视为超出事实范围。

评分演练：拿一份典型答案逐句对照判分点。第一句「SJC 加噪是为了让渲染图进入训练分布」——命中「加噪到训练分布」，得扰动目的的部分分。第二句「用 PAAS 平均多个噪声样本降方差」——命中「PAAS 平均降方差」，补足扰动目的的另一半。第三句「得分经雅可比回传 3D」——命中第三个判分点。第四句「和 SDS 一样」——只命中「同族」的字面，若没有雅可比形式的论证，这一半只能拿一半。合计约 75%，正是良好档。

要升到满分，需要在第四句后补上形式论证：写出 $\nabla_\theta \log p(g(\theta))=J_g^{\top}s$，说明两者共享这个骨架，差异在推导路径。再补一句噪声水平 t 的选择是真实超参数，以及 CFG 仍作用在 2D 得分上。这样四个判分点全部落地，且常见错误被主动排除。

判分点权重命中标志失分写法
加噪到训练分布扰动目的内说出干净图是分布外、前向过程映射只说「加噪更好」
PAAS 平均降方差扰动目的内写出均值估计量与 $1/k$ 方差只说「平均一下」
得分经雅可比回传关系部分内写出 $J_g^{\top}s$只说「指导 3D」
与 SDS 同族关系部分内共享骨架、推导路径不同只说「都是 SDS」

常见错误里，「直接对干净图问得分」对应分布论证缺失，「忽略噪声水平 t 的选择」对应 PAAS 结构缺失，「以为 SJC 不需要 CFG」对应同族链条断裂。这三条恰好一一映射到三个机制环节，说明错误不是零散的，而是机制没打通时的必然产物。

工程判断上，这道题的满分答案不需要长，但每一句都要落在机制上：分布外是因为训练只见过带噪样本；PAAS 是 $1/k$ 方差的蒙特卡洛均值；同族是因为共享 $J_g^{\top}s$ 骨架。把这三句写实，比堆砌「SJC 很重要」之类的套话有效得多。评分标准对半开的结构也提示：扰动目的和 SDS 关系不能互相替代，任何一半写成另一half的复述都会丢分。
