一 · 变体题：把“省内存”换成“省什么”

原题问的是“为什么比体素省内存”，但真正考察的是对表示复杂度的判断力。变体题的第一种常见改法是换比较对象：不问体素，而问“三平面与隐式神经场（如纯 MLP 坐标网络）相比，优势与代价各是什么”。这时答案的重心必须移动：三平面把空间信息显式地压进三个 2D 特征图，查询时靠双线性采样取特征，代价是特征图分辨率固定，细节受限于平面像素密度；纯坐标 MLP 不存特征图，参数随网络宽度增长而非分辨率平方增长，但每次查询都要跑前向，渲染一个像素需要几十到上百次网络求值。两者的省法不同：三平面省的是“每次查询的计算”，隐式场省的是“显式存储”。答题时必须点明这是两种不同的资源置换，而不是笼统说“三平面更高效”。

第二种改法是换维度：问“如果把三平面换成四平面或六平面（沿不同轴切分），会怎样”。机制上，增加平面数量意味着每个 3D 点被投影到更多平面上采样再拼接，特征表达能力上升，但存储从 3 个平面变成 k 个平面，线性增长；同时拼接后的特征维度变大，后续解码器输入变宽。系统代价在于：平面数量增加并不改变平方增长的阶，但常数项变大，且平面之间的冗余相关会浪费容量。一个具体例子是：三平面已经能通过 XY/XZ/YZ 三个正交投影覆盖全部三个坐标轴的两两组合，再加平面只能提供重复的轴向信息，收益递减。答题时若只说“更多平面更好”而不提冗余与常数代价，就落进了陷阱。

第三种改法是换任务：问“三平面表示能否直接用于动态场景或可控编辑”。机制上，三平面本身是静态的规范空间表示，要支持形变或编辑，需要在平面特征上叠加位移场或语义掩码，或者让生成器输出条件化的平面。代价是：神经渲染的解码过程必须跟着改，双判别器的姿态分支也要能处理变化后的视角一致性，否则监督信号会打架。失败模式很具体：若只在平面上做局部编辑而不重跑渲染与判别，编辑区域在多视角下会出现“贴图滑动”——同一个 3D 点在不同视角采样到不同平面位置，颜色不连贯。这个例子说明三平面的省内存优势建立在“规范空间固定”的前提上，一旦前提松动，省下来的资源会被一致性维护吃掉。

二 · 追问一：双线性采样到底在算什么

追问“投影到三个平面后怎么取特征”是最容易被含糊过去的一环。具体机制是：给定 3D 点 (x, y, z)，归一化到 [-1, 1] 后，XY 平面取 (x, y)，XZ 平面取 (x, z)，YZ 平面取 (y, z)，各自在对应 2D 特征图上做双线性插值。双线性插值不是取最近像素，而是用四个相邻格点的加权和，权重由小数坐标决定。设平面特征图为 F，格点坐标为 (i, j)，小数部分为 (u, v)，则采样值为：

$$F(x,y)=\sum_{a\in\{0,1\}}\sum_{b\in\{0,1\}} w_a(u)\,w_b(v)\,F[i+a,\,j+b]$$

其中 w_0(t)=1-t，w_1(t)=t。三个平面各得一个特征向量，拼接后送入轻量解码器得到该点的密度与颜色。追问的扣分点在于：只答“采样”不答“双线性”，或只答“拼接”不答“三个平面各自对应哪两个坐标”。评分标准里三平面采样占 50%，正是因为这一环是整套表示的物理核心——它把 3D 查询降维成三次 2D 查表。系统代价也要说清：双线性采样对特征图分辨率敏感，分辨率翻倍则存储四倍、采样带宽四倍，而采样误差随分辨率下降；分辨率不足时，高频细节在平面上被抹平，渲染出的边缘发虚。具体例子：若平面分辨率为 256，一个占据画面很小区域的物体，其 3D 点投影后落在少数格点之间，插值结果趋于平滑，细纹理丢失；这正是“平方增长”换来的省内存所必须支付的清晰度代价。

三 · 追问二：为什么骨干必须是 2D 卷积 GAN

追问“为什么不用 3D 卷积直接生成体素”时，答案要落在计算阶与配方复用两点上。机制上，2D 卷积在 H×W 特征图上滑动，参数量与计算量随 H·W 增长；3D 卷积在 H×W×D 上滑动，随 H·W·D 增长。同样把边长记为 N，2D 是 N²，3D 是 N³。生成三平面只需三个 N×N 的 2D 卷积网络（或一个共享骨干输出三通道组），而生成同分辨率的体素需要 N³ 的 3D 卷积。系统代价的差别不是常数级，而是阶的差别：N 从 128 到 256，2D 计算涨四倍，3D 涨八倍。另一个机制是配方复用：StyleGAN2 的调制卷积、噪声注入、渐进生长等成熟技巧在 2D 上已被验证，直接搬到三平面生成上，收敛行为可预期；而 3D GAN 的训练稳定性、显存占用、批大小都更难调。失败模式很具体：若强行用 3D 卷积骨干，显存会在中等分辨率下就被吃满，批大小降到个位数，判别器得不到足够样本，训练震荡。具体例子：在单卡条件下，2D 骨干能以较大批大小稳定训练三平面生成器，而同等分辨率的 3D 骨干往往需要梯度检查点与模型并行才能跑起来，工程复杂度陡增。答题时若只说“2D 便宜”而不提阶的差别与配方复用，扣分点在“骨干/判别”这 50% 里。

四 · 追问三：神经渲染与双判别器各管什么

追问“三平面生成完就结束了吗”是在查是否忽略了解码与监督。机制上，三平面只是特征存储，真正变成图像要靠神经渲染：沿相机射线采样若干 3D 点，逐点做三平面采样得到特征，经解码器输出密度与颜色，再按体渲染积分合成像素。没有这一步，三平面只是一堆特征图，不构成可监督的图像。双判别器则分工明确：图像判别器看渲染出的 2D 图像是否真实，姿态判别器看渲染视角与输入相机参数是否一致。前者提供外观监督，后者提供几何与视角一致性监督。系统代价在于：神经渲染每像素要采样几十个点，每点三次双线性采样加一次解码器前向，渲染成本随采样数线性增长；双判别器意味着两次前向与两次反传，训练吞吐下降。失败模式：若去掉姿态判别器，生成器可能学会在所有视角下渲染同一张“正面图”，图像判别器仍给高分，但多视角一致性崩塌；若去掉神经渲染、让平面直接出图，则三平面退化成普通 2D 特征图，3D 一致性无从谈起。具体例子：环绕视角渲染时，缺少姿态监督的模型在侧视角出现明显拉伸与重影，而双判别器配置下侧视角仍保持结构连贯。扣分点在于把“生成三平面”当成终点，或把双判别器说成“两个图像判别器”。

五 · 追问四与五：分辨率、显存与失败边界

追问四问“分辨率提高时谁先撑不住”。机制上，三平面存储随 N² 增长，但神经渲染的采样成本与解码器前向次数随像素数×采样数增长，后者往往先成为瓶颈。设渲染分辨率为 R²，每像素采样 S 点，则解码器前向次数为 R²·S，与平面分辨率 N 解耦；提高 N 只增加采样带宽与存储，提高 R 则直接放大渲染计算。系统代价：显存里同时驻留三平面特征图、采样中间激活、双判别器参数，激活值随 R²·S 增长最快。失败模式是显存碎片化导致的批大小骤降，进而训练不稳定。具体例子：在固定显存下，把渲染分辨率翻倍往往比把平面分辨率翻倍更早触发 OOM，因为前者放大的是每步激活，后者放大的是静态参数。答题时若把两者混为一谈，说明没有区分“存储阶”与“计算阶”。

追问五问“三平面表示在什么情况下会失效”。机制边界有三条：其一，高度非刚性或拓扑变化的物体，规范空间假设松动，平面特征难以对齐；其二，需要精确表面提取的任务，三平面输出的是体积密度场，等值面提取要额外跑 marching cubes，分辨率受平面像素密度限制，薄结构易断；其三，极端视角或超出训练分布的姿态，神经渲染的积分误差与判别器的监督盲区同时出现。失败模式具体表现为：薄壁物体在渲染中出现空洞，或大角度俯仰时背景与前景特征串扰。具体例子：对细长杆状物体，平面投影在某一轴上退化，三个平面中有两个几乎采到相同信息，表达能力被压缩，杆的截面细节丢失。这一追问的扣分点在于只答“三平面很好”而不给失效条件——满分答案必须能说出表示的前提假设。

六 · 扣分点、常见错误与教学建议

把判分点拆成可操作的扣分清单：未点明“三个 2D 平面分别是 XY/XZ/YZ”扣采样部分；未说明“投影后双线性采样再拼接”扣采样部分；未对比“平方 vs 立方”扣增长阶；未提“StyleGAN2 骨干”与“神经渲染+双判别器”扣骨干判别部分。常见错误有四类：把三平面当成三张 RGB 图（错在特征是学习到的，不是颜色）；忽略神经渲染的解码作用（错在把特征当图像）；以为模型直接输出网格（错在输出是密度场，网格需后处理）；把双判别器说成两个图像判别器（错在姿态分支的功能）。教学建议落在三个动作上：第一，让学生手写一次双线性采样的四格点加权，亲手算一个 3D 点在三平面上的取值；第二，用一张表对比 2D 与 3D 卷积在 N=128 与 N=256 时的计算阶，让“平方 vs 立方”变成可算的账；第三，给一个去掉姿态判别器的对照设定，让学生描述多视角一致性如何崩，从而理解双判别器的分工。表格如下，用于课堂快速核对：

判分维度必须出现的关键词典型失分表述
三平面采样（50%）XY/XZ/YZ、投影、双线性、拼接“三个平面就是三张图”
增长阶平方、立方、N² 对 N³“三平面更省”但不说阶
骨干（25%）StyleGAN2、2D 卷积、配方复用“用 3D 卷积也行”
判别与渲染（25%）神经渲染、体渲染积分、图像+姿态双判别“生成完三平面就出图”

工程判断上，这道题的深读价值不在于背下四个关键词，而在于建立“表示—计算—监督”三者的对应关系：三平面用平方阶的存储换掉了立方阶的存储与 3D 卷积，代价是必须靠神经渲染把特征解成图像、靠双判别器把多视角一致性钉住。任何一处缺失，省下来的内存都会以一致性或细节的形式还回去。
