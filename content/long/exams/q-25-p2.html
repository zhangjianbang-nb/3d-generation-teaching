一 · 变体题：把“架构题”改写成“机制归因题”

原题问的是“主干是什么、为什么能一次前向”，这属于描述加解释的混合题。变体一把它拧成纯归因题：给定 LRM 的推理路径，问“一次前向的能力究竟来自哪一部分设计，若去掉 cross-attention 只保留 ViT 编码器加三平面回归头，会发生什么”。这个变体考的不是背诵架构名词，而是能否把“amortized”落到具体模块上。参考答案的骨架是：ViT 把输入图切成 token，Transformer 的 cross-attention 把图像 token 映射为三平面 token，三平面再解码成 NeRF 或网格；能力来源是权重里蒸进了“图像到三平面”的先验，而这个先验是在约 50 万物体上训练出来的。若去掉 cross-attention，图像 token 与三平面 token 之间就没有可学习的对应关系，回归头只能做全局池化式的映射，空间对应被压平，多视角渲染损失无法把梯度精确分配到三平面的局部区域，训练会退化为学一个平均形状先验。

这里的具体机制是 cross-attention 的查询-键值分工：三平面 token 作为查询，图像 token 作为键和值，注意力权重形成一个可微的“采样坐标”，让每个三平面位置从图像中取它需要的证据。用公式表示，若记三平面 token 为 \(T_p\)、图像 token 为 \(I_q\)，则

$$T_p^{\text{new}}=\sum_q \operatorname{softmax}\!\left(\frac{(W_qT_p)\cdot(W_kI_q)}{\sqrt{d}}\right)W_vI_q$$

这个式子的工程含义是：梯度可以沿着注意力权重回传到图像编码器，也可以沿着值向量回传到三平面解码器，两侧被联合约束。系统代价在于注意力矩阵的规模随 token 数平方增长，高分辨率输入会推高显存与延迟；失败模式是注意力塌缩——所有权重集中到少数图像 token，三平面退化为少数全局特征的复制，表现为多视角渲染在未见视角上出现模糊或重复纹理。具体例子：若训练集中大量物体是居中拍摄的单物体，注意力容易学会“只看画面中心”，遇到偏心构图时三平面重建会丢掉边缘结构，这不是数据量不足，而是对应关系没有被监督信号逼出来。

二 · 变体题：分辨率上限的追问式改法

变体二不问架构，而问“LRM 的输出精度由什么决定，为什么提高输入图像分辨率不一定提高重建细节”。这题把注意力从“能不能一次前向”转到“一次前向的容量边界”。参考答案中的关键事实是三平面分辨率限制输出分辨率：三平面是一组二维特征图，解码器从三平面采样得到空间点的密度与颜色，三平面的像素数就是可表达细节的上限。设三平面分辨率为 \(R\times R\)，则单个平面可承载的独立特征数为 \(R^2\)，三个平面共享同一组空间坐标，实际可分辨的最小结构尺度受限于平面采样步长。用公式表达为

$$\Delta x \gtrsim \frac{L}{R}$$

其中 \(L\) 是物体包围盒的边长。输入图像分辨率提高，只会让 ViT 的 token 更细，cross-attention 能把更细的图像证据写进三平面 token；但如果三平面本身只有 \(R\times R\) 个位置，写入的证据会被邻近位置平均掉，细节无法落地。系统代价是显存与解码时间随 \(R^2\) 增长，而渲染多视角比对时需要在高分辨率下采样，否则损失函数看不到被抹掉的细节。失败模式是“训练损失很好看、渲染却发糊”：多视角渲染损失在低分辨率下计算，模型学会用低频结构骗过损失，三平面分辨率上限被掩盖。具体例子：同一物体用高分辨率输入图训练，但三平面固定为较低分辨率，渲染出的细长结构（如细腿、薄片）会出现断裂或粘连，这不是优化不收敛，而是表示容量的硬上限。

三 · 变体题：数据规模与“一次前向”的因果链

变体三把“50 万物体训练”从背景数字变成因果链的一环：问“如果训练物体数量减少一个量级，LRM 还能一次前向吗，失效表现是什么”。这题考的是对 amortized 边界的判断。参考答案的立场是：一次前向之所以成立，是因为优化过程被蒸进权重，而蒸进去的先验由训练数据的规模与质量决定上限。训练物体少，先验覆盖面窄，模型对未见类别、罕见拓扑、极端视角的映射会退化。具体机制是：cross-attention 学到的是一张“图像证据到三平面位置”的对应表，这张表由多视角渲染损失逐物体校准；物体类别与几何分布越窄，表越偏向训练分布，推理时遇到分布外输入就只能输出近似平均的形状。

伪代码思路可以写成：对每个训练物体，前向得到三平面，解码渲染多视角，与真值比对算损失，反传更新 ViT 与 Transformer 与解码器。整个循环里没有逐物体的测试时优化，所以推理成本是常数次前向；但训练循环的覆盖度决定了这个常数前向的可靠性。系统代价是训练侧的算力与数据清洗成本，失败模式是“一次前向仍然很快，但输出退化为模板”。具体例子：训练集若以刚性家具为主，遇到可变形或细长悬臂结构时，三平面会给出过于平滑的占据场，多视角渲染在侧视角出现明显偏差；这不是推理机制坏了，而是先验没有被足够多样的物体逼出对应关系。判分时若考生把“一次前向”说成“不需要 3D 数据”，就是踩中了常见错误：多视角渲染损失本身就需要真值视角或可微渲染的监督，3D 数据以渲染监督的形式参与训练。

四 · 五个追问：从名词到边界条件

追问一：ViT 切 token 后，图像的空间分辨率与三平面分辨率是什么关系？回答要点是两者不必相等，cross-attention 负责重采样，但三平面分辨率是输出细节的上限，图像 token 更细只提供更细的证据，不自动提高表示容量。追问二：多视角渲染损失为什么能替代显式 3D 监督？回答要点是可微渲染把三平面解码后的场投影到多个视角，与真值图像比对，梯度回传到三平面与编码器；它监督的是“从任意视角看都对”，而不是体素级标签。追问三：amortized 与测试时优化（test-time optimization）的代价差异在哪？回答要点是前者推理是常数次前向、成本低但受先验上限约束；后者逐物体优化、灵活但每个物体都要迭代，时间随物体数线性增长。追问四：三平面表示相比体素或纯 NeRF 的工程取舍是什么？回答要点是三平面把 3D 特征压到三个 2D 平面，显存与解码成本可控，但表达能力受平面分辨率与平面间耦合方式限制。追问五：如果渲染损失只在少数视角上计算，会出什么问题？回答要点是视角覆盖不足会让三平面在未监督视角上自由发挥，表现为背面或侧面的几何幻觉；这不是架构缺陷，而是监督信号的空间覆盖问题。

这五个追问的共同结构是：每个都要求把“架构名词”翻译成“约束条件”。判分时看考生能否说出机制、代价与失败模式三件事，而不是只复述 ViT、cross-attention、三平面这几个词。具体例子：追问三若只答“amortized 更快”，没有说出“快来自把优化蒸进权重、代价是数据规模决定上限”，就只拿到一半分。

五 · 扣分点与常见错误：评分表背后的失分结构

评分标准写明架构 50%、amortized 50%，扣分点就围绕这两块展开。架构侧的扣分点：只写“ViT + Transformer”而不写 cross-attention 的方向（图像 token 到三平面 token），扣；只写三平面而不写解码到 NeRF 或网格、再渲染多视角比对，扣；把渲染损失说成分类损失或重建损失而不提多视角，扣。amortized 侧的扣分点：把一次前向解释成“模型很大所以快”，没有说出优化过程被蒸进权重，扣；忽略训练数据规模与质量决定上限，扣；把“一次前向”误读为“不需要 3D 数据”，这是常见错误里最致命的一条，因为多视角渲染损失需要真值视角监督，3D 信息以渲染监督形式进入训练。

失分表述问题所在应补的机制
LRM 逐物体优化与 amortized 定义相反推理一次前向，优化在训练侧完成
一次前向不需要 3D 数据混淆推理与训练多视角渲染损失提供 3D 监督
三平面分辨率无关紧要忽略表示容量上限平面分辨率决定可表达细节尺度
只提 ViT 不提 cross-attention架构主干不完整图像 token 到三平面 token 的映射

还有一个隐性扣分点：把“50 万物体”当成装饰性数字，不说明它和先验覆盖面的关系。数字本身不是得分点，数字背后的因果链才是。具体例子：考生写“在 50 万物体上训练所以泛化好”，但没有说“训练分布决定先验边界、分布外输入会退化”，这在追问环节会被追着打。

六 · 教学建议：把这道题教成一条可复用的判断链

教学上不要把 LRM 讲成一个孤立模型，而要讲成“amortized 推理”的一个实例。第一步让学生画出推理路径：输入图、ViT 切 token、cross-attention 映射到三平面 token、三平面解码、多视角渲染。第二步在每条边上标注约束：token 数决定注意力成本，三平面分辨率决定细节上限，训练物体规模决定先验覆盖面。第三步给反例：去掉 cross-attention、降低三平面分辨率、缩小训练集，各问一次失效表现。这样学生记住的不是名词表，而是一条“设计选择、代价、失败模式”的判断链。

练习设计上，可以让读者用伪代码写出训练循环与前向循环的差异：训练循环里有多视角渲染与真值比对、有反传；前向循环里只有一次编码、一次 cross-attention、一次解码与渲染，没有逐物体迭代。这个对比能直接把 amortized 讲清楚。另一个练习是给一个分布外物体（如细长可变形结构），让学生预测三平面输出的失效形态，并说明是分辨率上限还是先验覆盖不足导致的。教学判断落在具体机制上：凡是学生能说出“哪个模块承担哪个约束、约束被突破时出现什么现象”，就算过关；凡是只能复述架构名词的，追问环节必然失分。
