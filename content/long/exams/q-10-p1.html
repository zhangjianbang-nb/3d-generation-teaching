一 · 三档答案的判分骨架

这道题的分值结构被切成两块：公式 50%，多面机制 50%。这不是随意分配，而是对应两种完全不同的能力——前者考你能否把 SDS 的梯度写对、写全，后者考你能否从这条公式里读出几何后果。三档答案的差别，本质上就是这两块各自完成到什么程度。

及格档的特征是“公式残缺 + 机制含糊”。典型写法是只写出 ∇θ L_SDS = E[w(t)(ε_φ − ε)]，把渲染雅可比 ∂x/∂θ 丢掉，然后补一句“SDS 让多视角不一致，所以出现两张脸”。这句话方向没错，但它没有说明“不一致”是从哪一步产生的，也没有把随机相机、CFG 与 Janus 的因果关系串起来。按判分点，公式块因为漏掉链式回传的关键因子而失分，机制块因为只给结论不给链条而失分，合起来落在及格线附近。

良好档能把公式写全，包括 w(t)、ε_φ(x_t;y,t)、ε 与 ∂x/∂θ 四个要素，并能指出“每个随机相机独立打分”。但它往往停在“独立”这个词上，没有进一步说明：独立打分意味着每个视角的梯度只优化“当前这张渲染图在 2D 先验眼里像不像”，而不同视角的梯度之间没有任何项去惩罚互相矛盾。于是良好档能拿到公式分的大部分，机制分只拿到一半——它知道现象，但说不清“为什么必然是多面而不是噪声”。

满分档则要同时做到三件事：公式逐项到位且解释每个符号的角色；把“逐视角独立”翻译成“优化目标在视角维度上可分解”；并明确指出 CFG 与随机相机是缓解手段而非根治手段，因为二者都没有在梯度里引入跨视角一致性约束。满分答案不会把 SDS 说成 3D 监督，也不会把提高 CFG 当成解法。

档位公式块机制块典型缺口
及格漏 ∂x/∂θ，符号不全只说“不一致导致两张脸”无因果链，无“独立”的展开
良好四要素齐全指出逐视角独立打分未说明目标可分解、未区分缓解与根治
满分齐全且逐项释义分解性 + 无一致性项 + 缓解边界无（需同时覆盖判分点全部）

这张表本身就是评分演练的底稿：阅卷时先看公式有没有 ∂x/∂θ，再看机制有没有把“独立”落到“目标可分解”上。两个判分点各自独立计分，所以“公式对但机制空”与“机制对但公式漏”都会掉档，而不是互相抵消。

二 · 公式的逐项机制解析

把梯度写成完整形式：

$$\nabla_\theta L_{\mathrm{SDS}} = \mathbb{E}\left[ w(t)\left(\varepsilon_\phi(x_t; y, t) - \varepsilon\right) \frac{\partial x}{\partial \theta} \right]$$

这里每个符号都承担一个不可省略的角色。x 是当前相机下渲染出的图像，它是参数 θ（比如 NeRF 的密度与颜色场、或高斯泼溅的均值与协方差）经过可微渲染器得到的输出；ε 是前向加噪时真实注入的噪声；ε_φ(x_t;y,t) 是 2D 扩散模型在噪声水平 t、以文本 y 为条件时对“这张带噪图里应该有多少噪声”的预测；二者之差就是 2D 先验给出的“去噪方向”，也就是所谓 2D 得分。w(t) 是随噪声水平变化的权重，控制不同 t 下这项得分的相对强度。

关键在最后那个因子 ∂x/∂θ。它把“图像空间里的修正方向”翻译成“参数空间里的更新方向”。没有它，梯度就停在像素域，无法回传到 3D 表示；有了它，链式法则才完整：2D 先验打分 → 图像梯度 → 渲染雅可比 → 3D 参数梯度。这也是为什么把 SDS 当成 3D 监督是错的——它没有 3D 真值，只有 2D 得分经雅可比回传。

用伪代码思路描述一次更新：

  • 采样一个随机相机位姿，渲染得到 x = R(θ, cam)；
  • 采样噪声 ε 与噪声水平 t，构造 x_t = √ᾱ_t·x + √(1−ᾱ_t)·ε；
  • 把 x_t、y、t 送入 2D 扩散网络，得到 ε_φ；
  • 计算残差 r = w(t)(ε_φ − ε)；
  • 通过可微渲染器反传 r·∂x/∂θ，得到 ∇θ，更新 θ。

注意这条流水线里没有任何一步读取“另一个视角的渲染结果”。每次迭代只看见一个相机、一张图、一个 2D 先验的判断。这就是“逐视角独立”在实现层面的确切含义：独立性不是抽象描述，而是循环体里根本没有跨视角的项。

系统代价也随之而来。可微渲染器要为每次采样保留计算图以回传 ∂x/∂θ，显存与算力开销随渲染分辨率与相机采样数上升；2D 扩散网络前向一次就是一次完整推理，若每步只采一个相机，收敛所需的迭代数会显著增加。失败模式则体现在：当渲染雅可比在某些区域接近退化（比如极薄结构、透明表面），∂x/∂θ 的数值不稳定会把 2D 得分放大成参数空间的噪声更新，表现为几何表面出现高频抖动而非平滑收敛。

一个具体例子：优化一个以文本“一个正面朝向镜头的人”为条件的 3D 头像。正面相机采样时，2D 先验强烈推动“有眼睛、有鼻子、有嘴”的结构；背面相机采样时，同一个先验在“人”这个语义下同样会推动“有五官”的结构，因为它并不知道这是背面。两次更新各自都让当前渲染图更像“一张脸”，但它们在参数空间里争夺同一块几何区域，最终长出正面与背面各一张脸。

三 · 数字底账：50/50 如何落到卷面

评分标准给出的 50% 与 50% 是硬约束，意味着任何一档答案都必须在这两块上分别被检验。把这块底账拆开，可以看到每个判分点对应的可观察证据。

判分点权重卷面证据缺失后果
SDS 梯度公式50%写出 ∇θ L_SDS 完整表达式，含 w(t)、ε_φ(x_t;y,t)、ε、∂x/∂θ漏 ∂x/∂θ 即失去链式回传，公式块大幅失分
2D 得分 + 渲染雅可比公式块内说明 ε_φ − ε 是图像域得分，∂x/∂θ 把它送到参数域只写残差而不解释雅可比，视为符号堆砌
逐视角独立到 Janus50%说明每次迭代只用一个相机、无跨视角项，故各视角各自合理但互相矛盾只说“不一致”不给机制，机制块减半
CFG/随机相机只是缓解机制块内指出二者未在梯度中引入一致性约束，不能根治把 CFG 当解法，机制块判错

这张底账的用法是逐项对照，而不是笼统给分。公式块的 50% 里，写出完整表达式是门槛，解释“2D 得分 + 渲染雅可比”是加分项；只写残差、不写雅可比的答案，即使符号看起来眼熟，也拿不到公式块的主要分值。机制块的 50% 里，“逐视角独立 → Janus”是主干，“CFG/随机相机只是缓解”是边界条件；缺边界条件的答案会被认为没有真正理解 SDS 的局限。

常见错误在底账上各有对应位置。“把 SDS 当成 3D 监督”直接冲击公式块——它意味着答题者不理解 ε_φ 是 2D 预测而非 3D 真值，也意味着 ∂x/∂θ 的存在被忽略。“漏掉 ∂x/∂θ”是公式块最典型的失分点，因为它恰好是连接 2D 与 3D 的那一环。“以为提高 CFG 能解决多面”落在机制块的边界条件上，属于把缓解手段误当根治手段。

一个具体例子：某份答案写出 ∇θ L_SDS = E[w(t)(ε_φ − ε)]，并说“SDS 让不同视角不一致，所以有 Janus，提高 CFG 可以缓解”。按底账，公式块因缺 ∂x/∂θ 失分，机制块因把 CFG 当解法且未展开“独立”而失分，最终落在及格档。若同一份答案补上 ∂x/∂θ 并说明“每次迭代只采一个相机、梯度里没有跨视角项”，公式块补齐，机制块升到良好；再补一句“CFG 只改变单视角打分的锐度，不引入一致性约束”，才触及满分。

四 · 评分演练：三份答卷的逐点对照

演练一：及格档答卷。它写出残差形式但漏掉雅可比，机制部分写“多视角不一致导致两张脸”，并提到随机相机。逐点对照：公式块缺 ∂x/∂θ，失分；机制块有现象无链条，“随机相机”只被提及未被解释为“每次只采一个相机”，边界条件缺失。结论是及格档，且失分位置可精确定位到“雅可比”与“独立性展开”两处。

演练二：良好档答卷。它写出完整公式并逐项标注 w(t)、ε_φ、ε、∂x/∂θ，机制部分说明“每个随机相机独立让 2D 先验打分，视角之间没有一致性约束”。逐点对照：公式块齐全，得分；机制块主干到位，但未说明“目标在视角维度上可分解”，也未点明 CFG 与随机相机只是缓解。结论是良好档，缺口在“分解性表述”与“缓解边界”。

演练三：满分档答卷。它在良好档基础上补两点：其一，把“独立”翻译成优化目标可按视角分解——每次迭代的损失只涉及单个相机的渲染图，梯度期望是对相机采样的期望，没有任何一项耦合两个视角；其二，明确 CFG 提高的是单视角条件打分的对比度，随机相机增加的是视角覆盖，二者都不在梯度里加入跨视角一致性项，因此只能缓解不能根治。逐点对照：公式块齐全且释义到位，机制块主干与边界条件同时满足。结论是满分档。

这三份答卷的差别不在文采，而在“是否把每个判分点落到可检验的表述上”。评分演练的价值在于：它把 50/50 的抽象权重变成可逐条勾选的证据清单，使“及格/良好/满分”不再是印象判断，而是缺口定位。

一个具体例子：演练中常出现的“半对”情形是公式写全但机制只写“Janus 是两张脸”。按判分点，公式块满分，机制块只拿到主干的一半——因为它描述了现象却没有给出“逐视角独立”的因果链，也没有触及缓解边界。这种答案落在良好档下沿，而不是满分，原因正是 50/50 不允许一块满分掩盖另一块的缺口。

五 · 机制与代价的耦合：为什么“两张脸”不是偶然

把机制再推一步：SDS 的期望是对随机相机的期望，而每次期望内的损失只依赖单个相机的渲染图。写成目标函数，它近似于对各视角损失的加权求和，但求和里没有交叉项。也就是说，优化问题在视角维度上是可分解的：每个视角各自把当前渲染图推向“2D 先验认为合理”的区域，而“合理”是由文本条件与噪声水平决定的、与视角无关的判断。于是正面与背面可以同时“合理”，却互相矛盾——这正是 Janus 的结构性来源，而不是随机噪声的偶然产物。

系统代价在这里表现为一种“收敛但错误”的形态：损失可以降得很低，因为每个视角单独看都像那么回事；但几何一致性没有被任何项约束，所以低损失不等于正确 3D。这与“优化不收敛”是两种不同的失败模式：后者表现为损失震荡或发散，前者表现为损失漂亮但物体多面。工程判断上，看到 SDS 损失平稳下降并不能推断几何正确，必须另做多视角一致性检查。

一个具体例子：优化一只动物模型，正面视角推动“有脸”，侧面视角在“动物”语义下推动“有腿与躯干”，背面视角又推动“有尾巴与另一张脸”。三次更新各自都降低了当前视角的 SDS 损失，但参数空间里正面与背面的几何被同时拉扯，最终模型在正面与背面各有一张脸，而损失曲线看起来很正常。这就是“两张脸”作为机制后果而非训练故障的典型表现。

缓解手段的作用边界也由此清晰：CFG 改变的是单视角条件打分的强度，它让“像不像文本”更锐利，但不改变“视角之间无耦合”这一事实；随机相机增加的是视角覆盖，让每个方向都被打分，但每个方向仍然独立打分。二者都能让多面现象不那么突兀，却不能从梯度里消除“无一致性项”这个根因。要根治，需要在梯度中引入跨视角约束（例如多视图先验或显式一致性损失），而这已经超出 SDS 原始形式。

因此，这道题的满分答案最终落在一条工程判断上：SDS 的梯度形式决定了它是一个“逐视角 2D 打分经雅可比回传”的机制，其可分解性既是它能在无 3D 真值下工作的原因，也是它长出两张脸的原因；CFG 与随机相机是缓解，不是根治。把这句话与完整公式一起写清，才同时覆盖 50% 与 50% 两个判分点。
