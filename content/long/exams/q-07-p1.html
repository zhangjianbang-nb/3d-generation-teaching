一 · 三档答案的边界：从“背结论”到“讲链路”

这道题问的是“GET3D 没有任何 3D 监督，怎么学会生成带纹理的显式网格”。同一句话可以答成三个完全不同的层次，而评分标准里“可微渲染链路 60%，无 3D 监督 40%”这条权重，恰好把三档答案的分水岭画出来了：及格档只覆盖了 40% 的那一半，良好档碰到了 60% 的边，满分档把 60% 拆成可验证的环节并说明每一环为什么必需。

及格档的典型形态是：“GET3D 用 2D 图像做对抗训练，不需要 3D 数据，就能生成带纹理的网格。”这句话本身没错，四个判分点里“无 3D 监督”和“显式网格输出”都沾到了，但它把最关键的问题——2D 图像的梯度凭什么能落到 3D 顶点上——当成了不言自明的事。阅卷人看到的是结论的复述，不是机制的交代。它对应的是“知道答案长什么样”，而不是“知道答案为什么成立”。

良好档会补上中间环节：“生成器输出顶点、面、纹理，用可微光栅化渲染成 2D 图，2D 判别器判断真假，梯度经光栅化回传到顶点和纹理。”这就把“可微光栅化”这个判分点明确说出来了，链路的方向（3D→2D→梯度→3D）也交代了。但它仍然是一个单句链条，缺少对“可微”二字的技术拆解：光栅化在哪些量上可微、梯度经过哪些中间量、为什么这条路径不会断。它拿到了 60% 的大部分，却没有证明自己理解这 60%。

满分档要再做三件事：第一，把链路写成有向的、逐环节可检查的计算图，指出每个节点的可微性来源；第二，解释“无 3D 监督”不是“没有约束”，而是把 3D 真值替换成了 2D 判别器提供的分布匹配信号；第三，主动点出这条链路最脆弱的环节和它带来的系统代价。下面几节分别展开这三件事，并在最后用一道评分演练把三档答案落到具体句子上。

二 · 机制解析：可微光栅化是整条链路的铰链

要讲清楚 GET3D，先要把“生成器输出什么”说死。它不是输出隐式场再 marching cubes 提取网格，也不是输出体素或点云，而是直接输出显式网格：一组顶点坐标、由顶点索引构成的三角面片、以及每个顶点（或每个面）上的纹理参数。显式的好处是表示即成品，导出即用；代价是拓扑和顶点数在生成时就固定下来，生成器必须一次性给出一个合法的、面片连接关系正确的网格，而不是先给一个连续场再事后离散。

关键在于，顶点坐标和纹理值都是连续可导的量，但它们本身不在 2D 像素空间里，判别器看不见它们。中间必须有一个把 3D 网格“拍”成 2D 图像的算子，这就是光栅化。普通图形学光栅化是离散操作：判断哪个三角形覆盖哪个像素、做深度测试、取最近的面——这些是分段常值的选择，对顶点坐标的导数几乎处处为零，梯度回传会断掉。可微光栅化要做的，是把这些离散选择替换成对像素颜色的连续加权，使渲染出的图像对顶点位置、对纹理采样都可导。

具体机制可以这样描述：对每个像素，光栅化不是硬性选出覆盖它的那个三角形，而是按三角形对该像素的覆盖权重做加权混合；覆盖权重是顶点投影坐标的连续函数，于是像素颜色对顶点坐标的偏导存在且非零。纹理一侧同理，采样从最近邻换成双线性插值，纹理坐标的微小扰动会连续地改变采样结果。把这两处软化之后，整条链路成为一个可微计算图：

$$\frac{\partial \mathcal{L}}{\partial V}=\frac{\partial \mathcal{L}}{\partial I}\cdot\frac{\partial I}{\partial \pi(V,T)}\cdot\frac{\partial \pi}{\partial V},\qquad \frac{\partial \mathcal{L}}{\partial T}=\frac{\partial \mathcal{L}}{\partial I}\cdot\frac{\partial I}{\partial \pi(V,T)}\cdot\frac{\partial \pi}{\partial T}$$

这里 $V$ 是顶点坐标，$T$ 是纹理参数，$\pi$ 是可微光栅化算子，$I$ 是渲染出的 2D 图像，$\mathcal{L}$ 是判别器回传的对抗损失。这个式子说明的不是“梯度能传”，而是“梯度必须同时经过图像空间和投影几何两条雅可比”。第一项来自 2D 判别器，是图像空间里的梯度；中间项是渲染算子对几何与纹理的敏感度；最后一项才是几何/纹理参数本身的更新方向。任何一环雅可比退化为零，顶点和纹理就收不到有效信号。

由此可以解释为什么“几何/纹理双分支”是判分点而不是装饰。几何分支决定轮廓、凹凸、面片朝向，纹理分支决定表面颜色分布，两者在渲染图像里是乘性耦合的：轮廓错了，纹理再对也会被判假；纹理糊了，几何再准也过不了判别器。GET3D 用两个分支分别参数化这两类量，再在光栅化处汇合，正是为了让上面两个偏导各自有独立的、不被对方掩盖的梯度通路。如果只做一个分支，梯度会在耦合处互相污染，几何误差会被误判成纹理误差，反之亦然。

三 · 数字底账：60% 与 40% 各自对应什么可验证内容

评分标准给出的两个数字不是修辞，而是可以逐条对照答案内容清点的账目。把 60% 拆开，它至少包含四个可验证的子项：其一，明确说出生成器输出的是显式网格而非隐式表示；其二，明确说出渲染环节是可微光栅化，而不是普通渲染或不可微的离散光栅化；其三，明确说出梯度从 2D 判别器经渲染回传到顶点与纹理，方向是 2D→3D 而非 3D→2D；其四，明确说出几何与纹理是两条并行分支并在渲染处汇合。四项里缺“可微”二字，第三项直接归零，因为整条链路的铰链被说成了不可微的离散操作，这与事实相反，也是常见错误里明确列出的“以为光栅化不可微”。

40% 的那一半对应“无 3D 监督”，同样可以拆成可验证的子项：其一，明确声明训练不使用任何 3D 真值（没有 3D 数据集、没有多视角几何监督、没有 CAD 模型）；其二，说明监督信号来自 2D 图像判别器，即对抗训练提供的分布匹配；其三，说明“无 3D 监督”不等于“无约束”，3D 结构是被 2D 渲染一致性间接约束出来的。第三项是区分良好与满分的关键：只说了“不需要 3D 数据”是复述事实，说清了“2D 判别器如何间接约束 3D”才是解释机制。

判分点权重归属可验证的答案内容缺失后果

这张表的作用是让“答了多少”变成可清点的项，而不是凭感觉估分。一个答案如果四个判分点都点到但每个只有一句话，它落在良好档；如果四个点都点到且其中“可微光栅化”与“双分支”给出了机制级解释，它才够满分档。反过来，如果答案只说了“2D 对抗训练、不需要 3D 数据”，它拿到的只是 40% 里的前两项，60% 的链路几乎全空，落在及格档。

四 · 失败模式：链路在哪里断、代价由谁承担

可微光栅化这条链路不是免费的，它的脆弱点也正是系统代价的来源。第一类失败是梯度消失于离散选择。如果实现里保留了硬性深度测试或最近邻纹理采样，覆盖关系对顶点坐标的导数在绝大多数位置为零，只有三角形边界附近有非零梯度。结果是顶点几乎收不到更新，几何分支停滞，而纹理分支因为双线性采样仍能收到梯度，于是训练表现为“纹理越来越像、轮廓始终不对”。这不是调参能解决的问题，是算子不可微导致的结构性失败。

第二类失败是几何与纹理的梯度串扰。两个分支在渲染图像里乘性耦合，若不加约束，判别器对颜色的惩罚会被错误地归因到几何上：模型可能通过扭曲轮廓去迎合纹理分布，而不是修正纹理本身。GET3D 用双分支分离参数化，正是为了给两类误差各自独立的梯度通路；一旦实现中把两支合并成单一输出头，这种串扰就会显现，表现为几何与纹理互相“甩锅”、收敛变慢。

第三类失败是视角覆盖不足导致的 3D 歧义。2D 判别器只看到渲染出的有限视角，同一个 2D 轮廓可以由无穷多个 3D 网格渲染得到，这是典型的反问题欠定。链路本身可微，但监督信号在欠定方向上没有梯度，模型会收敛到一个“在训练视角下像、换视角就崩”的解。这是“无 3D 监督”的固有代价：没有 3D 真值来钉住那些 2D 投影无法区分的自由度。工程上的应对是让渲染视角在训练中分布得足够广，用多视角的 2D 一致性去间接压缩歧义空间，但这仍然不能替代真正的 3D 监督，只是把欠定方向压窄。

具体例子可以这样构造：假设生成器输出的网格在正面视角下轮廓正确、纹理正确，判别器判真；但把同一网格绕竖直轴旋转九十度渲染，侧面轮廓塌陷。由于训练视角里没有侧面，判别器不会对这个塌陷给出惩罚，梯度为零，顶点在侧面方向上不被修正。这就是“2D 监督在未被覆盖的自由度上失效”的最小实例，也是答案里必须点出的系统代价：链路可微保证了“有信号的地方能学”，但不保证“所有自由度都有信号”。

五 · 评分演练：三句话分别落在哪一档

拿三句真实可能出现的答案做演练，看它们各自命中哪些判分点。第一句：“GET3D 不需要 3D 数据，用 2D 图像对抗训练就能生成带纹理的网格。”命中“无 3D 监督”的前两项与“显式网格输出”的关键词，但“可微光栅化”完全缺席，“双分支”缺席，链路方向未交代。按权重，40% 里拿到大部分，60% 里只沾到输出表示一项，落在及格档。它的典型缺陷是把“怎么学会”换成了“学会了什么”。

第二句：“生成器输出顶点、面和纹理，经可微光栅化渲染成 2D 图，2D 判别器判真假，梯度回传到顶点和纹理；几何与纹理是两个分支。”四个判分点全部命中，链路方向正确，“可微”二字出现，“双分支”出现。但它对“可微”只给了标签没给机制，对“双分支为何必需”只给了事实没给理由。它落在良好档的上沿：60% 的内容齐了，但可验证的深度不足，阅卷人无法从这句话判断作者是否理解光栅化在哪些量上可微。

第三句：“生成器直接输出显式网格的顶点、面片与纹理参数；普通光栅化的深度测试与最近邻采样对顶点不可导，因此必须用覆盖权重加权混合与双线性采样把渲染变成对顶点和纹理可导的算子，对抗损失经该算子回传，分别更新几何与纹理两条分支；训练不使用任何 3D 真值，3D 结构由 2D 判别器在多视角渲染一致性中间接约束，未被视角覆盖的自由度上没有梯度。”这句把 60% 拆成了“输出表示—可微性来源—梯度方向—双分支”，把 40% 拆成了“无真值—2D 判别器—间接约束—欠定代价”。每个判分点都有机制级支撑，且主动交代了失败模式。这是满分档的形态。

演练的结论可以落成一条工程判断：这道题的评分不是在数关键词，而是在检查答案是否把“2D 梯度如何落到 3D 参数上”这条因果链说完整。60% 买的是链路的完整性，40% 买的是对“无 3D 监督”这一前提的正确理解；两者相加才是对“怎么学会”的回答。只答前提不答链路，是把问题答成了背景介绍；只答链路不答前提，是把问题答成了渲染管线说明。两者都完整，才构成对 GET3D 机制的交代。
