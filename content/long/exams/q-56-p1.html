一 · 三档答案的分层：从“名词对应”到“机制闭环”

这道题表面上只问三个旋钮各起什么作用、去掉一个会怎样，但它真正考的是能否把“分数蒸馏采样（SDS）在 NeRF 上的工程化落地”讲成一个闭环：随机相机是数据侧的覆盖补丁，CFG 是条件侧的锐化补丁，w(t) 是优化侧的尺度补丁。三档答案的差别不在于是否提到这三个词，而在于是否说清它们各自修补的是 SDS 梯度中的哪一项偏差，以及补丁失效时系统以什么形态崩掉。

及格档答案的典型形态是“一名对一职”：随机相机让每个视角都被 2D 先验约束，避免只优化一个视角；CFG 放大文本条件让结果更贴提示；w(t) 按噪声水平加权，平衡不同尺度的梯度。三句话都对，但每句都停在“作用陈述”，没有交代机制，也没有交代去掉之后的失败形态。这种答案能拿到作用分的下限，却拿不到边界分，因为它无法回答“为什么三者都是补丁而不是解法”。

良好档答案会在每句话后面补一个“去掉会怎样”的因果链：去掉随机相机导致视角覆盖不足、背面崩；去掉 CFG 文本不听话；去掉 w(t) 则高低频梯度失衡，细节糊或噪。这一步把“作用”变成了“可观测的失效模式”，说明答题者理解了三者在训练回路中的位置。但它仍然缺一层：没有指出 SDS 本身的有偏性，因此无法解释为什么调参顺序是“先相机分布，再 CFG，再 w(t)”，也无法解释为什么 CFG 不是越高越好。

满分档答案要在前两层之上再加一层“底账”：把三者放回 SDS 的梯度表达式里，指出每一项对应公式中的哪个因子，并明确三者的联合边界——它们都是工程补丁，不能根治 SDS 的有偏性。评分标准给出的权重是三者作用各 30%、边界 10%，这个比例本身就说明了出题意图：作用陈述是基本盘，边界判断是区分度。换句话说，前 90 分考“知不知道”，最后 10 分考“敢不敢承认这套方法的上限”。

一个具体的对照例子：同样回答“去掉 w(t) 会怎样”，及格档写“细节会变差”，良好档写“高低频梯度失衡，细节糊或噪”，满分档则会进一步指出 w(t) 的加权对象是不同噪声水平下的分数梯度，去掉了等于让高噪声步和低噪声步的梯度以同一权重进入更新，于是低频结构被高频纹理的方差淹没，表现为大面积糊或颗粒噪。三档的文字量差别不大，但信息密度差在“是否把现象回溯到梯度尺度”这一层。

二 · 机制解析：三个补丁各自修补 SDS 的哪一项偏差

SDS 的核心是用一个预训练 2D 扩散模型对可微渲染出的图像打分，并把分数反传回 3D 表示。其梯度可写成对噪声水平 t 的期望形式，本质是“用 2D 先验的分数函数替代 3D 数据的似然梯度”。这个替代是有偏的：2D 先验只在单张图上成立，它不知道多视角一致性，也不知道文本条件与几何的对应关系。三个旋钮正是针对三类偏差分别打的补丁。

$$\nabla_{\theta}\mathcal{L}_{\mathrm{SDS}} \approx \mathbb{E}_{t,\epsilon}\left[ w(t)\,\big(\epsilon_\phi(x_t;y,t)-\epsilon\big)\,\frac{\partial x}{\partial \theta}\right]$$

先看随机相机。SDS 的期望是对 t 和噪声 ε 取的，但实际训练中还有一个隐变量：相机位姿。如果固定一个视角反复优化，2D 先验只会把该视角的图像拉向“看起来像自然图像”，而 NeRF 的几何可以在其他视角完全自由地漂移——这就是视角覆盖不足的根源。随机相机的作用是把相机位姿也纳入期望，使每个视角都被 2D 先验约束，从而间接施加多视角一致性。它的机制不是“增加数据”，而是“扩大期望的支撑集”，让梯度在视角维度上不再退化。去掉它，优化会收敛到一个单视角极优、背面无约束的解，表现为背面崩。

再看 CFG。文本条件 y 在分数网络中通过无分类器引导被放大：实际使用的分数是条件分数与无条件分数的线性外插。放大系数越高，采样越贴提示，但分数的方差也被同步放大。CFG 修补的是“条件信号太弱”的偏差——没有它，文本对几何的约束被图像先验的先验强度压过，结果“不听话”。但 CFG 不是越高越好：放大系数超过某个范围后，分数外插进入训练分布之外，梯度方向变得尖锐，几何出现过度饱和、重复结构或颜色溢出。这正是常见错误“以为 CFG 越高越好”的机制根源。

最后是 w(t)。扩散模型的分数在不同噪声水平上对应不同尺度：高 t 对应低频结构，低 t 对应高频细节。SDS 把不同 t 的梯度直接相加，若不加权，高噪声步的大幅梯度会主导更新，低噪声步的细节信号被淹没；反之若权重偏向低 t，则结构迟迟不收敛。w(t) 的作用是按噪声水平重新分配梯度预算，平衡不同尺度的更新。去掉它等于令 w(t)≡1，高低频梯度失衡，结果要么细节糊（低频主导），要么噪（高频方差未被压制）。把 w(t) 当常数是常见错误，因为它恰恰是唯一一个必须随 t 变化的因子。

系统代价层面，三者都不是免费的。随机相机把每次迭代的渲染成本乘以视角采样数，且相机分布设计不当会引入新的偏差（例如只采前半球，背面依旧崩）；CFG 需要每步两次前向（条件与无条件），显存与算力翻倍；w(t) 需要针对噪声调度做标定，标定错误会直接表现为训练不收敛。失败模式也各有形态：相机分布退化→背面崩；CFG 过高一→过饱和与重复纹理；w(t) 常数化→糊或噪。这三条失效链正好对应判分点中的三项作用与边界。

三 · 数字底账：把“各 30%、边界 10%”拆成可核对的条目

评分标准写得很直白：三者作用各 30%，边界 10%。这不是一个可以含糊过去的比例，它要求答案在结构上必须让三个作用各自独立成句、各自带失效形态，最后单独留出一句承认补丁的上限。下面把这张底账拆成可逐条核对的清单，便于评分演练时定位失分点。

判分点权重合格形态失分形态
随机相机覆盖视角30%说明随机相机把位姿纳入期望，使每个视角被 2D 先验约束；去掉则视角覆盖不足、背面崩只说“多视角训练”，未提期望支撑集；或未给失效形态
CFG 贴文本30%说明 CFG 放大条件分数使结果贴提示；指出过高会过饱和、重复，非越高越好只写“CFG 让文本生效”，把 CFG 当单调增益
w(t) 平衡尺度30%说明 w(t) 按噪声水平分配梯度预算，平衡高低频；去掉则糊或噪把 w(t) 当常数或只写“加权很重要”
三者不能根治偏差10%明确三者是工程补丁，SDS 的有偏性仍在；给出调参顺序：相机分布→CFG→w(t)把三者说成“解法”，或未提调参顺序

这张表的用法不是背，而是自查。一个答案如果三项作用都写了但没有失效形态，最多拿到作用分的一半，因为“去掉会怎样”是题目明文要求，属于作用陈述的一部分而非附加项。反过来，如果失效形态写了但没回溯到机制（例如只说“背面崩”不说“视角期望退化”），则在“机制解析”这一隐含维度上失分。边界 10% 最容易丢：多数答案会把三个旋钮写成“三件套解决方案”，而题目要的是“工程补丁”这一判断。

调参顺序也是底账的一部分：先相机分布，再 CFG，再 w(t)。这个顺序有机制依据——相机分布决定期望的支撑集，支撑集不对，后面两个旋钮调得再好也只是在错误的梯度场上做微调；CFG 决定条件信号的强度，它依赖一个已经覆盖多视角的梯度场才不会把单视角伪影放大；w(t) 是最后标定的尺度预算，它依赖前两者已经稳定，否则标定出的权重只是在补偿前两级的偏差。把顺序写反，等于承认不理解三者在回路中的层级关系。

一个具体例子可以检验底账是否真的被理解：若把相机分布设为只采前半球，CFG 调到很高，w(t) 标定得很精细，结果仍然是背面崩且正面过饱和。这个例子说明三个补丁不能互相替代：相机分布的缺陷不会被 CFG 补偿，CFG 的过冲不会被 w(t) 抹平。评分时看到“三者不能根治偏差”这句话，应当追问它是否伴随这种不可替代性的具体说明，否则 10% 只是口号。

四 · 评分演练：三段答案的逐条打分

演练一：答案写“随机相机让每个视角都被 2D 先验约束，避免只优化一个视角；CFG 放大文本条件让结果更贴提示；w(t) 按噪声水平加权，平衡不同尺度的梯度。去掉随机相机会背面崩，去掉 CFG 文本不听话，去掉 w(t) 细节糊。”逐条对照：三项作用各 30% 全部命中，失效形态也给了，但机制层只到“避免只优化一个视角”，未提期望支撑集；CFG 未提“越高越好是错的”；w(t) 未提“当常数是错的”；边界 10% 完全缺失。总分落在作用分的高位但拿不到边界分，属于典型良好档。

演练二：答案写“三者都是工程补丁，不能根治 SDS 的有偏性。随机相机扩大位姿期望，使每个视角被 2D 先验约束，去掉则视角覆盖不足、背面崩；CFG 放大条件分数，过高会过饱和与重复纹理，去掉则文本不听话；w(t) 按噪声水平分配梯度预算，去掉则高低频失衡、糊或噪。调参顺序是先相机分布，再 CFG，再 w(t)。”这条答案三项作用、失效形态、边界、调参顺序齐全，且每项都带机制关键词（位姿期望、条件分数放大、梯度预算）。按标准可得满分档，唯一可挑的是未给出“不可替代性”的具体例子，但这不属于判分点明文要求。

演练三：答案写“随机相机增加视角多样性；CFG 提高文本一致性；w(t) 是时间权重。去掉任何一个都会变差。”这条答案的问题不在字数，而在信息形态：三项作用都停在同义反复，“时间权重”没有说明加权对象是噪声水平，“变差”不是失效形态。按判分点，三项作用各只能拿到部分分，边界 0 分，且触发常见错误中的“把 w(t) 当常数”的邻近错误——没有说清 w(t) 随 t 变化。这条答案落在及格线下沿。

演练的要点是：评分不是数关键词，而是看每个 30% 是否同时具备“机制+失效形态”两个要件，看 10% 是否具备“补丁判断+调参顺序”两个要件。把这张核对表反过来用，就是答题时的自检清单：每写完一个旋钮，问自己“它的机制词是什么、去掉之后的系统形态是什么”；写完之后再问“我有没有承认它治不了根、有没有给出顺序”。这三问能在不改动知识量的前提下把答案从良好推到满分。

五 · 边界判断的工程含义：补丁的上限与调参的层级

“三者不能根治 SDS 的有偏性”这句话之所以值 10%，是因为它决定了一个工程团队在使用这套方法时的预期管理。SDS 的有偏性来自 2D 先验与 3D 似然之间的结构性错配：2D 分数函数在单图上定义，它无法表达多视角一致性，也无法表达文本与几何的严格对应。随机相机、CFG、w(t) 分别把位姿、条件、尺度三个维度上的错配压低，但没有一个能消除错配本身。因此这套流程的产出应当被理解为“受 2D 先验约束的可行解”，而不是“3D 真值的无偏估计”。

这个判断有直接的工程后果。第一，调参不能追求单指标最优：CFG 调高会让文本对齐指标好看，但几何过饱和会在多视角一致性上扣分；w(t) 偏向低 t 会让细节指标好看，但结构收敛变慢。第二，相机分布是层级最高的旋钮，因为它改变的是期望的支撑集，而不是在既定支撑集上重新分配权重；支撑集错了，后两个旋钮的调参只是在错误梯度场上做局部补偿。第三，任何“再加一个补丁”的方案都要先问它修补的是哪一类偏差，否则补丁之间会互相抵消——例如在相机分布已退化的前提下加大 CFG，只会把单视角伪影放大得更锐利。

一个具体的机制判断可以作为本部分的落点：当随机相机、CFG、w(t) 三者都调到看似合理、结果仍在背面出现结构性崩坏时，问题不在第三个旋钮，而在第一个旋钮的支撑集——此时继续调 CFG 或 w(t) 是把算力投入到一个已经被污染的梯度场。工程上的正确动作是回到相机分布，检查采样是否覆盖了目标视角的完整球面，而不是在条件强度或尺度权重上继续加码。这条判断把“三者不能根治偏差”从一句口号变成了可执行的排查顺序，也正是评分标准把边界单列 10% 的用意。
