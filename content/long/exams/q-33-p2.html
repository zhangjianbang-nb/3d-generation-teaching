一 · 变体题的三条改法：换问法、换对象、换约束

同一道题在考场上被改写，通常不会改变知识点，而是改变“知识点的挂载点”。对 q-33 这类“机制+预处理”复合题，变体设计有三条正交的轴，每条轴对应一种能力被单独拎出来检验。

第一条轴是换问法：把“为什么”改成“如果不这样做会怎样”。例如把原题改成“若 Hunyuan3D 2.1 只输出一张 RGB 贴图而不拆 metallic/roughness，下游引擎会发生什么”。这时评分重心从“陈述三通道定义”迁移到“推导失效链条”，考生必须走完“信息被烘死 → 无法重光照 → 光照变化下反射错误”这条因果链，而不是背出三个名词。第二条轴是换对象：把 PBR 换成法线贴图或 AO，问“为什么法线也需要独立通道”。这检验的是考生是否理解“通道拆分”的通用原则——每个通道承载一种在渲染方程中独立起作用的物理量，而不是记住 PBR 这个词。第三条轴是换约束：加上“在只有单张输入图、无多视角、无已知光照条件”的限制，问 delighting 是否仍必要、误差会集中在哪。这条轴把考生从“复述管线”推到“在资源受限下做工程判断”。

三条轴可以组合，但组合会显著抬高难度。工程上更稳妥的做法是单轴变体用于及格线附近的能力确认，双轴组合用于区分良好与满分。变体的判分点必须与原题保持可映射关系：原题四个判分点（base color/metallic/roughness、PBR 与重光照、delighting 去光照、引擎标准输入）在变体中应各有对应，否则变体就变成了另一道题，失去可比性。

$$\text{变体难度} \approx f(\text{轴数}) \times g(\text{判分点迁移距离})$$

这里的“迁移距离”指变体判分点与原题判分点在因果链上的跳数。跳数为 0（仅换措辞）时考生几乎无感；跳数为 1（换问法）时需一次推导；跳数为 2（换对象且换约束）时需重建整条链路。实践中跳数超过 2 的变体，区分度反而下降，因为多数考生直接放弃，分数分布塌缩到低分段，失去测量意义。

二 · 三个变体题的具体形态与预期作答骨架

变体 A（换问法，跳数 1）：“只给 RGB 贴图，引擎里换一套光照后金属件看起来像塑料，为什么？”预期骨架应包含：RGB 贴图把反照率、金属度、粗糙度混在同一组像素值里，渲染方程无法从中分离出镜面反射项的参数；金属件的镜面反射强度与粗糙度决定的 lobe 宽度都丢失，于是 BRDF 退化为近似漫反射，视觉上呈现塑料感。这里的关键机制是渲染方程中 BRDF 的参数化——金属度决定 F0（菲涅耳反射率）是取材质基色还是取常数，粗糙度决定微表面分布的宽度。只给一张图，等于把这两个自由度压成一个，引擎只能猜。失败模式是考生只答“因为没拆通道”，不落到 BRDF 参数上，判分时按“机制缺失”扣分。

变体 B（换对象，跳数 1）：“法线贴图为什么不能烘进 base color？”预期骨架：法线承载的是逐像素的几何扰动方向，参与光照计算时以切线空间向量形式进入；base color 承载的是反照率，二者在渲染方程中处于不同位置（一个改法线，一个改漫反射系数）。若合并，光照方向与法线的点积无法逐像素求值，高光位置会整体错位。这条变体检验的是“通道拆分原则”的迁移能力，答对的考生应能自己说出“每个通道对应渲染方程中一个独立自变量”。

变体 C（换约束，跳数 2）：“单图输入、未知光照，delighting 的误差会集中在哪，如何缓解？”预期骨架：单图意味着 delighting 是欠定问题——反照率与光照的乘积被观测到，但两个因子不可唯一分解，必须引入先验（如假设光照平滑、反照率局部恒定）。误差集中在两类区域：暗部（信噪比低，去光照后残留下光照梯度）与高光（高光被误判为反照率的一部分，去光照后留下亮斑）。缓解手段是置信度掩码——对高光与暗部像素降低 delighting 结果的权重，让后续金属/粗糙度估计更多依赖邻域统计而非单像素。这条变体最容易暴露“以为 delighting 无损”的错误认知，也是原题常见错误清单里最需要被变体逼出来的那一条。

变体改动轴核心机制考点典型失败模式
A换问法BRDF 参数化：金属度定 F0、粗糙度定 lobe只答“没拆通道”，不落到渲染方程
B换对象通道与渲染方程自变量的对应关系把法线当颜色，混淆两类贴图语义
C换约束欠定分解、先验、置信度掩码断言 delighting 无损，忽略暗部/高光失真

三 · 五个追问：从定义追到代价，从代价追到边界

追问的作用是把“知道结论”压成“能守住结论”。以下五问按认知深度递增排列，前两问确认定义，后三问逼出代价与边界。

  • 追问 1：metallic 通道的取值是二值还是连续？为什么工程上常存成连续值？——考的是对通道语义的理解：物理上金属度接近二值，但贴图边缘、磨损、混合材质需要连续过渡，存成连续值是工程妥协，不是物理必需。
  • 追问 2：roughness 与 glossiness 的关系是什么？为什么管线里通常存 roughness 而不是 glossiness？——考的是参数化约定：二者互为补，存 roughness 是因为它与微表面分布的宽度单调对应，便于线性插值与滤波。
  • 追问 3：delighting 之后，base color 的暗部为什么容易失真？——考的是欠定分解的信噪比问题：暗部观测值小，光照估计的相对误差被放大，反照率估计的方差随之升高。
  • 追问 4：如果 delighting 有误差，为什么还要做，而不是直接把带光照的图喂给引擎？——考的是代价权衡：不做 delighting，光照被烘死进 base color，重光照时出现“双重光照”，错误在引擎里不可撤销；做了 delighting，误差是局部的、可被后续置信度掩码缓解的。两害相权，预处理误差优于管线内不可逆错误。
  • 追问 5：delighting 与金属/粗糙度估计的先后顺序能否交换？——考的是管线依赖：先去光照才能让反照率与光照解耦，金属/粗糙度估计依赖解耦后的反照率统计；交换顺序会让金属度估计被光照梯度污染。这是原题“delighting 是关键预处理”这一判分点的最深一层。

追问 5 的作答质量最能区分档次。及格答案只说“不能交换，因为要先去掉光照”；良好答案能说出“金属度估计依赖反照率的局部统计，光照梯度会污染统计量”；满分答案会补上失败模式——交换后高光区域被误判为高金属度，暗部被误判为低金属度，且这种误判在后续无法通过后处理纠正，因为信息已经混叠。这里的机制是估计量的可辨识性：两个未知因子相乘被观测，必须先固定一个（光照先验）才能估另一个。

$$\hat{a} = \arg\min_{a}\ \| I - a \cdot l \|^2 + \lambda R(a),\quad \text{先验 } R \text{ 决定分解是否可辨识}$$

四 · 扣分点：判分表背后的四个可观测断点

原题评分标准写明三通道占 50%、delighting 占 50%，但考场上的扣分并不按这两个数字平均分布，而是集中在四个可观测断点上。所谓“可观测”，指阅卷人能在答卷文字里定位到具体缺失，而不是凭印象给分。

  • 断点 1：只写“三通道”不写通道名。判分点要求 base color/metallic/roughness 三者具名，缺一即扣该判分点的一半。这是最常见的失分，因为考生把“PBR”当成一个整体名词背下来，没有拆到通道粒度。
  • 断点 2：写了三通道但不连到重光照。PBR 与重光照是独立判分点，考生必须说出“三通道使材质在不同光照下正确反射”，否则三通道部分即使名词齐全也只拿一半。机制上，这是要求考生把通道与渲染方程的自变量对应起来。
  • 断点 3：delighting 只写“去光照”不写“得到反照率”。去光照是动作，反照率是产物，判分点要求二者同时出现，因为“去光照”可以被误解为简单调暗，而“得到反照率”才锚定到物理量。
  • 断点 4：不承认 delighting 有误差。原题解析明确“delighting 本身有误差，暗部/高光处容易失真”，考生若断言无损，直接触发常见错误清单里的“以为 delighting 无损”，该判分点清零。这是唯一一个“答得越肯定越扣分”的断点。

四个断点的分布揭示了这道题的设计意图：前两个断点考“拆得开”，后两个断点考“知道代价”。拆得开是及格线，知道代价是良好线，能把代价与管线顺序、置信度掩码连起来才是满分线。阅卷时若考生在断点 4 上给出“暗部信噪比低导致反照率方差升高”这类具体机制，即使表述简略，也应视为该判分点满分，因为它命中了误差的物理来源而非泛泛而谈。

2未连重光照PBR 与重光照三通道部分减半

五 · 常见错误的成因分类与教学干预

原题列出的三条常见错误——以为 PBR 就是一张彩色贴图、忽略 metallic/roughness、以为 delighting 无损——不是三个孤立的知识漏洞，而是三类认知成因的样本。教学干预若只针对错误本身纠正，考生换个问法仍会重犯；必须针对成因。

第一类成因是“名词替代结构”。考生把 PBR 记成一个标签，标签下面没有结构，于是“PBR 就是彩色贴图”成为自然推论。干预手段是强制画通道表：任何材质题，先列出渲染方程中出现的自变量，再把每个自变量映射到一个通道，映射不上的通道就是冗余或缺失。这个动作把名词还原成结构，考生无法跳过。第二类成因是“默认值幻觉”。考生知道 base color 显眼，就默认 metallic/roughness 是可选修饰，忽略它们在 BRDF 中决定反射形态。干预手段是反事实提问：把 metallic 设为 0 与设为 1，同一张 base color 在引擎里的视觉差异是什么？考生必须说出 F0 的变化，才能意识到这两个通道不是修饰而是主参数。第三类成因是“预处理透明化”。考生把 delighting 当成一个黑盒步骤，默认它不引入失真。干预手段是让考生自己构造失败案例：给一张暗部占主导的输入图，问 delighting 后 base color 的暗部会残留什么。考生一旦能描述残留的光照梯度，就理解了误差的来源。

三类成因对应三种干预，但干预的共同点是“把不可观测的中间量变成可观测的”。通道表让结构可观测，反事实让参数作用可观测，失败案例让误差可观测。教学上，这三步应在讲解原题答案之前完成，而不是之后——先建立可观测性，再给结论，考生才不会把结论当口诀背。

还有一个跨成因的干预点：管线顺序。追问 5 暴露的“delighting 与金属度估计能否交换”之所以难，是因为考生脑中没有管线的数据流图。教学中应要求考生画出“输入图 → delighting → 反照率 → 金属/粗糙度估计 → 三通道贴图 → 引擎”的数据流，并在每条边上标注该步的输入输出物理量。画不出这条链的考生，在变体 C 上必然失分，因为变体 C 的约束条件正好攻击链上最脆弱的一环——单图输入下 delighting 的欠定性。

$$\text{输入} \xrightarrow{\text{delight}} \text{反照率} \xrightarrow{\text{估计}} (\text{metallic},\ \text{roughness}) \xrightarrow{\text{打包}} \text{PBR 三通道}$$

这条链上任何一步的误差都会向下游传播，且不可逆：delighting 的暗部误差会污染反照率统计，进而污染金属度估计，最终在引擎里表现为暗部金属件反射异常。工程判断的落点在这里——不是“要不要做 delighting”，而是“delighting 的误差是否被下游的置信度机制吸收”。若管线没有置信度掩码，单图输入的 delighting 误差会全额传递到最终材质，此时宁可保留部分光照信息并在引擎侧做补偿，也不应盲目追求“完全去光照”。这一判断无法从名词定义推出，只能从数据流与误差传播推出，也正是这道题从及格走向满分的那一段距离。
