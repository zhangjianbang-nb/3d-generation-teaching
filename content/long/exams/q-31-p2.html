一 · 变体一：把“三平面”换成“局部三平面”

第一个变体题通常这样问：“如果 SLAT 只用全局三平面，会失去什么？”这是一道结构辨析题，考的是读者是否真的理解“局部”二字在 SLAT 里承担的功能。全局三平面是三个正交的二维特征平面，任何一个空间点通过三向投影加插值得到特征，参数量与分辨率平方成正比，但空间适应性差：平面上的一个像素要同时服务整条投影线上的所有体素，细节被强行平均。SLAT 的做法是先用稀疏体素回答“哪里有内容”，再在每个被占据的体素上挂一组局部三平面，特征只在该体素的小邻域内有效。于是同一张平面网格可以被不同体素复用，细节分辨率由体素内的局部平面密度决定，而不是由全局平面分辨率决定。

机制上，这相当于把特征场从“全局稠密函数”改成“稀疏分块函数”。伪代码思路是：给定点云或粗体素占据格 O，对每个占据体素 v 取局部坐标 u = (p - c_v)/s_v，在 v 自带的三平面上双线性采样得到 f_v(u)，再按体素索引聚合。全局三平面则没有 c_v 与 s_v 这一层，所有点共享同一组平面。代价立刻显现：局部三平面让每个体素携带自己的小平面，显存与体素数量线性相关，稀疏结构一旦退化（比如占据预测过密），解码开销会成倍上升；反过来，若占据过稀，局部平面之间出现空洞，网格解码会在边界处产生裂缝。

具体例子：一个包含细长栏杆的场景，全局三平面会把栏杆与背后的墙面在投影线上混在一起，栏杆边缘发糊；SLAT 的稀疏体素先把栏杆单独占据出来，局部三平面只编码栏杆附近的特征，边缘得以保留。但若占据预测把栏杆和墙面判成同一体素，局部平面被迫同时表达两种材质，解码出的高斯会在交界处出现半透明拖影。这个失败模式说明“局部”不是免费的：它把表达力换成了对占据质量的强依赖。

评分上，这个变体题的关键得分点是说清“稀疏体素决定支撑域、局部三平面决定带内细节”这一分工，以及全局三平面在参数量与空间适应性之间的取舍。只答“局部更细”而不提占据依赖，属于半对。

二 · 变体二：换掉 rectified flow，3D DiT 还成立吗

第二个变体题问：“如果把 rectified flow 换成 DDPM，SLAT 生成还成立吗？”这考的是生成机制与潜空间结构的耦合关系。3D DiT 在 SLAT 空间做去噪，骨干是 Transformer，输入是展平或序列化的稀疏体素 token 加局部三平面特征。rectified flow 的核心是学习一个从噪声到数据的直线速度场，训练目标可写成对速度的回归：

$$\mathcal{L}(\theta)=\mathbb{E}_{t,x_0,x_1}\left\|v_\theta(x_t,t)-(x_1-x_0)\right\|^2,\quad x_t=(1-t)x_0+t x_1$$

其中 x_1 是 SLAT 潜变量，x_0 是噪声。换成 DDPM 并不改变“在 SLAT 空间去噪”这一层，只是把直线插值换成噪声调度下的马尔可夫链，采样步数与调度更复杂，但潜空间语义不变。所以答案是：3D DiT 作为去噪骨干仍然成立，SLAT 作为生成目标也仍然成立，变的是采样器与训练目标。

真正的系统代价在于 token 布局。SLAT 是稀疏体素加局部平面，序列长度随占据体素数变化，rectified flow 的少步采样让推理时的 Transformer 前向次数少，序列长度波动的影响被压住；DDPM 需要更多步，每一步都要跑一次 3D DiT，稀疏序列的长度方差直接放大成延迟方差。失败模式是：在占据密集的室内场景，序列变长，DDPM 的多步采样让显存峰值与延迟同时抬升，而 rectified flow 的少步特性恰好掩盖这个问题。

具体例子：同一套 SLAT 编码器，配 rectified flow 时用少量步数出高斯，交互式预览可用；换 DDPM 后步数上升，预览延迟明显变长，但若只用于离线网格导出，质量差异不一定被感知。这说明变体题的判分不应停留在“能不能换”，而要落到“换完之后哪一类下游解码受害”。答题时若只写“DDPM 也能生成”，不给序列长度与步数的耦合分析，扣分点就在这里。

三 · 变体三：一套潜变量解三种表示，误差从哪来

第三个变体题是反向追问：“既然一套 SLAT 能解成高斯、网格和辐射场，为什么三者质量不能画等号？”这直接对应参考答案里“解码器各自有误差”的代价。三种解码器对 SLAT 的读取方式不同：高斯解码器把局部三平面特征映射为一组带位置、尺度、旋转、不透明度和颜色的高斯基元，追求实时渲染，误差表现为基元覆盖不足或过覆盖；网格解码器走符号距离或占据场路线，需要等值面提取，误差表现为薄结构丢失与拓扑错误；辐射场解码器用体积渲染，误差表现为高频细节被平滑。

机制上，可以把解码写成 D_k(SLAT) → R_k，k 取高斯、网格、辐射场。三者共享同一个 SLAT，但各自的归纳偏置不同：高斯是显式基元集合，网格是分段线性等值面，辐射场是连续密度场。共享潜变量保证了语义一致，却不保证误差同分布。系统代价是：为了兼顾三者，SLAT 的分辨率必须取折中，分辨率偏高则高斯基元数量爆炸、网格提取变慢，偏低则辐射场的高频先丢。失败模式是“一套潜变量、三种验收标准”——用高斯预览看着没问题，导出网格后发现薄壁穿孔，再用辐射场渲染发现表面发软，三者互相指责，实际是 SLAT 分辨率与解码器归纳偏置的错配。

具体例子：一个带镂空花纹的装饰件，高斯解码能靠半透明基元“看起来”有花纹，网格解码在花纹处因等值面分辨率不足而粘连，辐射场解码则把花纹边缘渲染成模糊过渡。三者都从同一 SLAT 出发，误差却落在不同环节。答题时能指出“共享潜变量降低的是模型数量，不是解码误差”，并给出至少一个具体几何例子，才算抓住这个变体的要害。

变体考什么核心机制典型失败模式
全局 vs 局部三平面结构分工稀疏体素定支撑域，局部平面编细节占据过密/过稀导致开销或裂缝
rectified flow → DDPM生成机制耦合潜空间不变，采样器与步数变稀疏序列长度方差放大延迟

四 · 五个追问：从定义到工程取舍

追问一：“SLAT 里的‘结构化’具体指什么？”应答成两层：稀疏体素提供离散的占据结构，局部三平面提供连续的带内特征，两者拼成一个既有离散支撑又有连续表达的潜变量。只答“稀疏体素”是漏掉一半。

追问二：“为什么 3D DiT 要在 SLAT 空间去噪，而不是直接在体素或三平面空间？”因为 SLAT 已经把“哪里有内容”和“长什么样”拆开，序列长度由占据决定而非稠密网格决定，Transformer 的注意力开销随有效 token 数走；直接在稠密体素上去噪会把空区域也拖进计算。代价是 token 化与反 token 化的实现复杂度上升。

追问三：“rectified flow 在这里解决了什么问题？”它把多步扩散压成少步直线传输，让 3D DiT 的前向次数与稀疏序列的长度波动解耦，推理延迟更可控。追问若继续问“那质量会不会降”，应答成：少步采样对高频细节有影响，但 SLAT 的局部平面已经把细节编码进潜变量，解码器承担了剩余的表达压力。

追问四：“一套潜变量多解码，工程上怎么选？”按下游需求选：实时预览走高斯，引擎资产走网格，离线高质量渲染走辐射场。关键是承认三者误差不同，验收标准要分开定，不能用一个指标通吃。

追问五：“SLAT 分辨率限制细节，怎么缓解？”两条路：提高局部平面密度，或在下游解码器里加超分/细化模块。前者增加显存与 token 数，后者把误差从潜变量转移到解码器，属于工程取舍而非免费提升。

这五个追问的共同扣分点是“只给结论不给机制”。例如追问二只答“因为稀疏更省”，不说明 token 数与注意力开销的关系，就会被判为记忆型回答而非理解型回答。

五 · 扣分点与常见错误：从“普通体素”到“解码等价”

第一类扣分点是结构误判：把 SLAT 当成普通稠密体素。普通体素是规则网格上的稠密占据加特征，SLAT 是稀疏体素加每体素局部三平面，前者没有“局部平面”这一层，后者没有“全网格稠密”这一约束。答成普通体素，等于把 50% 的结构分丢掉一半以上。

第二类扣分点是忽略稀疏结构。有人能背出“稀疏体素 + 三平面”，却在解释生成时把序列当成固定长度，忽略占据预测决定 token 数这一环。这会导致对推理开销、显存峰值、失败模式的分析全部失准。

第三类扣分点是以为所有解码器质量相同。参考答案明确写了“解码器各自有误差”，若答题时把高斯、网格、辐射场说成“同一潜变量的三种无损导出”，就与事实相反。正确表述是：共享潜变量保证语义一致，不保证误差一致。

第四类扣分点是生成机制与潜空间混淆。把“3D DiT + rectified flow”说成 SLAT 的定义的一部分，是把生成器与表示混为一谈。SLAT 是表示，3D DiT 与 rectified flow 是在该表示上做生成的机制，两者可分可换，变体二正是考这一点。

常见错误还有一类是“多解码等于多模态输入”。SLAT 的多解码是同一潜变量到不同输出表示的映射，不是接受多种输入模态。把“一套潜变量适配多种下游表示”误读成“多模态融合”，属于概念滑动，扣分点在多解码那 50% 里。

教学上，建议用一张两列表把“表示层”和“生成层”分开：左列写稀疏体素、局部三平面、分辨率限制；右列写 3D DiT、rectified flow、少步采样。再单列“解码层”写高斯、网格、辐射场及各自误差。三列一旦分开，变体题与追问的答案位置就清楚了。

六 · 教学建议：用失败模式反推机制

有效的讲法不是先给定义再给例子，而是先给失败模式再反推机制。比如先展示“全局三平面把栏杆和墙面混在一起”的现象，让学生判断缺了哪一层结构，再引出稀疏体素定支撑域、局部平面编细节的分工。这样“局部”二字就不是形容词，而是可被失败模式验证的机制。

第二个练法是让学生自己写解码误差表：给定同一 SLAT，分别列出高斯、网格、辐射场在薄壁、镂空、透明材质三类几何上的典型误差，再倒推 SLAT 分辨率应该取在哪一档。这个练习把“一套潜变量多解码”的代价从口号变成可操作的取舍。

第三个练法是变体对照：把 rectified flow 换成 DDPM，只改采样器不改潜空间，让学生预测延迟与显存的变化方向，并说明稀疏序列长度方差为什么会被放大。预测错了不要紧，关键是能否把“序列长度 × 步数 × Transformer 前向”这条链路讲清楚。

评分演练时，把 50% 结构分与 50% 多解码分拆成可勾选项：结构分看是否写出稀疏体素与局部三平面两层；多解码分看是否写出三种表示与各自误差。常见错误的扣分点逐条对应到这两块，避免“答得多但没答到点上”的虚高。最后落到一个工程判断：SLAT 的价值不在“一个潜变量”这个说法本身，而在于它把支撑域与细节表达解耦，使同一潜变量可以被不同归纳偏置的解码器读取；接受这一点，就必须同时接受解码误差不同、分辨率折中、占据质量敏感这三项代价，任何一项被忽略，变体题与追问都会露出破绽。
