一 · 变体一：把“一句话”换成“一段话”——自回归粒度与序列长度

第一个变体题通常这样问：如果把 MeshGPT 的面片序列从“一句话”扩展成“一段话”，即允许更长的 token 序列、更细的面片遍历顺序，系统会发生什么变化？这不是文字游戏，而是直接触碰自回归生成的核心约束。参考答案里“网格就变成 token 序列，decoder-only Transformer 自回归预测下一个 token”这句话，隐含了一个前提：序列长度必须落在 Transformer 的上下文窗口内，且每个 token 的预测都要以之前全部 token 为条件。

具体机制上，面片序列的长度等于面片数乘以每个面片被编码成的 token 数。若每个三角面片经图卷积编码后被 VQ 映射为单个 token，则序列长度就是面片数；若采用更细的分解（例如把面片的顶点或边也纳入 token 化），序列会成倍增长。自回归解码的代价随序列长度呈二次增长，因为注意力矩阵是 L×L。用公式表示，单层自注意力的计算量近似为：

$$\text{cost} \approx L^2 \cdot d$$

其中 L 是序列长度，d 是隐藏维度。面片数从几百增加到几千，L 随之增加，显存与延迟都会迅速膨胀。这就是该变体的系统代价：更长的“一段话”并不天然更好，它把生成问题从“短序列分类式预测”推向“长序列建模”，而后者在训练数据有限时更容易过拟合。

失败模式也很具体：当序列变长，早期 token 的误差会通过自回归链条放大。第一个面片预测偏了，后续面片都在错误条件下生成，最终拓扑出现裂缝或自交。举例来说，一个由数百面片组成的椅子，若前几个面片的朝向 token 选错，椅腿可能从椅面边缘“长”出去，而不是从底部延伸。追问时要说清：变体一考的是对序列长度与注意力代价的敏感度，而不是简单地说“更长更强”。

二 · 变体二：换掉 VQ 词表——词表大小与表达力的权衡

第二个变体题问：如果把 VQ 词表从较小规模换成较大规模，或者反过来，MeshGPT 的行为如何改变？参考答案已经给出定性判断：“词表大小决定能表达的面片类型”。这句话需要展开成机制。VQ 的作用是把图卷积输出的连续向量映射到有限词表里的一个 token，映射方式是最近邻查找：

$$k = \arg\min_{j \in \{1,\dots,K\}} \| z - e_j \|_2$$

其中 z 是面片编码向量，e_j 是词表中的第 j 个码字，K 是词表大小。词表越大，码字越密，连续几何被离散化时的量化误差越小，能区分的面片类型越多；词表越小，码字稀疏，许多不同面片被压到同一个 token，表达力下降，但序列的“词汇”更紧凑，Transformer 的预测分布更集中，训练更稳定。

系统代价出现在两个方向。词表过大时，每个 token 的嵌入矩阵和输出 softmax 都变宽，参数量和显存上升；更重要的是，大词表中许多码字在训练数据里出现次数很少，自回归模型难以学到它们的转移规律，生成时容易产生罕见 token 导致的拓扑异常。词表过小时，量化误差累积，面片朝向和连接关系被粗化，生成结果出现“块状”或重复模式。失败模式可以举一个具体例子：若词表小到无法区分“水平面片”和“垂直面片”，椅子的座面和靠背会被编码成同一类 token，自回归模型失去区分能力，生成出的形状可能把靠背摊平。

该变体的扣分点在于只答“词表越大越好”或“词表越小越快”，而没有指出这是表达力与可学习性之间的权衡。正确回答应同时给出量化误差公式、softmax 变宽的代价，以及罕见码字带来的转移学习困难。

三 · 变体三：跨分布生成——拓扑像艺术家，但只擅长分布内

第三个变体题把参考答案最后一句拿出来做压力测试：“MeshGPT 生成的面数少、拓扑像艺术家做的，但只擅长训练分布内的形状。”题目会问：如果给一个明显偏离训练分布的类别，例如训练集里只有椅子、桌子、飞机，现在要求生成一盏吊灯，系统会怎样？

机制上，VQ 词表是在训练分布上通过聚类或码本学习得到的，码字覆盖的是训练面片的几何类型。decoder-only Transformer 学的是这些 token 在序列中的转移概率。面对分布外形状，编码器仍会把面片压到最近的码字，但该码字可能并不代表吊灯所需的细长悬挂结构；自回归模型也没有学过相应的 token 转移模式。结果是生成过程要么退化成训练类别的混合体，要么产生面片数极少、拓扑断裂的碎片。

系统代价是“分布外检测”缺失：MeshGPT 没有显式的置信度输出，token 级 softmax 概率高并不等于几何合理，因为模型可以对一个错误码字给出高概率。失败模式举例：要求生成吊灯时，模型可能输出一个带四条腿的矮桌状结构，因为“四条腿支撑一个面”的 token 序列在椅子数据中出现频率最高。追问时应指出，这不是词表大小的问题，而是词表与转移矩阵都没有覆盖目标分布。

该变体的扣分点是把“只擅长分布内”说成“泛化能力差”就结束，而没有落到 VQ 码字覆盖与自回归转移学习两个具体环节。满分回答要能说明：分布外形状首先在量化阶段被错误映射，然后在自回归阶段被错误转移，两处失败叠加。

四 · 五个追问：从链路到边界的逐层加压

追问一：图卷积编码面片时，邻居信息如何进入向量？回答要落到“每个三角面片及其邻居”这一事实：图卷积在面片邻接图上聚合邻居特征，使单个面片的编码不只包含自身顶点坐标，还包含与相邻面片的连接关系。若去掉邻居聚合，面片编码退化为局部几何描述，序列中相邻 token 的拓扑一致性下降。

追问二：VQ 的码字是学出来的还是手工定的？参考答案只说“有限词表”，没有给训练细节。稳妥回答是：词表通过量化目标学习得到，码字代表训练面片的典型几何模式；具体算法不在给定事实内，不应编造。扣分点是虚构码本大小或训练轮数。

追问三：decoder-only 自回归与 encoder-decoder 的区别在这里意味着什么？decoder-only 意味着每个 token 只以左侧已生成 token 为条件，没有独立的编码输入；因此面片序列的顺序（面片遍历）直接决定条件信息的质量。参考答案已指出“序列顺序影响生成质量”，追问要把这一点与 decoder-only 的因果掩码联系起来。

追问四：为什么不能直接回归顶点？这是常见错误之一。直接回归顶点把网格当成连续坐标集合，输出维度随顶点数变化，且顶点顺序不确定；VQ 加 token 序列把变长几何转成离散序列，才使语言模型式生成可行。回答要强调“离散化使生成可行”这一因果链，而不是只说“token 更好”。

追问五：面数少是优点还是缺点？参考答案说“面数少、拓扑像艺术家做的”，这是定性描述。追问要区分：面数少意味着序列短、生成稳定、拓扑干净，但也意味着细节表达能力受限；它不是单纯的优点，而是与训练分布和词表表达力绑定的特征。

五个追问的共同扣分点是答成名词解释，没有把每个追问挂回“图卷积—VQ—自回归—面片序列”这条三步链路上。评分标准里三步链路占 60%，追问若脱离链路，即使单点正确也拿不到链路分。

五 · 扣分点与常见错误：从“以为”到“忽略”

给定事实列出三个常见错误：以为直接回归顶点；忽略 VQ 词表大小；以为任意网格都能 token 化。这三条正好对应三个扣分层次。

错误错误机制扣分落点
直接回归顶点把网格当连续坐标集合，输出维度随顶点数变化，顶点顺序无定义三步链路缺失，VQ 作用无法体现
忽略 VQ 词表大小不讨论量化误差与表达力权衡，只把 VQ 当黑盒VQ 作用 40% 中的核心部分失分
以为任意网格都能 token 化忽视训练分布与码字覆盖，把 token 化当成无条件操作边界判断失分，变体三直接命中

还有一个隐性扣分点：把“面片序列”说成“顶点序列”。参考答案明确写的是面片及其邻居被编码，序列单位是面片 token，不是顶点坐标。若回答写成顶点序列，图卷积编码面片这一环就断了。另一个隐性扣分点是只答“VQ 把连续变离散”而不说“映射到有限词表里的一个 token”，缺少“有限”和“一个 token”两个限定，VQ 作用答得过于笼统。

评分演练中，三步链路 60% 要求图卷积编码面片、VQ 离散词表、decoder-only 自回归三环齐全；VQ 作用 40% 要求说出离散化使语言模型式生成可行，并能联系词表大小与表达力。常见错误若出现，直接从对应环节扣，不因其他环节正确而抵消。

六 · 教学建议：用一条链路串起变体与追问

教学上不要把变体题当成额外知识点，而应把它们挂回同一条链路：图卷积把面片及邻居变成向量，VQ 把向量压进有限词表，decoder-only Transformer 在 token 序列上自回归。三个变体分别加压在这条链路的不同位置：变体一压序列长度与注意力代价，变体二压词表大小与量化误差，变体三压码字覆盖与转移学习。

具体做法是让学生对每个变体写出“机制—公式—代价—例子”四行。例如变体二要求写出最近邻量化公式、softmax 变宽的代价、罕见码字导致拓扑异常的例子。追问训练则要求每个回答必须出现链路中的至少一个环节名称，否则视为名词解释。常见错误用对照表让学生自己填“错误机制”和“扣分落点”，比直接给结论更能暴露理解缺口。

工程判断上，应把“只擅长训练分布内的形状”作为设计约束而非缺陷描述：如果目标形状不在训练分布内，先检查 VQ 码字是否覆盖该类面片，再检查自回归转移是否学到相应序列模式；两处任一不满足，生成结果都不可信。教学最后落在这条判断上，而不是落在“MeshGPT 很强”或“MeshGPT 有限”的空泛评价上。
