一 · 三档答案的分层结构：从“能写出来”到“能讲清楚”

同一道题，及格、良好、满分三档答案的差别不在字数，而在信息链条的完整度。及格档只完成“公式默写”：写出 C=Σ_i T_i (1−exp(−σ_i δ_i)) c_i 与 T_i=exp(−Σ_{j<i} σ_j δ_j)，并说明 T 是透射率。这已经覆盖判分点的一半，因为公式占 50%、T 含义占 50%。但及格档往往把 T 与“透明度”混为一谈，或者漏掉 δ 的量纲，导致公式虽然形式正确、物理语义却是错的。

良好档在公式之外补上两条关键解释：其一，T_i 是从相机出发到第 i 个采样点之前、光线未被任何粒子吸收或散射出视线的概率，取值在 0 到 1 之间，T 越小表示前方遮挡越强；其二，alpha_i=1−exp(−σ_i δ_i) 是第 i 段采样区间内发生一次有效遮蔽事件的概率，它与 T_i 相乘得到该段对最终像素的贡献权重。良好档还会指出合成顺序必须从前往后，因为 T_i 依赖所有 j<i 的累计光学厚度。

满分档再往前一步：把离散公式还原为连续积分 C=∫T(t)σ(t)c(t)dt，说明离散化是把积分区间切成 δ 宽度的片段、用常密度近似每段、并用指数衰减精确积分段内透射率的结果。满分档能解释为什么用 1−exp(−σδ) 而不是 σδ：后者是一阶近似，在 σδ 较大时会超过 1，破坏概率语义；指数形式对任意非负 σδ 都落在 [0,1)，且与 Beer–Lambert 定律一致。满分档还会主动指出 σ 是密度而非颜色、c 才是颜色，以及 δ 进入指数而不是被省略。

三档的共同骨架是“公式—语义—离散化动机”三层。评分演练时应按判分点逐项打钩：公式层看四项（离散合成式、T 定义、alpha 形式、合成方向），语义层看 T 是否被正确解释为“未被遮挡概率”而非“透明度”。任何一档只要把 T 说成透明度，语义层即失分，因为透明度通常指 1−alpha 或表面透过率，与沿路径累计的指数衰减不是同一个量。

二 · 机制解析：T 为什么是指数、alpha 为什么是 1−exp

体渲染的物理起点是辐射传输：光线沿方向穿过介质，每前进 dt，强度按 exp(−σ(t)dt) 衰减，同时介质自身在 dt 内以 σ(t)c(t)dt 的份额向外发射（或散射）亮度。把这两件事合起来，连续形式就是 C=∫_0^∞ T(t)σ(t)c(t)dt，其中 T(t)=exp(−∫_0^t σ(s)ds)。T(t) 的物理含义是：从相机到 t 处，光子没有与介质发生任何消光事件的概率。它不是“透明度”，而是沿路径累积的生存概率；t 越大，穿过的介质越多，T 单调不增。

$$T(t)=\exp\left(-\int_0^t \sigma(s)\,ds\right),\qquad C=\int_0^\infty T(t)\,\sigma(t)\,c(t)\,dt$$

离散化时把 [0,∞) 截断为 N 段，每段长度 δ_i，假设段内 σ 与 c 为常数。段内透射率从 exp(−σ_i δ_i) 精确算出，于是第 i 段对像素的贡献是“到达该段起点仍存活”乘以“在该段内被遮蔽”乘以“该段颜色”：T_i·(1−exp(−σ_i δ_i))·c_i。这里 1−exp(−σ_i δ_i) 正是段内至少发生一次消光事件的概率，与 T_i 的“到达概率”相乘，构成一个完整的概率链。从前往后累加时，T_{i+1}=T_i·exp(−σ_i δ_i)，这就是 T_i=exp(−Σ_{j<i}σ_jδ_j) 的递推来源。

一个具体例子：两段采样，σ_1δ_1=0.5、σ_2δ_2=1.0，颜色分别为 c_1、c_2。则 T_1=1，alpha_1=1−e^{−0.5}≈0.393；T_2=e^{−0.5}≈0.607，alpha_2=1−e^{−1}≈0.632。最终 C≈0.393c_1+0.607×0.632×c_2≈0.393c_1+0.384c_2。可以看到第二段的权重被前方的 0.607 存活率压低，这正是“前面越挡光、后面贡献越小”的数值体现。若把 T 误当透明度写成 (1−T_i)，第一段权重会变成 0，整条链断裂。

系统代价方面，从前往后合成需要维护一个标量 T 并逐段更新，时间复杂度 O(N)，但每个采样点都要做一次 exp 运算；在 GPU 上 exp 属于特殊函数单元，吞吐低于乘加。失败模式之一是数值下溢：当累计光学厚度很大时 T 趋近 0，后续段贡献被浮点截断，表现为远处物体突然消失而非平滑淡出。工程上常用“提前终止”策略：当 T 小于阈值时停止采样，节省算力但可能截断低贡献尾部；另一种失败是 δ 取常数而场景深度跨度极大，导致近处欠采样、远处过采样，alpha 估计偏差直接反映为条带。

三 · 数字底账：判分点与常见错误的对应账本

题目给出的评分标准是公式 50%、T 含义 50%，判分点拆成四项：离散合成公式、T 为透射率、alpha=1−exp(−σδ)、从前往后合成。把这四项与 50/50 的权重对齐，可以得到一张可执行的底账：公式层的 50% 覆盖前三项中的公式形态与 alpha 形式，语义层的 50% 覆盖 T 的解释与合成方向所隐含的因果顺序。常见错误有三类：把 T 当成透明度、漏掉 δ、把 σ 当成颜色。这三类错误分别击中不同的判分点。

判分点权重归属命中错误后果
离散合成公式公式 50%漏 δ、σ/c 混淆量纲不成立，权重不可解释
T 为透射率语义 50%把 T 当透明度概率语义反转，前后权重错位
alpha=1−exp(−σδ)公式 50%写成 σδ 或 1−σδ越界或非单调，破坏概率链
从前往后合成语义 50%从后往前累加T 依赖前序，顺序反了递推失效

逐项核对时，“漏掉 δ”是最隐蔽的失分：写成 exp(−σ_i) 或 1−exp(−σ_i) 在形式上仍像指数，但 δ 是采样间隔，决定了离散段的光学厚度；没有 δ，σ 的量纲（单位长度倒数）无法与无量纲的指数自变量对齐，公式在物理上不成立。第二个隐蔽错误是把 σ 当成颜色：σ 是密度，决定遮蔽概率；c 才是颜色，决定该段发出什么亮度。若把 σ 塞进 c 的位置，合成式变成 T·(1−exp(−cδ))·σ，颜色与密度互换，渲染出的图像会把“浓”误当成“亮”。

“把 T 当成透明度”则直接反转语义：透明度通常随遮挡增加而下降，但这里的 T 是“未被遮挡概率”，同样随遮挡增加而下降，数值方向一致却含义不同——透明度描述表面透过率，T 描述沿路径的生存概率，前者是局部材质属性，后者是全局累积量。评分时若考生写“T 越大越透明”，字面上似乎没错，但把 T 与 alpha 的互补关系搞混，语义层应扣分。数字底账的意义在于：每个错误都能定位到具体判分点，而不是笼统地“答得不好”。

四 · 评分演练：三段答案的逐项打分

演练一（及格档）：答案写出 C=Σ T_i(1−exp(−σ_iδ_i))c_i、T_i=exp(−Σσ_jδ_j)，并注“T 是透射率，σ 是密度，δ 是间隔，c 是颜色”。逐项核对：离散公式完整，含 δ 与 alpha 形式，公式层得满；T 被正确称为透射率但未展开“未被遮挡概率”的语义，语义层给一半。总分落在及格偏上。失分点不在公式，而在语义解释的深度——判分点要求“说明 T 的物理含义”，仅给名词不算说明。

演练二（良好档）：在及格档基础上补一句“T_i 表示从相机到第 i 段之前光线未被遮挡的概率，越小说明前面越挡光”，并写明“从前往后合成，每段用 T 乘以 alpha”。逐项核对：公式四项齐全，T 的语义到位，合成方向明确，公式层与语义层均得满。唯一可挑的是没有解释 alpha 为什么用指数形式而非线性近似，但这不属于题目判分点，因此不扣分。良好档的特征是“判分点全覆盖、无常见错误”，但不主动展开离散化动机。

演练三（满分档）：在良好档之上加入连续形式 C=∫Tσc dt、T 的积分定义、以及“1−exp(−σδ) 是段内遮蔽概率、对任意 σδ≥0 落在 [0,1)，避免线性近似越界”的论证，并主动指出“σ 不是颜色、漏 δ 会使量纲不成立”。逐项核对：四项判分点全中，且每个常见错误都被预先排除，语义层不仅给定义还给因果链。满分档与良好档的差距不在公式，而在“为什么这样离散”的解释力与对错误模式的免疫力。

演练的工程价值在于可复现：把判分点做成检查表，任何一份答案都能在几分钟内定位失分项。公式层看四个符号是否齐全（Σ、T、1−exp、δ、c），语义层看 T 是否被解释为概率、合成方向是否从前往后。若一份答案公式正确但 T 被写成“透明度”，按 50/50 权重，语义层失分，总分不可能达到满分；反之若 T 解释到位但 alpha 写成 σδ，公式层失分。两层的独立性使得评分不会因为一处错误而全盘否定。

五 · 从评分反推实现：公式里的每个符号都是一次工程决策

把评分表映射回渲染器实现，会发现每个判分点都对应一个可配置项。δ 对应采样步长策略：固定步长实现简单但在深度跨度大时浪费算力，自适应步长按密度或深度调整 δ，代价是需要额外的空间数据结构或深度预pass。T 的递推对应一个标量累加器，从前往后更新 T←T·exp(−σδ)，这个乘法的顺序不可交换，因为 exp 的参数依赖前序累计；若并行化按段独立计算 T_i，则每段都要重新求前缀和，复杂度从 O(N) 升到 O(N log N) 或需要扫描算法。

alpha=1−exp(−σδ) 对应传递函数的选择：线性近似 alpha≈σδ 在 σδ 小时误差可忽略，且省掉一次 exp，但 σδ 接近或超过 1 时会越界，必须 clamp，clamp 又引入非线性，破坏能量守恒的直觉。指数形式没有越界问题，代价是每段一次 exp。工程判断是：在采样密度足够高、σδ 普遍较小的场景用线性近似换吞吐；在密度对比强烈、段厚不均的场景用指数形式保正确性。这个取舍不影响判分点，但影响渲染结果的条带与尾部淡出。

σ 与 c 的分离对应数据布局：密度场与颜色场可以共享网格，也可以分离存储。共享网格省内存但耦合了遮蔽与外观，分离存储允许密度用低分辨率、颜色用高分辨率，代价是两次采样与插值。失败模式是插值顺序错误：先插值 σ 再算 exp，与先算 exp 再插值不等价，前者在网格边界产生块状伪影。正确做法是在采样点处插值 σ 与 c，再逐段计算 alpha 与 T。另一个失败是 δ 与深度非线性映射不匹配，导致近处 δ 过小、远处 δ 过大，T 的指数衰减在远处被过度离散，表现为雾状渐变的阶梯。

最后落到一个具体机制：从前往后合成的递推式 T_{i+1}=T_i·exp(−σ_iδ_i) 与贡献累加 C←C+T_i·(1−exp(−σ_iδ_i))·c_i 是同一循环里的两次更新，T 的更新必须先于下一段的贡献计算，且当前段的贡献用的是更新前的 T_i。这个顺序在代码里表现为“先取 T 算贡献，再乘衰减更新 T”，颠倒则当前段被自己的遮蔽概率错误压低。评分演练中“从前往后合成”这一判分点，本质上就是在检查考生是否理解这个循环不变式：T 是进入当前段时的生存概率，而不是离开时的。
