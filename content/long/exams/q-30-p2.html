一 · 变体一：把“为什么”换成“如果”

第一个变体题不问动机，而问反事实：“如果去掉 3D VAE，直接在体素或三平面上跑扩散，会发生什么？”这道题考的是对两阶段分工的因果理解，而不是背诵参考答案。合格的回答必须指出：扩散的每一步都要对整个数据张量做一次网络前向，采样又是几十步的迭代，代价随空间分辨率的立方（体素）或平方（三平面）增长；把扩散搬到原始高分辨率表示上，等于把最贵的迭代过程放在最大的张量上。

机制上可以用一个粗略的代价比说明问题。设原始 3D 表示的空间元素数为 N，VAE 的下采样倍率为 r，则潜变量元素数为 N/r³（体素）或按面积缩减（三平面）。扩散采样需要 T 步，每步一次网络前向，则两方案的相对计算量近似为：

$$\frac{C_{\text{pixel}}}{C_{\text{latent}}} \approx \frac{T \cdot f(N)}{T \cdot f(N/r^3)} \approx r^3 \cdot \frac{\text{cost per token at } N}{\text{cost per token at } N/r^3}$$

若网络对 token 数的依赖近似线性（Transformer 的注意力部分是超线性的，这里只取主导项），比值大致落在 r³ 量级。这就是“扩散太贵”的定量来源，也是 VAE 存在的第一性理由。

系统代价与失败模式：去掉 VAE 后，显存占用会先崩，而不是算力先崩。扩散训练需要保存每步的激活用于反向传播，高分辨率 3D 张量上的激活量远超单卡容量，工程上只能靠梯度检查点、分块计算或降低 batch 硬撑，训练吞吐随之塌陷。具体例子：一个以三平面为表示的系统，若把平面分辨率从潜空间的尺寸直接放大到原始尺寸，单次前向的激活规模按面积增长，注意力的键值缓存也按 token 数增长，采样时的自回归式迭代会把这一开销重复几十次，最终表现为“能训但采不动”。

另一个失败模式是优化难度：高分辨率扩散的噪声调度要在极细的空间尺度上定义，早期步的噪声几乎淹没结构信号，模型倾向于先学低频再学高频，收敛曲线更抖。VAE 把高频细节剥离到解码器，扩散只需建模低频语义布局，优化面更平滑。这一点在答题时应当明确说出：VAE 不只是省算力，它还改变了扩散任务本身的难度分布。

二 · 变体二：重建质量与扩散成本的拉锯

第二个变体题是设计题：“给定固定的推理预算，你如何在 VAE 压缩率与扩散质量之间取舍？说出你的判据。”这题把解析里那句“压得太狠丢细节，压得太松扩散贵”变成可操作的工程决策，考的是有没有把权衡当成一条曲线而不是一句口号。

机制上，VAE 的压缩率由潜变量维度与下采样倍率共同决定，重建误差随压缩率上升而上升，扩散侧的计算量随潜变量尺寸下降而下降。两条曲线相交处不是最优点，因为质量损失不可逆：扩散只能在潜空间里生成，解码器无法凭空补回 VAE 编码时丢掉的信息。因此判据应当是“先定质量下限，再在满足下限的前提下压到最狠”。形式化地，设重建指标为 Q（如 PSNR 或感知相似度），预算约束为 C ≤ Cmax，则问题写成：

$$\min_{\theta_{\text{VAE}}} \; C_{\text{diffusion}}(\theta_{\text{VAE}}) \quad \text{s.t.} \quad Q(\theta_{\text{VAE}}) \ge Q_{\min}$$

伪代码思路：固定扩散侧的超参（步数、模型宽度），对一组候选压缩配置各训一个短程 VAE，测重建指标与潜变量尺寸；把重建指标低于下限的配置直接淘汰；在剩下的配置里按“潜变量元素数 × 采样步数”估算推理成本，取最小者；最后用该配置跑一次端到端采样，检查解码后的细节是否出现系统性缺失（例如薄结构消失、表面纹理糊化）。这个流程的关键是先淘汰再优化，而不是把两个目标加权成一个标量——加权系数没有物理意义，且会掩盖质量硬约束。

系统代价：VAE 的压缩率一旦定下，扩散模型的所有超参都要跟着重调。潜变量尺寸变化会改变 token 数，进而改变注意力的计算图与显存布局，已训好的扩散权重不能直接迁移。这意味着取舍决策发生在训练管线的最前端，返工成本极高。失败模式是“为省算力过度压缩”：潜空间小到一定程度后，扩散模型学到的分布过于平滑，采样结果在解码后表现为整体形状正确但表面缺乏高频细节，且这种缺陷无法通过增加采样步数弥补，因为信息在编码阶段就已丢失。

具体例子：三平面表示下，若把平面分辨率压到每个平面只有很小的网格，平面间的交叉注意力能表达的细节受限于网格密度，细长结构（如杆状物、薄片）在编码时就可能被平均掉。答题时应把这种“结构性细节丢失”与“纹理模糊”区分开：前者是表示能力问题，后者是解码器容量问题，二者的补救手段不同。

三 · 变体三：3D 原生潜变量与 2D 多视图的对撞

第三个变体题是辨析题：“用 2D 多视图的 VAE 加多视图扩散，再重建成 3D，与 Direct3D 的 3D 原生潜变量路线相比，差在哪？”这题直接对应判分点里的“3D 原生潜变量”，考的是能否把“避免视角不一致”展开成机制层面的差异。

机制差异有三层。第一层是表示的一致性：2D 多视图路线把同一个 3D 物体投影到若干视角，各视图独立编码、独立扩散，视图之间没有共享的 3D 约束，生成时各视图的噪声采样相互独立，重建阶段必须靠额外的几何一致性损失或优化来缝合。3D 原生潜变量在编码阶段就把多视角信息融合进一个统一的三维（或三平面）张量，扩散在同一个潜空间里进行，采样天然自洽。第二层是误差传播：多视图路线中，单视图的生成错误会通过重建步骤扩散到整个 3D 结果，且错误之间可能相互矛盾（一个视图说这里有凸起，另一个说没有），重建优化会在矛盾约束间折中，产生局部几何伪影。第三层是视角覆盖：多视图只能覆盖有限视角，背向或遮挡区域缺乏监督，生成时这些区域的质量依赖先验补全；3D 原生表示没有“未观测视角”的概念，所有空间位置在同一潜变量里被同等对待。

系统代价：多视图路线的工程管线更长——渲染多视图、逐视图扩散、跨视图一致性约束、重建与后处理，每一环都有超参，调试面大。3D 原生路线把复杂度集中在前端的 VAE 与表示设计上，后端管线短，但 VAE 的训练难度更高，因为要在 3D 表示上同时学好压缩与重建。失败模式方面，多视图路线典型的问题是“视角间闪烁”：同一物体在不同视角下细节不一致，转一圈能看到纹理跳变；3D 原生路线典型的问题是“潜空间过于平滑”，即压缩率与表示分辨率限制了细节上限。

具体例子：一个带细密纹理的曲面，多视图路线在每个视角都能生成清晰的纹理，但相邻视角的纹理接缝对不上；3D 原生路线在潜空间里只有一份纹理场，接缝问题不存在，但若三平面分辨率不足，纹理会在解码后整体糊化。答题时把这两个失败模式并列写出，比单说“3D 原生更好”有说服力得多。

四 · 五个追问：从定义到边界

追问一：“VAE 的‘压缩’具体压的是什么？”答：压的是空间分辨率与通道冗余。3D 表示（体素或三平面）中相邻空间位置高度相关，VAE 的编码器通过下采样与卷积（或注意力）把局部冗余折叠进更少的潜变量元素，解码器再从潜变量重建。压缩率的两个旋钮是下采样倍率与潜变量通道数，前者影响空间细节上限，后者影响外观多样性上限。

追问二：“扩散在潜空间做，噪声调度还需要按原分辨率设计吗？”答：不需要，但要重新标定。噪声调度定义的是信噪比随步数的变化曲线，它与数据张量的尺度相关。潜变量的数值分布由 VAE 编码器决定，与原始表示的分布不同，因此调度参数必须针对潜空间重新调，不能直接沿用像素空间的经验值。这是“潜空间扩散一定更快”这一常见错误的反面：更快的前提是调度与网络都按潜空间重设，否则采样质量会下降。

追问三：“两阶段解耦具体解耦了什么？”答：解耦了优化目标与训练节奏。VAE 阶段只优化重建，扩散阶段只优化分布匹配，两个目标不共享梯度，各自的超参（学习率、batch、数据增强）可以独立调。若端到端联合训练，重建损失与扩散损失会相互拉扯：扩散希望潜空间平滑易建模，重建希望潜空间保留细节，二者冲突会让训练不稳定。解耦的代价是 VAE 的重建误差成为扩散质量的天花板，且这个天花板在扩散训练时不可见。

追问四：“重建质量的上限如何影响最终生成？”答：扩散生成的是潜变量，最终质量等于“潜变量分布匹配度”与“解码器重建能力”的复合。若 VAE 在某个细节上重建误差大，扩散即使完美匹配了潜空间分布，解码后该细节仍然缺失。因此评估生成质量时必须把 VAE 单独评估一遍，不能只看端到端样本的视觉观感——后者会把 VAE 的缺陷误记为扩散的缺陷。

追问五：“什么情况下不该用潜空间扩散？”答：当目标表示本身维度很低，或当任务要求逐元素的精确重建（例如需要保真到原始分辨率的下游几何处理）时，VAE 的有损压缩会成为瓶颈。此时像素空间或原始表示上的扩散虽然贵，但没有信息瓶颈。判断依据是：压缩带来的算力节省是否大于质量损失带来的下游代价。

五 · 扣分点与常见错误的对应关系

评分标准给的是“两阶段各 40%，潜空间优势 20%”，扣分点应当与这个权重结构对齐。下表把常见错误映射到失分位置与补救答法：

常见错误失分位置补救答法
以为 VAE 只做图像3D VAE 压缩（40% 中的一半）明确说出 3D 表示（三平面/体素）被压成低维潜变量，并指出压缩的是空间冗余
忽略重建质量上限潜空间优势（20%）补一句“VAE 重建误差是扩散质量的天花板，压太狠丢细节”
以为潜空间扩散一定更快潜空间优势（20%）补条件：更快的前提是调度与网络按潜空间重设，否则质量下降
只答“解耦”不答解耦什么压缩/生成解耦（40% 中的一半）说出优化目标分离、梯度不共享、超参独立调，以及天花板不可见的代价
把 2D 多视图当成等价方案3D 原生潜变量（判分点之一）说出视角不一致、误差跨视图传播、遮挡区域无监督三层差异

扣分的深层原因是答题者把“两阶段”当成两个并列的模块名，而没有说出它们之间的因果链：压缩率决定扩散的代价与难度，重建质量决定生成的细节上限，解耦决定训练的稳定性。凡是只列模块名不给因果的答案，即使名词全对，也会在 40% 的那一档里被压到及格线附近。

另一个隐性扣分点是数字底账的缺失。参考答案里没有具体数字，但答题者应当能定性说出量级关系：扩散代价随空间元素数增长，压缩倍率 r 带来约 r³ 量级的缩减（体素），采样步数把这一缩减重复 T 次。说不出这个关系，就无法支撑“扩散太贵”这一判断，只能停留在断言层面。

六 · 教学建议：把判断题改造成设计题

这道题的失分集中在“背了模块名但说不出因果”，因此教学上应当把记忆型问法改造成决策型问法。具体做法有三条。

第一条，让学生先画代价曲线再答题。给一个固定的推理预算，要求学生在“压缩率—重建质量”平面上标出可行域，并解释为什么最优点在可行域的边界而不是内部。这个练习强制学生把“压太狠丢细节、压太松扩散贵”变成一条有方向的曲线，而不是一句对称的口号。

第二条，用对照实验替代口头辨析。让学生分别用 3D 原生潜变量与 2D 多视图两条路线各跑一个小规模采样，观察视角一致性与细节保留的差异，再回到答题时用观察到的现象支撑论点。对照实验的价值在于把“避免视角不一致”从断言变成可复现的现象描述。

第三条，把评分标准前置为答题清单。告诉学生 40/40/20 的权重，并要求答案里必须出现“压缩率与扩散代价的定量关系”“重建质量作为上限”“解耦的代价”三个要素，缺一即扣。清单化的好处是让学生知道阅卷看的是因果链而非名词覆盖率。

教学上还要纠正一个思维习惯：不要把 VAE 当成“预处理”而把扩散当成“主模型”。二者是串联的质量链，前者的误差不可被后者修复。可以用一个具体的失败案例来说明：当 VAE 在薄结构上系统性丢失信息时，扩散模型在潜空间里学到的分布是“没有薄结构”的分布，采样再多步也不会长出薄结构，因为潜空间里根本没有对应的编码。这个案例能把“重建质量上限”讲成可感知的工程事实，而不是一句需要背诵的判分点。

最后，追问训练应当围绕边界条件展开：什么情况下潜空间扩散不划算、什么情况下解耦的代价超过收益、什么情况下 2D 多视图反而更合适（例如只有多视图监督数据、没有 3D 真值时）。能说清边界的答案，才真正掌握了两阶段分工的适用条件，而不是把它当成一条无条件成立的教条。
