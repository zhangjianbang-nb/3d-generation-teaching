一 · 条目定义与分类轴

《算法清单》附录里的 28 张算法卡不是按论文发表顺序堆叠的目录，而是一张按“3D 内容生产流程”排序的工程地图。每张卡固定四个字段：名字、年份、所属方向、核心公式与后继关系。名字用于索引，年份只用于标记它在流程演化中的位置，方向决定它解决哪一类子问题，核心公式与后继关系则回答两个工程问题：这张卡把什么量写成了可微目标，以及它把哪些能力交给了下一张卡。读这张清单时，先看方向再看公式，比先看年份有效得多，因为同一方向内的卡往往共享同一种表示，差异集中在损失构造与梯度路径上。

按条目主题，28 张卡可以归入六个方向。第一类是可微场景表示与体渲染，包括 NeRF 体渲染积分、多分辨率哈希编码、3D 高斯泼溅光栅化、NeuS 符号距离场体渲染、等值面/可微网格提取。它们的共同点是把场景写成连续或半连续的函数，并让像素颜色对场景参数可微。第二类是原生 3D 生成器，包括 Triplane 三平面生成器、DMTet 可微网格提取、LRM Triplane Transformer、结构化 3D 潜变量 SLAT、形状-材质双 DiT、前馈高斯输出头。它们不依赖逐场景优化，而是一次前向把条件映射成 3D 表示。第三类是蒸馏与得分家族，包括 SDS、Score Jacobian Chaining、VSD、Interval Score Matching。它们的共同机制是把 2D 扩散模型的得分借给 3D 参数。第四类是多视图扩散与视角条件生成，包括视角条件扩散 Zero-1-to-3、多视图自注意力扩散、跨域法线-颜色扩散、3D-aware 同步多视图生成。第五类是网格手艺与部件组合，包括网格序列化 tokenization、相邻网格 token 重拓扑、组合式部件潜变量扩散。第六类是场景、世界与数据管线，包括迭代式房间网格补全、高斯泼溅世界扩展、视频驱动物理参数估计、大规模 3D 资产清洗管线、UV 展开 + PBR 材质分解、LLM+程序化+扩散世界组合。

这六个方向不是互斥的盒子，而是流程上的接力段。可微表示提供梯度通道，原生 3D 生成器把通道变成前馈产物，蒸馏家族在没有 3D 监督时借用 2D 先验，多视图扩散补足不可见区域，网格手艺把隐式或高斯产物转成可编辑拓扑，场景与数据管线把单物体能力扩展到房间、世界与训练集。清单的排序正是按这条接力链展开，因此相邻两张卡之间往往存在明确的后继关系：前一张卡输出某种表示或损失，后一张卡把它当作输入或正则项。

二 · 可微表示：积分、哈希与泼溅

NeRF 体渲染积分（2020）定义了整条链的起点。它把场景表示成连续函数 F(x,y,z,θ,φ) 到 (颜色,密度)，沿相机射线积分得到像素颜色。工程上真正重要的是这个积分对网络参数可微，于是多视角照片的 photometric loss 可以直接优化 3D 场，不需要任何 3D 真值。积分写成离散求和时，每条射线采样若干点，按透射率累积颜色：

这里的系统代价非常具体：每条射线要采样几十到上百个点，每个点都要过一遍 MLP，训练一个场景的算力开销随分辨率与采样数线性上升，且高频细节需要更大的 MLP 才能表达。失败模式是“雾状”表面：密度场没有尖锐的零等值面，几何看起来像一团半透明云。多分辨率哈希编码（2022）正是针对这个代价的后继卡：它用一个多分辨率的可学习哈希表代替大 MLP 承担高频细节，查询点时在多个分辨率层级插值查表，再把拼接特征送进一个小 MLP。哈希冲突不靠完美哈希解决，而靠多个分辨率层级与一个小 MLP 共同消解；表项用即时更新的方式训练，即每次查到哪个表项就只更新那一项。代价从“大网络前向”转成“查表带宽与冲突噪声”，失败模式是冲突导致的特征串扰，表现为局部高频噪声或伪影。

3D 高斯泼溅光栅化（2023）换掉了积分路径。它把场景表示成一堆带位置、协方差、不透明度、球谐颜色的 3D 高斯；渲染时把它们投影到屏幕并按深度排序，做 alpha 混合，整个过程是显式、可并行、可微的。与 NeRF 的逐点采样相比，泼溅的代价集中在排序与混合：高斯数量可达百万级，投影后的 2D 协方差需要数值稳定化，深度排序在重叠区域决定混合顺序。失败模式是“针状”或“漂浮”高斯：优化过程中协方差塌缩或位置漂移，产生远离表面的伪影。它的后继关系指向世界扩展与实时渲染，因为显式表示可以被直接编辑、裁剪与增量添加。

NeuS 符号距离场体渲染（2021）解决的是表面质量问题。它把密度定义为 SDF 经过 logistic 变换后的概率密度，使体渲染的 alpha 在零等值面附近达到峰值；这样既能用体渲染的可微性，又能得到水密、平滑的表面。公式上，密度是 SDF 值的函数，alpha 在等值面处集中，避免了 NeRF 密度场的模糊。代价是 SDF 需要额外的正则（如 Eikonal 项）来保持距离性质，失败模式是薄结构丢失或等值面振荡。DMTet 可微网格提取（2021）把这一步推进到显式网格：用一张可变形的四面体网格表示空间，每个顶点带 SDF 值；根据 SDF 符号把四面体切成三角面，顶点位置由 SDF 线性插值得到，整个过程对 SDF 与顶点坐标可微。它让“隐式场”与“可编辑网格”之间的边界变得可训练，代价是四面体分辨率与拓扑变化的处理，失败模式是切分产生的非流形边或退化三角形。

三 · 原生 3D 与前馈工厂

Triplane 三平面生成器（2021）是原生 3D 方向的表示基石。它把 3D 场分解成三个正交平面（xy、xz、yz），每个平面是一张 2D 特征图；查询 3D 点时把三平面特征插值拼接，再送小 MLP 解码。2D 卷积负责生成平面，3D 一致性由三平面共享约束。这个设计的工程价值在于把 3D 生成问题降维成 2D 生成问题，代价是平面分辨率限制细节，且三个平面之间的相关性需要网络自己学。失败模式是平面间不一致，表现为某个视角下的几何接缝。

LRM Triplane Transformer（2023）把三平面变成前馈产物：用 ViT 把输入图编码成 token，再用 cross-attention 解码成三平面特征；三平面经体渲染出图，用多视图渲染损失训练；推理时一次前向出 triplane，再提取网格。它的代价从“逐场景优化”转成“训练一个大模型”，失败模式是输入视角覆盖不足时的背面臆造。前馈高斯输出头（2024）把输出表示换成高斯：Transformer 从多视图 token 预测每个高斯的均值、协方差、不透明度、球谐颜色；可微光栅化端到端训练。这条路径把前馈生成与显式泼溅接上，代价是高斯数量与 token 数的匹配，失败模式是稀疏区域的空洞。

结构化 3D 潜变量 SLAT（2024）把表示进一步结构化：把 3D 资产表示成“稀疏体素 + 局部特征”的结构化潜变量 SLAT，用 3D DiT 在潜空间做扩散；解码器可分别输出高斯、网格、辐射场。它的机制核心是潜空间扩散与多解码器解耦，代价是稀疏体素索引的构建与 DiT 的序列长度，失败模式是稀疏结构在生成中丢失细部。形状-材质双 DiT（2025）把形状与材质拆成两个 DiT：形状 DiT 生成高分辨率 SDF/网格，材质 DiT 生成 UV 空间 PBR 贴图；两者共享图像条件但独立训练，最后合成带材质的资产。这种拆分的工程判断是：几何与材质的监督信号不同，合在一个网络里会互相拖累；代价是两次生成与最后的 UV 对齐，失败模式是材质与几何的接缝错位。

四 · 蒸馏家族：把 2D 得分借给 3D

Score Distillation Sampling（2022）是这条支路的定义性条目。它把 3D 表示渲染成图 x，加噪后送进 2D 扩散模型，用“预测噪声 − 实际噪声”作为更新方向；这个方向不是真实得分，但足以把渲染图推向扩散模型的高概率区域。伪代码思路是：渲染 x，采样噪声 ε 与 timestep t，构造加噪图，送扩散模型预测噪声，计算噪声差，经渲染雅可比回传至 3D 参数。代价是每次更新都要前向一次扩散模型并反传，失败模式是过饱和、过度平滑与“正面好看、侧面崩坏”，因为噪声差方向并不约束多视角一致性。

Score Jacobian Chaining（2022）修正了梯度构造：把渲染图看作 3D 参数的函数，用扩散模型的得分（而非噪声差）乘渲染雅可比，得到 3D 参数的得分；再用退火 Langevin 动力学采样。它的机制差异在于得分与雅可比的链式组合，代价是得分估计的方差，失败模式是采样不稳定。Variational Score Distillation（2023）把 3D 参数视为分布，用一个可学习的粒子（LoRA）近似该分布的得分；用“预训练扩散得分 − 粒子得分”作为更新方向，等价于最小化 3D 分布与文本条件分布的 KL。这个构造把单点优化变成分布匹配，代价是要维护一个 LoRA 粒子并交替更新，失败模式是粒子近似不足导致的模式坍塌。Interval Score Matching（2023）用 DDIM 反演把渲染图映射到噪声，再沿同一轨迹去噪；比较反演终点与预测终点，构造区间得分匹配损失，减少随机噪声带来的方差。它的机制是用确定性轨迹替代随机加噪，代价是反演步数与轨迹一致性，失败模式是反演误差累积。

五 · 多视图扩散与网格手艺

视角条件扩散 Zero-1-to-3（2023）在预训练图像扩散模型上加入相机位姿条件（相对旋转/平移），用 Objaverse 渲染的多视图数据微调；推理时生成一圈视角，再交给重建。它的机制是把“新视角合成”写成条件生成，代价是位姿条件的精度与数据覆盖，失败模式是生成视角之间的几何漂移。多视图自注意力扩散（2023）把 4 个视角的图像拼成一个序列，在自注意力里让视角之间共享信息；用 3D 数据微调，使模型学会生成几何一致的多视图。代价是序列长度与注意力开销，失败模式是视角数增加后的显存压力。跨域法线-颜色扩散（2023）用两个扩散分支分别生成颜色与法线，共享视角条件与跨域注意力；法线提供几何监督，颜色提供纹理，两者互相约束。失败模式是两个分支的解耦误差，表现为法线与颜色的错位。3D-aware 同步多视图生成（2023）每一步把各视角特征反投影到共享 3D 体积，融合后再投影回各视角预测噪声，让几何信息在视角间流动。它的机制是显式的 3D 瓶颈，代价是体积融合的分辨率，失败模式是反投影的空洞。

网格序列化 tokenization（2023）把网格变成语言：用面片邻接关系把网格遍历成序列，每个面片编码为“顶点坐标 + 邻接面”的离散 token；训练 decoder-only Transformer 自回归生成。代价是序列长度随面片数增长，失败模式是长序列的拓扑断裂。相邻网格 token 重拓扑（2024）改进编码：把网格重拓扑当成序列生成，输入点云/网格，输出面片序列；用相邻面 token 编码，让每个面只引用前一个面的边，缩短序列并保证拓扑连续。它的机制是用邻接约束替代全局引用，代价是遍历顺序的敏感性，失败模式是顺序选择导致的局部扭曲。组合式部件潜变量扩散（2025）用一组潜变量分别表示各部件，扩散模型在组合潜空间去噪；部件之间通过注意力共享全局形状，但各自解码成独立网格。代价是部件划分与注意力耦合，失败模式是部件接缝处的穿插。

六 · 场景、世界与数据管线速查

迭代式房间网格补全（2023）用 2D 文本/图像扩散不断修补当前视角的深度与颜色，把新看到的几何反投影并融合进全局网格；相机逐步移动，场景逐步长出来。它的机制是“看一点、补一点、融一点”，代价是每步的反投影与网格融合，失败模式是漂移与重复几何。高斯泼溅世界扩展（2024）用 3D 高斯泼溅表示场景；从单图初始化高斯；相机移动时用视频扩散生成新视角，再蒸馏成新高斯；场景可以无限外扩。代价是视频扩散的时序一致性与高斯增量管理，失败模式是外扩区域的风格漂移。视频驱动物理参数估计（2024）用视频生成模型生成物体在外力下的运动，作为“物理视频先验”；再用可微物理仿真优化杨氏模量、泊松比等参数，使仿真轨迹匹配视频。它的机制是把视频当监督、把仿真当可微前向，代价是仿真步进与参数搜索，失败模式是视频先验的物理不合理导致参数偏差。

大规模 3D 资产清洗管线（2022）从 Sketchfab 等平台抓取 CC 许可模型，统一格式、去重、补元数据、渲染多视图；用 CLIP 过滤与分类，形成可训练的 3D 数据集。代价是格式转换与渲染吞吐，失败模式是许可与元数据的缺失导致训练集偏差。UV 展开 + PBR 材质分解（2024）在生成网格后做 UV 展开，把表面颜色/材质反投影到 UV 空间；用扩散模型补全反照率、粗糙度、金属度，并做光照解耦。代价是 UV 接缝与反投影误差，失败模式是光照解耦不彻底导致的烘焙阴影。LLM+程序化+扩散世界组合（2025）把世界生成拆成四个模块：LLM 布局推理、程序化地形/建筑、扩散 3D 物体、object-aware 组合；各模块预训练，系统级组合。代价是模块间接口与组合一致性，失败模式是布局与物体尺度的不匹配。

这张速查表的用法不是逐行背诵，而是按“输入表示—输出表示—梯度来源”三列做工程判断。若输入是多视图照片且需要高质量单场景，走 NeRF/NeuS/3DGS 这条可微表示线；若需要一次前向出资产，走 Triplane/LRM/SLAT/双 DiT 这条前馈线；若只有文本或单图且没有 3D 监督，走 SDS/VSD/ISM 这条蒸馏线；若需要补背面与多视角一致，走 Zero-1-to-3 与同步多视图这条扩散线；若产物必须可编辑，走 DMTet 与网格 token 这条拓扑线；若目标从物体扩展到房间与世界，走迭代补全、世界扩展与模块组合这条场景线。每条线的代价栏就是选型时的否决项：无法承受逐点采样就不要选 NeRF 原版，无法维护 LoRA 粒子就不要选 VSD，无法处理长序列就不要选网格自回归。
