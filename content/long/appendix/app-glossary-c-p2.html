二 · 从 NeuS 的权重函数看“表面从体积里长出来”的细节

NeuS 常被一句话概括为“用 SDF 替换 NeRF 的密度”，但工程上真正决定成败的是它把体积渲染的 alpha 权重与 SDF 值耦合起来的方式。NeRF 的密度 σ 是沿射线独立定义的标量场，而 NeuS 要求权重在表面处集中、在表面两侧衰减，且这个集中程度要随训练进行可控地收紧。它的无偏权重构造依赖一个可学习的逆温度参数 s：当 s 很小时权重在整条射线上摊平，梯度能覆盖较大范围；当 s 增大，权重逐渐逼近以零水平集为中心的窄峰。伪代码层面可以写成：对采样点 x_i 求 SDF 值 f_i 与梯度，按 f_i 的相对大小构造离散的透射率乘积，再对相邻点的权重差做归一化得到 alpha。这里容易错的细节是：很多人直接把 SDF 值当作“负密度”代入 NeRF 的积分，结果表面附近的权重不归一、颜色积分出现偏置，重建出的几何在薄结构上系统性偏厚。正确的做法是保持 alpha 由相邻 SDF 值之差导出，而不是由单个点的 SDF 值导出。

这个细节的代价是可微性与数值稳定性。SDF 梯度在零水平集附近模长接近 1，但在远离表面的区域会退化，若采样点恰好落在梯度接近零的位置，权重构造中的除法会放大噪声。工程上的失败模式是：训练初期 s 设得过大，权重过早尖锐，射线只在少数采样点上获得梯度，导致表面出现孔洞与碎片；反之 s 过小则表面模糊、细节被抹平。一个具体例子是重建带细腿的椅子：腿部直径远小于采样间距时，若权重峰宽大于腿的半径，腿会被“融”进周围空间，表现为腿部增粗甚至消失。因此采样策略必须与 s 的调度联动，粗到细的采样加上 s 的退火是这类系统的必备机制，而不是可选调优。

$$\alpha_i = \max\left(0, \frac{\Phi_s(f_i) - \Phi_s(f_{i+1})}{\Phi_s(f_i)}\right),\quad \Phi_s(f)=\left(1+e^{-sf}\right)^{-1}$$

上式用 logistic 累积分布把 SDF 值映射为透射率，alpha 由相邻点的透射率差得到。注意分母是当前点的透射率而非 1，这个归一化保证了沿射线权重之和为 1，从而颜色期望无偏。工程实现中还要处理 f_i 与 f_{i+1} 同号且都远离零的情况：此时差值极小，alpha 接近零，属于正确的“空区不贡献”，但浮点下溢会让梯度消失，需要给差值加一个与采样间距相关的下界。

三 · 哈希编码的冲突率与“看不见的容量上限”

Instant NGP 的多分辨率哈希编码把空间切成 L 层不同分辨率的网格，每层网格顶点通过一个空间哈希函数映射到固定大小的特征表。它的核心机制是：分辨率越高的层，网格越密，哈希冲突越严重，但因为高分辨率层只负责局部细节，冲突带来的串扰被低分辨率层的一致性约束所掩盖。工程上必须算清楚的是特征表大小 T 与最高分辨率层网格顶点数 N_L 的比值。当 T 明显小于 N_L 时，冲突率上升，表现为高频细节被“平均”掉，模型在训练集视角上仍然拟合得很好，但新视角出现块状伪影。这是一个典型的过拟合式失败：训练损失下降，验证视角质量下降，而调参者往往误以为是正则化不足。

具体例子是重建一个带密集文字标牌的场景：低分辨率层能给出标牌的整体平面，高分辨率层需要区分笔画，若 T 不足，笔画之间发生哈希碰撞，文字被糊成条纹。此时增加 T 或降低最高分辨率层的层数都能缓解，但前者增加显存与缓存压力，后者损失细节。系统代价体现在显存带宽上：每层每个采样点都要做哈希与查表，L 层意味着 L 次随机访存，这是这类编码在 GPU 上真正的瓶颈，而不是浮点算力。因此工程判断是：先确定目标细节尺度对应的最高分辨率，再据此反推 T，而不是先定 T 再调分辨率。

现象机制归因工程处置
训练视角清晰、新视角块状伪影高分辨率层哈希冲突增大特征表或减少层数
细节整体偏软最高分辨率不足提高最细层分辨率并同步扩表
训练后期损失震荡随机访存与缓存抖动调整采样批大小与层间访问顺序

四 · 3DGS 的致密化判据与“高斯数量失控”

3D Gaussian Splatting 的致密化不是无条件增加高斯，而是由两个判据驱动：视图空间位置梯度的模长超过阈值，以及高斯在屏幕上的投影半径过小。前者说明该区域欠拟合，后者说明该高斯覆盖的像素太少、贡献不足。克隆操作复制高斯并沿梯度方向平移，分裂操作把一个大高斯拆成两个按比例缩小的高斯。这里容易错的细节是梯度阈值的尺度依赖性：梯度模长与场景尺度、相机距离、学习率都相关，直接套用固定阈值在不同数据集上表现差异巨大。正确的做法是把阈值与当前高斯的尺度绑定，用相对梯度而非绝对梯度作为判据。

失败模式是高斯数量指数增长而质量不升。典型场景是反光或半透明表面：梯度持续存在但无法通过增加高斯消除，致密化不断触发，显存被耗尽，渲染帧率骤降。另一个场景是远离相机的背景区域，投影半径小但梯度大，克隆出的高斯在训练视角上几乎不可见，却占用了大量显存与排序开销。系统代价的关键在于高斯排序：每帧都要按深度对全部高斯排序，高斯数量翻倍意味着排序与光栅化成本翻倍，这是实时渲染的硬约束。工程判断是给致密化设总量上限，并在训练中周期性做不透明度剪枝，把不透明度低于阈值的高斯移除，用“增—剪”闭环替代单向增长。

$$\text{densify if } \|\nabla_{\mathbf{p}} \mathcal{L}\| > \tau \cdot r_{\text{proj}},\quad \text{split if } r_{\text{proj}} > r_{\max}$$

式中 r_proj 为高斯在视图空间的投影半径，τ 为相对阈值。把阈值乘以投影半径，等价于要求梯度相对于该高斯覆盖的像素面积足够大，这才使判据在不同尺度下可比。分裂条件则防止单个高斯覆盖过多像素而无法表达细节。

五 · SDS 与 VSD 的梯度差异：为什么“同一个提示词”会给出不同结果

DreamFusion 的 SDS 把 2D 扩散模型对含噪渲染图的去噪残差作为 3D 参数的梯度信号，其本质是用一个固定的先验分数函数去“拉”渲染图。ProlificDreamer 的 VSD 则引入一组粒子，用粒子分布自身的分数与先验分数之差作为梯度，相当于把单个样本的蒸馏变成分布级的蒸馏。机制差异体现在梯度公式里：SDS 的梯度只含先验项，VSD 的梯度含先验项减去粒子分布项。这个减项的作用是抑制模式坍塌：SDS 容易让不同随机种子收敛到几乎相同的几何，因为先验分数把所有样本拉向同一个高概率区域；VSD 的粒子项让样本之间保持排斥，从而提升多样性。

容易错的细节是把 VSD 的粒子数当成“越大越好”。粒子数增加确实提升多样性，但每个粒子都要独立渲染与反传，显存与计算量线性增长。更隐蔽的失败是粒子间的梯度耦合：若粒子共享同一组 3D 参数而只在不同噪声上采样，粒子项退化为噪声平均，多样性收益消失。正确实现要求每个粒子持有独立的 3D 表示或至少独立的参数副本，这在显存上是硬代价。具体例子是生成同一提示词下的多把椅子：SDS 往往给出形态接近的椅子，VSD 在粒子数足够且参数独立时能给出靠背高度、腿型明显不同的样本。工程判断是：先确认粒子是否真正独立，再谈粒子数，否则增加粒子只是增加计算而没有增加多样性。

$$\nabla_\theta \mathcal{L}_{\text{SDS}} = \mathbb{E}\left[w(t)\,(\epsilon_\phi(\mathbf{x}_t,t,y)-\epsilon)\frac{\partial \mathbf{x}}{\partial \theta}\right]$$
$$\nabla_\theta \mathcal{L}_{\text{VSD}} = \mathbb{E}\left[w(t)\,\big(\epsilon_\phi(\mathbf{x}_t,t,y)-\epsilon_\psi(\mathbf{x}_t,t,y)\big)\frac{\partial \mathbf{x}}{\partial \theta}\right]$$

两式只差一个由粒子分布参数 ψ 估计的分数项。工程上这意味着 VSD 需要额外训练一个小的分数估计网络，其容量与更新频率直接影响稳定性：更新太快则粒子项噪声大，更新太慢则退化为 SDS。

六 · 前馈重建模型的“输入视角数”与几何歧义

LRM 类模型把单图或稀疏视图编码为三平面或高斯基元，再由 Transformer 解码。它们的共同假设是：输入视角提供了足够的外观线索，模型依靠数据先验补全不可见区域。这里容易错的细节是混淆“重建”与“想象”。当输入只有一张图时，背面几何完全由先验决定，模型输出的背面是统计上合理的猜测，而非观测结果。工程上必须区分两类误差：可见区域的误差反映编码器与解码器的拟合能力，不可见区域的误差反映训练数据的分布覆盖。具体例子是输入一张正面拍摄的马克杯，杯柄在背面：若训练集中杯柄位置分布集中，模型会把柄放在统计常见的位置，与真实物体不符；这不是模型缺陷，而是单图任务的固有歧义。

系统代价体现在输入视角数与推理成本的关系上。稀疏视图模型通常把多张图编码为一组 token，token 数与视角数成正比，注意力计算随 token 数平方增长。因此从单图扩展到四视图不是线性增加成本。失败模式是视角间不一致：当输入视图之间存在曝光或白平衡差异，编码器会把差异当作几何线索，输出表面出现虚假凹凸。工程处置是在编码前做颜色归一化，或在训练中加入光度增强，让模型学会忽略这类差异。判断一个前馈模型是否可用，应看它在“输入视角外的区域”是否稳定，而不是只看输入视角的重建误差。

输入条件可见区误差来源不可见区误差来源
单图编码器拟合能力训练分布覆盖与歧义
稀疏多视图视角间一致性建模未观测区域的先验强度
视频序列时序对齐与运动模糊轨迹外区域的补全

七 · 网格生成的 token 化：顶点顺序与“合法网格”的边界

MeshGPT 与 MeshAnything 系列把三角形网格序列化为 token 序列，用自回归 Transformer 生成。机制核心是网格的 token 化方案：顶点坐标量化、面索引编码、以及序列的终止符。容易错的细节是顶点顺序的规范性。同一网格可以有多种顶点编号与面顺序，若训练数据未做规范化，模型学到的是“某种常见顺序”而非几何本身，生成结果在拓扑上合法但在顶点复用上低效，表现为大量重复顶点与退化面。工程上需要在 token 化前做顶点去重与面排序，使序列表示与几何一一对应。

失败模式是生成非法网格：自回归模型逐 token 预测，无法保证面索引始终引用已生成的顶点，也无法保证每条边恰好被两个面共享。工程处置是在解码阶段做合法性修复：丢弃引用未定义顶点的面，合并重复顶点，检测非流形边并拆分。这些修复会改变拓扑，因此生成模型的质量评估必须区分“原始输出合法性”与“修复后合法性”。具体例子是生成一个带孔洞的机械零件：模型可能生成环绕孔洞的面片，但面片之间的边不闭合，修复后孔洞被填平，几何语义丢失。判断这类系统是否可用于生产，关键看修复率与修复对语义的破坏程度，而不是只看渲染图。

$$\text{valid} \iff \forall f\in F:\ \text{idx}(f)\subset V_{\text{gen}},\ \text{且 } \forall e:\ \text{deg}(e)=2$$

该判据要求每个面的索引都指向已生成顶点，且每条边恰好被两个面共享。自回归解码时无法在生成过程中强制满足，只能在序列结束后校验与修复，这就是这类方法在工程上必须配一个几何后处理器的原因。

八 · 部件生成与场景生成中的组合性代价

PartCrafter 用组合式潜变量扩散生成结构化部件，SceneCraft 用 LLM 代理把场景描述翻译为 Blender 代码。两者的共同点是组合性：整体由部件或对象按空间关系拼装。容易错的细节是组合后的尺度与接触关系。部件模型在独立训练时各自归一化到单位尺度，拼装时需要恢复真实相对尺度，否则出现“椅子比桌子大”的错误。SceneCraft 的代码生成路径则把空间关系交给 LLM 推断，LLM 对物理合理性的判断不稳定，容易生成相互穿插的对象。

系统代价在于组合搜索空间。部件数增加时，部件间的接触与遮挡关系呈组合爆炸，纯生成模型难以在一次性前向中保证全局一致。工程处置是把组合性拆成两步：先生成部件及其局部坐标系，再用一个显式的布局求解器处理尺度、接触与碰撞。失败模式是布局求解器与生成模型的目标不一致：生成模型优化的是外观似然，布局求解器优化的是物理可行，两者冲突时外观被牺牲，表现为部件被强行拉开或压扁。具体例子是生成一张餐桌场景：碗碟若按外观似然放置会浮在桌面上方，布局求解器把它们压到桌面，接触面出现穿插。判断这类系统是否成熟，应看它是否把“物理可行”作为硬约束而非软惩罚。
