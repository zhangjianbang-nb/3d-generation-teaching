一 · 配方条目的定义与四段切分

“复现配方”不是论文摘要的合集，而是一份把论文结论还原成可执行工程对象的清单。它的基本单位是条目：一条配方对应一种表示加一条训练路径，并附带最小可跑配置、常见坑与验收断言。判断一条配方是否写清楚，标准只有一条——一个没有读过原论文的工程师，能否只凭这条配方把系统跑起来，并在跑不起来时定位到具体环节。因此配方必须把“表示—数据—训练—渲染—评测”切成可独立验收的段，每段都给出输入输出的张量形状与断言条件。

按表示族分类，可用事实中的条目可归为五类：神经辐射场类（NeRF、pixelNeRF）、哈希加速类（Instant NGP）、显式高斯基元类（3DGS 及其综述）、隐式表面类（NeuS、VolSDF 一系的体积渲染表面方法）、生成类（EG3D、GET3D、Point-E、Shap-E、SDS 家族与 DreamGaussian）。这个分类不是按论文年份排的，而是按“场景被存成什么”排的：存成 MLP 权重、存成哈希表、存成高斯集合、存成 SDF 零等值面、存成潜变量或点集。表示决定了渲染器的形状，渲染器决定了梯度如何回流，梯度回流方式决定了训练配置，这条链条是配方的骨架。

每条配方内部再切四段。第一段是数据与位姿：多视图照片、相机内参外参、归一化包围盒。第二段是表示与初始化：MLP 宽度层数、哈希表大小与层级数、高斯初始点数与协方差初始化、SDF 网络与 β 初值。第三段是训练循环：采样策略、损失项、致密化与剪枝节奏、学习率调度。第四段是渲染与评测：体渲染积分或投影排序混合、验证视图 PSNR/SSIM/LPIPS、表面法线一致性、几何倒角距离。四段之间用断言连接，前一段的断言不通过就不进入下一段，这是配方与教程的根本区别。

举一个具体例子说明切分的必要性。以 Instant NGP 为例，若把哈希编码与训练循环混在一段写，读者在遇到“训练几十步后画面仍是噪声”时无法判断是哈希表太小导致高频冲突、还是学习率对特征表过大导致表项震荡。配方把它拆开：先断言单层级哈希查询在给定坐标上返回固定长度特征向量且不同坐标碰撞率在预期范围内，再断言小 MLP 在固定特征输入下能拟合一个已知颜色函数，最后才进入多视图训练。每一段都有一个可独立运行的伪代码入口，失败模式被隔离在段内。

速查表还要标出跨条目的复用关系。pixelNeRF 的特征采样机制与 EG3D 的三平面插值在几何上是同一件事：把 3D 查询点投影或插值到低维特征网格上再解码。区别在于 pixelNeRF 的特征来自输入视图的 CNN，EG3D 的三平面由 2D 卷积生成器产生，3D 一致性由三平面共享与 2D 判别器共同约束。配方把这种复用写成“特征网格采样”子程序，两个条目共享同一段双线性采样代码与同一组断言，减少复现时的重复劳动。

三 · 数据与位姿段：最小可跑配置与位姿坑

数据段的最小可跑配置是：一组环绕拍摄的多视图照片、每张图对应的相机内参和外参、一个把场景包住的归一化包围盒。NeRF 类配方对位姿的敏感度远高于对网络宽度的敏感度，因为体渲染积分把位姿误差直接放大成射线方向误差，表现为所有视角一致地“糊”，而训练损失仍然下降。配方的做法是在数据段就加断言：用估计位姿三角化若干匹配点，检查重投影误差分布；若位姿来自 COLMET 类运动恢复结构，还要检查尺度归一化后包围盒是否把所有相机中心包住。

pixelNeRF 一类少视图配方把位姿坑推到更前面：查询点要按相机位姿投影到各输入视图并双线性采样特征，位姿符号约定错一个轴，采样就会落到图像外，网络只能学到常数颜色。配方要求先跑一个纯几何测试：给定已知 3D 点和已知位姿，投影后的像素坐标应与手工计算一致，这一步不涉及任何神经网络。这个测试是数据段与表示段之间的门禁。

生成类条目的数据段不同。EG3D 用三平面分解，训练数据是单视图图像加相机参数，3D 一致性不靠多视图监督而靠三平面共享结构与 2D 判别器；GET3D 用 DMTet 可微网格，生成器预测四面体顶点的 SDF 与纹理，按符号切出三角面，判别器在渲染图上工作。这两类配方的数据段断言是“渲染图与真实图在判别器特征空间的分布距离不塌缩”，而不是重投影误差。配方必须明确区分重建类与生成类的数据断言，否则复现者会把生成模型当成重建模型调，越调越差。

系统代价出现在数据段的存储与加载：多视图重建配方通常需要把图像与位姿打包成可随机访问的格式，若每步都从磁盘解码原图，GPU 利用率会被 IO 拖住。配方的工程判断是先把图像降采样到训练分辨率并缓存为连续数组，位姿单独存为浮点张量，加载器只做切片不做解码。失败模式是缓存分辨率与渲染分辨率不一致，导致验证视图 PSNR 被人为压低，而复现者误以为是表示容量不足。

四 · 表示与初始化段：哈希、高斯与 SDF 的三种初始化

Instant NGP 的表示段是配方里最需要写清“形状”的一段。坐标在 L 个分辨率层级上量化并哈希到固定大小表项，拼接特征后只过一个很小的 MLP。初始化要回答三个问题：层级数 L 与每层表大小如何随显存预算分配；哈希函数用什么；特征表初值取零还是小随机。取零初值时所有坐标共享同一特征，早期梯度只更新被采到的表项，未被采到的表项保持零，这会让高频细节出现得晚但不引入噪声；取小随机则早期就有纹理但可能过拟合。配方把这一选择写成显式开关，并要求在表示段单独断言：固定一组坐标，连续两次查询返回相同特征，且特征范数在合理区间内，不因哈希冲突而爆炸。

哈希冲突由多层级与梯度平均自然消解，这是该表示的核心机制，也是配方必须解释清楚的一点：同一表项被不同坐标共享时，梯度是这些坐标梯度的叠加，多层级中粗层级提供全局一致性、细层级提供局部细节，冲突在层级间被平均掉。失败模式是细层级表太小而场景细节密集，冲突过多导致细节互相污染，表现为局部区域出现不属于该处的纹理。配方的对策不是加大 MLP，而是按场景包围盒的体积与目标细节尺度重算层级分辨率与表大小。

3DGS 的初始化段是显式高斯基元：位置、协方差、不透明度、球谐颜色。初始化通常来自运动恢复结构产生的稀疏点云，协方差按最近邻距离设定，不透明度取一个较小值使早期混合接近透明。配方要写明致密化与剪枝的触发条件与上限：梯度大的高斯分裂，不透明度低的高斯剪除，两者必须成对配置，否则高斯数量单调增长。系统代价直接体现在显存与排序开销上：投影后按深度排序的代价随高斯数量增长，alpha 混合是逐像素的，帧率对高斯数量敏感。失败模式是致密化只在高梯度区域发生，导致薄结构（栏杆、树叶）被过度致密而平坦墙面高斯不足，画面出现“薄处毛刺、平处空洞”。

NeuS 与 VolSDF 一系的表示段是 SDF 网络加一个把 SDF 映射成密度的变换。NeuS 用 σ(x)=αΨ_β(−f(x))，其中 f 是 SDF、Ψ_β 是 sigmoid；VolSDF 用 α(x)=Ψ_β(−f(x))，Ψ_β 是 scaled CDF，β 控制表面厚度。初始化要定 β 的退火 schedule：β 大时表面厚、梯度平滑、易优化；β 小时表面薄、细节锐利、易陷入局部。配方的断言是：β 退火到目标值后，提取的零等值面法线与渲染深度图一致，若不一致说明密度峰值偏离零等值面，通常是 β 退火过快或 SDF 网络缺少 Eikonal 约束。Eikonal 项在配方里不是可选装饰，而是保证 f 近似真实符号距离函数的必要条件。

五 · 训练循环段：采样、损失与致密化节奏

训练段的第一项是采样策略。NeRF 类配方用粗网络均匀采样加细网络重要性采样，重要性采样依据粗网络的密度分布重新分配采样点，这一步把有限的 N 次前向集中到表面附近。配方的伪代码思路是：先跑粗网络得到各段权重，归一化后作为概率密度，用逆变换采样取细网络点，再把粗细两组的颜色按权重合成。失败模式是重要性采样退化成均匀采样（权重全相等），此时细网络没有增益，表现为细节提升不明显而计算量翻倍。断言是细网络采样点的密度加权方差显著高于均匀采样。

损失项在重建类配方里通常只有 RGB 损失，但 3DGS 与 NeuS 系会加正则：3DGS 对协方差的尺度加约束防止高斯退化成针状，NeuS 加 Eikonal 项。生成类配方则换成 SDS 或 VSD：DreamFusion 用可微渲染器渲染成图、加噪后送进冻结的 2D 扩散模型，用“预测噪声减实际噪声”作为梯度方向更新 3D 参数，CFG 增强文本对齐；Score Jacobian Chaining 把图像得分乘渲染雅可比 ∂x/∂θ 得到 θ 空间得分再退火 Langevin 采样；ProlificDreamer 的 VSD 梯度等于预训练扩散得分减粒子得分，等价于最小化 q 与文本条件分布的 KL。配方要把这些梯度公式写成可对照的形式，因为它们的差别只在“减去的项是什么”，实现上共用同一段渲染与加噪代码。

$$\nabla_\theta\mathcal{L}_{\text{SDS}}=\mathbb{E}_{t,\epsilon}\left[w(t)\left(\epsilon_\phi(x_t;y,t)-\epsilon\right)\frac{\partial x}{\partial\theta}\right]$$

上式的工程含义是：渲染雅可比 ∂x/∂θ 必须由可微渲染器提供，任何不可微的后处理（量化、排序中的非可微交换）都会截断梯度。3DGS 的排序步骤在配方里要特别标注：排序索引本身不可微，但 alpha 混合对高斯参数可微，梯度通过混合权重回流，排序只决定混合顺序。失败模式是排序在高斯重叠区域频繁翻转，导致同一像素的梯度方向在相邻迭代间震荡，表现为训练损失抖动而不下降。配方的对策是给不透明度加下限、限制协方差尺度，减少深度相近的高斯数量。

致密化节奏是 3DGS 配方独有的训练段参数：每隔固定迭代数执行一次致密化与剪枝，而不是每步都做。每步都做会让高斯数量爆炸且排序开销失控。DreamGaussian 用 3DGS 作为表示、SDS 直接优化高斯参数，收敛后从高斯提取网格再用 UV 空间纹理精修，两阶段总时间约 2 分钟——这个时间量级说明致密化节奏必须与 SDS 的步数预算匹配，否则要么高斯不足、要么时间超标。配方的验收断言是：致密化后高斯数量增长曲线应收敛，而不是线性上升。

六 · 渲染与评测段：断言链与失败模式归档

渲染段的第一道断言是几何一致性：体渲染得到的深度图与提取表面的深度图应一致，3DGS 的排序后混合权重和应不大于 1。第二道是视角一致性：绕场景一圈渲染，相邻视角的光流应连续，若出现跳变说明表示在某区域欠拟合或位姿有误。第三道是评测指标：验证视图 PSNR/SSIM/LPIPS，以及几何类的倒角距离与法线一致性。配方要求把这三道断言写成脚本，每次改动表示或训练参数后重跑，而不是靠肉眼看图。

失败模式归档是配方条目里最容易被忽略但最有价值的部分。以 NeuS 为例，常见失败是表面出现“双层壳”：密度在零等值面两侧各有一个峰值，原因是 β 退火与 Eikonal 约束不同步，SDF 在表面附近不单调。断言是沿法线方向采样密度，应单峰。以 pixelNeRF 为例，常见失败是换视图后密度预测方差大，原因是特征采样落到了输入视图的空白区域，断言是投影点必须落在图像有效像素内，否则用零特征并记录比例。以 EG3D 为例，三平面共享保证了 3D 一致性，但 2D 判别器可能奖励视角相关的纹理，表现为旋转时纹理“滑动”，断言是多视角渲染的特征距离在旋转下保持稳定。

评测段的系统代价是渲染分辨率与批量大小：验证视图若按训练分辨率渲染，显存峰值出现在体渲染采样数最大的那条射线上，配方建议按射线分块渲染再拼接，块大小由显存预算反推。生成类配方的评测更贵，因为要渲染多视角再送判别器或扩散模型，配方把这一步写成离线批处理而不是训练内循环。最后一段落在具体机制上：配方条目的可复现性不取决于论文写得多细，而取决于每条断言是否能在不依赖原论文代码的情况下独立运行——断言是配方与论文之间的唯一接口，接口不稳，整条配方就不可移植。
