一 · 条目定义与速查表

「60 分钟速成」是一条给忙人的路线，不是一套完整课程。它的定义是：用一张图建立全局坐标系，用一个故事把技术谱系串起来，用三道题逼出对关键链路的理解，再用一个最小复现把纸面知识压进工程肌肉。条目本身只规定路线形状，不规定每站的深度；深度由读者自己的工程背景决定。对已经写过渲染器、调过 CUDA kernel 或训过扩散模型的人，这条路线的作用是快速对齐术语与失败模式，而不是从零讲起。

按主题分类，这条路线覆盖五类条目：表示（NeRF、三平面、点云、隐式函数、高斯）、编码与加速（哈希表、分层采样、位置编码）、表面与正则（SDF、NeuS、VolSDF、Eikonal）、生成范式（SDS 家族、多视图扩散、前馈重建）、以及工程管线（可微光栅化、网格提取、PBR 材质）。分类不是互斥的：Instant-NGP 同时属于表示与编码，3DGS 同时属于表示与工程管线。速查表按「问题—机制—代价」三列组织，目的是让读者在 60 分钟内能定位到具体机制，而不是记住名词。

二 · 把 3D 变成像素的关键链路

NeRF 的输入是 5D：位置 (x,y,z) 与视角方向 (θ,φ)。网络输出该点的密度 σ 与视角相关的颜色 c。关键链路不是「网络多深」，而是「3D 如何被积分成像素」。沿相机射线采样，体渲染把颜色写成积分：

$$C(\mathbf{r})=\int_{t_n}^{t_f} T(t)\,\sigma(\mathbf{r}(t))\,\mathbf{c}(\mathbf{r}(t),\mathbf{d})\,dt,\quad T(t)=\exp\!\left(-\int_{t_n}^{t}\sigma(\mathbf{r}(s))\,ds\right)$$

透射率 T 是这条链路的核心：它让前面的密度遮挡后面的密度，使梯度能通过「谁挡住了谁」回传到 3D 参数。离散化后变成 alpha 合成，每段权重是 T·(1−exp(−σΔ))。分层采样（粗网络先找密度大的区间，细网络再集中采样）解决的是积分方差：均匀采样在空白区浪费样本，粗网络给出概率密度后细采样把样本压到表面附近。位置编码把低维坐标映射到高频，让 MLP 能拟合细节；没有它，网络对高频几何欠拟合。渲染损失是像素颜色与真值的 L2，它对 σ 和 c 可微，因此整条链路可端到端优化。

失败模式很具体：分层采样若粗网络欠训，细采样会漏掉薄结构，表现为细杆、栏杆在训练中期「消失又出现」；位置编码频率过高而视图少，会出现高频浮尘；透射率在数值上若用累乘而非 log 空间，长射线会下溢。工程代价是逐场景优化：每个场景要重新训，收敛慢，且视角外推时背面靠先验而非观测。具体例子：一个只有 2D 照片与相机位姿的场景，网络学出的不是「点云」，而是一个连续的密度场；当你从训练视角之外看，颜色由视角方向输入决定，几何由密度决定，二者解耦是 NeRF 能「无 3D 监督」的原因，也是它视角相关高光容易过拟合的原因。

三 · 哈希冲突与三角权衡

Instant-NGP 把空间切成多分辨率网格，每个网格顶点存一个可学习特征向量，查表用哈希。哈希必然冲突：不同顶点映射到同一槽位。它还能记细节，靠的是多分辨率分层：粗层冲突少、负责低频；细层冲突多、负责高频，冲突由多层平均与梯度消化——同一槽位被多个顶点共享，梯度是这些顶点梯度的叠加，网络学会用共享特征加小 MLP 解码来区分它们。三个超参各管一件事：L 是层数（分辨率级数），T 是每层哈希表大小，F 是每顶点特征维数。

$$\text{level } l:\ \text{resolution}=N_{\min}\cdot b^{\,l/(L-1)},\quad \text{hash}(v)=\left(\bigoplus_i v_i\pi_i\right)\bmod T$$

三角权衡是：L 增大提高最高分辨率，但层间分辨率跨度变大，粗层与细层特征拼接后 MLP 更难解码；T 增大减少冲突，但显存线性涨；F 增大表达力强，但每层查表带宽与显存同步涨。小 MLP 只做解码，不承担记忆，记忆在哈希表里，这是它与原始 NeRF 的分工差异。失败模式：T 过小且 F 过大时，冲突被高维特征放大，表现为高频噪点与「鬼影」；L 过大而训练视图少，最高层几乎无梯度，细层特征随机初始化后成为噪声源；F 过小则解码器被迫承担记忆，收敛慢且细节糊。具体例子：同一场景把 T 减半，冲突率上升，画面先丢失的是细纹理而非轮廓，因为轮廓由粗层承担；把 L 增加但保持 T，最高层分辨率翻倍而槽位不变，冲突在薄结构处集中，表现为边缘毛刺。

四 · 高斯投影与排序

3DGS 把每个高斯当成一个带协方差的椭球。3D 协方差由旋转与缩放分解：Σ=R S Sᵀ Rᵀ。投影到屏幕不是简单取中心点，而是把协方差经雅可比与视图变换搬到 2D：

$$\Sigma'=J\,W\,\Sigma\,W^{\mathsf{T}}J^{\mathsf{T}}$$

W 是视图变换，J 是投影的雅可比。Σ' 决定屏幕上的椭圆形状，均值决定中心。渲染按深度排序后做 alpha 合成：前面的高斯先写，后面的按 (1−α) 衰减。必须按深度排序，因为 alpha 合成不是交换的：若顺序错，遮挡关系错，表现为半透明物体后面的东西「透出来」或前面被后面盖住。致密化在梯度大的区域分裂高斯、在透明区域克隆，剪枝去掉低不透明度或过大的高斯，二者共同控制高斯数量与显存。

失败模式：致密化过激导致高斯数量爆炸，显存与排序开销同步涨；剪枝过狠导致薄结构断裂；深度排序在视角变化快时若用近似排序，会出现闪烁。具体例子：一只带细腿的椅子，致密化在腿处分裂出大量小高斯，若剪枝阈值按不透明度一刀切，腿会先消失；排序若按高斯中心深度而非按椭圆覆盖范围，腿与座面交界处会出现排序错导致的半透明缝。工程代价是显存：高斯数量与每高斯参数（均值、协方差、不透明度、球谐颜色）线性相关，实时渲染的瓶颈常在排序与带宽而非光栅化。

五 · SDF 转密度与退火

NeuS 与 VolSDF 都把 SDF 转成密度，差别在映射函数：VolSDF 用 Laplace 分布的 CDF，NeuS 用 logistic；α/β 参数化不同，但共同依赖 Eikonal 正则与 β 退火。Eikonal 约束梯度模长为 1：

$$\|\nabla f\|=1,\quad \text{零等值面 } f=0 \text{ 即表面}$$

β 退火控制密度在表面附近的锐度：β 大时密度过渡宽，表面糊；β 小时密度过渡窄，薄结构处采样不足，出现噪点或发散。退火 schedule 是隐形超参：从大到小，早期宽过渡让梯度覆盖大范围，后期窄过渡收紧表面。失败模式两类：β 大→表面糊、细节丢失；β 小→薄结构噪、训练发散。具体例子：一根细绳，β 过大时绳与背景密度差被抹平，渲染出「雾」；β 过小时绳的采样点落在密度过渡带外，梯度消失，绳断裂成噪点。Eikonal 正则约束的是「距离场性质」：没有它，网络可以学出任意等值面，密度映射失去几何意义；权重过大则表面过平滑，权重过小则等值面不自洽。

工程判断：β 退火不是「调参」，而是与采样策略耦合的机制。采样若集中在表面附近，β 可以更小；采样若均匀，β 必须更大以覆盖过渡带。VolSDF 与 NeuS 的差别在工程上表现为：Laplace 映射尾部更重，薄结构更容易被采到；logistic 映射更陡，表面更锐但更依赖退火。二者共同依赖 Eikonal 与退火，换映射不换正则，失败模式相似。

六 · 蒸馏与多视图的接口

SDS 的梯度形式是把 2D 得分经渲染雅可比回传到 3D 参数：

$$\nabla_\theta \mathcal{L}_{\text{SDS}}=\mathbb{E}_{t,\epsilon}\left[w(t)\left(\epsilon_\phi(x_t;y,t)-\epsilon\right)\frac{\partial x}{\partial \theta}\right]$$

它让模型长出「两张脸」，原因是逐视角独立：每个视角单独去噪，2D 先验不知道其他视角已生成什么，正面与背面各自长出完整人脸，拼在一起就是 Janus。CFG 与随机相机只是缓解：CFG 提高单视角一致性但不跨视角；随机相机增加视角覆盖但不强制同步。SJC 的扰动是把渲染图加噪到训练分布，再用 PAAS 平均降方差，得分经雅可比回传，与 SDS 同族但方差更低。VSD 与 SDS 的核心差别是 VSD 加粒子模型 ε_ψ，梯度含 (ε_φ−ε_ψ)，从 KL/变分视角看，它惩罚的是当前 3D 分布与 2D 先验的偏差，因此缓解过饱和与多样性差。

多视图路线用「互相看见」替代「逐视角独立」：MVDream 把 4 视图 token 拼接，3D 自注意力跨视角，代价是计算量×4、视角数固定；SyncDreamer 用 16 个固定视角与共享 3D 代价体，投影-采样同步，同步去噪显存高；Wonder3D 同时生成颜色与法线，跨域共享注意力让两者对齐，法线错误会传播到几何。前馈工厂则把「一次前向」做成接口：LRM 用 ViT+cross-attention 出三平面，多视角渲染损失训练；TripoSR 简化框架、混合精度把单图重建压到 0.5 秒；GS-LRM 把输出换成高斯，光栅化实时、显式可编辑，但漂浮物、稳定性、显存成为新问题；MeshLRM 做端到端可微网格，解决「先出 NeRF 再提取」不可微的问题，拓扑与薄结构更好。具体例子：同一张单图，TripoSR 出三平面再渲染，GS-LRM 出高斯可实时拖拽但背面靠先验，MeshLRM 出网格可直接进引擎但训练更重——三者接口不同，选型取决于下游是渲染、编辑还是引擎导入。
