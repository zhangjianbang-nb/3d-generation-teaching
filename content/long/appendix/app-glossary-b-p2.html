二 · 体渲染积分的离散化：从连续场到像素的账本

体渲染积分是连接 3D 表示与 2D 监督信号的唯一通道，它的离散化细节决定了 NeRF、NeuS、3DGS 三类方法在梯度层面的行为差异。连续形式写作沿射线的透射率加权积分：颜色是各采样点辐射亮度乘以透射率 T(t) 的累积，T(t) 本身是指数衰减项。工程实现里必须把它换成有限采样求和，于是出现两个必须显式处理的量：采样区间划分与 alpha 合成顺序。

$$C(\mathbf{r})=\int_{t_n}^{t_f}T(t)\,\sigma(\mathbf{r}(t))\,\mathbf{c}(\mathbf{r}(t),d)\,dt,\quad T(t)=\exp\!\Big(-\int_{t_n}^{t}\sigma(\mathbf{r}(s))\,ds\Big)$$

离散化时把区间切成 N 段，每段内假定 σ 与 c 恒定，得到 alpha 形式的合成：第 i 个采样点的 alpha 为 1−exp(−σ_i·δ_i)，透射率为前面所有段 (1−alpha_j) 的连乘。这个连乘顺序不可交换，因此渲染器必须严格按从近到远排序，否则透射率账本会错位。NeuS 一类隐式表面方法在此之上把 σ 换成与 SDF 值挂钩的密度函数，用 logistic 分布把 SDF 零水平集附近的密度拉高，从而让体积渲染的权重峰值收敛到表面处；这正是 Eikonal 正则能起作用的前提——若密度函数与 SDF 的耦合写错，表面会整体偏移。

具体失败模式出现在采样策略上。NeRF 原始实现用粗网络加细网络两轮采样，细采样按粗网络的权重分布做逆变换采样；如果粗网络的权重全落在背景（σ 接近零但非零的雾状区域），细采样会把预算浪费在空区，表面处的梯度信号被稀释。Instant NGP 用多分辨率哈希编码替代位置编码后，单次前向即可给出足够好的密度分布，但哈希冲突会引入高频噪声，表现为渲染图上的“萤火虫”亮点——这是查表换速度的直接代价。一个可操作的判断是：当训练损失下降但法线图出现块状伪影时，优先怀疑哈希表层级分辨率与场景尺度的不匹配，而不是优化器超参。

3D 高斯泼溅走的是另一条路：它不做沿射线的积分，而是把每个高斯基元投影到屏幕空间后按深度排序做 alpha 混合。投影协方差由三维协方差经雅可比矩阵变换得到，公式为 Σ' = J W Σ Wᵀ Jᵀ，其中 W 是视角变换，J 是投影的仿射近似。这里容易错的细节是：排序必须在屏幕空间按高斯中心深度进行，但高斯在屏幕上的覆盖范围可能跨越多个 tile，光栅化器按 tile 分块后需要处理跨块排序问题。若排序粒度不足，重叠区域会出现前后景闪烁，这是显式基元方法特有的失败模式，与体渲染的采样噪声性质完全不同。

举例来说，同一场景用 NeRF 与 3DGS 分别拟合：前者在薄结构（栏杆、叶片）上因采样不足而模糊，后者在薄结构上因高斯尺度难以压缩而出现“糊团”，两者都不是优化问题而是表示粒度问题。工程判断是：需要精确几何时选隐式表面加 Eikonal 正则，需要实时新视角合成时选高斯泼溅并接受其显式基元带来的内存账本——每个高斯存储位置、协方差、不透明度与球谐系数，数量级随场景复杂度线性增长。

三 · 哈希编码的查表机制与冲突代价

多分辨率哈希编码的核心是把空间坐标映射到 L 个不同分辨率的网格，每个网格层级维护一张大小为 T 的哈希表，表项存 F 维特征向量。查询时对每个层级做坐标缩放、取整、哈希，然后对 2^d 个角点特征做线性插值，最后把所有层级的插值结果拼接送入一个小 MLP。它的收益来自把“记忆”从 MLP 权重转移到查表：高频细节由细层级表项承载，低频结构由粗层级承载，MLP 只需学习特征到输出的映射。

$$h(x)=\bigoplus_{l=1}^{L}\mathrm{lerp}\big(\mathrm{Hash}_l(\lfloor x\cdot N_l\rfloor),\ \mathrm{Hash}_l(\lfloor x\cdot N_l\rfloor+\mathbf{1})\big)$$

关键机制是哈希函数的选择与表大小 T 的关系。当 T 小于层级网格的总角点数时，不同空间位置会映射到同一表项，形成冲突。冲突本身不致命，因为梯度会同时更新冲突双方，网络倾向于学习一个折中特征；但当冲突发生在高频层级且场景包含重复纹理时，会出现“特征串扰”：一处细节的梯度污染另一处。Instant NGP 的工程取舍是用较小的 T 配合较大的 L，让冲突概率可控，同时用 F=2 这类低维特征降低内存。代价是表达能力受限，极精细的高频（如文字、细密纹理）需要更大 T 或额外的位置编码补偿。

一个具体例子：对同一物体分别用纯 MLP 位置编码与哈希编码训练，前者在低频形状上收敛慢但高频稳定，后者收敛快但在薄壁处容易出现特征泄漏，表现为壁两侧的颜色互相渗透。失败模式还包括哈希表的“冷启动”问题：训练初期大量表项未被访问，梯度稀疏，若学习率过高，已访问表项被过度更新，形成局部过拟合。工程上常见的补救是 warm-up 阶段降低学习率并配合层级渐进启用，而不是一次性打开所有层级。

系统代价方面，哈希编码把显存占用从 MLP 的参数量转移到表项数量，T×L×F 个浮点数成为主要开销；推理时查表是随机访存，缓存命中率低，在 GPU 上表现为带宽瓶颈而非算力瓶颈。这与三平面表示形成对照：三平面把 3D 查询降为三次 2D 双线性采样，访存模式更规则，但表达能力受限于平面分辨率，高频细节需要更高分辨率平面，显存随分辨率平方增长。判断依据是：若瓶颈在随机访存且场景尺度中等，哈希编码更优；若需要与 2D 卷积网络共享骨干，三平面更自然。

四 · SDF、Eikonal 正则与隐式表面的干净程度

SDF 把表面定义为函数零水平集，理想性质是梯度的模处处为 1，即 Eikonal 方程 ‖∇f‖=1。这个约束的作用不是装饰：它保证 SDF 在表面附近近似为到表面的欧氏距离，从而让体积渲染的密度峰值、法线估计、表面提取三者一致。NeuS 的做法是把 SDF 转成密度，密度在零水平集附近取最大，远离表面指数衰减；若没有 Eikonal 正则，SDF 梯度模偏离 1，密度峰值会漂移，提取出的网格出现台阶或双层壳。

$$\mathcal{L}_{\text{eik}}=\frac{1}{N}\sum_{i}\big(\|\nabla f(x_i)\|-1\big)^2,\quad \mathcal{L}=\mathcal{L}_{\text{rgb}}+\lambda\mathcal{L}_{\text{eik}}+\mathcal{L}_{\text{mask}}$$

容易错的细节在于 Eikonal 项的采样位置。若只在表面附近采样，正则对远离表面的区域无约束，SDF 可能在空区产生虚假零交叉，表现为渲染深度图上的“鬼影”表面。若在全空间均匀采样，远离表面的梯度模约束会与体积渲染的密度衰减冲突，因为密度函数在远处本应趋于零，而 Eikonal 要求梯度模为 1，两者在数值上拉扯。工程实现通常采用分层采样：在表面附近密集采样加强 Eikonal，在远处稀疏采样并降低权重，同时用 mask 监督约束空区密度。

具体失败模式是“表面粘连”：两个靠近的物体在 SDF 场中融合成一个，因为 Eikonal 正则让场在两者之间平滑过渡，而体积渲染的密度在过渡区仍非零。这在多物体场景中尤其明显，表现为接触面处的网格桥接。判断方法是检查 SDF 在接触区的梯度方向是否连续；若连续则说明场已融合，需要引入实例级或部件级的分割监督，而不是加大 Eikonal 权重。另一个代价是训练时间：Eikonal 需要对采样点求二阶导（梯度再求导），计算图更深，显存与时间开销高于纯辐射场训练。

举例来说，NeuS 在重建薄片物体时，若 Eikonal 权重过低，提取的网格在薄片两侧各有一层壳，中间夹着低密度区；提高权重后两层壳合并，但薄片厚度被高估。这说明 Eikonal 不是越大越好，它控制的是场的“距离性”，而厚度精度还取决于密度函数的锐度参数。工程判断是：先固定密度锐度，再调 Eikonal 权重，用提取网格的厚度与法线一致性作为验收指标，而不是只看渲染 PSNR。

五 · 三平面表示与 2D 卷积的降维账本

三平面表示把 3D 查询点投影到三个正交平面（XY、XZ、YZ），在每个平面上做双线性插值得到特征，再把三组特征拼接或求和送入解码器。它的核心优势是 3D 生成可以复用 2D 卷积骨干：平面特征图天然是 2D 张量，可以直接用图像生成网络的结构与预训练权重。EG3D 正是这一路线的代表，用 2D GAN 生成三平面，再经体积渲染出多视角图像。

$$f(x,y,z)=\mathrm{concat}\big(\mathrm{Plane}_{xy}(x,y),\ \mathrm{Plane}_{xz}(x,z),\ \mathrm{Plane}_{yz}(y,z)\big)$$

机制上的代价是表达能力的不对称：三平面在轴对齐方向上分辨率高，但在对角线方向上的细节被三个平面的插值平滑掉。具体表现为生成物体的斜向边缘出现模糊，而正面与侧面边缘清晰。这是降维的固有损失，不是训练不足。另一个细节是平面之间的特征对齐：三个平面独立插值后拼接，若没有共享解码器约束，同一空间点在不同平面上的特征可能矛盾，导致渲染时出现方向依赖的颜色跳变。工程上通常让解码器同时接收三组特征并做早期融合，而不是分别解码后相加。

失败模式还包括“平面泄漏”：当物体在某个平面上投影重叠（如沿 Z 方向的两个不同深度结构），平面特征无法区分前后，渲染时出现前后景混叠。这与哈希编码的冲突性质类似，但发生在 2D 层面。缓解手段是增加平面分辨率或引入额外的深度通道，代价是显存随分辨率平方增长。LRM 一类大重建模型用三平面作为输出表示，一次前向出三平面，再经可微渲染监督；其系统代价主要在渲染环节：三平面查询需要三次双线性采样，比纯 MLP 查询的访存更规则但采样次数更多，训练时的渲染分辨率与 batch 大小直接受显存限制。

举例来说，用三平面表示生成带细长天线的物体，天线沿对角线方向时三平面会把它渲染成断续的片段，因为三个平面在该方向的采样密度不足。工程判断是：若目标资产以轴对齐结构为主（家具、建筑），三平面性价比高；若包含大量斜向细结构，应转向显式基元或高分辨率哈希编码。

六 · Score Distillation Sampling 与多视图一致性的错位

SDS 把预训练 2D 扩散模型的得分函数当作 3D 参数的梯度来源：对 3D 表示渲染出的图像加噪，送入扩散模型预测噪声，用预测噪声与注入噪声的差作为渲染图像的梯度，再经链式法则回传到 3D 参数。它的本质是用 2D 先验约束 3D 渲染的每个视角，而不是直接监督 3D 几何。

$$\nabla_\theta\mathcal{L}_{\text{SDS}}=\mathbb{E}_{t,\epsilon}\Big[w(t)\big(\epsilon_\phi(x_t;y,t)-\epsilon\big)\frac{\partial x}{\partial\theta}\Big],\quad x=\mathrm{Render}(\theta)$$

容易错的细节是噪声水平 t 的选择与视角采样的耦合。t 过大时，扩散模型预测的是粗粒度结构，梯度信号指向整体形状；t 过小时，梯度信号指向纹理细节。若在训练早期用小的 t，3D 表示会在几何未定型时被纹理梯度拉出高频伪影，表现为表面布满噪声凸起。工程实现通常做 t 的退火，从大到小，但退火曲线与视角分布必须匹配：若视角采样只覆盖正面，背面几何从未被约束，退火到小 t 后背面会被纹理梯度“脑补”出与正面矛盾的细节。

多视图一致性正是针对这一失败模式：MVDream 用多视图扩散模型同时生成多个视角的图像，让 2D 先验本身具备跨视角一致性；SyncDreamer 用同步的多视图生成保证背面也讲得通。它们的代价是推理成本随视图数线性增长，且多视图模型本身的训练数据要求高。另一个错位是 SDS 的梯度方差：单视角单噪声样本的梯度噪声很大，需要大量采样平均，训练时间远长于直接监督。Variational Score Distillation 把单点梯度换成分布层面的优化，用粒子分布近似 3D 参数的后验，缓解了 SDS 的过平滑与多样性不足，代价是维护多个粒子实例，显存与计算翻倍。

具体例子：用 SDS 从文本生成一个椅子，正面视角收敛良好，但侧面扶手出现“双层”结构，因为正面梯度与侧面梯度在扶手区域给出矛盾的法线方向。判断方法是渲染多视角法线图并检查跨视角一致性；若不一致，说明 2D 先验的视角间缺乏约束，应引入多视图扩散或显式的几何正则，而不是继续调 SDS 的学习率。系统代价上，SDS 类方法把 2D 扩散模型的推理纳入训练循环，每步都要前向扩散模型，训练吞吐受扩散模型推理速度限制，这是与直接 3D 监督方法最本质的工程差异。

七 · 潜变量表示与网格 tokenization 的接口细节

结构化 3D 潜变量 SLAT 把 3D 资产表示为稀疏的体素锚点集合，每个锚点携带局部几何与外观潜变量，再由解码器还原为三平面或高斯。它的机制是把“在哪里有东西”与“那里长什么样”解耦：锚点位置由稀疏占据决定，局部潜变量由扩散模型生成。这样做的代价是锚点分辨率固定，细长结构可能落在锚点之间被丢失；且锚点之间的潜变量需要空间一致性约束，否则相邻锚点解码出的局部表面在接缝处错位。

网格 tokenization 走的是另一条路：把三角面序列化成 token 序列，用仅解码器 Transformer 自回归生成。MeshGPT 与 MeshAnything 系列的核心机制是把面片顶点按顺序编码，模型学习面片之间的邻接关系。容易错的细节是 token 顺序的敏感性：同一网格的不同面片遍历顺序会产生不同的 token 序列，若训练数据中顺序不规范，模型学到的邻接统计被稀释。MeshAnything V2 用相邻面片 tokenization 缓解这一问题，让序列顺序与几何邻接一致。失败模式是生成长序列时的误差累积：一个面片预测错位，后续面片全部偏移，表现为网格出现裂缝或自交。系统代价是自回归生成的串行性，生成长序列的时间随面片数线性增长，且无法并行。

PBR 材质是这些表示的下游接口：生成资产要能重光照，必须输出反照率、粗糙度、金属度等通道，而不是烘焙颜色。Hunyuan3D 2.1 一类工作把 PBR 材质生成纳入流程，代价是材质通道的监督数据稀缺，且材质与几何的耦合容易出错——粗糙度贴图若与几何法线不匹配，重光照时高光位置会漂移。工程判断是：若下游需要可重光照资产，潜变量表示必须预留材质通道，而不是事后从颜色反推；网格 tokenization 路线则需要在 token 中编码材质索引，否则材质与面片的对应关系丢失。

场景一致性是长距离生成的另一处账本：单物体生成不涉及全局对齐，但场景生成（Text2Room、WonderWorld、WorldGen）需要保证相机移动时几何不漂移。机制上通常用增量式生成加全局优化，每一步生成局部几何后与已有场景对齐，代价是对齐误差随步数累积，表现为远处墙面弯曲。判断方法是闭环检测：相机绕一圈回到起点，若渲染图与起点不一致，说明漂移已发生，需要引入全局位姿优化或分层场景图，而不是继续增加生成长度。
