二 · 从积分到离散：体渲染公式的采样结构与代价

速查表里那条 NeRF 体渲染积分是连续形式，工程实现必须把它变成有限项求和，这一步的离散化方式直接决定梯度是否稳定、显存是否够用。连续式写作 \(C(\mathbf{r})=\int_{t_n}^{t_f}T(t)\sigma(\mathbf{r}(t))\mathbf{c}(\mathbf{r}(t),\mathbf{d})\,dt\)，透射率 \(T(t)=\exp(-\int_{t_n}^{t}\sigma(\mathbf{r}(s))ds)\)。分层采样把 \([t_n,t_f]\) 切成 \(N\) 个区间，在每个区间内均匀抽一个点 \(t_i\)，再按距离排序，得到离散近似 \(C\approx\sum_{i=1}^{N}T_i(1-\exp(-\sigma_i\delta_i))\mathbf{c}_i\)，其中 \(T_i=\exp(-\sum_{j

分层采样本身引入一个系统代价：粗网络和细网络两轮前向意味着同一批射线要跑两次 MLP，显存占用翻倍。重要性采样把细网络的采样点集中在粗网络权重 \(w_i=T_i\alpha_i\) 高的区段，用逆变换采样从分段常数 PDF 中抽点，这要求对 \(w_i\) 做归一化并构造累积分布，是一段不可微的宿主端代码。工程上常见的失败模式是把这段采样写进 autograd 图里，导致每次迭代都保留整条采样路径的计算图，显存随 \(N\) 线性增长。正确做法是用 torch.no_grad() 包裹采样索引计算，只让 \(\sigma\) 和 \(\mathbf{c}\) 的前向参与反传。

一个具体例子：单条射线 \(N=64\) 粗采样加 128 细采样，分辨率 \(800\times800\)，每像素一条射线，则单张图前向需要 \(800\times800\times192\) 次 MLP 调用。若 MLP 是 8 层 256 宽，单次前向约 \(8\times256^2\) 次乘加，总量在 \(10^{11}\) 量级，这就是为什么原始 NeRF 训练以天计。多分辨率哈希编码 \(h(\mathbf{x})=\bigoplus_{l=1}^{L}\mathrm{hash}_l(\lfloor\mathbf{x}\cdot2^l\rfloor)\) 把这件事压到可接受范围：查表是 \(O(1)\) 内存访问，MLP 只剩两层，单次前向从数百次乘加降到几十次。代价转移到显存——\(L\) 层、每层 \(2^l\) 分辨率的哈希表，参数量随层数线性增长，且哈希冲突会让远处细节共享表项，表现为高频纹理的糊化。这是编码换容量的典型权衡，不是免费午餐。

三 · 3DGS 投影：协方差变换与 \(\alpha\) 混合的顺序陷阱

3D 高斯泼溅的公式 \(C=\sum_{i\in\mathcal{N}}\mathbf{c}_i\alpha_i\prod_{j=1}^{i-1}(1-\alpha_j)\) 与 \(\Sigma'=JW\Sigma W^{\top}J^{\top}\) 是两条必须成对理解的式子。前者是前向到后的 over 合成，后者把世界空间的三维协方差投影到屏幕空间。\(\Sigma'\) 的计算里 \(W\) 是视图变换的旋转部分，\(J\) 是透视投影在均值点处的雅可比。雅可比近似在高斯离相机很近或视场角很大时失效：投影后的二维高斯不再严格是椭圆，边缘出现拉伸。工程上的补救是把近平面裁剪做在投影之前，丢弃均值深度小于近平面阈值的高斯，而不是让雅可比去处理极端透视。

顺序陷阱在于 \(\prod_{j=1}^{i-1}(1-\alpha_j)\) 要求高斯按深度排序。光栅化器通常按 tile 分块，每个 tile 内对覆盖该块的高斯排序。如果两个高斯深度几乎相同但排序不稳定，同一像素在不同帧的合成顺序会翻转，表现为闪烁。这不是数值精度问题，而是排序键的构造问题——用 16 位定点深度键在远距离场景会碰撞，必须用 32 位或按 tile 做局部排序。另一个易错点是 \(\alpha_i\) 的定义：3DGS 里 \(\alpha_i\) 是二维高斯在像素中心的值乘以不透明度，不是体渲染里的 \(1-\exp(-\sigma\delta)\)。把两者混用会让不透明度语义错位，训练时梯度尺度失配。

系统代价方面，\(\Sigma'\) 的求逆发生在每个高斯每次前向，\(2\times2\) 矩阵求逆本身便宜，但 tile 内高斯的重复计算是瓶颈。一个 \(1080p\) 场景若每像素覆盖 50 个高斯，总混合次数在 \(10^8\) 量级，显存带宽而非算力成为限制。失败模式是 densify 阶段高斯数量爆炸：梯度阈值和尺度阈值设得太松，一个纹理区域会被拆成上千个微小高斯，光栅化时间线性上升而视觉收益递减。工程判断是给每个 tile 设高斯数量上限，超出部分按不透明度截断，这比全局调阈值更可控。

具体例子：\(\Sigma'=JW\Sigma W^{\top}J^{\top}\) 中若 \(\Sigma\) 是各向异性很强的细长高斯（比如沿墙面延伸），投影后在一个视角下可能退化成接近线状，二维协方差的特征值比达到 \(10^3\) 量级，此时 \(\alpha\) 在垂直方向迅速衰减，光栅化器若用固定半径的包围盒会漏掉贡献。正确做法是按 \(\Sigma'\) 的特征值开方取 \(3\sigma\) 半径，且半径上限受 tile 尺寸约束。

四 · SDF 到密度：NeuS 的 \(\alpha\) 变换与 Eikonal 项的耦合

NeuS 的公式 \(\alpha_i=\max((\Phi(s_{i+1})-\Phi(s_i))/\Phi(s_{i+1}),0)\) 是把符号距离 \(s\) 通过 logistic 累积分布 \(\Phi\) 转成不透明度的无偏变换。这里 \(s_i=f(\mathbf{x}(t_i))\) 是 SDF 值，\(\Phi\) 是 sigmoid。这个式子的分母是 \(\Phi(s_{i+1})\) 而不是 \(\Phi(s_i)\)，这是保证无偏性的关键：它让 \(\alpha_i\) 对应的是从 \(t_i\) 到 \(t_{i+1}\) 区间内被表面遮挡的概率质量。写错分母会让近表面区域的 \(\alpha\) 系统性偏大，表面看起来“胖”一圈，且这种偏差随采样间距变化，训练时表现为几何在不同分辨率下不一致。

损失 \(\mathcal{L}=\mathcal{L}_{\mathrm{rgb}}+\lambda\|\nabla f\|-1\|^2\) 里的 Eikonal 项约束 SDF 梯度模长为 1，这是 SDF 作为距离场的前提。\(\lambda\) 的取值直接决定几何平滑度与细节保留的平衡：\(\lambda\) 过大时梯度被强行拉平，尖锐边缘被磨圆；\(\lambda\) 过小时 SDF 退化成任意标量场，\(\alpha\) 变换失去几何意义，表面出现孔洞。工程上常见的失败模式是在训练初期就开大 \(\lambda\)，此时 \(\mathcal{L}_{\mathrm{rgb}}\) 还没收敛，Eikonal 项把场拉向平凡解 \(f\equiv0\)，整片区域密度均匀，渲染出来是一团雾。正确顺序是先让颜色 loss 主导若干步，再逐步升 \(\lambda\)。

具体机制上，\(\alpha_i\) 的区间求和意味着采样间距 \(\delta\) 必须与表面尺度匹配。若 \(\delta\) 远大于表面曲率半径，相邻采样点跨过整个表面，\(\Phi(s_{i+1})-\Phi(s_i)\) 接近零，表面被漏掉。这是薄结构（叶片、栏杆）重建失败的典型原因，解决办法是在粗采样后按 SDF 值做一次二分细化，把采样点集中到 \(s\) 变号的位置附近。代价是每个区间多几次 \(f\) 的求值，前向成本上升，但相比全局加密采样更省。

一个具体例子：DMTet 的网格提取 \(x_e=x_a+\frac{s_a}{s_a-s_b}(x_b-x_a)\) 与 NeuS 的 \(\alpha\) 变换共享同一个 SDF 场。若 \(\alpha\) 变换的分母写错，从同一 SDF 提取的网格顶点位置会系统性偏移，表现为渲染图和提取网格对不上。调试时应当用同一组 \(s_v\) 分别跑体渲染和 marching tetrahedra，比对表面位置，这是定位分母错误最快的手段。

五 · 蒸馏采样：SDS、VSD、ISM 的梯度结构与失效模式

SDS 的梯度 \(\nabla_\theta\mathcal{L}_{\mathrm{SDS}}=\mathbb{E}_{t,\epsilon}[w(t)(\epsilon_\phi(x_t;y,t)-\epsilon)\partial x/\partial\theta]\) 里，\(\epsilon_\phi\) 是冻结的预训练扩散模型预测的噪声，\(\epsilon\) 是加进去的真实噪声，两者之差乘以 \(\partial x/\partial\theta\) 把 2D 分数函数回传到 3D 参数。这个式子的工程含义是：它并不要求扩散模型对 \(x\) 的似然可算，只需要噪声预测这一个量。代价是梯度方差极大——单次 \(t,\epsilon\) 采样的梯度方向噪声很重，必须靠大 batch 和 EMA 平滑。失败模式是过度饱和：\(w(t)\) 在低噪声段权重高时，模型会把颜色推向扩散模型先验的均值，产生塑料感的过曝表面，细节被抹平。

VSD 把 \(\epsilon\) 换成 \(\epsilon_\psi(x_t;c,t)\)，即一个随 \(\theta\) 在线训练的副本模型，梯度变成 \(\mathbb{E}[w(t)(\epsilon_\phi-\epsilon_\psi)\partial x/\partial\theta]\)。这相当于用副本模型吸收 \(\theta\) 的分布偏移，主模型只负责把副本拉向真实先验。机制上这是一个 minimax：副本拟合当前 3D 分布，主模型最小化与先验的差距。系统代价是多一份扩散模型的显存和一次额外前向，训练吞吐下降明显。失效模式是副本欠拟合：\(\psi\) 更新太慢时，\(\epsilon_\psi\) 退化成常数偏置，VSD 退化为带偏置的 SDS，颜色整体偏移。

ISM 的损失 \(\mathcal{L}_{\mathrm{ISM}}=\mathbb{E}_t\|\epsilon_\phi(x_t;y,t)-\epsilon_\phi(x^{\mathrm{inv}}_t;y,t)\|^2\) 用可逆采样构造 \(x^{\mathrm{inv}}_t\)，比较同一模型在两个时间点上的噪声预测，避免显式构造 \(\epsilon\)。这个式子的细节在于 \(x^{\mathrm{inv}}_t\) 必须由 \(x_0\) 经确定性 ODE 反演得到，若用随机采样反演，两次预测的差异混入了随机性，梯度变成噪声。工程判断是：ISM 对采样器的确定性要求高于 SDS，换采样器必须重验。

具体例子：SDS 训练一个场景时，若 \(\partial x/\partial\theta\) 来自可微渲染器，而渲染器本身有近似（比如软光栅的梯度截断），则梯度在遮挡边界处不连续。表现为物体轮廓处的颜色出现条带状伪影，且随视角变化游走。定位方法是关掉扩散项只留渲染 loss，看伪影是否消失——若消失则问题在 \(\partial x/\partial\theta\) 的连续性，而非蒸馏本身。

六 · 潜空间与结构化表示：SLAT、三平面、双 DiT 的维度账

SLAT 的式子 \(\mathbf{z}_t=\mathbf{z}_0+(1-t)\epsilon\)、\(v_\theta(\mathbf{z}_t,t)=\epsilon-\mathbf{z}_0\) 是 flow matching 的参数化，注意时间方向是 \(t=1\) 为纯噪声、\(t=0\) 为数据，与常见 diffusion 的 \(t\) 定义相反。这个符号约定一旦搞反，训练 loss 会收敛到一个平凡解：模型学会输出常数速度，生成结果全是均值形状。工程上必须在数据加载和采样器两处统一约定，并在单元测试里用已知的 \(\mathbf{z}_0,\epsilon\) 验证 \(v_\theta\) 的输出符号。SLAT 的结构化在于潜变量按空间锚点组织，每个锚点携带局部几何与外观特征，解码时按锚点位置聚合，这让生成器可以处理非均匀分布的点云而非规则网格。

三平面公式 \(F(\mathbf{x})=\mathrm{MLP}(\mathrm{interp}(T_{xy},\mathbf{x}),\mathrm{interp}(T_{xz},\mathbf{x}),\mathrm{interp}(T_{yz},\mathbf{x}))\) 把三维查询分解为三次二维插值。机制上这是用三个正交平面存储特征，查询时投影到各平面做双线性插值再拼接。代价是平面分辨率决定细节上限：\(512^2\) 的平面在物体表面曲率高的区域会出现平面内混叠，表现为沿坐标轴方向的条纹。失败模式是平面间特征不一致——三个平面独立生成时，同一空间点的三次插值可能给出矛盾的特征，MLP 被迫学一个折中，表面出现接缝。解决办法是在生成器里加平面间的一致性正则，或让 Transformer 在生成三平面时共享注意力。

双 DiT 的 \(\mathcal{L}=\mathcal{L}_{\mathrm{shape}}+\lambda\mathcal{L}_{\mathrm{PBR}}\)、\(\mathcal{L}_{\mathrm{PBR}}=\|\hat{a}-a\|^2+\|\hat{r}-r\|^2+\|\hat{m}-m\|^2\) 把形状和材质分开监督。这里 \(\hat{a},\hat{r},\hat{m}\) 分别是反照率、粗糙度、金属度。易错细节是材质监督的坐标系：PBR 参数定义在 UV 空间，而形状在三维空间，若 UV 展开在训练中变化，材质 loss 的对应关系断裂。工程上必须固定 UV 展开或让材质预测与 UV 解耦，否则 \(\mathcal{L}_{\mathrm{PBR}}\) 会在展开接缝处产生高梯度，把反照率拉花。\(\lambda\) 的取值决定材质是否被形状主导：\(\lambda\) 太小时材质退化为常数，金属感丢失；太大时形状被材质噪声干扰。

七 · 世界扩展与资产管线：增量更新的稳定性细节

高斯泼溅世界扩展 \(\mathcal{G}_{t+1}=\mathcal{G}_t\cup\mathrm{Densify}(\mathcal{G}_t,\hat{I}_{t+1})\) 的细节在于“并集”不是简单追加：新视角带来的高斯必须与已有高斯在重叠区域做一致性检查，否则同一表面被两套高斯重复表示，渲染时 over 合成出现双层边缘。机制上应当在 densify 前用已有高斯渲染 \(\hat{I}_{t+1}\) 的预测图，与真实图做残差，只在残差高的区域增密。代价是每帧多一次渲染前向，且残差阈值决定增密速率——阈值太低会让高斯数量随视角数线性膨胀。

迭代式房间补全 \(\mathcal{M}_{t+1}=\mathcal{M}_t\cup\mathrm{BackProject}(D_t,I_t,\mathbf{c}_t)\) 的失败模式是深度反投影的尺度漂移：单目深度估计的相对深度在不同帧之间尺度不一致，直接反投影会让墙面在多次迭代后错位。工程判断是维护一个全局尺度因子，用已知平面或相机基线做约束，而不是信任每帧的绝对深度。视频驱动物理参数估计 \(\theta^*=\arg\min_\theta\sum_t\|\mathrm{Render}(\mathrm{Sim}_\theta(x_0,t))-I_t\|^2\) 的细节是可微模拟器的梯度在接触瞬间不连续，优化会在碰撞时刻震荡，通常需要时间上的梯度平滑或分阶段优化。

资产清洗管线 \(\mathcal{D}=\{(M_i,I_i,\ell_i)\}\)、\(\ell_i=\mathrm{CLIP}(I_i)\) 的代价是 CLIP 嵌入对渲染视角敏感，同一资产不同视角的嵌入差异可能大于不同资产之间的差异，导致聚类失效。工程上应当对每个资产多视角取平均嵌入，而非单视角。UV 展开加 PBR 分解的 loss \(\mathcal{L}_{\mathrm{PBR}}=\sum_{v\in\mathcal{V}}\|\hat{\mathbf{a}}(u_v,v_v)-\mathbf{a}_v\|^2+\|\hat{r}_v-r_v\|^2+\|\hat{m}_v-m_v\|^2\) 里，求和遍历的是可见顶点集 \(\mathcal{V}\)，遮挡区域的材质没有监督，解码器会自由发挥，表现为背面材质与正面不一致。解决办法是在训练时随机翻转法线或补渲染背面视角，把 \(\mathcal{V}\) 扩到全表面。

落到一个具体机制上：所有这些增量式子共享同一个工程约束——新信息与旧表示的融合必须在一个统一的坐标系和尺度下完成。无论是高斯的并集、网格的并集还是深度的反投影，坐标系漂移和尺度漂移是增量管线最主要的失效来源，而它们都不会在单帧指标上暴露，只在多帧累积后显现。判断一个增量管线是否可靠，看它是否显式维护了全局对齐状态，而不是每帧独立估计。
