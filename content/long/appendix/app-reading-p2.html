一 · 从“读得懂”到“跑得动”：四阶段路线的检查点怎么落成可验证动作

阅读路线的四阶段不是四个书单，而是四组可被检验的状态。第一阶段的检查点只有一个：能否把“多视角 RGB 损失经体渲染积分反传到 3D 场参数”这条链在纸上走通一遍。具体做法是拿 NeRF 的 5D 函数 F(x,y,z,θ,φ)→(RGB,σ)，沿一条相机射线采样 N 个点，写出离散化的 alpha 合成式，然后对每个采样点的颜色与密度求偏导，确认梯度能穿过积分号回到 MLP 权重。走不通这条链，后面读哈希编码、读 3DGS 的排序混合都会变成背结论。

第二阶段的检查点是“表示替换实验”：把同一个场景分别用大 MLP、多分辨率哈希表、显式高斯三种表示各写一遍前向，比较三者的内存—带宽—算力分布。哈希编码的机制是把坐标在 L 个分辨率层级上量化后哈希到固定大小的表项，拼接特征再过一个很小的 MLP；它的代价不在算力而在表项查表的随机访存，冲突由多层级与梯度平均自然消解，但层级数 L 与表大小 T 直接决定显存占用与缓存命中率。3DGS 的机制是把场景表示成一堆带位置、协方差、不透明度、球谐颜色的 3D 高斯，投影到屏幕、按深度排序、做 alpha 混合；它的代价从“每像素多次 MLP 前向”转移到“每帧排序 + 高斯数量随致密化增长”，显式、可并行、可微，但排序是全局同步点。

第三阶段的检查点是“论文复现的最小闭环”：给定一篇论文，能说出它替换了前作的哪一个模块、替换后哪一项指标会动、哪一项代价会涨。第四阶段的检查点是“工程取舍表”：面对一个具体需求，能在表示、渲染器、监督信号、数据四个维度上给出选择并说明放弃项。四阶段之间不是线性递进，而是每进入下一阶段都要回头重读上一阶段的一篇论文，因为新阶段的失败模式往往暴露了旧阶段被忽略的细节。

二 · 一个容易错的细节：NeuS 的 σ(x)=αΨ_β(−f(x)) 里 β 到底在控制什么

NeuS 把密度定义为 SDF 经 logistic 变换后的概率密度：σ(x)=αΨ_β(−f(x))，其中 f 是 SDF、Ψ_β 是 sigmoid，零等值面自然成为表面。VolSDF 走的是同一条思路的另一个版本：α(x)=Ψ_β(−f(x))，Ψ_β 是 scaled CDF，β 控制表面厚度，密度在表面附近集中、远离表面趋于 0。这两个式子长得像，但容易错的地方在于把 β 当成“训练超参”随手调大调小。

β 的物理含义是表面过渡带的宽度：β 越大，sigmoid 或 CDF 越陡，密度越集中在零等值面附近，表面越“硬”；β 越小，过渡带越宽，体渲染积分在表面附近采样到的 alpha 越平滑，梯度越不容易在薄壳上消失。训练早期 β 取小值是为了让梯度有足够的空间穿过表面区域，训练后期 β 增大是为了把表面收紧。把 β 一开始就设得很大，常见失败模式是：渲染损失下降很快但几何出现大量漂浮碎片，因为密度只在极薄的壳上有响应，采样点稍偏就落进零密度区，梯度信号断掉。

$$\sigma(x)=\alpha\,\Psi_\beta\big(-f(x)\big),\qquad \alpha(x)=\Psi_\beta\big(-f(x)\big)$$

具体例子：一个用 NeuS 重建的物体，若在训练前 20% 迭代就把 β 拉到接近硬表面的量级，射线在表面附近的采样点落在过渡带之外的概率上升，体渲染的 alpha 合成近似退化为“全有或全无”，此时颜色损失对 f 的梯度只在少数命中采样点上非零，SDF 的零等值面会在没有监督的区域自由漂移。正确做法是让 β 随训练进度单调增，并把采样策略（分层采样 + 重要性采样）与 β 的当前值绑定：过渡带宽时采样可以稀，过渡带窄时必须加密表面附近的采样点。

这个细节之所以容易错，是因为它同时牵动三件事：密度的空间集中度、梯度的可达性、采样点的有效性。三者中任意一个失配，表现都是“损失在降但网格在烂”，而损失曲线本身不会告诉你原因。工程判断是：把 β 当成与采样密度耦合的调度量，而不是一个独立的损失权重。

三 · 哈希编码的冲突账：多分辨率为什么能“自然消解”而不是“消除”

Instant NGP 的多分辨率哈希编码用 L 个分辨率层级上的可学习哈希表代替大 MLP 承担高频细节：坐标在每一层量化并哈希到固定大小表项，拼接 L 层特征后只过一个很小的 MLP。哈希冲突由多层级与梯度平均自然消解——注意是“消解”不是“消除”。单层哈希表里两个不同坐标落到同一表项，它们的梯度会叠加，表项值变成两者的折中；但当 L 层同时存在时，两个坐标在粗层可能共享表项、在细层大概率落到不同表项，细层提供了区分度，粗层提供了平滑先验，冲突的破坏被多层结构摊薄。

代价是显存与带宽。表大小 T 与层级数 L 的乘积决定显存占用；每次查询要做 L 次哈希与 L 次随机访存，这些访存不连续，缓存命中率随 T 增大而下降。工程上的失败模式很具体：把 T 设得过大以追求细节，结果训练吞吐被随机访存拖垮，GPU 利用率掉到很低，而画面细节的收益远小于吞吐损失；把 L 设得过大而每层表很小，冲突率上升，细层区分度被粗层平滑掉，表现为高频纹理糊成一片。

配置倾向机制后果典型失败表现
T 过大、L 适中随机访存增多、缓存命中下降训练吞吐下降，细节收益递减
T 过小、L 过大单层冲突率升高高频细节被多层平均抹平
L 过小缺少粗层平滑先验细层冲突直接暴露为噪点

具体例子：同一场景用两套配置训练，一套把表压到很小、层级堆高，另一套表放大、层级适中。前者在薄结构（栏杆、叶片）上出现块状伪影，因为细层表项被多个坐标共享，梯度平均把不同结构的特征混在一起；后者在同样结构上更干净，但每步迭代耗时明显上升。判断依据不是“哪个 PSNR 高”，而是“单位算力换来的细节增量是否为正”。

四 · 3DGS 的五段流水与致密化的账：显式表示把代价搬到了哪里

3DGS 的流水可以拆成五段：高斯基元—投影—排序—混合—致密化。前四段是每帧渲染的固定路径，第五段是训练期的自适应增删。投影把 3D 协方差经雅可比近似映射到屏幕空间的 2D 协方差；排序按深度对屏幕空间的高斯做全局排序；混合按 alpha 合成逐像素累加；致密化在梯度大的区域分裂高斯、在透明度过低的区域剪枝。

容易错的细节在致密化的判据上：梯度大不等于“该加高斯”，它可能是该区域的高斯尺度不合适、也可能是该区域本就不该有几何。把梯度阈值调低会让高斯数量爆炸，显存与排序开销同步上涨；调高则欠拟合薄结构。剪枝的判据同样有陷阱：不透明度低的高斯可能是尚未训练充分的有效几何，过早剪掉会让该区域失去梯度来源，形成“越剪越空”的正反馈。

$$\Sigma' = J\,W\,\Sigma\,W^{\top}J^{\top}$$

上式是 3D 协方差到屏幕 2D 协方差的近似投影，J 是投影变换的雅可比，W 是视角变换。它的近似性在视角接近掠射时变差，表现为边缘高斯被拉成条状伪影。工程代价是：显式表示让渲染可并行、可微，但每帧的全局排序是同步点，高斯数量增长直接抬高排序与混合的固定开销；这与 NeRF 类方法“每像素多次 MLP 前向”的代价结构完全不同，前者随高斯数线性涨，后者随采样数与网络宽度涨。

具体例子：一个包含大量细碎植被的场景，致密化在叶片边缘反复分裂高斯，高斯总数在训练中期快速上升，排序耗时成为帧时间主项；此时正确的动作不是继续调低梯度阈值，而是检查投影近似在掠射角下的误差是否被误判为“需要更多高斯”，并考虑对边缘高斯做尺度正则。判断依据是“高斯数量的边际收益是否还为正”，而不是“画面是否还在变好”。

五 · 蒸馏家族的梯度账：SDS、链式法则与 VSD 的差别落在哪一项

DreamFusion 用可微渲染器把 3D 表示渲染成图，加噪后送进冻结的 2D 扩散模型，用“预测噪声 − 实际噪声”作为梯度方向更新 3D 参数，CFG 增强文本对齐。Score Jacobian Chaining 把同一件事写成更显式的形式：渲染图 x 是 3D 参数 θ 的函数，2D 扩散模型给出图像得分 ∇log p_t(x)，用链式法则乘渲染雅可比 ∂x/∂θ 得到 θ 空间的得分，再用退火 Langevin 动力学采样。

$$\nabla_\theta \log p_t(\theta)=\frac{\partial x}{\partial \theta}^{\top}\,\nabla_x \log p_t(x)$$

容易错的细节是：SDS 的“预测噪声 − 实际噪声”并不等于图像得分本身，它是得分的一个带噪估计，且依赖于所加噪声的强度 t。把 t 设得过大，梯度方向被噪声主导，3D 参数更新变成随机游走；设得过小，扩散模型几乎不提供语义修正，退化为普通渲染损失。VSD 的改动在于把 3D 参数视为分布 q(θ)，用一个可学习的粒子（LoRA）近似 q 的得分，梯度等于预训练扩散得分减粒子得分，等价于最小化 q 与文本条件分布的 KL。差别落在“减号后面那一项”：SDS 减的是噪声残差，VSD 减的是一个可学习的分布得分，后者缓解了 SDS 的模式坍塌与过饱和。

工程代价：SDS 每次更新要多次前向冻结扩散模型，显存与算力开销大；VSD 额外维护一个 LoRA 粒子，训练更稳但状态更多。失败模式具体表现为：只用 SDS 且 CFG 权重偏高时，渲染图出现过饱和与重复纹理，因为高 CFG 放大了条件得分而抑制了先验得分；VSD 在粒子欠训练时梯度偏差大，表现为几何抖动。具体例子：DreamGaussian 用 3DGS 作为表示、SDS 直接优化高斯参数，收敛后从高斯提取网格再做 UV 空间纹理精修，两阶段总时间约 2 分钟——这个数字的意义不是“快”，而是说明显式表示 + 蒸馏的组合把优化预算压到了可交互量级，代价是几何精度受高斯致密化策略制约。

六 · 前馈与原生表示的对照读法：三平面、点云、隐式函数各自把一致性放在哪

EG3D 把 3D 场分解成三个正交的 2D 特征平面，生成器用 2D 卷积生成三平面，查询 3D 点时插值拼接再送小 MLP 解码密度与颜色；3D 一致性由三平面共享与 2D 判别器共同约束。这里的机制要点是：三平面把 3D 查询降维成三次 2D 插值，算力从“3D 卷积”搬到“2D 卷积 + 插值”，代价是平面分辨率决定细节上限，且三个平面的正交假设对薄壳结构不友好。

Point-E 走两阶段：先用文本到图像扩散生成一张图，再用图像到点云扩散生成 1024 个点，点云扩散用 Transformer 去噪、条件为图像嵌入。它的“一致性”不在多视图，而在“图像作为中间桥”，代价是点云无序、缺少表面拓扑，后续要接网格化。Shap-E 训练编码器把 3D 资产映射成隐式函数的潜变量，在潜空间做扩散，解码器把潜变量变回隐式函数再提取网格；一致性由编码器—解码器的可逆性约束，代价是潜空间扩散的多样性受编码器容量限制。

具体例子：同一个文本提示，EG3D 类方法给出的是固定视角下一致、但背面可能靠先验补的三平面场；Point-E 给出的是稀疏点云，形状轮廓对但表面不闭合；Shap-E 给出的是可提取网格的隐式函数，拓扑更完整但细节受潜变量维度制约。读这三篇时的检查点是：各自把“3D 一致性”放在生成器结构、中间桥、还是潜空间约束上，以及这个位置对应的失败模式是什么。工程判断落在“下游要什么”：要实时渲染选显式表示，要可编辑网格选隐式函数加提取，要快速原型选点云。
