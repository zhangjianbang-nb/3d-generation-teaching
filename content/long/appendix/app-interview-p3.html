一 · 三十题速查：按五类归并的题面索引

附录里的三十道题不是三十个孤立知识点，它们按考察意图可以压成五类：表示选型、SDS 偏差、多视图一致性、前馈模型、拓扑/PBR/物理。速查的价值在于：看到题面第一眼就能判断面试官在测哪一类能力，从而决定回答的骨架是“链路推导”还是“工程权衡”。下表把题面、考察类别、必须落到的最小要点三者对齐，答题时缺哪一格就在哪一格失分。

二 · 三组对照：把易混题并排拆开

第一组对照是 NeuS 与 VolSDF。两者都把 SDF 转成密度，转换都借累积分布函数，但核不同：VolSDF 用 Laplace 分布，NeuS 用 logistic 分布，于是 α/β 的参数化含义不同，β 退火的行为也不同。共同依赖是 Eikonal 正则与退火 schedule。答题时若只说“一个用 Laplace 一个用 logistic”而不说“退火 schedule 是隐形超参”，就停在名词层。机制上，SDF 到密度的映射写作：

$$\sigma(\mathbf{x}) = \alpha \cdot \Phi_\beta\big(-f(\mathbf{x})\big),\qquad \|\nabla f\| = 1$$

其中 Φ 是所选分布的 CDF，f 是 SDF，β 控制密度在零等值面附近的锐度。Eikonal 项约束梯度模长为 1，保证 f 近似真实符号距离，零等值面才是表面。失败模式很具体：β 过大，密度过渡带太宽，表面糊成雾；β 过小，密度在薄结构处接近阶跃，采样不足导致噪点甚至训练发散。系统代价是退火 schedule 必须与采样密度、学习率一起调，属于“调不好就整场景崩”的隐形超参。

第二组对照是 SDS 与 VSD。SDS 的梯度可写成 2D 得分乘渲染雅可比的形式：

$$\nabla_\theta \mathcal{L}_{\mathrm{SDS}} = \mathbb{E}\Big[\big(\epsilon_\phi(\mathbf{x}_t;y,t)-\epsilon\big)\frac{\partial \mathbf{x}}{\partial \theta}\Big]$$

它只用当前 2D 扩散模型的得分，完全忽略“当前 3D 分布长什么样”，因此每个视角独立地被拉向 2D 先验，正面和背面各自合理、拼起来就是两张脸，即 Janus 问题。CFG 放大与随机相机只是缓解，不改变逐视角独立的本质。VSD 引入一个粒子模型 ε_ψ 去拟合当前 3D 分布，梯度里出现两个得分之差 (ε_φ−ε_ψ)，从变分/KL 视角看是在最小化 3D 分布与 2D 先验投影之间的散度，因而能缓解过饱和与多样性塌缩。代价是多一个模型要训、显存与调度复杂度上升。具体例子：同一提示词下 SDS 常给出高饱和、正面精细背面崩坏的资产，VSD 在多视角下颜色更收敛，但训练步数与显存开销明显更高。

第三组对照是前馈路线内部的“输出表示之争”：LRM 出三平面加 NeRF 渲染，GS-LRM 换成高斯输出头，MeshLRM 换成端到端可微网格。三者共享“一次前向、不逐物体优化”的骨架，差别在输出与梯度路径。GS-LRM 的好处是光栅化实时、显式可编辑；新问题是漂浮物、稳定性与显存。MeshLRM 的动机是“先出 NeRF 再提取”这一步不可微，梯度断在提取处，薄结构与拓扑容易坏；改成可微网格后梯度能回到顶点。代价是网格提取与拓扑处理进入训练回路，实现复杂度上升。答题时把“为什么换输出”与“换了以后新增什么失败模式”成对说出，才算完整。

三 · 自测题：十二道按链路追问

自测题的设计原则是每道题都要求“机制加代价”，只答名词不得分。下面十二题按五类分布，括号内是评分锚点。

  • NeRF 把 3D 变成像素的关键链路有哪四段？去掉透射率 T 会怎样？（5D 输入、体渲染积分与 T、分层采样与位置编码、渲染损失可微）
  • Instant-NGP 的哈希冲突为什么不会毁掉细节？L、T、F 各自变大时分别牺牲什么？（多分辨率分层、冲突由多层平均与梯度消化、三角权衡、小 MLP 只解码）
  • 写出 3DGS 的投影公式，并说明为什么必须按深度排序。（协方差分解、Σ'=J W Σ Wᵀ Jᵀ、排序加 alpha 合成、致密化与剪枝）
  • NeuS 的 β 退火设错会出现哪两类失败？Eikonal 正则约束的是什么？（表面糊与薄结构噪、‖∇f‖=1、零等值面、schedule 是隐形超参）
  • pixelNeRF 为什么不需要逐场景优化？它的特征是怎么进 MLP 的？（CNN 特征、3D 点投影采样、特征拼接、amortized 推理）
  • EG3D 三平面为什么比体素省内存？骨干是什么？（三平面双线性采样、平方对立方、StyleGAN2 加神经渲染加双判别器）
  • SDS 为什么会长出两张脸？SJC 的扰动和 ISM 的区间各自从哪个角度降方差？（逐视角独立、加噪到训练分布与 PAAS、DDIM 反演正反轨迹之差）
  • Magic3D 第二阶段为什么更细？VSD 与 SDS 的梯度差在哪一项？（DMTet 加可微渲染加 512 分辨率、探索与精修分离、ε_φ−ε_ψ）
  • MVDream 与 SyncDreamer 各自怎么让多视角一致？代价分别是什么？（4 视图 token 加 3D 自注意力、计算量四倍且视角数固定；16 固定视角加共享 3D 代价体、投影采样同步）
  • InstantMesh 的 LRM 与 FlexiCubes 各解决什么？CRM 为什么用卷积？（4 视图前向、可微提取、速度与拓扑折中；6 视图、卷积比全局注意力便宜）
  • TripoSR 半秒的工程来源有哪些？GS-LRM 换高斯后新增什么失败模式？（LRM 简化、三平面加 NeRF、大规模数据、混合精度；漂浮物、稳定性、显存）
  • TRELLIS 的 SLAT 为什么一套潜变量能解成高斯、网格与辐射场？Hunyuan3D 2.0 拆两个 DiT 的工程好处与风险？（稀疏体素加局部三平面、多解码；不同数据与目标、分别迭代、误差累积与接口对齐）

自测时建议用“三句话法”：第一句给机制链路，第二句给公式或伪代码思路，第三句给系统代价或失败模式。任何一题若第三句说不出来，说明只记住了名词，没有工程判断。

四 · 伪代码思路：把答题骨架写成可执行步骤

面试白板上最容易被要求“写个大概”的是 SDS 回路与 3DGS 光栅化的顺序依赖。前者考的是“得分如何经雅可比回到 3D 参数”，后者考的是“为什么排序不可省”。下面用伪代码思路表达，不写具体框架调用。

  • SDS 回路：采样相机位姿 → 从当前 3D 表示渲染出图像 x → 对 x 加噪到 x_t → 2D 扩散模型预测噪声 ε_φ → 取 (ε_φ−ε) 作为图像空间梯度 → 乘渲染雅可比 ∂x/∂θ 回传到 3D 参数 → 更新。关键点：雅可比由可微渲染器提供，噪声预测不直接更新 3D。
  • 3DGS 光栅化：对每个高斯做协方差分解 R S Sᵀ Rᵀ → 用视图与投影雅可比得 Σ'=J W Σ Wᵀ Jᵀ → 按深度排序 → 逐像素 alpha 合成。关键点：alpha 合成是顺序相关的非交换运算，排序错则遮挡关系错，颜色与梯度同时错。
  • 前馈重建：多视图图像过 ViT 提特征 → cross-attention Transformer 融合 → 输出三平面或高斯或网格潜变量 → 可微渲染出多视角 → 与真值图像算渲染损失 → 一次反向。关键点：没有逐场景优化循环，泛化靠大规模数据训练。

这三段伪代码的共同评分点是“梯度路径是否闭合”。SDS 若漏掉雅可比，梯度就断在图像空间；3DGS 若漏掉排序，合成结果不可微地错；前馈若漏掉可微渲染，输出表示就学不到几何。失败模式也由此派生：SDS 漏雅可比表现为几何不更新只改颜色；3DGS 漏排序表现为前后景闪烁；前馈漏渲染损失表现为潜变量塌缩成均值。

五 · 延伸阅读的取舍：按链路缺口补，不按论文列表刷

延伸阅读不该是“把三十篇论文都读一遍”，而应按自测中暴露的链路缺口定向补。缺口分四种：表示层缺口（说不清三平面、高斯、网格、SDF 之间的转换代价）、梯度层缺口（说不清可微渲染与雅可比）、先验层缺口（说不清 2D 扩散得分如何约束 3D）、工程层缺口（说不清显存、排序、退火 schedule 的代价）。补法不同：表示层缺口要重读 EG3D、Point-E、Shap-E 的表示对比；梯度层缺口要重读 NeRF 体渲染与 3DGS 投影推导；先验层缺口要并排读 SDS、SJC、VSD、ISM 的梯度形式；工程层缺口要重读 Instant-NGP 的 L/T/F 与 NeuS 的 β 退火。

一个具体的补法例子：若自测第四题答不出“β 过小为何发散”，不要泛读 SDF 综述，而是把 VolSDF 与 NeuS 的密度映射并排写一遍，亲手算 β 变小后零等值面附近密度梯度如何变大，再对照采样密度看数值稳定性。这样补的是机制，不是名词。再如自测第十一题答不出“GS-LRM 为何有漂浮物”，就去对照 3DGS 的致密化与剪枝策略，理解前馈输出高斯时缺少逐场景致密化，漂浮物来自无约束的初始高斯分布。延伸阅读的产出应是“一张自己画的梯度路径图加一张失败模式表”，而不是读书笔记。

工程判断上，三十题里真正区分候选人的不是“知不知道某个模型”，而是“能不能在给定约束下选表示并说出代价”。约束通常是三条：输出要不要可编辑网格、要不要实时渲染、要不要 PBR 重光照。要网格且要拓扑干净，前馈路线里 MeshLRM 与 InstantMesh 的 FlexiCubes 是候选，代价是提取复杂度；要实时且可编辑，GS-LRM 与 LGM 的高斯输出是候选，代价是漂浮物与显存；要 PBR 与引擎标准输入，Hunyuan3D 2.1 的三通道材质加 delighting 是候选，代价是管线里多一道去光照且误差会累积到纹理 DiT。把这三条约束与对应代价写成一张决策表，比背三十个模型名字更接近岗位真实需求。

最后落到一个具体机制：多视图一致性的题面几乎都会追问“视角数固定带来的代价”。MVDream 把 4 视图 token 拼进 3D 自注意力，跨视角互相看见，代价是计算量随视角数线性上升且视角数被训练分布锁死；SyncDreamer 用 16 个固定视角加共享 3D 代价体做投影采样同步，代价是视角集合不可自由扩展，超出集合的新视角要靠后续重建补。答题时若能把“一致性来自哪种跨视角信息通道”与“该通道锁死了什么自由度”成对说出，这道题就从背诵变成了工程判断。
