二 · 三道题的最小复现：从 5D 输入到像素的链路

60 分钟路线里的第一道题是“NeRF 为什么能从 2D 照片学出 3D”。复现的最小版本不需要训练，只需要把链路写成可执行的伪代码，并验证每一步的张量形状。关键在于理解：网络本身只回答“某个空间点的密度和颜色是多少”，真正把 3D 变成像素的是体渲染积分，而积分里的透射率 T 是让梯度能回传到 3D 参数的桥梁。

具体机制如下：给定相机位姿，沿每条光线采样 N 个点，每个点输入位置编码后的坐标（3 维）与视角方向（2 维），得到 5D 输入；MLP 输出该点的体密度 σ 与视角相关的 RGB。体渲染把颜色按权重累加：

$$ \hat{C}(r)=\sum_{i=1}^{N} T_i\left(1-e^{-\sigma_i \delta_i}\right)c_i,\quad T_i=\exp\left(-\sum_{j

其中 δ_i 是相邻采样点的间距。T_i 的乘积结构意味着前面的点会遮挡后面的点，这正是“从 2D 像素反推 3D 密度”的可微通道：渲染损失对 σ 和 c 的偏导会沿着 T_i 链式回传，密度大的位置获得更大梯度。分层采样（coarse 网络先找密度高的区间，fine 网络再集中采样）是工程上必须的，否则均匀采样在空白区域浪费大量查询。

容易错的细节在于位置编码的频率选择。位置编码把坐标映射到高频正弦基，目的是让 MLP 能表示细节；但频率过高会让远处或低纹理区域产生噪声，频率过低则表面糊。复现时若只改编码维度而不改采样数，会出现“损失下降但渲染图有雾”的失败模式：coarse 网络学到的密度分布被 fine 网络继承，但 fine 采样点没有覆盖真正的表面薄层，积分权重被摊薄。系统代价是每条光线两次前向，显存与时间都翻倍；最小复现里可以用 64 个 coarse 点加 128 个 fine 点，观察 T 曲线是否在表面处陡降。

三 · 哈希冲突与三个超参：Instant-NGP 的三角权衡

第二道题问“哈希表必然冲突，为什么还能记住细节”。答案不在哈希表本身，而在多分辨率分层：L 层不同分辨率的网格各自查表，冲突在单层内发生，但多层平均与梯度下降会把冲突“消化”成近似正确的特征。每一层有 T 个表项、F 个特征维度，分辨率从粗到细按几何级数增长。粗层负责低频形状，细层负责高频细节；冲突在细层更严重，但因为粗层已经提供了稳定的低频基底，细层的错误被约束在局部。

三个超参各管一件事：L 决定层数，即频率覆盖范围；T 决定每层表大小，即冲突概率与内存；F 决定每层特征维度，即表达能力与解码器负担。它们的三角权衡可以写成定性关系：冲突率随 T 减小而上升，细节容量随 L 与 F 增大而上升，但显存与查询带宽也随之上升。小 MLP 只做解码，把查表得到的多分辨率特征拼接后映射为密度与颜色，因此网络容量主要落在哈希表里，而不是 MLP 权重里。

失败模式很具体：若 T 太小而 L 太大，细层冲突密集，梯度会把不同空间位置的特征混在一起，表现为表面出现块状伪影或“记忆错位”；若 F 太小，解码器无法区分冲突后的混合特征，细节退化为平滑。复现时可以用一个固定场景，逐步减小 T 并观察伪影出现的阈值。系统代价是哈希表的随机访存，GPU 上表现为不规则的缓存命中率，查询延迟随冲突率上升。工程判断是：先定 F（通常较小），再按显存预算定 T，最后用 L 覆盖目标频率；不要同时调三个参数。

四 · 高斯投影与深度排序：3DGS 的协方差链路

第三道题是“3D 高斯如何投影到屏幕，为什么必须按深度排序”。3DGS 的每个高斯有中心 μ、协方差 Σ、不透明度 α 与球谐颜色。协方差由旋转与缩放分解：Σ = R S Sᵀ Rᵀ，其中 R 是旋转矩阵，S 是对角缩放。投影到屏幕时，先做视图变换 W，再用雅可比 J 近似透视投影的局部线性化：

$$ \Sigma' = J\,W\,\Sigma\,W^{\top}J^{\top} $$

Σ' 是屏幕空间的 2D 协方差，决定了高斯在像素上的椭圆覆盖范围。渲染时按深度排序后做 alpha 合成，前到后累加颜色与透射率。排序是必须的，因为 alpha 合成不是交换运算：若顺序错误，前景与背景的权重会错配，表现为边缘闪烁或半透明物体“穿透”。

容易错的细节是致密化与剪枝的触发条件。梯度大的高斯会被分裂或克隆，透明度过低或尺寸过大的会被剪枝；但若致密化过密，显存会爆炸，排序的基数变大，光栅化时间上升。失败模式是“漂浮物”：在欠约束区域，高斯被梯度推到空中形成孤立团块，排序后仍可见。复现时可以先固定致密化阈值，只改排序策略，观察同一场景在错误排序下的 alpha 合成差异。系统代价主要是排序与显存：高斯数量增长是显存的主要压力，排序是每帧的固定开销。

具体例子：一个半透明杯子后面放一个不透明球。若按中心深度排序，杯子的高斯可能被排到球后面，alpha 合成会把杯子颜色乘到球上，出现“杯子消失”的错觉。正确做法是按高斯中心的视图空间深度排序，并在致密化时限制单个像素覆盖的高斯数量。

五 · β 退火与 Eikonal：NeuS 的两类典型失败

NeuS 把 SDF 转成密度，β 是控制密度集中程度的参数。β 退火设错会出现两类典型失败：β 太大，密度在零等值面附近过于平缓，表面糊成一层厚雾，渲染图失去锐利边缘；β 太小，密度在薄结构处过度集中，梯度噪声大，薄结构出现噪点甚至发散。退火 schedule 是隐形超参：它决定了从“宽密度”到“窄密度”的过渡速度，太快会让优化在早期丢失薄结构，太慢则表面迟迟不收敛。

Eikonal 正则约束的是 SDF 的梯度模长：

$$ \left\|\nabla f\right\|=1 $$

它让 f 在空间中是“距离场”而非任意标量场，零等值面即表面。没有这个约束，网络可以学出一个任意形状的等值面，密度转换会失真。失败模式是：Eikonal 权重过大会压制颜色拟合，表面变得过于光滑；权重过小则等值面出现褶皱。复现时固定 β schedule，只改 Eikonal 权重，观察薄结构（如叶片边缘）的噪点与表面平滑度的权衡。

具体例子：一个带细杆的物体。β 太小且退火过快，细杆处的密度在早期被噪声主导，梯度把杆“打断”；β 太大则杆与背景的密度差不足，渲染图里杆变粗。工程判断是：先让 β 从较大值缓慢下降，Eikonal 权重从较小值逐步上升，二者同步退火，避免早期几何被过度约束。

六 · SDF 到密度的两种参数化：VolSDF 与 NeuS 的差别

VolSDF 与 NeuS 都把 SDF 转成密度，差别主要在转换函数与参数化。VolSDF 用 Laplace 分布的 CDF 把 SDF 映射为密度，α 与 β 控制分布的尺度；NeuS 用 logistic 分布的导数构造密度，β 控制集中度。两者共同依赖 Eikonal 正则与退火 schedule，但 α/β 的参数化不同，导致对薄结构的敏感度不同。

具体机制：VolSDF 的密度是 SDF 值的单调递减函数，远离表面时密度趋近于零；NeuS 的密度在零等值面附近达到峰值，两侧衰减。失败模式是：若 α 或 β 设得与场景尺度不匹配，密度在表面外的“尾巴”过长，渲染会出现半透明光晕；若过短，薄结构采样不足，出现空洞。系统代价是转换函数需要额外的数值稳定性处理，尤其在 SDF 值接近零时。

容易错的细节是退火与转换函数的耦合：VolSDF 的 β 与 NeuS 的 β 不是同一个量，迁移超参时不能直接照搬。复现时先用一个简单球体标定转换函数的尺度，再换到薄结构场景，观察光晕与空洞的边界。工程判断是：转换函数的参数应与场景的物理尺度绑定，而不是与网络容量绑定。

七 · SDS 的梯度与“两张脸”：逐视角独立的代价

SDS 的梯度形式可以写成：

$$ \nabla_{\theta}\mathcal{L}_{\text{SDS}}=\mathbb{E}_{t,\epsilon}\left[w(t)\left(\epsilon_{\phi}(x_t;y,t)-\epsilon\right)\frac{\partial x}{\partial \theta}\right] $$

其中 x 是渲染图，ε_φ 是 2D 扩散模型的噪声预测，∂x/∂θ 是渲染雅可比。它让 3D 参数 θ 沿着“让渲染图更像文本描述”的方向更新。问题是每个视角独立计算得分，视角之间没有一致性约束，于是模型会在不同视角长出不同的正面，形成“两张脸”（Janus 问题）。CFG 与随机相机只是缓解：CFG 放大文本条件，随机相机增加视角覆盖，但都没有在梯度里加入跨视角一致性。

具体例子：一个正面视角的渲染被 2D 模型判为“人脸”，背面视角也被判为“人脸”，两个视角的梯度各自把几何推向“正面”，结果物体前后各有一张脸。失败模式是几何在视角边界处撕裂，纹理在接缝处重复。系统代价是每次更新需要多次 2D 前向，计算量与视角数成正比。工程判断是：SDS 适合粗模探索，不适合直接产出干净表面；需要多视图一致性机制或后续精修。

八 · SJC 的扰动与 PAAS：把噪声加到训练分布

SJC 里的“扰动”是为了解决 SDS 在低噪声阶段得分不稳定问题。具体做法是把渲染图加噪到扩散模型训练分布对应的噪声水平，再用 PAAS（平均多个噪声样本的得分）降低方差。得分经渲染雅可比回传，与 SDS 同族，但扰动让 2D 模型在它“熟悉”的噪声区间工作，避免在干净图像上给出不可靠的梯度。

机制上，SJC 对每个视角采样多个噪声水平，平均得分后再回传；PAAS 的作用是减小单次采样的方差，让几何更新更稳。失败模式是：扰动过强会让渲染图丢失细节，梯度变成低频形状的推动；扰动过弱则回到 SDS 的不稳定区间。系统代价是每个视角多次前向，计算量上升。具体例子：一个细长物体，SDS 在低噪声下给出矛盾的边缘梯度，SJC 的扰动把边缘信息推到中噪声区间，梯度变得一致，细长结构不再被“折断”。

九 · Magic3D 的两阶段：探索与精修的分离

Magic3D 的第一阶段用低分辨率 NeRF 做粗模，第二阶段用 DMTet 加可微渲染做高分辨率精修。为什么第二阶段能比 DreamFusion 更细？因为探索与精修分离：粗模阶段用 SDS 快速找到大致形状与布局，精修阶段在显式表示上做可微渲染，分辨率更高，梯度更直接地作用在顶点与纹理上。DMTet 是可微的网格提取，允许梯度回传到几何。

具体机制：第一阶段低分辨率渲染降低每次迭代的采样成本，快速收敛到粗形状；第二阶段把粗模转成 DMTet，用高分辨率渲染损失与 SDS 联合优化。失败模式是：若粗模阶段形状错误，第二阶段会在错误拓扑上精修，误差被固化；若两阶段的分辨率跨度太大，接口处的尺度不匹配会导致表面裂缝。系统代价是两阶段的总时间远高于单阶段，但精修阶段的分辨率提升带来细节收益。工程判断是：粗模阶段宁可过平滑，也不要过细节，因为细节在第二阶段可以补，错误拓扑不能。

十 · VSD 与 SDS：粒子模型带来的多样性

VSD 与 SDS 的核心差别是：SDS 忽略当前 3D 分布，只用一个 2D 得分推动每个样本；VSD 加了一个粒子模型 ε_ψ，梯度里包含 (ε_φ − ε_ψ) 的差。这个差相当于在 2D 得分上减去当前 3D 分布的“平均得分”，从而在变分视角下优化 KL 散度。结果是过饱和与多样性差得到缓解：SDS 容易把所有样本推向同一个高得分模式，VSD 则保留样本间的差异。

具体机制：ε_ψ 在渲染图上训练，近似当前 3D 分布的得分；ε_φ 是文本条件的 2D 得分。梯度含两项之差，意味着只有当 2D 得分比当前分布的平均得分更“像文本”时才更新。失败模式是：若 ε_ψ 训练不足，差值噪声大，几何更新不稳定；若 ε_ψ 过强，梯度被拉回当前分布，文本条件失效。系统代价是额外的粒子模型训练与存储。具体例子：生成“一只狗”时，SDS 可能产出多个几乎相同的狗，VSD 则保留不同姿态与毛色，因为粒子模型惩罚了模式坍缩。

十一 · 显式网格与可微渲染：TextMesh 的工程差异

TextMesh 直接优化网格，与 DreamFusion 的 NeRF 路线相比，最大的工程差异是省掉了网格提取。DreamFusion 在 NeRF 上优化，最后需要用 marching cubes 提取网格，提取过程不可微，且提取参数（阈值、分辨率）会影响结果；TextMesh 用显式网格加可微渲染，SDS 梯度直接更新顶点与纹理，深度与法线条件帮助稳定几何。

具体机制：显式网格的顶点位置与纹理是可优化参数，可微光栅化把渲染图与梯度连起来。失败模式是：网格拓扑在优化中可能退化，出现自交或薄片；深度与法线条件若权重不当，会压制纹理细节。系统代价是光栅化的显存与时间随网格复杂度上升，但省掉了提取步骤的误差。具体例子：一个带凹陷的物体，NeRF 提取时凹陷可能被填平，TextMesh 直接优化顶点，凹陷得以保留，但需要正则防止自交。

十二 · 前馈工厂的工程取舍：从 LRM 到 TRELLIS

前馈路线把“逐物体优化”换成“一次前向”。LRM 用 ViT 加 cross-attention Transformer，输入图像输出三平面，用多视角渲染损失在 50 万物体上训练，因此推理时不需要逐场景优化。TripoSR 把单图重建压到 0.5 秒，靠的是 LRM 框架简化、三平面加 NeRF 渲染、大规模数据训练与混合精度等工程优化。GS-LRM 把输出换成高斯，带来光栅化实时与显式可编辑的好处，但新问题是漂浮物、稳定性与显存。

具体机制：三平面表示用三个 2D 平面双线性采样拼接，内存随分辨率平方增长，而不是体素的立方增长，这是它比体素省内存的原因。EG3D 用 StyleGAN2 骨干生成三平面，加神经渲染与双判别器。MeshLRM 做可微网格而不是“先出 NeRF 再提取”，因为提取不可微，梯度无法回顶点，拓扑与薄结构容易出错。LGM 用多视图高斯，输入 4 个视图，多视图 Transformer 输出高斯，高分辨率实时。Direct3D 先训 3D VAE 压缩，再在潜空间用 DiT 扩散，压缩与生成解耦。TRELLIS 的 SLAT 是稀疏体素加局部三平面，3D DiT 加 rectified flow，一套潜变量可解成高斯、网格与辐射场。

失败模式与代价：前馈模型的泛化受训练数据分布限制，输入视角少时背面补全可能出错；高斯输出的漂浮物需要剪枝与正则；网格输出的拓扑在薄结构处不稳定。具体例子：CRM 用 6 视图输入、卷积精修三平面、输出带纹理网格，卷积比全局注意力便宜，适合高分辨率但全局一致性弱。Hi3DGen 的法线桥接把法线作为中间监督，高频细节更稳，但法线错误会传播到几何。工程判断是：前馈工厂的选型取决于输出类型与实时性要求，三平面适合辐射场，高斯适合实时渲染，网格适合下游编辑。
