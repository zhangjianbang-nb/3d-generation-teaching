一 · 二十八张卡的名字与流程位置

《算法清单》附录把 28 张算法卡按流程顺序排列，每张卡记录名字、年份、所属方向、核心公式与后继关系。速查的第一件事不是背公式，而是建立“这张卡在管线哪一段”的位置感。28 张卡可归入六个流程段：表示与渲染（NeRF 体渲染积分、多分辨率哈希编码、3D 高斯泼溅光栅化、NeuS 符号距离场体渲染）、原生 3D 与提取（Triplane 三平面生成器、DMTet 可微网格提取、等值面/可微网格提取）、蒸馏与得分（Score Distillation Sampling、Score Jacobian Chaining、Variational Score Distillation、Interval Score Matching）、多视图与单图（视角条件扩散 Zero-1-to-3、多视图自注意力扩散、跨域法线-颜色扩散、3D-aware 同步多视图生成）、前馈与潜变量（LRM Triplane Transformer、结构化 3D 潜变量 SLAT、形状-材质双 DiT、前馈高斯输出头）、网格与世界（网格序列化 tokenization、相邻网格 token 重拓扑、组合式部件潜变量扩散、迭代式房间网格补全、高斯泼溅世界扩展、视频驱动物理参数估计、大规模 3D 资产清洗管线、UV 展开 + PBR 材质分解、LLM+程序化+扩散世界组合）。

这张位置表的价值在于：同一段内的卡通常共享输入输出契约，跨段替换才需要改接口。例如把 NeRF 体渲染积分换成 3D 高斯泼溅光栅化，两者都接受相机射线/投影与可微渲染，photometric loss 形式不变，但表示从连续函数变成显式高斯基元，显存与排序代价结构完全不同。把 SDS 换成 VSD，渲染器接口不变，变的只是“更新方向”的来源：前者用“预测噪声 − 实际噪声”，后者用“预训练扩散得分 − 粒子得分”。

一个具体机制差异：NeRF 体渲染积分把场景写成连续函数 F(x,y,z,θ,φ)→(颜色,密度)，沿射线积分得像素颜色，积分对网络参数可微，多视角照片的 photometric loss 直接优化 3D 场；3DGS 则把场景写成一堆带位置、协方差、不透明度、球谐颜色的 3D 高斯，投影到屏幕按深度排序做 alpha 混合，显式、可并行、可微。两者都能接同一个 loss，但前者失败模式是高频细节被 MLP 平滑掉、每射线采样不足导致混叠；后者失败模式是排序错乱造成遮挡穿透、高斯数量膨胀撑爆显存。

二 · 核心公式的对照读法

速查表若只列名字没有公式，等于没查。28 张卡里真正需要记住的公式骨架不多，可以按“积分型、变换型、得分型、序列型”四类归并。积分型的代表是体渲染：

$$C(\mathbf{r})=\int_{t_n}^{t_f} T(t)\,\sigma(\mathbf{r}(t))\,\mathbf{c}(\mathbf{r}(t),\mathbf{d})\,dt,\quad T(t)=\exp\!\Big(-\int_{t_n}^{t}\sigma(\mathbf{r}(s))\,ds\Big)$$

NeuS 的要点是把密度定义为 SDF 经 logistic 变换后的概率密度，使 alpha 在零等值面附近达到峰值，从而既保留体渲染可微性又得到水密平滑表面。读这张卡时要盯住“密度不是独立学的，而是 SDF 的函数”，这决定了梯度会同时推动几何与外观。

变换型的代表是 Triplane 与 DMTet。Triplane 把 3D 场分解成 xy、xz、yz 三张 2D 特征图，查询点插值拼接后送小 MLP 解码，2D 卷积生成平面，3D 一致性由三平面共享约束；DMTet 用可变形四面体网格，每顶点带 SDF，按符号切出三角面，顶点位置由 SDF 线性插值得到，对 SDF 与顶点坐标都可微。两者的共同工程判断是：把 3D 问题降维到 2D 或降到显式网格，换取卷积/切分的高效，代价是平面分辨率或四面体分辨率成为新的瓶颈。

得分型的代表是 SDS 家族。SDS 把 3D 表示渲染成图 x，加噪后送进 2D 扩散模型，用“预测噪声 − 实际噪声”作为更新方向；这个方向不是真实得分，但足以把渲染图推向扩散模型高概率区域。SJC 改用扩散模型得分乘渲染雅可比，得到 3D 参数得分，再用退火 Langevin 动力学采样。VSD 把 3D 参数视为分布，用可学习粒子（LoRA）近似该分布得分，用“预训练扩散得分 − 粒子得分”更新，等价于最小化 3D 分布与文本条件分布的 KL。ISM 用 DDIM 反演把渲染图映射到噪声，再沿同一轨迹去噪，比较反演终点与预测终点构造区间损失，减少随机噪声方差。四者的差别不在渲染器，而在“梯度从哪来、方差多大、要不要维护粒子”。

序列型的代表是网格 tokenization 与相邻 token 重拓扑。前者用面片邻接关系把网格遍历成序列，每个面片编码为“顶点坐标 + 邻接面”的离散 token，训练 decoder-only Transformer 自回归生成；后者把重拓扑当序列生成，每个面只引用前一个面的边，缩短序列并保证拓扑连续。失败模式很具体：序列一旦在中途生成了非法邻接，后续所有面片都建立在错误拓扑上，解码器没有回退机制，只能整段重采样。

三 · 八方向对比：选型时真正要比的列

第十二卷给出八方向对比，速查时应把“方向”翻译成可比较的工程列，而不是按论文热度排序。八方向可理解为：体渲染隐式场、显式高斯、SDF/网格提取、三平面原生 3D、SDS 蒸馏、多视图扩散、前馈潜变量、程序化与组合世界。对比表至少要比五列：输入模态、输出表示、训练信号来源、推理时是否需要逐资产优化、失败模式。

方向输入输出训练信号推理是否逐资产优化典型失败
体渲染隐式场多视角图+位姿连续场/密度photometric loss是高频细节被平滑、采样混叠
显式高斯多视角图+位姿高斯基元可微光栅化 loss是排序错乱、显存膨胀
SDF/网格提取多视角图或点云水密网格体渲染+Eikonal 类约束是薄结构丢失、切分分辨率不足
三平面原生 3D图像 tokentriplane→网格多视图渲染损失否（一次前向）平面分辨率限制细节
SDS 蒸馏文本/图像任意可微表示2D 扩散噪声差/得分是多面体伪影、过饱和

这张表的关键读法是“推理是否逐资产优化”这一列。它决定部署成本结构：逐资产优化意味着每个新物体都要跑一次拟合，时间随资产数线性增长；一次前向意味着训练成本前置，推理是常数级，但泛化边界由训练数据决定。LRM Triplane Transformer 用 ViT 编码输入图成 token，cross-attention 解码成三平面，体渲染出图，多视图渲染损失训练，推理一次前向出 triplane 再提取网格；前馈高斯输出头则由 Transformer 从多视图 token 预测每个高斯的均值、协方差、不透明度、球谐颜色，可微光栅化端到端训练。两者都把成本从“逐资产拟合”挪到“训练一个大模型”，代价是数据规模与显存。

一个容易错的细节：把“多视图扩散”与“前馈重建”混为一谈。Zero-1-to-3 在预训练图像扩散模型上加相机位姿条件，用 Objaverse 渲染的多视图数据微调，推理生成一圈视角再交给重建；它本身不输出 3D，输出的是“供重建消费的视图”。多视图自注意力扩散把 4 个视角拼成序列，在自注意力里让视角共享信息，用 3D 数据微调学会几何一致的多视图；它同样不保证像素级 3D 一致，仍需重建器兜底。选型时若把这两张卡当成“直接出资产”，就会在集成阶段发现缺少重建环节。

四 · 自测题：用机制而非名词作答

自测题的设计原则是：答案必须落到机制、公式或代价上，不能只报名字。以下十题按流程段排列，每题给出“答到什么程度算过”。

  • 题一：NeRF 体渲染积分为什么能让 photometric loss 直接优化 3D 场？答到“积分对网络参数可微、颜色与密度都是网络输出、loss 反传穿过积分”算过；只答“可微渲染”不算。
  • 题二：多分辨率哈希编码如何消解哈希冲突？答到“多个分辨率层级 + 小 MLP 共同承担、表项即时更新”算过；答“哈希表很大所以不冲突”不算。
  • 题三：3DGS 光栅化的并行性来自哪里、代价在哪里？答到“高斯基元投影后按深度排序做 alpha 混合、显式可并行、排序与显存是代价”算过。
  • 题四：NeuS 为什么能把密度定义成 SDF 的 logistic 变换？答到“alpha 在零等值面附近峰值、兼顾体渲染可微与水密表面”算过。
  • 题五：Triplane 的 3D 一致性由什么约束？答到“三平面共享约束、2D 卷积生成平面、查询插值拼接后小 MLP 解码”算过；答“三个平面独立生成”是错的。
  • 题六：DMTet 的可微性来自哪两个量？答到“SDF 值与顶点坐标、按符号切四面体、顶点位置由 SDF 线性插值”算过。
  • 题七：SDS 的更新方向为什么“不是真实得分却有用”？答到“预测噪声 − 实际噪声、把渲染图推向扩散模型高概率区域”算过；把它说成“精确得分”是错的。
  • 题八：VSD 与 SDS 的差别在哪一层？答到“3D 参数视为分布、可学习粒子近似得分、最小化与文本条件分布的 KL”算过。
  • 题九：网格序列化 tokenization 的序列为什么会变长、失败如何传播？答到“面片编码顶点坐标+邻接面、非法邻接使后续面片建立在错误拓扑上”算过。
  • 题十：迭代式房间网格补全的误差为什么随相机移动累积？答到“2D 扩散修补当前视角深度与颜色、反投影融合进全局网格、新几何依赖旧融合结果”算过。

自测时最容易失分的是把“表示”与“训练信号”混答。例如问 SDS，答“用扩散模型生成 3D”是错的，SDS 不生成 3D，它提供的是 3D 参数的更新方向；问 LRM，答“用扩散模型”也不准确，LRM 是 ViT 编码加 cross-attention 解码 triplane，用多视图渲染损失训练，扩散不在其核心路径上。把这两类混淆，选型时就会把“蒸馏”与“前馈”当成同一成本结构。

五 · 延伸阅读的路线：按失败模式而非按年份

延伸阅读若按年份排，会读成论文编年史；按失败模式排，才能形成工程判断。建议四条路线。第一条是“表面干净度”路线：从 NeRF 体渲染积分读到 NeuS，再读到 DMTet 与等值面/可微网格提取。这条线回答的问题是“密度场如何变成水密网格”，核心张力是体渲染的软 alpha 与表面提取的硬符号之间的折中。读的时候盯住 NeuS 的 logistic 变换与 DMTet 的四面体切分，前者解决 alpha 峰值位置，后者解决顶点位置可微。

第二条是“高频细节与显存”路线：从多分辨率哈希编码读到 3D 高斯泼溅光栅化，再读到前馈高斯输出头。这条线回答“细节放在哪、代价付在哪”：哈希编码把细节放进多分辨率表，冲突靠层级与小 MLP 消解，表项即时更新；3DGS 把细节放进显式高斯基元，代价是排序与显存；前馈高斯输出头把高斯基元变成 Transformer 的输出头，代价转移到 token 长度与训练显存。三条卡共享“显式基元”的直觉，但训练信号从逐资产拟合变成一次前向。

第三条是“文本到 3D 的方差”路线：从 SDS 读到 SJC、VSD、ISM。这条线回答“蒸馏信号为什么抖、怎么降方差”：SDS 用噪声差，SJC 用得分乘雅可比加退火 Langevin，VSD 维护粒子分布做 KL，ISM 用 DDIM 反演构造区间损失。读的时候注意每张卡新增了哪个状态：SJC 新增退火日程，VSD 新增 LoRA 粒子，ISM 新增反演轨迹。状态越多，工程实现越重，但方差越小。

第四条是“世界组合”路线：从迭代式房间网格补全读到高斯泼溅世界扩展、LLM+程序化+扩散世界组合、视频驱动物理参数估计。这条线回答“单资产之外，场景如何长出来、物理如何对上”。迭代式房间补全用 2D 扩散不断修补当前视角深度与颜色，反投影融合进全局网格，相机逐步移动场景逐步长出；高斯泼溅世界扩展从单图初始化高斯，相机移动时用视频扩散生成新视角再蒸馏成新高斯，场景可无限外扩；LLM+程序化+扩散世界组合把世界生成拆成 LLM 布局推理、程序化地形/建筑、扩散 3D 物体、object-aware 组合四个模块，各模块预训练、系统级组合。这条线的失败模式是坐标与尺度不匹配：布局推理给出的尺度、程序化地形的尺度、扩散物体的尺度若不在同一坐标系对齐，组合阶段就会出现悬浮或穿插。

数据与材质这条支线不应漏掉：大规模 3D 资产清洗管线从 Sketchfab 等平台抓取 CC 许可模型，统一格式、去重、补元数据、渲染多视图，用 CLIP 过滤与分类形成可训练数据集；UV 展开 + PBR 材质分解在生成网格后做 UV 展开，把表面颜色/材质反投影到 UV 空间，用扩散模型补全反照率、粗糙度、金属度并做光照解耦。这两张卡决定前馈工厂的上限：清洗管线的过滤标准决定训练分布，UV 展开的质量决定 PBR 贴图是否接得上。工程判断是：若下游要出带材质的资产，UV 与 PBR 分解不是可选项，而是与形状生成并列的另一条 DiT 分支——形状-材质双 DiT 正是用两个 DiT 分别生成高分辨率 SDF/网格与 UV 空间 PBR 贴图，共享图像条件但独立训练，最后合成。

六 · 速查的最后一列：后继关系与替换成本

28 张卡每张都记录后继关系，速查时这一列常被忽略，但它恰恰是选型的杠杆。后继关系不是“年份更晚所以更好”，而是“解决了前驱的哪个具体失败”。例如多分辨率哈希编码后继 NeRF 体渲染积分，解决的是大 MLP 承担高频细节时训练慢与细节糊；3DGS 后继体渲染路线，解决的是每射线采样数带来的渲染成本；NeuS 后继 NeRF 体渲染积分，解决的是密度场提取不出水密表面；DMTet 后继等值面提取，解决的是规则网格顶点位置不可微。把后继关系读成“失败模式修复链”，速查表就有了方向感。

替换成本要按接口算，不按论文算。把 SDS 换成 VSD，渲染器接口不变，但要多维护一个 LoRA 粒子及其更新，显存与每步前向次数上升；把 Triplane 换成 SLAT，输入仍是图像 token，但输出从三平面变成“稀疏体素 + 局部特征”的结构化潜变量，解码器要能分别输出高斯、网格、辐射场，接口从“一个 triplane”变成“一个潜变量加多解码头”；把网格 tokenization 换成相邻 token 重拓扑，序列编码从“顶点坐标 + 邻接面”变成“每个面只引用前一个面的边”，序列变短但生成器必须保证引用合法，解码器的约束检查变重。这些替换都不是免费的，速查表若不写替换成本，就会在集成时被接口变更反噬。

一个具体例子：组合式部件潜变量扩散用一组潜变量分别表示各部件，扩散在组合潜空间去噪，部件之间通过注意力共享全局形状但各自解码成独立网格。它与 SLAT 的接口差异在于“一个潜变量”还是“一组部件潜变量”，后者要求下游组装器理解部件分组与各自坐标系；若下游只接受单一网格，就要额外做合并与布尔运算，合并处的拓扑错误是这条路线最常见的失败。速查时把这一条写进“替换成本”列，比记住模型名字更有用。

最后落在工程判断上：速查表的最后一列应是“这张卡的后继是谁、替换它要改哪个接口、失败模式是否被真正修复”。28 张卡按流程顺序排列的意义，正在于让读者看出每一步的输入输出契约如何被下一张卡继承或改写；能回答“换掉这张卡，我的渲染器、loss、解码器哪一处要动”，才算把清单读成了工具，而不是读成了目录。
