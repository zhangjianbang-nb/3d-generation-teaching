一 · 词条的组织逻辑：从“怎么画”到“怎么评”

术语表 A–F 覆盖的是从 amortized 到 FID 的区间，但它的编排并不是简单按字母堆叠。真正决定条目归属的，是每个词在 3D 生成流水线里承担的角色。可以把这三十余个候选词分成四层：第一层是“把 3D 场画成 2D 像素”的渲染与表示机制，包括 NeRF 体渲染积分、多分辨率哈希编码、3D 高斯泼溅光栅化、NeuS 符号距离场体渲染、三平面表示；第二层是“把 2D 先验蒸进 3D”的蒸馏与扩散机制，包括 Score Distillation Sampling、Score Jacobian Chaining、Variational Score Distillation、Interval Score Matching；第三层是“一次前向出结果”的前馈生成器，包括 LRM Triplane Transformer、结构化 3D 潜变量 SLAT、网格序列化 tokenization、前馈高斯输出头；第四层是评测与数据侧，包括 FID、3D 数据 scaling、大规模 3D 资产清洗管线。这个分层决定了速查表的列设计：每个词条都要回答“它作用在哪个阶段、它的输入输出是什么、它的系统代价在哪里”。

按字母排序只是检索便利，不是认知顺序。工程读者查 A–F 时，真正想解决的是三类问题：这个机制在我的管线里替代了什么；它的失败模式是什么；它的代价是显存、时间还是数据。因此本部分的每个小节都围绕“机制—公式—代价—例子”四元组展开，而不是给每个词条写一段百科式定义。速查表放在本节末尾，作为跨小节的索引；后续小节则按主题把表里的行展开成可操作的判断。

二 · 渲染与表示：把 3D 场画成 2D 像素的四种代价

多分辨率哈希编码的机制是用多级网格查表加线性插值替代大 MLP。每一级网格分辨率按几何级数增长，查到的特征拼接后送入一个小 MLP 解码。它的收益来自“用查表换速度”：高分辨率细节由细网格承担，低频结构由粗网格承担。代价是显存随级数和分辨率增长，且哈希冲突会引入噪声。一个具体的失败模式是：当场景尺度远大于训练时设定的包围盒，细网格的有效分辨率被摊薄，高频细节退化为模糊；反过来，包围盒设得过小，哈希冲突率上升，渲染出现块状伪影。工程判断是：哈希编码适合“单场景过拟合”式优化，不适合直接当作跨场景前馈生成器的输出表示，因为它的参数与场景绑定。

3D 高斯泼溅光栅化的机制是把场景表示为一批带位置、协方差、颜色和不透明度的椭球，投影到屏幕后按深度排序，再做 alpha 混合。它的公式骨架是：像素颜色为按深度排序后的 \(\sum_i c_i\alpha_i\prod_{j

NeuS 符号距离场体渲染的机制是把密度表示为 SDF 的拉普拉斯，使得零等值面附近的密度集中，从而在体渲染框架内得到干净表面。它的关键正则是 Eikonal 正则，要求 SDF 的梯度模长接近 1：\(\|\nabla f\|=1\)。这个正则把“表面在哪”与“密度怎么分布”解耦，代价是训练时要额外计算梯度范数，且采样策略要围绕零等值面加密。失败模式是 Eikonal 权重过大时表面过度平滑、细节丢失；权重过小时密度弥散，提取的网格出现双层壳。DMTet 可微网格提取则把“提取”这一步也做成可微的：它维护一组顶点位移和面朝向，通过可微的移动与翻转把隐式场转成三角网格，再光栅化。代价是拓扑翻转会带来梯度不稳定，失败模式是训练后期出现自交或非流形边。三平面表示把 3D 特征降到三张 2D 特征图（XY、XZ、YZ），用 2D 卷积做解码，代价是平面分辨率与解码器容量共同决定细节上限；失败模式是平面对齐处的接缝，以及薄结构在某一平面上投影重叠导致的歧义。

这四种机制的共同点是都在回答“3D 场怎么变成像素”，但代价位置不同：体渲染积分贵在采样，哈希编码贵在显存与冲突，高斯泼溅贵在排序与带宽，NeuS 贵在正则与采样，三平面贵在分辨率与接缝。工程选型时，先问“我的瓶颈是训练时间、显存还是提取质量”，再对号入座，而不是按论文热度排序。

三 · 蒸馏家族：SDS、SJC、VSD、ISM 的方差与分布之争

Score Distillation Sampling 的机制是用一个预训练的 2D 扩散模型作为先验，把 3D 参数 \(\theta\) 的渲染图加噪后送入扩散模型，取噪声预测的残差作为梯度信号。其梯度骨架可写成 \(\nabla_\theta \mathcal{L}_{\text{SDS}} = \mathbb{E}_{t,\epsilon}\left[w(t)(\epsilon_\phi(x_t;y,t)-\epsilon)\frac{\partial x}{\partial \theta}\right]\)，其中 \(x\) 是渲染图，\(\epsilon_\phi\) 是扩散模型的噪声预测，\(w(t)\) 是时间步权重。这个式子的工程含义是：每一步优化都要对渲染图做一次前向加噪和一次扩散前向，因此单步成本远高于普通重建损失；同时残差是随机的，梯度方差大，表现为优化过程抖动、细节时好时坏。失败模式是“过饱和”与“多面”：当时间步权重偏向高噪时，先验只约束全局语义，3D 模型会在不同视角各自讨好先验，导致几何不一致。

Score Jacobian Chaining 的思路是把扩散模型的得分通过雅可比链式法则传回 3D 参数，强调“得分是分布的梯度”这一解释，从而在理论上把 SDS 的残差项与得分匹配联系起来。它的代价与 SDS 同源：仍要多次扩散前向，且雅可比的计算在图结构复杂时开销上升。Variational Score Distillation 则把“单点匹配”换成“分布匹配”：它引入一个可学习的打分网络来近似当前 3D 模型渲染图的分布，并让这个分布与先验分布对齐。公式骨架是 \(\nabla_\theta \mathcal{L}_{\text{VSD}} = \mathbb{E}\left[(\epsilon_\phi(x_t;y,t)-\epsilon_\psi(x_t;t))\frac{\partial x}{\partial \theta}\right]\)，其中 \(\epsilon_\psi\) 是随 \(\theta\) 更新的打分网络。代价是多了一个网络的训练与存储，失败模式是打分网络与主模型互相追逐导致训练不稳定，表现为模式坍塌或颜色漂移。Interval Score Matching 的机制是在一个时间步区间内做匹配，用区间内的平均得分降低单步方差；代价是区间调度与超参敏感，失败模式是区间选得过窄时先验信号不足、过宽时细节被抹平。

把这四个词放在一起看，它们的分歧不在“用不用 2D 先验”，而在“匹配什么”：SDS 匹配单点的噪声残差，SJC 强调得分的链式解释，VSD 匹配分布，ISM 匹配区间。工程判断是：如果目标是快速拿到一个可用的粗几何，SDS 的方差可以用较低的学习率和较多步数压住；如果目标是多视角一致且颜色稳定，VSD 的分布匹配更合适，但要接受额外网络的显存与调参成本；ISM 适合在已有 SDS 管线上做降方差的增量改造，而不是从零替换。一个具体例子是文本到 3D 的早期管线：用 SDS 在低分辨率下优化三平面，再切到 VSD 做细化，切换点通常选在几何轮廓稳定之后，因为此时分布匹配的收益才开始超过其不稳定性。

四 · 前馈与结构化：一次前向出结果的表示选择

LRM Triplane Transformer 的机制是用一个 Transformer 把输入图像编码成 token，再解码成三平面特征，最后由轻量解码器渲染。它的“摊销”含义是把逐场景优化摊到一次前向：训练时见过大量资产，推理时对新图像直接出三平面。代价是输入分辨率与 token 数决定细节上限，失败模式是输入视角稀疏时背面几何靠先验“猜”，表现为背面纹理模糊或几何外扩。结构化 3D 潜变量 SLAT 把潜变量挂到稀疏体素上，每个体素带一个特征向量，渲染时按射线采样体素特征。它的代价是体素分辨率与稀疏性：分辨率高则显存涨，稀疏性差则空体素浪费算力。失败模式是体素化过程中的量化误差，表现为薄结构断裂。

网格序列化 tokenization 把三角面变成 token 序列，用自回归或扩散模型生成。它的机制是“把网格当语言”：顶点坐标、面连接、拓扑顺序都被编码成离散 token。代价是序列长度随面数增长，失败模式是生成长序列时的拓扑不一致，表现为自交或非流形边；相邻网格 token 重拓扑则是在 token 层面做局部重排，试图在生成后修复拓扑，代价是额外的后处理与一致性检查。形状-材质双 DiT 把几何与 PBR 材质分成两个扩散 Transformer 分别生成，再对齐。代价是两路生成的对齐误差，失败模式是材质与几何错位，表现为纹理在 UV 接缝处拉伸。组合式部件潜变量扩散把物体拆成部件，分别生成潜变量再组合，代价是部件间的接触面一致性，失败模式是部件悬浮或穿插。迭代式房间网格补全则是在房间尺度上迭代补全缺失的网格，代价是长距离场景一致性，失败模式是补全区域与已有区域的法线或尺度不匹配。

前馈高斯输出头是把高斯泼溅作为前馈生成器的输出表示：网络一次前向输出一批高斯参数，再走光栅化。它的代价是高斯数量与排序开销，失败模式是生成的高斯在视角外推时出现空洞，因为网络只见过训练分布内的视角。3D-aware 同步多视图生成则是在一次前向中生成多个一致视角，用多视图自注意力扩散把视角间的信息打通；代价是注意力随视角数平方增长，失败模式是视角数增加后一致性反而下降，因为注意力被稀释。跨域法线-颜色扩散把法线图与颜色图作为两个域互相条件，代价是两域对齐，失败模式是法线正确但颜色漂移。这些机制的共同工程判断是：前馈生成器的表示选择决定了它的失败模式——三平面败在背面猜测，SLAT 败在量化，网格 token 败在拓扑，高斯败在视角外推。

五 · 评测与数据：FID 的适用边界与清洗管线的代价

FID 的定义是两个特征分布之间的 Fréchet 距离：\(\text{FID}=\|\mu_r-\mu_g\|^2+\text{Tr}(\Sigma_r+\Sigma_g-2(\Sigma_r\Sigma_g)^{1/2})\)，其中 \(\mu\) 与 \(\Sigma\) 是真实样本与生成样本在特征提取器下的均值与协方差。它的机制是“用特征分布的距离代替逐像素比较”，因此对像素级错位不敏感，但对特征提取器的选择敏感。用在 3D 生成上时，常见做法是把多视角渲染图当作样本集算 FID，代价是视角采样策略会直接影响分数：视角覆盖不全时，背面错误不被计入；视角过多时，计算量上升。失败模式是把 FID 当作唯一指标：一个几何崩坏但纹理讨喜的模型可能拿到好看的 FID，因为特征分布被纹理主导。工程判断是 FID 只适合做“分布层面的粗筛”，不能替代几何一致性、法线质量与重光照测试。

大规模 3D 资产清洗管线的机制是把原始资产（扫描、生成、爬取）过一遍几何修复、UV 展开、PBR 材质分解、尺度归一与语义标注。代价是每一步都有失败率，且失败会级联：UV 展开在非流形网格上失败，导致后续材质分解无坐标可用；PBR 分解在缺乏多光照观测时存在歧义，表现为反照率与阴影混淆。一个具体例子是 Objaverse 类资产的清洗：先做水密性检查与重拓扑，再做 UV 展开，最后用多视角渲染做材质分解的一致性校验。失败模式是清洗管线把“可渲染”误当成“可重光照”，产出的资产在训练管线里看着正常，换光照后出现明显的高光错位。3D 数据 scaling 的机制是“规模决定上限”：前馈生成器的泛化能力受训练资产的数量与多样性约束，代价是数据清洗与标注的人力，失败模式是规模上去但多样性没上去，模型对长尾类别仍然失效。UV 展开加 PBR 材质分解作为词条，其工程含义是：材质不是一张贴图，而是反照率、粗糙度、金属度等通道的组合，分解质量决定了资产能否进入下游渲染管线。

把评测与数据放在同一节，是因为它们共同构成“生成之后怎么办”的问题。FID 回答“像不像”，清洗管线回答“能不能用”，数据 scaling 回答“上限在哪”。三者的代价分别是视角采样、级联失败与人力，失败模式分别是纹理主导、可渲染不等于可重光照、规模不等于多样性。工程上，先定下游用途（离线渲染、实时引擎、训练数据），再选评测指标与清洗强度，而不是先追分数再补管线。

回到速查表的使用方式：查一个词条时，先看它所在阶段，再看它的代价列，最后回到对应小节找失败模式。比如查“3D 高斯泼溅光栅化”，阶段是渲染，代价是排序与带宽，失败模式是视角剧变时的闪烁；查“SLAT”，阶段是前馈，代价是体素分辨率，失败模式是薄结构断裂。这种查法把术语表从“定义集合”变成“选型索引”，每个词条都对应一个可验证的工程判断，而不是一段可以背诵的描述。
