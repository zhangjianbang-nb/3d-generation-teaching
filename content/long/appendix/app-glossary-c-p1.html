一 · 词条地图：N–Z 的八条主题带

术语表 N–Z 覆盖的是全书后半段的技术词汇，从辐射场一直延伸到变分蒸馏。这些词条并非按字母顺序松散排列，而是沿着八条主题带聚集：场景重建与可微渲染、原生 3D 生成表示、优化式蒸馏（SDS/VSD）、多视图扩散与重建、前馈 3D 原生大模型、网格与拓扑及部件生成、场景与世界及物理、数据与评测与生产化。理解这张地图比记住单个缩写更重要，因为同一个缩写在不同的主题带里承担不同的系统角色。例如 NeRF 既是场景重建的表示，也是优化式蒸馏的承载几何；3DGS 既是渲染原语，也是前馈大模型的输出格式。词条之间的引用关系构成一张有向图：表示层词条（NeRF、NeuS、3DGS、三平面、点云、隐式函数）被生成层词条（DreamFusion、LRM、Structured 3D Latents）引用，生成层又被生产化词条（SF3D、Hunyuan3D 2.1、CraftsMan3D）引用。速查表按主题带给出每个词条的核心机制与它在管线中的位置，便于在阅读正文时快速定位。

二 · 表示层：辐射场、SDF 与高斯的三角关系

NeRF 的核心机制是把场景编码为一个连续函数，输入是三维坐标与视角方向，输出是体积密度与颜色，再通过体渲染积分合成像素。其积分形式为：

$$C(\mathbf{r}) = \int_{t_n}^{t_f} T(t)\,\sigma(\mathbf{r}(t))\,\mathbf{c}(\mathbf{r}(t),\mathbf{d})\,dt,\quad T(t)=\exp\!\left(-\int_{t_n}^{t}\sigma(\mathbf{r}(s))\,ds\right)$$

这个积分在实现中离散化为沿射线的采样求和，采样数决定了渲染质量与计算量。NeRF 的失败模式是训练与渲染都慢：每条射线需要数十到上百次前向查询，优化一个场景需要大量迭代。Instant NGP 用多分辨率哈希编码把查询成本压下来，其机制是把空间划分为不同分辨率的网格，每个网格顶点存一个可学习特征向量，查询时对八个角点做三线性插值再拼接。哈希编码的代价是冲突：不同空间位置可能映射到同一哈希槽，冲突率随分辨率提高而上升，需要通过多分辨率层级来缓解。3D Gaussian Splatting 走另一条路，用一组各向异性高斯原语表示场景，每个高斯有位置、协方差、不透明度与球谐颜色系数，渲染时把高斯投影到屏幕并按深度排序做 alpha 混合。3DGS 的代价是显存：原语数量随场景复杂度增长，排序与混合的带宽开销在高质量设置下成为瓶颈。NeuS 与 VolSDF 则把密度替换为 SDF 导出的形式，使水平集在体渲染框架内可微，从而得到干净表面。NeuS 的机制是用 SDF 值构造不透明度，使零水平集附近的密度集中，其失败模式是薄结构容易丢失，因为 SDF 的梯度在薄壁处不稳定。pixelNeRF 把图像特征作为条件输入 NeRF，实现单图或少图的新视角合成，其代价是条件特征的对齐误差会在视角变化时放大。

这三种表示不是互斥的，而是按任务选择：需要干净网格时用 NeuS/VolSDF，需要实时渲染时用 3DGS，需要与哈希编码结合做快速拟合时用 Instant NGP。词条之间的比较应落在具体指标上：表面质量、渲染帧率、显存占用、训练时长。工程判断的依据是下游任务需要网格还是需要渲染图，前者倾向 SDF 路线，后者倾向高斯路线。

三 · 优化式蒸馏：从 SDS 到 VSD 的分数视角

DreamFusion 引入的 score distillation sampling 把预训练 2D 扩散模型当作 3D 生成的评分函数。其机制是对渲染图加噪，用扩散模型预测噪声，再把预测噪声与采样噪声之差作为梯度回传到 3D 表示。SDS 的梯度形式可写为：

$$\nabla_\theta \mathcal{L}_{\text{SDS}} = \mathbb{E}_{t,\epsilon}\left[ w(t)\,\big(\epsilon_\phi(\mathbf{x}_t; y, t) - \epsilon\big)\,\frac{\partial \mathbf{x}}{\partial \theta}\right]$$

其中 $\mathbf{x}$ 是渲染图，$\epsilon_\phi$ 是扩散模型的噪声预测，$w(t)$ 是时间步权重。Score Jacobian Chaining 把这个梯度解释为分数函数的雅可比链，指出 SDS 等价于在像素空间对分数做链式求导。SDS 的失败模式是过饱和与几何塌陷：因为梯度只约束渲染图与文本的匹配，不约束多视角一致性，优化容易收敛到从某些视角看合理但几何上不自洽的解。Magic3D 用两阶段策略缓解：先用低分辨率 SDS 得到粗几何，再切换到高分辨率并引入稀疏体素网格做精修。ProlificDreamer 提出变分分数蒸馏（VSD），把 3D 参数视为随机变量，用一组粒子近似后验，并训练一个 LoRA 副本作为分数修正项。VSD 的梯度形式为：

$$\nabla_\theta \mathcal{L}_{\text{VSD}} = \mathbb{E}_{t,\epsilon}\left[ w(t)\,\big(\epsilon_\phi(\mathbf{x}_t; y, t) - \epsilon_\psi(\mathbf{x}_t; y, t, c)\big)\,\frac{\partial \mathbf{x}}{\partial \theta}\right]$$

其中 $\epsilon_\psi$ 是带粒子条件的修正网络，$c$ 是相机参数。VSD 的代价是显存与训练时长：每个粒子需要独立的渲染与梯度计算，粒子数增加会线性放大开销。Fantasia3D 把几何与外观解耦，分别用不同的表示与损失优化，TextMesh 则直接在网格上做 SDS 以得到可导出的网格。DreamGaussian 把 SDS 与高斯表示结合，先在低分辨率下优化高斯原语，再做网格提取与纹理精修，其失败模式是高斯原语在优化中分裂过多导致网格提取困难。LucidDreamer 用区间分数匹配替代 SDS 的噪声采样，减少梯度方差。这些词条的共同点是：蒸馏的目标函数决定了几何质量的上限，而表示的选择决定了能否导出可用资产。

四 · 多视图扩散与前馈重建：单图到 3D 的两条路径

Zero-1-to-3 把单图新视角合成建模为条件扩散：输入一张图与相对相机变换，输出目标视角的图像。其机制是把相机变换编码为条件向量，与图像特征一起送入扩散模型。MVDream 把多视图一致性写进扩散过程，训练时同时生成多个视角并共享注意力，使生成的视图在几何上互相约束。SyncDreamer 用同步的多视图扩散，在每个去噪步交换视图间的特征以保持一致性。Wonder3D 用跨域扩散同时生成法线图与颜色图，法线图提供几何线索，颜色图提供外观，二者互为条件。这些方法的失败模式是视角外推：当目标视角远离输入视角时，扩散模型倾向于生成看似合理但与输入不一致的内容，表现为背面纹理错位或几何翻转。

前馈重建路线则跳过扩散，直接用大模型回归 3D 表示。LRM 用 Transformer 编码输入图像，解码为三平面表示，再渲染出新视角。TripoSR 在 LRM 基础上做效率优化，用更少的 token 与更快的解码器实现快速重建。GS-LRM 输出 3D 高斯而不是三平面，MeshLRM 输出网格，LGM 用多视图高斯做高分辨率生成。这些模型的共同机制是：编码器提取图像特征，解码器回归表示参数，训练损失是新视角渲染图与真值的差异。其系统代价在训练端：需要大规模多视图数据，Objaverse 与 Objaverse-XL 提供了这种数据基础。失败模式是输入视角外的区域缺乏监督，模型倾向于生成平滑但缺乏细节的背面。InstantMesh 用稀疏视图大重建模型做单图到网格，CRM 用卷积重建模型提升速度，Hi3DGen 用法线桥接提升几何保真度。Direct3D 与 Structured 3D Latents 把扩散引入前馈管线，用 3D 潜变量扩散 Transformer 做可扩展生成。Hunyuan3D 2.0 与 2.1 把这一路线推向高分辨率纹理与 PBR 材质，Step1X-3D 强调可控性。工程判断的分界线是：需要多样本多样性时用扩散路线，需要低延迟与确定性输出时用前馈回归路线。

五 · 网格、拓扑与部件：从 token 到可编辑资产

MeshGPT 把三角形网格序列化为 token 序列，用仅解码器 Transformer 自回归生成。其机制是把网格的面片按顶点索引编码为离散 token，训练模型预测下一个 token。失败模式是序列长度随面数增长，长序列生成容易失去全局一致性，且生成的网格拓扑不保证流形。MeshAnything 用自回归 Transformer 生成艺术家级网格，强调拓扑质量；MeshAnything V2 引入相邻网格 token 化，把相邻面片合并为 token 以减少序列长度。PartCrafter 用组合式潜变量扩散 Transformer 做结构化网格生成，把物体分解为部件再分别生成，其代价是部件间的接缝需要额外处理。CraftsMan3D 用 3D 原生生成加交互式几何精修，把生成与手工修整结合。这些词条的共同问题是拓扑：自回归生成的网格面数固定、边连接规则，难以直接用于动画绑定；重拓扑因此成为生产化管线中的必要步骤。SF3D 用 UV 展开与光照解耦把生成网格转为可贴图资产，Hunyuan3D 2.1 输出 PBR 材质，二者都指向同一个工程判断：生成网格的价值取决于它能否进入下游渲染与编辑管线，而不是仅能渲染出好看的图。

六 · 场景、世界与物理：词条的外延

Text2Room 从 2D 文本到图像模型提取纹理网格，逐房间生成场景；WonderWorld 从单图生成可交互场景；WorldGen 从文本生成可漫游的交互 3D 世界；SceneCraft 用 LLM 代理合成 Blender 代码来搭建场景。PhysDreamer 用视频生成模型驱动 3D 物体的物理交互，其机制是从视频中学习材质与运动先验，再把这些先验施加到 3D 表示上。这些词条的失败模式是尺度与一致性：房间级场景的几何误差会随视角累积，物理交互的稳定性依赖材质参数的准确估计。Objaverse 与 Objaverse-XL 作为数据词条支撑了上述训练，前者是带标注的 3D 物体集合，后者扩展到千万级规模。数据规模决定了前馈模型的泛化边界，而评测与生产化词条则决定了这些模型能否交付。词条 N–Z 的阅读顺序建议按依赖链走：先表示层，再蒸馏与多视图，再前馈大模型，最后网格与场景。每个词条都应带着三个问题读：它的机制是什么，它的公式或伪代码如何落地，它的系统代价与失败模式在哪里。
