一 · 从 G 到 M 的词条骨架：三类对象与两条流水线

术语表 G–M 覆盖的区间不是按字母随意切分的，它恰好落在 3D 生成技术栈的中段：往上是表征与渲染（Gaussian、hash grid、implicit surface），往下是生成范式与数据规模（latent、multi-view、LRM、mesh tokenization、PBR、scaling）。要在一张表里查这些词，先得知道它们各自回答的是哪一类问题。按工程视角，这批条目可以归为三类对象：表征（一个 3D 场景在内存里长什么样）、算子（怎么把表征变成像素或表面）、生成器（怎么从条件得到一个表征）。三者不是并列关系，而是串联关系：生成器输出表征，表征被算子消费，算子的可微性反过来约束生成器的训练方式。

与之对应的是两条流水线。第一条是优化式流水线：以 NeRF 类体渲染为起点，用多视图 photometric loss 反传梯度，DreamFusion 一类工作把 2D 扩散先验通过 Score Distillation Sampling 注入这条链路。第二条是前馈式流水线：LRM 把单图直接映射成三平面，TripoSR、InstantMesh 把这一步做成一次前向，GS-LRM、MeshLRM 更换输出头，Direct3D、Hunyuan3D 把扩散 Transformer 接在 3D 潜变量上。两条流水线的词条在术语表里交错出现，但它们的系统代价结构完全不同：优化式受限于每资产的迭代时间与得分函数的方差，前馈式受限于训练数据规模与输出表征的分辨率上限。

速查表按“词条—所属类别—一句话机制—典型失败模式”组织，供查阅时快速定位。表中不给出任何未在事实清单中出现的数值。

这张表的使用方式是“先定位类别，再查代价”。若一个词条属于表征，它的失败模式通常表现为分辨率或拓扑问题；若属于算子，失败模式通常表现为梯度方差或数值稳定性；若属于生成器，失败模式通常表现为条件覆盖不足。下面五节按主题展开，每节给出定义、分类与一个具体机制层面的说明。

二 · 高斯与哈希：显式基元与查表加速的对偶

3D 高斯泼溅（3D Gaussian Splatting）的定义是：用一组各向异性的三维高斯椭球作为显式基元，每个基元携带位置、协方差、不透明度与球谐颜色系数，渲染时把这些椭球投影到像平面并按深度排序做 alpha 混合。它与 NeRF 的根本差别在于“表示是否显式”：NeRF 把场景压进一个 MLP 的权重里，查询一次要跑一次网络；高斯泼溅把场景摊开成几十万到几百万个基元，查询一次是一次排序加混合。前者的代价是每像素多次网络前向，后者的代价是显存占用与排序开销。分类上，高斯泼溅属于“显式 + 光栅化”路线，其光栅化器可微，因此仍可用 photometric loss 优化基元参数，但不需要体渲染积分。

体渲染积分是这条路线的前身，也是理解所有 NeRF 类方法的入口。它把一条射线上的颜色写成透射率加权的积分：

$$C(\mathbf{r})=\int_{t_n}^{t_f} T(t)\,\sigma(\mathbf{r}(t))\,\mathbf{c}(\mathbf{r}(t),\mathbf{d})\,dt,\quad T(t)=\exp\!\left(-\int_{t_n}^{t}\sigma(\mathbf{r}(s))\,ds\right)$$

离散化后变成沿采样点的累加，透射率逐点相乘。这个式子的工程含义是：梯度会沿着整条射线回传到所有采样点，因此一次渲染的计算量与采样数线性相关。失败模式也在这里——当场景中存在薄结构或高频纹理时，有限的采样数会把它们积分掉，表现为细节糊化；反之采样过密则显存与时间双升。多分辨率哈希编码正是为缓解“查询太慢”而生：它把空间划分为若干级不同分辨率的网格，每级网格顶点存一个可学习特征向量，查询点在其所在体素内做三线性插值，多级特征拼接后送入一个小 MLP。哈希的作用是把稀疏的高分辨率网格压进固定大小的表，用查表换速度。其代价是哈希冲突：不同空间位置可能落到同一槽位，冲突在高分辨率级上引入伪影，表现为表面出现不属于该处的高频噪点。Instant Neural Graphics Primitives 把这一结构做成通用原语，使 NeRF 类训练从小时级降到可交互量级——这是定性表述，事实清单未给出具体倍数。

一个具体例子：用高斯泼溅重建一个带金属反光的桌面场景。基元的协方差矩阵决定椭球的朝向与扁平度，优化过程中扁平椭球会贴合平面，细长椭球会贴合边缘。若视角覆盖不足，优化器会把某些基元拉成跨越空旷区域的“漂浮椭球”以解释训练视角的颜色，换到新视角就露出破绽。这是显式表征特有的失败模式：错误是可见的、局部的、可编辑的，而不像 MLP 那样弥散在权重里。工程判断上，高斯泼溅适合“有足够多视角、要求实时渲染”的资产；哈希编码适合“单场景过拟合、要求快速训练”的重建；两者可以组合，例如用哈希编码的 NeRF 做几何初始化，再蒸馏到高斯基元。

三 · 隐式表面：SDF、Eikonal 与三平面的降维 trade-off

隐式表面的定义是：用一个标量场 \(f(\mathbf{x})\) 的零等值面表示几何，表面即 \(\{\mathbf{x}: f(\mathbf{x})=0\}\)。最常用的是有符号距离场（SDF），其值等于点到最近表面的距离并带内外符号。SDF 的优点是表面提取（marching cubes）稳定、法线可由梯度直接得到；缺点是纯 SDF 监督需要真值距离，而从多视图图像只能得到体渲染式的密度监督。NeuS 一类工作用体渲染训练隐式表面，把密度定义为 SDF 的变换，使零等值面附近密度陡升，从而在多视图 photometric loss 下学出干净表面。这里的关键正则是 Eikonal 方程：

$$\|\nabla f(\mathbf{x})\|=1$$

它约束标量场在任意处的梯度模为 1，等价于说“这确实是一个距离场而不是任意标量场”。没有这条正则，网络可以用极陡或极平的场去拟合颜色，表面提取时出现台阶或空洞。Eikonal 项的系数是一个需要调的工程参数：系数过大，场被压得过于平滑，薄结构（叶片、栏杆）被吞并；系数过小，表面出现噪点与自交。这是隐式表面最典型的失败模式——薄结构丢失，且丢失是渐进的、难以从渲染图上看出来的，只有换到侧视角或做几何评估才暴露。

三平面表示（triplane）是另一条降维路线：把 3D 特征场分解为三个轴对齐的 2D 特征平面（XY、XZ、YZ），查询点在三平面上分别双线性采样后拼接。它的动机是把 3D 卷积和 3D 注意力降成 2D 卷积与 2D 注意力，从而复用成熟的 2D 生成网络架构。EG3D 用三平面加神经渲染器做 3D 感知 GAN，GET3D 用类似结构生成带纹理的网格，LRM 则把单图编码后直接解码成三平面。三平面的代价是轴对齐偏置：沿坐标轴方向的特征被三个平面共享，斜向结构容易产生条纹状伪影；此外三平面本质上是 3D 场的低秩近似，高频细节受平面分辨率上限约束。一个具体例子：生成一把椅子，三平面能很好地表达座面与靠背这类轴对齐平面，但椅腿的斜撑在三个平面上投影不一致，容易出现边缘毛刺。工程上常见的补救是把三平面与少量 3D 体素或高斯基元混合，用显式基元补高频。

把这两条路线放在一起看，隐式表面给出的是“可提取的干净几何”，三平面给出的是“可被 2D 网络高效生成的潜表征”。前者适合做最终资产，后者适合做生成中间态。失败模式的分布也不同：SDF 路线的问题集中在正则系数与薄结构，三平面路线的问题集中在分辨率上限与轴向伪影。

四 · 扩散先验与蒸馏：从噪声预测到分布匹配

扩散得分与噪声预测是这批词条里最容易被混为一谈的一对。噪声预测网络 \(\epsilon_\theta(\mathbf{x}_t,t)\) 接收加噪样本与时间步，输出所加噪声的估计；扩散得分则是 \(\nabla_{\mathbf{x}}\log p_t(\mathbf{x})\)，二者在方差爆炸参数化下相差一个与 \(\sigma_t\) 有关的缩放因子。工程上重要的是：得分是“往数据分布高处走的方向”，而噪声预测只是它的一个参数化。Score Distillation Sampling（SDS）把这一方向用于 3D：把一个可微渲染器渲染出的图像加噪，送入预训练 2D 扩散模型，取噪声预测残差作为梯度信号更新 3D 参数。其伪代码思路是：

$$\nabla_\phi \mathcal{L}_{\text{SDS}}=\mathbb{E}_{t,\epsilon}\left[w(t)\,\big(\epsilon_\theta(\mathbf{x}_t;y,t)-\epsilon\big)\,\frac{\partial \mathbf{x}}{\partial \phi}\right]$$

其中 \(\mathbf{x}\) 是渲染图，\(\phi\) 是 3D 表征参数，\(w(t)\) 是时间步权重。SDS 的失败模式是著名的：它只提供单点梯度，不约束分布，导致结果过饱和、几何塌陷、多视角下正面精细背面糊。DreamFusion 是这条路线的最早系统化实现之一，Magic3D 用两阶段（粗到细）缓解分辨率问题，Fantasia3D 把几何与外观解耦以减轻纹理对几何的干扰，TextMesh 把输出落到网格上。这些工作共享同一个代价结构：每个资产需要一次长时间优化，且得分函数的方差使结果对随机种子敏感。

Variational Score Distillation（VSD）把“单点”升级为“分布”。它引入一个粒子集合，用另一个扩散模型（或同一模型的不同参数化）估计当前 3D 分布下的得分，使优化目标变成让 3D 样本分布与 2D 先验的边缘分布匹配，而不是让单个样本的渲染图取悦先验。ProlificDreamer 是这一思路的代表。VSD 的代价是显存与计算：粒子数增加意味着每步要渲染多张图并跑多次扩散前向；失败模式是粒子退化——若粒子间多样性不足，分布估计方差偏高，优化震荡。LucidDreamer 用区间得分匹配约束时间步区间，试图减轻 SDS 在极端时间步上的噪声。一个具体例子：用 SDS 生成一只带细长腿的动物，早期迭代会把腿合并成块状以降低渲染图与先验的差异，因为模糊的块状轮廓在低时间步上得分更高；换到 VSD 后，粒子集合中的不同样本被迫保持差异，腿的分离度更容易保留。这是定性机制层面的差别，事实清单未给出定量对比。

这一节的工程判断是：SDS 适合快速原型与单资产优化，VSD 适合需要多样性与分布覆盖的批量生成，但两者都受“2D 先验不懂 3D 几何”的根约束——先验只见过图像，没见过背面。

五 · 多视图一致性与前馈重建：LRM 家族的输出头之争

多视图一致性的定义是：同一 3D 对象在不同视角下的渲染结果互相印证，不出现只在一个视角成立的纹理或几何。它是所有单图生成方法的隐含约束，也是评估时的核心指标。实现上分两条：一条是显式生成多视图图像再三角化或重建（Zero-1-to-3、MVDream、SyncDreamer、Wonder3D 属于此类，用扩散模型生成跨视角一致的图像），另一条是直接把单图映射成 3D 表征（LRM 家族）。前者的失败模式是背面臆造：扩散模型对未见视角的生成是“合理但不正确”的，生成的背面纹理与正面风格一致但几何不闭合；后者的失败模式是输入视角外几何模糊，因为单图提供的信息不足以约束被遮挡部分。

LRM（Large Reconstruction Model）的机制是：用一个图像编码器提取特征，通过交叉注意力把特征注入一个三平面解码器，一次前向输出三平面，再由体渲染或表面提取得到 3D。TripoSR 把这一流程做得更轻更快，InstantMesh 用稀疏视图大重建模型输出网格，CRM 用卷积重建模型降低对注意力的依赖，GS-LRM 把输出头换成高斯基元，MeshLRM 把输出头换成网格。这一家族的共同结构是“编码器—潜表征—解码器”，差别只在潜表征的形式与解码器的可微性。输出头之争的实质是：三平面便于体渲染但分辨率受限，高斯基元便于实时渲染但显存占用高，网格便于下游编辑但拓扑生成难。Hi3DGen 用法线桥接提升几何保真度，属于在输出头上加约束的思路。

结构化 3D 潜变量 SLAT 是另一条路：不做全局三平面，而是在稀疏体素锚点上存结构化潜码，锚点由输入图像或粗几何决定，潜码之间通过 Transformer 交互。Direct3D 用 3D 潜扩散 Transformer 在潜空间做扩散，PartCrafter 用组合式潜扩散做部件级生成。SLAT 的失败模式是锚点覆盖不全：若初始锚点漏掉了某些结构（例如细长的把手），后续扩散无法在空白处凭空生成，表现为部件缺失。这与三平面的“全局但低秩”形成对照：SLAT 是“局部但高保真”，代价是锚点质量决定上限。一个具体例子：用 LRM 从一张正面照重建一个马克杯，杯身的三平面表达良好，但杯口内壁因为输入视角看不到，重建出的内壁要么过厚要么缺失；换用多视图扩散先生成侧后视角再重建，内壁闭合度提升，代价是多了一次扩散采样与一致性过滤。

六 · 网格 tokenization、PBR 与数据规模：资产化的最后一公里

网格 tokenization 的定义是：把三角网格的顶点与面序列化成离散 token，用自回归 Transformer 生成。MeshGPT 用 decoder-only Transformer 生成三角面序列，MeshAnything 与 MeshAnything V2 用相邻网格 tokenization 缩短序列长度并提升拓扑合法性。这条路线把“生成网格”变成“生成语言”，好处是可直接复用语言模型的训练基础设施，坏处是序列长度随面数增长，且拓扑合法性（流形、无自交）不能由 token 语法保证，需要在解码后做修复。失败模式具体表现为：生成的面片顺序错乱导致非流形边，或长序列在尾部失去全局约束，出现悬空面。工程上通常配合一个几何精修器（CraftsMan3D 的交互式精修属于此类思路）做后处理。

PBR 材质的定义是：把表面外观分解为反照率、粗糙度、金属度等通道，使资产可在任意光照下重渲染。生成侧的关键失败模式是“光照烘焙进反照率”：若训练数据或蒸馏目标把阴影与高光烘进颜色，资产换光照后出现错误的暗部与假高光。Hunyuan3D 2.1 明确把生产级 PBR 材质作为目标，SF3D 做 UV 展开与光照解耦，都属于在输出端分离外观与光照。判断一个生成资产是否可用，看的不是渲染图好不好看，而是把反照率通道单独打光后是否仍然合理。

场景一致性与 3D 数据 scaling 是这一段的两个约束端点。场景一致性要求长距离轨迹上几何与外观不漂移，Text2Room、WonderWorld、WorldGen 一类工作把 2D 生成模型用于场景扩展，失败模式是累积位姿误差与风格漂移——每扩一段，颜色与尺度就偏一点，长轨迹后整体失配。3D 数据 scaling 则指出规模决定上限：Objaverse 与 Objaverse-XL 提供了千万级资产，但类别长尾、许可混杂、几何质量参差，直接决定前馈模型的上限。一个具体例子：训练一个单图重建模型，若数据集中缺少透明与薄壁物体，模型在遇到玻璃杯时会把透明当成白色实心，这是数据覆盖问题而非架构问题。工程判断落在数据侧：在扩大模型之前，先检查目标类别在训练分布中的覆盖密度与材质通道的完整性。
