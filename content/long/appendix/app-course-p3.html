一 · 一张图：把 60 分钟路线压成决策链

“60 分钟速成”不是把全书读薄，而是把一条可执行链路钉在墙上：看一张图、读一个故事、做三道题、跑一个最小复现。这里的“图”不是知识地图，而是决策链——给定输入（照片、单图、文本、多视图）与约束（时间、显存、是否要显式网格、是否要重光照），你该走哪条表示与优化路线。决策链的第一层是“表示”：辐射场（NeRF 系）、显式高斯（3DGS 系）、隐式表面（SDF/NeuS 系）、原生 3D 潜变量（三平面/稀疏体素/点云/隐式函数参数）。第二层是“监督”：逐场景优化（每场景一个模型）、前馈推理（一次前向出表示）、2D 先验蒸馏（SDS/VSD 家族）、多视图扩散（零样本新视角）。第三层是“产物”：可渲染、可提取网格、可编辑、可进引擎。

把三层交叉，就得到速查表的主轴。表中每一行是一个“工程判断”，而不是论文分类。判断的依据是代价：逐场景优化的代价是时间与每场景算力；前馈推理的代价是训练数据规模与泛化边界；SDS 的代价是过饱和、Janus（两张脸）与多样性塌缩；多视图扩散的代价是视角数固定、背面靠猜；显式网格的代价是拓扑与薄结构；高斯的代价是漂浮物与显存。下表把常用路线的“输入—机制—产物—主要代价”压成一行，供你在白板上直接圈选。

二 · 一个故事：小泥的七次投胎与木工房

故事里的“小泥”是一团要被做成摆件的泥。它七次投胎，对应七种表示与七种代价。第一次投胎成辐射场：只有 2D 照片和相机位姿，却要学出 3D。关键链路是 5D 输入（位置+视角）→体渲染积分与透射率 T→分层采样/位置编码→渲染损失对 3D 参数可微。它能长出体积雾与视角相关高光，但产物是“场”，要进引擎还得提取网格，提取不可微且易丢薄结构。第二次投胎成哈希编码：Instant-NGP 的哈希表必然冲突，为什么还能记住细节？因为多分辨率分层让冲突由多层平均与梯度消化，小 MLP 只做解码；L、T、F 三个超参构成三角权衡——层数、表大小、特征维，任一项拉满都会挤压另两项的预算。冲突不是 bug，是被平均掉的噪声。

第三次投胎成高斯：一只 3D 高斯投影到屏幕，协方差按 R S Sᵀ Rᵀ 分解，投影公式 Σ'=J W Σ Wᵀ Jᵀ，再按深度排序做 alpha 合成；致密化与剪枝控制数量。排序不是美学要求，是 alpha 合成的前置条件：不按深度排，前后遮挡关系错，合成结果在视角变化时跳变。第四次投胎成 SDF：NeuS 把 SDF 转成密度，β 退火设错会出现两类典型失败——β 大到表面糊，β 小到薄结构噪/发散；Eikonal 正则 ||∇f||=1 约束梯度模长，零等值面即表面。VolSDF 与 NeuS 的差别主要在 SDF 到密度的 CDF 选择（Laplace 对 logistic）与 α/β 参数化，共同依赖 Eikonal 与退火。退火 schedule 是隐形超参，写进配置文件却常被当成常数。

第五次投胎成“偷梦”：SDS 的梯度形式把 2D 得分经渲染雅可比回传，逐视角独立优化会让模型长出“两张脸”（Janus）——每个视角都满足 2D 先验，但视角之间没有一致性约束；CFG 与随机相机只是缓解。SJC 的“扰动”是把渲染图加噪到 2D 模型训练分布，再用 PAAS 平均降方差，得分经雅可比回传，与 SDS 同族。VSD 的核心差别是加粒子模型 ε_ψ，梯度含 (ε_φ−ε_ψ)，从 KL/变分视角缓解过饱和与多样性差。Magic3D 两阶段：低分辨率 NeRF 粗模→DMTet+可微渲染 512 分辨率精修，探索与精修分离所以更细；Fantasia3D 先几何后外观，因为纹理掩盖几何，DMTet+BRDF 支持重光照；TextMesh 直接优化显式网格顶点/纹理，省掉网格提取，深度/法线条件辅助。

第六次投胎成“合唱团”：Zero-1-to-3 输入参考图+相对位姿，多视图数据训练，零样本换视角，但它不是直接出 3D；MVDream 把 4 视图 token 拼接，3D 自注意力跨视角互相看见，代价是计算量×4、视角数固定；SyncDreamer 用 16 个固定视角，共享 3D 代价体在去噪中投影-采样同步；Wonder3D 颜色+法线双分支，跨域共享注意力让两者对齐，多视图法线融合约束几何；InstantMesh 用 4 视图 LRM 前向+FlexiCubes 可微提取，速度与拓扑折中；CRM 用 6 视图卷积精修三平面，卷积比全局注意力便宜，输出带纹理网格；Hi3DGen 用法线桥接，多视图法线监督让高频细节更稳，法线错误会传播。

第七次投胎进“木工房”：前馈工厂。LRM 主干是 ViT+cross-attention Transformer，输出三平面，多视角渲染损失，50 万物体训练，所以一次前向而非逐物体优化；TripoSR 简化 LRM 框架，三平面+NeRF 渲染，大规模数据+混合精度/工程优化把单图重建压到 0.5 秒；GS-LRM 把输出换成高斯，光栅化实时、显式可编辑，但带来漂浮物/稳定性/显存问题；MeshLRM 做可微网格而非“先出 NeRF 再提取”，梯度回顶点，拓扑/薄结构更好；LGM 用 4 视图输入、多视图 Transformer、高斯输出，高分辨率实时；Direct3D 先训 3D VAE 压缩再在潜空间用 DiT 扩散，压缩与生成解耦；TRELLIS 的 SLAT 是稀疏体素+局部三平面，3D DiT+rectified flow，一套潜变量可解成高斯、网格、辐射场；Hunyuan3D 2.0 形状 DiT+纹理 DiT 分开迭代，代价是误差累积与接口对齐；2.1 的 PBR 三通道 base color/metallic/roughness 要 delighting 去光照，才能进引擎标准输入；CraftsMan3D 的“网格匠人”把重拓扑与部件生成当成独立手艺。

故事的用法不是复述，而是把“投胎顺序”当排错顺序：产物不对，先问表示选错没有；表示对了但表面糊，问退火与正则；表面干净但视角跳，问排序与一致性；视角一致但过饱和，问 SDS 族与 VSD；前馈快但泛化差，问训练分布与输出头。七次投胎对应七类失败模式，每类都有可观测症状。

三 · 三道题：从链路到超参到失败模式

第一题（链路题）：NeRF 只有 2D 照片和相机位姿，为什么能学出 3D？请写出它把 3D 变成像素的关键链路。答题要点必须落在四个环节：5D 输入（位置+视角）；体渲染积分与透射率 T；分层采样/位置编码；渲染损失对 3D 参数可微。评分看是否写出“可微”是闭环的关键——没有可微，2D 像素误差无法回传到 3D 密度与颜色。常见错答是只写“MLP 拟合”，漏掉积分与透射率，等于漏掉遮挡与深度。延伸问：如果把分层采样换成均匀采样，近表面细节的梯度信号会被稀释，收敛变慢，这是系统代价而非精度问题。

第二题（超参题）：Instant-NGP 的哈希表必然冲突，为什么还能把细节记住？L、T、F 三个超参各管什么？要点：多分辨率分层；哈希冲突由多层平均与梯度消化；L/T/F 的三角权衡；小 MLP 只做解码。答题时要给出“冲突被谁消化”的机制：同一空间位置在不同分辨率层落到不同桶，粗层提供平滑底座，细层提供细节，冲突表现为跨层混叠而非单层崩溃。三角权衡的工程含义是：显存预算固定时，L 增则 T 或 F 必须减，细层容量被挤压，细节先丢。延伸问：把 F 拉大而 T 不变，桶内特征维变高但碰撞概率不变，冲突的“平均”变得更贵。

第三题（失败模式题）：NeuS 的 β 退火如果设错，会出现哪两类典型失败？Eikonal 正则又在约束什么？要点：β 大到表面糊，β 小到薄结构噪/发散；Eikonal ||∇f||=1；零等值面即表面；β 退火 schedule 是隐形超参。答题要区分“糊”与“噪”的机理：β 大时密度对 SDF 的过渡带变宽，零等值面附近的权重弥散，表面被体积化；β 小时过渡带过窄，薄结构采样不足，梯度噪声放大甚至发散。Eikonal 约束梯度模长为 1，使 SDF 近似距离函数，零等值面才对应真实表面。延伸问：VolSDF 与 NeuS 都把 SDF 转成密度，差别在 CDF 选择（Laplace 对 logistic）与 α/β 参数化，共同依赖 Eikonal 与退火——所以换实现不等于换正则。

三道题的共同结构是“机制—公式—代价—例子”。第一题的公式是体渲染积分与透射率；第二题没有闭式公式，但有伪代码思路：多分辨率层循环→哈希桶索引→特征插值→拼接→小 MLP 解码；第三题的公式是 Eikonal 与 CDF 转密度。做题时把公式写在草稿纸左上角，把代价写在右下角，中间写例子，这个版式就是速查卡的雏形。

$$T(t)=\exp\left(-\int_{t_n}^{t}\sigma(s)\,ds\right),\qquad C=\int_{t_n}^{t_f}T(t)\,\sigma(t)\,c(t)\,dt$$
$$\|\nabla f\|=1,\qquad \sigma(x)=\alpha\,\Phi_\beta(-f(x))\ \text{（CDF 转密度）}$$

四 · 最小复现：跑通一条链路而不是跑完一个项目

“跑一个最小复现”的目标不是复现论文指标，而是让一条链路在你的机器上闭环：输入→表示→渲染→损失→梯度→更新→可视化。最小复现的选型原则是“单卡、单场景、单脚本、可观测”。NeRF 系最小复现：一张合成场景的多视角图+位姿，位置编码+小 MLP+分层采样+体渲染，损失是像素 MSE，输出一张新视角图；观测点是透射率曲线与深度图是否随训练收敛。Instant-NGP 系最小复现：把位置编码换成多分辨率哈希，保持其余不变，观察收敛步数与显存占用的变化；观测点是冲突层的特征范数是否被平均掉。3DGS 系最小复现：初始化点云+协方差参数，投影+排序+alpha 合成，致密化与剪枝各一个阈值；观测点是高斯数量曲线与漂浮物比例。

最小复现的系统代价要提前写进脚本：显存峰值、每步时间、收敛步数、产物大小。失败模式要可观测：NeRF 系常见失败是透射率不收敛导致背景雾；哈希系常见失败是细层冲突导致高频噪点；高斯系常见失败是排序错误导致视角跳变、致密化过度导致显存爆。复现脚本要留一个“开关”用于对照：关掉位置编码、关掉分层采样、关掉深度排序、关掉 Eikonal，各跑一次，观察症状是否与速查表一致。对照实验比指标更能教会你机制。

最小复现的验收标准是三条：一是能生成一张可辨认的新视角图；二是能打印出至少一个中间量（透射率、深度、高斯数量、SDF 梯度范数）；三是能复现一个已知失败模式并说清触发条件。三条都过，说明链路闭环；只过第一条，说明你只是跑通了前向。工程判断是：最小复现的价值在“可观测的中间量”，没有中间量的复现等于黑箱演示。

  • 输入检查：位姿约定（世界到相机还是相机到世界）、图像归一化、近远平面，三处错一处链路就断。
  • 数值检查：透射率是否单调下降、SDF 梯度范数是否接近 1、高斯深度排序是否随视角变化。
  • 代价检查：显存峰值是否随分辨率平方增长、哈希层数增加是否挤压表大小、高斯致密化是否失控。
  • 失败对照：逐个关闭关键组件，记录症状，形成自己的“症状—原因”表。

自测的用法是“错题驱动”：错哪题就回到哪一行，把该行的机制、公式、代价、例子各写一句，再跑一次最小复现的对照开关。三轮之后，速查表不再是表，而是你排错时的条件反射。最后落在具体机制上：任何一条 3D 生成路线，先问它的表示如何被渲染成像素、损失如何回传到表示参数、产物如何离开训练环境；这三问的答案就是选型与排错的全部依据。
