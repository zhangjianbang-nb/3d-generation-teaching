一 · 按方向分组的核验清单

附录的论文清单不是一份“读过就好”的收藏夹，而是一张按方向分组的索引表：49 篇核验论文，每条给出标题、年份、venue、方向、类型与一句话贡献。它的用法取决于你带着什么问题去查。工程上最有效的读法是“先定方向，再定类型，最后核对贡献句是否支撑你的选型假设”。方向回答“这篇论文解决哪一类问题”，类型回答“它是表示、是训练技巧、是系统、还是综述”，贡献句回答“它相对同组其他条目新增了什么”。三者缺一，条目就退化成标题列表。

把清单当作速查表时，需要先建立分组骨架。按全书结构，清单的方向至少覆盖：可微渲染与体渲染基础、哈希编码与显式表示、SDF 与表面重建、原生 3D 生成表示（三平面、点云、隐式函数）、SDS 文本到 3D、前馈重建与生成、网格后处理、场景与世界模型、数据与材质。分组不是装饰，它决定了你查表时的检索路径：如果你要解决“训练慢”，应该落在哈希编码与 3DGS 组；如果要解决“表面有孔洞”，落在 NeuS/VolSDF 组；如果要解决“文本生成几何不稳定”，落在 SDS 家族组。

类型字段的工程价值常被低估。同一方向里，表示类论文给出的是“场景用什么参数化”，系统类论文给出的是“这套参数化怎么在 GPU 上跑起来”，训练技巧类论文给出的是“损失与采样怎么改”。例如 3D Gaussian Splatting 属于表示加系统的混合体：它既定义了高斯基元（位置、协方差、不透明度、球谐颜色），又定义了投影、深度排序、alpha 混合的渲染管线，还定义了训练期的致密化与剪枝。你若只把它当“表示”读，会漏掉显式、可并行、可微这条系统线索；若只把它当“渲染加速”读，会漏掉致密化策略对内存的决定性影响。

一句话贡献的核对方法：把贡献句拆成“输入—机制—输出”三段。以 pixelNeRF 为例，输入是“一张或少量图像 + 相机位姿”，机制是“2D CNN 特征网格 + 按位姿投影双线性采样 + 拼接查询坐标送 MLP”，输出是“密度与颜色”。三段都能对上，说明这条目与你的任务形态匹配；若你的输入是单图但位姿未知，贡献句里没有位姿估计，这条目就不足以单独支撑方案。清单的作用正是把这种缺口显式化。

二 · 横向对比：同一问题的不同解法

速查表真正的用处是横向对比，而不是纵向罗列。以“如何把 3D 场变成可优化参数”为主线，可以把清单里的条目排成一条谱：NeRF 用 MLP 拟合 5D 函数 F(x,y,z,θ,φ)→(RGB,密度)，参数全在权重里，表达力靠宽度与深度，代价是每条射线要采样大量点做体渲染积分；Instant NGP 把高频细节外包给多分辨率可学习哈希表，坐标在 L 个层级上量化并哈希到固定大小表项，拼接特征后只过一个小 MLP，哈希冲突由多层级与梯度平均自然消解；3DGS 干脆放弃连续场，用一堆带协方差的高斯基元，投影到屏幕、按深度排序、alpha 混合，显式、可并行、可微。三者的参数增长方式完全不同：MLP 是稠密权重，哈希表是固定预算的稀疏查表，高斯是随场景自适应增删的图元集合。

表面质量的谱系同样值得并排看。NeRF 的密度是标量场，零等值面不天然对应表面，提取网格需要额外阈值与后处理。NeuS 把密度定义为 SDF 经 logistic 变换后的概率密度，σ(x)=αΨ_β(−f(x))，Ψ_β 是 sigmoid，f 是 SDF；这样体渲染的 alpha 在零等值面附近达到峰值，零等值面自然成为表面。Volume Rendering of Neural Implicit Surfaces 用 scaled CDF 做同样的映射，α(x)=Ψ_β(−f(x))，β 控制表面厚度，密度在表面附近集中、远离表面趋于 0。两条目的差别在映射函数的选择与 β 的语义，但共同点是：把“表面在哪”从后处理问题变成渲染积分的内在性质。

$$\sigma(x)=\alpha\,\Psi_\beta\big(-f(x)\big),\qquad \alpha(x)=\Psi_\beta\big(-f(x)\big)$$

生成侧的对比要按“表示切换点”来读。EG3D 把 3D 场分解成三个正交 2D 特征平面，生成器用 2D 卷积生成三平面，查询 3D 点时插值拼接再送小 MLP 解码密度与颜色，3D 一致性由三平面共享与 2D 判别器共同约束；GET3D 用 DMTet 作为可微网格表示，生成器预测四面体顶点的 SDF 与纹理，按符号切出三角面，几何分支与纹理分支共享主干但分开解码；Point-E 两阶段，先文本到图像扩散生成一张图，再图像到点云扩散生成 1024 个点，点云扩散用 Transformer 去噪、条件为图像嵌入；Shap-E 训练编码器把 3D 资产映射成隐式函数的潜变量，在潜空间做扩散，解码器把潜变量变回隐式函数再提取网格。四者的输出形态依次是：三平面场、网格、点云、隐式函数，选型时先问“下游管线吃什么”，再回查表。

SDS 家族的对比轴是“梯度从哪来、在哪个表示上更新”。DreamFusion 用可微渲染器把 3D 表示渲染成图，加噪后送进冻结的 2D 扩散模型，用“预测噪声 − 实际噪声”作为梯度方向更新 3D 参数，CFG 增强文本对齐；Score Jacobian Chaining 显式写出链式法则：渲染图 x 是 3D 参数 θ 的函数，2D 扩散给出图像得分 ∇log p_t(x)，乘渲染雅可比 ∂x/∂θ 得到 θ 空间得分，再用退火 Langevin 动力学采样；ProlificDreamer 把 θ 视为分布 q(θ)，用可学习粒子（LoRA）近似 q 的得分，VSD 梯度等于预训练扩散得分减粒子得分，等价于最小化 q 与文本条件分布的 KL。三者对“多样性”的处理不同：前者是单点优化，中者是采样，后者显式建模分布。

三 · 自测题：用清单反查理解

自测题的设计原则是“答案必须落在清单条目上”，而不是泛泛的概念问答。下面每组题都对应一个具体机制，答不上来时回到对应条目核对贡献句。

  • 题 1：NeRF 的体渲染积分为什么可以对 MLP 参数求导？答：像素颜色是沿相机射线对 (RGB,密度) 的积分，积分运算对 MLP 权重可微，多视角照片的 RGB 损失因此能直接优化 3D 场。追问：若把积分改成离散求和，梯度路径是否仍然成立？
  • 题 2：Instant NGP 的哈希冲突为什么不致命？答：坐标在 L 个分辨率层级上量化并哈希到固定大小表项，多层级提供冗余，梯度在冲突表项上平均，冲突被自然消解。追问：层级数 L 与表大小如何共同决定高频细节上限？
  • 题 3：3DGS 训练中致密化与剪枝解决什么问题？答：初始高斯不足以覆盖场景，致密化在梯度大的区域增删图元，剪枝去掉低不透明度或过大的图元，自适应控制图元数量。追问：图元数量增长对显存与排序代价的影响是线性的吗？
  • 题 4：NeuS 中 σ(x)=αΨ_β(−f(x)) 的 β 起什么作用？答：Ψ_β 是 sigmoid，β 控制过渡带宽度，alpha 在零等值面附近达到峰值，零等值面成为表面。追问：β 过大或过小分别导致什么渲染伪影？
  • 题 5：pixelNeRF 如何把 2D 特征送进 3D 查询？答：2D CNN 提取每张输入图的特征网格，对每个 3D 查询点按相机位姿投影到各输入视图，双线性采样特征，与查询坐标/方向拼接后送 MLP 输出密度与颜色。追问：输入视图增多时特征拼接维度如何变化？
  • 题 6：EG3D 的三平面为什么能保证 3D 一致性？答：三个正交 2D 特征平面共享查询点的插值拼接，2D 判别器在渲染图上对抗训练，一致性由共享与判别共同约束。追问：三平面分辨率提升的代价落在哪一层？
  • 题 7：Score Jacobian Chaining 与 DreamFusion 的梯度形式差别在哪？答：前者显式乘渲染雅可比 ∂x/∂θ 得到 θ 空间得分再退火 Langevin 采样；后者直接用噪声残差作为梯度方向。追问：雅可比链式法则在渲染器不可微部分如何处理？
  • 题 8：Magic3D 为什么要从 NeRF 切到 DMTet？答：粗阶段低分辨率 NeRF + SDS 负责全局形状，细阶段把粗几何转成 DMTet 网格，用高分辨率可微渲染 + SDS 精修纹理与几何，网格表示更适合高分辨率细节。追问：切换点选早了会怎样？
  • 题 9：DreamGaussian 的两阶段各做什么？答：先用 3DGS 作为表示、SDS 直接优化高斯参数，收敛后从高斯提取网格，再在 UV 空间精修纹理。追问：高斯到网格的提取损失哪些信息？
  • 题 10：3DGS 综述把管线拆成哪五段？答：高斯基元—投影—排序—混合—致密化，并按表示增强、渲染加速、压缩、动态、生成、应用六个维度梳理文献。追问：压缩维度主要压的是哪部分参数？

每道题的追问都是工程判断的入口。以题 3 为例，致密化的触发条件若只看位置梯度，会在纹理高频区过度增图元，导致排序与混合的每帧代价上升；若同时约束不透明度与尺度，图元数量增长更可控。这类判断无法从贡献句直接读出，必须回到机制层。

四 · 延伸阅读的排序策略

清单里的 49 条不是等权重的。延伸阅读应按“依赖深度”排序：先读被后续条目反复引用的基础机制，再读在其上做替换的变体，最后读综述与系统整合。以体渲染线为例，NeRF 定义了 5D 函数与积分，是后续几乎所有隐式场条目的语法基础；NeuS 与 Volume Rendering of Neural Implicit Surfaces 替换的是密度到不透明度的映射，属于“同一积分、不同映射”的变体；Instant NGP 替换的是坐标编码，属于“同一积分、不同参数化”；3DGS 则替换了整个渲染管线，从体渲染积分改为投影排序混合。按这个顺序读，每步只改一个变量，理解成本最低。

SDS 线同理。DreamFusion 给出噪声残差这一最简梯度形式；Score Jacobian Chaining 把它写成显式的链式法则，暴露雅可比这一中间量；ProlificDreamer 把单点参数换成分布，引入粒子得分；Magic3D、Fantasia3D、TextMesh、DreamGaussian 则分别在阶段划分、几何外观分离、深度条件、表示切换上做工程改造。若跳过前三条直接读工程改造条目，你会看到一堆“两阶段”“分离”“条件”的术语，却不知道它们在修正哪个梯度缺陷。

综述条目应放在最后读，而不是最先读。3DGS 综述把管线拆成五段、按六个维度梳理文献并对比 NeRF 类方法优劣，它的价值是在你已有机制直觉后提供地图；若先读综述，五段管线只是名词，六个维度只是目录。延伸阅读的排序策略本质上是把“地图”放在“地形”之后。

一个具体的排序例子：若你的任务是“单图生成可编辑网格”，合理的阅读顺序是 pixelNeRF（单图条件场的特征采样机制）→ EG3D（三平面共享约束一致性）→ GET3D（DMTet 可微网格与分支解码）→ Shap-E（隐式函数潜空间扩散）→ DreamGaussian（高斯到网格的提取与 UV 精修）。每步都在回答“上一部的输出如何变成下一部的输入”，而不是并列地刷完五篇。

五 · 清单的维护与失效边界

速查表会失效，失效点必须写清楚。清单条目的年份与 venue 是核验过的，但“一句话贡献”是对论文机制的压缩，压缩必然丢信息。以 3DGS 为例，贡献句写“投影到屏幕、按深度排序、做 alpha 混合，整个过程显式、可并行、可微；训练中通过致密化与剪枝自适应增删高斯”，这句话没有给出排序算法的具体形式，也没有给出致密化的阈值规则。工程实现时若只按这句话写，排序稳定性与图元爆炸这两个失败模式都会出现。清单的正确用法是“定位条目”，不是“替代论文”。

另一个失效边界是方向分组之间的重叠。DreamGaussian 同时属于 SDS 家族与 3DGS 显式表示，TextMesh 同时属于 SDS 与网格表示，EG3D 同时属于原生 3D 生成与前馈生成。分组是为了检索，不是为了排他。查表时应允许一条目出现在多个检索路径上，并在对比时明确你比较的是它的哪一面：比较 DreamGaussian 与 DreamFusion 时比的是梯度机制，比较 DreamGaussian 与 3DGS 时比的是表示与提取管线。

维护清单的工程习惯：每次选型后回写一条“为什么没选某条目”。例如你选了 NeuS 而非原始 NeRF 做表面提取，回写理由应是“零等值面自然成为表面，省去阈值后处理”，而不是“效果更好”。前者是可核对的机制差异，后者是不可核对的判断。清单随时间增长的价值，正来自这些可核对的回写记录。

最后落在具体机制上：清单的检索键应该是“表示形式 + 梯度来源 + 失败模式”三元组，而不是标题字母序。按三元组查表，NeRF 落在“MLP 隐式场 + RGB 积分 + 采样不足”，Instant NGP 落在“哈希表 + RGB 积分 + 冲突与层级预算”，3DGS 落在“高斯基元 + 投影混合 + 排序与致密化失控”，NeuS 落在“SDF + logistic 映射 + β 过渡带”，DreamFusion 落在“隐式场 + 噪声残差 + 过饱和”。三元组一致，条目才真正可被工程判断调用。
