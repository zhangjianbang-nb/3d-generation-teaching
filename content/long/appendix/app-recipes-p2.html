一 · 体渲染积分的离散化：配方里最容易写错的一步

复现 NeRF 类配方时，绝大多数“跑不起来”或“跑出来是雾”的问题不在 MLP 结构，而在体渲染积分的离散采样约定。连续形式是沿射线的透射率积分：颜色等于 ∫ T(t)·σ(t)·c(t) dt，其中 T(t)=exp(−∫σ ds)。工程实现必须把它换成有限个采样点的求和，而求和公式里 Δt 的定义、采样区间的开闭、以及“最后一个采样点的透射率是否参与颜色累加”，三处只要有一处与参考实现不一致，梯度就会系统性偏移。

离散形式通常写成 α_i = 1 − exp(−σ_i·δ_i)，权重 w_i = T_i·α_i，T_i = Π_{j<i}(1−α_j)，像素颜色为 Σ w_i·c_i。注意 δ_i 是相邻采样点之间的距离，不是均匀步长；在分层采样（粗网络 + 细网络）中，细网络的采样点来自粗网络权重的逆变换采样，δ_i 因此不均匀。若代码里把 δ 写成常数，细网络阶段的颜色就会偏向采样密集区，表现为表面附近过亮、背景过暗。

$$w_i = \exp\Big(-\sum_{j<i}\sigma_j\delta_j\Big)\big(1-e^{-\sigma_i\delta_i}\big),\quad \hat{C}=\sum_i w_i c_i$$

一个具体的失败模式：把 δ 取成 1（归一化坐标下常见），同时把近远平面设成 0 到 1，采样数 N=64。此时每个 δ 实际应为 1/64 量级，若误写为 1，σ 的梯度会被放大 64 倍，训练前几百步密度就饱和到极大值，渲染结果是一片不透明的前景墙，损失下降后卡住。验收断言应当包括：对一条射线，Σ w_i 在无遮挡时应接近 1；把 σ 全部置零时输出应为背景色而非黑色；以及 δ 的均值应等于 (t_far−t_near)/N。

另一个易错点是“白背景”与“黑背景”的合成顺序。NeRF 原始配方在最后一步把累积颜色与背景色按 (1−Σw_i) 混合，若数据集是白底，必须显式加白，否则学出来的密度会在无物体区域残留，因为模型用残余密度去拟合白色。这个细节在合成数据集（Blender 渲染）与真实捕获数据之间切换时尤其致命：同一份代码换数据集，白底忘了改，PSNR 会掉一大截，而人眼看上去只是“边缘发灰”。

二 · 哈希编码的层级与表大小：冲突不是 bug，是设计

Instant NGP 的配方把大 MLP 的高频细节职责转移给多分辨率哈希表。机制是：对查询坐标 x，在 L 个分辨率层级上分别量化到网格，每层网格顶点通过一个哈希函数映射到固定大小的表项数组，取出的 F 维特征拼接后送入一个小 MLP。层级分辨率从粗到细按几何级数增长，粗层负责低频、细层负责高频。哈希冲突由多层级冗余与梯度平均自然消解：同一表项被多个顶点共享时，梯度是这些顶点贡献的叠加，只要层级足够多，冲突带来的混叠会被粗层的一致性约束压住。

配方中的关键超参是表大小 T、每层特征维数 F、层级数 L、以及最细层分辨率 N_max。常见的最小可跑配置是 T 在 2^19 到 2^21 量级、F=2 或 4、L=16 左右、N_max 取 512 到 2048。这里有一个容易错的细节：最细层分辨率决定了能表达的最高频率，但它与表大小共同决定冲突率。若把 N_max 调大而不同步调大 T，冲突率上升，表现为高频细节变成块状噪声，且训练损失下降变慢。冲突率可以粗略按“顶点数 / 表项数”估计，顶点数约为 Σ_l N_l^3，当这个比值接近或超过 1 时，细层实际上退化成随机特征。

参数作用调错的症状验收断言

系统代价方面，哈希表是显存大户：T×L×F 个浮点数，T=2^21、L=16、F=2 时约 6700 万个参数，单精度约 268 MB，加上优化器状态会翻数倍。这也是为什么 NGP 配方强调“小 MLP + 大表”而非“大 MLP”：表可以按需增长，MLP 不能。失败模式还包括哈希函数本身的实现：若用简单的取模哈希且量化坐标存在负数，取模在不同语言里符号不同，会导致特征错位，表现为训练完全无法收敛但代码不报错。验收断言：固定随机种子后，同一坐标两次查询应返回完全相同的特征；以及把表全部置零时输出应等于小 MLP 的偏置输出。

三 · 3DGS 的致密化与剪枝：自适应增删的判据

3D Gaussian Splatting 把场景表示为一堆带位置、协方差、不透明度、球谐颜色的 3D 高斯。渲染时把每个高斯投影到屏幕，按深度排序，做 alpha 混合。整个过程显式、可并行、可微。配方中最容易被忽略的是训练中的致密化与剪枝：这不是可选的调参，而是表示本身的自适应机制。判据通常基于位置梯度的幅值：梯度大的高斯说明该区域欠拟合，需要分裂或克隆；不透明度低于阈值且尺寸过大的高斯则被剪枝。

具体机制可以写成伪代码思路：每隔固定步数遍历所有高斯，若某高斯的位置梯度范数超过阈值，则按两种方式之一处理——克隆（复制一份并沿梯度方向微移）用于填补空洞，分裂（把协方差缩小并生成两个子高斯）用于细化过大的椭球。同时，对不透明度低于阈值的 Gaussian 执行剪枝。分裂与克隆的数量需要上限约束，否则高斯数会指数增长，显存与排序开销随之爆炸。

$$\text{densify if }\|\nabla_\mu L\|_2>\tau_\mu,\quad \text{prune if }\alpha<\tau_\alpha \text{ and } s>s_{\max}$$

一个具体例子：在稀疏视角（比如只有 8 张图）下复现，初始高斯数若按 SfM 点云给定，致密化阈值设得过低，会在无观测区域疯狂克隆，高斯数在几千步内翻十倍，排序阶段成为瓶颈，帧率从实时掉到个位数，而视觉质量并未提升——因为这些高斯没有多视图约束，只是在拟合单视图的噪声。验收断言应包括：高斯总数随训练步数的增长曲线应趋于平台而非线性上升；以及渲染时每个像素覆盖的高斯数应有上限，超过上限说明致密化失控。

另一个易错细节是协方差参数化。配方通常不直接优化 3×3 协方差矩阵，而是优化一个旋转四元数和一个三维缩放向量，再组合成 Σ = R S S^T R^T。这样做的原因是协方差必须半正定，直接优化矩阵会遇到约束问题。但四元数的归一化若在优化器更新后忘记执行，旋转会漂移，投影后的椭圆会逐渐变形，表现为训练后期画面出现拉伸条纹。验收断言：每次参数更新后检查四元数范数是否接近 1；以及协方差矩阵的最小特征值应为正。

四 · SDF 到密度的变换：β 控制的是表面厚度而非细节

NeuS 与 VolSDF 两条配方共享一个核心思想：把 SDF 经 logistic 或 scaled CDF 变换成体渲染所需的概率密度，使 alpha 在零等值面附近达到峰值，零等值面自然成为表面。NeuS 的形式是 σ(x)=αΨ_β(−f(x))，其中 f 是 SDF、Ψ_β 是 sigmoid；VolSDF 用 Laplace 分布的 CDF。两者都用 β 控制表面附近的密度集中程度。

容易错的细节在于对 β 的直觉：β 变大时表面更“薄”，但这不是“更锐利”的同义词。β 过大会让密度在零等值面附近变成近似 delta 函数，采样点稍有偏离就采不到表面，梯度信号消失，表现为几何出现孔洞或训练停滞；β 过小则表面模糊，重建出“胖”几何，薄壁结构被填实。配方中常见的做法是 β 从较大值退火到较小值，先粗后细，但退火日程若与学习率日程耦合不当，会在中途出现表面突然收缩的跳变。

$$\sigma(x)=\alpha\,\Psi_\beta(-f(x)),\quad \Psi_\beta \text{ 为 sigmoid 或 scaled CDF}$$

系统代价方面，SDF 类配方要求采样点足够密才能捕捉薄表面，这直接推高每条射线的采样数，渲染与训练成本高于纯 NeRF。失败模式还包括 Eikonal 正则的权重：SDF 应满足梯度范数为 1，若正则权重过低，f 会退化成任意标量场，零等值面虽然存在但不对应真实表面，表现为渲染颜色对但提取的网格破碎。验收断言：在表面附近采样点上，SDF 梯度范数的均值应接近 1；以及提取网格的连通分量数不应随训练步数剧烈波动。

一个具体例子：复现薄壁物体（比如叶片或布料）时，若 β 取固定小值且采样数不足，体渲染的 alpha 峰值落在采样点之间，权重 w_i 在整条射线上都很小且分散，颜色是多个采样点的平均，表面看起来半透明。此时提高采样数比调 β 更有效，因为问题出在离散化而非密度形状。这个判断顺序是配方里值得写死的工程经验：先查采样密度与 δ，再查 β。

五 · SDS 的梯度方向与 CFG：符号错一位，结果全变

DreamFusion 类配方用冻结的 2D 扩散模型给 3D 表示提供梯度。机制是：用可微渲染器把 3D 表示渲染成图，加噪后送入扩散模型，取“预测噪声 − 实际噪声”作为更新 3D 参数的方向，即 SDS。这个方向的符号与缩放极其敏感：符号反了，3D 参数会朝让图像更不像文本的方向走，表现为几何坍缩成噪声球；缩放过大，每步更新跨越多个模式，画面出现高频振铃。

CFG（无分类器引导）在 SDS 里不是可选项而是文本对齐的主要来源。配方通常把条件与无条件噪声预测做外推：ε = ε_uncond + s·(ε_cond − ε_uncond)，s 为引导强度。容易错的细节是：SDS 的梯度应当用哪一个 ε 计算。若用未引导的 ε_cond，文本对齐弱；若用引导后的 ε，梯度幅值被放大 s 倍，需要同步缩小学习率，否则优化发散。很多复现失败源于把 CFG 只用在采样而忘了它进入梯度。

$$\nabla_\theta L_{\text{SDS}}=\mathbb{E}\big[(\hat{\epsilon}-\epsilon)\,\partial x/\partial\theta\big],\quad \hat{\epsilon}=\epsilon_{\text{uncond}}+s(\epsilon_{\text{cond}}-\epsilon_{\text{uncond}})$$

系统代价：SDS 每步要跑一次扩散模型前向与反向，显存与算力开销远高于纯 NeRF 训练，且没有真值多视图约束，容易过拟合到 2D 模型的偏见，表现为从某些视角看几何合理、换视角则背面崩坏。失败模式还包括加噪时间步 t 的采样分布：t 过大时梯度主要塑造全局形状，t 过小时只修纹理；若日程固定不变，会出现“形状早熟、纹理后期无法改动”的僵局。验收断言：固定文本提示与种子，连续两次运行的渲染图在感知上应接近；以及梯度范数应随训练下降而非震荡。

一个具体例子：复现 DreamGaussian 时，第一阶段用 3DGS + SDS 优化高斯参数，收敛后从高斯提取网格，再在 UV 空间做纹理精修。这里容易错的是提取网格的等值面阈值：高斯的不透明度场不是 SDF，阈值选得偏高会丢掉细薄结构，偏低则网格膨胀。配方里应把阈值与高斯不透明度的分布挂钩，而不是照搬固定常数。两阶段总时间约 2 分钟这一事实说明，SDS 阶段的步数与致密化日程必须紧凑，任何一处多跑几百步都会让总时间翻倍。

六 · 评测断言的写法：把“看起来对”变成可执行检查

复现配方的验收环节最容易流于主观。可执行的断言应当分层：表示层、渲染层、优化层。表示层检查参数是否落在合法域，例如四元数范数、协方差正定、哈希表索引不越界、SDF 梯度范数接近 1。渲染层检查像素统计，例如 Σw_i 的范围、背景色是否正确、深度排序是否单调。优化层检查损失曲线与梯度范数的形态，例如损失应单调下降后平台、梯度范数不应在致密化步出现尖峰后不回落。

一个具体的断言设计：对 NeRF 配方，取一条穿过场景中心的射线，检查权重 w_i 的分布应单峰且峰值位置随训练步数稳定；若出现双峰，说明密度在射线上分裂出两层表面，通常是分层采样或 δ 计算错误的信号。对 3DGS 配方，检查每帧渲染的高斯覆盖计数，若某像素覆盖数超过阈值，说明致密化在该区域失控。对 SDS 配方，检查同一提示在不同种子下的渲染图在低分辨率下的结构相似度，若方差过大，说明引导强度或学习率设置让优化落在不同模式。

这些断言的价值在于把调试从“看图猜”变成“定位到环节”。例如白底数据集上 PSNR 下降，若 Σw_i 断言通过而背景合成断言失败，问题就锁定在背景色而非密度场；若两者都通过而损失曲线在致密化步尖峰后不回落，问题就在 3DGS 的剪枝阈值。配方写作时应把每条断言与一个具体环节绑定，而不是笼统地写“检查渲染质量”。这也是复现配方与论文方法部分的区别：论文给的是思想，配方给的是可执行的检查点与它们的因果归属。
