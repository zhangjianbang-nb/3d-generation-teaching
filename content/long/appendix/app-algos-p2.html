一 · 体渲染积分的离散化：从 NeRF 到 NeuS 的同一套求积

NeRF 把像素颜色写成沿射线的积分，工程实现里必须把它换成有限求和。设射线起点 o、方向 d，在近端 t_n 与远端 t_f 之间切 N 段，第 i 段长度为 δ_i，采样点为 t_i，则颜色估计为

$$\hat{C}=\sum_{i=1}^{N} T_i\,\bigl(1-\exp(-\sigma_i\delta_i)\bigr)\,c_i,\qquad T_i=\exp\Bigl(-\sum_{j

这里 T_i 是透射率，括号内那一项就是该段的 alpha。注意一个容易错的细节：alpha 不是 σ_i δ_i，而是 1−exp(−σ_i δ_i)。当 σ_i δ_i 很小时两者近似相等，但在密度高的区域，用线性近似会把 alpha 算到大于 1，导致 T_i 变成负数、梯度爆炸。这是复现 NeRF 时最常见的数值 bug，尤其在训练初期密度尚未收敛时。

NeuS 的关键改动正是针对这个 alpha。它不再让密度自由浮动，而是把密度定义为 SDF 值 f 经过 logistic 变换后的概率密度：

$$\sigma(t)=\frac{\alpha\,\Phi_\beta\bigl(-f(\mathbf{x}(t))\bigr)}{1-\Phi_\beta\bigl(-f(\mathbf{x}(t))\bigr)}$$

其中 Φ_β 是尺度为 β 的 logistic 累积分布。这个式子的作用是：alpha 在零等值面附近取峰值，离表面越远衰减越快。于是体渲染的可微性被保留，同时提取出的零等值面是水密、平滑的。代价是 β 需要退火——β 太大时表面过渡带过宽，提取的网格会糊；β 太小时梯度只在极窄的带内非零，远处采样点拿不到有效监督。工程上通常让 β 随训练步数从大到小变化，这个调度写错会让整个训练塌掉。

具体例子：一条穿过球体的射线，若采样点全部落在球外且 SDF 全为正，NeuS 的 σ 接近零，该射线对损失的贡献几乎为零；而 NeRF 的 MLP 可能在球外也输出中等密度，产生“雾”。这就是为什么 NeuS 在同样视角数下能给出干净表面，而 NeRF 的密度场往往带一层壳。系统代价是 NeuS 需要额外的 Eikonal 正则（SDF 梯度模长接近 1），每个采样点都要算一次梯度，反向传播的显存开销比纯 NeRF 高。

二 · 哈希编码的冲突消解：多分辨率层级如何兜底

多分辨率哈希编码把 3D 点映射到 L 个分辨率层级的可学习表。每层分辨率从粗到细，粗层表小、细层表大。查询时对每层做体素内插值，把 L 个特征拼接后送一个小 MLP。核心机制是：细层的哈希表远小于该分辨率下的体素总数，冲突不可避免，但冲突由“多个层级 + 小 MLP”共同消解——粗层提供无冲突的低频骨架，细层提供高频细节，MLP 学会从混合特征里分离出有用信号。

伪代码思路如下：对点 x，对每层 l 计算体素坐标下取整与小数部分，用空间哈希函数把 8 个角点映射到表索引，做三线性插值得到 f_l；拼接 [f_1,…,f_L] 与可选的编码（如球谐方向编码），送 MLP 输出颜色与密度。表项用即时更新训练：每个 batch 只更新被采样到的表项，未被采样的表项保持旧值，这让训练能在大表上稀疏地推进。

容易错的细节在哈希函数的选择与表大小。若表太小，细层冲突率过高，高频细节被随机抹平，表现为渲染结果“糊”且训练损失下降后反弹；若表太大，显存占用线性上升，且稀疏更新导致大量表项长期未被训练，推理时出现块状伪影。工程判断是：细层表大小取到该层体素数的某个比例，让冲突率维持在可控范围，而不是盲目堆表。

具体例子：同一场景用纯 MLP 需要很宽的网络才能表达高频纹理，训练慢且难以收敛；换成哈希编码后，小 MLP 加多分辨率表能在更短迭代内达到相近视觉质量。系统代价是显存：L 层表的总量随分辨率增长，且每层都要存特征向量，显存成为主要瓶颈，而不是算力。

三 · 3DGS 光栅化的排序与 alpha 混合：显式表示的代价

3D 高斯泼溅把场景表示成一组高斯，每个带位置均值 μ、协方差 Σ、不透明度 α 与球谐颜色。渲染时把每个高斯投影到屏幕：用视图变换与雅可比把 3D 协方差变成 2D 协方差，得到屏幕上的椭圆；按深度排序后做 alpha 混合。整个过程显式、可并行、可微。

投影的公式核心是 2D 协方差：

$$\Sigma_{2D}=J\,W\,\Sigma\,W^{\top}J^{\top}$$

W 是视图变换的旋转部分，J 是透视投影在均值处的雅可比。这个式子容易写错的地方是 J 的选取：必须在高斯均值处求雅可比，而不是在相机原点；否则离相机近的高斯投影会明显偏移。另一个细节是协方差必须保持正定，工程上通常参数化为缩放与旋转的四元数，再组装 Σ，避免直接优化 Σ 的元素导致非正定。

排序是 3DGS 的性能关键。每帧要对所有高斯按深度排序，高斯数量大时排序成为瓶颈；且排序是全局的，不能简单分块并行。alpha 混合按排序后的顺序累加，公式与体渲染的离散求和同构，但这里 alpha 直接是不透明度乘以 2D 高斯在该像素的值，没有 exp 项。失败模式是“ popping”：当相机移动导致排序顺序突变，重叠区域的颜色会跳变，表现为闪烁。缓解手段包括按 tile 分块排序、限制单像素混合的高斯数量。

具体例子：一个包含大量高斯的场景，若不做数量裁剪，每帧排序与混合的代价随高斯数线性上升，帧率下降；工程上常用不透明度阈值剔除贡献极小的高斯，并在训练后做致密化与剪枝。系统代价是显存：每个高斯要存均值、协方差参数、不透明度、球谐系数，数量大时显存占用远超隐式表示。

四 · SDS 的梯度不是真得分：噪声差方向的偏差

Score Distillation Sampling 把 3D 表示渲染成图 x，加噪得到 x_t，送进 2D 扩散模型预测噪声 ε_θ，用“预测噪声 − 实际噪声”作为更新方向。这个方向不是真实得分，但足以把渲染图推向扩散模型的高概率区域。其梯度形式可写为

$$\nabla_\phi \mathcal{L}_{SDS}=\mathbb{E}_{t,\epsilon}\Bigl[w(t)\,\bigl(\epsilon_\theta(x_t;t,y)-\epsilon\bigr)\,\frac{\partial x}{\partial \phi}\Bigr]$$

容易错的细节是：这个式子里的 ε_θ−ε 并不等于扩散模型对干净图的得分，它带有噪声采样带来的方差，且权重 w(t) 的选择直接影响优化行为。w(t) 过大时高频噪声主导更新，渲染图出现过度锐化的伪影；w(t) 过小时更新太弱，3D 表示几乎不动。工程上常用与信噪比相关的权重，而不是常数。

SDS 的失败模式是“过饱和”与“多面”：同一 3D 表示在不同视角下被推向不同的 2D 先验模式，导致几何在不同视角间不一致，表现为从某些角度看是合理的，换角度就出现扁平或重复结构。这不是优化 bug，而是 2D 先验本身缺乏 3D 一致性约束的必然结果。

具体例子：用 SDS 从文本生成一个物体，训练早期渲染图模糊，SDS 把它推向扩散模型认为“像该文本”的区域；训练后期若权重不降，噪声差方向会让纹理过锐、颜色过饱和。系统代价是每次更新都要前向一次 2D 扩散模型并反传，计算量远大于纯 3D 监督；且需要大量采样步数，训练时间长。

与之对比，Variational Score Distillation 把 3D 参数视为分布，用可学习粒子（LoRA）近似该分布得分，用“预训练扩散得分 − 粒子得分”作为更新方向，等价于最小化 3D 分布与文本条件分布的 KL。这减少了单点 SDS 的方差，但引入了粒子模型的训练开销。Interval Score Matching 则用 DDIM 反演把渲染图映射到噪声再沿同一轨迹去噪，比较反演终点与预测终点构造损失，目的是降低随机噪声带来的方差——代价是每步要做一次反演，计算量翻倍。

五 · 前馈三平面与网格提取：一次前向的误差传播

LRM 用 ViT 把输入图编码成 token，再用 cross-attention 解码成三平面特征；三平面经体渲染出图，用多视图渲染损失训练；推理时一次前向出 triplane，再提取网格。三平面的机制是：查询 3D 点时，把点投影到 xy、xz、yz 三个正交平面，各自做 2D 插值，拼接后送小 MLP 解码。2D 卷积负责生成平面，3D 一致性由三平面共享约束——同一个 3D 点在不同平面上被独立插值，但拼接后的特征必须一致地解码出同一颜色与密度。

容易错的细节在网格提取的阈值与三平面的分辨率匹配。三平面是 2D 特征图，分辨率有限；若在规则网格上按密度阈值提取等值面，阈值选得稍高会丢掉薄结构，选得稍低会产生漂浮的壳。工程上常用 DMTet 式的可变形四面体：每个顶点带 SDF 值，按符号切出三角面，顶点位置由 SDF 线性插值得到，整个过程对 SDF 与顶点坐标可微。这样提取的网格顶点位置是连续的，不是体素化的阶梯。

失败模式是前馈模型的泛化边界：单图输入时，背面完全不可见，三平面在背面区域只能靠先验“猜”。若训练数据中同类物体的背面分布单一，模型会对所有输入输出相似的背面，表现为“背面糊成一片”。这不是渲染 bug，而是单图到 3D 的固有欠定性。

具体例子：输入一张椅子图，LRM 一次前向出 triplane，提取网格后正面细节合理，背面椅腿可能粘连或缺失；若把同一 triplane 渲染到新视角，背面颜色与正面纹理不一致。系统代价是前馈模型需要大量多视图渲染数据训练，且 triplane 分辨率受显存限制，高分辨率三平面在推理时显存占用高。

结构化潜变量 SLAT 把 3D 资产表示成“稀疏体素 + 局部特征”，用 3D DiT 在潜空间做扩散，解码器可分别输出高斯、网格、辐射场。这里的工程判断是：稀疏体素只在实际有表面的位置存特征，显存随表面面积而非包围盒体积增长；但稀疏结构的构建与解码比三平面复杂，且 3D DiT 的注意力在稀疏体素上实现需要专门的分块策略。

六 · 网格序列化与重拓扑：邻接关系决定序列长度

网格序列化 tokenization 用面片邻接关系把网格遍历成序列，每个面片编码为“顶点坐标 + 邻接面”的离散 token，训练 decoder-only Transformer 自回归生成。相邻网格 token 重拓扑把这个思路推进：输入点云或网格，输出面片序列，用相邻面 token 编码，让每个面只引用前一个面的边，缩短序列并保证拓扑连续。

容易错的细节是遍历顺序与 token 的引用方式。若每个面都独立编码三个顶点坐标，序列长度随面数线性增长且顶点重复存储；若让每个面只引用前一个面的共享边，新顶点只需编码一个坐标，序列长度显著缩短，但要求遍历时相邻面确实共享边——遇到非流形或分离部件时，引用链断裂，需要插入“新起点” token。这个断裂处理写错会导致生成的网格出现孔洞或自交。

失败模式是自回归生成的误差累积：早期生成的面片若顶点坐标偏差，后续面片引用该边时偏差被继承并放大，最终网格出现扭曲。缓解手段包括在训练时加入教师强制与坐标量化，推理时限制单步坐标的取值范围。

具体例子：一个由多个部件组成的资产，若用全局序列化，部件之间的邻接关系稀疏，序列中出现大量“跳转”，模型难以学到部件边界；组合式部件潜变量扩散改用一组潜变量分别表示各部件，扩散在组合潜空间去噪，部件之间通过注意力共享全局形状，但各自解码成独立网格。这样每个部件的序列更短、更规整，代价是部件之间的接缝需要额外处理，且部件数量的组合爆炸让潜空间维度管理变复杂。

形状-材质双 DiT 的工程判断是分工：形状 DiT 生成高分辨率 SDF/网格，材质 DiT 生成 UV 空间 PBR 贴图，两者共享图像条件但独立训练，最后合成带材质的资产。独立训练降低了单模型的复杂度，但合成时 UV 展开的质量直接决定材质是否错位——UV 展开写错会让反照率、粗糙度、金属度贴图在接缝处撕裂。
