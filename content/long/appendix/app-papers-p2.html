二 · 从 5D 函数到哈希表：NeRF 与 Instant NGP 的容量分配错位

NeRF 的原始形式把整个场景压进一个 MLP：输入是五维坐标 (x,y,z,θ,φ)，输出是 RGB 与体密度 σ。沿射线 r(t)=o+td 做积分，像素颜色写成 C=∫T(t)σ(r(t))c(r(t),d)dt，其中 T(t)=exp(−∫σ ds) 是透射率。这个积分对 MLP 参数可微，于是多视角照片的 RGB 损失可以直接反传。问题在于容量分配：一个宽度 256、深度 8 的 MLP 要同时承担低频全局形状和高频表面细节，位置编码把坐标升到高维来缓解，但参数总量固定，细节一多就互相挤占。工程上的表现是训练后期 PSNR 停滞、近景纹理发糊，而增大 MLP 会让每次前向的矩阵乘成本线性上升，采样点又多（每条射线几十到上百个），单步开销迅速失控。

Instant NGP 的解法是把“记忆”从 MLP 里搬出来：坐标在 L 个分辨率层级上量化，每层用空间哈希把量化格点映射到固定大小的表项，取格点周围 2^d 个角点的特征做插值，再把 L 层特征拼接，只过一个很小的 MLP 解码密度与颜色。哈希冲突不是被消除，而是被多层级与梯度平均消解：粗层负责全局、细层负责局部，同一表项被不同坐标共享时，梯度是这些坐标贡献的叠加，冲突带来的噪声在平均意义上被摊薄。代价是表大小成为新的超参：表太小冲突严重、细节丢失，表太大显存吃紧；而且哈希表的访问是随机访存，GPU 上的缓存命中率远低于规则网格，实际吞吐受内存带宽约束而非算力约束。一个具体例子：把同一场景分别用纯 MLP 与哈希编码训练，后者能在相同墙钟时间内把高频细节（草叶、砖缝）拉到可辨程度，但显存占用随层级数近似线性增长，L 从 16 加到 20 就要重新核算预算。

$$\sigma(x)=\alpha\Psi_\beta(-f(x)),\quad \Psi_\beta(s)=\text{sigmoid}(\beta s)$$

上面这条公式属于 NeuS 一类，放在这里是为了点出一个容易错的细节：NeRF 的 σ 是“密度”，NeuS 的 σ 是 SDF 经 logistic 变换后的概率密度，两者在体渲染公式里位置相同，但语义不同。把 NeuS 的 σ 直接当成 NeRF 的密度去调参，会出现表面附近 alpha 峰值位置偏移、表面厚度随 β 漂移的问题。β 控制的是过渡带的锐利程度，训练中通常要退火增大，若固定 β 不变，重建表面要么过厚要么出现孔洞。

三 · 3DGS 的五段流水线与致密化的账

3D Gaussian Splatting 把场景表示成一堆带位置 μ、协方差 Σ、不透明度 α、球谐颜色系数的 3D 高斯。渲染时先把每个高斯投影到屏幕：Σ'=JWΣWᵀJᵀ，其中 W 是视图变换、J 是投影雅可比；再按深度排序，做 alpha 混合 C=Σ c_i α_i Π_{j<i}(1−α_j)。整个过程显式、可并行、可微，不需要沿射线采样，因此单帧渲染能到实时。训练中通过致密化与剪枝自适应增删高斯：梯度大的区域分裂或克隆，不透明度低于阈值的被剪掉。

这里有一个容易错的细节：致密化的判据用的是位置梯度而非颜色损失。位置梯度大说明该区域欠拟合，但梯度大也可能来自视角覆盖不足或排序错误，盲目分裂会在错误位置堆出冗余高斯，显存和排序开销一起上涨。工程上的失败模式是“高斯爆炸”：场景边缘和反光区域不断分裂，几轮迭代后高斯数量翻数倍，排序阶段从毫秒级退化到几十毫秒，实时性丢失。对应的系统代价是排序本身：显式表示必须每帧按深度排序，高斯越多排序越贵，而且排序是全局的，不能像 NeRF 那样按射线局部采样。一个具体例子：同一场景用 3DGS 训练，收敛后从高斯提取网格再做 UV 空间纹理精修，两阶段总时间约 2 分钟——这个数字来自 DreamGaussian 的设定，说明 3DGS 作为生成后端时，收敛速度是它相对 SDS+NeRF 的主要优势，但提取网格这一步会丢失高斯的部分视角相关效果（如镜面高光），纹理精修只能补回漫反射部分。

四 · 三平面与 DMTet：原生 3D 的两种折中

EG3D 把 3D 场分解成三个正交的 2D 特征平面（triplane）：查询 3D 点时，把坐标分别投影到 xy、xz、yz 三个平面，双线性插值得到三组特征，拼接后送小 MLP 解码密度与颜色。生成器用 2D 卷积生成三平面，3D 一致性由三平面共享与 2D 判别器共同约束。这个设计的代价是表达能力受限于三个平面的交集：沿坐标轴高度结构化的形状（如细长杆件）在某个平面上投影后信息被压缩，重建会出现轴向伪影。系统代价则是显存：三平面是稠密张量，分辨率提高一倍显存翻四倍，而 NeRF 的 MLP 参数不随分辨率增长。

GET3D 走的是另一条路：用 DMTet 作为可微网格表示，生成器预测四面体顶点的 SDF 与纹理，按符号切出三角面，2D 判别器在渲染图上对抗训练；几何分支与纹理分支共享主干但分开解码。DMTet 的好处是输出直接是网格，不需要后续 marching cubes 的后处理；代价是四面体网格的分辨率固定，细节受限于网格密度，且按符号切面在薄结构处容易产生非流形边。一个具体例子：生成带纹理的椅子时，几何分支负责椅腿的细长结构，纹理分支负责坐面的材质，两者共享主干意味着几何误差会传导到纹理解码，训练中若几何分支梯度占主导，纹理分支会欠拟合。

$$\nabla_\theta \mathcal{L}=\mathbb{E}_t\left[\left(\epsilon_\phi(x_t;y,t)-\epsilon\right)\frac{\partial x}{\partial\theta}\right]$$

这条链式法则是 Score Jacobian Chaining 的核心：渲染图 x 是 3D 参数 θ 的函数，2D 扩散模型给出图像得分 ∇log p_t(x)，乘上渲染雅可比 ∂x/∂θ 就得到 θ 空间的得分，再用退火 Langevin 动力学采样。容易错的细节是雅可比的尺度：不同可微渲染器对 θ 的导数尺度差异很大，直接乘上去会让不同参数（顶点位置 vs 纹理）的更新步长失衡，实践中要按参数分组做归一化，否则几何先动、纹理滞后。

五 · SDS 家族的梯度构成与两阶段分工

DreamFusion 用可微渲染器把 3D 表示渲染成图，加噪后送进冻结的 2D 扩散模型，用“预测噪声 − 实际噪声”作为梯度方向更新 3D 参数，CFG 增强文本对齐。这个梯度不是精确的得分，而是带噪的近似，因此训练容易出现过度饱和、颜色过艳、几何扁平化。ProlificDreamer 的 VSD 把 3D 参数视为分布 q(θ)，用一个可学习的粒子（LoRA）近似 q 的得分，梯度等于预训练扩散得分减去粒子得分，等价于最小化 q 与文本条件分布的 KL。粒子项的作用是抵消 SDS 的偏差，代价是要多训一个 LoRA，显存与时间都增加。

两阶段分工是这一族的共同工程判断：Magic3D 先用低分辨率 NeRF + SDS 得到粗几何，再把粗几何转成 DMTet 网格，用高分辨率可微渲染 + SDS 精修纹理与几何；粗阶段负责全局形状，细阶段负责细节。Fantasia3D 把几何与外观彻底拆开：几何阶段用 DMTet + 法线/深度条件的 SDS 优化形状，外观阶段固定几何，用可微 PBR 渲染器 + MLP 材质 + RGB SDS 优化纹理与材质参数。TextMesh 则把 2D 扩散模型改成深度条件版本，渲染深度图作为条件，避免纹理与几何混淆，SDS 同时更新顶点与纹理。这里的失败模式很具体：若几何阶段用 RGB SDS，纹理的高频图案会被误读成几何起伏，表面出现虚假凹凸；改用深度或法线条件后，几何梯度只来自形状，纹理不再污染形状。

  • 粗阶段用低分辨率表示，是为了让 SDS 的噪声梯度在全局形状上平均掉，分辨率太高会让局部噪声主导。
  • 细阶段转成显式网格或 DMTet，是为了让高分辨率渲染的可微性落在网格顶点上，而不是隐式场的采样点上。
  • 外观阶段固定几何，是为了让 PBR 材质的反照率、粗糙度、金属度不被几何梯度拉扯。
  • 深度条件替代 RGB 条件，是为了切断纹理到几何的梯度通路。

LucidDreamer 用 DDIM 反演把渲染图映射回噪声空间，用区间得分匹配约束，思路同样是减少 SDS 的随机性。系统代价是反演本身要多次前向，单步开销比一次 SDS 高，训练总时长增加，但换来的几何稳定性在薄结构和多视角一致性上体现明显。

六 · 前馈与单图：pixelNeRF 的投影采样细节

pixelNeRF 用 2D CNN 提取每张输入图的特征网格；对每个 3D 查询点，按相机位姿投影到各输入视图，双线性采样特征；把采样特征与查询坐标/方向拼接，送 MLP 输出密度与颜色。容易错的细节是投影时的可见性：查询点投影到某视图后可能落在遮挡区域，直接采样会把背面特征混进来，实践中要加可见性权重或按视图做注意力。另一个细节是特征网格的分辨率与查询点密度的匹配：网格太粗，双线性采样把邻近结构混在一起；网格太细，显存吃紧且 CNN 感受野覆盖不到全局。

Point-E 走两阶段：先用文本到图像扩散模型生成一张图，再用图像到点云扩散模型生成 1024 个点，点云扩散用 Transformer 去噪，条件为图像嵌入。1024 个点对复杂物体明显不够，点云稀疏导致表面断裂，后续要么上采样要么转网格补面。Shap-E 则训练编码器把 3D 资产映射成隐式函数的潜变量，在潜空间做扩散，解码器把潜变量变成隐式函数再提取网格。潜空间扩散的好处是维度低、采样快，代价是编码器的重建误差会限制生成上限：编码器没见过的拓扑（如高 genus 的孔洞结构）在潜空间里被压扁，解码后丢失。

把这些条目放在一起看，选型的分界线在“是否需要显式表面”：NeRF 与哈希编码适合新视角合成、不要求导出网格；NeuS 与 Volume Rendering of Neural Implicit Surfaces 适合需要干净零等值面的重建；3DGS 适合实时渲染与快速生成后端；三平面与 DMTet 适合原生 3D 生成且要网格输出；SDS 家族适合文本到 3D 但训练慢、需两阶段；pixelNeRF 与 Point-E/Shap-E 适合少视图或前馈场景。每条目的系统代价都落在具体环节上：哈希表的随机访存、3DGS 的全局排序、三平面的稠密显存、DMTet 的固定网格密度、SDS 的反演开销、pixelNeRF 的可见性判断——这些才是工程落地时要逐项核算的量。
