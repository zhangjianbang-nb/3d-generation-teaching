一 · 条目边界：什么算“代码与工具”

《3D AI 生成全书》附录里的“代码与工具”条目，指的不是泛泛的深度学习框架清单，而是把某一类 3D 生成方法从论文公式落到可执行程序时，必须同时交代的四件事：实现语言与运行时、外部依赖与权重来源、显存与算力门槛、以及一条最小跑通命令。这四件事构成一个条目的最小完整单元。缺任何一项，条目就退化成论文摘要，读者拿不到可复现的入口。

按这个定义，条目可以分成三类。第一类是表示与渲染内核：NeRF 的体渲染积分、多分辨率哈希编码、3DGS 的可微光栅化、NeuS 的 SDF 体渲染。它们的共同点是“给定参数，能渲染出像素，且梯度能回传”，代码主体是渲染器与编码器，依赖通常很轻（PyTorch + 少量 CUDA 扩展），显存门槛由采样点数、高斯数量或哈希表规模决定。第二类是生成器与前馈网络：Triplane 生成器、LRM 的 Triplane Transformer、SLAT 的 3D DiT、形状-材质双 DiT、前馈高斯输出头。它们的代码主体是 Transformer 或扩散骨干加一个可微渲染头，依赖重（预训练 ViT、扩散权重、渲染库），显存门槛由 token 数、多视图张数和渲染分辨率共同决定。第三类是蒸馏与流水线工具：SDS、SJC、VSD、ISM、Zero-1-to-3、多视图自注意力扩散、网格 tokenization、迭代式房间补全、世界扩展、资产清洗管线。它们的代码主体是“冻结模型 + 优化循环 + 数据管线”，依赖最杂，失败模式也最偏工程。

分类的意义在于定位代价。内核类条目的失败多半是数值与显存问题；生成器类条目的失败多半是数据分布与权重对齐问题；流水线类条目的失败多半是接口、坐标系、尺度与许可问题。下面这张速查表把三类条目的关键字段压到一行，便于在选型时先看门槛再看机制。

二 · 内核条目：渲染器即接口

内核条目的定义特征是“渲染函数就是对外接口”。以 NeRF 体渲染积分为例，条目要写清的不是“用 MLP 表示场景”，而是射线采样、密度与颜色查询、离散求和、损失回传这条链上的每个可调参数。对每条射线采样 N 个点，查询 MLP 得到密度 σ 与视角相关颜色 c，再用体渲染离散求和把 σ、c 合成为像素值；损失是渲染像素与真实像素的 MSE，梯度穿过采样点回传到 MLP。离散形式可写成：

$$\hat{C}=\sum_{i=1}^{N} T_i\left(1-e^{-\sigma_i\delta_i}\right)c_i,\qquad T_i=\exp\left(-\sum_{j

其中 δ_i 是相邻采样点间距，T_i 是透射率。这个公式直接决定显存：N 越大，每条射线的中间张量越长，反向传播要保存的激活越多。工程上把 N 从粗采样的几十点提到细采样的上百点，显存与时间近似线性上涨，这是内核条目必须写清的门槛来源。位置编码把坐标映射到高频基，弥补 MLP 对高频细节的频谱偏置；但位置编码的频带数一高，MLP 第一层输入维度随之膨胀，这又是一笔显存账。

多分辨率哈希编码把这件事换了一种代价结构。输入坐标在 L 个分辨率层级上分别量化、哈希到固定大小的表，取对应特征向量并拼接；拼接向量送入一个很小的 MLP 输出密度与颜色。粗层保证全局一致，细层负责高频；哈希冲突由梯度平均自然处理。它的伪代码思路是：对每个层级 l，把坐标按分辨率缩放后取整，得到整数格点索引，再对索引做哈希映射到表槽位，双线性插值取特征；L 个特征拼接后过 MLP。代价从“大 MLP 的激活”转移到“哈希表容量与层级数”：表太小则冲突严重、细节互相污染，表太大则显存与缓存命中率恶化。失败模式很具体——细层分辨率过高而训练视图不足时，高频特征会记住训练视角的噪声，换视角出现絮状伪影。

3D 高斯泼溅把接口换成光栅化。每个高斯有均值 μ、协方差 Σ、不透明度 α 和球谐系数；投影到 2D 得到椭圆，按深度排序后从前到后 alpha 混合；训练时用可微光栅化回传梯度，并通过致密化/剪枝自适应增删高斯。它的显存门槛由高斯数量与球谐阶数决定，而高斯数量不是超参数而是训练过程的因变量：致密化在梯度大的区域分裂高斯，剪枝删除低不透明度或过大的高斯。失败模式是致密化失控——场景边缘与高频纹理处高斯数量爆炸，显存与排序开销同时上涨，最终触发显存不足或帧率崩塌。工程判断是给致密化设梯度阈值与最大数量上限，而不是任由它自适应。

NeuS 把内核换成符号距离场体渲染。网络输出 SDF 值 f(x)，用可学习的温度参数把 f 映射成 α；沿射线积分得到颜色；损失包含 RGB 重建、Eikonal 正则（||∇f||=1）和可选掩码；推理时在零等值面跑 Marching Cubes。这里的系统代价有两处：Eikonal 正则要对采样点求梯度范数，等于在反向图里再开一条求导路径；温度参数控制 α 的锐度，温度过低表面过锐、梯度稀疏，温度过高表面糊。失败模式是 Eikonal 权重与 RGB 损失失衡——正则太强则表面平整但丢细节，太弱则 SDF 出现局部非度量、Marching Cubes 抽出毛刺。一个具体例子是薄壁物体：SDF 在薄壁两侧符号相反，采样间距大于壁厚时体渲染积分跨过零等值面却采不到足够点，重建出空洞。

三 · 生成器条目：权重、token 与渲染头

生成器条目的定义特征是“一次前向出 3D 表示”，因此条目必须交代权重来源、输入契约与渲染头的可微性。Triplane 三平面生成器是这一类里结构最清楚的：生成器从隐向量生成三张平面特征图；给定 3D 点，分别在三张图上双线性插值并拼接；MLP 输出密度与颜色；用 2D 判别器 + 相机分布做对抗训练，可加姿态条件。它的显存门槛由三平面分辨率与判别器批大小决定，失败模式是平面间特征不对齐——三张平面各自学到局部结构，拼接后 MLP 无法融合出一致表面，表现为视角间几何漂移。

LRM 的 Triplane Transformer 把输入换成图像：输入图过 DINO ViT；相机参数调制；Transformer 解码器输出三平面；三平面 + MLP 渲染任意视角；训练用 Objaverse 渲染的多视图，损失是渲染图 MSE/感知损失。条目要写清的关键点是“相机参数调制”发生在哪一层，以及渲染头是否参与训练。系统代价在 token 数：ViT patch 数乘以解码器查询数，注意力矩阵随视图数增长；失败模式是背面塌陷——单图输入下，不可见区域的三平面特征由先验填充，渲染损失只在可见视角监督，背面几何趋于平滑或重复正面纹理。

SLAT 的结构化 3D 潜变量把表示从平面换成稀疏体素：从多视图输入构建稀疏体素特征；rectified flow 训练 3D DiT；推理时采样 SLAT；不同解码器把 SLAT 解成 3DGS 或网格；支持图生/文生。这里的工程代价是“一个潜变量、多个解码器”的接口一致性：SLAT 的体素网格分辨率决定了几何上限，解码成 3DGS 时高斯初始化位置来自体素中心，解码成网格时走等值面提取。失败模式是解码器与潜变量分布错配——在 3DGS 解码器上训练的 SLAT 直接喂给网格解码器，表面出现块状阶梯。

形状-材质双 DiT 把几何与外观拆成两条扩散链：形状分支用 VecSet/稀疏体素扩散出 SDF，Marching Cubes 出网格；材质分支在 UV 空间扩散反照率/粗糙度/金属度；用渲染损失与材质监督训练。条目必须写清 UV 空间的坐标约定与材质通道顺序，否则下游渲染器读错通道。系统代价是两条链的采样步数相加，且材质分支依赖 UV 展开质量；失败模式是几何与材质错位——形状分支出的网格 UV 接缝与材质分支的 UV 布局不一致，贴图在接缝处撕裂。

前馈高斯输出头是“生成器 + 内核”的缝合条目：多视图 patch 化 + 相机嵌入；Transformer 编码/解码；高斯参数头；可微光栅化渲染；渲染损失训练。它的显存门槛同时受 token 数与高斯数量约束，失败模式是高斯参数头输出的协方差非正定或尺度失控，光栅化时椭圆退化成针状，渲染出现拉丝。工程上要在输出头加协方差参数化（如四元数 + 尺度）与不透明度截断，这些细节正是条目要写清的最小跑通条件。

四 · 蒸馏条目：冻结模型与优化循环的耦合

蒸馏条目的定义特征是“不训练生成器，只优化 3D 参数”，因此条目要写清冻结了哪些模型、每步查询几次、梯度如何穿过渲染器。SDS 的机制是：随机采相机与时间步 t，对渲染图 x 加噪得 x_t；冻结的扩散模型预测噪声 ε_φ(x_t;y,t)；计算 SDS 梯度 w(t)(ε_φ−ε)∂x/∂θ；更新 3D 参数。CFG 把条件与无条件噪声相减增强文本对齐。写成式子：

$$\nabla_\theta \mathcal{L}_{\mathrm{SDS}}=w(t)\left(\epsilon_\phi(x_t;y,t)-\epsilon\right)\frac{\partial x}{\partial \theta}$$

系统代价立刻显现：CFG 意味着每个优化步要做条件与无条件两次噪声预测，显存与时间翻倍；∂x/∂θ 要求渲染器可微，于是 3DGS 或 NeRF 内核必须常驻显存。失败模式是过饱和与多面——SDS 梯度是噪声预测之差，方差大，优化步长稍大就出现颜色过饱和、几何在多视角间折中成“多面体”。工程判断是配合小学习率、梯度裁剪与多视角批采样。

SJC 换了得分视角：对渲染图加噪，查询扩散模型得分 ∇log p_t(x)；乘以渲染雅可比 ∂x/∂θ 得到参数空间得分；按 Langevin 更新 θ；用多尺度退火从粗到细。它与 SDS 的差别在于用得分而非噪声差，条目要写清退火 schedule 与每尺度迭代数。失败模式是尺度切换处的几何跳变——粗尺度收敛到低频形状后，细尺度突然引入高频，若步长未随尺度缩小，表面出现振铃。

VSD 引入粒子模型：维护一组 3D 粒子（或一个 LoRA）；渲染加噪后，分别查询冻结扩散模型与粒子模型的噪声预测；两者相减得到 VSD 梯度；粒子模型用渲染图做去噪训练，随 3D 分布更新。系统代价是显存里同时驻留冻结扩散模型、粒子模型与 3D 表示，三者叠加；失败模式是粒子模型更新过快导致梯度信号塌缩，或更新过慢导致梯度退化成 SDS。ISM 则对渲染图做 DDIM inversion 得到噪声轨迹；从该噪声出发做条件去噪；用两个终点之差作为损失；配合 3DGS 表示加速。它的代价是每步多一次 inversion 前向，失败模式是 inversion 不精确时终点差含轨迹误差，几何出现高频抖动。

多视图扩散条目介于生成器与蒸馏之间：Zero-1-to-3 输入参考图与相对位姿 ΔR、ΔT，通过 cross-attention 注入位姿嵌入；输出目标视角图像；训练数据是同一物体的多视角渲染对；推理时采样多个视角。多视图自注意力扩散输入文本 + 4 个相机位姿；每张图 patch 化后加位姿嵌入；自注意力跨视角；一次去噪输出 4 张一致图像；可接 Zero-1-to-3 做图生 3D。跨域法线-颜色扩散让颜色分支与法线分支并行去噪，跨域注意力交换特征，输出多视角颜色与法线，用法线做泊松重建或作为 LRM 的额外输入。这一族的失败模式是视角间不一致：自注意力跨视角若位姿嵌入尺度不对，四张图各自合理但拼不回同一物体；法线分支与颜色分支若跨域注意力权重失衡，法线出现颜色泄漏。

五 · 流水线条目：坐标系、尺度与许可

流水线条目的定义特征是“多阶段串联，每阶段有独立输入输出契约”，条目必须写清阶段间的坐标系、单位与文件格式。网格序列化 tokenization 用面片邻接做深度优先遍历；每个面片量化顶点坐标与相邻面索引；BPE 压缩序列；Transformer 学习下一个 token；推理时逐步生成面片。它的系统代价是序列长度随面数增长，失败模式是量化误差累积——顶点坐标量化步长过大时，相邻面片共享边不重合，输出网格出现裂缝。相邻网格 token 重拓扑输入网格采样点云；编码器提取特征；解码器自回归输出面片 token；相邻 token 编码复用上一条边；输出网格面数大幅降低。它的失败模式是自回归误差传播，一个错误 token 导致后续面片拓扑错乱。

组合式部件潜变量扩散输入图像/文本；编码器预测部件数量与布局；组合式 DiT 去噪各部件潜变量；每个潜变量解码成网格；输出带部件分割的资产。条目要写清部件坐标是相对布局还是世界坐标，否则拼装时部件互相穿插。迭代式房间网格补全从一张图估计深度；反投影成网格；移动到新视角，渲染当前网格的洞；用 2D 扩散补洞；融合新几何；重复直到房间闭合。失败模式是深度尺度漂移——每轮补洞引入新的深度估计，多轮后房间尺度与首帧不一致，闭合处出现错位。高斯泼溅世界扩展单图 + 深度初始化高斯；渲染当前视角；视频扩散生成下一帧；用新帧监督高斯增密；重复扩展。失败模式是视频扩散的时序漂移被高斯增密固化，远处区域高斯密度与近处失衡。

视频驱动物理参数估计生成或收集交互视频；用可微 MPM 仿真；优化物理参数使渲染轨迹与视频一致；输出可交互的物理资产。它的系统代价是可微仿真每步要保存粒子状态，显存随粒子数与步数增长；失败模式是参数不可辨识——多种材质参数组合产生相似轨迹，优化收敛到错误组合。大规模 3D 资产清洗管线抓取模型与许可；转 GLB；去重与质量过滤；渲染多视图；CLIP 嵌入与标注；发布数据集与工具链。这条条目的失败模式不在算法而在许可与去重：许可字段缺失的模型混入训练集，或几何近似但拓扑不同的模型未被去重，导致数据分布偏斜。UV 展开 + PBR 材质分解网格 UV 展开；多视图渲染反投影到 UV；材质扩散补全；光照解耦训练；输出 PBR 贴图组。失败模式是反投影遮挡——多视图反投影到 UV 时，被遮挡区域没有观测，材质扩散补全出与几何不符的贴图。

3D-aware 同步多视图生成参考图编码 + 16 个目标位姿；各视角特征反投影到 3D 体积；3D 卷积/注意力融合；投影回各视角；同步去噪；最后用多视图重建 3D。它的显存门槛由 16 个视角的特征体积决定，失败模式是反投影分辨率不足导致高频丢失。LLM+程序化+扩散世界组合文本到 LLM 场景图；程序化生成地形与建筑；扩散模型生成物体；object-aware 分解与放置；导出到游戏引擎；支持布局/尺度/风格控制。失败模式是尺度契约断裂——LLM 场景图的单位与程序化地形的单位不一致，物体放置悬空或陷入地面。等值面/可微网格提取条目则把 Marching Cubes 与 DMTet 并列：规则网格查表生成三角面；DMTet 初始化四面体、预测顶点 SDF、按符号切面、线性插值顶点；可微渲染回传梯度。失败模式是四面体分辨率不足时薄结构被符号组合抹掉。

把这些条目放在一张速查表里，选型的第一步不是看效果，而是看“最小跑通命令”需要哪些前置：内核条目通常只需一个场景数据与一条训练命令；生成器条目需要权重下载与渲染库版本对齐；流水线条目需要资产库、仿真器与许可清单。条目写作的工程判断是：把显存门槛写成“由哪个量决定”，把失败模式写成“在哪个阶段可观测”，而不是给一个笼统的“需要大显存”。
