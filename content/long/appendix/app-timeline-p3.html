清单的用法是“缺项即风险”：若某条目的监督信号在你的数据里不存在（例如没有位姿、没有多视图），该条目就不能直接进入流水线，只能作为先验或初始化。表中“工程落点”一列不是评价，而是接口位置——它决定你需要在哪个模块加校验。

二 · 对比表：四条主线的机制差异与代价

时间线上的条目可以归并为四条主线：优化式辐射场、显式泼溅、SDS 蒸馏、前馈重建/生成。它们的差别不在“谁更好”，而在失败模式与系统代价的形状不同。下面这张表按机制、公式抓手、代价与典型失败逐列展开。

主线核心机制公式抓手系统代价典型失败模式
优化式辐射场（NeRF/NeuS/Instant NGP）沿射线积分密度与颜色，梯度回传到场景参数体积渲染积分与哈希编码查表每场景需优化；哈希表显存随分辨率增长位姿误差导致模糊；薄结构被积分抹平；SDF 与密度耦合不稳
显式泼溅（3DGS）各向异性高斯投影与 alpha 混合协方差投影到屏幕空间的 2D 椭圆显存随高斯数量线性增长；排序开销稀疏视角下漂浮物；大高斯遮挡细节；编辑困难
SDS 蒸馏（DreamFusion 家族）用 2D 扩散对渲染图打分，反传为场景梯度分数蒸馏的梯度估计每步多次扩散前向；优化时长以小时计过度饱和/纹理幻觉；多面角不一致（Janus 问题）；提示词敏感
前馈重建/生成（LRM/InstantMesh/TripoSR/CRM）单图编码到三平面或网格，一次前向出资产编码器-解码器重建损失训练数据与算力前置；推理显存固定背面臆造；训练分布外的类别崩坏；输出拓扑不可控

对比表的关键读法是“代价换什么”。优化式把时间换成几何精度；泼溅把显存换成帧率；SDS 把算力换成无需 3D 数据的开放性；前馈把训练成本换成推理确定性。工程判断由此变成预算分配问题：若推理时延是硬约束，前馈主线优先；若需要可编辑的显式资产，泼溅与网格主线优先；若数据稀缺且类别开放，SDS 仍是可用但昂贵的兜底。

$$\hat{C}(\mathbf{r})=\int_{t_n}^{t_f} T(t)\,\sigma(\mathbf{r}(t))\,\mathbf{c}(\mathbf{r}(t),\mathbf{d})\,dt,\quad T(t)=\exp\!\Big(-\int_{t_n}^{t}\sigma(\mathbf{r}(s))\,ds\Big)$$

上式是优化式主线的公共骨架；NeuS 的差异在于把不透明度由 SDF 导出，使等值面成为渲染的自然副产物。工程上这意味着：表面质量的上限由采样密度与位姿精度共同决定，而不是由网络宽度单独决定。

三 · 自测题：把时间线读成可验证的判断

以下题目不给选项，要求写出机制层面的理由；每题都对应前文出现过的一个易错细节，用来检验你是否把“年份记忆”转成了“接口判断”。

  • 题 1：给定一组只有单视图且无位姿的输入，为什么 pixelNeRF 与 Zero-1-to-3 不能互换使用？请指出二者对位姿假设的差异，以及互换后最先崩坏的是哪个模块。
  • 题 2：Instant NGP 的哈希编码提升了吞吐，但它改变了渲染方程的哪一部分、没有改变哪一部分？若把哈希表分辨率翻倍，显存与收敛行为分别如何变化？
  • 题 3：DreamFusion 与 ProlificDreamer 同属 SDS 家族，变分形式缓解了什么失败模式？请用“梯度估计的方差”这一角度说明，并指出它没有解决的多视图一致性问题。
  • 题 4：3DGS 的显存随高斯数量线性增长。若场景中出现大量细小高频结构，你会优先增加高斯数量还是提高每高斯的球谐阶数？给出代价对比。
  • 题 5：LRM、InstantMesh、CRM、TripoSR 都是单图前馈，为什么它们的推理时延差异不能只用参数量解释？请从稀疏视图输入与卷积/Transformer 结构的角度作答。
  • 题 6：MeshGPT 用解码器生成三角形序列，它的失败模式与三平面前馈的失败模式有何本质不同？提示：一个关于拓扑合法性，一个关于几何臆造。

参考式作答要求：每题至少写出一个公式或伪代码片段作为论据。例如题 2 应写出哈希编码的查表与插值伪代码思路：多级分辨率网格各自查表、按层插值、拼接后送入小型 MLP；并说明渲染积分本身未被替换，因此采样策略仍是瓶颈。题 3 应写出 SDS 梯度形如“扩散模型对加噪渲染图的分数减去噪声”的表达式，并说明变分版本用粒子近似后验以降低方差。

四 · 练习：从条目到可运行的最小实验

练习的目标不是复现论文，而是让每个条目在你的环境中留下一个可观测的接口。下面四个练习按主线排列，每个都给出输入、机制抓手与预期失败信号，便于在无标注数据上做小规模验证。

  • 练习 A（辐射场）：用少量多视图与已知位姿训练一个带哈希编码的辐射场，固定采样数，记录薄结构（如细杆）的重建厚度随采样数变化的趋势。失败信号：厚度随采样数增加而不收敛，说明位姿或积分边界设置有误。
  • 练习 B（泼溅）：在同一场景上比较高斯泼溅与辐射场的显存占用与帧时间，保持输出分辨率一致。失败信号：稀疏视角侧出现漂浮高斯，需检查致密化策略与深度排序。
  • 练习 C（SDS）：用固定提示词跑 SDS 优化，分别在两个随机种子下渲染四个方位，观察纹理与几何是否一致。失败信号：不同方位出现互相矛盾的部件（多面角不一致），此时应引入多视图扩散先验而非继续调提示词。
  • 练习 D（前馈）：用单图前馈模型重建一个训练分布内的物体与一个分布外物体，比较背面与拓扑。失败信号：分布外物体出现破碎网格或悬空面，说明编码器特征未覆盖该类别，需回退到优化式或补数据。

每个练习都应记录三项系统指标：峰值显存、单步时延、收敛所需步数。这三项构成时间线条目的“工程指纹”——同一主线内不同条目的差异往往体现在这三项的比例上，而不是在视觉质量上。例如 Instant NGP 相对早期 NeRF 的差异主要体现在收敛步数与单步时延，而几何精度上限仍受采样与位姿约束。

五 · 延伸阅读：按问题而非按年份组织

时间线容易读成编年史，但工程阅读应按问题组织。下面给出四条阅读路径，每条都把附录条目重新排序，使机制相邻而非年份相邻。

问题阅读顺序关注点
如何从 2D 监督得到干净表面NeRF → Volume Rendering of Neural Implicit Surfaces → NeuS密度与 SDF 的耦合方式、等值面提取的稳定性
如何把生成从优化搬到前馈EG3D → LRM → InstantMesh / CRM / TripoSR三平面潜变量的接口、稀疏视图输入、推理预算
如何用 2D 先验绕过 3D 数据DreamFusion → Score Jacobian Chaining → Magic3D → ProlificDreamer / Fantasia3D / LucidDreamer梯度估计方差、几何外观解耦、两阶段分辨率
如何保证多视图一致与背面Zero-1-to-3 → MVDream → SyncDreamer → Wonder3D视角条件注入、视图间注意力、跨域扩散

延伸阅读的判据是“能否回答接口问题”：读 NeRF 时应能说出渲染积分对采样数的依赖；读 LRM 时应能说出三平面分辨率与显存的关系；读 MVDream 时应能说出视图条件如何进入去噪网络。不能回答这些问题的阅读只是年份记忆，无法支撑选型。

数据一侧的阅读同样按问题组织：Objaverse 回答“监督从哪来”，Objaverse-XL 回答“规模如何扩展”，二者共同决定前馈主线的上限。许可与标注质量是这条路径上最容易被忽略的系统代价——训练分布外的类别崩坏往往不是模型容量问题，而是数据覆盖问题。

六 · 速查的边界：哪些判断不能从表里读出

速查表能压缩条目，但不能替代对失败模式的现场观测。三个边界值得在工程评审中明确写出。第一，年份不等于成熟度：同一年的条目可能处于完全不同的验证阶段，前馈模型的推理确定性依赖训练分布，而优化式模型的确定性依赖位姿质量，二者不可用同一套验收标准。第二，表示跃迁不等于精度跃迁：三平面与高斯提升了接口效率，但几何精度上限仍由监督信号与采样决定，把表示升级当作精度升级是常见误判。第三，公式抓手不等于实现细节：体积渲染积分在论文中是连续形式，在实现中是离散采样与边界截断，薄结构失败几乎总在离散化这一步发生。

因此速查表的正确用法是“定位接口，再回到机制”。当某个条目在你的流水线中失败时，先查表确定它消费的信号与输出的表示，再回到对应主线的公式检查离散化与约束是否满足。清单、对比表、自测题与练习共同构成一个闭环：清单保证不漏项，对比表保证代价可见，自测题保证判断可验证，练习保证失败可观测。闭环的终点不是记住年份，而是能在给定预算下说出“这条目在我的系统里会在哪一步坏、坏成什么样”。
