二 · NeRF 的采样与梯度路径：为什么“跑通”不等于“跑对”

NeRF 的最小实现只有三件事：射线生成、沿射线采样、把采样结果按体渲染离散求和合成像素。工程上最容易出错的地方不在 MLP 结构，而在采样区间与梯度路径的耦合。对每条射线，相机原点 o 与方向 d 确定后，需要给出近端 t_n 与远端 t_f；分层采样在 [t_n, t_f] 上先粗采 N_c 个点，再根据粗网络的密度分布做逆变换采样得到 N_f 个细点，最终把粗、细两组的 σ 与 c 一起送入离散求和。离散求和的形式是：

$$ \hat{C}(\mathbf{r}) = \sum_{i=1}^{N} T_i \left(1 - \exp(-\sigma_i \delta_i)\right) \mathbf{c}_i, \quad T_i = \exp\left(-\sum_{j

其中 δ_i 是相邻采样点的间距。这里有一个容易被忽略的细节：δ_i 随采样点位置变化，而采样点位置本身是由粗网络的密度分布决定的，因此梯度不仅穿过 σ 与 c 回传到 MLP，还穿过“采样点在哪”这一层。如果实现时把细采样点的坐标用 detach 切断，或者用不可微的排序/逆变换采样实现，网络仍然能收敛出一个模糊的平均解，但高频细节的梯度信号被削弱，表现为训练损失下降正常、渲染结果却偏软。这是“跑通”与“跑对”的分界线。

位置编码是另一个必须对齐的细节。把坐标 x 映射到多频基：

$$ \gamma(\mathbf{x}) = \left[\mathbf{x}, \sin(2^0\pi\mathbf{x}), \cos(2^0\pi\mathbf{x}), \ldots, \sin(2^{L-1}\pi\mathbf{x}), \cos(2^{L-1}\pi\mathbf{x})\right] $$

L 的选择直接决定 MLP 能表达的最高频率。L 太小，网络对高频纹理存在频谱偏置，学不出锐利边缘；L 太大，在采样不足的区域会出现高频混叠，表现为远处或薄结构上的闪烁。工程判断是：L 与场景尺度、采样密度一起调，而不是单独调。一个具体例子是薄叶片或栏杆：粗采样 N_c 不足时，细采样根本不会落在薄结构上，位置编码再高也无济于事，此时应提高 N_c 或改用基于深度的采样区间收缩，而不是加大 L。

系统代价方面，NeRF 的显存门槛主要来自每条射线的采样点数与批大小之积。N_c 与 N_f 各取数十到上百，批大小取数千条射线时，中间激活（每个采样点的 MLP 隐层输出）会迅速占满显存；梯度检查点可以换显存，代价是训练时间上升。失败模式还包括：近端 t_n 设得过大导致近处几何被截断；远端 t_f 设得过小导致背景缺失；以及密度无界导致 T_i 在数值上下溢。工程上通常对 σ 做 softplus 或截断，并在求和时用累乘而非逐项重算 T_i，避免数值不稳定。

环节具体机制常见错误代价或表现

分层采样粗密度做逆变换采样得细点细点坐标 detach细节梯度弱、结果偏软

把这条链路讲清楚之后，最小跑通命令的意义才明确：命令能启动训练，只说明张量形状对齐；要判断是否“跑对”，应检查细采样点是否真的落在高密度区域、位置编码的频率是否与分辨率匹配、以及损失下降时渲染图的高频成分是否同步增长。这三项检查比看总损失曲线更能暴露实现错误。

三 · 哈希编码的层级与冲突：粗层一致性与细层高频的取舍

多分辨率哈希编码把输入坐标在 L 个分辨率层级上分别量化，再哈希到固定大小的表，取对应特征向量拼接后送入一个小 MLP 输出密度与颜色。其结构可以写成伪代码思路：对每个层级 l，分辨率 N_l 随 l 指数增长；坐标乘以 N_l 后取整得到体素索引，再对体素角点做哈希得到表下标；对每个角点的特征做线性插值，得到该层级的特征向量；把所有层级的特征拼接，送入两层小 MLP。粗层分辨率低、感受野大，保证全局一致；细层分辨率高，负责高频细节。

哈希冲突是这个机制的核心代价。表大小固定，细层的体素数量远超表容量，不同空间位置会映射到同一组表项。实现上并不显式检测冲突，而是让冲突由梯度平均自然处理：同一表项被多个位置查询时，反传的梯度会累加，等价于这些位置共享一个特征，网络被迫在冲突位置之间做折中。冲突率随细层分辨率上升而上升，表现为细层特征被“抹平”，高频细节的学习被粗层主导。工程判断是：表大小与最细层分辨率要一起定，表太小则细层失效，表太大则显存与缓存命中率恶化。

$$ N_l = \left\lfloor N_{\min} \cdot b^{\,l} \right\rfloor, \quad l = 0, \ldots, L-1 $$

其中 b 是层级间的增长倍率。这个式子说明层级分辨率是指数增长的，因此最细层的体素数量远大于粗层，哈希冲突几乎全部集中在细层。一个具体例子是：当场景包含大量重复的细碎结构（草地、栅栏）时，细层冲突会让这些结构趋向同质化，渲染结果出现“纹理被抹平”的观感；此时提高表大小或降低最细层分辨率，比加大 MLP 宽度更有效。

系统代价方面，哈希编码的显存主要花在表本身与每个层级的插值中间量上；训练时的瓶颈往往不是算力而是缓存：哈希表的随机访问模式对 GPU 缓存不友好，表越大、访问越随机，有效带宽越低。失败模式包括：层级数 L 过大导致最细层分辨率超过场景实际采样密度，产生高频混叠；表太小导致细层特征退化；以及学习率与表大小不匹配，表项更新过快导致训练震荡。工程上常见的做法是对不同层级使用不同的学习率衰减，粗层更新慢、细层更新快，以匹配它们各自负责的频率范围。

层级分辨率职责冲突表现工程对策
粗层低全局一致、大尺度形状冲突少较低学习率、稳定更新
中层中中等尺度结构偶发冲突表大小与分辨率匹配
细层高高频纹理与边缘冲突集中、特征被平均加大表或降最细分辨率

容易错的细节在于：把哈希编码当成“越大越好”的万能加速器。实际上粗层与细层的分工是频谱分工，粗层负责低频、细层负责高频；如果表大小不足以支撑细层，细层的高频能力会被冲突吃掉，网络退化为一个只有粗层有效的模型，训练损失仍能下降，但细节不再增长。判断方法是分别冻结粗层或细层做消融，看渲染图的高频成分由谁贡献，而不是只看总损失。

四 · 3DGS 的可微光栅化：排序、混合与致密化的耦合

3D 高斯泼溅的每个高斯有均值 μ、协方差 Σ、不透明度 α 和球谐系数。投影到 2D 时，协方差经雅可比变换得到 2D 椭圆；按深度排序后从前到后做 alpha 混合。混合公式与 NeRF 的离散求和同构，但 T_i 的累乘顺序由排序决定：

$$ \mathbf{C} = \sum_{i \in \mathcal{N}} \mathbf{c}_i \alpha_i \prod_{j

其中 N 是按深度排序后与当前像素重叠的高斯集合。这里的关键细节是排序必须与混合顺序一致，且排序本身在训练中是分段常数、不可微的。工程实现通常按 tile 分块，每块内对高斯排序，再逐像素混合；排序变化时梯度路径会跳变，表现为训练后期的局部闪烁。可微光栅化回传梯度到 μ、Σ、α 与球谐系数，其中 Σ 的梯度要经过协方差的分解（旋转与缩放），实现上常用重参数化避免正定性问题。

致密化与剪枝是 3DGS 自适应的核心机制：根据梯度幅值与高斯在屏幕上的覆盖面积决定是否分裂或克隆高斯，根据不透明度与尺度决定是否剪枝。致密化阈值设得过低会导致高斯数量爆炸，显存与排序开销同步上升；设得过高则欠拟合薄结构。一个具体例子是：场景中有一根细杆，初始高斯尺度较大，覆盖面积大但梯度小，致密化不会触发，结果是细杆被渲染成模糊的一团；此时需要调低致密化的梯度阈值，或引入基于深度的初始化让高斯初始尺度更贴近几何。

系统代价方面，3DGS 的显存主要来自高斯参数与排序缓冲；训练时的瓶颈是排序与混合的带宽，而不是矩阵乘。失败模式包括：排序不稳定导致前后景混合错误；协方差退化导致椭圆过扁或过胖；致密化与剪枝节奏不匹配导致高斯数量震荡。工程判断是：致密化应分阶段进行，前期宽松、后期收紧，并与学习率衰减同步；否则会出现“先爆炸后剪枝”的反复。

参数作用调参风险表现
致密化梯度阈值决定何时分裂/克隆过低高斯数量爆炸、显存吃紧
致密化梯度阈值同上过高薄结构欠拟合
不透明度剪枝阈值剔除无效高斯过高半透明结构被误删
协方差重参数化保证正定分解不当椭圆退化、渲染伪影

容易错的细节在于把排序当成纯工程优化而忽略它对梯度的影响：排序在训练中是分段常数，相邻迭代间排序变化会让同一像素的梯度路径突变。若在致密化附近同时大幅调整学习率，两者叠加会放大震荡。稳妥的做法是把致密化窗口与学习率变化窗口错开，并在排序变化频繁的阶段降低学习率。

五 · NeuS 与 DMTet：SDF 到表面的两道关口

NeuS 的网络输出 SDF 值 f(x)，用可学习的温度参数把 f 映射成 α，沿射线积分得到颜色；损失包含 RGB 重建、Eikonal 正则与可选掩码；推理时在零等值面跑 Marching Cubes。把 SDF 映射成 α 的机制是：

$$ \alpha_i = \mathrm{sigmoid}\left(\frac{f(\mathbf{x}_i)}{\tau}\right) $$

其中 τ 是可学习的温度，控制表面过渡的锐度。τ 过大则表面模糊、细节丢失；τ 过小则梯度在表面附近过尖，训练不稳。Eikonal 正则 ||∇f||=1 约束 SDF 的梯度幅值，保证它近似为到表面的距离；缺少这一项时，网络可以用任意形状的等值面拟合颜色，表面质量下降。一个具体例子是：当场景包含薄壁结构时，τ 偏大导致两侧壁面在体渲染中被合并成一层，Marching Cubes 提取出的网格出现孔洞；调小 τ 并配合更密的采样可以缓解。

DMTet 走的是另一条路：初始化一个稠密四面体网格，网络预测每个顶点的 SDF，对每个四面体按符号组合查表生成三角面，顶点位置用线性插值，渲染网格并与 2D 图像算损失，梯度回传到 SDF 与顶点。它与 NeuS 的差别在于表面提取发生在训练过程中而非推理时，因此梯度可以直接穿过网格拓扑。DMTet 的失败模式是拓扑翻转：当顶点 SDF 符号在迭代中反复变化时，四面体的切面方式跳变，网格出现自交或空洞。工程上通常对 SDF 做平滑正则，并限制单步符号变化的幅度。

方法表面提取时机梯度路径主要正则失败模式
NeuS推理时 Marching Cubes体渲染积分回传Eikonal薄壁合并、孔洞
DMTet训练中可微提取网格渲染回传SDF 平滑拓扑翻转、自交

容易错的细节在于把 Eikonal 正则当成可选项：没有它，SDF 的等值面可以任意扭曲来拟合颜色，体渲染损失仍能下降，但提取出的网格法线混乱、尺度失真。判断方法是检查 ∇f 的幅值分布，若大量采样点偏离 1，说明正则权重不足或温度参数与正则不匹配。

六 · 前馈生成器的训练信号：三平面、SLAT 与网格 token 的梯度落点

Triplane 生成器从隐向量生成三张平面特征图，给定 3D 点分别在三张图上双线性插值并拼接，MLP 输出密度与颜色，用 2D 判别器加相机分布做对抗训练。这里的梯度落点值得说清：判别器只看渲染出的 2D 图像，梯度经渲染器回传到三平面特征，再回传到生成器。对抗训练的不稳定性来自判别器与生成器的节奏不匹配，表现为三平面特征在高频区域震荡。工程上常用姿态条件与相机分布采样来约束判别器看到的视角覆盖，避免生成器只在少数视角上过拟合。

结构化 3D 潜变量（SLAT）走的是另一条链路：从多视图输入构建稀疏体素特征，用 rectified flow 训练 3D DiT，推理时采样 SLAT，再由不同解码器解成 3DGS 或网格。它的梯度落点在稀疏体素特征上，解码器是冻结或单独训练的，因此生成质量的上限由 SLAT 的表示能力与解码器的保真度共同决定。失败模式是解码器与 SLAT 分布不匹配：SLAT 采样出的特征落在解码器训练分布之外，解出的几何出现碎片或空洞。

网格序列化 tokenization 的梯度落点又不同：用面片邻接做深度优先遍历，每个面片量化顶点坐标与相邻面索引，BPE 压缩序列，Transformer 学习下一个 token。这里没有可微渲染，训练信号是 token 的交叉熵；推理时逐步生成面片。它的失败模式是序列过长导致自回归误差累积，生成长序列时面片邻接关系断裂，输出网格出现非流形边。工程判断是：token 化时的量化精度与 BPE 压缩率要一起调，量化过粗则几何失真，压缩过强则邻接信息丢失。

生成器训练信号梯度落点失败模式
Triplane2D 对抗 + 相机分布三平面特征高频震荡、视角过拟合
SLATrectified flow稀疏体素特征解码器分布不匹配
网格 token下一 token 交叉熵Transformer 权重长序列邻接断裂

容易错的细节在于混淆“渲染损失”与“生成损失”的梯度路径：Triplane 与 SLAT 都经过渲染或解码，但前者是对抗信号、后者是流匹配信号，两者的失败表现不同。对抗信号失效表现为模式坍塌或视角伪影，流匹配信号失效表现为采样偏离训练分布。排查时应分别检查判别器准确率与流匹配的终点误差，而不是只看渲染图的观感。
