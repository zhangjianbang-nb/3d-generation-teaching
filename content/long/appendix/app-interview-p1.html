一 · 题目定义与能力分层

“面试题”在这里不是一份背诵清单，而是一套能力分层表。3D 生成岗位的 30 道高频题，按条目主题可归为五类：表示选型、SDS 偏差、多视图一致性、前馈模型、拓扑/PBR/物理。每一类题目的共同特征是：它逼你在“表示—优化—监督—工程代价”四个维度上同时给出判断，而不是复述某个模型的论文结论。面试官问“NeRF 为什么能从 2D 照片学出 3D”，真正想听的是你能否把 5D 输入、体渲染积分、透射率 T、分层采样与位置编码、渲染损失对 3D 参数可微这条链路讲成一条因果链；问“Instant-NGP 哈希冲突为什么还能记住细节”，想听的是多分辨率分层、冲突由多层平均与梯度消化、L/T/F 三角权衡、小 MLP 只做解码这套机制。定义清楚这一点，后面的分类才有意义。

能力分层可以这样切：第一层是“表示与渲染的映射关系”，即给定一种表示（体素、三平面、点云、隐式函数、高斯、网格），你能否写出它到像素的可微链路；第二层是“监督信号从哪来”，即 2D 对抗、SDS 得分蒸馏、多视图扩散、前馈回归各自的偏差结构；第三层是“工程代价”，包括显存、训练时长、推理时延、拓扑质量、可编辑性。30 道题几乎都落在三层交叉处。例如 3DGS 的投影题同时考协方差分解 R S Sᵀ Rᵀ、投影公式 Σ'=J W Σ Wᵀ Jᵀ、按深度排序与 alpha 合成、致密化与剪枝，这四件事分别属于映射、监督（渲染损失）、工程代价三个层。

一个具体机制的例子：NeRF 的关键链路可写成伪代码思路——对每条相机射线做分层采样得到若干 3D 点，每点输入位置编码后送入 MLP 输出颜色与密度，沿射线做体渲染积分并累积透射率 T，最后与像素真值算渲染损失，梯度经积分与采样回传到 MLP 参数。这条链路里没有显式 3D 监督，3D 结构是“渲染一致性”逼出来的。失败模式也很具体：如果采样过稀或位置编码频带不足，高频细节会糊；如果透射率累积实现有误，前后遮挡关系会错，表现为“透视穿帮”。系统代价是每像素要采样数十点、每点一次 MLP 前向，训练与渲染都重。

$$T(t)=\exp\left(-\int_{t_n}^{t}\sigma(s)\,ds\right),\qquad C=\int_{t_n}^{t_f}T(t)\,\sigma(t)\,c(t)\,dt$$

二 · 表示选型：从隐式到显式再到结构化潜变量

表示选型题的判据不是“哪个新”，而是“增长阶与可微性是否匹配任务”。三平面表示用三个 2D 平面做双线性采样再拼接，内存随分辨率平方增长，而体素是立方增长，这就是 EG3D 用三平面省内存的核心理由；它的骨干是 StyleGAN2 加神经渲染与双判别器。点云表示没有拓扑，Point-E 因此分两阶段从 1024 到 4096 生成，文本条件扩散，下游必须重建或重拓扑，这是表示本身带来的工程债。Shap-E 反过来生成“隐式函数的参数”，即扩散生成 MLP 权重，查询占用与颜色，可提取网格或渲染，好处是表达连续、代价是高维参数训练难。

显式网格路线里，GET3D 没有任何 3D 监督，靠显式网格输出、可微光栅化、2D 对抗监督、几何与纹理双分支学会带纹理网格；TextMesh 直接优化网格顶点与纹理，用 SDS 更新，省掉网格提取，并用深度/法线条件约束，和 DreamFusion 的 NeRF 路线最大工程差异就在这里。Magic3D 两阶段：阶段一低分辨率 NeRF 粗模，阶段二 DMTet 加可微渲染到 512 分辨率，探索与精修分离，所以第二阶段能更细。这些题共同考一件事：你能否说清“表示的可微链路断在哪”。

结构化潜变量是第八卷的主线。Direct3D 先训 3D VAE 压缩再在潜空间做 DiT 扩散，压缩与生成解耦；TRELLIS 的 SLAT 是稀疏体素加局部三平面，用 3D DiT 与 rectified flow，一套潜变量可解成高斯、网格与辐射场，多解码器共享同一潜空间。Hunyuan3D 2.0 把形状与纹理拆成两个 DiT，不同数据与目标分别迭代，代价是误差累积与接口对齐；2.1 的 PBR 材质要 base color/metallic/roughness 三通道，delighting 去光照以对齐引擎标准输入。CraftsMan3D 的条目在此只作为网格手艺方向的代表，具体机制留到后续卷展开。

一个具体失败模式：把三平面分辨率盲目拉高，显存按平方涨而细节收益递减，且双线性采样在薄结构处会因平面分辨率不足出现“断层”；把点云直接喂给需要拓扑的下游，重拓扑阶段会引入新的几何误差。系统代价的判断标准是：训练显存、推理时延、下游可编辑性三者取交集。

三 · SDS 偏差：得分梯度为何长出两张脸

SDS 题的共同考法是写出梯度形式并解释偏差来源。SDS 梯度由 2D 得分与渲染雅可比组成，本质是用 2D 扩散模型的得分指导 3D 参数更新；因为每个视角独立计算得分，缺少跨视角约束，模型会在不同视角各自“讨好”2D 先验，于是长出 Janus 两张脸。CFG 与随机相机只是缓解，不是根治。SJC 的“扰动”是把渲染图加噪到训练分布，再用 PAAS 平均降方差，得分经雅可比回传，与 SDS 同族但方差更低。

$$\nabla_\theta \mathcal{L}_{\text{SDS}}=\mathbb{E}_{t,\epsilon}\left[w(t)\left(\epsilon_\phi(x_t;y,t)-\epsilon\right)\frac{\partial x}{\partial \theta}\right]$$

VSD 与 SDS 的核心差别在于 SDS 忽略当前 3D 分布，VSD 加粒子模型 ε_ψ，梯度含 (ε_φ−ε_ψ)，从 KL/变分视角看是让 3D 分布与 2D 先验对齐，因此能缓解过饱和与多样性差。ISM 的“区间”指 DDIM 反演得 x_t 后走正反两条轨迹，区间得分等于两轨迹差，降方差、稳几何。Fantasia3D 把几何与外观分开优化，因为纹理掩盖几何，先几何后外观，几何用 DMTet、外观用 BRDF，支持重光照。DreamGaussian 用 3DGS 快速收敛加少步 SDS，再网格提取与 UV 精修，速度换精度，把文生 3D 压到分钟级。

具体失败模式有两类：一是 β 退火设错（这是 NeuS 的题，但同属偏差家族），β 大到表面糊、β 小到薄结构噪或发散，Eikonal 正则约束 ||∇f||=1、零等值面即表面，β 退火 schedule 是隐形超参；二是 VolSDF 与 NeuS 都把 SDF 转成密度，差别在 VolSDF 用 Laplace、NeuS 用 logistic，α/β 参数化不同，共同依赖 Eikonal 与退火，参数化选错会让密度在表面附近过尖或过平。系统代价是 SDS 每步要多次 2D 扩散前向与渲染，显存与时间都按视角数线性涨。

四 · 多视图一致性与前馈模型：谁看见谁

多视图一致性题的核心是“信息通路”。MVDream 把 4 视图 token 拼接，用 3D 自注意力跨视角，2D 与多视图混合训练，代价是计算量乘 4、视角数固定。SyncDreamer 用 16 个固定视角，共享 3D 代价体在去噪中投影-采样同步，实现同步去噪。Wonder3D 同时生成颜色与法线双分支，法线约束几何，跨域共享注意力让两者对齐，多视图法线融合；失败模式是法线错误会传播到几何。Zero-1-to-3 的输入是参考图加相对位姿，多视图数据训练后零样本换视角，但它不是直接出 3D，只是新视角生成器。

前馈模型的判据是“一次前向替代逐场景优化”。LRM 主干是 ViT 加 cross-attention Transformer，输出三平面，用多视角渲染损失、50 万物体训练，所以能一次前向。pixelNeRF 用 CNN 图像特征，3D 点投影到视图采样特征拼进 NeRF MLP，amortized 推理而非逐场景优化。TripoSR 把单图重建压到 0.5 秒，靠 LRM 框架简化、三平面加 NeRF 渲染、大规模数据训练、混合精度与工程优化。InstantMesh 用 4 视图 LRM 前向，三平面/网格潜变量，FlexiCubes 可微提取，速度与拓扑折中；CRM 用 6 视图输入、卷积精修三平面、输出带纹理网格，卷积比全局注意力便宜。

输出换成高斯会带来新问题：GS-LRM 用高斯输出头，光栅化实时、显式可编辑，但漂浮物、稳定性与显存问题随之而来；MeshLRM 做可微网格而非“先出 NeRF 再提取”，因为提取不可微，端到端可微网格让梯度回顶点，拓扑与薄结构更好；LGM 用 4 视图输入、多视图 Transformer、高斯输出，高分辨率实时。Hi3DGen 的法线桥接把法线作为中间桥，多视图法线监督让高频细节更稳，比直接回归几何稳，因为法线错误会传播但比几何回归的歧义小。

具体例子：SyncDreamer 的共享 3D 代价体若投影采样实现错位，16 个视角会各自去噪出不一致的背面，表现为“转一圈看到接缝”。系统代价是 16 视角同步去噪的显存按视角数线性涨，且视角数固定意味着输入视图数变化时要重训或退化。

五 · 拓扑、PBR 与物理：网格手艺的工程判断

拓扑与 PBR 题考的是“下游能不能用”。FlexiCubes 可微提取解决速度与拓扑折中；MeshLRM 的可微网格解决提取不可微；CraftsMan3D 属于网格手艺方向，条目在此只作分类占位。PBR 三通道题要能说清 base color/metallic/roughness 与重光照的关系，delighting 去光照让材质对齐引擎标准输入；Hunyuan3D 2.1 把 PBR 材质拆三通道正是为此。物理题落在场景与交互，第十卷展开，此处只标记为“表示—材质—物理”链条的末端。

一个具体机制：可微光栅化把顶点位置、纹理与法线经光栅化变成像素，梯度回传到顶点与纹理，GET3D 与 TextMesh 都靠它；失败模式是纹理掩盖几何，几何错误被高分辨率纹理“粉饰”，所以 Fantasia3D 先几何后外观。系统代价是光栅化对薄结构与自交敏感，拓扑差时梯度噪声大。

最后落在一个工程判断上：面试题的价值不在答案本身，而在你能否把“表示的可微链路、监督的偏差结构、工程代价”三件事在同一张表上对齐；30 道题按五类展开时，每一类都至少有一个机制、一个公式或伪代码思路、一个失败模式、一个具体例子，缺一项就说明你只记住了结论没握住链路。
