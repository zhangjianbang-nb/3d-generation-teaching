一 · 这条方向要回答的三个问题，以及它们为什么必须一起回答

把“数据、评测与生产化”当成一个研究方向，最容易犯的错误是把它拆成三件互不相干的事：找数据的人只管爬资产，做评测的人只管刷榜单，做工程的人只管导出文件。但 3D 生成的真实链条是首尾咬合的：数据的分布决定了模型能学到什么材质与拓扑，评测的口径决定了什么样的输出会被判为“好”，而生产化的约束（UV 是否展开、法线是否可导、材质是否 PBR）反过来决定了评测必须测量哪些量。三者中任何一环单独优化，都会把另外两环的缺陷放大成系统性失败。

核心问题可以精确表述为三问。第一问是数据问：3D 生成模型需要什么样的数据，才能覆盖真实交付场景中的物体类别、材质类型与拓扑结构？第二问是评测问：在缺乏几何真值、且人类感知与像素指标长期脱节的条件下，怎样构造一个既可比又不误导的评测口径？第三问是生产问：如何把模型的原始输出（通常是三角网格加顶点色，或带噪点的隐式场提取结果）转换成可直接进入渲染引擎与动画管线的 PBR 资产？

这三问的共同点在于，它们都不是模型结构问题，而是“模型之外的一切”。一个生成模型的上限由数据决定，这是这一方向最重要的判断：Objaverse 把可用 3D 资产从十万级推到千万级（Objaverse-XL 明确以 10M+ 为规模目标），这一量级变化不是“多一点训练样本”的线性增益，而是让模型第一次有可能见到足够长的长尾——罕见材质、非标准拓扑、扫描噪声与手工建模混杂的分布。没有这一层，模型指标再高也落不了地，因为落地的判据不在论文表格里，而在引擎里能否被正确着色、能否被绑定骨骼、能否被批量导入。

边界也需要说清楚。这一方向不研究生成模型的网络结构、不研究扩散采样器的数学性质、不研究 3DGS 的栅格化性能优化。它研究的是模型之前的数据、模型之后的资产、以及横跨两者的评价体系。它与“生成模型”方向的关系是供给与验收的关系：前者产出候选，后者定义候选是否合格。它与“渲染”方向的关系是契约关系：生产化环节输出的 UV 布局与 PBR 通道，必须满足渲染管线对切线空间、金属度/粗糙度语义、光照解耦的硬性约定。

二 · 数据侧：从“抓取 Objaverse”到“合成数据引擎 + 版权清洗”

早期做法是把 Objaverse 当作静态语料：下载、去重、按类别分层采样、丢进训练。这条路径的机制很直接——资产自带标注与层级标签，采样器按标签做类别均衡，渲染器用固定光照与固定相机轨道批量出图，形成“资产→多视图→训练对”的流水线。它的代价也很直接：Objaverse 的资产来源高度异质，扫描件带有传感器噪声与缺失面，手工模型带有非流形边与重叠面，两者混在同一批次里会让法线监督信号自相矛盾。更严重的失败模式是标签噪声：层级标签由上传者填写，同一物体可能被标成“家具”也可能被标成“装饰”，按标签做均衡采样会把长尾类别反复过采样成伪高频类。

Objaverse-XL 把规模推到千万级，带来的不是简单的数量红利，而是分布形状的改变。规模上去之后，长尾不再由人工分层保证，而必须由数据引擎自动处理。近年数据侧的转向因此可以概括为两条：合成数据引擎与版权清洗。合成数据引擎的机制是“程序化生成 + 物理合理约束”：用参数化模板批量生成物体（例如同一类椅子的靠背角度、腿数、材质粗糙度在合理区间内采样），再用渲染器生成配对的多视图与材质真值。它的优势是真值完备——几何、UV、PBR 通道全部已知，可以直接用于监督 UV 展开与材质分解；代价是分布偏移，合成资产的材质统计与真实扫描差异明显，纯合成训练出的模型在真实长尾物体上会退化。

版权清洗则是另一类机制，本质是数据治理而非数据生成：对资产来源做许可追溯，剔除许可不明或禁止商用的条目，对可商用条目保留来源元数据，并在训练集中按许可类型分层。它的系统代价是吞吐——逐条追溯许可意味着数据管线从“批量下载”退化为“带审计的批处理”，吞吐下降且需要维护许可数据库。失败模式是清洗不彻底导致的许可污染：一旦训练集混入禁止商用资产，下游交付的模型输出就带有法律风险，而这种风险无法通过再训练消除，只能通过重建数据集解决。

一个具体例子可以说明这两条路径的互补性：训练一个面向电商家具的生成模型，真实扫描件提供材质真实感与磨损细节，合成引擎提供拓扑规整、UV 完备的配对样本，版权清洗保证最终交付的资产可用于商业场景。三者缺一，模型要么材质失真，要么 UV 无法展开，要么不可商用。这里的关键工程判断是：数据侧的目标不是“最大数据集”，而是“许可可追溯、真值可配对、分布可分层”的三元组。

$$\mathcal{D}_{\text{train}} = \{(A_i, L_i, c_i)\}_{i=1}^{N},\quad \text{s.t.}\ \text{license}(A_i)\in\mathcal{L}_{\text{ok}},\ \text{paired}(A_i)\ \text{exists}$$

上式只是一个约束式而非优化目标：它表达的是训练集必须同时满足许可白名单与配对真值存在两个条件，缺任一条件的资产只能进入无监督或弱监督分支。工程上这意味着数据管线要维护两条索引：许可索引与配对索引，任何一次采样都要先过这两道闸。

三 · 生产侧：UV 展开、PBR 分解与光照解耦的耦合关系

生产化的核心命题是：模型输出的网格不是资产，资产是“网格 + UV + PBR 材质 + 可动画拓扑”的四元组。SF3D 与 Hunyuan3D 2.1 之所以被视作生产化的分水岭，正是因为它们把 UV 展开、光照解耦与 PBR 材质分解放进了同一条输出链路，而不是留给下游手工处理。这三件事在数学上是耦合的，不能分开做。

UV 展开的机制是网格参数化：把三维曲面映射到二维平面，要求映射尽量保角或保面积，同时避免三角形翻转与重叠。一个常用的能量形式是最小化保角失真与面积失真的加权和，并对翻转三角形施加惩罚。它的系统代价是拓扑依赖：非流形边、孔洞、高亏格网格会让参数化求解器失败或产出严重拉伸的 UV 岛，而生成模型输出的网格恰恰经常带有这类缺陷。失败模式是 UV 接缝处的着色断裂——接缝两侧的纹素不连续，渲染时出现可见缝线，这在批量交付中是不可接受的。

$$E_{\text{UV}} = \sum_{t}\left(\|J_t\|_F^2 + \|J_t^{-1}\|_F^2\right) + \lambda\sum_{t}\mathbb{1}[\det J_t < 0]$$

上式中第一项同时惩罚拉伸与压缩，第二项对翻转三角形计数惩罚。工程上这个能量不是一次求解就完事，而是要在求解后做接缝对齐与纹素密度均衡，否则同一资产上不同 UV 岛的纹素密度差异会导致材质细节忽粗忽细。

PBR 材质分解的机制是把观测到的外观拆成反照率、金属度、粗糙度与法线四个通道，其物理基础是渲染方程中各通道的可辨识性：在已知光照与几何的条件下，反照率与光照的乘积存在固有的歧义，金属度与粗糙度则通过高光瓣的形状与菲涅尔响应体现。光照解耦正是为消除这一歧义：把输入图像中的光照估计出来并从外观中除掉，剩下的才是材质。SF3D 的“光照解耦”与 Hunyuan3D 2.1 的“production-ready PBR material”指向同一件事——输出必须能在任意光照下被重新照亮而不带原始照片的阴影。

失败模式在这里非常具体：如果光照解耦不彻底，反照率通道会烘焙进原始照片的阴影与高光，资产进入引擎后在新光照下会出现“双重阴影”——几何阴影叠加烘焙阴影，视觉上表现为脏污与不自然的暗部。系统代价是解耦需要额外的光照估计分支与训练配对数据（同一物体在不同光照下的多视图），这使数据需求从“多视图”升级为“多光照多视图”，采集成本显著上升。

可动画拓扑则是第四个约束，也是最容易被忽视的：生成模型输出的网格往往是无结构的高密度三角面，没有一致的边环与对称性，无法直接绑定骨骼。生产化要求输出具备可动画的拓扑结构（例如规整的四边形主导网格或带语义分段的网格），这反过来约束了生成阶段的表示选择。一个具体例子是角色类资产：即便几何与材质都正确，若拓扑在关节处没有足够的边环密度，蒙皮变形会出现塌陷，资产在动画管线上不可用。这就是为什么生产侧的转向被概括为“从出网格转向出 UV + PBR + 可动画拓扑”——四元组缺一不可。

四 · 评测侧：CLIP/FID/用户偏好与几何真值之间的鸿沟

评测的困境在于口径混乱。当前主流做法是 CLIP 相似度、FID 与用户偏好三类。CLIP 相似度衡量渲染图与文本或参考图的语义对齐，机制是把图像与文本嵌入到同一空间做余弦相似度；它的系统代价是对几何不敏感——一个几何完全错误但语义正确的渲染图可以得到高分。FID 衡量渲染图分布与真实分布的距离，机制是比较两组图像在特征空间的均值与协方差；它的失败模式是对小样本与渲染风格极度敏感，同一模型换一个渲染器 FID 就会显著变化，导致跨论文比较失效。用户偏好的机制是成对比较或 Likert 打分，代价是成本高、方差大、难以复现。

3DGS 综述暴露的正是这一混乱：不同工作使用不同的渲染协议、不同的相机采样、不同的背景与光照，指标之间不可比。更根本的问题是缺几何真值指标。语义指标无法区分“形状对但拓扑错”与“拓扑对但形状错”，而生产化恰恰关心后者。几何评测需要真值网格，而真实场景中真值往往不存在；用合成数据可以拿到真值，但又回到分布偏移问题。

指标类型测量对象主要失效模式生产化相关性
CLIP 相似度语义对齐对几何错误不敏感低：不能判 UV 与拓扑
FID图像分布距离渲染协议一变即不可比低：与材质通道无关
用户偏好整体感知成本高、方差大中：可捕捉材质真实感
几何真值指标形状与拓扑真值缺失、分布偏移高：直接对应可动画性

这张表的工程含义是：现有指标与生产化需求之间存在结构性错配。语义指标回答“像不像”，生产化问的是“能不能用”。一个可行的折中机制是分层评测：语义层用 CLIP/FID 做粗筛，几何层用真值网格的 Chamfer 距离与法线一致性做精筛，材质层用重光照一致性（同一资产在不同光照下渲染，比较其反照率通道的稳定性）做验收。分层评测的代价是管线复杂度上升，但它是目前唯一能把“感知”与“可用”分开度量的路径。

$$d_{\text{geo}}(M,\hat{M}) = \frac{1}{|\hat{M}|}\sum_{x\in\hat{M}}\min_{y\in M}\|x-y\|_2 + \frac{1}{|M|}\sum_{y\in M}\min_{x\in\hat{M}}\|y-x\|_2$$

Chamfer 距离的双向形式能捕捉缺失面与多余面，但它对拓扑错误不敏感：一个拓扑完全错误但点集接近的网格可以得到很低的值。因此几何层还必须加入拓扑一致性检查（边环结构、亏格、连通分量数），这类检查无法用连续距离表达，只能作为离散判据。

五 · 为什么其他方向替代不了这一层

一个自然的反问是：模型能力足够强时，是否可以直接端到端输出可用资产，从而绕过数据治理、评测口径与生产化环节？答案是否定的，原因在于这三件事各自对应一类不可由模型内部消化的约束。

数据治理对应法律约束。许可与版权不是分布内的统计规律，而是分布外的硬性规则。模型无法从数据中“学会”哪些资产不可商用，因为禁止商用的条目与可商用条目在视觉上无法区分。版权清洗必须在数据管线层面执行，且必须可审计——这是模型参数无法承载的信息。

评测口径对应认识论约束。模型无法自证其输出的几何正确性，因为生成过程本身不提供真值。评测必须依赖外部参照（真值网格、重光照协议、人类判断），而这些参照的构造是独立于模型的工程工作。把评测交给模型自评，等于用同一个可能有偏的分布去检验自身，误差不会被发现只会被放大。

生产化对应管线契约约束。渲染引擎对 UV 布局、切线空间、PBR 通道语义有硬性约定，这些约定是历史形成的工业标准，不随模型能力变化。模型可以学会输出“看起来像 PBR”的贴图，但若通道语义不符合引擎约定（例如金属度通道被写进了粗糙度信息），资产在引擎中就是错的。这类错误无法通过提升生成质量解决，只能通过生产化环节的显式转换与校验解决。

一个具体例子可以收束这三类约束：假设一个模型在 CLIP 与 FID 上均达到当时最优，但其输出网格带有翻转三角形、反照率烘焙了原始阴影、拓扑无关节边环。这个模型在论文表格里是成功的，在交付管线里是失败的。失败的原因不在模型，而在数据（缺少 UV 配对真值）、评测（缺少几何与重光照指标）、生产化（缺少展开与解耦环节）三层的缺失。这正是这一方向不可替代的工程判断：模型的上限由数据决定，模型的下限由评测与生产化决定，而后者不能由前者替代。

进一步说，这三层之间还存在反馈回路。生产化环节发现的失败模式（接缝断裂、双重阴影、拓扑不可绑定）应当回流为评测指标，评测指标应当回流为数据采集的约束（例如增加多光照多视图配对），数据约束再回流为训练分布的设计。这个回路的每一段都需要显式的工程实现，而不是指望模型在训练中自动发现。回路闭合的程度，决定了一个 3D 生成系统能否从“演示”走到“交付”。
