一 · 生产管线的真实瓶颈：从网格到可交付资产

在工程视角下，“生成一个网格”与“交付一个可进引擎的资产”是两件不同量级的事。网格只是顶点与面的集合，而引擎需要的是带 UV 参数化的拓扑、分离的 PBR 通道、明确的光照假设，以及可被骨骼绑定的合理布线。SF3D 与 Hunyuan3D 2.1 之所以在方向中占据关键位置，不是因为它们把 Chamfer Distance 刷得更低，而是因为它们把“后处理链”内化进了模型：SF3D 在重建阶段直接输出 UV 展开与光照解耦的结果，Hunyuan3D 2.1 则把生产级 PBR 材质作为输出的一部分。这一步的意义在于，原本需要美术在 DCC 工具里手工完成的展开、烘焙、材质拆分，被压缩成一次前向推理。

具体机制上，UV 展开的本质是一个从三维曲面到二维平面的映射问题。给定网格表面 $S$，需要构造参数化 $f: S \to \mathbb{R}^2$，使得映射尽量保角或保面积，同时把接缝（seam）放在曲率低、视觉不敏感的区域。工程上常用的是基于 LSCM（Least Squares Conformal Maps）或 ABF（Angle Based Flattening）的求解，其目标函数可写为最小化保角能量：

$$E_{\text{conf}}(f) = \int_S \left\| \nabla f \right\|^2 - \left| \nabla f \times \nabla f \right| \, dA$$

当模型直接回归 UV 坐标而非在网格上求解时，网络必须隐式学会接缝的放置策略，这带来一个系统代价：UV 接缝处的纹理连续性无法用几何损失约束，只能靠渲染损失或对抗损失间接监督，训练不稳定且容易在接缝处产生可见的拉伸与色差。失败模式很具体——一个带复杂凹槽的机械零件，网络回归的 UV 在凹槽内壁产生重叠面（overlap），烘焙时纹理互相污染，进引擎后表现为闪烁的暗斑。这类缺陷不会出现在 Chamfer 指标里，却直接导致资产不可用。

光照解耦是另一条被内化的链路。SF3D 的做法是把反照率（albedo）与光照项分离，使得输出资产在任意光照环境下可复用。其隐含假设是 Lambertian 反射加低频环境光，对于金属与高光材质，这一假设会失效：解耦出的 albedo 把高光“烤”进了基础色，导致资产在引擎里换光照后高光位置错误。工程判断是，光照解耦的收益在漫反射主导的物体上成立，在金属、陶瓷、湿润表面这类长尾材质上需要额外的镜面分离监督，否则解耦只是把错误从光照通道搬到了 albedo 通道。Hunyuan3D 2.1 强调 PBR 材质分解，正是试图用多通道监督缓解这一问题，但 PBR 的 metallic-roughness 通道在缺乏真实材质真值的情况下，仍主要依赖合成数据与渲染一致性约束。

二 · 评测口径的混乱：指标与感知的错位

3DGS 综述暴露的评测口径问题，在生成侧同样存在，且更严重。当前主流评测以 CLIP 相似度、FID、用户偏好研究为主。CLIP 分数衡量的是渲染图与文本/参考图的语义对齐，FID 衡量渲染分布与真实分布的统计距离，用户偏好则是对成对渲染做主观投票。这三类指标的共同缺陷是：它们都在二维渲染空间上度量，而资产的三维正确性——拓扑是否流形、UV 是否无重叠、法线是否一致、PBR 通道是否物理合理——完全不在度量范围内。

具体机制上，CLIP 分数的计算是对渲染图与条件嵌入做余弦相似度，其梯度对几何细节不敏感：一个拓扑破损但渲染图语义正确的资产，CLIP 分数可以很高。FID 更依赖渲染视角的采样策略，视角集合的选择直接决定分数，不同论文的视角集合不一致，导致跨论文比较失去意义。用户偏好的系统代价是标注成本与方差：成对比较需要大量被试，且被试对 PBR 材质的判断受显示设备与光照环境影响，重复实验的一致性难以保证。

缺失的是几何真值指标。可行的方向包括：基于采样的表面距离（Chamfer、Hausdorff）、法线一致性、UV 重叠率、流形性检查、以及 PBR 通道的物理约束违反率。这些指标在重建任务中已有成熟定义，但在生成任务中难以应用，因为生成没有配对的真值网格。一个折中方案是用渲染一致性作为代理：在固定光照与材质假设下，从多个视角渲染生成资产与参考资产，比较其差异，但这又回到二维空间，无法捕捉三维结构错误。

指标类别度量空间能捕捉的缺陷系统性盲区
CLIP 相似度二维渲染 + 语义嵌入语义对齐、整体外观拓扑、UV、法线、PBR 物理性
FID二维渲染分布分布层面的真实感单资产几何正确性、视角依赖
用户偏好主观感知整体可用性、材质观感可复现性、成本、设备依赖

一个具体例子：两个模型生成同一把椅子，模型 A 的 CLIP 分数更高但椅腿与座面的连接处拓扑断裂，模型 B 分数略低但拓扑完整。按现有口径 A 胜出，但进引擎后 A 需要手工修补，B 可直接使用。这说明评测口径与生产可用性之间存在结构性错位，而非随机噪声。

三 · 数据侧的工程转向：合成引擎与版权清洗

Objaverse 与 Objaverse-XL 把可用资产从十万级推到千万级，这一规模跃迁改变了训练范式，但也把工程瓶颈从“抓取”转移到了“清洗与合规”。千万级资产中，许可协议混杂、重复资产、破损网格、缺失材质的比例不可忽略。工程管线必须做许可过滤（区分 CC0、CC-BY、禁商用许可）、去重（基于几何哈希与渲染指纹）、以及网格修复（补洞、重算法线、统一尺度）。这些步骤的计算成本与人工审核成本，往往超过训练本身的数据加载开销。

近年数据侧的转向是从“抓取 Objaverse”走向“合成数据引擎 + 版权清洗”。合成引擎的逻辑是：用程序化生成或渲染管线合成带精确真值的资产，绕开版权与标注问题。具体机制上，合成管线可以控制几何复杂度、材质参数、光照条件，从而生成配对的（资产，UV，PBR，渲染）四元组，为监督学习提供真值。代价是合成数据的分布偏移：程序化生成的资产在长尾物体与罕见材质上覆盖不足，模型在合成数据上训练后在真实扫描资产上泛化下降。

版权清洗的系统代价体现在两个层面。其一是许可解析：Objaverse 的元数据中许可字段格式不统一，需要规则引擎加人工抽检，抽检比例与误判率直接决定合规风险。其二是衍生作品追踪：即使原始资产是 CC0，其纹理可能来自受版权保护的来源，清洗管线需要纹理级溯源，这在千万级规模上难以全量执行。失败模式是合规资产池在清洗后规模缩水，训练数据量下降，模型 ceiling 随之下降——这正是“数据决定 ceiling”的工程体现。

一个具体例子：一个包含大量扫描家具的资产池，清洗后发现相当比例的资产缺失 metallic-roughness 通道，只有一张烘焙了光照的 diffuse 贴图。这类资产无法直接用于 PBR 监督，必须经过材质分解或重新烘焙，而分解算法在无真值情况下引入误差。工程判断是，数据侧的清洗成本应计入训练预算，而非视为一次性预处理。

四 · 长尾与罕见材质：分布尾部的系统性失败

长尾物体与罕见材质是数据与评测共同暴露的开放问题。生成模型在常见类别（椅子、桌子、汽车）上表现稳定，但在罕见类别（专业仪器、传统器物、生物标本）上几何与材质同时退化。机制上，这是因为训练分布的长尾部分样本稀疏，模型对这些类别的先验不足，回归出的几何趋向于平均形状，材质趋向于默认的灰色漫反射。

罕见材质的失败更隐蔽。PBR 材质的真实感依赖 metallic、roughness、以及各向异性、次表面散射等扩展通道。主流数据集对这些通道的标注稀疏，模型学到的材质分布集中在少数常见材质上。当输入图像包含罕见材质（如丝绸的各向异性高光、蜡质的次表面散射），模型输出的 PBR 通道趋于保守，渲染结果失去材质辨识度。评测侧对此几乎无感知，因为 CLIP 与 FID 对材质物理性的敏感度低。

可行的缓解机制是材质先验注入：在训练中引入材质分类或材质参数回归的辅助任务，迫使模型学习材质通道的分布；或在推理时用参考材质库做检索增强，把罕见材质映射到库中最近的物理合理参数。系统代价是辅助任务增加训练复杂度，检索增强引入推理延迟与库维护成本。失败模式是材质库覆盖不足时，检索增强把罕见材质错误映射到常见材质，产生“看起来对但物理错”的资产，这类错误比明显的几何破损更难被发现。

一个具体例子：生成一件带刺绣的织物，几何上褶皱正确，但 PBR 输出把刺绣的金属线误判为漫反射，渲染后失去金属光泽。用户偏好研究可能仍给出较高评分，因为整体形状与颜色正确，但材质真实感已丢失。这说明长尾材质的评测需要材质级别的判别，而非整体偏好。

五 · 开放问题与下一步的工程判断

开放问题可以归为三条主线，每条都对应具体的工程决策。第一条是评测的真值问题：生成任务缺乏配对真值，几何指标无法直接应用。可行的下一步是建立带真值的生成基准，用合成管线生成配对资产，或在真实资产上做受控退化再生成，从而获得参考。工程判断是，这类基准的构建成本高，但它是把评测从二维语义拉回三维正确性的唯一路径。

第二条是 PBR 材质的监督信号问题。当前材质分解依赖渲染一致性约束，缺乏材质参数的真值。下一步的方向是用可控光照与材质已知的合成渲染做监督，或在真实数据上用多光照采集做分解。系统代价是采集设备与标注成本，失败模式是合成与真实的材质分布偏移导致分解在真实资产上退化。工程上，材质监督的投入应优先于几何指标的微调，因为材质是资产可用性的直接决定因素。

第三条是数据合规与规模的权衡。版权清洗缩水资产池，合成数据补足规模但引入分布偏移。下一步的工程判断是建立混合数据管线：合规真实资产做分布锚点，合成资产做规模与真值补充，并用分布匹配约束合成数据的采样。失败模式是混合比例失当导致模型偏向合成分布，在真实资产上泛化下降。

在系统层面，生产化管线的下一步不是追求单模型端到端，而是把 UV 展开、PBR 分解、拓扑修复拆成可独立验证的模块，每个模块有明确的输入输出契约与失败检测。例如 UV 模块输出重叠率与接缝长度作为质量信号，PBR 模块输出通道物理约束违反率，拓扑模块输出流形性检查结果。这些信号进入评测管线，替代单一的 CLIP 分数。工程判断是，模块化带来的接口成本低于端到端模型在长尾上的系统性失败成本，且模块级质量信号使失败可定位、可回退。

最终落在具体机制上：生产化管线的核心是把“生成”定义为带质量契约的资产交付，而非带分数的渲染输出。质量契约包括 UV 无重叠、PBR 通道物理合理、拓扑流形、光照解耦假设明确。评测管线围绕这些契约构建，数据管线围绕这些契约清洗与合成。当契约被违反时，系统回退到修复模块而非重新生成，这是把生成模型嵌入生产流程的工程前提。
