一 · 从 NeRF 到哈希编码：把「慢」从算法问题降级为工程问题

NeRF 的原始贡献有两层，常被混为一谈。第一层是表示：用 MLP 把空间坐标 $(x,y,z)$ 与视角方向 $(\theta,\phi)$ 映射到密度 $\sigma$ 与颜色 $\mathbf{c}$，场景被隐式地存进网络权重里。第二层是渲染算子：沿相机射线积分，把连续场变成像素值，使「用 2D 光度损失反传梯度到 3D 表示」在数学上成立。体渲染离散化后的形式是

$$\hat{C}(\mathbf{r})=\sum_{i=1}^{N} T_i\left(1-e^{-\sigma_i\delta_i}\right)\mathbf{c}_i,\qquad T_i=\exp\left(-\sum_{j

这个式子的关键在于它对 $\sigma_i$ 与 $\mathbf{c}_i$ 都可微，因此整条链路——采样、积分、损失、反向传播——是一个可训练的计算图。NeRF 真正的瓶颈不在表示能力，而在每个像素要沿射线采样数十到上百个点，每个点都要过一遍多层 MLP；一次训练迭代要评估数百万次前向，训练以天计，渲染以秒计。这不是理论缺陷，是算力配置问题。

Instant NGP 的继承关系非常清晰：它保留了 NeRF 的体渲染积分与光度监督，只替换了「坐标到特征的映射」这一环。多分辨率哈希编码把空间切成 $L$ 层不同分辨率的网格，每层顶点存一个可学习的特征向量，查询时对 $2^d$ 个角点做线性插值再拼接。分辨率按几何级数增长，粗层负责全局结构，细层负责高频细节。哈希表把内存从「按分辨率立方增长」压到「按预算线性增长」，冲突由多个哈希函数与梯度平均来消化。代价是：哈希冲突会引入高频噪声，细层特征在未被观测到的区域缺少梯度，表现为空洞或雾状伪影；同时哈希表本身是显存驻留结构，分辨率层数与特征维度的组合直接决定显存占用，调参空间被硬件卡死。

具体例子：一个室内场景若用纯 MLP 表示，训练需要反复评估网络，单卡难以在小时级完成；换成哈希编码后，同样的体渲染损失函数不变，但每次查询变成几次查表与插值，训练时间被压到分钟级。这里发生的不是算法范式的断裂，而是把「表达能力」从网络深度转移到了显式特征表上——后续 3DGS 走的正是同一条思路的极端版本：干脆不要网络，把场景离散成一堆可优化图元。

继承关系上还要注意一点：哈希编码并未解决稀疏视图的几何歧义，它只是让「多视图密集监督」这条路线变得便宜。当视角数量掉到个位数，光度损失对几何的约束不足，哈希编码的高频容量反而会拟合出错误的表面——这是后来 NeuS 与生成式先验要接手的部分。

二 · NeuS 与 VolSDF：把体积密度重新解释成表面

NeRF 的密度场没有「表面」的概念，等值面是事后提取的，提取质量取决于密度分布的锐利程度。对重建任务而言这是结构性缺陷：优化目标是渲染颜色，几何只是副产品，因此会出现表面糊、薄结构丢失、多视角下几何不一致。NeuS 与 Volume Rendering of Neural Implicit Surfaces 属于同一批工作，处理的是同一个断裂点——如何让体渲染的梯度直接约束一个符号距离场（SDF）。

核心机制是把密度定义为 SDF 的变换。设 $f(\mathbf{x})$ 为 SDF，则密度可写成

$$\sigma(\mathbf{x})=\alpha\,\Phi_\beta\!\left(-f(\mathbf{x})\right),\qquad \Phi_\beta(s)=\frac{1}{1+e^{-\beta s}}$$

其中 $\Phi_\beta$ 是带温度参数的 logistic 函数，$\beta$ 随训练增大，使密度逐渐收敛到表面处的阶跃。这样，体渲染积分仍然照旧，但积分里的 $\sigma$ 现在由一个有符号距离场导出，梯度可以穿过渲染损失回传到 SDF 参数上。NeuS 进一步推导了无偏的权重函数，使渲染权重在表面处取极大值，避免表面位置被系统性偏移。Volume Rendering of Neural Implicit Surfaces 则从概率密度与不透明度的关系出发给出另一条推导，两者在工程上等价于同一件事：让「画出来的图」与「提取出来的面」共享同一组参数。

系统代价很具体。第一，SDF 需要良好的初始化与 Eikonal 正则（梯度模长接近 1），否则密度变换会退化成模糊的体积雾；第二，$\beta$ 的退火 schedule 是超参，退火太快表面会锁死在错误位置，太慢则训练末期仍有残余雾；第三，SDF 的查询仍是全空间网络评估，训练成本高于哈希编码路线，实时渲染更谈不上。失败模式典型表现为：薄板、栏杆、树叶这类结构在 SDF 上被平滑掉，因为体积分对薄结构的梯度贡献弱；反射表面则因为颜色场与几何解耦不足而出现「表面正确但外观错」的分离。

具体例子：一个带细长支架的物体，纯 NeRF 的密度场会把支架渲染成半透明絮状，深度图无法用于下游；换成 NeuS 后，支架在 SDF 上表现为窄带高梯度区域，提取的网格能保留结构，但训练时间与显存开销明显上升。这解释了为什么 2023 年后 NeuS 系工作没有成为实时主流，而是退居「需要干净网格」的重建管线中。

三 · 3DGS：不是 NeRF 的改进，而是对体渲染积分的一次替代

3D Gaussian Splatting 与 NeRF 的关系常被描述为「更快」，这个说法掩盖了真正的断裂。NeRF 系方法的核心是沿射线做数值积分，渲染是「采样—积分」；3DGS 把场景表示为一组各向异性高斯椭球，每个高斯带位置、协方差、不透明度与球谐颜色系数，渲染是把这些椭球投影到屏幕并按深度排序后做 alpha 混合。它没有体积分，只有光栅化。

投影后的 2D 协方差由下式给出：

$$\Sigma'=J\,W\,\Sigma\,W^{\top}J^{\top}$$

其中 $\Sigma$ 是 3D 协方差（通常由缩放与旋转参数化以保证半正定），$W$ 是视图变换，$J$ 是投影的雅可比。像素颜色是沿排序后高斯的加权和，权重来自不透明度与 2D 高斯在像素处的取值。这个结构使渲染成为一次前向光栅化，不需要沿射线采样，因此可以在交互帧率下出图；梯度则通过可微光栅化回传到每个高斯的参数上。

继承与替代的边界要讲清楚。继承的是「用 2D 光度损失优化 3D 表示」这一总纲，以及球谐颜色这类视角相关外观的参数化思路。替代的是渲染算子本身：积分换成了排序混合，隐式网络换成了显式图元集合。由此带来的系统代价是内存与工程复杂度：高斯数量随场景规模增长，每个高斯要存几十个浮点数，大场景的显存占用直接顶到硬件上限；排序在每帧都要做，动态场景下排序稳定性与图元增删策略成为新的失败源。典型失败模式包括：高斯在未观测区域过度生长造成「漂浮絮状物」，薄结构与镜面反射处出现拉长的高斯「针状」伪影，以及大场景分块后块间颜色与几何不一致。

具体例子：同一段多视角视频，NeRF 系方法训练以小时计、渲染以秒计；3DGS 训练在分钟级、渲染在毫秒级，代价是显存占用高一个量级，且优化过程依赖致密化与剪枝的启发式规则——这些规则没有理论保证，参数敏感，是工程落地时最主要的调试负担。这也解释了为什么 3DGS 之后的研究迅速分叉：一路做稀疏视图与生成式先验，一路做动态与材质，一路做大场景分块，而很少有人再回头改体渲染积分本身。

四 · pixelNeRF：把「先验」从优化里拿出来，放进网络里

前三节的工作都假设视角足够多，光度损失足以约束几何。pixelNeRF 处理的是这个假设失效的情形：单图或极少视图。它的机制不是改渲染，而是改输入的构造方式——把每张输入视图的像素特征作为条件，查询时对空间点投影到各输入视图的相机平面，取对应位置的特征，再与查询坐标一起送入网络，输出该点的密度与颜色。渲染与积分仍沿用 NeRF 的体渲染，但网络不再只依赖坐标，而是依赖「坐标 + 观测到的图像特征」。

伪代码层面的思路是：对查询点 $\mathbf{x}$，对每个输入视图 $i$ 计算投影坐标 $\pi_i(\mathbf{x})$，双线性采样特征图 $F_i$，聚合（拼接或平均）后与 $\mathbf{x}$ 一起过 MLP，得到 $(\sigma,\mathbf{c})$。训练时用多视图数据监督，推理时给一张图即可前向出辐射场，无需针对该场景重新优化。

这条路线的重要性在于它确立了「前馈先验」这一范式：歧义不再靠逐场景优化去猜，而是靠跨场景训练学到的统计规律去补。代价是：前馈网络的输出受训练分布限制，跨类别泛化会退化；投影聚合在遮挡与视角外区域失效，表现为背面与侧面的几何塌陷；特征图分辨率决定了细节上限，高分辨率意味着显存与计算上升。失败模式典型是「正面看起来对、转过去是糊的」，因为网络只学到了训练集里常见的视角相关性。

与后续生成式先验的关系是延续而非替代：扩散模型与前馈大模型补的正是 pixelNeRF 留下的「未见区域」缺口，而 pixelNeRF 确立的条件化查询结构——把观测图像特征注入辐射场查询——仍是少视图重建管线的骨架。工程判断上，pixelNeRF 类方法适合「一次前向、多场景批量」的场景，不适合「单场景极致质量」的场景；后者仍要回到逐场景优化，只是优化目标里要加先验正则。

五 · 年代线上的断裂点与延续线

把上述工作按依赖关系而非年份排序，能得到一条更清楚的继承链。第一段是「可微渲染算子成立」：NeRF 给出体渲染积分与光度监督的闭环，这是所有后续工作的公共底座。第二段是「算子变便宜」：Instant NGP 用多分辨率哈希编码替换坐标网络，保持积分不变，把训练成本压到工程可接受范围，使密集多视图重建成为常规操作。第三段出现分叉：一支继续在体渲染框架内修几何，NeuS 与 VolSDF 把密度重解释为 SDF，使渲染与表面提取共享参数；另一支直接换掉算子，3DGS 用显式高斯与光栅化替代积分，换取实时性。第四段是「歧义补足」：pixelNeRF 把跨场景先验注入查询，为少视图提供条件化结构，后续扩散与前馈模型沿这条线继续补未见区域。

断裂点集中在两处。其一是渲染算子：3DGS 对体渲染积分的替代是范式级的，它把「每像素采样」变成「每图元投影」，因此实时性来自结构而非近似。其二是监督来源：pixelNeRF 之后，优化目标里出现了「跨场景学到的先验」这一项，逐场景优化不再是唯一路径，这直接导向后来的前馈大模型与蒸馏管线。延续线则是「2D 光度损失反传 3D 参数」这一条始终未断，无论表示是 MLP、哈希表、SDF 还是高斯集合。

工程判断上，这条年代线的实用含义是：选型时先问「监督密度」。视角充足时，哈希编码 + 体渲染或 3DGS 都能给出高质量重建，后者胜在实时；需要干净网格时，SDF 系方法不可替代，但要接受训练成本；视角稀疏时，任何逐场景优化都会陷入歧义，必须引入前馈或生成式先验，此时 pixelNeRF 式的条件化查询结构仍是接入点。把这三条判据混用——例如在稀疏视图上硬跑 3DGS 致密化——会得到漂浮伪影与错误几何，这不是调参能解决的问题，而是监督信息量不足的结构性失败。

还有一条容易被忽略的延续：评测。体渲染积分与光栅化给出的图像在感知上接近，但深度、法线、表面提取的语义不同，PSNR 与 LPIPS 无法区分「几何正确但外观错」与「外观对但几何糊」。这导致论文间的数字不可直接比较，也导致工程上必须自建几何一致性检查——例如多视角深度重投影误差、表面法线与观测梯度的一致性——而不能只看渲染指标。这一点在稀疏视图与大场景分块两条线上尤其致命，因为块间与视图间的几何不一致往往在单图指标上不可见。

最后落在机制上：3DGS 的致密化规则以屏幕空间梯度为信号，在梯度大的区域分裂高斯、在透明度过低的区域剪枝，这条规则没有几何约束，因此在反射与薄结构处会持续产生错误图元；工程上可行的缓解是把 SDF 或多视图深度作为额外监督注入光栅化损失，让图元增长受几何一致性约束，而不是只受光度残差驱动。这正是当前管线把 NeuS 系几何先验与 3DGS 渲染效率拼接在一起的动机——不是回到体渲染，而是把表面约束作为正则项挂到光栅化算子上。
