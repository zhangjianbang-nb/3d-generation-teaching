一 · 问题的定义：从一张图到一个可重建的视图集合

多视图扩散与重建要解决的问题可以精确表述为：给定单张输入图像 I₀ 及其相机参数 π₀，生成一组 N 张图像 {I₁,…,I_N} 及对应相机参数 {π₁,…,π_N}，使得这组图像既满足 2D 图像的自然性（纹理、光照、材质合理），又满足 3D 几何一致性（同一物体在不同视角下的投影关系自洽），并且能够被后续重建模块恢复成显式 3D 表示（网格、高斯、隐式场）。这个定义里三个约束同时成立才算成功，缺一不可。

它与普通图像生成的根本差别在于「一致性」是硬约束而非软偏好。单图扩散模型只对单张图的像素分布负责；多视图扩散必须对视图之间的对应关系负责。形式化地，若 X = {x_i} 是各视图像素，π_i 是相机，则要求存在一个 3D 场景 S 使 x_i ≈ Render(S, π_i) 对所有 i 成立。这就是多视图一致性约束：

$$\min_{S}\ \sum_{i=1}^{N}\ \big\|\,x_i-\mathrm{Render}(S,\pi_i)\,\big\|^2 \ \ \text{s.t.}\ \ x_i\sim p_\theta(\cdot\mid I_0,\pi_i)$$

这个式子的含义是：生成模型给出每个视角的条件分布，而一致性要求这些样本共同落在一个可渲染的 3D 场景的像平面上。工程上无法直接求解，于是拆成两步：先用扩散模型采样出满足联合分布的多视图，再用重建模型拟合 S。两步之间的缝隙——生成图像不严格一致、重建模型容错有限——正是这个方向所有失败模式的总源头。

具体机制上，视角条件扩散把相机参数编码进条件通路。以 Zero-1-to-3 为代表的做法是：把相对视角变换（旋转 R、平移 t）作为条件注入，模型学习 p(x_{\text{novel}} \mid I_0, R, t)。这本质上是把「新视角合成」当作条件生成问题，模型在训练中见过大量 (输入图, 目标视角, 目标图) 三元组，从而学会在给定视角下推断被遮挡区域的外观。代价是：每个视角独立采样时，视图之间没有耦合，背面与正面的纹理会在不同采样中漂移，出现「每张图都好看，拼起来不是同一个物体」的典型失败。

一个具体例子：用 Zero-1-to-3 分别以 0°、90°、180°、270° 为条件采样四次，得到四张各自合理的图；但若把 90° 视图的纹理与 270° 视图的轮廓做极线检查，会发现同一物体边缘的对应点不重合，重建出的网格在接缝处出现双层表面。这不是模型能力不足，而是「逐视角条件生成」这一机制本身不携带跨视图耦合项。要修掉它，必须把多视图放进同一个去噪过程里联合建模，这就是下一节要讨论的自注意力机制。

二 · 为什么单图生 3D 绕不开多视图：背面未知的信息论边界

单张图生 3D 的核心困难不是网络容量，而是信息缺失。一张图像是 3D 场景在单一视锥内的投影，被遮挡的背面、侧面、内部结构在像素上完全不存在。任何从单图直接回归 3D 的模型，都必须对未见区域做先验补全。这个补全的可靠性由训练分布决定，而不是由输入决定。

从信息角度，可以把问题写成条件熵：给定输入图 I₀，真实 3D 场景 S 的后验熵 H(S | I₀) 并不为零，且随遮挡比例上升。单图回归模型实际上在学习一个确定性映射 f: I₀ → S，它把整个后验分布压缩成一个点估计，于是背面区域只能是「平均意义上的合理猜测」，在多类物体混合训练时表现为模糊、扁平、对称化。多视图扩散改变了这个结构：它不直接回归 S，而是采样 p({x_i} | I₀)，把后验的多样性保留在图像空间，再由重建模块做几何拟合。

这个转换的工程价值在于把「3D 先验」拆成「2D 图像先验 + 多视图一致性」。2D 扩散模型在大规模图像上训练，具备强纹理与语义先验；一致性则由多视图注意力与极线约束提供。两者相乘，使得背面生成从「凭空的 3D 想象」变成「受几何约束的 2D 外推」。这就是 2023 年图生 3D 质量跃升的中间层逻辑：不是端到端 3D 生成变强了，而是把 3D 问题降维成多视图一致性问题，让成熟的 2D 生成能力得以复用。

具体机制上，多视图自注意力（MVDream、SyncDreamer 路线）把 N 个视角的 latent 拼成一个序列，在去噪的每一层做跨视图注意力。设第 l 层第 i 个视图的 token 为 h_i^l，则更新为：

$$h_i^{l+1}=\mathrm{Attn}\!\left(h_i^{l},\ \big[\,h_1^{l},\dots,h_N^{l}\,\big]\right)$$

关键在于注意力是全局的：视图 i 的每个 token 都能看到其他视图的所有 token，模型因此在去噪过程中被迫协商出一致的纹理与轮廓。SyncDreamer 进一步引入极线约束，把注意力限制在沿极线的候选区域，减少无关视图的干扰；代价是注意力矩阵随 N² 增长，显存与计算量迅速膨胀。生成 4 视图尚可，扩到 16 视图时注意力开销成为瓶颈，这是「视图数量」与「一致性质量」之间的直接工程权衡。

失败模式很具体：当输入图包含强反光或透明材质时，多视图注意力会把高光「抹平」到所有视角，因为模型倾向于用一致的漫反射解释像素，结果重建出的材质失去各向异性。另一个例子是细长结构（如自行车辐条），极线注意力在稀疏视图下采样不足，辐条在不同视图中数量与位置不一致，重建时被融合成一片模糊的薄片。这些都不是调参能解决的问题，而是「用 2D 一致性近似 3D 一致性」这一降维策略的固有误差。

三 · 边界：这个方向不负责什么，以及为什么其他路线替代不了

明确边界比罗列能力更重要。多视图扩散与重建不解决以下问题：它不做单视图的语义理解与部件分割（那是识别任务）；它不保证物理合理性（生成的衣服褶皱可能不符合布料力学）；它不处理动态场景与关节运动（训练数据以静态物体为主）；它不提供水密、流形、可制造性保证（重建网格常有自交与孔洞）。把这些问题误认为该方向的目标，会导致对结果的错误期待。

与其他路线相比，它的不可替代性体现在三点。第一，与「单图直接回归 3D」相比，它保留了生成多样性并显式处理遮挡：回归模型输出单一确定解，多视图扩散可以采样多个合理背面，再择优重建。第二，与「文本生 3D」相比，它以图像为条件，绕开了文本描述的歧义性，输入即目标外观，适合「给定这张照片，做出这个物体」的工程场景。第三，与「神经渲染新视角合成」相比，它输出的是可导出、可编辑的显式几何，而不是仅能渲染的隐式场；重建模块把图像转成网格或高斯，才能进入下游管线。

具体机制上，跨域法线-颜色扩散（Wonder3D 路线）体现了这个方向的边界扩展方式：同时生成颜色图与法线图，用法线作为几何锚点约束颜色的一致性。设颜色分支输出 c_i，法线分支输出 n_i，训练时用共享的几何潜变量耦合两者，推理时法线图直接喂给重建器做几何初始化。这解决了一个具体失败：纯颜色多视图在弱纹理区域（白墙、纯色塑料）缺乏对应点，重建器无法对齐；法线图提供了与纹理无关的几何线索，使弱纹理表面也能被正确三角化。代价是双分支使采样成本翻倍，且法线图本身的视角一致性误差会直接传播到几何。

另一个边界例子是分辨率错配。扩散模型通常在较低分辨率上训练（受显存与注意力开销限制），而重建模型期望较高分辨率的输入以恢复细节。直接把低分辨率生成图喂给重建器，会丢失边缘与细纹理，网格在轮廓处出现阶梯状锯齿。工程上的处理是分阶段超分或使用法线桥接（Hi3DGen 路线）把几何细节从法线域迁移回颜色域，但这引入了额外的误差累积：超分模型可能「编造」不存在的细节，重建器再把这些编造当成真实几何。这条误差链是这个方向当前最实际的精度上限来源之一。

四 · 系统代价：一致性、分辨率、相机分布三者的耦合约束

把多视图扩散接入实际管线时，代价不是单一指标，而是三个约束的耦合：一致性要求更多视图与更强跨视图注意力；分辨率要求更高像素与更长 token 序列；相机分布要求训练数据覆盖推理时的视角采样策略。三者互相挤压显存与算力。

先看一致性。跨视图注意力的计算量随视图数 N 与 token 数 L 增长，近似为 O(N²L²)。当 N 从 4 增到 8，注意力矩阵扩大四倍；若同时把分辨率翻倍使 L 变为四倍，总开销扩大十六倍。这就是为什么早期工作普遍停在 4–6 视图：不是不想更多，而是显存墙。SyncDreamer 用极线稀疏化缓解，MVDream 用共享潜变量与固定视角集缓解，但都只是常数因子改善。

再看相机分布偏差。训练数据的相机位姿分布决定了模型在哪些视角上可靠。若训练集以物体中心、固定仰角、均匀方位角为主，推理时给出一个俯视或近距离视角，模型的条件通路会落入分布外，生成质量骤降。具体表现是：俯视图的顶部纹理被拉长，或者近距离视图出现透视畸变。工程上的对策是显式约束推理视角落在训练分布内（例如固定 4 个正交方位角），代价是失去自由视角能力；这与「生成一圈一致视图」的初衷形成张力。

重建侧的代价同样具体。稀疏视图大重建模型（InstantMesh、CRM 路线）把 4–6 张图直接编码为三平面或体素特征，再解码网格。它对输入一致性极度敏感：若生成图之间存在轻微视角误差，编码器会把误差平均成模糊几何。CRM 用卷积重建模型提升吞吐，但卷积的局部感受野限制了跨视图全局对齐能力，长距离对应仍需注意力补足。Hi3DGen 用法线桥接把几何精度从颜色域解耦，代价是管线更长、误差源更多。

一个具体例子：在 4 视图、256 分辨率、单卡显存的设定下，多视图注意力的中间激活占用是单图扩散的数倍；若把视图增至 8 且分辨率提到 512，激活占用超出显存，必须引入梯度检查点或分块注意力，采样时间随之上升。这不是实现细节，而是决定「能不能在消费级硬件上跑通」的系统边界。工程判断因此变成：先固定视图数与分辨率，再在该预算内优化一致性与相机覆盖，而不是反过来。

五 · 从图像中间产物到联合训练：一致性约束的位置迁移

近年这个方向的结构性变化是：多视图扩散正从「生成 4–6 张图再交给重建器」转向「与重建网络联合训练」。InstantMesh 与 CRM 把稀疏视图直接喂给 LRM（大重建模型），Hi3DGen 用法线桥接几何。纯图像中间产物的重要性下降，但一致性约束仍是核心——它从「图像空间的显式约束」迁移为「重建损失反传的隐式约束」。

具体机制上，联合训练把重建器的渲染损失作为扩散采样的监督信号：给定生成的多视图 {x_i}，重建出 S，再用 S 在相同相机下渲染 {x̂_i}，比较 x_i 与 x̂_i 的差异并反传。这迫使生成器产出的图像不仅单张自然，而且能被重建器拟合。伪代码思路是：

  • 采样 N 个视角条件，运行多视图去噪得到 {x_i}；
  • 用稀疏视图重建器编码 {x_i} 得到三平面/体素特征，解码网格 S；
  • 在 {π_i} 下可微渲染 S 得到 {x̂_i}，计算重投影与感知损失；
  • 把损失对 {x_i} 的梯度回传至扩散采样过程（或作为微调阶段的监督）。

这条路径的收益是消除「生成好看但不可重建」的错配：图像空间的一致性不再靠人工设计的注意力稀疏化，而由重建可行性直接定义。代价是训练复杂度上升——需要可微渲染器、需要联合调度扩散与重建两个网络的优化节奏，且重建器的容量成为一致性上限。若重建器对某类几何（薄壳、镂空）拟合能力弱，反传信号会把生成器也拉向「重建器擅长」的平庸形状，造成模式坍缩。

失败模式具体表现为：联合训练后，生成的多视图在轮廓上高度一致，但纹理细节变平——因为重建损失对低频几何敏感、对高频纹理不敏感，梯度自然偏向几何对齐而牺牲纹理锐度。另一个例子是相机分布偏差被放大：联合训练时若重建器在训练相机集上过拟合，生成器会被推向该相机集，推理时换视角则一致性崩溃。这说明一致性约束的位置迁移并不消除原有边界，只是把边界从图像空间搬到了「生成器-重建器」的联合分布上。

工程判断因此落在具体机制上：是否联合训练取决于下游是否需要显式几何。若只需要可渲染的视图集合，纯多视图扩散加轻量一致性后处理足够；若要导出网格进入建模管线，则必须让重建损失参与优化，否则图像空间的微小不一致会在三角化时放大成可见缺陷。这条判断线，正是这个方向从「生成问题」走向「生成-重建耦合问题」的分界。
