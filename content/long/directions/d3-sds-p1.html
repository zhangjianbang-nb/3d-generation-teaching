一 · 任务定义：从「没有 3D 数据」这个约束反推方法形态

优化式蒸馏要回答的问题可以写得很窄：给定一个预训练的 2D 文生图扩散模型、一个可微的 3D 表示与渲染器，能否在不引入任何 3D 配对数据的前提下，优化出一致的三维资产，使其从任意视角渲染出的图像都落在扩散模型所刻画的条件分布上。这里的「蒸馏」不是把教师网络的权重压进学生网络，而是把 2D 模型隐式的图像先验当作一个只可查询、不可求导端到端的目标函数，通过采样其分数函数来为 3D 参数提供梯度。教师始终是冻结的，学生是 3D 表示本身，训练信号是渲染图在加噪后所收到的去噪方向。

这个定义里嵌了三个硬约束，它们共同决定了方法形态。第一，没有 3D 监督，因此损失不能写成「渲染图与真值图的距离」，只能写成「渲染图在 2D 先验下的似然」或其代理。第二，3D 表示必须可微渲染，否则梯度无法回传到几何与外观参数；这直接把体素网格、点云等不易微分的结构排除在主流之外，把 NeRF、DMTet、3DGS 推到台前。第三，2D 先验只在单张图上定义，而 3D 一致性要求多视角之间自洽，于是「如何把单图分数变成多视图一致的梯度」成为整个方向的技术核心，也是后面所有改进（VSD、ISM）的着力点。

把这三条放在一起看，就能理解为什么这条路线在 2022 年之前不存在：不是没人想到，而是缺一个足够强的 2D 先验。文生图扩散模型在图文对上训练后，其分数函数隐含了「什么样的图像看起来像这个文本」的判断，这种判断可以跨视角迁移，因为自然图像的多视角统计是共享的。DreamFusion 的贡献不在于发明了新的 3D 表示，而在于证明了这种迁移在工程上可行：一个冻结的 2D 模型加上一个可微渲染器，就足以把文本变成可用的三维资产。

二 · 目标函数：SDS 把「不可解似然」换成「可采样的分数」

形式化地，设 3D 参数为 θ，渲染器为 g，相机为 c，则渲染图为 x = g(θ, c)。理想目标是最大化该图在文本条件 y 下的对数似然，但扩散模型的似然本身不可解，只能通过噪声预测网络 ε_φ 近似其分数。SDS 的做法是对渲染图加噪得到 x_t = α_t x + σ_t ε，然后取噪声预测与真实噪声之差作为「去噪方向」，并乘以一个与噪声调度相关的系数，得到参数梯度：

$$\nabla_\theta \mathcal{L}_{\mathrm{SDS}} = \mathbb{E}_{t,\epsilon,c}\left[ w(t)\,\big(\epsilon_\phi(x_t; y, t) - \epsilon\big)\,\frac{\partial x}{\partial \theta} \right]$$

其中 w(t) 吸收 α_t、σ_t 与雅可比项的组合。这个式子的关键在于：它并不要求 ε_φ 对 x 可导，梯度只经过渲染器回传，教师网络只需前向一次。这正是「只可查询」约束下的自然解法——把教师当作一个给出方向的预言机，而不是一个可反传的模块。

但这个估计量是有偏的。U-Net 的噪声预测是在单张图上训练的，它给出的方向对应「让这张图更像文本描述」，并不保证不同相机下的方向彼此一致。当同一组 θ 在不同视角被反复拉扯时，几何会向「每个视角都局部合理、整体不自洽」的解漂移，这就是多面（Janus）问题的根源。同时，CFG 尺度被放大后，去噪方向被推向条件分布的极端尾部，表现为颜色过饱和与纹理在高频处粘连。这两类失败不是调参能消除的，而是估计量本身的结构性缺陷。

系统代价同样来自这个结构：每个优化步要跑一次渲染加一次（或多次）U-Net 前向，而收敛通常需要数千到上万步，于是单资产耗时落在数十分钟量级。渲染分辨率越高、视角采样越密，代价越线性增长；这也是 Magic3D 采用由粗到细两阶段、DreamGaussian 转向 3DGS 的直接动机——不是换目标函数，而是换一个前向更便宜的表示。

三 · 边界：它能做什么，以及它在哪些维度上先天不足

这条路线的能力边界由「2D 先验覆盖什么」决定。文本描述中能被自然图像统计充分表达的部分——整体轮廓、材质观感、风格、配色——蒸馏效果稳定；而需要跨视角精确约束的部分——拓扑正确性、薄结构、封闭性、部件之间的刚性关系——缺乏来自 2D 先验的直接信号，只能靠多视角采样间接约束，因而脆弱。一个具体例子是带细长附件的物体：从某些视角看附件被主体遮挡，渲染图仍然「像」，梯度不会惩罚几何上的错误连接，最终网格常出现粘连或断裂。

与替代方向相比，这条路线的位置很清楚。前馈生成模型（在 3D 数据或大规模合成数据上训练的网络）在速度与视角一致性上占优，但它依赖 3D 监督或精心构造的数据管线，且对训练分布外的文本组合泛化有限；优化式蒸馏不需要任何 3D 数据，因而在长尾描述、风格化、单资产精修上仍不可替代。程序化建模与 CAD 路线能保证拓扑与物理正确，但无法从自由文本直接生成观感丰富的资产。换句话说，SDS 类方法填补的是「无 3D 数据、要自由文本、可接受数十分钟离线优化」这个象限，一旦任务落在这个象限之外，它的劣势就会立刻显现。

需要强调的是，「无 3D 数据」不是免费的。它把数据成本换成了优化成本：每个资产都要重新跑一遍随机优化，结果依赖随机种子与超参，可复现性弱于前馈推理。工程上这意味着它适合离线、单件、高价值的场景，而不适合批量交付。

四 · 为什么其他方向替代不了：三个不可让渡的性质

第一个性质是数据无关性。前馈模型的能力上限被其训练集的覆盖度锁死，遇到训练集中罕见的文本组合时，网络只能插值到最近的已知形态。优化式蒸馏则把泛化责任交给 2D 先验，而 2D 先验在图文对上见过远多于任何 3D 数据集的视觉概念，因此对「没见过的物体组合」有更强的外推能力。这不是定量优势，而是定性差异：前者是分布内插值，后者是跨模态迁移。

第二个性质是表示无关性。SDS 只要求渲染器可微，不要求 3D 表示是某种特定格式。同一套目标函数可以驱动 NeRF、DMTet 网格、3DGS，也可以在优化过程中切换表示——Magic3D 先用粗 NeRF 定大局，再用 DMTet 提分辨率；DreamGaussian 直接把表示换成 3DGS 以换取速度。这种「目标函数与表示解耦」的结构，使它能作为下游工具嵌入不同管线，而前馈模型一旦训练完成，输出格式与分辨率就被固定。

第三个性质是可组合的目标。因为优化是在参数空间里做的，除蒸馏损失外可以叠加任意可微正则：物理上的重力与碰撞、制造上的壁厚约束、风格上的一致性项。前馈模型要把这些约束编进训练数据或条件编码，代价高且不灵活。这也是 2024 年后 SDS 不再是主流交付路线、却仍是单资产精修与物理属性优化常用工具的原因——它退化成了一个可编程的优化器，而不是一个端到端产品。

代价是这三条性质都以时间为代价。数据无关意味着每个资产都要从零优化；表示无关意味着没有共享的推理缓存；可组合目标意味着超参空间随约束数量增长，CFG 尺度、噪声调度区间、正则权重之间相互耦合，调参本身成为工程负担。一个具体的失败模式是：为了压制过饱和而降低 CFG 尺度，结果去噪方向变弱、几何细节不足；提高尺度又回到过饱和。这个矛盾在 SDS 框架内没有干净的解，只能靠方差缩减类方法（VSD、ISM）从估计量层面缓解，而不是从超参层面调和。

五 · 问题的真正难点：单图分数到多视图一致的映射

把整个方向的问题浓缩成一句：如何构造一个估计量，使它的期望梯度指向「多视图一致且符合文本」的 3D 解，而不是「每个视图各自合理」的解。SDS 用的是单图噪声预测之差，其偏差来源已在第二节说明。VSD 的思路是引入一个可学习的多视图分布作为学生，用粒子近似其分数，再把教师分数与学生分数之差作为梯度，本质是把「单图先验」替换成「在多个视角上联合定义的先验」，从而在估计量层面压低方差。ISM 则从另一个角度切入，用间隔分数匹配把去噪轨迹的中间状态纳入监督，减少单步估计的随机性。

这些改进共享一个结构：它们都不改变「教师冻结、渲染可微」的基本框架，只在梯度的构造上做文章。这说明该方向的边界不在表示、不在渲染，而在估计量的统计性质。伪代码层面可以概括为：采样相机与噪声层级，渲染，加噪，查询教师（可能多次），构造方向，回传，更新 θ。所有变体都是在这条流水线上替换「构造方向」那一步。

由此可以给出一个工程判断：评估一个 SDS 变体，不应只看最终渲染的观感，而应看它在多视角下的自洽程度与在 CFG 尺度扫描下的稳定性。前者暴露估计量的偏差，后者暴露其对条件分布尾部的敏感度。一个在单视角渲染上很漂亮、但换视角就出现多面或纹理漂移的结果，说明方差缩减没有到位；一个只在极窄的 CFG 区间内可用的方法，说明它没有真正解决过饱和的结构性成因。

最后落到机制上：这个方向的全部技术张力，集中在「冻结的 2D 教师只提供单图条件分数」与「3D 一致性要求多视图联合约束」之间的缺口。SDS 用最简单的估计量填补它，代价是偏差与高方差；VSD 与 ISM 用更贵的估计量缩小缺口，代价是每次迭代要跑更多次教师前向或维护额外网络。缺口本身无法消除，因为 2D 教师从未见过三维一致性这个约束——它只是被借用来提供视觉合理性。理解这一点，就理解了这个方向为什么在速度上永远输给前馈模型，又为什么在数据无关与可组合性上无法被后者取代。
