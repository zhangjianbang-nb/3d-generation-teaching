一 · 问题的硬约束：单次前向必须同时兑现几何、外观与可渲染性

这个方向的核心命题可以写成一句很窄的话：给定一张图或一段文本，网络在一次前向中直接输出一个带纹理、带材质、可被渲染器直接消费的 3D 资产。窄的地方在于「一次前向」这四个字，它把问题从「生成什么」变成了「在固定计算预算下同时兑现哪些属性」。一个可渲染资产至少包含三层信息：几何（网格顶点、面片、拓扑）、表面外观（纹理、基础色、粗糙度、金属度等 PBR 通道）、以及空间一致性（同一物体从任意视角看都自洽）。前馈模型必须在没有逐资产优化的条件下，把这三层一次性回归出来。

形式化地，设输入为图像 I 或文本 T，网络 fθ 的输出是一个结构化表示 S，再由确定性解码器 D 转成可渲染资产 A：

$$A = D\big(f_\theta(I)\big),\qquad S = f_\theta(I)$$

关键约束是 fθ 只跑一次，D 必须是可微或至少是确定性的、不依赖每资产迭代的转换。这与 SDS（Score Distillation Sampling）路线形成结构性对立：SDS 把 2D 扩散先验当作损失，对每个资产做几十分钟的梯度优化，本质是「每资产一次搜索」。前馈路线把搜索挪到训练阶段，用大规模 3D 监督数据把「如何从单图推断三维」压缩进权重里，推理时只剩一次回归。LRM 的意义正在于此：它证明了「大模型 + 3D 监督数据」可以一次前向输出 triplane，TripoSR 把这条路径压到 0.5 秒量级，从而把 3D 生成从「离线工艺」变成「在线服务」。

代价也随之固定下来。单次前向意味着网络没有机会在推理时纠正自己的错误：背面看不见的部分只能靠先验补，薄结构（叶片、线缆、衣褶）只能靠分辨率硬扛，拓扑错误一旦输出就无法回退。这就是为什么后续工作不得不在表示层做文章——triplane 的分辨率上限直接决定薄结构能否存活，高斯泼溅输出头绕开拓扑但引入渲染管线的耦合，SLAT 这类结构化潜变量则试图在潜空间里保留可编辑的分块结构。换句话说，前馈不是「更快的 SDS」，而是把误差来源从「优化不收敛」换成了「先验覆盖不足 + 表示容量不够」，这是一次误差类型的整体迁移。

二 · 边界在哪：前馈能承诺什么，不能承诺什么

把边界画清楚，需要区分三类承诺。第一类是「单物体、以物体为中心」的资产级生成：输入一张抠好的物体图，输出一个可渲染的物体资产。这是 LRM、TripoSR、GS-LRM、MeshLRM、LGM、Hunyuan3D 2.x、Step1X-3D 共同覆盖的区间，也是当前主战场。第二类是「多视图一致性」：输入稀疏视图（几张不同角度的图），输出一个自洽的三维表示，这属于稀疏视图重建的范畴，GS-LRM、MeshLRM 都在这个设定下工作。第三类是「场景级、开放世界」生成：输入一段文本描述一个房间或街区，输出可漫游的场景。第三类目前不是前馈单次前向能兑现的，原因不是模型不够大，而是监督数据的组织方式与表示的容量都不支持——场景的几何复杂度、遮挡关系、材质多样性远超单物体分布，且缺少可规模化、版权清晰的场景级 3D 监督。

边界还体现在「可控性」上。前馈模型的可控性来自条件注入的位置与粒度：文本条件通常注入到 cross-attention 或潜变量的调制层，图像条件注入到编码器特征，而几何级控制（比如指定某处必须是一个平面、某处必须挖空）需要额外的控制分支或后处理精修。Step1X-3D 强调可控生成，CraftsMan3D 用几何精修补拓扑，恰恰说明「一次前向」在精细控制上是弱的：网络输出的是一个分布意义上的合理资产，不是满足硬约束的资产。硬约束只能靠外挂的精修器或交互式 refiner 兑现，而这一步又回到了迭代，破坏了「单次前向」的纯粹性。

还有一个常被忽略的边界：光照解耦。PBR 材质要求基础色、粗糙度、金属度与光照分离，但单张输入图里的像素是「材质 × 光照」的乘积，网络必须隐式地做一次逆渲染。这是一个病态问题：同一张图可以由无数种材质-光照组合解释。前馈模型只能靠数据先验选一个「最像训练分布」的解，因此在训练分布外的光照条件（强逆光、彩色环境光）下，材质估计会系统性偏移。这不是模型容量问题，是信息论层面的欠定问题，只能靠多视图输入或额外先验缓解。

用一张表把承诺与边界对齐：

能力维度前馈单次前向可承诺结构性不可承诺
几何单物体整体形状、主要部件薄结构完整拓扑、精确硬约束
外观纹理、PBR 通道的合理估计训练分布外光照下的精确解耦
一致性稀疏视图下的自洽表示场景级遮挡与开放世界漫游
可控性文本/图像条件的粗粒度控制几何级硬约束的一次性满足

这张表的意义在于：它解释了为什么这个方向的工作重心不在「把模型再放大一倍」，而在表示层（SLAT、高斯泼溅、mesh 输出头）与数据引擎（3D 监督数据的规模与版权）。边界不是靠 scaling 推过去的，是靠换表示、换监督、换解码器一点点挪过去的。

三 · 为什么其他方向替代不了：三条替代路线的结构性缺陷

要论证「替代不了」，必须逐个检查替代路线在最关键的那一项上是否成立。第一替代路线是 SDS / 逐资产优化。它的优势是无需 3D 监督数据，只用 2D 扩散先验；缺陷是每资产几十分钟的优化时间，无法规模化。这不是工程优化能解决的问题：SDS 的每一步都要反向传播穿过一个 2D 扩散模型，计算量与资产复杂度成正比，且优化过程本身不稳定（过饱和、多面体伪影）。把它放进一个需要每秒处理大量请求的生产管线，成本结构直接崩塌。前馈路线把这份计算挪到训练阶段一次性摊销，这是替代不了的根本原因。

第二替代路线是纯 2D 多视图生成 + 三角化。先用多视图扩散生成若干视角，再做深度估计与三角化融合。缺陷在于多视图之间的一致性没有硬保证：扩散模型各视图独立采样，融合时会出现几何冲突，需要额外的对齐与修补。更致命的是，三角化只能恢复可见表面，背面与遮挡区域仍然缺失，且融合出的网格拓扑质量差。前馈模型（如 GS-LRM、MeshLRM）把多视图一致性作为训练目标的一部分，输出的是原生三维表示而非「先 2D 再拼」，这是结构性的差异，不是精度上的差异。

第三替代路线是程序化 / CAD 建模。它可控、拓扑干净、可编辑，但依赖人工或规则，无法从一张图直接泛化到开放类别。程序化路线在特定品类（家具、机械件）上精度极高，但覆盖面窄，且不解决「从任意图片生成」的问题。前馈模型覆盖开放类别，代价是拓扑质量与可控性弱，两者是互补而非替代关系——CraftsMan3D 的「前馈生成 + 几何精修」正是这种互补的工程化表达。

三条路线各自缺一项：SDS 缺速度，2D 多视图缺一致性，程序化缺泛化。前馈路线是唯一同时具备「速度、一致性、开放类别泛化」三项的路线，代价是监督数据与表示容量。这就是为什么它是当前 3D 生成的主战场，而不是一个可被绕过的中间态。

四 · 表示层决定边界：triplane、高斯、SLAT 各自把问题推到哪

前馈模型的边界很大程度上由输出表示决定，而不是由骨干网络决定。triplane 表示把三维场分解为三个正交平面特征图，查询时做三线性插值后拼接。它的优点是紧凑、与 Transformer 的 token 序列天然对齐（LRM、TripoSR 都用 Triplane Transformer），解码成网格时用 marching cubes 或神经 SDF。它的硬上限是平面分辨率：分辨率 R 下，可表达的最小特征尺度约为 1/R，薄结构一旦细于这个尺度就在采样中丢失。这是 TripoSR 类模型在细长物体上失败的直接机制，不是训练不足。

$$\text{有效细节尺度} \sim \frac{1}{R},\qquad \text{显存} \propto 3 R^2 C$$

高斯泼溅输出头换了一条路：不回归隐式场，直接回归一组各向异性高斯的中心、协方差、颜色与不透明度。GS-LRM、LGM 走这条路线，优势是渲染快、显式、无需 marching cubes，且高分辨率下细节保留更好。代价是拓扑：高斯集合不是网格，转成网格需要额外的表面重建步骤，且高斯的协方差回归对薄结构与背面极不稳定——一个高斯可以跨越物体两侧，造成「漂浮」伪影。显存代价也随高斯数量线性增长，高分辨率意味着高斯数量暴涨，推理显存成为硬瓶颈。

SLAT（结构化 3D 潜变量）是第三条路：把三维空间划分为稀疏的体素块，每个被占据的块携带一个局部潜变量，未被占据的块不分配计算。TRELLIS 用 SLAT 统一表示，好处是计算随表面面积而非体积增长，且块结构天然支持局部编辑与生成。代价是块划分的粒度：块太大则细节丢失，块太小则序列变长、Transformer 的注意力成本上升。SLAT 把「分辨率 vs 计算」的权衡从稠密网格转移到了稀疏块，但没有消除这个权衡，只是把它挪到了一个更可控的位置。

三种表示对应三种失败模式：triplane 失败于薄结构，高斯失败于拓扑与漂浮，SLAT 失败于块粒度与长序列的注意力成本。这说明前馈路线的边界不是单一的，而是随表示选择而移动的——换表示就是换边界，这也是 2024–2025 年主线工作集中在表示层而非单纯 scaling 的原因。

五 · 数据与监督：规模、版权与「背面从哪来」

前馈模型的监督信号必须覆盖「单图看不到的那部分」。训练时，网络见到的是（输入图，完整 3D 资产）配对，损失同时约束可见面与不可见面。这意味着 3D 监督数据的规模直接决定背面先验的质量：如果训练集里绝大多数资产是正面扫描、背面缺失，网络学到的背面就是「平滑外推」，薄结构与内部结构一律抹平。这是背面细节失败的数据侧根因，不是网络侧根因。

数据规模与版权是一对耦合约束。可规模化获取的 3D 资产来源包括合成资产库、扫描重建、以及从视频/多视图重建出的资产。合成资产拓扑干净但分布窄；扫描资产真实但噪声大、背面常缺失；重建资产覆盖广但几何质量参差。三者混合是工业级管线（Hunyuan3D 2.x、Step1X-3D）的常见做法，但混合比例与清洗策略直接决定模型在不同品类上的偏置。版权问题则限制了可直接使用的资产库范围，使得「更大数据引擎」不是单纯的抓取问题，而是授权与清洗的工程问题。

监督的另一个维度是材质。PBR 材质需要（基础色、粗糙度、金属度）与光照解耦的 ground truth，而这类标注比几何标注更稀缺：扫描能拿到几何，但材质通道往往要靠逆渲染估计，估计本身带误差，误差又被当作监督信号喂给模型。这是一个误差放大的闭环。工程上的缓解手段是分离形状与材质的生成路径——Hunyuan3D 2.0/2.1 把形状与材质分成两个 DiT，让几何监督与材质监督各自独立，避免材质估计误差污染几何先验。这是「分而治之」在监督层的体现，代价是两阶段之间的对齐误差。

用伪代码概括一次训练样本的构造思路：

$$\text{sample} = (I_{\text{cond}},\ A_{\text{geo}},\ A_{\text{mat}}),\quad \mathcal{L} = \lambda_g \mathcal{L}_{\text{geo}} + \lambda_m \mathcal{L}_{\text{mat}} + \lambda_r \mathcal{L}_{\text{render}}$$

其中 Lrender 用可微渲染把预测资产渲染回输入视角与若干随机视角，约束外观一致性；Lgeo 约束几何（SDF、高斯参数或块潜变量）；Lmat 约束 PBR 通道。三项的权重平衡决定了模型偏向「几何准」还是「渲染像」，这是一个没有普适最优的工程判断，只能按下游用途调。

六 · 推理侧的系统代价：显存、分辨率与吞吐的三角约束

前馈路线的卖点是速度，但速度不是免费的。推理侧存在一个三角约束：高分辨率、低显存、高吞吐三者不能同时满足。分辨率提高意味着 token 数或高斯数增加，注意力的计算与显存随序列长度超线性增长；显存受限则必须降分辨率或分块推理；分块推理又引入块间不一致，需要重叠与融合，吞吐下降。这个三角约束是工业级管线（Hunyuan3D 2.x 的高分辨率网格、TRELLIS 的 SLAT 长序列）必须正面处理的系统问题。

$$\text{Mem} \approx \alpha L^2 + \beta L C,\qquad L \propto R^2\ \text{(triplane)}\ \text{或}\ L \propto N_{\text{voxel}}\ \text{(SLAT)}$$

其中 L 是序列长度，αL2 是注意力项，βLC 是特征存储项。triplane 下 L 随分辨率平方增长，SLAT 下随被占据体素数增长。这解释了为什么 SLAT 在高分辨率下更划算：它把计算集中到表面附近，而不是均匀铺满整个体积。但 SLAT 的稀疏结构对 GPU 不友好，稀疏索引与 gather/scatter 带来额外的内核启动与内存带宽开销，实际吞吐未必线性优于稠密 triplane——这是一个必须用实测决定的工程判断，不能靠复杂度分析拍板。

另一个系统代价是解码器。triplane 解码成网格需要 marching cubes，其成本随分辨率立方增长，且在高分辨率下产生大量三角形，后处理（简化、去噪、补洞）成为瓶颈。高斯输出头绕开 marching cubes，但转网格仍需表面重建。MeshLRM 直接回归高质量网格，把解码成本前移到网络内部，代价是网格输出的拓扑回归更难训练。这三条路径的系统代价分布不同，选型取决于下游是渲染优先还是编辑优先。

具体例子：一个在线 3D 资产服务，若单请求预算为秒级、显存为单卡上限，则 triplane 路线必须在分辨率与批大小之间做取舍，高斯路线必须限制高斯数量上限，SLAT 路线必须限制块粒度与序列长度。三者都不是「调大模型」能解决的，而是表示与解码器的联合设计问题。这正是本方向第 1/4 部分要划定的问题全景：前馈 3D 原生大模型要解决的是「在单次前向的固定预算内，用可规模化监督数据把三维先验压进权重，并用合适的表示把这份先验兑现成可渲染资产」；它的边界由表示容量、监督覆盖与推理预算三者共同决定；其他方向替代不了它，是因为它们在速度、一致性、泛化三项中至少缺一项。工程判断落在表示选型与预算分配上，而不是模型参数量的竞赛上。
