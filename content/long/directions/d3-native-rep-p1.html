一 · 问题的定义：生成器的输出空间究竟落在哪

「原生 3D 生成表示」这个方向的核心命题只有一句：能否不经过 2D 图像中介，直接在 triplane、SDF、点云或隐式函数等 3D 表示空间里采样生成物体？要理解这句话的分量，必须先把「输出空间」这个概念拆开。任何生成模型都可以写成从一个先验分布到目标分布的映射，目标分布支撑在什么样的空间上，决定了模型必须内化什么样的结构约束。当目标空间是 2D 像素网格时，模型只需要学会局部纹理统计与全局布局；当目标空间是三维隐式场时，模型必须同时学会占据性、表面连续性、视角一致性以及拓扑合法性。这不是难度上的线性叠加，而是约束类型的变化。

形式化地，设生成器 G 把潜变量 z ~ p(z) 映射到某个表示空间 X 中的元素。若 X 是图像集合，则判别器或损失只需在像素域上定义；若 X 是带符号距离场 f: R^3 → R，则 G(z) 本身就是一个连续函数，采样过程等价于在这个函数空间上做分布建模。原生 3D 路线的实质，是把「三维」从监督信号的位置挪到输出变量的位置。前者是 2D 监督下的间接约束，后者是表示层面的直接构造。

$$G_\theta: z \mapsto \mathcal{X},\quad \mathcal{X} \in \{\text{triplane},\ \text{SDF},\ \text{point cloud},\ \text{implicit function}\}$$

这个定义立刻划出了方向的边界。它不解决「如何从文本得到语义」的问题，也不解决「如何渲染得好看」的问题；它只回答一件事：生成器吐出的对象本身是不是三维的。Efficient Geometry-aware 3D Generative Adversarial Networks 把 triplane 作为输出表示，GET3D 把带纹理的显式网格作为输出，Point-E 把点云作为输出，Shap-E 把隐式函数参数化作为输出——四条路线的共同点不是网络结构，而是输出变量的三维属性。反过来，任何以多视图图像为唯一监督、最终仍需渲染出 2D 结果来评估的方案，即便内部有三维推理，也不属于这个方向的原生范畴。

边界之外还有一层容易被忽略的约束：原生表示必须可被下游消费。一个 SDF 若无法被稳定地提取成网格，它在工程上就是半成品；一个 triplane 若无法被高效解码成密度与颜色，它就只是潜变量的别名。DMTet 之所以成为关键组件，正是因为它把「可微的隐式表示」与「可提取的显式网格」接了起来，使原生生成器的输出能进入渲染、仿真与资产管线。因此这个方向的完整问题陈述应包含三段：采样发生在 3D 表示空间、表示本身携带几何与外观、表示可被确定性地转换为下游可用资产。

二 · 为什么 2D 中介替代不了：一致性的来源不同

以 2D 渲染为中介的生成路线，其三维一致性只能靠多视图约束间接获得。典型做法是：生成器输出一个中间结构，渲染器把它投影到若干视角，判别器或重建损失在这些视角上比对。这里的「一致性」是一个被优化的结果，而不是表示的内禀属性。只要视角采样不足、遮挡关系覆盖不全、或者判别器对某类视角偏差不敏感，不一致就会以几何错误的形式残留下来。多视图约束本质上是把一个三维问题降维成若干个二维问题的交集，交集之外的区域没有任何约束。

原生 3D 表示把三维放进输出空间之后，一致性的来源改变了。以 SDF 为例，零水平集 {x : f(x)=0} 是一个全局定义的对象，任意视角的渲染都只是对这个同一对象的采样。视角之间不共享任何可调参数，因此不存在「两个视角各自合理但拼起来矛盾」的自由度。triplane 的情况稍微妙：它把三维坐标投影到三个正交平面并做特征插值，一致性由投影几何本身保证，但平面分辨率与特征通道数决定了表达上限。点云则把一致性退化为「点集是否覆盖同一表面」，其难点从视角一致性转移到了密度均匀性与离群点控制。

$$\mathcal{L}_{\text{multi-view}}=\sum_{v}\big\|\,\mathcal{R}_v(G(z))-I_v\,\big\|^2 \quad\text{vs.}\quad \mathcal{L}_{\text{native}}=\mathcal{D}\big(G(z),\,\mathcal{X}_{\text{ref}}\big)$$

上式的对比说明了两类损失的监督对象不同：左侧监督的是渲染结果，右侧监督的是表示本身。左侧的梯度必须穿过渲染器才能到达生成器，渲染器的可微性、采样噪声与遮挡梯度都会污染信号；右侧的梯度直接作用在表示参数上，路径更短，但也要求参考表示本身可得——这正好引出该方向最硬的约束，即 3D 训练数据的稀缺。没有原生 3D 监督时，原生生成器只能靠可微渲染反传，此时它和 2D 中介路线的差距就被压缩了，这也是纯 GAN 路线后来被吸收的根本原因之一。

一个具体例子可以说明替代不了的地方：当目标物体包含薄壁结构或自遮挡凹腔时，多视图监督在有限视角下几乎必然漏掉背面与内腔，生成结果在这些区域呈现为壳体粘连或空洞。原生 SDF 表示虽然同样缺乏这些区域的直接监督，但其全局连续性先验会把零水平集约束成闭合曲面，错误表现为平滑的拓扑合并而非破碎的薄片。两种失败模式不同，工程上的修复成本也不同：前者需要补视角，后者需要改拓扑正则。这正是「原生」二字在失败模式层面的实际含义。

三 · 四条表示路线的分工与各自的系统代价

triplane 把三维函数分解为三个二维特征平面，查询点 (x,y,z) 的特征由三个平面上双线性插值的结果聚合而成。其机制优势是内存从三维体素的三次方降为三个平面的二次方，使高分辨率解码成为可能；代价是平面投影丢失了沿轴方向的高频变化，对细长结构和锐利边缘的表达受限。Efficient Geometry-aware 3D Generative Adversarial Networks 用 triplane 配合轻量解码器实现了高分辨率几何感知生成，这一表示后来成为 LRM 类前馈模型的标准中间表示，原因正在于它在表达力与显存之间的平衡点足够靠前。

$$\mathbf{f}(x,y,z)=\mathrm{Agg}\big(\phi_{xy}(x,y),\ \phi_{yz}(y,z),\ \phi_{zx}(z,x)\big)$$

DMTet 走的是另一条路：它维护一个可微的四面体网格，每个顶点携带 SDF 值与形变偏移，通过可微的网格提取把隐式场转成显式三角网格。其机制价值在于把「拓扑」变成可优化的对象——顶点符号决定表面穿越哪些四面体，因此拓扑可以在训练中改变，而不是被固定体素网格锁死。代价是提取过程涉及四面体遍历与顶点合并，显存与时间开销随分辨率上升而显著增长，且提取出的网格质量依赖四面体剖分的规则性。GET3D 用 DMTet 产出带纹理的高质量网格，正是看中它在拓扑灵活性与可微性之间的折中。

点云扩散把生成对象定义为无序点集，扩散过程在点坐标上定义噪声与去噪。机制上它绕开了网格拓扑与隐式场的连续性约束，采样速度快、实现简单，Point-E 即以点云作为复杂提示下的快速三维输出。代价同样明确：点云没有表面定义，无法直接给出法线与封闭性，从点云到可用网格需要额外的重建步骤，且点集的无序性使损失设计必须对称化。工程上它退居为快速预览方案，正是因为「预览」这一场景对拓扑合法性的要求最低。

隐式函数 Transformer 把场景或物体参数化为一个由 Transformer 解码的连续函数，查询任意坐标即得密度或 SDF。Shap-E 以隐式函数作为条件生成的目标，其机制优势是输出分辨率与查询分辨率解耦——函数本身不绑定网格，可以在任意精度上采样。代价是训练时必须依赖可微渲染或采样的近似，且隐式函数的潜空间与显式资产之间存在转换损耗。四条路线的共同系统代价可以归到一张表里：

表示一致性来源主要系统代价典型失败模式
triplane正交投影几何平面分辨率与通道数的显存开销轴向高频细节丢失、薄结构模糊
SDF + DMTet零水平集全局定义四面体提取的时间与显存拓扑合并、提取网格的非流形边
点云点集覆盖同一表面无序性带来的对称损失设计密度不均、离群点、无封闭表面

这张表的意义不在于比较优劣，而在于说明「原生」不是一个单一技术，而是一组在一致性来源与系统代价之间做出不同取舍的表示选择。选 triplane 意味着接受投影带来的表达上限以换取显存；选 DMTet 意味着接受提取开销以换取拓扑自由；选点云意味着放弃表面定义以换取速度。工程判断发生在取舍点上，而不是在路线名称上。

四 · 固定拓扑与可编辑性：原生表示的结构性欠账

原生 3D 表示最常被低估的代价是固定拓扑对可编辑性的限制。以体素或固定分辨率的 triplane 为例，生成器输出的对象在拓扑上是预先确定的：体素网格的连通性、平面的采样格点都不随物体变化。这意味着生成结果无法在不重建的情况下插入孔洞、分离部件或改变部件数量。DMTet 通过可微提取缓解了这一点，但缓解的程度受限于四面体剖分的初始分辨率——粗剖分下细小部件无法被表示，细剖分下显存迅速吃紧。可编辑性因此不是后处理问题，而是表示分辨率与拓扑自由度之间的直接权衡。

这一欠账在工程上表现为资产管线的摩擦。下游的绑定、仿真与布尔运算要求网格是流形的、部件可分离的；而原生生成器输出的往往是单一连通曲面，部件边界只存在于纹理或语义上，不存在于拓扑上。要获得可编辑性，通常需要额外的分割与重网格步骤，这些步骤本身不保证与生成结果一致。材质与光照解耦是同一类欠账的另一面：原生表示若把反照率与光照烘进颜色通道，重光照就需要重新估计，而解耦要求表示中显式区分材质参数与光照条件，这又反过来增加了监督的维度。

$$\text{Editability}\ \propto\ \frac{\text{topological degrees of freedom}}{\text{extraction cost}},\qquad \text{Decoupling}=\text{separate}(\text{albedo},\text{lighting})$$

一个具体机制可以说明这种欠账如何传导：当生成器以固定拓扑的网格模板输出时，形变场只能移动顶点而不能改变连接关系，因此两个本应分离的部件在模板中共享边，生成结果必然呈现为粘连。修复方式要么是提高模板分辨率使粘连变细，要么是引入拓扑改变操作——前者增加显存，后者增加实现复杂度。高分辨率下的内存开销与固定拓扑限制可编辑性，在这里是同一个约束的两端，而不是两个独立的问题。

五 · 数据稀缺如何塑造了这个方向的形态

3D 训练数据稀缺是原生路线无法回避的起点。可用的原生 3D 资产在规模与多样性上远不及图像数据，且标注质量参差：网格的流形性、材质通道的完整性、尺度归一化的一致性都需要额外清洗。这直接决定了原生生成器的训练形态——纯监督的原生生成难以规模化，于是可微渲染成为主要通道，2D 图像重新进入训练回路。此时「原生」只体现在输出表示上，监督仍然来自 2D，这正是该方向与 2D 中介路线边界模糊的地带。

数据稀缺还塑造了表示的选型。点云与隐式函数对数据格式的要求较低，可以从深度图、多视图重建或合成管线中获取监督；triplane 与 DMTet 则更依赖成对的几何监督或高质量可微渲染。Efficient Geometry-aware 3D Generative Adversarial Networks 与 GET3D 都选择在图像监督下训练原生表示，说明该方向在数据约束下的现实路径是「原生输出 + 非原生监督」。这一组合的代价是梯度路径变长，渲染器的近似误差会以几何偏差的形式沉淀在表示中。

从系统角度看，数据稀缺带来的失败模式是过拟合于视角分布而非几何分布。当训练视角集中在某一半球时，生成器会把未见区域的几何外推为训练集的平均形状，表现为背面平坦化或内腔消失。原生表示在这里并不能自动修复问题，它只是把错误从「视角间不一致」转换为「全局形状偏差」。要判断一个原生生成器是否真的在三维空间上泛化，必须检查其在未见视角与未见拓扑上的行为，而不能只看渲染图的视觉质量。

近年纯 GAN 与点云路线在 2023 年后基本被前馈重建大模型吸收，这一事实本身就是数据约束的产物：前馈重建模型可以从大规模图像中学习三维先验，再把 triplane 作为标准中间表示、DMTet 作为标准网格化后处理，点云扩散退居快速预览。原生表示的组件没有消失，而是被重新安置到更大的管线中——triplane 成为潜变量载体，DMTet 成为确定性出口，点云成为低延迟预览。这个安置方式说明，原生 3D 生成表示要解决的问题从来不是「取代 2D」，而是在输出空间上为三维一致性提供一个不依赖视角采样的锚点；当监督仍然稀缺时，这个锚点的价值体现在失败模式的可控性上，而不是体现在指标上。
