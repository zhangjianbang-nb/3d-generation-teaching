一 · 从单视图条件化到多视图联合建模：Zero-1-to-3 的接口遗产

Zero-1-to-3 在这条谱系里的位置，不是"第一个多视图扩散模型"，而是"把视角控制显式参数化"的那一步。它沿用单图条件扩散的骨架，把输入图像与相对相机变换（方位角、仰角）一起作为条件，输出指定视角下的图像。关键在于：它并没有要求模型一次生成一圈视图，而是把"新视角合成"变成可复用的条件生成算子——给定同一张输入图，改变相机参数就能采样出不同视角。这个接口设计后来被反复继承，因为它把几何控制从隐式的图像先验里剥离出来，变成可枚举、可批处理的输入变量。

机制上，条件注入通常走两条路：一条是把相机参数编码成嵌入向量，与图像 token 拼接或做调制；另一条是把目标视角的相机射线/极线几何编码进注意力。Zero-1-to-3 属于前者，代价是相机参数与图像内容在同一个条件流里竞争容量，视角精度受嵌入表达力限制。伪代码层面可以写成：给定输入图 I 与相对位姿 ΔT，采样 x ~ p(x | I, ΔT)，对多个 ΔT 独立采样即得到多视图集合。这种"独立采样"是它最重要的失败模式来源：每个视角各自条件于同一张输入图，视角之间没有显式耦合，背面与侧面的内容可以各自"合理"却互相矛盾。

系统代价体现在两处。其一是采样成本随视图数线性增长，生成 4 个视角就是 4 次完整去噪；其二是几何一致性没有保证，后续重建网络必须容忍这些矛盾。工程上这决定了它的定位：Zero-1-to-3 更像"视角条件生成器"和"训练数据放大器"，而不是端到端重建方案。它提供的真正遗产是那个条件接口——后来的多视图模型几乎都保留"输入图 + 相机"这一对条件，只是把独立采样换成了联合去噪。

二 · MVDream：把多视图自注意力变成一致性机制

MVDream 的改进点非常具体：不再让每个视角独立去噪，而是在去噪网络内部让不同视角的 token 互相看见。做法是把同一场景的多个视角图像在 token 维度拼接，然后在注意力层里做跨视图的全局自注意力，同时保留每个视图内部的自注意力。这样，视角间的一致性不是靠损失函数事后惩罚，而是靠注意力在每一步去噪中即时交换信息。用公式描述，若第 l 层输入为按视图分块的 token 序列 [z^{(1)}, …, z^{(V)}]，则注意力计算的是跨所有块的联合 softmax，而不是逐块独立 softmax。

这个机制的代价是显存与计算量随视图数呈二次增长：注意力矩阵规模是 (V·N)^2，其中 N 是每视图 token 数。视图数从 4 增到 8，注意力开销约翻四倍，这是它难以直接扩展到稠密环绕视图的原因。另一个失败模式是"一致性过强导致多样性塌缩"：跨视图注意力会让模型倾向于生成彼此相似、保守的内容，背面细节被平均化。工程判断是：MVDream 适合固定少量视角（典型是 4 视图的正交或环绕布局），把一致性压到可接受水平，再把剩余矛盾交给重建阶段。

与 Zero-1-to-3 的关系是替代而非修补：条件接口保留，采样结构被替换。它把"多视图一致性"从后处理问题变成生成时的内生约束，这是整条路线的一次结构性断裂。具体例子：给定一张正面人物图，Zero-1-to-3 分别采样背面和侧面时可能给出两套不同的发型轮廓；MVDream 在同一去噪轨迹里让背面 token attend 到正面 token，轮廓在早期去噪步就被拉齐。

三 · SyncDreamer：用 3D-aware 注意力替代全连接跨视图注意力

SyncDreamer 要解决的是 MVDream 留下的扩展性问题：全连接跨视图注意力在视图数增多时不可承受，而"一圈一致视图"恰恰需要更多视角。它的做法是引入 3D-aware 的极线/体积式注意力——不是让所有视图 token 两两互看，而是借助相机参数把 token 映射到一个共享的 3D 表示（如体积网格或极线采样），在 3D 空间里做信息聚合，再投影回各视图。这样，视图间的一致性通过共享的 3D 缓冲间接实现，注意力复杂度对视图数的依赖从二次降为近似线性（取决于 3D 缓冲的分辨率）。

公式层面可以概括为：每个视图的 token 先按相机参数反投影到 3D 位置 p，在 3D 缓冲上做聚合 F(p) = Σ_v w_v(p) · f_v(p)，再按各视图相机投影回 2D 特征。权重 w_v 通常与可见性/深度相关，遮挡区域的权重趋近于零，这正是它处理遮挡的机制。代价是 3D 缓冲的分辨率成为新的瓶颈：分辨率高则显存吃紧，分辨率低则高频细节被抹平，生成分辨率与几何精度之间出现错配。

失败模式很典型：当输入图的相机分布与训练分布偏离（例如极端俯仰角），反投影的可见性权重估计失准，3D 缓冲里出现"鬼影"——同一几何位置被不同视图填入矛盾内容，投影回 2D 后表现为局部模糊或重影。具体例子：生成一圈 16 视图时，MVDream 式的全连接注意力在显存上不可行，SyncDreamer 的 3D 缓冲方案能跑通，但背面靠近轮廓的区域容易出现细节粘连。它相对 MVDream 是"改进 + 部分替代"：一致性机制从 2D 注意力换成 3D 中介，视图数上限提高，但单视图锐度让位。

四 · Wonder3D：跨域扩散把几何与外观拆成两条流

Wonder3D 的断裂点不在一致性机制，而在"生成什么"。此前的模型生成的是颜色图，几何信息只能隐式地藏在像素里，重建网络需要从颜色反推法线。Wonder3D 用跨域扩散同时生成法线图和颜色图，并让两条流在去噪过程中互相条件：法线流提供几何约束，颜色流提供外观约束，跨域注意力保证同一视角下两者对齐。这相当于把"几何可重建性"从重建阶段的负担前移到生成阶段。

机制上，跨域扩散可以写成两个耦合的去噪过程：x_t^{n} ~ p(x_t^{n} | x_{t+1}^{n}, x_{t}^{c}) 与 x_t^{c} ~ p(x_t^{c} | x_{t+1}^{c}, x_{t}^{n})，互为条件。一致性同时存在于两个维度：视角间（同一域内多视图一致）与域间（同视角法线-颜色对齐）。系统代价是双倍采样开销与双倍显存，且两个域的收敛速度不一致时会出现"法线清晰但颜色模糊"或反之的失配。失败模式：当输入图存在强反光或透明材质，法线流给出错误朝向，颜色流被法线条件带偏，跨域耦合反而放大了错误。

与 SyncDreamer 的关系是互补而非替代：SyncDreamer 解决"多少视图能一致"，Wonder3D 解决"每个视图携带什么信息"。具体例子：重建阶段若只有颜色图，背面轮廓靠光度立体近似；有了法线图，重建网络可以直接用法线做几何监督，背面曲率不再依赖颜色明暗猜测。这条思路后来在 Hi3DGen 里以"法线桥接"的形式被继承，说明跨域监督是这条谱系里被验证有效的延续线。

五 · InstantMesh 与 CRM：稀疏视图大重建模型把生成与重建缝合

InstantMesh 和 CRM 代表另一类断裂：不再追求"生成一圈稠密视图再走通用重建管线"，而是把少量稀疏视图直接喂给大重建模型（LRM）。InstantMesh 的流程是：多视图扩散生成固定数量（典型 4–6 张）的一致视图，然后由稀疏视图大重建模型一次性回归出网格与纹理。CRM 走卷积式重建路线，把多视图图像组织成紧凑的几何缓冲，用卷积网络直接输出 textured mesh，避免了对隐式场的慢速采样。

这里的工程判断是"接口收敛"：生成端的输出被固定为稀疏视图集合，重建端的输入被固定为同样的集合，两端联合训练或至少联合调参。伪代码思路：M = Recon(Gen(I, {T_1..T_k}))，其中 Gen 是多视图扩散，Recon 是 LRM。代价是生成端的视角布局必须与重建端训练时的相机分布匹配，否则重建质量骤降——这是"训练数据的相机分布偏差"最直接的体现。失败模式：扩散生成的视图在轮廓处有轻微不一致，LRM 会把这些不一致解释为几何噪声，产生表面褶皱；CRM 的卷积缓冲对视图顺序与布局敏感，视图排列变化会改变输出。

与前三者的关系是"替代管线、保留一致性约束"：Zero-1-to-3/MVDream/SyncDreamer 的一致性机制仍是核心，但"生成图作为最终中间产物"的地位下降——图像只是重建网络的输入张量。具体例子：InstantMesh 在数秒级完成单图到网格，靠的不是生成更多视图，而是把 4 张视图的重建误差压到可接受范围。这条路线把多视图扩散从"独立产品"变成"前馈重建的数据源与前端"。

六 · Hi3DGen：法线桥接与联合训练的收束

Hi3DGen 的改进点是把 Wonder3D 的跨域思想与 LRM 管线合并：生成阶段产出法线作为几何中介，重建阶段以法线桥接图像域与几何域，使高保真几何不再完全依赖颜色图的纹理细节。机制上，法线图充当"几何先验的压缩表示"——它比颜色图更直接地约束表面朝向，又比隐式场更易于被 2D 网络生成。公式化地看，重建损失里加入法线一致性项 L_n = ‖n_pred − n_gen‖，把生成端的法线作为监督信号传回几何优化。

系统代价是管线更长：扩散生成法线、生成颜色、重建、法线对齐，每一环都有误差累积。失败模式是"法线-几何循环失配"：生成的法线在局部自洽但与重建出的网格朝向不符，桥接项反而把错误固化。工程上这要求生成分辨率与重建分辨率匹配——生成法线过平滑，重建网格就丢失锐边；生成法线过噪，重建表面出现伪影。具体例子：对带精细浮雕的物体，纯颜色管线会把浮雕当成纹理贴图，法线桥接则迫使重建网络把浮雕还原为几何起伏。

从谱系看，Hi3DGen 是"延续 + 收束"：延续 Wonder3D 的跨域监督，收束 InstantMesh/CRM 的联合训练思路，把"纯图像中间产物"进一步降级为"法线中介 + 稀疏视图"。近年趋势正是如此：多视图扩散与重建网络联合训练，图像不再是终点，一致性约束仍是不可替代的核心。工程判断落在具体机制上——只要视角间几何一致性还靠生成端保证，跨视图注意力或 3D 中介就仍是这条路线的心脏；而一旦重建端能容忍不一致，生成端的视图数就可以继续压缩，管线重心从"生成更多"转向"约束更准"。
