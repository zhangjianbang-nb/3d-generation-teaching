一 · 从 LRM 的 triplane 到 TripoSR 的工程化压缩

LRM 确立的范式是「图像编码器 + 三平面 Transformer 解码器 + 可微渲染监督」。它的关键机制在于把 3D 表示固定为三张正交特征平面，查询任意空间点时对三平面做双线性插值并拼接成特征向量，再经小 MLP 解出密度与颜色。训练信号来自渲染损失：对采样射线做体渲染，与真值图像比对。这使网络无需 3D 卷积或显式体素，就能在单次前向中输出可渲染的隐式场。

$$\hat{C}(\mathbf{r})=\int_{t_n}^{t_f} T(t)\,\sigma(\mathbf{x}(t))\,\mathbf{c}(\mathbf{x}(t),\mathbf{d})\,dt,\quad T(t)=\exp\!\Big(-\int_{t_n}^{t}\sigma\,ds\Big)$$

TripoSR 的继承关系不是换模型，而是把 LRM 的训练与推理管线做工程压缩：更激进的数据筛选、更短的训练日程、对输入图像做前景归一化与背景统一，并把三平面分辨率与通道配置调到在单卡上可跑的量级。它证明「一次前向出 triplane」不只是可行性演示，而是能压到亚秒级延迟的产品级路径。代价同样明确：三平面分辨率一旦降低，薄结构（叶片、栏杆、线缆）在插值时被抹平，背面细节完全依赖先验幻觉；渲染监督对高光与反光的解耦能力弱，材质只能以颜色近似。

具体例子：给定一张带细长手柄的马克杯照片，LRM 类模型能恢复杯身与把手的大致拓扑，但把手内侧的遮挡区域与杯口厚度常出现粘连或空洞。这不是训练不足，而是三平面在低分辨率下对细尺度几何的频谱截断所致。工程判断上，TripoSR 的定位是「速度优先的基线」：它把 LRM 的学术范式转成可部署的前馈重建器，同时把精度天花板暴露给后续工作。

二 · 输出头分叉：GS-LRM、MeshLRM 与 LGM 的表示之争

LRM 之后出现一次明确的表示分叉：同一套 Transformer 骨干，换不同的输出头，就得到不同的资产形态与代价结构。GS-LRM 把输出头换成高斯泼溅参数：每个高斯基元预测中心、协方差、不透明度与球谐颜色，用泼溅光栅化替代体渲染。训练监督仍是图像比对，但渲染是可微的显式光栅化，梯度路径更短。收益是渲染质量与速度，尤其在反光与高频纹理上优于三平面体渲染；代价是输出不是网格，高斯核的各向异性在薄结构上产生「绒毛状」伪影，且要从泼溅结果提取水密网格需要额外步骤。

MeshLRM 走相反方向：输出头直接产出网格（或可微分的网格提取），把拓扑质量作为一等目标。它的机制通常是在隐式场之上加可微的网格化与拉普拉斯平滑正则，使训练信号不仅约束渲染，还约束面片分布。收益是下游可直接编辑、绑定、仿真；代价是网格化操作不可微或近似可微，训练不稳定，且高分辨率网格的显存开销随面数增长。

LGM 则把多视图生成与前馈重建串联：先用多视图扩散生成环绕视角，再用高斯泼溅头做前馈融合。它的继承点是「前馈」被保留在融合阶段，而视图生成阶段仍是迭代采样。这带来一个系统代价：多视图之间的一致性误差会被融合放大，背面视角的幻觉细节与正面冲突时，泼溅核在重叠区产生重影。具体例子：生成一只毛绒玩具，正面纹理清晰，但侧后方视图由扩散模型编造，融合后在轮廓边缘出现双层毛发。工程上，LGM 的判据是「高分辨率外观优先、可接受非水密输出」。

工作输出头继承自主要代价
LRM三平面 + 体渲染—薄结构频谱截断
TripoSR三平面 + 体渲染LRM精度天花板、材质近似
GS-LRM高斯泼溅LRM 骨干非水密、薄结构绒毛伪影
MeshLRM网格LRM 隐式场网格化不可微、显存随面数
LGM多视图 + 泼溅前馈融合视图一致性误差放大

三 · 结构化潜变量：SLAT 与 Direct3D 的断裂点

三平面与泼溅都是「稠密、无结构」的表示：它们不区分物体表面与空白空间，也不携带部件语义。SLAT（Structured 3D Latents）代表一次断裂式改进：把 3D 资产编码为一组稀疏的、带位置的局部潜变量，每个潜变量对应空间中的一个小区域，并可在其上做扩散生成。机制上，SLAT 先由稀疏体素化或表面采样确定活跃位置，再在这些位置上放置特征向量，Transformer 在活跃集合上做注意力，而非在全空间网格上做。这让生成过程可以「只在有东西的地方算」，分辨率提升时计算量随表面面积而非体积增长。

$$\mathcal{L}_{\text{SLAT}}=\mathbb{E}_{\mathbf{z}_0,\epsilon,t}\Big\|\epsilon-\epsilon_\theta\big(\{\mathbf{z}_t^{(i)},\mathbf{p}^{(i)}\}_{i\in\mathcal{A}},t\big)\Big\|_2^2,\quad \mathcal{A}=\{\text{active cells}\}$$

Direct3D 的贡献在于把 3D 潜扩散 Transformer 直接架在稀疏结构上，用整流流做采样，避免「先多视图再重建」的两段式误差累积。继承关系上，它继承了 SLAT 的稀疏结构思想，但把生成与解码更紧密地耦合。系统代价是稀疏结构的构建本身依赖一个前置的几何估计（如稀疏视图重建或粗网格），前置误差会传导到生成阶段；且稀疏注意力的实现需要自定义 kernel，显存访问不规则，批处理效率低于稠密注意力。

具体例子：生成一把带镂空花纹的椅子。稠密三平面在低分辨率下会把镂空填成实心；SLAT 类方法因为只在表面活跃单元上放置潜变量，镂空区域没有活跃单元，反而更容易保留通透性。但若前置几何估计把镂空误判为实体，后续扩散无法纠正。这是「结构化」带来的新失败模式：错误从表示层转移到了结构层。

四 · 工业级管线：Hunyuan3D 2.x 与 Step1X-3D 的分工

Hunyuan3D 2.0 的继承与改进体现在管线拆分：形状与材质不再由一个网络同时输出，而是分成两个 DiT——形状 DiT 生成几何潜变量，材质 DiT 在给定几何的条件下生成 PBR 参数（反照率、粗糙度、金属度）。这种拆分是对「渲染监督难以解耦光照与材质」的直接回应。机制上，材质 DiT 以几何法线与位置为条件，输出纹理场，再烘焙到网格 UV。收益是 PBR 材质可用于真实光照管线；代价是两阶段误差叠加：几何的法线错误会让材质在错误表面上烘焙，且两阶段各自需要独立的训练数据与算力。

Step1X-3D 强调可控生成：在潜变量生成阶段引入几何与纹理的条件控制，使同一文本下可指定风格或结构约束。它的继承点是 SLAT/Direct3D 的稀疏潜变量扩散，改进点在于控制信号的注入位置与强度调度。系统代价是控制越强，生成多样性越窄；且控制信号与稀疏结构的对齐需要额外标注或前置估计。

CraftsMan3D 走的是另一条继承线：它不追求端到端一次前向出最终网格，而是「3D 原生生成 + 交互式几何精修」。机制上，前馈生成给出粗几何与拓扑，随后用几何精修器做局部重网格、补洞与拓扑清理。这是对「网格拓扑质量」这一失败模式的工程回应：前馈网络的输出面片分布不受拓扑约束，直接下游使用会出现非流形边与退化面。代价是管线不再是单次前向，精修阶段引入人工或半自动交互，吞吐下降。具体例子：生成一个带凹槽的机械零件，前馈输出在凹槽底部出现自交面，精修器通过局部重采样消除自交，但凹槽的锐边被轻微圆化。

管线阶段划分解决的失败模式新增代价
Hunyuan3D 2.x形状 DiT + 材质 DiT光照与材质耦合两阶段误差叠加
Step1X-3D条件注入 + 稀疏扩散不可控生成多样性收窄
CraftsMan3D前馈 + 几何精修拓扑质量差非单次前向、吞吐下降

五 · 2024–2025 的 scaling 主线与数据引擎

这一阶段没有新的表示范式断裂，主线是把已验证的范式做大：更大 Transformer、更大 3D 数据引擎、更高分辨率、PBR 与可编辑性。继承关系清晰：LRM 的三平面骨干被 TripoSR 压缩，GS-LRM 与 MeshLRM 换头，SLAT 与 Direct3D 换结构，Hunyuan3D 与 Step1X-3D 换管线拆分。每一代都在前一代表现出的具体失败模式上做针对性改进，而非推翻。

数据引擎是 scaling 的真正瓶颈。3D 监督数据的规模与版权约束决定了模型能学到多少背面先验与材质多样性。机制上，数据引擎通常包含：从渲染资产中采样多视图与相机参数、自动标注几何与材质、用重建模型做伪标签过滤。系统代价是伪标签会引入系统性偏差——若过滤模型本身对薄结构无能，偏差会被放大进训练集。具体例子：用前代模型过滤一批细长工具资产，过滤后数据集中这类资产被大量丢弃，下一代模型在细长结构上反而退化。这是「scaling 不等于全面变好」的工程现实。

推理显存与高分辨率是另一条硬约束。稀疏结构缓解了体积增长，但高分辨率纹理与 PBR 多通道输出使显存随通道数与面数线性上升。工程判断上，2024–2025 的竞争点不在单张图的峰值质量，而在「单位算力下的可用资产产出率」：能否在固定显存预算内稳定输出可下游使用的网格与材质。

六 · 继承图谱中的判据与未解断裂

把关键论文按继承关系排成图谱，可以看到三条清晰的延续线：表示线（三平面 → 稀疏结构化潜变量）、输出头线（体渲染 → 泼溅 → 网格）、管线线（单网络 → 形状/材质拆分 → 生成/精修分离）。替代关系发生在输出头之间：泼溅替代体渲染以获得外观质量，网格替代泼溅以获得可编辑性，二者不是简单优劣，而是下游用途决定。断裂点出现在 SLAT：它把「稠密无结构」换成「稀疏有结构」，从此分辨率提升的代价结构改变。

未解的断裂有三处。其一，背面细节与薄结构仍依赖先验幻觉，任何前馈网络在单视图下都无法获得被遮挡区域的真实信息，结构化表示只是让幻觉更局部化，而非消除。其二，PBR 材质与光照解耦在训练数据不足时退化为颜色近似，拆分 DiT 缓解但不根治。其三，网格拓扑质量与前馈单次前向存在根本张力：拓扑是全局组合问题，而前馈网络输出的是局部场值，CraftsMan3D 的精修阶段正是对这一张力的工程妥协。

工程判断落在具体机制上：选型时先问下游要什么——要渲染质量选泼溅头，要编辑与仿真选网格头加精修，要可控与多样选稀疏潜变量扩散；再问算力预算——单次前向的亚秒级路径只在前馈头加低分辨率潜变量下成立，高分辨率 PBR 必然引入多阶段。继承图谱的价值不是记住谁在谁之后，而是看清每个改进对应的失败模式是否在你的场景中真实存在。
