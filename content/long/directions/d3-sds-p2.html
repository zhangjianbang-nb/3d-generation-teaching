一 · 从单点采样到分布匹配：SDS 与 VSD 的路线分野

优化式蒸馏的第一条路线是 Score Distillation Sampling（SDS），它的本质是把 2D 扩散模型的去噪得分当作一个“伪梯度源”，通过可微渲染器把梯度回传到 3D 参数上。给定 3D 表示参数 θ、相机位姿 c、文本条件 y，渲染出图像 x = g(θ, c)，再对 x 加噪得到 x_t = α_t x + σ_t ε，SDS 的梯度形式为：

$$ \nabla_\theta \mathcal{L}_{\text{SDS}} = \mathbb{E}_{t,\epsilon}\left[ w(t)\,(\epsilon_\phi(x_t; y, t) - \epsilon)\,\frac{\partial x}{\partial \theta} \right] $$

这里 ε_φ 是预训练扩散模型的噪声预测网络，w(t) 是时间步权重。机制上，它并不要求扩散模型输出一张“正确”的图，只要求它给出一个指向更高概率密度的方向；因此 SDS 可以在没有任何 3D 监督的情况下驱动优化。DreamFusion 正是靠这一条公式，配合 Imagen 与一个可微的 NeRF 渲染器，第一次让文本直接生成 3D 在质量上可用。

但 SDS 的梯度是一个期望下的单样本估计，方差极大。工程上的直接后果是：优化过程抖动明显，纹理容易过饱和、颜色被推向极端值，几何细节被高频噪声污染。更隐蔽的失败模式是“多面问题”（Janus）：因为 SDS 对每个相机视角独立施加 2D 先验，缺少跨视角一致性约束，模型会把正面语义复制到背面，生成一个从两侧看都“合理”但整体不自洽的物体。系统代价上，每个资产需要数十分钟的优化，且对 CFG 尺度极其敏感——尺度偏低导致模糊，偏高导致过饱和与纹理粘连。

ProlificDreamer 提出的 Variational Score Distillation（VSD）换了一个视角：不再把 3D 参数当作一个待优化的点，而是当作一个分布。它引入一个可学习的粒子分布 q_μ(θ)，并用一个额外的扩散模型（或 LoRA 适配的副本）去建模“当前 3D 分布在某视角下渲染出的图像分布”。VSD 的梯度写成两个得分之差：

$$ \nabla_\theta \mathcal{L}_{\text{VSD}} = \mathbb{E}_{t,\epsilon}\left[ w(t)\,\big(\epsilon_\phi(x_t; y, t) - \epsilon_{\phi'}(x_t; t, c)\big)\,\frac{\partial x}{\partial \theta} \right] $$

其中 ε_{φ'} 是在线更新的“学生”噪声预测器，条件里带有相机位姿 c。减去的这一项充当控制变量，抵消了 SDS 中与 3D 内容无关的噪声分量，方差显著下降。代价是显存与算力翻倍：需要同时维护两个扩散网络的前向，还要周期性更新学生网络；训练时间比 SDS 更长，超参（学生网络的学习率、更新频率）也更难调。具体例子是 ProlificDreamer 在 NeRF 阶段能明显缓解过饱和，但它并没有消除多面问题，只是让每个视角的渲染更接近条件分布。

二 · 区间得分匹配：把“随机时间步”换成“确定性桥”

LucidDreamer 的 Interval Score Matching（ISM）针对的是 SDS 方差里的另一个来源：时间步 t 的随机采样。SDS 在整条噪声日程上随机取 t，导致同一视角在不同迭代中收到方向不一的梯度。ISM 的做法是构造一条从加噪图像到干净图像的确定性扩散桥（DDIM 逆过程），在固定的区间内做得分匹配，而不是在随机 t 上做单点估计。

机制上，ISM 先用 DDIM 逆过程把渲染图像 x 加噪到某个中间状态，再沿同一确定性轨迹反向去噪，比较去噪结果与原始渲染之间的差异，把这个差异作为梯度信号。伪代码思路如下：

  • 渲染 x = g(θ, c)，采样一个固定区间 [t_hi, t_lo]；
  • 沿 DDIM 逆过程把 x 映射到 x_{t_hi}，再沿确定性反向轨迹得到去噪估计 x̂_0；
  • 计算 x̂_0 与 x 的差异，经 ∂x/∂θ 回传，权重按区间长度归一。

因为轨迹是确定性的，同一视角在相邻迭代中收到的梯度方向更一致，抖动下降，纹理粘连与过饱和随之减轻。系统代价是每步需要多次扩散网络前向（逆过程加反向过程），单步开销高于 SDS；同时区间端点 t_hi、t_lo 的选择对结果影响很大，端点选得不好会退化成近似 SDS 或过度平滑。具体例子是 LucidDreamer 在 NeRF 与 3DGS 两种表示上都报告了更干净的几何边缘，但它同样没有从机制上解决跨视角一致性，多面问题仍需靠提示词工程或视角采样策略缓解。

把这三条路线放在一张表里对比，可以看出它们共享同一个骨架（可微渲染 + 2D 先验 + 梯度回传），差别只在“梯度估计器”的设计上：

路线梯度估计器方差来源主要代价典型失败模式
SDS（DreamFusion）单样本噪声预测残差随机 t、随机 ε、无跨视角约束每资产数十分钟；CFG 敏感过饱和、纹理粘连、多面
VSD（ProlificDreamer）两个得分之差，含学生网络学生网络建模误差双网络前向，显存与算力翻倍学生网络滞后导致梯度偏差
ISM（LucidDreamer）确定性扩散桥的区间匹配区间端点选择每步多次前向端点不当导致过度平滑

三 · 3D 表示与网格化：DMTet 与 3DGS 如何改变代价结构

优化式蒸馏的第二条分野不在梯度估计器，而在被优化的 3D 表示。DreamFusion 用 NeRF，优点是体渲染可微、拓扑自由，缺点是每条光线要采样大量点，渲染慢，且提取高质量网格需要额外的 Marching Cubes 后处理，表面细节在体密度场里容易被平滑掉。Magic3D 的两阶段路线是这一问题的工程回答：第一阶段用低分辨率 NeRF 快速搭出粗几何与颜色，第二阶段切换到 DMTet 表示做高分辨率精修。

DMTet 是一种可微的混合表示：它维护一个稀疏的四面体网格，每个顶点带符号距离值，通过可微的 Marching Tetrahedra 提取三角面片，再在面片上做可微光栅化。相比 NeRF，它的渲染开销与分辨率近似线性，梯度可以直接落在顶点位移与表面颜色上，因此高分辨率阶段的收敛更快，几何边缘更锐利。代价是 DMTet 的拓扑在优化中可能发生剧烈变化（顶点合并、面片翻转），需要正则项约束；同时四面体网格的构建与更新本身有内存开销。具体例子是 Magic3D 用这一两阶段结构把高分辨率内容的生成时间压到比纯 NeRF 路线更可控的量级，同时把过饱和问题部分归因于低分辨率阶段的先验偏差。

DreamGaussian 走的是另一条加速路线：用 3D Gaussian Splatting（3DGS）作为 3D 表示。3DGS 把场景表示为一组带位置、协方差、不透明度与球谐颜色的高斯椭球，渲染是屏幕空间的分裂-投影-混合，速度远高于体渲染。DreamGaussian 先用 3DGS 做快速几何与外观优化，再把高斯“网格化”（提取表面点、做泊松重建或直接转成网格）用于下游交付。机制上的关键点是：SDS 梯度可以直接作用在高斯参数上，而高斯的显存占用随数量增长，数量过多时显存成为瓶颈，数量过少时表面出现空洞与漂浮物。失败模式是网格化阶段引入的重建误差——高斯优化出的外观在转成网格后丢失高频细节，纹理出现模糊或接缝。

把表示与梯度估计器交叉组合，会得到不同的代价曲线。NeRF + SDS 是“慢而稳”的基线；NeRF + VSD 是“更慢但更干净”；DMTet + SDS 是“两阶段、高分辨率友好”；3DGS + SDS 是“快但网格化有损”。选型时不能只看单步开销，要看“达到可交付质量所需的总迭代数 × 单步开销”，以及网格化后处理带来的质量折损。

四 · 几何与外观解耦：Fantasia3D 与 TextMesh 的路线选择

Fantasia3D 的核心主张是把几何与外观拆成两个阶段分别优化。第一阶段只优化几何（通常用 DMTet 或 NeRF 的密度场），用扩散先验驱动表面法线与轮廓；第二阶段固定几何，优化材质与光照参数（如 BRDF），让渲染结果匹配文本条件。这样做的机制理由是：SDS 的梯度同时作用于几何与颜色，二者耦合时，模型倾向于用颜色“补偿”几何错误——例如用暗色纹理掩盖凹陷，导致过饱和与纹理粘连。解耦后，几何阶段只收到形状相关的梯度，外观阶段只收到颜色相关的梯度，各自的失败模式更容易诊断。

代价是两阶段的误差会累积：几何阶段的错误（如缺失的部件、错误的拓扑）在外观阶段无法被修正，只能被纹理掩盖。另一个代价是材质优化需要可微的光照模型，增加了渲染器的复杂度。具体例子是 Fantasia3D 在金属与高光材质上表现更稳定，因为 BRDF 参数被显式优化，而不是让扩散先验去“猜”颜色。

TextMesh 走的是更偏工程交付的路线：直接以网格为输出目标，用 SDS 驱动一个带位移的网格表示，并在优化中引入拉普拉斯平滑与法线一致性正则，抑制网格自交与尖刺。它的机制特点是“先粗后细”的网格细分策略：低分辨率网格先收敛到大形状，再逐步细分并继续优化。失败模式是细分过程中出现的表面褶皱与法线翻转，需要正则项持续压制。与 Fantasia3D 相比，TextMesh 不追求材质解耦，而是把工程重心放在“网格可直接用”上，代价是外观丰富度受限于网格顶点颜色或简单纹理。

五 · 选型判据：什么条件下仍应选优化式蒸馏

2024 年之后，前馈模型在速度与一致性上全面胜出，SDS 不再是主流交付路线。但这不等于优化式蒸馏失去位置。选型判据可以从四个维度展开：

  • 数据条件：当目标资产类别缺少配对 3D 数据、或需要针对特定文本风格做单资产定制时，优化式蒸馏不依赖 3D 训练集，只需要一个 2D 先验和一个可微渲染器，这是前馈模型无法替代的边界。
  • 物理属性优化：当目标不只是“看起来像”，而是要让几何满足物理约束（如可打印性、重心稳定、碰撞体积）时，优化式蒸馏可以把物理项直接写进损失函数，与前馈模型的“一次性生成”形成互补。
  • 精修与风格化：前馈模型给出的粗资产可以用 SDS/VSD 做局部精修——固定大部分参数，只对局部区域或材质做优化，此时单资产数十分钟的代价可以接受。
  • 方差缩减思想的复用：VSD 与 ISM 的控制变量与确定性桥思想，被后续少步蒸馏借鉴。选型时若关心的是“梯度估计器设计”而非“3D 交付”，这三条路线的对比仍然是理解蒸馏方差来源的最小完整样本。

反过来，什么条件下不应选：需要批量、一致性、低延迟交付的场景；需要严格多视角一致（如产品展示）的场景；以及 CFG 尺度难以稳定的场景——SDS 对 CFG 的敏感性意味着调参成本会随资产类别漂移，批量生产时这是不可接受的系统代价。

一个具体的工程判断是：把优化式蒸馏当作“单资产精修工具”而不是“生成管线主干”。在这个定位下，SDS 适合快速粗调，VSD 适合对过饱和敏感的高保真单资产，ISM 适合需要稳定梯度的几何精修，DMTet 与 3DGS 的选择取决于是否需要高分辨率网格交付还是快速预览。多面问题在这一定位下不再是阻断性缺陷，而是需要在视角采样策略与提示词上做局部补偿的已知失败模式。

最后落在机制上：优化式蒸馏的选型本质是选择“梯度估计器的方差-代价曲线”。SDS 用最低的单步开销换取最高方差，VSD 用双网络前向换取方差下降，ISM 用多次前向换取确定性梯度；3D 表示的选择则决定“单步开销”的量级与“网格化折损”的大小。把这两条轴画在一起，任何具体项目的选型都可以落在一个可比较的坐标上，而不是靠“哪个效果好看”的定性判断。
