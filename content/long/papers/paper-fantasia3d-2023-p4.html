一 · 实验设置：没有 3D 训练集时的证据从哪来

Fantasia3D 的实验配置有一个必须先讲清的前提：它不使用任何 3D 训练集。这不是一句轻描淡写的“零样本”标签，而是决定了整篇论文证据结构的根本约束。既然没有成对的（文本，3D 资产）监督，也就不存在传统意义上的训练集/验证集划分、不存在 held-out 测试集上的 Chamfer 距离或 F-score 报表，更不存在“在 X 万资产上预训练”的规模叙事。取而代之的是：每个资产从随机初始化出发，靠冻结的 2D 扩散先验做逐资产的 SDS 优化，数小时收敛；评价则依赖渲染图与用户偏好。这意味着论文的实验章节本质上不是“模型泛化能力”的测量，而是“优化过程能否稳定地把 2D 先验蒸馏成干净的几何与可重光照的材质”的测量。

这一约束带来一个具体的机制后果：所有对比都必须控制优化预算与扩散先验的一致性。因为基线 DreamFusion、Magic3D、TextMesh 同样是无 3D 训练集的逐资产优化路线，若给 Fantasia3D 更多的采样步数或更大的 DMTet 分辨率，几何更干净就可能只是算力差异而非方法差异。论文因此把对比放在同一类“SDS 家族”内，并明确把“解耦”作为唯一被操纵的变量：几何阶段用 DMTet 表示 + 法线条件扩散，外观阶段冻结网格、用 PBR 渲染 + RGB 扩散。基线的共同点是几何与纹理耦合在同一个辐射场里联合优化——这正是被对照的机制。

评价口径上，论文给出的不是数值指标而是两类证据：定性渲染对比（几何干净度、材质可重光照性）与用户偏好研究。用户偏好优于同期 SDS 方法，这是一个方向性结论，论文未给出具体人数、偏好比例或置信区间，因此这里只能定性表述其存在，不能编造百分比。对工程读者而言，需要理解这种证据的强度边界：用户偏好能反映“看起来更像可用资产”，但不能替代几何精度或材质参数误差的定量测量；而后者在这篇论文的设定下根本无法构造，因为没有真值资产。

还有一个容易被忽略的设置细节：几何阶段用带法线（及深度）条件的扩散模型算 SDS，外观阶段用 RGB 扩散。两个阶段共享同一个冻结的 2D 先验家族，但条件通道不同。这带来一个系统代价——两阶段之间存在表示不匹配的风险：几何阶段优化的法线场要经由 DMTet 的可微渲染转成法线图，外观阶段的 PBR 渲染又要用同一套法线与材质参数合成 RGB。若两阶段的相机采样分布、光照假设或分辨率不一致，SDS 梯度就会在阶段交界处互相拉扯。论文的实验设置必须固定这些共享量，否则消融就无法归因。

二 · 基线选择：为什么只和 SDS 家族比

基线名单是 DreamFusion、Magic3D、TextMesh。这三者不是随意拼凑：DreamFusion 确立了 SDS + 隐式辐射场的基本范式，Magic3D 引入两阶段粗到细与更高分辨率表示，TextMesh 走的是从 2D 图像到网格的另一条工程路径。把它们放在一起，恰好覆盖了“耦合式优化”的三种典型实现，从而让 Fantasia3D 的差异可以被定位在“解耦”这一条轴上，而不是被表示能力或分辨率差异混淆。

具体机制上，DreamFusion 类方法把密度与颜色一起塞进 MLP 辐射场，SDS 的 RGB 梯度同时回流到几何与纹理参数。这会产生一个可预测的失败模式：当文本提示包含高频外观细节（例如“锈迹斑斑的金属”“编织纹理”）时，RGB 扩散的梯度会倾向于用几何位移去“解释”这些亮度变化，因为辐射场里几何与颜色共享同一组参数，梯度没有理由区分二者。结果是表面出现本不该有的凹凸，纹理“长”进几何。Magic3D 用两阶段与稀疏网格缓解分辨率问题，但没有从参数层面切断几何与外观的耦合，因此同样的失败模式只是被削弱而非被消除。TextMesh 从多视角 2D 图像生成网格，几何来自图像监督而非 SDS，纹理与几何的分离程度取决于其管线设计，但在“可重光照”这一维度上并不提供 PBR 材质输出。

因此基线对比的实质是：在同样依赖 2D 先验、同样逐资产优化的前提下，把“几何参数与外观参数是否共享同一组可微变量”作为对照。Fantasia3D 的几何阶段只优化 DMTet 的顶点位移与拓扑相关参数，外观阶段冻结网格、只优化 MLP 输出的反照率 a、粗糙度 r、金属度 m。这个参数隔离是提升的直接来源，而不是更大的模型或更多的数据。

系统代价也随之明确：两阶段意味着两次独立的 SDS 优化循环，每资产数小时的预算被切成两段，且阶段二必须在阶段一的网格上做 PBR 渲染，渲染器要可微、要支持所选的材质模型。与单阶段耦合方法相比，这多了一次表示转换（DMTet 网格提取）和一套 PBR 着色管线，工程复杂度上升。基线选择因此也隐含了一个公平性问题：耦合方法只需一次优化，解耦方法要两次，若总预算相同，单阶段方法在采样步数上占优。论文的定性对比需要在这个预算约束下解读。

三 · 主要结果：提升来自参数隔离而非算力

论文报告的主要结果是两条定性结论：几何更干净，材质可重光照。要把这两条拆成可归因的机制，需要回到两阶段的公式分工：

$$\mathcal{L}_{\mathrm{geo}}=\mathcal{L}_{\mathrm{SDS}}(\hat{n},y),\qquad \mathcal{L}_{\mathrm{app}}=\mathcal{L}_{\mathrm{SDS}}(\mathrm{PBR}(\mathbf{a},r,m,\hat{n}),y)$$

几何阶段的 SDS 作用在法线图 ĥ 上，而不是 RGB 上。这是一个关键设计：法线条件扩散模型对“表面朝向是否合理”敏感，对颜色不敏感。于是文本提示里描述外观的词（颜色、材质感）不会通过几何阶段的梯度去推动顶点位移——它们在这一阶段根本没有入口。几何的干净度因此不是靠正则项压出来的，而是靠条件通道的选择从源头切断了外观梯度污染几何的路径。这是“几何更干净”的第一层机制。

第二层机制在外观阶段。网格被冻结后，PBR 渲染器把材质参数 (a, r, m) 与固定法线 ĥ 合成为 RGB，RGB SDS 的梯度只回流到材质 MLP。由于几何不可动，任何“用凹凸解释亮度”的捷径被物理上封死；模型只能通过调整反照率、粗糙度、金属度去匹配扩散先验的 RGB 分布。这就是“可重光照”的来源：输出的是标准 PBR 通道，换一套环境光照重新渲染时，材质响应会随光照变化，而不是把亮度烘死在几何里。对比之下，耦合式辐射场把颜色与密度混在一起，重光照时无法区分“这是材质反射”还是“这是几何遮挡”，因此不可重光照。

一个具体例子可以说明这两层机制如何共同起作用：提示“一把磨损的铜壶”。在耦合方法里，RGB SDS 可能把壶身高光区域的亮度差异解释成表面凹坑，几何出现虚假起伏，且这些起伏在高光下被烘成颜色，换光照后凹坑依然“亮”，物理上不成立。在 Fantasia3D 里，几何阶段只看法线条件，壶身保持光滑的旋转体；外观阶段把高光归因于低粗糙度与金属度 m 接近 1 的反照率组合，换光照后高光位置随光源移动。提升不来自更多采样或更大网络，而来自“外观梯度无法改写几何”这一参数隔离。

需要诚实标注证据强度：论文没有给出几何精度或材质参数误差的数值，因为无 3D 训练集意味着无真值。所谓“几何更干净”是渲染图上的定性判断，“可重光照”是换光照渲染的定性演示。用户偏好优于同期 SDS 方法，方向明确但无具体统计量。工程读者应把这两条理解为机制层面的可信结论，而非精度层面的定量承诺。

四 · 消融：三个变量各自值多少

论文的消融围绕三个变量展开：几何/外观解耦、法线条件、PBR 与纯 RGB 的对比。这三者不是并列的“技巧清单”，而是分别对应方法的三条支柱，消融的作用是把每条支柱的边际贡献从整体效果里剥离出来。

第一项，几何/外观解耦。去掉解耦即回到单阶段耦合优化，几何与材质共享同一组可微变量。预期失败模式在第二节已述：纹理长进几何、表面虚假凹凸、不可重光照。消融的意义在于确认“提升来自解耦”而非“提升来自 DMTet 表示”或“提升来自两阶段更多的优化步数”。因为 DMTet 本身是一种高分辨率可微网格表示，若不做解耦消融，就无法排除“只是换了个更好的几何表示”这一替代解释。

第二项，法线条件。几何阶段的 SDS 若改用 RGB 条件而非法线条件，外观信息就会重新获得影响几何的通道，几何阶段的“纯净性”被破坏。法线条件的作用是提供一个与颜色无关的监督信号：扩散模型判断的是“这个法线图看起来像不像一个合理表面”，而不是“这个渲染看起来像不像提示词”。消融此项可验证几何干净度是否真的依赖条件通道的选择。系统代价是：法线条件扩散模型需要能接受法线图输入，这要求额外的条件适配，且法线图的数值范围与归一化方式必须与扩散模型的训练分布匹配，否则 SDS 梯度会有偏。

第三项，PBR 与纯 RGB。外观阶段若不用 PBR 渲染而直接用纯 RGB 输出（例如一个颜色 MLP），则材质参数不再有物理含义，重光照能力消失。PBR 的价值在于把“外观”分解为具有物理语义的反照率、粗糙度、金属度，使 RGB SDS 的梯度被约束在一个低维、可解释的材质空间里。消融此项确认“可重光照”来自 PBR 分解而非仅仅来自冻结几何。代价是 PBR 渲染器必须可微且与所选光照模型一致，材质 MLP 的输出需要满足物理约束（如金属度在 [0,1]、反照率非负），这些约束的实现方式会影响优化稳定性。

消融变量被移除后的机制后果对应失败模式
几何/外观解耦几何与材质共享可微变量，外观梯度可改写顶点纹理长进几何、虚假凹凸、不可重光照
法线条件几何阶段重新获得颜色通道，监督信号与外观纠缠几何干净度下降，外观词污染形状
PBR 渲染材质参数失去物理语义，输出退化为纯 RGB重光照能力消失，材质不可编辑

三项消融共同支撑一个归因判断：提升是三条机制叠加的结果，且每条机制各自对应一个可预测的失败模式。这也解释了为什么论文把“解耦”放在标题位置——它是三条里唯一改变参数拓扑结构的一条，法线条件与 PBR 是在解耦框架内进一步收紧监督信号与输出语义。

五 · 证据的边界：慢、材质先验有限、分辨率受限

实验证据的另一面是局限，而局限同样要从机制里读出来，不能只当免责声明。第一条是慢：每资产数小时。这个代价直接来自两阶段 SDS 的结构——几何阶段要迭代 DMTet 顶点与拓扑，外观阶段要在冻结网格上反复做可微 PBR 渲染并回传 RGB SDS。两段循环串行，且每步都要调用冻结的扩散模型做前向与梯度，采样成本随阶段数线性叠加。与单阶段耦合方法相比，解耦把一次优化拆成两次，时间预算被结构性拉长。这不是实现优化能轻易抹平的，除非把扩散模型的调用次数压下来或做缓存近似。

第二条是材质真实感受 2D 先验限制。外观阶段的监督信号来自 RGB 扩散模型的 SDS，而这个先验是在 2D 图像上训练的，它对“材质在物理上如何响应光照”没有显式建模。PBR 渲染器提供了物理正确的合成方式，但 SDS 只告诉模型“这张渲染图看起来像不像提示词”，不告诉它“粗糙度应该是多少才符合真实铜的 BRDF”。因此材质参数可能落在物理上合理但数值上偏离真实的区域，且不同随机种子下的材质分解可能不一致。这是先验层面的限制，消融无法消除，只能靠更强的材质先验或真实材质数据来补。

第三条是几何仍受 DMTet 分辨率限制。DMTet 是一种基于稀疏体素与可微网格提取的表示，其可表达的几何细节上限由体素分辨率决定。几何阶段再干净，也无法表达低于体素尺度的细节；细薄结构、尖锐边缘、小孔洞在低分辨率下会被平滑掉。这与“解耦带来干净几何”并不矛盾：干净指的是没有虚假凹凸，分辨率指的是细节上限，两者是不同维度。工程上这意味着 Fantasia3D 适合中等细节的资产，对高精度硬表面或精细镂空结构需要更高分辨率的 DMTet 配置，而这又会进一步推高每资产的优化时间。

把三条局限放在一起看，证据的边界就清楚了：论文证明的是“解耦机制在定性层面有效且可归因”，不是“该方法在精度、速度、材质保真度上全面占优”。用户偏好优于同期 SDS 方法是方向性证据，但它衡量的更接近“资产看起来是否可用”，而非“资产是否物理精确”。对工程读者，这意味着采用这套管线时应把预期设在“干净几何 + 可重光照材质 + 数小时每资产”，而不是“高精度 + 快速 + 物理精确材质”。

六 · 证据如何支撑后续影响：可归因的机制才可复用

这篇论文的实验证据之所以在后续工作中被反复引用，不是因为某个数值指标领先，而是因为它的消融把提升归因到了可复用的机制上：参数隔离（几何变量与外观变量不共享）、条件通道选择（法线条件切断外观对几何的污染）、输出语义分解（PBR 通道使材质可重光照）。这三条都是结构性的，不依赖特定数据集或特定扩散模型版本，因此可以被后续架构直接继承。

具体到继承路径：Hunyuan3D 2.x 的形状-材质双 DiT 延续了“形状与材质分开建模”的思想，把两阶段的串行优化换成两个生成分支，但参数隔离的原则不变；SF3D 的 PBR 分解延续了“外观输出必须是物理语义通道”的原则，使重光照能力成为资产的默认属性而非附加功能。这两条继承都对应 Fantasia3D 消融里被验证过的变量——若没有解耦消融与 PBR 消融，后续工作就无法判断“分开建模”到底是必要的还是仅仅是一种实现偏好。

从证据结构看，Fantasia3D 的实验章节提供了一个可复制的归因模板：在无真值数据的设定下，用“移除某机制 → 出现可预测失败模式”的方式建立因果，而不是用数值指标排名。这个模板的代价是证据强度依赖定性判断与用户偏好，优点是结论直接指向机制而非超参。对工程读者，读这篇论文的实验部分时应把注意力放在消融表的三行上：每一行都是一个可以被自己管线复用的设计决策，而主要结果的定性结论只是这些决策的下游表现。

最后落到一个工程判断：如果你的目标是可重光照的游戏或电商资产，Fantasia3D 的证据链支持你采用“几何阶段法线条件 + 外观阶段 PBR 分解”的两阶段结构，并接受每资产数小时的预算与 DMTet 分辨率上限；如果你的目标是极高细节或极快 turnaround，这篇论文的消融并不能给你速度或精度上的承诺，它给出的只是“解耦能换来干净几何与可重光照材质”这一条被三项消融分别验证过的因果链。证据的价值在于这条链的可归因性，而不在于任何单张渲染图。
