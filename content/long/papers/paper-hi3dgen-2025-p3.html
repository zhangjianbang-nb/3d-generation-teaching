一 · 几何阶段的目标函数与变量含义

Hi3DGen 的几何阶段不是把图像直接映射成网格，而是把法线图 n̂ 作为条件输入，让几何生成器输出一个可微的几何表示 M。论文给出的核心式子是 L_geo = ‖n̂ − n‖² + λ·L_render，以及 M = GeoGen(n̂)。这两行看似简单，但每一项的变量含义决定了梯度往哪里流、哪些参数被更新、哪些被冻结。

先拆第一项。这里的 n̂ 是法线扩散阶段产出的预测法线图，n 是几何表示在当前相机与当前采样下渲染出来的法线图。注意它不是数据集里的 ground-truth 法线，而是几何自身渲染出的法线——也就是说，这一项是一个自一致性项：它要求“几何渲染出来的法线”逼近“扩散模型给出的法线”。梯度从渲染法线 n 反传，穿过可微渲染器，落到几何表示的参数上（三平面特征或网格顶点偏移）。这一项的直接后果是：几何网络学到的是“如何让自己的表面朝向匹配法线图”，而不是“如何匹配像素颜色”。

第二项 L_render 是渲染损失，通常是颜色/轮廓层面的重建项，权重 λ 控制它与法线项的平衡。它的作用不是提供高频细节，而是约束几何不要为了迎合法线而漂移到荒谬的形状——法线项只约束朝向，不约束位置与轮廓，单靠它会出现“朝向对了但整体形状塌陷”的解。λ 太小，几何会过拟合法线噪声；λ 太大，几何退回平滑的颜色回归，法线桥接的高频优势被抹掉。这个权衡是训练配方的第一个关键旋钮。

第二行 M = GeoGen(n̂) 定义了前向路径：法线图是唯一条件，几何生成器是确定性的（在推理时），随机性全部前置到法线扩散阶段。这意味着几何阶段的失败模式与扩散阶段解耦：法线错了，几何阶段无法纠正，只会忠实地把错误法线“立体化”。这正是论文局限里“误差传导”的机制根源——桥接把 2D 误差原样搬进 3D，且没有反馈回路。

$$\mathcal{L}_{\mathrm{geo}}=\|\hat{n}-n\|^2+\lambda\mathcal{L}_{\mathrm{render}},\qquad \mathcal{M}=\mathrm{GeoGen}(\hat{n})$$

一个具体例子：假设输入是一张带细密铆钉的金属板图像。法线扩散阶段给出了铆钉处的法线扰动，几何阶段如果 λ 偏大，渲染损失主导，几何会把这些扰动当作噪声平滑掉，输出一块光板；如果 λ 偏小，法线项主导，铆钉的朝向被保留，但板的整体厚度可能漂移。工程上判断 λ 是否合适，看的是“法线项梯度范数与渲染项梯度范数的比值”在训练后期的走势，而不是看单项 loss 的绝对值。

二 · 法线扩散阶段的训练目标与采样

法线扩散是标准条件扩散：输入图像 I 作为条件，目标是从高斯噪声逐步去噪出法线图 n̂。训练目标是噪声预测的均方误差，写作 L_diff = E_{t,x₀,ε}[‖ε − ε_θ(x_t, t, I)‖²]，其中 x_t 是第 t 步加噪后的法线图，ε 是注入的真实噪声，ε_θ 是网络预测。条件 I 通过交叉注意力或拼接注入，具体形式论文未展开，但机制上必须保证图像特征在每一步去噪都可访问——否则早期步（高噪声）会失去几何锚点，采样出与输入无关的法线。

采样阶段的关键变量是步数与采样器。扩散采样是串行的：每一步都要跑一次网络前向，步数直接乘以单步延迟。这就是论文所说“推理数秒到数十秒”的主要成本来源之一。步数太少，法线图高频区域（边缘、细小凸起）去噪不充分，出现块状伪影；步数太多，收益递减但延迟线性增长。工程上的判断是：在验证集上画“步数–法线保真度”曲线，找拐点，而不是盲目堆步数。

这里有一个容易被忽略的失败模式：法线图的值域约束。法线是单位向量，三个通道必须满足 n_x² + n_y² + n_z² = 1。扩散网络输出的是三个实数通道，如果不做归一化，采样结果会落在单位球外，几何阶段拿到的是“非法线”。常见做法是采样后逐像素归一化，但这会在法线接近退化（如正对相机的平面，n_z ≈ 1）时放大数值噪声。更稳的做法是在损失里加一项单位长度惩罚，或在网络输出端做参数化（如输出两个角度）。论文未给出具体选择，但这是训练配方里必须显式处理的细节。

另一个机制是条件强度。图像条件太强，扩散退化为确定性回归，法线变得平滑，高频细节丢失——这正好是论文要避免的“直接回归”问题；条件太弱，采样偏离输入图像，法线图与图像几何不一致，几何阶段会生成与图像无关的形状。这个平衡通过 classifier-free guidance 的缩放系数控制，是法线阶段的第二个关键旋钮。

三 · 几何表示与可微渲染的梯度路径

几何阶段的梯度要能从渲染法线 n 反传到几何参数，前提是几何表示可微且渲染可微。论文提到“法线条件的三平面/网格生成”，两种表示对应两条不同的梯度路径，代价不同。

三平面表示：几何被编码为三个正交平面上的特征图，查询任意 3D 点 p 时，把 p 投影到三个平面、双线性采样、拼接后过一个小 MLP 得到符号距离或占用值。渲染法线通过对符号距离场求梯度得到：n = ∇_p SDF(p) / ‖∇_p SDF(p)‖。这条路径的梯度要穿过“平面采样–MLP–SDF 梯度–归一化–渲染”整条链，计算图深，显存占用高。好处是分辨率可以靠平面特征图的分辨率调节，且拓扑不受限。

网格表示：顶点位置直接是优化变量，法线由面法线或顶点法线插值得到。梯度路径短，但拓扑固定，无法表达输入图像里未预见的孔洞或分支结构；且网格的离散化会引入法线不连续，在 L_geo 的第一项里表现为高频残差，训练时容易被误判为“细节”。

论文的消融包含“几何表示”，说明这个选择对结果有可测影响。工程判断是：如果目标是高保真细节且拓扑开放，三平面更合适，代价是显存与渲染时间；如果目标是快速出可编辑网格，网格表示更直接，代价是细节上限被拓扑锁死。可微渲染器的实现细节（是否用光栅化近似、是否对法线做平滑）会直接改变 L_geo 的梯度尺度，进而影响 λ 的最优值——换渲染器必须重新调 λ，这是复现时最常见的坑。

一个具体失败模式：可微渲染在 silhouette 边缘处的法线梯度不稳定，因为边缘像素的可见性在优化中会跳变。表现是训练 loss 在边缘区域震荡，几何出现“毛边”。常见缓解是对边缘像素降权，或用软可见性近似。论文未展开，但这是几何阶段训练配方里必须处理的系统代价。

四 · 训练配方与关键超参

论文的训练是“法线扩散 + 几何生成 + 纹理”三段，数据来自 Objaverse 与合成 CAD 数据。三段不是端到端联合训练，而是分阶段：先训法线扩散，再训几何生成（法线监督贯穿），最后训纹理。分阶段的好处是每段的失败可归因；代价是前段的误差无法被后段修正，误差传导在训练阶段就已固化。

关键超参可以列成一张表，每一项都对应一个可观测的失败模式：

超参作用位置调大/调小的后果
λ（渲染损失权重）L_geo调大：几何平滑、高频丢失；调小：法线噪声被立体化、轮廓漂移
扩散采样步数法线阶段推理调大：延迟线性增长、收益递减；调小：高频块状伪影
guidance 缩放法线阶段采样调大：法线贴近图像但过平滑；调小：法线偏离图像、几何不一致
三平面分辨率几何表示调大：细节上限高、显存与渲染时间上升；调小：细节被分辨率截断
法线单位长度惩罚权重法线阶段调大：法线合法但退化区噪声被压制过度；调小：非法线进入几何阶段

训练顺序上有一个机制性约束：几何阶段的法线监督用的是扩散阶段产出的 n̂，如果扩散阶段还在更新，n̂ 的分布会漂移，几何阶段的目标就变成移动靶。所以几何阶段必须在扩散阶段冻结后训练，或者至少用固定的教师法线。这是“法线监督贯穿几何阶段”能稳定工作的前提。

数据配比是另一个不写在公式里但影响很大的旋钮。Objaverse 提供真实扫描/ authored 资产，合成 CAD 数据提供干净的几何与精确法线。合成数据的法线是解析的、无噪声，真实数据的法线带扫描噪声。如果合成数据占比过高，几何阶段学到的是“理想法线→理想几何”的映射，遇到扩散阶段带噪声的法线就崩；如果真实数据占比过高，法线噪声被当作信号学进去，输出几何出现高频抖动。论文未给出配比数字，但定性上这是训练配方必须显式控制的变量。

五 · 数值玩具例子：一次 L_geo 的前向与梯度

为了看清梯度怎么流，构造一个一维玩具：几何是一个高度场 h(x)，只有一个参数 θ，h(x) = θ·x。法线由高度场导数得到：n(x) = normalize(−θ, 1)，即法线的水平分量随 θ 变化。设扩散阶段给出的目标法线在采样点 x=1 处为 n̂ = normalize(−0.5, 1)，对应“真值” θ* = 0.5。

法线项：‖n̂ − n(θ)‖²。当 θ = 0（平面），n = normalize(0,1) = (0,1)，残差为 (−0.5/√1.25)² + (1/√1.25 − 1)²，数值上约 0.2 + 0.006 ≈ 0.206。梯度对 θ 的符号：增大 θ 会让 n 的水平分量变负、靠近 n̂，所以法线项把 θ 往 0.5 推。这是“法线桥接”在最小尺度上的机制：法线项直接给出朝向的梯度，不需要颜色监督。

渲染项：假设颜色损失在 θ 偏离某个值时上升，比如 L_render = (θ − 0.2)²，它把 θ 往 0.2 拉。取 λ = 1，总梯度在 θ 处是两项梯度之和。在 θ = 0 时，法线项梯度指向增大 θ，渲染项梯度指向增大 θ（因为 0 < 0.2），两者同向，θ 上升；在 θ = 0.4 时，法线项仍指向 0.5，渲染项指向 0.2，两者反向，平衡点落在中间——具体位置由两项梯度的相对斜率决定。这个玩具说明：λ 不是“细节 vs 平滑”的抽象开关，它直接移动平衡点；法线项越陡（法线残差对 θ 的导数越大），平衡点越靠近法线目标。

采样层面：扩散阶段在 x=1 处采样出的 n̂ 本身带噪声。若 n̂ 的水平分量在 −0.5 附近抖动 ±0.1，玩具里的平衡点也随之抖动，几何的 θ 在多次采样间不稳定。这就是“误差传导”的数值形态：法线阶段的采样方差直接变成几何阶段的参数方差，且没有机制在几何阶段把它平均掉——因为几何阶段是确定性的，一次采样对应一个输出。工程上要压这个方差，只能在前段加采样步数或做多采样平均，代价是延迟。

把玩具放大到真实规模：三平面分辨率决定法线项能在多细的尺度上给出梯度。分辨率不足时，高频法线残差被双线性采样抹平，法线项对细节的梯度趋近于零，几何阶段实际上只优化低频——这与“直接回归过平滑”的失败模式在梯度层面是同一件事。所以分辨率不是画质选项，它是法线桥接能否传递高频的带宽上限。
