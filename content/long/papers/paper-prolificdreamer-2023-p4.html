一 · 评测协议：没有 3D 训练集时，证据从哪里来

ProlificDreamer 的实验部分首先要回答一个方法论问题：文生 3D 的优化式方法并不在某个 3D 数据集上训练，因此不存在传统意义上的「训练集/验证集/测试集」划分。论文明确把数据集一项标为「无 3D 训练集」，这意味着所有证据都必须来自推理侧的评测协议：给定一组文本提示，逐条优化出一个 3D 资产，再对这些资产做人工与自动评分。这一设定决定了实验设计的重心不在数据规模，而在提示集的覆盖度、评分维度与基线可比性。

具体机制上，评测被拆成两条并行通道。第一条是用户偏好研究：把同一提示下由不同方法生成的渲染结果并排呈现给受试者，让其选择更真实、更贴合文本、更多样的一项。第二条是自动指标：用 CLIP 分数衡量渲染图与文本的语义对齐，并辅以对多视图一致性与纹理质量的定性检查。两条通道的分工是明确的——CLIP 分数给出可复现的排序信号，用户偏好则捕捉 CLIP 难以刻画的真实感与「像同一个物体」的整体判断。论文报告的结论是用户偏好与 CLIP 分数均显著优于 SDS，多样性更好，纹理更真实；这里不引用具体数值，因为给定事实中并未给出。

这套协议的系统代价在于评测本身极其昂贵。每个提示都要跑完整的优化流程，而单资产优化需要数小时量级，因此提示集规模不可能像 2D 生成那样动辄上千。样本量小带来的直接后果是统计功效有限：用户偏好研究中的 pairwise 比较虽然直观，但在提示数与受试者数都受限时，置信区间的宽度不可忽略。失败模式也很典型——若提示集偏向某类物体（例如以动物或载具为主），则结论容易高估方法在开放词汇上的泛化；反之若提示过于刁钻，则所有基线都塌陷，区分度消失。工程判断是：读这类论文的实验章节时，应把「提示集构成」当作与指标同等重要的信息，而不是只看排名。

一个具体例子可以说明协议的必要性。考虑同一提示下 SDS 与 VSD 各自优化出的资产：SDS 的结果往往在单一视角下观感尚可，但换视角后出现纹理粘连与几何塌陷，而 VSD 的多视图一致性更好。若评测只取固定视角的 CLIP 分数，这一差异会被系统性低估；因此多视图渲染与用户偏好成为不可省略的环节。这也是为什么论文把「多样性更好」单列为结论——多样性只有在同一提示下采样多个资产并比较其差异时才能被观测到，单资产单视角的指标对此完全失明。

二 · 基线选择：为什么必须与 SDS 本身对照

论文列出的基线是 DreamFusion、Magic3D 与 SDS。这三者的关系需要拆开看：DreamFusion 与 Magic3D 是完整的系统实现，前者以 NeRF 为主体、后者引入两阶段（粗到细）与网格精修；而 SDS 是它们共享的蒸馏目标。把 SDS 单列为基线，等于把「目标函数」与「系统实现」解耦，从而把性能差异归因到蒸馏目标本身，而不是归因到 NeRF 表示、网格精修或渲染分辨率等工程细节。

这一设计的机制含义是：VSD 与 SDS 的差别只在梯度项的第二项——SDS 用单一高斯近似渲染分布，VSD 用粒子 LoRA 估计其得分。因此若 VSD 在相同 3D 表示、相同渲染器、相同主扩散模型下稳定优于 SDS，则提升可以被归因于分布匹配这一改动，而非其他变量。公式上，两者共享同一外层结构：

$$\nabla_\theta\mathcal{L}=\mathbb{E}\!\left[w(t)\big(\epsilon_\phi(x_t;y,t)-\epsilon_{\text{particle}}(x_t;c,t)\big)\frac{\partial x}{\partial\theta}\right]$$

差别在于第二项的估计器：SDS 把它固定为对噪声的解析近似，VSD 则用一个随渲染图在线训练的 LoRA 去逼近。消融实验正是围绕这一项展开的，后文会具体说明。

基线对照的系统代价在于复现成本。DreamFusion 与 Magic3D 各自有不同的渲染分辨率、不同的 NeRF 实现与不同的阶段划分，直接比较原始论文数字并不可靠，因此论文需要在自己的代码基线上重跑 SDS 作为主对照。这意味着实验章节的算力开销至少是「基线数 × 提示数 × 单资产数小时」的量级。失败模式是：若重跑的 SDS 基线调参不足，VSD 的相对优势会被高估；论文对此的处理是把 SDS 作为同一框架内的可切换目标，使两者的超参尽量对齐，从而把差异压缩到目标函数这一维度上。

一个具体例子：在 NeRF 阶段，SDS 与 VSD 使用同一套冻结的 Stable Diffusion 与同一渲染分辨率，唯一变化是粒子项是否存在。此时若观察到 VSD 的渲染在过饱和度上明显减轻、纹理不再跨视图粘连，则这一观察可以直接对应到「粒子得分修正了单点高斯的偏差」这一机制解释，而不需要引入表示层面的解释。这正是基线选择服务于归因的体现。

三 · 主要结果：提升来自分布匹配而非表示升级

论文的主要结果可以概括为三点：真实感提升、多样性提升、文本对齐提升。三者并非独立，而是同一机制在不同侧面的表现。要讲清提升来自哪里，需要把 VSD 梯度拆成两项来看：第一项是冻结的预训练扩散模型给出的文本条件得分，它负责把渲染图拉向「符合提示的自然图像流形」；第二项是粒子 LoRA 给出的当前 3D 分布得分，它负责抵消「所有粒子都被拉向同一模式」的坍缩力。SDS 缺少第二项的可学习估计，等价于假设渲染分布是单点，于是第一项在每个粒子上的作用完全一致，粒子间的差异被系统性抹平。

多样性提升的机制由此可以直接推出：当第二项存在时，粒子得分随渲染图变化，梯度对不同粒子产生不同的修正，粒子得以在模式间分散。真实感提升的机制则稍间接：单点假设下，优化会把渲染图推向扩散模型条件分布的某个高密度点，但该点未必与 3D 几何自洽，于是出现过饱和与纹理粘连这类「看起来像但不像同一个物体」的伪影；分布匹配允许优化在多个自洽解之间分配质量，从而减轻单点过拟合。文本对齐的提升来自同一根源——当渲染分布不再坍缩到单一模式，提示中描述的多重属性（形状、材质、布局）才有机会被分别满足。

系统代价在这里表现为「提升不是免费的」。VSD 需要在线训练粒子 LoRA，这带来显存与时间的双重开销：显存上要同时容纳冻结的主扩散模型、粒子 LoRA 与 3D 表示及其渲染缓冲；时间上每个优化步都要额外做一次粒子去噪训练。论文明确指出代价是显存、时间与超参开销，且每资产优化需要数小时。失败模式是：当显存不足以支撑足够大的粒子 batch 或足够高的 LoRA rank 时，粒子得分估计的方差变大，VSD 退化为噪声较大的 SDS，提升幅度收窄——这一点在消融中会以粒子数与 rank 的形式被间接观测到。

一个具体例子能说明「提升来自哪里」的判别方式。假设在同一提示下分别用 SDS 与 VSD 各生成多个资产：SDS 的多个资产在整体构图与配色上高度相似，差异仅限于局部噪声；VSD 的多个资产在姿态、材质分配与背景布局上出现可辨的分化。这一现象无法用「渲染分辨率更高」或「网格更精细」解释，因为两者共享同一表示与同一阶段划分；它只能由梯度中第二项的存在来解释。这就是论文把多样性作为核心证据的原因——多样性是分布匹配最直接的观测窗口。

四 · 消融：粒子模型、粒子数、LoRA rank 与多阶段

消融的对象有四项：粒子模型、粒子数、LoRA rank、多阶段。这四项恰好对应 VSD 的三个可调结构维度与一个流程维度，因此消融的作用不是「证明每个模块都有用」，而是「标定每个维度的敏感度与失效边界」。

粒子模型是最核心的一项。去掉粒子模型，VSD 退化为 SDS——此时第二项不再由渲染图在线训练得到，而是回到单点近似。消融在此处的观测是：多样性首先塌陷，随后真实感与文本对齐的指标随之下降。这一顺序很重要，它说明多样性不是「附带好处」，而是真实感提升的前置条件：没有模式分散，优化就会重新落入单点过拟合的伪影区。机制上，粒子模型的作用是提供一个随当前 3D 分布变化的得分估计，使梯度成为「条件得分减去当前分布得分」的差，而不是「条件得分减去固定噪声」的差。

粒子数是第二个维度。粒子数决定了得分估计的样本量：粒子太少，粒子得分方差大，梯度噪声压过信号，VSD 接近 SDS 的行为；粒子太多，显存与每步时间线性上升，且粒子间的多样性若不足，得分估计反而被同一模式主导。论文把粒子数列为消融项，说明它是一个需要按显存预算调的超参，而不是越大越好。这里的系统代价是直接的：粒子数乘以每粒子的渲染与去噪开销，就是每步的额外成本；失败模式是显存溢出导致的 batch 缩减，进而使估计方差回升。

LoRA rank 是第三个维度，它控制粒子模型的容量。rank 过低，粒子模型无法刻画渲染分布的细节，得分估计偏向粗糙的高斯近似，VSD 向 SDS 回退；rank 过高，粒子模型容量足以记住单个粒子，估计过拟合到当前渲染图，梯度失去对分布的修正能力，同时显存与训练时间上升。因此 rank 存在一个由「估计精度」与「过拟合风险」共同约束的可行区间，消融的作用就是把这个区间标出来。多阶段则是流程维度：NeRF 阶段负责几何与粗纹理，网格精修阶段负责表面细节与可导出性；消融多阶段即去掉精修，观测到的是细节锐度与网格质量的下降，而非多样性或文本对齐的下降——这说明多阶段与 VSD 的分布匹配机制是正交的，前者解决的是表示与导出问题，后者解决的是蒸馏目标问题。

一个具体例子可以说明消融的读法。假设在固定提示集上，把粒子数从较大值降到较小值，同时保持 LoRA rank 不变：若观测到多资产差异收窄、过饱和回升，则说明粒子数不足导致得分估计方差过大，梯度被噪声主导；若此时再提高 rank，观测到单资产内部细节变多但多资产差异并未恢复，则说明 rank 提升补偿不了粒子数不足——因为过拟合的粒子模型给出的是对单个渲染图的精确拟合，而不是对分布的估计。这一组对照把「粒子数」与「rank」两个维度的作用区分开来，是消融设计的关键。

五 · 证据的边界：开销、超参与可复现性

实验章节的可信度不仅取决于结果方向，还取决于证据的边界是否被诚实标出。论文明确列出的局限是：开销大、超参多、每资产优化。这三条不是客套话，而是直接约束了实验结论的适用范围。

开销大的机制根源在于 VSD 的双重优化：每个训练步既要更新 3D 参数，又要用渲染图训练粒子 LoRA，而主扩散模型保持冻结。冻结主模型是为了保住预训练先验不被 3D 数据污染，代价是每步都要前向一次大模型；粒子 LoRA 的在线训练则再叠一层反向传播。两者相加，使单资产优化落在数小时量级。这一量级直接决定了实验的样本规模上限，也决定了用户偏好研究不可能做成大规模在线评测。失败模式是：当算力预算被压缩时，最先被削减的往往是粒子数与精修阶段，而这恰好是消融中敏感度最高的两个维度，于是复现者容易得到偏弱的 VSD，进而低估论文报告的提升幅度。

超参多是第二个边界。VSD 至少引入粒子数、LoRA rank、粒子学习率、粒子训练步数与 3D/粒子更新的相对节奏，这些超参与原有的 NeRF 学习率、阶段切换时机、CFG 尺度交织在一起。论文把这些列为消融项，本身就是在承认：结论依赖于超参落在可行区间内。工程判断是，读这类结果时应把「超参敏感度」视为结论的一部分——一个在宽超参区间内稳定的提升，与一个只在窄区间内出现的提升，证据强度完全不同。论文的消融给出了敏感度的方向，但没有给出完整的敏感度曲面，这是证据的边界所在。

可复现性方面，「无 3D 训练集」意味着不存在数据版本这一变量，但也意味着复现完全依赖代码、提示集与超参配置。提示集若未公开或未固定，用户偏好研究的结论就无法被独立复核；CLIP 分数则依赖具体的 CLIP 模型版本与渲染视角选择。这些细节不构成对结论方向的否定，但构成对结论强度的限定。一个具体例子：若复现者使用不同的渲染视角集合计算 CLIP 分数，多视图一致性好的方法会获得系统性优势，而这正是 VSD 的强项——因此视角选择本身就是一个需要被固定的实验变量，而不是可以随意处置的实现细节。

把这三条边界放在一起看，实验章节传递的工程判断是清晰的：VSD 的提升是机制性的、可归因的，但它的成本是结构性的、不可忽略的。分布匹配换来了真实感与多样性，代价是显存、时间与超参调校；这一交换在单资产优化范式下是划算的，因为质量是这一范式的核心诉求，而数小时的单资产成本在离线资产生产中是可控的。真正需要警惕的是把这一结论外推到对延迟敏感或对算力敏感的场景——在那里，粒子得分估计的开销会成为主导项，而分布匹配带来的质量收益未必能抵消它。

最后落在具体机制上：VSD 的实验证据之所以能支撑「分布匹配优于单点拟合」这一判断，是因为消融把粒子模型这一项单独拿掉后，观测到的退化顺序（多样性先塌、真实感后塌）与梯度分解的预测一致——第二项缺失导致粒子间差异被抹平，进而使第一项在每个粒子上作用相同，优化重新落入单点过拟合。这一致性是实验章节最硬的证据，也是后续工作把 VSD 作为强基线的原因。
