一 · 45 分钟教学节奏的骨架

给新工程师讲 EG3D，最容易犯的错误是按论文顺序讲：先讲背景，再讲方法，再讲实验。这条路径对读者不友好，因为听众在听到“三平面”之前，脑子里没有承载它的钩子。45 分钟的排法应当反过来：先用一个可感知的失败场景建立动机，再给表示，再给训练，最后给边界。具体切分是：0–8 分钟讲问题现场与旧表示的代价；8–20 分钟讲三平面表示与查询机制；20–30 分钟讲生成器、判别器与训练配方；30–38 分钟讲证据与消融怎么读；38–45 分钟讲误解澄清与自测。每一段都要留一个“可复述的句子”，让听众带走。

第一段的核心不是罗列历史，而是让听众亲手算一次显存。体素表示的存储量随分辨率立方增长：若边长从 128 升到 512，体素数量放大 64 倍，特征通道再乘上去，单卡根本放不下。纯隐式 MLP 路线则相反，参数量可控，但生成器要凭空产生高频细节，2D 卷积那套成熟的多尺度上采样机制用不上，训练慢且细节糊。把这两条路的代价并排写在白板上，听众自然接受“需要一个既省算力又能被 2D 卷积生成的 3D 表示”这个命题。这里要强调一句：EG3D 的贡献不是“更好的 3D 表示”，而是“把 3D 生成的计算负担从体素和大 MLP 转移到 2D 卷积”，这句话是整个讲座的主轴。

第二段讲表示。三平面是三个正交的 2D 特征平面，分别记为 T_xy、T_xz、T_yz，每张尺寸为 256×256×32。查询一个 3D 点 x=(x,y,z) 时，把它分别投影到三张平面上做双线性插值，得到三个特征向量，拼接后送入一个两层的小 MLP，输出该点的密度与 RGB。公式写成：

$$G(\mathbf{z})=\mathrm{TriPlane}_\theta(\mathbf{z}),\qquad F(\mathbf{x})=\mathrm{MLP}\!\left(\mathrm{interp}(T_{xy},\mathbf{x}),\mathrm{interp}(T_{xz},\mathbf{x}),\mathrm{interp}(T_{yz},\mathbf{x})\right)$$

讲这一段时必须让听众看清“谁承担了什么”。三平面由 StyleGAN2 主干用 2D 卷积生成，所以高频细节来自 2D 卷积的归纳偏置；MLP 只做逐点解码，容量很小，因此不承担生成负担。3D 一致性来自两个约束：三张平面描述的是同一个场，同一点在三张平面上的插值必须拼得上；2D 判别器在多个相机视角上打分，逼着渲染结果在视角间自洽。这里可以给一个伪代码思路：采样一批 3D 点，逐点做三次插值、拼接、过 MLP，得到密度与颜色，再沿射线做体渲染积分出像素。系统代价在于：每条射线要采样几十个点，每个点三次插值加一次小 MLP，渲染成本随采样数线性增长，分辨率越高越贵；这也是为什么训练要以天计而不是以小时计。

二 · 三个类比：把抽象表示钉在直觉上

第一个类比是“三张正交的透明胶片”。想象一个物体被三张互相垂直的半透明胶片夹住，每张胶片上印着从那个方向看过去的纹理信息。要知道空间中某一点长什么样，就把该点垂直投影到三张胶片上，各取一个读数，拼起来交给一个小解码器判断“这里是实心还是空心、是什么颜色”。这个类比的好处是直接解释了为什么三平面能省算力：存储从三维立方降成三张二维图，查询从查体素变成查三次二维表。它的局限也要当场说清：胶片是固定的，物体拓扑一旦超出胶片能表达的折叠关系，就会失真，这正是固定拓扑限制的直觉来源。

第二个类比是“三视图工程制图”。机械工程师用主视图、俯视图、侧视图描述零件，任何一点的位置都能由三视图的对应关系确定。三平面就是这个思路的可微版本：三视图不再是黑白线条，而是 32 通道的特征图，且由神经网络生成而非人手绘制。这个类比能帮听众理解“正交”二字的必要性——三个方向必须互相垂直且覆盖三个坐标轴，否则某些空间位置在三张图上投影重叠，信息无法区分。同时它也能引出失败模式：三视图对遮挡和内部结构表达弱，一个被外壳包住的复杂内腔，三视图上看不出层次，三平面同样会在密度场上糊掉。

第三个类比是“把 3D 问题编译成 2D 问题”。EG3D 的工程本质是一次编译：把“生成一个 3D 场”编译成“用 2D 卷积生成三张图，再加一个逐点小函数”。编译的收益是复用 StyleGAN2 在 2D 上积累的全部技巧——多尺度上采样、噪声注入、风格调制；代价是编译后丢失了三维卷积那种对局部立方邻域的归纳偏置，几何精度只能靠判别器和数据分布去逼。这个类比最适合讲给有编译器背景的工程师：他们会立刻追问“编译损失的语义是什么”，答案就是固定拓扑与有限几何精度。

三个类比要按顺序讲，每个不超过三分钟，讲完立刻回到公式，指出类比中哪个词对应公式里的哪一项。胶片类比对应三次 interp，三视图类比对应三个平面的正交性，编译类比对应“2D 卷积生成 + 小 MLP 解码”的分工。这样听众不会停留在比喻里，而是能把比喻当索引去查公式。

三 · 两个常见误解：必须在课上拆掉

误解一：“三平面是一个完整的 3D 表示，可以直接当网格用。”这是最常见的误读。三平面本身只是特征图，它不包含显式表面；要得到网格，必须先在密度场上跑 marching cubes 之类的等值面提取，而密度场的精度受限于三平面的分辨率与 MLP 容量。工程后果是：直接把三平面当资产交付，下游拿不到可编辑的拓扑，网格会出现碎片、孔洞和过度平滑。正确的说法是：三平面是生成与重建的中间表示，是“可查询的场”，不是“可交付的模型”。课上要举一个具体例子：ShapeNet 上生成的汽车和椅子视角一致，但若把密度场提成网格，细薄的椅腿和车镜容易断，这就是固定拓扑与有限几何精度的直接体现。

误解二：“有了 2D 判别器就不需要 3D 一致性约束了。”2D 判别器只在采样到的相机视角上打分，它约束的是“每个视角看起来像真图”，并不直接约束“不同视角描述同一个物体”。三平面共享结构提供了隐式的一致性：同一点在三张平面上的插值必须拼成同一个密度值，这个结构本身就把视角间的矛盾压下去了。但这不是无条件的：如果相机分布采样不足，或者姿态条件没给对，判别器可以在稀疏视角上被糊弄，出现视角间漂移。工程判断是：2D 判别器是必要但不充分条件，三平面共享是另一半。课上要强调消融里“2D vs 3D 判别器”的对比正是在检验这一点——3D 判别器直接看体数据，一致性更强但算力代价高，2D 判别器便宜但需要表示结构兜底。

这两个误解之所以危险，是因为它们都听起来“顺”。第一个把中间表示误当最终产物，会让下游管线在集成时崩溃；第二个把判别器的作用夸大，会让工程师在相机分布设计上偷懒，训练出的模型在训练视角外露馅。拆误解的方法不是反复声明，而是给可验证的断言：交付前三平面必须经过等值面提取并做水密性检查；验收时必须在训练相机分布之外的视角上做一致性抽查。

四 · 训练配方怎么讲才不空

讲训练时不要念超参表，而要讲“每个正则项在挡什么失败”。对抗训练的主线是：生成器渲染出图，与真实图像一起送进 2D 判别器；判别器是 2D CNN，配合相机分布采样，可加姿态条件。R1 正则约束判别器在真实样本附近的梯度，抑制判别器过强导致的训练震荡；路径长度正则约束生成器对隐变量的响应平滑度，避免隐空间出现陡峭跳变；相机分布采样决定模型见过哪些视角，直接决定视角一致性的覆盖范围。这三项各自对应一类失败：没有 R1，判别器赢太快，生成器梯度消失；没有路径长度正则，隐变量微调导致图像突变，插值不平滑；相机分布偏窄，模型在未见视角上几何崩坏。

可以给一个数值玩具例子说明渲染成本：假设每条射线采样 64 个点，每个点做 3 次双线性插值加一次两层 MLP，输出 512×512 的图像需要 512×512×64 次逐点查询。这个乘法一写出来，听众立刻明白为什么“把负担转移到 2D 卷积”是必要的：三平面的生成是一次 2D 卷积前向，成本与分辨率平方相关；而逐点查询的成本与像素数乘采样数相关，两者量级不同，前者可被 GPU 高效并行，后者是渲染时的固定开销。训练数天、单卡可跑这个事实也要讲，它说明方法在工程上是可复现的，不是靠算力堆出来的。

姿态条件值得单独讲一段。加上姿态条件后，生成器可以根据指定相机位姿出图，这让判别器的相机分布采样与生成器的条件输入对齐，减少“生成器不知道判别器在看哪个角度”的错配。消融里姿态条件的影响正是检验这个对齐是否必要。工程代价是：姿态条件把模型从无条件生成变成条件生成，采样时需要给位姿，接口复杂度上升；好处是视角可控，下游可以做指定视角的渲染。

五 · 五道自测题与判分要点

自测题不是考记忆，而是考“能不能把机制讲给别人听”。每道题给出判分要点，方便讲师当场判断听众是否真的懂了。

  • 题一：为什么三平面能把 3D 生成的算力从体素转移到 2D 卷积？判分要点：说出存储从立方降为三张二维图、生成由 StyleGAN2 的 2D 卷积承担、查询变成三次插值加小 MLP；能指出代价是固定拓扑与几何精度有限。
  • 题二：写出查询一个 3D 点的完整数据流。判分要点：投影到三平面、各自双线性插值、拼接、两层 MLP 输出密度与 RGB、沿射线体渲染积分；漏掉“拼接”或“体渲染”任一项算不完整。
  • 题三：2D 判别器与三平面共享各自负责哪一半的 3D 一致性？判分要点：判别器负责单视角真实感，三平面共享负责跨视角的结构自洽；能说出相机分布采样不足时判别器会被糊弄。
  • 题四：R1 正则、路径长度正则、相机分布采样分别挡什么失败？判分要点：分别对应判别器过强导致震荡、隐空间响应不平滑、未见视角几何崩坏；三项要一一对应，不能笼统说“稳定训练”。
  • 题五：三平面能不能直接当网格交付？判分要点：不能，必须做等值面提取；能举出细薄结构断裂的具体例子；能说出验收断言是水密性检查与分布外视角一致性抽查。

这五道题覆盖了表示、数据流、一致性分工、训练正则、交付边界五个层面，正好对应讲座的五段。讲师可以在每段结束时抛出对应题目，让听众用一句话回答，答不上来的地方就是下一段要补的地方。题目的顺序也是复述顺序：先表示后训练再边界，与 45 分钟的节奏一致。

六 · 把课讲成工程判断而非论文复述

最后十分钟要落到工程判断上。EG3D 的三平面后来成为前馈重建模型的标准中间表示，LRM、TripoSR 这类模型直接继承 triplane，只是把生成器从 StyleGAN2 换成图像条件 Transformer。这个事实的教学价值在于：它说明三平面的价值不在 GAN 本身，而在“表示与生成器解耦”。课上要让听众看清这个解耦点：三平面是一层接口，上游可以是隐变量生成器，也可以是图像条件编码器；下游可以是体渲染出图，也可以是等值面提取出网格。接口稳定，上下游可以各自替换，这是它能成为标准表示的原因。

与之对应，工程的验收断言也要围绕接口写。第一，三平面分辨率与通道数是否满足下游查询精度；第二，渲染出的多视角图在训练分布外是否自洽；第三，密度场提取的网格是否水密、细薄结构是否断裂；第四，相机分布与姿态条件的对齐是否在采样接口上落实。这四条断言不依赖具体实验数字，只依赖机制，因此可以在任何复现项目里直接使用。讲师要提醒听众：不要用 FID 单项指标替代这四条，FID 好不代表几何对，尤其在三平面这种几何精度有限的表示上。

课程收尾不要抒情，而要落在一个具体机制上：三平面的三次插值拼接是整套方法的信息瓶颈，所有几何精度问题最终都追溯到这三个 32 通道的二维表能承载多少空间信息。理解了这一点，听众再看到任何继承 triplane 的前馈重建模型，都能立刻问出正确的问题——它的三平面分辨率是多少、查询 MLP 多深、等值面提取在什么阈值上做。这三个问题就是这堂课真正要留下的东西。
