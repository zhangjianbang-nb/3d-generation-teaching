一 · 对比的坐标系：表示、监督、速度、显存

把 DreamGaussian 与同期方法放在一张表里比较，第一步不是看谁的 FID 更低，而是先把比较的维度拆开。文生 3D 系统的差异几乎全部来自四个正交选择：三维表示是什么、监督信号从哪里来、单资产优化需要多少步渲染、以及显存峰值由什么决定。DreamFusion 与 Magic3D 的第一阶段都用 NeRF 类隐式表示承载 SDS 梯度，区别在于 Magic3D 加了第二阶段在网格上做高分辨率精修；ProlificDreamer 则把监督从单点 SDS 换成粒子变分分数蒸馏（VSD），用一组粒子估计更平滑的分数场。DreamGaussian 的选择是把第一阶段整体换成 3DGS 显式表示，第二阶段换成从高斯密度提网格再在 UV 空间做 RGB 精修。这四个维度不是独立的：表示决定渲染代价，渲染代价决定每步能采多少视角，监督信号的质量又依赖视角数量与噪声水平。

用公式刻画这个耦合关系更清楚。SDS 梯度本质是对噪声预测残差做加权：

$$\nabla_{\theta}\mathcal{L}_{\mathrm{SDS}}=\mathbb{E}_{t,\epsilon}\left[w(t)\,(\epsilon_{\phi}(\mathbf{x}_{t};y,t)-\epsilon)\,\frac{\partial \mathbf{x}}{\partial \theta}\right]$$

其中 $\mathbf{x}=\mathrm{Render}(\mathcal{G})$ 是渲染图像，$\partial\mathbf{x}/\partial\theta$ 这一项由表示的可微渲染器给出。NeRF 的体渲染每像素要沿射线采样数十到上百个点，梯度要穿过整条采样链；3DGS 的光栅化把每个高斯投影成二维椭圆并做 alpha 混合，参与求导的图元数由可见高斯数决定，而不是由射线采样密度决定。这就是「渲染速度提高两个量级」的来源，也是 DreamGaussian 能把第一阶段压到 500 步的根本原因。代价同样来自这里：光栅化只对投影后的二维足迹负责，对三维拓扑没有全局约束，高斯可以漂浮、可以穿透、可以在视线外堆积，这些都不会被图像损失直接惩罚。

显存的账要分开算。NeRF 类方法的显存峰值通常出现在采样点缓存与自动微分图，随分辨率与采样数增长；3DGS 的显存峰值由高斯数量与每高斯的属性（位置、协方差、不透明度、球谐系数）决定，随致密化过程单调上升。DreamGaussian 在 500 步内做致密化，高斯数会快速膨胀，显存压力来自「点太多」而不是「采样太密」。这解释了为什么它的失败模式里有一类是多面问题与漂浮絮状物：致密化在缺乏多视角几何约束时会把噪声固化成图元。

具体例子：同一句提示词下，DreamFusion 的第一阶段要在每个优化步渲染一批视角，每视角每像素做体采样，单步耗时由采样数主导；DreamGaussian 的单步耗时由可见高斯数与分辨率主导，因此在 RTX 3090 上 500 步约 2 分钟成为可能。这不是同一算法的加速，而是换了计算对象。工程判断上，凡是「每步渲染开销主导」的管线，换显式表示收益最大；凡是「拓扑正确性主导」的管线，换显式表示会把问题从优化时间转移到后处理与修补。

二 · 与 DreamFusion 逐项对照：监督相同、承载不同

DreamFusion 与 DreamGaussian 的监督信号是同一个东西：预训练二维扩散模型的 SDS 梯度，提示词 $y$ 固定，随机时间步 $t$ 与噪声 $\epsilon$ 采样。差别只在 $\mathrm{Render}(\cdot)$ 的实现。DreamFusion 用 NeRF 的密度场与颜色场，渲染方程是沿射线的积分；DreamGaussian 用一组各向异性高斯，渲染是投影加排序加 alpha 混合。监督相同意味着两者的失败模式有重叠部分：都会出现「 Janus 问题」（多面神），即同一条提示词在不同视角被解释成不同语义，因为 SDS 只保证单视角似然，不保证跨视角一致性。

重叠之外是分化。DreamFusion 的 NeRF 密度场是连续的，提取网格需要 marching cubes，等值面阈值一改拓扑就变，且体渲染的模糊性会让密度场在表面附近弥散，提取出的网格偏「胖」。DreamGaussian 的提取用局部密度（local density）而不是全局等值面，把每个高斯的不透明度与邻域累积作为占据判据，再走网格化。这个机制让提取对阈值更敏感：阈值低则絮状物被保留，阈值高则薄结构（如细杆、叶片）被削掉。消融里专门有一项是网格提取阈值，说明作者清楚这是质量分水岭。

速度对照要给出口径。DreamFusion 每资产几十分钟到数小时，瓶颈是体渲染每步采样太多点；DreamGaussian 第一阶段 500 步约 2 分钟，第二阶段约 1 分钟，总计约 2 分钟量级。这里不能把「快一个量级」直接套到 DreamFusion 头上，因为论文给出的对照基准是 Magic3D：速度比 Magic3D 快一个量级。对 DreamFusion 的加速倍数取决于其采样配置，定性上更大。工程上要警惕的是把不同硬件、不同分辨率、不同视角批大小下的墙钟时间直接相除，这种比较没有意义。

显存对照同样要拆。DreamFusion 的显存随射线采样数与批视角数增长，调大 batch 提升梯度质量但显存吃紧；DreamGaussian 的显存随高斯数增长，致密化阈值与致密化频率是真正的旋钮。一个具体失败模式：在高分辨率下对复杂提示词做 DreamGaussian，致密化把大量低不透明度高斯堆在物体外围，显存上升而视觉收益递减，此时应当调高致密化梯度阈值而不是加步数。这类调参在 NeRF 管线里不存在对应物，是显式表示带来的新运维面。

三 · 与 Magic3D 对照：两阶段结构的同与异

Magic3D 与 DreamGaussian 都是两阶段，这是最容易被误读为「同类」的地方。Magic3D 的第一阶段是低分辨率 NeRF 上的 SDS，第二阶段把密度场提成网格，在更高分辨率下用可微渲染做精修，监督仍是扩散先验（对网格渲染图加噪后求 SDS）。DreamGaussian 的第二阶段也是提网格加可微渲染，但监督换成了 RGB 损失：在 UV 空间对提取出的网格做纹理优化，用参考视角的渲染结果与目标图像做像素级回归，不再调用扩散模型。这个差别决定了第二阶段的行为：Magic3D 的第二阶段仍在「想象」细节，能把低分辨率阶段缺失的高频结构补出来，但也把扩散模型的语义漂移带进高分辨率；DreamGaussian 的第二阶段只做「贴合」，把已有纹理投影并修补接缝，速度快（约 1 分钟）但不会凭空生成新几何。

用伪代码把两条第二阶段的控制流并排：

  • Magic3D 阶段二：mesh ← extract(NeRF); for step: img ← diffrender(mesh, cam); x_t ← add_noise(img, t); loss ← SDS(x_t, y); update(mesh 或纹理参数)。
  • DreamGaussian 阶段二：mesh ← extract(gaussians, local_density, threshold); uv ← unwrap(mesh); for step: img ← diffrender(mesh, uv_tex, cam); loss ← ‖img − target‖; update(uv_tex)。

结构上的同构掩盖了监督上的异构。这带来一个具体的系统代价：DreamGaussian 的第二阶段质量上限由第一阶段决定，第一阶段的高斯如果已经把细节糊掉，UV 精修只能把糊掉的部分摊平，不能恢复。反过来，Magic3D 的第二阶段可以纠正第一阶段的语义错误，但也可能引入新的多面问题，因为高分辨率 SDS 同样缺乏跨视角约束。工程判断：如果管线目标是「稳定出可用资产」，RGB 精修的第二阶段更可控，失败可预测；如果目标是「极限质量」，扩散监督的第二阶段上限更高但方差更大。

速度对照要按阶段拆。Magic3D 的两阶段都跑扩散监督，第二阶段步数与分辨率都不低，总时间在几十分钟量级；DreamGaussian 第一阶段 500 步、第二阶段约 1 分钟，总时间约 2 分钟，比 Magic3D 快一个量级。显存上，Magic3D 第二阶段在高分辨率网格上做可微渲染，光栅化缓冲随分辨率平方增长；DreamGaussian 第二阶段在 UV 空间做纹理回归，显存主要吃 UV 图分辨率与网格面数，通常更温和。一个具体失败模式：UV 展开在拓扑复杂时会产生大量接缝与拉伸，RGB 损失在接缝处没有跨边界梯度，精修后接缝可见；这是 DreamGaussian 拓扑一般这一局限的直接来源之一。

四 · 与 ProlificDreamer 对照：监督强度换时间

ProlificDreamer 的核心不是换表示，而是换监督：用粒子变分分数蒸馏（VSD）替代 SDS。VSD 维护一组粒子（可理解为对同一三维场景的多个噪声样本），用一个可学习的分数网络拟合这些粒子的分布，再对渲染图做蒸馏。相比 SDS 的单点噪声残差，VSD 的梯度方差更低、对高 CFG 尺度的过饱和更耐受，因此能产出更细的纹理与更少的「过度平滑」。代价是每步要更新粒子集与分数网络，计算量与显存都显著高于 SDS。

对照到 DreamGaussian，这是「监督强度换时间」的典型取舍。DreamGaussian 用最便宜的 SDS 加最便宜的显式渲染，把时间压到分钟级；ProlificDreamer 用更贵的监督换质量，时间回到小时级。两者不在同一 Pareto 前沿点上，比较谁「更好」没有意义，比较的是在给定时间预算下谁能交付可用资产。具体机制上，VSD 的粒子集相当于在优化过程中做了隐式的多视角一致性正则，缓解 Janus 问题；DreamGaussian 没有这层正则，只能靠 SDS 的随机视角采样碰运气，因此多面问题在其失败模式里被明确列出。

显存对照：ProlificDreamer 的显存峰值由粒子数、分数网络与扩散模型前向共同决定，通常需要较大显存；DreamGaussian 的显存峰值由高斯数与渲染分辨率决定，在消费级卡上可跑。一个具体例子：同一提示词下，DreamGaussian 能在单卡上几分钟出结果并允许快速试错多次，ProlificDreamer 单次运行时间长到不适合交互式迭代。工程判断：前期概念探索用 DreamGaussian 扫提示词与种子，锁定方向后再用重监督方法做终稿，这是把两者放进同一流水线而不是二选一的正确用法。

失败模式的差异也来自监督。ProlificDreamer 的典型失败是「过度细节」与几何不闭合，因为 VSD 鼓励纹理锐利但对拓扑无约束；DreamGaussian 的典型失败是纹理糊、薄结构丢失、漂浮絮状物。前者是「想太多」，后者是「看不清」。修复路径不同：前者要加几何正则或后处理重拓扑，后者要提高第一阶段分辨率或换更强的二维先验。

五 · 与前馈后继对照：LGM、GS-LRM 把优化换成推理

DreamGaussian 是「显式表示 + 快速优化」路线的代表，它的直接后继是前馈高斯模型：LGM 与 GS-LRM 不再对每个资产做 SDS 优化，而是用网络一次前向直接预测高斯参数。这把「分钟级」进一步压到「秒级」，但代价是训练数据依赖：前馈模型需要多视角图像或视频监督，而 DreamGaussian 明确不需要 3D 训练集，只用预训练二维扩散模型。这是两条路线的根本分野：优化路线把先验放在二维扩散模型里，前馈路线把先验蒸馏进三维预测网络。

机制上，前馈模型输入是图像或图像序列，输出是像素对齐的高斯（pixel-aligned Gaussians），每个像素预测一个高斯原语，深度与协方差由网络回归。这解决了 DreamGaussian 的两个痛点：一是多面问题，因为输入多视角图像天然提供跨视角约束；二是拓扑，因为像素对齐的高斯与输入视角的可见表面对应，不会在视线外堆积。但它引入了新失败模式：输入视角覆盖不足时，背面与遮挡区域由网络「猜」，会出现拉伸与空洞；训练分布外的物体类别泛化差。

速度与显存对照要换口径。DreamGaussian 的时间花在 500 步 SDS 加 1 分钟精修，显存花在高斯数与渲染；前馈模型的时间花在一次前向，显存花在骨干网络与输出高斯数（像素数乘以每像素高斯数）。具体例子：给定同一组多视角输入，前馈模型一次前向即可出高斯，无需逐资产优化；DreamGaussian 则要从随机点云开始跑完整 SDS，且每次换提示词都要重跑。工程判断：有多视角采集条件时前馈路线在速度与一致性上占优；只有文本或单图输入时，优化路线仍是可行路径，DreamGaussian 的 2 分钟量级是这条路径的实用下限之一。

继承关系上，DreamGaussian 证明了两件事：3DGS 可以作为 SDS 的承载表示而不崩溃；高斯提网格加 UV 精修的两阶段可以在分钟级内闭合。这两点被后继工作直接继承，前馈模型输出的高斯同样需要提网格与纹理化才能进下游管线，DreamGaussian 的第二阶段思路在其中反复出现。它的局限（质量有限、拓扑一般、多面问题）则被前馈路线用数据监督部分解决，但没有被完全消除。

读表要点：DreamGaussian 的定位是「时间预算紧、输入只有文本、可接受质量略低但可用」的格子。它的速度优势不是免费的，代价写在质量与拓扑两列。Magic3D 与 DreamFusion 占据「时间充裕、质量优先」的格子，ProlificDreamer 占据「质量最优先、不计时间」的格子，前馈模型占据「有多视角输入、要秒级」的格子。任何跨格子的比较都要先声明约束，否则会把不同 Pareto 点当成同一赛道的排名。

工程落地时还有一层：DreamGaussian 的两阶段可以拆开复用。第一阶段的高斯优化可以单独作为「快速几何草稿」生成器，第二阶段的 UV 精修可以接到任何高斯或网格输出上做纹理闭合。这种模块化是它在流水线里长期有价值的原因，而不是作为一个端到端黑盒去和重监督方法比质量。决策表最后一行应当记住：选方法不是选最强，是选约束匹配；DreamGaussian 在分钟级文本输入这一格上没有同期的等价替代，这正是它被反复引用为「显式表示 + 快速优化」代表的工程理由。
