一 · 目标函数的分解与三项的实际职责

SF3D 的总损失写成三项加权和，这个形式本身不新鲜，关键在于每一项监督什么、在哪一层施加、以及彼此之间如何争夺梯度预算。给定事实给出的形式是：

$$\mathcal{L}=\mathcal{L}_{\mathrm{geo}}+\lambda\mathcal{L}_{\mathrm{uv}}+\mu\mathcal{L}_{\mathrm{mat}},\qquad \mathcal{L}_{\mathrm{uv}}=\|\hat{T}(u,v)-T(u,v)\|^2$$

这里 \(\mathcal{L}_{\mathrm{geo}}\) 作用于网格/SDF 解码分支，约束的是隐式场到显式网格的几何一致性；\(\mathcal{L}_{\mathrm{uv}}\) 是 UV 空间上的纹理回归，\(\hat{T}(u,v)\) 是网络在 UV 参数域采样点 \((u,v)\) 处预测的纹素值，\(T(u,v)\) 是对应的监督纹素；\(\mathcal{L}_{\mathrm{mat}}\) 则覆盖材质与法线预测分支，把反照率、粗糙度、金属度一类参数与法线贴图拉向监督值。\(\lambda\) 与 \(\mu\) 不是装饰性系数，它们决定了「几何先收敛还是纹理先收敛」的时序：几何项在早期梯度中占主导，UV 项与材质项在网格拓扑稳定后才真正起作用。

机制上，UV 项与顶点色监督的根本差别在于梯度的作用对象。顶点色监督把颜色绑在顶点索引上，梯度只沿顶点位置回传，纹理分辨率被网格密度硬性封顶；UV 项把梯度回传到 UV 参数域上的纹素网格，同一块几何可以承载远高于顶点数的纹素密度，且梯度不经过拓扑结构。这就是为什么 UV 项必须显式写成参数域上的 L2，而不是在渲染图像上做感知损失——后者会把 UV 展开的误差和纹理误差混在一起，无法分离。

失败模式很具体：当 UV 展开出现接缝错位或面片翻转时，\(\mathcal{L}_{\mathrm{uv}}\) 的梯度会指向错误的参数域位置，网络会把纹素学到接缝的另一侧，表现为纹理在接缝处「渗色」。这类错误不会因为加大 \(\lambda\) 而消失，反而会被放大——加大权重只是让网络更快地拟合错误的对应关系。工程上的判断是：UV 项的有效性完全依赖展开质量，展开失败时这一项应当被降权或屏蔽，而不是调参硬扛。

具体例子：假设一个茶杯的网格有 2 万个顶点，UV 图集为 1024×1024。顶点色方案下颜色自由度约 2 万；UV 方案下纹素自由度约一百万，且每个纹素通过 \((u,v)\) 映射独立回传梯度。若展开把杯口一圈面片映射到了图集的错误象限，那么这一圈纹素的监督信号全部错位，损失值会居高不下，但梯度方向是系统性偏移的——这正是「UV 失败」作为局限被单独列出的原因。

二 · 变量的含义与参数域采样的实现路径

把公式里的符号逐个落地，才能看清训练时到底在算什么。\(\hat{T}\) 是纹理预测头输出的 UV 空间张量，其定义域是展开后的图集坐标；\(T\) 是监督纹理，来自训练资产的原始材质经同一套展开规则烘焙后的结果。\((u,v)\) 不是任意连续坐标，而是每个面片在 UV 图集上的重心坐标插值结果——采样点由网格面片决定，而非均匀网格采样。这意味着 \(\mathcal{L}_{\mathrm{uv}}\) 的实际计算是对每个可见面片取若干采样点，按面片面积加权求和。

伪代码思路如下：对每个训练样本，先由几何分支得到网格与面片到 UV 的映射 \(\phi\)；对每个面片 \(f\)，在其 UV 三角形内采样 \(k\) 个重心坐标点，得到 \((u_i,v_i)\)；用双线性插值从 \(\hat{T}\) 取预测值，从 \(T\) 取监督值；按面片面积 \(A_f\) 加权累加 L2。写成式子即 \(\mathcal{L}_{\mathrm{uv}}=\sum_f A_f \sum_i \|\hat{T}(u_i,v_i)-T(u_i,v_i)\|^2 / \sum_f A_f k\)。面积加权不是细节洁癖：不做加权时，UV 图集里占据大面积的面片与只占几个像素的面片获得同等梯度，小面片会被过度优化，大面片欠拟合，表现为大平面上出现低频色块。

采样密度 \(k\) 是一个真实的系统代价点。\(k\) 太小，纹素梯度稀疏，纹理出现高频噪点；\(k\) 太大，每个样本的 UV 项计算量线性上升，而 0.5 秒的推理预算意味着训练侧也不能无限堆采样。工程上的折中是按面片在 UV 图集中的像素覆盖数自适应决定 \(k\)，让每个纹素平均被采样常数次，而不是每个面片固定采样数。

另一个变量是 \(\mathcal{L}_{\mathrm{mat}}\) 里的法线监督。法线贴图与几何法线是两套东西：几何法线由网格位置决定，法线贴图是在 UV 空间里对几何法线的扰动。训练时若两者监督不一致——比如监督资产的法线贴图烘焙自高模，而几何分支只重建了低模——\(\mathcal{L}_{\mathrm{mat}}\) 会把法线贴图拉向高模细节，但几何项又把网格拉向低模，两项在法线方向上持续对抗。失败表现是渲染时高光位置随视角跳变，因为法线贴图与几何法线在切线空间里的基准不一致。这不是靠调 \(\mu\) 能解决的，属于监督数据本身的构造问题。

三 · 梯度路径与三项之间的耦合

三项损失的梯度并不共享同一条回传路径，这是理解训练稳定性的关键。\(\mathcal{L}_{\mathrm{geo}}\) 的梯度经过 SDF 解码器回传到单图编码器；\(\mathcal{L}_{\mathrm{uv}}\) 的梯度经过纹理预测头回传，但它依赖 \(\phi\) 提供的 UV 坐标，而 \(\phi\) 由几何分支的输出决定——所以 UV 项的梯度会间接穿过几何分支，尽管这条路径不被显式写出。\(\mathcal{L}_{\mathrm{mat}}\) 的梯度同时触及材质头和法线头，并在法线头上与几何项交汇。

这个耦合结构带来一个具体机制：训练早期几何尚未收敛时，\(\phi\) 是不稳定的，UV 坐标随网格形变而漂移，此时 \(\mathcal{L}_{\mathrm{uv}}\) 的梯度方向是噪声。若 \(\lambda\) 在早期就很大，纹理头会去拟合一个不断变化的参数域，结果是纹理模糊、接缝错乱。合理的配方是让 \(\lambda\) 随训练进程上升，或者在前若干步只训几何项。这不是玄学，而是梯度路径的拓扑决定的：UV 项的有效梯度必须以稳定的 \(\phi\) 为前提。

系统代价体现在显存与吞吐上。UV 项需要在每个面片上做插值采样，采样操作不可向量化到与纯卷积同等效率，实际训练中 UV 项的计算图比几何项大得多，激活值占用随图集分辨率平方增长。把图集从 512 提到 1024，UV 项的激活显存约变为四倍，这是训练配方里图集分辨率不能随便加的直接原因。

失败模式举例：若 \(\mathcal{L}_{\mathrm{mat}}\) 的权重 \(\mu\) 设置得使材质项在早期就压过几何项，网络会倾向于用一个「平坦但材质参数好看」的几何去降低总损失，因为平坦几何让法线贴图的监督更容易拟合。结果是重建出的网格缺乏凹凸，几何细节被材质项「买断」。这正是论文把「几何细节有限」列为局限的机制性来源之一——不是几何分支能力不足，而是联合训练中材质项对几何项的梯度挤压。

四 · 训练配方与关键超参的作用面

给定事实说明训练在 Objaverse 与内部资产上进行，监督是网格、UV、材质联合监督，并配合 delighting 数据增强。把这几件事拆成配方要素：数据侧的核心是「同一资产的多光照版本」，delighting 增强通过改变低频光照来迫使网络把反照率与光照分开；监督侧的核心是三路标签必须来自同一套 UV 展开规则，否则 \(\mathcal{L}_{\mathrm{uv}}\) 与 \(\mathcal{L}_{\mathrm{mat}}\) 的监督纹素在参数域上不对齐。

关键超参中，\(\lambda\) 与 \(\mu\) 的作用面已在上文说明；图集分辨率决定纹理上限与显存；采样密度 \(k\) 决定 UV 项梯度密度；delighting 增强的强度决定光照解耦的彻底程度。这里有一个容易被忽略的配方细节：delighting 增强若只改光照强度而不改光照方向，网络学到的只是「亮度归一化」，而非真正的反照率-光照分离。方向变化才会迫使网络在法线与反照率之间做出区分，因为不同方向的光照在同一个法线上产生不同的明暗分布。

表格给出各要素的作用面与失效表现，便于工程对照：

配方要素作用面设置不当的失效表现
几何项权重网格收敛速度与细节保留过低则网格粗糙，过高则压制材质项
UV 项权重 \(\lambda\)纹理在参数域的拟合强度早期过大导致纹理模糊与接缝渗色
材质项权重 \(\mu\)PBR 参数与法线贴图过大导致几何被「买断」变平
图集分辨率纹理上限、UV 项显存过高则训练吞吐骤降，过低则纹理糊
采样密度 \(k\)UV 项梯度密度过低则高频噪点，过高则计算量失控
delighting 增强反照率与光照分离只改强度则学成亮度归一化

系统代价还有一处：联合监督要求每个训练资产同时具备干净网格、合规 UV 与 PBR 材质，这类资产的获取成本远高于只有多视角图像的资产。内部产品图数据的存在正是为了补这个缺口，但也意味着材质真实感受限于内部资产库的覆盖范围——这是「材质真实感受数据限制」这一局限的直接来源，而非网络结构问题。

五 · 数值玩具例子：三项损失如何拉扯一个纹素

构造一个最小可算的例子。设某面片在 UV 图集上覆盖 4 个纹素，监督纹素值 \(T=[0.8,0.8,0.8,0.8]\)（灰白反照率），当前预测 \(\hat{T}=[0.5,0.5,0.5,0.5]\)。取 \(\lambda=1\)，则 \(\mathcal{L}_{\mathrm{uv}}=4\times(0.3)^2=0.36\)。若该面片的几何项当前为 \(\mathcal{L}_{\mathrm{geo}}=0.5\)，材质项 \(\mathcal{L}_{\mathrm{mat}}=0.2\)，取 \(\mu=0.5\)，总损失为 \(0.5+0.36+0.1=0.96\)。

现在假设 UV 展开把该面片映射到了错误象限，监督纹素实际应为 \([0.2,0.2,0.2,0.2]\)（深色），但网络读到的监督是错位后的 \([0.8,\dots]\)。此时 \(\mathcal{L}_{\mathrm{uv}}\) 仍为 0.36，梯度却指向把预测推向 0.8——网络在把一块本该深色的区域学成浅色。总损失看不出异常，因为数值上它与正确展开时完全相同。这就是 UV 失败在损失曲面上「隐形」的机制：损失值不区分对应关系的正确性，只区分数值差异。

再看材质项的拉扯。设该面片的几何法线与监督法线贴图在切线空间相差一个固定角度，\(\mathcal{L}_{\mathrm{mat}}\) 贡献 0.2。若把 \(\mu\) 从 0.5 提到 2，总损失中材质项变为 0.4，网络为降低它会把法线贴图拉向监督值，但几何项不变——梯度在法线方向上被材质项主导，几何分支收到的有效信号被稀释。数值上表现为：几何项损失下降变慢，网格细节停止增长，而材质项损失快速下降。工程判断是，当观察到「材质损失降而几何损失平」时，应当降 \(\mu\) 而非加训练步数。

最后看采样密度的数值效应。若 \(k=1\)，每个面片只采一个点，4 个纹素中只有 1 个获得梯度，其余 3 个纹素在本步不更新；若 \(k=4\)，四个纹素各得一次梯度，\(\mathcal{L}_{\mathrm{uv}}\) 的数值不变（仍是四点平均），但梯度覆盖完整。这说明 \(k\) 影响的是梯度的空间覆盖率而非损失值本身——损失值相同而收敛行为不同，是采样参数最容易被误判的地方。

六 · 从损失设计到推理预算的传导

训练配方的每一个选择都会传导到 0.5 秒的推理预算上。UV 项要求网络在参数域输出纹理，这意味着推理时必须先完成 UV 展开再生成纹理，展开步骤的耗时直接进入总预算；材质项要求同时输出反照率、粗糙度、金属度与法线贴图，多张图集的生成与打包是并行的但共享同一时间窗；delighting 在训练侧是数据增强，在推理侧则体现为网络已内化的分离能力，不额外增加一次前向。

传导的具体机制是：图集分辨率越高，纹理头的一次前向输出张量越大，0.5 秒内可完成的分辨率存在硬上限；采样密度只在训练侧消耗算力，不影响推理，但它决定了纹理头学到的纹素间相关性强度——\(k\) 过低的训练会让纹理头倾向于独立预测每个纹素，推理时缺乏空间一致性，表现为纹理块状伪影。这是一个训练参数影响推理质量的非对称传导。

工程判断落在联合监督的对齐成本上：三路监督必须共享同一套 UV 展开规则，这条约束使得数据管线的任何一处展开实现变更都会同时影响几何、UV、材质三项的监督正确性。换言之，SF3D 的损失设计把「展开正确性」变成了一个跨三项的全局前提，而不是某一项的局部问题。这也解释了为什么 UV 失败被列为独立局限：它不是某一项损失调参能修补的，而是整个联合监督体系的前置条件失效。
