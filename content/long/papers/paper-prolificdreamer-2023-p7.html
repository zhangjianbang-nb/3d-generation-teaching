一 · 对比维度先定死：表示、监督、速度、显存、失败模式

把 ProlificDreamer 与同期方法放在一张表上比较，最容易犯的错误是拿“论文里的最好一张图”对“另一篇论文的最差一张图”。工程上真正决定选型的是五个可测维度：3D 表示（NeRF、网格、隐式场加显式提取）、监督信号（SDS 单点、VSD 分布、或多阶段混合）、单资产优化时间、峰值显存、以及可复现的失败模式。这五项里，前三项由方法架构决定，后两项由实现细节与超参决定，必须分开讨论。

先明确对照组。DreamFusion 是 SDS 的原始形态：冻结的文本到图像扩散模型给出得分，3D 参数作为单点被拉向该得分的高密度区。Magic3D 在同一 SDS 目标上换了两阶段表示：先粗 NeRF，再转网格并用高分辨率扩散精修，本质仍是单点拟合，改进来自表示分辨率与第二阶段的重参数化。SDS 作为基线指的是同一目标在不同 3D 表示上的直接复现。ProlificDreamer 的 VSD 把 3D 参数视为分布 q(θ)，用粒子 LoRA 近似 q 的得分，梯度是“预训练扩散得分减粒子得分”。这四者的差别不在渲染器，而在监督项里有没有第二项。

监督项的差别可以用一个式子看清。SDS 的梯度只含冻结扩散模型的噪声预测误差，等价于把渲染图往条件分布的一个模态上拽；VSD 的梯度多减了一项粒子模型的预测：

$$\nabla_\theta\mathcal{L}_{\mathrm{VSD}}=\mathbb{E}\!\left[w(t)\big(\epsilon_\phi(x_t;y,t)-\epsilon_\psi(x_t;c,t)\big)\frac{\partial x}{\partial\theta}\right]$$

其中 ε_φ 是冻结主扩散模型在文本条件 y 下的噪声预测，ε_ψ 是粒子 LoRA 在渲染图条件 c 下的噪声预测。减号后面这一项是“当前 3D 分布自己的得分”，它把单点拉力变成分布匹配的拉力：当 q 已经覆盖某个模态时，粒子得分会抵消主模型在该处的过度拉力，梯度不再把样本继续往同一处挤。这就是多样性提升的机制来源，也是显存与时间开销的来源——多了一个要训练的模型，且它和 3D 参数交替更新。

速度与显存必须按阶段拆。NeRF 阶段每步要渲染多视角、过冻结扩散、再过粒子 LoRA 做去噪训练，显存里同时驻留主扩散权重、LoRA 权重、NeRF 网络与渲染缓冲；网格精修阶段换表示后，渲染分辨率提高，单步成本上升但收敛步数下降。论文给出的量级是“每资产数小时”，没有给出具体秒数，工程上应按“数小时每资产、单卡显存吃紧”来规划，而不是按“分钟级”规划。失败模式也按阶段分化：NeRF 阶段容易出现多面伪影与过饱和，网格阶段容易出现纹理粘连与几何-纹理错位。

二 · 表示与监督的耦合：为什么换表示不等于换监督

Magic3D 的对比价值在于它证明了一件事：把 NeRF 换成网格、把分辨率提上去，能在 SDS 框架内显著改善纹理细节，但不会改善多样性。原因是 SDS 的梯度里没有“当前分布”这一项，换表示只是改变了参数化，拉力的方向没变。工程上这意味着：如果你的痛点是“纹理糊”，优先换表示与提高渲染分辨率；如果你的痛点是“同一 prompt 出十个资产长得一样”，换表示无效，必须动监督项。

ProlificDreamer 的多阶段是表示与监督同时动。NeRF 阶段用 VSD 把粗几何与粗纹理拉到文本条件分布的覆盖区，网格阶段继续用 VSD 精修。这里有一个具体的机制耦合：粒子 LoRA 是在渲染图上训练的，渲染图的分辨率与视角分布随阶段变化，所以粒子模型必须跟着阶段走。若在网格阶段沿用 NeRF 阶段训好的 LoRA 而不继续更新，粒子得分与当前渲染分布失配，减号后面那一项变成有偏估计，梯度会把纹理往旧阶段的统计上拉，表现为精修阶段纹理“回退”到粗分辨率的样子。这是复现时最常见的隐性错误之一。

伪代码层面的交替更新可以写成：

  • 采样一个视角与时间步 t，渲染 x = render(θ, view)；
  • 对 x 加噪得 x_t，冻结主模型算 ε_φ(x_t; y, t)；
  • 粒子 LoRA 算 ε_ψ(x_t; c, t)，用去噪损失更新 ψ（粒子自己学当前渲染分布）；
  • 用 ε_φ − ε_ψ 乘 ∂x/∂θ 更新 θ（3D 参数）；
  • 进入下一阶段时重置或继续训练 ψ，并按新分辨率调整视角采样。

系统代价在这里显形：每一步要做两次前向（主模型与 LoRA）加一次渲染反向。相比 SDS 只做一次主模型前向，单步计算量约翻倍，显存多出 LoRA 权重与它的优化器状态。粒子数增多会进一步放大开销，因为粒子得分是对多个 LoRA 实例的聚合。消融里粒子数与 LoRA rank 都是敏感项：粒子太少，q 的近似退化为单点，VSD 趋近 SDS；rank 太低，粒子模型拟合不了渲染分布的细节，减号项变成噪声，梯度方差上升。

具体例子：同一 prompt 下，SDS 复现常出现所有样本共享同一视角的过饱和配色，纹理在物体背面粘连成一片；VSD 在粒子数足够时，样本间配色与材质分化，背面纹理不再复制正面。这个差别不来自渲染分辨率，而来自减号项抑制了主模型把样本往同一模态挤的拉力。反过来，若把粒子数降到极小，VSD 的输出会肉眼可见地退回 SDS 的形态——这正是消融要验证的因果链。

三 · 速度与显存：三档预算下的选型判断

把三个方法放进同一预算框架，判断会清晰很多。第一档是“分钟级、单卡显存有限、只要一个能看的资产”：SDS 或 DreamFusion 的直接复现是唯一可行项，VSD 的额外前向与 LoRA 状态会直接超预算。第二档是“小时级、可接受两阶段、痛点是纹理细节”：Magic3D 式的表示升级性价比最高，因为它的额外成本主要来自第二阶段的高分辨率渲染，不引入第二个可学习模型。第三档是“数小时、显存充足、痛点是多样性与文本对齐”：VSD 是唯一在监督项上动了刀的选项。

显存的构成要拆开算，不能只看权重。主扩散模型冻结但仍占权重与激活；粒子 LoRA 占权重、梯度与优化器状态；3D 表示（NeRF 网络或网格加纹理）占参数与渲染中间缓冲；反向传播经过渲染器时还要存视角相关的中间量。VSD 的峰值出现在“主模型前向 + LoRA 前向 + 渲染反向”同时活跃的步上。工程上降低峰值的可行手段是梯度检查点、降低单步渲染视角数、把粒子更新与 3D 更新分 micro-batch，但这些都会拉长时间。论文只给出“开销大、超参多、每资产优化数小时”的定性判断，没有给出显存数字，所以选型时应按“比 SDS 高一档显存、时间翻倍以上”做容量规划。

速度的另一面是收敛步数。VSD 的梯度方差比 SDS 低（因为减号项抵消了部分过度拉力），在粒子模型跟得上的前提下可以用更稳的步长，但每步更贵。净效果是总时间增加，而不是减少。这一点常被误读为“VSD 更慢所以更差”，实际是“用时间换分布覆盖”。若下游只需要单模态高质量资产，这笔交换不划算；若下游要做多样性采样或作为正则项，这笔交换是必要的。

失败模式与预算强相关。显存不足时常见的降级做法是减小粒子数或 rank，这直接把 VSD 拉回 SDS 的行为，表现为多样性消失但过饱和仍在；另一种降级是跳过网格阶段，只做 NeRF，结果是几何细节不足、纹理在高频处糊。两种降级都不会报错，只会让输出“看起来像 SDS”，所以验收断言必须包含多样性指标（同一 prompt 多次采样的 CLIP 分数方差或人工偏好），否则无法区分“VSD 生效”与“VSD 被降级成 SDS”。

四 · 失败模式的逐项对照与可观测信号

逐项对照失败模式，比对照成功案例更有工程价值。SDS 的典型失败是过饱和与纹理粘连：主模型把渲染图往条件分布的高密度点拉，单点参数无法表达多模态，结果颜色被推到极端、不同视角的纹理互相污染。可观测信号是同一 prompt 多次优化的输出高度相似、颜色直方图集中在两端。Magic3D 的典型失败在阶段切换：粗 NeRF 转网格时若提取阈值不当，细几何（如细杆、薄片）丢失，第二阶段的高分辨率扩散会把纹理画在错误的几何上，表现为纹理与轮廓错位。可观测信号是轮廓与纹理梯度不重合。

VSD 的失败模式更隐蔽，主要是超参敏感与粒子失配。粒子 LoRA 的学习率、更新频率、rank 与粒子数共同决定减号项是否是当前分布的无偏得分估计。学习率过高，粒子得分抖动，梯度方差上升，输出出现高频噪声；学习率过低，粒子跟不上 3D 参数的变化，减号项滞后，VSD 在早期近似 SDS、在后期突然反向拉扯，表现为训练中期纹理突变。粒子数与 rank 不足则退化为单点。可观测信号是训练曲线中 VSD 梯度范数的方差异常、以及粒子去噪损失不下降。

还有一个跨方法的共同失败：文本对齐漂移。三种方法都依赖冻结扩散模型的文本条件，若 prompt 含罕见组合或空间关系，主模型的得分本身有偏，SDS 会把偏差放大成过饱和，VSD 会把偏差分布化但不会纠正偏差本身。可观测信号是 CLIP 分数在训练后期不再上升甚至下降。工程判断是：文本对齐的上限由主扩散模型决定，VSD 改善的是覆盖与真实感，不是文本理解。把 VSD 当作“文本对齐修复器”是选型中最常见的误判。

五 · 决策表：按痛点与预算选方法

决策表要按“痛点优先、预算约束”排序，而不是按方法新旧排序。第一行判断痛点是纹理细节还是多样性：纹理细节优先考虑表示升级（Magic3D 式两阶段），多样性优先考虑监督升级（VSD）。第二行判断预算是分钟级还是小时级：分钟级只能选 SDS 系，小时级才谈得上 VSD。第三行判断显存是否够驻留第二个可学习模型：不够则 VSD 会被迫降级，降级后不如直接选 SDS 并接受其失败模式，至少行为可预测。

还有一条容易被忽略的判断：下游是否需要“每资产数小时”的离线优化。若下游是批量资产生成，VSD 的时间成本会线性放大，此时更合理的做法是把 VSD 用作教师或正则（论文影响里提到分布匹配思想影响了少步蒸馏与 3D 大模型的正则），而不是对每个资产跑完整优化。若下游是少量高价值资产，VSD 的数小时开销可以接受，且多样性带来的可选样本能摊薄人工筛选成本。

决策表的最后一列应写“验收断言”，因为三种方法在降级时都不会报错。SDS 系的断言是“单资产视觉合格”；Magic3D 系的断言是“阶段切换后细几何保留”；VSD 的断言必须包含“同一 prompt 多次采样的多样性指标”与“粒子去噪损失随训练下降”。没有这两条，无法证明 VSD 真的在跑分布匹配，而不是被超参或显存降级成了昂贵的 SDS。

把这张表落到具体机制上：选型的本质是判断你的瓶颈在参数化还是在监督项。参数化瓶颈（分辨率、几何表达）用表示升级解决，成本可控且行为可预测；监督项瓶颈（多模态覆盖、过饱和）只能动梯度里的减号项，代价是第二个可学习模型带来的显存、时间与超参敏感。ProlificDreamer 的工程判断因此不是“全面优于 SDS”，而是“在显存与时间预算允许、且痛点是分布覆盖时，用可观测的粒子损失与多样性指标换取真实感与多样性；预算不足时，降级路径会静默退回 SDS，必须用验收断言把这条降级路径挡住”。
