一 · 从单图到部件集合：一次前向的整体数据流

PartCrafter 的推理入口是一张 RGB 图像 \(I\)，出口是一个部件网格的并集 \(\mathcal{M}\)。中间不存在“先分割、再逐块重建”的串行阶段，整条链路是一次并行的组合式去噪。把数据流按张量形态拆开看，可以分成五步：图像条件编码、组合式潜变量初始化、联合去噪、逐部件解码、网格并集装配。理解这条链路的关键在于：图像只被编码一次，而潜变量按部件数 \(K\) 复制成 \(K\) 组，去噪过程在同一个 Transformer 里同时处理这 \(K\) 组 token。

第一步，图像条件通过预训练网格 DiT 已有的条件通路注入。论文继承预训练权重，因此图像编码器与条件注入方式沿用原模型，不额外引入一个图像分割网络。这一点决定了 PartCrafter 与两阶段方案的分野：图像特征是一份全局共享的条件，而不是被切成 \(K\) 份分别喂给 \(K\) 个重建器。第二步，初始化 \(K\) 组潜变量 \(\{\mathbf{z}^{(k)}\}_{k=1}^{K}\)，每组对应一个语义部件的 token 序列。\(K\) 从何而来是这套架构的第一个工程难点，论文把部件数作为生成目标的一部分，而不是外部给定。第三步是核心：所有 \(K\) 组 token 拼接进同一个注意力计算，但注意力被划分为局部与全局两种模式。第四步，去噪完成后每组潜变量独立送入解码器 \(\mathrm{Dec}\)，得到该部件的网格。第五步，把 \(K\) 个网格按各自的位置与尺度放回同一坐标系，取并集得到 \(\mathcal{M}\)。

$$\{\mathbf{z}^{(k)}\}_{k=1}^{K}\sim p_\theta(\cdot\mid I),\qquad \mathcal{M}=\bigcup_{k=1}^{K}\mathrm{Dec}(\mathbf{z}^{(k)})$$

这个公式的形式看似简单，但它把两件事压在了一起：采样分布 \(p_\theta\) 必须同时决定“有几个部件”和“每个部件长什么样”，而并集操作 \(\bigcup\) 隐含了各部件的空间对齐必须由模型自身保证，没有任何外部的配准或拼接后处理。工程上这意味着，如果两组潜变量解码出的网格在空间上错位，并集不会自动修复，只会留下缝隙或穿插。这是架构层面的代价，而不是训练不足导致的偶发失败。

举一个具体例子：输入一张带轮子的椅子图，理想输出是座面、靠背、四条腿、轮组等若干语义部件。数据流中，图像条件只编码一次，随后 \(K\) 组潜变量在同一个 DiT 里同步去噪；局部注意力让“腿”的 token 只与“腿”自己的 token 交互，避免腿的几何被座面的特征污染；全局注意力则在每个去噪步让所有部件 token 互相可见，从而把腿的长度、安装位置对齐到座面下沿。最终解码出的每个网格都是独立可编辑的对象，移动一条腿不会牵动其他部件。整个前向在数十秒量级完成，相比逐部件串行重建的累积误差路径，这是一次性闭合的。

二 · 组合式潜空间：每部件一组 token 的表征分工

组合式潜空间是 PartCrafter 区别于整体网格 DiT 的表征核心。整体网格生成把整个物体压进一组潜变量，几何与语义纠缠在一起，解码出的网格是一个不可分的整体；PartCrafter 则把潜变量按部件切成 \(K\) 组，每组 \(\mathbf{z}^{(k)}\) 是一个独立的 token 序列，承载一个语义部件的几何与外观。这种切分不是把整体潜变量简单分段，而是让每组 token 在去噪中拥有独立的噪声采样与独立的解码路径。

从表征分工看，每组 \(\mathbf{z}^{(k)}\) 需要编码三类信息：部件自身的形状（局部几何）、部件在整体中的位姿（相对位置与朝向）、以及部件的语义类别（是腿还是靠背）。这三类信息在同一组 token 内耦合，模型必须学会在去噪过程中把它们分离到不同的 token 位置上。局部注意力负责让形状信息在组内充分交互，全局注意力负责让位姿与语义信息跨组对齐。工程上一个直接后果是：组内 token 数决定了单个部件的几何分辨率上限，而组间通信带宽决定了整体一致性的精度。这两者共享同一个 Transformer 的注意力预算，因此存在明确的权衡——增大单部件 token 数会挤占跨部件对齐所需的注意力容量。

训练时，组合式潜空间的监督信号来自带部件标注的 3D 数据。每个部件的真值网格被独立编码成一组潜变量，作为该组 token 的去噪目标；同时，部件数 \(K\) 也作为生成目标被监督。这里的分工是：编码器把每个部件网格压成 token 序列，解码器 \(\mathrm{Dec}\) 把每组 token 还原成网格，而 DiT 主体学习的是在图像条件下联合去噪这 \(K\) 组 token 的分布。继承预训练 DiT 权重让主体已经具备单物体网格的先验，组合式改造只需要让注意力模式与 token 分组适配新的多组结构。

失败模式在这里很具体：如果某组 token 在去噪中“抢占”了本属于另一组的几何特征，解码后会出现两个部件形状雷同，或者一个部件吞并了相邻部件的体积。这类失败不会在损失曲线上表现为整体误差飙升，因为并集的总覆盖面积可能仍然接近真值，但语义归属已经错了。另一个代价是数据需求：组合式潜空间的监督要求每个训练样本都有部件级标注，而带部件标注的 3D 资产远少于整体网格资产，这直接限制了可训练数据的规模，也是论文把数据需求列为局限的原因。

三 · 局部与全局注意力：独立性与一致性的双约束

注意力模式的分工是整套架构里最需要工程直觉的部分。局部注意力把计算限制在同一组潜变量的 token 内部，即第 \(k\) 组 token 只与第 \(k\) 组 token 交互；全局注意力则允许所有 \(K\) 组 token 互相可见。两者在同一个去噪步内交替或并行施加，形成一对相互拉扯的约束：局部注意力保证部件几何不被其他部件污染，全局注意力保证部件之间的空间关系不漂移。

用伪代码思路描述一个去噪步的注意力组织：对每组 token 先做组内自注意力，得到该部件的独立几何表征；再把所有组的 token 拼成一个长序列做全局注意力，得到跨部件的位姿与语义对齐；最后把全局注意力的输出按组切回，与组内表征融合进入下一层。关键在于全局注意力的输出不能直接覆盖组内表征，否则局部独立性会被稀释；融合方式决定了独立性与一致性之间的平衡点。论文的消融把组合式潜空间、局部/全局注意力、部件数分别拆开验证，说明这三者是各自独立起作用的机制，而不是单一设计的副产品。

$$\mathbf{h}^{(k)}_{\text{local}}=\mathrm{Attn}(\mathbf{z}^{(k)}),\qquad \mathbf{h}_{\text{global}}=\mathrm{Attn}\Big(\bigoplus_{k=1}^{K}\mathbf{z}^{(k)}\Big),\qquad \mathbf{z}^{(k)}\leftarrow \mathrm{Fuse}\big(\mathbf{h}^{(k)}_{\text{local}},\ \mathbf{h}_{\text{global}}^{(k)}\big)$$

系统代价体现在注意力的计算量上。全局注意力的序列长度是 \(K\) 组 token 之和，计算复杂度随 \(K\) 与单组 token 数之积呈二次增长；当部件数较多时，全局注意力成为推理时延的主要来源。局部注意力虽然把组内计算隔离，但并没有减少总 token 数，它节省的是跨组干扰而非算力。工程判断上，这意味着 PartCrafter 的推理成本对部件数敏感：部件越多，全局注意力的二次项越重，数十秒的推理时延会随 \(K\) 上升而拉长。

具体例子可以说明双约束的必要性。生成一张多层架子：局部注意力让每一层的板面保持平整、厚度均匀，不被其他层的边缘特征干扰；全局注意力则让各层在竖直方向上等距排列、宽度对齐。如果去掉全局注意力，各层可能各自生成得很干净，但层间距随机、左右错位，并集后是一个歪斜的架子；如果去掉局部注意力，层与层之间会互相渗透，板面边缘出现不属于本层的凸起。两种失败模式方向相反，正好对应两个注意力机制各自负责的那一半约束。

四 · 逐部件解码与并集装配：从潜变量到可编辑网格

去噪结束后，每组潜变量 \(\mathbf{z}^{(k)}\) 独立送入解码器 \(\mathrm{Dec}\)。这里的“独立”是结构性的：解码器对每组 token 的处理不依赖其他组的 token，因此第 \(k\) 个部件的网格只由 \(\mathbf{z}^{(k)}\) 决定。这一设计直接支撑了可编辑性——修改某一组潜变量或替换某个部件的网格，不会改变其他部件的解码结果。解码器沿用预训练网格 DiT 的解码通路，输出的是网格表示而非体素或隐式场，因此每个部件拿到的是可直接进入下游管线（渲染、仿真、铰接绑定）的网格。

并集装配 \(\mathcal{M}=\bigcup_{k}\mathrm{Dec}(\mathbf{z}^{(k)})\) 看似只是把 \(K\) 个网格放进同一场景，实际承担了两个隐含任务：空间对齐与尺度归一。对齐由全局注意力在潜空间里完成，装配阶段不做配准；尺度同样在去噪中被约束到统一坐标系。工程上这意味着装配是一个“零后处理”的并集，好处是链路短、无累积误差，代价是模型必须自己学会精确的位姿，任何潜空间的位姿偏差都会原样出现在最终网格上。

失败模式在这里表现为缝隙与穿插。缝隙出现在两个本应接触的部件之间——例如腿的顶端与座面下沿之间留有可见空隙，原因是两组潜变量各自把边界收缩了一点，全局注意力没有把它们拉到精确接触。穿插则是相反方向：一个部件侵入另一个部件的体积，例如靠背嵌入座面内部。这两种失败的共同根源是并集操作不做布尔求交或碰撞消解，它只是把网格放在一起。论文把缝隙/穿插列为局限，说明这不是可以通过简单后处理消除的边角问题，而是组合式潜空间在位姿精度上的固有张力。

一个具体场景：生成一张带抽屉的柜子，抽屉面板与柜体框架是两个独立部件。解码后两者各自是干净网格，但并集时面板可能略微陷入框架，或者与框架之间留有一条细缝。对渲染来说这是可见瑕疵，对铰接动画来说则是更严重的问题——抽屉的滑动轴需要面板与框架精确配合，缝隙会让运动轨迹出现可见抖动。这正是逐部件解码带来的可编辑性红利与位姿精度代价并存的典型例子。

五 · 训练流程与继承策略：预训练权重的复用边界

训练流程的骨架是：在带部件标注的 3D 数据上，把每个部件的真值网格编码成一组潜变量，以图像为条件，让 DiT 学习联合去噪这 \(K\) 组 token；同时监督部件数 \(K\) 的预测。组合式去噪意味着一次前向覆盖全部 \(K\) 组，而不是对每个部件单独跑一次去噪。继承预训练 DiT 权重是这套流程能收敛的前提：主体已经具备单物体网格的几何先验，组合式改造只需让注意力分组与多组 token 结构适配，而不必从零学习网格分布。训练时间在数天量级，推理在数十秒量级，这个量级差反映了训练期要同时拟合部件分组、注意力模式与部件数预测三件事。

继承策略的边界需要说清楚：预训练权重提供的是单物体整体网格的先验，它并不包含“部件如何切分”的知识。因此组合式潜空间的引入不是简单地在原模型上改输入输出，而是要在注意力层面重新组织 token 的分组结构，并让模型学会把整体先验拆解到各组。局部/全局注意力的消融正是为了验证这一层改造是否真的必要——如果只加组合式潜变量而不改注意力，部件独立性与整体一致性无法同时成立。

训练期的失败模式集中在部件数预测上。部件数 \(K\) 是一个离散的、与图像内容强相关的量，模型在训练中同时学习它，导致两个方向的错误：预测偏多时，多出的组会解码出冗余或碎片化的网格，并集后表现为物体表面附着的小块；预测偏少时，缺失的部件不会被补出，并集后是一个残缺的物体。这类错误在训练损失上不易被单独定位，因为几何损失与部件数损失耦合在一起。论文把部件数易错列为局限，说明离散计数与连续几何的联合建模本身就是这套架构的薄弱环节。

数据需求的代价同样落在训练流程上。带部件标注的 3D 数据规模有限，而组合式潜空间的监督要求每个样本的部件切分与语义标签都准确；标注噪声会直接转化为潜空间分组的错误，进而表现为部件语义混淆。工程判断上，PartCrafter 的训练可行性高度依赖部件标注数据的质量与覆盖，这也是它作为“部件级 3D 生成起点”而非成熟生产方案的原因——架构把问题从“整体网格”推进到了“部件级结构”，但把数据与计数预测的负担留给了训练侧。
