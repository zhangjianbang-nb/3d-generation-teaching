一 · 失效条件：AMT 在哪些输入上会退化

AMT 的收益来自“相邻面共享边、只编码新顶点”这一前提。它把每个新面片压缩成“一条已存在的边 + 一个新顶点”的引用，因此序列长度近似减半。但这个前提在若干具体几何形态上不成立，工程上必须把这些形态列为拒绝或降级条件，而不是指望模型自行吸收。

第一类失效是面片不连通或连通性弱。若网格由大量孤立小岛组成（扫描重建的碎片、布尔运算后的残片、粒子化风格化模型），相邻面片之间没有共享边，AMT 无法复用任何已有边，每个面片退化为完整的顶点编码。此时序列长度回到接近逐面 token 的水平，而解码器仍按 AMT 的引用语义解析，容易产生悬空引用。判定机制很直接：对输入网格做一次并查集连通分量统计，若最大连通分量面数占比低于阈值，或平均每面共享边数接近零，就应判定 AMT 不适配。

第二类是高度非流形与自交输入。AMT 的序列化依赖“边”作为一等公民：一条边被两个面片共享时才能被引用。非流形边（被三个以上面片共享）、边界边、以及自交产生的重合但拓扑不连通的边，都会让“这条边是否已存在”的判定出现歧义。序列化器必须定义确定的边标识规则，否则同一几何边在不同遍历顺序下产生不同 token，训练分布被污染。系统代价是序列化器与解码器必须共享同一套边哈希约定，任何一侧的浮点量化差异都会造成引用失配。

第三类是细节密度超过序列预算。论文明确指出序列长度仍有限、细节存在上限。1600 面是在同等预算下的输出上限，而不是任意复杂度的通行证。对于需要数万面的硬表面机械模型或高曲率雕刻，AMT 只能给出粗粒度近似，继续增大预算会遭遇自回归的二次注意力代价与长序列误差累积。

一个具体例子：把一件由上百个独立铆钉与薄板组成的资产送入 AMT 管线。铆钉彼此不共享边，薄板之间多为边界边，序列化后有效压缩率极低，模型在铆钉区域反复输出孤立面片，解码后出现大量未焊接的裂缝。正确做法是先做连通分量拆分，对主体薄板使用 AMT，对铆钉改用实例化或贴图表达。

二 · 拓扑合法性：解码之后必须检查什么

AMT 保证的是 token 序列的语法，不保证输出网格的拓扑合法。自回归模型逐 token 采样，任何一步的边引用错误都会在解码阶段放大。工程验收必须把拓扑检查作为独立关卡，而不是信任模型输出。

解码器的还原逻辑可以概括为：维护一张“已存在边 → 端点”的表；遇到引用 token 时取出该边，遇到新顶点 token 时分配新顶点并登记新边。伪代码思路如下：对序列中每个面片 token 组，先解析边引用，若引用不在表中则标记为悬空引用并终止该面片；再解析新顶点，写入顶点数组；最后把新产生的两条边登记入表。任何一步失败都应记录失败类型而非静默跳过。

$$\text{valid}(\mathcal{M}')=\big[\forall e\in E(\mathcal{M}'):\ \deg(e)\in\{1,2\}\big]\ \wedge\ \big[\forall f\in F(\mathcal{M}'):\ \text{area}(f)>\epsilon\big]$$

上式给出最小验收断言：每条边度数为一（边界）或二（流形内部），每个面片面积非退化。实际工程还需追加三项：面片绕向一致性（相邻面共享边时端点顺序相反）、无自交（至少对薄壁与凹形区域做采样检测）、以及顶点索引不越界。绕向检查的机制是沿共享边比较两个面片的顶点序，若同向则法线翻转，渲染会出现黑面。

失败模式很具体：模型在收尾阶段为闭合孔洞而重复引用一条已饱和的边，解码器得到度数为三的非流形边。渲染器通常不报错，但布尔运算、碰撞检测与有限元网格化会直接失败。系统代价是必须引入修复环节：对度数超标的边做边分裂或面片删除，修复本身会改变面数，破坏“输出 1600 面”的预算承诺，因此修复策略要在预算内预留余量。

另一个例子是薄壁结构：两个面片几乎重合但顶点不共享，AMT 视其为两条独立边，解码后形成零厚度夹层。面积阈值与薄壁检测应放在拓扑检查之前，否则后续绕向检查会在退化面上产生无意义结果。

三 · 被谁继承：AMT 作为 tokenization 层的定位

论文的影响陈述很明确：AMT 成为网格自回归生成的标准 tokenization，后续 PartCrafter 等也借鉴其效率思想；它让“生成 1600 面网格”成为可用基线。理解这一定位的关键是区分“tokenization 层”与“生成模型层”：AMT 只规定面片如何被序列化与还原，不规定 Transformer 结构、条件编码方式或采样策略。因此它可以被替换进不同的生成骨架，也可以被更强的形状编码器包裹。

被继承的部分是效率思想而非具体实现：把“共享结构”从序列中剔除，只编码增量信息。这一原则可迁移到部件级生成——若一个部件由多个面片组成且内部共享边，部件级 tokenization 同样只编码新增边与顶点。PartCrafter 一类工作借鉴的正是这种“增量编码”视角，而非逐字复用 AMT 的边表格式。

被替代的风险来自两条路线。其一是隐式或半隐式表示路线：以符号距离场、高斯泼溅或神经隐式面提取替代显式面片序列，从根本上绕开序列长度约束，代价是提取阶段的可控性与拓扑合法性更差。其二是并行/非自回归面片生成路线：一次性预测面片集合而非逐 token 采样，能缓解长序列误差累积，但需要解决面片间共享边的全局一致性，这恰好是 AMT 用序列顺序换来的局部一致性。AMT 在这两条路线面前不是被否定，而是被降级为“需要显式拓扑时的基线”。

继承/替代路径继承的是什么不能照搬的部分
后续部件级生成工作增量编码、共享边复用边表格式与遍历顺序约定
隐式表示路线无序列预算与逐 token 解码假设
非自回归面片集合预测面片为单位的输出粒度依赖序列顺序的局部一致性机制

工程判断是：若下游需要显式、可编辑、拓扑可检查的网格，AMT 仍是合理基线；若下游只需要可渲染的外观或可微分的表面，隐式路线更省事，但要把拓扑检查的责任转移到提取后处理。

四 · 复现清单：从数据到推理的最小闭环

复现 AMT 管线的第一步不是训练，而是把序列化器与解码器写成可互相验证的一对。清单按依赖顺序排列，每项都附带验收断言。

  • 形状编码器接口：输入网格或点云，输出条件向量；断言是同一输入两次前向结果在容差内一致，且与面片顺序无关。
  • AMT 序列化器：按确定遍历顺序（如按面片索引与共享边优先级）生成 token 序列；断言是序列化解码回原网格后顶点数与面数完全一致，边集合一致。
  • 序列长度统计：对训练集抽样统计 AMT 与逐面 token 的长度比；断言是比值落在论文所述的约减半量级，偏离过大说明遍历顺序或边标识有问题。
  • 自回归训练配方：在 Objaverse 艺术家网格上训练，数天量级；断言是训练损失单调下降且验证集序列的 token 准确率不塌陷。
  • 推理与解码：逐 token 采样，遇到悬空引用即终止；断言是输出面数不超过预算上限，且拓扑检查通过率被记录而非忽略。
  • 拓扑验收：边度数、绕向、面积、自交四项检查；断言是四项全部通过才进入下游。

系统代价集中在序列化器与解码器的对偶性上：两者必须共享边哈希、浮点量化规则与遍历顺序。任何一处不一致都会让训练时的序列分布与推理时的解码语义错位，表现为模型“学会了语法但还原不出网格”。一个具体例子：序列化器用顶点坐标四舍五入到固定小数位做边标识，解码器却用原始浮点比较，训练集上损失正常，推理时大量边引用失配，输出面数远低于 1600。修复方式是让两侧调用同一个边标识函数，并在单元测试里做序列化—解码往返。

五 · 不能照搬的地方：预算、顺序与条件的边界

最容易被误用的是“1600 面”这个数字。它是同等预算下的输出上限，不是质量保证，也不是可随意放大的常数。把预算直接翻倍去追求更高细节，会同时放大自注意力的计算代价与长序列的误差累积；AMT 减半的是序列长度，不是把复杂度问题消解掉。工程上应把面数预算当作超参，与下游用途绑定：实时渲染资产与离线雕刻资产的预算不应相同。

第二个不能照搬的是遍历顺序假设。AMT 的压缩率依赖相邻面片在序列中彼此靠近，序列化器的遍历顺序实际上定义了“哪些边可以被复用”。若把序列化器换成按空间哈希排序，压缩率会下降，模型学到的局部依赖也会改变。跨数据集迁移时，必须重新验证遍历顺序与压缩率的匹配，而不能直接复用在一个数据集上训好的权重与顺序约定。

第三个是条件编码的边界。论文的架构包含形状编码器，但条件信号的类型（点云、体素、图像）会改变模型对“哪里需要更多面片”的判断。把在 Objaverse 艺术家网格上训练的权重直接用于扫描重建数据，输入分布差异会让模型在噪声区域过度分配面片，挤占主体预算。正确做法是固定序列化器与解码器，只微调形状编码器与输出头。

第四个是拓扑合法性的责任归属。AMT 不保证合法，后续工作也不一定继承检查环节。若把 AMT 嵌入一条自动化资产管线，拓扑检查必须作为硬门槛而非可选项；失败样本应回流为训练数据或触发降级到逐面 token 的保守路径。一个具体机制是：对拓扑检查失败的输出，回退到同一形状编码器下的逐面 token 解码分支，牺牲序列效率换取可还原性，并把该样本记入失败日志用于后续微调。
