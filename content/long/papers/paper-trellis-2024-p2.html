一 · 从多视图到 SLAT：编码器的数据流

TRELLIS 的输入不是点云，也不是体素网格，而是一组多视图图像（图生场景下由单图或少量图补足视图，文生场景下由文本先出图再进入同一管线）。编码器的任务是把这些 2D 观测转成结构化潜变量 SLAT：一组稀疏体素坐标，加上每个被激活体素上的局部特征向量。这一步决定了后续 3D DiT 能在什么粒度上做去噪。

具体机制上，多视图编码器先把每张视图过视觉主干提取 patch 级特征，再通过跨视图注意力把不同视角的对应关系对齐，随后把 2D 特征反投影到 3D 空间。反投影不是稠密地铺满整个体积，而是只在实际有表面证据的位置激活体素——某个体素如果在足够多的视图中被投影命中、且深度一致性通过阈值，才被保留。这样得到的是一份稀疏占据结构，体素数量随物体表面积而非包围盒体积增长，这是 SLAT 能在高分辨率下不炸显存的前提。

每个被激活体素携带一个局部特征，它聚合了来自多个视图的投影特征。可以把这一步写成加权聚合的思路：对体素 $v$，其特征为各视图投影特征的加权和，权重由视角可见性与深度置信度决定。

$$\mathbf{f}_v=\sum_{i\in \mathcal{V}(v)} w_{i,v}\,\phi_i\big(\pi_i(v)\big),\qquad \sum_i w_{i,v}=1$$

其中 $\mathcal{V}(v)$ 是能看到该体素的视图集合，$\pi_i$ 是第 $i$ 个视图的投影映射，$\phi_i$ 是该视图的特征图。权重 $w_{i,v}$ 通常与视线夹角、深度一致性挂钩，避免把背面或遮挡处的特征错误地混进来。

这一步的系统代价很直接：反投影与跨视图对齐是显存和带宽密集的，视图数增加会线性抬高编码成本；同时稀疏激活依赖深度估计的质量，深度噪声会让体素在表面附近“膨胀”成多层，抬高后续 DiT 的 token 数。一个具体例子是薄壁结构（比如叶片、纸张）：从少数视角看，前后表面投影到同一批体素上，深度置信度区分不开，编码器会把两层表面糊成一层，后续无论 DiT 多强都补不回这个几何细节。这是分辨率受限这一局限在编码端的根源之一。

二 · 3D DiT 与 rectified flow：潜空间里的去噪

拿到 SLAT 之后，生成的主体是 3D DiT 上的 rectified flow。这里的关键判断是：扩散不在体素原始值上做，也不在图像上做，而在“稀疏体素 + 局部特征”这个结构化潜空间里做。DiT 的 token 就是被激活的体素，每个 token 的输入是体素坐标编码加上局部特征，注意力在稀疏 token 集合上计算，而不是在稠密网格上计算。

rectified flow 的构造把噪声与数据之间拉成一条直线路径。给定数据潜变量 $\mathbf{z}_0$ 与噪声 $\epsilon$，时刻 $t$ 的插值状态与目标速度场为：

$$\mathbf{z}_{t}=\mathbf{z}_0+(1-t)\epsilon,\qquad v_\theta(\mathbf{z}_t,t)=\epsilon-\mathbf{z}_0,\qquad \mathcal{O}=\mathrm{Dec}(\mathbf{z}_0)$$

训练时网络 $v_\theta$ 回归这个常数速度，推理时从纯噪声出发沿速度场积分到 $t=0$ 得到 $\mathbf{z}_0$，再交给解码器。相比常规扩散的弯曲轨迹，直线路径在采样步数少的情况下误差更小，这是“速度兼顾”在方法层面的来源，而不是靠蒸馏或缓存技巧硬压出来的。

DiT 主干要在稀疏 token 上同时建模局部几何与全局形状，因此位置编码必须处理不规则坐标：体素坐标经过多尺度编码后与特征相加，注意力层则依赖稀疏索引来构造 token 间的连接。伪代码层面的前向可以概括为：读取稀疏坐标与特征，按坐标做位置编码，堆叠若干 DiT block（自注意力 + 条件注入 + 前馈），输出每个 token 的速度预测，再按稀疏索引散射回体素坐标。条件注入承载文本或图像条件，图生与文生共用同一主干，区别只在条件编码器的输出。

失败模式在这里体现为两点。其一是 token 预算：稀疏结构虽然省，但高分辨率下激活体素数仍然可观，注意力复杂度随 token 数增长，显存成为硬约束，这是“显存高”这一代价的直接来源。其二是稀疏性带来的连通性风险：如果编码阶段漏激活了某个区域，DiT 在去噪时没有任何 token 能“长”回那片区域，生成结果会出现空洞或断裂，且这种错误无法通过增加采样步数修复。一个具体例子是带细长把手的器物：把手在部分视角下被主体遮挡，编码时激活稀疏，DiT 采样后把手容易断开，解码出的网格在断口处出现非流形边。

三 · 三个解码头：同一潜变量的不同出口

SLAT 的统一性体现在解码端：同一个 $\mathbf{z}_0$ 可以走三条不同的出口，分别产出高斯、网格与辐射场。三个头共享潜变量，但各自的归纳偏置与代价不同，这正是“多格式输出”在工程上可用的原因。

解码头输出表示关键机制主要代价
高斯头3D Gaussian splats每个 token 回归一组高斯的中心偏移、尺度、旋转、不透明度与颜色渲染快，但几何是“软”的，边界不精确
网格头三角网格在体素局部特征上预测符号距离或有符号密度，再用可微等值面提取等值面提取带来拓扑与分辨率耦合
辐射场头神经辐射场以体素特征为条件查询密度与颜色渲染慢，适合做参考与监督信号

网格头的机制值得单独说清楚：它不是从潜变量直接回归顶点，而是在每个激活体素的局部邻域内定义一个隐式场（符号距离或有符号密度），再在规则网格上做等值面提取得到三角面片。可微性来自隐式场对特征的连续依赖，使得解码器可以与编码器联合训练，让潜变量学到“能被等值面读出几何”的结构。代价是分辨率耦合：等值面提取的网格精度受限于查询网格的步长，潜变量再精细，读出时也会被量化，这是“分辨率受限”在解码端的落点。

三个头共享同一个潜变量，意味着训练时三者可以互相约束：高斯头需要颜色与不透明度，辐射场头需要密度与视角相关颜色，网格头需要几何，这些监督信号共同塑造 $\mathbf{z}_0$，使其同时携带几何与外观信息。失败模式出现在头之间的不一致：如果网格头读出的表面与高斯头渲染出的边界偏差过大，说明潜变量在几何与外观之间没有对齐，常见于高光或透明材质——外观监督把特征拉向视角相关解释，几何监督又要求表面确定，两者在潜空间里打架。一个具体例子是金属器皿：高斯头能渲染出可信的高光，网格头却把高光处的微小起伏读成几何噪声，导致表面出现不该有的褶皱。

四 · 两阶段训练：先把潜空间立住，再学去噪

训练被切成两个阶段，这个切分不是工程上的随意拆分，而是因为两个阶段优化的对象根本不同。第一阶段训练 SLAT 编码器与三个解码器，目标是让“多视图 → SLAT → 多格式输出”这条链路自洽：编码出的潜变量要能被解码器还原成合理的高斯、网格与辐射场。第二阶段冻结或半冻结这条链路，训练 3D DiT 在潜空间里做 rectified flow，目标是让去噪轨迹的终点落在编码器产出的潜变量分布上。

第一阶段的核心是重建损失的多头组合：高斯头比对渲染图像，网格头比对隐式场或表面采样点，辐射场头比对渲染像素。这里有一个隐含的约束：三个头必须共用同一个潜变量，因此损失加权会决定潜变量偏向几何还是外观。加权不当会让某一头主导，另外两头退化成“能跑但不好用”。第二阶段则是在大规模数据（Objaverse 等）上做条件生成训练，条件编码器与 DiT 联合优化，数十 GPU 天的量级说明这一阶段的成本主要花在 token 数与数据规模上，而不是模型参数量上。

两阶段切分带来的系统代价是管线复杂：第一阶段与第二阶段之间的接口是潜变量分布，如果第一阶段后期改了编码器或损失权重，第二阶段的 DiT 就得重训，因为去噪网络拟合的是旧分布。这种耦合让迭代变慢，也让复现变得挑剔。失败模式是分布漂移：第一阶段若在某些类别上过拟合（比如 Objaverse 里占多数的日常器物），潜变量分布会偏向这些类别，第二阶段在这些类别上生成质量好，在长尾类别（比如极端比例的建筑或软体）上则明显退化。一个具体例子是生成带大量镂空的装饰件：第一阶段的重建损失在镂空处容易把稀疏激活抹平，潜变量学不到“空”的结构，第二阶段采样出的结果倾向于把镂空填实。

五 · 条件注入与图生/文生的共用主干

图生与文生不是两条管线，而是同一主干上的两种条件输入。图生路径把输入图像过编码器得到条件 token，文生路径先用文本到图像的模型产出参考图，再走同一套图像条件编码。条件通过交叉注意力注入 DiT 的每一层，与稀疏体素 token 做注意力交互，因此条件信息在去噪的每一步都能影响速度预测，而不是只在输入端拼接一次。

这个设计的机制优势在于条件与稀疏结构的对齐方式：交叉注意力让每个体素 token 自行决定关注条件的哪一部分，局部几何 token 关注图像的对应区域，全局形状 token 关注整体轮廓。代价是条件编码器的质量直接决定上限：如果文本到图像阶段生成的参考图视角不足或存在透视错误，反投影出的条件 token 会把错误带进 DiT，且这种错误在去噪中不会被纠正，只会被“合理化”成一致的几何。失败模式是多视角不一致：图生输入若只有单视图，编码器需要补足其他视角，补出的视角与真实视角在遮挡关系上冲突时，条件 token 会给出矛盾信号，采样结果在冲突区域出现双表面或悬空碎片。

一个具体例子是文生一个“带靠背的木质长椅”：文本先出图，图中靠背的镂空条数与透视角度是模糊的，条件 token 在靠背区域信号弱，DiT 采样时倾向于用训练分布里的常见靠背样式填补，结果是几何合理但与文本描述的具体条数不符。这不是采样步数能解决的问题，而是条件分辨率与条件编码器容量的问题。

六 · 消融指向的分工边界

论文的消融集中在三处：SLAT 分辨率、DiT 规模、解码器类型。这三者恰好对应管线里的三个分工边界，读消融时要看的是“哪个模块在为哪种能力买单”，而不是只看指标涨跌。

SLAT 分辨率决定几何细节的上限：体素越细，激活体素越多，token 数上升，DiT 的注意力成本与显存同步上升，但表面细节与薄壁结构的保真度改善。这是一条明确的权衡曲线，工程判断是分辨率不能无限堆，因为显存是硬墙，而稀疏激活只能缓解不能消除。DiT 规模决定全局一致性与条件遵循：参数量与深度增加会改善大范围结构的合理性，但对局部细节的增益有限，因为局部细节已被 SLAT 分辨率锁死。解码器类型则决定输出的“形态”：换高斯头得到可实时渲染但边界软的结果，换网格头得到精确拓扑但受等值面分辨率约束的结果，换辐射场头得到慢速但可作为监督参考的结果。三者的分工可以概括为：SLAT 定几何上限，DiT 定全局与条件，解码器定输出形态与下游可用性。

这套分工的工程含义是：当生成结果出问题时，先定位是哪一层分工失效。表面细节糊，查 SLAT 分辨率与编码激活；整体结构崩，查 DiT 规模与条件注入；输出格式不合下游，查解码头选择。管线复杂这一代价正来自这三层各自可调、又相互耦合：调分辨率会改 token 数进而改 DiT 训练成本，换解码头会改第一阶段损失进而改潜变量分布。一个具体例子是下游需要游戏引擎可用的网格：选网格头，但要接受等值面分辨率带来的面数膨胀与拓扑伪影；若改用高斯头再转网格，边界软的问题会转成重拓扑的工作量。这个取舍不是模型能力问题，而是分工边界上的工程判断。
