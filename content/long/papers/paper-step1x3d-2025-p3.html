一 · 几何分支的目标函数：从 SDF 场到可微表面

几何 DiT 的输出不是网格，而是一个隐式的有符号距离场。把 SDF 记作 $f_\theta(\mathbf{x}\mid c_{\mathrm{geo}})$，其中 $\mathbf{x}\in\mathbb{R}^3$ 是查询点，$c_{\mathrm{geo}}$ 是几何条件编码（文本、草图、分割掩码经条件编码器得到的 token 序列）。训练目标由三部分叠加：表面附近的距离回归、Eikonal 正则、以及远离表面的符号约束。

$$\mathcal{L}_{\mathrm{geo}}=\underbrace{\mathbb{E}_{\mathbf{x}\sim\mathcal{S}}\big(|f_\theta(\mathbf{x})-0|+\lambda_1\,|\nabla_{\mathbf{x}}f_\theta(\mathbf{x})-1|\big)}_{\text{近表面}}+\underbrace{\mathbb{E}_{\mathbf{x}\sim\mathcal{F}}\,\mathrm{softplus}\big(-s(\mathbf{x})\,f_\theta(\mathbf{x})\big)}_{\text{自由空间符号}}$$

$\mathcal{S}$ 是从真值网格表面采样的点集（含少量法向偏移以稳定梯度），$\mathcal{F}$ 是自由空间采样点，$s(\mathbf{x})\in\{+1,-1\}$ 表示该点位于物体外部还是内部。Eikonal 项 $|\nabla f-1|$ 强制场是一阶距离函数，否则近表面区域会出现“平台”，行进立方体提取时产生阶梯状伪影。$\lambda_1$ 是这一项的相对权重，工程上把它压得太低会让网格在薄壁处塌陷，抬得太高则会让训练在早期就锁死在近似球面的解上。

关键机制在于梯度路径：SDF 本身对 $\theta$ 可微，但“网格”这一步（行进立方体）不可微。因此几何分支的监督完全发生在场层面，网格只是推理期的导出物。这意味着训练时的分辨率（采样点密度）与推理时的提取分辨率是两个独立旋钮：采样点太稀，薄结构（如手柄、叶片）在损失里几乎不出现，模型学会忽略它们；提取分辨率太低，则场是对的但网格读不出来。这是几何分支最典型的失败模式——损失曲线漂亮，导出网格却丢细节。

具体例子：给定一张椅子草图作为 $c_{\mathrm{geo}}$，模型在椅腿与座面交接处若采样点密度不足，Eikonal 项会把该区域平滑成一个圆角，损失下降但拓扑错误。工程上的应对是在采样时按曲率加权，并在训练后期提高近表面采样比例。

二 · 纹理分支：多视图扩散的噪声预测目标与 UV 回投

纹理不走 3D 原生扩散，而是把几何 $\mathcal{M}$ 渲染成一组固定视角的多视图，在该视图集合上做条件扩散，再把去噪后的图像回投到 UV 空间。记视图集合为 $\{V_k\}_{k=1}^{K}$，第 $k$ 个视图的图像为 $\mathbf{I}^{(k)}$，扩散步为 $t$，噪声为 $\boldsymbol{\epsilon}$。纹理扩散网络 $\mathrm{TexDiff}$ 的预测目标是噪声本身：

$$\mathcal{L}_{\mathrm{tex}}=\mathbb{E}_{t,\boldsymbol{\epsilon},\{V_k\}}\Big[\big\|\boldsymbol{\epsilon}-\boldsymbol{\epsilon}_\phi\big(\mathbf{I}^{(k)}_t,\,t,\,\mathcal{M},\,c_{\mathrm{tex}}\big)\big\|_2^2\Big]$$

条件里同时含几何 $\mathcal{M}$（通过法向图与深度图编码，提供视角一致的几何线索）与纹理条件 $c_{\mathrm{tex}}$（文本或参考图）。$\mathcal{M}$ 进入条件的意义在于：同一张“木质纹理”图像在不同几何上的投影完全不同，若不给几何，模型会把纹理画成与表面朝向无关的平面图案，回投后出现拉伸与接缝。

采样阶段用 DDIM 类的确定性采样以压缩步数，推理成本主要在这里：$K$ 个视图各自跑一遍去噪链，再叠加回投与 UV 修补。回投的机制是：对每个视图的每个像素，沿相机射线求与网格的交点，取交点处的 UV 坐标，把像素颜色写入该 UV 位置；多视图重叠区域按视角权重（通常按法向与视线夹角）融合。融合权重写错会直接导致接缝，这是纹理分支最典型的系统代价。

失败模式之二在 UV 参数化本身：几何分支导出的网格若 UV 展开有重叠或极端拉伸，回投时多个 3D 点争抢同一 UV 像素，纹理在拉伸区糊成一片。这不是扩散模型的问题，而是几何与纹理两个分支解耦后的接口问题——分离生成降低了联合建模难度，代价是把 UV 质量的责任推给了几何导出与后处理。

具体例子：一个带凹槽的花瓶，凹槽内侧在多数视角下不可见，回投后该区域 UV 像素稀疏甚至空缺，需要 UV 空间修补（inpainting）补全；若修补不基于几何法向一致性，凹槽内侧会出现与外侧完全不同的材质，视觉上突兀。

三 · 条件编码与局部编辑接口的变量语义

条件编码器把三类输入映射到统一 token 空间：文本经文本编码器得到 $c_{\text{txt}}$，草图与分割掩码经图像编码器得到 $c_{\text{sketch}}$、$c_{\text{seg}}$。几何分支与纹理分支各自取用不同的子集——几何主要吃草图与分割（结构信息），纹理主要吃文本与参考图（外观信息），但两者共享同一套条件 token 接口，这是“可控”在公式层面的落点：控制不是外挂模块，而是条件变量 $c_{\mathrm{geo}},c_{\mathrm{tex}}$ 的取值组合。

局部编辑接口的变量语义需要单独说明。编辑不是重新采样整条去噪链，而是给定一个编辑区域掩码 $\mathbf{m}$（在 3D 空间或某个视图上定义）与编辑指令 $\Delta c$，在采样过程中对掩码内区域施加新的条件、掩码外区域沿用原条件。写成采样期的条件替换：

$$c_{\mathrm{eff}}(\mathbf{x})=\mathbf{m}(\mathbf{x})\odot\Delta c+\big(1-\mathbf{m}(\mathbf{x})\big)\odot c_{\mathrm{orig}}$$

$\odot$ 表示按空间位置的门控。这个式子的工程含义是：编辑的保真度取决于 $\mathbf{m}$ 的边界与去噪步的耦合——掩码边界若落在高频几何区域，去噪过程会在边界两侧产生不一致的纹理梯度，表现为可见的接缝。因此局部编辑接口通常配合较低的编辑强度与较多的采样步数，推理时间进一步上升。这是“可控”的直接代价：控制越细，采样越慢。

消融里条件类型与编辑接口是分开验证的，说明二者在训练配方上是独立变量：条件类型决定模型能否响应输入，编辑接口决定响应能否被局部化。工程判断上，前者是数据问题（需要带条件标注的大规模数据），后者是采样策略问题（不需要重训，但需要调采样器）。

四 · 训练配方：分离训练、可微渲染监督与数据构成

几何与纹理分开训练，不是简单的两阶段串行，而是各自有独立的损失与数据管线。几何阶段用 SDF 监督（第一节的 $\mathcal{L}_{\mathrm{geo}}$），纹理阶段用多视图扩散监督（第二节的 $\mathcal{L}_{\mathrm{tex}}$），中间通过“用当前几何渲染多视图”衔接。可微渲染监督在这里的作用是提供几何与纹理之间的一致性约束：渲染出的图像与真值视图比对，梯度回传到纹理场（几何在纹理阶段通常冻结，或只做很小的微调）。

训练配方的关键超参可以按分支列出：

分支关键超参作用与调参后果
几何 DiT近表面/自由空间采样比、Eikonal 权重 $\lambda_1$、条件 dropout 率采样比决定薄结构是否被学到；$\lambda_1$ 过大导致过度平滑；dropout 率决定无分类器引导的可用性

数据构成上，Objaverse 提供大规模通用资产，内部可控数据提供带草图、分割、编辑标注的样本。这里有一个结构性代价：可控数据的规模远小于通用数据，条件控制的泛化因此受限——模型在训练分布内的草图响应良好，分布外的草图（如工业件的工程图风格）响应会退化。这不是训练技巧能完全弥补的，是数据构成的直接后果，也是论文自述“控制能力仍有限”的机制来源之一。

条件 dropout 是配方里容易被忽视的一项：训练时以一定概率把 $c_{\mathrm{geo}}$ 置空，使模型同时学会有条件与无条件生成，推理时才能用分类器无关引导放大条件信号。dropout 率过高会让条件分支欠拟合，过低则引导失效，这是一个需要在验证集上扫的旋钮，而非固定常数。

五 · 数值玩具例子：一次几何损失与一次纹理回投

取一个一维化的玩具：真实表面在 $x=0$，模型当前预测的 SDF 在查询点 $x=0.2$ 处给出 $f_\theta=0.1$（真值应为 $0.2$），在自由空间点 $x=1.0$ 处给出 $f_\theta=0.6$（真值应为 $1.0$），且该点符号正确（外部，$s=+1$）。取 $\lambda_1=0.5$，并假设近表面梯度模为 $|\nabla f|=0.8$。

近表面项：距离误差 $|0.1-0|=0.1$；Eikonal 误差 $|0.8-1|=0.2$，乘 $\lambda_1$ 得 $0.1$；合计 $0.2$。自由空间项：$\mathrm{softplus}(-1\times0.6)=\mathrm{softplus}(-0.6)\approx0.44$（定性说明：符号正确时该项随距离增大而趋近 0，此处因预测距离偏小仍有残值）。总损失约 $0.64$。若把 $\lambda_1$ 提到 $2.0$，Eikonal 项变成 $0.4$，总损失升到 $0.94$，梯度会更用力地把场拉成一阶距离函数——这正是“$\lambda_1$ 过大导致过度平滑”的数值来源：模型优先满足距离性质，牺牲局部几何细节。

纹理侧的例子：设 $K=6$ 个视图，某 UV 像素被 3 个视图覆盖，三视图给出的颜色分别为 $\mathbf{c}_1,\mathbf{c}_2,\mathbf{c}_3$，融合权重按法向与视线夹角余弦取 $w_1=0.7,w_2=0.2,w_3=0.1$（归一化后）。回投颜色为 $0.7\mathbf{c}_1+0.2\mathbf{c}_2+0.1\mathbf{c}_3$。若权重写反（把掠射角视图权重给高），融合结果会偏向低质量观测，表现为该 UV 区域偏暗、细节模糊。这个例子说明回投融合不是平均，而是带几何先验的加权，权重设计错误是纹理真实感下降的一个具体机制。

推理成本可以这样估：几何分支一次前向加行进立方体提取，纹理分支 $K$ 次去噪链乘以步数。论文给出推理在数十秒量级，与“$K$ 个视图 × 多步采样”的结构一致；局部编辑因为要改采样条件并增加步数，落在这一量级的上沿。

六 · 梯度路径与失败模式的工程判断

把两条分支的梯度路径画清楚，能解释大部分失败模式。几何分支：$\theta_{\mathrm{geo}}\rightarrow f_\theta\rightarrow\mathcal{L}_{\mathrm{geo}}$，全程可微，梯度稳定，失败主要来自采样分布与 $\lambda_1$ 的权衡。纹理分支：$\phi\rightarrow\boldsymbol{\epsilon}_\phi\rightarrow\mathcal{L}_{\mathrm{tex}}$，梯度只在图像域，几何 $\mathcal{M}$ 作为条件输入不接收梯度（冻结），因此纹理不会“纠正”几何错误——几何错了，纹理只会忠实地在错误几何上画图。这是分离生成的结构性代价：两个分支各自收敛，但接口处（UV、法向、遮挡）的错误没有联合优化的通道。

可微渲染监督是缓解这一点的机制：渲染图像与真值比对，梯度可以回传到纹理场，甚至在微调阶段少量回传到几何。但它的覆盖受限于渲染视角与真值视图的重合度，未观测区域仍无监督。工程判断上，若目标是工业资产管线，应当把 UV 质量检查与多视图覆盖检查放在生成之后、纹理生成之前，作为硬门槛；否则纹理分支会在坏 UV 上浪费采样预算，且失败不可见——损失正常，输出却有接缝。

条件控制的梯度路径另有一条：条件编码器的参数在几何与纹理两个阶段都被训练，但两阶段的数据分布不同（几何阶段吃草图/分割，纹理阶段吃文本/参考图），共享编码器会出现模态间的梯度干扰。配方上通常用分离的条件编码头来隔离，代价是参数量增加与跨模态对齐变弱。这一权衡在消融的条件类型一项里被间接验证：不同条件类型的响应质量并不一致，说明共享与分离的选择对最终可控性有实质影响。

最后一个机制层面的判断：扩散采样的随机性在纹理分支被 DDIM 类确定性采样压缩，但局部编辑需要重新注入噪声以允许掩码内区域偏离原结果，这使编辑接口与快速采样在原理上冲突——编辑越强，越需要随机性与步数。因此“可控”与“快”在 Step1X-3D 的公式结构里不是并列的两个缺点，而是同一个采样机制的两面：条件门控越细，去噪链越难被截短。
