一 · 组合式目标：把“世界”拆成可分别优化的四项

WorldGen 的训练问题不能按“一个网络、一个损失、一次反向传播”来读。论文给出的组合式定义是整条系统的目标骨架：

$$\mathcal{W}=\mathrm{Compose}\!\left(\mathrm{Layout}_{\mathrm{LLM}}(t),\mathrm{Terrain}_{\mathrm{proc}},\{\mathrm{Gen}(o_i)\}\right)$$

这里 $\mathcal{W}$ 是最终导出的世界，$t$ 是输入文本，$\mathrm{Layout}_{\mathrm{LLM}}$ 把文本映射为场景图与布局（物体类别、数量、粗略位置、尺度约束、区域划分），$\mathrm{Terrain}_{\mathrm{proc}}$ 是程序化地形/建筑生成器，$\{o_i\}$ 是布局中列出的物体实例集合，$\mathrm{Gen}(o_i)$ 是扩散模型对第 $i$ 个物体的条件生成，$\mathrm{Compose}$ 是 object-aware 分解与放置、组合、优化、引擎导出的总装算子。这个式子的关键在于：它不是可微的端到端函数，而是一个“分段可训练、整体靠接口约束”的组合系统。$\mathrm{Compose}$ 内部包含不可微的离散决策（放置、尺度归一、碰撞消解、导出格式转换），因此梯度不会从最终世界回传到 LLM 或扩散模型；各模块只能各自用自己的目标训练，再由组合层用几何与语义约束把误差压回去。

具体机制上，布局阶段的目标是条件序列生成：给定文本 $t$，LLM 以自回归方式输出结构化场景图 $G=(V,E)$，$V$ 是物体节点（含类别、尺寸先验、朝向），$E$ 是空间关系边（相邻、支撑、朝向、包含）。训练信号来自指令微调与结构化输出约束（schema 约束解码），而不是几何损失。地形阶段是规则与噪声驱动的程序化生成，参数（地形尺度、起伏幅度、建筑密度、道路连通性）由布局中的区域语义给出。物体阶段是条件扩散：每个 $o_i$ 以类别标签加文本描述为条件，采样出网格或神经表示。组合阶段做 object-aware 分解：把生成资产按布局位姿放入世界坐标，做尺度对齐、地面吸附、碰撞检测与遮挡关系修正。

系统代价在这里第一次显形：因为四段各自预训练、各自有误差分布，组合层必须承担“误差缝合”的职责。LLM 布局可能给出物理上不可达的摆放（物体悬空、通道被堵），程序化地形可能与布局区域边界冲突，扩散资产可能尺度漂移或朝向错乱。组合层用规则修复这些冲突，但修复是启发式的，不能保证全局最优。失败模式典型如：布局要求一条穿过山谷的路径，程序化地形却生成陡坡，组合层只能抬高路径或削平地形，结果是“可穿越”但视觉上不自然。另一个例子是物体资产生成后包围盒与布局尺度不符，组合层按类别先验强行缩放，导致细长物体被压扁。这些都不是训练能消除的，而是组合式架构的固有代价。

二 · 各段的目标函数与变量含义

把公式拆开看，每一段有自己的目标与变量。布局段：设文本为 $t$，场景图为 $G$，LLM 建模的是 $p_\theta(G\mid t)$，训练用最大似然（指令微调下的下一 token 预测），变量 $\theta$ 是 LLM 参数。结构化输出把 $G$ 序列化为带类型标签的 token 流，因此“布局推理”在优化层面就是条件语言建模，没有任何几何监督。这意味着布局的物理合理性完全依赖预训练语料中的空间常识与提示词约束，而不是损失函数里的碰撞项。

地形段：程序化生成器不是学习模型，没有梯度。它的“目标”是参数化规则 $T=\mathrm{Proc}(\pi)$，$\pi$ 是地形参数向量（尺度、噪声频率、建筑密度、道路宽度等），由布局中的区域标签映射得到。变量 $\pi$ 由规则确定，不参与训练；可调的是映射表与规则库，属于工程配置而非学习参数。

物体段：条件扩散模型建模 $p_\phi(x_i\mid c_i)$，$x_i$ 是物体 $i$ 的几何表示（网格顶点、体素或三平面特征），$c_i$ 是条件（类别标签加文本描述加可能的参考图）。训练目标是去噪得分匹配的变体，标准形式为

$$\mathcal{L}_{\mathrm{diff}}(\phi)=\mathbb{E}_{x_0,\epsilon,t}\left[\left\|\epsilon-\epsilon_\phi(x_t,t,c)\right\|_2^2\right]$$

其中 $x_t=\sqrt{\bar\alpha_t}\,x_0+\sqrt{1-\bar\alpha_t}\,\epsilon$ 是加噪样本，$\epsilon$ 是真实噪声，$\epsilon_\phi$ 是网络预测，$t$ 是噪声等级，$c$ 是条件。变量 $\phi$ 是扩散网络参数，$\bar\alpha_t$ 是噪声调度累积系数。这个损失只约束单物体生成质量，不约束物体在世界中的位置与尺度——位置尺度归组合层管。

组合段：$\mathrm{Compose}$ 没有可微损失，它是一组约束满足与几何操作。可以把它写成伪代码思路：对每个 $o_i$，读取布局位姿 $p_i$ 与类别先验尺度 $s_i^{\mathrm{prior}}$，计算生成资产包围盒 $b_i$，做尺度归一 $s_i=s_i^{\mathrm{prior}}/\mathrm{diag}(b_i)$，做地面吸附（沿重力方向投影到地形高度场），做碰撞消解（与已放置物体做包围盒相交测试，冲突时按优先级平移或替换），最后写入引擎场景图。变量是位姿、尺度、碰撞标志，全部是离散或几何量，无梯度。

这套分段目标的直接后果是：训练配方不是“一个学习率跑到底”，而是四套独立配方加一套组合规则。LLM 用指令微调配方，扩散用条件生成配方（含类别 dropout 以支持无分类器引导），程序化用参数配置，组合用规则库与阈值。关键超参因此分散在各段：LLM 的解码温度与 schema 约束强度、扩散的引导尺度与采样步数、组合层的碰撞容差与尺度先验表。论文没有给出统一的端到端超参，因为系统本身就不是端到端可训的。

三 · 梯度、采样与“不可微缝隙”

梯度在这套系统里只存在于两处：LLM 的反向传播与扩散网络的反向传播。两者互不相通，也不与世界导出相通。LLM 的梯度来自 token 级交叉熵，更新的是布局先验；扩散的梯度来自噪声预测误差，更新的是单物体几何先验。组合层位于两者下游，是一个纯前向的、不可微的“缝合器”。这就是“不可微缝隙”：布局输出的离散场景图无法对物体生成求导，物体生成的网格也无法对布局位置求导。系统靠接口契约（schema、尺度先验、位姿约定）代替梯度来传递约束。

采样层面，三段各有采样机制。布局采样是自回归解码，受 schema 约束解码器限制，非法 token 被屏蔽，保证输出可解析为场景图；解码温度影响布局多样性，温度过低会重复同类物体，过高会破坏空间关系一致性。地形采样是确定性的参数化过程，同一组参数给同一地形，噪声种子控制细节变化。物体采样是扩散反向过程，从纯噪声出发迭代去噪，引导尺度控制条件贴合度：引导过强会过饱和、几何畸变，引导过弱则类别不符。组合层没有采样，只有确定性规则，因此同一布局加同一组资产种子给同一世界——可复现性由种子链保证。

失败模式集中在缝隙处。第一类：布局采样出合法 schema 但物理不可行的图，例如把大型建筑放在陡坡上，组合层只能削坡或悬空，前者破坏地形连续性，后者破坏可穿越性。第二类：扩散采样出类别正确但拓扑错误的资产，例如“桥”生成成实心块，组合层按包围盒放置后通道被堵，可穿越性检查失败。第三类：尺度先验表缺失类别，组合层退回默认尺度，导致物体过大或过小，视觉比例失调。这些失败不是某一模块的训练不足，而是缝隙处缺少联合约束的必然结果。工程判断是：组合层的规则库与先验表质量，直接决定系统可用性，其重要性不亚于扩散模型本身。

具体例子：文本要求“山谷中有一座石桥连接两侧小路”。LLM 布局输出桥的位姿在山谷中线、朝向沿路，程序化地形生成 V 形谷，扩散生成石桥资产。组合层做地面吸附时发现桥两端支撑点低于谷壁高度，于是抬高桥体，结果桥面与小路出现台阶，可穿越性检查通过但视觉断裂。这个例子说明缝隙处的修复是局部启发式，不能回改布局或地形，只能在下游打补丁。

四 · 训练配方：分段预训练加组合规则

论文明确说这是系统级组合，非单一端到端训练。训练配方因此是“三段预训练加一套组合配置”。LLM 布局段：在通用 LLM 上做指令微调，训练数据是文本到场景图/布局的配对，输出受 schema 约束；关键超参是学习率、批大小、序列长度、schema 约束强度、解码温度。程序化段：无训练，配方是参数映射表与规则库，关键“超参”是地形尺度、噪声频率、建筑密度、道路连通性阈值。扩散段：在 3D 资产数据上做条件生成预训练，条件是类别标签加文本，关键超参是噪声调度、引导尺度、采样步数、类别 dropout 比例。组合段：规则库加阈值表，关键参数是碰撞容差、尺度先验表、地面吸附偏移、导出格式选项。

消融在论文中覆盖 LLM 布局、程序化、扩散资产、分解四项，含义是逐项移除后看世界是否还成立。移除 LLM 布局：失去文本到空间关系的映射，世界退化为随机或固定布局，布局可控性消失。移除程序化：失去大尺度地形与建筑骨架，世界退化为物体堆叠，可穿越性依赖手工地形。移除扩散资产：物体退化为占位几何，视觉质量崩塌但布局与可穿越性仍在。移除分解：物体无法按布局组合，尺度与位姿失配，世界不可用。这组消融说明四项各自承担不同职责，没有哪一项可以被其他项替代；也说明系统的“可穿越、可交互、可进引擎”是四项共同产物，不是单一模型的输出。

训练配方的工程代价在于数据与接口的耦合。LLM 布局的训练数据需要文本与场景图配对，场景图的 schema 必须与组合层的读取格式一致；扩散资产的条件标签必须与布局输出的类别词表对齐；程序化参数必须与布局的区域标签对齐。任何一处词表或 schema 不一致，组合层就会在运行时失败。这不是模型精度问题，是接口契约问题。失败模式典型如：布局输出类别“石拱桥”，扩散词表只有“桥”，组合层按“桥”的先验尺度放置，石拱桥被缩放到通用桥尺寸，比例失真。修复靠词表映射表，属于工程配置，不进入训练。

具体例子：消融扩散资产后，世界仍可导出、仍可穿越，但物体是低多边形占位块，视觉质量与论文主张的“扩散生成物体”差距明显；这说明扩散段贡献的是资产质量而非世界结构。反过来，消融 LLM 布局后，扩散资产仍在，但摆放随机，布局可控性消失；这说明布局段贡献的是结构与可控性。两组消融的对比给出了工程判断：结构与质量是两条独立轴，组合式架构把两条轴分开优化，代价是接口复杂度。

五 · 数值玩具例子：一次组合的账

用一个极简例子把变量与代价算清楚。设文本 $t$ 要求“一片平地，三棵树，一条路”。布局段输出场景图：区域 $R_1$ 为平地，面积 $100\times100$ 单位；物体 $o_1,o_2,o_3$ 为树，位姿 $p_1=(10,10)$、$p_2=(30,20)$、$p_3=(50,40)$，朝向随机；路径边 $e_1$ 连接入口到出口。地形段按 $R_1$ 生成平坦高度场，参数 $\pi=(\text{尺度}=100,\text{起伏}=0,\text{密度}=0)$。物体段对每棵树做条件扩散采样，得到包围盒 $b_1,b_2,b_3$。组合段读取类别先验尺度 $s^{\mathrm{prior}}_{\text{树}}=5$ 单位高，计算缩放因子 $s_i=s^{\mathrm{prior}}/\mathrm{diag}(b_i)$，做地面吸附（高度场为 0，偏移 0），做碰撞检测（树之间距离大于包围盒半径和，无冲突），写入引擎场景图。

账算在这里：布局段一次自回归解码，序列长度约几十 token，成本可忽略；地形段一次参数化生成，成本与面积成正比；物体段三次扩散采样，每次采样步数 $N$，成本约 $3N$ 次网络前向；组合段三次尺度归一加三次碰撞测试，成本可忽略。总成本由扩散采样主导。若把采样步数从 $N$ 降到 $N/2$，资产质量下降但世界结构不变；若把布局解码温度调高，树的数量与位置变化，但组合层仍能处理。这说明成本与质量的权衡主要在扩散段，结构与可控性的权衡主要在布局段。

失败模式在这个玩具例子里也能算：若扩散采样出的树包围盒高度为 10 而非先验 5，缩放因子为 0.5，树被压扁；若布局把两棵树放在距离 1 单位内，碰撞检测触发，组合层平移其中一棵，路径可能被挤占；若地形段起伏参数非零而布局假定平地，地面吸附后树高低不一，视觉不一致。这些失败都不需要实验数字，靠变量关系就能推出。工程判断是：组合层的先验表与容差阈值是数值稳定性的关键，先验表错一个类别，整类物体比例失真；容差过松，碰撞漏检导致不可穿越；容差过紧，频繁平移破坏布局意图。

把玩具例子推广到论文的世界级场景，账的结构不变：布局段决定物体数量与位置，扩散段决定资产质量与成本，地形段决定大尺度骨架，组合段决定可用性。四段的变量与目标各自独立，梯度不互通，采样各自进行，训练配方分段配置。这就是 WorldGen 公式与训练的真实含义：它不是一次端到端优化，而是一次分段优化加一次组合缝合，缝合的质量决定世界是否可穿越、可交互、可进引擎。

六 · 超参敏感性与工程落点

关键超参按段列出并给出敏感性判断。布局段：解码温度决定布局多样性，温度偏高会破坏空间关系一致性，偏低会重复同类物体；schema 约束强度决定输出可解析性，约束过强会限制布局表达，过弱会输出非法图导致组合层崩溃。地形段：起伏幅度与建筑密度决定可穿越性，起伏过大配合布局的平地假设会产生地面吸附冲突；道路连通性阈值决定路径是否闭合，阈值不当会生成断头路。扩散段：引导尺度决定条件贴合度，过强几何畸变，过弱类别不符；采样步数决定质量与成本，步数不足细节缺失，步数过多成本线性上升；类别 dropout 比例决定无分类器引导的可用性，比例不当引导失效。组合段：碰撞容差决定可穿越性，尺度先验表决定比例正确性，地面吸附偏移决定视觉连续性。

敏感性排序的工程判断：组合段的先验表与容差最先崩，因为它们直接决定世界是否可用；扩散段的引导尺度其次，因为它决定资产是否类别正确；布局段的 schema 约束再次，因为它决定组合层能否解析；地形段参数最后，因为它的错误通常表现为视觉不自然而非不可用。这个排序不是论文给的，是从变量关系推出的：可用性失败比质量失败更致命。

落点上，训练配方不是调一个学习率，而是维护四套配置加一套契约。LLM 布局的 schema 必须与组合层读取格式一致，扩散词表必须与布局类别词表对齐，程序化参数必须与布局区域标签对齐。任何一处不一致，运行时失败，且失败不体现在训练损失上。这是组合式架构的工程本质：训练损失只保证各段局部质量，世界可用性由接口契约保证。WorldGen 把场景生成推到世界级，代价就是这套契约的维护成本；它也让“可穿越世界”成为可分解、可分段优化、可组合缝合的工程对象，而不是单一模型的输出。
