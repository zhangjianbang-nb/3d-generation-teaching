一 · 评测对象与数据集构成：为什么“能进引擎”本身就是指标

SF3D 的实验设计有一个容易被忽略的前提：它要证明的不是“单图重建能不能出网格”，而是“单图重建能不能直接产出可被下游引擎消费的资产”。这两个命题的评测口径完全不同。前者只需要几何相似度，后者必须同时考察拓扑合法性、UV 完整性、材质通道语义与光照解耦程度。论文把评测拆成两条线：一条是 Objaverse 上的通用三维重建对比，另一条是内部产品图上的生产可用性验证。前者提供与学术基线的可比性，后者提供工业管线的可落地性。

Objaverse 作为训练与评测的公共底座，其资产带有相对规范的网格与纹理，适合做 UV 空间纹理监督；内部产品图则补上了真实拍摄条件下的光照耦合问题——产品图几乎必然带有拍摄环境的低频照明，若不做 delighting，模型会把环境光烘进反照率，换光照即崩。这两条线合起来构成 SF3D 的证据链：公共集证明方法不弱于基线，内部集证明方法在真实输入上仍然成立。

评测指标的组织方式也对应这一前提。几何侧看重建网格与参考网格的偏差；纹理侧不看顶点色误差，而看 UV 空间纹理图与参考纹理的一致性，这正是训练目标中 Luv 的评测镜像；材质侧看预测的反照率、粗糙度、金属度与法线是否落在合理区间，以及重光照后渲染结果与参考光照下渲染结果的一致性。换句话说，评测指标是训练目标的直接外化，而不是另起一套。

这里有一个工程判断值得明确：UV 空间纹理误差与顶点色误差不可直接比较。顶点色方法的误差被顶点密度稀释，稀疏区域的大误差会被平均掉；UV 纹理误差是逐 texel 的，任何一处展开重叠或接缝错位都会在图上留下可见的撕裂。因此 SF3D 报告的纹理质量提升，本质上来自表示层的改变，而不是单纯把某个回归头训得更准。这一点在后面的消融中被单独隔离出来。

二 · 基线选择与对比口径：TripoSR、InstantMesh、CRM 各自代表什么

三个基线不是随意挑的，它们分别代表了 SF3D 之前三条主流技术路线。TripoSR 代表“快速前馈三平面/隐式表示”路线，优势是推理快，短板是输出不是标准 UV 网格，纹理落在三平面或顶点上，进引擎需要额外烘焙；InstantMesh 代表“多视图扩散 + 重建”路线，几何细节更丰富，但多视图生成与重建两级串联带来更高的时延，且 UV 仍需后处理；CRM 代表“卷积重建网格”路线，直接出网格，但在材质与光照解耦上不做显式建模。

对比口径因此必须分层。第一层是时延：SF3D 的推理耗时是 0.5 秒，这是它相对多视图串联方案的核心优势，也是它能被称为“快速”的依据。第二层是输出契约：是否带标准 UV、是否带 PBR 材质通道、是否光照解耦。第三层才是几何与纹理的相似度。论文的结论顺序也照此展开——先确立输出契约的差异，再在可比指标上给出对比。

这张表的意义不在于贬低基线，而在于说明“快”与“可进引擎”在 SF3D 之前是分裂的：快的不能进引擎，能进引擎的不快。SF3D 的实验要证明的是这两者可以同时成立，而不是在单一指标上压倒所有基线。因此论文在几何相似度上并不宣称全面领先，而是在输出契约与时延的组合上给出新的可行点。

对比中的一个系统性代价必须点明：基线若要做公平的 UV 与 PBR 对比，需要额外的烘焙与材质估计后处理，这些后处理本身耗时且不稳定，会把基线的端到端时延进一步拉长。SF3D 把这些步骤内化进单次前向，代价是模型必须同时学会几何、展开与材质，任一环节失败都会污染最终资产。这就是后文消融要回答的问题：三个环节各自的贡献能否被隔离。

三 · 主要结果：提升来自表示层，而非单纯算力

主要结果可以概括为三点：0.5 秒出带 UV、带 PBR、光照解耦的网格；重光照表现优于顶点色方法；在 Objaverse 与内部产品图上都能稳定产出可进引擎的资产。这三点中，第一点是时延与契约的组合，第二点是 delighting 的直接证据，第三点是泛化性的证据。

重光照对比是整篇论文最有说服力的实验设计。做法是：固定预测出的网格与材质，替换光照条件重新渲染，与参考资产在相同新光照下的渲染结果比较。顶点色方法在这个测试下必然失败，因为顶点色把反照率与拍摄光照烘在了一起，换光即偏色；三平面纹理方法同样失败，纹理图里含有低频照明。SF3D 因为显式预测反照率并做 delighting，重光照后的颜色偏移显著更小。这个对比不依赖任何绝对数值，靠的是机制上的必然性：解耦了就是解耦了，没解耦就是没解耦。

纹理质量的提升同样来自表示层。训练目标中的 UV 监督项为：

$$\mathcal{L}_{\mathrm{uv}}=\|\hat{T}(u,v)-T(u,v)\|^2$$

这一项直接在 UV 参数域上比较预测纹理与参考纹理。相比顶点色回归，它的梯度不会被网格稀疏度调制，高频细节能落在正确的 texel 上。工程上的直接后果是：接缝处的颜色连续性由展开质量与纹理预测共同决定，而不是靠顶点插值掩盖。论文报告的纹理改善因此应归因于“纹理在 UV 空间生成”这一设计，而不是更大的纹理分辨率或更深的解码器。

时延的 0.5 秒同样是设计的结果而非硬件堆叠。快速 UV 展开把传统上耗时的参数化过程压缩到可与前向传播同量级；纹理与材质在 UV 空间一次生成，省去了“先出顶点色再烘焙到 UV”的两段式管线。这里的系统代价是：UV 展开一旦失败（重叠、翻转、过度拉伸），后续纹理与材质预测全部建立在错误的参数化上，错误会被放大而不是被平均。这是 SF3D 最典型的失败模式，也是它把 UV 质量作为独立监督项的原因。

一个具体例子可以说明提升的来源。假设输入是一张带强烈侧向室内光的产品图，物体表面有细微的凹凸纹理。顶点色方法会把侧向光造成的明暗渐变直接写进顶点颜色，凹凸细节被光照梯度淹没；SF3D 在 delighting 后把低频照明剥离，反照率图保留凹凸的局部对比，法线贴图单独承载凹凸方向，重光照时侧向光重新作用在法线上产生正确的明暗。同一个输入，前者换光后凹凸消失，后者换光后凹凸仍在。这个差异不是指标小数点后的差别，而是资产能否被复用的分界。

四 · 消融一：UV 纹理 vs 顶点色，隔离表示层的贡献

第一个消融直接对应核心主张：纹理在 UV 空间生成而非顶点色。实验做法是保持几何解码与材质头不变，只把纹理表示从 UV 空间换成顶点色，比较纹理质量与下游可用性。这个消融的设计要点是控制变量——几何、材质、训练数据、时延预算都尽量对齐，唯一变化的是纹理的承载方式。

结果的方向是明确的：UV 空间纹理在细节保留与接缝一致性上优于顶点色。机制上的解释是采样密度的解耦。顶点色的表达力受限于网格顶点数，纹理细节的上限就是顶点密度；UV 纹理的表达力受限于纹理分辨率与展开质量，与顶点密度脱钩。对于同一张输入图，SF3D 可以在中等顶点数的网格上承载高分辨率纹理，而顶点色方法必须靠加密网格才能接近同等细节，加密又反过来推高时延与显存。

这个消融还暴露了一个失败模式：当 UV 展开出现重叠时，UV 纹理消融组的接缝撕裂会明显劣于顶点色组。也就是说，UV 表示的优势是有条件的，条件就是展开质量。论文因此把 UV 监督作为独立损失项，而不是让纹理损失隐式地倒逼展开。工程上的启示是：UV 展开不能当作“预处理黑盒”，它必须是可监督、可评估的环节，否则表示层的收益会被展开失败吃掉。

从系统代价看，UV 表示的引入增加了两个成本：展开模块的推理开销，以及纹理图的内存占用。前者被快速展开压到可接受范围，后者与纹理分辨率成正比。顶点色方法在这两项上都更轻，但代价是资产不可直接进引擎、细节受顶点密度限制。消融的意义就是把这条权衡曲线画出来，让读者看到 SF3D 选择 UV 不是免费的，而是用可控的展开风险换取了表示层的上限。

五 · 消融二：材质/法线与 delighting，解耦的两个必要条件

第二个消融拆的是材质与光照解耦。它实际上包含两个可分离的组件：材质/法线预测头，以及 delighting 步骤。实验需要分别回答：只加材质头够不够？只做 delighting 够不够？两者都加才成立吗？

只加材质头而不做 delighting，模型会从带光照的输入中回归材质参数，反照率里仍然混有低频照明。此时重光照测试会暴露问题：换光后颜色偏移依旧存在，因为反照率不干净。只做 delighting 而不显式预测材质，则缺少承载解耦结果的通道——delighting 剥离的低频光照需要有地方去，若没有反照率与法线的显式监督，剥离后的信息无法稳定落到正确的材质通道上。两者同时存在，才构成“预测干净反照率 + 单独承载法线 + 剥离低频照明”的完整解耦链。

训练配方中的 delighting 数据增强是这条链的数据侧支撑。做法是在训练时对资产施加可控的光照扰动，迫使模型学会把光照变化归因到照明而非反照率。这里的系统代价是数据工程：增强策略若过强，模型会把真实的材质明暗误判为光照而过度剥离，导致反照率过平；若过弱，解耦不彻底。论文把 delighting 作为管线必备步骤的结论，正是从这个消融中得出的——它不是可选的润色，而是重光照可用的前提。

材质真实感受数据限制是这一消融暴露的另一个边界。PBR 通道的语义（粗糙度、金属度）在 Objaverse 与内部产品图上的分布并不均衡，模型对少见材质的预测会退化。这不是网络容量问题，而是监督信号覆盖问题。消融中可以看到：在常见材质上材质头的收益明显，在长尾材质上收益被数据稀疏吞掉。工程判断因此是：材质头的价值随资产品类集中度上升而上升，做垂直品类时收益最大，做全品类通用资产时需要用数据配比来兜底。

法线贴图的独立监督同样在消融中被隔离。若把法线并入反照率一起回归，高频凹凸会被低频明暗污染，重光照时凹凸方向错误。独立法线通道让几何细节与光照解耦各走各的路，代价是法线预测对输入图的视角与遮挡敏感，单图看不到的背面法线只能靠先验补全，这是几何细节有限的直接来源之一。

六 · 失败模式与证据边界：0.5 秒买到了什么、没买到什么

把消融与主要结果放在一起看，SF3D 的证据边界就清楚了。它买到的是：标准 UV、PBR 通道、光照解耦、0.5 秒时延，这四者在同一份资产上同时成立。它没买到的是：UV 展开的鲁棒性、材质的长尾真实感、几何细节的完整性。这三项局限不是实验没做好，而是方法取舍的必然结果——单图输入的信息量、快速展开的时间预算、显式网格的拓扑约束，三者共同划定了上限。

UV 失败是最需要工程兜底的失败模式。快速展开在复杂拓扑、薄壁、多连通组件上容易产生重叠或翻转，一旦发生，纹理与材质预测会沿着错误参数化扩散。论文把 UV 监督独立出来是对策之一，但监督只能降低失败率，不能消除失败。生产管线因此需要在 SF3D 之后加一道 UV 质量检查：检测重叠率、拉伸率、接缝长度，失败则回退到慢速展开或人工修复。这道检查的耗时不在 0.5 秒内，是端到端管线的隐藏成本。

几何细节有限来自单图与显式网格的双重约束。单图看不到的背面只能靠先验，显式网格的分辨率与拓扑又限制了细节承载。消融中法线贴图能补一部分高频，但补的是着色细节而非轮廓细节。工程判断是：SF3D 适合做“中景资产”——在镜头中占中等画面比例、不需要特写的物体；做特写资产时几何细节会成为瓶颈，需要叠加多视图或细化阶段。

材质真实感受数据限制则决定了 SF3D 的适用品类。PBR 通道的预测精度随训练分布中的材质覆盖率变化，金属、织物、次表面散射等品类在单图条件下本身就存在歧义。这不是 SF3D 独有的问题，而是所有单图材质估计方法的共同边界。SF3D 的贡献在于把这个边界明确地暴露出来，而不是用渲染技巧掩盖。

最后落到一个具体机制上：SF3D 的实验证据之所以成立，是因为它把“表示层改变”与“解耦链完整”这两件事分别用消融隔离了出来。UV vs 顶点色的消融证明纹理收益来自参数域而非算力；材质/法线与 delighting 的消融证明重光照收益来自解耦链而非单一模块。两条消融合起来，把 0.5 秒这个数字从一个时延指标变成了一个契约指标——它承诺的不只是快，而是快的同时资产带 UV、带 PBR、可重光照。这个契约能否兑现，取决于 UV 展开是否成功、材质是否落在训练分布内、几何是否满足镜头要求，三者任一不满足，0.5 秒买到的就只是一个半成品。
