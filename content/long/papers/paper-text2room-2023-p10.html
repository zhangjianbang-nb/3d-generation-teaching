一 · 45 分钟课表：把论文拆成可讲授的六个节拍

给新工程师讲这篇论文，最大的风险是把“生成房间”讲成“跑一个模型”。Text2Room 的实质是一条流水线：文本先被翻译成一组按视角排布的图像，图像再被深度反投影成网格，网格之间的空洞由文本条件 inpainting 填补，新帧与旧网格连续对齐融合，相机每前进一步，房间就长出一块。45 分钟必须让听众在脑子里跑通这条流水线，而不是记住几个模块名。

建议的时间切分是：5 分钟讲问题现场（单张图只能看到一角，全景图重建缺几何约束）；8 分钟讲数据流（文本→2D 文生图→单目深度→反投影→inpainting→对齐融合）；10 分钟讲公式与融合机制（逐帧并集更新与对齐误差如何累积）；8 分钟讲实验证据与消融（视角选择、连续对齐、inpainting 各自贡献什么）；7 分钟讲失效条件与复现清单；最后 7 分钟做三个类比、两个误解澄清和五道自测题。这个配比的原则是：机制占一半以上，证据和边界各占一块，类比只做锚点不做主线。

讲授顺序上有一个具体技巧：先放一张“相机走一圈”的示意图，让听众看到房间是被“走”出来的，而不是被“渲染”出来的。这样后面讲连续对齐融合时，听众自然理解为什么对齐误差会随帧数累积——因为每一帧都挂在前一帧的坐标系上。若先讲公式再讲数据流，听众会把并集更新误当成一次性重建，后面所有关于漂移的讨论都会失去落点。

每一节都要留一个“可验证的钩子”。讲反投影时给出针孔相机反投影的表达式；讲融合时给出并集更新公式；讲消融时明确说清三个被消融的组件各自对应流水线里的哪一步。钩子的作用是让听众在课后能自己复述流水线，而不是只记得“用了 Stable Diffusion”。

二 · 三个类比：把抽象机制钉在工程直觉上

第一个类比：贴瓷砖。把单目深度反投影出的每一帧网格想成一块形状不规则的瓷砖，瓷砖上带着文生图生成的纹理。连续对齐融合就是把新瓷砖的边缘与已铺好的墙面咬合，咬合处重叠的三角形被合并，缝隙由 inpainting 补上。这个类比能直接解释两件事：为什么视角选择重要（瓷砖的朝向决定咬合面是否够宽），以及为什么长距离会漂移（每块瓷砖都相对上一块对齐，误差像铺砖时的累积偏斜，走到房间另一头时墙面已经歪了）。

第二个类比：边走边拍照拼全景。相机逐步移动，每停一个视角就生成一张图、估一次深度、反投影一块几何，再把这块几何焊到已有网格上。与手机全景不同的是，这里每一张“照片”不是拍出来的，而是文生图模型按文本条件画出来的，所以相邻帧之间没有真实的视差约束，一致性只能靠对齐融合和 inpainting 事后修补。这个类比解释了补洞为什么依赖 2D 先验：缝隙里没有真实观测，只能让 2D 模型“猜”出合理纹理。

第三个类比：用 2D 模型的“想象力”当 3D 扫描仪。传统扫描仪靠真实光线测距，Text2Room 靠单目深度估计把 2D 图像“读”成深度，再用文生图把没看到的地方“画”出来。类比的价值在于点明系统代价：扫描仪的误差是传感器噪声，这里的误差是 2D 模型的先验偏差，两者性质不同，后者不会因为多拍几张就自动收敛。讲到这里可以顺势引出显存限制——每多走一步就多一帧图像和一块网格，显存是这条流水线的硬天花板。

三个类比要按顺序讲，不能打乱。贴瓷砖对应几何融合，拼全景对应视角序列，扫描仪对应 2D 先验的角色。顺序乱了，听众会把“漂移”误解成“图像质量问题”，而它本质是几何对齐误差的累积。

三 · 两个常见误解：必须当场拆掉

误解一：“Text2Room 是一个 3D 生成模型。” 它不是。系统里没有任何 3D 训练，没有 3D 数据，没有 3D 监督。它用的是预训练的 2D 文生图、单目深度估计和文本条件 inpainting，逐场景生成，每个房间数分钟。3D 几何是反投影和对齐融合“拼”出来的，不是模型直接输出的。这个误解的工程后果很实际：如果有人以为可以拿它当 3D 先验去微调，就会找不到可训练的参数；正确做法是把它当一条推理流水线，调的是视角选择策略、对齐融合的容差和 inpainting 的调用时机。

误解二：“补洞就是把洞填上，几何自然就完整了。” 补洞用的是文本条件 inpainting，它补的是图像像素，不是几何真值。补出来的纹理要再经过深度反投影才能变成网格，而这一步的深度同样来自单目估计，带有 2D 先验的偏差。所以补洞能提升视觉连续性，却不能保证几何正确；洞越大，补出来的内容越依赖 2D 模型的想象，几何一致性越弱。这解释了为什么消融里 inpainting 是必要组件，但它不是几何完整性的保证。

拆误解的方法要具体：对误解一，直接展示流水线里没有任何反向传播到 3D 表示的路径；对误解二，展示补洞后的像素如何再次进入反投影，指出误差来源是两次 2D 先验的叠加。两个误解都指向同一个工程判断：这条流水线的上限由 2D 模型的一致性和深度估计的准确性共同决定，而不是由某个 3D 模块决定。

还有一个容易被误读的点要顺带澄清：连续对齐融合不是“全局优化”。它是逐帧的并集更新，新帧对齐到当前网格坐标系后就并入，没有回环检测，也没有全局平差。这正是长距离漂移的机制根源，也是后面复现清单里必须加验收断言的原因。

四 · 融合机制与误差累积：公式背后的工程账

核心更新式是逐帧并集：

$$\mathcal{M}_{t+1}=\mathcal{M}_t\cup\mathrm{BackProject}\!\left(D_t,I_t,\mathbf{c}_t\right)$$

其中 $\mathcal{M}_t$ 是第 $t$ 步已有的网格，$I_t$ 是文生图按视角生成的图像，$D_t$ 是单目深度，$\mathbf{c}_t$ 是该视角的相机参数，$\mathrm{BackProject}$ 把像素连同深度反投影成带纹理的三角形集合，$\cup$ 表示与已有网格合并。这个式子的关键在 $\cup$ 的实现：新网格必须先对齐到 $\mathcal{M}_t$ 的坐标系，重叠区域做融合，边界处留出的空洞交给 inpainting。对齐不是精确的，因为 $D_t$ 有偏差、$\mathbf{c}_t$ 是选定的而非测得的，所以每次并集都引入一点残差。

误差累积可以用一个简单的递推描述：设第 $t$ 步对齐后的残余偏移为 $\epsilon_t$，则第 $t$ 步网格相对初始坐标系的累计偏移近似为 $\sum_{i\le t}\epsilon_i$。这不是严格的误差上界，但它抓住了机制：没有全局回环校正时，逐帧残差会线性叠加。工程上的直接后果是，相机走得越远，墙面越歪，纹理接缝越明显。这也是为什么视角选择被列为消融对象——选更宽的视角重叠能压低单步 $\epsilon_t$，从而延缓漂移。

系统代价还有显存。每步要保留当前网格、新生成的图像、深度图和 inpainting 的中间结果，网格随步数增长，显存占用单调上升。规模受显存限制不是一句定性话，它对应一个具体的工程事实：房间越大、走的步数越多，单卡能撑住的网格和图像缓存就越吃紧。复现时必须在步数和分辨率之间做取舍，而不是指望模型自己“记住”整个房间。

一个具体例子：设想相机从房间一角出发，沿墙走四步生成四面墙。第一步的深度偏差让第一面墙略微内倾，第二步对齐到这面内倾的墙上，偏差被继承并放大，走到第四面墙时接缝已经错位。inpainting 能把接缝的像素抹平，但抹不平几何错位。这个例子在课堂上讲一遍，比讲十遍“长距离漂移”更有效。

五 · 五道自测题与复现验收断言

自测题要能区分“记住了模块名”和“理解了流水线”。以下五题按难度递增，建议在课末用 7 分钟口头过一遍。

  • 题一：给定文本和一组选定视角，说出从文本到纹理网格的完整数据流，并指出哪一步引入了 2D 先验、哪一步引入了几何误差。
  • 题二：写出逐帧并集更新式，解释 $\cup$ 为什么必须先对齐，以及对齐残差如何随步数累积。
  • 题三：消融里的视角选择、连续对齐、inpainting 各自对应流水线的哪一步？去掉任一个，失效模式分别是什么？
  • 题四：为什么说 Text2Room 不是 3D 生成模型？如果把它当 3D 先验去微调，会卡在哪一步？
  • 题五：房间规模受显存限制，具体限制的是哪些缓存？在步数与分辨率之间你如何取舍，验收时用什么断言判断漂移已不可接受？

题三的参考答案要落到机制上：视角选择影响重叠宽度和单步对齐残差；连续对齐融合决定新帧如何并入旧网格；inpainting 决定空洞处的纹理连续性。三者缺一，分别表现为接缝错位、网格断裂和空洞可见。题五的验收断言应写成可执行的检查：相邻帧重叠区的几何偏差超过阈值即判定漂移不可接受，而不是靠肉眼看图。

复现清单里要加三条硬断言：第一，每步并集后检查新网格与旧网格在重叠区的对齐残差，超阈值就停下调整视角；第二，记录每步的显存占用，逼近上限时降分辨率或缩短步数；第三，对 inpainting 补出的区域单独标记，验收时区分“真实反投影几何”和“补洞想象几何”，避免把后者当成几何真值。这三条断言直接对应论文的三个局限：长距离漂移、补洞先验、显存限制。

课堂上的收尾不要落在“这门课讲完了”，而要落在一个工程判断上：Text2Room 把场景生成从单物体推向房间，靠的是把 2D 模型的迭代生成能力接到一条带对齐融合的几何流水线上；这条流水线的可靠性由单步对齐残差和显存预算共同决定，前者决定走多远，后者决定走多细。新工程师上手时，先调这两个量，再谈纹理质量。
