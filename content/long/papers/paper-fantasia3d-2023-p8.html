一 · 训练数据的真实构成：没有 3D 监督，只有 2D 先验与文本

讨论 Fantasia3D 的评测之前，必须先把它“用了什么数据”讲清楚，否则后面所有指标都会被误读。论文在数据集一栏给出的答案是“无 3D 训练集”——这句话不是修辞，而是字面事实：整个方法不消费任何带 GT 网格、GT 材质、GT 多视图的 3D 资产库。它消费的是三类东西：一个冻结的文本到图像扩散模型（提供 SDS 梯度）、一个冻结的法线/深度条件扩散模型（几何阶段专用）、以及每个资产自带的一句文本提示。换句话说，监督信号全部来自 2D 图像先验，3D 一致性是靠多视角渲染 + SDS 在优化过程中“逼”出来的，而不是靠数据里已有的 3D 真值教出来的。

这个构成决定了评测协议的形状。因为没有留出的 3D 测试集，也就不存在“在 X 个 GT 资产上算 Chamfer 距离”这种常规 3D 生成评测。论文能做的只有两类：一是定性/半定量的视觉对比（几何是否干净、材质能否重光照），二是用户偏好研究（human preference），把同期 SDS 方法作为基线让受试者 pairwise 比较。基线名单是 DreamFusion、Magic3D、TextMesh，三者都是“几何与外观混在一个辐射场里优化”的代表，正好构成“解耦 vs 不解耦”的对照。

这里有一个容易被忽略的机制细节：文本提示本身也是“数据”。SDS 的梯度是 \(\nabla_\theta \mathcal{L}_{\mathrm{SDS}}\)，其期望形式可写作

$$\nabla_\theta \mathcal{L}_{\mathrm{SDS}} = \mathbb{E}_{t,\epsilon}\left[w(t)\,(\epsilon_\phi(x_t;y,t)-\epsilon)\,\frac{\partial x}{\partial \theta}\right]$$

其中 \(y\) 是提示词，\(\epsilon_\phi\) 是冻结的扩散去噪器，\(x\) 是当前渲染图。提示词的措辞、材质描述的有无、风格词的密度，会直接改变 \(\epsilon_\phi\) 的输出，从而改变优化轨迹。这意味着“数据质量”在 Fantasia3D 里部分等价于“提示词质量”，评测时若不控制提示词集合，方法间的差异会被提示词差异污染。工程上复现时，必须固定一份提示词清单并公开，否则用户偏好结果不可比。

失败模式也在这里：由于没有 3D 真值，任何“看起来对”的评估都可能是 2D 先验的偏见。例如扩散模型对“光滑金属”的先验很强，优化器会倾向于把表面推向先验偏好的高光分布，哪怕几何本身有细微错误。系统代价是：评测无法给出绝对精度，只能给相对排序；而且排序对提示词分布敏感。一个具体例子：同一句“a rusty metal helmet”，若提示词里没有“rusty”，材质 MLP 会收敛到更光滑的反照率，用户偏好分数上升，但这不是方法更好，而是先验被喂得更顺。

二 · 评测协议：用户偏好为主，定性对比为辅

Fantasia3D 的评测协议核心是用户偏好研究。做法是把同一提示词下不同方法生成的资产渲染成固定视角的图（或转台视频），让受试者 pairwise 选择“哪个更好”。这个协议的设计要点在于：比较的是渲染结果而非网格，因此它同时检验几何与外观；受试者看到的是 2D 图像，因此它继承了 2D 先验的全部偏见。论文报告的结论是“用户偏好优于同期 SDS 方法”，这是一个定性表述，没有给出具体百分比，读者不应自行补数字。

协议里有一个具体机制值得拆开：pairwise 偏好的统计量。若方法 A 在 \(N\) 次比较中胜 \(w\) 次，则胜率 \(\hat{p}=w/N\)，其标准误约为 \(\sqrt{\hat{p}(1-\hat{p})/N}\)。当 \(N\) 不大时，胜率的置信区间很宽，两个方法差几个百分点在统计上不可区分。工程判断是：看到“偏好优于”时，先问样本量与提示词数量，再看是否报告了置信区间；论文没有给这些数字，所以只能把它当作方向性证据，不能当作效应量。

定性对比的协议则围绕两个可检验的性质展开：几何是否干净（表面是否被纹理“长”出凹凸）、材质是否可重光照（换光照后高光/阴影是否合理）。这两个性质正好对应解耦的两个卖点。对比基线 DreamFusion/Magic3D/TextMesh 时，论文展示的是同一提示词下的并排渲染。这里的失败模式是“cherry-picking”：定性图只展示成功案例，不展示失败案例，读者无法估计失败率。系统代价是评测不可复现——没有固定随机种子、没有固定提示词全集，第三方无法重跑同一协议。

一个具体例子：几何干净度的判断依赖法线可视化。阶段一渲染的是法线图 \(\hat{n}\)，SDS 用 \(\mathcal{L}_{\mathrm{SDS}}(\hat{n},y)\) 优化。若法线图出现高频噪声，说明几何被 2D 先验的纹理细节污染；解耦方法因为外观阶段冻结几何，法线图在阶段二不再变化，所以“干净”是可保持的。评测时若只给 RGB 渲染而不给法线图，受试者其实无法区分“几何干净”与“纹理碰巧平滑”，这是协议的一个口径漏洞。

三 · 指标口径：几何、材质、可重光照各自度量什么

因为没有 GT，Fantasia3D 的指标口径是“性质导向”而非“误差导向”。可以把它拆成三层，每层度量不同的东西，混用会导致误读。

层级度量对象口径主要风险
几何网格表面、法线连续性定性看法线图/轮廓；无 Chamfer无法量化，依赖观察者
材质反照率、粗糙度、金属度换光照后的渲染一致性2D 先验偏差被当成材质正确
可重光照PBR 渲染在 novel lighting 下的表现定性对比 + 用户偏好光照设置未公开则不可复现

几何层的口径是法线与轮廓。阶段一用 DMTet 表示网格，渲染法线/深度送条件扩散算 SDS。几何质量的判据是法线是否分段光滑、轮廓是否闭合。这里没有 Chamfer 距离，因为无 GT；也没有 F-score，因为没有对应关系。代价是几何质量只能定性描述，方法间的几何差异无法给出数值排序。

材质层的口径是 PBR 参数的可解释性。外观阶段 MLP 输出 \(\mathbf{a}\)（反照率）、\(r\)（粗糙度）、\(m\)（金属度），渲染为 \(\mathrm{PBR}(\mathbf{a},r,m,\hat{n})\)，再用 RGB SDS 优化。判据是：换一个光照方向，高光位置是否随法线移动、粗糙度是否控制高光锐度。这个口径的失败模式是“先验冒充材质”：RGB SDS 只约束渲染图与文本一致，不约束参数本身；若扩散模型偏好某种高光，MLP 会收敛到能复现该高光的参数，哪怕物理上不自洽。论文用“材质正则”缓解，但正则的权重与形式未在事实中给出，复现时需自行调。

可重光照层的口径最容易被误读。它度量的是“同一几何 + 同一材质在不同光照下的渲染合理性”，而不是“材质参数与真实资产一致”。一个具体例子：把资产放进一个全新的 HDRI 环境，若高光出现在错误位置，说明法线与材质不匹配；但若高光位置对、强度不对，则可能是粗糙度偏差。评测协议若不公开光照设置，第三方无法区分这两类错误。系统代价是：可重光照的结论只在论文自己的光照配置下成立，不能外推。

四 · 作弊风险：SDS 评测里那些“看起来赢了”的陷阱

无 GT 的评测天然有作弊空间，因为“好”是由 2D 先验和受试者共同定义的。第一类风险是提示词调优：给基线用原始提示词，给本方法用加了材质/光照描述的提示词，偏好分数会系统性偏移。第二类风险是视角选择：只渲染最能展示解耦优势的视角，回避几何瑕疵暴露的角度。第三类风险是光照选择：可重光照演示只用与训练先验一致的光照，回避极端光照。

更隐蔽的一类是“几何冻结”带来的评测不对称。阶段二冻结几何，所以外观阶段的渲染图在几何上是固定的；基线方法则在优化纹理时继续改动几何。若评测只看最终 RGB，解耦方法的图可能因为几何未被纹理扰动而显得更干净，但这不等于它的几何更准——它只是没有被后续优化破坏。口径上应区分“几何质量”与“几何稳定性”：前者是形状对不对，后者是形状会不会被纹理优化带偏。论文的卖点主要是后者，评测若混为一谈，就会高估几何精度。

还有一个机制层面的作弊点：SDS 的权重 \(w(t)\) 与时间步采样分布。不同方法若采样不同的 \(t\) 分布，梯度尺度不同，收敛速度不同，最终渲染的“锐利度”也不同。偏好研究里，受试者往往偏好更锐利、对比度更高的图，这会奖励更大的梯度尺度而非更好的几何。工程判断是：比较方法时必须固定 \(t\) 采样策略与 \(w(t)\)，否则偏好分数不可比。论文未在事实中给出这些超参的对比，复现时应把它们列为验收断言。

一个具体例子：若基线 Magic3D 的纹理优化把几何表面推出高频凹凸，RGB 渲染会出现细碎阴影，受试者可能判为“细节丰富”；而 Fantasia3D 因为几何冻结，表面平滑，被判为“细节少”。这其实是解耦的代价（材质真实感受 2D 先验限制），但在偏好协议里可能被读成劣势。评测若不区分“细节丰富”与“几何被污染”，就会把失败模式当成优点。

五 · 那个容易误读的数字：“无 3D 训练集”不等于“无数据依赖”

最容易被误读的表述是数据集一栏的“无 3D 训练集”。很多读者会把它读成“这个方法不依赖数据、纯优化”，进而推断“它的评测不受数据偏见影响”。这两步推理都是错的。正确读法是：它不依赖 3D 监督数据，但它强依赖 2D 扩散先验，而 2D 先验本身是在海量图像上训练的，带有图像数据的全部偏见。所以“无 3D 训练集”描述的是监督信号的来源，不是数据依赖的有无。

这个误读会直接污染评测解读。若认为方法“无数据偏见”，就会把用户偏好结果当作客观质量排序；实际上偏好结果同时反映了 2D 先验的偏好与受试者的偏好。机制上，SDS 梯度是 \(\epsilon_\phi\) 的函数，\(\epsilon_\phi\) 的训练分布决定了哪些形状/材质更容易被生成。例如扩散模型对“正面视角的物体”先验更强，优化器会倾向于把资产摆成正面朝向，评测若固定正面视角，就正好迎合了这个先验。系统代价是：偏好分数里混入了“与先验对齐程度”这一项，而这一项与方法优劣无关。

另一个误读是把“每资产数小时”读成“训练成本可忽略”。事实是每资产仍需数小时优化，这意味着评测的样本量受算力限制：用户偏好研究不可能覆盖大量资产，提示词集合必然小，统计功效低。工程判断是：看到“偏好优于”时，应把它理解为“在小样本、特定提示词分布下的方向性证据”，而不是“普适胜出”。复现清单里应包含：固定提示词全集、固定视角、固定光照、固定 \(t\) 采样、报告样本量与置信区间——这些论文未给，但复现时必须补齐。

具体例子：假设提示词集合只有十几条，每条比较若干次，胜率的置信区间可能跨越 50%。此时“优于”与“不劣于”在统计上无法区分。这不是说结论错，而是说结论的强度被高估了。正确口径是：把“无 3D 训练集”与“小样本偏好”放在一起读，得出“在 2D 先验覆盖良好的提示词上，解耦带来可感知的偏好优势；在先验覆盖差的提示词上，优势未验证”。

六 · 工程复现的评测断言：把口径钉死

要把这一部分的评测讲成可执行的工程判断，需要把口径钉成断言。第一条断言：几何阶段与外观阶段的渲染必须分开记录，法线图与 RGB 图都要留存，否则无法区分“几何干净”与“纹理平滑”。第二条断言：外观阶段必须冻结几何，并在日志里证明网格顶点在阶段二未变；这是解耦成立的操作定义。第三条断言：可重光照演示必须公开光照配置（HDRI 或方向光参数），否则结论不可复现。

第四条断言关于指标口径：不得用 RGB 渲染的偏好分数替代几何精度。偏好分数是“几何 + 材质 + 先验对齐”的混合量，不能拆出单一因素。若必须给几何一个数值，只能用代理量，例如法线图的局部方差或轮廓闭合度，并明确它是代理而非真值误差。第五条断言关于基线：比较时必须固定提示词、视角、光照、\(t\) 采样与 \(w(t)\)，任何一项不同都要在报告里标注，否则偏好差异归因不清。

失败模式的验收方式是“反例测试”：构造一个提示词，其 2D 先验与目标材质冲突（例如“matte metal”），看方法是否把粗糙度推向先验偏好而非文本描述。若外观阶段完全跟随先验、忽略文本，说明材质正则不足，这是解耦方法的已知局限（材质真实感受 2D 先验限制）。另一个反例是极端光照：用与先验分布差异大的光照渲染，看高光是否物理合理；若不合理，说明材质参数只是拟合了先验光照，不是真实 PBR 参数。

最后一个工程判断落在“数字的用法”上：本部分唯一可引用的数字性事实是“两阶段”“每资产数小时”“无 3D 训练集”，其余均为定性。任何在复现报告里出现的百分比、Chamfer 距离、F-score，都必须是复现者自己测的，并附协议；不能假借论文名义。把“无 3D 训练集”读成“无数据依赖”是这一部分最需要防住的误读，因为它会让人把 2D 先验偏见误当成客观质量，从而在评测里系统性地高估解耦方法的几何精度、低估其材质局限。
