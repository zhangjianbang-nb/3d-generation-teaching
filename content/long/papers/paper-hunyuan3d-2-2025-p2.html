一 · 双分支的职责切分：为什么不是一条流水线

Hunyuan3D 2.0 的方法骨架不是一条把图像直接映射到带纹理网格的端到端网络，而是两条在训练上彼此独立、在推理时串行拼接的分支。形状分支负责“几何是什么”，纹理分支负责“表面长什么样”。这个切分不是工程上的偷懒，而是由两类监督信号的物理含义决定的：几何的监督来自 SDF 场与多视角渲染的轮廓一致性，纹理的监督来自多视角 RGB 与 UV 域的颜色一致性。把两者塞进同一个损失里，梯度会互相拉扯——几何为了迎合纹理的高频细节而长出伪结构，纹理为了掩盖几何误差而在边缘处涂抹。论文把总目标写成可分解的形式：

$$\mathcal{L}=\mathcal{L}_{\mathrm{shape}}+\lambda\mathcal{L}_{\mathrm{tex}},\qquad \mathcal{L}_{\mathrm{tex}}=\sum_{v}\|\hat{I}_v-I_v\|^2$$

关键在于这个式子描述的是联合目标的形式，而训练过程并不对它做联合优化。形状分支先在 SDF 监督加可微渲染下单独收敛，纹理分支随后在冻结的几何上单独收敛。λ 在这里不是训练时的权重，而是描述两阶段在总目标中的相对地位：几何是硬约束，纹理是在既定几何上的拟合。这样做的直接收益是 scaling 的自由度——形状分支可以堆分辨率、堆 VecSet 的容量，纹理分支可以堆视角数、堆 UV 分辨率，两者的数据配比、GPU 预算、收敛判据互不牵制。

代价也很明确。两阶段串行意味着几何阶段的任何误差都会被纹理阶段继承并放大：如果 Marching Cubes 出的网格在薄壁处出现孔洞，纹理扩散不会去修补几何，它只会在错误的 UV 参数化上画出看似合理的颜色。这就是论文自述的 UV 展开失败模式之一的来源。另一个代价是推理时延：两套扩散采样串行执行，加上 UV 展开与投影，整体落在数十秒量级，比单阶段前馈模型慢一个档次。这个时延不是实现粗糙，而是解耦架构的结构性开销。

一个具体的例子可以说明分工的必要性：给定一张带复杂雕花的椅子图，形状分支要决定的是扶手曲面的 SDF 等值面位置，纹理分支要决定的是木纹在 UV 上的走向与磨损分布。前者错 2 毫米，后者无论多真实都无法补救；后者错在接缝处，前者也无力回天。两个错误源性质不同，必须由不同的监督、不同的网络、不同的数据分布去分别压制。

二 · 形状分支的数据流：从图像条件到 VecSet 再到网格

形状分支的输入是图像条件（单图或少量视图），输出是 SDF 场，最终经 Marching Cubes 转成网格。中间表示是 VecSet——一组无序的、带位置的隐向量集合，而不是稠密的体素网格或三平面。VecSet 的作用是把高分辨率几何的存储与计算从“按体积缩放”改成“按表面附近的活跃元素缩放”：空旷区域不分配 token，细节区域加密。扩散过程在这个集合上定义，去噪网络是 DiT，条件通过图像编码器注入。

数据流的每一步可以这样拆开。第一步，图像经编码器得到条件嵌入，同时 VecSet 从纯噪声初始化，元素数量与空间分布由分辨率档位决定。第二步，DiT 在扩散时间步上迭代去噪，每个元素的位置与特征联合更新；注意力的计算范围受元素邻域限制，否则集合规模一大，注意力的二次代价会直接压垮显存。第三步，去噪完成的 VecSet 被解码为隐式场，查询任意空间点的 SDF 值。第四步，在固定分辨率的规则栅格上采样 SDF，跑 Marching Cubes 提取等值面，得到三角网格。第五步，网格做后处理——去孤立片、简化、法线重算——再交给纹理分支。

伪代码层面的关键控制点在于采样栅格分辨率与 VecSet 容量的匹配：

  • 栅格分辨率决定几何的上限频率，VecSet 容量决定网络能表达的细节量；两者不匹配时，要么容量浪费，要么栅格欠采样导致细节被抹平。
  • Marching Cubes 的等值面阈值是全局常量，薄结构处 SDF 梯度陡，阈值微偏就会产生孔洞或粘连，这是几何阶段最典型的失败模式。
  • 可微渲染监督要求从 SDF 出发做体渲染或表面渲染，渲染分辨率与视角采样数直接决定轮廓监督的锐度，也直接决定训练成本。

系统代价集中在两处。其一是显存：VecSet 的元素特征与邻域注意力在训练时需要保存中间激活，分辨率档位每上一级，激活占用非线性增长，这是“数十 GPU 天”里相当一部分的来源。其二是 Marching Cubes 的时间与内存：高分辨率栅格上的等值面提取是 CPU/GPU 混合的稠密操作，栅格边长翻倍，查询点数按立方增长。一个具体场景：生成一把带镂空花纹的金属椅，花纹的孔径接近栅格间距时，等值面提取会在孔壁处产生阶梯状锯齿甚至闭合孔洞，纹理阶段随后在这些错误面上贴出连续色块，视觉上表现为“花纹被糊住”。这不是纹理分支的错，而是几何分辨率与拓扑提取的联合失败。

三 · 纹理分支的数据流：多视图扩散与 UV 投影的接缝

纹理分支的输入是冻结的网格加同一组图像条件，输出是 UV 贴图。它走的是多视图扩散路线：先在若干预设视角下生成一致的 RGB 视图，再把视图颜色反投影到网格表面，最后通过 UV 参数化把表面颜色烘焙成贴图。这条路线回避了直接在 UV 域做扩散的一个根本困难——UV 域没有自然的平移不变性与局部连续性，卷积与注意力的先验在接缝处失效；而多视图域天然继承 2D 图像扩散的成熟先验。

数据流的步骤是：网格先做 UV 展开，得到从三维表面到二维参数域的映射；相机阵列按固定方位角与仰角采样，每个视角渲染出几何缓冲（深度、法线、可见性）；多视图扩散在图像条件与几何缓冲的共同约束下逐视图去噪，视图之间通过跨视图注意力或共享噪声调度保持一致性；去噪后的视图按可见性与视角权重反投影到表面点，形成带置信度的颜色样本；最后把这些样本按 UV 映射写入贴图，接缝处的样本做加权融合，不可见区域用扩散补全或对称填充。

这里的关键机制是几何缓冲对扩散的约束方式：深度与法线作为额外条件通道注入，使网络在生成颜色时知道哪块表面朝向相机、哪块被遮挡。没有这层约束，多视图扩散会在遮挡边界处生成与几何不符的颜色，反投影时把这些颜色错误地分配给背面表面。跨视图一致性则依赖注意力在视图间的信息交换，视图数越多，一致性约束越强，但注意力的计算量按视图数平方增长，这是纹理分支 scaling 的主要成本项。

失败模式集中在 UV 展开与接缝。UV 展开是组合优化问题，对高亏格、薄壁、多连通分支的网格，自动展开算法会产生重叠岛、拉伸畸变或断裂接缝。重叠岛意味着两个表面点映射到同一 UV 区域，烘焙时颜色互相覆盖；拉伸畸变意味着纹素在表面上分布不均，细节区域纹素不足。论文把 UV 失败列为明确的局限，这不是可以靠增大纹理扩散规模消除的问题——它发生在扩散之前。一个具体例子：生成一个带把手的杯子，把手与杯身连接处的凹角在自动展开中常被切成独立岛，接缝落在高曲率区域，反投影的可见性样本在接缝两侧不连续，最终贴图上出现一条颜色突变的缝。纹理真实感受数据限制则是另一层：多视图渲染监督的分布由训练资产决定，资产里稀缺的材质（比如特定工艺的釉面）在生成时倾向于回归到数据集中更常见的近似材质。

四 · 两分支的接口契约：网格、UV 与条件的共享方式

解耦架构能不能成立，取决于接口定义得是否干净。Hunyuan3D 2.0 的接口有三条：几何以网格（含法线）交付，纹理以 UV 贴图交付，图像条件在两个分支间共享但各自独立编码。共享条件而不共享权重，意味着两个分支对同一张输入图的理解可以不同——形状分支关注轮廓与遮挡关系，纹理分支关注材质与颜色分布——但都锚定在同一张图上，避免语义漂移。

接口的脆弱点在于网格的质量直接决定 UV 展开的质量，而 UV 展开的质量又直接决定纹理烘焙的质量。这条链上没有任何一环做联合优化：形状分支不知道自己的网格会被怎样展开，纹理分支不知道网格的拓扑是否友好。工程上的缓解手段是在几何后处理阶段做拓扑清理与面向展开的预处理，但这只是把失败率压低，不是消除。表格对比两条分支在接口上的关注点：

接口项形状分支的职责纹理分支的职责典型失配
网格拓扑等值面提取的连通性与亏格假设可展开为少量无重叠岛高亏格处展开断裂
法线由 SDF 梯度导出作为扩散条件通道薄壁法线翻转导致光照错误
分辨率栅格边长决定几何频率上限贴图分辨率决定颜色频率上限几何细节不足而贴图过采样
图像条件轮廓与遮挡一致性材质与颜色一致性两分支对同一区域的语义解读分歧

这张表说明接口契约不是形式上的文档，而是失败模式的分类依据。每一条失配都对应一个可观测的症状，工程上可以据此定位是几何阶段还是纹理阶段的问题，而不是笼统地归因于“生成质量不够”。

五 · 独立 scaling 的机制与它的账单

论文的核心主张是两阶段可以独立 scaling。这句话的技术含义是：形状分支的容量、数据、训练时长可以单独增加而不触动纹理分支，反之亦然。实现这一点的前提是接口的稳定性——网格与 UV 的格式不随分支规模变化，条件编码的语义不随分支规模漂移。只要接口稳定，两个分支就可以按各自的瓶颈曲线分别投入。

独立 scaling 的收益体现在消融所检验的三个维度上：形状与纹理分离、VecSet 表示、分辨率。分离带来的收益是各自监督信号不被稀释；VecSet 带来的收益是高分辨率几何不必付出稠密体素的存储代价；分辨率带来的收益是几何与纹理的频率上限同时抬升。这三者的组合使开源 3D 生成第一次在“高分辨率几何 + 纹理”这个组合上达到工业可用性，也让这一组合成为后续模型（2.1 与 Step1X-3D）的基线要求。

账单同样清晰。其一是数据：纹理分支的多视图监督需要大量带材质标注的资产，数据分布决定了材质的真实感上限，论文把纹理真实感受数据限制列为局限，说明这条曲线还没走完。其二是推理：两阶段串行加 UV 展开加烘焙，整体数十秒，交互式场景无法接受，这是解耦换来的确定性代价。其三是失败率的乘积效应：设形状阶段网格可用率为 p₁，纹理阶段在可用网格上烘焙成功率为 p₂，端到端成功率为 p₁·p₂，两个阶段各自 95% 的可用率合起来就是约 90%，误差在串行链上相乘而不是相加。这个乘积效应是双分支架构最容易被低估的系统成本。

工程判断落在接口的监控上：与其追求单个分支的极限指标，不如把网格拓扑健康度、UV 展开重叠率、接缝颜色跳变作为一等公民的运行时指标。因为在这个架构里，端到端质量的上限由最弱的那一环决定，而最弱的一环往往不在扩散网络内部，而在两个网络之间的那层格式转换上。
