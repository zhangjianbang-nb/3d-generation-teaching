一 · 两阶段训练的分工边界

Direct3D 的架构不是一个端到端网络，而是被切成两个训练阶段、三个可独立替换的模块。这个切分不是工程上的偷懒，而是把「表示学习」和「分布学习」这两类目标分开：VAE 只关心一件事——一个网格或 SDF 能否被压进潜空间再被还原回来；DiT 只关心另一件事——潜空间里的样本服从什么分布、条件如何影响这个分布。两阶段之间唯一的契约是潜变量的形状与数值范围，一旦这个契约定下来，VAE 和 DiT 可以各自独立扩展规模、独立调试。

第一阶段是 3D VAE 的重建训练。输入是资产 $\mathcal{M}$（SDF 场或网格采样得到的 occupancy/符号距离体素），编码器把它压成潜变量 $\mathbf{z}$，解码器再把 $\mathbf{z}$ 还原成 $\mathcal{M}'$。这一阶段的损失是重建损失，通常是体素级的 L1/L2 加上表面附近的加权项，目标是让 $\mathcal{M}'$ 在几何上逼近 $\mathcal{M}$。注意这一阶段完全不涉及条件、不涉及扩散，它是一个纯自编码问题。第二阶段冻结 VAE，把训练集里所有资产编码成潜变量 $\mathbf{z}$，然后训练 DiT 去拟合这些 $\mathbf{z}$ 的分布：给定加噪后的 $\mathbf{z}_t$、时间步 $t$ 和条件 $c$（图像或文本嵌入），预测噪声或速度场。

这个分工带来一个具体的系统代价：VAE 的重建误差是整条链路的误差下界。DiT 无论多强，解码出来的网格精度都不可能超过 VAE 解码器对 $\mathbf{z}_0$ 的还原能力。如果 VAE 的压缩率设得激进，潜变量维度小、DiT 训练快、显存占用低，但解码出的细节（薄壁、锐边、小孔洞）会系统性丢失；如果压缩率保守，重建好，但 DiT 要在一个高维潜空间上做扩散，注意力矩阵的规模随 token 数平方增长，训练成本立刻上去。论文的消融把 VAE 压缩率列为关键变量，正是因为这条边界决定了后面所有阶段的可行域。

举个具体例子：假设一个资产被体素化为 $64^3$ 的 SDF 网格，VAE 编码器用 3D 卷积下采样若干次，把 $64^3$ 压成 $16^3 \times C$ 的潜变量张量（$C$ 为通道数）。DiT 看到的序列长度就是 $16^3=4096$ 个 token，每个 token 是 $C$ 维向量。若把压缩率改成 $8^3=512$ 个 token，DiT 的注意力代价降一个量级，但解码器要从 512 个 token 恢复 $64^3$ 的几何，薄结构必然糊掉。这就是为什么 VAE 阶段必须先独立收敛、并且重建指标要单独报告——它是后面扩散质量的物理上限。

二 · 3D VAE：从网格到潜变量再回来

3D VAE 的编码路径要解决一个 2D VAE 不存在的问题：3D 资产没有天然的规则网格表示。网格是稀疏的、拓扑可变的、分辨率不固定的，而卷积和 Transformer 都需要张量。Direct3D 的做法是把资产转成规则体素场（SDF 或 occupancy），再在这个体素场上做 3D 卷积编码。这一步转换本身就是有损的：体素化分辨率决定了能保留的最小特征尺度，低于体素间距的薄片会被采样漏掉或混叠。

编码器的结构是 3D 卷积下采样堆叠，每一级把空间分辨率减半、通道数增加，最后得到一个低分辨率的潜变量张量。解码器是镜像的上采样路径，把潜变量逐步还原回体素场，再通过等值面提取（marching cubes 一类）转成网格。公式上这一对映射写成：

$$\mathbf{z}=\mathrm{VAE}_{\mathrm{enc}}(\mathcal{M}),\qquad \mathcal{M}'=\mathrm{VAE}_{\mathrm{dec}}(\mathbf{z})$$

关键在于潜变量的空间结构必须被保留。如果编码器把整个资产压成一个全局向量，DiT 就没有空间 token 可扩散，条件控制也无从下手；Direct3D 保留的是 $D\times H\times W$ 的三维潜网格，每个位置对应原体素场的一个局部区块。这样 DiT 的注意力可以在潜网格的 token 之间建立长程依赖，同时解码器能按位置还原局部几何。

失败模式很具体：VAE 的重建损失在训练集上收敛，但在分布外资产上崩掉。比如训练集里多为闭合的、厚度均匀的物体，遇到带细长支架或薄壳的资产时，解码器倾向于把细结构「补厚」或直接抹平，因为体素级的 L2 损失对少量薄壁像素不敏感。这不是 DiT 能修的——DiT 只会生成一个落在潜空间里的 $\mathbf{z}_0$，解码器照样把它糊掉。工程判断是：VAE 阶段要单独看表面距离指标（Chamfer 距离一类）而不只看体素 IoU，否则压缩率的选择会被体素指标误导。

另一个代价是 VAE 的潜变量尺度必须与扩散过程匹配。扩散模型假设潜变量近似标准正态，VAE 训练时通常加一个 KL 正则把 $\mathbf{z}$ 的分布往先验拉。3D VAE 上这个正则的权重很难调：太强会把几何信息压掉（潜变量趋近噪声），太弱则 DiT 要拟合一个尺度混乱的分布，训练不稳。论文把 VAE 压缩率作为消融项，实质上是在调这个权衡。

三 · DiT：潜空间里的扩散 Transformer

DiT 这一侧的数据流是标准的扩散去噪，但操作对象换成了 3D 潜网格。训练时取一个真实潜变量 $\mathbf{z}_0=\mathrm{VAE}_{\mathrm{enc}}(\mathcal{M})$，采样时间步 $t$，加噪得到 $\mathbf{z}_t$，把 $\mathbf{z}_t$、$t$ 和条件 $c$ 一起喂给 Transformer，让它预测噪声（或等价的 velocity）。推理时从纯噪声 $\mathbf{z}_T$ 出发，迭代去噪 $T$ 步得到 $\mathbf{z}_0$，再交给冻结的解码器。核心公式：

$$\mathbf{z}_{t-1}=\mathrm{DiT}_\theta(\mathbf{z}_t,t,c),\qquad \mathcal{M}'=\mathrm{VAE}_{\mathrm{dec}}(\mathbf{z}_0)$$

DiT 的输入是潜网格展平成的 token 序列。三维潜网格 $D\times H\times W$ 展平后长度是 $D\cdot H\cdot W$，每个 token 带一个 3D 位置编码，否则 Transformer 无法区分空间邻接关系。条件 $c$ 的注入方式决定了图生/文生能否共用一套骨干：图像条件通常经一个图像编码器（如预训练的视觉编码器）得到嵌入序列，文本条件经文本编码器得到嵌入序列，两者都通过交叉注意力注入 DiT 的每一层，或者通过 adaLN 一类的调制把条件统计量加到归一化参数上。论文明确支持图生与文生两种条件，说明条件编码是可替换的模块，DiT 骨干对条件类型不敏感。

伪代码层面的训练循环可以写成：取 batch 的资产，用冻结 VAE 编码成 $\mathbf{z}_0$；对每个样本采样 $t\sim\mathcal{U}(0,T)$ 和噪声 $\epsilon\sim\mathcal{N}(0,I)$；构造 $\mathbf{z}_t=\alpha_t\mathbf{z}_0+\sigma_t\epsilon$；把 $(\mathbf{z}_t,t,c)$ 送入 DiT 预测 $\epsilon_\theta$；损失为 $\|\epsilon-\epsilon_\theta\|^2$。注意 VAE 在这一步是冻结的，梯度不回传到编码器——这是两阶段训练的硬边界，也是训练成本的主要来源之一：潜变量要预先算好并缓存，否则每个 step 都要跑一遍 VAE 前向。

系统代价集中在注意力规模上。潜网格 token 数是 $D\cdot H\cdot W$，自注意力的计算与显存都是 token 数的平方级。把潜网格从 $16^3$ 提到 $32^3$，token 数从 4096 涨到 32768，注意力代价涨约 64 倍，单卡放不下，必须切分或换稀疏注意力。论文把 DiT 规模列为消融项，背后就是这条 scaling 曲线：模型容量和 token 数要一起调，单独放大参数量而不动 token 数，收益会饱和。失败模式则是条件塌陷——如果条件注入太弱（比如只在输入层拼一次），DiT 会退化成无条件生成，图生结果与输入图无关；交叉注意力每层注入是防止这一点的手段，但代价是每层多一份条件序列的注意力开销。

四 · 条件编码与多格式输出的接口

条件编码模块的分工是把异构输入（一张图或一段文本）映射成 DiT 能消费的嵌入序列。图像侧需要一个能把 2D 像素转成 token 的编码器，文本侧需要一个语言模型编码器。两者的输出维度要对齐到 DiT 的隐藏维度，否则交叉注意力的 key/value 投影要额外做适配。这一步的具体机制是：条件嵌入序列作为 cross-attention 的 key 和 value，DiT 的潜 token 作为 query，每一层都做一次条件查询。这样条件信息在去噪的每个时间步、每一层都被重新读取，而不是一次性注入。

输出侧的多格式支持来自解码器之后的处理链。VAE 解码出的是体素场（SDF 或 occupancy），要变成可用资产还需要等值面提取得到网格，再根据目标格式做转换。论文说支持多格式输出，意味着这条后处理链是可配置的：同一份 $\mathbf{z}_0$ 可以走不同的提取参数或转换路径，得到不同分辨率或不同表示的资产。这里有一个工程上的接口约定：解码器输出的体素场分辨率决定了网格的上限精度，后处理只能在这个上限内做取舍，不能凭空增加细节。

纹理是这条链路上的一个明确缺口。几何由 VAE 解码器给出，但颜色/材质不在 3D VAE 的潜变量里——论文把纹理列为需要后处理的局限。具体机制上，几何生成完之后要另跑一个纹理化流程（比如多视图投影加融合，或专门的纹理生成网络），把颜色贴到网格表面。这意味着 Direct3D 的推理链路不是「一次前向出成品」，而是「几何前向 + 纹理后处理」两段，后一段的耗时和失败模式（视角覆盖不全导致贴图空洞、接缝错位）不在 DiT 的控制范围内。

举个条件接口的具体例子：图生模式下，输入是一张单视图渲染图，图像编码器输出一组 patch token；DiT 在去噪每一步用这组 token 做交叉注意力，逐步把噪声潜变量拉向与该视图一致的几何。如果输入视图只看到物体的正面，背面几何没有任何条件约束，DiT 只能靠先验补全——这是单视图条件的固有欠定性，不是架构缺陷，但工程上要预期背面质量低于正面。文生模式则相反，条件是一段文本嵌入，约束更粗，几何多样性更高但可控性更低。

五 · 端到端数据流与各阶段的耦合代价

把链路串起来看，从输入到输出是：条件输入（图/文）→ 条件编码器 → 条件嵌入序列；同时从纯噪声 $\mathbf{z}_T$ 开始，DiT 在条件引导下迭代去噪 $T$ 步 → $\mathbf{z}_0$；$\mathbf{z}_0$ 送入冻结的 VAE 解码器 → 体素场 → 等值面提取 → 网格 → 纹理后处理 → 最终资产。训练侧则是：资产 → 体素化 → VAE 编码 → 缓存潜变量 → DiT 扩散训练。两条链路共享的是 VAE 和解码器，DiT 只在潜空间里活动。

这条数据流上有三处耦合代价需要说清楚。第一处是 VAE 与 DiT 的分布耦合：DiT 学的是 VAE 潜变量的分布，如果 VAE 换了（重训或换压缩率），DiT 必须重训，缓存全部失效。第二处是条件编码器与 DiT 的维度耦合：换一个图像编码器就要重训条件注入层，甚至整个 DiT。第三处是解码器分辨率与后处理的耦合：解码器输出的体素分辨率固定，后处理链只能在这个分辨率下工作，想要更高精度的网格就得重训 VAE 解码器或加一个超分模块。

训练成本的量级来自这些耦合。论文说在 Objaverse 上训练需要数十 GPU 天，这个数字对应的是两阶段之和：VAE 重建训练要跑遍全数据集并收敛重建指标，DiT 扩散训练要在缓存好的潜变量上跑大量 step，且 token 数大、注意力重。推理则是数秒级，因为去噪步数是固定的 $T$ 步前向加一次解码，没有训练时的反向与数据遍历。这个「训练贵、推理快」的剖面是潜空间扩散路线的典型特征，也是它相对前馈重建模型（一次前向出结果但分辨率受限）的取舍点。

失败模式在端到端层面表现为误差叠加而非抵消。VAE 解码器对薄结构的抹平，叠加 DiT 在欠定条件下的先验补全，再叠加纹理后处理的视角空洞，最终资产的缺陷可能来自三处中的任意一处，而端到端指标（比如渲染图的感知质量）无法区分归因。工程判断是：调试时必须分段评估——先单独测 VAE 重建的 Chamfer 距离，再测 DiT 在已知 $\mathbf{z}_0$ 下的去噪误差，最后测后处理链的覆盖率。把三段分开看，才能定位是压缩率选错、条件注入太弱，还是纹理流程没覆盖背面。论文的消融按 VAE 压缩率、DiT 规模、条件类型三项拆开，正是这条分段归因思路的体现。

最后一个具体机制层面的判断：Direct3D 把 2D 潜空间扩散的「VAE + DiT」配方原样搬到 3D，真正的工程难点不在 DiT 的 Transformer 结构（那是成熟的），而在 3D VAE 的体素化-潜变量-解码这条有损链，以及条件注入如何在三维 token 序列上保持空间一致性。后续 TRELLIS、Hunyuan3D 2.x 采用类似结构，说明这条分工边界是被验证可行的；但纹理后处理仍留在链路之外，说明「几何潜空间」与「外观潜空间」的统一还没有在这套架构里解决。
