一 · 45 分钟课表：从“一张照片为什么能约束三维”排到“哪里不能照搬”

给新工程师讲 NeRF，最容易犯的错误是按论文的章节顺序讲：先讲背景，再讲方法，再讲实验。这样讲完，听众记住了“有个 MLP 输出颜色和密度”，但说不清这套东西为什么能收敛、代价花在哪里。45 分钟的排法应该反过来，从工程直觉出发，先建立“可微渲染回路”的心智模型，再往里填公式和实现细节。下面这张表是可直接照用的时间分配。

时段内容目标
0–5 min问题现场：离散表示的三条死路让听众认同“连续表示”不是审美选择，而是被显存和采样密度逼出来的
5–15 min核心回路：5D 函数 + 体渲染积分 + RGB 损失画出一条从像素到参数梯度的完整链路
15–25 min架构细节：位置编码、跳跃连接、视角相关分支、两阶段采样讲清每个部件去掉后会发生什么
25–33 min训练配方与代价核算让听众能估算一次训练的时间与显存
33–40 min三个类比 + 两个常见误解纠正“NeRF 是三维重建”“NeRF 输出网格”这类错位期待
40–45 min五道自测题现场作答检验听众是否真的掌握了回路而非名词

这个排法的关键取舍是：把实验数字压到 3 分钟以内，只讲“合成数据集 PSNR 30.5 dB 左右、LLFF 真实场景约 26.5 dB、去掉位置编码掉到 28 以下”这三个锚点，其余时间全部留给机制。因为对工程师而言，PSNR 是结果，机制才是可迁移的知识。

二 · 三个类比：把抽象回路钉在工程直觉上

第一个类比：把 NeRF 想成一台“可调参数的雾机”。场景不是一堆三角面，而是一团充满整个空间的雾，每一点都有自己的颜色和浓度。相机射线穿过这团雾，沿途累积颜色，浓的地方遮挡后面的东西，稀的地方几乎透明。体渲染积分做的就是这件事：

$$C(\mathbf{r})=\int_{t_n}^{t_f}T(t)\,\sigma(\mathbf{r}(t))\,\mathbf{c}(\mathbf{r}(t),\mathbf{d})\,dt,\qquad T(t)=\exp\!\left(-\int_{t_n}^{t}\sigma(\mathbf{r}(s))\,ds\right)$$

其中 T(t) 是透射率，物理含义是“光从 t_n 走到 t 没被挡住的比例”。这个类比的价值在于：它立刻解释了为什么密度 σ 必须是标量且非负、为什么颜色要乘透射率、为什么沿射线越往后贡献越小。它也解释了失效模式——如果雾的浓度处处接近零，梯度信号极弱，网络会退化成一片均匀色；如果浓度处处极大，透射率迅速归零，远处的几何永远学不到。实际训练中这两种退化都会出现，表现为渲染图整体发灰或整体发黑。

第二个类比：位置编码是“把坐标翻译成一组不同频率的探针”。原始坐标 (x,y,z) 是三个低频标量，直接喂给 MLP，网络倾向于学出过度平滑的函数，细节被抹平。位置编码把每个坐标映射成 sin/cos 的多个频段（坐标 L=10、方向 L=4），相当于给网络一组“从粗到细的尺子”。消融里去掉位置编码 PSNR 掉到 28 以下，正是这个类比的实证：不是网络容量不够，而是输入本身没有携带高频信息，MLP 无法凭空造出细节。工程上要提醒的是，编码维度随 L 线性增长，L 调大能提升细节，但同时放大显存与计算，且过高频段在稀疏视角下容易过拟合出噪声。

第三个类比：粗采样 + 细采样是“先撒网定位，再在鱼群处下细钩”。粗网络沿射线均匀采样一批点，算出粗略的密度分布；细网络根据这个分布做逆变换采样，把点集中到密度高的区段。这本质是一种重要性采样，用第一次前向的结果指导第二次采样的位置。代价是每条射线要做两次网络前向，训练和渲染的计算量翻倍；收益是同样的采样点数下，积分估计的方差显著下降，细节不再糊。消融中去掉分层采样细节变糊，说的就是这个方差问题。

三 · 两个常见误解：讲清楚“不是什么”比讲“是什么”更省时间

误解一：“NeRF 是一种三维重建方法，训练完能导出网格或点云。”这是最普遍也最危险的错位期待。NeRF 优化的对象是一个 5D 连续函数 F(x,y,z,θ,φ)→(RGB,σ)，它没有显式的几何载体，密度场只是体渲染的中间量。要拿到表面，必须额外做等值面提取（比如在密度场上跑 marching cubes），而密度场在表面附近往往是软过渡而非硬边界，提取出来的网格质量取决于阈值选取，且对透明、薄结构、反射面基本无能为力。论文本身的局限里写明“静态、无反射/透明建模”，这意味着把它当“扫描仪”用会直接撞墙。工程判断是：NeRF 适合做新视角渲染与可微渲染底座，不适合直接当资产生产管线里的几何源。

误解二：“NeRF 训练好之后可以泛化到新场景，像普通神经网络那样推理。”事实相反：它是单场景过拟合式优化，一个场景一套参数，换场景必须重训。每次随机采 4096 条射线、渲染像素与真值算 MSE、Adam 从 5e-4 指数衰减到 5e-5、一个场景通常 100–300k 步、数小时到一天——这套配方里没有任何“跨场景共享”的成分。所以它无法前馈泛化，渲染也慢，难实时。这个误解的工程后果是排期错误：有人以为“训练一次，部署到处用”，实际是“每个场景一条独立训练流水线”。后续 Instant-NGP 解决的是速度，3DGS 换成显式基元，NeuS 换成 SDF，生成侧的 SDS 拿它当可微渲染器——这些继承者改的都是“怎么更快、怎么更显式”，而不是“怎么一次训练泛化所有场景”。

四 · 五道自测题：检验回路是否真的建立

第一题：给定一条相机射线，写出从 MLP 参数到像素 RGB 的完整前向链路，并指出梯度从哪一步回传。期望答案要覆盖：射线参数化 r(t)=o+td → 采样 t 值 → 坐标过位置编码 → 8 层 256 宽 MLP 带跳跃连接输出 σ 与 256 维特征 → 特征与方向编码拼接再过一层 MLP 得视角相关 RGB → 按体渲染积分加权求和得 C(r) → 与真值算 MSE。关键点是积分对 σ 和 c 都是可微的，梯度经由采样点的网络输出回传到 MLP 参数，采样位置本身不参与求导。答不出“采样位置不求导”的人，通常也没理解为什么这是“可微渲染”而非“可微采样”。

第二题：为什么密度 σ 只依赖坐标而不依赖视角方向，而颜色 c 依赖两者？期望答案：密度是几何属性，同一空间点从任何方向看浓稠程度相同；颜色是外观属性，同一表面点从不同方向看可以有不同的反射颜色，这正是视角相关高光的来源。消融里去掉视角方向高光消失，验证了这个分工。反过来，如果让 σ 也依赖方向，几何会随视角漂移，多视角一致性被破坏，训练会震荡。

第三题：粗网络和细网络各自的作用是什么，为什么不能只留一个？期望答案：粗网络做均匀采样给出粗略密度分布，细网络据此做重要性采样把点集中到高密度区段，降低积分估计方差。只留粗网络，固定采样点数下细节区段采样不足，结果变糊；只留细网络，没有先验分布无法定位该往哪里采样。代价是每条射线两次前向，计算量翻倍——这是用算力换方差的典型交易。

第四题：位置编码的 L 从 10 调到 20，预期会发生什么？期望答案：输入维度增加，网络能表达更高频细节，但显存与计算上升；同时高频基在视角稀疏时更容易拟合出噪声，出现过拟合。这不是单调收益，需要和采样密度、视角覆盖一起权衡。注意方向编码 L=4 通常小于坐标编码，因为视角相关外观的变化频率低于几何细节。

第五题：如果要给一个静态场景做验收，你会断言哪些指标，哪些断言不能下？期望答案：能断言的是留出视角的 PSNR（合成数据 30.5 dB 量级、LLFF 真实场景 26.5 dB 量级作为参照）、消融对照（去位置编码、去方向、去分层采样各自的退化方向）、训练步数与收敛曲线。不能断言的是“导出网格的几何精度”“实时渲染帧率”“跨场景泛化能力”——这三项都超出论文的表示与训练范式。答错这一题的人，往往会把 NeRF 塞进错误的工程位置。

五 · 讲课时必须点破的一处实现陷阱：采样与积分的离散化误差

45 分钟里最容易被跳过、但工程上最致命的一环，是连续积分怎么变成离散求和。体渲染公式是连续积分，实现时必须用有限个采样点做数值积分，通常是矩形法或分层采样后的加权和。这里有两个误差源：其一是采样点数量，点太少则积分估计方差大，表现为画面噪点；其二是采样点的分布，均匀分布在密度剧烈变化处会漏掉薄结构。粗采样 + 细采样正是针对第二个误差源的设计，但它不消除第一个——细采样只是把点挪到该在的地方，点数上限仍由算力决定。

伪代码思路可以这样讲：对每条射线，先在 [t_n, t_f] 上均匀取 N_c 个 t，前向得 σ_i 与 c_i，按离散透射率累加得粗颜色；再由 σ_i 构造分段常数概率密度，做逆变换采样得 N_f 个新 t，与粗采样点合并排序后统一做一次精细积分。注意合并后要重新计算透射率，不能把两批点的贡献简单相加，否则透射率会被重复计入。这个细节在复现时经常出错，症状是渲染图整体偏亮、远处物体异常清晰——因为透射率被高估，遮挡关系被削弱。

系统代价要算清楚：每条射线两次 MLP 前向，每次前向是 8 层 256 宽加一层输出，参数量不大但前向次数极多；每次训练采 4096 条射线，每条射线几十个采样点，等于每步数十万次 MLP 前向。这就是“数小时到一天”训练时间的来源，也是渲染慢、难实时的根源。工程判断是：NeRF 的瓶颈不在参数量而在前向次数，任何加速方案（缓存、显式结构、更少的采样点）本质上都是在削减这个次数，而不是在缩小网络。

六 · 把课讲成“可复现的判断”而非“论文摘要”

最后 5 分钟不应该复述结论，而应该让听众带走三条可操作的判断。第一条：NeRF 的核心资产是“可微渲染 + 2D 监督”这个回路，而不是某个具体网络结构；理解了回路，就能理解为什么 Instant-NGP 换哈希网格、3DGS 换显式基元、NeuS 换 SDF、SDS 拿它当渲染器，都是在同一回路上换零件。第二条：单场景优化意味着每个场景一条训练流水线，排期时要把“数小时到一天”乘以场景数，而不是当成一次性的模型训练。第三条：验收断言要卡在表示范式之内——留出视角 PSNR、消融退化方向、收敛步数可以断言，网格精度、实时帧率、跨场景泛化不能断言。

这三条判断的落点，其实是同一个机制：NeRF 把几何与外观压进一个连续 5D 函数，用体渲染积分把它投影成像素，再用像素误差反传。所有能力与所有局限都从这个机制里长出来——连续所以可微、可微所以能用 2D 监督、单场景所以不泛化、逐射线积分所以慢。讲课时只要让听众能自己从这个机制推出上述四条推论，这 45 分钟就算讲透了；推不出来，记住再多名词也只是复述。
