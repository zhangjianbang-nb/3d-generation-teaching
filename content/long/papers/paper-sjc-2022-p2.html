一 · 从参数到像素：一条可微分的正向通路

SJC 的整个方法可以看成一条从 3D 参数 θ 到 2D 像素 x 的可微通路，得分估计与采样都建立在这条通路的可导性上。正向通路的第一步是 3D 表示：论文允许 NeRF 体密度场或显式网格，二者都参数化为 θ。第二步是可微渲染器 R，它把 θ 与相机位姿 c 一起映射成一张渲染图 x = R(θ, c)。第三步才是预训练 2D 扩散模型，它不参与正向渲染，只在图像空间给出得分。这条通路的关键性质是：x 对 θ 的偏导 ∂x/∂θ 必须存在且可计算，因为链式法则的乘数就是它。

把这三段串起来的直接后果是，3D 参数空间里没有独立的概率模型。SJC 不训练一个 3D 先验，也不在 3D 数据上做扩散；它把 2D 扩散模型当作唯一的分布来源，3D 分布是从 2D 分布经渲染映射“拉回”得到的。用测度论的语言说，若 θ 上的分布经 R 推前得到图像分布，则图像得分乘雅可比给出的是 θ 空间得分的一个估计，而不是 θ 空间本身的得分。这个区别决定了后面所有工程细节：估计是有偏的、方差大的、依赖相机采样的。

正向通路的系统代价集中在渲染器上。每取一个得分样本，就要做一次前向渲染得到 x，再做一次反向传播把图像空间的梯度乘上 ∂x/∂θ 传回 θ。NeRF 的体积渲染需要对每条光线做大量采样点求值，网格渲染则要处理光栅化与可见性，两者的反向代价都不低。更麻烦的是，渲染图 x 必须落在扩散模型训练分布之内：分辨率、视角、背景、光照都要与预训练数据匹配，否则 ∇log p_t(x) 给出的方向本身就不可信。这是 SJC 在实现上绕不开的失败模式——渲染器与扩散模型之间的域差会直接污染得分。

举一个具体例子：优化一个 NeRF 表示的椅子时，θ 是密度场与颜色场的网络权重。取一个随机相机位姿 c，渲染出 64×64 的图像 x，把它加噪到扩散时间步 t，送入冻结的 Stable Diffusion 得到图像得分，再乘上渲染雅可比，得到对网络权重的梯度。一次迭代的完整数据流就是 θ → x → 噪声图像 → 图像得分 → 乘雅可比 → θ 梯度。任何一步断开，整条链就失效。

二 · 得分链式法则：把图像梯度搬回参数空间

核心公式是 SJC 全部理论重量的落点：

$$\nabla_\theta\log p(\theta)\approx\mathbb{E}\!\left[\nabla_x\log p_t(x)\frac{\partial x}{\partial\theta}\right],\qquad \theta\leftarrow\theta+\eta\nabla_\theta\log p(\theta)+\sqrt{2\eta}\,\xi$$

左半部分是得分估计，右半部分是退火 Langevin 更新。理解这条公式要分两层。第一层是链式法则：若 x 是 θ 的确定性函数，则 θ 空间的对数密度梯度等于图像空间得分与雅可比的乘积，再对相机与噪声取期望。第二层是期望的位置：∇log p_t(x) 是在加噪图像上取的，t 是退火 schedule 上的当前噪声水平，因此这个估计随 t 变化，不是一个固定的 3D 得分，而是一族随噪声尺度变化的得分。

伪代码层面的流程可以写成：对每个外层步，采样相机位姿 c 与噪声水平 t；渲染 x = R(θ, c)；采样噪声 ε 得到 x_t；查询扩散模型得到 s_x = ∇log p_t(x_t)；反向传播计算雅可比向量积 J^T s_x，即把图像梯度乘 ∂x/∂θ 传回 θ；累加为 g；执行 θ ← θ + η g + sqrt(2η) ξ。这里 J^T s_x 不是显式构造雅可比矩阵再相乘，而是用自动微分做向量-雅可比积，这是让方法可行的工程关键，否则雅可比矩阵的维度会让显存直接爆掉。

这条链的代价与失败模式都很具体。其一是方差：s_x 本身是随机量，相机 c 与噪声 ε 又各引入一层随机性，单步梯度噪声很大，需要多次采样平均，而每次采样都要付一次渲染与一次扩散前向的代价。其二是雅可比近似的偏差：渲染过程包含遮挡、可见性跳变等不可微或弱可微环节，∂x/∂θ 在这些位置不可靠，梯度会指向错误方向。其三是得分模型的域差：如果渲染图带有扩散模型没见过的背景或色调，s_x 会给出与物体结构无关的方向。消融里专门检查了雅可比近似与得分模型选择，正是因为这两处是偏差的主要来源。

一个能说明问题的例子：优化早期 θ 还是模糊的团块，渲染图与任何真实物体都不像，此时 ∇log p_t(x_t) 在低噪声步上给出的方向接近于把图像推向“像某个东西”的通用方向，而不是具体结构。SJC 用多尺度退火来对付这一点：先在高噪声步上取粗粒度方向，让团块先收敛到大致形状，再逐步降低噪声细化细节。退火 schedule 因此不是可有可无的调参项，而是让得分估计在“图像不像物体”的阶段仍然有用的必要机制。

三 · 多尺度退火 Langevin：噪声日程即优化日程

退火 Langevin 动力学的标准形式是 θ ← θ + η∇log p(θ) + sqrt(2η) ξ，其中 ξ 是标准高斯噪声。SJC 把它搬到 3D 参数上，但得分不是固定的，而是随扩散时间步 t 变化的一族。于是“退火”有两重含义：一是 Langevin 自身的步长与噪声随优化进程衰减，二是扩散模型的噪声水平 t 从高到低推进。这两重退火在实现上被绑成一条 schedule，粗尺度对应高噪声，细尺度对应低噪声。

机制上，高噪声步的扩散得分对图像细节不敏感，只对大体轮廓与语义有反应，因此在这一阶段更新 θ 相当于在参数空间做大步长的粗搜索；低噪声步的得分对纹理与边缘敏感，更新变成小步长的细化。这个从粗到细的顺序与图像生成的 coarse-to-fine 直觉一致，但 SJC 的版本有概率论依据：每个 t 对应一个被平滑过的分布，退火过程是在一族逐渐锐化的分布上依次采样，而不是在单一分布上做随机梯度下降。

系统代价在于 schedule 的设计与计算预算的分配。每个 t 都要跑若干步 Langevin，步数太少则粗尺度没收敛，步数太多则计算量爆炸；t 的下降速率太快会让参数在粗尺度还没稳定时就进入细尺度，得到的是局部模糊的解。论文把退火 schedule 列为消融对象，说明它对结果的影响不是次要的。另一个代价是随机项 sqrt(2η) ξ 在 3D 参数上的作用：对 NeRF 的网络权重加噪，噪声会通过渲染放大成图像上的高频扰动，若 η 不随尺度调整，细尺度阶段会被噪声主导。

具体例子：一条典型的 schedule 会先在较高的 t 上跑较多步，让 θ 从随机初始化收敛到可辨认的轮廓；随后把 t 分几档下降，每档减少步长 η，同时减少 Langevin 步数；最后在低 t 上做少量细化步。整个资产优化数小时，时间主要花在渲染与扩散前向的反复调用上，而不是花在参数更新本身。这也解释了为什么 SJC 的速度与质量提升有限：它的计算结构比 SDS 更重，收益却主要落在理论严格性上。

四 · 模块分工：冻结的扩散、可训的表示、被借用的雅可比

把架构拆成模块看，分工非常清楚。预训练 2D 扩散模型是冻结的，只提供图像空间得分，不参与训练，也不接收 3D 梯度；它的角色是一个固定的分布评判器。3D 表示是可训的，NeRF 或网格的参数 θ 是唯一的优化变量；所有更新都落在 θ 上。可微渲染器是桥梁，它既产生正向的 x，又在反向提供 ∂x/∂θ；它不含有可学习的参数，但它的可微性质量直接决定得分链的质量。得分链式法则模块是粘合剂，把图像梯度转成参数梯度。多尺度退火 Langevin 是外层控制器，决定何时用哪个噪声水平、步长多大、跑多少步。

这个分工带来一个结构性后果：整个系统的质量上限由最弱的一环决定，而最弱的一环通常是渲染器与扩散模型之间的匹配度。冻结扩散模型不能被微调去适应渲染风格，渲染器也不能被训练去迎合扩散模型，二者之间的域差只能靠工程手段（分辨率、背景、视角分布）去缩小。这是 SJC 实现复杂的根源之一：它不是调一个模型，而是调一条跨模型的通路。

另一个分工细节是相机位姿 c 的处理。c 是得分期望里的随机变量，每次采样都要重新抽；它不被优化，但它的分布决定了 3D 物体被从哪些角度评判。若相机分布过窄，物体只在少数视角上像样，其他视角会崩；若过宽，单次更新的信号被稀释。这个取舍在实现里体现为相机采样的策略，属于数据流里容易被忽略但影响很大的一步。

五 · 一次迭代的完整数据流与它的断点

把一次迭代逐步画出来：初始化 θ（随机 NeRF 权重或模板网格）；进入外层循环，按 schedule 取当前噪声水平 t 与步长 η；内层循环采样相机 c，渲染 x = R(θ, c)；对 x 加噪到 t 得到 x_t；把 x_t 与 t 送入冻结扩散模型，取图像得分 s_x；反向传播，用向量-雅可比积算 J^T s_x，累加得到 g；执行 θ ← θ + η g + sqrt(2η) ξ；内层步数用尽后下降 t，重复；外层 schedule 走完后输出 θ 对应的 3D 资产。每一步的输入输出都是确定的，链上没有隐藏状态，这也是 SJC 相对 SDS 更容易讲清楚的地方。

断点出现在三处。第一处是渲染图与扩散模型分布不匹配：x 的统计特性偏离预训练数据，s_x 的方向失真。第二处是雅可比在遮挡边界与可见性跳变处不可靠，J^T s_x 在这些位置给出错误方向，表现为物体表面出现不该有的凸起或空洞。第三处是方差：单次采样的 g 噪声太大，若平均次数不足，Langevin 的随机项会盖过信号，优化在原地抖动。这三处断点分别对应消融里的得分模型选择、雅可比近似与退火 schedule，说明论文自己也知道偏差来自哪里。

具体例子：优化一个网格表示的物体时，可见性跳变会让某些面的梯度突然翻转，表现为面片在两步之间来回翻折；NeRF 表示则更多表现为密度场在边界处的模糊扩散，因为体积渲染的雅可比在低密度区数值很小，梯度传不回去。两种表示下的断点形态不同，但根源相同：正向通路的可微性不是全局成立的。工程上的应对是降低对这些位置的依赖，比如用更平滑的渲染近似、在 schedule 上避开最敏感的噪声档，而不是指望雅可比处处准确。

从数据流的角度看，SJC 与 SDS 的差别不在更新式的形式，而在更新方向的来源。SDS 用噪声差作为方向，是一个启发式的替代量；SJC 用图像得分乘雅可比，是一个有链式法则依据的估计量。二者在实现上都要渲染、都要查询扩散模型、都要反向传播，计算结构相似，但 SJC 多了一层显式的雅可比向量积，也多了一层对估计偏差的自觉。这正是它“把启发式变成可推导的得分链”的落点：不是换了一个更强的模型，而是把同一条通路的每一步都写成了可推导的形式，代价是实现更复杂、方差更大、质量提升有限。
