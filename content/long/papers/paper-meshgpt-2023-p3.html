一 · 两阶段目标：重建项与似然项各自优化什么

MeshGPT 的训练不是一个端到端可微的联合目标，而是把「网格能否被离散词表无损表达」和「词表序列能否被自回归模型学会」拆成两个独立优化问题。第一阶段训练图卷积 VQ-VAE，目标是让编码器-量化-解码器这条链路在重建意义上逼近原始网格；第二阶段冻结词表与解码器，只训练 decoder-only Transformer 在 token 序列上的条件似然。这个拆分决定了梯度的来源完全不同：第一阶段梯度穿过量化算子（用直通估计器 STE 近似），第二阶段梯度只来自离散 token 的交叉熵，与几何本身没有直接联系。

第一阶段的重建损失由三部分组成。重建项度量解码器输出的面片顶点坐标与真实面片顶点坐标之间的差异，通常取逐坐标的 L1 或 L2；量化项把编码器输出拉向量化表中被选中的嵌入，使码本不至于漂移；承诺项（commitment loss）则约束编码器输出不要频繁跳动，稳定码本分配。写成统一形式：

$$\mathcal{L}_{\text{VQVAE}}=\underbrace{\|\hat{V}-V\|_2^2}_{\text{重建}}+\underbrace{\|\mathrm{sg}[z_e]-e_k\|_2^2}_{\text{码本}}+\underbrace{\beta\|z_e-\mathrm{sg}[e_k]\|_2^2}_{\text{承诺}}$$

其中 $z_e=\mathrm{GCN}(\text{face}_i)$ 是图卷积编码器对面片局部几何与拓扑的输出，$e_k$ 是码本中第 $k$ 个嵌入，$\mathrm{sg}[\cdot]$ 表示停止梯度，$\beta$ 是承诺项权重。关键机制在于：量化操作 $\arg\min_k\|z_e-e_k\|$ 本身不可导，梯度通过 STE 直接复制为恒等映射回传给编码器，因此编码器收到的梯度信号实际上是「解码器希望这个面片长什么样」，而不是量化误差本身。这个近似在码本利用率高时工作良好，一旦出现码本坍缩（大量面片被映射到少数几个嵌入），重建梯度就会集中在这几个嵌入上，其余嵌入长期得不到更新，形成死码。

这里的 $p_\theta$ 是 softmax 后的词表分布，$\theta$ 只包含 Transformer 参数。注意 $t_i$ 的语义不是「第 i 个顶点」，而是「第 i 个面片的量化嵌入索引」，一个 token 对应一个三角面。序列长度 $N$ 因此等于网格面数，这直接解释了论文指出的序列长度限制：面数越多，$N$ 越大，注意力代价按 $O(N^2)$ 增长，位置编码外推也更困难。训练时对每个网格独立计算该损失并对 batch 求平均，没有任何几何正则项进入这一阶段——几何正确性完全由第一阶段冻结的解码器保证。

一个具体的失败模式是两阶段目标不一致：第一阶段优化的是「平均重建误差最小」，因此码本倾向于把常见面片配置压缩得很准、把罕见配置压得很糙；第二阶段却按 token 频率学习分布，罕见配置的 token 在训练集中出现次数少，交叉熵梯度弱，采样时几乎不被选中。结果是生成的网格在常见区域（如椅面、桌面）很干净，在过渡区域（如椅腿与座面连接处）出现面片缺失或穿插。这不是 Transformer 容量不足，而是两阶段目标没有对齐「几何保真」与「分布覆盖」的权衡。

二 · 变量含义：从面片到 token 的每一步映射

把公式里的符号逐一落地，才能看清梯度到底在优化什么。设网格 $\mathcal{M}=(V,F)$，$V$ 是顶点坐标集合，$F$ 是三角面索引集合。对面片 $f_i\in F$，取其局部邻域——与该面片共享顶点或边的一圈面片——构成子图，送入图卷积编码器。图卷积在此处的具体机制是：节点特征沿网格的边做消息传递，每层聚合邻居特征后线性变换，因此编码器看到的不是孤立的三个顶点坐标，而是「这个面片周围的面片如何排布」。这是 MeshGPT 与把面片当无序点集处理的做法之间的核心差别。

编码器输出 $z_e\in\mathbb{R}^{d}$，$d$ 是嵌入维度。量化步骤在码本 $E=\{e_1,\dots,e_K\}$ 中找最近邻：$k=\arg\min_j\|z_e-e_j\|_2$，$t_i=k$。这里 $K$ 是词表大小，是消融实验里被重点考察的超参：$K$ 太小，词表无法区分不同局部拓扑，重建退化；$K$ 太大，码本利用率下降，大量嵌入成为死码，且 Transformer 的 softmax 输出维度变大、每个 token 的监督信号变稀疏。论文的消融正是围绕这个权衡展开的。

解码器接收 $e_k$ 与面片的参考信息，输出三个顶点的坐标 $\hat{V}_i\in\mathbb{R}^{9}$（或带索引的离散化形式）。注意顶点在网格中是共享的，相邻面片必须引用同一顶点，因此解码器不能独立地为每个面片生成坐标，否则会产生裂缝。MeshGPT 的处理方式是在序列化时让 token 携带顶点引用信息，解码阶段按序列顺序合并顶点，这也是为什么序列顺序本身携带拓扑信息——顺序错了，顶点合并就会错。

这里有一个容易被忽略的系统代价：$t_i$ 是离散索引，它把「面片长什么样」压缩成一个整数，信息损失不可逆。如果两个面片的局部几何差异落在同一个 Voronoi 区域内，它们共享同一个 token，解码器只能输出该 token 对应的那个代表面片。这意味着重建误差的下界由码本的划分粒度决定，而不是由解码器容量决定。工程判断上，这意味着调大解码器不会改善重建，只有调码本或改编码器特征才有用。

三 · 梯度路径与采样：直通估计与逐 token 解码

VQ-VAE 的梯度路径是整条链路里最反直觉的部分。前向是 $z_e\rightarrow k\rightarrow e_k\rightarrow\hat{V}$，反向时 $\partial\hat{V}/\partial e_k$ 正常回传，但 $\partial e_k/\partial z_e$ 在数学上为零（最近邻选择是分段常数）。STE 的做法是在反向时把这一步的雅可比近似为单位矩阵，于是编码器收到的梯度等于解码器对嵌入的梯度。伪代码层面可以写成：

  • 前向：$k=\arg\min_j\|z_e-e_j\|$；$z_q=e_k$；$\hat{V}=\mathrm{Dec}(z_q)$
  • 反向：$\nabla_{z_e}\mathcal{L}\leftarrow\nabla_{z_q}\mathcal{L}$（STE）；$\nabla_{e_k}\mathcal{L}\leftarrow\nabla_{z_q}\mathcal{L}+\nabla_{\text{codebook}}\mathcal{L}$
  • 码本更新：$e_k\leftarrow e_k-\eta(\nabla_{e_k}\mathcal{L})$，或用指数滑动平均替代梯度更新

STE 的失败模式是梯度与真实量化误差脱节：当 $z_e$ 离 $e_k$ 很远时，前向仍然用 $e_k$，反向却告诉编码器「你就该输出 $z_e$」，编码器会持续把 $z_e$ 推离码本，直到承诺项把它拉回。承诺项权重 $\beta$ 因此是一个稳定器：太小则编码器漂移、码本利用率下降；太大则编码器被钉死在码本附近，失去表达力。论文没有给出 $\beta$ 的具体数值，只说明通过消融验证了图卷积编码器相对 MLP 编码器的优势，这说明局部拓扑特征的提取质量比损失权重的微调更关键。

四 · 训练配方与关键超参：两阶段各自的敏感项

第一阶段的可调项集中在码本与编码器：码本大小 $K$、嵌入维度 $d$、承诺项权重 $\beta$、图卷积层数与邻域半径。论文的消融明确考察了词表大小与图卷积 vs MLP 两组，结论指向「局部拓扑必须由图卷积捕获」以及「词表大小存在可用区间」。工程上，$K$ 的选择要与数据规模匹配：ShapeNet 的椅子、桌子、飞机等类别面片局部构型有限，$K$ 过大只会制造死码；$K$ 过小则把不同构型混为一谈，重建出现系统性偏差。嵌入维度 $d$ 决定每个 token 能携带多少几何细节，但 $d$ 增大也会让码本在同样 $K$ 下更难被充分利用。

第二阶段的可调项集中在 Transformer：层数、注意力头数、隐藏维度、上下文长度、学习率与 warmup。上下文长度必须覆盖训练集中最长序列，否则长网格被截断，模型学不到收尾模式；但上下文越长，注意力代价越高。论文给出的训练规模是单卡数天、ShapeNet 数据集，这个量级说明模型并非靠海量数据堆出来的——数据规模小是论文自己承认的局限，也意味着超参搜索空间有限，过拟合风险实际存在。工程判断上，这类小数据配方对类别平衡敏感：椅子样本多、飞机样本少时，模型对飞机面片构型的 token 预测会偏弱。

两阶段之间的耦合超参是序列化顺序。面片按什么顺序排成序列，决定了 Transformer 学到的条件依赖结构：按空间邻近排序，前缀就携带局部几何上下文，模型容易学到「邻接面片应该长什么样」；按索引排序，前缀的几何意义弱，模型更多依赖位置统计。论文没有把序列化顺序列为独立消融项，但它实际影响第二阶段的学习难度，是配方里隐性的关键选择。

五 · 数值玩具例子：四个面片的梯度与采样

取一个极小的网格：一个四面体去掉一个面，剩 3 个三角面，再加一个独立面片，共 4 个面片，序列长度 $N=4$。设嵌入维度 $d=2$，码本 $K=3$，三个嵌入为 $e_1=(1,0)$、$e_2=(0,1)$、$e_3=(1,1)$。图卷积编码器对四个面片输出 $z_e^{(1)}=(0.9,0.1)$、$z_e^{(2)}=(0.2,0.8)$、$z_e^{(3)}=(0.6,0.6)$、$z_e^{(4)}=(0.4,0.4)$。

量化按最近邻：面片 1 到 $e_1$ 距离约 0.14，到 $e_3$ 约 0.90，选 $e_1$；面片 2 选 $e_2$（距离约 0.28）；面片 3 到 $e_3$ 距离约 0.57，到 $e_1$ 约 0.72，选 $e_3$；面片 4 到 $e_2$ 约 0.57，到 $e_3$ 约 0.85，选 $e_2$。于是 token 序列为 $(1,2,3,2)$。注意面片 4 与面片 2 共享同一 token，尽管它们的 $z_e$ 不同——这就是离散化的信息损失，解码器对两者输出同一个代表面片，重建误差被锁定在码本划分上。

第二阶段，设 Transformer 在已见前缀 $(1,2,3)$ 后对第 4 个位置的词表分布为 $p=(0.1,0.7,0.2)$。若真实 token 是 2，该位置的交叉熵为 $-\log 0.7\approx 0.357$。若模型把分布学成 $(0.05,0.9,0.05)$，交叉熵降到约 0.105，梯度相应变小——这展示了训练如何把概率质量推向训练集中高频的 token。但若训练集中面片 4 这类构型只出现一次，模型对它的监督信号就只有这一个样本，泛化到新网格时该位置的分布会退回先验，采样容易选出高频 token 而非几何上正确的 token。

采样时，若温度设为 1，从 $p=(0.1,0.7,0.2)$ 采样，有 70% 概率选 token 2，与训练标签一致；若温度调高到使分布趋平，选到 token 1 或 3 的概率上升，解码器会输出与前三面片不共享顶点的代表面片，产生裂缝。这个玩具例子把两个失败模式量化地摆出来了：重建误差由最近邻距离决定（面片 3 的距离 0.57 明显大于面片 1 的 0.14，说明码本对该区域覆盖不足），采样错误由分布锐度与训练覆盖共同决定。工程上的直接推论是：调 $K$ 改善前者，调数据平衡与温度改善后者，两者不能互相替代。

六 · 目标函数选择的工程后果

把两阶段目标放在一起看，MeshGPT 的训练配方本质上是在用一个离散瓶颈换取序列可学习性。重建损失保证 token 有几何意义，似然损失保证 token 序列有统计规律，但两者之间没有联合微调——第二阶段不会回头修正码本，第一阶段也不会感知 Transformer 的预测难度。这个设计的代价是：码本的划分是按重建误差最优做的，不是按「可预测性」最优做的。一个面片构型如果重建误差小但出现频率低，它仍会占据一个 token，而这个 token 在第二阶段几乎学不到条件分布，采样时成为噪声源。

对应的工程判断是：当生成质量在局部连接处反复出问题时，先查码本利用率与序列化顺序，再查 Transformer 容量。因为梯度路径决定了编码器只对重建负责、Transformer 只对似然负责，任何跨阶段的失配都不会被任何一个损失项惩罚。论文的消融把图卷积 vs MLP 单列，正是在验证第一阶段特征质量对下游的决定性影响——编码器丢失邻域拓扑，码本再大也补不回来，因为 token 从一开始就不携带连接信息。这个判断可以直接迁移到后续沿「网格即语言」路线改进的工作：tokenization 的质量上限，就是自回归生成的质量上限。
