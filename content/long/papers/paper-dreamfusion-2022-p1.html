一 · 场景：当“文本到 3D”卡在数据与真实感之间

设想一个 2022 年的生产环境：美术团队要在一周内为一批游戏资产产出几十个“文本描述即建模”的候选体。工程师手里有的是文本到图像模型——输入一句提示词，几秒内就能得到一张照片级渲染图；但要把这句话变成可旋转、可导出、可进引擎的 3D 物体，流程立刻断掉。当时的现实是：既没有大规模的“文本—3D”配对数据集，也没有能直接监督 3D 几何的预训练 3D 模型。团队只能退回到“用 2D 信号间接约束 3D”的老路，而这条老路的产物，往往在形状上勉强可辨、在材质与光照上完全失真。DreamFusion 要解决的，正是这个断点：在没有 3D 训练数据的前提下，如何借一个已经训练好的 2D 文本到图像扩散模型，产出高质量的 3D 物体。

这个场景的关键不在于“能不能生成一个像样的东西”，而在于“生成的依据是什么”。如果监督信号只来自图像层面的语义相似度，那么优化器会找到一切能让 2D 判据满意的捷径，而这些捷径在 3D 世界里通常意味着几何与外观的妥协。理解这一点，才能理解为什么这篇论文之前的主流做法必须被替换，而不是被微调。

二 · 此前的主流路线：CLIP 引导的网格优化

在 DreamFusion 之前，文本到 3D 的代表性做法是 CLIP-guided mesh optimization，Dream Fields 是其中被反复引用的实例。其机制可以概括为三步：先用一个可微的 3D 表示（例如带密度的神经场或网格）参数化物体；再从随机视角用可微渲染器渲染出 2D 图像；最后把渲染图与文本提示一起送进冻结的 CLIP 编码器，最大化图像嵌入与文本嵌入的相似度，并把这个相似度对 3D 参数的梯度回传，迭代更新几何与颜色。

用伪代码表达，其优化目标是：

$$\max_{\theta}\ \mathbb{E}_{c\sim\mathcal{C}}\ \mathrm{sim}\big(E_{\mathrm{img}}(R(\theta,c)),\ E_{\mathrm{txt}}(y)\big)$$

其中 $\theta$ 是 3D 参数，$c$ 是随机相机，$R$ 是可微渲染器，$E_{\mathrm{img}}$ 与 $E_{\mathrm{txt}}$ 分别是 CLIP 的图像与文本编码器，$y$ 是提示词。这个目标只要求“渲染图在语义上像这句话”，并不要求渲染图本身像一张真实照片。

痛点正出在这里。CLIP 是一个对比学习得到的语义对齐模型，它对图像的判断是全局的、粗粒度的：它能把“一只青蛙”和“一只狗”分开，却不会因为渲染图里出现多张正面脸、表面过饱和、几何自相交而给出强烈惩罚。于是优化器会系统性地利用这些盲区。具体表现是：为了同时满足“从任何角度看都像青蛙”这一语义约束，模型倾向于在物体表面堆叠多个正面朝向的“脸”或纹理块，形成所谓的多面结构；为了让语义相似度更高，颜色会被推到高饱和区域，因为语义嵌入对鲜明的颜色更敏感；几何则常常是漂浮的、不闭合的、缺乏内部结构的薄壳。这些都不是偶发的失败，而是目标函数的结构性后果。

从系统代价看，这条路线还有两个工程层面的问题。其一，CLIP 引导的梯度信号很弱且噪声大，优化往往需要大量迭代与多次重启，才能从随机初始化中“碰”出一个可辨的形状；其二，评价标准与优化目标同源，导致团队无法用同一套指标判断“是否真的变好了”——相似度上升不等于渲染图更真实。对生产流程而言，这意味着产出不可控：同一提示词多次运行得到的结果差异大，且没有可靠的早期停止判据。

一个具体的例子足以说明问题：提示词为“一只坐在垫子上的青蛙”。CLIP 引导的优化能收敛出一个大致呈蛙形、带绿色表面的团块，但从侧面看，它的背部会重复出现正面的眼部纹理，垫子与蛙体之间没有正确的接触与遮挡关系，材质呈现塑料般的均匀高光。它在语义上“像青蛙”，在图像层面却不像一张照片。这正是“缺乏图像级真实感”的准确含义：不是形状不对，而是渲染结果不具备真实图像的统计特征。

三 · 为什么非改不可：监督信号的层级错位

把问题抽象一层，CLIP 引导的失败源于监督信号与被监督对象之间的层级错位。3D 物体最终要被渲染成图像，图像的 quality 由像素级的统计规律决定——噪声分布、光照衰减、材质反射、遮挡边缘。CLIP 的嵌入是在语义层面压缩后的向量，它丢弃了绝大部分像素级信息。用一个语义向量去约束像素级生成，等于用低维的、对细节不敏感的判据去驱动一个高维的、对细节极度敏感的过程，优化器必然在未被约束的方向上自由漂移。

要修复这个错位，需要一种“以图像为单位、对像素统计敏感”的监督信号。2022 年的一个关键事实是：文本到图像的扩散模型已经在真实图像分布上训练到位，它们对“一张图是否像真实照片”有极强的判别力——扩散模型的学习目标就是预测加噪图像中的噪声，而这个预测能力本质上编码了真实图像的得分函数（score function），即数据分布的对数密度梯度。换句话说，扩散模型不只是一个生成器，它同时是一个可查询的、关于“真实图像长什么样”的密度梯度 oracle。

这就构成了非改不可的理由：既然 2D 扩散模型已经掌握了图像级的真实感先验，而 3D 的瓶颈恰恰是缺乏图像级真实感，那么正确的做法不是继续在语义相似度上做文章，而是把这个图像级先验“借”过来，作为 3D 优化的监督。问题随之转化为一个工程问题：扩散模型只接受 2D 图像作为输入，如何把它的图像级梯度传回 3D 参数？答案必须经过一个可微渲染器，而渲染出的图像必须被加噪后送进扩散模型，才能让扩散模型在其训练分布内工作。这条链路一旦打通，监督信号就从“语义像不像”升级为“像素分布像不像真实图像”，层级错位被消除。

这里有一个必须正视的代价：扩散模型的每次查询都要跑一次前向与反向，而 3D 优化需要成千上万次查询。这决定了新方法在算力上不可能廉价——后续事实也印证了这一点，每个资产需要 15k 步、单卡数小时。但在 2022 年的约束下，这是用可接受的算力换取质量跃迁的合理交易：CLIP 引导的路线算力更省，却产不出可用的资产；扩散先验的路线算力更贵，但第一次让“无 3D 数据的高质量文生 3D”成为可能。

四 · 具体机制：从 2D 先验到 3D 梯度的通路

DreamFusion 的机制可以拆成一条明确的通路。3D 表示采用 mip-NeRF 360 风格的哈希网格 NeRF，它把空间划分为多级分辨率的哈希网格，用插值特征加小型 MLP 解码出密度与颜色，兼顾了表达力与查询速度。优化时，从随机相机与随机光照下渲染出 64×64 的图像 $x$；对 $x$ 采样一个随机时间步 $t$ 与随机噪声 $\epsilon$，构造加噪图像 $x_t$；把 $x_t$、提示词 $y$ 与 $t$ 一起送进冻结的 Imagen，得到预测噪声 $\epsilon_\phi(x_t;y,t)$。关键的一步是把“预测噪声减实际噪声”当作梯度方向，而不是当作重建目标：

$$\nabla_\theta\mathcal{L}_{\mathrm{SDS}}=\mathbb{E}_{t,\epsilon}\!\left[w(t)\big(\epsilon_\phi(x_t;y,t)-\epsilon\big)\frac{\partial x}{\partial\theta}\right]$$

这个式子里，$\epsilon_\phi-\epsilon$ 是扩散模型指出的“这张图离真实图像分布还差多远”的方向，$\partial x/\partial\theta$ 是可微渲染器把图像空间的修改翻译回 3D 参数的雅可比。两者相乘，就把 2D 的得分梯度变成了 3D 参数的更新方向。注意损失是 SDS，不是 RGB 重建：没有任何真实 3D 或真实多视图图像作为回归目标，监督完全来自冻结的扩散模型。文本对齐由 CFG 增强，尺度约 100，这个远高于常规文生图的值是为了在“贴合提示词”与“保持真实感”之间把优化器推向文本一侧。

训练循环的伪代码思路是：初始化 NeRF 参数；循环 15k 步，每步采样随机相机、随机光照、随机 $t$ 与 $\epsilon$；渲染 64×64 图；加噪；查询冻结 Imagen；按上式算梯度；更新 NeRF 参数。冻结扩散模型意味着反向传播只穿过渲染器与 NeRF，不穿过 Imagen 的权重，这既省显存也避免了在少量 3D 样本上过拟合。优化结束后，用 Marching Cubes 从密度场提取网格，得到可导出的资产。

随机相机与随机光照不是可有可无的装饰，而是机制的一部分。随机相机迫使 3D 表示在多个视角下都满足 2D 先验，从而抑制“只在一个视角下成立”的捷径；随机光照则防止模型把光照烘焙进反照率，逼它学出与光照解耦的材质。消融实验正是围绕这些因素展开的：CFG 尺度、视角范围、光照随机化、哈希网格与纯 MLP 的对比，都是在这条通路上逐个确认“哪个部件在承担哪部分监督”。

五 · 失败模式与系统代价：数小时、多面、过饱和

这条通路解决了真实感问题，但没有消除所有失败模式，反而引入了新的、可归因于机制的缺陷。最直接的系统代价是时间：每个资产 15k 步、单卡数小时。原因是每次迭代都要跑一次冻结扩散模型的前向与反向，而 64×64 的分辨率限制了单次查询能提供的信息量，必须靠步数累积。这与 CLIP 引导路线形成了鲜明对比：后者单步便宜，但需要大量重启；前者单步昂贵，但一次运行就能收敛到可用结果。工程判断上，这是“把不确定性从重启次数转移到单次运行时长”的交换。

质量层面的失败模式有三类，且都能从 SDS 的机制找到解释。其一是多面结构：SDS 梯度来自 2D 先验，而 2D 先验对“同一物体上出现多个正面朝向的语义块”并不敏感，因为单张渲染图在语义上仍然成立；优化器于是倾向于在表面铺开多个满足文本的局部图案。其二是过饱和：扩散模型的得分函数在颜色分布上偏好高对比、高饱和的区域，SDS 沿着这个方向更新，导致材质颜色被推到不自然的鲜艳程度。其三是几何不精确：SDS 只约束渲染图的分布，不约束几何的闭合性、厚度与内部结构，因此提取出的网格常有薄壳、漂浮部件与不闭合的边界。这三类缺陷不是调参能根治的，它们与“用 2D 分布梯度监督 3D”这一机制本身绑定。

一个具体例子：提示词为“一把木制椅子”。SDS 优化能产出纹理真实、光照自然的椅子渲染图，但从背面看，椅腿可能与座面缺乏正确的连接，靠背的木纹在不同视角下出现重复的正面图案，颜色比真实木材更饱和。这些缺陷在单张渲染图上几乎不可见，只有在多视角检查或导入引擎后才会暴露。这正是“多面与过饱和”作为已知局限被明确记录的原因：它们是机制的结构性副产品，而非偶发 bug。

与基线对比时，这个代价的合理性才显现出来。CLIP-guided mesh optimization 与 Dream Fields 在算力上更省，但生成质量显著落后；DreamFusion 用数小时的单资产成本，换来了用户偏好上的明显优势。消融实验进一步确认了各因素的贡献：CFG 尺度决定文本贴合度与真实感的平衡点，视角范围决定多面结构的抑制程度，光照随机化决定材质解耦的质量，哈希网格相对纯 MLP 则决定了表达力与查询速度的折中。这些消融不是锦上添花，而是在告诉工程读者：这条通路的每个旋钮都对应一个具体的失败模式，调参就是在失败模式之间做取舍。

把这条通路放回开场的生产场景，工程判断就很清楚了：DreamFusion 不是把文生 3D 变成“点一下就出资产”的魔法，而是把“不可用的语义近似”替换为“可用的、带已知缺陷的真实感近似”。它用冻结的 2D 扩散模型作为图像级真实感的 oracle，用可微渲染器作为 2D 与 3D 之间的翻译层，用 SDS 把预测噪声与实际噪声之差变成 3D 参数的更新方向；代价是每资产数小时的算力、多面与过饱和的固有缺陷、以及几何精度的不足。后续工作正是在这三个代价上做改进——得分估计、表示与速度——而这条通路的骨架，即“冻结 2D 先验 + 可微渲染 + SDS 梯度”，从这篇论文起成为优化式文生 3D 的标准框架。
