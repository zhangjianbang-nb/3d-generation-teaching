一 · 一个必须先把话说清楚的场景

设想你在一台单卡工作站上，要给一批人脸做可自由环绕观看的资产。需求很朴素：输入一个隐向量，输出一张 512×512 的图，而且相机一转，鼻子还是那个鼻子、耳廓还是那个耳廓，不许出现“正面像人、侧面像塑料壳”的跳变。你打开 2021 年之前的 3D GAN 代码库，会发现两条路都走不通。第一条路是体素：把物体放进一个稠密的三维网格，每个格点存密度和颜色，生成器直接吐一个 N×N×N 的张量。显存随分辨率立方增长，这是硬约束，不是调参能绕过去的。第二条路是纯隐式 MLP：用一个多层感知机把坐标映射成密度与颜色，几何连续、内存友好，但生成器本身没有 2D 卷积那种在像素网格上逐层扩张感受野、逐级合成高频细节的能力，于是要么分辨率上不去，要么每渲染一张图都要对海量采样点跑一遍大 MLP，慢到无法支撑对抗训练的迭代节奏。

这个场景的关键不在于“哪个表示更优雅”，而在于工程上的三重挤压：显存、渲染吞吐、细节保真度，三者同时被卡住。EG3D 要解决的正是这个挤压，而它的解法不是把某一条路修得更好，而是换一个把计算负担重新分配的表示。理解这一点，必须先看清旧路线各自死在哪里。

二 · 体素路线：立方增长的显存墙

体素表示最直观：物体被离散成规则网格，生成器输出一个三维特征体，渲染时沿射线做体素遍历或三线性采样。它的优点是“3D 一致性”几乎自动成立——同一个格点被所有视角共享，不存在视角间不一致的漏洞。问题在于复杂度。若边长为 $R$，体素数量是 $R^3$；把特征通道数记为 $C$，单个样本的激活张量规模就是 $R^3 C$。分辨率翻倍，显存与计算量翻八倍。这在 2D 生成里是不可想象的：2D 图像从 256 到 512 只是四倍像素。

$$\text{Mem}_{\text{voxel}} \propto R^3 C,\qquad \text{Mem}_{\text{2D}} \propto R^2 C$$

这条公式解释了一个具体的失败模式：当你想把体素分辨率推到能表达五官细节的级别时，显存先于模型能力崩溃。工程上常见的妥协是“低分辨率体素 + 超分网络”，但超分是在 2D 图像上做的，它无法把几何信息补回来，侧视角一转，几何的粗糙就暴露了。另一种妥协是稀疏体素或八叉树，只存表面附近的格点，可这要求生成器输出稀疏结构，而稀疏结构的生成本身是个离散决策问题，和 2D 卷积的稠密、可微、易扩展的性格不合。对抗训练需要梯度在生成器里顺畅回传，稀疏化带来的索引操作与动态形状会让训练循环变得脆弱。

举个具体例子：在 FFHQ 这类人脸数据上，要让嘴部表情在侧 45 度仍然合理，几何分辨率必须细到牙齿与唇缘的尺度；稠密体素在这个尺度上的张量规模已经超出单卡可承受的对抗训练批量。批量一小，判别器的梯度噪声就大，训练稳定性下降，于是你陷入“分辨率—批量—稳定性”的三角困境。这不是实现细节的问题，是表示本身的代价结构决定的。

三 · 纯隐式 MLP 路线：连续但生成不动

另一条路是把场景写成连续函数 $F(\mathbf{x}) \to (\sigma, \mathbf{c})$，用 MLP 表示。它在内存上是优雅的：参数量与分辨率解耦，理论上可以无限精细地查询任意坐标。但把它塞进 GAN 的生成器位置，会立刻遇到两个机制性障碍。

第一是生成端的表达效率。StyleGAN2 之所以能在 2D 上做出高频细节，靠的是卷积层堆叠：浅层抓局部纹理，深层抓全局结构，特征图在像素网格上逐级放大。纯 MLP 没有这个网格，它把坐标当作输入，靠位置编码制造高频，但位置编码的高频是“人为注入”的，缺乏数据驱动的层级结构。结果是生成器很难在隐空间里组织出“先有脸型、再有五官、最后有毛孔”这样的层级语义，细节要么糊，要么变成不自然的噪声。

第二是渲染端的吞吐。体渲染要对每条射线上的几十到上百个点查询 MLP。一张 512×512 的图，按每条射线 64 个采样点算，就是千万量级的 MLP 前向。对抗训练每步都要渲染生成图，判别器还要反传，这个量级的前向在当时的单卡上会把一个训练步拖到不可接受的长度。论文背景里明确写了这一点：2021 年前的高质量 3D GAN 要么分辨率低，要么渲染慢。这不是定性抱怨，而是“每步渲染成本 × 迭代步数”直接决定了一个课题能不能在合理时间内做完。

失败模式也很具体：为了提速，人们减少每条射线的采样点，或者用粗糙的 importance sampling。采样一稀，薄结构（比如椅子的细腿、眼镜框）就会被漏采，渲染出的图出现断裂或空洞；判别器看到这些伪影，会把“有薄结构”判成假，生成器于是学会回避薄结构，几何多样性下降。这是一个由渲染预算反向塑造几何分布的典型链条。

四 · 混合路线与它们的未竟之处

在 EG3D 之前，已有工作试图在两条路之间搭桥。StyleNeRF 一类方法把 NeRF 式的体渲染接到 2D 卷积主干上，用 2D 特征图加射线上的采样来提升效率，但它对 3D 一致性的约束主要靠 2D 判别器与一些正则，几何的“体积感”仍然依赖隐式 MLP 的表达力。pi-GAN 用 SIREN 式周期激活的隐式表示做生成，几何连续性好，但同样受制于渲染吞吐与生成端的高频合成能力。GIRAFFE 走的是组合式路线，把场景拆成多个可变换的体素/特征块再合成，擅长多物体场景，但对单一物体的高分辨率细节与视角一致性并不是它的主攻方向。

这些方法的共同未竟之处可以归纳为一个结构性矛盾：高频细节的合成需要 2D 卷积的层级网格，而 3D 一致性需要某种跨视角共享的三维结构。体素把共享做到了极致但代价是立方增长；纯 MLP 把代价降下来了但丢掉了卷积的层级合成；混合方法在两者之间摇摆，往往在其中一个维度上妥协。EG3D 的问题定义正是从这个矛盾里长出来的：如何用一个高效的 3D 表示，让 GAN 生成高分辨率、视角一致、几何合理的 3D 物体，同时保持 2D 卷积的可扩展性。

注意这个问句里的三个限定词都不是装饰。“高分辨率”指向 2D 卷积的可扩展性，“视角一致”指向跨视角共享，“几何合理”指向密度场必须真的对应一个可渲染的表面而不是一堆视角相关的贴片。三者同时满足，才构成对旧路线的实质超越。

五 · 判别器一侧的隐性痛点

问题不只在生成器。3D GAN 的判别器设计同样是一个现场痛点，而这一点常被忽略。若用 3D 判别器直接判别体素或隐式场，判别器本身就要承受同样的立方或查询成本，而且 3D 卷积在当时的算子生态里远不如 2D 卷积成熟，显存与速度都吃亏。更麻烦的是，3D 判别器看到的“真假”是几何层面的，它会把注意力放在密度分布上，而对渲染出来的图像纹理不敏感——可最终用户看的是渲染图。

若用 2D 判别器判别渲染图，则判别器只能看到某个视角的投影，单张图无法约束背后的三维结构。一个视角的图可以由无数个不同的三维场渲染出来，2D 判别器无法区分它们。这就是为什么“2D 判别器 + 相机分布采样”必须成对出现：只有让判别器在训练中看到同一物体在多个采样相机下的渲染，跨视角的一致性才被间接约束。相机分布的设计因此不是超参数装饰，而是 3D 一致性的约束来源之一。

具体代价是：相机采样若过窄（比如只在小角度内扰动），生成器可以学出一个“正面专用”的场，侧视角崩溃；若过宽且均匀，训练早期生成器还没学会基本几何，宽视角采样会带来大量无意义的梯度。工程上要在训练过程中安排相机分布的调度，这本身增加了训练循环的复杂度。EG3D 的架构里，判别器保持 2D CNN，配合相机分布采样与姿态条件，正是把这一侧的痛点用“2D 判别器 + 多视角监督”的方式绕过去，而不是硬碰 3D 判别器。

六 · 为什么非改不可：三个代价的叠加

把上面的分析收拢，旧路线不可行的理由可以写成三条互相叠加的代价，每一条都能在工程上被具体测量。

  • 显存代价：体素路线的 $R^3C$ 增长使得高分辨率与可承受批量不可兼得，批量一小，对抗训练的梯度噪声上升，稳定性下降。
  • 吞吐代价：纯隐式路线的每射线多点 MLP 查询使得单步渲染时间过长，迭代步数被压缩，课题周期被拉长；减采样又反过来损伤薄结构。
  • 一致性代价：2D 判别器单独使用时无法约束三维结构，必须靠相机分布与正则补足；3D 判别器则把成本重新拉回立方级别。

一个具体的对照例子：在 ShapeNet 的汽车类别上，要让生成的车在侧视角保持车轮与车身的正确遮挡关系，体素路线需要足够细的网格来区分轮辐与轮毂，纯隐式路线需要足够密的射线采样来捕捉薄轮辐。两者都在“细”字上付出高昂代价。EG3D 的切入点是把这份“细”的工作从三维网格或密集查询里挪出来，交给 2D 卷积在平面上完成——平面上的分辨率增长是平方的，而且 2D 卷积的算子成熟度、显存效率、并行度都远好于 3D 对应物。

这就是本部分要落到的那条工程判断：旧路线的痛点不是“效果不够好”这种模糊表述，而是三个可测量的代价结构同时压在单卡训练循环上；只要表示不换，任何一个维度的改善都会从另一个维度漏出去。EG3D 的三平面表示正是针对这个代价结构做的重新分配，而它的具体机制与随之而来的新代价，是后续部分要展开的内容。
