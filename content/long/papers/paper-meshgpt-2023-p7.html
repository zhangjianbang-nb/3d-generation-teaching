一 · 对比的坐标系：先把“同一张网格”拆成四个可测维度

把 MeshGPT 与同期或后继方法放在一起比较，最容易犯的错误是拿“看起来更好的图”直接下结论。工程上更可靠的做法是先固定一个坐标系：同一批输入条件（类别、点云或图像）、同一套评价口径（表示紧凑度、监督信号、采样吞吐、显存占用、失败模式），再逐项对齐。MeshGPT 的表示是“面片 token 序列”，监督是两阶段（VQ-VAE 重建 + 自回归下一 token），速度受自回归逐 token 采样支配，显存受序列长度与词表大小共同支配。任何对比方法只要在这四项中有一项换了口径，结论就不能直接搬到产线。

先给出本文使用的形式化对照。设一个网格 $\mathcal{M}$ 被序列化为 $N$ 个 token，词表大小为 $K$，每个 token 的嵌入维度为 $d$。自回归采样的总步数是 $N$，每步要对长度为 $i$ 的前缀做一次前向，注意力代价按 $\sum_{i=1}^{N} i \cdot d$ 量级增长；而等值面提取的代价主要由体素分辨率 $R$ 决定，输出面数约与 $R^2$ 同阶。两条代价曲线的形状不同：前者随序列长度超线性增长，后者随分辨率平方增长，但两者的“产物质量”定义完全不同——一个是拓扑紧凑度，一个是几何逼近精度。

$$\text{cost}_{\text{AR}}(N,d)\;\approx\;\sum_{i=1}^{N} i\cdot d \;=\; \frac{N(N+1)}{2}\,d,\qquad \text{cost}_{\text{MC}}(R)\;\approx\; c\,R^{2}$$

这个式子说明一个具体机制：MeshGPT 的推理时间不是线性的，而是随面片数近似二次增长；当网格面数从几百涨到几千，采样步数与每步注意力长度同时变大，端到端延迟会被放大。反过来，等值面提取的分辨率提高一档，面数按平方涨，但每一步都是并行的、无状态的，延迟曲线平缓得多。这就是为什么 MeshGPT 在“面数少、拓扑紧凑”的椅子上表现好，而一旦类别里出现大量细碎结构，序列长度就成为硬约束。

一个具体例子：ShapeNet 的椅子类别中，艺术家网格通常由数百个面片构成，序列长度落在模型可承受范围内；而同一数据集中带复杂靠背与扶手的样本，面片数上升后序列被截断，生成结果会出现局部缺失或面片错位。这不是随机噪声，而是序列长度上限直接导致的系统性失败模式。对比时若不把这个上限写进表格，就会把“截断”误读为“生成质量差”。

二 · 与等值面提取逐项对比：紧凑度换来了序列约束

等值面提取（以神经场为输入、按固定分辨率采样后提取三角面）的表示是“稠密、规则、无拓扑意识”的：它不关心面片之间的邻接关系，只保证几何逼近。MeshGPT 的表示是“稀疏、离散、带拓扑语义”的：每个 token 对应一个面片的局部几何与拓扑，词表由 VQ 量化得到。监督上，等值面提取几乎不需要训练一个生成模型，只需要一个可查询的隐式场；MeshGPT 需要两阶段训练，先让 VQ-VAE 学会重建，再让 Transformer 学会在 token 序列上预测下一个 token。

维度等值面提取MeshGPT
表示稠密三角面，拓扑由采样规则决定面片 token 序列，拓扑由词表与序列顺序编码
监督无需生成式训练，依赖隐式场质量两阶段：VQ-VAE 重建 + 自回归下一 token
面数随分辨率平方增长，显著偏高显著低于等值面提取，拓扑更紧凑

显存主要受分辨率与批大小支配受序列长度、词表大小、注意力缓存共同支配
失败模式面数爆炸、拓扑混乱、出现薄片与自交序列截断导致局部缺失、面片错位、长网格退化

机制上，等值面提取的“面数爆炸”来自它对空间的均匀采样：无论该区域是否需要细节，分辨率一视同仁。MeshGPT 的词表把“一个面片长什么样”压缩成离散码字，序列只记录“哪些面片、按什么顺序”，因此同样的几何可以用远少于采样面的 token 表达。代价是表达能力被词表容量限制：词表大小 $K$ 决定了可复用的局部模式数量，$K$ 太小则重建粗糙，$K$ 太大则自回归的 softmax 与嵌入表膨胀。

系统代价的具体体现：在单卡训练数天的配方下，VQ-VAE 阶段的重建质量直接决定第二阶段的上限；如果重建阶段对细长面片、非流形邻接覆盖不足，自回归阶段无论怎么调都不会生成这些结构。这是一个“监督信号分层”的失败模式——错误不在 Transformer，而在词表的覆盖度。对比等值面提取时，后者没有这个分层，它的误差是连续的几何误差，不会因为“词表没覆盖”而突然出现结构性缺失。

具体例子：飞机类别的机翼前缘是细长、高曲率的面片集合。等值面提取会在该区域生成大量碎片面，面数高但几何连续；MeshGPT 若词表中缺少对应的细长面片码字，生成结果会把前缘简化成较粗的面片，面数更少、拓扑更整洁，但几何细节被抹平。两者都不是“更好”，而是把误差放在了不同位置：一个放在面数与拓扑，一个放在局部几何保真度。

三 · 与 Mesh R-CNN 对比：监督口径不同，不能只看 FID

Mesh R-CNN 属于“从图像/体素到网格”的判别式路线：它把网格生成拆成体素预测与网格细化，监督信号来自渲染或几何损失，输出是每个样本一份网格。MeshGPT 是“在网格 token 空间里做生成”的自回归路线：监督是离散的下一 token 交叉熵，输出是从词表中采样并解码出的面片序列。两者的监督口径不同，直接比较 FID 会把“分布匹配”与“单样本几何精度”混在一起。

具体机制差异在于“条件如何进入模型”。Mesh R-CNN 的条件（图像特征）在每个细化步骤中被反复注入，模型对输入的依赖是稠密、连续的；MeshGPT 的条件若存在，则通常以序列前缀或类别 token 的形式进入，模型对条件的依赖是离散、稀疏的。这带来一个工程后果：MeshGPT 在类别条件生成上更自然（一个类别前缀就能控制全局风格），但在“严格贴合给定图像”的任务上缺少逐像素的约束通道。

上式中左侧是 MeshGPT 的监督，右侧是判别式网格方法的典型监督。前者只要求“下一个 token 在词表中选对”，后者要求“渲染出来像”。这解释了一个失败模式：MeshGPT 可以在 token 层面完全合法（每个 token 都在词表内、序列顺序合理），但解码出的面片在空间上出现裂缝或重叠，因为 token 的局部合法性不保证全局几何一致性。判别式方法则相反，渲染损失会惩罚裂缝，但可能生成面数爆炸的稠密网格。

速度与显存上，Mesh R-CNN 的前向是固定步数的细化网络，延迟与输入分辨率相关但与输出面数弱相关；MeshGPT 的延迟与输出面数强相关。显存方面，MeshGPT 在采样时需要缓存已生成 token 的键值（KV cache），缓存大小与序列长度、层数、头数成正比；判别式方法没有这个随输出长度增长的缓存。具体例子：在批量生成椅子时，若批大小固定，MeshGPT 的显存峰值会随批内最长序列被拉高，短序列样本被迫按最长序列对齐，造成显存浪费；判别式方法按固定分辨率对齐，浪费模式不同但更可预测。

因此对比 Mesh R-CNN 时的工程判断是：若任务是“给定图像、要一份尽量贴合且面数可接受的网格”，判别式路线在约束强度上更直接；若任务是“给定类别、要一批拓扑紧凑、风格统一的网格”，MeshGPT 的离散 token 空间更容易做采样与多样性控制。把两者放在同一张 FID 表里排名，会掩盖监督口径的差异。

四 · 与 PolyGen 对比：同为自回归，序列化方式决定代价

PolyGen 也是自回归生成网格，但它把网格拆成“顶点序列 + 面序列”两段式建模：先自回归生成顶点坐标，再以顶点为条件自回归生成面。MeshGPT 则先用 VQ-VAE 把面片压成离散词表，再在单一 token 序列上自回归。两者都是 decoder-only Transformer，但序列化的粒度不同，直接导致速度、显存与失败模式的差异。

机制上，PolyGen 的顶点 token 是连续坐标的离散化，面 token 是顶点索引的组合，序列长度随顶点数与面数同时增长；MeshGPT 的每个 token 是一个面片码字，序列长度约等于面片数。在同等面数的网格上，MeshGPT 的序列通常更短，因为一个 token 承载了一个面片的局部几何与拓扑，而不是一个坐标或一个索引。这就是论文报告 FID 优于 PolyGen 的表示层原因：更短的序列让 Transformer 更容易学到长程依赖，词表的量化也起到了正则化作用。

维度PolyGenMeshGPT
序列化顶点序列 + 面序列，两段式面片 token 单序列
词表来源坐标/索引的离散化图卷积 VQ-VAE 学出的面片词表
序列长度随顶点数与面数共同增长约等于面片数，通常更短
监督两段自回归，顶点与面分别建模两阶段训练，重建与自回归分离
失败模式顶点与面不一致、索引越界、悬空顶点词表覆盖不足、序列截断、面片错位

系统代价的具体差异在采样阶段。PolyGen 需要先完成顶点序列再生成面序列，两段之间的条件传递是一次性的；若顶点阶段出现坐标漂移，面阶段无法回退修正。MeshGPT 的单序列在理论上允许面片之间相互约束，但自回归的因果掩码意味着每个面片只能看到前缀，后续面片无法影响已生成的面片，因此局部错误同样不可回退。两者的失败模式都源于“因果生成不可撤销”，只是错误的表现位置不同：一个在顶点-面一致性，一个在词表-几何一致性。

显存上，PolyGen 的两段式需要保存两套序列的 KV 缓存，峰值出现在面序列阶段；MeshGPT 只有一套缓存，但词表嵌入表随 $K$ 增长。具体例子：生成一张桌子时，PolyGen 的顶点序列可能包含大量重复坐标的离散化 token，面序列则要反复引用这些索引，序列冗余高；MeshGPT 把桌腿、桌面等局部模式压成少数码字，序列更紧凑，但若词表对“桌腿与桌面的连接方式”覆盖不足，连接处会出现面片错位。这是词表粒度与几何复杂度之间的权衡，不是模型容量的问题。

决策表的使用方式是“先剔除硬约束，再比较软指标”。硬约束包括：序列长度上限是否覆盖目标类别的最复杂样本、显存是否能容纳批内最长序列的 KV 缓存、延迟预算是否允许逐 token 采样。软指标包括 FID、面数、拓扑紧凑度。一个具体判断：若目标类别是椅子、桌子、飞机等 ShapeNet 常见类别，且允许单卡数天量级的训练，MeshGPT 路线在紧凑度上有明确优势；若目标类别包含大量细碎结构且样本面数分布长尾，序列截断会成为主要失败模式，此时应优先考虑后继的 tokenization 改进，而不是在 MeshGPT 上调参。

还需要注意“监督口径”这一列不在表中但决定可比性：MeshGPT 的 FID 优势是在其自身监督口径下取得的，与判别式方法的渲染损失不可直接换算。工程上应把“分布匹配”和“单样本贴合”分开验收：前者看采样多样性、FID、面数分布；后者看给定条件下的几何误差与裂缝率。把两者混在一个指标里，决策表就会失真。

六 · 失败模式的对照清单与工程断言

对比实验的价值最终落在失败模式的可预测性上。MeshGPT 的失败模式可以归为三类：序列截断、词表覆盖不足、因果生成不可回退。等值面提取的失败模式是面数爆炸与拓扑混乱；判别式方法的失败模式是面数偏高与规则性差；PolyGen 的失败模式是顶点-面不一致。把这些失败模式写成验收断言，比比较单一指标更能指导复现。

  • 序列截断断言：对目标类别统计面片数分布，若高分位数超过训练时的序列长度上限，则生成结果在该分位数以上样本上出现局部缺失的概率显著上升；验收时应单独报告长尾样本的完成度，而不是只看平均值。
  • 词表覆盖断言：对重建阶段的面片重建误差按面片类型（细长、高曲率、非流形邻接）分组统计；若某类面片的量化误差明显高于整体，则自回归阶段在该类结构上必然退化，调 Transformer 无效。
  • 因果不可回退断言：对生成结果做全局一致性检查（裂缝、自交、悬空面片）；token 层面的合法率不能替代几何层面的合法率，两者必须分开报告。
  • 显存对齐断言：批内按最长序列对齐会放大显存峰值；验收时应记录“批内最长序列/平均序列”的比值，比值越大，显存浪费越严重，应改用长度分桶或动态批。

一个具体机制层面的收尾：MeshGPT 把“网格生成”转成了“离散序列建模”，这让紧凑度和多样性可以通过词表与采样温度直接调节，但也把几何一致性责任从连续损失转移到了词表覆盖与序列长度上。工程判断因此不是“MeshGPT 比谁更好”，而是“在给定序列长度预算与词表覆盖范围内，它能把哪一类网格稳定生成出来”。决策表的每一行都应附带这两个预算的数值边界，否则对比就退化成不可复现的印象。
