一 · 复现边界：先把“能跑”与“能验收”分开

复现 MeshAnything V2 时，最容易犯的错误是把“训练脚本能启动”当成“复现成功”。论文给出的核心承诺只有两条：AMT 把序列长度压到逐面顶点 token（VTT）的约一半，并在同等预算下把输出面数从 800 提到 1600。工程上必须把这两条拆成两个独立验收面：序列侧的可测断言（token 数比值）与生成侧的可测断言（面数上限与拓扑合法性）。前者不依赖训练，后者依赖完整训练与采样。复现目录应当围绕这两个断言组织，而不是围绕“模型代码”组织。

最小可跑版本（MVP）的判定标准是：给定一个 Objaverse 艺术家网格，能完成形状编码、AMT 序列化、自回归训练若干步、逐 token 采样、解码回网格、并通过拓扑检查。它不需要达到 1600 面，只需要证明数据流闭合。完整复现则要求在同一预算下把面数推到 1600，并给出与 MeshAnything、MeshGPT 基线的对照。两者之间的差距正是超参与数据管线的工作量所在。

目录结构建议按“数据—序列—模型—采样—验收”五层切分，而不是按论文小节切分。原因很直接：AMT 的失败模式大多出现在序列层与解码层的边界上，按论文结构组织会把序列化代码散落在数据加载与模型前向里，崩溃点难以定位。

  • data/：Objaverse 艺术家网格的原始资产、清洗后的水密/流形子集、按面数分桶的索引清单。
  • tokenize/：AMT 序列化器、VTT 对照序列化器（仅用于比值断言与消融）、序列长度统计脚本。
  • model/：形状编码器、自回归 Transformer、面片解码头。
  • train/：训练循环、预算配置、检查点与序列长度直方图落盘。
  • sample/：逐 token 采样、解码还原、拓扑合法性检查。
  • asserts/：验收断言集合，每个断言一个可执行脚本，输出通过/失败与失败样本 id。

这个划分的直接代价是代码重复：形状编码器在训练与采样两处被调用，序列化器在数据管线与断言脚本两处被调用。工程判断是接受这份重复，因为断言脚本必须能在不加载模型权重的情况下独立运行，否则序列长度断言会被训练环境的随机性污染。

二 · 数据准备：面数分桶与序列长度直方图

论文在 Objaverse 艺术家网格上训练，数据侧的第一个具体机制是面数分桶。AMT 的序列长度近似与面数线性相关，但常数因子取决于相邻面片共享边的比例。把资产按面数分桶（例如按 2 的幂次切桶），可以在每个桶内统计 AMT 与 VTT 的序列长度比值，从而在训练前就发现“共享边比例异常低”的资产。这类资产通常是三角化不一致或存在大量孤立面片的网格，它们会把序列长度推到接近 VTT，破坏“约减半”的前提。

序列长度比值是一个可直接计算的量。设网格面片集合为 F，AMT 序列长度为 N_amt，VTT 序列长度为 N_vtt（每个面片三个顶点 token），则断言写成：

$$\rho=\frac{N_{\mathrm{amt}}}{N_{\mathrm{vtt}}},\qquad \text{assert}\ \ \rho \le 0.6\ \text{对桶内中位数成立}$$

阈值取 0.6 而非 0.5，是因为论文表述为“约减半”，工程上需要一个容忍共享边比例波动的上界。这个断言不依赖任何实验数字，只依赖 AMT 的定义：相邻面片共享一条边时只编码新顶点，理想情况下每两个面片新增一个顶点 token 量级，比值趋近 0.5；共享边比例下降时比值上升。桶内中位数而非均值，是为了避免少量退化网格拉偏统计。

数据准备的第二个机制是拓扑预检。AMT 解码依赖“相邻面片共享边”的假设，如果输入网格存在非流形边（一条边被三个以上面片共享），序列化器在寻找相邻面片时会产生歧义，解码端无法唯一还原。预检脚本应统计非流形边数量、孤立顶点数量、重复面片数量，并把超标资产移出训练集。这一步的系统代价是数据量下降，但它是必要的：拓扑非法资产进入训练会让模型学到无法解码的序列模式，表现为采样阶段解码失败率上升，而训练损失仍然正常下降。

第三个机制是序列长度直方图落盘。训练前对全量数据跑一遍序列化，把每个资产的 N_amt 写入清单，按桶输出直方图。这个直方图是后续超参选择的依据：最大序列长度必须覆盖目标面数对应的分位数，而不是覆盖全体最大值。若按全体最大值设长度，显存会被极少数超大网格绑架；若按目标面数分位数设长度，则超出长度的资产在训练时被截断或跳过，截断会破坏 AMT 的相邻性假设，因此应选择跳过而非截断。

具体例子：一个由四边形面片三角化而来的艺术家网格，若三角化方向不一致，相邻三角形可能不共享边而是共享顶点，此时 AMT 序列化器找不到“下一条共享边”，只能回退到编码全部三个顶点，该面片的 token 数从 1 跳到 3。桶内中位数比值会因此上升，断言失败，脚本输出该资产 id 与三角化方向统计。这就是把失败模式定位到数据侧而非模型侧的具体路径。

三 · 超参配置：预算、序列上限与面数目标

论文的关键对照是“同等预算下面数从 800 到 1600”。复现时“预算”必须被显式定义，否则对照无法成立。工程上把预算定义为三项乘积：最大序列长度 L、批大小 B、训练步数 S。AMT 把序列长度减半，因此在 L 不变的前提下，同一预算可以覆盖面数翻倍的样本；或者在同一面数下，L 可以减半从而腾出显存给更大的 B。复现配置必须明确选择哪一条路径，并在配置文件中把 L、B、S 与目标面数一起锁定。

超参的第一条断言是序列上限与面数目标的匹配。设目标面数为 M_target，桶内 AMT 每面片平均 token 数为 c（由直方图给出），则所需序列长度近似为：

$$L_{\min}\approx c\cdot M_{\mathrm{target}},\qquad \text{assert}\ \ L \ge L_{\min}\ \text{且}\ L\ \text{不超过显存实测上限}$$

c 不是常数，它随共享边比例变化，因此 L_min 必须用目标面数所在桶的实测 c 计算，而不是用全局均值。若 L 小于 L_min，采样阶段会在达到 1600 面前触发序列结束，表现为面数分布被硬截断在某个值，而不是模型能力不足。这个失败模式很容易被误判为“模型没学会生成复杂网格”，实际是配置错误。

第二条断言是面数上限的可达性。采样时以序列结束 token 为终止条件，解码后的面数应能覆盖到 1600 附近。验收脚本应统计采样面数的分位数，并断言高分位达到目标量级。注意这里不能用“平均面数”作为断言，因为面数分布长尾，平均值会被大量简单样本拉低，掩盖上限是否可达。

第三条是形状编码的消融开关。论文的消融包含形状编码一项，复现时应把形状编码器的输入（点云或体素）与自回归条件拼接方式做成可切换配置，以便在 MVP 阶段先关闭形状条件跑通序列闭合，再打开做完整对照。关闭形状条件时，模型退化为无条件序列生成，拓扑合法性会显著下降，这正是消融要展示的方向，但不应作为 MVP 的验收标准。

系统代价方面，L 的提升是显存与时间的双重开销：自回归注意力的计算随 L 增长，逐 token 采样的步数也随 L 增长。把 L 从覆盖 800 面提到覆盖 1600 面，采样延迟近似翻倍。工程判断是：训练阶段用分桶采样控制单批内的长度方差，采样阶段用长度上限而非固定步数终止，避免为短样本浪费步数。

具体例子：直方图显示目标桶内 c≈0.55 token/面片，M_target=1600，则 L_min≈880。若配置里 L=512，采样面数会被截断在约 930 面以下，验收断言失败并直接指向 L 配置，而不是指向模型权重。这就是把超参错误与模型错误分开的具体机制。

四 · 训练循环：序列打包与相邻性保持

AMT 序列的相邻性假设对训练循环有一个具体约束：批内不能随意打乱面片顺序，也不能在序列中间插入填充 token 破坏相邻关系。标准做法是按资产打包（packing），每个样本的 AMT 序列保持原序，样本之间用分隔 token 隔开，损失只在面片 token 上计算，分隔与填充位置被掩码。若把多个样本拼接后统一截断到 L，截断点落在样本中间会切断相邻面片对，模型会学到“序列突然终止”的伪模式。

训练循环的伪代码思路如下：

  • 按桶采样一个批，桶的选择按面数分布加权，避免大批简单样本主导梯度。
  • 对每个样本调用 AMT 序列化器，得到面片 token 序列与对应的新顶点坐标 token。
  • 拼接为 [形状条件 token][面片序列][结束 token]，记录每个 token 的样本归属与是否为面片 token。
  • 前向计算自回归损失，掩码掉分隔、填充与非面片位置。
  • 反传前检查批内最大序列长度是否超过 L，超过则丢弃该批并重采样，而不是截断。

这里的具体机制是“丢弃而非截断”。丢弃的代价是吞吐下降，尤其在长尾桶内；收益是相邻性假设不被破坏。工程上可以用桶内长度排序加动态批来降低丢弃率，但动态批会引入批内长度方差，需要重新校准学习率与梯度累积步数。

第二个机制是顶点坐标的量化与还原。AMT 只编码新顶点，但新顶点的坐标仍需离散化后才能进入自回归词表。量化位数决定细节上限，这是论文局限中“细节上限”的直接来源。复现时必须把量化位数写进配置并在解码端做逆量化，验收脚本应断言逆量化后的顶点与原始顶点在量化格点上的误差为零（即往返一致），否则解码器会引入系统性偏移。

失败模式：若量化格点分辨率过高，词表膨胀，嵌入层显存与输出层计算上升；若过低，相邻面片共享边的几何一致性被破坏，解码后出现裂缝或自交。论文的局限表述为“细节上限”，工程上对应的是量化位数与序列长度的联合约束：在固定 L 下，提高量化位数会挤占面片 token 的预算，因为每个新顶点需要更多坐标 token。

具体例子：一个 1600 面的网格，若每两个面片新增一个顶点，约 800 个新顶点；每个顶点三轴坐标各用 k 位量化，则坐标 token 数约为 3k·800 量级，与面片 token 同量级。若 k 取大值，坐标 token 会超过面片 token，AMT 的“减半”收益被坐标开销抵消。验收脚本应分别统计面片 token 与坐标 token 的占比，断言面片 token 占主导，否则说明量化配置与序列预算不匹配。

五 · 采样与解码：逐 token 终止与拓扑断言

推理是逐 token 的，这带来一个具体机制：终止条件不是固定步数，而是模型输出结束 token 或达到 L。逐 token 采样的系统代价是延迟随面数线性增长，1600 面对应的 token 数约为 800 面时的两倍，单样本采样时间近似翻倍。工程上可以用批内并行采样摊薄，但批内样本的终止步数不同，需要动态掩码，否则短样本会被长样本拖到 L 才返回。

解码端的具体机制是“按共享边还原面片”。AMT 序列中每个 token 表示一个新顶点或一个面片引用，解码器维护一个已还原顶点表与面片表，遇到面片 token 时按序列化时的相邻关系取回共享边的两个端点，加上新顶点构成三角形。这里的关键断言是：解码出的每条边被引用的次数必须与序列化时的记录一致，否则说明序列在采样中被模型生成了非法相邻关系。

拓扑合法性断言应至少覆盖三项：非流形边数量为零、面片方向一致（法向不翻转）、无重复面片。论文明确把“拓扑合法性仍需检查”列为局限，因此复现不能假设模型输出天然合法。断言脚本应对每个采样样本输出三项计数，并统计合法率。合法率的分母是采样样本数，分子是三项全过的样本数，这个比值是完整复现的核心验收指标之一，与面数上限并列。

失败模式：模型在长序列后段倾向于生成重复面片或退化三角形（三个顶点共线），表现为解码后出现零面积面片。这类失败在训练损失上不可见，因为训练数据中退化面片已被预检剔除，模型只是在分布外采样时产生它们。验收脚本应把零面积面片计入非法计数，并输出对应序列位置，便于定位是坐标量化还是面片引用出错。

具体例子：采样得到 1600 面输出，拓扑断言报告 3 条非流形边，全部集中在序列末段。检查发现末段的面片 token 引用了已被前文使用过的边，而 AMT 序列化器在训练数据中从不会产生这种引用。这说明模型在接近 L 上限时失去了相邻性约束，工程判断是把 L 上限与目标面数解耦：让 L 略大于 L_min，给终止 token 留出余量，而不是让目标面数恰好顶到 L。

六 · 验收断言清单与常见崩溃点定位

把验收断言做成可执行清单，是复现从“能跑”走到“可信”的分界线。下表列出最小断言集合，每条都对应一个具体机制或失败模式，且不依赖论文未给出的数字。

断言检查对象失败指向
序列比值 ρ 桶内中位数 ≤ 0.6AMT vs VTT 序列长度数据三角化不一致、共享边比例低
L ≥ c·M_target配置与直方图序列上限不足，面数被硬截断
坐标往返误差为零量化与逆量化量化格点与解码器不一致
面片 token 占比占主导序列构成统计量化位数过高，AMT 收益被抵消
采样面数高分位达目标量级采样输出终止条件或 L 配置错误
拓扑合法率（非流形/方向/重复）解码输出相邻性约束在长序列失效
批内最大长度 ≤ L 才反传训练循环截断破坏相邻性，伪终止模式

常见崩溃点按出现频率排序，第一是序列化器的相邻面片查找。实现时若用面片索引做哈希而不用边做键，共享边的判定会退化为顶点集合交集，导致四边形三角化方向不一致的网格被误判为不相邻，ρ 上升。第二是解码器的顶点表索引偏移：AMT 只编码新顶点，解码时新顶点在全局顶点表中的位置必须与序列化时一致，若训练与采样用了不同的顶点排序，解码出的面片会整体错位。第三是采样时的终止 token 与填充 token 混淆，导致序列在非预期位置结束，面数分布出现尖峰。

工程判断落在最后一条机制上：把 AMT 序列化器与解码器做成一对可往返的纯函数，输入网格输出网格，断言往返后顶点集合与面片集合在量化格点上完全一致。这个往返测试不依赖模型，能在几分钟内暴露序列化与解码的绝大多数实现错误。只有往返测试通过后，才值得投入数天量级的训练去追求 1600 面与拓扑合法率。复现的可信度不来自训练损失曲线，而来自这条往返链与上表断言的联合通过。
