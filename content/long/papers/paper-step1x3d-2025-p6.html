一 · 复现边界：先钉死“最小可跑”与“不可照搬”

复现 Step1X-3D 的第一件事不是拉代码，而是把“最小可跑版本”定义成一条能端到端出结果的窄路径：输入一张草图或一段文本，几何 DiT 产出 SDF 场，经网格解码得到三角网格，纹理扩散以该网格的多视图渲染为条件生成 UV 纹理，最后用可微渲染做一次闭环校验。这条路径必须能在单机多卡上跑通，且每一步都有可观测的中间产物落盘。凡是不能落盘的环节，在复现中一律视为不可调试的黑盒，必须先拆开。

论文明确给出的边界是：控制能力有限、纹理真实感受数据限制、推理慢。这三条直接决定复现策略。控制有限意味着条件编码器不能当作通用接口来用，草图与分割条件的预处理必须与训练分布对齐，否则条件信号会被几何先验淹没；纹理真实感受数据限制意味着纹理分支的泛化上限由数据决定，复现时不要指望用小规模数据调出论文级质感；推理慢意味着不能把几何与纹理串行放在同一条同步流水线里做在线服务，必须做阶段化缓存。

不可照搬的部分集中在两处。其一是几何与纹理分开训练带来的耦合假设：几何分支输出的 SDF 与网格解码器之间存在分辨率与拓扑约定，纹理分支的多视图渲染依赖这套约定，任何一方改动都会让可微渲染监督失配。其二是局部编辑接口，它依赖条件编码与几何表示之间的可寻址结构，复现时若没有对应的数据标注，编辑接口只能做几何层面的裁剪与重生成，不能复刻论文里的语义级局部编辑。工程判断是：先复现“生成”，再复现“可控”，最后才碰“编辑”。

最小可跑版本的验收断言写成可执行的形式，而不是主观描述：几何分支在固定随机种子下对同一条件输入产出结构一致的网格（顶点数、面数在容差内稳定）；纹理分支对同一网格与同一视角集合产出可复现的 UV 图；可微渲染的重投影误差在训练集子集上单调下降而非震荡；整条链路在数十秒量级的推理预算内完成一次前向。这些断言不引用具体数值，只约束行为形态，因为论文未给出可复用的绝对阈值。

二 · 目录结构：按“阶段产物”而不是按“模型”切分

复现工程最常见的错误是按模型文件组织目录，导致几何与纹理的中间产物散落在各处，调试时无法定位是哪一级退化。正确做法是按阶段产物切分，每个阶段一个目录，目录内只放该阶段的输入契约、输出产物与校验脚本。几何阶段的产物是 SDF 场与网格，纹理阶段的产物是多视图渲染与 UV 图，监督阶段的产物是重投影误差与损失曲线。

具体结构可以这样落地：顶层分 data、geo、tex、render、cond、edit、eval 七个目录。data 存放原始资产与预处理后的条件数据，geo 存放几何 DiT 的配置、SDF 解码器与网格导出脚本，tex 存放纹理扩散的配置、多视图采样器与 UV 烘焙，render 存放可微渲染器与相机采样策略，cond 存放文本、图像、草图三类条件编码器及其预处理，edit 存放局部编辑接口的掩码与重生成逻辑，eval 存放验收断言脚本。每个目录下必须有 contracts 子目录，写明输入输出的张量形状、坐标系约定与单位。

坐标系约定是复现中最容易被忽略的崩溃点。几何分支输出的网格在哪个规范空间、纹理分支的多视图相机在哪个世界坐标系、可微渲染的投影矩阵采用哪种手性，三者必须写进 contracts 并在每个阶段的入口做断言。一个具体例子：若几何导出时做了 Y 轴翻转而纹理采样器未同步，多视图渲染会出现上下颠倒的纹理，可微渲染的梯度会把错误固化进 UV，表现为纹理在物体底部出现镜像拉伸。这类错误不会让训练崩溃，只会让结果“看起来不对”，因此必须靠契约断言而不是靠肉眼发现。

条件编码目录要单独拆出，因为三类条件的预处理差异极大。文本条件走 tokenizer 与嵌入查表，图像条件走固定分辨率的归一化与裁剪，草图条件走二值化与线宽归一化。把三者混在一个预处理脚本里，会在数据加载阶段引入隐式的分布偏移，而这种偏移在训练曲线上不可见，只在生成结果上体现为条件不响应。工程上要求每类条件有独立的预处理函数与独立的单元测试，测试内容是“同一原始输入经两次预处理得到相同张量”。

三 · 数据准备：条件数据与几何纹理的对齐是主矛盾

论文的数据集是 Objaverse 与内部可控数据。复现时 Objaverse 可直接获取，但内部可控数据不可得，这意味着条件控制分支的复现只能依赖自建的小规模条件数据。自建数据的核心不是数量，而是对齐：每一条条件数据必须与一个几何资产、一套纹理、一组相机视角严格对应，否则条件编码器学到的是噪声与几何之间的伪相关。

对齐的具体机制是三元组索引：资产 ID、条件类型、条件内容。几何分支用资产 ID 取 SDF 与网格，纹理分支用资产 ID 加相机集合取多视图，条件分支用资产 ID 加条件类型取条件张量。索引必须做完整性校验，任何一条记录缺任一字段即整条丢弃，不做补全。这是防止训练时静默错位的唯一可靠手段，因为错位在损失上表现为缓慢上升的基线噪声，很难归因。

条件数据的构造要区分“强条件”与“弱条件”。草图与分割属于强条件，因为它们直接约束几何轮廓；文本属于弱条件，因为它只约束语义与风格。复现时若把弱条件与强条件混在同一批次里等权训练，几何分支会偏向强条件而忽略文本，表现为文本输入下生成结果趋同。工程做法是分批采样并在损失里对条件类型加权，权重不引用论文数值，只按“强条件权重不低于弱条件”的定性原则设定，并在验收断言里检查不同文本输入是否产出结构不同的网格。

纹理数据准备的关键是多视图一致性。纹理扩散以多视图渲染为条件，若同一资产的不同视角渲染来自不同光源或不同曝光，纹理分支会学到光照而非反照率。复现时必须固定渲染时的光照模型与相机内参，并把光照参数写进 contracts。一个具体失败模式：相机内参在不同资产间不一致，导致多视图之间的尺度失配，纹理在 UV 展开时出现接缝错位，可微渲染的重投影误差在接缝处出现尖峰。验收断言应检查 UV 接缝处的重投影误差是否与面内误差同量级。

数据规模与训练配方的匹配也是复现难点。论文用大规模数据训练，复现时数据量下降后，几何 DiT 的容量必须同步下调，否则会过拟合到少数资产的结构先验，表现为对未见草图的结构不响应。工程判断是：先固定模型容量，用数据量做扫描，找到损失开始震荡的拐点，再把容量定在拐点之下。这个过程不需要论文数值，只需要行为观测。

四 · 超参：分开训练意味着两套独立配方

几何与纹理分开训练，意味着超参不能共用一套。几何分支的核心超参是扩散步数、SDF 解码器的分辨率与网格提取的等值面阈值；纹理分支的核心超参是多视图数量、UV 分辨率与可微渲染的采样密度。两套配方的耦合点只有一个：几何输出的网格质量决定纹理分支的输入质量，因此几何分支的验收必须先于纹理分支的训练。

几何分支的扩散过程可写成离散步的迭代：

$$\mathcal{M}_0=\mathrm{GeoDiT}(c_{\mathrm{geo}}),\qquad \mathcal{M}_{t}=\mathrm{Denoise}(\mathcal{M}_{t+1},c_{\mathrm{geo}},t)$$

其中去噪步的条件注入方式决定控制强度。复现时要区分“条件作为额外 token 注入”与“条件作为交叉注意力键值”两种实现，前者控制弱、后者控制强但训练更不稳定。工程上先用前者跑通最小版本，再用后者做控制增强，两者之间的切换必须通过配置而非改代码，否则消融无法复现。

SDF 解码器的分辨率是几何分支最敏感的超参。分辨率过低会让薄结构丢失，表现为草图里的细长部件在网格上消失；分辨率过高会让网格提取的内存占用陡增，且在等值面附近产生大量退化三角形。验收断言应检查网格的退化三角形比例，超过阈值即判定该分辨率不可用。这个阈值不引用论文数值，按“退化三角形不影响后续渲染”的定性标准设定。

纹理分支的超参核心是多视图数量与视角分布。视角太少会让 UV 背面区域缺乏监督，表现为纹理在不可见区域出现涂抹；视角太多会让可微渲染的单步代价线性上升，拖慢整条链路。复现时按“覆盖球面均匀分布”的原则采样视角，并把视角集合固定写进配置，避免每次训练重新采样导致纹理分支学到视角分布而非纹理本身。一个具体例子：视角集合每次随机重采样，纹理分支在早期训练中会把视角编号当作隐变量，表现为同一资产在不同批次下生成不同 UV 布局，可微渲染误差不降反升。

可微渲染的采样密度是纹理分支的隐性超参。采样密度不足会让梯度稀疏，UV 图出现块状伪影；采样密度过高会让显存溢出。工程做法是把采样密度与 UV 分辨率绑定，按“每个 UV 像素至少被一个渲染样本覆盖”的原则设定，并在 contracts 里写明绑定关系。这是防止显存崩溃与伪影同时出现的唯一可控手段。

五 · 验收断言：把“看起来对”变成可执行检查

验收断言分三层：契约层、行为层、端到端层。契约层检查张量形状、坐标系手性、单位与视角集合的一致性，任何一条不满足即终止，不进入训练。行为层检查几何分支的结构稳定性、纹理分支的视角一致性、条件分支的响应性。端到端层检查整条链路在固定种子下的可复现性与推理预算。

行为层的具体断言可以写成伪代码思路：对同一条件输入，用两个不同随机种子跑几何分支，比较网格的顶点数、面数与包围盒，若差异超过容差则判定几何分支不稳定；对同一网格与同一视角集合跑纹理分支两次，比较 UV 图的逐像素差异，若差异集中在接缝处则判定多视图一致性不足；对同一几何输入换不同文本条件，比较生成网格的结构差异，若差异低于阈值则判定条件未生效。这些断言不依赖绝对数值，只依赖相对比较，因此可以在没有论文阈值的情况下落地。

端到端层的断言要覆盖推理预算。论文给出推理数十秒的量级，复现时按阶段拆分预算：几何分支占大头，纹理分支次之，可微渲染校验最小。若某一阶段超预算，优先降该阶段的分辨率而非降整条链路的精度，因为分辨率与质量的权衡在几何分支上更可控。一个具体失败模式：把纹理分支的多视图数量翻倍以提升质感，结果推理时间超出预算且显存溢出，整条链路无法在单机上完成一次前向。工程判断是：预算先于质量，先保证链路可跑，再在预算内做质量调优。

局部编辑接口的验收单独一层。编辑接口依赖条件编码与几何表示之间的可寻址结构，复现时若没有语义标注，只能做几何层面的掩码重生成。验收断言应检查掩码区域外的几何与纹理是否保持不变，掩码区域内的重生成是否与条件一致。一个具体例子：掩码边界未做羽化，重生成后边界处出现几何裂缝与纹理接缝，可微渲染误差在边界处出现不连续跳变。断言应检查边界处的误差连续性，而非只看区域内的生成质量。

六 · 常见崩溃点：从显存到语义的四类失效

第一类是显存崩溃，集中在 SDF 解码器的高分辨率网格提取与可微渲染的高采样密度。前者在等值面提取时产生稀疏大张量，后者在反向传播时保留渲染中间结果。缓解手段是分块提取与梯度检查点，但分块会引入块间接缝，检查点会拖慢训练。工程判断是：几何分支用分块加接缝后处理，纹理分支用检查点加降低采样密度，两者不可互换。

第二类是数值崩溃，集中在扩散过程的步长与条件注入的尺度。条件张量未归一化会让交叉注意力的键值尺度失衡，表现为损失在前若干步爆炸。缓解手段是在条件编码器出口做层归一化，并在 contracts 里写明条件张量的均值与方差约束。这类崩溃在日志上表现为损失尖峰，若不看中间张量统计很难归因。

第三类是语义崩溃，集中在条件不响应与纹理光照混淆。前者源于强弱条件混批与条件注入方式过弱，后者源于多视图渲染的光照不一致。这两类崩溃不会让训练失败，只会让结果“可控性”与“真实感”同时退化，且退化在损失曲线上不可见。唯一可靠的发现手段是行为层验收断言，即在训练中途定期跑条件响应性与视角一致性检查。

第四类是接口崩溃，集中在局部编辑的掩码与重生成逻辑。掩码坐标系与几何坐标系不一致会让编辑区域错位，重生成时若未冻结掩码外区域会让整条链路退化为全量重生成。工程做法是把掩码坐标系写进 contracts，并在重生成入口做断言：掩码外区域的顶点坐标在重生成前后必须逐位相同。这是防止编辑接口退化的硬约束。

把这四类崩溃点与前面的验收断言对齐，复现的工程判断就落在一条具体机制上：每个阶段入口做契约断言，每个阶段出口做行为断言，端到端做预算断言，三类断言共同构成最小可跑版本的准入门槛。门槛之内的链路可以调参，门槛之外的链路必须先修契约，因为契约错误会让所有调参都变成对错误目标的拟合。
