一 · 训练数据的来源与分布假设

EG3D 的实验覆盖四个数据集：FFHQ、AFHQ、ShapeNet、CompCars。这四个名字在论文里并列出现，但它们对训练流程提出的要求并不相同，把它们当成同质的“数据集列表”是阅读时最常见的偷懒。FFHQ 与 AFHQ 是真实拍摄的人脸与动物脸，图像本身没有配套的相机参数与三维真值；ShapeNet 与 CompCars 则是以物体为中心的数据，类别受控、视角分布相对规整。EG3D 的生成器只被 2D 判别器监督，因此它对“真值”的全部依赖就是一批图像加上一个相机分布假设。这一点决定了后面所有评测数字的口径：网络学到的不是某个物体的三维扫描，而是“在给定相机分布下，渲染结果看起来像这批图像”的场。

具体机制上，训练时每个样本的相机位姿从预设分布中采样，生成器据此渲染出图，判别器只看这张 2D 图与真实图。相机分布不是从数据中估计出来的，而是人为设定的先验——俯仰角、方位角、半径各有取值范围。于是数据的作用被压缩成两件事：提供外观纹理的统计量，以及隐式地约束“哪个视角下应该看到什么”。对于 FFHQ 这类正面为主的人脸数据，侧后方视角几乎没有真实图像覆盖，模型在这些角度上的输出完全由三平面的共享结构与判别器的归纳偏置外推出来。这不是缺陷披露，而是理解评测的前提：指标衡量的是分布内的渲染质量，不是分布外的几何正确性。

系统代价在这里体现为一种不对称：增加数据量能改善分布内的纹理保真度，却不会自动扩展相机分布的有效覆盖。若把相机采样范围调宽而数据不变，判别器在极端视角上收到的真实样本稀疏，梯度信号变弱，生成器倾向于在这些角度输出模糊或塌陷的几何。失败模式是“视角一偏就露馅”，而 FID 这类在固定视角集合上计算的指标对此并不敏感。具体例子：在 AFHQ 上，正面与四分之三侧面的渲染锐利，接近轮廓边缘的大角度侧视则出现密度场被削平、毛发细节消失的现象，这来自相机分布与数据覆盖的错配，而非三平面表示本身的容量不足。

二 · 评测协议：固定视角集合与指标口径

EG3D 报告的核心指标是 FID，在 512×512 渲染分辨率上计算。FID 的机制是把生成图与真实图分别送进一个固定的图像分类特征提取器，对两组特征做高斯拟合，度量两个多元高斯分布之间的弗雷歇距离：

$$\mathrm{FID}=\lVert\mu_r-\mu_g\rVert_2^2+\mathrm{Tr}\!\left(\Sigma_r+\Sigma_g-2(\Sigma_r\Sigma_g)^{1/2}\right)$$

公式里没有任何三维量。这意味着 FID 只对“渲染出来的 2D 图像看起来像不像真实图像”负责，对多视角一致性、对几何是否合理完全不置一词。论文用 FID 优于 StyleNeRF 来支撑 FFHQ 上的结论，这个比较在口径上是自洽的——两者都是 2D 图像分布的距离——但它不能被读成“EG3D 的三维几何比 StyleNeRF 更准”。指标的名称与它实际约束的对象之间存在一条鸿沟，跨过这条鸿沟的推论都是越界的。

评测协议的另一半是视角集合。生成多视角图时，相机位姿按固定规则选取，通常包含若干方位角与俯仰角的组合，渲染出图后统一计算指标。这个集合一旦固定，就形成了一个可以被针对性优化的目标：模型只要在这几个特定视角上表现好，指标就好看，而视角之间的连续性、视角之外的合理性都不进入分母。工程上这带来一个具体风险：调参时若以该固定集合的 FID 为唯一验收信号，容易选出在集合内锐利、在集合外崩坏的配置。合理的做法是把评测视角分成“报告集”与“留出集”，后者不参与任何模型选择，只用于检查视角连续性。

系统代价是计算量。FID 需要足够多的样本估计协方差，多视角渲染又要为每个样本跑完整的体渲染管线，成本随视角数线性增长。失败模式则是特征提取器与数据域的耦合：在 ShapeNet 这类以物体为中心、背景干净的数据上，特征提取器对形状差异敏感；在 FFHQ 上它更敏感于纹理与光照。同一个 FID 数值在不同数据集之间不可比，跨数据集的指标排名没有意义。具体例子：ShapeNet 上“能生成视角一致的汽车与椅子”这一结论，是靠多视角渲染的目视一致性支撑的，而不是靠某个标量指标——论文并没有给出一个统一的三维一致性分数，读者不应把 FID 的改善误读为该结论的量化证据。

三 · 消融的评测逻辑：三平面、判别器维度、姿态条件

论文的消融覆盖三组对照：三平面对比单平面与体素表示；2D 判别器对比 3D 判别器；姿态条件的有无。这三组消融各自回答一个不同层面的问题，把它们混为一谈会掩盖真正的因果链。

三平面对比体素的消融，检验的是表示效率。体素表示的显存随分辨率立方增长，在目标分辨率下很快触顶；三平面把存储压到三张 256×256×32 的二维特征图，查询时做双线性插值再拼接。机制上，插值把连续坐标映射到离散网格的四个角点，权重由坐标的小数部分决定：

$$F(\mathbf{x})=\mathrm{MLP}\!\left(\mathrm{interp}(T_{xy},\mathbf{x}),\ \mathrm{interp}(T_{xz},\mathbf{x}),\ \mathrm{interp}(T_{yz},\mathbf{x})\right)$$

代价是表达能力被网格分辨率与平面数量锁死：三个正交平面无法表示在三个投影方向上都高频变化的场，固定拓扑的限制由此而来。失败模式是薄结构与非凸形状的几何精度不足，比如椅子的细腿、汽车的后视镜，在插值网格上被平滑掉。具体例子：ShapeNet 的椅子类别中，靠背的镂空与腿部的分离在渲染中常常粘连，这不是训练不充分，而是三平面在那些空间频率上的固有截断。

2D 判别器对比 3D 判别器的消融，检验的是监督信号的来源。3D 判别器需要三维真值或至少多视角一致的真实数据，获取成本高；2D 判别器只需单张图像，配合相机分布就能施加约束。代价是 3D 一致性只能间接获得：它来自三平面在三个投影上共享同一组特征，加上判别器在不同采样视角上看到同一物体时施加的隐式压力。这里没有显式的多视角一致性损失项，一致性是结构性的副产品而非被优化的目标。失败模式是判别器可以被“视角特定的纹理捷径”欺骗——生成器在某个视角放置判别器偏好的高频纹理，而在几何上并不自洽，指标不会察觉。

姿态条件的消融检验的是可控性。加入姿态条件后，生成器接收相机参数作为输入，渲染与位姿对齐；去掉它，模型退化为在固定或平均视角附近生成，视角一致性无从谈起。代价是条件化引入了位姿与内容的耦合：若训练时位姿分布与内容分布相关（比如人脸数据里大角度总是伴随特定光照），模型可能学到虚假关联，换一个位姿就改变身份特征。具体例子：在 CompCars 上，若数据中某一侧视角的样本偏少，条件化后的生成器在该侧视角可能改变车型细节，而 FID 在报告视角集合上仍然稳定。

四 · 一个容易误读的数字：FID 优于 StyleNeRF

论文在 FFHQ 上报告 FID 优于 StyleNeRF，渲染分辨率为 512×512。这个结论被大量后续工作引用，但引用时的语境经常发生漂移：从“在 512×512 的 2D 渲染图上，EG3D 的图像分布距离小于 StyleNeRF”滑向“EG3D 是更好的三维生成模型”。这两句话的差别正是本部分要拆开的东西。

先看口径。FID 的比较对象是渲染图与真实图的特征分布，评价的是“像不像照片”。StyleNeRF 同样是基于神经辐射场的 2D 监督生成模型，两者的比较在同一口径下成立。但“更好”这个词在三维语境下至少还包含三层含义：多视角一致性、几何精度、视角外推能力。FID 对这三层都不做测量。一个模型完全可以在 FID 上落后而在多视角一致性上领先，反之亦然。因此这个数字的正确读法是：在固定视角集合、固定分辨率、固定特征提取器的条件下，EG3D 的 2D 渲染分布更接近真实分布。它是一个条件句，条件被省略后就变成了误导。

再看机制上的解释。EG3D 的 FID 优势来自计算负担的转移：把三维场的生成交给 2D 卷积，StyleGAN2 主干能在高分辨率上生成高频细节，三平面查询只是把这些细节映射到空间。相比之下，纯隐式 MLP 的生成器难以用 2D 卷积高效生成高频细节，体素表示则受显存立方增长的限制。所以 FID 的改善主要来自渲染图的高频保真度，而不是几何精度的提升——后者恰恰是论文自己承认的局限。把 FID 优势归因于“几何感知更好”是因果误读，正确的归因是“2D 卷积的可扩展性被保留了下来”。

作弊风险在这里具体化为两种操作。其一是视角集合过拟合：在报告用的固定位姿上反复调参，模型在这几个视角上的 FID 被压低，而视角间的插值出现跳变。其二是特征提取器的域偏置：若真实图与生成图在背景、裁剪、色彩统计上被人为对齐，FID 会下降，但三维结构并未改善。两种操作都不违反评测协议的字面规定，却让数字失去意义。工程判断是：任何以 FID 为唯一验收信号的 3D 生成流水线都不可靠，必须搭配不参与模型选择的留出视角集与目视的多视角连续性检查。具体例子：把同一模型在报告视角集与旋转 30 度后的留出集上分别渲染，若两者 FID 差距显著拉大，说明模型在拟合视角而非学习场。

五 · 指标口径与工程验收的对应关系

把评测协议翻译成工程验收断言，需要明确每个指标约束的对象。FID 约束 2D 渲染分布，对应断言是“在指定视角集合与分辨率下，渲染图的特征分布距离低于阈值”。多视角一致性没有标量指标，对应断言只能是成对比较：同一隐变量在两个相邻视角渲染，光流或特征匹配的差异应低于阈值，且随视角间隔增大而平滑增长，而不是阶跃。几何精度同样没有直接指标，对应断言是渲染深度图与轮廓的稳定性——密度场在物体表面的梯度方向应连续，薄结构不应在相邻视角间闪烁。

系统代价在于这些断言的执行成本。成对多视角渲染把渲染次数翻倍，深度图导出需要额外的体渲染通道，光流或特征匹配又要引入外部模型。相比之下 FID 只需一次批量渲染加一次特征提取。工程上常见的折中是：FID 作为快速回归信号，多视角一致性作为发布前的门禁，几何检查作为抽样人工复核。这个分层不是理论最优，而是成本与覆盖面的折中。

失败模式是断言之间的冲突。压低 FID 的调参可能同时恶化多视角一致性——生成器学会在报告视角上放置判别器偏好的纹理，而视角间的场不连续。此时两个断言给出相反信号，需要判断哪个更接近部署需求。若下游任务是单视角渲染，FID 优先；若下游是三维资产导出或前馈重建的监督信号，一致性优先。具体例子：LRM、TripoSR 等前馈重建模型继承 triplane 表示时，它们需要的是几何上可查询的场，而不是某个视角的锐利渲染，因此对上游生成器的验收应以多视角一致性为主，FID 为辅。这个判断来自下游用途，而非指标本身的优劣。

六 · 数据与评测的耦合：为什么口径必须先于数字

回到数据来源与评测协议的耦合关系。EG3D 的训练不依赖三维真值，评测也不测量三维真值，两者在“只有 2D 图像”这一点上是一致的。这种一致性是方法的设计选择，也是它可扩展的原因：任何有图像的物体类别都能训。但它同时意味着，数据分布的任何偏置都会直接进入评测口径而不被察觉。FFHQ 的正面偏置、AFHQ 的物种内视角规整、ShapeNet 的类别受控、CompCars 的拍摄角度集中，这些偏置在 FID 上表现为“分布内很好”，在视角外推上表现为“一偏就崩”。

机制上，相机分布是连接数据与评测的枢纽。训练时的采样分布决定了模型见过哪些视角，评测时的固定集合决定了哪些视角被计分。两者若不重合，数字就只覆盖了交集。工程上可执行的检查是：把训练相机分布的覆盖范围与评测视角集合画在同一张角度图上，标出评测集合落在训练覆盖之外的视角比例。这个比例越高，FID 数字的解释力越弱。代价是需要记录训练时的采样日志，很多复现流程并不保留这一项，导致事后无法做这个检查。

最后一个具体判断落在三平面表示的继承关系上。EG3D 的三平面成为前馈重建模型的标准中间表示，LRM、TripoSR 把生成器换成图像条件 Transformer，但保留了 triplane 作为可查询的场。这意味着上游生成器的评测口径会被下游继承：若上游用固定视角 FID 选型，下游重建模型拿到的 triplane 可能在某些视角上不自洽，而重建阶段的监督信号无法修正这一点。工程判断是：为 triplane 这类中间表示建立验收时，指标必须约束“场”而不是“图”，也就是在连续视角上采样查询而非在离散集合上渲染计分。这个判断不依赖任何实验数字，只依赖表示的可查询性这一事实。
