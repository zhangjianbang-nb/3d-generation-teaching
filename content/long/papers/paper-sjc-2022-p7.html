一 · 对比轴的确立：表示、监督、速度、显存与失败模式

把 SJC 放进同期与后继方法的坐标系里，第一步不是比“谁出图更好看”，而是先把可比维度拆干净。SJC 的得分链是对渲染雅可比做链式法则：给定 3D 参数 θ（NeRF 的密度与颜色场，或网格顶点），可微渲染器给出图像 x=r(θ)，2D 扩散在噪声级 t 上给出图像得分 ∇xlog pt(x)，于是 θ 空间得分写成期望形式

$$\nabla_\theta\log p_t(\theta)\approx\mathbb{E}_{\xi}\!\left[\nabla_x\log p_t\big(r(\theta)\big)\,\frac{\partial r(\theta)}{\partial\theta}\right]$$

这个式子的每一个因子都对应一个工程维度：∇xlog pt 来自哪个 2D 模型（监督来源），∂r/∂θ 由什么渲染器给出（表示与可微性），期望怎么估（采样次数决定方差与速度），以及整条链在什么条件下失效（失败模式）。因此本部分的对照轴固定为五项：3D 表示、监督信号形态、单资产优化速度、显存占用结构、典型失败模式。对照对象选 DreamFusion（同期，SDS）、CLIP-guided 早期路线（前驱式监督）、以及 VSD（后继，分布匹配）。选择这三者是因为它们恰好覆盖了“启发式得分—严格得分—分布匹配”的演化线，而 SJC 正卡在中间。

需要先说明一个判断：SJC 与 DreamFusion 在最终质量上接近，这是论文自身给出的定性结论；SJC 的增量在于“可推导”，而不是“更好看”。因此下面的逐项对比里，凡是速度与质量维度，SJC 都不应被描述成赢家；它赢的是可解释性与偏差来源的可见性。这个基调决定了决策表的形状：SJC 不是默认选项，而是当团队需要可审计的得分路径时的选项。

二 · 表示与监督：雅可比把“表示选择”变成“梯度通路选择”

在表示维度上，SJC 的架构明确写了 NeRF/网格两条路。这不是风格选择，而是雅可比结构的选择。对 NeRF，θ 是场参数（密度 σ 与颜色 c 的网络权重或体素栅格），渲染是沿射线的体积积分，∂x/∂θ 通过每条射线的采样点回传，雅可比是稠密但局部的：一个像素的梯度只经过该射线上的采样点。对网格，θ 是顶点位置与顶点色，渲染是光栅化，∂x/∂θ 通过重心坐标插值回传，雅可比稀疏且拓扑相关：一个像素只触碰三个顶点，但拓扑改变（分裂、合并）会让雅可比不连续。工程后果是：NeRF 路线的梯度通路平滑、易写，但每条射线要采样几十到上百点，反向图巨大；网格路线的反向图小，但需要处理拓扑事件与自相交，雅可比在轮廓处最不稳定。

监督维度上，三者的差别可以用一个统一写法看清。设渲染图为 x，2D 模型在噪声级 t 的得分记为 st(x)。SDS 的更新方向是“噪声差”

$$\Delta_{\text{SDS}}=\big(\epsilon_\phi(x_t;t,y)-\epsilon\big)$$

它把加进去的噪声 ε 与网络预测的噪声 εφ 之差当作梯度用，量纲上像得分（差一个系数），但没有显式的雅可比因子，也没有对 x 的分布做严格边缘化。SJC 则把 st(x) 显式乘上 ∂x/∂θ，并且这个乘是逐像素、逐通道的矩阵向量积。VSD 走得更远：它不直接用 2D 模型的得分，而是训练一个 3D 感知的得分蒸馏网络去匹配 2D 分布，监督形态从“单点得分”变成“分布匹配”。三者的监督信息量排序是 VSD ≥ SJC > SDS（就“是否显式建模分布”而言），但实现代价排序恰好相反。

一个具体例子能说明雅可比因子的实际作用：优化一个位于画面中央的球体，若只对轮廓像素施加得分，SDS 的噪声差会把轮廓整体推向外或内，方向由噪声实现决定，同一噪声级下不同随机种子可能给出相反符号；SJC 乘上 ∂x/∂θ 后，轮廓像素的梯度按“该像素由哪些顶点/采样点贡献”分摊，符号由几何投影决定，因此同一噪声级下更新方向更一致。代价是：轮廓处雅可比接近奇异（投影面积对顶点位移的导数在遮挡边界跳变），方差在这里被放大，这正是 SJC“方差大”的一个具体来源，而不是笼统的随机性。

三 · 速度与显存：期望估计把成本压在哪一侧

SJC 的得分是期望，工程上必须用有限样本估。伪代码层面的循环是：对每个优化步，采样若干噪声级 t（退火 schedule 决定 t 的分布），对每个 t 采样若干 ξ，渲染一次得到 x，查询 2D 模型得分，反向传播雅可比，累加得到 θ 梯度，再做 Langevin 更新

$$\theta\leftarrow\theta+\eta\,\widehat{\nabla_\theta\log p_t(\theta)}+\sqrt{2\eta}\,\xi_{\text{step}}$$

成本结构由此确定：每步的渲染次数 = 噪声级样本数 × 每级 ξ 样本数。这与 SDS 形成鲜明对比——SDS 每步只需一次前向加一次反向（一次渲染、一次噪声预测），而 SJC 的期望估计天然要求多次渲染，否则期望的方差会淹没信号。论文给出的训练事实是“每资产数小时”，这与 DreamFusion 同量级，说明 SJC 并没有在速度上取得突破；它的额外渲染被退火 schedule 的粗到细结构部分抵消——粗尺度阶段分辨率低、渲染便宜，细尺度阶段样本数可以减少。但这条抵消是有条件的：如果场景需要高分辨率细节，细尺度阶段的渲染成本会主导总时长。

显存维度上，两者的压力点不同。SDS 的显存峰值主要由 2D 扩散模型的前向激活与单次渲染的反向图构成，随分辨率线性增长但常数小。SJC 的显存峰值由雅可比反向图主导：NeRF 路线下，每条射线的采样点都要保留中间量以回传 ∂x/∂θ，若批内像素数为 P、每射线采样数为 S，反向图规模随 P×S 增长；网格路线下反向图小，但需要额外存储拓扑与光栅化中间缓冲。这意味着 SJC 在显存上更容易撞墙，尤其是在高分辨率、多视角批次的配置下；缓解手段是减小每步像素批次、把雅可比计算分块累加，代价是梯度噪声上升，又回到方差问题。这是一个闭环代价：显存换方差，方差换步数，步数换时间。

对照 VSD，速度与显存的账又不一样：VSD 需要额外训练一个蒸馏网络，前期有一次性的训练开销与显存占用，但每步只需查询蒸馏网络，不需要对 2D 模型做多次噪声级采样，因此单步更便宜、方差更小。SJC 在这条线上是“单步贵、方差大、但不需要额外网络”的位置。工程判断因此很直接：如果团队已经有稳定的 2D 扩散推理管线且不想引入第二个可训练网络，SJC 的链路更短；如果要压方差与单步成本，VSD 的结构更合适。

四 · 失败模式逐项对照

SJC 的失败模式可以按链路因子归类，每一项都能在同期的其他方法里找到对应或缺失。第一类是雅可比近似误差：论文的消融明确列了“雅可比近似”，说明实现中雅可比并非精确解析，而是有近似（例如忽略二阶项、或在轮廓处做平滑）。近似在平滑区域误差小，在遮挡边界与高频纹理处误差大，表现为几何边缘的“融化”或纹理拖影。DreamFusion 的 SDS 没有显式雅可比，因此不出现这类误差，但它以另一种方式失败：噪声差的方向偏差会在多视角间累积成“过饱和、过平滑”的外观，这是 SDS 已知的偏差来源，SJC 的理论价值恰恰是把这类偏差归因到“缺少雅可比与分布边缘化”上。

第二类是退火 schedule 失配：消融里列了退火 schedule，说明它对结果敏感。粗尺度阶段 t 大、得分平滑，适合定大局；细尺度阶段 t 小、得分尖锐，适合定细节。若 schedule 过快进入小 t，几何尚未收敛就被细节梯度锁死，表现为局部最优的“扁平化”物体；若过慢，则总时长膨胀且细节始终不出现。CLIP-guided 路线的对应失败是“提示词敏感”：CLIP 相似度是全局标量，缺少空间定位，容易出现多面同一语义（Janus 问题），SJC 用逐像素得分链在原理上缓解了这一点，但退火失配会重新引入类似的全局锁定。

第三类是得分模型选择带来的域偏移：消融列了“得分模型选择”。SJC 用预训练 2D 扩散（Stable Diffusion）且冻结，这意味着 2D 模型只在自然图像分布上可靠；渲染图在优化早期是噪声状或单色块，落在分布外，得分方向不可信。工程表现是早期步数“空转”，梯度大但方向乱。VSD 的分布匹配结构对这一点更稳健，因为它学的是“3D 渲染分布到 2D 分布”的映射，而不是直接查询分布外点的得分。这条对照给出了一个可操作的验收断言：在优化前若干步内，若渲染图的 2D 模型得分范数持续偏高而几何指标不动，应判定为域偏移导致的空转，而不是学习率问题。

第四类是方差导致的种子敏感：期望估计的有限样本让同一提示词、不同随机种子给出不同几何。这不是“随机性大所以多样”的优点，而是优化不稳定：Langevin 的噪声项 √(2η)ξ 与估计方差叠加，细尺度阶段若 η 不随 schedule 收缩，噪声会覆盖细节梯度。对照 DreamFusion，SDS 同样有种子的敏感性，但 SJC 的方差来源更明确（期望样本数），因此可以通过增加样本数或做控制变量来压，代价是时间。这条是 SJC 相对 SDS 的一个“可诊断性”优势：失败可以归因，而不是只能调参。

还有一个跨列的判断：SJC 与 SDS 的质量接近意味着不要为了质量从 SDS 迁到 SJC；迁移的理由只能是可审计性或需要显式雅可比的下游用途（例如把得分链嵌进更大的可微管线）。反过来，从 SDS 迁到 VSD 的理由可以是方差与单步成本，而不是“理论更严格”本身。这张表的用途是防止把“理论贡献”误读成“工程收益”。

六 · 一个具体对照场景：轮廓像素的梯度账

取一个可复现的小场景：单个物体、正面视角、分辨率中等，优化到粗尺度收敛后进入细尺度。此时轮廓像素占画面比例小，但对几何误差最敏感。在 SDS 下，轮廓像素的更新来自噪声差，其符号由该步采样的 ε 决定；由于 SDS 不做雅可比分摊，轮廓像素的梯度与内部像素的梯度量纲相同，导致轮廓被“整体推移”，物体要么膨胀要么收缩，细尺度阶段表现为轮廓抖动。在 SJC 下，轮廓像素的梯度被 ∂x/∂θ 分摊到少数顶点或射线采样点上，量纲随投影面积变化，因此轮廓处的有效步长小于内部，抖动被抑制，但雅可比在遮挡边界的跳变会引入局部尖刺。

这个场景给出两条工程断言。其一，若在细尺度阶段观察到轮廓周期性抖动且内部稳定，应优先检查退火 schedule 的小 t 进入时机，而不是调学习率；这是 SDS 与 SJC 共有的 schedule 敏感，但 SJC 的抖动幅度应更小（因雅可比分摊），若观察到相反结果，说明雅可比近似在轮廓处失效。其二，若显存峰值出现在细尺度阶段而非粗尺度阶段，说明雅可比反向图的像素批次没有随分辨率调整；正确的做法是把细尺度阶段的每步像素数下调、样本数上调，用时间换显存与方差，而不是降低分辨率——降低分辨率会让细尺度失去意义。

把这两条断言放回决策表：SJC 的工程价值不在“更快更好”，而在“每个失败都能指到链路上的一个因子”。当团队需要在有限算力下判断“是 schedule 错了、是雅可比近似错了、还是 2D 模型域偏移”，SJC 的显式得分链提供了可分离的诊断路径；这正是它相对 SDS 的实质差异，也是它被后继方法继承的那一层——VSD 的分布匹配与 SJC 的得分链同源，继承的是“把 2D 信号严格提升到 3D 参数空间”的问题设定，而不是具体的雅可比实现。
