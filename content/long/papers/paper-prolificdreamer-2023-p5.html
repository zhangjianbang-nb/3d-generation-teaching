一 · 失效条件：VSD 在哪些输入与配置下会退化

VSD 的梯度表达式看起来只是把 SDS 里的单一扩散得分换成「预训练得分减粒子得分」，但这个减法的有效性依赖若干前提。第一个前提是粒子得分必须真的逼近当前 3D 分布 q(θ) 的得分。粒子 LoRA 是在渲染图上做去噪训练得到的，它看到的是 3D 参数当前迭代产生的图像分布；如果 3D 参数在两次粒子更新之间移动太远，粒子得分就落后于 q，减出来的项不再是 KL 的梯度，而是一个带滞后偏差的方向。工程上表现为：3D 损失短暂下降后出现纹理抖动，粒子损失与 3D 损失交替震荡。失效条件可以写成：粒子更新步数与 3D 更新步数的比例失配，或粒子 LoRA 的学习率相对 3D 学习率过大/过小。

第二个前提是文本条件 y 与渲染视角 c 的配对不能错位。VSD 梯度里 ε_φ(x_t;y,t) 是文本条件下的预训练得分，ε_ψ(x_t;c,t) 是粒子在渲染图上的得分。若 c 只包含相机参数而不包含任何与当前视角一致的条件信息，粒子项退化为对渲染图分布的无条件拟合，减去的项会把文本对齐信号抵消掉一部分。具体机制是：粒子模型在训练时若把视角编码与图像内容解耦不充分，它学到的得分主要描述「这类渲染图长什么样」，而不是「这个文本对应的渲染图在该视角下长什么样」，于是 ε_φ − ε_ψ 中的文本项被系统性削弱。例子：多阶段流程中 NeRF 阶段用低分辨率渲染图训练粒子，进入网格精修阶段后分辨率提升，粒子若未同步重训，其得分描述的是低分辨率伪影分布，减法会把高频细节当成「粒子已解释的部分」压掉，输出偏平滑。

第三个前提是粒子数量与 LoRA rank 足以覆盖 q 的多模态结构。粒子数太少时，粒子得分是少数样本的经验得分，方差大；LoRA rank 太低时，粒子模型容量不足以区分不同模态，减出来的梯度会把多个模态平均成一个「中间态」，这正是 SDS 过饱和与纹理粘连的另一种表现形式。消融里粒子模型、粒子数、LoRA rank 都是敏感项，说明这些不是可随便取默认值的装饰参数。系统代价在这里体现为：增大粒子数或 rank 直接抬高显存与每步时间，而收益在超过某个点后递减；工程判断是先把粒子数与 rank 调到损失曲线稳定，再谈画质。

第四个失效条件是阶段切换。NeRF 到网格的精修阶段改变了 3D 表示的参数化与渲染管线，q(θ) 的几何含义变了，粒子得分若沿用上一阶段的权重，减法项与当前渲染分布不匹配。复现时必须把阶段切换视为一次分布重置：重训粒子或至少重置其优化器状态，否则精修阶段的前若干步会朝错误方向走。

二 · 被谁继承：分布匹配思想的下游迁移

VSD 之后，优化式文生 3D 的基线位置基本由它占据，后续工作多以它为对照。继承发生在三个层面。第一层是目标函数层面：把「单点拟合」换成「分布匹配」的写法被反复借用，凡是需要让生成器输出覆盖多模态目标分布的场景，都可以写成「预训练得分减当前生成分布得分」的形式。第二层是组件层面：用一个小型可学习模型（LoRA 或轻量网络）近似当前生成分布的得分，这个「粒子模型」模式被迁移到少步蒸馏中——教师模型提供目标得分，学生模型或辅助模型提供当前分布得分，两者相减构成蒸馏梯度。第三层是正则层面：3D 大模型训练时用分布匹配项约束渲染分布不要塌缩到少数模式，VSD 的减法结构被当作一种无需显式配对数据的正则。

需要写清哪里不能照搬。VSD 的粒子模型是针对单个资产、在优化过程中在线训练的，它不是一个可复用的先验。把它当成「训练好的得分模型」跨资产复用是错的：粒子得分描述的是特定 q(θ) 在当前迭代的分布，换一个资产或换一个文本，q 变了，粒子得分不再对应。工程上常见错误是缓存粒子 LoRA 权重以节省时间，结果是在新资产上减法项失配，表现为多样性下降但单图看起来还行——因为预训练得分仍在起主要作用，粒子项只是没帮上忙。另一个不能照搬的点是「每资产数小时」的预算假设：VSD 的开销结构是冻结主扩散模型加在线粒子训练，若把主模型也微调，显存与时间会成倍上升，且冻结主模型正是保证 ε_φ 稳定的前提，动它等于破坏减法两侧的语义。

还有一个边界是数据条件。论文的实验设定里没有 3D 训练集，VSD 完全依赖预训练 2D 扩散模型的图像先验。这意味着它的上限由 2D 先验决定：文本里描述的、2D 扩散模型没见过的几何结构或材质，VSD 无法凭空造出正确的 3D 分布，只能给出与 2D 先验一致的近似。工程判断是：当目标资产超出 2D 先验覆盖范围时，VSD 的分布匹配会匹配到一个「看起来合理但几何不对」的分布，此时增加粒子数或训练时长不会修复，需要外部几何约束或额外监督。

三 · 复现清单：从环境到阶段切换的可执行项

复现 VSD 的清单按依赖顺序排列，每项都对应一个具体机制而非泛泛的「调参」。第一项是冻结主扩散模型并固定其权重与精度模式；ε_φ 的稳定性是减法项有意义的前提，任何对主模型的微调或精度切换都会改变得分尺度。第二项是 3D 表示与渲染管线：NeRF 阶段的渲染分辨率、采样数、视角分布要与粒子训练输入一致，否则粒子学到的得分与 3D 渲染分布错位。第三项是粒子 LoRA 的配置：rank、目标模块、学习率、每步去噪的噪声调度，这些决定粒子得分逼近 q 的速度。第四项是更新比例：每个 3D 更新步对应多少次粒子更新，这个比例是失效条件一里的关键量。第五项是多阶段切换的重置策略。

伪代码思路如下（文字描述，不用代码块）：外层循环遍历 3D 更新步；每步先渲染若干视角得到图像 x；用当前粒子 LoRA 对 x 加噪后在多个 t 上做去噪训练，更新粒子参数 ψ；然后用冻结主模型与粒子模型分别对同一 x_t 预测噪声，按 VSD 公式加权相减，乘 ∂x/∂θ 后更新 3D 参数 θ；阶段切换时重置粒子优化器并重训若干步。关键点是粒子训练与 3D 更新共享同一批渲染图，保证减法两侧看到的是同一分布样本。

系统代价要逐项列清。显存：冻结主扩散模型常驻，粒子 LoRA 虽小但需保存激活以做去噪训练，渲染管线本身也占显存；三者叠加使单卡可跑的资产规模受限。时间：每资产数小时，主要花在粒子在线训练与多视角渲染上，粒子更新比例越高越慢。超参：粒子数、rank、学习率、更新比例、阶段划分点，论文消融显示这些项都影响结果，意味着复现不是「跑默认值」而是「按资产调」。失败模式：粒子损失不降说明粒子容量或学习率有问题；3D 损失震荡说明更新比例失配；精修阶段画质回退说明阶段切换未重置。验收断言应写成可观测的量：粒子去噪损失在若干步内单调下降并稳定；3D 损失在阶段内不出现持续震荡；多视角渲染的文本对齐分数与多样性指标同时不退化；阶段切换后若干步内损失回到切换前水平。

四 · 验收断言：怎么判断复现成功而不是「看起来像」

「看起来像」是 SDS 时代的验收陷阱，VSD 的验收必须同时看真实感、多样性与文本对齐三个维度，因为它的目标就是分布匹配而非单点拟合。具体断言分四类。第一类是一致性断言：同一文本、不同随机种子跑多次，输出的几何与纹理应有可辨差异，而不是几乎相同的过饱和结果；这是多样性是否真的来自分布匹配的检验。第二类是对齐断言：用冻结的图文相似度模型对多视角渲染打分，分数应在训练过程中上升并在阶段切换后保持，若精修阶段分数下降说明粒子项在抵消文本信号。第三类是稳定性断言：粒子去噪损失与 3D 损失的曲线形状，前者应平滑下降，后者允许波动但不能持续发散。第四类是几何断言：多视角渲染的轮廓与深度应互相一致，纹理粘连在几何上表现为不同视角下同一区域颜色跳变，可用跨视角颜色方差检测。

这些断言对应具体机制：多样性断言检验粒子数是否足够覆盖多模态；对齐断言检验 ε_φ 项是否未被 ε_ψ 项过度抵消；稳定性断言检验更新比例；几何断言检验渲染管线与粒子输入是否一致。工程上把四类断言做成每若干步记录一次的量表，比事后看图更早发现失效。例子：若多样性断言失败而单图质量尚可，优先检查粒子是否被缓存复用或 rank 过低；若对齐断言在精修阶段失败，优先检查阶段切换是否重训粒子。

不能照搬的验收标准也要写明。SDS 时代常用的「单图 CLIP 分数高即成功」在 VSD 下不充分，因为分布匹配允许单个样本分数一般但整体分布更接近文本条件分布；反过来，单图分数很高但多次采样几乎相同，说明退化成单点拟合，正是 VSD 要修的问题。验收应报告多次采样的分布统计而非单次最优。

五 · 工程判断：什么时候用 VSD，什么时候不用

VSD 的适用边界由预算与目标共同决定。当目标是高真实感、多多样性、可接受每资产数小时优化时，VSD 是强基线，其分布匹配结构比 SDS 更不容易产生过饱和与纹理粘连。当目标是批量资产生成、单资产预算以分钟计时，VSD 的在线粒子训练与多阶段流程不划算，此时应退到 SDS 类方法或前馈生成模型，并接受质量与多样性的折衷。当目标资产超出 2D 先验覆盖范围时，VSD 的分布匹配会匹配到错误分布，增加粒子数不解决问题，应引入几何先验或额外监督。

超参开销是工程判断里的硬约束。粒子数、rank、更新比例、阶段划分点构成一个高维调参空间，论文消融证明每一项都影响结果，这意味着复现的人力成本不只是算力。工程上应把调参顺序固定为：先固定阶段划分与渲染管线，再调更新比例使损失稳定，最后调粒子数与 rank 换取画质与多样性；反过来先调画质参数会在不稳定的损失上得到误导性的结论。系统代价的另一个来源是粒子在线训练与 3D 更新共享渲染图，渲染分辨率提升会同时抬高两者成本，精修阶段的分辨率提升必须与粒子重训预算一起规划。

最后落在具体机制上：VSD 的减法项 ε_φ − ε_ψ 是一个有符号的量，它的符号决定 3D 参数往哪个方向走，而符号的正确性依赖粒子得分对 q 的逼近程度与文本条件的一致性。工程上判断一次复现是否可信，不看最终渲染图是否好看，而看这个减法项在训练过程中的均值是否随文本对齐分数同向变化、其方差是否随粒子数增加而下降。若均值不随对齐变化，说明文本项被抵消；若方差不随粒子数下降，说明粒子得分没有收敛到 q。这两个观测量比任何单图指标都更直接地暴露失效条件，也是把 VSD 从「能跑」推进到「可复现」的分界线。
