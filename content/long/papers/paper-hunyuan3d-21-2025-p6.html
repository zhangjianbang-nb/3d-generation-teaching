一 · 复现边界与最小可跑版本的定义

复现 Hunyuan3D 2.1 的第一件事不是拉代码，而是把“复现”这个词切分成可验收的层次。论文描述的系统由两段构成：形状 DiT 沿用 2.0，PBR 材质分支是新增部分。对工程读者而言，完整复现意味着形状与材质两段都能跑通、且材质输出能被可微 PBR 渲染器消费；最小可跑版本则只要求 PBR 分支在固定形状输入下产出反照率、粗糙度、金属度三通道并完成一次 UV 融合与一次渲染监督前向。这两者的差别决定了目录结构与数据准备的重心：完整复现要处理多视图 PBR 数据的采集与光照解耦，最小版本可以把形状冻结、只验证材质链路。

把最小版本定义清楚，需要一条明确的输入输出契约。输入是：一组已对齐的多视图图像（相机内外参已知）、对应的掩码、以及一张已 UV 展开的基础网格。输出是：三张与 UV 布局一致的 PBR 贴图，以及一次可微渲染得到的重光照图像。中间必须存在三个可断言的检查点：多视图 PBR 预测是否在掩码内、UV 融合是否无空洞、渲染损失是否在有限值域内。任何一环缺失，后续超参调优都失去意义。

这里要强调一个常被忽略的工程判断：PBR 分支的失败大多不是扩散模型本身的问题，而是数据管线与 UV 拓扑的问题。论文把 UV 展开失败列为局限之一，这意味着复现时必须在目录里为“UV 失败样本”留出隔离区，而不是让失败样本静默污染训练集。最小可跑版本的价值就在于用少量样本把这条隔离逻辑跑通。

二 · 目录结构与模块切分

建议的目录按“数据—模型—渲染—验收”四层切分，而不是按论文的章节切分。数据层存放多视图图像、掩码、相机参数与 PBR 真值；模型层存放形状 DiT 的冻结权重与 PBR 分支的可训练权重；渲染层存放可微 PBR 渲染器及其材质参数映射；验收层存放断言脚本与失败样本清单。这样切分的好处是：当 UV 融合出现空洞时，能立刻定位是数据层的 UV 布局问题还是渲染层的材质映射问题。

模型层内部再细分三个子模块：多视图 PBR 扩散、UV 空间融合、光照解耦。多视图扩散的输出是逐视图的三通道预测；UV 融合把逐视图预测投影回 UV 空间并做补全；光照解耦在训练时把反照率与光照分量分离，使粗糙度与金属度不被烘焙进基础色。三者的接口必须用张量形状显式约束，例如逐视图预测的形状为视图数乘以通道数乘以分辨率，UV 融合的输出为通道数乘以 UV 分辨率。接口一旦模糊，光照解耦的监督信号就会串到错误的通道上。

渲染层的关键是材质参数到渲染器输入的映射。反照率直接进入漫反射项，粗糙度与金属度进入微表面 BRDF 的参数。复现时最常见的崩溃点是通道顺序与色彩空间：反照率若被当作线性空间处理而实际是 sRGB，渲染出的重光照图像会整体偏暗，进而让渲染监督的梯度方向错误。目录里应为色彩空间转换单独设一个模块，并在验收层加一条断言：同一材质在两种色彩空间下的渲染结果差异必须可解释。

验收层不是可选项。它至少包含三类脚本：数据完整性断言（视图数、掩码覆盖率、相机参数范围）、UV 融合断言（空洞率、接缝处梯度连续性）、渲染断言（损失有限、重光照图像在掩码内非零）。这三类脚本应在最小可跑版本跑通前全部就位，否则后续超参调整只是在噪声上做优化。

三 · 数据准备与光照解耦的工程代价

论文的数据集由 Objaverse 与内部 PBR 资产构成。复现时无法获得内部资产，这意味着光照解耦的训练信号只能来自公开数据中带 PBR 通道的子集。工程上的代价是：公开 PBR 资产的粗糙度与金属度分布偏窄，模型在极端金属度或高粗糙度区域的表现无法被充分监督。复现者必须接受这一数据限制，并在验收断言里显式标注“金属度大于某阈值的样本不参与损失统计”，而不是假装数据分布与论文一致。

光照解耦的具体机制是把观测图像分解为反照率与光照的乘积，再约束反照率通道不携带镜面高光。伪代码思路是：对每个视图，先用当前预测的反照率与粗糙度、金属度做一次可微渲染，得到重建图像；再把重建图像与观测图像的差异回传到三个通道。关键在于反照率的梯度要被光照项调制，否则反照率会把高光吸收进去，导致重光照时高光位置错误。这一调制在实现上表现为渲染器对反照率通道的偏导与对光照参数的偏导分离。

公式上，PBR 分支的监督是逐视图的三通道均方误差：

$$\mathcal{L}_{\mathrm{PBR}}=\sum_{v}\left\|\hat{\mathbf{a}}_v-\mathbf{a}_v\right\|^2+\left\|\hat{r}_v-r_v\right\|^2+\left\|\hat{m}_v-m_v\right\|^2$$

其中 a、r、m 分别是反照率、粗糙度、金属度，帽子表示预测值，v 遍历视图。这个损失看似简单，但复现时的陷阱在于三通道的量纲不一致：反照率是色彩量，粗糙度与金属度是标量。若直接相加，反照率的梯度会主导训练，粗糙度与金属度收敛缓慢。工程上的处理是给标量通道加权重，或在损失里对每个通道做归一化。论文未给出权重数值，复现者应以验收断言中的“三通道收敛速度可比”为目标自行标定。

一个具体例子：取一个带金属把手的杯子，多视图图像中把手处有强镜面高光。若光照解耦失败，反照率通道会在把手处出现亮斑，粗糙度通道则偏平滑。复现时可通过重光照断言发现：把光源方向旋转后，亮斑位置不随光源移动，说明高光被烘焙进了反照率。这类样本应进入失败样本清单，而不是被当作噪声丢弃。

四 · 超参与训练配方的可复现设定

形状分支沿用 2.0，复现时最稳妥的做法是冻结形状 DiT，只训练 PBR 分支。这样做的代价是无法联合优化形状与材质的一致性，但换来了训练稳定性。PBR 分支的超参需要覆盖四个维度：扩散步数、UV 融合的补全半径、光照解耦的分解强度、渲染监督的采样密度。论文只给出定性描述，复现者应以最小可跑版本的断言通过率为准绳逐项标定。

扩散步数影响推理时间，论文给出推理数十秒的量级。复现时若步数过多，单样本推理会超出工程预算；步数过少，多视图预测的一致性下降，UV 融合出现接缝。建议在最小版本里固定一个中等步数，先用少量样本验证 UV 融合的空洞率，再逐步调整。UV 融合的补全半径决定接缝处的平滑程度，半径过大导致细节丢失，半径过小导致空洞残留。这一参数与贴图分辨率耦合，论文的消融包含贴图分辨率，说明分辨率是影响材质完整性的关键变量。

光照解耦的分解强度是一个容易被忽略的超参。分解过强，反照率被过度平滑，失去材质细节；分解过弱，高光残留。复现时应把分解强度与渲染监督的采样密度联合调整：采样密度高时，渲染损失对高光位置更敏感，分解强度可以适当降低。表格给出最小版本的超参检查项：

超参作用失败模式
扩散步数控制多视图预测一致性过少导致 UV 接缝
UV 补全半径控制接缝平滑过大丢失细节，过小留空洞
光照分解强度分离反照率与高光过强平滑，过弱高光残留
渲染采样密度监督高光位置过低导致梯度噪声

训练配方的另一个关键是批次内视图的组织方式。多视图 PBR 扩散要求同一物体的多个视图在同一批次内，以便 UV 融合时能跨视图补全。若批次按视图随机打乱，融合模块拿不到同一物体的完整视图集，空洞率会显著上升。复现时应在数据加载器里按物体分组，并在验收断言里检查批次内视图的物体一致性。

五 · 验收断言与常见崩溃点

验收断言要写成可执行的检查，而不是人工目测。第一类断言针对数据：每个物体的视图数必须一致，掩码覆盖率必须高于阈值，相机参数必须在合理范围内。第二类断言针对 UV 融合：融合后的贴图在 UV 空间的无空洞率必须达标，接缝处的梯度必须连续。第三类断言针对渲染：渲染损失必须是有限值，重光照图像在掩码内必须非零，且光源旋转后高光位置必须随光源移动。这三类断言覆盖了论文列出的主要失败模式：数据限制、UV 失败、推理慢。

常见崩溃点按出现频率排序。首位是 UV 展开失败：输入网格的 UV 布局存在重叠或翻转，导致融合后的贴图在重叠区域出现颜色串扰。复现时应在数据准备阶段就过滤掉 UV 重叠的网格，而不是在训练中让模型去学习修补。第二位是色彩空间错误：反照率被当作线性空间输入渲染器，重光照图像整体偏暗，渲染损失的梯度方向错误，训练不收敛。第三位是通道顺序错误：粗糙度与金属度被交换，渲染出的材质在金属区域表现为粗糙，在粗糙区域表现为金属，重光照断言会直接暴露这一错误。

第四位是推理慢导致的验收超时。论文给出推理数十秒的量级，复现时若扩散步数与 UV 融合分辨率都取上限，单样本推理可能超出验收脚本的超时阈值。工程上的处理是把推理拆成两段：先跑多视图预测并缓存，再跑 UV 融合与渲染。这样验收脚本可以分段计时，定位慢在哪个环节。第五位是光照解耦的监督信号串通道：反照率的梯度被错误地回传到粗糙度通道，导致粗糙度通道出现色彩纹理。这一崩溃点在渲染断言里表现为重光照图像的粗糙度区域出现彩色噪声。

一个具体例子：取一个带织物质感的沙发，UV 展开时靠背与坐垫的 UV 岛相邻。若融合半径过大，坐垫的粗糙度会渗到靠背上，重光照时靠背出现不自然的平滑。验收断言应检查相邻 UV 岛接缝处的粗糙度梯度，若梯度突变超过阈值则判定融合失败。这类断言比整体损失更能定位问题。

六 · 从最小版本到完整复现的工程判断

最小可跑版本跑通后，向完整复现推进的顺序应是：先扩数据，再调超参，最后联合形状与材质。扩数据时优先补充金属度与粗糙度分布更宽的样本，因为论文明确把数据限制列为局限。调超参时以验收断言的通过率为目标，而不是以训练损失为目标；训练损失下降但断言失败，说明模型在拟合数据管线的偏差。联合形状与材质是最后一步，因为形状分支的改动会改变 UV 布局，进而让已标定的融合半径失效。

工程判断的核心是：PBR 分支的可复现性取决于数据管线与 UV 拓扑的确定性，而不是扩散模型的规模。论文把可微 PBR 渲染作为监督手段，这意味着渲染器必须是确定性的，同一材质在相同光源下两次渲染的结果必须一致。若渲染器带随机采样，渲染损失的方差会掩盖真实的梯度信号，验收断言也会变得不可重复。复现时应在渲染层固定采样种子，并在断言里检查两次渲染的差异为零。

另一个判断是推理预算的分配。论文给出推理数十秒，复现时应把预算优先分配给 UV 融合的分辨率，而不是扩散步数。因为 UV 融合的分辨率直接决定材质完整性，而扩散步数只影响多视图预测的一致性，后者可以通过跨视图补全部分弥补。这一分配在最小版本里就能验证：固定扩散步数，逐步提高融合分辨率，观察空洞率与重光照断言的变化。

最后落在具体机制上：光照解耦的监督信号必须与可微渲染的材质参数映射严格对齐，反照率通道的梯度要被光照项调制，粗糙度与金属度通道的梯度要被 BRDF 的偏导调制。这一对齐是复现 Hunyuan3D 2.1 材质分支的工程底线，任何通道顺序、色彩空间或量纲的错位都会在这一层暴露为渲染断言失败，而不是训练损失异常。
