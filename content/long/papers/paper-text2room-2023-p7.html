一 · 对比坐标系的建立：为什么不能只比"谁的图好看"

把 Text2Room 放进同期与后继方法的谱系里，第一件要拒绝的事就是"以单张渲染图的观感论高下"。房间级场景生成的评价维度至少分裂成四条互不替代的轴：表示形式（输出是隐式场、点云、网格还是分层图像）、监督信号（是否依赖 3D 真值、是否只用 2D 先验、是否引入多视图扩散）、生成速度与显存占用（逐场景优化还是前馈推理）、以及失败模式的空间分布（漂移是全局累积还是局部塌陷）。任何两个方法在其中一条轴上占优，往往在另一条轴上付出代价，因此逐项对比必须先把这四条轴钉死，再谈具体方法。

Text2Room 在这套坐标系里的位置非常明确：表示是显式带纹理网格，监督完全来自预训练 2D 模型（文生图、单目深度、文本条件 inpainting），没有 3D 训练环节，速度是逐场景迭代、每个房间数分钟量级，显存随场景规模线性增长并成为硬上限。它的融合规则可以写成一次集合式的增量并集：

$$\mathcal{M}_{t+1}=\mathcal{M}_t\cup\mathrm{BackProject}\!\left(D_t,I_t,\mathbf{c}_t\right)$$

这条公式本身就是对比的锚点：新帧反投影出的几何被无条件并入已有网格，对齐误差不会被"平均掉"，而是被"叠加进去"。任何后继方法若想改善长距离漂移，就必须在这条并集运算上做文章——要么引入全局优化，要么改变表示使误差可回退。下面三个对照方法正是沿不同方向切开这个并集。

二 · 对照 DreamFusion：单物体优化的表示与监督差异

DreamFusion 是 Text2Room 论文中列出的基线之一，也是"文生 3D"早期最具代表性的路线。它的机制核心是分数蒸馏采样：把一个隐式辐射场（NeRF 类表示）的参数化渲染结果送入 2D 扩散模型，用扩散模型对图像的评分作为损失梯度，反传回 3D 参数。伪代码思路大致是：采样一个相机位姿，渲染出图像，给图像加噪到某个扩散时刻，让 2D 模型预测噪声，把预测噪声与真实噪声的差作为梯度信号更新场参数。整个过程中没有任何 3D 真值，监督信号全部来自 2D 先验，这一点与 Text2Room 同源。

差异出现在表示与优化范围上。DreamFusion 优化的是单个物体的隐式场，相机分布被约束在物体周围的一个球壳上，视角覆盖是封闭且有界的；Text2Room 优化的是不断扩张的房间网格，相机沿一条逐步推进的轨迹移动，视角覆盖是开放且累积的。前者可以在每次迭代中全局回看所有视角，误差有机会被联合优化抹平；后者只能做增量并集，早期帧的误差一旦写入网格就难以撤销。这就是为什么 DreamFusion 在单物体上几何自洽性较好，而把它直接搬到房间尺度会遭遇视角覆盖不足与优化时间爆炸。

速度与显存上，DreamFusion 是典型的逐场景长时优化，单场景需要大量迭代步数，显存主要被隐式场的参数与渲染采样占据，规模扩大时参数密度上升导致显存与时间同时恶化。Text2Room 把重负担转移给了三个预训练 2D 模型的前向推理，单帧成本固定，但帧数随房间扩张而增长，显存被已融合的网格与纹理占据。失败模式也不同：DreamFusion 的典型失败是几何在缺乏视角约束的方向上"糊成一片"、多面体伪影；Text2Room 的典型失败是沿轨迹的累积漂移与补洞处的纹理接缝。一个具体例子：让两者都生成"一间有窗的卧室"，DreamFusion 倾向于给出一个可从任意角度观看但比例失真的孤立房间块，Text2Room 能给出可走入的连续墙面，但走到远端时墙线会缓慢偏斜。

三 · 对照 Text2Light：全景先验与几何约束的取舍

Text2Light 是论文列出的另一条基线，走的是"先合成全景、再从中提取结构"的路线。它的机制是先由文本驱动生成一张全景图或分层全景表示，再从全景中解析出光照与几何线索，最终得到可渲染的场景。监督信号同样以 2D 先验为主，但它把一致性责任压在"单张全景必须自洽"这一约束上：全景的环形连续性天然消除了接缝，代价是几何细节只能从全景的有限分辨率中推断。

与 Text2Room 对比，表示差异最尖锐：Text2Light 的输出偏向图像域与光照域的分层表示，几何是派生的、粗糙的；Text2Room 的输出是显式网格，几何是主产物，纹理由反投影与 inpainting 附着其上。监督差异在于几何约束的来源：Text2Light 依靠全景的环状闭合来保证视角间一致，Text2Room 依靠单目深度反投影加连续对齐来保证，前者在全局一致性上有结构性优势，后者在局部几何完整性上有优势，因为每新加一帧都带来新的深度观测。

速度上 Text2Light 更接近前馈式，一次全景生成加解析即可出结果，显存压力集中在全景分辨率；Text2Room 是迭代式的，帧数越多越慢。失败模式的分野很清楚：Text2Light 在全景分辨率不足或文本描述涉及强纵深结构时，几何会退化为"贴图盒子"，缺乏可走入的空间层次；Text2Room 则在长距离漂移上失守，且补洞完全依赖 2D 先验，遇到文本未覆盖的区域会生成与已有纹理风格不一致的内容。具体例子：描述"一条通向厨房的走廊"，Text2Light 容易给出一张漂亮的环形全景但走廊纵深被压扁，Text2Room 能拉出真实纵深的走廊网格，但走廊尽头的门框会因累积对齐误差而错位。

四 · 对照后继路线 WonderWorld / WorldGen：漂移治理的不同切法

论文影响部分明确指出，Text2Room 开启了"2D 模型迭代长场景"的路线，WonderWorld 与 WorldGen 都在其思想上演进。这一族方法的共同骨架与 Text2Room 一致：用 2D 生成模型按视角出图、用深度反投影、增量融合。它们的演进方向集中在 Text2Room 最痛的两处：长距离漂移与补洞先验的单薄。

漂移治理的一条切法是引入可回退的表示或全局对齐。Text2Room 的并集运算没有回退能力，后继方法若改用带全局优化的场景表示（例如在融合时维护一个可优化的场景参数，定期对所有已观测帧做联合校正），就能把累积误差从"只增不减"变成"可被后续观测修正"。代价是每次全局校正都要重渲染或重优化，速度从"每帧固定成本"退化为"周期性尖峰成本"，显存也要同时容纳历史帧的观测缓存。另一条切法是改变相机推进策略，用重叠更高的视角序列换取更强的帧间约束，代价是同样房间规模需要更多帧、更长时间。

补洞先验的演进则是把单帧 inpainting 换成具备多视图一致性的生成先验，让补洞时能"看到"邻近视角已生成的内容。这在机制上要求把已融合网格的局部渲染作为条件输入，等于把 2D 模型的部分能力改造成条件生成器。系统代价是每次补洞都要额外渲染条件图并做条件推理，单次补洞成本上升；失败模式则从"纹理风格不一致"转为"条件图与生成图之间的几何错配"，即补出的内容在语义上合理但在深度上与洞口边缘对不上。具体例子：修补一面被家具遮挡的墙，Text2Room 可能补出风格漂移的花纹，后继方法能补出风格一致的花纹，但花纹的透视消失点可能与墙体走向有细微偏差。

决策依据可以落成三条工程判断。第一，若任务要求"可走入、可导出、可进渲染管线"的房间资产，显式网格是硬需求，Text2Room 及其后继是唯一直接匹配的选项，DreamFusion 的隐式场需要额外提取步骤且房间尺度覆盖不足。第二，若任务对全局一致性敏感而对几何细节宽容（例如背景环境、远景氛围），Text2Light 类全景路线的前馈速度与环状闭合是更划算的取舍。第三，若任务明确要求抑制漂移且能接受周期性优化尖峰，应选择在并集运算上引入全局校正的后继路线，而不是在原版 Text2Room 上叠加后处理。

还有一条容易被忽略的判据：失败模式是否可诊断。Text2Room 的漂移沿轨迹单调累积，表现为远端墙线偏斜，工程上可以通过闭合回路检测与已知平面约束来定位；DreamFusion 的糊化发生在缺乏视角约束的方向，难以用几何断言捕获；Text2Light 的纵深压扁是分辨率的结构性后果，无法通过增加帧数修复。可诊断性直接决定复现清单里的验收断言能否写死，这一点比单张渲染图的观感更能决定方法在管线中的去留。

最后落到机制层面：这四个方法的真正分水岭不在生成模型本身，而在"误差写入后是否可撤销"。Text2Room 的并集公式决定了误差只进不出，因此它的所有优点（速度可预测、显存可估算、几何完整）与所有缺点（漂移、接缝）都来自同一个设计选择；后继方法的全部演进，本质上都是在不放弃显式网格的前提下，为这条并集运算补上一个可回退的旁路。
