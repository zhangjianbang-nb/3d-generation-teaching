一 · 实验骨架：数据集构成与评测口径

Hunyuan3D 2.1 的实验部分围绕一个核心问题组织：把纹理阶段从基础颜色升级为完整 PBR 材质之后，生成资产是否真的能在引擎里重光照、是否真的能被工业管线接收。这个问题决定了数据集与基线的选择方式，也决定了结果表里哪些指标有意义。

数据集由两部分构成：Objaverse 与内部 PBR 资产。这两类数据在实验中承担不同职责。Objaverse 提供规模与形状多样性，使 PBR 分支在多视图扩散阶段见到足够广的物体类别与几何形态；内部 PBR 资产提供带完整反照率、粗糙度、金属度通道的监督信号，是光照解耦训练与可微 PBR 渲染监督的数据来源。这个组合本身就是一个工程判断：公开数据集普遍缺少物理正确的材质通道，单靠 Objaverse 无法训练出可信的粗糙度与金属度预测，必须引入内部采集或制作的 PBR 资产来补足监督。

评测口径同样分成两层。第一层是材质通道的完整性：生成结果是否同时具备反照率、粗糙度、金属度三个通道，且通道之间在物理上自洽。第二层是重光照表现：把生成的资产放进渲染管线，更换光照条件后观察其表现是否优于基础色模型。第二层是这篇论文真正想证明的东西，因为基础色纹理在固定光照下可以看起来正确，一旦换光就暴露出材质缺失的问题。实验设计上，这两层不是并列的指标，而是递进关系：通道完整性是前提，重光照表现是判据。

这里有一个容易被忽略的机制细节。PBR 材质的评测不能只看单通道的像素误差，因为反照率、粗糙度、金属度之间存在耦合：一个物体的金属度预测偏高、粗糙度预测偏低，单通道误差可能都不大，但渲染出来的高光形态会明显偏离。论文用可微 PBR 渲染作为监督，实际上把这个耦合关系放进了训练目标里，评测时也沿用渲染层面的判据。这一点决定了后面消融实验的解释方式：拆掉某个通道或某个训练环节，看的不是该通道的孤立误差，而是整体渲染表现的变化。

系统代价在这里第一次显现。内部 PBR 资产的规模受采集与制作成本限制，无法与 Objaverse 的体量相比。这意味着 PBR 分支的监督信号在数量上是不平衡的：形状与多视图外观可以从大规模公开数据中获得，而物理材质通道的监督相对稀疏。实验结果的解读必须带着这个前提，否则会把数据限制带来的泛化缺口误读为方法缺陷。

二 · 基线选择：为什么是这三个

基线列表是 Hunyuan3D 2.0、SF3D、TRELLIS。这三个基线各自对应一类对照，选择它们是为了把提升来源切分开。

Hunyuan3D 2.0 是自身的前代，对照它回答的问题是：在形状不变的前提下，把纹理阶段换成 PBR 分支，带来了多少材质层面的增益。这个对照最干净，因为形状 DiT 沿用 2.0，两者的差异集中在纹理与材质阶段。任何在重光照表现上的提升，都可以归因于 PBR 通道、光照解耦与可微渲染监督，而不是形状质量的改善。

SF3D 是生产级材质方向的另一条路线，对照它回答的问题是：Hunyuan3D 2.1 在“生产可用”这个判据上处于什么位置。SF3D 同样以 PBR 材质为目标，两者的比较不是单点指标的胜负，而是材质完整性与管线可用性的对照。论文的表述是 Hunyuan3D 2.1 与 SF3D 一起定义了生产级材质标准，这句话的含义是两者共同把“有 PBR 通道”变成了这类系统的准入条件，而不是互相替代。

TRELLIS 代表另一类 3D 生成路线，对照它回答的问题是：多视图 PBR 扩散加 UV 融合这套组合，相对于其他生成范式在材质保真度上的差异。TRELLIS 的对照价值在于它提供了不同技术路径的参照，使结果表不至于只在自家方法族内自证。

基线选择本身也暴露了一个评测难点。三个基线中只有 SF3D 明确以 PBR 为目标，Hunyuan3D 2.0 输出基础色，TRELLIS 的材质能力与本文口径不完全对齐。这意味着跨基线的比较不能简单看单一数值，而要看各自在“通道完整性”与“重光照表现”两个层面上的表现。论文的结果表述因此偏定性：PBR 材质完整，重光照表现优于基础色模型，工业管线可用。这三个判断分别对应三个基线对照的核心结论，而不是一张统一的数值排名表。

从工程角度看，基线选择还隐含了一个代价判断。与 2.0 的对照说明升级纹理阶段的边际成本落在哪里：形状分支不变，新增的是多视图 PBR 扩散、UV 融合与可微渲染监督，推理时间从 2.0 的水平上升到数十秒。这个代价是否值得，取决于下游管线是否真的需要重光照能力。对于只需要固定视角展示的场景，2.0 的基础色纹理已经够用；对于要进引擎、要换光、要做材质编辑的场景，PBR 通道是硬性要求。

三 · 主要结果：提升来自哪三个环节

主要结果的表述是：PBR 材质完整，重光照表现优于基础色模型，工业管线可用。这三句话对应三个不同的证据层面，需要拆开看提升的具体来源。

第一个来源是 PBR 通道的引入。基础色模型只输出反照率，粗糙度与金属度缺失，渲染时引擎只能用默认值填充，导致高光形态与材质感失真。Hunyuan3D 2.1 的多视图 PBR 扩散同时预测反照率、粗糙度、金属度三个通道，使资产在进入引擎时具备完整的材质描述。这个提升不是像素层面的，而是表达能力层面的：同样的几何，具备 PBR 通道后可以响应不同光照条件，而基础色纹理只能在一个光照假设下看起来正确。

第二个来源是光照解耦训练。多视图 PBR 数据在采集时带有当时的光照条件，如果直接监督，模型会把光照信息烘进反照率通道，生成的资产换光后就出现明显的颜色偏移。光照解耦训练把光照从材质中分离出来，使反照率通道表达的是物体本身的颜色而非拍摄时的照明。这个环节的提升体现在重光照表现上：更换光照后，反照率保持稳定，粗糙度与金属度驱动的反射行为随之变化，整体渲染结果符合物理预期。

第三个来源是 UV 空间融合与可微 PBR 渲染监督。多视图扩散的输出是若干视角下的材质预测，视角之间可能存在不一致；UV 空间融合把这些预测补全到统一的 UV 布局上，可微 PBR 渲染则把渲染结果与真值的差异回传，约束融合后的材质在物理上自洽。这个环节解决的是多视图到 UV 的转换损失问题：如果只做多视图预测而不做 UV 融合，资产在视角之间会出现接缝；如果只做 UV 融合而不做渲染监督，融合结果可能在单通道上接近真值但渲染表现偏离。

训练目标把这三个通道的监督写在一起：

$$\mathcal{L}_{\mathrm{PBR}}=\sum_{v}\left\|\hat{\mathbf{a}}_v-\mathbf{a}_v\right\|^2+\left\|\hat{r}_v-r_v\right\|^2+\left\|\hat{m}_v-m_v\right\|^2$$

这个式子逐视角对反照率、粗糙度、金属度求误差平方和。它的结构说明了一件事：三个通道在监督层面是并列的，但它们在渲染层面的作用不是并列的。反照率的误差直接影响颜色，粗糙度与金属度的误差影响高光与反射的形态。消融实验拆开这三个通道时，看到的不是三个独立的误差数字，而是渲染表现的不同退化模式。

系统代价在结果层面表现为推理时间。PBR 分支的多视图扩散、UV 融合与可微渲染监督使推理达到数十秒量级，相对于只输出基础色的流程明显更慢。这个代价是生产级材质的入场费：多视图扩散要跑多个视角，UV 融合要做空间补全，渲染监督在训练时消耗算力，推理时虽不直接做可微渲染，但多视图与融合的计算量仍然存在。

具体例子可以说明提升的位置。一个金属质感的物体，基础色模型给出的是带高光的颜色纹理，换到不同光照下高光位置与强度都不对，因为纹理里烘进了拍摄时的光照。Hunyuan3D 2.1 的输出把金属度设为高值、粗糙度设为低值，反照率表达物体本色，换光后高光随光源移动，反射形态符合金属的物理行为。这个差异不是颜色更准，而是材质描述完整之后渲染行为正确。

四 · 消融：三个被拆开的环节各自值多少

消融实验拆的是三个环节：PBR 通道、光照解耦、贴图分辨率。这三个变量分别对应材质完整性、光照独立性、空间保真度，拆开它们是为了确认提升不是来自某一个环节的偶然叠加。

拆掉 PBR 通道，等价于退回基础色纹理的设定。此时反照率仍然可以预测，但粗糙度与金属度缺失，渲染时引擎用默认值填充。退化模式很明确：资产在固定光照下看起来尚可，换光后高光形态与材质感失真，重光照表现回落到基础色模型的水平。这个消融确认了 PBR 通道是重光照表现的直接来源，而不是形状质量或反照率精度的副产品。

拆掉光照解耦，多视图 PBR 数据中的光照信息会被烘进反照率通道。退化模式是颜色漂移：生成的资产在训练光照下颜色正确，换到不同色温或方向的光照后，反照率出现系统性偏移，原本应该是中性色的表面带上拍摄时的色调。这个消融确认了光照解耦不是锦上添花的正则项，而是反照率通道能否表达物体本色的前提。它同时暴露了数据侧的依赖：光照解耦的效果取决于多视图 PBR 数据中光照条件是否有足够的多样性，如果数据的光照条件单一，解耦训练能分离出的光照成分有限。

拆掉贴图分辨率，UV 空间的材质表达被压缩。退化模式是细节丢失：粗糙度的空间变化被平滑，金属度的高低频细节消失，渲染结果在高频区域显得均匀。这个消融确认了 UV 融合与贴图分辨率共同决定了材质的空间保真度，分辨率不足时，即使通道完整、光照解耦正确，渲染表现仍然会在细节层面偏离。

三个消融的共同结构是：每个环节拆掉后，退化模式不同，但都指向同一个判据——渲染表现。这说明实验设计把可微 PBR 渲染监督放在了评测的核心位置，而不是把单通道误差当作主要指标。这个选择有工程含义：下游管线关心的是渲染结果，不是通道误差表。一个通道误差很小但渲染表现偏离的资产，在管线里仍然是不可用的。

消融还暴露了一个失败模式的来源。UV 展开本身可能失败，尤其是几何复杂或拓扑不规则的物体，UV 布局出现重叠或拉伸时，融合后的材质在对应区域出现接缝或失真。这个失败模式不是消融变量能修复的，它属于 UV 展开环节的固有风险。消融实验里贴图分辨率的变化会放大或缓解这个问题的可见程度，但不会消除它。工程判断上，这意味着 Hunyuan3D 2.1 的材质质量在几何规则、UV 展开顺利的资产上更可靠，在拓扑复杂的资产上需要额外的检查与修补。

五 · 证据的边界：数据限制与失败模式如何影响结论

实验证据的边界由三个局限划定：数据限制、UV 失败、推理慢。这三个局限不是附注，它们直接决定了结果表述的适用范围。

数据限制体现在内部 PBR 资产的规模与多样性上。PBR 分支的监督信号来自这部分数据，而公开数据集缺少物理正确的材质通道。结果是模型在内部 PBR 资产覆盖的材质类型上表现可靠，在覆盖之外的材质上泛化能力受限。这个限制在结果表里的表现是定性的：论文没有给出跨材质类别的细分数字，而是用“PBR 材质完整、重光照表现优于基础色模型”这样的表述。工程上解读这句话时，需要把它限定在数据覆盖的范围内，而不是理解为对所有材质类型都成立。

UV 失败是几何与材质衔接处的失败模式。多视图扩散给出的是视角空间的预测，UV 融合要把它搬到统一的 UV 布局上，这个转换依赖 UV 展开的质量。几何复杂、拓扑不规则的物体在展开时出现重叠或拉伸，融合后的材质在这些区域出现接缝、拉伸纹理或通道不一致。这个失败模式在消融实验里通过贴图分辨率的变化被间接观察到，但它不是分辨率能解决的问题，而是 UV 展开环节的固有限制。工程判断上，这意味着管线需要为 UV 失败准备回退路径：检测到展开质量不足时，退回多视图材质或人工修补，而不是直接把融合结果送进引擎。

推理慢是系统代价的直接体现。数十秒的推理时间相对于基础色流程明显更长，来源是多视图 PBR 扩散的多个视角、UV 空间融合的补全计算，以及训练阶段可微渲染监督带来的算力消耗。这个代价在生产管线里需要被预算进去：如果资产是批量生成，数十秒乘以批量规模会形成明显的吞吐瓶颈；如果资产是单件生成、后续有人工审核环节，这个时间可以被审核流程吸收。

这三个局限共同决定了证据的解读方式。结果表述里的“工业管线可用”不是无条件成立，而是有条件成立：在数据覆盖的材质类型内、在 UV 展开顺利的几何上、在推理时间可被管线预算吸收的场景下。把这三个条件去掉，结论就会过度外推。论文的实验设计本身也反映了这个边界意识：它没有用统一的数值排名来宣称全面领先，而是用通道完整性、重光照表现、管线可用三个定性判断来划定适用范围。

从证据结构上看，这篇论文的实验部分做了一件明确的事：把提升来源切分成可消融的环节，把评测判据放在渲染层面，把结论限定在数据与几何的适用范围内。这个结构使结果的可信度不依赖于单一数字，而依赖于多个环节的退化模式是否与预期一致。消融实验里每个环节拆掉后的退化模式各不相同，但都指向渲染表现，这个一致性是结果可信度的主要来源。

工程判断落在具体机制上：Hunyuan3D 2.1 的材质质量由多视图 PBR 扩散的通道完整性、光照解耦的反照率独立性、UV 融合与贴图分辨率的空间保真度三者共同决定，任何一个环节的缺失都会在渲染层面留下可识别的退化模式；而 UV 展开失败与数据覆盖限制是这套机制之外的边界条件，管线接入时需要在材质融合之后加一道 UV 质量检查，把展开失败的资产分流到回退路径，而不是让融合结果直接进入渲染。
