一 · 双流架构：几何 DiT 与纹理扩散的分工边界

Step1X-3D 的架构不是一条从文本到网格的单链，而是两条并行、在中间汇合的处理流。第一条流是几何流，核心是一个 DiT（Diffusion Transformer）骨干，输出被约束为 SDF 场，再由 SDF 解码为网格；第二条流是纹理流，以多视图扩散为主体，在给定几何的前提下生成多视角图像，再投影回 UV 空间。两条流的分工边界非常明确：几何流决定“形状是什么”，纹理流决定“表面长什么样”，而两者之间的耦合点只有一个——几何网格本身。

这种切分的直接后果是条件注入的位置被拆成两组。几何条件记为 $c_{\mathrm{geo}}$，纹理条件记为 $c_{\mathrm{tex}}$，前者包括草图、分割掩码、粗几何提示，后者包括文本描述、参考图像、材质风格线索。整条前向过程可以写成两个串接的映射：

$$\mathcal{M}=\mathrm{GeoDiT}(c_{\mathrm{geo}}),\qquad \mathcal{T}=\mathrm{TexDiff}(c_{\mathrm{tex}},\mathcal{M})$$

注意第二个式子把 $\mathcal{M}$ 作为纹理扩散的输入条件，而不是让纹理模型自己去猜形状。这是与“一体化生成网格加纹理”的模型最本质的差别：纹理扩散不需要在隐空间里同时建模几何与外观，它只需要在一个已知的、已经离散化为网格的表面上去解一个图像生成问题。工程上这意味着纹理分支可以复用成熟的视图扩散技术，而不必承担几何拓扑的建模负担。

具体机制上，几何 DiT 在隐空间上做去噪，但其监督信号来自 SDF 的符号与距离值，而不是体素占用概率。SDF 的好处是零水平集天然定义了一个封闭曲面，解码时用移动立方体一类算法提取等值面即可得到网格，不需要额外的后处理来封闭孔洞。代价是 SDF 解码对分辨率敏感：等值面提取的网格密度随隐式场采样网格走，采样网格粗则细节丢失，采样网格细则显存与提取时间线性上升。这是一个典型的系统代价——几何保真度与解码开销直接绑定，无法通过单纯增大 DiT 参数量来绕开。

一个具体例子：用户给出一张正面草图，草图上标出人物姿态与轮廓。几何流把草图编码为 $c_{\mathrm{geo}}$，DiT 在 SDF 隐空间去噪，解码得到带正确姿态的网格；纹理流此时收到的是这个网格加上一句“穿红色夹克、牛仔裤”的文本，多视图扩散在网格的法线引导下渲染出若干视角的 RGB 与对应深度，再反投影到 UV。两条流各自失败的模式不同：几何流失败表现为姿态错、肢体融合或表面出现非流形碎片；纹理流失败表现为视角间颜色不一致、接缝处出现明显色带、或反投影时被遮挡区域出现拉伸条纹。把两者分开，正是为了让这两类失败可以被独立定位和独立修复。

二 · 从输入到输出的数据流：每一步的形态变化

把整条管线摊开，输入到输出经历了一次明显的表示形态切换，理解这些切换点是理解架构的关键。下面按顺序列出每一步的数据形态与负责模块。

  • 输入层：文本提示、参考图像、手绘草图、分割掩码。它们先进入条件编码器，被映射为两组条件向量或条件特征图，分别对应几何与纹理。
  • 几何隐空间：条件 $c_{\mathrm{geo}}$ 进入几何 DiT，在 SDF 隐表示上迭代去噪，得到隐式几何场。
  • 网格解码：隐式场经等值面提取转为显式网格 $\mathcal{M}$，包含顶点、面片与法线。此时还没有任何颜色信息。
  • 多视图渲染：以 $\mathcal{M}$ 为几何代理，在预设相机位姿下渲染深度图与法线图，作为纹理扩散的空间引导。
  • 纹理扩散：纹理扩散以 $c_{\mathrm{tex}}$ 与上述引导为条件，逐视角生成 RGB 图像，视角之间通过共享的隐表示或交叉注意力保持一致性。
  • UV 反投影：多视图 RGB 连同深度被反投影到网格的 UV 参数化上，做可见性判断与加权融合，得到纹理图 $\mathcal{T}$。
  • 可微渲染监督：在训练阶段，渲染器把 $\mathcal{M}$ 与 $\mathcal{T}$ 一起渲染成图像，与真值视图比对，梯度回传到纹理分支乃至几何分支的条件编码器。

这条数据流里有两个容易被忽视的工程细节。其一是 UV 参数化的质量直接决定反投影的成败：如果网格的 UV 展开存在大量重叠或极端拉伸，反投影会在接缝处产生无法消除的伪影，而几何流并不对 UV 质量负责，所以 UV 展开通常是管线中一个独立的、非学习的后处理步骤。其二是多视图的相机位姿选择：位姿覆盖不足会在背面留下空洞，位姿过多则纹理扩散的推理时间线性增长。推理“数十秒”这个量级的开销，很大一部分就消耗在逐视角的扩散采样上，而不是几何 DiT 本身。

用一个具体场景串起来：输入是一段文本加一张正面照片。条件编码器把照片编码为几何侧的轮廓先验与纹理侧的外观先验；几何 DiT 生成与照片轮廓一致的 SDF，解码为网格；渲染器在若干方位角上渲染深度与法线；纹理扩散在这些引导下生成各视角图像，其中正面视角受照片先验约束最强，背面视角则更多依赖文本；反投影融合得到 UV 纹理；可微渲染输出最终带纹理资产。整个过程中，用户看到的是一次前向，但内部实际发生了“隐式场→显式网格→多视图图像→UV 纹理”三次表示转换，每一次转换都是一个潜在的误差放大点。

三 · 条件编码：三类控制信号如何进入两条流

Step1X-3D 的可控性来自条件编码模块，而它的设计难点在于：草图、分割、文本这三种信号的“刚性”差别很大，不能一视同仁地塞进同一个条件向量。草图与分割是空间对齐的，它们带有明确的二维位置信息，适合作为几何侧的控制；文本是语义的、无空间对齐的，更适合作为纹理侧与几何侧的粗粒度语义约束。因此条件编码的实际做法是按信号类型分流，而不是简单拼接。

具体机制可以这样理解：草图与分割掩码经过一个图像编码器，保留其空间分辨率，作为几何 DiT 的附加条件特征，在去噪的每一步通过交叉注意力注入；文本经过文本编码器得到 token 序列，同时注入几何流与纹理流，但在几何流中它更多影响整体比例与类别，在纹理流中它影响颜色、材质与局部语义。这种“同一文本、两处注入、不同权重”的安排，使得文本既能约束形状大类，又不会过度压制草图给出的具体轮廓。

条件强度的调节是可控性的实际抓手。工程上通常用一个条件缩放系数来控制注入特征的幅度，系数过大则生成结果僵硬、失去多样性，系数过小则条件被忽略、退化为无条件生成。这个系数的调参不是免费的：不同条件类型（草图 vs 分割 vs 纯文本）对应的合适系数区间不同，且与去噪步数耦合。这是“控制能力仍有限”这一局限的一个具体来源——模型提供了控制接口，但接口的灵敏度需要用户自己试探。

失败模式在这里很典型：当草图与文本冲突时（例如草图画的是四足动物，文本写的是“一只鸟”），几何流会在两者之间折中，产生既不像四足也不像鸟的混合体，而纹理流则倾向于服从文本，导致外观与形状不匹配。系统没有内建的冲突消解机制，冲突的代价由用户承担。另一个失败模式是分割掩码的粒度：掩码只标注了前景轮廓而没有部件分割时，几何流无法把“手臂”与“躯干”分开控制，局部编辑接口也就失去了作用对象。

一个具体例子：用户用分割掩码圈出“椅子座面”区域，希望只改这一部分的几何厚度。条件编码把掩码作为空间条件注入，几何 DiT 在对应区域加强条件权重，其余区域保持原样。这个流程能工作，前提是掩码与生成网格在空间上对齐——而由于几何流是从隐空间生成的，掩码的二维位置需要经过相机投影才能对应到三维区域，这个投影假设了固定的视角与尺度，视角一变，同一张掩码就指向了不同的三维部位。这是局部编辑接口在工程上必须固定视角约定的原因。

四 · 局部编辑接口：在已生成资产上做增量修改

局部编辑是 Step1X-3D 区别于纯生成模型的关键模块，它的设计思路不是“重新生成”，而是“在已有 $\mathcal{M}$ 与 $\mathcal{T}$ 上做条件化的局部重采样”。接口的输入包括：待编辑区域的空间定位（通过掩码或草图给出）、编辑指令（文本或参考图）、以及保留区域的约束。输出是修改后的网格与纹理，未编辑区域应尽量保持不变。

具体机制上，局部编辑复用了两条流的条件注入能力，但把去噪过程限制在局部。几何侧的做法是在 SDF 隐空间上只对掩码对应的隐变量子集做去噪更新，其余隐变量冻结为原资产的值；纹理侧的做法是在 UV 空间上只对受影响的面片重新做多视图扩散与反投影，其余 UV 区域直接沿用原纹理。这种“冻结加局部重采样”的策略使得编辑的推理开销远小于全量生成，但也带来一个硬约束：编辑区域与保留区域的边界必须平滑过渡，否则会出现几何裂缝或纹理接缝。

边界处理是局部编辑最主要的失败模式。几何侧，冻结区域与重采样区域在 SDF 隐空间上的拼接不保证零水平集连续，解码后可能在边界处出现台阶或孔洞；纹理侧，重采样区域的反投影颜色与保留区域的颜色分布不一致，接缝处出现可见色差。工程上的缓解手段是在边界带做加权混合，但加权带宽本身是个超参，带宽太窄接缝仍在，带宽太宽则编辑效果被稀释。

另一个失败模式是编辑的语义传播。用户希望“把这件衣服改成皮衣”，指令落在纹理侧，但皮衣的质感往往伴随几何上的厚度与褶皱变化。由于几何与纹理分开生成，纹理编辑不会自动触发几何重采样，结果是外观变了、形状没变，皮衣贴在原本的布料褶皱上，真实感下降。这正是“几何与纹理分离”这一核心思想的代价：分离带来了可控性与可定位性，却切断了外观与形状之间的耦合。要弥补这一点，需要用户在编辑时同时给出几何侧的指令，或者由上层系统做指令分解——而论文的接口并未内建这种分解。

一个具体例子：用户对已生成的角色资产做“把左手换成机械手”的编辑。掩码定位左手区域，文本给出“金属机械结构”。几何流在左手区域重采样 SDF，得到机械手的形状；纹理流在对应 UV 区域重新扩散，生成金属材质。保留区域（躯干、右臂）冻结。若掩码边界恰好落在手腕处，而机械手的几何在边界处比原手腕更粗，接缝处就会出现几何不连续，反投影后的纹理也会在接缝处出现拉伸。这个例子说明局部编辑的可用性高度依赖掩码质量与边界处理，而不是单纯依赖模型能力。

五 · 可微渲染监督：训练信号如何跨流回传

几何与纹理分开训练，但两者并非完全独立——可微渲染是连接它们的监督通道。训练时，渲染器把 $\mathcal{M}$ 与 $\mathcal{T}$ 一起渲染成二维图像，与真值视图比对得到光度损失，梯度沿渲染路径回传。对纹理分支，梯度直接更新纹理扩散的参数；对几何分支，梯度通过渲染对网格的依赖回传到 SDF 隐表示，进而影响几何 DiT。

这条监督通道的价值在于它提供了二维观测到三维表示的桥梁。纯三维监督（如 SDF 真值、网格真值）获取成本高，而二维图像监督可以从大规模图像数据中获得。可微渲染把“渲染出来像不像”变成可优化的目标，使得几何与纹理都能从二维信号中学习。公式上，光度损失可以写成渲染图像与真值图像的逐像素差异：

$$\mathcal{L}_{\mathrm{photo}}=\big\|\mathrm{Render}(\mathcal{M},\mathcal{T};\pi)-I^{\star}\big\|^{2}$$

其中 $\pi$ 是相机参数。这个损失对纹理分支是直接的，对几何分支则要穿过等值面提取这一离散操作——而等值面提取本身不可微。工程上的处理通常是在 SDF 隐表示上做可微的体渲染或软等值面近似，把梯度绕过离散提取步骤。这是一个典型的系统代价：为了让梯度回传，训练时的渲染路径与推理时的网格解码路径并不完全一致，训练与推理之间存在表示鸿沟，鸿沟越大，训练损失下降与推理质量之间的相关性越弱。

失败模式在这里表现为“渲染好看但网格难看”。由于监督信号来自二维渲染，模型可能学会生成在特定视角下渲染正确、但三维结构本身有缺陷的几何——例如面向相机的薄片结构在渲染中看不出问题，换一个视角就暴露出非流形或自交。这是二维监督的固有盲区，也是为什么几何流仍需 SDF 真值或三维正则项来约束。另一个失败模式是纹理分支的“视角过拟合”：多视图扩散在训练视角上表现良好，但在训练未覆盖的视角上出现颜色漂移，反投影到 UV 后表现为某些 UV 岛的颜色与相邻岛不一致。

一个具体例子：训练数据中某类资产的真值视图只覆盖了正面与侧面，可微渲染监督在这两个视角上施加约束，几何与纹理都在这两个视角上收敛良好。推理时用户要求背面视角的渲染，几何流生成的背面结构缺乏监督、纹理流生成的背面颜色缺乏约束，输出资产的背面质量明显低于正面。这不是模型容量问题，而是监督覆盖问题——可微渲染只能监督它看得见的视角。

六 · 模块分工的工程判断：分离的收益与代价落在哪里

把架构、数据流、条件编码、局部编辑、可微渲染监督放在一起看，Step1X-3D 的模块分工可以用一张表概括其输入、输出与主要失败模式。这张表的目的不是罗列，而是让每个模块的责任边界清晰，便于在工程部署时定位问题。

从这张表能读出一个工程判断：分离架构把失败模式也分离了。几何问题在几何流内定位，纹理问题在纹理流内定位，局部编辑问题在编辑接口内定位，三者不会互相掩盖。这是分离相对一体化生成的实际收益——一体化模型出现“形状对但纹理错”时，很难判断是隐空间耦合导致还是解码导致，而分离架构下这类判断是直接的。代价则落在耦合点上：几何与纹理之间的语义耦合被切断，外观变化不自动带动形状变化；条件冲突没有内建消解；可微渲染的训练路径与推理路径存在表示鸿沟。

这些代价与论文自述的局限是一致的：控制能力仍有限，因为条件接口的灵敏度需要用户试探、冲突需要用户消解；纹理真实感受数据限制，因为纹理扩散的监督来自有限视角的二维图像；推理慢，因为多视图扩散要逐视角采样，而局部编辑虽然冻结了大部分区域，边界处理仍需额外的重采样与融合。把“数十秒”的推理开销拆开看，几何 DiT 的去噪步数与纹理扩散的视角数是最主要的两个乘数，减少任一乘数都会直接牺牲保真度或视角覆盖。

最终落到一个具体机制上：Step1X-3D 的模块分工之所以能成立，靠的是把“几何”压缩成一个显式网格这一单一耦合点。网格既是几何流的输出，又是纹理流的输入，还是局部编辑的作用对象，也是可微渲染的载体。所有跨模块的误差都必须经过这个耦合点，因此网格的质量——包括拓扑、UV、法线——实际上决定了整条管线的上限。工程部署时，若发现纹理接缝严重或局部编辑边界破裂，第一检查点不应是纹理扩散的参数，而应是网格解码与 UV 展开的质量；这是分离架构给出的可操作的排查顺序。
