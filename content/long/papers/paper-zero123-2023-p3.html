一 · 目标函数：从噪声预测到位姿条件化的去噪回归

Zero-1-to-3 的训练目标在形式上沿用 Stable Diffusion 的潜空间去噪回归，但把条件集合从纯文本扩展为「参考图 + 相对位姿」。给定同一物体的参考视角 x 与目标视角 x'，模型学习的不是一个确定映射，而是目标视角图像在潜空间中受噪声污染后的噪声分量。记 VAE 编码器为 E，目标图像潜变量 z' = E(x')，采样噪声 ε ~ N(0, I)，时间步 t，则训练样本为 z'_t = √ᾱ_t · z' + √(1 − ᾱ_t) · ε。去噪网络 ε_θ 的输入包含三项：被污染的潜变量 z'_t、时间步嵌入、以及条件 c = (c_img, c_pose)。损失是标准的噪声均方误差：

$$L(\theta)=\mathbb{E}_{z',\varepsilon,t}\left[\left\|\varepsilon-\varepsilon_\theta\!\left(z'_t,\,t,\,c_{\text{img}},\,c_{\text{pose}}\right)\right\|_2^2\right]$$

这里的关键工程判断是：条件不是拼在输入通道上，而是通过 cross-attention 注入。参考图的 CLIP 图像嵌入与位姿嵌入被拼接成条件序列，作为 U-Net 各层 cross-attention 的 key/value；被污染的潜变量作为 query。这样做的直接后果是，位姿信息必须在每一层都参与注意力竞争，而不是像 AdaIN 那样只做全局调制。代价是 cross-attention 的 key/value 序列长度增加，显存与注意力计算量随条件 token 数线性上升；当参考图被切成多个 patch token 时，这一开销在训练中不可忽略。

变量含义需要逐一钉死，否则复现时极易错位。x 是参考视角 RGB 图，x' 是目标视角 RGB 图；ΔR 是相对旋转，ΔT 是相对平移，二者定义在相机坐标系下，而非世界坐标系。论文给出的定义是 ΔR = R'R⁻¹、ΔT = T' − T，即把目标相机变换到参考相机坐标系中的相对量。这个定义决定了位姿嵌入的数值范围：旋转矩阵元素落在 [−1, 1]，平移量取决于数据集归一化尺度，二者量纲不同，必须分别嵌入再拼接，不能直接拼接原始数值送进 MLP。一个常见失败模式是把 ΔT 当成世界坐标平移直接输入，导致模型在训练集上尚可、在推理时对平移方向系统性偏移。

具体例子：设参考相机 R 为单位阵、T = (0, 0, 2)，目标相机绕 Y 轴旋转 30°、T' = (0.5, 0, 2)。则 ΔR 是绕 Y 轴 30° 的旋转矩阵，ΔT = (0.5, 0, 0)。模型看到的条件就是「绕竖直轴转 30°、向右平移 0.5」；若把 ΔT 误写成 T'，条件就变成绝对位置，训练分布与推理分布错位。

二 · 位姿嵌入与注入路径：从矩阵到 token

位姿条件的工程实现分三步：降维、嵌入、注入。第一步把 3×3 旋转与 3 维平移展平为 12 维向量（或 9+3 分开处理），第二步用一个小型 MLP 映射到与 CLIP token 同维的嵌入空间，第三步把该嵌入作为一个额外 token 追加到条件序列尾部。伪代码思路如下：

  • 输入：ΔR (3×3)、ΔT (3)，参考图 x
  • e_img ← CLIPImageEncoder(x)　// 形状 [N_tok, D]
  • v_pose ← flatten(ΔR) ⊕ ΔT　// 12 维
  • e_pose ← MLP(v_pose)　// 形状 [1, D]
  • c ← concat(e_img, e_pose)　// 形状 [N_tok+1, D]
  • 对每个 U-Net cross-attention 层：Attention(Q=z'_t, K=c, V=c)

这条路径的系统代价在于：位姿 token 只有 1 个，而图像 token 有几十个，注意力 softmax 会被图像 token 主导，位姿信号在数值上被稀释。论文的应对是让位姿嵌入参与所有层、并在训练中同时优化位姿 MLP 与 cross-attention 的 key/value 投影，使位姿 token 的梯度不被图像分支淹没。失败模式是只训练位姿 MLP 而冻结 cross-attention 投影：此时 key/value 空间没有为位姿 token 留出区分度，模型倾向于忽略位姿条件，生成结果对 ΔR 不敏感，表现为「换视角但姿态不变」。

另一个机制细节是参考图的双重编码。Stable Diffusion 本身有 VAE 与 CLIP 两条通路，Zero-1-to-3 把参考图同时送入 CLIP 图像编码器作为条件 token，而目标图只走 VAE 潜空间。这意味着参考图的像素级细节通过 CLIP 语义嵌入间接传递，而非逐像素对齐。具体例子：参考图是一只左前方视角的椅子，CLIP 嵌入保留「椅子、木质、四腿」的语义，但椅背的具体纹理走向不会精确进入条件序列；目标视角的纹理一致性因此依赖 U-Net 在训练中见过的多视图统计，而不是显式的像素对应。这正是后续一致性问题的根源之一。

三 · 训练配方：冻结、微调与数据规模

训练配方遵循「冻结大部分、只训条件通路」的原则。Stable Diffusion 的 VAE 与文本编码器保持冻结，U-Net 的主体卷积与自注意力层也冻结，可训练参数集中在两部分：位姿嵌入 MLP，以及 U-Net 中 cross-attention 的 key/value 线性投影。这样做的工程理由是显存与稳定性：全量微调 2D 扩散模型在单图多视图数据上极易过拟合到训练物体的纹理，而冻结主体保留了预训练模型的图像先验，使零样本泛化成为可能。

训练数据是 Objaverse 渲染的多视图对。每个物体渲染多个视角，任意两视角构成一个训练样本：一为参考、一为目标，相对位姿由渲染时的相机参数算出。数据规模直接决定位姿条件的覆盖度：视角方位角与仰角的分布若集中在少数几个角度，模型对连续位姿的插值能力就弱。消融实验关注的三项——位姿条件、训练数据规模、分辨率——正好对应三个失效维度：去掉位姿条件则退化为无条件新视角幻想；缩小数据规模则位姿泛化变差；降低分辨率则细节与几何精度同时下降。

训练时长以「数天」量级计，具体取决于 GPU 数量与渲染数据吞吐。这里的系统瓶颈往往不在梯度计算，而在数据加载：多视图渲染图需要在线解码、VAE 编码、CLIP 编码，若不做缓存，I/O 与编码开销会压过前向反向。一个具体失败模式是缓存了 VAE 潜变量却未缓存 CLIP 嵌入，导致每个 batch 重复跑 CLIP 前向，训练吞吐被编码器拖慢。工程上的判断是：参考图的 CLIP 嵌入与目标图的 VAE 潜变量都应预计算并落盘，训练循环只做采样与去噪。

组件状态原因
VAE 编码器/解码器冻结保留潜空间统计，避免重建漂移
文本编码器冻结本任务条件不含文本，无需更新

四 · 采样：从噪声到目标视角，以及多视角重建

推理时给定参考图 x 与目标位姿 (ΔR, ΔT)，从纯噪声 z'_T 开始迭代去噪。每一步的模型输出是噪声估计，按 DDIM 或祖传采样器更新潜变量，条件 c 在整个采样过程中固定不变。采样步数是精度与成本的直接权衡：步数少则几何结构粗糙、背面细节缺失；步数多则单视角生成时间线性增长。由于每个目标视角都要独立跑一遍完整采样，生成 K 个视角的总代价约是单视角的 K 倍，这是逐视角独立生成范式的固有成本。

伪代码层面的采样循环：

  • c ← encode(x, ΔR, ΔT)　// 一次编码，多视角复用
  • z ← N(0, I)
  • for t = T … 1：ε ← ε_θ(z, t, c)；z ← sampler_step(z, ε, t)
  • x' ← D(z)　// VAE 解码

多视角重建的用法是：对同一参考图采样若干目标视角，把生成的 RGB 图连同已知相机位姿送入 NeRF 或高斯泼溅类重建器，拟合一个可渲染的 3D 表示。这里的失败模式是视角间不一致：每个视角独立采样，噪声种子不同，生成的纹理与几何在重叠区域对不上，重建器被迫在冲突观测之间折中，产生模糊或重影。具体例子：采样正面与背面两个视角，背面由模型幻想生成，若幻想出的椅背结构与正面视角的轮廓不吻合，重建出的网格在侧向渲染时出现双层边缘。这一代价不是采样器能消除的，而是目标函数逐视角独立的直接后果。

五 · 数值玩具例子：一次前向的维度与量级

为把上述机制落到可核对的数值上，构造一个最小例子（数值为示意，非实验测量）。设潜空间分辨率 32×32、潜通道 4，则 z'_t 形状为 [4, 32, 32]。CLIP 图像编码器输出 8 个 token、维度 64，位姿嵌入 1 个 token、维度 64，条件序列 c 形状为 [9, 64]。U-Net 某一层 cross-attention 的 query 投影把 z'_t 展平为 1024 个位置、每位置 64 维，则注意力矩阵形状为 [1024, 9]。

噪声调度取 ᾱ_t 在 t = 500 时为 0.5（示意值），则 z'_t = 0.707 · z' + 0.707 · ε。若 z' 某元素为 1.0、ε 同位置为 −1.0，则 z'_t 该元素为 0；模型要预测的噪声真值是 −1.0，损失项为 (ε_θ − (−1.0))²。若模型输出 0（即完全忽略噪声），单元素损失为 1.0；若输出 −0.8，损失为 0.04。这个量级说明：损失对噪声估计的偏差是二次敏感的，训练早期模型倾向输出接近 0 的均值预测，损失下降主要来自学会「有噪声」而非「噪声方向」。

位姿条件的数值检查：ΔR 绕 Y 轴 30°，展平后含 cos30° ≈ 0.866、sin30° = 0.5、−0.5 等元素；ΔT = (0.5, 0, 0)。12 维向量经 MLP 映射到 64 维，若 MLP 第一层权重未归一化，输入量级 0.5 与 0.866 混合后输出可能落在 [−3, 3]，与 CLIP 嵌入的量级（通常经 LayerNorm 后接近单位方差）不匹配，导致位姿 token 在注意力中要么过强要么过弱。工程判断是：位姿 MLP 输出后接 LayerNorm，使其与图像 token 同量级，这是让位姿信号不被稀释的必要条件。

采样成本估算：单视角 50 步、每步一次 U-Net 前向，若单次前向在某一 GPU 上耗时 τ，则单视角约 50τ；采样 8 个视角约 400τ，再加 8 次 VAE 解码。参考图的 CLIP 与位姿编码只做一次，可忽略。这说明多视角重建的瓶颈在逐视角去噪，而非条件编码——也正是后续工作转向「多视角联合去噪」以摊薄成本的动机所在。

六 · 超参敏感性与失效边界

关键超参中，位姿嵌入维度与 cross-attention 学习率最敏感。嵌入维度过低，旋转与平移的细微差异被压平，模型对小于某阈值的视角变化不响应，表现为连续视角插值时的「跳变」；维度过高而训练数据不足，位姿 token 过拟合到训练物体的特定角度分布，零样本推理时对未见方位角生成崩溃。学习率方面，cross-attention 投影的学习率若与位姿 MLP 相同，前者参数量大、梯度噪声大，容易在早期破坏预训练的注意力结构；常见做法是给 cross-attention 更小的学习率或分层衰减。

分辨率超参直接绑定几何精度。训练分辨率低时，模型学到的多视图统计偏粗，生成的目标视角在轮廓上正确、在细节上模糊；提高分辨率需要重训位姿嵌入与 cross-attention，因为 token 数量随分辨率变化，注意力矩阵形状改变。失败模式是「分辨率不匹配推理」：用低分辨率训练的模型在高分辨率潜空间上采样，U-Net 的位置编码与注意力感受野错位，生成图出现重复纹理或结构断裂。

训练数据规模与位姿覆盖度的关系是定性的：Objaverse 多视图提供的是物体级多样性，而非视角级均匀覆盖。若某类物体的渲染视角集中在正面与侧面，模型对背面位姿的条件响应就弱，推理时背面生成更依赖幻想而非条件约束。这与论文自述的「背面靠幻想」局限一致：不是采样器的问题，而是训练分布中背面视角的条件监督不足，模型学到的是「背面大致长什么样」的先验，而非「给定这个位姿该长什么样」的映射。工程上的判断是：位姿条件的有效性上限由训练数据的视角覆盖决定，扩大数据规模而不改善视角分布，收益递减。
