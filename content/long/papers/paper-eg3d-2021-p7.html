一 · 对比坐标：把“表示—监督—算力”拆成可比的轴

把 EG3D 与同期方法放在一张表里比较，最容易犯的错误是只比 FID。FID 是渲染结果的 2D 分布距离，它不告诉你这个 3D 场是否视角一致、是否能在任意相机下稳定渲染、显存峰值落在哪一层。真正决定一个方法能不能落地的，是三条互相牵制的轴：表示（3D 场如何参数化）、监督（梯度从哪个域回传）、算力（显存与渲染时间随分辨率如何增长）。EG3D 的每一个设计选择都可以在这三条轴上定位，而它的竞争者恰恰是在这三条轴上做了不同的取舍。

表示轴上，EG3D 把 3D 场写成三个正交 2D 特征平面加一个小 MLP：

$$G(\mathbf{z})=\mathrm{TriPlane}_\theta(\mathbf{z}),\qquad F(\mathbf{x})=\mathrm{MLP}\!\left(\mathrm{interp}(T_{xy},\mathbf{x}),\mathrm{interp}(T_{xz},\mathbf{x}),\mathrm{interp}(T_{yz},\mathbf{x})\right)$$

这里的 interp 是双线性插值，三平面各为 256×256×32。关键点在于：生成高频细节的卷积全部发生在 2D 平面上，3D 查询只做插值与一个 2 层 MLP 解码。这与体素表示形成鲜明对照——体素的显存随分辨率立方增长，256³ 的密度网格已经吃掉大量显存，再往上加分辨率直接撞墙；而三平面的存储是 3×256×256×32，与 3D 分辨率解耦。与纯隐式 MLP 对照则相反：纯 MLP 没有 2D 卷积的归纳偏置，生成器很难高效产出高频细节，训练慢且分辨率上不去。EG3D 的取舍是把计算负担从体素/大 MLP 转移到 2D 卷积，代价是固定拓扑与有限的几何精度。

监督轴上，EG3D 只用 2D 判别器，配合相机分布采样与姿态条件。这意味着梯度只从渲染出的 2D 图像回传，3D 一致性不是靠 3D 真值或 3D 判别器强加的，而是靠三平面共享（同一个点在三张平面上被一致地查询）与 2D 判别器在多视角下的统计约束共同“逼”出来的。这是一个弱监督选择：它让训练可以吃进只有单视角图像的数据集（FFHQ、AFHQ、CompCars），但也意味着几何正确性没有任何显式保证。对比之下，GIRAFFE 走的是另一条路——把场景分解成背景与若干可控的物体辐射场，用组合式场景图做监督，可控性强但表示能力受限于分解假设；pi-GAN 用 SIREN 式周期激活的隐式场配合 FiLM 条件，追求的是连续表示的表达能力，代价是渲染时每条射线要跑大量 MLP 查询；StyleNeRF 则把 NeRF 式的体积渲染与 2D 上采样结合，用 2D 卷积补高频，思路上与 EG3D 最接近，但它的 3D 表示仍是隐式场而非三平面，且渲染路径里保留了较重的逐点查询。

算力轴上，EG3D 的渲染成本由“每条射线采样点数 × 每点三次插值 + 一个小 MLP 前向”构成，与平面分辨率相关而与 3D 网格分辨率无关。这带来一个具体的系统代价：三平面在 256×256 上的双线性插值对缓存不友好，逐点查询时三张平面各自要取四个邻域值，采样点一多，内存带宽就成为瓶颈，而不是 FLOPs。工程上这表现为渲染阶段的吞吐受限于访存而非算力，批处理射线时若采样点排布不连续，缓存命中率下降会直接拖慢出图。这是三平面表示固有的失败模式之一，也是后续前馈重建模型继承 triplane 时必须面对的同一个问题。

一个具体例子能说明这种差异的工程含义。在 ShapeNet 上生成视角一致的汽车与椅子时，EG3D 的固定拓扑问题会显形：三平面是在规范空间里生成的，物体的大致朝向与部件布局被训练分布锁定，生成一辆车可以，但要让这辆车以训练中未出现的极端视角呈现且保持部件不穿插，几何精度就不够用了。这不是渲染 bug，而是表示的容量上限——三平面共享让同一个 3D 点在三张平面上被一致查询，保证了视角一致性，但也意味着平面之间没有显式的几何约束，薄壁、镂空、细长部件这类需要高精度几何的结构容易被“糊”成连续体。对比 GIRAFFE，后者在物体级分解下能更好地保持部件独立，但代价是它难以生成 EG3D 那种照片级的高频纹理。

三 · 消融给出的因果链：三平面、判别器域、姿态条件

EG3D 的消融不是调参记录，而是三条因果链的证据。第一条是三平面 vs 单平面/体素：把表示换成单平面，3D 点的查询退化成从一个平面插值，表达能力骤降，多视角一致性失去结构支撑；换成体素，显存随分辨率立方增长，高分辨率渲染直接不可行。这条消融说明三平面的“三”不是装饰，正交三方向各自承载一个投影面的特征，拼接后小 MLP 才能解码出视角相关的颜色与密度。第二条是 2D 判别器 vs 3D 判别器：3D 判别器需要 3D 真值或至少可微的 3D 监督，而 EG3D 的目标数据集只有单视角图像；用 2D 判别器配合相机分布采样，梯度从多个随机视角的渲染图回传，等价于用 2D 统计间接约束 3D 场。这条消融的代价是几何正确性没有显式保证，收益是训练可以规模化到真实图像数据集。第三条是姿态条件的影响：把相机姿态作为条件输入生成器与判别器，让模型知道当前渲染的是哪个视角，从而在多视角间建立对应；去掉姿态条件，视角一致性明显退化，因为模型无法区分“这是同一个物体的不同视角”还是“这是不同的物体”。

这三条因果链可以写成一段伪代码式的训练回路，帮助理解梯度从哪里来：

  • 采样隐变量 z 与相机姿态 c（来自相机分布）；
  • 生成器产出三平面 T，按 c 发射射线，逐点三插值拼接后经 MLP 解码密度与 RGB；
  • 体渲染得到 2D 图像，与真实图像一起送 2D 判别器；
  • 对抗损失回传，同时施加 R1 正则与路径长度正则；
  • 关键点：梯度不经过任何 3D 真值，全部从 2D 判别器的视角统计回传，三平面共享是唯一的 3D 结构约束。

这条回路的系统代价在于：2D 判别器看到的只是投影，它无法区分“几何正确但纹理错误”与“纹理正确但几何错误”在投影上的等价表现，于是模型可能学到一个在训练视角分布内投影正确、但 3D 结构经不起推敲的场。这就是“依赖 2D 判别器”这一局限的机制根源，也是为什么 EG3D 在训练分布内的视角上表现稳定，而在分布外视角上几何精度有限。一个具体失败模式是：在 FFHQ 上训练的人脸，转到接近侧面的极端视角时，耳部与下颌的几何容易塌陷，因为训练相机分布里这类视角的样本稀疏，2D 判别器没有足够的统计压力去约束该区域的 3D 结构。

这张表还有一列隐含信息：EG3D 在“作为前馈重建的中间表示”一行是唯一适用的，这不是因为它生成质量最高，而是因为三平面是一种显式的、可被下游网络直接预测的张量结构。LRM、TripoSR 等前馈重建模型直接继承 triplane，只是把生成器换成图像条件 Transformer——它们不需要 GAN 的对抗训练，只需要一个能把输入图像映射到三平面的编码器，再复用 EG3D 的插值加小 MLP 解码与体渲染路径。这说明三平面的价值不止在生成，更在它把“3D 场”变成了一个固定形状、可批量预测、可微渲染的中间表示。继承的代价同样明确：固定拓扑与有限几何精度这两个局限被原样继承，前馈模型在薄壁与镂空结构上同样受制于三平面的表达能力，而不是换一个更强的编码器就能解决。

五 · 失败模式的对照与工程判断

把失败模式逐项对照，能看出各方法的失效点其实对应各自的核心假设。EG3D 的失效点是固定拓扑与几何精度有限：三平面在规范空间生成，物体的部件布局被训练分布锁定，分布外视角与高精度结构上塌陷；根因是 2D 判别器只约束投影统计，三平面共享只保证一致性不保证正确性。StyleNeRF 的失效点是上采样伪影与视角漂移：2D 上采样补高频的同时可能引入与 3D 结构不一致的细节，多视角下这些细节不跟随视角变化，表现为漂移；根因是 2D 与 3D 两条路径的耦合不够紧。pi-GAN 的失效点是渲染慢与高频细节不足：SIREN 场的逐点查询成本高，且周期激活对高频的拟合需要更宽的 MLP；根因是表达能力与渲染效率的权衡偏向表达。GIRAFFE 的失效点是分解假设不成立时穿帮：物体与背景的边界、遮挡关系在复杂场景下难以用固定分解描述；根因是结构先验的刚性。

这些失败模式对工程复现的意义在于：验收断言必须针对具体失效点写，而不是只写“FID 低于某阈值”。对 EG3D 的复现，至少要有三类断言：其一，多视角一致性断言——同一隐变量在相机分布内采样多个姿态渲染，投影到同一 3D 点上的颜色与密度应一致，这是三平面共享的直接检验；其二，分布外视角的几何稳定性断言——在训练相机分布边缘之外的视角渲染，检查是否出现部件穿插或塌陷，这是固定拓扑局限的暴露点；其三，渲染吞吐断言——在目标分辨率下测每帧时间与显存峰值，确认瓶颈在访存而非算力，若吞吐不达标，优先检查射线采样点的排布与批处理方式，而不是加宽 MLP。

最后一个工程判断落在表示的选择上：如果你的下游任务是前馈重建而非无条件生成，三平面是当前最成熟的中间表示，因为它固定形状、可微渲染、可被 Transformer 批量预测，EG3D 的生成器可以被整体替换而不动解码与渲染路径；但你必须接受它继承的几何精度上限，并在验收里把薄壁与镂空结构单列为已知失败模式，而不是当作待调参解决的 bug。如果你的任务是物体级可控生成，三平面不是正确起点，GIRAFFE 式的分解表示在结构上更匹配，代价是放弃高频纹理与复杂场景鲁棒性。这两种判断的分界线不是方法的新旧，而是你的硬约束落在表示轴的哪一端——需要固定形状的可微中间表示，还是需要显式的结构分解。
