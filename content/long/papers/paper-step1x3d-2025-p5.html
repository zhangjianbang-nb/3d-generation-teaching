一 · 失效条件：几何与纹理分离在哪些输入上先崩

Step1X-3D 的核心赌注是几何与纹理解耦：几何由 3D 原生扩散在 SDF/网格空间求解，纹理由多视图扩散加 UV 反投影生成。这个分解在“几何语义清晰、纹理可由多视图一致观测”的资产上成立，但它的失效边界同样由这个假设划定。第一类失效是几何条件本身欠定：当用户给出的草图只有单一视角、分割掩码只覆盖可见面时，几何 DiT 的 c_geo 无法约束背面与凹腔结构，模型只能按训练分布“补全”一个合理但未必正确的背面。此时几何看似高保真，实际是把先验当成了证据。第二类失效是纹理与几何的耦合断裂：多视图扩散在渲染视图上采样颜色，再经 UV 反投影聚合，若网格存在薄壁、自遮挡或高曲率褶皱，反投影会在 UV 缝处产生可见接缝与拉伸，纹理真实感受数据限制的表现就在这里——训练数据中同类材质的覆盖不足时，模型倾向于输出平滑、塑料感的 albedo，而不是正确的粗糙度与微观法线变化。

第三类失效是局部编辑接口的语义半径。局部编辑依赖对网格区域的选择与条件重采样，但几何 DiT 的潜变量是全局耦合的：改动一个区域的 SDF 会通过扩散去噪的全局注意力影响邻近区域，编辑边界因此不是硬约束。工程上表现为“改了把手，底座轻微变形”。第四类失效是尺度与拓扑：SDF 解码在封闭流形上稳定，对薄片、开放边界、非流形扫描件则会出现厚度塌陷或孔洞。这些不是调参能解决的问题，而是表示与训练分布的共同边界。

$$\text{edit}(x)=\arg\max_{x'}\ p(x'\mid c)\,\cdot\,\mathbb{1}\big[\mathrm{IoU}(\Omega(x'),\Omega_{\text{keep}})\ge\tau\big]$$

上式是局部编辑的理想约束：在保持未编辑区域 Ω_keep 的前提下最大化条件似然。实际系统中 τ 无法硬保证，因为扩散采样没有投影步，只能在采样后做一次区域回贴。代价是每次编辑都要重新跑完整去噪链，推理数十秒的量级在交互式编辑里被放大为“每次改动等一轮”。一个具体例子：给一只带纹理的马克杯换杯身图案，若图案跨过 UV 缝，反投影聚合会在缝两侧取到不同视图的颜色，接缝在可微渲染监督下也不会被惩罚，因为监督只对齐渲染图与真值图，不对齐 UV 连续性。

二 · 系统代价：慢从哪里来，控制能力的天花板在哪

推理数十秒的代价可拆成三段：几何 DiT 的去噪步数、SDF/网格解码的等值面提取、纹理多视图扩散的视图数与 UV 聚合。几何阶段每步都要在 3D 潜空间做全局注意力，步数与分辨率共同决定耗时；解码阶段 marching cubes 类的等值面提取在细分辨率下是内存与时间的双重开销；纹理阶段要对每个采样视图跑扩散再反投影，视图数增加线性推高成本，而视图太少又会让反投影出现空洞。这三段是串行的，没有跨阶段并行，因此端到端延迟近似为三段之和，而不是取最大值。

阶段主要开销来源失败模式工程对策
几何 DiT去噪步数 × 3D 注意力背面先验补全、薄壁塌陷多视角草图条件、步数蒸馏
SDF/网格解码等值面提取分辨率非流形、开放边界孔洞拓扑预检、分块解码
纹理扩散视图数 × 每视图扩散UV 缝接缝、材质塑料感缝感知反投影、材质数据增补
局部编辑整链重采样编辑边界外溢区域回贴、潜变量局部冻结

控制能力的天花板不在接口数量，而在条件编码的信息带宽。文本条件只能指定类别级属性，草图条件只能约束投影轮廓，分割条件只能约束可见区域的部件归属；三者都无法直接指定“这个凹槽深 3 毫米”这类度量级几何。模型能做的可控是选择式的：在训练分布内挑一个满足条件的样本，而不是求解一个约束优化问题。这就是“控制能力仍有限”的机制根源——条件是被编码进扩散的引导信号，不是被求解的硬约束。系统代价因此是双重的：时间上慢，语义上只能软约束。工程判断是，把 Step1X-3D 放在“候选生成 + 人工筛选”的管线里是合适的，放在“按图纸精确建模”的管线里则不成立。

三 · 被谁继承：条件控制作为 2025 年 3D 生成的方向

Step1X-3D 的可继承部分不是某个模块，而是管线切分方式：几何与纹理分开训练、条件编码统一进扩散、局部编辑作为独立接口、可微渲染作为监督闭环。这四件事让“可控生成”从口号变成可复现的工程结构。后续工作继承它的路径有两条。第一条是条件侧的扩展：把草图、分割、文本之外的条件（深度、法线、部件标签、材质先验）编码进同一条件空间，几何 DiT 与纹理扩散共享条件编码器，从而让几何条件与纹理条件对齐。第二条是编辑侧的深化：把局部编辑从“重采样 + 回贴”推进到潜变量局部冻结或区域约束采样，减少编辑外溢。

与 Hunyuan3D 2.x 的关系是互补而非替代：后者在质量与规模化上更强，Step1X-3D 在条件接口与编辑可用性上更明确，形成“质量 vs 控制”的分工。这个分工的工程含义是，选型不应按单一指标排序，而应按管线需求排序——需要批量出高保真资产时选质量侧，需要按条件迭代修改时选控制侧。被替代的部分则是那些把可控性当作后处理补丁的做法：在生成后做网格布尔或纹理重投影，无法处理条件与几何的联合约束，Step1X-3D 把条件放进生成过程本身，这类后处理路线在可控场景里被边缘化。

$$c=\mathrm{Enc}_{\text{shared}}(c_{\text{geo}},c_{\text{tex}}),\qquad \mathcal{L}=\mathcal{L}_{\text{geo}}+\mathcal{L}_{\text{tex}}+\lambda\mathcal{L}_{\text{render}}$$

共享条件编码器加可微渲染监督是继承的核心配方。它的代价是训练时必须保证几何监督与纹理监督的梯度不互相干扰：几何分支的 SDF 监督与纹理分支的渲染监督若共享编码器，编码器会被两个目标拉扯，表现为几何条件响应变钝或纹理条件响应过强。一个具体例子：分割条件在几何侧要求部件边界锐利，在纹理侧要求材质边界与部件边界对齐，共享编码器若只优化渲染损失，几何边界会因渲染对边界的宽容而模糊。复现时必须分开条件通路的梯度尺度，或给几何条件单独加辅助损失。

四 · 工程复现清单：从数据到接口的最小可验证集

复现 Step1X-3D 的最小集不是“跑通训练脚本”，而是把四个可验证环节拆开。数据侧：Objaverse 提供几何与纹理的通用分布，内部可控数据提供条件对齐样本；复现时必须确认条件数据与几何数据的配比，否则条件编码器学不到稳定的条件到几何映射。训练侧：几何与纹理分开训练意味着两条独立的课程，几何先收敛再冻结或半冻结进入纹理训练，纹理训练依赖几何输出的网格质量，网格有孔洞时纹理反投影会出现空洞，因此几何阶段要加拓扑预检。监督侧：可微渲染把渲染图与真值图对齐，但渲染器对 UV 缝不敏感，复现时要额外加缝连续性检查。接口侧：局部编辑要定义选择粒度（面级还是区域级）、回贴策略与边界容差，否则编辑结果不可复现。

  • 几何条件通路：草图/分割/文本三路编码，检查每路单独生效时的条件响应，避免多路条件互相淹没。
  • 纹理条件通路：多视图扩散的视图采样策略与反投影聚合权重，检查 UV 缝处的颜色一致性。
  • 局部编辑：区域选择、潜变量冻结范围、回贴掩码，检查编辑外溢的 IoU 边界。
  • 可微渲染：渲染分辨率、材质模型（albedo/roughness/normal）、缝感知损失项。

失败模式清单同样要写进复现文档：薄壁塌陷、背面先验补全、UV 缝接缝、材质塑料感、编辑外溢、非流形输入孔洞。每一项都要有对应的验收断言，而不是靠肉眼判断。代价是复现周期被拉长，因为每个断言都要构造针对性样本；收益是可控性从“感觉能用”变成“可回归测试”。一个具体例子：构造一只薄壁花瓶，几何阶段若输出厚度低于阈值即判定失败，而不是等到纹理阶段发现内壁颜色穿透。

五 · 验收断言：把“可控”写成可执行的检查

验收断言要覆盖三个层面：条件遵从、几何有效性、纹理一致性。条件遵从的断言是“给定条件 c，生成结果在条件指定的属性上与 c 一致”，例如草图轮廓的投影 IoU、分割部件的归属准确率、文本类别的分类器置信度。几何有效性的断言是流形性、厚度下限、孔洞数量、自交检测。纹理一致性的断言是多视图渲染的颜色方差、UV 缝两侧的颜色差、材质参数在同类区域内的方差。这些断言不追求绝对阈值，而是追求回归稳定性：同一输入两次生成的结果在断言上的差异要小于容差。

断言检查对象失败含义
草图投影 IoU生成网格的指定视角轮廓几何条件未生效或被先验淹没
部件归属准确率分割条件对应的面片集合条件编码器部件边界模糊
厚度下限SDF 解码后的薄壁区域表示在薄结构上塌陷
UV 缝颜色差缝两侧反投影颜色多视图聚合不一致
编辑外溢 IoU未编辑区域的前后差异潜变量全局耦合未被约束

断言的工程代价是必须固定随机种子与采样步数，否则扩散采样的方差会掩盖真实回归。另一个代价是断言本身可能被“刷分”：模型可以在草图 IoU 上过拟合而牺牲背面合理性，因此断言要成组使用，单一断言通过不构成验收。一个具体例子：局部编辑换把手，断言要求未编辑区域 IoU 高于容差且把手区域几何有效，两者同时满足才算通过；只满足前者说明模型根本没改，只满足后者说明编辑外溢。

六 · 哪里不能照搬：边界条件的工程判断

不能照搬的第一处是“几何与纹理分离”的普适性。分离成立的前提是纹理可由几何表面的多视图观测充分决定，这对不透明、漫反射主导的资产成立；对透明、折射、次表面散射、强各向异性高光的资产，多视图反投影无法恢复正确的材质参数，分离管线会把材质错误地烘进 albedo。这类资产要回到联合优化或显式材质求解，而不是照搬 TexDiff + UV。第二处是“条件控制进扩散”的普适性。扩散的软约束适合候选生成，不适合度量级精确建模；把 Step1X-3D 放进 CAD 式管线会得到“看起来对、量起来错”的结果。第三处是“局部编辑重采样”的普适性。整链重采样在数十秒量级下只适合离线编辑，交互式场景要换成潜变量局部冻结或缓存去噪轨迹，否则每次编辑的等待不可接受。

第四处是数据前提。纹理真实感受数据限制，照搬架构而不复现条件数据与材质覆盖，得到的只是几何尚可、纹理塑料感的系统；这不是架构问题，是数据分布问题，靠调架构无法修复。第五处是拓扑前提。SDF 表示对封闭流形友好，对扫描件、薄片、开放边界不友好，照搬前要做拓扑修复或换表示。工程判断可以归纳为一条：Step1X-3D 的可控性是“条件引导下的分布内选择”，它的价值在候选生成与迭代编辑，它的边界在度量精度、材质复杂度与拓扑开放性。把这三条边界写进管线的前置检查，比在生成后做补救更省代价——前置检查拒绝一个不合适的输入，比跑完数十秒推理再发现 UV 缝接缝要便宜得多。
