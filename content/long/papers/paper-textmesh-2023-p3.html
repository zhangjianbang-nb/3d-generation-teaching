一 · SDS 目标的变量解剖：θ、x、y、d、t 各管什么

TextMesh 的优化对象是网格参数 θ，它同时包含顶点位置（可带位移场）与纹理参数。渲染器 R 把 θ 与相机 c 映射成两张图：RGB 图 xrgb 与深度图 xd。SDS 的梯度表达式里出现的 x 是扩散模型实际看到的输入，在 TextMesh 中它是 RGB 图，而深度图 d 作为条件被送进网络，与文本嵌入 y、时间步 t 一起构成去噪网络的输入三元组。理解这个分工是理解整篇论文训练逻辑的起点：θ 是被优化的几何与外观，x 是被加噪的观测，d 是把几何信息从外观中剥离出来的“旁路”。

把公式拆开看，每一项都有明确的工程含义：

$$\nabla_\theta\mathcal{L}_{\mathrm{SDS}}=\mathbb{E}\left[w(t)\big(\epsilon_\phi(x_t;y,d,t)-\epsilon\big)\frac{\partial x}{\partial\theta}\right]$$
  • εφ(·) 是冻结的深度条件去噪网络，φ 不参与梯度更新，它只提供“预测噪声”这一标量场式的监督信号。
  • xt 是渲染图 x 经前向扩散加噪到第 t 步的结果，t 从噪声调度中采样。
  • ε 是实际注入的噪声样本，括号内的差就是网络预测噪声与真实噪声的残差，本质是一个 score 方向的估计。
  • w(t) 是时间步权重，用于平衡不同噪声水平下的梯度量级。
  • ∂x/∂θ 是可微渲染器回传的雅可比，把图像空间的残差翻译成网格顶点与纹理像素的更新方向。
  • y 是文本提示的嵌入，d 是当前相机下渲染出的深度图，二者共同作为条件约束去噪网络。

关键机制在于 d 的引入改变了残差的语义。若没有 d，网络只能凭文本 y 判断“这张图应该长什么样”，于是它会同时惩罚几何错误与纹理错误，梯度无法区分二者，优化器倾向于把纹理信息烘进顶点色或几何起伏里，产生“纹理被几何吸收”的失败模式。加入 d 后，网络在已知几何的前提下判断外观，残差主要反映纹理与文本的不匹配，几何则由深度图自身的一致性约束承担。这一分离是 TextMesh 相对 RGB-only SDS 的核心改动。

系统代价随之而来：深度条件网络需要在深度-图像对上微调，这意味着额外的训练数据管线与一次模型微调开销；同时每次 SDS 迭代要渲染两张图（RGB 与深度）并跑一次去噪前向，显存与算力都高于单图 SDS。失败模式也很具体：若渲染深度与训练时深度条件的分布不一致（例如相机近平面设置不同、深度归一化方式不同），条件信号会偏移，网络给出的残差方向失真，表现为几何在迭代中缓慢漂移而不收敛。

一个具体例子：优化一只“带纹理的陶罐”时，某次迭代相机从侧面看，渲染深度显示罐口是凹的，而文本要求“圆润的罐口”。若只用 RGB SDS，网络可能通过把罐口附近顶点染成亮色来“假装”圆润；有了深度条件，网络知道几何已经凹了，残差会推动顶点向外位移，而不是只改颜色。这就是 d 在梯度层面的实际作用。

二 · 梯度的采样结构与可微渲染的回传路径

SDS 的期望是对 t 与相机 c 的联合采样。TextMesh 的训练循环里，每次迭代采样一个时间步 t（按噪声调度分布）和一个随机相机位姿，渲染一次，加噪一次，跑一次去噪网络，得到残差，再经可微光栅化回传。采样策略直接决定梯度的方差：t 太靠近 0 时图像几乎无噪，网络预测接近平凡解，梯度信号弱；t 太大时图像接近纯噪声，残差方向随机，梯度噪声大。w(t) 的作用就是在这一权衡上做加权，使不同噪声水平的贡献量级可比。

伪代码层面的循环结构可以写成：

  • 初始化 θ（模板网格 + 初始纹理），冻结 εφ。
  • 循环：采样相机 c ~ C，采样 t ~ U(调度)，采样 ε ~ N(0,I)。
  • 渲染 xrgb, xd = R(θ, c)。
  • 构造 xt = √ᾱt·xrgb + √(1−ᾱt)·ε。
  • 计算残差 r = εφ(xt; y, xd, t) − ε。
  • 损失 L = w(t)·‖r‖²，反传得到 ∂L/∂θ，更新顶点与纹理。
  • 施加 Laplacian 平滑与法线一致正则项，抑制顶点飞散与自交。

回传路径的工程细节值得展开。可微光栅化把每个像素的梯度分配到覆盖它的三角形顶点上，纹理梯度则通过 UV 采样分配到纹理像素。顶点梯度与纹理梯度共享同一个残差 r，但它们的雅可比不同：顶点梯度经由屏幕空间位置与深度缓冲，纹理梯度经由 UV 坐标与采样权重。这意味着同一个残差会同时推动几何与外观，若不加约束，几何会通过“移动顶点改变轮廓”来降低残差，纹理则通过“改颜色”来降低残差，两者竞争。Laplacian 正则与法线一致正则的作用就是给几何更新加一个平滑先验，防止几何用高频位移去拟合本应由纹理承担的外观变化。

失败模式在这里非常具体：当相机采样覆盖不足时（例如只从正面采样），背面几何得不到梯度，顶点会在无监督区域自由漂移，出现“背面塌陷”。当纹理分辨率低于渲染分辨率时，纹理梯度在像素级被上采样放大，产生高频振铃，表现为表面出现细密条纹。系统代价是每次迭代要跑一次扩散网络前向，扩散网络参数量远大于渲染器，因此训练时间由扩散前向主导，每资产数十分钟到数小时的量级正来源于此。

数值玩具例子：设某次迭代采样 t 使 ᾱt=0.5，渲染图某像素 xrgb=0.8，采样噪声 ε=0.2，则 xt=√0.5×0.8+√0.5×0.2≈0.566+0.141=0.707。设网络预测 εφ=0.35，则残差 r=0.35−0.2=0.15。取 w(t)=1，单像素损失为 0.0225。若该像素对应三角形三个顶点的重心权重为 (0.5,0.3,0.2)，则顶点梯度按权重分摊这个残差乘以 ∂x/∂θ 的局部雅可比；纹理梯度则按 UV 采样权重分配到对应纹素。这个例子说明：残差是标量，但它在顶点与纹理之间的分配由渲染器的雅可比结构决定，而不是人为设定。

三 · 训练配方：冻结、正则与更新节奏

TextMesh 的训练配方可以概括为“一冻结、两更新、三正则”。一冻结指深度条件扩散模型全程冻结，只做前向提供残差；两更新指顶点参数与纹理参数同时被 SDS 梯度更新；三正则指 Laplacian 平滑、法线一致以及纹理表示的约束。冻结扩散模型是 SDS 家族的通例，目的是把 2D 先验当作固定的“评分函数”，避免在优化网格的同时漂移 2D 先验导致模式崩溃。

Laplacian 平滑的机制是惩罚顶点与其一环邻域平均位置的偏差，等价于对网格施加低通滤波。它的作用不是让网格变圆，而是抑制 SDS 梯度中高频分量造成的顶点抖动。法线一致正则则惩罚相邻面法线的突变，防止出现折痕状的伪几何。两者都以加权项加入总损失，权重需要与 SDS 损失量级匹配；权重过大时网格过度平滑，丢失文本要求的细节（例如“带棱角的石块”被磨圆），权重过小时几何噪声残留。这是一个典型的调参权衡，论文以定性方式表述其必要性，未给出固定数值。

纹理表示的约束体现在“纹理比辐射场提取更清晰”这一结果上。辐射场提取的网格纹理来自体渲染积分，本质是沿射线累积的颜色，高频细节被积分平滑掉；TextMesh 直接在纹理参数上优化，纹理梯度不经体积积分，因此保留了更高频的外观。代价是纹理参数与几何参数耦合在同一残差下，若纹理分辨率不足，几何会被迫承担外观细节，回到“纹理烘进几何”的老问题。消融实验中纹理表示是被检验的变量之一，说明这一设计选择对最终清晰度有实质影响。

更新节奏上，顶点与纹理共享同一学习率体系并不理想：顶点位移的量级是空间坐标，纹理像素的量级是颜色值，二者梯度尺度不同。工程上通常对两组参数分别设学习率或做梯度归一化，否则会出现“几何已收敛而纹理仍在震荡”或反之的失败模式。系统代价是调参成本：每换一个资产类别（器物、动物、场景），正则权重与学习率都要重新平衡，这解释了为什么方法虽可行但每资产仍需数十分钟到数小时的人工监督式训练。

具体例子：优化“一只带鳞片的蜥蜴”时，若 Laplacian 权重偏高，鳞片起伏被平滑掉，纹理只能画出鳞片图案而几何是光滑的，侧光下显得扁平；若权重偏低，鳞片区域顶点在高频残差下抖动，出现锯齿状轮廓。法线一致正则在此处的作用是允许鳞片有规律起伏但禁止相邻面法线随机翻转，从而在“保留细节”与“抑制噪声”之间取得可用的中间态。

四 · 关键超参的作用面与敏感性

把超参按作用面分类，可以看清哪些是“结构性”的、哪些是“调优性”的。结构性超参决定方法能否成立：深度条件的注入方式、扩散模型的冻结策略、纹理的参数化形式。调优性超参决定结果好坏：时间步采样分布、w(t) 的形式、正则权重、顶点与纹理的学习率、相机采样分布、每资产迭代步数。

超参作用面偏大/偏小的失败模式
时间步采样范围梯度方差与信号强度偏小：残差接近平凡解，梯度弱；偏大：残差近随机，几何漂移
w(t) 权重形式不同噪声水平的贡献平衡失衡时某噪声段主导更新，纹理过饱和或几何过平滑
Laplacian 权重几何高频抑制偏大：细节丢失；偏小：顶点抖动、自交
法线一致权重面法线连续性偏大：折痕被抹平；偏小：伪折痕与噪声面
纹理学习率外观收敛速度偏大：颜色震荡、过饱和；偏小：纹理滞后于几何
相机采样分布梯度覆盖度覆盖不足：背面塌陷；覆盖过密：单视角过拟合

过饱和是论文明确列出的局限，它与 w(t) 和纹理学习率的组合直接相关。SDS 残差在颜色通道上的累积若缺乏约束，优化器会把颜色推向极端值以降低残差，表现为纹理鲜艳得失真。这不是某一个超参的错，而是“残差驱动 + 无颜色先验”的结构性后果；深度条件缓解了几何与纹理的混淆，但没有消除颜色过冲。分辨率受限同理：渲染分辨率与纹理分辨率共同封顶了可表达的高频，超出部分只能以过饱和或几何噪声的形式“代偿”。

具体例子：把相机采样限制在水平环绕一圈而缺少俯视视角时，器物顶部几何得不到梯度，SDS 会把顶部纹理推向高亮以“补偿”缺失的几何线索，渲染出来顶部发白。这不是文本要求的效果，而是采样覆盖与残差补偿共同造成的失败模式。工程判断是：相机分布必须覆盖文本描述中暗示的所有可见面，否则深度条件也救不了未采样区域。

五 · 数值玩具例子：一次完整迭代的账

用一个极小的设定把上述机制串起来。设网格是一个低面数模板，顶点参数 θv 与纹理参数 θt 各若干维；相机 c 固定为侧视；文本 y 描述“粗糙的石块”。渲染得到 64×64 的 RGB 图与深度图。采样 t 使 ᾱt=0.7，某像素 xrgb=0.6，ε=0.1，则 xt=√0.7×0.6+√0.3×0.1≈0.502+0.055=0.557。网络在深度条件 d 下预测 εφ=0.18，残差 r=0.08，w(t)=0.5，单像素损失 0.5×0.0064=0.0032。

把这一像素的梯度拆成两路：几何路。该像素落在某三角形上，重心权重 (0.6,0.25,0.15)，残差经 ∂x/∂θv 回传，三个顶点各得到一个与权重成正比、方向沿屏幕投影反传的位移分量。纹理路。该像素的 UV 落在某纹素，残差经采样权重回传，该纹素颜色向降低残差的方向移动。若此时 Laplacian 正则发现某顶点偏离邻域均值过大，它会给该顶点一个反向拉力，抵消一部分 SDS 位移。总更新是两路梯度与正则项的加权和。

这个玩具例子的价值在于暴露量级问题：单像素损失 0.0032 看似很小，但一张 64×64 图有数千像素，且每次迭代只采样一个 t 和一个相机，梯度是稀疏且高方差的。若学习率按单像素量级设定，累积数千次迭代后顶点位移可能过冲；若按整图量级设定，单像素信号又被淹没。工程上的做法是对残差做归一化或对梯度做裁剪，这正是“每资产数十分钟到数小时”背后反复调参的现实来源。

再考虑失败路径：若深度条件 d 的归一化与扩散模型微调时的约定不一致（例如渲染深度被截断到近平面而训练时用线性归一化），网络看到的条件偏移，残差 r 的方向不再指向“纹理不匹配”，而指向“几何与条件不符”，于是顶点被错误推动，表现为石块表面出现不属于文本的凸起。这个失败不报错、不崩溃，只是结果偏离，属于最难排查的一类。消融实验对深度条件的检验正是为了确认这一路信号是否真的在起作用，而非被其他正则掩盖。

六 · 从损失结构看工程边界

把 SDS 损失与正则项写在一起，可以看出 TextMesh 的工程边界在哪里：

$$\mathcal{L}=\mathbb{E}\left[w(t)\big\|\epsilon_\phi(x_t;y,d,t)-\epsilon\big\|^2\right]+\lambda_{\mathrm{lap}}\mathcal{L}_{\mathrm{lap}}(\theta_v)+\lambda_{\mathrm{nrm}}\mathcal{L}_{\mathrm{nrm}}(\theta_v)$$

第一项由冻结的 2D 先验提供，它的上限由扩散模型对“深度条件 + 文本”的理解能力决定；后两项只作用于顶点，不作用于纹理，因此纹理的规整性完全依赖 SDS 残差自身，没有额外的外观先验。这解释了为什么过饱和是结构性局限而非调参疏忽：损失里没有任何一项在惩罚颜色极值。同理，分辨率受限是因为第一项的监督信号来自固定分辨率的 2D 网络，超出该分辨率的高频既无监督也无正则。

工程判断落在“何时值得用这条路线”。当面数需要可控、纹理需要清晰、且可以接受数十分钟到数小时的单资产优化时，深度条件 + 网格 SDS 的损失结构是自洽的：几何由深度条件与 Laplacian/法线正则共同约束，外观由纹理参数直接承载，二者通过同一个残差但不同的雅可比路径解耦。反之，若要求秒级生成或极高分辨率，这条损失结构的采样方差与扩散前向开销就是硬约束，不是调参能绕过的。消融实验对网格正则与纹理表示的检验，实质上是在确认这三个损失项的相对贡献是否稳定，从而判断方法在换资产类别时的可迁移性。

最后落到一个具体机制上：深度条件 d 在残差中的角色相当于把“几何是否正确”从“外观是否匹配”中解析出来，使得 ∂x/∂θ 的回传在顶点与纹理两路上各司其职。这一解析是否彻底，取决于渲染深度与扩散模型训练时深度分布的匹配程度；匹配偏差会以几何漂移的形式静默出现，而 Laplacian 正则只能抑制漂移的高频部分，无法纠正系统性偏移。因此训练配方的第一优先级不是正则权重，而是深度条件的归一化与相机采样的一致性——这是损失结构里最脆弱、也最容易被忽视的一环。
