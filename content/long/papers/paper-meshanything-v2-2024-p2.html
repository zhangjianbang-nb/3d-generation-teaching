一 · 从形状到 token：编码器与序列化的接缝

MeshAnything V2 的数据流起点不是网格，而是一个条件形状。系统先由一个形状编码器把输入几何（点云或体素化的形状表示）压成一个条件向量，这个向量不直接参与面片序列的生成，而是作为自回归 Transformer 的交叉注意力条件，在每一步解码时被反复查询。形状编码器的输出维度与 Transformer 的隐藏宽度对齐，因此它扮演的是“全局上下文提供者”的角色：它告诉模型这个物体大致是椅子、飞机还是台灯，但不告诉模型第一个面片该放在哪。这个分工是刻意的，因为面片序列的局部合法性（相邻面共享边）必须由序列本身保证，而不能依赖一个池化后的全局向量。

真正决定序列长度的是 AMT 面片序列化模块。它把网格 $\mathcal{M}$ 的面片集合转换成一个 token 序列，规则是：按面片遍历顺序，若当前面片与上一个面片共享一条边，则只编码该面片带来的那一个新顶点；若不共享边（即拓扑上的“断裂”），则退回逐面编码，把三个顶点全部写出。形式化地，序列化结果满足

$$\mathrm{AMT}(\mathcal{M})=\big(t_1,\ldots,t_N\big),\qquad |\mathrm{AMT}(\mathcal{M})|\approx \frac{1}{2}|\mathrm{VTT}(\mathcal{M})|$$

这里 VTT 指逐面三顶点 tokenization（MeshAnything 的做法）。系数约二分之一来自一个几何事实：在规则四边形网格或流形三角网格中，每个面片平均只引入一个新顶点，另外两个顶点由共享边继承。序列化的输出是一串离散 token，每个 token 对应一个顶点坐标的量化索引，而不是浮点坐标本身。这意味着编码器与序列化之间没有可学习的参数，序列化的质量完全取决于面片遍历顺序是否让共享边尽可能连续出现。

一个具体例子：一个由 1600 个三角面组成的艺术家网格，若用 VTT 需要约 4800 个顶点 token；用 AMT 在遍历顺序良好的情况下只需约 2400 个 token。这个差距直接决定了自回归模型能否在固定上下文窗口内完成生成。失败模式出现在遍历顺序被打断时：如果面片序列在拓扑上频繁跳转，共享边检测失败，AMT 退化为 VTT，序列长度回升，模型在预算内只能生成更少的面。系统代价因此不在编码器，而在序列化顺序的预处理上——需要一个确定性的面片排序策略，把共享边尽量排在相邻位置。

二 · 自回归 Transformer：逐 token 的条件分解

序列化后的 token 流被送入一个自回归 Transformer，按标准的因果语言建模目标训练。给定 AMT 序列 $t_1,\ldots,t_N$，模型学习分解

其中 $c$ 是形状编码器给出的条件向量。每一步的输出是一个顶点 token 的分类分布，词表大小由顶点坐标的量化分辨率决定。模型在生成时逐 token 采样或取 argmax，每生成一个 token 就把它追加到上下文里，供下一步查询。这个分解的关键在于：相邻面共享边的信息不是显式传给模型的，而是隐含在“上一个面片已经写出了哪两个顶点”这一历史里。模型必须从上下文中推断出当前面片继承了哪条边，才能正确预测新顶点。这正是 AMT 让序列变短后仍然可学的原因——继承关系由序列结构本身编码，而不是由额外的边指针编码。

训练在 Objaverse 艺术家网格上进行，序列来自 AMT 序列化，目标是自回归的下一 token 预测。训练耗时以数天计，这个量级反映的是序列长度减半后仍然可观的计算量：即便 AMT 把序列压到约一半，1600 面的网格仍有约 2400 个 token，批量训练时的注意力矩阵规模随序列长度平方增长。推理则是逐 token 的，每个 token 一次前向，生成一个 1600 面的网格需要约 2400 次前向传播。这个推理代价是自回归网格生成的固有成本，AMT 没有改变它，只是让同样次数的前向能覆盖更多面。

失败模式在这里表现为“上下文漂移”：当序列较长时，模型对早期面片位置的记忆被稀释，后续面片可能继承错误的边，导致生成的面片在空间上不闭合。系统代价是注意力机制的显存占用随序列长度增长，这也是为什么序列长度上限直接等于输出面数上限——模型无法生成超过上下文窗口能容纳的 token 数的面片。一个具体机制上的判断是：AMT 把“每面三 token”变成“每面约一 token”，等价于把上下文窗口的有效面数容量翻倍，这是 800 面到 1600 面提升的直接来源，而不是模型容量本身的变化。

三 · 解码器还原网格：从 token 到拓扑

解码器接收自回归模型产出的 token 序列，按 AMT 的逆规则还原成网格。还原过程是确定性的：遍历 token 序列，维护一个“当前面片”的状态，遇到继承 token 时复用上一条共享边的两个顶点，遇到新顶点 token 时分配新顶点索引，三个顶点凑齐后输出一个三角面。这个逆过程不需要学习，它只是把序列化时丢弃的顶点重复信息重新补上。还原出的网格是顶点索引加面片索引的集合，可以直接送入渲染或下游处理。

这里有一个容易被忽略的机制细节：AMT 的逆映射要求序列在语法上合法，即每个面片的三个顶点必须构成一个非退化三角形，且继承的边必须确实存在于上一个面片中。解码器不做几何合法性检查，它只做语法还原。因此拓扑合法性检查是独立的后处理步骤，而不是解码器的一部分。这意味着模型可能生成语法合法但几何上自交或非流形的网格，系统必须在外围加一道校验。这个分工是工程上的取舍：把合法性检查从解码器里剥离，换来自回归模型可以自由地生成任意 token 序列，而不被硬约束卡住。

失败模式具体表现为“悬空边”：如果模型在某个面片处预测了一个新顶点 token，但该顶点与上一个面片并不共享边，还原出的网格会出现两个面片在空间上接近但拓扑上不相连的情况。这类错误在复杂网格上更常见，因为长序列中继承关系更难维持。系统代价是后处理校验的计算量，以及校验失败时整条序列作废的重生成成本。一个具体例子：生成一个带细长支架的台灯时，支架部分的面片序列容易在细长结构处断裂，还原后支架与灯罩之间出现缝隙，校验步骤会标记这些边为非法并要求重采样。

四 · 模块分工与数据流全景

把四个模块串起来，输入到输出的每一步是：形状编码器接收条件形状，输出条件向量 $c$；AMT 序列化把目标网格（训练时）或空序列（推理时）转成 token 流；自回归 Transformer 在 $c$ 的条件下逐 token 生成；解码器把 token 流还原成网格；最后是拓扑合法性校验。训练时序列化模块提供监督信号，推理时它不参与，模型从起始 token 开始自回归地写出整个序列。这个不对称是自回归生成的常态：序列化只在训练时定义目标格式，推理时格式由模型自己维持。

这个分工的核心判断是：可学习的部分只有编码器和 Transformer，序列化与还原是确定性的、互为逆运算的格式转换。AMT 的改进全部落在格式转换这一层，它不改变模型容量，只改变同样容量下能覆盖的面数。消融实验对比 AMT 与逐面 token、面数上限、形状编码三者的贡献，其中 AMT 的贡献体现在序列长度减半带来的面数上限提升，形状编码的贡献体现在条件生成的多样性上。这两者的作用点不同：前者是序列经济性，后者是条件控制。

失败模式出现在模块边界上。形状编码器若把条件压得过于粗糙，Transformer 生成的网格会丢失局部特征，表现为面片分布均匀但细节缺失；AMT 序列化若面片排序策略不佳，序列长度回升，面数上限下降；解码器与校验之间若校验过严，大量合法但边缘退化的面片被拒，生成成功率下降。系统代价因此是分布式的，没有单一瓶颈，但序列长度上限是最硬的约束，因为它同时限制了面数和细节上限。

五 · 序列经济性与它的硬边界

AMT 的经济性可以用一个简单的比值来衡量：每个面片平均消耗的 token 数。VTT 下这个比值恒为 3，AMT 下它取决于共享边的命中率，理想流形网格接近 1，断裂多时回升到 3。输出面数上限 $F_{\max}$ 与上下文窗口 $L$ 的关系是

$$F_{\max}\approx \frac{L}{\rho},\qquad \rho=\frac{|\mathrm{AMT}(\mathcal{M})|}{|\mathcal{M}|}$$

其中 $\rho$ 是每面平均 token 数。AMT 把 $\rho$ 从 3 压到约 1.5，因此在同样的 $L$ 下 $F_{\max}$ 翻倍，这就是 800 到 1600 的机制来源。这个公式也说明了局限：序列仍有限，$L$ 不增大，$F_{\max}$ 就不会继续提升；$\rho$ 也不可能低于 1，因为每个面片至少引入一个新顶点。因此 AMT 是一次性的效率改进，不是无限的。细节上限同样受此约束：更高细节需要更多面片，而面片数被 $L$ 卡住。

一个具体例子能说明这个边界的实际含义：生成一个 1600 面的网格时，若 $\rho$ 因排序不佳升到 2，所需 token 数约 3200，超出窗口则生成中断，还原出的网格面数不足且带缺口。工程上的应对是改进面片排序策略，让共享边命中率尽可能高，把 $\rho$ 压向 1。这是序列化层的优化，不涉及模型训练。系统代价是排序预处理的时间，以及排序策略对网格类型的敏感性——规则网格排序容易，艺术家手工网格的局部拓扑不规则，排序收益会打折扣。

拓扑合法性仍需检查这一点与序列经济性无关，它是解码器不做几何校验的直接后果。AMT 让序列变短，但没有让合法性变得更容易：长序列中继承关系的维持难度随面数增长，1600 面的网格比 800 面的网格更容易出现悬空边。因此面数提升与合法性风险是同时增长的，工程判断是：AMT 把可用基线推到 1600 面，但这条基线必须配一道校验才能用于生产。AMT 成为网格自回归生成的标准 tokenization，后续 PartCrafter 等借鉴其效率思想，借鉴的正是这个“共享边只编码新顶点”的序列经济性，而不是它的校验流程。
