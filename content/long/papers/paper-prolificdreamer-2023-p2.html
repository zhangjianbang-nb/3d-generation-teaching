一 · 从单点参数到参数分布：架构的第一层抽象

ProlificDreamer 的架构选择，首先要回答一个表示层面的问题：优化的对象究竟是什么。SDS 把 3D 参数 θ 当作一个确定性的点，每一次梯度更新都在把这个点往「当前文本条件下最像的单张渲染图」方向拽。ProlificDreamer 则把 θ 视为从一个分布 q(θ) 中采样的随机变量，优化目标从「找到一个好点」变成「让 q(θ) 逼近文本条件所隐含的真实 3D 分布」。这一层抽象直接决定了后面所有模块的分工：既然要匹配分布，就必须有东西能估计 q 的得分函数；既然 q 是隐式的、无法解析写出，就必须用一个可学习的代理去近似它。

形式化地，VSD 的目标是最小化变分分布 q(θ) 与文本条件分布 p(θ|y) 之间的 KL 散度。对 q 求导会得到一个包含两项的梯度：一项来自真实分布的对数密度梯度（由冻结的预训练扩散模型在渲染图上给出），另一项来自 q 自身的对数密度梯度（需要一个能对 q 采样的模型来估计）。这正是变分推断的标准结构，也是「变分得分蒸馏」名字的由来。写成公式即：

$$\nabla_\theta\mathcal{L}_{\mathrm{VSD}}=\mathbb{E}\!\left[w(t)\big(\epsilon_\phi(x_t;y,t)-\epsilon_\psi(x_t;c,t)\big)\frac{\partial x}{\partial\theta}\right]$$

公式里 ε_φ 是冻结的预训练扩散模型的噪声预测，条件为文本 y；ε_ψ 是粒子模型的噪声预测，条件为相机参数 c（以及可选的文本）。两项之差构成一个「得分残差」：预训练模型说这张带噪渲染图应该往哪个方向去噪，粒子模型说在当前 q 下这张图本来应该长什么样，差值就是推动 q 向 p 靠拢的方向。注意这个梯度对 θ 的作用是通过渲染过程 ∂x/∂θ 链式传回去的，也就是说 3D 表示的每一次参数更新，都是由「渲染图在像素空间里应该怎么变」反向映射得到的。

这一层抽象带来的系统代价立刻显现：q 是一个分布，意味着每次梯度估计都要从 q 中采样、都要前向渲染、都要过两个扩散网络。SDS 每次更新只需要一次渲染加一次扩散前向；VSD 需要一次渲染、一次冻结扩散前向、一次粒子扩散前向，并且粒子模型自身还要训练。显存占用从「一个 3D 网络 + 一个冻结扩散」变成「一个 3D 网络 + 一个冻结扩散 + 一个可训练 LoRA」，时间开销也相应上升。论文给出的定性描述是「每资产数小时」，这是分布匹配换来的真实成本，不是可以忽略的常数项。

二 · 数据流：一张渲染图如何走完整个回路

把架构拆成数据流，可以看清每一步的输入输出。起点是 3D 表示（NeRF 或网格）与一个相机位姿 c。采样阶段从当前 q(θ) 中取一个粒子——在实现上，这等价于用当前的 3D 参数渲染出一张图 x，因为 q 的随机性由粒子模型和训练噪声共同承载。渲染图 x 随后进入两条并行的扩散路径：一条喂给冻结的 Stable Diffusion，在随机时间步 t 上加噪得到 x_t，用文本 y 作为条件预测噪声 ε_φ；另一条喂给粒子 LoRA，在同样的 x_t 上用相机参数 c 作为条件预测噪声 ε_ψ。两条路径的输出相减，得到公式中的残差项，再乘以时间步权重 w(t) 和 ∂x/∂θ，回传更新 3D 参数。

与此同时，粒子 LoRA 自身也在被训练。它的训练信号来自渲染图 x 的去噪任务：把 x 加噪到 x_t，让 LoRA 学会在给定相机条件下预测所加的噪声。这一步的关键在于，粒子模型拟合的是「当前 q 下渲染图长什么样」，而不是「文本要求渲染图长什么样」。随着 3D 参数不断被 VSD 梯度推动，q 在变化，渲染图的统计特性也在变化，粒子 LoRA 必须持续跟踪这个移动目标。于是训练回路里存在两个相互耦合的优化：3D 参数追着「预训练得分减粒子得分」走，粒子模型追着「当前渲染分布」走。二者交替更新，形成一个类似对抗但又不同于 GAN 的结构——没有判别器，粒子模型扮演的是「当前分布的得分估计器」。

用伪代码思路描述这个交替过程：

  • 初始化 3D 参数 θ、粒子 LoRA 权重 ψ；冻结扩散模型 φ。
  • 循环：采样相机 c，从 q(θ) 渲染 x；采样时间步 t，加噪得 x_t。
  • 计算 ε_φ(x_t;y,t) 与 ε_ψ(x_t;c,t)，得到残差，按公式回传更新 θ。
  • 用同一张（或新采样的）渲染图对 ψ 做去噪训练，最小化 ε_ψ 与真实噪声的差异。
  • 按阶段切换 3D 表示：先 NeRF 粗优化，再转网格精修。

这条数据流里有一个容易被忽视的失败模式：如果粒子 LoRA 训练得太快，它会迅速拟合当前渲染图，残差项趋近于零，VSD 梯度消失，3D 参数停止更新；如果训练得太慢，粒子得分估计滞后，残差项包含大量与 q 无关的噪声，梯度方向失准。论文把粒子数、LoRA rank 列为消融对象，正是因为这两个量直接控制粒子模型对 q 的近似质量与跟踪速度。工程上这意味着 VSD 不是一个「设好学习率就能跑」的流程，粒子侧的超参和 3D 侧的超参必须联合调。

三 · 关键模块的分工：冻结扩散、粒子 LoRA、3D 表示

三个模块的分工可以用一句话概括：冻结扩散提供「文本想要什么」的先验，粒子 LoRA 提供「当前 3D 分布是什么」的后验，3D 表示是二者博弈的载体。冻结的 Stable Diffusion 在整个训练中不更新，它的角色是一个固定的评分函数——给定带噪渲染图和文本，它给出一个去噪方向，这个方向编码了大规模图像数据中学到的真实感与文本对齐知识。把它冻结有两个好处：一是避免文本先验被单个 3D 资产过拟合而漂移，二是省去主扩散模型的训练开销。代价是冻结模型对渲染图的域差异没有自适应能力，渲染图如果偏离自然图像统计（比如早期 NeRF 的模糊、过饱和），冻结模型的评分会系统性偏斜，这也是为什么需要多阶段、需要粒子模型来校正。

粒子 LoRA 是 VSD 相对 SDS 最核心的新增模块。它不是对 3D 参数建模，而是对「渲染图」建模：一个低秩适配器挂在冻结扩散模型上，用渲染图做去噪训练，从而在不改动主模型的前提下得到一个针对当前 3D 分布的得分估计。选择 LoRA 而不是全参数微调，是因为每个资产都要训练一个粒子模型，全参数微调的成本不可接受；LoRA 的低秩结构在显存和训练时间上把这件事压到可行区间。粒子数（多个 LoRA 粒子）则是对 q 的多模态性的一种粗糙近似：单个 LoRA 只能刻画一个相对集中的分布，多个粒子各自跟踪分布的不同区域，残差项在粒子间平均，降低单粒子估计的方差。论文把粒子数作为消融维度，说明这个量对多样性有直接影响。

3D 表示承担的是「可微渲染」的角色。NeRF 阶段提供连续的密度场与颜色场，梯度可以通过体渲染回传到每一个采样点，适合早期大范围形状的优化；网格阶段把密度场转成显式表面，纹理通过可微光栅化优化，适合后期高频细节与纹理真实感的提升。多阶段的分工不是装饰性的：NeRF 的体渲染在细节分辨率上受采样数限制，网格的显式表面在拓扑变化上不灵活，两者各管一段。系统代价在于阶段切换需要一次表示转换，转换本身有信息损失，且两个阶段的超参（学习率、正则权重、粒子更新频率）需要分别设定，这直接对应论文列出的「超参多」局限。

一个具体例子可以说明分工的必要性：优化一只带纹理的动物时，NeRF 阶段先把大体形状和粗色块拉到位，此时渲染图模糊、边缘不清，冻结扩散给出的去噪方向偏向「整体轮廓与语义」，粒子 LoRA 学到的是这团模糊分布的得分；进入网格阶段后，渲染图出现清晰表面，冻结扩散开始对纹理细节给出强梯度，粒子 LoRA 必须重新跟踪新的渲染统计。如果跳过 NeRF 直接上网格，早期拓扑未定时的网格优化容易陷入局部结构；如果只用 NeRF 不做网格精修，纹理的真实感上不去。这就是多阶段分工在数据流上的具体体现。

四 · 梯度回传路径与两个优化器的耦合

VSD 梯度公式看起来只是一个残差乘链式导数，但回传路径上有两处工程上必须处理的问题。第一处是 w(t) 时间步权重：不同噪声水平下，冻结扩散与粒子模型的预测可靠性不同，权重的作用是平衡各时间步对梯度的贡献。权重设得偏重高噪声，梯度更多塑造全局结构；偏重低噪声，梯度更多打磨细节。第二处是 ∂x/∂θ 的可微性：渲染过程必须对 3D 参数可导，NeRF 的体渲染天然可导，网格的光栅化需要可微渲染器支持。任何一处不可导或梯度断裂，残差项就无法落到 3D 参数上。

两个优化器的耦合体现在更新频率上。3D 参数每个迭代步都更新，粒子 LoRA 也在同一循环里更新，但二者的有效学习率不同：粒子模型要跟踪一个移动的 q，跟踪太快会抹平残差，太慢会引入滞后噪声。工程上的做法是给粒子侧设置独立的更新节奏和较小的学习率，并在粒子数大于一时对残差做平均。这个平均本身有代价：粒子数增加，单步计算量线性上升，显存也线性上升，而方差下降带来的收益是次线性的。论文把粒子数列为消融维度，隐含的判断是存在一个收益递减的拐点，超过拐点后多样性提升不足以抵消开销。

另一个失败模式来自残差项的量级。ε_φ 与 ε_ψ 都是噪声预测，量级相近，相减后的残差在训练初期可能很小——因为粒子模型刚初始化时接近冻结模型的行为，二者预测接近，梯度微弱。随着粒子模型逐渐偏离、开始刻画当前 q 的特有统计，残差才变得有信息量。这意味着 VSD 有一个「预热期」，在此期间 3D 参数几乎不动。如果预热期与 3D 侧的学习率调度不匹配，会出现早期形状没定好、后期纹理已经锁死的错位。论文的多阶段设计在某种程度上缓解了这个问题：NeRF 阶段允许较长的预热，网格阶段再加速细节优化。

用一只具体资产的训练过程来看这条路径：初始时 3D 参数随机，渲染图接近噪声，冻结扩散给出的去噪方向是「往任何合理物体靠」，粒子模型也学到同样的方向，残差接近零；随着 NeRF 逐渐收敛出粗形状，渲染图开始有语义，冻结扩散的方向变得具体（比如「这是一只四足动物」），粒子模型仍在跟踪这团粗分布，残差开始推动形状细化；进入网格阶段，渲染图出现表面法线与纹理，冻结扩散对材质和光照给出细粒度梯度，粒子模型重新拟合，残差推动纹理真实感。整条路径上，梯度不是恒定的，而是随 q 的演化而变化，这正是分布匹配与单点拟合在数据流上的本质差别。

五 · 输入到输出的完整链路与阶段边界

把链路从头到尾串一遍：输入是一段文本提示 y 和一组相机位姿采样策略（训练时相机从预设分布中采，不依赖外部 3D 数据）。初始化 3D 表示为随机 NeRF，初始化粒子 LoRA 为冻结扩散上的低秩适配器。第一个阶段循环执行「渲染—加噪—双路预测—残差回传—粒子更新」，直到 NeRF 的形状与粗色块稳定。随后执行表示转换，把 NeRF 的密度场提取为网格，进入第二阶段，循环结构相同但渲染器换成可微光栅化，粒子 LoRA 继续跟踪新的渲染统计。输出是一个网格资产加纹理，同时附带训练好的粒子 LoRA（后者通常不作为交付物，但它是整个优化过程的副产物）。

阶段边界上有两个具体的工程判断。其一是转换时机：转换太早，NeRF 形状未定，网格拓扑错误且难以修正；转换太晚，NeRF 的模糊渲染已经让冻结扩散的梯度偏向平滑解，纹理细节被抹掉。论文没有给出固定步数，而是把多阶段作为方法的一部分，意味着边界需要按资产调。其二是粒子模型在阶段切换时的处理：网格阶段的渲染统计与 NeRF 阶段差异明显，粒子 LoRA 如果沿用旧权重，残差会短暂失准；重新初始化或降低学习率重训是常见选择，这又是一项超参。

这条链路里没有 3D 训练集。整个方法只依赖预训练的图像扩散模型和文本，3D 监督完全来自 2D 渲染图上的蒸馏信号。这既是优点——不需要 3D 资产库——也是局限的来源：所有 3D 知识都必须经由 2D 扩散先验传递，先验的偏差会直接进入 3D 结果。冻结扩散对渲染图域差异的敏感性、粒子模型对 q 的近似误差、多阶段转换的信息损失，三者叠加构成这条链路的系统性误差预算。论文报告的用户偏好与 CLIP 分数优于 SDS，多样性更好、纹理更真实，这些定性结论对应的正是残差项把「单点拟合」换成「分布匹配」之后，q 不再坍缩到单一模式。

从工程角度看，这条链路的可复现性瓶颈不在公式，而在超参组合：粒子数、LoRA rank、粒子侧学习率、w(t) 的形状、两个阶段各自的迭代预算、阶段切换点。论文把这些列为消融对象，等于承认它们对结果有实质影响。VSD 后来成为优化式文生 3D 的强基线，原因也在这里：它的架构分工清晰、数据流可追踪、每个模块的失败模式都能定位到具体环节，代价是每资产数小时的优化和一组必须联合调的超参。分布匹配带来的真实感与多样性，是用显存、时间和调参人力换来的，这个交换比是否划算，取决于资产数量和多样性要求，而不是方法本身能一句话回答的。
