一 · 目标函数：逐 token 的负对数似然与它的分解

MeshAnything V2 的训练目标没有任何花哨的对抗项或几何正则项，它就是一个标准的自回归最大似然。给定形状条件 $c$（由形状编码器给出的条件向量）与 AMT 序列 $\big(t_1,\ldots,t_N\big)$，模型参数 $\theta$ 的优化目标是让真实序列在模型下的概率最大，等价于最小化负对数似然：

损失按 token 求和的写法有一个容易被忽略的工程后果：它对序列中每个位置等权。AMT 序列里不同位置的语义并不等价——序列开头的 token 决定了起始面片的锚点，后续 token 则是在已有邻接关系上“只编码新顶点”。等权求和意味着模型在开头犯错和在中段犯错付出同样的损失代价，但开头错误的几何后果更严重，因为它会污染整条邻接链。论文没有引入位置加权，这属于设计上的简化，也解释了为什么推理阶段仍需要拓扑合法性检查：损失函数本身不区分“合法但错位”和“非法拓扑”，它只关心符号是否匹配。

还有一个变量含义需要说清：$c$ 不是逐 token 变化的。形状编码器只运行一次，产出一个条件表示，然后被注入到自回归 Transformer 的每一层（典型做法是交叉注意力或条件拼接）。这意味着形状信息在整条序列上是共享的、静态的，模型必须学会在生成到第 $i$ 个 token 时仍然“记得”全局形状约束。这也是为什么消融实验里形状编码是一个独立项：去掉它，模型就退化成无条件序列生成，输出面数再多也没有形状对齐意义。

二 · 梯度与采样：教师强制训练、逐 token 推理的错位

训练时使用教师强制（teacher forcing）：把真实前缀 $t_{

采样策略因此不是可有可无的细节。训练目标是最大似然，对应推理时的贪心或束搜索会倾向于高频、保守的续写；而温度采样、top-k、top-p 则引入随机性，可能生成训练分布外的邻接组合。论文的推理是逐 token 进行的，每步都要跑一次完整前向（或带 KV 缓存的增量前向），这意味着推理成本与 $N$ 成正比，而 $N$ 已经被 AMT 压到约一半，所以“序列减半”不只是训练收益，也是推理延迟收益。用伪代码表达这个循环：

初始化空前缀，取形状条件 $c$；循环 $i$ 从 1 到 $N_{\max}$：把当前前缀与 $c$ 送入 Transformer，得到下一个 token 的分布；按采样策略选出一个 token 追加到前缀；若命中终止符或达到面数上限则停止；最后把 token 序列交给解码器还原网格并做拓扑合法性检查。这里的 $N_{\max}$ 是硬上限，对应论文局限里“序列仍有限”的那一条：无论 AMT 多省，模型能生成的面数终究被这个上限卡住，1600 面就是在这个预算下达到的输出面数。

梯度层面还有一个系统代价：损失对 $c$ 的梯度要穿过形状编码器回传，而形状编码器通常比自回归主干小得多，这导致条件分支的参数更新信号相对弱。工程上的失败模式是形状编码器“塌缩”——它对所有输入给出近似相同的条件向量，模型转而依赖序列自身的统计规律，生成结果面数达标但形状对齐变差。消融形状编码正是为了暴露这个问题。另一个失败模式是长序列上的梯度方差：$N$ 越大，单条样本损失求和项越多，梯度尺度随 $N$ 漂移，需要靠学习率预热或梯度裁剪稳住，这也是训练要花数天的原因之一。

三 · 训练配方：Objaverse 艺术家网格、数天、自回归

训练数据是 Objaverse 中的艺术家网格。选择艺术家网格而不是程序化或扫描数据，是因为 AMT 的前提是网格本身具有规则的邻接结构：相邻面片共享一条边，才能“只编码新顶点”。艺术家手工建模的网格通常满足这一前提，而杂乱的重叠面、非流形边会破坏 AMT 的序列化假设。数据管线因此包含一步序列化：把每个网格转成 AMT 序列，作为监督目标。这一步不是模型的一部分，但它决定了训练分布的上界——序列化失败的网格进不了训练集。

训练配方可以概括为：自回归目标、教师强制、在 AMT 序列上做下一 token 预测、训练持续数天。数天这个量级对应的是中等规模 Transformer 在长序列上的常规训练成本，不是大规模预训练的尺度。关键超参里，序列长度上限直接对应输出面数上限：AMT 把每面片所需 token 数压到约一半，所以在同一序列长度预算下，可容纳的面片数翻倍，输出面数从 800 提到 1600。换句话说，1600 不是模型容量的直接度量，而是“序列长度预算 ÷ AMT 每面片 token 数”的结果。词表大小由 AMT 的符号集决定（顶点坐标离散化后的符号、面片分隔符、终止符等），词表越大，单 token 的嵌入与输出投影越贵，这是序列减半之外的另一项成本权衡。

下表把训练与推理的关键量对齐，便于看清哪些超参在起作用：

环节变量/超参作用与代价
序列化$N$，AMT 每面片 token 数决定监督信号长度；AMT 约为 VTT 的一半，直接换算成面数上限
目标函数$\mathcal{L}$ 按 token 等权求和实现简单；不区分开头/中段错误，拓扑合法性需后验检查

一个具体的失败模式值得单独指出：面数上限与终止符的竞争。模型在训练中见到的最长序列受 $N_{\max}$ 截断，如果截断发生在网格中部，监督目标就是“在非自然结束处终止”。模型会学到在接近上限时倾向于输出终止符，导致复杂网格被提前截短，输出面数达不到 1600 而拓扑上留下开放边界。这是序列长度限制的直接体现，也是为什么论文把“序列仍有限”列为局限，而不是靠增大模型解决。

四 · 数值玩具例子：一条 8 token 的 AMT 序列如何算损失与梯度

为了把公式落到具体数字，构造一个极小的例子。设词表只有 5 个符号：$a,b,c,d,e$，其中 $e$ 是终止符。设某网格的 AMT 序列为 $t=(a,b,c,d,e)$，长度 $N=5$。形状条件 $c$ 已由编码器给出，此处视为固定向量，不参与数值。模型在每个位置的输出经 softmax 后得到概率分布，下表给出模型预测的概率与对应的负对数：

按公式求和，$\mathcal{L}=0.693+1.386+0.223+0.916+0.105=3.323$（自然对数，单位 nats）。这个数就是这条样本对总损失的贡献。注意第 2 位损失最大：模型只给了正确 token 0.25 的概率，说明它在“$a$ 之后接 $b$”这个邻接决策上最不确定。梯度上，这一位对 logits 的偏导是 $p_\theta - 1$（对正确类）与 $p_\theta$（对其他类），即正确类梯度为 $-0.75$，其余类分摊 $+0.75$，是五个位置里信号最强的一处。工程含义是：AMT 序列中“新顶点接在哪个已有边上”的决策点往往就是损失尖峰，也是采样时最容易走偏的位置。

现在把这个例子放到 AMT 与 VTT 的对比里。若同一网格用逐面三顶点表示，序列长度约为 AMT 的两倍，即约 10 个 token。假设每 token 平均损失与上表同量级，VTT 的单样本损失约为 AMT 的两倍，梯度累积步数也约两倍。在固定显存与固定训练步数预算下，AMT 让每条样本更短，于是同样预算能覆盖更多网格、或覆盖面数更多的网格——这正是“同等预算下面数从 800 提到 1600”的算术来源。反过来，若把 $N_{\max}$ 固定在能容纳 800 面的 VTT 长度，AMT 就能在这个长度里塞下约 1600 面，因为每面片 token 数减半。

再看采样。若在第 2 位用贪心，模型会选概率最高的符号而非 $b$，前缀立刻偏离训练分布，后续第 3、4 位的条件就落在模型没见过的前缀上，损失尖峰从“预测错”变成“条件错”。这解释了为什么逐 token 推理必须配合拓扑合法性检查：玩具例子里的 5 个符号还能人工核对邻接，真实 1600 面网格的邻接链一旦在早期分叉，解码器还原出的面片就可能共享了不存在的边。数值例子虽小，但它把三件事绑在一起：损失是逐 token 等权求和、梯度尖峰落在邻接决策点、采样错位会把符号错误放大成拓扑错误。

五 · 超参之间的耦合：序列预算、词表与面数上限

把超参分开看会漏掉它们之间的耦合。序列长度预算 $N_{\max}$、AMT 每面片 token 数 $k_{\mathrm{AMT}}$、输出面数上限 $F_{\max}$ 满足 $F_{\max}\approx N_{\max}/k_{\mathrm{AMT}}$。论文给出的关系是 $k_{\mathrm{AMT}}\approx \frac{1}{2}k_{\mathrm{VTT}}$，而 $k_{\mathrm{VTT}}=3$（每面片三个顶点 token），所以 $k_{\mathrm{AMT}}$ 约为 1.5 量级——这不是整数，实际实现里靠“共享边只编码新顶点”的可变长编码达成，平均下来接近一半。于是同样 $N_{\max}$ 下 $F_{\max}$ 翻倍，800 变 1600。这条链上任何一环变动都会传导：增大 $N_{\max}$ 提高面数上限但拉长训练序列、增加注意力成本；缩小词表降低嵌入成本但可能损失顶点坐标精度，进而影响细节上限——这正是局限里“细节上限”的来源。

最后落到一个具体机制上：AMT 的序列化把“共享边”这一几何事实转成了“少一个 token”的序列事实，损失函数因此变短、梯度尖峰集中在邻接决策点、推理成本随 $N$ 线性下降。这套机制的代价是序列上限硬卡面数、损失不校验拓扑、采样错位会放大成非法网格，所以训练配方里数天的自回归训练与推理端的合法性检查是配套的，不是可选项。判断一个 AMT 训练是否健康，看的是损失尖峰是否集中在邻接位置、形状条件消融是否有可见落差、以及接近 $N_{\max}$ 时终止符是否被过早触发——这三项比单看最终面数更能说明模型学到了什么。
