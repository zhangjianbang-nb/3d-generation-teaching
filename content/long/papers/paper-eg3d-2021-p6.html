一 · 目录结构与最小可跑版本的边界

复现 EG3D 的第一件事不是写模型，而是把"最小可跑"定义清楚。论文的完整系统包含三平面生成器、点采样与体渲染、2D 判别器、相机分布采样、R1 与路径长度正则，任何一项缺失都会让训练在几百步内发散或退化成纯 2D 纹理图。工程上应把仓库切成四层：configs/ 存超参与数据路径，models/ 放 StyleGAN2 主干、三平面解码器与判别器，render/ 放采样与体渲染，train/ 放循环、正则与检查点。最小可跑版本只要求三件事同时成立：生成器能输出三张平面特征、给定相机能渲染出与分辨率匹配的图像、判别器能对真实图与渲染图给出同形状的 logits。姿态条件、超分辨率模块、多视角一致性损失都可以先关掉，但三平面共享这一条不能省——它是 3D 一致性的唯一来源。

目录划分要对应论文的数据流，而不是对应论文的章节顺序。models/triplane.py 只负责把 StyleGAN2 的中间特征映射成三张平面，不掺渲染逻辑；render/ray.py 只负责由相机内外参生成射线与采样点；render/volume.py 只负责把密度与颜色积分成像素。这样做的直接收益是：当渲染出黑图或全透明图时，可以单独跑一个"固定三平面、固定相机、只调渲染"的单元测试，把问题锁在渲染层而不是生成器。反过来，如果渲染层与生成器耦合在一个文件里，任何形状错误都会表现为整图噪声，排查成本翻倍。

最小可跑版本的验收断言必须写成可执行的检查，而不是"看起来对"。三条硬断言：第一，三张平面特征的形状严格为 256×256×32，通道数 32 是论文给定的，改小会让高频细节塌陷，改大则显存与解码 MLP 的输入维度同步上涨；第二，任取一个 3D 点，三次双线性插值后拼接的向量维度必须是 96，与解码 MLP 第一层输入对齐；第三，体渲染输出的图像形状必须与判别器输入一致，否则对抗损失在广播时不会报错，只会静默地训练一个错位的目标。这三条断言用几行 assert 就能写完，却能在第一次跑通前拦掉绝大多数形状类崩溃。

二 · 数据准备与相机分布的落地

EG3D 的实验覆盖 FFHQ、AFHQ、ShapeNet、CompCars 四类数据，它们的准备方式完全不同，不能共用一条流水线。FFHQ 与 AFHQ 是单视角对齐图像，复现时只需要图像与可选的姿态估计；ShapeNet 与 CompCars 是多视角或带相机标注的数据，必须把每张图的相机内外参读进来，否则姿态条件与 2D 判别器的相机分布采样都无从谈起。工程上建议把数据集抽象成"图像 + 相机"的记录，即使 FFHQ 这类数据没有真值相机，也要用预训练的姿态估计器补一个伪相机，让训练循环里的相机张量永远非空。这样同一份训练代码可以在四类数据上切换，而不需要在数据加载处写分支。

相机分布采样是复现里最容易被低估的一环。论文用相机分布采样配合姿态条件，让判别器见到覆盖不同视角的渲染图。落地时要把相机参数化成方位角、仰角、半径与焦距，采样时先在角度区间上均匀取，再叠加小扰动，避免所有样本挤在同一视角导致判别器只学会区分"正面纹理"。一个具体的失败模式是：相机半径采样范围过窄，渲染出的物体在图像中占比几乎不变，判别器退化为纹理判别器，生成器随之放弃几何、只优化平面上的颜色分布，表现为多视角旋转时物体像贴纸一样滑动。验收断言可以写成：对固定隐向量渲染 N 个不同方位角，相邻视角的图像差异必须随角度单调变化，若差异在某段角度上突然归零，说明采样或插值出了问题。

数据准备的另一个代价是显存与吞吐的权衡。三平面是 256×256×32，三张合计约 6M 个浮点数，本身不大；真正吃显存的是每条射线上采样点的解码。若每张图采 64 条射线、每条射线 64 个点，单次前向就要过 4096 个点的 MLP，批量一上来显存就顶到上限。工程上的做法是把采样点数与批量做成反比配置：批量减半时采样点数可以适度上调，但不要指望靠增加采样点数换分辨率——论文的 512×512 渲染是靠 2D 卷积与超分辨率路径撑起来的，不是靠体素级密集采样。这一点在数据准备阶段就要写进配置注释，否则调参时很容易走错方向。

三 · 超参配置与训练循环的关键取舍

论文给出的训练配方里，R1 正则、路径长度正则与相机分布采样是三个必须显式打开的超参组。R1 正则约束判别器在真实样本附近的梯度范数，抑制判别器过强导致的生成器梯度消失；路径长度正则约束生成器对隐变量的敏感度，防止平面特征在高频处抖动。复现时最常见的错误是把 R1 的频率设成每步都算——R1 需要对真实样本求梯度，计算代价接近一次额外前向，每步都开会让训练时间显著拉长。工程判断是：R1 按固定间隔触发，间隔与批量大小联动，批量越大间隔可以越疏。路径长度正则则相反，它作用在生成器侧，代价小，可以每步都开，但要确保它作用在渲染前的平面特征上而不是渲染后的图像上，否则约束的是像素而不是几何。

$$\mathcal{L}_{R_1}=\frac{\gamma}{2}\,\mathbb{E}_{x\sim p_{data}}\left\|\nabla_x D(x)\right\|^2,\qquad \mathcal{L}_{path}=\mathbb{E}_{\mathbf{z}}\left\|\frac{\partial G(\mathbf{z})}{\partial \mathbf{z}}\right\|^2$$

训练循环的顺序也有讲究。正确顺序是：先采样隐向量与相机，生成器出三平面并渲染，判别器对渲染图与真实图打分，更新判别器并周期性施加 R1，再更新生成器并施加路径长度正则。若把生成器更新放在判别器更新之前，判别器看到的永远是上一轮的渲染分布，对抗博弈的节奏被打乱，表现为损失曲线周期性尖峰。另一个具体机制是姿态条件的注入位置：姿态应作为条件拼进判别器的输入，而不是拼进生成器的隐向量，否则生成器会把视角信息编码进平面特征，破坏三平面的视角无关性。验收断言可以写成：固定隐向量、只改相机条件，生成器输出的三平面必须逐元素相同；若不同，说明姿态泄漏进了生成器。

超参的另一个陷阱是学习率与平面通道数的耦合。三平面通道数 32 是论文给定值，解码 MLP 只有 2 层，容量有限，学习率过高会让平面特征在早期就饱和成常数，渲染出的图像失去视角变化。工程上的做法是把生成器学习率压到判别器之下，并给平面特征加一个小的初始化缩放，让训练初期的三平面接近低幅噪声而不是全零。全零初始化是一个典型的崩溃点：三平面全零时所有 3D 点插值结果相同，解码 MLP 输出常数密度，体渲染得到均匀色块，判别器立刻学会区分，生成器梯度被压到接近零，训练再也起不来。

四 · 常见崩溃点与对应断言

复现 EG3D 的崩溃点可以按发生位置分三类：形状类、数值类、语义类。形状类最容易发现，断言写在模块入口即可。数值类表现为损失 NaN 或渲染全黑，根因通常是密度过大导致体渲染的指数项溢出，或双线性插值越界读到未初始化内存。语义类最隐蔽：损失正常下降、图像看起来也像人脸，但旋转视角时几何错乱，根因是三平面共享被破坏或判别器只学到了 2D 纹理。

崩溃点典型现象根因验收断言
三平面通道数错配解码 MLP 输入维度报错或静默广播平面通道与拼接维度不一致拼接向量维度恒为 96
密度溢出渲染图全白或 NaN密度未做激活约束，指数项爆炸渲染像素值落在 [0,1] 且无 NaN

密度溢出这一条值得单独展开。体渲染的积分里密度经过激活后进入指数，若激活函数没有上界约束，早期随机平面可能给出极大密度，单条射线上的透射率瞬间归零，整张图变成背景色。工程上的做法是给密度加一个软上界，并在渲染函数入口断言透射率非负且不出现 NaN。这个断言的成本是一次逐元素检查，收益是把一个隐蔽的数值崩溃提前到第一次前向就暴露。另一个具体例子是插值越界：3D 点投影到平面后坐标可能落在 [−1,1] 之外，双线性插值若不做裁剪会读到平面边界外的填充值，表现为物体轮廓外的条纹。断言写成"采样坐标裁剪后与未裁剪的插值结果在边界内一致"，可以在不增加运行时代价的前提下锁住这个错误。

五 · 单卡复现的工程判断与验收清单

论文明确训练数天、单卡可跑，这意味着复现不需要多卡并行，但需要对单卡的显存与时间做精确预算。最小可跑版本的验收清单应包含四层：形状层断言、数值层断言、语义层断言、性能层断言。形状层与数值层在前两节已给出；语义层的核心是固定隐向量渲染多视角并检查几何一致性；性能层的断言是单步训练时间与显存占用落在配置声明的区间内，超出则说明采样点数或批量设置与硬件不匹配。四层断言全部通过，才算"最小可跑"成立，此时再打开姿态条件与超分辨率路径，逐项增加复杂度。

一个具体的工程判断是：不要一上来就复现 512×512。论文的 512×512 渲染依赖 2D 卷积主干与超分辨率路径的配合，直接在 512 上调试会让形状错误与显存错误混在一起。正确路径是先在低分辨率上跑通三平面生成、插值、解码、体渲染、判别器这条链，确认语义层断言通过，再逐级升分辨率。每升一级只改分辨率一个变量，其余超参冻结，这样任何新出现的崩溃都能归因到分辨率相关的模块，而不是归因到"某个地方错了"。这个做法牺牲了一点前期速度，换来的是崩溃点的可定位性。

另一个判断是关于三平面表示的固定拓扑。论文的局限里写明固定拓扑与几何精度有限，复现时要接受这一点而不是试图绕过：三平面是三个正交平面的笛卡尔积式查询，它天然无法表示超出该拓扑的几何，比如薄壳结构或自交表面。工程上的应对不是改表示，而是在验收断言里明确"几何精度以多视角一致性为准，不以单视角细节为准"。若把单视角细节当成验收标准，会不断加大平面通道数或解码 MLP 容量，最终偏离论文的算力预算，得到一个又慢又不一致的模型。三平面后来成为前馈重建模型的标准表示，LRM、TripoSR 等直接继承它、只把生成器换成图像条件 Transformer，这说明固定拓扑在工程上是可接受的取舍，复现时应把这一取舍写进配置而不是写进待办。

最后一个具体机制是检查点的验收。检查点不能只存权重，必须同时存相机分布参数、平面通道数、解码 MLP 层数与渲染采样配置，否则加载后无法复现同一张图。验收断言写成：加载检查点后，用固定隐向量与固定相机渲染，输出与保存前逐像素一致。这条断言把"可复现"从口号变成可执行检查，也是单卡复现里成本最低、收益最高的一条。
