一 · 目标函数：对抗项、R1 与路径长度正则的合成

EG3D 的训练目标不是单一损失，而是三项职责分明的项叠加：非饱和对抗损失驱动生成分布逼近真实图像分布；R1 正则约束判别器在真实样本附近的梯度范数；路径长度正则约束生成器对隐变量的响应尺度。三者的作用点不同，混在一起调会掩盖问题来源。写成统一形式：

$$ \mathcal{L}_G = -\mathbb{E}_{\mathbf{z}\sim p_z,\ \mathbf{c}\sim p_c}\left[\log D\!\left(R(G(\mathbf{z}),\mathbf{c})\right)\right] + \lambda_{\text{path}}\,\mathbb{E}_{\mathbf{z},\mathbf{c}}\left(\left\|\mathbf{J}_\mathbf{z}G(\mathbf{z})\right\|_2 - a\right)^2 $$
$$ \mathcal{L}_D = -\mathbb{E}_{\mathbf{x}\sim p_{\text{data}}}\left[\log D(\mathbf{x})\right] - \mathbb{E}_{\mathbf{z},\mathbf{c}}\left[\log\left(1-D\!\left(R(G(\mathbf{z}),\mathbf{c})\right)\right)\right] + \frac{\lambda_{\text{R1}}}{2}\,\mathbb{E}_{\mathbf{x}\sim p_{\text{data}}}\left\|\nabla_\mathbf{x}D(\mathbf{x})\right\|_2^2 $$

这里 G 输出三平面，R 是体渲染算子（沿相机射线采样、查询三平面、解码、积分），c 是相机参数，D 是 2D CNN 判别器，a 是路径长度目标值。注意判别器看到的始终是渲染后的 2D 图像，梯度要穿过整个体渲染链路才能回到三平面参数——这是 EG3D 反向传播的核心代价，也是它区别于纯 2D GAN 的地方。

R1 项只对真实图像求梯度，不对生成图像求，这一点在实现上必须严格区分：若误把生成样本混入 R1 的期望，判别器会被推向在假样本附近也平坦，削弱其区分能力。R1 的系数在 StyleGAN2 系谱里通常取一个较小的值，作用是抑制判别器过拟合到高频纹理，从而把判别信号让渡给几何一致性。路径长度正则则是对生成器隐空间的尺度约束：它惩罚雅可比范数偏离目标值 a 的程度，防止某些 z 方向的扰动被放大成剧烈图像变化，从而让隐空间插值更平滑。雅可比 JzG 的精确计算代价高，实践中用有限差分或随机投影近似，每次只对少量随机方向求范数。

失败模式很具体：去掉 R1，判别器在训练早期迅速记住真实图像的高频细节，生成器梯度被高频噪声主导，三平面上的低频几何结构学不出来，表现为渲染图视角间闪烁；去掉路径长度正则，隐空间出现“死区”与“爆炸区”并存，插值时物体突然变形。这两项都不是可有可无的装饰，而是把 2D 判别器的注意力从纹理拉回到结构的必要约束。

二 · 变量含义：从隐变量到三平面再到像素的完整链路

把符号逐个钉死，才能读懂梯度流向。z 是 StyleGAN2 主干的输入隐变量，经映射网络变成多层风格向量 w；主干用 2D 卷积逐级上采样，最终输出三张平面特征 Txy, Txz, Tyz，每张尺寸为 256×256×32。三张平面共享同一组 2D 卷积参数，这是“3D 一致性由共享约束”的具体落点：同一个卷积核在三个正交切面上提取特征，任何一张平面的局部模式都必须与另外两张在交线处相容，否则渲染出的 3D 点颜色会在视角切换时跳变。

查询一个 3D 点 x=(x,y,z) 时，分别把它投影到三个平面做双线性插值：Txy 取 (x,y)，Txz 取 (x,z)，Tyz 取 (y,z)，得到三个 32 维向量，拼接成 96 维，送入两层 MLP 输出密度 σ 与 RGB 颜色。体渲染沿射线积分：

$$ \hat{C}(\mathbf{r}) = \int_{t_n}^{t_f} T(t)\,\sigma(\mathbf{x}(t))\,\mathbf{c}(\mathbf{x}(t))\,dt,\qquad T(t)=\exp\!\left(-\int_{t_n}^{t}\sigma(\mathbf{x}(s))\,ds\right) $$

离散实现用分层采样加重要性采样，每条射线取若干采样点，密度决定不透明度，颜色按透射率加权累加。梯度从渲染像素 C 出发，经积分权重回传到每个采样点的 σ 与 RGB，再经 MLP 回传到拼接向量，最后经双线性插值的权重矩阵回传到三平面像素，再经 2D 卷积回传到 w 与 z。整条链路上，双线性插值是唯一的空间耦合点——它把三个平面的梯度按插值系数分摊到四个邻近像素，这就是三平面能保持 2D 卷积可扩展性的数学原因。

系统代价在于：每条射线要采样数十个点，每个点要做三次双线性插值加一次两层 MLP 前向，渲染一张 512×512 图的计算量远大于纯 2D 卷积生成同尺寸图像。训练时判别器每步都要对生成图做一次完整渲染，反向传播还要再走一遍，显存峰值出现在渲染缓冲与三平面特征同时驻留的时刻。失败模式是采样点分布不当：若重要性采样把点集中在密度高处，梯度会集中在少数不透明区域，半透明边缘（如毛发、车窗）学不好，表现为轮廓锯齿与视角切换时的边缘闪烁。

三 · 梯度与采样：相机分布、姿态条件与射线预算

相机分布 pc 是训练配方里最容易被低估的一项。EG3D 在每次生成器前向时从相机分布中采样一个位姿，渲染图与真实图一起送判别器。相机分布决定了模型见过的视角覆盖：若只在正面小角度范围内采样，三平面在侧面切面上的特征永远得不到梯度，侧视渲染会退化成正面纹理的拉伸。数据集本身带有的相机先验（如 FFHQ 的人脸对齐分布、ShapeNet 的物体环绕分布）被用来构造这个采样分布，而不是均匀采样整个球面。

姿态条件是可选项：把相机参数作为条件输入生成器，让同一 z 在不同位姿下渲染出同一物体的不同视角。没有姿态条件时，生成器只能靠三平面的 3D 一致性隐式地维持视角一致，判别器需要更强的几何约束才能学会；加上姿态条件后，生成器显式知道当前渲染的是哪个视角，训练更稳定，但代价是推理时必须提供位姿，失去了“任意视角自由渲染”的便利。消融里姿态条件的影响正是落在这条权衡线上。

射线预算是一个工程超参：每条射线的采样点数、是否启用重要性采样、粗采样与细采样两阶段的点数分配。点数太少，密度积分失真，薄结构丢失；点数太多，显存与算力线性上涨。一个可操作的伪代码思路：

  • 对每条射线先均匀取 Ncoarse 个点，查询三平面得到粗密度；
  • 由粗密度构造分段常数概率分布，逆变换采样出 Nfine 个点，集中在密度高的区间；
  • 合并两批点排序后做一次积分，透射率按相邻点间距累乘；
  • 只对最终像素损失反传，粗阶段不单独设损失，梯度经采样权重自然流回。

失败模式：重要性采样若在训练早期就启用，粗密度尚未成形，采样点分布剧烈抖动，梯度方差大，训练发散；常见做法是前期只用均匀采样，待密度场初步收敛后再引入重要性采样。另一个代价是渲染分辨率与射线数的乘积决定显存，512×512 下每像素一条射线已是不小的开销，若再对每条射线做数百点采样，单卡 batch size 会被压到很小，只能用梯度累积补偿。

四 · 训练配方与关键超参：从数天到单卡可跑

训练流程是标准的交替对抗：每步先更新判别器若干次（对真实图与生成图各算一次损失，加 R1），再更新生成器一次（渲染图过判别器，加路径长度正则）。生成器更新时判别器参数冻结，但梯度要穿过判别器回传到渲染链路，所以生成器一步的反向传播成本高于判别器一步。关键超参分四组：

组别超参作用与调整后果
对抗平衡判别器/生成器更新比、R1 系数比值偏大判别器过强，生成器梯度消失；R1 偏大判别器过于平滑，几何信号变弱
隐空间路径长度目标值 a、正则系数a 偏小隐空间响应过平，细节丢失；偏大插值不平滑
渲染粗/细采样点数、射线数、分辨率点数不足薄结构丢失；分辨率提升显存线性上涨
相机采样分布范围、是否姿态条件范围过窄侧面无梯度；姿态条件增加推理约束

三平面分辨率 256×256×32 是主干输出尺寸，它决定了空间细节的上限：平面像素越密，双线性插值能表达的 3D 细节越细，但 2D 卷积的显存与算力随边长平方增长。通道数 32 是特征维度，拼接后 96 维送 MLP，通道太少颜色与密度耦合不清，太多则 MLP 输入维度膨胀。训练数天、单卡可跑是论文给出的量级判断，其含义是：相比体素表示随分辨率立方增长的显存，三平面把增长压回平方，使得高分辨率 3D GAN 从多卡集群降到单卡可行。

失败模式按出现顺序排列：训练初期判别器损失迅速降到接近零，说明判别器过强，需降低其学习率或提高 R1；中期渲染图出现视角间颜色跳变，说明三平面共享不足或相机分布覆盖不够；后期 FID 停滞但视觉质量尚可，往往是几何精度到顶——固定拓扑与三平面分辨率共同限制了细节，继续训练只优化纹理不优化形状。

五 · 数值玩具例子：一次前向与一次梯度回传的手算

把链路缩到可手算的规模。设三张平面各为 2×2 像素、每像素 1 维特征（真实是 256×256×32，这里只为看清机制）。平面 Txy 取值 [[1,0],[0,1]]，Txz 取值 [[0,1],[1,0]]，Tyz 全为 0.5。查询点 x=(0.5,0.5,0.5)，落在每张平面正中，双线性插值取四邻域均值：Txy 得 0.5，Txz 得 0.5，Tyz 得 0.5，拼接向量 (0.5,0.5,0.5)。设 MLP 第一层权重使密度 σ = 2·(0.5+0.5+0.5) = 3，颜色 c = (0.5,0.5,0.5)。

沿一条射线取两点，间距 Δt=0.1，近点 σ1=3、远点 σ2=1。透射率：T1=1，T2=exp(−3×0.1)=exp(−0.3)≈0.741。像素颜色 C ≈ 0.1×(1×3×0.5) + 0.1×(0.741×1×0.5) = 0.15 + 0.037 = 0.187。设判别器对该像素的目标是让它更亮，损失对 C 的梯度为 +1（示意）。回传时，近点贡献的梯度权重是 0.1×3=0.3 乘颜色梯度，远点是 0.1×0.741=0.0741，可见近点主导梯度。再往上一层，σ 对拼接向量的梯度是每维 2，拼接向量对 Txy 四邻域的梯度各为 0.25（双线性权重），于是 Txy 每个像素分到 0.3×2×0.25=0.15 量级的梯度，三张平面按各自插值权重同步更新。

这个玩具例子暴露两个工程事实。其一，梯度在双线性插值处被摊薄：一个 3D 点的梯度分散到三张平面共 12 个像素上，平面像素的更新信号天然比 2D 卷积直接生成的图像弱，这是三平面需要更多训练步数或更大学习率的根源。其二，密度高的采样点主导梯度，若某区域密度饱和（σ 很大），透射率迅速衰减，远处点的梯度被压到接近零，模型会“看不见”被遮挡结构——这正是遮挡区域几何学不好的机制性原因，而非数据不足。工程判断落在采样策略上：提高远处点的采样密度、或在损失里对透射率加权，都是针对这条梯度衰减链的补偿手段。
