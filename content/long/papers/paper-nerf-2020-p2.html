一 · 输入是什么：一条射线、五个坐标、两个频率尺度

NeRF 的输入不是图像，也不是点云，而是一条相机射线。给定相机内参和外参，像素坐标 (u,v) 反投影成世界坐标系中的一条射线：起点是相机光心 o，方向是单位向量 d。射线上任意一点可以写成 r(t) = o + td，t 从近端 t_n 走到远端 t_f。整条射线上的采样点构成一个连续的一维参数化，网络要在这条线上逐点回答两个问题：这里有多不透光（密度 σ），以及从某个方向看过去这里是什么颜色（RGB）。

于是网络的输入被拆成两组坐标。第一组是空间位置 (x,y,z)，它决定几何与密度；第二组是观察方向 (θ,φ)，它只影响颜色，用来表达高光、镜面反射这类视角相关外观。这就是论文所说的 5D 函数 F：(x,y,z,θ,φ) → (RGB, σ)。注意这个拆分不是随意的，它直接对应一个物理假设——密度是各向同性的，颜色是各向异性的。这个假设让网络能把「形状」和「材质外观」解耦，也是后面消融实验里「去掉视角方向高光消失」的根源。

原始坐标不能直接喂给 MLP。原因很具体：神经网络对低频函数有强烈的谱偏置，直接输入 (x,y,z) 这类连续标量，网络会倾向于拟合平滑的大尺度结构，高频细节被抹掉。NeRF 的做法是位置编码，把每个标量映射到一组正弦基上：

$$\gamma(p)=\left(\sin(2^0\pi p),\ \cos(2^0\pi p),\ \dots,\ \sin(2^{L-1}\pi p),\ \cos(2^{L-1}\pi p)\right)$$

坐标用 L=10，也就是每个标量展开成 20 维，三个坐标共 60 维；方向用 L=4，两个角度展开成 8 维。这个设计的机制是：把单一低频输入变成一组从低频到高频的基函数，让 MLP 的第一层就能线性组合出任意频段的响应，绕开谱偏置。代价是输入维度膨胀，第一层权重的规模随之变大，但这个代价相对整个网络可以忽略。真正昂贵的代价在采样：每条射线要在 t 上积分，而积分需要大量前向计算，这是后面渲染慢的直接来源。

一个具体例子：合成数据集里一台相机分辨率为 800×800，就是 640,000 条射线；每条射线粗采样 64 个点、细采样 128 个点，一次完整渲染就是数千万次 MLP 前向。这就是为什么单场景渲染要数十秒量级——不是网络大，而是查询次数乘以射线数太大。

二 · 网络结构：一条主干、一个跳跃连接、一次方向拼接

主干是一个 8 层、每层 256 宽的全连接 MLP。输入是 60 维位置编码，第 5 层处把原始 60 维输入再拼回去，这就是论文里的跳跃连接（skip connection）。这个连接的机制值得说清楚：它让深层网络仍然能直接看到输入的高频基，避免多层非线性把高频信息逐层稀释；工程上它也是稳定深层 MLP 训练的常用手段。主干输出两个东西：一个标量密度 σ，和一个 256 维特征向量。

关键的分叉在这里。密度 σ 直接从主干取出，不再经过任何视角相关的层——因为密度按假设与方向无关。256 维特征则与方向编码（8 维）拼接，送进一个额外的全连接层（论文中是 128 宽），输出 3 维 RGB。这个「特征 + 方向 → 颜色」的结构是 NeRF 表达视角相关外观的具体机制：同一空间点在不同方向下共享同一个特征，但颜色可以不同。如果去掉这一层、让主干直接输出 RGB，网络就只能表达朗伯表面，高光消失。

用伪代码描述前向数据流：

  • 输入：位置 x=(x,y,z)，方向 d=(θ,φ)
  • γx = posenc(x, L=10)；γd = posenc(d, L=4)
  • h = MLP_1(γx)，8 层 256 宽，第 5 层拼接 γx
  • σ = Linear(h) → 标量；f = Linear(h) → 256 维
  • rgb = MLP_2(concat(f, γd)) → 3 维
  • 返回 (rgb, σ)

系统代价方面，这个结构有一个容易被忽略的失败模式：密度头与颜色头共享主干，意味着几何监督和外观监督在同一个参数空间里竞争。训练早期，颜色损失会通过共享主干反向影响密度，导致几何在颜色还没收敛时就被拉扯。论文用两阶段分层采样和联合训练来缓解，但没有从根本上解耦。后续工作里把密度与颜色分成两个子网、或给密度单独的梯度缩放，都是在处理这个耦合问题。

另一个具体例子是视角方向的编码维度。L=4 只有 8 维，远小于位置的 60 维。这不是疏忽：方向只用于调制颜色，不需要表达精细几何；维度过高反而会让网络把方向噪声拟合进颜色，产生视角间闪烁。这个取舍在消融里体现为——去掉方向编码，高光消失；方向编码过强，则会出现训练集视角外推时的颜色漂移。

三 · 从场到像素：体渲染积分与分层采样

网络给出的是连续场，像素需要的是标量颜色。桥接两者的是体渲染积分。沿射线累积透射率 T(t)，每一点贡献 σ·c 乘以透射率，积分得到像素颜色：

$$C(\mathbf{r})=\int_{t_n}^{t_f}T(t)\,\sigma(\mathbf{r}(t))\,\mathbf{c}(\mathbf{r}(t),\mathbf{d})\,dt,\qquad T(t)=\exp\!\left(-\int_{t_n}^{t}\sigma(\mathbf{r}(s))\,ds\right)$$

这个公式的机制是：T(t) 表示光从 t_n 走到 t 没有被吸收的概率，σ 越大衰减越快，颜色贡献越早被截断。它把「不透明度」和「颜色」乘在一起，天然实现了遮挡——近处高密度点会压低远处点的权重。工程实现上积分被离散化成求和，每个采样区间用 σ 和 c 的常值近似，透射率用指数衰减累乘。离散化误差主要来自采样密度：区间太粗，薄结构会被漏掉；区间太细，查询次数爆炸。

NeRF 的解法是两阶段分层采样。粗阶段在 [t_n, t_f] 上均匀采 N_c 个点（论文用 64），前向一次得到每点的 σ，据此构造一个分段常值的概率密度，再逆变换采样出 N_f 个细点（论文用 128），细点集中在密度高的区域。最终颜色只用细点的积分结果，粗阶段的输出只用于引导采样分布。这个机制的代价是两倍前向：粗网络和细网络各跑一遍，且细网络的输入依赖粗网络的输出，无法完全并行。

失败模式很具体：如果场景里有细长的结构（栏杆、树枝、铁丝），粗阶段 64 个均匀点很可能一个都没落在结构上，密度处处接近零，采样分布退化成均匀，细阶段也就找不到它。消融实验里「去掉分层采样细节变糊」正是这个机制的直接后果——不是网络容量不够，而是采样没打到该打的地方。反过来，如果场景是薄壁或透明物体，密度在边界处剧烈变化，分段常值近似会产生阶梯状伪影，这是离散化的系统性误差，靠增加采样数只能缓解不能消除。

一个具体例子：LLFF 真实前向场景里，前景物体与背景的深度差很大，均匀采样会把大部分点浪费在空区域。分层采样把细点集中到前景表面附近，等效于把有限的查询预算花在有信息的地方。这也是为什么 NeRF 在真实场景上 PSNR 能到约 26.5 dB，而纯均匀采样会明显更差。

四 · 损失与优化：4096 条射线、两级网络、一条 MSE

训练目标极其简单：渲染出的像素颜色与真值照片的 RGB 做均方误差。没有深度监督，没有法线监督，没有掩码，没有多视图几何约束。监督信号只有 2D 像素，3D 几何是从多视角一致性里「涌现」出来的。这是 NeRF 最核心的工程判断：可微渲染把 2D 损失直接传回 3D 场，几何不需要显式标注。

每次迭代随机采 4096 条射线，每条射线来自训练集里的一张图和一个像素。粗网络与细网络联合训练，损失是两者各自渲染颜色的 MSE 之和（细网络权重更高）。优化器是 Adam，学习率从 5e-4 指数衰减到 5e-5。一个场景通常训练 100–300k 步，耗时数小时到一天。这些数字背后是一个明确的取舍：单场景过拟合，不追求泛化，把全部容量压在一个场景上。

这里有一个具体的机制细节：射线是随机采的，不是按图像整张采的。这意味着同一批次里的 4096 条射线可能来自不同视角、不同空间位置，梯度是这些不相邻点的平均。好处是每步都覆盖场景的多个区域，坏处是梯度方差大，早期收敛慢。工程上这解释了为什么 NeRF 训练前期会出现「整体雾状、细节后现」的现象——低频结构先被多视角一致性约束住，高频细节要等采样密度和梯度信号积累够了才出现。

失败模式是过拟合到训练视角。因为损失只在训练射线所在的像素上计算，网络可以在训练视角之间「编造」不合理的几何，只要这些几何不投影到训练像素上。具体表现是：训练 PSNR 很高，但换一个略微偏离训练轨迹的视角，会出现漂浮的雾状伪影或结构断裂。这不是正则化能完全解决的，而是单场景过拟合范式的固有代价。后续工作用深度先验、多视图立体约束、或显式基元来补这个洞。

另一个具体例子是学习率衰减的作用。5e-4 到 5e-5 的指数衰减让早期大步长快速拟合低频几何，后期小步长精修高频纹理。如果去掉衰减、固定 5e-4，高频细节会持续被大步长扰动，收敛不到锐利结果；如果一开始就用 5e-5，低频几何收敛太慢，100k 步内到不了好结果。这个调度不是调参玄学，而是对应了「先粗后细」的频谱拟合顺序。

五 · 模块分工与数据流的闭环

把整条链路画清楚，可以看到五个模块各司其职。位置编码负责把连续坐标抬到高频基，解决谱偏置；主干 MLP 负责把空间位置映射成密度与特征，承担几何；方向拼接层负责把特征调制成视角相关颜色，承担外观；分层采样负责把查询预算分配到有密度的区域，承担效率；体渲染积分负责把逐点输出压成像素，承担可微性。五个模块里任何一个失效，都会在消融里对应一个具体退化：去编码→细节丢失，去方向→高光消失，去分层→细节变糊，去积分（换成直接回归像素）→无法表达遮挡。

模块输入输出承担的角色失效后果
位置编码标量坐标/方向高频基向量绕开谱偏置高频细节被抹平
主干 MLP60 维位置编码σ + 256 维特征几何与不透明度形状模糊、密度错乱
方向拼接层特征 + 8 维方向3 维 RGB视角相关外观高光消失、全朗伯
分层采样粗网络密度细采样点分布查询预算分配薄结构漏检、细节糊
体渲染积分逐点 (σ, c)像素颜色遮挡与可微性无法表达前后关系

数据流的闭环是这样的：相机位姿 → 射线 → 采样点 → 编码 → 主干 → 密度与特征 → 方向调制 → 颜色 → 积分 → 像素 → 与真值比 MSE → 梯度回传 → 更新 MLP 参数。整个闭环里唯一不可微的环节是采样位置的选择（粗阶段的逆变换采样），但论文用「细阶段只用细点积分、粗点只做分布引导」的方式绕开了这个问题——梯度不穿过采样位置，只穿过颜色与密度。这是一个容易被忽略的工程判断：如果让梯度穿过采样位置，训练会不稳定，因为采样分布本身是密度的函数，梯度会形成反馈回路。

系统代价的另一个来源是内存。8 层 256 宽 MLP 本身不大，但每条射线 64+128 个点、每批 4096 条射线，前向激活值在反向传播时要全部保留，显存占用随采样数线性增长。这就是为什么早期 NeRF 实现要用梯度检查点或减小批次。具体例子：把细采样从 128 降到 64，显存减半，但薄结构细节明显变差——这是显存与质量的直接 trade-off，不是算法问题。

最后落到一个工程判断上：NeRF 的方法总览之所以成立，不是因为某个模块特别精巧，而是因为五个模块的分工恰好让「2D 像素损失 → 3D 连续场」这条梯度路径保持完整且稳定。位置编码保证高频可表达，方向拼接保证外观可解耦，分层采样保证查询有效率，体渲染保证遮挡可微，MSE 保证监督简单。任何一处断开，整条链路就退化成离散表示或不可微近似——这正是 2020 年之前主流方法没能跨过去的那道坎。
