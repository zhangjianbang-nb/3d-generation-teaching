一 · 失效条件：三平面表示在哪里先崩

EG3D 的三平面不是万能的参数化。它把 3D 场写成三张正交 2D 特征图的双线性插值拼接，这个构造隐含一个强假设：场景的几何与纹理在三个主轴方向上具有可分性，且高频信息能被 2D 卷积在平面内捕获。一旦物体偏离这个假设，失效不是渐进的，而是结构性的。

具体机制在于插值算子的秩。查询点 \(\mathbf{x}=(x,y,z)\) 的特征是三个平面采样值的拼接：

$$F(\mathbf{x})=\mathrm{MLP}\!\left(\mathrm{interp}(T_{xy},\mathbf{x}),\mathrm{interp}(T_{xz},\mathbf{x}),\mathrm{interp}(T_{yz},\mathbf{x})\right)$$

每个平面只承载两个坐标的函数，第三个坐标的信息完全靠拼接后的小 MLP 隐式耦合。这意味着沿任一轴向的精细结构，若不能在该轴参与的两个平面内被表达，就会在拼接处丢失。薄壁、镂空、细长悬臂这类几何，其截面在某一轴上近乎零厚度，双线性插值在平面内无法分辨亚像素级的密度跃变，体渲染时表现为边缘发虚或密度泄漏。

系统代价体现在两个层面。其一是拓扑：三平面是固定分辨率的稠密网格，生成器输出 256×256×32 的特征，拓扑在训练分布内被锁定，模型没有机制去表示训练集之外的连通性——比如把椅子的四条腿合并成一条连续曲面，或生成一个带内部空腔的壳体。其二是几何精度：密度由 2 层 MLP 从拼接特征解码，MLP 容量小是刻意为之（为了渲染速度），代价是它只能做局部平滑决策，无法执行全局的几何一致性推理。一个具体例子是 ShapeNet 上的汽车：EG3D 能生成视角一致的车身，但车轮与轮拱的接触边界、后视镜这类小尺度凸起，在 512×512 渲染下常出现粘连或缺失，因为它们在三个平面上的投影都只占几个像素，插值后特征几乎相同。

还有一个容易被忽略的失效模式：三平面共享约束与 2D 判别器的联合作用，只在训练相机分布覆盖的视角附近有效。判别器是 2D CNN，它看到的是渲染图，不是 3D 场本身。若推理时把相机推到训练分布边缘（极端俯仰、贴脸特写），三平面之间的一致性没有被任何损失显式约束，拼接处的矛盾会以“视角一换就变形”的形式暴露。这不是数值 bug，而是监督信号的覆盖问题。

二 · 不能照搬的边界：固定拓扑与 2D 判别器的双重约束

工程上最常见的误用，是把 EG3D 当成“任意 3D 内容生成器”直接套到新领域。它的两个设计选择决定了不可迁移的边界。

第一是固定拓扑。三平面是规则网格，生成器是 StyleGAN2 主干，输出尺寸固定。这意味着模型无法表示分辨率之外的细节层级，也无法表示非流形或高亏格结构。若你的目标域包含大量拓扑变化（比如从完整杯子到破碎杯子的连续谱），三平面的稠密网格会把破碎状态编码成密度场的模糊衰减，而不是清晰的断裂面。可行的替代是引入稀疏体素或点云表示，但那会牺牲 2D 卷积的可扩展性——这正是 EG3D 要回避的代价，绕不开。

第二是 2D 判别器。判别器只看渲染图，它给生成器的梯度是“这张图看起来真不真”，而不是“这个 3D 场是否自洽”。三平面之间的一致性靠共享参数和插值结构隐式维持，没有显式的多视角一致性损失。这在 FFHQ、AFHQ 这类以正面为主的分布上够用，因为训练相机分布窄；但一旦相机分布变宽，或者目标域本身要求严格的多视角几何（比如工业零件的尺寸校验），2D 判别器提供的信号不足以约束 3D 精度。消融里“2D vs 3D 判别器”的对比说明 3D 判别器并非必需，但也说明 2D 判别器是这套效率方案的组成部分，换掉它就要重新付计算账。

第三是姿态条件的依赖。EG3D 配合相机分布采样与姿态条件训练，推理时可以指定相机。但姿态条件是输入，不是输出——模型不估计相机，也不校验渲染视角与三平面几何是否匹配。若把 EG3D 塞进一个需要“从单图反推相机再渲染”的流水线，相机误差会直接转化为几何误差，而模型没有机制去纠正。一个具体场景：用 EG3D 生成训练数据去喂一个位姿估计器，若生成时的相机分布与估计器的假设不一致，生成图的视角一致性会掩盖真实的几何偏差，导致下游模型学到错误的先验。

系统代价上，这三条边界共同指向一个判断：EG3D 是“在受控相机分布下、固定拓扑类别内、追求渲染效率”的方案。离开这个盒子，要么换表示，要么加显式 3D 监督，两者都会让“把计算负担转移到 2D 卷积”的收益打折。

三 · 被谁继承：三平面作为前馈重建的标准中间表示

EG3D 最持久的遗产不是 GAN 本身，而是三平面这个中间表示。它把“3D 场”压缩成三张 2D 特征图，使得任何能输出图像的骨干网络都可以接一个轻量解码器变成 3D 重建器。这个接口的吸引力在于：2D 骨干（CNN 或 Transformer）的预训练权重可以直接复用，3D 解码端只需要一个小 MLP 和体渲染，训练成本远低于从零学一个 3D 表示。

继承路径很清晰：LRM、TripoSR 这类前馈重建模型直接采用 triplane，把 EG3D 的 StyleGAN2 生成器换成图像条件 Transformer——输入一张或几张图，输出三平面，再走同样的插值拼接与 MLP 解码。差别在于监督：EG3D 用 2D 判别器做对抗训练，前馈重建模型用渲染损失对 ground-truth 多视角或 3D 监督做回归。三平面在这里的角色从“生成器的输出”变成“编码器的瓶颈表示”，但插值、拼接、解码的算子完全一致。

这个继承之所以成立，是因为三平面解决了前馈重建的一个核心矛盾：输出 3D 表示若用体素，显存随分辨率立方增长；若用纯隐式 MLP，编码器到 MLP 的接口难以用 2D 卷积高效生成高频细节。三平面把高频细节留在 2D 平面内，把跨轴耦合交给小 MLP，正好匹配“2D 骨干 + 轻量 3D 头”的架构范式。一个具体机制例子：TripoSR 类模型用 Transformer 从输入图提取特征，reshape 成三平面，查询点的特征拼接后送 MLP 出密度与颜色，体渲染出多视角图与真值比对——整条链路里没有任何一步需要 3D 卷积，全部计算落在 2D 算子和小 MLP 上。

代价也随之继承。前馈重建模型同样受固定拓扑与几何精度限制：三平面分辨率决定了重建细节的上限，薄结构和小尺度凸起依旧会丢。且前馈模型没有 GAN 的随机性，单图输入下三平面的跨视角一致性完全依赖训练数据的多视角覆盖，若训练分布窄，推理时的新视角会出现与 EG3D 同源的“换角度就变形”。工程判断是：继承三平面表示时，必须同时继承对相机分布和分辨率边界的清醒认识，而不是把它当成通用的 3D 万能接口。

四 · 工程复现清单：从数据到验收的逐项断言

复现 EG3D 不是把论文公式抄一遍，而是把每个模块的接口和失败模式钉死。下面是一份可执行的清单，每项配一个验收断言。

  • 数据与相机：准备目标域图像及对应的相机内参、外参分布。断言：训练相机分布的俯仰角与方位角覆盖范围被显式记录，推理时的采样不得超出该范围，超出即标记为分布外。
  • 三平面分辨率与通道：按论文设定生成三张 256×256×32 的平面特征。断言：三平面张量的形状、插值方式（双线性）、拼接顺序在生成器与解码器之间完全一致，任何一处 reshape 错误都会让密度场错位。
  • 解码器容量：2 层 MLP 输出密度与 RGB。断言：MLP 宽度与层数固定，不随分辨率缩放；若增大 MLP，渲染时间线性上升，需重新评估是否仍满足效率目标。
  • 体渲染：沿射线采样、密度积分、颜色合成。断言：渲染出的图与 2D 判别器输入的预处理（归一化、裁剪）一致，否则对抗信号会被预处理差异污染。
  • 判别器与正则：2D CNN 判别器，配 R1 正则、路径长度正则、相机分布采样、可选姿态条件。断言：R1 与路径长度正则的系数在训练日志中被记录，且正则项不作用于三平面特征本身，只作用于渲染图与生成器输出。
  • 训练规模：单卡可跑，训练数天。断言：单步显存占用与渲染分辨率、采样数成正比，先在小分辨率上跑通全链路再放大，避免在 512×512 上直接调试。

验收断言要落到可观测的量上，而不是“看起来对”。一个具体例子：检查三平面一致性时，固定 \(\mathbf{z}\)，从两个不同相机渲染同一 3D 点，比较其密度值；若差异超过阈值，说明插值拼接或 MLP 解码存在实现错误。另一个例子：把生成图送入一个独立的位姿估计器，若估计出的相机与输入相机系统性偏离，说明 2D 判别器没有约束住视角一致性，需要检查相机分布采样是否覆盖了该视角。

五 · 验收之后：什么该留下，什么该替换

复现清单跑通，只说明实现正确，不说明方案适配你的问题。验收之后要做的是边界判断：哪些组件是 EG3D 的效率来源、必须保留；哪些是它的局限来源、应当替换。

必须保留的是“2D 卷积生成 + 三平面插值 + 小 MLP 解码”这条计算路径。它把 3D 生成的负担从体素或大 MLP 转移到 2D 算子，这是 EG3D 在 512×512 渲染下仍能单卡训练数天的根本原因。替换这条路径，就等于放弃它的效率优势，回到体素显存立方增长或纯隐式 MLP 渲染慢的老问题。

应当替换的是监督信号与表示粒度。若目标域要求严格多视角几何，2D 判别器不够，需要加显式的多视角一致性损失或 3D 监督；若目标域拓扑变化大，三平面的固定网格不够，需要换稀疏表示或引入拓扑先验。这两类替换都会增加计算或工程复杂度，但它们是边界内的必要修正，不是对 EG3D 的否定。

一个工程判断落在具体机制上：三平面的跨轴耦合完全由拼接后的小 MLP 承担，MLP 容量小是效率设计，也是精度上限。若你的验收断言显示密度场在轴向交界处系统性模糊，第一反应不应是加大 MLP——那会破坏效率目标——而应检查三平面分辨率是否足以表达该尺度的结构，以及训练相机分布是否覆盖了暴露该结构的视角。多数“几何精度不足”的报障，根因在分辨率与相机覆盖，而不在解码器容量。把这两项钉死，再决定是否动 MLP，才是可复现的工程路径。
