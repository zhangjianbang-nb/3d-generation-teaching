一 · SDS 目标函数的逐项解剖

DreamFusion 的训练循环里没有一张真实的三维监督信号，也没有任何配对的多视角图像。唯一的监督来自冻结的 2D 扩散模型 Imagen。把这件事写成可优化的形式，就是 Score Distillation Sampling（SDS）梯度。它不是一个普通的损失函数：你无法写出一个标量 LSDS 并直接对它求导，实际做法是构造一个梯度表达式，把它当作伪梯度喂给优化器。公式为：

$$\nabla_\theta\mathcal{L}_{\mathrm{SDS}}=\mathbb{E}_{t,\epsilon}\!\left[w(t)\big(\epsilon_\phi(x_t;y,t)-\epsilon\big)\frac{\partial x}{\partial\theta}\right]$$

逐项拆开看。θ 是可微 3D 表示的全部参数，在 DreamFusion 里是 mip-NeRF 360 风格哈希网格 NeRF 的密度与颜色特征，包括多分辨率哈希表的表项、MLP 权重与颜色分支参数。x 是渲染器 g(θ, c) 输出的图像，c 是随机采样的相机位姿与光照条件；注意 x 本身是 θ 的函数，所以 ∂x/∂θ 是渲染过程对 3D 参数的雅可比。y 是文本提示。ε 是从标准高斯采样的实际噪声，形状与 64×64 渲染图一致。t 是扩散时间步，在训练中随机抽取。xt 是按扩散前向过程对 x 加噪后的结果。εφ(xt; y, t) 是冻结的 Imagen 噪声预测网络在给定含噪图、文本与时间步时输出的预测噪声。w(t) 是时间步权重，用来平衡不同噪声水平下梯度幅值的差异。

关键机制在于括号里的差值：预测噪声减去实际噪声。它衡量的是「扩散模型认为这张图在该噪声水平下应该带什么噪声」与「我们实际注入的噪声」之间的偏差。这个差值本身不是图像空间的像素误差，而是噪声空间的残差；把它乘上 ∂x/∂θ，就等价于把噪声空间的纠正方向回传到 3D 参数上。直观地说，扩散模型在告诉渲染器：你生成的这张图偏离了「一个符合文本描述的自然图像」的流形，往这个方向改你的 3D 参数。因为 εφ 是冻结的，梯度不会穿透扩散网络去更新它，计算图在 εφ 输出处截断，只保留 ∂x/∂θ 这条链。

这里有一个容易被忽略的工程细节：SDS 梯度不是任何标量损失的精确梯度。它丢弃了扩散模型对 xt 求导时产生的 U-Net 雅可比项，只把预测噪声当作一个「常数向量」使用。这一近似是 SDS 能用低成本跑起来的原因，也是它产生过饱和与多面伪影的根源之一——梯度方向带有偏置，优化器会沿着扩散先验的偏好走，而不是沿着真实图像似然走。系统代价直接体现在：每步需要一次前向渲染（64×64，多视角采样）、一次扩散网络前向、一次反向传播到 NeRF 参数；扩散网络虽冻结但前向并不便宜，15k 步的量级决定了单卡数小时的训练时长。

二 · 采样：随机相机、随机光照与随机 t

SDS 的期望是对 t、ε、相机 c 与光照联合求的。实践中每一项都用蒙特卡洛单样本估计：每步只抽一个 t、一组 ε、一个相机位姿、一套光照参数。这种「一步一采样」的做法让梯度方差很大，但换来的是每步极低的计算量。t 的分布不是均匀的，而是按 w(t) 加权采样；w(t) 的设计要让不同噪声水平下的梯度贡献可比，否则高噪声步（结构主导）会淹没低噪声步（细节主导）。论文没有给出 w(t) 的具体解析形式，但明确它是时间步权重，且训练中随机抽 t。

相机采样是这套配方里最容易被低估的部分。DreamFusion 在训练时随机采样相机方位角、仰角与距离，覆盖一个较宽的视角范围，而不是固定几个正面视角。原因很直接：如果只在窄视角范围内优化，NeRF 会在未见视角上塌陷成「正面贴图」，从侧面看出现拉伸或多面。随机光照同理：光照方向与强度随机化，迫使 NeRF 把反照率与阴影解耦，否则模型会把光照烘焙进颜色，换一个光照就露出破绽。消融实验确认了视角范围与光照随机化都是必要的，去掉它们生成质量下降。

伪代码层面的训练循环可以写成：

  • 初始化哈希网格 NeRF 参数 θ；冻结 Imagen 的 εφ。
  • 循环 15k 步：采样相机 c、光照 l、时间步 t、噪声 ε；渲染 x = g(θ, c, l)；构造 xt = √ᾱt x + √(1−ᾱt) ε；前向 εφ(xt; y, t)，可加 CFG；计算 SDS 伪梯度；用优化器更新 θ。
  • 训练结束后用 Marching Cubes 在密度场上提取网格。

失败模式在这里很具体：如果相机采样分布偏向某一侧，NeRF 会在该侧过拟合，另一侧出现「鬼影」几何；如果光照随机化不足，颜色分支会把阴影当成固有颜色，导致提取出的网格带有多余的暗斑。这些都是采样配方而非目标函数本身的问题，但它们决定了最终资产能不能用。

三 · CFG 尺度与训练配方

文本对齐靠 classifier-free guidance（CFG）。Imagen 在训练时以一定概率丢弃文本条件，因此可以同时算有条件和无条件的噪声预测，再外推：ε̃ = εφ(xt; ∅, t) + s·(εφ(xt; y, t) − εφ(xt; ∅, t))，其中 s 是 CFG 尺度。DreamFusion 用的 s 约 100，这个数字远高于 2D 文生图常用的个位数尺度。原因在于 SDS 的梯度是噪声空间残差，尺度放大会放大文本条件的方向，让 3D 参数更快地被拉向提示语义；代价是过饱和与色彩失真——高 CFG 尺度把扩散模型的偏好推到分布外，渲染图颜色被推向极端值，NeRF 把这些极端颜色学进颜色分支，最终网格呈现过饱和外观。

训练配方的其余部分：扩散模型全程冻结，只优化 3D 参数；每资产 15k 步；渲染分辨率 64×64；3D 表示为哈希网格 NeRF；最后 Marching Cubes 提网格。消融实验覆盖了 CFG 尺度、视角范围、光照随机化、哈希网格 vs 纯 MLP 四组。哈希网格相对纯 MLP 的优势在于收敛更快、细节更丰富，这是表示层面的选择，不是目标函数的变化。损失是 SDS，不是 RGB 重建——这一点必须强调：训练过程中没有任何一张目标图像，渲染图与任何参考图都不做像素级比较，所有监督都来自冻结扩散模型的噪声预测。

四 · 数值玩具例子：一维参数上的 SDS 一步

为了看清 SDS 梯度到底在做什么，把问题降到一维。假设 3D 表示只有一个标量参数 θ，渲染器输出一张单像素图 x = θ（把「渲染」简化成恒等映射，∂x/∂θ = 1）。文本提示固定。取某个时间步 t，令 ᾱt = 0.5，于是 xt = √0.5·θ + √0.5·ε。设实际采样噪声 ε = 1.0，当前 θ = 2.0，则 xt = 0.7071×2.0 + 0.7071×1.0 = 2.1213。设冻结扩散模型在该 (xt, y, t) 下预测噪声 εφ = 0.6，w(t) = 1。则 SDS 伪梯度 = 1×(0.6 − 1.0)×1 = −0.4。若优化器学习率为 0.1，更新后 θ = 2.0 − 0.1×(−0.4) = 2.04。

解读这个结果：扩散模型认为这张图「应该」带 0.6 的噪声，而我们实际注入了 1.0，说明渲染出的像素偏「噪」了，模型建议往噪声更少的方向走，于是 θ 被推大（在这个玩具设定下 θ 增大使 xt 增大，等价于信号更强）。换一组数：若 εφ = 1.4，梯度 = +0.4，θ 被推小。可见 SDS 的更新方向完全由「预测噪声 − 实际噪声」的符号决定，而 ∂x/∂θ 只负责把这个方向映射回参数空间。真实系统里 ∂x/∂θ 是一个高维雅可比，每个像素对每个 NeRF 参数的偏导都不同，所以同一个噪声残差图会在不同空间位置产生不同方向的参数更新——这正是 SDS 能把一张 64×64 的噪声残差变成三维几何修正的机制。

这个玩具例子还暴露了方差问题：单样本估计下，梯度符号随 ε 与 εφ 的抽样剧烈波动。若某步 ε 恰好接近 εφ，梯度接近零，该步几乎不更新；若两者差距大，更新幅度大。15k 步的意义就是用大量带噪样本把期望方向平均出来。工程判断是：SDS 的收敛不是靠精细的每步梯度，而是靠大量高方差步骤的统计平均，这也是为什么步数不能太少、学习率不能太激进。

五 · 梯度回传路径与失效模式

把计算图摊开：θ → 哈希网格查询 → NeRF MLP → 体渲染积分 → 64×64 图像 x → 加噪 xt → 冻结 Imagen 前向 → 噪声预测 εφ → 与 ε 相减 → 乘 w(t) → 乘 ∂x/∂θ → 更新 θ。梯度在 εφ 处被当作常数截断，不回传进 Imagen。这条路径上最脆弱的一环是 ∂x/∂θ：体渲染的积分与哈希网格的插值都必须是可微的，任何不可微操作（如硬阈值、离散采样）都会切断梯度，导致某些空间区域收不到监督。DreamFusion 用 mip-NeRF 360 风格的锥形采样与哈希插值保证可微性。

失效模式可以按机制归类。过饱和：高 CFG 尺度把噪声预测推向极端，残差方向持续把颜色参数往边界推，颜色分支学出超出自然范围的 RGB。多面伪影：SDS 梯度在视角覆盖不足的区域没有约束，NeRF 用「正面朝向相机的平面」去拟合所有视角的监督，从侧面看就出现多个面片。几何不精确：64×64 分辨率与噪声空间残差的性质决定了梯度只提供粗粒度形状信号，细部几何缺乏精确监督。这些不是调参能完全消除的，它们是 SDS 近似与低分辨率监督的结构性代价。

一个具体例子：优化一个「一只戴帽子的猫」提示。早期步里，随机相机从背面看，NeRF 背面没有监督，密度场在背面塌成薄片；随着训练推进，背面视角的 SDS 梯度开始修正薄片，但修正速度受限于该视角被采样的频率。如果相机分布均匀，背面最终会被拉成合理体积；如果分布偏正面，背面薄片保留到 Marching Cubes 阶段，提取出的网格从背后看是破的。这说明采样配方与梯度回传路径是耦合的：梯度只在被渲染到的像素上存在，没被渲染的视角没有梯度。

六 · 从公式到工程判断

SDS 公式的工程含义可以浓缩成三条。第一，监督信号在噪声空间而非像素空间，因此不能用 RGB 重建的直觉去调学习率与损失权重；梯度幅值随 t 与 w(t) 变化，优化器状态（如 Adam 的二阶矩）会吸收这种变化，但步数不足时偏差仍在。第二，∂x/∂θ 把图像空间的残差翻译成参数空间的更新，渲染器的可微性与分辨率直接决定梯度的空间精度；64×64 是一个成本与精度的折中，不是随意选的。第三，CFG 尺度约 100 是一个远离 2D 文生图常规值的设定，它把文本对齐推到很强，代价是颜色分布偏移；消融实验里 CFG 尺度是被单独检验的变量，说明它对结果的影响是主导级的。

训练配方的可复现要点：冻结扩散模型、随机相机与光照、随机 t、15k 步、哈希网格 NeRF、Marching Cubes 提网格。这套配方在无 3D 训练数据的条件下跑通了文生 3D，生成质量显著优于 CLIP 引导的网格优化与 Dream Fields 基线，用户偏好高。代价是每资产数小时、多面与过饱和、几何不精确。后续工作（Magic3D、ProlificDreamer、Fantasia3D、DreamGaussian）主要在得分估计、表示与速度三个轴上改进这套公式与配方，而 SDS 本身成为 3D 生成的标准术语——这说明公式的抽象层级选对了：它把「2D 扩散先验」与「3D 可微表示」解耦，任何一边的进步都能直接插进这个框架。

最后一个具体机制值得盯住：w(t) 与 t 的采样分布共同决定了梯度在「结构」与「细节」之间的分配。高噪声步的残差偏向全局形状，低噪声步的残差偏向纹理与颜色；如果 t 采样偏向高噪声，几何先收敛但纹理粗糙；偏向低噪声则颜色先饱和但形状漂移。DreamFusion 没有公开 w(t) 的解析形式，但训练中随机抽 t 并用 w(t) 加权这一做法本身，就是把「先形状后细节」的课程学习隐式地编码进了采样分布。工程上要复现或改进这套配方，第一件要盯的事就是 t 的采样与加权，而不是学习率。
