一 · 失效条件：解耦在哪些输入与场景下会失灵

Fantasia3D 的两阶段结构把「几何」与「外观」拆成两个独立优化问题，但拆分本身并不保证两个子问题都良态。它的失效条件可以从三条链路分别定位：几何阶段的条件信号、外观阶段的材质可辨识性、以及两阶段之间的几何冻结假设。

几何阶段的机制是：DMTet 维护一个可微的符号距离场与网格提取规则，渲染出法线图与深度图，送入法线条件扩散模型计算 SDS 梯度。这里的关键是法线条件扩散模型只「看见」法线，它对几何的监督是二维投影意义上的。当目标物体的法线在投影下高度自遮挡——例如多指缠绕的手部、层叠的衣褶、带内凹腔体的器物——法线图会把不同深度的表面压到同一像素上，SDS 梯度无法区分前后层，几何会倾向于把内凹填平或把薄片加厚。这是一个结构性失效，不是调参能解决的。

外观阶段的失效来自材质参数的可辨识性。外观阶段固定几何，MLP 输出反照率 a、粗糙度 r、金属度 m，经可微 PBR 渲染后与 RGB 扩散模型的 SDS 对齐。PBR 方程把这三组参数耦合进同一个辐射结果：

$$L_o(\omega_o)=\int_{\Omega} f_r(\omega_i,\omega_o)\,L_i(\omega_i)\,(\omega_i\cdot n)\,d\omega_i,\quad f_r=f(a,r,m)$$

在单一环境光照、单一视角采样的条件下，不同的 (a,r,m) 组合可以产生几乎相同的 L_o。这意味着材质 MLP 的解不唯一，优化会落到某个「看起来对」但物理上错的组合上——典型表现是把高光误解释为反照率的一部分，得到一张「烘焙了光照」的反照率贴图，重光照时高光位置随光源移动而暴露错误。RGB SDS 只约束渲染结果，不约束参数本身，所以这个歧义不会被自动消除；论文中提到的材质正则正是为缓解这一点，但它只能收窄解空间，不能消除歧义。

第三个失效条件是几何冻结假设。外观阶段完全信任阶段一产出的网格，如果阶段一的几何在局部有系统性偏差——比如整体偏胖、局部缺失细节、拓扑在薄结构处断裂——阶段二没有任何机制去修正它，只会在错误几何上贴一层自洽的材质。工程上这表现为：渲染图在训练视角下很好看，换一个视角或换一套光照就露出几何缺陷。这是两阶段串行优化的固有代价，也是后续工作转向「形状-材质联合但解耦表示」的动因之一。

具体例子：给「一把带镂空花纹的金属椅」做生成。几何阶段法线条件 SDS 对镂空结构的梯度信号极弱，因为镂空在法线图上只表现为边缘，扩散先验更倾向于把它当作噪声抹平，结果得到一把实心椅；外观阶段在实心几何上优化金属材质，反照率与粗糙度被调成「看起来像有花纹」的图案，重光照后花纹完全不随光照变化，暴露为贴图幻觉。这个例子说明：解耦让每个阶段各自可解释，但也让错误在阶段之间被固化。

二 · 被谁继承：解耦思想在后续系统中的形态迁移

Fantasia3D 的持久贡献不是某个具体模块，而是把「几何与外观分开建模、分开监督」确立为文生 3D 的一条工程路线。后续系统继承这条路线时，改动的重点在于把「两阶段串行」换成「双分支并行」或「显式 PBR 分解」，因为串行结构的前述失效条件在规模上会被放大。

Hunyuan3D 2.x 的形状-材质双 DiT 是这条路线最直接的形态迁移：形状由一个扩散 Transformer 生成，材质由另一个分支生成，两者共享条件但各自有独立的去噪过程。与 Fantasia3D 的差别在于，它不再依赖 SDS 的二维梯度去「雕刻」几何，而是用在大规模 3D 数据上训练过的生成先验直接产出形状表示，从而绕开了法线条件 SDS 在自遮挡与薄结构上的失效。代价是它需要 3D 训练数据，而 Fantasia3D 的设定是「无 3D 训练集」——这是两种范式的根本分野：前者用 2D 先验换数据自由，后者用 3D 数据换几何可靠性。

SF3D 的 PBR 分解延续的是 Fantasia3D 外观阶段的那一半：把外观显式拆成反照率、粗糙度、金属度，用可微 PBR 渲染器与图像监督对齐。它继承的核心判断是「RGB 监督不足以约束材质参数，必须引入渲染方程作为归纳偏置」。但 SF3D 把这一半做得更彻底：它不是在一个冻结的、由 SDS 优化出来的网格上贴材质，而是在一个已经具备合理几何的资产上做材质估计，从而避开了 Fantasia3D 中「几何错误被材质固化」的链条。

被替代的部分同样清楚。Fantasia3D 的几何阶段——DMTet 加 法线条件 SDS——在后续工作中基本不再作为主路径出现。原因有三：其一，法线条件 SDS 的收敛依赖每资产数小时的优化，无法批量；其二，DMTet 的分辨率上限直接限制了可表达的几何细节，薄壁与锐边在网格提取时会被平滑；其三，法线条件扩散模型的对齐质量决定了几何质量的上限，而这个对齐是脆弱的。取而代之的是前馈式或大规模数据驱动的形状生成器。

工程判断上，应当把 Fantasia3D 视为「解耦范式的定义者」而非「可直接部署的流水线」。它的价值在于给出了一个可检验的命题：把几何与外观分开监督，能得到可重光照的资产；它的失效条件则标出了这条路线在哪些维度上必须被后续系统补强——数据规模、几何表示的分辨率、材质参数的可辨识性。

三 · 复现清单：从零搭一条可跑通的两阶段流水线

复现 Fantasia3D 的难点不在公式，而在把两个阶段的接口对齐。下面按依赖顺序列出必须落实的组件与断言，每一条都对应一个具体的失败模式。

  • 几何表示：DMTet 的符号距离场初始化与网格提取规则。必须固定提取的分辨率与等值面阈值，并记录网格顶点数随优化的变化；失败模式是提取阈值漂移导致网格在优化中反复「呼吸」，SDS 梯度被拓扑变化淹没。
  • 法线渲染：从 DMTet 网格渲染法线图与深度图，需保证渲染可微且与扩散模型输入分辨率一致。失败模式是法线与扩散模型训练分布不匹配（例如坐标系手性相反），表现为几何整体镜像或法线朝内。
  • 法线条件扩散模型：冻结参数，只做前向与梯度回传。必须验证 SDS 梯度的符号方向：对同一提示词，沿梯度上升应使法线图更接近扩散先验的高概率区域。失败模式是梯度尺度未归一化，导致几何阶段被少数高幅值像素主导。
  • 外观 MLP：输入为表面点与视角，输出 a、r、m 三通道，需约束在合法区间。失败模式是粗糙度饱和到 0 或 1，使 PBR 退化为纯镜面或纯漫反射，材质失去可辨识性。
  • 可微 PBR 渲染器：需实现环境光照积分与阴影项（至少近似）。失败模式是省略阴影项，导致反照率吸收全部明暗信息，重光照时出现「自带阴影」的贴图。
  • RGB SDS 与材质正则：SDS 对齐渲染图与提示词，正则约束材质参数的平滑性与物理合理性。失败模式是正则权重过大，材质被压成常数，外观阶段退化为只优化几何的间接光照。

两阶段的接口是复现中最容易出错的地方。阶段一结束时必须冻结网格的顶点位置与拓扑，阶段二只优化材质 MLP 与渲染参数。接口断言应包括：阶段二开始后网格顶点坐标不再变化；阶段二的渲染图在固定视角下与阶段一末期渲染图的几何轮廓一致；材质 MLP 的参数量与输出通道数在阶段间不变。

伪代码层面的调度思路如下：

$$\text{for } t \text{ in geo\_steps: } \theta_{\text{DMTet}} \leftarrow \theta_{\text{DMTet}} - \eta \nabla \mathcal{L}_{\text{SDS}}(\hat{n}(\theta_{\text{DMTet}}), y)$$
$$\text{freeze } \theta_{\text{DMTet}};\ \text{for } t \text{ in app\_steps: } \phi \leftarrow \phi - \eta \nabla \big[\mathcal{L}_{\text{SDS}}(\mathrm{PBR}(\phi,\hat{n}), y) + \lambda \mathcal{R}(\phi)\big]$$

一个具体的复现陷阱：DMTet 在优化过程中会产生退化面（面积趋零的三角面），这些面在法线渲染时产生数值噪声，被 SDS 放大后表现为表面尖刺。工程上需要在每次网格提取后做一次退化面剔除，并断言剔除前后顶点数变化不超过给定比例。另一个陷阱是阶段二的材质 MLP 若以顶点为单位输出参数，会在网格分辨率不足处产生块状材质；改用表面点查询加三线性插值可以缓解，但代价是渲染时的采样开销上升。

四 · 验收断言：怎么判断复现成功而不是「看起来像」

「看起来像」是文生 3D 复现中最危险的验收标准，因为 SDS 优化出的资产在训练视角下几乎总是自洽的。验收必须针对 Fantasia3D 声称的两个核心属性：几何干净、材质可重光照。下面给出可执行的断言，每条都对应一个可观测的量。

断言观测方式失败含义
几何不含纹理性高频对网格做曲率统计，比较有无提示词纹理描述时的曲率分布差异纹理长进几何，解耦未生效
反照率与光照解耦固定几何与材质，换两套环境光照渲染，比较反照率通道是否不变反照率烘焙了光照，PBR 未起作用
材质参数在合法域内统计 a、r、m 的分布，检查是否饱和材质退化为常数或极端值
几何分辨率上限可复现在 DMTet 提取分辨率下测量最薄结构厚度薄结构被平滑，几何受表示限制
阶段间几何冻结比较阶段一末期与阶段二末期的顶点坐标哈希阶段二偷偷改了几何，两阶段名不副实

其中「反照率与光照解耦」是最能区分 Fantasia3D 与同期 SDS 方法的断言。DreamFusion/Magic3D 一类把几何与纹理混在辐射场里的做法，其输出本质上是「带光照的颜色场」，换光照无法重渲染；Fantasia3D 的外观阶段显式输出材质参数并经 PBR 渲染，理论上支持重光照。验收时应把同一资产在两套差异明显的光照下渲染，若反照率通道出现明显变化，说明材质 MLP 把光照信息吸收进了反照率，解耦在外观阶段内部就已经失败。

「几何不含纹理性高频」这条断言针对的是论文声称解决的核心痛点。做法是对比两组生成：一组提示词只描述形状，另一组提示词在形状描述外加强烈纹理描述（如「粗糙的、有划痕的」）。若后者的网格曲率高频分量显著高于前者，说明纹理描述通过 SDS 泄漏进了几何阶段，法线条件并未把几何监督限制在形状层面。这是一个定性可观测的失败模式，不需要精确阈值即可判断方向。

还有一个容易被忽略的断言：材质正则的有效性。正则需要在不破坏材质表达力的前提下抑制歧义解。验收方式是关闭正则重跑外观阶段，比较两次的反照率图；若关闭正则后反照率出现明显的高频噪点或与光照相关的结构，说明正则在起实际作用；若两次几乎相同，说明正则权重形同虚设，材质歧义未被约束。

五 · 不能照搬的地方：工程移植的边界

把 Fantasia3D 的思路移植到生产管线时，有几处不能照搬，且每一处都有明确的机制原因。

第一，不能照搬「每资产数小时优化」的预算假设。两阶段 SDS 的计算量集中在扩散模型的反复前向与梯度回传，几何阶段的步数与外观阶段的步数相乘，再加上 DMTet 的网格提取开销。这在单资产演示中可接受，在批量生产中直接不可行。移植时必须把「优化式生成」替换为「前馈式生成 + 轻量后优化」，否则吞吐量无法达标。这不是调参问题，是范式问题。

第二，不能照搬法线条件 SDS 作为几何监督的主信号。法线条件扩散模型的对齐质量是外部依赖，且它对自遮挡与薄结构的梯度信号弱，这一点在第一节已经定位为结构性失效。移植到需要精细几何的场景（工业零件、角色面部）时，必须引入额外的几何监督，例如多视角深度一致性、或直接用 3D 数据训练的生成先验。仅靠法线 SDS 无法保证几何在非训练视角下的正确性。

第三，不能照搬「几何冻结后贴材质」的顺序假设。当几何来自不可靠的来源（SDS 优化、低分辨率提取），冻结会把几何误差固化。工程上更稳的做法是让材质阶段对几何有有限的修正能力，或者至少在材质优化前做一次几何质量筛查。Fantasia3D 的顺序结构适合「几何已经可信」的前提，而这个前提在它的自身管线中并不总是成立。

第四，不能照搬材质 MLP 的参数化而不加可辨识性约束。PBR 参数在单一光照下的歧义是数学事实，不是实现缺陷。移植时必须配合多光照训练、材质先验正则、或显式的环境光照估计，否则得到的反照率贴图无法在目标光照环境下复用。论文中提到的「材质真实感受 2D 先验限制」正是这一点的定性表述：2D 扩散先验只知道「看起来像」，不知道「物理上对」。

第五，不能照搬 DMTet 的分辨率设定而不评估目标资产的细节尺度。DMTet 的分辨率上限直接决定最薄可表达结构，超出这个尺度的细节会在网格提取时丢失，且外观阶段无法补回——材质只能改变表面外观，不能创造不存在的几何。移植前应先按目标资产的最小特征尺寸反推所需分辨率，再评估该分辨率下的显存与提取耗时是否可接受。

工程判断落在一个具体机制上：Fantasia3D 的解耦之所以有效，是因为它把「几何监督」与「外观监督」分别绑定到不同的条件信号——法线条件扩散模型约束形状，RGB 扩散模型约束渲染结果，PBR 渲染器作为两者之间的可微桥梁。这条桥梁的可靠性取决于材质参数的可辨识性，而可辨识性取决于光照与视角的多样性。因此任何移植都必须先回答一个问题：目标管线能否提供足够多样的光照与视角监督？若不能，解耦只完成了一半，外观阶段会退化为在错误几何上烘焙一张自洽但不可重用的贴图。
