一 · 从四张图到一个高斯场：前向计算图与变量绑定

LGM 的前向过程可以写成一条严格串行的计算链，链上每个张量的形状与语义都必须固定下来，否则梯度无法回溯。给定四个视图 \(I_{1:4}\in\mathbb{R}^{4\times H\times W\times 3}\)，多视图 Transformer 先把它们切成 patch 序列，加上视图编号嵌入与相机位姿编码，做跨视图注意力，输出一组每视图的 token 特征 \(F_{1:4}\)。高斯头把每个 token 映射为一组高斯原语参数：中心 \(\mu\in\mathbb{R}^{3}\)、尺度 \(s\in\mathbb{R}^{3}\)（在对数域预测再取指数）、旋转四元数 \(q\in\mathbb{R}^{4}\)（归一化后使用）、不透明度 \(\alpha\in[0,1]\)（sigmoid）、球谐颜色系数 \(sh\)（三阶即 16 个系数×3 通道）。于是单视图 token 数 \(N_t\) 决定高斯数量 \(N=N_t\times 4\)，这是 LGM 中“视图数×每视图 token 数”直接等于高斯预算的结构性事实，也是后面显存代价的根源。

论文给出的核心式子是：

$$\mathcal{G}=\mathrm{GaussianHead}\big(\mathrm{Transformer}(I_{1:4})\big),\qquad \hat{I}=\mathrm{Rasterize}(\mathcal{G},\mathbf{c})$$

这里 \(\mathcal{G}=\{(\mu_i,s_i,q_i,\alpha_i,sh_i)\}_{i=1}^{N}\) 是高斯集合，\(\mathbf{c}\) 是任意目标相机，\(\hat{I}\) 是该相机下的渲染图。注意变量绑定关系：\(\mu_i\) 必须落在世界坐标系，而 Transformer 的输入是相机坐标系下的像素，因此高斯头里隐含一次由输入相机外参决定的坐标变换；四个视图各自预测的高斯被拼接到同一个世界坐标系中，重复区域靠不透明度与尺度自然竞争，没有任何显式的去重或融合模块。这一“拼接即融合”的设计是 LGM 简洁性的来源，也是误差传导的入口：任一视图的位姿估计偏差会直接变成该视图高斯子集的整体刚性偏移。

可微光栅化把 \(\mathcal{G}\) 投影到目标相机平面，按深度排序做 alpha 混合：像素颜色为 \(\sum_{i\in\mathcal{N}} c_i\alpha_i'\prod_{j<i}(1-\alpha_j')\)，其中 \(\alpha_i'\) 是投影后高斯在像素处的不透明度贡献。渲染损失通常是像素级 L1/L2 加上感知或 LPIPS 项，梯度经光栅化回传到每个高斯的 \(\mu,s,q,\alpha,sh\)，再回传到 Transformer 与高斯头。整条链没有可学习的渲染器，光栅化是确定性的、可微的、无参数的，这使得训练信号非常“干净”，但也意味着任何几何错误都无法被渲染器“修补”。

一个具体例子：设 \(H=W=512\)，patch 大小 16，则每视图 \(32\times 32=1024\) 个 token，四视图共 4096 个高斯。若把分辨率提到 \(1024\)，token 数变为 4096/视图、总数 16384，高斯数量翻四倍，显存与光栅化开销同步上升。这就是消融中“高斯数”与“视图数”两个变量耦合的机制：它们不是独立超参，而是通过 token 预算绑定在一起。

二 · 目标函数：多视图渲染损失与它的梯度结构

LGM 的训练目标是对多视图渲染结果做监督，而不是对三维真值做监督。这一点决定了梯度的形状。设训练时从物体或场景的环绕轨迹上采样 \(K\) 个监督相机 \(\{\mathbf{c}_k\}\)，每个相机渲染出 \(\hat{I}_k\)，与真值 \(I_k^*\) 比较：

$$\mathcal{L}=\sum_{k=1}^{K}\Big(\lambda_{\ell_1}\|\hat{I}_k-I_k^*\|_1+\lambda_{\mathrm{lpips}}\,\mathrm{LPIPS}(\hat{I}_k,I_k^*)\Big)$$

\(\lambda_{\ell_1}\) 与 \(\lambda_{\mathrm{lpips}}\) 是两个权重，前者管像素级颜色与轮廓，后者管局部纹理结构。梯度经光栅化分配到高斯：对 \(\mu_i\) 的梯度正比于该高斯在像素上的覆盖面积与残差；对 \(\alpha_i\) 的梯度直接来自混合权重；对 \(sh_i\) 的梯度只经由颜色项。关键机制在于：一个高斯若在所有监督视角中都被遮挡或落在视野外，它收到的梯度为零，成为“死高斯”，既占显存又不贡献渲染。LGM 没有显式的剪枝或致密化步骤（这与原生 3DGS 的 adaptive density control 不同），因此高斯预算在训练前就由 token 数固定，死高斯只能靠不透明度被压到接近零来“软删除”。

失败模式由此产生：当输入四视图之间存在遮挡差异时，某些区域只在一个视图可见，该视图预测的高斯缺乏其他视图的梯度约束，容易长出“薄片”状伪影，在侧视角下表现为拉伸的条纹。这是多视图误差传导在损失层面的具体表现——不是优化不收敛，而是监督信号在视图间分布不均。工程上的缓解手段是训练时随机采样监督相机，让每个高斯在其可见的视角上都能被覆盖到，但这只是概率性缓解，不能消除。

另一个梯度结构上的事实是：\(\mu\) 与 \(s\) 的梯度存在尺度耦合。若 \(s\) 过大，高斯覆盖多个像素，\(\mu\) 的梯度被平均化，位置修正变慢；若 \(s\) 过小，高斯只覆盖亚像素，梯度稀疏，训练抖动。LGM 在高斯头中对 \(s\) 做对数域预测并加下界约束，正是为了把这一耦合控制在可训练区间内。这是一个具体机制，不是调参玄学：对数域让尺度梯度与尺度本身解耦，下界防止高斯塌缩到零。

三 · 采样与两阶段训练配方

LGM 的训练分两阶段，两阶段的采样对象完全不同。第一阶段是 MVDream 生成多视图：给定一张输入图或文本，扩散模型在固定相机方位（论文使用四个正交或近似正交的方位）上生成四张 \(512\) 级别的视图。这一阶段不训练 LGM 的参数，它是数据生产环节，其采样步数、引导系数、随机种子都会影响下游。第二阶段训练高斯模型：在 Objaverse 与场景数据上，对每个资产渲染四视图作为输入，再渲染若干监督视图作为目标，优化上面的渲染损失。训练耗时以“数天”量级计，推理则是“数秒”量级——这个不对称是前馈模型的典型特征：把迭代优化从推理时搬到训练时。

训练配方的关键超参可以列成一张表，表中只写机制与相对量级，不写具体数值：

超参/变量作用机制代价或失败模式
输入视图数 \(4\)决定高斯预算与跨视图约束强度减到 2 时覆盖变差、背面 hallucination 增多
每视图 token 数与分辨率平方成正比，决定高斯数量翻倍即显存与光栅化时间翻倍
监督相机数 \(K\)控制梯度在视图间的覆盖均匀度过少导致死高斯与视角外伪影
\(\lambda_{\mathrm{lpips}}\)约束局部纹理，抑制模糊过大时高频噪声被放大为几何毛刺
尺度下界防止高斯塌缩、稳定 \(\mu\) 梯度过大时细节被抹平
场景分块大小把大场景切成可独立前馈的块块边界处高斯不连续、接缝可见

场景分块是 LGM 相对 GS-LRM 扩展覆盖面的具体机制：把大场景按空间网格切块，每块单独走一次四视图前馈，再把各块高斯合并到同一世界坐标系渲染。代价是块与块之间没有跨块注意力，边界处的高斯各自独立预测，容易出现密度不匹配的接缝；同时分块数线性增加显存峰值，因为每块的前向都要保留激活。这是“覆盖更大”与“显存更高”之间的直接兑换关系，不是可以靠工程技巧免费消除的。

还有一个采样层面的细节：输入四视图的相机方位在训练时是固定的，而监督相机是环绕采样的。这种“固定输入、随机监督”的不对称让模型学会从有限视角外推到任意视角，但也意味着输入方位之外的区域完全依赖先验。若推理时输入图的方位与训练分布偏移，高斯场的整体朝向会出现系统性偏差，而渲染损失无法在推理时纠正它——因为没有真值。

四 · 数值玩具例子：一次前向与一次梯度步

为了把上面的变量关系落到具体数字上，构造一个极小的玩具设定（以下数字是为说明机制而设的玩具值，不是论文实验数据）。设每视图只有 2 个 token，四视图共 \(N=8\) 个高斯。取其中一个高斯 \(i\)，其参数为 \(\mu_i=(0.1,0.0,0.0)\)、\(s_i=(0.05,0.05,0.05)\)、\(\alpha_i=0.6\)、颜色为纯红。目标相机为正前方，该高斯投影到像素 \((u,v)\) 后覆盖约 \(3\times 3\) 像素区域，中心像素的 \(\alpha'=0.6\)。若该像素真值为绿色 \((0,1,0)\)，而当前渲染为红绿混合，则残差在红通道为正、绿通道为负。

梯度分配：颜色系数 \(sh_i\) 收到与残差同向的梯度，把红色往下压；\(\alpha_i\) 收到使混合权重下降的梯度（因为该高斯贡献了错误颜色）；\(\mu_i\) 收到沿图像平面把高斯推离该像素的梯度，量级正比于覆盖面积与残差乘积。若学习率固定，一步更新后 \(\alpha_i\) 降到约 \(0.5\)，\(\mu_i\) 沿 \(u\) 方向移动一个小量。这里可以看到尺度耦合：若把 \(s_i\) 改为 \(0.2\)，覆盖面积变成约 \(12\times 12\) 像素，同样的残差被摊到更多像素上，\(\mu_i\) 的单步位移变小，收敛变慢；若把 \(s_i\) 改为 \(0.01\)，覆盖不足一个像素，\(\alpha'\) 在离散像素采样下不稳定，梯度出现抖动。玩具例子说明的不是数值本身，而是三个变量（尺度、不透明度、位置）在同一残差下的梯度分配比例由覆盖面积决定。

再算一笔预算账：\(N=8\) 时显存可忽略；若按真实配置每视图上千 token、四视图数千高斯，每个高斯存 \(\mu\)(3)+\(s\)(3)+\(q\)(4)+\(\alpha\)(1)+\(sh\)(48) 共 59 个浮点数，数千高斯即数十万浮点，加上 Transformer 激活与光栅化的排序缓冲，显存峰值由激活而非参数主导。这解释了为什么消融里“高斯数”是显存敏感变量：参数本身不大，大的是前向中间张量。

五 · 误差传导的量化路径与工程判断

多视图误差传导不是一句定性描述，它有一条可追踪的路径。设 MVDream 生成的某视图存在视角相关的纹理错误（例如把背面纹理画到了侧面），该错误进入 Transformer 后，跨视图注意力会把它部分传播到其他视图的 token 上，因为注意力无法区分“真实观测”与“生成幻觉”。于是高斯头在多个视图上一致地预测出错误几何，渲染损失在训练分布内无法惩罚它——训练真值来自同一资产的多视图渲染，而推理时输入是生成的，分布已经偏移。这条路径的终点是：模型对生成视图的信任度与对真实视图的信任度没有区别，误差被“一致化”而非被纠正。

工程判断由此而来。LGM 的定位是前馈、实时、高分辨率，它的训练目标决定了它擅长“把四视图解释成一个自洽的高斯场”，而不擅长“发现四视图之间的矛盾”。若下游应用对几何保真度敏感（例如需要精确尺寸的工业资产），误差传导会成为硬约束，此时应把 LGM 当作初始化，再叠加少量视角的测试时优化；若下游只要求实时渲染与视觉合理性（例如内容创作、预览），前馈一次的数秒推理就是正确取舍。显存高这一局限则直接约束批量与分辨率：在单卡上提高输入分辨率会同时抬高 token 数与高斯数，二者是乘法关系而非加法关系，因此分辨率提升的边际成本是超线性的。

最后落在机制上：LGM 的训练把“迭代优化”从推理时移到了训练时，代价是训练以数天计、推理以数秒计，收益是高斯参数由一次前向直接给出。这一交换的可行性依赖于渲染损失对高斯参数的梯度足够稠密——而梯度稠密性由监督相机数与高斯覆盖面积共同决定。当视图数、token 数、分块数三者同时上调时，显存峰值与接缝风险同步上升，这是该配方在扩大覆盖范围时无法回避的结构性约束。
