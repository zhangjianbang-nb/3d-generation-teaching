一 · 从单图到 PBR 网格：一条被切成六段的数据流

SF3D 的推理管线不是“一个大网络端到端吐模型”，而是一条被刻意切成六段、每段都有明确张量形状与失败边界的流水线。把这条流水线画清楚，比记住任何单个模块的名字都重要，因为论文的核心主张——0.5 秒、带 UV、带 PBR、光照解耦——正是靠这种分段换来的：每一段只做一件形状明确的事，段与段之间用显式的中间表示（SDF 场、UV 参数化、UV 空间纹理图、材质图）解耦，从而允许各段用不同的监督信号训练、允许在推理时对单段做替换或降级。

输入是一张单视图 RGB 图，记为 I∈R^{H×W×3}。第一段是单图编码：一个图像编码器把 I 压成一组条件特征，供后续几何解码查询。第二段是几何解码：网络在规范空间里预测一个有符号距离场（SDF），再经等值面提取得到三角网格 M=(V,F)，V 是顶点集、F 是面片集。第三段是快速 UV 展开：把 M 切成若干 chart，为每个顶点分配 UV 坐标，得到参数化映射 φ:M→[0,1]^2。第四段是 UV 空间纹理生成：在 UV 栅格上预测反照率图 A(u,v)，而不是在顶点上存颜色。第五段是材质与法线预测：在同一套 UV 栅格上再预测粗糙度、金属度与切线空间法线图。第六段是 delighting：从预测的反照率中剥离低频光照成分，输出可直接进引擎的 PBR 资产。

这条链的关键工程判断是：几何与外观被彻底分开。几何只由 SDF 解码器决定，外观只由 UV 空间的几张图决定。二者通过 UV 参数化这一“契约”连接。契约成立时，外观图可以独立替换、独立超分、独立压缩；契约破裂时（UV 展开失败），整条链的外观部分全部失效。这就是为什么论文把 UV 展开单列为一个模块而不是塞进纹理网络里——它是整条流水线唯一的单点故障源。

二 · 几何段：显式网格训练与 SDF 等值面

“显式训练网格生成”是论文标题里最容易被误读的一句。它不意味着网络直接回归顶点坐标，而是指训练目标显式地落在网格这一表示上：网络内部用 SDF 隐式场做中间表示，但损失与评估都针对提取出来的网格。这样做的好处是梯度可以从网格表面回传到 SDF 场，让几何监督直接约束最终产物，而不是只约束一个与网格脱节的隐式场。

几何解码的具体机制是：在规范空间采样查询点 x，解码器输出 f_θ(x|c) 作为 SDF 值，c 为图像条件特征。等值面提取在 f_θ(x|c)=0 处生成三角面。为了让 0.5 秒的预算成立，查询不是稠密体素网格，而是稀疏的、由粗到细的采样策略：先在低分辨率格点上定位表面附近区域，再只在窄带内细化查询。窄带宽度决定了能恢复的最小几何特征尺度——窄带越窄，细节越锐利，但漏检薄结构的风险越高。

$$\hat{M}=\{\,x \mid f_\theta(x\mid c)=0\,\},\qquad \mathcal{L}_{\mathrm{geo}}=\sum_{x\in\mathcal{S}}\big(|f_\theta(x\mid c)|+\big\|\nabla_x f_\theta(x\mid c)-n(x)\big\|\big)$$

上式左侧是提取出的网格，右侧第一项是 SDF 的绝对值损失（把采样点拉向零等值面），第二项是 Eikonal 型梯度约束（让场在表面附近的梯度逼近单位法线 n(x)），这是隐式场能稳定提取网格的前提。没有梯度约束，SDF 会在表面附近出现平坦区，等值面提取就会产生阶梯状伪影。

这一段的系统代价是采样预算与显存。窄带细化意味着查询点数量随表面面积而非体积增长，这是它能压进 0.5 秒的原因；但代价是薄结构（叶片、织物褶皱、细杆）容易落在窄带之外被整体漏掉，表现为几何细节有限。一个具体例子：单图输入一把带细长手柄的杯子，杯身能重建，手柄若在图像中投影宽度只有几个像素，窄带采样很可能整段跳过它，输出一个“无柄杯”。这不是网络没学到手柄先验，而是采样分辨率在预算约束下不足以覆盖该尺度。

三 · UV 段：把参数化当成可微的中间表示

UV 展开是整条流水线里最“传统图形学”的一段，也是 SF3D 区别于顶点色方法的分水岭。顶点色方法把颜色绑在顶点上，颜色分辨率等于顶点密度，且无法被标准引擎的材质管线消费；UV 空间纹理把颜色放在一张二维图上，分辨率与几何解耦，可以直接喂给引擎的贴图采样器。代价是必须先有一个合法的参数化。

快速 UV 展开的机制是分 chart：依据面片法线与拓扑把网格切成若干近似可展的块，每块用一个局部参数化投影到平面，再在 UV 平面上做 chart 间的排布（packing）以避免重叠。切 chart 的判据通常是法线夹角与曲率突变，接缝优先落在低可见性或高曲率处，让接缝在渲染时不易被察觉。整个过程要在毫秒级完成，因此不能用迭代优化式的展开，只能用一次性的、带贪心合并的分割加投影。

$$\mathcal{L}_{\mathrm{uv}}=\big\|\hat{T}(u,v)-T(u,v)\big\|^2,\qquad (u,v)=\phi(x),\ x\in M$$

上式是 UV 纹理损失：φ 把网格上的点映到 UV 坐标，T 是监督纹理，\hat{T} 是预测纹理。它的形式简单，但依赖一个前提——φ 必须是双射且无重叠，否则同一个 (u,v) 会对应多个表面点，损失就会把不同位置的颜色强行拉到一起，训练出模糊或错位的纹理。这就是 UV 失败为何是灾难性的：它不是“纹理差一点”，而是监督信号本身变得矛盾。

系统代价体现在接缝与 chart 数量上。chart 越多，排布越容易，但接缝总长度增加，接缝处的纹理会因两侧独立预测而出现色差；chart 越少，排布越难，大块非可展区域投影会产生拉伸，纹理在拉伸区被压缩采样，细节糊掉。工程上的折中是限制 chart 数量上限并对接缝做膨胀（dilate）填充，让纹理在接缝边缘有重叠像素可供双线性采样。一个具体失败模式：重建一个带凹槽的机械零件，凹槽内壁曲率突变被切成独立 chart，接缝正好落在凹槽棱上，渲染时棱线出现一条细窄的颜色断层——几何是对的，外观契约在接缝处破裂。

四 · 外观段：UV 空间的纹理、材质与法线三张图

UV 展开完成后，外观预测变成二维图像生成问题：给定 UV 栅格和图像条件特征，预测反照率 A、粗糙度 r、金属度 m 与切线空间法线 N。这一步的设计要点是把“几何细节”和“材质细节”分流：法线图承担高频表面起伏（凹槽、织物纹理、划痕），几何网格只承担中低频形状。这样几何段不必为高频细节付出采样预算，外观段则用二维卷积的高分辨率栅格补回观感。

机制上，UV 栅格被当作一张规则图像处理，网络在 (u,v) 上做卷积或注意力，条件特征通过交叉注意力注入。反照率与材质共享同一套 UV 布局，因此三张图在像素级对齐，引擎采样时同一 (u,v) 取到的是同一表面点的颜色、粗糙度与法线。法线图输出在切线空间，需要每个顶点提供切线与副切线，这也是 UV 段必须输出合法参数化的另一个原因——没有 UV 就没有切线基。

$$\mathcal{L}_{\mathrm{mat}}=\lambda_a\big\|\hat{A}-A\big\|^2+\lambda_r\big\|\hat{r}-r\big\|^2+\lambda_m\big\|\hat{m}-m\big\|^2+\lambda_n\big(1-\langle\hat{N},N\rangle\big)$$

上式把四张图合成一个材质损失，法线项用余弦相似度而非欧氏距离，因为法线是方向量，长度归一化后欧氏距离会惩罚无关的尺度差异。总损失即 \mathcal{L}=\mathcal{L}_{\mathrm{geo}}+\lambda\mathcal{L}_{\mathrm{uv}}+\mu\mathcal{L}_{\mathrm{mat}}，三个系数控制几何、纹理、材质的相对权重；权重失衡的典型症状是几何锐利但纹理糊，或纹理鲜艳但表面凹凸与几何矛盾。

这一段的系统代价是数据而非算力。材质真实感受数据限制：反照率、粗糙度、金属度的监督需要带 PBR 标注的资产，这类数据的多样性与物理准确性远不如纯几何数据。网络能学会“金属看起来亮、粗糙看起来哑”的统计关联，但难以从单图推断出准确的粗糙度数值——单图里高光形状与光源方向耦合，同一粗糙度在不同光照下呈现不同高光。一个具体例子：输入一张在柔光箱下拍摄的哑光塑料杯，预测可能给出偏低粗糙度，因为柔光下的高光被误读为光滑表面；换到硬光源渲染，这个杯子就会显得比真实更亮更“塑料”。

五 · Delighting 段：把低频光照从反照率里剥出来

Delighting 是 SF3D 把“可重光照”落到工程上的最后一步，也是它区别于早期图生 3D 方法的关键。单图输入的像素值本质是 反照率×光照 的乘积，如果直接把像素颜色当反照率烘进纹理，资产就永久带上了拍摄时的光照——换一个环境光，模型就会整体偏亮或偏暗，暗部会显得脏。Delighting 的目标是把光照项从反照率中分离，让输出纹理接近“固有颜色”。

机制上，它假设光照在空间上是低频的：阴影、环境光遮蔽、整体明暗渐变都属于低频成分，而材质纹理、划痕、印刷图案属于高频成分。于是可以对预测的反照率图做低频分解，估计出一个平滑的光照场 L(u,v)，再用 A_{\mathrm{delit}}=A/L 去除它。低频假设的合理性来自物理：单图条件下的光照主要来自少数几个光源加环境光，其在物体表面的变化尺度远大于纹理细节尺度。

$$A_{\mathrm{delit}}(u,v)=\frac{A(u,v)}{\max\big(L(u,v),\epsilon\big)},\qquad L=\mathrm{LowPass}\big(A\big)$$

分母加 ε 是数值保护，防止暗部除零放大噪声。这个公式形式极简，但失败模式很具体：低频假设会把“固有暗部”误判为“阴影”。一个黑色皮革沙发，其反照率本身就低，低频分解会把整块暗区当成光照阴影剥掉，结果 delighted 反照率被抬亮，重光照后沙发变成灰色。反过来，一个白色物体上的真实软阴影若频率偏高，会被保留在反照率里，换光照后阴影“焊”在纹理上。工程上的缓解是用 delighting 数据增强训练：在训练时对资产施加随机低频光照再要求网络还原，让网络学会区分“材质固有明暗”与“外部光照”，而不是靠固定的低通滤波。

系统代价是这一段的误差会直接进入最终资产且不可逆。几何错了可以重跑几何段，UV 错了可以重展开，但 delighting 错了，反照率已经被改写，下游引擎拿到的就是错误颜色。这也是为什么论文把它单列为一步而非塞进纹理预测里：单独一步意味着可以单独评估、单独关闭（对不需要重光照的场景保留原始反照率），也意味着它成为管线里一个显式的质量检查点。

六 · 模块分工与联合训练：为什么不能拆开单独训

把六段拆开看，每段都像一个独立的小问题；但 SF3D 的实际训练是联合的，原因在于段与段之间存在梯度依赖。UV 纹理损失要经过 φ 回传到几何，几何的顶点位置微调会改变 UV 展开结果；材质损失要经过切线基回传到 UV 布局；delighting 的增强会改变反照率目标，从而改变纹理网络的监督。任何一段单独训练都会与其他段的最优解错位。

联合训练的伪代码思路是：每个训练步先跑几何解码得到网格，再跑 UV 展开得到 φ，然后在 UV 栅格上采样预测三张图，最后按总损失反传。关键工程细节是 UV 展开必须对顶点坐标可微，否则几何段收不到来自纹理损失的梯度，联合训练退化为两阶段串行。可微 UV 展开的实现代价是切 chart 的离散决策不可微，通常用直通估计（straight-through）把离散分割的梯度近似为恒等映射，这会在 chart 边界引入梯度噪声。

训练数据来自 Objaverse 与内部资产，监督是网格、UV、材质三者的联合标注；delighting 通过数据增强注入，即在训练时对资产的照明做随机扰动，要求网络输出与扰动无关的反照率。推理时整条链一次前向，0.5 秒的预算被分配到六段上，几何采样与 UV 排布是主要耗时项，纹理与材质预测因为作用在二维栅格上反而便宜。

模块分工的工程判断可以归结为一句话：几何段负责“形状对不对”，UV 段负责“契约成不成立”，外观段负责“看起来像不像”，delighting 段负责“换光照崩不崩”。四类失败互不掩盖——几何平滑不会让 UV 变合法，UV 接缝不会让材质变准确，材质偏差不会让 delighting 变正确。这种失败的可分离性正是分段架构的价值：生产管线可以在每一段后插入检查，把不合格的资产挡在下一段之前，而不是等一个端到端黑盒吐出无法定位的坏结果。与 TripoSR、InstantMesh、CRM 这类基线相比，SF3D 的差异不在单段更强，而在于它把“UV + PBR + 光照解耦”做成了流水线里可检查、可降级、可替换的显式环节。
