一 · 从一张渲染图开始的现场

设想一个典型的 2022 年中的 3D 生成实验台：一块单卡或几块 A100，一个刚写好的可微渲染器，一个已经冻结的 Stable Diffusion 权重，以及一个待优化的 NeRF 或网格参数 θ。目标是输入一句文本，输出一个能从任意视角渲染出合理图像的 3D 资产。工程上最直接的做法是：随机采一个相机位姿，把当前 θ 渲染成图像 x，把 x 连同文本提示送进 2D 扩散模型，得到某种“图像是否像这句话”的信号，再把该信号对 x 的梯度经渲染器反传回 θ。整条链路的可行性完全取决于一个中间量——图像空间的更新方向，究竟是不是一个合法的得分函数。

DreamFusion 的 SDS 正是在这个位置上做了近似。它把扩散模型在加噪样本上的噪声预测残差 ϵ̂−ϵ 当作更新方向，乘一个系数后经雅可比反传。这个量在工程上极其好用：一次前向、一次反向即可，不需要采样完整轨迹，也不需要显式的概率密度。但它的理论身份是模糊的。噪声残差与得分之间存在关系，但 SDS 使用的加权、噪声尺度、以及“把残差直接当作图像梯度”的做法，并不能被写成某个概率分布对 θ 的梯度的无偏估计。于是出现了一个尴尬局面：系统能跑，结果能看，但任何一次失败——比如多视角不一致、几何塌陷、纹理过饱和——都无法从理论上判断是超参问题、是表示容量问题，还是估计量本身就是有偏的。

这种“能跑但说不清”的状态，在需要把系统推向生产时会变成具体代价。调参靠网格搜索，因为缺少可解释的中间量；复现靠固定随机种子和固定 schedule，因为方差来源未被分解；当换一个扩散模型或换一个渲染器时，无法预判信号是否会退化。SJC 的出发点不是“再做一个更好的 3D 生成器”，而是先把这条链路上的估计量写清楚：图像得分是什么，渲染雅可比是什么，两者相乘之后在 θ 空间里得到的是什么。这个动机决定了论文的形态——它更像一次对既有启发式的概率论重建，而不是一次以指标为导向的模型竞赛。

二 · 主流做法的两条路线与各自的断点

在 SJC 之前，用 2D 先验做 3D 的主流做法可以粗分为两条路线。第一条是 CLIP-guided：把渲染图和一个文本提示分别送进 CLIP，最大化两者嵌入的余弦相似度，梯度经渲染器反传。这条路线的问题不在实现而在信号：CLIP 相似度是一个判别式的、全局的标量，它对图像的局部结构、视角一致性、几何细节几乎不提供约束。优化过程容易收敛到“从某些角度看像提示、从另一些角度看是噪声”的退化解，工程上表现为需要大量数据增强（随机裁剪、随机视角、随机背景）来压制退化，而这些增强本身又引入了新的方差。

第二条就是 DreamFusion 的 SDS。它比 CLIP-guided 前进了一大步：使用扩散模型在多个噪声尺度上的残差，相当于给图像提供了一个多尺度的、逐像素的更新场，而不是一个全局标量。SDS 的更新可以写成对图像 x 的一个向量场，再经 ∂x/∂θ 反传。问题在于这个向量场的概率含义。扩散模型的得分 ∇_x log p_t(x) 与噪声残差 ϵ̂ 之间有明确关系，但在 SDS 里，残差被直接用作图像空间的“梯度”，并且乘上了与噪声尺度相关的权重。这个组合并不能被证明为某个 θ 分布的对数梯度的无偏估计；它更像是一个在实践中有用的、带偏的下降方向。

两条路线的共同断点在于“提升”这一步缺乏可推导性。2D 先验定义在图像空间，3D 参数空间里的分布 p(θ) 并没有被显式定义。要从图像得分得到 θ 得分，唯一严格的桥梁是链式法则：θ 的得分等于图像得分乘渲染雅可比，再对渲染所引入的随机性（相机位姿、噪声）取期望。SDS 跳过了这个期望的严格处理，CLIP-guided 则根本没有“得分”这个概念。于是工程团队面对的是一个无法分解的误差预算：不知道偏差来自 2D 模型、来自雅可比近似、还是来自采样过程。SJC 要补的正是这座桥。

三 · 为什么非改不可：偏差、方差与归因

“非改不可”不是审美诉求，而是三个具体的工程压力叠加的结果。第一是偏差不可控。SDS 的更新方向在噪声尺度较大时偏向于粗结构，在噪声尺度较小时偏向于纹理；这个尺度依赖的加权是人为设定的。当生成对象从单个物体扩展到多物体场景，或者从物体中心视角扩展到环绕视角时，同一组权重不再适用，而团队没有理论工具去推导新的权重，只能重新扫参。第二是方差不可分解。一次更新里同时混入了相机位姿采样、扩散模型内部的随机噪声、以及渲染器的离散化误差。SDS 把这些都塞进一个残差里，导致梯度的信噪比无法单独评估；工程上表现为训练曲线剧烈抖动，早停点靠肉眼判断。

第三是归因困难，这一点在系统层面代价最大。当一个资产生成失败——比如背面出现重复纹理、或者几何在某个视角下出现“双层壳”——团队需要判断：是 2D 先验在该视角下本身给出了错误得分，还是雅可比把图像空间的正确方向映射错了，还是采样器在退火过程中跳出了合理区域。SDS 的表述方式无法回答这个问题，因为它没有把“图像得分”和“提升算子”分开。SJC 的核心贡献之一，就是把这两个量显式分离：图像得分由冻结的 2D 扩散模型给出，提升算子由渲染雅可比给出，采样由退火 Langevin 完成。分离之后，每一段都可以单独诊断。

一个具体的场景可以说明这种压力的现实性。假设团队要把生成系统从“单物体、白背景、固定视角分布”扩展到“带地面接触的物体、任意环绕视角”。在 SDS 下，视角分布一变，残差的统计特性就变，原先的噪声尺度 schedule 和残差权重全部失效，表现为物体底部出现悬浮或穿透。团队无法从 SDS 的公式出发判断应该调整哪一项，只能把视角分布、噪声 schedule、权重一起做网格搜索。SJC 的写法则允许把期望显式地写成对相机位姿的积分，从而把“视角分布变化”定位为期望项的变化，而不是一个黑箱超参的变化。这正是“非改不可”的实质：不是为了更快的收敛，而是为了让系统在分布迁移时仍然可推理。

四 · 得分链的构造：从图像得分到 θ 得分

SJC 的构造从一句话开始：渲染图 x 是 3D 参数 θ 的函数，x = R(θ, c)，其中 c 是相机位姿等渲染条件。2D 扩散模型在加噪尺度 t 上给出图像空间的得分 ∇_x log p_t(x)。若把 p(θ) 理解为“由 2D 先验诱导的、在 θ 空间上的分布”，那么它对 θ 的得分可以通过链式法则写成图像得分与渲染雅可比的乘积，并对渲染条件取期望：

$$\nabla_\theta\log p(\theta)\approx\mathbb{E}_{c,\epsilon}\!\left[\nabla_x\log p_t(x)\,\frac{\partial x}{\partial\theta}\right]$$

这里 ∂x/∂θ 是渲染器对 3D 参数的雅可比，形状为（图像维度 × 参数维度）。这个式子的严格性来自两点：一是 x 对 θ 的可微依赖被显式写出，二是图像得分是扩散模型在对应噪声尺度上的合法得分。与 SDS 的差别在于，SDS 把噪声残差直接当作图像空间的更新方向并乘上人为权重，而 SJC 把“图像得分”与“雅可比”分开，前者由扩散模型定义，后者由渲染器定义，两者的乘积才是 θ 空间的得分估计。这也解释了为什么 SJC 能给 SDS 提供理论解释：SDS 可以被看作这个链式法则在特定加权和近似下的一个变体。

得到得分之后，采样使用退火 Langevin 动力学：

$$\theta\leftarrow\theta+\eta\nabla_\theta\log p(\theta)+\sqrt{2\eta}\,\xi$$

其中 η 是步长，ξ 是标准高斯噪声。Langevin 项的作用不是装饰：它让采样过程能够逃离得分估计的局部高估区域，而退火（随训练进程降低噪声尺度 t 与步长）则实现从粗到细的生成顺序。多尺度退火的具体机制是：先在较大的噪声尺度上采样，此时图像得分主要约束低频结构，雅可比反传后的 θ 更新幅度大、覆盖全局形状；随后逐步降低噪声尺度，得分转向高频细节，步长同步缩小，避免在细节阶段破坏已成型的大尺度结构。这个 schedule 是 SJC 的消融对象之一，说明它对最终质量有实质影响，而不是一个可以随意固定的常数。

系统代价在这里变得具体。雅可比 ∂x/∂θ 的维度是图像像素数乘以参数数，直接构造并存储不可行，因此实现上必须依赖自动微分逐样本反传，或者使用雅可比向量积的近似。这带来两个后果：一是每次更新的计算量随渲染分辨率和参数规模增长，二是雅可比近似本身引入误差，成为方差来源之一。论文把“雅可比近似”列为消融项，正说明这个环节不是免费的。另一个代价是期望项：对相机位姿和噪声取期望需要多次采样，单次更新的样本数直接决定梯度信噪比，而每个资产数小时的训练预算又限制了样本数不能无限增大。

五 · 一次更新的伪代码与失败模式

把上述机制写成伪代码，可以看清每一步的工程含义。外层是退火循环，内层是对渲染条件与噪声的采样循环：

  • 初始化 θ（NeRF 或网格参数），设定退火 schedule {t_k} 与步长 {η_k}。
  • 对每个退火阶段 k：采样一批相机位姿 c 与噪声 ε；由 θ 渲染得到 x = R(θ, c)。
  • 对每个样本，把 x 加噪到尺度 t_k，送入冻结的 2D 扩散模型，取得图像得分 ∇_x log p_t(x)。
  • 计算雅可比向量积：把图像得分经 ∂x/∂θ 反传，得到该样本对 θ 得分的贡献；对批内样本取平均，得到 ∇_θ log p(θ) 的估计。
  • 执行 Langevin 更新：θ ← θ + η_k ∇_θ log p(θ) + sqrt(2η_k) ξ。
  • 降低 t_k 与 η_k，进入下一阶段；直至最细尺度，输出 θ。

这条伪代码暴露了三个失败模式。其一是得分估计的方差：批内样本数不足时，相机位姿的离散采样使期望项估计抖动，Langevin 噪声又叠加进来，θ 会在合理区域附近随机游走而不收敛。其二是雅可比近似的偏差：当渲染器包含不可微或近似可微的操作（例如离散化的可见性判断、网格光栅化的梯度近似），∂x/∂θ 与真实导数不一致，图像空间的正确得分被映射成 θ 空间的错误方向，表现为几何出现本不该有的尖刺或空洞。其三是退火 schedule 与步长的不匹配：若在细节阶段步长仍然过大，Langevin 噪声会抹掉已成型的高频结构；若在粗阶段步长过小，则全局形状无法在有限步数内成型。论文把退火 schedule 列为消融项，正是因为这三者中它的调节最直接地改变最终资产的可辨认度。

一个具体例子可以把失败模式落到可观察的现象上。生成一个带细长结构的物体（例如带柄的杯子）时，粗阶段的大尺度得分会把整体体积推向“杯状”，但杯柄这种细结构在低分辨率渲染下几乎不贡献图像得分；进入细节阶段后，若雅可比近似在细结构处的梯度不可靠，得分链会把杯柄错误地拉向主体，形成粘连。工程上看到的不是“优化失败”，而是“柄消失了”。在 SDS 下，这类现象只能归因于“噪声 schedule 不对”；在 SJC 的分解下，可以分别检查：是图像得分在对应尺度上对柄不敏感，还是雅可比在柄处失真，还是退火在该尺度上停留过短。这正是把启发式变成可推导得分链的实际价值——它把一次失败拆成可分别验证的几个环节。

六 · 质量接近与理论更严之间的工程判断

论文给出的实验事实是克制的：没有 3D 训练集，基线是 DreamFusion 与 CLIP-guided，结果是能生成可辨认的 3D 物体，质量与 DreamFusion 接近；理论更严格，但速度与质量提升有限；消融覆盖退火 schedule、雅可比近似与得分模型选择。这组事实本身就构成一个工程判断的素材：SJC 不是一个以指标取胜的方案，它的收益在于可推导性与可归因性，代价是实现复杂与方差大。把这两面放在一起，才能理解为什么这篇论文在后续工作中被反复引用为 SDS 的理论解释，而不是被当作一个更强的生成器来复现。

从系统设计角度看，“质量接近”意味着在相同训练预算下，SJC 与 DreamFusion 的产出处于同一档；而“实现复杂、方差大”意味着同样的产出需要更多的工程投入去稳定。于是选择就变成一个明确的权衡：如果目标是快速拿到可用的 3D 资产，SDS 的简洁性有优势；如果目标是建立一个能在换模型、换渲染器、换视角分布时仍然可推理的系统，SJC 的得分链提供了 SDS 所没有的分段诊断能力。论文把“得分模型选择”也列为消融项，说明图像得分的来源（用哪个扩散模型、在哪个尺度上取分）会改变链路的统计特性，这进一步支持了“可归因”这一价值主张：链路中每一段都是可替换、可单独评估的。

需要强调的是，SJC 的局限不是可以忽略的边角。方差大意味着单次更新的信噪比低，工程上必须用批采样和退火来压制；实现复杂意味着雅可比与期望项的处理需要专门的自动微分管线，而不是几行调用。这些代价与它的理论收益是同一枚硬币的两面：正因为把图像得分与提升算子显式分开，才需要为这两段分别付出计算与实现成本。论文没有声称解决了 3D 生成的效率问题，它声称的是把“用 2D 得分做 3D”这件事从启发式提升为可推导的得分链。后续 VSD 的分布匹配思想与这条链同源，也说明这个重建动作的影响不在单次生成质量，而在后续方法能够站在一个被写清楚的估计量上继续改进。
