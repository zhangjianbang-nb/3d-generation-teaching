一 · 从形状张量到材质张量：两条并行的生成干线

Hunyuan3D 2.1 的整体数据流可以拆成两条干线：一条是形状干线，直接沿用 2.0 的形状 DiT（Diffusion Transformer），负责从输入图像推断几何；另一条是 PBR 材质干线，是本篇论文真正的增量所在。两条干线在 UV 空间汇合，最终由可微 PBR 渲染器把材质参数与几何一起渲染成图像，与真实多视图做比对。理解这个架构的关键，是不要把 PBR 分支当成“给网格上色”的后处理，它是一条与形状解耦、但在 UV 域与形状耦合的独立生成路径。

输入是一张（或少量）物体图像。形状 DiT 输出的不是网格本身，而是隐式几何表示，经等值面提取与网格化后得到带 UV 参数化的网格。这里的 UV 展开不是生成模型的输出，而是几何管线的产物，因此它天然携带失败风险：拓扑复杂、有孔洞、细长结构的物体在展开时会出现接缝错位、面片重叠、拉伸畸变。这些 UV 缺陷会直接传导到材质干线，成为后文所述失败模式的上游根源。

材质干线的输入是同一组输入图像，加上从形状管线继承的相机/视角假设。它输出的是多视图下的三通道 PBR 参数图：反照率 a、粗糙度 r、金属度 m。注意这三个通道在物理意义上并不对等：反照率是去光照的基色，粗糙度与金属度描述微表面与导体行为，它们对光照的响应方式完全不同。把三者塞进同一个扩散过程，是架构上的一个明确取舍，也是损失函数需要逐通道加权的原因。

$$\mathcal{L}_{\mathrm{PBR}}=\sum_{v}\left\|\hat{\mathbf{a}}_v-\mathbf{a}_v\right\|^2+\left\|\hat{r}_v-r_v\right\|^2+\left\|\hat{m}_v-m_v\right\|^2$$

这条逐视图、逐通道的 L2 损失看似朴素，但它定义了材质分支的监督信号形态：监督发生在视图空间而非 UV 空间。这一点很重要，因为视图空间的像素是“渲染可见”的，而 UV 空间存在大量不可见区域（被遮挡的背面、接缝附近），直接在 UV 上做监督会遇到大面积无标签区域。视图空间监督 + UV 空间补全，构成了这套方法的基本分工。

二 · 多视图 PBR 扩散：把三通道材质当作联合分布来采样

材质分支的核心是一个多视图扩散模型，它在给定输入图像条件下，联合生成多个视角的反照率、粗糙度、金属度图。所谓“联合”有两层含义：跨视角的联合（同一物体的不同视角必须材质一致，否则融合后会出现斑块），以及跨通道的联合（金属度高的区域其反照率往往偏暗、粗糙度与高光形态相关，三者存在物理相关性）。扩散过程在去噪时同时处理视角维与通道维，使模型能够学到这种相关性，而不是三个通道各自独立生成再拼接。

具体机制上，可以把去噪网络视为一个以输入图像为条件、以噪声化的多视图 PBR 张量为输入的 Transformer。条件注入通过交叉注意力完成，输入图像的特征作为 key/value，多视图 latent 作为 query。视角间的一致性靠注意力在视角维上的全局感受野保证：每个视角的去噪都“看得见”其他视角的当前状态，从而在采样早期就把跨视角的材质冲突抹平。这是一个隐式的多视图一致性约束，替代了显式的几何重投影一致性损失。

系统代价在这里第一次显现：多视图联合扩散的显存与计算量随视角数近似线性增长，而注意力在视角维上的全局连接使其实际开销高于线性。视角数增加会提升一致性与覆盖率，但推理时间随之上升，这与论文所述的“推理数十秒”直接相关。工程上的折中是固定一个较小的视角集合（覆盖正面与侧面），把背面交给 UV 补全阶段，而不是靠增加视角数硬扛。

一个具体例子：对一个金属质感的机械零件，输入单张正面图。多视图扩散需要生成侧面的反照率与金属度。如果通道独立生成，侧面金属度可能被预测为低值（因为侧面在输入图中不可见，模型缺少证据），融合后零件侧面会呈现塑料感。联合建模让金属度通道能借助反照率通道的暗色线索与视角间的一致性压力，把侧面金属度拉到与正面接近的水平。这正是“联合分布”而非“三通道拼接”的工程价值。

三 · UV 空间融合与补全：视图证据到纹理图的映射

多视图扩散产出的是视图空间的 PBR 图，必须映射回 UV 空间才能成为可被引擎采样的纹理。这一步是典型的反投影 + 融合：对每个视角，利用相机参数与网格几何，把视图像素反投影到 UV 坐标，得到该视角对 UV 图上每个 texel 的观测值；多个视角的观测在重叠区域做加权融合，权重通常与视角与表面法线的夹角、可见性、置信度相关。融合的本质是一个带可见性掩码的加权平均问题。

融合之后，UV 图上必然存在未被任何视角覆盖的区域：背面、凹陷内部、接缝附近、被自身遮挡的部分。这就是 UV 空间补全模块的任务。补全不是简单的插值，而是在 UV 域上运行一个修复/生成过程，利用已观测 texel 的材质统计与几何邻域信息，推断缺失区域的 PBR 值。补全的质量直接决定资产在任意视角下重光照时是否露馅：一个未被观测的背面如果粗糙度被填成常数，旋转到背面打光时高光形态就会与正面断裂。

这里的系统代价是 UV 展开失败的上游传导。若 UV 展开产生重叠面片，反投影时同一 texel 会收到来自不同表面点的观测，融合权重无法区分，结果是材质被“糊”在一起；若展开产生严重拉伸，texel 密度在拉伸区过低，补全模块在低分辨率区域只能给出粗糙的推断，贴图分辨率消融所揭示的正是这一维度。工程判断是：UV 质量是材质管线的前置条件，形状管线输出的 UV 若不可用，材质分支再强也无法补救，因此生产管线需要在网格化后加一道 UV 质量检查与重展开。

一个具体例子：一个带把手的杯子，把手内侧是典型的自遮挡区域，多视图扩散几乎不可能观测到。UV 融合后该区域为空，补全模块需要根据把手外侧的材质与杯身的材质连续性推断内侧。如果补全把内侧金属度填错，渲染时把手内侧会出现不自然的暗区或错误高光，进引擎后一眼可见。这说明补全不是“填满即可”，而是要维持物理通道的语义一致性。

四 · 光照解耦：让反照率真的成为反照率

PBR 材质生成最容易被忽视、却最决定成败的环节是光照解耦。输入图像里的像素是“反照率 × 光照”的乘积，若模型直接把输入像素当反照率监督，学到的反照率会烘焙进输入图的光照（阴影、高光、环境色），资产一旦换光照就会露出原图的影子。光照解耦训练的目标，是让反照率通道剥离输入光照，只保留材质本征颜色。

机制上，解耦依赖可微 PBR 渲染器构成闭环：模型预测 a、r、m，渲染器在给定光照下把三者与几何一起渲染成图像，与真实多视图比对，梯度回传同时修正三个通道。关键在于训练时的光照配置：若训练中光照固定，模型可以把光照“吸收”进反照率而不受惩罚；只有在训练中对光照做随机化（改变方向、强度、环境），渲染监督才会迫使反照率通道承担与光照无关的本征颜色，让粗糙度与金属度承担光照响应。这就是“光照解耦训练”的实质——它不是一条额外的损失项，而是通过光照随机化让渲染损失自然地把三个通道的职责分开。

公式上，渲染监督可以写成渲染图与真实图的差异，而 PBR 损失则约束预测通道与真值通道。两者并用：渲染损失提供物理正确的梯度（尤其在缺少通道真值的区域），通道损失提供直接的参数监督（在有 PBR 真值的数据上）。这种双监督结构解释了为什么论文强调“多视图 PBR 数据 + 渲染监督”——单靠通道真值数据覆盖不足，单靠渲染监督则通道语义可能漂移。

系统代价是数据限制。带完整 PBR 通道真值的数据远少于普通图像或基础色纹理数据，光照解耦的质量受限于 PBR 真值数据的多样性与光照配置的覆盖度。若训练光照分布与目标引擎的光照模型不匹配，解耦出的反照率在目标引擎里仍会偏色。这是定性层面的已知局限，也是“PBR 真实感受数据限制”的具体含义。

一个具体例子：输入图是一张在暖色室内光下拍摄的白色塑料件。若不做解耦，反照率会带暖黄偏色，进引擎后在冷色天光下渲染会明显偏黄。光照解耦训练通过随机化光照，让渲染损失惩罚这种偏色，把反照率拉回中性白，粗糙度则学到塑料的宽高光。重光照表现优于基础色模型，正是这一机制的直接结果。

五 · 可微 PBR 渲染：闭环的最后一环与它的开销

可微 PBR 渲染器在架构中扮演双重角色：训练时它是监督闭环的一部分，把材质参数与几何渲染成图像供损失比对；推理时它（或其非可微版本）是把生成的 PBR 纹理与网格合成最终可视资产的出口。渲染器的物理正确性决定了监督信号的质量：若渲染器的 BRDF 模型、阴影、环境光近似与真实数据不一致，梯度就会把模型往错误的方向推。

从数据流看，完整链路是：输入图像 → 形状 DiT → 隐式几何 → 网格化 + UV 展开 → 多视图 PBR 扩散（条件于输入图像）→ 视图空间 PBR 图 → 反投影融合 → UV 空间 PBR 纹理 → 补全 → 可微 PBR 渲染（训练时闭环，推理时输出）。每一步都有明确的输入输出契约，工程上可以把这条链路拆成可独立测试的模块：形状质量、UV 质量、视图一致性、融合覆盖率、补全语义、渲染一致性，各自有对应的失败模式。

推理开销集中在两处：多视图扩散的采样步数与视角数，以及 UV 补全的 UV 域生成。论文给出的“推理数十秒”是这两部分叠加的结果，而非单一模块的耗时。工程上压缩推理时间的抓手也在这两处：减少采样步数（以一致性为代价）、减少视角数（以覆盖率为代价，把负担转移给补全）、降低贴图分辨率（以细节为代价，正是贴图分辨率消融所覆盖的维度）。这三者构成一个明确的三角权衡，而不是可以同时优化的独立参数。

一个具体例子：把同一资产分别以高、低贴图分辨率生成，低分辨率下粗糙度的空间变化被抹平，金属件表面的拉丝感消失，重光照时高光变成一整片；高分辨率下细节保留但 UV 补全在低 texel 密度区域的推断更不稳定。这说明分辨率不只是“清晰度”问题，它改变了补全模块可用的信息量，进而改变物理通道的语义保真度。

把这条链路放回生产管线看，Hunyuan3D 2.1 的工程判断是清晰的：形状沿用 2.0 意味着几何质量的上限由既有形状模型决定，材质分支的增量价值在于把“有颜色”推进到“有 PBR 通道且可重光照”。这条链路的瓶颈不在扩散模型的表达能力，而在 UV 展开的可靠性、PBR 真值数据的覆盖度、以及推理开销与视角/分辨率之间的三角权衡。任何一处失守，都会以“进引擎后光照不对”的形式在最终资产上暴露，而不是在生成阶段被掩盖。
