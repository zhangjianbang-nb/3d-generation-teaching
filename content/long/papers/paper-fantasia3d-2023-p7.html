一 · 对比坐标：三条技术路线与一个共同约束

把 Fantasia3D 放进同期与后继方法的坐标系里，先要明确比较的维度不是「谁生成的图更好看」，而是「谁在哪个约束下把哪一类错误压得更低」。同期基线 DreamFusion、Magic3D、TextMesh 与后继的 SF3D、Hunyuan3D 2.x 分属三条路线：单辐射场联合优化（DreamFusion、Magic3D 的粗阶段）、显式网格加可微渲染（TextMesh、Fantasia3D 的几何阶段）、以及前馈式形状-材质分解（SF3D、Hunyuan3D 2.x）。三条路线共享同一个约束：监督信号只有 2D 扩散先验，没有任何 3D 真值。这个约束决定了所有方法的失败模式都带有「2D 先验看不到的地方就没人管」的家族相似性，但各自把错误推向不同的位置。

Fantasia3D 的定位必须从「它把什么从什么里拆出来」来读。DreamFusion 与 Magic3D 粗阶段把密度与颜色放进同一个辐射场，SDS 梯度同时作用于两者，于是颜色梯度会沿着密度梯度方向渗入几何——表面为了迎合 2D 纹理观感而产生虚假凹凸，这就是「纹理长进几何」。Fantasia3D 把优化切成两段：几何阶段只让法线图进扩散模型，外观阶段冻结网格只优化材质参数。这个切分的代价是两阶段之间不可回退：几何阶段一旦收敛，外观阶段无法通过纹理梯度反向修正形状。对比时这一点必须单独列出，因为它是 Fantasia3D 与所有联合优化方法的根本分歧点。

对比的第二个坐标是表示。DreamFusion 用 NeRF 式 MLP 辐射场，分辨率隐式且连续，但渲染慢、提取网格需要 marching cubes 且表面质量受密度阈值影响。Magic3D 用两阶段：粗阶段 NeRF，细阶段带稀疏体素的神经场，速度提升来自粗到细的稀疏化。TextMesh 直接用网格加可微光栅化，几何是显式的，但没有材质分解，颜色直接烘在顶点或纹理上。Fantasia3D 选 DMTet——一种可微的混合表示，把符号距离场与三角网格绑定，允许梯度通过顶点位移回传。DMTet 的好处是几何阶段就能拿到显式网格并渲染法线图，坏处是分辨率被网格细化层级锁死，这是它相对 NeRF 类方法的硬上限。

第三个坐标是监督信号的条件化方式。DreamFusion 用无条件图像扩散的 SDS，分数函数只见过 RGB 图，不知道法线是什么，所以几何梯度是从「这张渲染图不像文本描述的图」反推出来的，间接且噪声大。Fantasia3D 几何阶段改用法线条件扩散模型：把渲染出的法线图作为条件输入，扩散模型在「已知法线」的条件下评估图像似然，SDS 梯度因此直接对准法线图的合理性，而不是绕道 RGB。这是它几何更干净的直接机制来源。代价是必须有一个法线条件扩散模型可用，且该模型的法线先验分布与 DMTet 渲染出的法线统计必须匹配，否则条件化本身会引入偏置。

$$\mathcal{L}_{\mathrm{geo}}=\mathcal{L}_{\mathrm{SDS}}(\hat{n},y),\qquad \mathcal{L}_{\mathrm{app}}=\mathcal{L}_{\mathrm{SDS}}(\mathrm{PBR}(\mathbf{a},r,m,\hat{n}),y)$$

上式两个式子并列，恰好标出对比的核心：几何阶段的输入是法线图，外观阶段的输入是 PBR 渲染结果。任何对比方法只要把这两项塞进同一个损失、同一个可优化变量集合，就会重新引入耦合。判断一个后继方法是否真的继承了 Fantasia3D 的思想，标准就是看它是否在优化过程中保持「几何变量与材质变量不同时受同一个 RGB SDS 梯度支配」。

二 · 逐项对比：表示、监督、速度、显存

先看表示维度。DreamFusion 的 NeRF 表示在几何阶段没有显式表面，提取网格是后处理，表面平滑度取决于密度场等值面，容易出现「云雾状」厚度。Magic3D 细阶段用稀疏体素网格加神经特征，分辨率可调但显存随体素数量线性增长。TextMesh 的网格表示最轻，但顶点颜色或纹理图没有物理含义，无法重光照。Fantasia3D 的 DMTet 在几何阶段就产出可微网格，顶点位移与面细分都参与梯度，显存开销集中在网格细化层级与法线渲染的栅格化缓冲上，而不是体素网格。对比结论是：论几何的显式性与可编辑性，DMTet 优于 NeRF 类；论分辨率上限，DMTet 受细化层级限制，不如稀疏体素可调。

监督维度要分开看几何监督与外观监督。几何监督上，DreamFusion 是无条件 RGB SDS，Magic3D 粗阶段同样，TextMesh 也是 RGB SDS 加少量正则。Fantasia3D 是唯一在几何阶段引入法线条件扩散的。外观监督上，DreamFusion 与 TextMesh 的颜色就是辐射场输出或顶点色，没有反照率、粗糙度、金属度的物理分解；Magic3D 细阶段仍以 RGB 为主。Fantasia3D 外观阶段用 MLP 输出反照率 a、粗糙度 r、金属度 m，经可微 PBR 渲染器合成 RGB 再算 SDS，并加材质正则。这意味着它的外观监督是「物理参数 → 渲染 → 2D 先验」的链式反传，梯度要穿过 PBR 渲染器才能到达材质 MLP。链越长，梯度越容易被渲染器的非线性（尤其是高光项与菲涅尔项）扭曲，这是它材质真实感受限的机制根源。

速度维度不能只看单步耗时，要看「达到可接受质量所需的总优化时间」。DreamFusion 的 NeRF 每步要大量射线采样，单步慢但步数需求相对固定；Magic3D 用粗到细把大部分步数花在低分辨率粗阶段，细阶段步数少，整体比 DreamFusion 快，这是它宣称的速度优势来源。TextMesh 光栅化快，但网格拓扑在优化中频繁变化，重网格化开销不可忽略。Fantasia3D 是两阶段串行：几何阶段要跑完 DMTet 细化与法线 SDS，外观阶段再从零优化材质 MLP，两段相加是数小时量级。串行结构意味着它没有 Magic3D 那种「粗阶段快速收敛」的加速路径，速度上不占优。对比时要诚实：Fantasia3D 的速度代价是解耦换来的，不是实现缺陷。

显存维度上，DMTet 的显存峰值出现在网格细化与法线图渲染同时驻留时：细化层级越高，顶点与面缓冲越大，栅格化需要保存每个像素的法线与深度用于反传。外观阶段的显存主要被 PBR 渲染的多通道缓冲（反照率、粗糙度、金属度、法线、深度）与材质 MLP 的激活占据。相比之下，NeRF 类方法的显存随射线采样数与网络宽度增长，稀疏体素方法随体素网格分辨率立方增长。Fantasia3D 的显存曲线在几何阶段随网格分辨率近似线性（面数），在外观阶段随渲染分辨率平方增长，两个阶段的峰值不叠加，这是串行结构的一个隐性好处：峰值显存是两阶段的最大值而非总和。

三 · 失败模式对照：错误被推到哪一层

对比方法的价值一半在成功案例，一半在失败模式的位置。DreamFusion 的典型失败是「多面视图」：从不同角度看同一物体，几何与纹理不一致，因为无条件 RGB SDS 没有跨视图的几何约束，模型用纹理欺骗单视图评分。Magic3D 的粗到细流程缓解了这一点，但细阶段仍可能把高频纹理烘进几何细节。TextMesh 的失败是拓扑病态：网格在优化中自交、出现非流形边，因为没有几何先验约束拓扑演化。

Fantasia3D 把错误推到了两个新位置。第一是几何阶段的法线条件偏置：如果法线条件扩散模型对「合理法线」的先验偏向平滑，几何阶段会过度平滑掉真实细节；如果偏向高频，则会生成不存在的凹凸。这个偏置无法在外观阶段修正，因为几何已冻结。第二是外观阶段的材质-光照歧义：PBR 渲染中反照率与光照是乘积关系，2D 扩散先验只看到最终 RGB，无法区分「暗反照率 + 强光」与「亮反照率 + 弱光」，材质 MLP 会收敛到其中一个任意解。这是所有 PBR 分解方法的共同病，Fantasia3D 用材质正则缓解但没有消除。对比之下，DreamFusion 根本没有材质变量，也就没有这个歧义，但它用耦合换来了另一个病——纹理长进几何。两种病没有优劣，只有工程上你更能接受哪一种。

后继方法的失败模式又不同。SF3D 走前馈路线，一次前向出形状与 PBR 材质，失败模式是泛化边界：训练分布外的物体类别会崩，且前馈没有每资产优化的迭代修正机会。Hunyuan3D 2.x 用形状 DiT 与材质 DiT 双流，失败模式是两流之间的对齐：形状流生成的法线与材质流假设的法线不一致时，渲染会出现光照错位。这两个后继都把 Fantasia3D 的「解耦」继承下来，但把「每资产优化」换成了「前馈生成」，于是错误位置从「优化过程的局部极小」搬到了「模型分布的覆盖盲区」。这是解耦思想在不同生成范式下的必然位移。

举一个具体例子说明失败模式的工程后果。假设目标是一个金属质感的机械零件。DreamFusion 类方法会把高光当成几何凹凸来生成，因为无条件 SDS 看到「亮斑」就推动密度变化，结果表面出现假的棱线，拿去重光照立刻暴露。Fantasia3D 的几何阶段只看法线，金属高光不进几何梯度，几何保持干净；但外观阶段的反照率-金属度歧义会让它把金属度推到极端值以拟合高光，换一个 HDRI 环境后高光位置全错。SF3D 前馈若训练集缺少这类零件，形状流直接生成一个圆润的近似体，材质流再贴上金属参数，几何与材质各自「合理」但拼在一起不对。三种失败对应三个不同的修复动作：调几何监督、调材质正则、扩训练分布。决策表要能区分这三种修复成本。

四 · 决策表：按约束选方法

决策表不是「哪个方法最好」的排名，而是「在你的约束下哪个失败模式最可修」。表的行是工程约束，列是方法族，单元格填该约束下的判断。约束包括：是否需要重光照、是否有 3D 训练数据可用来做前馈、单资产时间预算是多少、显存上限、以及目标物体是否在常见类别分布内。

读表的关键是两列不能同时满足的行。第一行「需要重光照」与第二行「无 3D 训练数据」交叉后，只剩 Fantasia3D 一个格子同时打勾：它不需要训练集，又能出物理材质。这就是它在 2023 年这个时间点的不可替代性——不是它质量最高，而是它是当时唯一同时满足这两个约束的路线。SF3D/Hunyuan3D 2.x 族在重光照上更强（前馈、快），但一旦没有训练数据就整列失效。DreamFusion 族在无训练数据上可用，但重光照整列不可用。TextMesh 两列都不满足。

决策表还要标注修复成本。若选了 Fantasia3D 且遇到材质歧义，修复动作是加材质正则或换更强的 PBR 先验，成本中等，因为几何已冻结不用重跑几何阶段。若选了 DreamFusion 族且遇到纹理长进几何，修复动作是换表示或加几何正则，成本高，因为耦合优化没有干净的切入点。若选了前馈族且遇到长尾崩，修复动作是扩训练集或加每资产微调，成本最高，因为要重新训练或引入优化回路。工程判断的顺序应该是：先确定重光照与数据两个硬约束筛掉整列，再在剩下的格子里按修复成本排序。

还有一个隐性维度是「验收断言的可写性」。Fantasia3D 的两阶段结构让验收可以分段：几何阶段结束后检查法线图的平滑度与网格流形性，外观阶段结束后在固定 HDRI 下检查高光位置与反照率一致性。DreamFusion 族没有中间检查点，只能看最终渲染。前馈族没有优化过程，只能看输出。可分段验收意味着 Fantasia3D 的失败可以在阶段边界被截住，不必等数小时跑完才发现几何已经错了。这是解耦在工程可观测性上的额外收益，决策表里不显式列，但影响实际落地时的调试成本。

五 · 解耦的代价结构与后继的位移

把对比收束到机制层面：Fantasia3D 相对同期方法的全部差异，可以归到一个代价结构——它用「两阶段不可回退」换「几何与材质变量不同时受 RGB SDS 支配」。这个交换的收益是几何干净、材质可重光照；代价是几何阶段的法线条件偏置无法被外观阶段修正，外观阶段的材质歧义无法被几何阶段约束。同期方法没有这个代价结构，因为它们根本不做这个交换，代价以另一种形式存在（纹理长进几何、拓扑病态）。所以对比的结论不是「Fantasia3D 更好」，而是「它把错误从不可修复的位置搬到了可分段修复的位置」。

后继方法的位移验证了这个判断。SF3D 与 Hunyuan3D 2.x 继承了「形状与材质分开」的变量划分，但把优化回路换成前馈网络。变量划分保留，代价结构就保留了一半：材质歧义仍在（前馈也要从 2D 数据学反照率-光照分解），但「两阶段不可回退」消失了，因为前馈没有阶段。取而代之的新代价是分布覆盖：前馈把「每资产优化能逃出的局部极小」变成了「训练分布没覆盖就生成不出」。这是解耦思想从前馈化中必然付出的代价，也是为什么在长尾类别上，每资产优化的 Fantasia3D 仍然比前馈族更稳——它的失败是局部极小，不是分布盲区，前者可以用更多步数或重启缓解，后者只能靠数据。

工程上落地这一部分对比的最后一个判断是：不要把 Fantasia3D 当成「质量上限」来对标后继方法。它的角色是「约束满足器」——在无 3D 训练集且需要重光照的约束下，它是当时唯一可行的路线。一旦你的场景允许前馈（有训练数据、目标在分布内、要秒级出资产），SF3D/Hunyuan3D 2.x 族在速度和规模上全面占优，此时 Fantasia3D 的两阶段串行与数小时优化就是纯成本。决策的分界线不在方法的新旧，而在「你是否愿意用每资产数小时换分布外的稳健性」。这个判断落到具体机制上，就是看你的资产类别是否落在前馈训练分布内：在分布内，前馈的形状-材质双流对齐误差小于 Fantasia3D 的法线条件偏置；在分布外，前馈直接失效，而 Fantasia3D 的法线 SDS 仍能靠 2D 先验逐资产收敛，只是慢。
