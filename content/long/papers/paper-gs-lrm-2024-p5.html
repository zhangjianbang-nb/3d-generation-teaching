一 · 失效条件：稀疏视图下的几何欠定与高斯漂移

GS-LRM 的前向映射在输入视图数降到 2 时最先暴露问题。机制上，Transformer 把 K 张图的 patch token 与相机嵌入拼成一个序列，解码出 N 个高斯的均值 μ、协方差 Σ、不透明度 α 与球谐颜色 c。问题在于，2 张视图只提供两条视线方向的深度约束，场景中大量表面在两条视锥之外没有任何观测，模型只能依赖在 Objaverse 多视图数据上习得的先验去“补”这些区域。补出来的高斯不是几何上被约束的解，而是数据分布下的条件期望：同一组输入图，轻微改变相机嵌入的数值精度，解码出的 μ 会在无观测区域成片漂移，Σ 随之被拉长成薄片状，光栅化时表现为视角相关的“鬼影”或边缘毛刺。

这个失效可以用一个简单的观测计数来刻画。对场景中任一空间点 x，记它在 K 张输入视图中的可见视图数为 V(x)。当 V(x)=0 时，该点的深度完全由先验决定；当 V(x)=1 时，深度只被一条射线约束，沿射线方向的自由度不可观。可微光栅化的渲染损失只在被观测的像素上产生梯度，因此这些区域的梯度信号为零，参数只能靠 Transformer 的隐式正则维持。写成梯度视角：

$$\frac{\partial \mathcal{L}}{\partial \mu_i}=\sum_{k=1}^{K}\sum_{p\in \mathrm{Vis}(i,k)}\frac{\partial \mathcal{L}}{\partial \pi_k(\mu_i)}\frac{\partial \pi_k(\mu_i)}{\partial \mu_i}$$

其中 Vis(i,k) 表示高斯 i 在第 k 张视图中的可见像素集合。若该集合为空，则高斯 i 的均值梯度恒为零，训练时它只受其他损失项（如不透明度正则、邻居高斯的相互遮挡）间接影响。这就是稀疏视图不稳的数学根源，不是调参能消除的，只能靠增加输入视图或引入几何先验来缓解。

具体例子：一个仅有正面与背面两张图的物体，其侧面轮廓在两张图中都只以极薄的边缘出现。模型会在侧面生成一层朝向相机、法线方向随机的薄高斯，渲染正面与背面时看不出问题，但绕到 45° 视角时这层高斯会同时向两侧投影，产生半透明的重影。验收时若只比对输入视图的重建误差，这个缺陷完全不会被发现；必须在新视角上做环拍采样才能暴露。

二 · 显存墙：高斯数量与光栅化的二次代价

GS-LRM 的第二个硬边界是显存。前向一次输出 N 个高斯，每个高斯携带 3 个均值分量、协方差（通常存四元数加三轴缩放，7 个分量）、1 个不透明度、球谐颜色（三阶球谐为 16 系数 × 3 通道 = 48 个分量），合计约 59 个浮点数。N 取数万量级时，单次前向的高斯参数张量本身就在数十 MB 到百 MB 量级；训练时还要保留可微光栅化中间量：每个高斯的屏幕空间投影、每个 tile 的深度排序索引、每个像素的混合权重。光栅化的排序步骤对每张视图的每个 tile 维护高斯列表，其规模随 N 与视图分辨率乘积增长。

代价的结构可以用一个粗略的显存分解表示：

$$M \approx \underbrace{N\cdot d_g}_{\text{高斯参数}}+\underbrace{K\cdot N\cdot d_p}_{\text{投影缓存}}+\underbrace{K\cdot T\cdot \bar{n}_t\cdot d_s}_{\text{tile 排序}}$$

其中 d_g 为每高斯参数字节数，d_p 为投影缓存每高斯字节数，T 为 tile 数，n̄_t 为每 tile 平均高斯数，d_s 为排序索引字节数。第二项与 K 成正比，第三项与 N 和分辨率都成正比。这解释了为什么论文把“高斯数限制”列为局限：不是模型不能输出更多高斯，而是训练时的可微光栅化缓存随 N 线性膨胀，单卡放不下。工程上常见的做法是分块渲染或降低训练分辨率，但这会改变梯度尺度，需要同步调整学习率与损失权重。

失败模式很具体：当 N 提高到超出显存时，框架不会优雅降级，而是触发重计算或分块，导致每步训练时间陡增，或者在排序阶段因 tile 内高斯数超过预设上限而截断，截断掉的高斯收不到梯度，表现为局部区域细节在训练后期突然“冻结”。复现时应把 N 当作一等超参，先在目标显存下测出可承受的 N 上限，再固定它去调 Transformer 规模，而不是反过来。

例子：在 24GB 卡上以 512×512 分辨率、4 视图训练时，若 N 设为数万，投影缓存与排序索引会占据相当比例的显存，留给 Transformer 激活值的余量被压缩，只能减小 batch 或层宽。这与“Transformer 规模”消融的结论一致：高斯数与模型容量是竞争关系，不是各自独立可调的旋钮。

三 · 被谁继承：前馈输出头范式的扩散与替代路径

GS-LRM 的核心遗产不是某个具体网络结构，而是把 3DGS 当作前馈输出头这一范式。它证明了一件事：三平面中间表示不是必需的，Transformer 可以直接回归显式高斯的参数，并用可微光栅化端到端监督。后续工作如 LGM 延续了这条路线，把输出头换成更易并行的表示（如多视图特征加轻量解码），在保持前馈一次推理的同时降低显存压力。这说明 GS-LRM 的边界恰恰是它被继承时被修改的部分：继承的是“前馈 + 实时渲染”的接口契约，被替换的是高斯参数的直接回归与光栅化监督的具体实现。

替代路径主要有三类。第一类是把高斯输出改为分块或分层输出，先预测粗粒度高斯再局部细化，以缓解 N 的显存线性增长；第二类是用多视图特征图作为中间量，渲染时再转高斯，牺牲一部分显式性换取显存；第三类是保留三平面但用高斯做后处理提取，回到 LRM 的路线做折中。这三类都在不同程度上承认了 GS-LRM 暴露的两个问题：高斯显存与稀疏视图几何。判断一个后续工作是否真正继承了 GS-LRM，看它是否满足同一接口：输入 2–4 张图与相机参数，一次前向，输出可实时光栅化的显式表示，且训练信号来自渲染损失而非 3D 真值。只满足前两条而用真值监督的，不属于这条脉络。

工程判断上要注意：GS-LRM 的“优于 LRM 体渲染”结论依赖于实时渲染这一目标。若下游任务需要提取水密网格或做物理仿真，显式高斯反而比三平面更难转成网格，此时照搬 GS-LRM 的输出头是错误选择。它的适用边界是“新视角合成与实时渲染”，越出这个边界，三平面或隐式场的优势会重新出现。

四 · 复现清单：从数据到光栅化的可执行步骤

复现 GS-LRM 时，以下清单按依赖顺序排列，每项都对应一个可验证的中间产物，避免一次性堆完再调试。

  • 数据管线：Objaverse 多视图采样，固定每物体视图数与相机分布，输出图像、相机内外参、物体归一化变换。验收断言：随机抽一个物体，把相机参数重投影到图像，特征点残差应在像素级可接受范围内。
  • Token 化：多视图 patch 化，patch 尺寸与 Transformer 序列长度匹配；相机嵌入与 patch token 拼接方式固定。验收断言：序列长度与视图数 K 呈线性关系，改变 K 时位置编码不冲突。
  • 输出头：N 个高斯的均值、协方差参数化（四元数 + 缩放，保证 Σ 半正定）、不透明度经 sigmoid、球谐颜色截断到合理阶数。验收断言：随机初始化下 Σ 的特征值全为正，α 落在 (0,1)。
  • 可微光栅化：投影、tile 分桶、深度排序、α 混合，梯度可回传至 μ、Σ、α、c。验收断言：单高斯单像素场景下，渲染值与解析计算一致，梯度与数值差分误差在容差内。
  • 损失：MSE + LPIPS，渲染损失作用在输入视图与额外采样视图上。验收断言：固定输入，只优化高斯参数（冻结 Transformer）时损失单调下降。
  • 训练配方：数天量级，学习率与 batch 随 N 与分辨率联动调整。验收断言：训练中期 N 不被截断，排序阶段无高斯被静默丢弃。

清单里最容易漏的是第三条的协方差参数化。若直接回归 Σ 的六个分量而不加半正定约束，训练早期会出现负特征值，光栅化时投影椭圆面积为负，渲染出 NaN 并污染整条梯度链。正确做法是回归四元数与三轴缩放再合成 Σ，这也是 3DGS 原始实现的约定，照搬它比自创参数化更稳。

五 · 验收断言：区分“能跑”与“可信”

复现完成后，仅看训练损失下降不足以判定成功。以下断言按可信度从低到高排列，每条都针对一个已知失效模式。

断言检查对象针对的失效
输入视图重渲染误差低于阈值输入 K 张图输出头与光栅化链路是否打通
环拍新视角无成片重影输入视锥外区域稀疏视图几何欠定
N 提高一倍时显存线性增长且无截断光栅化缓存高斯数限制与静默丢弃
冻结 Transformer 仅优化高斯时损失可降输出头梯度梯度断链或参数化错误
改变相机嵌入精度后 μ 漂移有界无观测区域高斯先验主导的几何不稳

第二条断言最容易被跳过，因为环拍采样需要额外渲染开销。但它恰恰是 GS-LRM 边界所在：输入视图误差低只说明模型拟合了观测，不说明它补出的几何可信。工程上应把环拍采样做成固定验收脚本，对每个测试物体在输入视锥外均匀取视角，统计重影像素比例，超过阈值即判定该物体不可用。这与论文把“稀疏视图不稳”列为局限的定性结论一致，不需要编造具体数字也能执行。

第三条断言针对显存墙。做法是把 N 从基准值翻倍，观察显存是否近似线性增长、训练步时间是否突变、排序阶段是否有高斯被截断。若出现截断，说明 tile 内高斯上限设置过紧，需要调大上限或降低分辨率，而不是简单减小 N——减小 N 会直接损失细节，与“高斯数限制”这一局限的工程含义相悖。

六 · 哪里不能照搬：三条明确的移植禁区

第一条禁区是把 GS-LRM 的输出头直接接到需要水密网格的下游。高斯是显式但非流形的点集表示，转网格需要额外的泊松重建或 TSDF 融合，且稀疏视图补出的薄片高斯会让重建出现孔洞与悬浮面。若下游是碰撞检测或流体仿真，应回到三平面或隐式场路线，GS-LRM 的实时渲染优势在此处不构成收益。

第二条禁区是在视图数少于 2 或相机参数不可靠时照搬。GS-LRM 的输入契约是 2–4 张图加相机嵌入，相机外参误差会直接进入 token 序列，模型没有机制去校正它。把 COLMAP 估计的含噪位姿直接喂入，等价于在无观测区域注入错误的视线约束，高斯漂移会比稀疏视图本身更严重。移植前必须先做位姿质量门控，位姿残差超阈值的样本应剔除而非硬训。

第三条禁区是把“一次前向出高斯”误解为“无需任何优化”。GS-LRM 的前向是快速的，但训练是数天量级，且对 N、分辨率、Transformer 规模三者联动敏感。把预训练模型迁移到新数据分布时，若只做推理不做微调，输出头的球谐颜色与不透明度会偏向训练分布，新分布下的曝光或材质差异会表现为整体色偏与过曝。此时需要至少对输出头做轻量微调，冻结编码器，用渲染损失对齐新分布——这与“冻结 Transformer 仅优化高斯时损失可降”的验收断言是同一机制的正向使用。

最后落在工程判断上：GS-LRM 的可移植边界由它的监督信号定义——渲染损失只约束被观测像素，因此任何依赖无观测区域几何正确性的下游任务都不能照搬。复现时把环拍重影比例作为一等验收指标，把 N 与显存的线性关系作为训练前的硬约束，比追求输入视图误差的更低数值更能反映系统是否真正可用。
