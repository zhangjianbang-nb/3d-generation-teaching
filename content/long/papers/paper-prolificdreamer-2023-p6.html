一 · 目录骨架与最小可跑闭环

复现 ProlificDreamer 的第一步不是抄超参，而是把代码切成四个职责互不重叠的层，否则 VSD 的“双更新”会在实现里退化成互相污染的全局状态。推荐的目录结构如下：顶层 configs/ 存放每阶段的 YAML（NeRF 阶段、网格精修阶段各一份，字段名与论文变量一一对应）；representations/ 放 NeRF 与可微网格两套 3D 表示，二者共享同一个 render(camera) -> image 接口；particles/ 放粒子 LoRA 的构建、注入与去噪训练逻辑；distill/ 放 VSD 梯度计算与 3D 参数更新；stages/ 放多阶段调度器；eval/ 放验收断言脚本。关键约束是：粒子 LoRA 的参数必须与 3D 参数分属两个独立的优化器，且粒子模型的权重在每个训练步内先被冻结用于计算 VSD 梯度、再被解冻用于自身的去噪训练——顺序反了，梯度里就会出现“粒子跟着 3D 一起动”的污染项。

最小可跑版本应只保留一条路径：单条文本提示、单卡、NeRF 阶段、粒子数取小值、LoRA rank 取小值、关闭网格精修。它的目的是验证梯度符号与数据流正确，而不是产出可用资产。伪代码思路如下：

$$\begin{aligned} &\text{for step in }1..N:\\ &\quad x = \mathrm{render}(\theta, c)\ \text{// 可微渲染，c 为随机相机}\\ &\quad t \sim \mathcal{U}(0,T),\ \epsilon \sim \mathcal{N}(0,I)\\ &\quad x_t = \alpha_t x + \sigma_t \epsilon\\ &\quad g_\theta = w(t)\,(\epsilon_\phi(x_t;y,t) - \epsilon_\psi(x_t;c,t))\,\partial x/\partial\theta\\ &\quad \theta \leftarrow \theta - \eta_\theta g_\theta\\ &\quad \mathcal{L}_\psi = \|\epsilon_\psi(x_t;c,t) - \epsilon\|^2,\ \psi \leftarrow \psi - \eta_\psi \nabla_\psi \mathcal{L}_\psi \end{aligned}$$

注意第二行渲染出的 x 必须带梯度回传到 θ，而 ε_ψ 分支在第一步计算时对 ψ 是 detach 的。这是最常见的实现错误：把粒子去噪损失和 VSD 梯度写在同一个 loss.backward() 里，结果 3D 参数收到了粒子模型的梯度，粒子模型也收到了渲染图的梯度，训练在几百步内发散。系统代价上，这条最小路径已经需要同时驻留冻结的 Stable Diffusion、一份 LoRA 副本和 NeRF 网络，显存占用由“主模型 + 粒子 + 渲染分辨率”三者共同决定，单卡上把渲染分辨率与粒子数同时调大是最容易触发 OOM 的组合。

二 · 数据准备：没有 3D 训练集时的输入构造

论文的设定是“无 3D 训练集”，这意味着复现时不存在 train/ 目录，所有监督信号来自冻结的文本条件扩散模型。数据准备实际要做的是三件事：文本提示的规范化、相机采样器的构造、以及渲染分辨率与批次的排布。文本提示需要固定一个模板（例如把主体描述与风格描述拼成单句），因为 VSD 的文本条件 y 同时进入先验得分与粒子得分，模板不一致会让两个得分项在语义上错位，表现为几何正确但纹理漂移。

相机采样器是容易被低估的模块。NeRF 阶段需要一个覆盖上半球、带仰角约束的随机相机分布，网格阶段需要更贴近真实观察的相机轨迹；两阶段若共用同一采样器，网格精修会因视角分布突变而出现表面法线的翻转伪影。具体机制上，相机位姿应作为 render 的显式输入而非全局随机状态，否则多阶段切换时无法复现同一视角下的对比。一个具体例子：把仰角范围从接近水平放宽到接近俯视，NeRF 阶段的密度场会在顶部堆积，进入网格阶段后这些密度被提取成悬浮碎片——这不是超参问题，而是相机分布与 3D 表示不匹配。

渲染分辨率决定了 VSD 梯度里 ∂x/∂θ 的噪声水平。分辨率过低时，先验得分与粒子得分的差值被量化误差淹没，梯度方向随机；分辨率过高时，单步渲染成为瓶颈，粒子 LoRA 的去噪训练无法在同一批次内完成足够多的更新。工程上的做法是把分辨率与粒子数做成联动配置项，而不是各自独立调。数据准备的验收断言应包含：同一提示下连续两次采样相机得到的渲染图在固定种子下可复现；文本条件张量的形状与扩散模型的 cross-attention 期望一致；渲染图的值域与扩散模型输入归一化匹配（这一条错了，先验得分会系统性偏移，表现为整体过饱和或过暗）。

三 · 超参分层：哪些必须对齐论文，哪些必须自调

ProlificDreamer 的超参多，复现时要把它们分成三层，避免把“论文没给”的项当成可随意填的空。第一层是语义性超参，必须与论文设定一致：VSD 梯度中的 w(t) 加权形式、粒子得分的条件输入 c 与先验条件 y 的区分、以及“3D 参数被视为分布”这一设定所要求的粒子数大于一。粒子数取一，VSD 就退化为 SDS，这是复现时最隐蔽的降级——代码能跑、loss 能降，但多样性与真实感全部丢失。第二层是结构性超参，需要按硬件自调：LoRA rank、粒子数、每步粒子去噪的更新次数、渲染分辨率与批大小。第三层是优化器超参：3D 参数与粒子模型的学习率必须分开设置，粒子模型的学习率通常需要显著高于 3D 参数，否则粒子得分跟不上 3D 分布的移动，梯度里出现滞后项。

超参归属层失配时的典型症状
粒子数语义层取一即退化为 SDS，多样性消失
LoRA rank结构层过小则粒子得分欠拟合，纹理粘连；过大则显存与时间陡增
粒子学习率优化层过低则梯度滞后，几何震荡；过高则粒子得分爆炸，渲染过饱和
渲染分辨率结构层过低则梯度被噪声淹没；过高则单步耗时压垮粒子更新
阶段切换点结构层过早切网格则密度场未收敛，提取出破碎表面

一个具体机制：粒子 LoRA 的去噪训练目标与主扩散模型相同，但输入是当前 3D 渲染图加噪后的样本，因此粒子得分实际上在拟合“当前 3D 分布”的得分。当 3D 参数更新过快而粒子更新过慢时，ε_ψ 描述的是旧分布，VSD 梯度里的减项失效，等价于回到单点拟合。系统代价上，粒子数与 LoRA rank 的乘积直接决定显存中的可训练参数规模与每步前向次数；把两者同时调大是复现中最常见的“跑得动但跑不完”的配置。

四 · 多阶段切换与网格精修的工程细节

论文的多阶段是 NeRF 到网格。复现时最容易崩的地方不在单阶段内部，而在切换瞬间。NeRF 阶段的输出是密度场与颜色场，网格阶段需要一次提取（marching cubes 类操作）把密度转成表面，再把颜色烘焙到顶点或纹理上。提取阈值是一个没有出现在公式里、却决定成败的超参：阈值偏高会丢掉细结构，偏低会把背景噪声提成表面。切换后，粒子 LoRA 仍在拟合旧阶段的渲染分布，若不在切换点重置或至少让粒子模型继续训练若干步再恢复 VSD 更新，网格阶段前若干步的梯度方向会系统性错误。

网格阶段的可微渲染与 NeRF 的可微渲染在梯度性质上不同：前者对拓扑变化不连续，后者对密度场连续。这意味着网格阶段的 VSD 梯度不能直接沿用 NeRF 阶段的学习率与 w(t) 配置。一个具体例子：在网格阶段继续使用 NeRF 阶段的高学习率，表面顶点会在几步内被推离，产生自交与法线翻转，渲染图出现黑斑；此时 loss 可能仍在下降，因为先验得分对黑斑不敏感，但验收断言里的“表面连通分量数”会立刻报警。

阶段切换的验收断言应包含三项：提取后的网格面数在合理区间内（相对上一阶段不出现数量级跳变）；切换前后同一相机下的渲染图在结构上可对应（可用简单的轮廓重叠度做定性检查）；粒子模型在切换后重新参与去噪训练的步数被显式记录。系统代价上，网格精修阶段的可微渲染通常比 NeRF 阶段更耗显存，因为要同时持有顶点、面、纹理与渲染中间缓冲；把两个阶段放在同一进程里跑而不释放 NeRF 阶段的优化器状态，是显存溢出的常见来源。

五 · 验收断言：把“看起来对”变成可判定的检查

复现 ProlificDreamer 不能靠肉眼判断“像不像”。验收断言要覆盖四个层面，每个层面都要有明确的通过条件，而不是“大概可以”。第一层是数值健康：VSD 梯度范数在训练中不应出现数量级尖峰，粒子去噪损失应单调下降到一个平台而非持续震荡；出现尖峰通常意味着粒子学习率过高或 w(t) 在某个 t 区间取值失配。第二层是分布性质：固定提示、固定种子、改变粒子初始化，多次采样应产出结构不同的资产——这是“分布匹配而非单点拟合”的直接检验，若多次结果几乎一致，说明粒子数或粒子多样性机制失效。

第三层是文本对齐：用冻结的 CLIP 类模型对渲染图与提示做相似度检查，但要注意这只在定性层面有效，因为论文的结论是相对 SDS 的显著提升，而不是绝对阈值。第四层是几何健全：网格阶段检查连通分量数、退化面比例、法线一致性。一个具体机制：VSD 梯度里的减项 ε_ψ 若欠拟合，会表现为渲染图过饱和与纹理在高频处粘连，这在 CLIP 相似度上不一定下降，但在“同一提示多次采样的颜色分布方差”上会异常小——多样性断言比对齐断言更早暴露粒子模型的问题。

  • 数值断言：梯度范数无数量级尖峰；粒子损失收敛到平台。
  • 多样性断言：换粒子初始化后资产结构可区分。
  • 对齐断言：渲染图与提示的相似度相对 SDS 基线不退化。
  • 几何断言：网格连通分量与退化面比例在阈值内。

系统代价上，跑全套验收断言的采样次数远多于训练本身的单次前向，复现时要把验收脚本与训练脚本分离，避免在训练循环里插入昂贵的多样性采样。失败模式上，最常见的“假通过”是把验收跑在训练用的同一相机分布上，此时渲染图与训练视角高度相关，几何缺陷被视角覆盖掩盖；验收必须使用独立的相机采样种子。

六 · 常见崩溃点与最小可跑版本的边界

按出现频率排序，复现 ProlificDreamer 的崩溃点集中在四处。其一，粒子模型与 3D 参数的优化器耦合，表现为 loss 前期正常、中期突然发散；修法是两次反向传播严格分离，并在计算 VSD 梯度时对粒子参数做 detach。其二，粒子数退化为单粒子，代码不报错但方法语义已变；修法是在配置加载时对粒子数做下限断言。其三，阶段切换时未重置粒子模型的训练节奏，网格阶段出现系统性伪影；修法是在切换点插入固定步数的粒子预热。其四，渲染图归一化与扩散模型输入不匹配，表现为整体色调偏移且无法通过调学习率修复；修法是在数据准备层做一次值域断言。

最小可跑版本的边界必须写清楚：它验证的是梯度符号、数据流与优化器分离，不验证真实感、多样性与多阶段收益。把最小版本的输出当作方法有效性的证据，是复现中最常见的判断错误。一个具体例子：最小版本在低分辨率、单粒子初始化下也能让 loss 下降并产出有轮廓的资产，但这与 SDS 的行为无法区分；只有把粒子数调大、开启多阶段、并跑多样性断言，才能观察到 VSD 相对 SDS 的差异。工程判断上，复现的优先级应是“先让双更新正确分离，再让粒子数生效，最后才调分辨率与阶段切换点”——顺序颠倒会让后两步的调参建立在错误的梯度之上，所有超参搜索都失去意义。
