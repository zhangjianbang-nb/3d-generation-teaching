一 · PBR 监督的逐视图目标与变量含义

Hunyuan3D 2.1 的 PBR 分支不是把三张图拼成一个“大 RGB 图”去回归，而是把反照率、粗糙度、金属度当作三条独立通道，在每一个采样视图上分别施加监督。论文给出的目标函数写成逐视图的通道平方误差和：

$$\mathcal{L}_{\mathrm{PBR}}=\sum_{v}\left\|\hat{\mathbf{a}}_v-\mathbf{a}_v\right\|^2+\left\|\hat{r}_v-r_v\right\|^2+\left\|\hat{m}_v-m_v\right\|^2$$

变量含义需要逐个钉死：$v$ 遍历参与监督的视图集合，既包括扩散模型生成的多视图，也包括 UV 融合后重新投影到视图空间的采样点；$\hat{\mathbf{a}}_v$ 是网络预测的反照率图，$\mathbf{a}_v$ 是监督目标的反照率，二者都是三通道量，所以第一项是逐像素、逐通道的 L2；$\hat{r}_v$ 与 $r_v$ 是粗糙度的标量场，通常落在 $[0,1]$；$\hat{m}_v$ 与 $m_v$ 是金属度的标量场，同样在 $[0,1]$。三项权重相同，意味着论文没有用超参去人为压制某一通道——这是有意为之：金属度预测错会让高光整体错位，粗糙度预测错会让反射从镜面滑向漫反射，反照率错则直接改变物体固有色，三者对最终渲染的误差贡献在同一量级上，等权是合理的默认。

这个式子的一个直接后果是：它只约束“渲染前”的材质参数，不约束“渲染后”的像素。也就是说，单靠 $\mathcal{L}_{\mathrm{PBR}}$ 无法保证物理正确——一组反照率偏暗、粗糙度偏高的参数，和一组反照率偏亮、粗糙度偏低的参数，可以在某些光照下渲染出几乎相同的图像。这正是下一节要引入可微渲染监督的原因。工程上还有一个细节：逐视图求和意味着视图数 $V$ 直接放大梯度幅值，若不同视图的监督质量不均（例如背面视图由补全生成、可信度低），等权求和会把低质量视图的噪声按 $V$ 倍灌进梯度。实际配方里必须对视图做筛选或加权，否则训练早期会出现“背面视图把正面学坏”的失败模式。

举个具体例子：假设某视图上真实材质是 $\mathbf{a}=(0.8,0.2,0.1)$、$r=0.3$、$m=0.0$（一个红色塑料件），网络预测 $\hat{\mathbf{a}}=(0.6,0.25,0.1)$、$\hat{r}=0.5$、$\hat{m}=0.2$。反照率项贡献 $(0.2)^2+(0.05)^2+0=0.0425$，粗糙度项 $(0.2)^2=0.04$，金属度项 $(0.2)^2=0.04$，单视图损失约 $0.1225$。这个量级说明：三个通道的误差在同一数量级，任何一项被系统性低估都会主导梯度方向。若金属度被错判为 0.2，渲染时该区域会获得本不该有的金属高光，视觉错误远大于数值上的 0.04——这就是为什么论文强调通道完整而非单通道精度。

二 · 可微 PBR 渲染作为第二层监督

仅有参数空间的 L2 监督会遭遇“参数等价类”问题：不同的 $(\mathbf{a}, r, m)$ 组合在特定光照下渲染一致。Hunyuan3D 2.1 的解法是把渲染方程接进计算图，让渲染出的图像与真实图像比对，梯度穿过渲染器回传到材质参数。渲染的核心是 Cook-Torrance 类的 BRDF：

$$L_o(\omega_o)=\int_{\Omega} f_r(\omega_i,\omega_o)\,L_i(\omega_i)\,(\mathbf{n}\cdot\omega_i)\,\mathrm{d}\omega_i,\quad f_r=\frac{k_d\mathbf{a}}{\pi}+\frac{DFG}{4(\mathbf{n}\cdot\omega_i)(\mathbf{n}\cdot\omega_o)}$$

这里 $L_o$ 是出射辐射度，$\omega_i,\omega_o$ 是入射/出射方向，$\mathbf{n}$ 是法线，$L_i$ 是环境光照，$f_r$ 是 BRDF。$k_d=(1-m)$ 是漫反射系数，$D$ 是法线分布项（由粗糙度 $r$ 控制），$F$ 是菲涅耳项（由反照率与金属度共同决定金属的 F0），$G$ 是几何遮蔽项。关键点在于：$r$ 通过 $D$ 影响高光锐度，$m$ 通过 $k_d$ 与 $F_0$ 同时影响漫反射与镜面反射的配比，$\mathbf{a}$ 在金属情形下直接充当 $F_0$。三者在渲染方程里是耦合的，因此渲染监督能打破参数等价类。

可微性来自对积分做蒙特卡洛采样：把环境光离散成若干方向样本，每个样本的贡献对 $(\mathbf{a},r,m)$ 都可导。伪代码思路是：对每个视图，采样 $N$ 个光照方向，累加 $f_r\cdot L_i\cdot(\mathbf{n}\cdot\omega_i)$，得到渲染图 $\hat{I}_v$，再与真实图 $I_v$ 做 L1 或感知损失。梯度经渲染器回传，落到材质图上。系统代价很直接：渲染监督让每个训练步的计算量从“一次前向”变成“前向 + $N$ 次着色 + 反向穿过着色器”，显存与算力都显著上升；$N$ 取小了方差大、梯度噪声重，取大了显存爆。这是训练配方里必须调的超参。

失败模式也很典型：若环境光照估计不准（光照解耦没做好），渲染监督会把光照误差错误地归因到材质上——网络会学会用“更暗的反照率”去补偿“更亮的环境光”，产出的资产在换光照后立刻露馅。论文因此把光照解耦作为独立训练环节，而不是让渲染损失自己去猜光照。具体例子：一个金属球在强环境光下渲染偏亮，若光照未解耦，网络会把金属度往下调、粗糙度往上调来压暗高光，结果资产进引擎后在标准 HDRI 下显得像塑料——这正是 2.0 基础色纹理进引擎后的典型病症，2.1 用解耦训练切断这条错误归因路径。

三 · UV 空间融合与梯度回传路径

多视图扩散产出的是视图空间的材质图，但引擎要的是 UV 空间的贴图。UV 融合模块把多视图预测反投影到 UV 域并做补全，这一步的梯度路径决定了训练能否端到端。机制上分两步：先按相机参数把每个视图的像素反投影到网格表面，得到带视图标签的 UV 采样点；再对 UV 图上未被任何视图覆盖的缝隙（遮挡区、拉伸区）用扩散补全或邻域插值填充。反投影是可微的（只涉及坐标变换与双线性采样），补全若用网络则也可微，若用插值则是固定算子。

这里的关键工程判断是：UV 融合的误差不会平均掉，而是集中体现在接缝处。多视图预测在同一物理点上的值若有微小色差，反投影到 UV 后会在接缝两侧形成可见的条带。训练时若只监督视图空间，接缝误差不会被惩罚；因此配方里必须把 UV 融合后的贴图重新渲染回视图空间，纳入 $\mathcal{L}_{\mathrm{PBR}}$ 的 $v$ 集合。这就是公式中 $v$ 既含原始视图又含重投影视图的原因。代价是每次迭代要多做一次“UV→视图”的重渲染，训练吞吐下降，但换来的是接缝一致性。

失败模式：UV 展开本身会失败。当网格拓扑复杂（薄壁、自交、高亏格）时，自动 UV 展开会产生重叠岛或极端拉伸，反投影时多个视图争抢同一 UV 像素，融合结果出现撕裂。论文把“UV 失败”列为明确局限，说明这不是偶发噪声而是系统性风险。工程上的缓解是：在 UV 展开后做岛重叠检测，对失败区域降权或回退到视图空间直接输出；同时把贴图分辨率作为消融项——分辨率越高，接缝越细但显存与融合时间越涨，存在一个收益拐点。具体例子：一个带细长把手的杯子，把手内侧的 UV 岛在展开时被压成极窄条带，反投影采样不足，融合后把手内侧出现模糊色块；提高分辨率能缓解但无法根除，因为根因是展开拓扑而非采样密度。

四 · 训练配方与关键超参

形状分支沿用 2.0 的 DiT 与训练配置，本部分不重复。PBR 分支的配方由四块组成：数据、监督、解耦、规模。数据侧用多视图 PBR 数据（Objaverse 与内部 PBR 资产），每条样本需自带反照率/粗糙度/金属度真值；渲染监督需要配套的环境光照与相机参数。监督侧是 $\mathcal{L}_{\mathrm{PBR}}$ 与渲染损失的组合，前者管参数精度，后者管物理一致性。解耦侧是光照解耦训练：把光照作为可分离变量，避免材质与光照互相污染。规模侧是大规模数据加数十秒级推理——注意这是推理耗时，不是训练耗时，说明模型在部署时仍需可观的采样步数。

超参/配置作用调错的后果
视图数 $V$决定 $\mathcal{L}_{\mathrm{PBR}}$ 的求和规模与覆盖度过少则背面无监督，过多则低质量视图放大噪声
渲染采样数 $N$控制蒙特卡洛积分方差过小梯度噪声重，过大显存爆
通道权重默认等权，可按数据质量微调压制金属度会让高光系统性错位
贴图分辨率决定 UV 融合的接缝精细度过高收益递减且融合变慢
光照解耦强度切断材质-光照错误归因过弱则换光照露馅，过强则材质欠拟合

消融实验针对 PBR 通道、光照解耦、贴图分辨率三项，说明这三者是配方里最敏感的自由度。通道消融回答“少一个通道会怎样”：去掉金属度，高光退化为统一镜面；去掉粗糙度，反射锐度不可控；去掉反照率，固有色丢失。光照解耦消融回答“不解耦会怎样”：材质学会补偿光照，重光照表现崩坏。分辨率消融回答“贴图多大够用”：存在收益拐点。这三个消融共同支撑了论文的核心主张——PBR 完整性不是锦上添花，而是重光照可用的必要条件。

训练稳定性上有一个容易被忽略的点：$\mathcal{L}_{\mathrm{PBR}}$ 的三项等权，但三通道的数值分布不同。反照率是三通道、方差较大；粗糙度与金属度是标量、分布偏向两端（大量 0 或 1）。等权 L2 会让反照率项在早期主导梯度，粗糙度/金属度学得慢。配方上通常靠数据归一化与损失归一化来平衡，而不是改公式里的权重——这也是公式保持简洁的原因：平衡放在实现层，公式只表达监督结构。

五 · 数值玩具例子：一步梯度怎么走

把上面的机制压成一个可手算的例子。设单个视图、单个像素，真实材质 $\mathbf{a}=(0.8,0.2,0.1)$、$r=0.3$、$m=0.0$；网络初始预测 $\hat{\mathbf{a}}=(0.6,0.25,0.1)$、$\hat{r}=0.5$、$\hat{m}=0.2$。按 $\mathcal{L}_{\mathrm{PBR}}$ 算得损失约 $0.1225$（见第一节）。对反照率红通道求偏导：$\partial\mathcal{L}/\partial\hat{a}_R=2(\hat{a}_R-a_R)=2(0.6-0.8)=-0.4$；对粗糙度：$2(0.5-0.3)=0.4$；对金属度：$2(0.2-0.0)=0.4$。取学习率 $\eta=0.1$，梯度下降一步后：$\hat{a}_R\leftarrow0.6-0.1\times(-0.4)=0.64$，$\hat{r}\leftarrow0.5-0.1\times0.4=0.46$，$\hat{m}\leftarrow0.2-0.1\times0.4=0.16$。三个量都朝真值方向移动，步长与误差成正比。

现在加入渲染监督看耦合效应。设该像素法线朝上、环境光为均匀白光 $L_i=1$、观察方向与法线夹角余弦为 0.8、入射方向余弦为 0.9。用简化 BRDF：漫反射贡献 $k_d\mathbf{a}/\pi$，镜面贡献近似 $m\cdot D(r)$。初始预测下 $k_d=0.8$，漫反射红通道约 $0.8\times0.6/\pi\approx0.153$；镜面项因 $m=0.2$、$r=0.5$ 给出中等高光。真实材质 $k_d=1.0$、$m=0$，漫反射红通道约 $1.0\times0.8/\pi\approx0.255$，镜面为零。渲染图与真实图的差会同时推动 $\hat{\mathbf{a}}$ 上调、$\hat{m}$ 下调——与参数 L2 的方向一致，但渲染损失的梯度会额外惩罚“金属度带来的假高光”，因为它在真实图中不存在。两个损失的梯度叠加后，金属度下降更快，反照率上升更稳。

这个玩具例子暴露一个工程判断：参数 L2 与渲染损失并非总是同向。若光照估计偏亮，渲染损失会要求材质变暗，而参数 L2 要求材质贴近真值，两者拉扯。光照解耦的作用就是把“光照偏亮”这个自由度从材质梯度里摘出去，让两个损失重新对齐。玩具例子里的数字是手算示意，不是论文实验数据；但它精确展示了梯度幅值、通道耦合与两步更新的方向，足以说明为什么配方里必须同时保留参数监督与渲染监督，且必须做解耦。

最后落到具体机制：Hunyuan3D 2.1 的训练不是“一个大损失端到端”，而是参数空间 L2 与渲染空间损失的双轨监督，中间夹着 UV 融合的重投影闭环与光照解耦的归因切断。任何一环缺失，产出的 PBR 贴图要么参数不准，要么物理不一致，要么换光照即崩。推理数十秒的代价，本质上是在为这套双轨监督与多视图采样买单——生产级材质的“可重光照”不是免费的，它把成本从“生成一张好看的颜色图”转移到了“生成一组经得起渲染方程检验的参数”。
