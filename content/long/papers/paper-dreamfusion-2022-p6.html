一 · 最小可跑版本的目录骨架

复现 DreamFusion 时最容易犯的错误，是把论文里的「一个算法」当成「一个仓库」来写。论文只给了 SDS 梯度公式和几个超参，但真正跑起来需要五个彼此解耦的子系统：可微渲染、哈希网格 NeRF 表示、扩散先验封装、随机相机与光照采样器、网格提取与验收。把它们塞进一个文件里，第一次崩溃时你无法判断是渲染梯度错了还是扩散调用错了。最小可跑版本应当按职责切目录，每个目录只暴露一个窄接口。

推荐的骨架如下：configs/ 放 YAML 超参与场景描述；nerf/ 放哈希网格编码器与 MLP 头，暴露 query(points, dirs) → rgb, sigma；render/ 放光线采样、体积渲染积分与相机采样，暴露 render(camera) → image 并保证对 nerf 参数可微；diffusion/ 只做一件事：把 (x_t, t, y) 送进冻结模型拿回 ε_φ，并封装 CFG 的两路前向；sds/ 实现损失与反传；extract/ 放 Marching Cubes 与网格后处理；asserts/ 放验收断言脚本。这个切法的关键收益是：diffusion/ 可以被单独替换成任何冻结的 2D 模型而不动其他目录，render/ 可以单独做梯度数值校验。

接口设计上有一条硬约束：render 的输出必须是形状为 [B, 64, 64, 3] 的张量，且 ∂x/∂θ 必须由自动微分给出，不能在 SDS 里手写链式法则。论文的 SDS 公式里 ∂x/∂θ 是渲染器对 3D 参数的雅可比，手写几乎必错，尤其是哈希网格的插值梯度。把这一项交给框架的 autograd，SDS 模块只负责构造 w(t)(ε_φ − ε) 这个标量权重向量并调用 backward。

一个具体的失败模式：把扩散模型和 NeRF 放在同一个 nn.Module 里并忘记 requires_grad_(False)，优化器会把扩散权重也收进参数组。症状是显存暴涨、每步变慢数倍，且损失曲线看起来「正常下降」——因为模型在偷偷微调先验。验收断言里必须有一条：优化器参数组的元素总数应等于 NeRF 参数量，且扩散模块所有参数的 requires_grad 为假。

另一个常见结构错误是把相机采样写进 render 内部。论文的训练配方是随机相机、随机光照、随机 t，三者都应在训练循环里采样，而不是在渲染函数里隐式决定。否则你无法在验收时固定相机做可重复的对比渲染，也无法做「固定视角范围」的消融。

二 · 数据准备：没有 3D 数据，但要准备四类输入

DreamFusion 的卖点是无 3D 训练集，但这不等于零数据准备。复现时需要四类输入，缺一类就跑不出论文描述的行为。

  • 文本提示词集合：每个资产一条描述，用于 CFG 的条件分支。提示词需要足够具体到能约束视角内容，否则多面问题会提前暴露。
  • 冻结的 2D 扩散权重：Imagen 在论文中是冻结先验。复现时若换用其他文本到图像扩散模型，必须重新校准 CFG 尺度与 w(t)，因为不同模型的噪声预测尺度不同。
  • 相机分布参数：仰角范围、方位角全覆盖、半径范围、视场角。论文用随机相机覆盖多视角，这是几何一致性的唯一来源。
  • 光照分布参数：随机光照方向与强度，用于让反照率与阴影解耦，避免模型把光照烘进几何。

数据准备里最容易被忽略的是「提示词与相机分布的匹配」。如果提示词描述的是「从正面看的椅子」，而相机均匀采样到背面，SDS 会在背面产生与文本矛盾的梯度，表现为背面几何塌陷或纹理涂抹。工程上的做法是给每个资产配一组视角相关的提示词变体，或在采样时按方位角对提示词做轻微改写。这不是论文的原始配方，但它是复现时让结果稳定的必要补丁。

扩散模型的封装需要处理分辨率不匹配。NeRF 渲染是 64×64，而多数文本到图像模型在更高分辨率上训练。直接把 64×64 图送进去，噪声预测的网络感受野与训练分布不一致，SDS 梯度会偏向高频伪影。复现时的处理是把渲染图上采样到模型的原生分辨率再送进去，或选择在低分辨率上仍然表现稳定的模型。这个选择直接影响「多面」与「过饱和」两个已知缺陷的严重程度。

验收断言层面，数据准备要能回答三个问题：给定固定随机种子，相机序列是否可复现；给定固定相机与固定 t，扩散前向是否确定；给定固定提示词，CFG 的两路条件与非条件输入是否形状正确。这三个断言把「随机性来源」钉死，后续调参才有意义。

三 · 超参配方与它们的耦合关系

论文给出的关键数字很少但每个都牵动全局：渲染 64×64、CFG 尺度约 100、每个资产 15k 步、单卡数小时。复现时不能把这些当成独立旋钮，它们之间存在强耦合。

超参作用位置耦合对象调错的症状
CFG 尺度 ≈ 100扩散前向的两路组合提示词具体度、w(t)过低则文本对齐弱、几何泛化；过高则过饱和与多面
随机 t 分布SDS 权重 w(t)噪声调度、扩散模型训练区间偏向高噪声则形状粗糙；偏向低噪声则纹理噪点
相机仰角/方位范围训练循环采样提示词视角描述范围过窄则背面缺失；过宽则几何冲突

哈希网格分辨率NeRF 编码器MLP 宽度、步数过低则细节丢失；过高则高频噪声与显存压力

CFG 尺度约 100 这个数字在工程上非常反直觉：常见 2D 生成里 CFG 在个位数到十几。这里之所以能到百量级，是因为 SDS 的梯度是噪声残差乘以 ∂x/∂θ，而 ∂x/∂θ 的量级远小于像素空间梯度，需要放大条件分支的差异来补偿。复现时若换用尺度不同的扩散模型，必须重新扫描这个值，扫描的判据不是损失下降，而是固定相机下的渲染图是否同时满足文本对齐与不过饱和。

$$\nabla_\theta\mathcal{L}_{\mathrm{SDS}}=\mathbb{E}_{t,\epsilon}\!\left[w(t)\big(\epsilon_\phi(x_t;y,t)-\epsilon\big)\frac{\partial x}{\partial\theta}\right]$$

公式里 w(t) 的选择直接决定训练动力学。工程上把它实现为一个按 t 查表的标量，表由噪声调度推导，而不是常数。常见崩溃点是把 w(t) 写成 1，结果是低噪声步的梯度被高噪声步淹没，几何先粗后细的收敛顺序被打乱，表现为「形状早早就定死、纹理一直糊」。

步数 15k 是论文的量级，不是硬性收敛判据。复现时应把验收断言设在「固定相机渲染在若干检查点的变化量」上：当相邻检查点的渲染差异低于阈值且文本对齐不再改善时提前停止。盲目跑满 15k 在单卡上就是数小时的空转，而真正的失败模式往往在前几千步就已显现。

一个具体例子：把 CFG 尺度从百量级降到十量级，同时保持其他超参不变，渲染图会变得灰暗、文本对齐下降，但几何反而更干净——这说明过饱和主要来自 CFG 放大而非 SDS 本身。复现记录里必须把这类耦合写清楚，否则调参变成碰运气。

四 · 训练循环的伪代码与梯度路径校验

最小训练循环的结构可以写成如下伪代码思路，重点在每一步的张量形状与梯度路径，而不在具体框架 API。

  • 初始化哈希网格编码器与 MLP 头，参数记为 θ；加载冻结扩散模型，全部参数 requires_grad=False。
  • 循环 15k 步：采样相机 c ~ p(camera)、光照 l ~ p(light)、时间步 t ~ p(t)、噪声 ε ~ N(0, I)。
  • 前向渲染：x = render(θ, c, l)，形状 [1, 64, 64, 3]；上采样到扩散模型输入分辨率得 x_up。
  • 加噪：x_t = sqrt(ᾱ_t) x_up + sqrt(1-ᾱ_t) ε。
  • 两路扩散前向：条件分支 ε_cond = ε_φ(x_t; y, t)，非条件分支 ε_uncond = ε_φ(x_t; ∅, t)；组合 ε_φ = ε_uncond + s(ε_cond − ε_uncond)，s 为 CFG 尺度。
  • 构造权重 g = w(t)(ε_φ − ε)，形状与 x 对齐；调用 (x * g.detach()).sum().backward()，让梯度只经 ∂x/∂θ 回传。
  • 优化器步进，只更新 θ。

这里有一个必须显式处理的细节：g 必须 detach。若把 ε_φ 留在计算图里，反传会试图穿过冻结的扩散模型，虽然参数不更新，但计算图会保留扩散中间激活，显存占用成倍增长，且梯度数值会被扩散网络的雅可比污染。detach 之后，SDS 就是一个「用外部向量加权的渲染梯度」，语义干净。

梯度路径校验是复现的第一道验收断言。做法是：固定相机、固定 t、固定 ε，对 θ 做有限差分，与 autograd 给出的 SDS 梯度在若干随机方向上做内积比较，方向应一致、量级应同阶。这个校验能抓出三类错误：渲染积分对深度的可微性写错、哈希网格插值梯度被截断、上采样层不可微。三类错误在端到端训练里都表现为「损失在降但几何不收敛」，极难从曲线上诊断。

系统代价方面，每步的主要开销是扩散模型的双路前向，而不是 NeRF 渲染。64×64 的渲染加体积积分在单卡上是毫秒级，而百量级 CFG 意味着两次完整前向。这解释了为什么论文的量级是「每资产数小时」：步数乘以双路前向的固定成本。复现时的优化方向应是减少扩散调用次数或降低其分辨率，而不是优化 NeRF 查询。

一个具体崩溃点：在 t 采样时把 t 当作连续值送进扩散模型，而模型期望离散的整数时间步索引。症状是噪声预测出现 NaN 或极端值，SDS 梯度爆炸，渲染图在几百步内变成纯色。验收断言应检查 t 的 dtype 与取值范围。

五 · 网格提取与验收断言的清单

训练结束后用 Marching Cubes 从密度场提取网格。这一步的工程细节决定最终资产能不能用：提取分辨率、密度阈值、是否做平滑、是否保留顶点颜色。论文的流程是渲染图直接优化，网格只是导出产物，因此提取参数不影响训练，但严重影响观感。提取分辨率过低会把哈希网格学到的细节抹平，过高则把高频噪声当成几何，产生碎片。

验收断言应分三层，每层都能独立失败。

  • 数值层：SDS 梯度与有限差分方向一致；优化器参数组只含 NeRF 参数；t 为整数且在调度范围内；扩散前向在固定输入下确定。
  • 视觉层：固定相机与固定光照下，渲染图在文本描述的主要属性上可辨认；多视角渲染的轮廓一致，无背面塌陷；颜色未出现过饱和（可用通道直方图做定性检查）。
  • 资产层：Marching Cubes 输出为非空网格；网格水密性检查；顶点数在合理范围；导出格式可被下游工具加载。

视觉层的断言最难自动化，但可以用一个廉价代理：在固定相机下渲染正面与背面，计算两者的轮廓 IoU。若 IoU 过低，说明多面问题已经发生。这不是精确判据，但能在调参时快速筛掉明显失败的配置。注意这个代理只用于工程验收，不能当作论文指标的替代。

已知的失败模式要在验收清单里显式列出：多面（同一物体在不同视角呈现矛盾几何）、过饱和（颜色通道被 CFG 放大推向极值）、几何不精确（细节缺失或表面噪声）。这三者在论文的局限里被明确承认，复现时不应把它们当成 bug 去修，而应把它们当成「当前配方的固有代价」记录在验收报告里。试图用后处理强行修复多面，往往会破坏其他视角的一致性。

一个具体例子：提取分辨率设为与训练渲染相同的 64×64 网格，得到的网格会明显块状化，因为训练时的监督信号只有 64×64。把提取分辨率提高到数倍于训练分辨率，几何并不会变细，只会把噪声放大成尖刺。正确的做法是让提取分辨率与哈希网格的有效分辨率匹配，而不是盲目提高。

六 · 常见崩溃点与工程判断

把复现中反复出现的崩溃点按发生阶段归类，比按症状归类更有用，因为阶段决定了你该看哪一段日志。

阶段崩溃点根因工程判断
初始化扩散权重被加入优化器未冻结参数组计数断言
前向渲染图与扩散输入分辨率不匹配未上采样或上采样不可微形状断言 + 梯度校验
加噪NaN 损失t 类型或调度越界dtype 与范围断言
反传显存成倍增长g 未 detach计算图节点数监控
收敛损失降但几何不收敛梯度路径错误或 CFG 尺度失配固定相机检查点对比
导出网格为空或碎片化密度阈值与提取分辨率失配网格统计断言

其中「损失降但几何不收敛」是最具欺骗性的失败模式。SDS 损失本身不是重建误差，它衡量的是噪声残差，可以在几何完全错误时仍然下降——因为模型学会的是让渲染图落在扩散模型的某个高概率区域，而不是落在文本描述的区域。这正是 CFG 尺度存在的意义：它把条件分支的差异放大，使损失下降的方向偏向文本对齐。复现时若只看损失曲线，会把一个文本不对齐的资产误判为成功。

工程判断上有一条分界线：哪些是配方问题，哪些是实现问题。多面与过饱和属于配方问题，调实现无法根治，只能通过相机分布、提示词、CFG 尺度去缓解；梯度路径错误、冻结失效、分辨率不匹配属于实现问题，必须修到断言全绿才能开始调参。把两类问题混在一起调，会陷入「改了十个数，不知道哪个起了作用」的状态。

最小可跑版本的定义应当是：单卡、单资产、能在数小时内产出可辨认网格、三层验收断言全部通过。达到这个定义之后，再谈换扩散模型、换表示、换采样策略。论文的贡献是把 2D 先验变成 3D 监督这一条路径，复现的价值在于把这条路径上的每个接口钉死，使得后续替换任一模块时，失败能被定位到具体接口而不是整体重来。

最后一个具体机制层面的判断：SDS 的梯度只经渲染器回传，扩散模型永远在前向之外。这意味着整个系统的可复现性瓶颈不在扩散模型的随机性，而在相机与光照采样器的随机性。把这两个采样器的种子固定，SDS 训练就变成确定性的；把它们的分布参数记录进配置文件，资产之间的差异才可归因。复现报告里若没有这两个采样器的分布与种子，任何结果都无法被他人重放。
