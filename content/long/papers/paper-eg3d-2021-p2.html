一 · 生成器主干：从隐向量到三张平面特征

EG3D 的数据流起点是一个标准的 StyleGAN2 隐向量。生成器主干并不直接输出体素或点云，而是把 StyleGAN2 的 2D 卷积堆叠改造为输出三张正交平面特征图，每张尺寸为 256×256×32。这个尺寸选择本身就是一次工程折中：256×256 保证平面内空间分辨率足够承载面部或车身的细节，32 通道则控制每个 3D 查询点拼接后的特征维度，使后续 MLP 的输入宽度保持在可训练范围内。三张平面分别对应 xy、xz、yz 三个坐标平面，共享同一组 2D 卷积权重生成，而非三个独立网络。

关键在于，StyleGAN2 的调制卷积与上采样机制被完整保留。隐向量 z 经过映射网络进入各层，逐级上采样到 256×256。这意味着生成三平面的计算代价与生成一张 256×256 的 2D 特征图同阶，而不是随 3D 分辨率立方增长。用公式表达生成器这一步：

$$G(\mathbf{z})=\mathrm{TriPlane}_\theta(\mathbf{z}),\qquad F(\mathbf{x})=\mathrm{MLP}\!\left(\mathrm{interp}(T_{xy},\mathbf{x}),\mathrm{interp}(T_{xz},\mathbf{x}),\mathrm{interp}(T_{yz},\mathbf{x})\right)$$

这里 T_xy、T_xz、T_yz 就是三张平面特征，interp 表示把 3D 点 x 投影到对应平面上做双线性插值。注意生成器输出的是平面，不是场；场是在查询阶段由平面加 MLP 临时构造出来的。这个分工把“生成高频 2D 细节”交给卷积，把“从平面特征解码密度与颜色”交给一个很小的 MLP，两者职责清晰分离。

系统代价出现在平面分辨率与通道数的乘积上。三张 256×256×32 的平面在训练时同时驻留显存，加上 StyleGAN2 主干各层的中间激活，单卡训练需要精细的 batch 控制。失败模式是平面分辨率不足时，高频细节被双线性插值抹平：例如人脸的眼睫毛或车轮辐条在平面上只占几个像素，插值后特征趋于平均，渲染出的边缘发软。这不是 MLP 能补救的，因为信息在插值那一步已经丢失。具体例子是 FFHQ 上的头发丝：平面分辨率决定了发丝能否被分辨，而通道数决定了每根发丝的颜色与密度能否被独立编码。

二 · 三平面查询：投影、插值、拼接

给定一个 3D 点 x=(x,y,z)，查询过程分三步。第一步投影：把 x 的三个坐标两两组合，分别落到 xy、xz、yz 三个平面上，得到三个 2D 坐标。第二步插值：在每个平面上做双线性插值，取出该点在该平面的特征向量，每个向量长度 32。第三步拼接：三个 32 维向量首尾相接成 96 维，送入解码 MLP。这个顺序是固定的，三平面的顺序不能乱，因为 MLP 的输入权重是按拼接顺序训练的。

双线性插值的具体机制是：对平面上的连续坐标，取周围四个整数格点的特征，按距离加权求和。这一步是可微的，梯度能通过插值回传到平面特征，进而回传到 StyleGAN2 主干。这正是三平面表示能与 2D 卷积联合训练的根本原因：查询操作对平面特征是线性的，反向传播没有障碍。伪代码思路如下：

  • 输入：三张平面 T_xy、T_xz、T_yz，查询点 x
  • 对每个平面，计算投影坐标 (u,v)，取 floor 与 ceil 四个邻点
  • 按 (u-floor(u)) 与 (v-floor(v)) 做双线性加权，得到 32 维特征
  • 三个特征拼接为 96 维，送入 2 层 MLP
  • MLP 输出一个标量密度 σ 和一个 3 维 RGB 颜色 c

系统代价在这里体现为查询次数。体渲染一条射线要采样几十到上百个点，每个点都要做三次插值加一次 MLP 前向。分辨率 512×512 的图像有二十六万条射线，每条射线几十个采样点，总计千万级的查询。这个量级下，MLP 必须足够小，否则渲染一张图的时间会失控。EG3D 选择 2 层 MLP，正是为了把单点查询成本压到最低。失败模式是采样点落在平面边界之外：投影坐标超出 [0,255] 时插值无定义，工程上需要 clamp 或返回零特征，处理不当会在物体边缘产生伪影。具体例子是 ShapeNet 汽车的车顶轮廓，射线擦过物体边界时，边界外的采样点若被错误插值，会在轮廓外渲染出漂浮的密度。

三 · 体渲染与 2D 判别器：从场到图像，从图像到梯度

MLP 输出的密度与颜色沿射线累积，得到每个像素的 RGB。体渲染的离散形式是沿射线采样 N 个点，按密度加权求和颜色，权重同时决定该点的可见性。这一步把 3D 场变成 2D 图像，图像再送入判别器。判别器是一个标准的 2D CNN，不感知 3D，只判断渲染图与真实图在纹理、频率分布上是否一致。这个设计是 EG3D 效率的另一半：判别器完全复用 2D GAN 的成熟架构，不需要 3D 卷积或体素判别器。

3D 一致性从何而来？来自三平面的共享结构。同一个 3D 点在不同视角下查询的是同一组平面特征，因此不同视角渲染出的颜色与密度天然一致。判别器只约束单张 2D 图像的真实感，但生成器为了让所有视角都骗过判别器，必须让三平面在不同投影下都产生合理的图像，这反过来迫使平面特征在 3D 空间上自洽。相机分布采样是这条链路的关键一环：训练时从预设的相机分布中采样姿态，渲染对应视角，判别器比较该视角的渲染图与真实图。姿态条件可选地输入生成器，让生成器知道当前渲染的是哪个视角。

系统代价是渲染与判别的串行开销。每步训练要先渲染一批图像，再跑判别器，渲染的千万级查询是主要瓶颈。失败模式是判别器与渲染分辨率不匹配：判别器在低分辨率下学到的纹理统计，无法约束高分辨率渲染的高频细节，导致高分辨率输出出现棋盘格或过锐边缘。具体例子是 FFHQ 上 512×512 渲染时，若判别器感受野不足，面部皮肤的细纹会被生成器过度锐化以骗取判别器分数。R1 正则与路径长度正则在这里起到稳定作用：R1 惩罚判别器对真实样本的梯度范数，路径长度正则惩罚生成器输出随隐向量变化的幅度，两者共同抑制训练震荡。

四 · 模块分工与消融指向的分工边界

把数据流拆开看，各模块的分工可以列成一张表。生成器主干负责把隐向量变成三张平面，承担全部高频 2D 细节的生成；三平面查询负责把平面特征定位到 3D 空间，承担几何与视角的绑定；解码 MLP 负责把拼接特征变成密度与颜色，承担局部材质与透明度的表达；体渲染负责积分，承担从场到像素的转换；2D 判别器负责真实感约束，承担纹理统计的匹配；相机分布负责视角覆盖，承担 3D 一致性的训练信号。

消融实验指向的分工边界值得细看。三平面对比单平面与体素：单平面把三个投影压到一张图上，查询时不同坐标组合共享同一特征，表达能力受限，几何细节丢失；体素表示显存随分辨率立方增长，无法在同等分辨率下训练。2D 判别器对比 3D 判别器：3D 判别器需要体素输入，代价高且难以扩展到高分辨率，2D 判别器配合多视角渲染同样能约束 3D 一致性，且复用成熟架构。姿态条件的影响则体现在视角可控性上：无姿态条件时生成器不知道当前视角，相机分布采样退化为随机视角，训练信号变弱。

一个具体例子能说明分工边界：ShapeNet 上的椅子生成。椅子的腿是细长结构，在三个平面上都只占很窄的区域。若平面分辨率不够，腿的密度在插值时被邻域平均掉，渲染出的腿变粗或消失。这不是 MLP 的问题，而是平面分辨率与物体细长结构之间的尺度不匹配。反过来，若把 MLP 加大以补偿，渲染时间上升，训练轮次减少，最终图像质量未必改善。这说明分工的瓶颈在平面分辨率这一环，而非解码环节。

五 · 训练数据流与单卡可行性

训练一步的完整数据流是：采样一批隐向量 z，生成三平面；从相机分布采样一批姿态；对每个姿态沿射线查询三平面加 MLP，体渲染出图；渲染图与对应真实图送入 2D 判别器；判别器损失与生成器损失反传，梯度经渲染与插值回到平面特征，再回到 StyleGAN2 主干。R1 正则作用于判别器对真实图的梯度，路径长度正则作用于生成器输出随 z 的变化。整个过程单卡可跑，训练数天，这是 EG3D 相对体素或大 MLP 方案的核心工程优势。

数据流中有一个容易被忽略的细节：渲染图的视角必须与真实图的视角对应。真实数据集（FFHQ、AFHQ、CompCars、ShapeNet）的图像本身带有隐含或标注的姿态，训练时需要把相机分布与数据集姿态对齐，否则判别器比较的是不同视角的图像，梯度信号错误。工程上这通过预设相机分布并假设数据集姿态落在该分布内来实现，对齐误差是训练不稳定的来源之一。失败模式是数据集姿态分布与预设相机分布偏差过大：例如 CompCars 的拍摄角度集中在少数几个方位，预设分布覆盖过宽时，采样到数据集未覆盖的视角，判别器缺乏对应真实图，生成器在该视角上得不到有效约束。

另一个数据流细节是渲染分辨率与平面分辨率的关系。渲染 512×512 时，每条射线在 3D 空间采样，采样点的投影坐标落在 256×256 平面上。渲染分辨率高于平面分辨率意味着多个像素查询到相近的平面位置，插值后的特征差异很小，高频信息由 MLP 与体渲染的采样密度决定，而非平面本身。这解释了为什么平面分辨率是细节的上限：渲染分辨率再高，也无法从 256×256 的平面中恢复出超过其奈奎斯特频率的细节。具体例子是 AFHQ 上的动物毛发，渲染 512×512 时毛发的细碎纹理受限于平面分辨率，呈现出略软的外观。

六 · 固定拓扑与几何精度的架构根源

三平面表示的固定拓扑来自其结构本身：三张平面在空间上无限延展，查询任意 3D 点都有定义，但平面的特征分布由 StyleGAN2 主干一次性生成，不随查询点自适应。这意味着物体的拓扑在平面生成那一刻就被决定，后续查询只是读取。对于单物体、固定类别的生成任务（人脸、猫脸、汽车、椅子），这个假设成立；对于多物体场景或需要精细几何的任务，固定拓扑成为限制。几何精度有限的根源也在这里：平面是 2D 特征的堆叠，3D 结构是三个 2D 投影的交织，尖锐边缘与薄壁结构在投影交织时被平滑。

这个架构判断直接影响了后续工作。三平面作为标准中间表示被前馈重建模型继承，LRM、TripoSR 等把生成器换成图像条件 Transformer，输出仍是三平面，查询与解码流程不变。这说明三平面的价值不在生成器，而在“2D 卷积生成平面 + 插值查询 + 小 MLP 解码”这条数据流本身：它把 3D 生成的负担从体素或大 MLP 转移到 2D 卷积，代价是固定拓扑与几何精度。工程上选择这条数据流，等于接受“用 2D 卷积的可扩展性换 3D 表示的灵活性”这一交易。具体到部署，若任务要求薄壁或锐边，三平面的插值平滑会在这些区域产生可见的几何误差，需要额外的几何后处理或换用更高分辨率的平面，而后者又回到显存与训练成本的约束上。
