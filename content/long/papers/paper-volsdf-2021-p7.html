一 · 对比坐标：三个方法各自把「表面」放在哪一层

把 VolSDF 与同期、后继方法逐项对比，第一步不是比指标，而是比「表面在哪一层被定义」。这决定了后续所有工程代价的形状。NeRF 把场景表示为体密度 σ(x) 与视角相关颜色 c(x,d)，表面是密度场的一个隐式等值面，没有任何显式约束要求密度在某处集中；渲染公式里的透射率 T 沿射线单调衰减，深度期望由权重分布的重心给出。IDR 走的是另一条极端：MLP 直接输出 SDF 值 f(x) 与颜色，表面由 f=0 定义，渲染时把表面点投影到图像平面求法线与颜色，本质上是一种表面渲染而非体渲染，它依赖前景掩码把射线与表面的交点唯一化。VolSDF 处在两者之间：它保留 NeRF 的体渲染积分框架，但把密度从「自由学习的量」改成「由 SDF 经固定变换导出的量」。

这个坐标差异直接体现在监督信号上。NeRF 只有 RGB 重建损失，几何是副产品；IDR 需要掩码与 Eikonal 正则来把 SDF 拉成真正的距离场，且难以处理无掩码的复杂背景；VolSDF 用 RGB + Eikonal 就能在多视图下得到几何，掩码是可选项而非必需。对比时必须把「输入契约」列清楚：IDR 的掩码是额外人工标注，VolSDF 与 NeuS 把它降级为可选，这是工程落地时成本差异最大的一项。三者的表示层级可以用一句话概括：NeRF 是密度自由场，IDR 是表面场加表面渲染，VolSDF 是表面场加体渲染。后续所有关于速度、显存、失败模式的差异，都是这句话的推论。

二 · 监督项逐项拆解：谁在约束几何，谁在约束外观

把损失函数拆成项来对比，比整体指标更能看清方法的能力边界。VolSDF 的损失由三块构成：RGB 重建项、Eikonal 正则项、可选的深度或法线监督项。RGB 项走体渲染积分，形式上是沿射线对权重 w(t) 与颜色 c 的加权求和再与像素值比较；Eikonal 项约束 SDF 梯度的模长趋近 1，即 ‖∇f‖≈1，使 f 成为近似有符号距离场而非任意标量场；可选监督项把渲染深度或法线与外部先验对齐。β 退火不是损失项，而是调度策略：β 从大到小变化，控制 α(x)=Ψ_β(−f(x)) 的锐度，早期 β 大时不透明度过渡平缓、梯度覆盖范围广，后期 β 小时表面收紧。

$$\mathcal{L}=\sum_{r}\left\|\hat{C}(r)-C(r)\right\|^{2}+\lambda_{e}\sum_{x}\left(\|\nabla f(x)\|-1\right)^{2}+\lambda_{s}\,\mathcal{L}_{s}$$

对比 NeuS：它的密度变换写成与 SDF 相关的 logistic 形式，且引入一个可学习的逆温度参数随训练推进而增大，效果上与 β 退火同构——都是「先宽后窄」地把不透明度推向表面。两者的 Eikonal 项几乎一致，差别在于权重系数与采样策略的耦合方式。对比 IDR：IDR 没有 RGB 体渲染积分，它的颜色损失建立在表面交点投影上，因此必须靠掩码把交点唯一化，Eikonal 项在 IDR 里承担更重的几何约束角色，因为没有体渲染的「软」几何信号来兜底。对比 NeRF：NeRF 完全没有 Eikonal 项，几何完全由密度与 RGB 的联合拟合涌现，这也解释了为什么 NeRF 在 DTU 这类要求精确 Chamfer 距离的任务上不如 VolSDF——不是优化不够，而是约束缺失。

监督项的工程代价不对称。Eikonal 项需要对采样点求梯度，反向传播时要多算一阶导，显存与算力开销直接翻倍于纯 RGB 训练；β 退火需要额外的调度逻辑与「退火到多小」的超参判断，退火过快会让表面在早期就被锁死、丢失薄结构，退火过慢则训练后期仍在优化一个模糊的表面。可选深度监督看似免费，实则要求外部深度图与渲染深度在同一尺度上对齐，尺度错配会引入系统性偏差。一个具体例子：在 BlendedMVS 这类背景复杂、视角跨度大的场景里，若只开 RGB + Eikonal 而不开深度监督，VolSDF 仍能得到几何完整的重建，这正是它与 IDR 的关键分野——IDR 在无掩码的同类场景上无法启动。失败模式上，Eikonal 权重 λ_e 过大时 SDF 被强行拉成严格距离场，但颜色拟合不足，RGB 损失降不下去；λ_e 过小时几何松散，Chamfer 距离变差。这个权衡在 VolSDF 与 NeuS 上同样存在，只是数值区间不同。

三 · 数值行为：β 与逆温度如何决定「表面锐度」与梯度覆盖

VolSDF 与 NeuS 最实质的差别不在架构，而在密度变换的数值行为。VolSDF 的 α(x)=Ψ_β(−f(x))，其中 Ψ_β 是 scaled Laplace CDF：当 f 为负（点在表面内侧）时 α 以 exp(s/β) 形式增长，当 f 为正（外侧）时 α 以 1−exp(−s/β) 形式饱和。这个函数在 f=0 处的斜率与 1/β 成正比，β 越小，过渡带越窄，不透明度越接近阶跃函数，表面越锐。它的一个重要性质是：α 对 f 的导数在远离表面时指数衰减，这意味着梯度只集中在表面附近一个宽度约 β 的带内。β 退火因此等价于「逐步缩小梯度有效覆盖带」，早期宽带宽覆盖让射线上的采样点都能收到颜色梯度，后期窄带把优化聚焦到表面。

$$\frac{\partial\alpha}{\partial f}=\frac{1}{2\beta}\exp\!\left(-\frac{|f|}{\beta}\right),\qquad w(t)=T(t)\,\alpha(t)$$

NeuS 的变换形式不同，它把密度写成与 SDF 相关的 logistic 表达，并让逆温度随训练增大。两者在「表面附近集中」这一目标上同构，但数值行为有可观测差异：Laplace CDF 的尾部是指数衰减，logistic 的尾部是多项式衰减，前者在远离表面处更快趋零，后者在中等距离上保留更多梯度。这导致在薄结构（如叶片、栏杆）上，VolSDF 的梯度带更容易「漏掉」厚度小于 β 的结构——当 β 退火到小于结构厚度时，结构两侧的表面带重叠，不透明度互相抵消，重建结果倾向于把薄结构抹平或合并。这是论文自述的局限之一：薄结构难。NeuS 在同一场景下的表现差异在实际中不大，论文也明确说两者差异在实际中不大，这提示我们不要把数值差异当成选型的主要依据。

工程代价方面，β 退火引入一个隐式的「时间-精度」耦合：β 的调度曲线决定了训练的有效分辨率。若把 β 退火与学习率调度独立设置，容易出现「β 已很小但学习率仍大」的组合，表面在窄带内震荡；反之「β 仍大但学习率已衰减」会让表面停在模糊状态。一个具体机制上的例子：在 NeRF synthetic 这类合成场景上，PSNR 接近 NeRF，说明外观拟合能力与纯密度场方法相当；但在 DTU 上 Chamfer 与 NeuS 相当，说明几何精度提升来自 Eikonal 与密度变换的组合而非单纯容量。失败模式上，β 退火去掉后质量下降（消融结论），原因是密度变换始终处于宽过渡状态，表面无法收紧；Eikonal 去掉后同样下降，原因是 SDF 失去距离语义，密度变换的「距离→不透明度」映射不再成立。这两个消融共同说明：变换函数与正则项是耦合的，不能单独拆开评估。

四 · 速度与显存：三条成本曲线的形状

速度对比要区分「单次迭代成本」与「收敛所需迭代数」。VolSDF 的单次迭代比 NeRF 贵，因为 Eikonal 项要对每个采样点求 SDF 梯度，反向传播多一层；同时体渲染积分本身需要沿射线采样几十到上百个点，每个点都要过 MLP。显存占用主要来自采样点数量乘以 MLP 激活的保存量，Eikonal 的梯度计算进一步放大了这部分。论文给出的定性表述是「单场景数小时」，这个量级与同期神经表面重建方法一致，比纯 NeRF 训练更重。IDR 的单次迭代在表面渲染下采样点少，但掩码与交点求解带来另一类开销，且无法扩展到无掩码场景。NeuS 与 VolSDF 的成本结构几乎相同，因为两者都是「SDF MLP + 体渲染 + Eikonal」，差别只在变换函数的几次指数运算，这在 GPU 上可以忽略。

显存上的一个具体机制：Eikonal 项要求对采样点 x 求 ∇f，反向传播时需要对「∇f 对参数的导数」再求一次，形成二阶计算图。若采样点数为 N、MLP 宽度为 W，激活保存量大致随 N·W 增长，二阶图让这部分常驻显存无法及时释放。工程上常见的缓解手段是减小每射线采样数、把 Eikonal 项在子采样集上计算、或用梯度检查点换显存，这些都会改变训练动态，需要与 β 退火曲线一起调。失败模式上，显存不足时最直接的反应是减小 batch 内射线数，但这会让 Eikonal 项的方差变大，几何约束变噪，表现为 Chamfer 距离在训练后期不再下降。另一个失败模式是采样范围设置不当：若近远平面把表面包得太紧，薄结构落在采样范围边缘，权重积分截断，表面出现「缺块」。

速度对比还必须考虑「达到可用质量所需的总时间」，而非单步时间。β 退火把训练拉长：早期宽 β 阶段梯度覆盖广但表面模糊，必须等 β 降下来才进入几何精修，这段「等待」是纯开销。对比 NeRF，后者没有退火阶段，收敛曲线更短但几何精度上限更低；对比 IDR，后者依赖掩码所以在简单场景上更快，但在复杂背景上根本无法启动，速度优势不成立。一个具体例子：在 BlendedMVS 上，VolSDF 能得到几何完整的重建，这个「完整」来自体渲染对背景的软处理，代价是每条射线都要积分，速度上不占优。工程判断是：若场景有可靠掩码且目标是不透明表面，IDR 类方法在速度上有优势；若无掩码或存在半透明、复杂背景，VolSDF/NeuS 的体渲染路线是唯一可行选项，速度代价必须接受。

五 · 失败模式对照：每种方法在哪里断掉

把失败模式按「触发条件」分类，比按方法分类更有工程价值。第一类是输入契约不满足：IDR 在无掩码时断掉，这是硬性失败，不是精度下降。第二类是表示能力不足：NeRF 的密度无几何约束，在稀疏视角或弱纹理区域长出雾状伪表面，Chamfer 距离变差；IDR 无法表达半透明与体积散射，遇到毛发、烟雾直接失效。第三类是数值/调度失配：VolSDF 与 NeuS 在薄结构上断掉，原因是 β（或逆温度）退火到小于结构厚度时梯度带重叠、不透明度抵消；β 退火曲线与学习率调度错配时表面震荡或停在模糊态；Eikonal 权重过大时颜色拟合不足，过小时几何松散。第四类是采样与范围问题：近远平面截断导致表面缺块，采样数不足导致权重积分方差大。

逐项对照可以看到一个规律：NeRF 的失败是「几何不可靠」，IDR 的失败是「输入不可得或表示不覆盖」，VolSDF/NeuS 的失败是「调度与数值的边界」。这三类失败的工程应对完全不同：第一类要靠增加视角或改损失，第二类要靠换表示或补输入，第三类要靠调退火曲线与正则权重。论文自述的局限——训练慢、薄结构难、与 NeuS 差异在实际中不大——正好落在第三类。其中「与 NeuS 差异在实际中不大」是一条重要的工程判断：它意味着选型时不必在两者之间做精细的数值比较，而应看生态、实现成熟度与超参可调性。两者共同把「SDF + 体渲染」变成标准范式，后续神经表面重建工作常以两者为基线，这说明它们的失败模式也成了后续方法要绕开的默认障碍。

一个具体机制上的失败例子：薄结构在 β 退火末期的表现可以用权重函数 w(t)=T(t)α(t) 分析。当结构厚度 d 小于 β 时，射线穿过结构时先遇到外侧表面（α 上升），再遇到内侧表面（α 再次上升），但两段过渡带在 f 轴上重叠，导致 α 在结构内部也保持较高值，透射率 T 在穿过第一层后已大幅衰减，第二层的权重被压制，最终渲染颜色接近「单层厚表面」，几何上表现为结构被填实或合并。这个机制在 VolSDF 与 NeuS 上都存在，只是触发阈值不同。工程上的缓解是让 β 的最终值不小于目标最薄结构的尺度，代价是表面锐度下降——这是一个显式的精度-尺度权衡，必须在验收断言里写清楚。
