一 · 数据集与评测协议：四个域、三条基线、一个分辨率锚点

EG3D 的实验设计围绕一个判断展开：三平面表示是否真的能在保持 2D 卷积可扩展性的同时，产出视角一致的 3D 物体。要回答这个问题，评测集必须覆盖两类截然不同的数据——一类是近似刚性、几何结构清晰的物体，另一类是人脸这种高频细节密集但几何自由度受限的域。论文选取的四个数据集正好构成这个谱系：FFHQ 代表人脸，AFHQ 代表动物面部，ShapeNet 代表合成刚体（汽车、椅子），CompCars 代表真实车辆。这四个域的共同点是都存在明确的相机分布，可以采样姿态条件；差异在于几何复杂度与纹理复杂度不同，因此能暴露三平面表示在不同数据分布下的行为差异。

基线选择同样有针对性。StyleNeRF、pi-GAN、GIRAFFE 三者都是 2021 年前后以隐式场为核心的 3D 感知生成模型，它们的共同瓶颈在于：要么用大 MLP 逐点查询导致渲染慢，要么用体素表示导致显存随分辨率立方增长。EG3D 把这三者作为对照，实质是在问——把 3D 场的计算负担从体素/大 MLP 转移到 2D 卷积之后，质量是否还能超过这些以纯隐式场为主的方案。评测指标以 FID 为主，辅以渲染分辨率这一硬性指标：FFHQ 上达到 512×512，这是一个在 3D GAN 语境下具有区分度的分辨率锚点，因为同期多数 3D 感知 GAN 要么停留在较低分辨率，要么渲染速度不足以支撑高分辨率出图。

评测协议里有一个容易被忽略但影响结论的机制：相机分布采样。判别器是 2D CNN，它看到的是渲染图，而渲染图由采样相机决定。若相机分布与真实数据集的拍摄分布不匹配，判别器会把渲染伪影误判为真实分布内的变化，从而削弱 3D 一致性约束。EG3D 的做法是在训练中对相机姿态进行采样并可作为条件输入，使得生成器在不同视角下都被同一 2D 判别器审视。这个机制的直接代价是训练时间拉长——论文定性表述为训练数天、单卡可跑，说明其计算预算被控制在可复现范围内，而不是靠大规模集群堆出来的。这也解释了为什么消融实验必须单独考察姿态条件的影响：它不是一个可有可无的正则项，而是 3D 一致性信号能否被 2D 判别器有效传递的前提。

数据集域类型几何/纹理特征评测关注点
FFHQ人脸高频纹理密集、几何自由度受限FID、512×512 渲染质量
AFHQ动物面部姿态多样、毛发细节视角一致性与纹理保真
ShapeNet合成刚体拓扑清晰、视角可精确控制汽车/椅子的视角一致性
CompCars真实车辆真实拍摄分布、反射与材质真实域下的几何合理性

这张表的意义不在于罗列，而在于说明每个数据集承担不同的证伪职责：ShapeNet 用来验证几何与视角一致性，因为合成刚体的正确视角可以由相机参数精确界定；FFHQ 用来验证高频细节与 FID，因为人脸纹理是最容易被 2D 卷积擅长的部分；CompCars 与 AFHQ 则把结论从合成域推向真实域。若只在 ShapeNet 上报告视角一致性，结论会被质疑为“只对干净合成数据有效”；四个域并列，正是为了堵住这条退路。

二 · 主要结果：提升来自 2D 卷积承担高频、三平面承担共享

FFHQ 上的核心结果是 FID 优于 StyleNeRF，同时渲染分辨率达到 512×512。这两个数字必须放在一起读：单独看 FID，一个低分辨率模型也可能刷出好看的数字；单独看分辨率，一个高分辨率模型也可能视角不一致。EG3D 同时拿下两者，说明它的提升不是靠牺牲其中一项换来的。机制上，这个提升可以拆成两条来源。第一条来源是生成器主干：StyleGAN2 的 2D 卷积在 256×256×32 的三平面特征上生成高频细节，2D 卷积的归纳偏置天然适合纹理，这与纯隐式 MLP 逐点查询时高频信号难以高效生成形成对比。第二条来源是三平面共享：三个正交平面在查询 3D 点时被双线性插值后拼接，同一个 3D 点在不同视角下的特征来自同一组平面，这构成了 3D 一致性的表示层约束。

$$G(\mathbf{z})=\mathrm{TriPlane}_\theta(\mathbf{z}),\qquad F(\mathbf{x})=\mathrm{MLP}\!\left(\mathrm{interp}(T_{xy},\mathbf{x}),\mathrm{interp}(T_{xz},\mathbf{x}),\mathrm{interp}(T_{yz},\mathbf{x})\right)$$

这条公式里的每个符号都对应一处工程代价。$\mathrm{TriPlane}_\theta(\mathbf{z})$ 由 StyleGAN2 主干产出三张 256×256×32 的平面特征，显存占用是 $3\times256\times256\times32$ 量级的特征图，与体素表示随分辨率立方增长形成鲜明对比——这是 EG3D 能把分辨率推到 512×512 的直接原因。$\mathrm{interp}$ 是双线性插值，它对每个 3D 点做三次独立插值再拼接，查询成本与点数线性相关，而不是与体素分辨率立方相关。最后的 2 层 MLP 只负责把拼接特征解码为密度与 RGB，容量很小，因此高频细节的生成责任被前移到 2D 卷积，而不是压在小 MLP 上。这个分工是“提升来自哪里”的答案：高频来自 2D 卷积的可扩展性，一致性来自三平面的共享插值，两者各司其职。

ShapeNet 上的结果则换了一个证据类型：能生成视角一致的汽车与椅子。这里的关键不是 FID，而是视角一致性——同一潜在码在不同相机姿态下渲染出的物体，其几何结构应保持稳定。三平面表示天然支持这一点，因为 3D 点的特征由三个平面的插值拼接决定，与观察视角无关；视角只影响体渲染的积分路径与投影。换句话说，一致性被编码进了表示结构，而不是靠判别器事后纠正。但这也暴露了一个失败模式：三平面的固定拓扑意味着它只能表达三个正交平面能覆盖的几何，对于拓扑复杂或存在自遮挡歧义的物体，插值拼接会抹平细节，几何精度因此有限。论文对此的定性表述是“固定拓扑与几何精度有限”，这不是谦辞，而是表示本身的容量边界。

把 FFHQ 与 ShapeNet 的结果并置，可以看出提升的分布并不均匀：在纹理密集、几何自由度受限的人脸域，2D 卷积的高频优势被最大化；在几何结构清晰的合成刚体域，三平面的共享插值优势被最大化。反过来，若数据域的几何复杂度超出三平面容量，提升就会收窄。这个判断对工程选型有直接意义：三平面不是万能表示，它的收益上界由“几何能否被三个正交平面近似”决定。

三 · 消融一：三平面 vs 单平面 vs 体素，容量与代价的三角权衡

消融实验的第一组对比是三平面、单平面与体素三种表示。这组对比的设计逻辑是控制变量：保持生成器主干与判别器不变，只替换 3D 场的参数化方式，观察质量与代价如何变化。单平面是容量下界——它只能表达一个方向的切片特征，查询 3D 点时缺失另外两个正交方向的约束，几何一致性会明显退化。体素是代价上界——它的显存随分辨率立方增长，在相同分辨率下无法与三平面竞争，若强行匹配分辨率则训练预算爆炸。三平面处在两者之间：容量足以覆盖三个正交方向的共享约束，代价保持在 2D 特征图的量级。

从机制上看，三平面的容量来自“三个平面各自贡献一个正交投影，拼接后由小 MLP 融合”。单平面缺失两个投影，等于把 3D 问题退化成 2D 切片问题，视角一致性失去表示层支撑；体素则把每个 3D 点独立存储，容量最大但代价也最大，且 2D 卷积无法直接在体素上高效生成高频——这正是论文背景里指出的痛点：体素表示显存立方增长，纯隐式 MLP 又难以用 2D 卷积高效生成高频细节。三平面的工程判断是：用三个 2D 平面近似 3D 场，牺牲一部分几何精度，换取 2D 卷积的可扩展性与可控显存。

$$\text{cost}_{\text{voxel}}\propto N^3,\qquad \text{cost}_{\text{triplane}}\propto 3\times H\times W\times C$$

这条代价对比是消融结论的量化骨架：体素代价随分辨率 $N$ 立方增长，三平面代价只随平面边长 $H,W$ 与通道数 $C$ 线性（乘以 3）增长。在 256×256×32 的平面特征下，三平面的特征张量规模是固定的，与查询的 3D 点数量解耦；体素则必须为每个分辨率级别分配完整体积。这解释了为什么三平面能在单卡上训练数天，而体素方案在同等分辨率下难以复现。失败模式也随之明确：三平面的固定拓扑意味着它无法表达平面覆盖不到的几何结构，比如薄壳、镂空或强自遮挡的细节；单平面则连基本的视角一致性都难以维持。消融的价值不在于证明三平面全面胜出，而在于标定它的容量边界——在边界内，它用远低于体素的代价换取了可接受的几何精度。

一个具体的对照场景可以说明这组消融的工程含义：在 ShapeNet 的汽车上，车身的主平面、侧面与顶面恰好与三个正交平面近似对齐，三平面能用较低的代价捕捉主要几何；但车轮的辐条、后视镜的薄片这类结构，在平面插值下会被平滑掉。体素能保留这些细节，代价是显存立方增长；单平面则连车身的主方向都难以稳定。三平面的定位因此清晰：它是“几何可被三个正交平面近似”这一假设下的高效解，而不是通用高精度几何表示。

四 · 消融二：2D 判别器 vs 3D 判别器，一致性信号从哪来

第二组消融对比 2D 判别器与 3D 判别器。这个对比直指 EG3D 的一个设计选择：判别器是 2D CNN，而不是在 3D 空间里做判别的 3D 网络。选择 2D 判别器的理由是计算效率——2D 卷积在渲染图上操作，与生成器主干共享同一套可扩展性；3D 判别器则需要在体积数据上卷积，代价随分辨率立方增长，与体素表示的痛点同源。但 2D 判别器带来一个结构性风险：它只看单张渲染图，无法直接比较不同视角之间的一致性。若没有额外约束，生成器可以针对每个视角分别“画”出看起来合理的图，而几何在视角间并不自洽。

EG3D 用两个机制堵住这个风险。第一个是三平面共享：同一个 3D 点的特征由三个平面的插值拼接决定，与视角无关，因此不同视角的渲染天然共享同一几何底稿。第二个是相机分布采样与姿态条件：训练时对相机姿态采样，判别器在不同视角下审视同一潜在码的渲染，迫使生成器在视角变化时保持结构稳定。消融实验考察姿态条件的影响，实质是在验证第二个机制是否必要——若去掉姿态条件，2D 判别器失去跨视角的约束锚点，一致性信号会退化。这组消融的结论指向一个工程判断：2D 判别器的效率优势必须由表示层的共享结构与姿态条件共同兜底，三者缺一不可。

失败模式在这里很具体：2D 判别器容易被渲染伪影欺骗。体渲染的积分近似、平面插值的平滑效应、以及视角边缘的采样不足，都会在渲染图上留下判别器可能误判的痕迹。若判别器容量不足以区分这些伪影与真实分布内的变化，生成器就会利用它们。3D 判别器理论上能直接看到体积结构，但代价是立方增长的显存与卷积成本，在 512×512 渲染分辨率下不可行。EG3D 的选择是用 2D 判别器换取可扩展性，再用三平面共享与姿态条件补偿一致性——这是一次明确的权衡，而不是无代价的胜利。消融实验的作用就是把这次权衡的边界画出来：在什么条件下 2D 判别器足够，在什么条件下它需要表示层兜底。

五 · 消融三：姿态条件的影响与训练配方的耦合

第三组消融考察姿态条件的影响。姿态条件在架构上体现为相机分布采样与条件输入：生成器与判别器都可以接收姿态信息，使得同一潜在码在不同姿态下的渲染被显式关联。这个机制的作用不是提升单视角的图像质量，而是把“视角一致性”从一个隐含期望变成训练信号的一部分。若去掉姿态条件，生成器仍可借助三平面共享获得一定程度的一致性，但判别器失去跨视角的显式锚点，一致性约束会变弱，尤其在相机分布宽泛的数据集上（如 AFHQ 的动物面部姿态多样）退化更明显。

姿态条件与训练配方是耦合的。论文的训练配方包含 R1 正则、路径长度正则与相机分布采样。R1 正则约束判别器在真实样本附近的梯度，抑制判别器过强导致的训练震荡；路径长度正则约束生成器对潜在码的响应平滑性，避免潜在空间中的突变导致视角间跳变；相机分布采样则决定判别器看到哪些视角。三者共同构成一个平衡：R1 防止判别器压倒生成器，路径长度正则防止生成器在视角间产生不连续结构，姿态条件把两者与 3D 一致性目标对齐。消融若只单独去掉姿态条件而不调整其他正则，结论会被混淆——这正是消融实验需要控制变量的原因。

$$\mathcal{L}=\mathcal{L}_{\text{adv}}+\lambda_{\text{R1}}\mathcal{L}_{\text{R1}}+\lambda_{\text{path}}\mathcal{L}_{\text{path}},\qquad \mathbf{c}\sim p(\text{camera})$$

这条训练目标的骨架说明姿态条件不是一个孤立的开关，而是与正则项共同作用的系统。工程代价体现在训练时间上：相机分布采样意味着每个训练步要渲染多个视角或至少在不同步之间切换视角，渲染成本随采样策略上升；论文定性表述为训练数天、单卡可跑，说明这个代价被控制在可接受范围内，但它确实比单视角 2D GAN 的训练更重。失败模式则是姿态条件与数据分布不匹配：若采样相机分布与真实数据的拍摄分布偏离，判别器会把分布外视角的渲染误判，生成器随之学到错误的几何先验。这个失败模式在 CompCars 这类真实拍摄数据集上尤其需要警惕，因为真实车辆的拍摄视角分布并不均匀。

把三组消融放在一起看，提升的来源可以被分解为三个可分离的贡献：三平面提供容量与代价的平衡点，2D 判别器提供可扩展的对抗信号，姿态条件把一致性约束显式化。任何一项缺失，系统都会退化到某个已知的失败模式——单平面失去一致性，体素失去可扩展性，无姿态条件失去跨视角锚点。消融实验的证据价值正在于这种可分离性：它让“提升来自哪里”不再是一句笼统的断言，而是可以被逐项定位的工程结论。

六 · 证据的边界：固定拓扑、几何精度与 2D 判别器依赖

实验证据的边界由三个局限划定，而这三个局限恰好对应三组消融的反面。第一是固定拓扑：三平面的三个正交平面构成固定的参数化结构，无法表达平面覆盖不到的几何，因此几何精度有限。这不是训练不充分的问题，而是表示容量的上界——增加平面分辨率或通道数只能细化平面内的细节，不能突破正交平面的结构假设。第二是几何精度有限：在 ShapeNet 的汽车与椅子上，主结构可以被三平面捕捉，但薄壳、镂空、强自遮挡的细节会被插值平滑。第三是依赖 2D 判别器：一致性信号最终要靠 2D 判别器在渲染图上审视，若判别器被渲染伪影欺骗，表示层的共享结构也无法完全兜底。

这三个局限的工程含义是：EG3D 的适用域是“几何可被三个正交平面近似、纹理高频占主导、相机分布可采样”的数据。在这个域内，它用 2D 卷积的可扩展性换取了高分辨率与视角一致性，代价是几何精度；在域外，它的提升会收窄甚至失效。论文没有编造跨域的普适性，而是用四个数据集与三组消融把适用域画出来。这种证据组织方式本身就是一种工程判断：与其宣称通用性，不如标定边界，让后续工作知道在哪里继承、在哪里替换。

影响层面的证据同样落在这个边界上。EG3D 的三平面成为 3D 生成的标准中间表示，LRM、TripoSR 等前馈重建模型直接继承 triplane，只是把生成器换成图像条件 Transformer。这个继承关系说明三平面的价值不在 GAN 本身，而在表示的可复用性：三个正交平面加小 MLP 解码的结构，既能被 2D 卷积生成，也能被图像条件 Transformer 预测，且查询成本与点数线性相关。继承的同时，局限也被继承——前馈重建模型同样受固定拓扑与几何精度上界的约束，只是把对抗训练换成了回归训练，把相机分布采样换成了输入图像的条件。这条继承链是 EG3D 实验证据最持久的产出：它证明的不是某个 FID 数字，而是一个表示结构在生成与重建两条路径上的可迁移性。

回到实验本身，最有信息量的不是 FFHQ 上 FID 优于 StyleNeRF 这一条结论，而是这条结论与 512×512 分辨率、ShapeNet 视角一致性、三组消融共同构成的证据网络。单条结果可以被质疑，但四条证据互相支撑：分辨率证明可扩展性，视角一致性证明表示层约束有效，消融证明贡献可分离，局限证明边界被诚实标定。这个网络的结构决定了后续工作的引用方式——继承 triplane 的模型引用的是表示结构，比较 FID 的工作引用的是评测协议，而讨论几何精度的工作引用的是局限。实验部分的工程价值，就在于它把这三类引用各自锚定到了具体的机制与代价上。
