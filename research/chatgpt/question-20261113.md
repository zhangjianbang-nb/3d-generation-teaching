# 3D AI 生成调研：方向划分与演进主线（外部评审问题）

我在做一份「3D AI 生成算法」的工程向调研与教学材料，读者是有后端/训练经验的工程师。论文库 49 篇（2020–2025），按「解决什么问题」分成 8 个方向：

1. d3-scene-recon 场景重建与可微渲染（NeRF / Instant-NGP / 3DGS / SDF 表面）
2. d3-native-rep 3D 原生表示与生成（点云/体素/三平面/高斯/神经场作为生成对象）
3. d3-sds 优化式蒸馏（SDS / SJC / VSD / ISM / DreamFusion / ProlificDreamer）
4. d3-multiview 多视图扩散与一致性（Zero-1-to-3 / MVDream / SyncDreamer / Wonder3D / Hi3DGen）
5. d3-feedforward 前馈 3D 大模型（LRM / TripoSR / InstantMesh / CRM / GS-LRM / MeshLRM / LGM / SF3D / Direct3D / TRELLIS / Hunyuan3D 2.x / CraftsMan3D / Step1X-3D）
6. d3-mesh-topo 网格、拓扑与部件（MeshGPT / MeshAnything / MeshAnything V2 / PartCrafter）
7. d3-scene-world 场景、世界与物理（Text2Room / WonderWorld / WorldGen / SceneCraft / PhysDreamer）
8. d3-data-production 数据、材质与生产化（Objaverse / Objaverse-XL / PBR / UV / 光照解耦 / 数据 scaling）

演进主线我写成五段：
- 2020–2021：可微渲染把 2D 监督变成 3D 几何（NeRF、SDF/NeuS、Instant-NGP 加速）
- 2022–2023：预训练 2D 扩散当「3D 监督器」（SDS、多视图扩散），以及 3D 原生扩散（Point-E、MeshDiffusion）
- 2023–2024：3DGS 把表示换成显式高斯，前馈 LRM 把「逐场景优化」换成「一次前向」
- 2024–2025：三平面/高斯/网格输出头统一到 Transformer 骨干；SLAT 稀疏体素+DiT；PBR 与 UV 进入生成目标
- 2025–：从「物体生成」走向「场景/世界生成」，物理与可交互性成为新瓶颈；数据与评测成为最大短板

我的几个判断，请逐条批：
A. 「3D 生成的核心矛盾是 3D 监督信号稀缺」——所以 SDS/多视图/前馈三条路线本质都是在「造监督」。
B. 「前馈模型的上限由 3D 数据规模与质量决定，而不是由骨干网络决定」——2024 后架构收敛，数据成为分水岭。
C. 「多视图一致 ≠ 3D 正确」——多视图扩散能保证视角间自洽，但不保证度量尺度、背面几何与物理可交互。
D. 「SDS 的偏置来自 2D 分数函数的维度错配，VSD/ISM 只是降低方差，不消除偏置」。
E. 「网格生成（MeshGPT/MeshAnything）与前馈重建（LRM/TRELLIS）最终会合流为『生成 + 重拓扑 + 材质』三段式管线」。

请回答：
1. 这 8 个方向的划分有没有明显遗漏或重叠？如果有，给出你建议的合并/拆分，并说明理由。
2. 五段演进主线有没有史实错误、时间线错位或因果倒置？逐条指出。
3. 判断 A–E 哪些成立、哪些过强或过弱？给出反例论文（标题+年份即可）。
4. 如果只保留 3 个方向给新工程师入门，你选哪 3 个、按什么顺序？
5. 你认为 2026 年最可能改变这条主线的技术变量是什么（数据、表示、物理、评测、硬件）？
